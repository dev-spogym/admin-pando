# D05 상품관리 도메인 인덱스

이 도메인은 센터에서 판매하는 모든 상품(이용권·PT 수강권·GX 수강권·골프 이용권·락커 부가서비스·패키지 상품·단일 판매 상품)의 마스터 운영, 할인 정책, 카탈로그 노출, 비교 도구, 재고 관리, 시즌 가격 자동화를 책임집니다. 상품 마스터는 결제처리·매출통계·KPI 대시보드·회원앱·키오스크가 모두 참조하는 단일 정본(Single Source of Truth)으로 동작합니다.

## 도메인 핵심 운영 정책

상품 분류 체계는 1단계 대분류(MEMBERSHIP/PT/GX/PRODUCT/SERVICE)와 2단계 세부종목의 2단계 체계이며, GX 세부종목은 시스템 고정 6종(요가·필라테스·스피닝·줌바·에어로빅·GX 기타)입니다. 이 6종은 상품 등록·매출통계·KPI 대시보드에서 동일한 키로 사용됩니다.

상품 마스터는 모든 도메인의 단일 정본으로 결제처리·매출통계·KPI 대시보드·카탈로그·회원앱·키오스크가 참조합니다.

운영 정책 구분 5종(단일지점·법인·홈&오피스·주말·통합)은 회원권 계열 상품에 필수이며 다지점 운영의 기본값을 결정합니다.

판매 이력 보호 정책은 판매 이력이 있는 상품의 완전 삭제를 차단하고 미사용 비활성 전환으로 분기하여 회원의 이용권을 만료일까지 보호합니다.

가격 변경 자동 기록 정책은 모든 가격 변경을 `price_history`에 자동 INSERT 하고 카탈로그·키오스크·결제 화면을 5분 캐시 무효화로 동기화합니다.

전 지점 배포는 슈퍼관리자만 가능하며 본사 표준 상품을 일괄 복제하고 지점별 차등 가격은 배포 후 개별 수정으로 처리합니다.

할인 우선순위는 시즌가격 → 할인 → 쿠폰 → 마일리지 순으로 적용되며 중복 정책 토글(중복 허용/단독/큰 것만)로 결합 방식을 명시합니다.

시즌 가격 자동 활성/비활성은 매시 정각 Cron 배치로 처리되며 시작일 도래 시 자동 활성, 종료일 23:59 자동 비활성입니다.

재고 관리는 실물 상품(PRODUCT/GENERAL)에 한정되며 POS 결제 완료 시 자동 차감되고 안전 재고 미달 시 NFR-19 알림 센터로 발주 알림이 발송됩니다.

카탈로그 정본 정책은 어드민·외부 공유·회원앱이 동일한 정본을 사용하여 가격·이미지·노출이 일관되게 보이도록 합니다.

감사 로그 정책은 모든 등록·수정·삭제·비활성·배포·재고 이벤트가 SCR-097 감사 로그에 비동기로 INSERT 되어 5초 안에 조회 가능해야 합니다.

## 도메인 간 연계

상품 마스터 변경 → 결제처리(SCR-S003) 즉시 반영, 매출통계(SCR-S004) 분류축 갱신, KPI 대시보드(SCR-094) GX 세부종목 분포 자동 확장, 카탈로그(PRD-05) 노출 자동 갱신, 회원앱·키오스크 5분 캐시 무효화.

할인 정책 변경 → 결제 화면 자동 적용 대상 회원 즉시 반영, 시즌 가격과의 우선순위 결합, 변경 이력 타임라인 + 감사 로그 INSERT.

시즌 가격 진행 → 카탈로그·키오스크 자동 강조("할인" 배지·정상가 취소선·특가), 결제 시점 가격 락인, 매출통계 시즌별 매출·할인액·전환율 집계.

재고 관리 → POS 결제 완료 시 자동 차감, 안전 재고 미달 NFR-19 알림 센터 발송, 카탈로그·키오스크 "품절" 배지 자동 표시.

모든 도메인 이벤트 → SCR-097 감사 로그에 5초 안에 비동기 INSERT, 사후 추적 가능.

## 문서 정합성 기준

각 화면과 다이얼로그 문서는 자기완결형으로 작성되어 다른 문서를 함께 보지 않아도 그 화면 한 장만으로 모든 영역·버튼·모달·권한·예외·운영 정책을 이해할 수 있도록 작성되었습니다. 정책이 바뀌면 관련 문서가 함께 갱신되어야 하며, 코드 변경과 정책 변경은 항상 짝지어 진행됩니다.
