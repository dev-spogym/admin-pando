## 2. 다이얼로그 개요와 목적

비활성화 안내 모달은 누적 판매 이력이 있는 상품을 삭제하려고 할 때 자동으로 분기되는 안전 모달입니다. 판매 이력이 있는 상품은 완전 삭제가 불가능하므로 "미사용" 상태로 비활성 전환하여 신규 판매는 차단하면서 기존 보유 회원의 이용권은 만료일까지 유지되도록 합니다.

이 모달은 회원 보호 정책의 핵심 가드 역할을 하며, 운영자가 보유 회원 수를 정확히 인지한 상태에서 비활성 전환을 결정하도록 합니다. 비활성 전환 후 카탈로그와 키오스크에서 자동으로 제외되고 결제 화면에서 선택이 차단됩니다.

## 3. 호출 트리거와 진입 경로

SCR-P003 상품 상세 패널 또는 SCR-P002 수정 모드의 "삭제" 버튼을 누른 직후 시스템이 누적 판매 이력을 확인합니다. 1건 이상 발견되면 자동으로 이 모달이 호출됩니다. 0건이면 DLG-P003 상품삭제확인이 호출되고, 패키지 구성 상품으로 사용 중이면 별도 안내가 표시됩니다.

권한이 없는 계정에서는 삭제 버튼이 보이지 않아 모달 호출 자체가 차단됩니다.

## 4. 레이아웃과 UI 구성

모달은 화면 중앙의 작은 크기로 표시되며 배경은 어둡게 처리됩니다.

모달 상단에는 "이용 중 회원이 있어요"라는 주황 톤 제목과 정보 아이콘이 표시됩니다.

본문에는 대상 상품명과 함께 "현재 이용 중 회원 {인원수}명이 있어 완전 삭제는 불가능합니다. 미사용 상태로 전환할까요?"라는 안내가 표시됩니다. 비활성 전환의 효과를 설명하는 부가 안내가 작은 글씨로 함께 표시됩니다: "신규 판매는 차단되지만 기존 보유 회원의 이용권은 만료일까지 정상 사용됩니다. 카탈로그와 키오스크에서도 자동 제외됩니다."

하단에는 두 개의 버튼이 있습니다. 좌측은 "취소" 버튼(변경 없음), 우측은 "미사용 전환" 버튼(주황 톤)입니다. 위험도가 빨강보다 낮은 주황 톤으로 표시되어 회원 보호 안전 장치임을 시각적으로 알립니다.

## 5. 입력 검증과 저장 규칙

이 모달은 추가 입력이 없는 단순 확인 모달입니다.

"미사용 전환" 버튼 클릭 시 `POST /api/products/:id/deactivate`가 호출되어 `isActive`가 false로 변경됩니다. 응답에는 영향을 받는 보유 회원 수가 포함되어 부모 화면에 비활성 배지와 함께 갱신됩니다.

비활성 전환은 신규 판매만 차단하고 기존 보유 회원의 이용권은 만료일까지 유지됩니다. 카탈로그(PRD-05)와 키오스크에서 5분 내에 자동으로 제외되며 결제 화면에서 선택이 차단됩니다.

비활성 전환 시 Owner(지점장)에게는 NFR-19 알림 센터로 보유 회원 수 알림이 발송됩니다.

감사 로그에는 `actor_id, product_id, action='DEACTIVATE', before, after, affected_member_count`가 INSERT 됩니다.

## 6. 주요 UX 흐름

1. 운영자가 상세 패널 또는 수정 모드에서 삭제 버튼 클릭
2. 시스템이 판매 이력 확인 → 1건 이상이면 이 모달 호출
3. 모달에 보유 회원 수와 비활성 전환 효과 안내 표시
4. 운영자가 "미사용 전환" 선택 → POST deactivate 호출 → 부모 화면에 비활성 배지로 갱신
5. 카탈로그·키오스크 5분 캐시 무효화로 자동 제외
6. Owner(지점장)에게 NFR-19 알림 발송
7. 운영자가 "취소" 선택 → 모달 닫힘 + 변경 없음

## 7. 화면 상태와 예외 처리

기본 표시 상태에서는 보유 회원 수와 비활성 전환 효과 안내가 표시됩니다.

전환 진행 중 상태에서는 "미사용 전환" 버튼이 로딩 스피너로 전환됩니다.

전환 실패 상태에서는 빨강 토스트가 뜨고 모달은 닫히지 않으며 재시도가 가능합니다.

이미 비활성 상태에서 호출 시도는 차단되어 "이미 비활성 상태입니다" 안내가 표시되고 모달이 닫힙니다.

예외 케이스별 처리는 다음과 같습니다. 보유 회원 수 조회 실패는 "회원 정보를 불러올 수 없어요" + 재시도 버튼입니다. 권한 없음(403)은 "권한이 없어요" 토스트와 함께 모달이 닫힙니다. 동시 전환 충돌은 낙관적 락으로 처리됩니다.

## 8. 권한별 처리

비활성 전환 권한이 있는 슈퍼관리자·Owner(지점장)·매니저·상품 편집 권한자만 부모 화면에서 삭제 버튼이 보이므로 모달 호출이 가능합니다. 일반 직원과 readonly는 삭제 버튼 자체가 보이지 않습니다.

매니저는 비활성 전환은 가능하지만 완전 삭제는 차단됩니다. 이 모달은 매니저에게도 호출 가능합니다.

## 10. 운영 정책 (이 다이얼로그에 연결된 부분)

판매 이력 보호 정책은 판매 이력이 1건 이상인 상품의 완전 삭제를 차단하고 비활성 전환만 허용한다는 것입니다.

회원 보유 이용권 유지 정책은 비활성 전환 시 신규 판매만 차단되고 기존 보유 회원의 이용권은 만료일까지 정상 사용된다는 것입니다.

카탈로그·키오스크 자동 제외 정책은 비활성 전환 후 5분 내에 자동으로 제외되어 회원과 직원이 신규 결제할 수 없게 된다는 것입니다.

보유 회원 수 안내 정책은 운영자가 비활성 전환의 영향을 정확히 인지하도록 영향을 받는 회원 수를 명시적으로 표시한다는 것입니다.

NFR-19 알림 정책은 비활성 전환 시 Owner(지점장)에게 보유 회원 수 알림이 발송되어 사후 회원 응대를 준비할 수 있도록 합니다.

복구 가능 정책은 비활성 상품을 다시 활성으로 전환할 수 있다는 것입니다. 신규 판매가 재개되며 카탈로그·키오스크에 다시 노출됩니다.

감사 로그 정책은 비활성 전환 이벤트가 SCR-097에 `actor_id, product_id, action='DEACTIVATE', before, after, affected_member_count`로 INSERT 된다는 것입니다.

권한 정책은 슈퍼관리자·Owner(지점장)·매니저·상품 편집 권한자가 모달 진입과 비활성 전환이 가능하다는 것입니다.

이상의 모든 정책은 이 다이얼로그를 구현하고 운영하는 사람이 별도 문서 없이 이 한 장만 보면 이해할 수 있도록 풀어 적었습니다.
