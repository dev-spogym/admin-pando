## 2. 화면 개요와 목적

상품 상세/수정 패널은 상품 목록(SCR-P001)에서 상품을 클릭하면 화면 우측에서 슬라이드로 나타나는 상세 패널입니다. SCR-P002 상품 등록(신규)과 같은 입력 UI를 공유하되, 이 화면은 기존 상품 값이 채워진 상태로 열려 운영자가 패널 내부에서 직접 편집·저장·삭제·비활성 전환을 처리합니다. 별도의 상품 수정 전용 모달이나 별도 화면으로 전환하지 않고, 패널 그 자체가 수정 폼이 됩니다. 상품의 모든 설정값(기본 정보·요일·시간·옵션·패키지)을 한눈에 확인하고 즉시 변경할 수 있으며, 가격 변경 이력을 조회하거나 카탈로그 미리보기를 띄울 수 있습니다. 누적 판매 건수와 회원별 보유 현황, 최근 가격 변경 타임라인을 함께 확인하여 가격 인상 검토, 단종, 재고 회전 같은 운영 의사결정을 지원합니다.

이 화면이 다루는 운영 흐름은 다음과 같습니다. 카운터 매니저는 회원의 상품 문의를 받았을 때 목록에서 상품 행을 클릭해 패널을 열고 가격·옵션·기간·홀딩/양도 정책을 즉시 확인하며, 가격 인상을 검토하는 Owner(지점장)은 패널의 가격 이력 + 누적 판매 + 최근 30일 판매를 함께 보고 가격 변동률 vs 판매량 추세를 비교한 뒤 패널에서 바로 현금가·카드가를 변경해 저장합니다. 단종 후보를 식별하는 매니저는 누적 판매 0건 + 등록 후 90일 경과 상품을 찾아 패널의 삭제 버튼으로 비활성 전환을 진행하고, FC는 패널의 만료 임박 {인원수}명을 눌러 회원 검색(SCR-M001)으로 자동 점프해 만료자 리스트를 추출한 뒤 재구매 권유 메시지를 발송합니다. 패키지 상품을 점검하는 매니저는 구성 상품 링크를 차례로 눌러 개별 상품 상세를 확인하고, 본사 슈퍼관리자는 다중 지점에서 같은 상품 패널을 비교해 지점별 가격 차등을 식별합니다.

패널 내부에는 저장(수정)·삭제·카탈로그 미리보기·비교 추가의 네 가지 액션이 있으며, 삭제는 누적 판매 이력에 따라 DLG-P003 상품삭제확인 또는 DLG-P004 비활성화안내로 자동 분기됩니다. 가격 이력의 전체 50건 이상은 DLG-P008 가격이력조회 다이얼로그에서 페이지네이션으로 확인합니다. 입력 변경이 있는 상태에서 닫기·다른 행 클릭 시 DLG-P002 작업취소확인이 호출되어 변경 사항 손실을 방지합니다.

가격이 변경되어 저장되면 `price_history` 테이블에 자동으로 INSERT 되며, 동시에 다른 사용자가 같은 상품을 수정 중이었으면 낙관적 락(`updated_at` 비교)으로 충돌이 감지되어 "최신 정보 보기" / "덮어쓰기" 선택지가 제공됩니다.

## 3. 진입 경로와 인접 화면

이 화면에 진입하는 경로는 세 가지입니다.

첫 번째 경로는 SCR-P001 상품 관리에서 상품 행을 클릭하는 것입니다. 클릭 시 본문이 55%로 축소되면서 우측에 45% 폭의 패널이 슬라이드 인 됩니다. 두 번째 경로는 `/products/detail/:id` 직접 URL입니다. 외부 도구나 북마크로 공유된 특정 상품 상세 링크로 진입하며 동일한 패널 내용이 단독 화면으로 표시됩니다. 세 번째 경로는 다른 패널에서 패키지 구성 상품 링크를 클릭하는 것입니다. 패키지 상품 패널의 구성 상품을 누르면 현재 패널이 닫히고 그 구성 상품의 패널이 새로 열립니다.

이 화면에서 다시 빠져나가는 인접 화면으로는, 저장 완료 후 자동으로 갱신되는 SCR-P001 상품 관리 목록, 입력 변경 후 닫기 시 호출되는 DLG-P002 작업취소확인, 삭제 액션이 호출하는 DLG-P003 상품삭제확인 또는 DLG-P004 비활성화안내, 카탈로그 미리보기 액션이 호출하는 SCR-P005 카탈로그 카드 미리보기, 비교 추가 액션으로 이동하는 SCR-P006 상품 비교(현재 상품 자동 추가), 가격 이력 전체 보기로 진입하는 DLG-P008 가격이력조회, 만료 임박 회원 클릭 시 점프하는 SCR-M001 회원 검색(해당 상품 보유자 자동 필터)이 있습니다. 슈퍼관리자에게는 패널에서 SCR-097 감사 로그로 점프하는 "감사 로그 보기" 링크가 추가로 노출됩니다.

## 4. 레이아웃과 UI 구성

상품 상세/수정 패널은 우측 슬라이드 패널일 때 화면 우측 45% 폭, 단독 화면일 때 중앙 정렬된 컨테이너에 같은 내용을 표시합니다. 본 패널은 조회만 가능한 정적 패널이 아니라 입력 가능한 폼 패널이며, 모든 항목은 기존 상품 값으로 자동 채워진 상태에서 운영자가 직접 변경할 수 있습니다. 위에서 아래로 다음 영역들이 차례로 배치됩니다.

가장 위에는 헤더 영역이 있습니다. 좌측에 "상품수정" 제목과 상품명이 표시되고 그 옆에 활성/비활성 배지(사용은 녹색, 미사용은 회색)가 따라옵니다. 비활성 상품을 조회한 경우 헤더 아래에 회색 배너로 "이 상품은 미사용 상태입니다, 신규 판매 불가"라는 안내가 표시됩니다. 헤더 우측에는 닫기(X) 버튼이 있고, 입력 변경 사항이 있는 상태에서 누르면 DLG-P002 작업취소확인 모달이 먼저 뜨고, 변경 사항이 없으면 즉시 슬라이드 아웃되며 본문 가로폭이 100%로 복원됩니다.

헤더 바로 아래에는 이미지 갤러리 영역이 있습니다. 등록된 이미지 1~5장이 가로 슬라이드 형태로 표시되고, 클릭 시 라이트박스로 확대됩니다. 등록된 이미지가 없으면 기본 placeholder가 표시되고, 어드민 모드에서는 "이미지 미등록" 라벨이 함께 보입니다.

상품 기본 정보 영역에서는 상품 구분(레슨/이용/락커/운동복/일반), 상품 대분류(MEMBERSHIP/LESSON_PASS/LOCKER/WEAR/GENERAL), 세부 유형·세부종목(LESSON_PASS는 lessonType·GX는 6종 필수 배지), 상품명, 현금가/카드가(천 단위 콤마), 이용 기간(기간제 일수), 이용 횟수(횟수제), 수업 구분(개인/정규클래스, 레슨에만), 레슨 시간(1회 시간, 레슨에만), 이용 구분(기간/횟수/포인트), 태그, 설명이 라벨-값 형식으로 정렬되어 표시됩니다. GX 상품인데 세부종목이 빈값인 레거시 데이터는 노랑 경고 배지 + "수정" 권유가 표시됩니다.

이용 요일·시간 영역에서는 월~일 7개 요일이 정사각형 박스로 가로 배치되고, 이용 가능 요일에는 체크 표시가, 불가능 요일에는 엑스 표시가 들어갑니다. 그 아래에 이용 가능 시간대가 텍스트로 표시됩니다.

옵션 현황 영역에서는 여덟 가지 옵션(예약 가능/시설 이용/홀딩 가능/양도 가능/포인트 적립/회원 직접 휴회/키오스크 노출/판매 유형)이 라벨과 O/X 또는 enum 값으로 표시됩니다. 판매 유형은 전체/카운터/키오스크/온라인 중 하나가 표시됩니다.

패키지 구성 영역은 패키지 상품에만 표시됩니다. 비패키지 상품에서는 이 섹션 자체가 노출되지 않습니다. 패키지 상품일 때는 구성 상품 목록이 각 행으로 표시되고, 각 구성 상품을 클릭하면 현재 패널이 닫히고 그 상품의 패널이 새로 열립니다. 합산 정가와 패키지 할인가가 마지막에 표시되며, 구성 상품 중 비활성이 있으면 회색 처리 + "비활성" 배지가 함께 보입니다.

가격 변경 이력 영역에서는 최근 5건이 시간순(최신 위)으로 표시됩니다. 각 행은 `2026-04-15 14:23 / 100,000원 → 110,000원 / 김매니저` 형식으로 변경 일시·전 가격→후 가격·변경자가 한 줄에 나옵니다. 변경자가 탈퇴 직원이면 "(탈퇴 직원)"으로 마스킹됩니다. 5건을 초과하는 이력은 "전체 보기" 링크를 통해 DLG-P008 가격이력조회 모달에서 페이지네이션으로 조회합니다. 가격 이력이 0건이면 "가격 변경 이력이 없습니다" 안내가 표시되고 섹션 자체는 노출이 유지됩니다.

판매 현황 영역에서는 네 가지 카드가 표시됩니다. 누적 판매 건수는 결제 완료 누적 카운트, 활성 보유 회원 수는 만료 전 보유자 수, 최근 30일 판매는 결제일 기준 최근 30일 건수, 만료 임박은 만료일이 30일 이내인 회원 수입니다. 만료 임박 카드를 누르면 SCR-M001 회원 검색으로 점프하면서 그 상품 보유자 + 만료 임박 필터가 자동 적용됩니다. 만료 임박 0명이면 "만료 임박 회원이 없습니다" 안내가 표시됩니다. 판매 현황은 5분 캐시로 비동기 로드되어 기본 정보보다 약간 늦게 채워질 수 있습니다.

패널 가장 아래에는 액션 영역이 있습니다. 좌측부터 삭제 버튼(권한자만, 빨강 톤), 카탈로그 미리보기 버튼, 비교 추가 버튼, 가운데에 취소 버튼, 우측에 저장 버튼(편집 권한자만, 변경 사항 있을 때만 활성화)이 가로로 배치됩니다. 슈퍼관리자/Owner(지점장)에게는 추가로 "감사 로그 보기" 링크가 표시되어 SCR-097 감사 로그로 점프합니다(해당 상품 필터 자동 적용).

VAT 표시 모드 토글은 패널 우측 상단에 작은 토글로 표시되어, 지점 정책에 따라 공급가/소비자가 표시 모드를 전환할 수 있습니다.

## 5. 탭 구성과 탭별 동작

이 화면은 별도의 탭 구성이 없는 단일 패널 화면입니다. 모든 정보가 위에서 아래로 차례로 표시되며, 스크롤로 탐색합니다. 패키지 구성 상품 클릭으로 다른 패널로 전환할 때는 자동으로 스크롤이 최상단으로 리셋됩니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

이 화면에 등장하는 모든 클릭 가능 요소를 정의합니다.

닫기(X) 버튼은 패널을 슬라이드 아웃으로 닫고 본문 가로폭을 100%로 복원합니다. 입력 변경 사항이 있으면 DLG-P002 작업취소확인 모달이 먼저 뜨고, 없으면 즉시 닫힙니다.

이미지 갤러리의 각 썸네일은 클릭 시 라이트박스로 확대되어 표시됩니다. 라이트박스 안에서는 좌우 화살표로 다음/이전 이미지를 탐색할 수 있고, ESC 또는 배경 클릭으로 닫힙니다.

가격 변경 이력의 "전체 보기" 링크는 DLG-P008 가격이력조회 모달을 호출합니다. 모달에서는 50건씩 페이지네이션으로 전체 이력을 조회할 수 있습니다. 가격 이력이 0건이면 이 링크는 비활성화됩니다.

판매 현황의 만료 임박 카드는 클릭 시 SCR-M001 회원 검색으로 점프하면서 그 상품 보유자 + 만료 임박 30일 이내 필터가 URL 쿼리 파라미터로 자동 적용됩니다.

활성 보유 회원 수 카드는 슈퍼관리자·Owner(지점장)에게만 회원 목록 점프 액션이 활성화되며, 클릭 시 해당 상품 보유자 전체가 필터된 회원 검색으로 이동합니다.

패키지 구성 상품의 각 행은 클릭 시 현재 패널이 닫히고 그 상품의 상세 패널이 새로 열립니다. 비활성 구성 상품도 패널 진입은 가능하며 회색 배너로 비활성 안내가 표시됩니다.

저장 버튼은 변경 사항이 있을 때만 활성화되며 모든 필수 입력 및 검증을 통과해야 클릭이 가능합니다. 클릭 시 Supabase `products` 테이블에 UPDATE 되며, 가격이 변경되었으면 `price_history`에도 같은 트랜잭션 내에서 자동 INSERT 됩니다. 저장 중에는 모든 입력이 비활성화되고 버튼이 로딩 상태로 전환되어 더블클릭이 차단되며, 저장 성공 시 "수정되었어요" 토스트가 표시되고 패널이 갱신된 값으로 다시 렌더됩니다. 동시 수정 충돌(409 낙관적 락)이 발생하면 "다른 사용자가 먼저 저장했어요" 안내와 함께 "최신 정보 보기" / "덮어쓰기" 선택지가 제공됩니다. 권한이 없는 계정에서는 이 버튼이 보이지 않습니다.

취소 버튼은 입력 변경 사항이 있으면 DLG-P002 작업취소확인 모달을 호출하고, 변경 사항이 없으면 즉시 패널을 닫습니다.

삭제 버튼은 누적 판매 이력을 먼저 확인한 뒤 분기합니다. 판매 이력이 0건이면 DLG-P003 상품삭제확인을 호출해 완전 삭제 흐름으로, 1건 이상이면 DLG-P004 비활성화안내를 호출해 미사용 전환 흐름으로 진입합니다. 패키지 구성 상품으로 사용 중인 경우 별도로 "패키지 {개수}개에서 사용 중입니다" 안내가 표시되고 패키지 분리 후에만 삭제가 가능합니다. 권한이 없는 계정에서는 이 버튼이 보이지 않습니다.

카탈로그 미리보기 버튼은 PRD-05의 카드 형태로 즉시 미리보기를 띄웁니다. 비활성 상품의 경우 "비활성 상품은 카탈로그에 노출되지 않습니다" 안내가 함께 표시됩니다.

비교 추가 버튼은 SCR-P006 상품 비교 화면으로 이동하면서 현재 상품을 비교 대상에 자동 추가합니다. 이미 비교 화면에 3개 상품이 있으면 "1개를 교체합니다" 안내가 뜨고 교체할 상품을 선택하는 모달이 표시됩니다.

감사 로그 보기 링크(슈퍼관리자/Owner(지점장) 전용)는 SCR-097 감사 로그 화면으로 점프하면서 해당 상품 ID 필터를 자동 적용합니다.

VAT 표시 모드 토글은 클릭 시 즉시 공급가↔소비자가 표시 모드를 전환하며, 토글 상태는 사용자 단위로 보존됩니다.

다른 행 클릭(다른 상품으로 전환)은 입력 변경 사항이 없으면 즉시 새 패널 데이터가 로드되어 표시되고, 변경 사항이 있으면 DLG-P002 작업취소확인 모달이 먼저 뜹니다.

## 7. 호출되는 모달 동작

이 화면에서 호출되는 모달은 네 가지입니다.

### 7-1. DLG-P002 작업취소확인 모달

입력 변경 사항이 있는 상태에서 취소 버튼, 닫기(X), 패널 외부 클릭, 또는 다른 상품 행 클릭으로 패널을 떠나려고 할 때 호출됩니다. 모달은 "변경 사항이 저장되지 않았어요. 정말 닫으시겠어요?"를 묻고 확인/취소를 받습니다. 확인 시 폼 데이터를 버리고 패널이 닫히거나 새 패널이 로드되며, 취소 시 모달만 사라지고 폼은 그대로 유지됩니다. dirty 비교는 초기 로드값과 현재값의 deep equal로 판정되어, 입력했다가 동일한 값으로 되돌리면 dirty가 아닌 것으로 간주됩니다.

### 7-2. DLG-P003 상품삭제확인 모달

삭제 버튼을 눌렀고 누적 판매 이력이 0건일 때 호출됩니다. 모달은 "상품을 삭제하시겠어요? 이 상품은 판매 이력이 없어 완전 삭제됩니다"라는 안내와 함께 확인/취소를 받습니다. 확인 시 Supabase에서 DELETE 되며 감사 로그에 기록되고, 패널이 자동으로 닫히면서 SCR-P001 목록이 갱신되고 "삭제되었습니다" 토스트가 표시됩니다.

### 7-3. DLG-P004 비활성화안내 모달

삭제 버튼을 눌렀고 누적 판매 이력이 1건 이상일 때 호출됩니다. 모달은 "이용 중 회원 {인원수}명이 있어 완전 삭제는 불가능합니다. 미사용 상태로 전환할까요?"를 묻고 미사용 전환 확인 또는 취소를 받습니다. 확인 시 `isActive`가 false로 변경되어 신규 판매가 차단되지만 기존 보유 회원의 이용권은 만료일까지 유지되며 카탈로그·키오스크에서 자동 제외됩니다. 패널은 자동으로 갱신되어 비활성 배지로 전환되고, 활성/비활성 배너가 회색으로 바뀝니다.

### 7-4. DLG-P008 가격이력조회 모달

가격 변경 이력 섹션의 "전체 보기" 링크를 눌렀을 때 호출됩니다. 모달에서는 가격 변경 이력 전체를 50건씩 페이지네이션으로 조회할 수 있고, 변경 일시·변경 전·변경 후·변경자·변경 사유가 표시됩니다. 1년이 경과한 이력은 SCR-097 감사 로그에서 조회하도록 안내됩니다. 모달 내 이력 행을 클릭하면 그 시점의 상품 스냅샷을 별도 패널에 표시할 수도 있습니다(향후 확장).

## 8. 토스트와 확인 팝업과 알럿

상품 상세/수정 패널에서 발생하는 알림성 UI는 다음 패턴을 따릅니다.

성공 토스트는 "수정되었어요", "삭제되었습니다", "비활성으로 전환되었습니다", "비교 화면으로 이동했어요" 같은 짧은 문구로 결과를 알려 줍니다.

실패 토스트는 "저장에 실패했어요", "정보를 불러올 수 없어요", "권한이 없어요", "다른 사용자가 동시에 편집했어요", "상품명이 이미 존재해요" 같은 빨강 톤 안내가 표시되며, 동시 수정 충돌(409)의 경우 "최신 정보 보기" 또는 "덮어쓰기" 선택지가 함께 제공됩니다.

확인 팝업은 DLG-P002 작업취소확인, DLG-P003 상품삭제확인, DLG-P004 비활성화안내가 사용됩니다. 이 외 다른 액션(전환·미리보기)에는 별도 확인이 없습니다.

인라인 검증 메시지는 입력 필드 바로 아래에 표시되며, 상품명 중복, GX 세부종목 미선택, 카드가 > 현금가, 기간/횟수 동시 0, 시작 시간 ≥ 종료 시간, 패키지 구성 0개, 패키지 할인가 > 합산 정가 같은 검증 실패가 인라인 메시지로 즉시 표시됩니다.

알럿은 권한이 없는 계정이 직접 URL로 진입했을 때 표시되며, "이 화면에 접근할 권한이 없습니다" 메시지와 3초 카운트다운으로 대시보드 자동 이동됩니다.

비활성 상품 안내 배너는 패널 헤더 아래에 회색 톤으로 표시되며, "이 상품은 미사용 상태입니다, 신규 판매 불가"라는 안내가 들어갑니다.

GX 세부종목 빈값 안내 배너는 노랑 톤으로 "GX 세부종목이 설정되지 않았습니다, 수정해 주세요"라는 안내와 함께 수정 버튼으로의 빠른 진입 링크가 표시됩니다.

## 9. 데이터 흐름과 외부 연동

이 화면은 여러 데이터 소스를 비동기로 로드합니다.

화면 진입 시 `GET /api/products/:id` API로 상품 기본 정보를 불러옵니다. 응답에는 상품 기본 정보, 옵션, 패키지 구성, 이미지 URL 목록, 현재 활성 상태가 포함됩니다.

가격 변경 이력은 `GET /api/products/:id/price-history`로 별도 조회됩니다. 패널은 기본 정보를 먼저 표시하고 가격 이력 섹션은 비동기로 로드하여 사용자 체감 속도를 높입니다. 응답은 시간순 내림차순(최신 위)이며 최근 5건만 패널에 표시되고, 전체는 DLG-P008 가격이력조회에서 페이지네이션으로 조회합니다.

판매 현황은 `GET /api/products/:id/sales-summary`로 조회됩니다. 응답에는 누적 판매 건수, 활성 보유 회원 수, 최근 30일 판매, 만료 임박 회원 수가 포함되며, 5분 캐시가 적용되어 같은 상품을 반복 조회할 때 부담을 줄입니다.

회원별 보유 목록은 `GET /api/products/:id/holders`로 조회되지만 패널 자체에는 표시되지 않고, 만료 임박 카드 클릭 시 회원 검색(SCR-M001)으로 점프할 때 사용됩니다. 만료 임박 회원만 별도로 `GET /api/products/:id/expiring-holders`로 조회됩니다.

저장(수정)은 `PUT /api/products/:id`로 처리됩니다. 요청 본문에는 상품 구분(category·productType), 상품명, 가격(price·cashPrice·cardPrice), 기간(duration), 횟수(sessions·totalCount), 상품그룹(productGroupId), GX 세부종목(sportType), 요일·시간 제한(usage_restrictions JSON), 옵션 boolean들, 채널, 지점 운영 정책이 모두 들어갑니다. 가격이 변경되면 `price_history` 테이블에 `before_cash, after_cash, before_card, after_card, actor_id, changed_at`이 같은 트랜잭션 안에서 자동 INSERT 됩니다. 동시 수정 충돌은 낙관적 락(`updated_at` 비교)으로 감지되며 다른 사용자가 먼저 저장했으면 409 응답으로 "최신 정보 보기" 또는 "덮어쓰기" 선택지가 제공됩니다.

삭제는 `DELETE /api/products/:id`, 비활성 전환은 `POST /api/products/:id/deactivate`로 처리됩니다. 비활성 전환 응답에는 영향을 받는 보유 회원 수가 포함됩니다.

감사 로그 점프는 `GET /api/products/:id/audit-log`로 해당 상품의 감사 이력을 가져와 SCR-097 감사 로그 화면에서 표시합니다.

모든 수정·삭제·비활성 이벤트는 SCR-097 감사 로그에 비동기로 INSERT 됩니다. 기록 필드는 `actor_id, product_id, action, before, after`이며 5초 안에 조회 가능합니다.

이미지 갤러리는 Supabase Storage의 `products/{branchId}/{productId}/` 경로에 저장된 파일을 응답에서 받은 URL로 직접 표시합니다. 이미지 로딩 실패 시 기본 placeholder가 대체됩니다.

회원앱·키오스크 동기화는 패널 표시 시점에 5분 캐시를 확인하여 캐시가 유효하면 그대로 사용하고, 만료되었으면 최신 데이터를 다시 받아옵니다.

화면에서 호출하는 주요 API 엔드포인트는 다음과 같습니다. 상품 상세 `GET /api/products/:id`, 수정 `PUT /api/products/:id`, 가격 이력 `GET /api/products/:id/price-history`, 판매 현황 `GET /api/products/:id/sales-summary`, 보유 회원 `GET /api/products/:id/holders`, 만료 임박 회원 `GET /api/products/:id/expiring-holders`, 삭제 `DELETE /api/products/:id`, 비활성 전환 `POST /api/products/:id/deactivate`, 감사 로그 `GET /api/products/:id/audit-log`.

## 10. 화면 상태와 예외 처리

이 화면은 다음 상태들을 가질 수 있습니다.

정상 조회 상태는 상품 정보가 모두 로드된 가장 일반적인 상태로, 모든 영역이 정상적으로 표시되고 액션 버튼이 권한에 맞게 활성화됩니다.

기본 정보 로딩 상태는 패널을 처음 연 직후로, 헤더와 기본 정보 자리에 스켈레톤이 표시되고 가격 이력·판매 현황 영역도 함께 스켈레톤으로 표시됩니다.

가격 이력 로딩 상태는 기본 정보가 표시된 후에도 가격 이력 섹션만 별도로 비동기 로드되는 상태로, "불러오는 중..." 텍스트가 표시됩니다.

판매 현황 로딩 상태는 5분 캐시를 비동기로 채우는 동안의 상태로, 네 개의 카드가 스켈레톤으로 표시됩니다.

삭제 확인 중 상태는 삭제 버튼을 눌러 DLG-P003 또는 DLG-P004가 표시된 상태입니다.

비활성화 확인 중 상태는 DLG-P004 비활성화안내가 표시되어 이용 중 회원 수와 미사용 전환 확인이 노출된 상태입니다.

비활성 상품 조회 상태는 미사용 상품을 조회 중인 상태로, 헤더에 회색 배지가 표시되고 아래에 "이 상품은 미사용 상태입니다, 신규 판매 불가" 안내 배너가 표시됩니다.

데이터 로딩 실패 상태는 서버 5xx 또는 네트워크 오류로 상품 정보를 불러올 수 없는 상태로, 패널 본문에 "정보를 불러올 수 없어요" 메시지와 "재시도" 버튼이 표시됩니다.

패키지 일부 비활성 상태는 패키지 구성 상품 중 일부가 비활성인 상태로, 해당 구성 상품 행이 회색 처리되고 "비활성" 배지가 함께 표시됩니다.

권한 부족 상태는 일반 직원이 패널을 조회하는 상태로, 수정·삭제 버튼이 숨겨지고 조회만 가능합니다.

FC 권한 + 담당 외 상품 상태는 FC가 본인 담당 회원이 보유하지 않은 상품을 조회하려는 경우로, 패널 자체가 표시되지 않거나 "권한 없음" 안내가 표시됩니다.

예외 케이스별 처리는 다음과 같습니다. 상품 데이터 로딩 실패는 "정보를 불러올 수 없어요" + 재시도 버튼으로 처리됩니다. 가격 이력 0건은 "가격 변경 이력이 없습니다" 안내가 표시되고 섹션 자체는 노출 유지됩니다. 패키지 상품 + 구성 상품 일부 비활성은 회색 처리 + "비활성" 배지로 시각화됩니다. GX 세부종목 빈값(레거시 데이터)은 노랑 경고 배지 + 수정 안내로 운영자에게 수정을 권유합니다. 비활성 상품 조회는 정상 노출되지만 회색 배지와 안내 배너가 추가됩니다. 삭제 시 패키지 구성 사용 중은 "이 상품은 패키지 {개수}개에서 사용 중입니다" + 패키지 링크 + 분리 안내로 처리됩니다. 판매 현황 로딩 지연(데이터 많음)은 기본 정보를 먼저 표시한 뒤 스켈레톤이 비동기로 채워집니다. 권한 부족(일반 직원)은 저장·삭제 버튼이 숨겨지고 조회만 가능합니다. FC + 담당 외 상품은 패널 미노출 또는 "권한 없음" 안내가 표시됩니다. 입력 변경 사항이 없는 상태에서의 다른 행 클릭은 즉시 전환되지만, 변경 사항이 있으면 DLG-P002 작업취소확인이 먼저 호출됩니다. 동시 수정 충돌(409 낙관적 락)은 "다른 사용자가 먼저 저장했어요" + "최신 정보 보기" / "덮어쓰기" 선택지로 분기되며, 덮어쓰기 선택 시 경고가 함께 표시됩니다. 상품명 중복은 인라인 "이미 등록된 상품명입니다" + 저장 차단, GX 세부종목 미선택은 빨강 인라인 + 저장 차단, 카드가 > 현금가는 빨강 인라인 + 저장 차단, 기간·횟수 동시 0은 "최소 하나 입력" + 저장 차단, 시작 시간 ≥ 종료 시간은 인라인 차단입니다. 분류 변경 + 판매 이력 있음은 "분류 변경 불가(판매 이력)" + 차단됩니다. 가격 이력 페이지네이션(50건 초과)은 DLG-P008 가격이력조회 전체 보기에서 처리됩니다. 만료 임박 0명은 "만료 임박 회원이 없습니다" 안내가 표시됩니다. 상품 삭제 후 패널 잔존은 자동으로 닫히고 목록이 갱신되며 "삭제되었습니다" 토스트가 표시됩니다. 회원별 보유 현황 클릭은 SCR-M001로 점프하면서 해당 상품 보유자 필터가 자동 적용됩니다. 카탈로그 미리보기 + 비활성 상품은 "비활성 상품은 카탈로그에 노출되지 않습니다" 안내와 함께 정보만 표시됩니다. VAT 표시 정책 다름(공급가↔소비자가)은 지점 정책에 따라 표시값이 자동 보정됩니다.

## 11. 권한별 처리

이 화면은 권한에 따라 보이는 정보와 가능한 액션이 달라집니다.

슈퍼관리자(superAdmin)와 본사 최고관리자(primary)는 전체 정보를 볼 수 있으며 수정·삭제·비교 추가·카탈로그 미리보기·회원별 보유 조회·감사 로그 점프 모두 가능합니다.

Owner(지점장)은 자기 지점 상품의 전체 정보를 볼 수 있으며 수정·삭제·비교 추가·카탈로그 미리보기·감사 로그 점프 모두 가능합니다.

매니저(manager)는 자기 지점 상품의 전체 정보를 볼 수 있고 저장(수정)·비교 추가·카탈로그 미리보기는 가능하지만 삭제 권한은 없습니다. 패널에서 삭제 버튼이 숨겨지고 비활성 전환도 차단됩니다(Owner(지점장) 요청 흐름으로 처리).

상품 편집 권한 보유자는 매니저와 유사하게 수정·이미지·비교·카탈로그가 가능하며 삭제 권한 여부는 조직 정책에 따릅니다.

일반 직원(staff)은 상품 기본 정보·옵션·판매 현황을 조회할 수 있지만 가격 이력은 마지막 변경자가 마스킹되어 표시됩니다. 수정·삭제 버튼은 보이지 않고, 비교 추가와 카탈로그 미리보기는 가능합니다.

FC(fc)는 본인이 담당하는 회원이 보유한 상품만 조회할 수 있습니다. 담당 외 상품의 패널은 표시되지 않거나 "권한 없음" 안내가 표시됩니다. 가능한 액션은 조회와 비교 추가뿐입니다.

읽기 전용(readonly)은 이 화면 자체에 접근할 수 없으며, 직접 URL 접근 시 대시보드로 자동 이동됩니다.

권한이 부족해서 액션이 차단된 경우의 사용자 경험은 일관됩니다. 첫째, 진입점(상품 행 클릭)에서 패널은 열리지만 권한 부족 액션은 버튼 자체가 숨겨집니다. 둘째, 가격 이력의 마지막 변경자 정보는 일반 직원에게 마스킹됩니다. 셋째, 직접 URL 접근 시 권한 미달이면 백엔드 응답이 403이 되어 "권한이 없어요" 토스트가 표시되고 변경이 적용되지 않습니다.

## 14. 핵심 디자인 요청사항

이 화면이 운영자에게 잘 작동하려면 다음 디자인 원칙이 시각적으로 명확히 드러나야 합니다.

패널은 부드럽게 슬라이드 인 되며 본문 가로폭이 동시에 축소되는 애니메이션이 함께 일어나야 합니다. 닫을 때는 슬라이드 아웃과 본문 가로폭 확장이 동시에 일어납니다.

헤더의 상품명은 가장 큰 폰트로, 활성/비활성 배지는 그 옆에 강한 색상 대비로 배치되어 운영자가 한눈에 상품 상태를 파악할 수 있어야 합니다.

이미지 갤러리는 패널 가로폭에 맞춰 정사각형 또는 16:9 비율 썸네일이 가로로 나열되고, 좌우 화살표로 슬라이드 탐색이 가능해야 합니다.

기본 정보는 라벨-값 그리드로 정렬되며 라벨은 회색 톤, 값은 짙은 톤으로 시각적 위계가 명확합니다. GX 세부종목 빈값은 노랑 경고 배지로 강조됩니다.

요일·시간 영역에서는 7개 요일이 정사각형 박스로 가로 배치되고, 체크는 녹색 + 체크 아이콘, 엑스는 회색 + 엑스 아이콘으로 표시됩니다.

옵션 현황은 라벨-O/X 형식의 행으로 깔끔하게 정렬되며, O는 녹색, X는 회색으로 표시되어 시각적으로 즉시 구분됩니다.

패키지 구성 영역은 별도 박스로 묶이며 구성 상품 각 행에 호버 시 진한 톤으로 변하여 클릭 가능함을 알립니다. 비활성 구성 상품은 회색 처리 + "비활성" 배지로 명확히 구분됩니다.

가격 변경 이력은 시간순 타임라인 형태로 표시되어 변경의 시간적 순서를 시각적으로 알려 줍니다. 가격 상승은 빨강 화살표, 하락은 녹색 화살표로 방향성을 알리고, 변경자 이름은 작은 글씨로 우측에 표시됩니다.

판매 현황 네 개 카드는 동일 크기·동일 그리드로 배치되어 한눈에 비교 가능해야 합니다. 카드 안의 숫자는 가장 큰 폰트로, 라벨은 그 아래 작은 글씨로 배치합니다. 만료 임박 카드는 호버 시 약간 들떠 클릭 가능함을 알립니다.

액션 버튼 영역은 패널 하단에 sticky로 고정되어 스크롤해도 항상 보입니다. 수정은 브랜드 톤, 삭제는 빨강 톤, 카탈로그 미리보기와 비교 추가는 보조 톤으로 구분됩니다.

비활성 상품 안내 배너는 헤더 바로 아래에 회색 톤으로 표시되어 운영자가 즉시 비활성 상태를 인지할 수 있어야 합니다.

모바일에서는 패널이 풀스크린으로 표시되고 헤더가 sticky로 고정되어 닫기 버튼이 항상 보입니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

이 화면은 단순한 조회 패널이 아니라 조회·수정·삭제·비활성·정책 의사결정을 동시에 수행하는 통합 운영 패널입니다.

조회+수정 통합 정책은 본 화면이 별도 수정 전용 화면(예: SCR-P002)으로 전환하지 않고 패널 자체에서 즉시 편집·저장이 가능하다는 것입니다. SCR-P002는 신규 등록 전용이며, 기존 상품의 모든 수정 책임(입력·검증·저장·동시 수정 충돌·작업 취소 보호)은 본 화면 SCR-P003이 가집니다. 폼 입력 UI는 SCR-P002와 같은 컴포넌트를 공유하지만 진입 모드가 다르게 동작합니다.

작업 취소 보호 정책은 사용자 변경 사항 손실을 방지합니다. 입력값 한 개라도 dirty면 닫기·다른 행 클릭·패키지 구성 클릭 시 DLG-P002 작업취소확인이 호출됩니다. dirty 비교는 초기 로드값과 현재값의 deep equal로 판정됩니다.

동시 수정 충돌 정책은 낙관적 락(`updated_at` 비교)으로 감지되며, 다른 사용자가 먼저 저장했으면 운영자가 최신 정보를 다시 보거나 덮어쓰기를 선택할 수 있습니다. 덮어쓰기 선택 시 경고가 함께 표시되어 무의식적 덮어쓰기를 방지합니다.

가격 이력 자동 기록 정책은 모든 가격 변경을 `price_history`에 자동으로 INSERT 합니다. 기록 필드는 `before_cash, after_cash, before_card, after_card, actor_id, changed_at`이며, 메인 저장(PUT)과 같은 트랜잭션 안에서 일어나 가격 변경과 이력 기록이 항상 일관됩니다.

분류 변경 차단 정책은 판매 이력이 있는 상품의 대분류(category) 변경을 차단하여 분류 정합성을 보호합니다. 분류 이동이 필요하면 운영 정책 변경 절차로 별도 처리됩니다.

감사 로그 기록 정책은 수정·삭제·비활성·이미지 변경을 모두 SCR-097 감사 로그에 비동기로 기록하며, 5초 안에 조회 가능해야 합니다. 기록 필드는 `actor_id, product_id, action, before, after`입니다.

분류 표시 정책은 1단계 대분류와 2단계 종목·세부종목을 함께 표시한다는 것입니다. `category=LESSON_PASS`이고 `lessonType=GX`인 상품은 세부종목 배지를 필수로 표시하며, 빈값은 노랑 경고로 운영자에게 수정을 권유합니다. GX 세부종목 값은 매출통계 GX종목별 탭과 KPI 대시보드 GX 세부 종목 분포에서 동일하게 사용됩니다.

가격 이력 정책은 모든 가격 변경 시점·전·후·변경자를 기록한다는 것입니다. 패널에는 최근 5건만 인라인으로 표시되고, 전체는 DLG-P008 가격이력조회 모달에서 50건씩 페이지네이션으로 조회합니다. 1년 경과 이력은 SCR-097 감사 로그에서 조회하며, 변경자가 탈퇴 직원이면 "(탈퇴 직원)"으로 마스킹됩니다. 가격 이력 표시 형식은 `2026-04-15 14:23 / 100,000원 → 110,000원 / 김매니저`이고 시간순 내림차순입니다.

판매 이력 보호 정책은 판매 이력이 있는 상품의 삭제를 차단하고 미사용 비활성으로 전환한다는 것입니다. DLG-P004 비활성화안내가 호출되어 이용 중 회원 수가 안내되고, 비활성 전환 시 신규 판매는 차단되지만 기존 보유 회원의 이용권은 만료일까지 유지됩니다.

패키지 구성 표시 정책은 패키지 상품에만 구성 영역을 노출한다는 것입니다. 비패키지는 섹션 자체가 미노출되며, 패키지 구성 상품 클릭 시 현재 패널을 닫고 새 패널을 열어 운영자가 구성 상품 정보를 연속 탐색할 수 있습니다.

판매 현황 집계 정책은 5분 캐시 기반의 비동기 로드입니다. 누적 판매는 결제 완료 누적 건수, 활성 보유는 만료 전 보유자 수, 최근 30일은 결제일 30일 이내, 만료 임박은 만료일 30일 이내 회원 수입니다. 만료 임박 30일 기준은 만료일이 오늘 기준 30일 이내인 회원이며, 클릭 시 SCR-M001 회원 검색에 자동 필터됩니다.

권한별 정보 노출 정책은 일반 직원에게 가격 이력의 마지막 변경자를 마스킹하고, FC에게는 담당 회원이 보유한 상품만 노출하는 것입니다. 슈퍼관리자·Owner(지점장)에게는 감사 로그 점프 링크가 추가로 노출됩니다.

데이터 부분 로딩 정책은 사용자 체감 속도를 높이기 위한 것입니다. 기본 정보 → 옵션 → 가격 이력 → 판매 현황 순으로 비동기 로드되어 기본 정보가 먼저 표시되고 나머지는 차례로 채워집니다.

다른 행 클릭 전환 정책은 입력 변경 사항이 없으면 확인 없이 즉시 새 패널이 로드되고, 변경 사항이 있으면 DLG-P002 작업취소확인이 호출되어 변경 사항 손실을 방지한다는 것입니다.

VAT 표시 정책은 지점 정책에 따라 공급가/소비자가 표시 모드를 토글하며, 패널 우측 상단에 표시 모드 토글이 있습니다. 표시값은 자동으로 환산되어 일관성이 유지됩니다.

태그 표시 정책은 5개를 초과하면 ... 으로 축약하고 호버 시 전체 태그가 툴팁으로 펼쳐집니다.

이미지 갤러리 정책은 1~5장의 이미지를 슬라이드 형태로 표시하며 클릭 시 라이트박스로 확대됩니다. 이미지 로딩 실패는 기본 placeholder로 대체됩니다.

감사 로그 조회 정책은 슈퍼관리자·Owner(지점장)이 패널에서 "감사 로그 보기" 링크로 SCR-097에 점프할 때 해당 상품 ID 필터가 자동 적용되어 그 상품의 이력만 즉시 보일 수 있도록 합니다.

카탈로그 미리보기 정책은 PRD-05 카드 형태를 패널 안에서 즉시 미리보기 모드로 표시하여 운영자가 회원에게 노출될 형태를 사전 확인할 수 있게 합니다. 비활성 상품의 경우 "노출되지 않습니다" 안내가 함께 표시됩니다.

비교 추가 정책은 현재 상품을 SCR-P006 비교 화면에 자동 추가하여 빠른 비교 진입을 지원합니다. 이미 비교 화면에 3개 상품이 있으면 교체 모달이 표시되어 어느 상품을 교체할지 선택합니다.

이상의 모든 정책은 이 화면을 구현하고 운영하는 사람이 별도 문서 없이 이 한 장만 보면 이해할 수 있도록 풀어 적었습니다.
