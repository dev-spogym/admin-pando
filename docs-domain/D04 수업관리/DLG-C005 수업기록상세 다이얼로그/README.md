## 2. 다이얼로그 개요와 목적

완료된 수업의 출석·서명·메모·QR 체크인 로그·녹화 영상 링크를 한 화면에서 통합 조회하는 분쟁 대응 증빙 모달입니다. 회원이 "출석했다"고 주장하거나 "서명 안 했다"고 주장하는 분쟁 상황에서 운영자가 즉시 증빙을 제시할 수 있도록 5년 이상 보관됩니다. 매니저 이상은 출석/노쇼 정정도 본 모달에서 수행할 수 있습니다.

## 3. 호출 트리거와 진입 시 초기값

SCR-C002 수업관리에서 완료 상태 행의 수업명을 클릭하거나, SCR-C011 유효 수업의 [기록] 버튼, SCR-C015 수업 녹화 관리에서 연결 수업 조회 시 열립니다. 진입 시 해당 수업의 모든 기록이 통합 표시됩니다.

## 4. 레이아웃과 표시 항목

모달 상단에는 수업명·강사·일시·장소가 표시됩니다. 본문은 세 영역으로 구분됩니다.

출석 기록 영역에서는 회원별 출석 상태(출석/결석/노쇼/미처리)와 처리 시각·처리자·정정 이력이 표시됩니다. 서명 영역에서는 회원 서명 이미지(있을 경우) + 서명 시각이 표시되고, 권한 검증 후 노출됩니다. QR 체크인 로그 영역에서는 QR 스캔 시각·디바이스·위변조 시도 여부가 표시됩니다.

메모 영역은 강사가 수업 중 입력한 메모와 수업 종료 후 추가 기록이 표시됩니다. 녹화 영상 영역은 SCR-C015에 업로드된 영상이 있으면 링크가 표시되어 클릭 시 스트리밍 재생됩니다.

모달 하단에는 [정정] (매니저+ 권한자만 노출) / [닫기] 버튼이 있습니다.

## 5. 액션과 검증

[정정] 버튼은 출석/노쇼 정정 영역을 활성화해 새 상태 + 사유(필수 5자) 입력을 받습니다. 노쇼 → 출석 정정 시 자동 페널티 자동 해제 + 횟수 자동 차감이 일어나고, 출석 → 노쇼 정정 시 자동 페널티가 새로 부과됩니다. 모든 정정은 append-only 이력으로 기록되어 기존 이력은 절대 사라지지 않습니다.

## 6. 화면 상태와 예외 처리

기본 표시는 부모 화면에서 받은 수업 ID 기준 최신 기록을 불러옵니다. 정정 모드 활성 시 사유 입력 영역이 노출됩니다. 서명 미수령 상태에서는 노랑 배지 + [DLG-C006 재시도] 안내가 표시됩니다.

예외로 권한 부족(FC/스태프)은 정정 버튼 숨김, 트레이너 타 강사 수업은 read-only, 동시 정정 충돌은 낙관적 락 재로드, 서명 이미지 로드 실패는 재시도 안내, 5년 미만 데이터는 정상 조회·5년 이상 보관 정책은 영구 보관입니다.

## 7. 권한별 동작

owner / manager는 조회 + 정정이 가능합니다. trainer는 본인 담당 수업 정정만 가능하고 타 강사는 read-only입니다. fc / staff는 조회만 가능하고 정정 버튼이 숨겨집니다. readonly는 조회만 가능합니다.

## 8. 부모 화면과의 상호작용

정정 처리 후 부모 화면(SCR-C002 또는 SCR-C011)의 행 출석 상태·노쇼 카운트·페널티 상태가 즉시 갱신됩니다. 자동 페널티 해제 또는 부과는 CLS-08 페널티 관리와 양방향 동기화됩니다. 모든 정정은 SCR-097 감사 로그에 기록됩니다.

## 9. 데이터 흐름과 외부 연동

API는 수업 기록 조회 `GET /api/lessons/:id/record`, 정정 `POST /api/lessons/:id/attendance` (정정 모드)입니다. 서명 이미지는 암호화 저장된 클라우드에서 권한 검증 후 토큰 기반으로 노출됩니다. QR 체크인 로그는 CLS-14에서 적재된 데이터를 그대로 표시합니다.

정정 시 CLS-07 횟수 관리·CLS-08 페널티·NFR-19 알림·SCR-097 감사 로그가 함께 트리거됩니다.

## 12. 디자인 요청사항

출석·서명·QR·메모·녹화 5개 영역이 명확히 구분된 카드 형태로 배치되어 분쟁 대응 시 운영자가 한 화면에서 모든 증빙을 확인할 수 있어야 합니다. 서명 이미지는 큰 미리보기 + 시각 시간 라벨로 표시되어 진위 확인이 즉시 가능해야 합니다. 정정 이력은 시간 역순(최신 우선)으로 정렬되고 각 이력에 처리자·시각·사유가 함께 표시됩니다. 노쇼 → 출석 정정 시 자동 페널티 해제 안내가 강조 색상으로 표시되어 결과를 즉시 인지할 수 있게 합니다.

## 13. 운영 정책

수업 기록은 분쟁 대응을 위해 최소 5년 이상 보관되며 본 모달에서 통합 조회됩니다. 이력은 append-only이며 삭제 불가, 정정은 새 이력 추가(역방향 조정)로만 가능합니다.

출석 정정 권한은 매니저+로 한정되며 트레이너는 본인 담당 수업만 가능합니다. 사유 텍스트 최소 5자가 필수이며 모든 정정은 감사 로그에 기록됩니다. 수업 종료 후 7일 이상 경과한 기록은 trainer가 수정할 수 없고 manager+ 권한자만 정정 가능합니다(DLG-C011 세션 기록과 동일 정책, 현장 기록 책임 강화 정책).

노쇼 → 출석 정정 시 자동 페널티 자동 해제 + 횟수 자동 차감, 출석 → 노쇼 정정 시 자동 페널티 부과가 자동 흐름입니다. 서명 이미지는 암호화 저장되고 권한 검증 후 토큰 기반으로 노출되어 보안이 보장됩니다. QR 체크인 로그는 CLS-14에서 적재된 데이터(스캔 시각·디바이스·위변조 시도 여부)를 그대로 표시합니다.
