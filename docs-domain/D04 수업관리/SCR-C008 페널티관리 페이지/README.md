## 2. 화면 개요와 목적

페널티 관리 페이지는 노쇼·늦은 취소로 회원에게 부과된 페널티의 현황을 관리하고 자동 페널티 정책을 설정하는 화면입니다. 운영자는 회원이 무단 결석하거나 수업 시작 직전에 취소해 자리가 낭비되는 일을 줄이기 위해 단계별 페널티(1회 노쇼: 기본 예약 제한 7일 + 1회 차감 → 누적 3회 노쇼: 14일 + 2회 차감 → 누적 5회 노쇼: 30일 + 3회 차감, 본사 권장값 기준)를 정의하고, 부당하다고 판단되는 페널티는 수동으로 해제합니다. 자동 페널티 크론(A05)이 매분 노쇼·늦은 취소를 자동 부과해 운영 부담을 줄이고, 노쇼/취소 정책(DLG-C007)은 회원앱에 자동 노출되어 사전 인지를 통한 분쟁 감소를 돕습니다.

## 3. 진입 경로와 인접 화면

사이드바의 "수업관리 > 페널티 관리" 또는 D04 도메인 탭 내비게이션의 "페널티 관리" 탭으로 진입합니다. 탭에는 적용 중 페널티 건수가 빨강 배지로 표시되어 누락 방지를 돕습니다. 인접 화면은 SCR-C001 캘린더(노쇼 발생 원천), SCR-C002 수업관리(출석 정정 시 자동 해제), SCR-M004 회원 상세, SCR-097 감사 로그입니다.

## 4. 레이아웃과 UI 구성

페이지 헤더 아래에는 "페널티 현황"과 "정책 설정" 2개 탭이 있습니다.

페널티 현황 탭은 회원 검색 입력, 유형 필터(노쇼/늦은 취소), 상태 필터(적용 중/해제), 기간 필터, 그리고 [+ 페널티 등록] 버튼이 있고, 본문은 페널티 목록 테이블입니다. 컬럼은 회원명(클릭 시 SCR-M004)·연락처·페널티 유형·부과일·해당 수업·페널티 내용(예약 제한 N일 / 횟수 차감 N회)·상태(적용 중/해제)·액션([해제])입니다. 적용 중 페널티는 빨강 배지, 해제 페널티는 회색 배지로 구분됩니다.

정책 설정 탭은 자동 페널티 토글, 자동 페널티 규칙 설정 진입(DLG-C015), 늦은 취소 기준 시간(예: 수업 시작 2시간 전), 페널티 내용 기본값(예약 제한 7일 / 횟수 차감 1회), 노쇼/취소 정책 진입(DLG-C007)을 한 페이지에서 관리합니다. 본사 표준 정책이 활성된 테넌트에서는 변경이 차단되고 "본사 표준 정책" 안내가 표시됩니다.

## 5. 탭 구성과 탭별 동작

페널티 현황 탭은 실시간 운영 데이터를, 정책 설정 탭은 마스터 정책을 다룹니다. 두 탭은 같은 화면에 있지만 책임이 다르고 권한 요건도 다릅니다. 정책 설정은 매니저+가 변경 가능합니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

[+ 페널티 등록]은 DLG-C014를 열어 수동 부과를 가능하게 합니다. 행의 [해제] 버튼은 매니저+에게만 노출되며 해제 사유(필수 5자 이상) 입력 후 처리됩니다. 횟수 차감 페널티였다면 자동 횟수 복구(CLS-07)가 함께 일어납니다. 정책 설정 탭의 자동 페널티 토글은 매니저+가 ON/OFF 할 수 있고, [자동 페널티 규칙]은 DLG-C015를, [노쇼/취소 정책]은 DLG-C007을 엽니다.

회원명 클릭은 SCR-M004 회원 상세로 이동합니다. 본사 통합 모드에서는 지점 컬럼이 추가됩니다.

## 7. 호출되는 모달 동작

### 7-1. DLG-C014 페널티 등록 다이얼로그
회원 선택 + 페널티 유형(노쇼/늦은 취소/기타) + 사유(필수 5자 이상) + 페널티 내용(예약 제한 일수, 횟수 차감 횟수) 입력 후 저장 시 즉시 적용되고 회원 알림이 발송됩니다.

### 7-2. DLG-C015 자동 페널티 정책 다이얼로그
단계별 규칙(1회 노쇼: 7일 예약 제한 + 1회 차감, 누적 3회 노쇼: 14일 + 2회 차감, 누적 5회 노쇼: 30일 + 3회 차감 - DLG-C015 본사 권장값 기준), 늦은 취소 기준 시간, 페널티 내용을 설정합니다. 누적 카운트 윈도우는 30/90(기본)/영구 중 선택합니다. 신규 회원 면제 정책(첫 노쇼는 경고만)도 활성화할 수 있습니다. manager가 한 단계의 강도를 크게 증가시키려고 하면(예: 노쇼 1회 예약 제한 14일 이상 증가) owner 이상 승인 요청 흐름으로 자동 전환되어 보류되며, 이는 매니저 단독 판단으로 회원 전체에 적용되는 정책이 급변하는 것을 막기 위한 정책입니다.

### 7-3. DLG-C007 노쇼/취소 정책 다이얼로그
회원앱에 자동 노출되는 노쇼·취소 정책 텍스트와 늦은 취소 기준 시간을 정의합니다. 회원이 사전 인지하도록 표시되어 분쟁 감소를 돕습니다.

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 "회원에게 페널티를 부과했어요", "페널티를 해제했어요"로 표시됩니다. 자동 해제 토스트는 "노쇼 → 출석 정정 → 자동 페널티 해제됨"으로 자동으로 안내됩니다. 본사 표준 정책 변경 시도 시 차단 안내가 표시됩니다. 횟수 차감 페널티 vs 잔여 0인 경우 "차감할 잔여가 없어요"가 뜨고 보류 또는 다음 결제 후 차감 옵션이 표시됩니다.

## 9. 데이터 흐름과 외부 연동

API는 페널티 목록 `GET /api/penalties`, 수동 부과 `POST /api/penalties`, 해제 `POST /api/penalties/:id/release`, 정책 조회 `GET /api/penalties/policy`, 정책 변경 `PUT /api/penalties/policy`입니다. 자동 페널티 크론(A05)은 매분 노쇼·늦은 취소를 자동 부과합니다. 출석 정정 webhook(CLS-02)은 노쇼 → 출석 정정 시 자동 페널티를 자동 해제하고 횟수도 복구합니다.

페널티 부과·해제 시 NFR-19 알림으로 회원·트레이너에게 알림이 발송되고 회원앱 마이페이지에 적용 중 페널티가 표시됩니다. SCR-097 감사 로그에 actor·penalty_id·member_id·reason이 모두 기록되며 데이터는 영구 보관됩니다.

## 10. 화면 상태와 예외 처리

페널티 적용 중 상태는 빨강 배지, 해제는 회색 배지, 자동 해제 상태는 노란 강조로 구분됩니다. 정책 비활성 상태에서는 "자동 페널티가 비활성화되어 있어요"가 표시됩니다. 본사 표준 정책 활성 상태에서는 변경이 차단되고 안내 라벨이 함께 표시됩니다.

예외로 사유·해제 사유 미입력은 인라인 에러, 횟수 차감 vs 잔여 0은 보류 또는 다음 결제 차감, 예약 제한 만료 후는 자동 해제 토스트, 출석 정정 시 자동 해제, 본사 표준 정책 변경 시도는 차단, 권한 부족(FC)은 등록·해제 버튼 숨김, 자동 부과 webhook 실패는 retry 3회 → 운영자 수동 부과 안내, 페널티 적용 중 회원의 예약 시도는 회원앱에서 자동 차단됩니다.

## 11. 권한별 처리

슈퍼관리자·본사 최고관리자·센터장·매니저는 페널티 등록·해제·정책 변경을 모두 수행합니다. 트레이너는 담당 회원 페널티 조회만 가능합니다. FC·스태프는 전체 페널티 조회만 가능하며 등록·해제 버튼이 숨겨집니다. readonly는 접근 불가입니다.

## 14. 핵심 디자인 요청사항

페널티 유형(노쇼/늦은 취소) 배지는 강한 빨강·주황 톤으로 명확히 구분되어야 합니다. 페널티 내용 컬럼은 "예약 제한 7일" + "횟수 차감 1회" 같이 복합 적용 가능하므로 줄바꿈을 통해 가독성을 확보합니다. 정책 설정 탭의 단계별 규칙은 시각화된 단계 차트(1회→3회→5회) 형태로 표시되어 운영자가 단계 흐름을 한눈에 이해할 수 있게 합니다. 본사 표준 정책 활성 상태는 정책 카드 위에 잠금 아이콘과 안내 텍스트로 명확히 표시됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

자동 페널티는 활성 시 노쇼 또는 늦은 취소 즉시 부과됩니다. 늦은 취소 기준 시간은 기본 2시간(수업 시작 2시간 전 이내 취소)이며 수업별로 차등 가능합니다. 페널티 내용은 예약 제한 기본 7일 / PT 횟수 차감 기본 1회이고 둘 다 복합 적용도 가능합니다.

단계별 정책(1회 노쇼: 7일 예약 제한 + 1회 차감, 누적 3회 노쇼: 14일 + 2회 차감, 누적 5회 노쇼: 30일 + 3회 차감 - 본사 권장값 기준, 지점 자율 조정 가능)은 운영 규율을 점진적으로 강화하기 위한 정책입니다. 누적 카운트 윈도우는 30/90(기본)/영구 중 본사가 결정합니다. 사유 필수(최소 5자), 부과·해제 알림 자동 발송, 모든 변경의 감사 로그 기록은 강제 정책입니다. manager가 강한 단계의 페널티 강도를 크게 증가시키려고 하면 owner 이상 승인 요청 흐름으로 자동 전환되며, 본사 표준 정책 적용 테넌트에서는 슈퍼관리자·본사 최고관리자만 변경 가능합니다(DLG-C015 정책).

수업별 차등 정책으로 PT는 횟수 차감, GX는 예약 제한 등 수업 유형별 페널티가 다를 수 있습니다. 횟수 차감 vs 잔여 0인 경우 정책에 따라 즉시 차단 또는 다음 결제 후 차감으로 처리됩니다. 예약 제한 적용 회원의 회원앱·운영자 등록 모두 차단되며 만료 후 자동 해제됩니다.

자동 페널티 크론(A05)은 매분 실행되어 노쇼·늦은 취소를 자동 부과하고, 출석 정정 시 자동 페널티 자동 해제 + 횟수 복구가 일어납니다. 본사 표준 정책은 활성 시 지점 변경이 차단되어 표준화가 보장됩니다. 신규 회원 면제 정책 활성 시 첫 노쇼는 경고만 부과되어 신규 회원 이탈을 막습니다.

페널티 이력은 영구 보관(분쟁 대응)이며 적용 중 페널티는 회원앱 마이페이지에 표시되어 사전 인지를 통한 분쟁 감소를 돕습니다.
