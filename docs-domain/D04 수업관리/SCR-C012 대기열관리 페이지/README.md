## 2. 화면 개요와 목적

대기열 관리 페이지는 만석이 된 그룹 수업의 대기 신청자를 관리하고 자리가 발생하면 자동 또는 수동으로 배정하는 화면입니다. 자동 배정 토글이 ON이고 회원이 자동 배정 동의 상태이면 자리 발생 시 순번 1번에게 자동 예약되고, 동의하지 않은 회원에게는 알림만 발송됩니다. 1번이 이용권 만료·페널티 적용 중이면 자동으로 다음 순번으로 넘어가는 스킵 로직이 작동합니다.

매니저는 VIP 회원을 우선 배정하기 위해 드래그로 순번을 조정할 수 있고(사유 입력 필수), 정원 확대(CLS-05) 시 동의 회원을 일괄 자동 배정할 수도 있습니다. 응답 만료 정책(24시간 미응답 시 자동 다음 순번)이 운영 부담을 줄이며, 대기자가 일정 수 이상이면 인기 수업 추가 개설 안내가 owner+에게 자동 발송됩니다.

## 3. 진입 경로와 인접 화면

사이드바의 "수업관리 > 대기열 관리"로 진입합니다. 인접 화면은 SCR-C001 캘린더(자리 발생 원천), SCR-C005 그룹수업현황(정원 확대 후 대기 일괄 배정), SCR-M004 회원 상세입니다.

## 4. 레이아웃과 UI 구성

페이지 헤더 아래에는 수업 선택 드롭다운(만석 수업 우선 노출)과 자동 배정 토글이 있습니다. 본문은 대기 신청자 목록 테이블이며 컬럼은 순번·회원명(클릭 시 SCR-M004)·연락처·대기 신청 일시·이용권 유효(유효/만료 배지)·자동 배정 동의(동의/알림만)·액션([수동 배정]/[대기 취소]/[알림])입니다.

매니저+는 드래그로 순번을 조정할 수 있으며 사유 입력이 필수입니다. 본사 통합 모드에서는 지점 컬럼이 추가됩니다.

## 5. 탭 구성과 탭별 동작

탭은 없으며 수업 선택 드롭다운으로 화면 내용을 전환합니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

수업 선택 드롭다운에서 수업을 고르면 그 수업의 대기열이 표시됩니다. 자동 배정 토글은 매니저+가 ON/OFF 할 수 있으며 활성 시 자리 발생 webhook에 의해 1번부터 순차 시도됩니다.

행의 [수동 배정] 버튼은 FC/스태프/매니저+가 사용할 수 있으며 즉시 예약 확정 + 회원 알림을 처리합니다. [대기 취소]는 회원 본인 또는 매니저+가 수행할 수 있고, [알림]은 자리 발생 알림을 대기자에게 수동 발송합니다(자동 미동의 회원용).

매니저+는 드래그로 순번을 변경할 수 있으며 변경 시 사유 입력 모달이 뜹니다. 회원 검색 + 순번 추가로 운영자가 직접 대기자를 등록할 수도 있습니다.

## 7. 호출되는 모달 동작

본 화면은 자체 호출 다이얼로그가 없으며, 순번 변경 사유 입력은 인라인 모달, 대기 취소 확인은 단순 yes/no 팝업으로 처리됩니다.

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 "회원을 수동 배정했어요", "대기자에게 알림을 발송했어요", "순번을 변경했어요"입니다. 자동 배정 webhook 결과 토스트는 "1번이 만료되어 2번으로 넘어갔어요" 같이 스킵 사유를 명시합니다. 응답 만료 시 "24시간 미응답으로 다음 순번에 넘어갔어요" 토스트가 자동 안내됩니다.

## 9. 데이터 흐름과 외부 연동

API는 대기열 조회 `GET /api/waitlist/:lessonId`, 추가 `POST /api/waitlist/:lessonId`, 배정 `POST /api/waitlist/:lessonId/assign`, 취소 `DELETE /api/waitlist/:lessonId/:memberId`, 알림 발송 `POST /api/waitlist/:lessonId/notify`, 자동 배정 토글 `PUT /api/waitlist/:lessonId/auto-assign`입니다.

자리 발생 webhook(회원 취소·정원 확장)이 자동 배정 잡을 트리거합니다. 응답 만료 잡(매분)이 24시간 초과 미응답을 다음 순번으로 넘기고, 인기 수업 추가 개설 안내 잡(매일 04:00)이 대기자 N명 이상인 수업을 owner+에게 알립니다. 회원 탈퇴 webhook은 대기 자동 취소를 처리하고 모든 변경은 SCR-097 감사 로그에 기록되며 90일 보관됩니다.

## 10. 화면 상태와 예외 처리

대기자 없음 상태에서는 "대기 신청자가 없어요"가 표시됩니다. 대기자 있음 상태는 순번별 목록을 보여주고 자동 배정 활성 시 "자리 발생 시 자동 처리됩니다" 안내가 함께 표시됩니다. 이용권 만료 회원은 회색 + "만료" 라벨, 페널티 적용 중은 빨강 + "예약 제한" 라벨로 표시됩니다.

예외로 자동 배정 vs 미동의 1번은 알림만 + 다음 순번, 만료 회원은 자동 스킵, 페널티 회원도 자동 스킵, 응답 만료 24시간은 자동 다음 순번, 시작 임박 자리 발생은 정책에 따라 차단 또는 즉시 배정, 순번 변경 사유 미입력은 차단, 동시 순번 변경 충돌은 낙관적 락 재로드, 회원 탈퇴는 자동 취소, 권한 부족(트레이너)은 액션 숨김 + 조회만, 자동 배정 webhook 실패는 retry 3회 → 운영자 수동 배정 안내가 적용됩니다.

## 11. 권한별 처리

슈퍼관리자·본사 최고관리자·센터장·매니저는 수동·자동·취소·순번 변경을 모두 수행합니다. 트레이너는 담당 수업 대기열을 조회만 합니다. FC·스태프는 수동 배정과 알림 발송이 가능합니다. readonly는 접근 불가입니다.

## 14. 핵심 디자인 요청사항

순번 번호는 큰 숫자로 좌측 컬럼에서 가장 두드러지게 표시되어 대기 순서를 한눈에 알 수 있어야 합니다. 자동 배정 동의 / 알림만 배지는 색상으로 명확히 구분되어 운영자가 자동 처리 가능 회원을 빠르게 식별할 수 있어야 합니다. 이용권 만료·페널티 적용 라벨은 행 좌측 인디케이터로 표시되어 자동 스킵이 일어날 수 있음을 사전에 알립니다. 매니저의 드래그 순번 조정은 시각 피드백 + 사유 입력 모달로 의도가 명확히 기록되도록 합니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

자동 배정은 자동 배정 동의 회원에 한해 적용되며 미동의 회원은 알림만 받습니다. 자리 발생 시 순번 1번에게 우선 배정되며 이용권 만료·페널티 적용 중이면 다음 순번으로 자동 스킵됩니다. 응답 만료 정책은 24시간이며 미응답 시 자동 다음 순번 또는 자리 회수(정책에 따름)입니다.

순번 변경은 매니저+만 가능하며 사유 입력이 필수입니다. 대기 취소는 회원 본인 또는 매니저+가 수행할 수 있고 자동 재정렬됩니다. 수동 배정은 매니저+ 또는 FC/스태프가 수행할 수 있습니다.

시작 임박 자리 발생(수업 시작 N시간 전 이내)은 정책에 따라 자동 배정 차단 또는 즉시 배정으로 처리됩니다. 회원앱 대기 신청은 즉시 본 화면에 반영되고 회원 탈퇴 webhook은 대기 자동 취소를 처리합니다.

CLS-05 정원 확대 webhook은 동의 회원을 일괄 자동 배정하는 후속 처리를 트리거합니다. 인기 수업 추가 개설 안내는 대기자 N명 이상 시 owner+에게 매일 04:00 잡으로 발송됩니다.

데이터 보관 기간은 신청·취소·배정 이력 90일이며 모든 변경은 감사 로그에 기록됩니다. 본사 통합 모드는 지점 컬럼 + 전 지점 합산을 제공합니다.
