## 2. 다이얼로그 개요와 목적

캘린더에서 수업 블록을 클릭했을 때 그 수업의 상세 정보를 빠르게 보여주는 읽기 중심 모달입니다. 수업 기본 정보·예약 현황·출석 상태 요약을 한 화면에 모으고 후속 액션(수정·취소·출석 처리·승인/거절)으로 바로 진입할 수 있게 합니다. 데이터 변경은 자체에서 처리하지 않고 DLG-C001 또는 SCR-C011 유효 수업 목록으로 위임합니다.

## 3. 호출 트리거와 진입 시 초기값

캘린더 수업 블록 클릭 또는 우측 패널의 수업 카드 클릭으로 열립니다. 진입 시 해당 수업의 모든 필드 값이 미리 채워진 상태로 표시됩니다. 미승인 상태 블록을 owner 이상이 클릭하면 모달 하단에 "승인"·"거절" 버튼이 추가로 노출됩니다.

## 4. 레이아웃과 표시 항목

모달 상단에는 수업명과 수업 유형 배지, 강습 세션 유형 배지(있는 경우)가 표시됩니다. 본문은 카드 형태로 정렬된 정보 영역입니다.

표시 항목은 다음과 같습니다. 일시 정보(날짜, 시작~종료 시간), 강사명, 장소/룸, 예약 현황(현재 예약 인원 / 정원, 잔여 자리 수), 예약 회원 목록(간략히), 출석 상태 요약(출석/결석/노쇼/미처리 건수), 분류(상담·OT·수업·PT 등), 승인 상태(미승인 일정인 경우 강조).

모달 하단에는 액션 버튼이 배치됩니다. [수정]은 DLG-C001 수정 모드 진입, [취소]는 수업 취소 확인 후 상태 변경, [출석 처리]는 SCR-C011 유효 수업 목록 이동, [승인]/[거절]은 미승인 일정에 한해 노출됩니다.

## 5. 액션과 검증

[수정]은 DLG-C001을 수정 모드로 다시 엽니다. [취소]는 사유 입력(최소 5자) 후 확인하면 수업 상태가 "취소"로 변경되며 예약 회원에게 자동 알림이 발송되고 PT 횟수가 자동 복구됩니다. 결제 완료 1회권은 SCR-S007 환불 화면 안내가 함께 표시됩니다. [출석 처리]는 SCR-C011 유효 수업 목록으로 이동시켜 정밀 출석/노쇼 처리를 수행하게 합니다.

[승인]은 owner 이상이 사용 가능하며 미승인 상태를 활성으로 전환합니다. [거절]은 사유를 받아 미승인을 "취소"로 전환합니다.

## 6. 화면 상태와 예외 처리

기본 표시 상태에서는 부모 화면에서 받은 최신 값을 불러옵니다. 권한 제한 상태에서는 일부 액션 버튼이 비활성화되거나 숨겨집니다. readonly 계정은 모든 액션 버튼이 비활성화됩니다.

예외로 권한이 없는 사용자가 미승인 일정을 클릭해도 승인/거절 버튼이 노출되지 않습니다. 트레이너가 타 강사 수업의 [수정] 클릭 시 DLG-C001이 read-only로 열립니다. 동시 편집 충돌은 부모 화면에서 stale 데이터 안내로 처리됩니다.

## 7. 권한별 동작

owner / manager는 모든 액션을 수행할 수 있으며 미승인 승인은 owner+에 한정됩니다. trainer는 본인 담당 수업이면 수정/취소가 가능하고 타 강사 수업은 조회만 가능합니다. fc / staff는 조회만 가능하며 [출석 처리] 이동만 사용할 수 있습니다. readonly는 모든 액션 버튼이 비활성화됩니다.

## 8. 부모 화면과의 상호작용

수정·취소·승인 처리 후 모달이 닫히고 SCR-C001 캘린더 블록과 우측 패널 카드가 즉시 갱신됩니다. 미승인 → 활성 전환 시 미승인 배너 카운트가 -1 감소합니다. 모든 변경은 감사 로그에 기록되고 회원 알림이 자동 발송됩니다.

## 9. 데이터 흐름과 외부 연동

본 모달은 별도 API를 갖지 않고 부모 화면에서 로드된 일정 데이터를 표시합니다. [취소] 액션은 `POST /api/lessons/:id/cancel`, [승인]/[거절]은 일정 상태 변경 API를 호출합니다. CLS-07 횟수 복구·NFR-19 알림·SCR-097 감사 로그가 동시에 트리거됩니다.

## 12. 디자인 요청사항

상태 배지와 강습 세션 유형 배지는 모달 상단에서 가장 두드러져야 합니다. 정원 진행 바는 예약 현황 카드에서 시각적 우선순위가 높고 잔여 자리가 한눈에 들어와야 합니다. 미승인 상태에서는 모달 외곽선이 주황 톤으로 강조되어 일반 일정과 구분됩니다. 출석 상태 요약은 출석/결석/노쇼/미처리를 색상 배지로 동시에 표시해 운영자가 처리 진척도를 즉시 파악할 수 있어야 합니다.

## 13. 운영 정책

본 모달은 읽기 중심이며 데이터 변경은 DLG-C001 또는 SCR-C011로 위임됩니다. 미승인 승인은 owner 이상 권한자에게만 노출되어 운영 권한 분리를 강제합니다. 취소 시 사유 텍스트 최소 5자 필수, PT 횟수 자동 복구, 회원 자동 알림 발송이 모두 트랜잭션으로 묶여 일부 실패 시 롤백됩니다. 결제 완료 1회권 수업 취소는 SCR-S007 환불 화면 안내가 함께 표시됩니다. 모든 액션은 감사 로그에 기록되어 5초 안에 SCR-097에서 조회 가능합니다.
