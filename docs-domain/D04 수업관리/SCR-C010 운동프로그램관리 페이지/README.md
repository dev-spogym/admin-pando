## 2. 화면 개요와 목적

운동 프로그램 관리 페이지는 트레이너가 회원에게 제공할 맞춤 운동 프로그램을 만들고, 동작·세트·반복·중량을 구성해 회원에게 배정하는 콘텐츠 라이브러리 화면입니다. 한번 배정한 프로그램은 회원의 PT 세션에서 DLG-C011 세션상세에 자동 노출되어 강사 화면에서 즉시 활용할 수 있습니다. 회원앱에서는 본인 프로그램과 수행 기록을 확인할 수 있습니다.

트레이너는 본인이 작성한 프로그램만 수정·삭제·배정할 수 있고 매니저는 조회·삭제만 가능합니다(트레이너 퇴사 등 정리 목적). 권장 자동 생성은 v1에서 제외하고 v2 또는 별도 협의 범위로 둡니다. 회원 목표·체성분 데이터는 검색·필터 참고 정보로만 사용합니다.

## 3. 진입 경로와 인접 화면

사이드바의 "수업관리 > 운동 프로그램 관리"로 진입합니다. 인접 화면은 SCR-C002 수업관리(세션 진행 시 노출), SCR-M004 회원 상세, 회원앱 운동 기록 화면입니다.

## 4. 레이아웃과 UI 구성

페이지 헤더 우측에는 [+ 프로그램 등록] 버튼과 필터 토글(내 프로그램만 보기·배정 회원 있는 것만·활성/비활성)이 있습니다. 본문은 프로그램 목록이며 카드 또는 테이블 뷰로 표시됩니다. 한 행에 프로그램명·담당 트레이너·배정 회원 수·동작 수·생성일·마지막 수정일·활성 토글이 표시됩니다.

행 클릭 시 프로그램 상세/수정 드로어가 열리며 동작 목록(동작명·세트·반복·휴식·중량·메모)을 드래그&드롭으로 순서 변경할 수 있습니다. 회원 배정은 회원 검색 + 다중 선택으로 추가합니다.

## 5. 탭 구성과 탭별 동작

탭은 없으며 필터 토글 조합으로 목록을 좁힙니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

[+ 프로그램 등록]은 등록 드로어를 엽니다. 프로그램명(1~50자 필수, 활성 중복 차단), 카테고리(근력/유산소/유연성/회복/다이어트/재활), 난이도(초급/중급/고급), 동작 목록(동작 라이브러리 검색 또는 직접 입력)을 입력합니다. 동작 순서는 드래그&드롭으로 즉시 저장됩니다.

행의 활성 토글은 ON/OFF로 신규 추천 목록에서 숨길 수 있습니다. 행의 [회원 배정] 버튼은 회원 검색 + 다중 선택 후 일괄 추가합니다. 행의 [삭제] 버튼은 트레이너 본인 작성 프로그램은 트레이너가 삭제 가능, 매니저+는 모든 프로그램 삭제 가능합니다. 삭제 시 배정 회원이 있으면 회원에게 안내 발송 후 삭제됩니다.

## 7. 호출되는 모달 동작

### 7-1. DLG-C011 세션상세 다이얼로그
프로그램 상세 드로어의 세션 기록 행 클릭으로 조회 모드 진입하거나, SCR-C011 유효 수업 목록의 "세션 기록 입력"·DLG-C005 수업기록상세의 "세션 기록 보기"를 통해서도 호출됩니다. PT 세션 진행 시 호출되면 배정된 프로그램이 자동 노출되고, 동작별 실제 수행 기록(실제 세트·반복·중량)을 입력하면 회원앱 운동 기록과 동기화됩니다. trainer 본인이 진행한 세션에 한해 입력·수정·저장 가능하며, 수업 종료 후 7일 경과 시 manager+만 사후 수정 가능합니다(현장 기록 책임 강화 정책).

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 "프로그램을 등록했어요", "회원에게 프로그램을 배정했어요"입니다. 차단 안내는 "이미 같은 이름의 프로그램이 있어요", "최소 1개 동작이 필요해요"입니다. 본인 외 프로그램 수정 시도는 read-only 모드 안내가 표시됩니다.

## 9. 데이터 흐름과 외부 연동

API는 목록 `GET /api/exercise-programs`, 등록 `POST /api/exercise-programs`, 수정 `PUT /api/exercise-programs/:id`, 배정 `POST /api/exercise-programs/:id/assign`, 배정 해제 `DELETE /api/exercise-programs/:id/assign/:memberId`입니다. PT 세션 시 자동 노출은 DLG-C011 호출 시 회원의 배정 프로그램을 조회해 표시합니다. 회원앱 운동 기록은 webhook으로 즉시 동기화됩니다.

회원 탈퇴 webhook은 배정을 자동 해제하고, 트레이너 퇴사 webhook은 매니저 검토 후 삭제 또는 다른 트레이너에게 이관됩니다. 등록·수정·삭제·배정 이력은 SCR-097 감사 로그에 기록되며 90일 보관됩니다.

## 10. 화면 상태와 예외 처리

기본 목록은 전체 프로그램이며 활성/비활성 토글로 필터링됩니다. 프로그램 0건 상태는 등록 CTA가 표시됩니다. 배정 회원 0명 상태는 "배정 회원이 없어요"가 표시됩니다. 비활성은 회색 처리되고 매니저 모드에서는 본인 외 프로그램이 read-only 모드입니다. 권장 자동 생성은 v1에서 미제공이며 수동 선택/작성이 기본입니다.

예외로 프로그램명 미입력·중복·동작 0개 저장 시도는 인라인 에러, 트레이너의 타 프로그램 수정 시도는 read-only, 매니저의 본인 프로그램 작성 시도는 권한 안내(트레이너만 작성), 삭제 시 배정 회원 있음은 확인 모달 + 회원 안내, 회원 탈퇴는 자동 해제, 동작 순서 동시 변경 충돌은 최신 값 재로드, FC 접근은 차단됩니다.

## 11. 권한별 처리

트레이너는 본인 작성 프로그램의 생성·수정·삭제·배정을 모두 수행합니다. 매니저·센터장·슈퍼관리자·primary는 전체 프로그램 조회 + 삭제(트레이너 퇴사 등 정리 목적)만 가능하며 작성은 트레이너 전용입니다. FC·스태프는 접근 불가 또는 조회만 가능합니다. readonly는 접근 불가입니다.

## 14. 핵심 디자인 요청사항

프로그램 목록은 동작 수와 배정 회원 수가 가장 두드러져 사용 현황을 한눈에 알 수 있어야 합니다. 동작 라이브러리 검색은 카테고리 필터와 함께 검색되어 트레이너가 빠르게 원하는 동작을 찾을 수 있게 합니다. 드래그&드롭 순서 변경은 즉시 시각 피드백과 함께 저장되며 변경 토스트가 따라옵니다. 트레이너의 본인 작성 / 매니저의 read-only는 카드 우상단 작은 잠금 아이콘으로 구분됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

트레이너는 본인 작성 프로그램만 수정 가능하며 매니저는 삭제만 가능합니다. 회원 배정 후에는 PT 세션에서 자동 노출됩니다. 비활성 프로그램은 배정 가능하나 신규 회원 추천 목록에서는 제외됩니다.

권장 프로그램 v1 정책: 자동 생성하지 않고 트레이너가 기존 프로그램 또는 템플릿을 직접 선택해 회원에게 배정합니다. 회원 목표·체성분 데이터는 검색·필터 참고 정보로만 사용하며 자동 생성은 v2 또는 별도 협의 범위입니다.

동작 순서는 드래그&드롭으로 즉시 저장됩니다. 프로그램명은 1~50자 필수, 활성 중복 차단입니다. 동작 라이브러리는 본사 표준 동작 + 트레이너 커스텀 동작으로 구성됩니다. 카테고리는 근력/유산소/유연성/회복/다이어트/재활 등 테넌트 커스터마이즈 가능합니다.

회원 탈퇴 시 배정 자동 해제, 트레이너 퇴사 시 매니저 검토 후 삭제 또는 다른 트레이너에게 이관됩니다. MBR 종합평가 결과에 따라 프로그램 변경 안내가 가능합니다. 회원앱 동기화는 배정·수정·해제 즉시 반영되며 동작 라이브러리도 본사 표준 동작 변경 시 지점 자동 동기화됩니다.

이력은 90일 보관(분쟁 대응)이며 본 화면의 등록·수정·삭제·배정은 모두 감사 로그에 기록됩니다.
