# DLG-S012 목표 매출 설정 다이얼로그

## 1. 다이얼로그 메타 정보

이 문서는 월·분기·연간 매출 목표 금액을 설정·수정해 매출 예측과 달성률 표시의 기준값을 갱신하는 목표 매출 설정 다이얼로그(DLG-S012)에 대한 자기완결형 요구사항 정의서입니다. 외부 문서 없이도 이 문서 한 장만으로 호출 트리거, 입력 폼, 검증, 확인·취소 동작, 부모 화면 갱신, 권한, 예외 처리, 운영 정책까지 모두 이해해 구현·운영할 수 있도록 작성합니다.

## 2. 다이얼로그 목적과 사용 맥락

목표 매출 설정 다이얼로그는 Owner(지점장)·매니저가 운영 계획의 기준이 되는 매출 목표 금액을 시스템에 등록·수정하는 입력 모달입니다. SAL-07 운영 시나리오에 따르면 매월 초 Owner(지점장)이 그 달의 목표를 정하고, 분기 시작 시 분기 목표를 정하며, 연초에 연간 목표를 정하는 정기적 운영 루틴이 있습니다. 본 다이얼로그는 그 루틴을 시스템에서 실행하는 도구입니다.

이 다이얼로그가 다루는 운영 흐름은 네 가지입니다. 첫째는 월간 목표 신규 설정 흐름으로, 새 달이 시작되기 전 또는 직후 Owner(지점장)이 그 달의 매출 목표를 입력합니다. 둘째는 분기/연간 목표 설정 흐름으로, 분기·연간 단위로 더 큰 목표를 별도로 설정합니다. 셋째는 기존 목표 수정 흐름으로, 운영 환경 변화(시즌·프로모션·외부 이벤트)에 따라 이미 설정된 목표를 중간에 조정합니다. 넷째는 1억원+ 대형 목표 승인 흐름으로, 본사 정책에 따라 일정 금액 이상의 목표는 본사 슈퍼관리자의 승인을 거쳐 적용됩니다.

다이얼로그는 입력 즉시 SCR-S011 매출 예측의 달성률 게이지를 실시간으로 갱신하고, SCR-S001·SCR-S004의 목표 대비 표시도 함께 갱신합니다. 목표 변경 이력은 모두 감사 로그에 기록되어 사후 추적이 가능합니다.

## 3. 호출 트리거와 부모 화면 컨텍스트

이 다이얼로그는 다음 세 가지 진입점에서 호출됩니다.

첫 번째 진입점은 SCR-S011 매출 예측 페이지의 "목표 설정" 버튼입니다. 부모는 현재 선택된 예측 기간(다음 달/다음 분기/연간)을 컨텍스트로 전달하며, 다이얼로그는 그 기간의 기존 목표를 자동 로드해 입력란에 채워줍니다.

두 번째 진입점은 SCR-S001 매출 현황 페이지의 "목표 설정" 버튼입니다. 부모는 현재 조회 중인 기간(이번 달이 기본)을 컨텍스트로 전달합니다.

세 번째 진입점은 SCR-S004 매출 통계 페이지의 "목표 설정" 버튼입니다. 부모는 통계 기간 필터의 값을 컨텍스트로 전달합니다.

다이얼로그가 받는 컨텍스트는 기본 기간 단위(MONTH/QUARTER/YEAR), 기본 기간 값(예: 2026-05), 기존 목표 금액(있을 경우), 부모 화면 식별자입니다. 기존 목표가 있는 경우 다이얼로그는 "기존 목표 수정" 모드로 시작하고, 없는 경우 "신규 목표 설정" 모드로 시작합니다.

## 4. 레이아웃과 UI 구성

다이얼로그는 데스크톱에서 가로 480px의 중앙 정렬 모달이고, 모바일에서는 풀너비 시트로 표시됩니다. 위에서 아래로 다음 영역이 순차 배치됩니다.

가장 위에는 다이얼로그 헤더가 있습니다. 좌측에 "목표 매출 설정" 제목, 우측 끝에 X 닫기 버튼이 있습니다. 헤더 아래에 모드 안내(신규 목표 설정 / 기존 목표 수정)가 작은 라벨로 표시됩니다.

헤더 아래에는 설정 기간 선택 영역이 있습니다. 첫 번째 컨트롤은 기간 단위 라디오(월 / 분기 / 연간)로, 사용자가 어떤 단위의 목표를 설정할지 결정합니다. 두 번째 컨트롤은 기간 값 선택 드롭다운/날짜 피커로, 단위에 따라 컨트롤이 달라집니다. 월이면 월 선택기(2026-05 형식), 분기면 분기 선택기(2026 Q2), 연간이면 연도 선택기(2026)가 표시됩니다.

설정 기간 아래에는 기준 유형 선택 영역이 있습니다. 라디오 또는 토글로 "전체 매출 목표"와 "상품 카테고리별 목표"를 선택할 수 있습니다. 전체 매출 목표는 단일 금액 하나만 입력하면 되고, 상품 카테고리별 목표를 선택하면 카테고리(멤버십·PT·필라테스·락커·운동복 등)별로 별도 금액 입력란이 펼쳐집니다.

기준 유형 아래에는 이전 기간 실적 카드가 표시됩니다. SAL-07 "이전 기간 실적: 동일 기간의 전년도 또는 전월 실제 매출액 (참고용)" 정책에 따라, 운영자가 목표 입력의 근거로 활용할 수 있는 참고 정보가 표시됩니다. 카드에는 전월 실제 매출, 전년 동월 매출(있을 경우), 전년 YoY 증감률, 최근 3개월 평균 매출이 한눈에 비교되도록 정렬됩니다. 운영자는 이 정보를 참고해 합리적인 목표를 입력할 수 있습니다.

그 아래에는 목표 금액 입력란이 있습니다. 천 단위 콤마가 자동 포맷되며, 입력값이 0원이면 입력 안내가 표시되고 저장 버튼이 비활성화됩니다. 입력값 우측에는 전월 대비 증가율이 실시간으로 표시되어(예: "전월 대비 +15%"), 운영자가 목표의 공격성·보수성을 즉시 판단할 수 있게 합니다. 목표가 1억원을 초과하면 입력란 아래에 "1억원 초과 목표는 본사 승인 후 적용됩니다" 안내가 표시됩니다.

목표 금액 아래에는 적용 시점 선택이 있습니다. 라디오로 "즉시 적용"과 "다음 기간부터 적용" 중 선택합니다. SAL-07 "즉시 vs 다음 기간 적용" 정책에 따라, 즉시 적용은 현재 진행 중인 기간의 목표를 변경하는 것이고, 다음 기간 적용은 다음 월/분기/연부터 새 목표를 적용한다는 의미입니다. 둘 중 하나는 반드시 선택해야 하며 기본값은 "즉시 적용"입니다.

마지막 섹션은 변경 사유 입력란(선택)입니다. 자유 형식 textarea로 최대 300자까지 입력 가능하며, 기존 목표를 수정하는 경우 권장 입력으로 안내됩니다. 변경 사유는 감사 로그에 함께 기록됩니다.

다이얼로그 가장 아래에는 액션 바가 있습니다. 우측에 회색 "취소" 버튼과 강조색 "저장" 버튼이 나란히 놓입니다. 1억원+ 목표인 경우 저장 버튼 라벨이 "본사 승인 요청"으로 자동 변경되어 운영자가 일반 저장과 구분할 수 있게 합니다.

## 5. 입력 검증과 자동 계산

목표 매출 설정은 다음 검증을 순서대로 통과해야 저장됩니다.

첫째, 기간 검증입니다. 설정 기간은 과거가 아닌 현재 또는 미래여야 합니다. 과거 기간의 목표를 사후에 설정하는 것은 의미가 없으므로 차단되며, 단 본사 권한자에게는 마이그레이션 목적으로 과거 일자 허용 토글이 제공될 수 있습니다.

둘째, 목표 금액 검증입니다. 1원 이상이어야 하며, 0원 또는 음수는 차단됩니다. SAL-07 "목표 0원 처리: 목표 0원이면 게이지 hidden, 입력 안내" 정책에 따라 0원은 입력 자체가 차단됩니다.

셋째, 카테고리별 목표 합계 검증입니다. 상품 카테고리별 목표를 선택한 경우 모든 카테고리의 합계가 자동 계산되어 영역 하단에 표시됩니다. 운영자가 합계를 인식하지 못한 채 카테고리별 목표를 따로 입력하는 사고를 막기 위해 합계가 항상 표시됩니다.

넷째, 적용 시점 검증입니다. 둘 중 하나는 반드시 선택해야 하며, 미선택 상태에서는 저장 버튼이 비활성화됩니다.

다섯째, 1억원+ 목표 승인 검증입니다. SAL-07 "목표 승인 워크플로우: 1억원+ 목표는 본사 슈퍼관리자 승인 필수 (정책 토글)" 정책에 따라, 입력 금액이 1억원을 초과하면 즉시 저장이 아닌 본사 승인 요청으로 분기됩니다. 저장 버튼 라벨이 "본사 승인 요청"으로 변경되고, 클릭 시 승인 큐에 등록됩니다. 본사 슈퍼관리자가 별도 승인 화면에서 승인하면 목표가 실제 적용됩니다.

여섯째, 권한 검증입니다. FC 이하 권한자는 다이얼로그가 열리지 않으며, 직접 API 호출 시도는 403으로 차단됩니다.

전월 대비 증가율 자동 계산은 입력 금액과 부모 화면에서 받은 이전 기간 실적을 비교해 즉시 계산됩니다. 입력 도중 실시간으로 갱신되며, 마이너스 증가(목표가 전월보다 낮음)도 그대로 표시되어 운영자가 의도된 보수적 목표인지 인지할 수 있게 합니다.

## 6. 확인·취소 동작과 부모 화면 갱신

저장 버튼을 누르면 다이얼로그는 즉시 로딩 상태로 전환되어 모든 버튼이 비활성화되고, 저장 버튼 라벨이 "저장 중..." 또는 "승인 요청 중..."으로 바뀝니다.

일반 저장(1억원 이하) 성공 응답이 도착하면 다이얼로그가 자동으로 닫히고 부모 화면이 갱신됩니다. 부모 화면별로 다음 갱신이 일어납니다. 부모가 SCR-S011 매출 예측이면 달성률 게이지가 즉시 새 목표 기준으로 재계산되어 표시되고, 12개월 예측 테이블의 목표 컬럼이 갱신되며, 차트의 목표 라인이 새 값으로 그려집니다. 부모가 SCR-S001 매출 현황이면 목표 대비 달성률 표시가 갱신됩니다. 부모가 SCR-S004 매출 통계이면 통계 차트의 목표 라인이 갱신됩니다.

1억원+ 목표 승인 요청 성공 응답이 도착하면 다이얼로그가 자동으로 닫히고 부모 화면에 "본사 승인 요청을 보냈어요" 토스트가 표시됩니다. 목표는 아직 적용되지 않으며 부모 화면의 게이지·라인은 변경되지 않습니다. 본사 슈퍼관리자가 별도 화면에서 승인하면 그 시점에 게이지가 갱신됩니다.

저장 처리는 동시에 다음 시스템 영향을 미칩니다. SCR-097 감사 로그에 `sales_goal_set` 액션이 적재되고, 변경 전 목표 값과 변경 후 목표 값이 함께 기록됩니다. SAL-07 "예측 캐시 갱신: 5분마다, 갱신 시 무효화" 정책에 따라 5분 캐시가 즉시 무효화되어 예측 데이터가 새 목표로 갱신됩니다. SCR-101 대시보드의 매출 위젯도 다음 갱신 주기에 새 목표가 반영됩니다.

실패 응답이 오면 다이얼로그는 닫히지 않고 입력 내용이 보존됩니다. 4xx 입력 오류는 사유가 인라인 메시지로 표시되며, 동시 목표 변경 충돌(다른 운영자가 동시에 같은 기간 목표를 변경한 경우)은 SAL-07 "동시 목표 변경 충돌: 자동 재시도" 정책에 따라 자동 재시도가 수행됩니다.

취소 버튼은 다음과 같이 동작합니다. 입력 내용이 기존 값과 동일하면 즉시 다이얼로그를 닫습니다. 입력이 변경된 상태에서는 "변경 사항이 사라집니다. 닫으시겠습니까?" 확인 팝업이 표시됩니다.

ESC 키와 배경 클릭도 취소와 동일하게 동작합니다.

## 7. 화면 상태

다이얼로그는 다음 상태들을 가지며 각 상태마다 보이는 모습이 달라집니다.

기본 표시 상태는 다이얼로그가 갓 열린 직후의 상태로, 기존 목표가 있으면 자동 채워져 있고 없으면 빈 입력 상태입니다.

이전 기간 실적 로딩 중 상태는 참고용 실적 카드의 데이터를 로드 중인 상태로, 카드가 스켈레톤으로 표시됩니다.

전체 매출 목표 상태는 기준 유형 "전체 매출 목표"를 선택한 일반적인 상태로, 단일 금액 입력란만 표시됩니다.

카테고리별 목표 상태는 기준 유형 "상품 카테고리별 목표"를 선택한 상태로, 카테고리별 별도 입력란이 펼쳐지고 합계가 자동 계산되어 표시됩니다.

1억원+ 승인 대기 안내 상태는 입력 금액이 1억원을 초과한 상태로, "1억원 초과 목표는 본사 승인 후 적용됩니다" 안내와 함께 저장 버튼 라벨이 "본사 승인 요청"으로 변경됩니다.

저장 중 상태는 저장 버튼을 누른 직후의 상태로, 모든 입력이 잠기고 버튼이 "저장 중..."으로 표시됩니다.

승인 요청 중 상태는 1억원+ 목표의 본사 승인 요청 처리 중 상태로, 버튼이 "승인 요청 중..."으로 표시됩니다.

성공 완료 상태는 API 성공 응답을 받은 직후의 상태로, 다이얼로그가 자동으로 닫히고 부모 화면이 갱신됩니다.

승인 대기 상태는 1억원+ 목표가 본사 승인 큐에 등록된 상태로, 부모 화면에 "승인 대기" 토스트와 함께 부모 화면 게이지는 변경되지 않습니다.

실패 상태는 4xx 또는 5xx 응답을 받은 상태로, 입력 내용이 보존되고 사유에 따라 메시지가 표시됩니다.

동시 변경 충돌 상태는 다른 운영자가 같은 기간 목표를 동시에 변경한 상태로, 자동 재시도가 진행됩니다.

권한 부족 상태는 권한이 없는 계정의 직접 진입 시도로, 다이얼로그가 열리지 않습니다.

## 8. 예외 처리

네트워크 오류로 저장이 실패하면 "목표 설정에 실패했어요" 빨강 토스트가 표시되고 입력 내용은 보존됩니다. 자동 재시도는 1회 백그라운드에서 수행됩니다.

이전 기간 실적 로드 실패는 참고 카드에 "이전 실적을 불러올 수 없어요" 안내가 표시되지만, 목표 설정 자체는 계속 진행 가능합니다.

목표 0원 입력은 SAL-07 "목표 0원 처리" 정책에 따라 차단되며, 저장 버튼이 비활성화됩니다.

1억원+ 입력 시 본사 승인 요청으로 자동 분기되며, 저장 버튼 라벨이 변경됩니다.

동시 목표 변경 충돌(다른 운영자가 동시에 같은 기간 목표 변경)은 SAL-07 "동시 목표 변경 충돌: 자동 재시도" 정책에 따라 자동 재시도됩니다. 재시도가 실패하면 "다른 운영자가 동시에 변경했어요" 안내가 표시되고, 최신 값으로 재로드 옵션이 제공됩니다.

권한 부족(403)은 모달 닫기와 함께 부모 화면에 "권한이 없어요" 토스트를 띄우고 감사 로그에 권한 우회 시도가 기록됩니다.

본사 승인 요청이 이미 진행 중인 상태에서 같은 기간에 새 승인 요청을 시도하면 "이미 승인 대기 중인 요청이 있어요" 안내가 표시되고 중복 요청이 차단됩니다.

과거 기간 설정 시도는 일반 운영자에게는 차단되며, 본사 권한자가 마이그레이션 토글을 사용한 경우에만 허용됩니다.

다지점 RLS 누수가 감지되면 보안 이벤트가 즉시 발생하고 차단됩니다.

본사 통합 모드 권한 미달 상태에서 다른 지점 목표 설정 시도는 다이얼로그가 열리지 않습니다.

캐시 갱신 실패는 백그라운드에서 자동 재시도되며, 운영자에게는 별도 안내가 표시되지 않고 다음 5분 캐시 주기에 자연스럽게 갱신됩니다.

## 9. 권한별 처리

슈퍼관리자(superAdmin)와 본사 최고관리자(primary)는 전체 지점의 목표를 설정할 수 있으며, 본사 통합 모드에서 전 지점 목표 통합 관리도 가능합니다. 1억원+ 목표 승인 권한도 보유합니다.

Owner(지점장)과 매니저(manager)는 자기 지점의 목표를 설정할 수 있습니다. 1억원+ 목표는 본사 승인이 필요하므로 다이얼로그가 자동으로 승인 요청 모드로 전환됩니다.

FC(fc), 스태프(staff), 프런트(front), 트레이너(trainer), 읽기 전용(readonly)은 SAL-07 "권한별 가시성: 매니저+ 만 목표 설정" 정책에 따라 다이얼로그가 열리지 않습니다.

권한 우회 시도(직접 API 호출)는 403으로 차단되고 감사 로그에 기록됩니다.

본사 통합 모드는 본사 슈퍼관리자만 사용 가능합니다.

## 10. 운영 정책

이 다이얼로그는 SAL-07 매출 예측 기능의 입력 도구이며, 목표 변경이 즉시 예측 화면의 달성률 게이지에 반영되는 시각화 흐름의 시작점입니다.

목표 변경 감사 로그 적재(`sales_goal_set`)는 SAL-07 "목표 변경 감사: 목표 금액 변경 시 SCR-097 기록 (actor, period, before, after)" 정책의 결과이며, 누가 언제 어떤 기간 목표를 얼마에서 얼마로 바꿨는지가 사후에도 재구성 가능합니다.

이전 기간 실적 카드는 SAL-07 "이전 기간 실적: 동일 기간의 전년도 또는 전월 실제 매출액 (참고용)" 정책의 시각화이며, 운영자가 합리적 목표를 입력할 수 있도록 의사결정 근거를 제공합니다.

즉시 적용 vs 다음 기간 적용은 SAL-07 "즉시 vs 다음 기간 적용" 정책의 결과이며, 운영자가 기간 진행 중 목표 조정과 다음 기간 목표 미리 설정을 명확히 구분할 수 있게 합니다.

1억원+ 목표 본사 승인 워크플로우는 SAL-07 "목표 승인 워크플로우: 1억원+ 목표는 본사 슈퍼관리자 승인 필수 (정책 토글)" 정책의 결과이며, 대형 목표가 운영 부담을 무리하게 키우지 않도록 본사 검토를 거치게 합니다.

목표 0원 차단은 SAL-07 "목표 0원 처리: 목표 0원이면 게이지 hidden, 입력 안내" 정책에 따라 의미 없는 목표 설정을 사전에 차단합니다.

5분 캐시 무효화는 SAL-07 "예측 캐시: 5분 캐시, 갱신 시 무효화" 정책에 따라 목표 변경 즉시 캐시가 무효화되어, 새 목표가 예측 화면에 즉시 반영됩니다.

다지점 RLS 격리는 본사 통합 모드가 아닌 경우 자기 지점 목표만 설정 가능하다는 보안 정책의 결과입니다.

권한 매트릭스(매니저+ 만 설정)는 매출 목표가 운영 방향을 결정하는 의사결정이므로, 책임 있는 권한자에게만 설정 권한을 부여하는 정책입니다.

CFO 분기 보고서(SAL-07 "CFO 분기 보고서: 분기별 예측 vs 실적 자동 보고서") 자동 생성은 다이얼로그에서 설정한 목표가 보고서의 핵심 비교 기준이 되는 구조이며, 목표 변경이 보고서에 그대로 반영됩니다.

목표 변경 이력 5년 보관은 SAL-07 "데이터 보관: 예측 이력 5년 보관 (회계·세무)" 정책의 결과이며, 모든 목표 변경이 5년간 보존되어 회계·세무 점검에 활용됩니다.

이상의 정책은 목표 매출 설정 다이얼로그가 단순 입력 도구가 아닌 운영 의사결정의 핵심 진입점임을 보여줍니다.

## 13. 핵심 디자인 요청사항

이전 기간 실적 카드는 운영자가 합리적 목표 입력을 위한 의사결정 근거이므로, 다이얼로그 안에서 적절한 시각적 비중을 가져야 합니다. 전월·전년·최근 3개월 평균이 동일한 가독성으로 비교 가능하도록 정렬됩니다.

목표 금액 입력란은 다이얼로그의 시각적 중심이며, 큰 폰트와 천 단위 콤마 자동 포맷으로 입력 직후 자릿수를 즉시 인식할 수 있어야 합니다. 우측의 전월 대비 증가율은 부드러운 보조 정보로, 양수는 녹색, 음수는 빨강의 짧은 라벨로 표시됩니다.

1억원+ 안내는 입력 도중 자연스럽게 등장하는 인라인 안내로, 사용자에게 모드 전환을 알리되 위협적이지 않은 톤으로 디자인됩니다. 저장 버튼 라벨이 "저장" → "본사 승인 요청"으로 부드럽게 변경되는 시각 효과가 있어야 합니다.

카테고리별 목표 입력은 기준 유형 선택 시 부드럽게 아래로 펼쳐지는 아코디언 애니메이션으로 표시되고, 합계는 카테고리 입력란 바로 아래에 항상 표시되어 운영자가 의도와 입력값이 일치하는지 즉시 확인할 수 있게 합니다.

적용 시점 라디오는 두 옵션이 시각적으로 동등하게 배치되어 운영자가 의식적으로 선택하도록 설계됩니다.

변경 사유 입력란은 다이얼로그 하단에 작고 차분하게 배치되어, 권장 입력이지만 필수가 아니라는 위계를 시각적으로 전달합니다.

저장 버튼은 검증 통과 시에만 강조색으로 활성화되며, 1억원+ 모드에서는 라벨이 변경되어 사용자가 다른 흐름임을 즉시 인식할 수 있게 합니다.

성공 후 부모 화면의 달성률 게이지는 새 목표 기준으로 부드럽게 애니메이션 갱신되어, 운영자가 변경 결과를 즉시 시각적으로 확인할 수 있게 합니다.

모바일에서는 풀너비 시트로 전환되며, 입력란이 화면 대부분을 차지하도록 비율이 조정됩니다.

## 14. 운영 정책 (이 다이얼로그에 연결된 부분)

이 다이얼로그가 따르는 운영 정책은 SAL-07 매출 예측의 핵심 규칙들을 그대로 시각화한 것입니다.

목표 변경 감사 로그는 운영 의사결정의 추적성을 보장하기 위한 정책이며, before/after 값이 모두 기록되어 사후 분석에 활용됩니다.

이전 기간 실적 참고 표시는 운영자가 단순한 직관이 아닌 데이터 기반 의사결정을 할 수 있도록 돕는 정책의 시각화입니다.

즉시 적용 vs 다음 기간 적용 구분은 운영 기간 진행 중 조정과 다음 기간 미리 설정의 의미가 다르다는 운영 현실을 반영한 정책입니다.

1억원+ 본사 승인 워크플로우는 대형 목표 설정이 운영 부담을 무리하게 키우지 않도록 본사 검토를 거치게 하는 정책이며, 정책 토글로 임계값 변경이 가능합니다.

목표 0원 차단은 의미 없는 목표 설정을 사전에 차단해 게이지·차트의 표시 오류를 방지합니다.

5분 캐시 무효화는 목표 변경이 즉시 예측 화면에 반영되도록 보장하는 정책이며, 운영자가 결과를 즉시 확인할 수 있습니다.

다지점 RLS 격리는 자기 지점 목표만 설정 가능하다는 보안 정책의 결과이며, 본사 통합 모드에서만 다른 지점 목표 설정이 가능합니다.

권한 매트릭스(매니저+ 만 설정)는 매출 목표 설정이 운영 의사결정이므로 책임 있는 권한자에게만 권한을 부여하는 원칙의 결과입니다.

목표 변경 이력 5년 보관은 회계·세무 점검 가능성을 보장하기 위한 정책이며, 모든 목표 변경이 5년간 보존됩니다.

CFO 분기 보고서와의 연계는 이 다이얼로그에서 설정한 목표가 보고서의 핵심 비교 기준이 되는 구조이며, 목표 변경이 보고서에 자동 반영됩니다.

본사 통합 모드는 본사 슈퍼관리자만 사용 가능하며, 전 지점 통합 목표 관리가 본사 차원의 자원 배분 의사결정 도구로 사용됩니다.

이상의 정책은 목표 매출 설정 다이얼로그가 단순 입력 화면이 아닌 운영 의사결정의 시작점임을 보여줍니다. 정책이 바뀌면 이 문서도 함께 갱신되어야 합니다.
