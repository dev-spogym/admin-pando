## 2. 화면 개요와 목적

할부결제 관리 페이지는 회원이 분할 납부 방식(`collectionMode=INSTALLMENT_PLAN`)으로 결제한 할부 계약의 전체 현황을 한눈에 파악하고, 매월 납입 회차별 진행 상태를 추적하며 미납된 회차를 후속 관리하는 화면입니다. 어느 회원이 몇 회차까지 납부했고 잔여 금액이 얼마이며 다음 납입일이 언제인지를 즉시 확인하고, 미납 회차에는 경고 표시와 함께 납입 처리·연락 액션을 수행합니다.

운영 맥락은 다양합니다. 카운터 매니저는 매월 입금 확인 시 통장 입금 확인 후 회차 펼침 → [납입처리] → DLG-S008로 회수합니다. FC는 본인 담당 회원의 할부 추적을 회원명 검색으로 진행률·잔여 금액·다음 납입일 확인 후 입금 약속 통화와 메모 기록을 수행합니다. Owner(지점장)은 월말 미납 회차 점검 시 미납 탭에서 30일+ 연체 회차를 회수 작업 위임하고, 본사 슈퍼관리자는 통합 모드에서 지점별 회수율을 모니터링합니다.

이 화면은 `정기 분납 계획` 전용입니다. 계약금만 받고 잔액을 단기 미수금으로 남긴 건은 SCR-S008 미수금 관리에서 우선 다룹니다. 신규 할부 등록은 DLG-S009 할부 등록 모달로 진행하며, 자동 미납 감지 크론(매일 00:01)이 예정일+1일 경과 회차를 자동 "미납"으로 갱신합니다.

PAY-03 미수금 자동 동기화는 미납 회차가 PAY-03에 자동 등록되고, 회수 시 양쪽이 자동 갱신되도록 보장합니다. SAL-EXT-04 환불 진행 시 잔여 회차는 일괄 취소되며 미수 상계와 환불 계산이 함께 수행됩니다.

## 3. 진입 경로와 인접 화면

할부결제 관리 페이지에 진입하는 경로는 다음과 같습니다.

첫 번째 경로는 사이드바입니다. 좌측 사이드바의 "매출관리" 메뉴 아래 "할부결제 관리" 항목을 클릭하면 진입합니다. URL은 `/sales/installment`이며, 상태 탭은 "전체"가 기본 활성화됩니다.

두 번째 경로는 결제 처리(SCR-S003) 계약금 등록 + 정기 분납 계획 선택 완료 후 "할부 관리로 이동" 링크 또는 미수금 관리(SCR-S008)에서 발생 유형 "정기 할부 미납" 행의 "할부 상세 보기" 링크를 누를 때입니다.

세 번째 경로는 회원 상세(SCR-M004)의 할부 이력에서 특정 할부 건을 클릭할 때 또는 자동 미납 감지 알림(매일 00:01)에서 운영자가 알림을 클릭할 때입니다.

네 번째 경로는 D-3 자동 알림(NFR-05)에서 회원 또는 운영자가 알림을 클릭하거나 회차 D-Day 알림에서 진입할 때입니다.

이 화면에서 빠져나가는 인접 화면으로는, 회원명 클릭으로 진입하는 회원 상세(SCR-M004), 미납 회차의 미수금 관리는 SCR-S008, 환불 진입은 SCR-S012 또는 SCR-S007, 그리고 모든 등록·납입처리·메모·해지가 기록되는 감사 로그(SCR-097)가 있습니다.

## 4. 레이아웃과 UI 구성

할부결제 관리 페이지는 위에서 아래로 차곡차곡 쌓이는 세로형 단일 컬럼 레이아웃을 기본으로 합니다.

가장 위에는 페이지 헤더가 있습니다. 헤더 좌측에는 "할부결제 관리"라는 페이지 타이틀과 지점 컨텍스트 배지가 표시됩니다. 헤더 우측에는 [+ 할부 등록] 버튼과 [엑셀 내보내기] 버튼이 매니저+ 권한자에게 표시됩니다.

페이지 헤더 아래에는 요약 지표 카드 4개가 가로로 배치됩니다. 첫 번째 카드는 "진행 중인 할부 계약 수"로 status=ongoing 카운트를 표시합니다. 두 번째 카드는 "이번 달 납입 예정 건수"로 이번 달 회차 예정 합계를 표시합니다. 세 번째 카드는 "이번 달 납입 완료 건수"로 이번 달 입금 완료 합계를 표시합니다. 네 번째 카드는 "미납 총액"으로 기한 초과 회차 합계를 표시합니다. 각 카드는 클릭 가능하며, 진행중 탭·이번 달 필터·완료 필터·미납 탭으로 자동 라우팅됩니다.

요약 카드 아래에는 상태 탭 4개가 있습니다. 전체 / 진행중 / 완납 / 미납으로 펼쳐지며, 각 탭에 해당 건수 배지가 표시됩니다.

상태 탭 아래에는 검색 및 필터 영역이 있습니다. 회원명 검색 입력창(디바운스 300ms), 기간 범위 필터(계약 시작일·다음 납입일 기준), 계약 출처 필터(직접 등록 / 현장 결제 연계 / 결제링크 연계)가 가로로 배치됩니다.

검색·필터 아래에는 할부 계약 목록 테이블이 있습니다. 컬럼은 좌측부터 회원명 / 상품명 / 계약 출처 / 선납금 / 총 할부 금액 / 납입 완료 금액 / 잔여 금액 / 총 회차 / 납입 회차 (예: "12 / 4") / 다음 납입일 / 상태 배지 순서입니다.

상태 배지는 진행중(파랑)·완납(초록)·미납(빨강) 색상으로 즉시 구분됩니다. 다음 납입일은 D-Day로 표시되며, D-3 이내이면 빨강 강조됩니다. 잔여 금액은 빨강 강조로 표시됩니다.

계약 행을 클릭하면 하단에 회차별 납입 현황이 펼쳐집니다. 펼침 영역에는 컬럼별 회차 / 예정일 / 완료일 / 금액 / 상태(예정·완료·미납) / 액션([납입 처리] / [메모])이 표시됩니다. 회차별 펼침에서 미납 회차의 [납입 처리] 버튼을 누르면 DLG-S008이 호출됩니다.

본사 통합 모드에서는 테이블에 "지점" 컬럼이 추가됩니다.

페이지 가장 아래에는 페이지네이션이 배치됩니다. 페이지당 건수(20·50·100), 페이지 번호 이동, 총 건수 표시가 일반적인 동작을 수행합니다.

## 5. 탭 구성과 탭별 동작

이 화면은 상태 탭 4개를 가집니다. 전체 / 진행중 / 완납 / 미납으로 펼쳐집니다.

전체 탭은 모든 상태의 할부 계약을 표시합니다. 진행중 탭은 현재 회차가 진행 중인 계약(완납되지 않고 미납도 없는 계약), 완납 탭은 모든 회차가 완납된 계약, 미납 탭은 한 건 이상의 미납 회차가 있는 계약을 표시합니다.

각 탭의 우측에 건수 배지가 표시되어 분포를 즉시 파악할 수 있습니다. 미납 탭 배지는 빨강 강조이며, 30일 이상 연체 회차가 있는 계약은 행 옆에 추가 경고 라벨이 표시됩니다.

탭 전환 시 다른 필터(검색·기간·계약 출처)는 유지됩니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

요약 지표 카드 4개는 클릭 가능합니다. 진행 중 카드는 진행중 탭, 이번 달 예정·완료 카드는 이번 달 필터 적용, 미납 총액 카드는 미납 탭으로 자동 라우팅됩니다.

상태 탭 4개는 누르면 즉시 데이터 fetch와 탭 전환이 일어납니다. 다른 필터는 유지됩니다.

회원명 검색은 디바운스 300ms 후 자동 검색됩니다. 기간 범위 필터와 계약 출처 필터는 즉시 적용됩니다.

테이블의 계약 행 클릭은 회차 펼침을 토글합니다. 펼침 상태에서 회차별 [납입 처리] 버튼을 누르면 DLG-S008 납입 처리 모달이 호출됩니다. [메모] 버튼은 DLG-S005 메모 편집 모달을 엽니다.

회원명 클릭은 회원 상세(SCR-M004)로 이동시킵니다. 탈퇴 회원은 회원 카드 진입이 차단되고 할부 정보만 표시됩니다. 상품명 클릭은 상품 상세(SCR-P003)로 이동시킵니다.

페이지 헤더의 [+ 할부 등록] 버튼은 DLG-S009 할부 등록 모달을 엽니다. 매니저+ 권한자에게만 표시되며, FC는 등록 불가입니다.

[엑셀 내보내기] 버튼은 현재 필터가 적용된 할부 계약 목록을 엑셀로 다운로드합니다. 파일명은 `yyyymmdd_지점_할부계약목록.xlsx` 규칙이며, 30,000건 초과 시 백그라운드 다운로드로 분기됩니다.

회차 펼침 영역에서 회원 신용 검증 경고(미수 3건 이상)는 행 옆에 "주의" 라벨로 표시됩니다.

테이블 우측 상단의 정렬 옵션 드롭다운은 다음 납입일 가까운 순/잔여 금액 큰 순/총 할부 금액 큰 순/등록일 최신 순 중 선택할 수 있습니다.

DLG-S007 할부 상세 모달은 페이지 헤더의 회원 검색 결과 또는 회원 상세에서 진입할 때 호출됩니다. 모달에서 중도 상환·계약 해지·납입 처리 등 후속 액션이 가능합니다.

모든 버튼은 클릭 후 응답이 돌아오기 전까지 자동으로 비활성화됩니다.

## 7. 호출되는 모달 동작

이 화면에서 호출되는 모달은 네 가지입니다.

### 7-1. DLG-S007 할부 상세 모달

할부 상세 모달은 할부 결제 건의 전체 납입 현황을 회차별로 확인하는 모달입니다. 회원 상세나 외부 진입 경로에서 특정 할부 건을 선택했을 때 열립니다.

모달에는 할부 번호, 회원 정보(이름·연락처), 상품 정보, 총 할부 금액, 할부 기간(총 회차 수), 월 납입액, 납입 회차 목록(회차별 예정일·납입 금액·납입 상태)이 표시됩니다. 납입 합계와 잔여 금액이 강조 표시되며, 미납 회차의 [납입 처리] 버튼은 DLG-S008을 호출합니다.

모달 하단에는 [중도 상환] 버튼이 있어 잔여 금액 일괄 납입과 잔여 회차 일괄 완납 + "완납" 상태 전환을 수행합니다. 영수증 출력 옵션도 제공됩니다.

### 7-2. DLG-S008 납입 처리 모달

납입 처리 모달은 미납 회차에 대해 납입 처리를 확인하고 완료하는 모달입니다. 회차 펼침의 [납입 처리] 버튼이나 DLG-S007 할부 상세에서 호출됩니다.

납입 대상 정보(회원·상품·해당 회차), 납입 금액, 실수령 금액 입력(기본값: 납입 예정 금액), 수령 일시, 결제 수단 선택을 입력합니다. 처리 확인 시 회차 상태가 "완료"로 갱신되고 잔여 금액이 자동 차감됩니다. PAY-03 미수금이 자동 동기화되며, 잔액 ≠ 회차 금액인 경우 부분 입금 옵션(회차 분할 또는 다음 회차 차감)이 제공됩니다.

### 7-3. DLG-S009 할부 등록 모달

할부 등록 모달은 새로운 할부 결제 계약을 등록하는 모달입니다. 페이지 헤더의 [+ 할부 등록] 버튼을 누르면 열립니다.

회원 정보(읽기 전용), 상품 정보(읽기 전용), 총 할부 금액(잔액 기준), 할부 기간(3·6·12회 등 선택), 월 납입액(자동 계산), 첫 납입일을 입력합니다. 납입 일정 미리보기가 자동 계산되어 표시되며, [등록] 버튼은 계약을 생성하고 SCR-S009 목록에 즉시 추가됩니다.

이 모달은 `정기 분납 계획`만 등록합니다. 당일 계약금 수납과 미수금 생성은 SCR-S003에서 먼저 확정되어야 합니다.

회원 신용 검증(미수 이력 3건 이상)이 발동하면 경고 모달이 한 번 더 호출되며, 진행 또는 취소를 선택할 수 있습니다.

### 7-4. DLG-S005 메모 편집 모달

메모 편집 모달은 회차별 메모를 추가·수정하는 모달입니다. 회차 펼침의 [메모] 버튼을 누르면 열립니다. 자유 형식 텍스트 입력창과 글자 수 표시, 저장/취소 버튼이 표시되며, 변경 이력은 SCR-097 감사 로그에 기록됩니다.

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 우측 상단에 녹색 계열로 5초 동안 표시되며, "납입 처리가 완료되었어요", "할부 계약을 등록했어요", "중도 상환이 완료되었어요" 같은 짧은 문구로 결과를 알려줍니다.

실패 토스트는 우측 상단에 빨강 계열로 표시되며, "납입 처리에 실패했어요", "회차 금액 미달입니다", "환불 진행 중인 계약입니다" 같은 문구와 함께 보조 액션이 따라옵니다.

자동 미납 감지 알림은 매일 00:01 크론이 예정일+1일 경과 회차를 "미납"으로 자동 갱신하고 PAY-03에 자동 동기화합니다. 실패 시 운영자에게 알림이 발송됩니다.

회차 D-3 자동 알림은 NFR-05 만료 알림 배치로 회원과 운영자에게 발송됩니다. 회차 D-Day 알림은 매일 09:00에 발송됩니다.

반복 미납 회원 알림은 동일 회원이 3회 이상 미납을 받으면 회원명 옆에 "주의" 라벨이 표시되고 운영자에게 NFR-19 알림이 발송됩니다.

회원 신용 경고는 할부 등록 시 회원 미수 이력 3건 이상이면 경고 모달이 표시되어 진행 또는 취소를 선택할 수 있습니다.

권한 알럿은 FC가 할부 등록 시도 시 차단되고 매니저 요청이 안내됩니다.

## 9. 데이터 흐름과 외부 연동

화면 진입 시점에는 할부 계약 조회 API(`GET /api/installments`)가 호출됩니다. 응답으로는 계약 배열, 4개 요약 카드 합계, 페이지 정보가 함께 내려옵니다.

계약 상세는 `GET /api/installments/:id`로 호출됩니다. 회차별 납입 현황 펼침에 사용됩니다.

할부 등록은 `POST /api/installments`로 처리됩니다. 회원·상품·총액·회차·시작일이 함께 전송되며, 자동 일정 산출(매월 동일 일자, 말일 보정: 1/31 → 2/28)이 적용됩니다.

납입 처리는 `POST /api/installments/:id/payments`로 처리됩니다. 입금 처리 결과는 PAY-03 미수금과 자동 동기화됩니다.

중도 상환은 `POST /api/installments/:id/early-repay`로 처리되며, 잔여 회차가 일괄 완납되고 계약 상태가 "완납"으로 전환됩니다.

계약 취소(환불 연계)는 `POST /api/installments/:id/cancel`로 처리됩니다. SAL-EXT-04 환불 진행 시 잔여 회차가 일괄 취소되고 미수 상계와 환불 계산이 함께 수행됩니다.

자동 미납 감지 크론은 매일 00:01에 실행되어 예정일+1일 경과 회차를 자동 "미납"으로 갱신합니다.

회차 D-3 자동 알림은 NFR-05 만료 알림 배치를 통해 회원과 운영자에게 발송됩니다. 회차 D-Day 알림은 매일 09:00에 발송됩니다.

PAY-03 미수금 동기화는 미납 회차 시 PAY-03에 자동 INSERT되고, 회수 시 양쪽이 자동 갱신됩니다.

SAL-04 선수익금은 회차 회수(회원권/PT) 시 선수익 인식이 수행됩니다.

회차 일정 자동 산출은 시작일 기준 매월 동일 일자에 회차를 생성하며, 말일 보정 규칙(1/31 → 2/28)이 적용됩니다.

엑셀 다운로드는 `GET /api/installments/export`로 처리되며, 30,000건 초과 시 백그라운드 다운로드로 분기됩니다.

회원 탈퇴 이벤트는 할부 계약을 유지하고 회원 카드 진입만 차단합니다.

다지점 RLS는 지점별 할부 계약을 격리하며, 본사 통합 모드만 전 지점에 접근 가능합니다.

감사 로그는 등록·납입처리·메모·해지를 모두 SCR-097에 비동기로 기록합니다. 기록 필드는 `actor_id`, `installment_id`, `round`, `amount`, `timestamp`입니다.

화면에서 호출하는 주요 API 엔드포인트는 다음과 같습니다. 할부 조회 `GET /api/installments`, 상세 조회 `GET /api/installments/:id`, 등록 `POST /api/installments`, 납입처리 `POST /api/installments/:id/payments`, 중도 상환 `POST /api/installments/:id/early-repay`, 계약 취소 `POST /api/installments/:id/cancel`, 엑셀 내보내기 `GET /api/installments/export`.

## 10. 화면 상태와 예외 처리

할부결제 관리 페이지는 다음 상태들을 가질 수 있습니다.

로딩 중 상태에서는 카드와 테이블 영역에 스켈레톤이 표시됩니다.

정상 표시 상태는 카드 + 테이블 + 회차 펼침이 함께 표시되는 일반적인 상태입니다.

검색 결과 없음 상태는 회원명 검색 결과가 0건일 때 "검색 결과가 없어요" 안내가 표시됩니다.

탭 데이터 없음 상태는 탭별로 데이터가 없을 때 빈 상태 안내가 표시됩니다.

회차 펼침 상태는 행을 선택했을 때 하단에 회차 상세가 펼쳐지는 상태입니다.

미납 경고 상태는 납입 기한이 지난 회차에 경고 색상과 아이콘이 표시되는 상태입니다.

처리 중 상태는 납입처리·등록·중도 상환 처리 중으로, 버튼이 로딩 표시되고 비활성화됩니다.

처리 실패 상태는 토스트와 재시도 버튼이 표시되는 상태입니다.

권한 미달 상태에서는 등록 버튼이 hidden 처리됩니다.

예외 케이스별 처리는 다음과 같이 정의됩니다. 데이터 없음 시 "검색 결과가 없어요" 안내, 입금액 < 회차 금액 시 "회차 금액 미달" 경고 + 부분 입금/정정 안내, 입금액 > 회차 금액 시 "다음 회차 차감 옵션" 노출, 미납 자동 감지 누락 시 운영자 알림 + 수동 갱신, 회차 D-3 알림 발송 실패 시 운영자 재시도 알림 + 재발송, 회원 신용 경고(미수 3건+) 시 등록 시 경고 모달 + 진행/취소, 할부 회차 한도 초과(24회+) 시 "최대 24회까지 가능" 정정 안내, 회차 금액 < 10,000원 시 "회차당 최소 10,000원" 정정 안내, 시작일 과거 시 "오늘 이후만 가능" 본사 권한자 안내, FC 등록 시도 시 등록 버튼 hidden + 매니저 요청 안내, PAY-03 동기화 실패 시 "동기화 오류" 토스트 + 자동 재시도(3회), 동시 납입처리 충돌 시 "잠시 후 다시 시도" 자동 재시도, 환불 진행 중 납입처리 시도 시 "환불 진행 중인 계약" 차단, 회원 탈퇴 후 진입 시 "탈퇴 회원" 안내 + 할부만 표시, 본사 통합 모드 권한 미달 시 통합 토글 hidden, 엑셀 다운로드 한도 초과 시 백그라운드 다운로드, 반복 미납 회원(3회+) 시 "주의" 라벨 + 운영자 알림, 회차 일정 변경 권한 부족 시 변경 버튼 hidden + Owner(지점장) 요청, 할부 삭제 권한 부족 시 삭제 버튼 hidden + 환불 처리 안내, 자동 일정 산출 오류(말일) 시 말일 보정(1/31→2/28) 등이 있습니다.

## 11. 권한별 처리

슈퍼관리자(superAdmin)와 본사 최고관리자(primary)는 등록, 납입 처리, 엑셀 내보내기, 삭제, 본사 통합 모드, 회차 일정 변경까지 모두 가능합니다.

Owner(지점장)과 매니저(manager)는 자기 지점의 등록, 납입 처리, 엑셀 내보내기가 가능합니다. 회차 일정 변경은 Owner(지점장) 이상만 가능합니다.

FC(피트니스 코치, fc)는 담당 회원 계약의 납입 처리·메모만 가능합니다. 할부 등록은 매니저+ 만 가능하므로 FC는 등록 버튼이 hidden 처리됩니다.

트레이너(trainer)와 스태프(staff)는 조회만 가능합니다.

읽기 전용(readonly)은 화면 자체에 접근할 수 없습니다.

권한 차단 시 버튼 hidden 또는 비활성, 403 응답 시 "권한이 없어요" 토스트, 모든 권한 차단 이벤트는 감사 로그에 기록됩니다.

## 14. 핵심 디자인 요청사항

요약 지표 카드 4개는 동일 크기 그리드로 배치되며, 미납 총액 카드는 빨강 경고 톤으로 강조됩니다. 진행중 카드는 파랑 톤, 완료 카드는 초록 톤으로 시각적으로 구분됩니다.

상태 탭의 미납 탭 배지는 빨강 강조이며, 30일 이상 연체 회차가 있는 계약은 행 옆에 추가 경고 라벨이 표시됩니다.

테이블에서 잔여 금액은 빨강 강조, 다음 납입일은 D-Day 표시(예: "D-3", "D-Day", "D+5")로 즉시 인지 가능합니다. D-3 이내는 빨강 강조, D-Day는 더 진한 빨강과 펄스 애니메이션이 적용됩니다.

상태 배지는 진행중(파랑)·완납(초록)·미납(빨강) 색상으로 구분되며, 회차 진행 정보(예: "12 / 4")는 강조된 폰트로 표시되어 한눈에 진행 상황을 파악할 수 있습니다.

회차 펼침은 부드러운 슬라이드 애니메이션으로 펼쳐지며, 회차별 상태 배지(예정·완료·미납)가 각 행에 표시됩니다. 미납 회차는 행 전체에 약한 빨강 배경이 적용되어 즉시 식별 가능합니다.

[+ 할부 등록] 버튼은 강조 색상으로 페이지 헤더 우측에 배치됩니다. FC 권한자에게는 hidden 처리됩니다.

DLG-S007 할부 상세 모달은 회차별 납입 현황을 컴팩트한 테이블로 보여주며, 중도 상환 버튼은 강조 색상으로 표시됩니다.

DLG-S009 할부 등록 모달의 납입 일정 미리보기는 회차별 예정일과 금액이 카드 리스트로 표시되어 운영자가 계약 조건을 시각적으로 확인할 수 있습니다.

진행 스피너와 로딩 스켈레톤은 매출관리 전체에서 동일한 톤으로 통일됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

본 화면 범위 정책은 `collectionMode=INSTALLMENT_PLAN` 계약만 노출합니다. PAY-03 미수금 분리 정책은 `collectionMode=DEPOSIT` 후 잔액만 남은 건은 SCR-S008에서 우선 관리합니다.

선납금 처리 정책은 선납금이 원결제 시 이미 수납된 금액이며 총 할부 금액은 잔액 기준으로 계산합니다.

회차당 분납액 정책은 잔액 ÷ 총 회차로 자동 계산하며 마지막 회차는 끝수 보정합니다.

자동 미납 감지 정책은 매일 00:01 크론이 예정일+1일 경과 회차를 "미납"으로 자동 갱신합니다.

납입 처리 감사 정책은 납입 처리 시 SCR-097에 기록합니다(`installment_id`, `round`, `amount`, `actor`).

중도 상환 정책은 잔여 회차를 일괄 완납 처리하고 계약 상태를 "완납"으로 갱신합니다.

회차 D-3 자동 알림 정책은 NFR-05 만료 알림 배치를 통해 회차 예정일 3일 전 회원과 운영자에게 알림을 발송합니다.

PAY-03 동기화 정책은 미납 회차가 PAY-03에 자동 INSERT되고, 회수 시 양쪽이 자동 갱신되도록 보장합니다.

계약 해지(환불) 정책은 SAL-EXT-04 환불 시 잔여 회차가 일괄 취소되고 환불 계산이 함께 수행됩니다.

할부 등록 권한 정책은 FC는 등록 불가하며, 매니저+ 만 등록이 가능합니다.

회원 신용 경고 정책은 회원 미수 이력 3건 이상 시 등록 시 경고가 표시되지만 강제 차단은 아닙니다.

할부 회차 한도 정책은 최대 24회(정책 한도, 변경 가능)입니다.

회차 금액 최소 정책은 회차당 분납액이 최소 10,000원입니다.

계약 시작일 정책은 시작일이 등록일 이후만 허용되며, 과거 시작일은 본사 권한자만 가능합니다.

회차 일정 산출 정책은 시작일 기준 매월 동일 일자, 말일 보정(1/31 → 2/28)을 적용합니다.

부분 입금 옵션 정책은 입금액 < 회차 금액 시 회차 분할 또는 다음 회차 차감을 선택할 수 있습니다(정책 토글).

초과 입금 옵션 정책은 입금액 > 회차 금액 시 다음 회차에 자동 차감하는 옵션을 제공합니다.

회원 탈퇴 후 할부 정책은 탈퇴 회원도 할부 계약을 유지하고 회원 카드 진입만 차단합니다.

본사 통합 모드 정책은 본사 슈퍼관리자만 전 지점 통합 조회가 가능합니다.

엑셀 다운로드 정책은 30,000건 초과 시 비동기 백그라운드 다운로드입니다.

반복 미납 회원 정책은 동일 회원 3회 이상 미납 시 운영자에게 알림이 발송됩니다.

회차 변경 권한 정책은 회차 일정 변경이 Owner(지점장)+ 만 가능하며 변경 이력이 감사 로그에 기록됩니다.
