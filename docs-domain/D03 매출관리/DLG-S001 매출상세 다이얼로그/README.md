# DLG-S001 매출 상세 다이얼로그

## 2. 다이얼로그 개요와 목적

매출 상세 다이얼로그는 특정 매출 건의 결제 정보·결제경로·링크 상태·카드 승인·메모를 한 화면에서 종합적으로 조회하는 모달입니다. SCR-S001 매출 현황의 매출 목록 테이블 행을 클릭하거나, SCR-M004 회원 상세의 결제 이력에서 특정 건을 선택하거나, 글로벌 검색 결과에서 매출 건을 선택했을 때 호출됩니다. 운영자가 매출 데이터를 SCR-S001 페이지를 떠나지 않고 즉시 확인하기 위한 모달이며, 고객 문의 응대와 내부 정산 확인에 활용됩니다.

이 다이얼로그는 조회 전용이지만 메모 편집(DLG-S005), 환불 요청 진입(DLG-S015), 세금계산서 발행 진입(DLG-S011), 회원 상세(SCR-M004) 페이지 이동 같은 후속 액션의 진입점 역할도 합니다.

## 3. 호출 트리거와 진입 경로

다이얼로그가 열리는 트리거는 다음과 같습니다.

첫 번째 트리거는 SCR-S001 매출 현황의 매출 목록 테이블 행 클릭입니다. 단, 행 내부의 상품명·구매자명 같은 텍스트 링크를 누르면 페이지 이동이 일어나므로, 행의 빈 영역 클릭 또는 명시적인 "상세" 액션만 모달 호출 트리거입니다.

두 번째 트리거는 SCR-M004 회원 상세의 결제 이력 탭에서 특정 결제 건을 선택할 때입니다.

세 번째 트리거는 글로벌 검색(SCR-103) 결과에서 매출 건을 선택할 때입니다.

네 번째 트리거는 SCR-S001 운영 코크핏 처리 큐의 "거래 보기" 버튼이나 알림 센터의 매출 알림 클릭입니다.

다이얼로그를 닫으면 호출 화면으로 그대로 복귀하며, 호출 화면의 필터·페이지·선택 상태는 그대로 유지됩니다.

## 4. 레이아웃과 UI 구성

매출 상세 다이얼로그는 화면 중앙에 표시되는 중간 크기 다이얼로그(데스크톱 약 800px 너비)이며, 모바일에서는 풀스크린 시트로 자동 전환됩니다. 배경은 어두운 오버레이로 처리되어 호출 화면과 시각적으로 분리됩니다.

모달 상단에는 매출 번호와 결제일시가 한 줄로 표시되고, 우측 상단에 [X 닫기] 아이콘이 배치됩니다.

상단 헤더 아래에는 결제 금액 영역이 있습니다. 결제 금액이 페이지 전체에서 가장 큰 폰트로 강조 표시되고, 그 옆에 할인 내역(할인 항목 + 할인 금액)이 작게 표시됩니다.

결제 금액 아래에는 결제 정보 카드가 있습니다. 결제 수단, 결제 경로(POS / LINK / MANUAL 배지), 링크 상태(LINK인 경우 SENT/OPENED/PAID/EXPIRED/CANCELED 배지), 카드 승인번호(카드 결제인 경우), 외부 거래번호, 결제일시, 영수증 파일 링크가 표시됩니다. 영수증 파일은 클릭 시 미리보기 모달이 별도로 열립니다.

결제 정보 카드 아래에는 상품 정보 카드가 있습니다. 구매한 상품명·수량·단가·소계가 표 형태로 표시되고, 마지막 행에 총 합계가 강조됩니다.

상품 정보 아래에는 구매 회원 카드가 있습니다. 회원명, 연락처, 회원 등급, 마지막 방문일이 표시됩니다. 회원명은 클릭 가능한 링크로 SCR-M004 회원 상세로 이동시킵니다. 비회원 결제 건은 "비회원" 라벨이 표시됩니다.

구매 회원 아래에는 처리 직원 정보가 표시됩니다. 결제를 처리한 직원 이름과 직급이 표시되며, 본사 통합 모드에서는 소속 지점도 함께 표시됩니다.

가장 아래에는 메모 영역이 있습니다. 해당 매출 건에 등록된 관리자 메모가 표시되고, 메모 옆 [편집] 아이콘을 누르면 DLG-S005 메모 편집 모달이 호출됩니다. 메모가 없으면 "메모 없음"이 표시되고 추가 입력이 가능합니다.

모달 하단에는 액션 버튼이 배치됩니다. [회원 상세 보기] 버튼(SCR-M004 이동), [환불 요청] 버튼(DLG-S015 호출), [세금계산서 발행] 버튼(법인 회원의 경우 DLG-S011 호출), [닫기] 버튼이 있습니다.

ESC 키 또는 배경 클릭으로도 모달을 닫을 수 있습니다.

## 5. 버튼·아이콘·링크 액션 전체 정의

상단 [X 닫기] 아이콘은 모달을 닫고 호출 화면으로 복귀합니다.

영수증 파일 링크는 영수증 미리보기 모달을 별도로 엽니다. 이미지(JPG/PNG)는 미리보기 이미지로, PDF는 PDF 뷰어로 표시됩니다.

상품명을 클릭하면 상품 상세(SCR-P003)로 이동시킵니다.

회원명을 클릭하거나 [회원 상세 보기] 버튼을 누르면 SCR-M004 회원 상세로 이동시킵니다. RLS 위반 시 "조회 권한이 없습니다" 토스트가 표시되고 진입이 차단됩니다.

처리 직원명을 클릭하면 직원 프로필 또는 KPI 상세로 이동시킵니다(권한자에 한해).

메모 영역의 [편집] 아이콘은 DLG-S005 메모 편집 모달을 호출합니다. 메모 편집 권한이 없는 계정에서는 아이콘이 hidden 처리됩니다.

[환불 요청] 버튼은 DLG-S015 환불 요청 모달을 호출합니다. 이미 전액 환불된 건이거나 환불 권한이 없으면 hidden 처리됩니다.

[세금계산서 발행] 버튼은 법인/사업자 회원 결제 건에만 표시되며, DLG-S011 세금계산서 발행 모달을 호출합니다. 매니저+ 권한자에게만 노출됩니다.

[닫기] 버튼은 모달을 닫고 호출 화면으로 복귀합니다.

모든 버튼은 클릭 후 응답이 돌아오기 전까지 자동으로 비활성화됩니다.

## 6. 다이얼로그 상태와 예외 처리

기본 표시 상태는 부모 화면에서 선택한 매출 건의 최신 값을 불러와 표시하는 일반적인 상태입니다.

로딩 중 상태는 모달 진입 직후 데이터를 불러오는 중으로, 영역별 스켈레톤이 표시됩니다.

저장/처리 중 상태는 후속 액션(메모 편집·환불 요청·세금계산서 발행) 모달이 호출된 직후로, 주요 버튼이 비활성화됩니다.

완료 상태는 후속 액션이 성공적으로 처리된 후 부모 화면 데이터가 갱신되고 모달이 닫히는 상태입니다.

실패 상태는 데이터 로딩 실패 또는 후속 액션 실패 시 토스트 또는 인라인 메시지로 사유가 안내되고 입력값은 유지되는 상태입니다.

권한 미달 상태는 RLS 위반으로 회원 정보 접근이 차단되거나 환불·세금계산서 권한이 없을 때 해당 액션 버튼이 hidden 처리되는 상태입니다.

예외 케이스별 처리는 다음과 같이 정의됩니다. 결제 데이터 누락 시 "결제 정보를 불러올 수 없습니다" 메시지와 재시도 버튼이 표시됩니다. RLS 위반 시 회원 상세 진입이 차단되고 "조회 권한이 없습니다" 토스트가 표시됩니다. 영수증 파일 누락 시 "영수증 파일이 없습니다" 안내가 표시됩니다. 메모 편집 권한 부족 시 편집 아이콘이 hidden 처리됩니다. 환불 권한 부족 시 [환불 요청] 버튼이 hidden 처리됩니다. 법인 회원이 아니면 [세금계산서 발행] 버튼이 hidden 처리됩니다. 비회원 결제 건은 [회원 상세 보기] 버튼이 hidden 처리되고 "비회원" 라벨이 표시됩니다. 매출 5년 경과 시 회원명·연락처가 마스킹된 상태로 표시됩니다(매출 금액·상품 정보는 보존). 모달 진입 권한 부족 시 다이얼로그가 열리지 않고 부모 화면에서 권한 안내 토스트가 표시됩니다.

## 7. 권한별 처리

슈퍼관리자(superAdmin)와 본사 최고관리자(primary)는 모든 매출 상세를 조회할 수 있고 메모 편집·환불 요청·세금계산서 발행까지 모두 가능합니다.

Owner(지점장)과 매니저(manager)는 자기 지점 매출의 상세를 조회하고 메모 편집·환불 요청·세금계산서 발행이 가능합니다.

FC(피트니스 코치, fc)는 담당 회원 결제의 상세만 RLS로 조회 가능하며, 메모 편집과 환불 요청이 가능합니다. 세금계산서 발행은 매니저+ 만 가능하므로 hidden 처리됩니다.

트레이너(trainer)와 스태프(staff)는 조회만 가능합니다. 메모 편집, 환불 요청, 세금계산서 발행 버튼이 모두 hidden 처리됩니다.

읽기 전용(readonly)은 다이얼로그 진입이 차단됩니다.

권한 차단 시 버튼 hidden, 다이얼로그 진입은 부모 화면에서 권한 안내, 모든 권한 차단 이벤트는 감사 로그에 기록됩니다.

## 8. 데이터 흐름과 외부 연동

다이얼로그 진입 시 매출 상세 조회 API(`GET /api/sales/:id`)가 호출됩니다. 응답으로는 결제 정보, 결제경로, 링크 상태, 카드 승인, 영수증 파일 메타데이터, 상품 정보, 구매 회원 정보, 처리 직원 정보, 메모가 모두 내려옵니다.

영수증 파일 미리보기는 `payment_receipts` 테이블의 파일 ID로 별도 조회됩니다.

회원 상세 진입은 RLS 검증을 거치며, FC의 비담당 회원 진입 시도는 403 응답으로 차단됩니다.

메모 편집, 환불 요청, 세금계산서 발행 진입은 각각 DLG-S005, DLG-S015, DLG-S011을 호출하며 해당 모달의 API를 통해 처리됩니다.

매출 5년 경과 시 PII 마스킹 배치가 회원명·연락처를 익명화하지만, 매출 금액·상품 정보·결제 정보는 보존됩니다.

감사 로그는 매출 상세 모달 진입을 SCR-097에 비동기로 기록합니다. 기록 필드는 `actor_id`, `payment_id`, `action=view`, `timestamp`입니다.

화면에서 호출하는 주요 API 엔드포인트는 `GET /api/sales/:id`입니다.

## 10. 핵심 디자인 요청사항

다이얼로그는 화면 중앙에 표시되는 중간 크기(데스크톱 약 800px)이며, 모바일에서는 풀스크린 시트로 자동 전환됩니다. 배경은 어두운 반투명 오버레이로 호출 화면과 시각적으로 분리됩니다.

결제 금액은 페이지 전체에서 가장 큰 폰트로 강조되며, 천 단위 콤마와 우측 정렬을 적용합니다. 할인 내역은 결제 금액 옆에 작은 회색 글씨로 표시됩니다.

결제 정보 카드, 상품 정보 카드, 구매 회원 카드, 메모 영역은 각각 분리된 카드형 섹션으로 표시되어 운영자가 빠르게 스캔할 수 있습니다.

결제 경로 배지(POS / LINK / MANUAL)와 링크 상태 배지(SENT/OPENED/PAID/EXPIRED/CANCELED)는 시각적으로 구분된 컬러 톤으로 표시됩니다.

영수증 파일 링크는 작은 영수증 아이콘과 함께 표시되며, 호버 시 미리보기 가능함이 명확히 인지되도록 합니다.

회원명, 상품명 같은 링크는 호버 시 강조 색상으로 변경되어 클릭 가능함을 알립니다. 비회원은 회색 톤 "비회원" 라벨로 표시됩니다.

[회원 상세 보기], [환불 요청], [세금계산서 발행] 버튼은 모달 하단에 가로로 일렬 배치되며, 권한에 따라 동적으로 hidden 처리됩니다. [닫기] 버튼은 우측 끝에 배치됩니다.

진행 스피너와 로딩 스켈레톤은 매출관리 전체에서 동일한 톤으로 통일됩니다.

## 11. 운영 정책

조회 책임 분리 정책은 매출 상세 다이얼로그가 조회 전용이며, 환불·세금계산서 발행 같은 트랜잭션 처리는 별도 모달이나 화면에서 수행함을 명시합니다.

RLS 검증 정책은 회원 상세 진입 시 RLS를 검증해 FC의 비담당 회원 진입을 차단합니다.

매출 5년 보관 정책은 매출 데이터가 5년간 보관되며, 5년 경과 후 PII 마스킹이 적용되지만 매출 금액·상품 정보·결제 정보는 보존됩니다.

감사 로그 정책은 매출 상세 모달 진입을 SCR-097에 기록합니다. 기록 필드는 `actor_id`, `payment_id`, `action=view`, `timestamp`입니다.

권한별 액션 정책은 매니저+ 모든 후속 액션 가능, FC는 메모 편집·환불 요청 가능(세금계산서 발행 불가), 트레이너·스태프는 조회만, readonly는 진입 차단입니다.

비회원 결제 정책은 회원 상세 진입을 hidden 처리하고 "비회원" 라벨을 표시합니다.

법인 회원 세금계산서 발행 정책은 법인/사업자 회원 결제 건에만 [세금계산서 발행] 버튼을 노출합니다.

환불 권한 정책은 이미 전액 환불된 건의 [환불 요청] 버튼을 hidden 처리하고, 환불 권한이 없는 계정에서도 hidden 처리합니다.

영수증 파일 보관 정책은 영수증을 결제 기록과 연결해 보관하며, 매출 상세에서 미리보기 가능하도록 합니다.

이상의 모든 정책은 이 다이얼로그를 구현하고 운영하는 사람이 별도 문서 없이 이 한 장만 보면 이해할 수 있도록 풀어 적었습니다. 정책이 바뀌면 이 문서가 함께 갱신되어야 합니다.
