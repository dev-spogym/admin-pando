## 2. 화면 개요와 목적

매출 예측 페이지는 과거 매출 데이터를 기반으로 향후 매출을 예측하고, 설정한 목표 대비 달성률을 시각적으로 확인하는 화면입니다. Owner(지점장)과 매니저는 다음 달·분기·연간 예측 매출을 미리 파악해 인력 배치, 상품 프로모션, 목표 조정 등 선제적인 운영 계획을 수립합니다. 본사는 지점별 예측을 비교해 전사 자원 배분 의사결정을 지원합니다.

운영 맥락은 다양합니다. Owner(지점장)은 월간 운영 계획 시 다음 달 예측 + 목표 설정으로 인력·프로모션을 배치하고, 본사 슈퍼관리자는 통합 모드 + 지점별 예측 비교로 자원을 배분합니다. CFO는 분기·연간 예측 + 목표 달성률로 재무 계획을 수립하고, 마케팅 팀은 상품별 예측 기여도 1~10위로 집중 영역을 파악합니다. 인사 팀은 매출 예측을 토대로 트레이너·매니저 채용 계획을 수립하고, 매니저는 달성률 게이지 100% 초과 시 색상 변화로 목표 조정을 검토합니다.

이 화면은 운영 의사결정 지원이 목적입니다. 예측치는 참고용이며 실제 매출은 다양한 변수의 영향을 받습니다. 예측 알고리즘은 이동평균 + 계절성 조정을 기본으로 사용하며, 향후 ML 모델로 고도화될 수 있습니다. 매주 월요일 04:00에 예측 모델이 자동 갱신되며, 매월 1일 04:00에 정확도 검증 배치가 실행됩니다. 정확도 < 80% 시 운영자에게 모델 점검 알림이 발송됩니다.

데이터 부족 정책으로 과거 매출이 6개월 미만이면 예측 차트가 비활성화되고 데이터 누적 안내가 표시됩니다.

## 3. 진입 경로와 인접 화면

매출 예측 페이지에 진입하는 경로는 다음과 같습니다.

첫 번째 경로는 사이드바입니다. 좌측 사이드바의 "매출관리" 메뉴 아래 "매출 예측" 항목을 클릭하면 진입합니다. URL은 `/sales/forecast`이며, 예측 기간은 "다음 달"이 기본 활성화됩니다.

두 번째 경로는 대시보드(SCR-101)의 매출 예측 카드 또는 달성률 게이지 카드 클릭입니다. 카드 종류에 따라 예측 기간이 자동 적용됩니다.

세 번째 경로는 매출 현황(SCR-S001) 또는 매출 통계(SCR-S004)에서 "예측 보기" 링크를 누를 때입니다.

네 번째 경로는 1억원 이상 목표 승인 알림(본사 슈퍼관리자) 또는 정확도 검증 실패 알림(매월 1일)에서 진입할 때입니다.

이 화면에서 빠져나가는 인접 화면으로는, 매출 현황(SCR-S001), 매출 통계(SCR-S004), 선수익금(SCR-S006), 대시보드(SCR-101), KPI(SCR-094), 그리고 모든 목표 변경이 기록되는 감사 로그(SCR-097)가 있습니다.

## 4. 레이아웃과 UI 구성

매출 예측 페이지는 위에서 아래로 차곡차곡 쌓이는 세로형 단일 컬럼 레이아웃을 기본으로 합니다.

가장 위에는 페이지 헤더가 있습니다. 헤더 좌측에는 "매출 예측"이라는 페이지 타이틀과 지점 컨텍스트 배지가 표시됩니다. 헤더 우측에는 [목표 설정] 버튼이 매니저+ 권한자에게 표시됩니다.

페이지 헤더 아래에는 요약 지표 카드 4개가 가로로 배치됩니다. 첫 번째 카드는 "이번 달 예측 매출"로 잔여 일수 보정한 월 예측치를 표시합니다. 두 번째 카드는 "목표 달성률"로 누적 매출 ÷ 목표 × 100을 표시하며, 100% 초과 시 성공 색상(초록)으로 변경됩니다. 세 번째 카드는 "전월 대비 증감"으로 (이번 달 - 전월) / 전월 × 100을 표시하며, 증가는 초록·감소는 빨강으로 강조됩니다. 네 번째 카드는 "이번 분기 누적 매출"로 분기 시작일부터 합산한 누적 매출을 표시합니다.

요약 카드 아래에는 예측 기간 선택 영역이 있습니다. 라디오/세그먼트 컨트롤로 다음 달 / 다음 분기 / 연간 예측 중 하나를 선택하며, 기간 변경 시 차트와 테이블이 즉시 갱신됩니다.

예측 기간 선택 아래에는 매출 예측 차트가 있습니다. 과거 실적(실선)과 예측값(점선)을 하나의 차트에 겹쳐 표시하며, 목표 라인(수평선)도 함께 표시됩니다. X축은 월/분기/연, Y축은 매출 금액이며, 라인 1은 과거 실적, 라인 2는 예측치(점선, ±10% 신뢰 구간 음영), 라인 3은 목표(수평선)입니다. 차트 호버 시 수치·신뢰 구간·증감률 툴팁이 표시됩니다.

차트 옆 또는 아래에는 달성률 게이지가 있습니다. 현재 누적 매출의 목표 대비 비율을 프로그레스 바와 숫자로 표시하며, 100% 초과 시 게이지 색상이 성공 색(초록)으로 변경됩니다. 잔여 목표 금액이 게이지 하단에 함께 표시됩니다.

달성률 게이지 아래에는 상품별 예측 기여도 영역이 있습니다. 순위 1~10위의 상품명·예측 매출·전체 예측 매출 대비 비중(%)이 테이블 또는 카드 리스트로 표시되어, 마케팅 팀이 집중해야 할 상품을 즉시 식별할 수 있습니다.

가장 아래에는 월별 예측 테이블이 있습니다. 다음 12개월 월별 예측 매출·입력 목표·달성률(예측/목표 × 100)·전년 동기 대비(YoY 증감률)가 컬럼으로 구성됩니다. YoY 데이터가 없으면 "비교 불가"가 표시됩니다.

본사 통합 모드에서는 차트와 테이블이 전 지점 합산으로 표시되고 지점별 드릴다운이 활성화됩니다.

## 5. 탭 구성과 탭별 동작

이 화면은 탭이 없습니다. 단일 분석 화면이며, 예측 기간 라디오(다음 달 / 다음 분기 / 연간)가 탭과 비슷한 역할로 차트와 테이블을 동적으로 전환합니다.

기간 변경 시 4개 요약 카드는 그대로 유지되지만(이번 달 / 분기 / 전월 대비는 고정 의미), 차트와 월별 예측 테이블은 새 기간으로 갱신됩니다. 예를 들어 "연간" 선택 시 차트는 12개월 예측 라인을, 테이블은 다음 12개월 월별 예측을 보여줍니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

요약 지표 카드 4개는 클릭 가능합니다. 이번 달 예측 매출 카드는 차트의 이번 달 영역으로 자동 줌, 목표 달성률 카드는 달성률 게이지 영역으로 스크롤, 전월 대비 증감 카드는 매출 통계(SCR-S004)의 전월 대비 토글 ON 상태로 라우팅, 이번 분기 누적 매출 카드는 매출 현황(SCR-S001)의 분기 기간 필터로 라우팅됩니다.

예측 기간 라디오 3개(다음 달 / 다음 분기 / 연간)는 누르면 즉시 차트·테이블·달성률 게이지가 새 기간으로 갱신됩니다.

매출 예측 차트는 호버 시 툴팁, 클릭 시 자동 드릴다운(해당 기간의 매출 현황 또는 매출 통계로 이동)을 수행합니다.

상품별 예측 기여도 테이블의 상품명을 클릭하면 상품 상세(SCR-P003)로 이동시킵니다.

월별 예측 테이블의 월 항목을 클릭하면 해당 월의 매출 현황으로 이동시킵니다. YoY 컬럼의 "비교 불가" 항목은 클릭 불가입니다.

페이지 헤더의 [목표 설정] 버튼은 DLG-S012 목표 매출 설정 모달을 엽니다. 매니저+ 권한자에게만 표시되며, FC·트레이너·스태프는 hidden 처리됩니다.

달성률 게이지 옆의 [잔여 목표 금액 보기] 링크는 잔여 목표 달성을 위한 일별 평균 필요 매출을 계산해 안내합니다.

본사 통합 모드 토글은 본사 슈퍼관리자에게만 노출됩니다. 토글 ON 시 전 지점 합산과 지점별 드릴다운이 활성화됩니다.

모든 버튼은 클릭 후 응답이 돌아오기 전까지 자동으로 비활성화됩니다.

## 7. 호출되는 모달 동작

이 화면에서 호출되는 모달은 한 가지이며, DLG-S012 목표 매출 설정 모달입니다.

### 7-1. DLG-S012 목표 매출 설정 모달

목표 매출 설정 모달은 월별 또는 특정 기간의 매출 목표 금액을 설정하는 모달입니다. SCR-S011 매출 예측에서는 페이지 헤더의 [목표 설정] 버튼을 누르면 열리며, SCR-S001 매출 현황과 SCR-S004 매출 통계에서도 같은 모달이 호출됩니다.

모달 상단에는 "목표 매출 설정"이라는 제목과 함께 설정 기간 단위 선택(월/분기/연간), 그 아래에 목표 금액 입력 필드(천 단위 콤마 자동), 적용 시점 선택(즉시 / 다음 기간부터), 이전 기간 실적 참고값이 표시됩니다.

저장 버튼을 누르면 목표가 저장되고 달성률 게이지·차트의 목표 라인·월별 예측 테이블의 목표 컬럼이 즉시 갱신되며, 변경 이력은 SCR-097 감사 로그에 actor·period·before·after로 기록됩니다.

1억원 이상의 목표는 본사 슈퍼관리자 승인 큐로 전송되어 "본사 승인 대기" 상태로 표시됩니다. 승인 후 적용됩니다.

매니저 이상만 목표 설정이 가능하며 FC·트레이너·스태프는 차단됩니다. 즉시 vs 다음 기간 적용에 대한 명시가 필수이며, 즉시 적용 시 과거 데이터 영향 안내가 표시될 수 있습니다.

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 우측 상단에 녹색 계열로 5초 동안 표시되며, "목표 매출을 저장했어요", "예측 모델이 갱신되었어요" 같은 짧은 문구로 결과를 알려줍니다.

실패 토스트는 우측 상단에 빨강 계열로 표시되며, "예측 데이터를 불러올 수 없습니다", "권한이 없어요", "데이터가 부족합니다" 같은 문구와 함께 보조 액션이 따라옵니다.

데이터 부족 알럿은 과거 매출이 6개월 미만일 때 차트 자리에 "데이터 누적 안내" 메시지가 표시되며, 예측 차트가 비활성화됩니다. 데이터가 누적되면 자동으로 활성화됩니다.

목표 미설정 안내는 게이지 자리에 입력 안내가 표시되며, DLG-S012 진입 안내가 함께 표시됩니다.

1억원+ 목표 승인 대기 안내는 본사 슈퍼관리자 승인 큐 전송 후 "본사 승인 대기" 안내가 표시됩니다.

모델 정확도 < 80% 알림은 매월 1일 04:00 검증 배치 결과로 운영자에게 NFR-19 알림이 발송됩니다.

모델 갱신 실패 알림은 매주 월요일 04:00 모델 갱신 실패 시 운영자에게 발송됩니다.

CFO 분기 보고서 생성 실패 알림은 분기 마지막 날 04:00 자동 생성 실패 시 운영자에게 발송됩니다.

권한 알럿은 FC·트레이너 등이 목표 설정 시도 시 차단되고 매니저 요청이 안내됩니다.

## 9. 데이터 흐름과 외부 연동

화면 진입 시점에는 예측 조회 API(`GET /api/sales/forecast`)가 호출됩니다. 요청에는 예측 기간(다음 달 / 다음 분기 / 연간), 지점(통합 모드)이 쿼리 파라미터로 들어갑니다. 응답으로는 과거 실적 라인, 예측 라인(±10% 신뢰 구간 포함), 목표 라인, 4개 요약 카드 합계, 월별 예측 테이블 데이터가 함께 내려옵니다.

목표 매출 설정은 `POST /api/sales/goals`로 처리됩니다. 기간 단위, 목표 금액, 적용 시점이 함께 전송되며, 1억원 이상 목표는 본사 슈퍼관리자 승인 큐로 전송됩니다.

달성률 조회는 `GET /api/sales/goals/achievement`로 별도 호출됩니다.

상품별 예측 기여도는 `GET /api/sales/forecast/by-product`로, YoY 비교는 `GET /api/sales/forecast/yoy`로 호출됩니다.

모델 갱신 트리거는 `POST /api/sales/forecast/refresh-model`로 처리됩니다. 매주 월요일 04:00 자동 실행이 기본이며, 운영자가 수동 트리거할 수도 있습니다.

예측 알고리즘은 이동평균 + 계절성 조정을 기본으로 사용합니다. 12개월 이동평균 + 월별 계절성 가중치를 적용하며, 예측 라인의 신뢰 구간은 ±10%로 음영 표시됩니다. 향후 ML 모델로 고도화될 수 있습니다.

데이터 부족 안내는 과거 매출 6개월 미만일 때 예측 차트가 비활성화되고 데이터 누적 안내가 표시됩니다.

모델 정확도 검증 배치는 매월 1일 04:00에 실행되어 예측 vs 실적의 정확도를 검증합니다. 정확도 < 80% 시 운영자에게 NFR-19 알림이 발송됩니다.

PAY-01 결제 webhook과 SAL-EXT-04 환불 webhook 도착 시 5분 캐시가 무효화되어 다음 조회에서 최신 데이터가 반영됩니다.

SAL-01 매출 현황, SAL-03 매출 통계, SAL-04 선수익금이 예측 모델 입력 데이터로 사용됩니다.

CFO 분기 보고서는 분기 마지막 날 04:00에 자동 생성되어 다운로드 가능합니다.

1억원+ 목표 승인 워크플로우는 DLG-S012 저장 시 본사 슈퍼관리자 승인 큐로 전송됩니다(정책 토글).

데이터 보관은 5년이며, 5년 경과 후 PII 마스킹 배치(매월 1회)가 회원명·연락처를 익명화합니다. 단 매출 합산 데이터는 보존됩니다.

다지점 RLS는 지점별 예측을 격리하며, 본사 통합 모드만 전 지점에 접근 가능합니다.

예측 캐시는 5분 캐시이며, webhook 도착 시 무효화됩니다.

감사 로그는 목표 변경을 SCR-097에 기록합니다. 기록 필드는 `actor`, `period`, `before`, `after`, `timestamp`입니다.

화면에서 호출하는 주요 API 엔드포인트는 다음과 같습니다. 예측 조회 `GET /api/sales/forecast`, 목표 설정 `POST /api/sales/goals`, 달성률 조회 `GET /api/sales/goals/achievement`, 상품별 예측 `GET /api/sales/forecast/by-product`, YoY 비교 `GET /api/sales/forecast/yoy`, 모델 갱신 `POST /api/sales/forecast/refresh-model`.

## 10. 화면 상태와 예외 처리

매출 예측 페이지는 다음 상태들을 가질 수 있습니다.

로딩 중 상태에서는 차트·테이블·게이지 영역에 스켈레톤이 표시됩니다.

정상 표시 상태는 차트 + 테이블 + 게이지가 함께 표시되는 일반적인 상태입니다.

데이터 부족 상태는 과거 6개월 미만 시 예측 차트가 비활성화되고 "데이터 누적 안내"가 표시되는 상태입니다.

목표 미설정 상태는 게이지 자리에 입력 안내가 표시되는 상태입니다. DLG-S012 진입 안내가 함께 표시됩니다.

목표 초과 달성 상태는 달성률 100% 초과 시 게이지 색상이 성공 색(초록)으로 변경되는 상태입니다.

예측 실패 상태는 모델 오류 시 토스트와 재시도 버튼이 표시되는 상태입니다. 운영자에게 모델 점검 알림이 발송됩니다.

본사 통합 모드 상태에서는 차트와 테이블이 전 지점 합산으로 표시되고 지점별 드릴다운이 활성화됩니다.

목표 변경 중 상태는 DLG-S012 모달이 열린 상태입니다.

YoY 비교 불가 상태는 전년 동기 데이터가 없을 때 "비교 데이터 없음" 안내가 표시되는 상태입니다.

권한 미달 상태에서는 통합 모드 토글이 hidden 처리되고 목표 설정 버튼이 비활성화됩니다.

모델 갱신 중 상태는 "예측 갱신 중" 안내가 표시되는 상태로, 다음 조회에서 새 모델 결과가 반영됩니다.

예외 케이스별 처리는 다음과 같이 정의됩니다. 데이터 부족(6개월 미만) 시 "데이터 누적 안내" 예측 비활성화, 목표 미설정 시 게이지 대신 입력 안내, 목표 0원 시 게이지 hidden + 입력 안내, 예측 모델 오류 시 "예측 실패" 토스트 + 운영자 알림, 모델 정확도 < 80% 시 운영자 알림 + 모델 점검 안내, YoY 데이터 없음 시 "비교 불가" 표시, 본사 통합 모드 권한 미달 시 토글 hidden, 목표 변경 권한 부족(FC) 시 DLG-S012 진입 차단 + 매니저 요청, 1억원+ 목표 승인 미처리 시 "본사 승인 대기" 안내 + 본사 승인 요청, 모델 갱신 실패 시 운영자 알림 + 다음 주기 재시도, 즉시 적용 시 과거 데이터 영향 안내, 기간 변경 시 캐시 갱신 지연 시 "갱신 중" 표시 + 5초 후 자동, 신뢰 구간 표시 누락 시 예측 라인만 표시, 차트 로딩 실패 시 "차트를 불러올 수 없습니다" + 재시도, 5년 경과 데이터는 익명화(매출 합산 보존), 다지점 RLS 누수 시 보안 이벤트 즉시 차단, 권한 부족(트레이너) 시 조회만, 동시 목표 변경 충돌 시 "잠시 후 다시 시도" 자동 재시도, 모델 갱신 중 조회 시 "예측 갱신 중" 안내 + 잠시 후 재시도, CFO 분기 보고서 생성 실패 시 운영자 알림 + 수동 생성 등이 있습니다.

## 11. 권한별 처리

superAdmin와 primary는 전체 지점 예측 조회, 목표 설정(1억원+ 승인 포함), 본사 통합 모드까지 모두 가능합니다.

Owner(지점장)과 매니저(manager)는 자기 지점의 예측 조회와 목표 설정이 가능합니다. 1억원 미만의 일반 목표는 즉시 적용되고, 1억원 이상은 본사 슈퍼관리자 승인 큐로 전송됩니다.

FC(피트니스 코치, fc)는 매출 카드 일부와 조회만 가능합니다. 목표 설정 버튼은 hidden 처리됩니다.

트레이너(trainer)와 스태프(staff)는 조회만 가능합니다.

읽기 전용(readonly)은 화면 자체에 접근할 수 없습니다.

권한 차단 시 버튼 hidden 또는 비활성, 403 응답 시 "권한이 없어요" 토스트, 모든 권한 차단 이벤트는 감사 로그에 기록됩니다.

## 14. 핵심 디자인 요청사항

요약 지표 카드 4개는 동일 크기 그리드로 배치됩니다. 목표 달성률 카드는 게이지 형태로 직관적으로 비율을 표시하고, 100% 초과 시 초록 강조와 함께 "초과 달성" 라벨이 추가됩니다. 전월 대비 증감 카드는 증가는 초록 화살표(↑), 감소는 빨강 화살표(↓)와 함께 표시됩니다.

매출 예측 차트는 페이지 중앙에 큰 영역으로 배치되며, 과거 실적은 실선 + 명확한 컬러, 예측치는 점선 + 동일 계열의 옅은 컬러, 신뢰 구간은 ±10% 음영으로 표시됩니다. 목표 라인은 빨강 또는 주황 수평선으로 시각적으로 분리되며, 호버 시 부드러운 툴팁이 표시됩니다.

달성률 게이지는 큰 원형 또는 반원형 게이지로 표시되며, 0~50%는 회색, 50~100%는 점진적으로 진해지는 색상, 100% 초과는 초록 성공 색상으로 변경됩니다. 게이지 중앙에 큰 폰트로 % 숫자가 표시되고, 게이지 하단에 잔여 목표 금액과 잔여 일수 안내가 표시됩니다.

상품별 예측 기여도는 1~10위 순위와 비중 % 막대 차트가 함께 표시되어, 어느 상품이 매출 기여도가 큰지 한눈에 파악할 수 있습니다.

월별 예측 테이블은 다음 12개월 행이 카드형 또는 콤팩트한 테이블로 배치되며, 달성률 컬럼은 색상 그라데이션으로 시각화됩니다. YoY 증감률은 증가는 초록·감소는 빨강으로 강조됩니다.

DLG-S012 목표 매출 설정 모달은 이전 기간 실적 참고값을 작은 차트로 보여줘 운영자가 합리적 목표를 설정할 수 있도록 돕습니다. 1억원+ 목표 입력 시 "본사 승인 필요" 안내가 자동 표시됩니다.

데이터 부족(6개월 미만) 상태에서는 차트 자리에 큰 안내 메시지와 함께 "매출 데이터를 N개월 더 누적하면 예측이 활성화됩니다" 카운트다운이 표시됩니다.

진행 스피너와 로딩 스켈레톤은 매출관리 전체에서 동일한 톤으로 통일됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

예측 알고리즘 정책은 이동평균 + 계절성 조정을 기본으로 사용하며, 향후 ML 모델로 고도화 가능합니다. 12개월 이동평균 + 월별 계절성 가중치를 적용합니다.

데이터 부족 안내 정책은 과거 매출 6개월 미만이면 예측 차트가 비활성화되고 데이터 누적 안내가 표시됩니다.

달성률 공식 정책은 달성률 = 누적 매출 / 목표 × 100이며, 100% 초과 시 성공 색상으로 변경됩니다.

본사 통합 모드 정책은 본사 슈퍼관리자만 활성화되며, 지점 합산과 드릴다운을 제공합니다.

상품별 기여도 정책은 다음 기간 예측 매출 기준 상위 10위를 표시합니다.
