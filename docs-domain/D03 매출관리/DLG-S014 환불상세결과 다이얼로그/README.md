# DLG-S014 환불 상세 결과 다이얼로그

## 2. 다이얼로그 목적과 사용 맥락

환불 상세 결과 다이얼로그는 DLG-S013에서 환불이 성공적으로 처리된 직후 운영자에게 처리 결과를 명확히 보여주어, 회원에게 즉시 환불 결과를 음성·문자·이메일로 안내할 수 있도록 정보를 제공하는 결과 확인형 모달입니다. SAL-EXT-04 운영 시나리오에서 "처리 완료 후 DLG-S014가 자동으로 표시됩니다"라는 문구로 표현된 흐름의 시각화이며, 환불 운영의 마지막 단계에서 운영자와 회원 모두에게 결과 인지를 보장합니다.

이 다이얼로그가 다루는 운영 흐름은 세 가지입니다. 첫째는 회원 응대 흐름으로, 운영자가 회원과 통화하면서 환불이 처리되었음을 즉시 확인해 응대합니다. 둘째는 결제링크 PG 환불 폴링 흐름으로, 결제링크 카드 환불의 경우 PG webhook 응답이 도착할 때까지 처리중 상태를 폴링합니다. 셋째는 후속 액션 진입 흐름으로, 운영자가 환불 이력(DLG-S006) 또는 환불 영수증을 추가로 확인합니다.

다이얼로그는 새로운 데이터를 입력받지 않고 결과를 표시만 합니다. 변경 액션이 없으며 단순 확인·닫기 동작만 제공합니다.

## 3. 호출 트리거와 부모 화면 컨텍스트

이 다이얼로그는 단일 진입점만 가집니다. DLG-S013 환불 처리에서 처리 확인 버튼을 누르고 백엔드가 성공 응답(201)을 반환하는 순간 DLG-S013이 자동으로 닫히면서 즉시 이 다이얼로그가 열립니다. 운영자가 별도로 다른 화면이나 메뉴에서 이 다이얼로그에 진입할 수 없으며, 환불 처리 직후에만 일회성으로 표시되는 모달입니다.

다이얼로그가 받는 컨텍스트는 DLG-S013에서 반환된 환불 처리 응답 전체입니다. 구체적으로 환불 번호(`refundId`), 환불 금액, 환불 수단, 처리 일시, 처리 담당자, 원 매출 정보, 환불 사유, 결제링크 카드 환불의 경우 PG 처리 상태, 법인 회원의 경우 마이너스 세금계산서 발행 상태, 그리고 DLG-S013을 호출한 원래 부모 화면 식별자(닫기 시 복귀 위치)입니다.

DLG-S013이 닫히고 이 다이얼로그가 열리는 모달 교체 애니메이션은 부드럽게 진행되어, 운영자가 두 단계 흐름을 자연스럽게 따라갈 수 있게 디자인됩니다.

## 4. 레이아웃과 UI 구성

다이얼로그는 데스크톱에서 가로 480px의 중앙 정렬 모달이고, 모바일에서는 풀너비 시트로 표시됩니다. 위에서 아래로 다음 영역이 순차 배치됩니다.

가장 위에는 처리 완료 안내 헤더가 강조 영역으로 표시됩니다. 큰 체크 아이콘(녹색)과 함께 "환불 처리가 완료되었어요" 메시지가 한 화면의 중심에 표시됩니다. 결제링크 PG 환불이 처리중인 상태이면 체크 아이콘 대신 노란 시계 아이콘과 "PG 환불을 처리 중입니다" 메시지가 표시됩니다. 우측 끝에는 X 닫기 버튼이 있습니다.

헤더 아래에는 환불 금액 강조 카드가 있습니다. 환불 금액 숫자가 다이얼로그 안에서 가장 큰 폰트로 표시되며 빨강 강조 색상이 적용됩니다. 그 아래에는 부분 환불 여부 배지("전체 취소" 또는 "부분 환불")가 작은 칩으로 붙고, 부분 환불의 경우 원결제 금액 대비 환불 비율이 보조 설명으로 추가됩니다.

환불 금액 카드 아래에는 처리 정보 카드가 있습니다. 환불 번호(`R-2026-0512-00123` 형식), 처리 일시(분 단위까지), 처리 담당자 이름과 권한 라벨이 표시됩니다.

처리 정보 아래에는 환불 수단 카드가 있습니다. 환불이 실제로 어떤 경로로 이루어졌는지가 결제 수단별로 분기 표시됩니다. 현장 카드 환불은 "외부 POS 환불 완료 후 CRM 기록"과 함께 승인번호·단말 ID, 결제링크 카드 환불은 "PG 환불 처리 중"(처리중 상태) 또는 "PG 환불 완료"(완료 상태)와 PG 응답 코드, 현금/계좌이체는 이체 정보, 포인트는 "포인트 즉시 회복"과 회복된 포인트 잔액이 표시됩니다.

환불 수단 아래에는 원 매출 정보 카드가 있습니다. 환불 대상이 된 원 매출의 번호, 결제일, 상품명이 작게 표시되고, 우측에 "원 매출 보기"(DLG-S001) 텍스트 링크가 있습니다.

법인 회원 환불의 경우 그 아래에 마이너스 세금계산서 발행 안내 카드가 추가됩니다. SAL-EXT-04·SAL-EXT-02 연계에 따라 자동 발행이 완료된 경우 "마이너스 세금계산서 자동 발행 완료" 녹색 안내가 표시되고, 자동 실패한 경우 "마이너스 세금계산서 수동 발행 필요" 빨강 안내와 SAL-EXT-02 진입 링크가 강조됩니다.

다이얼로그 가장 아래에는 액션 바가 있습니다. 좌측에 "환불 영수증 다운로드"(PDF) 텍스트 링크와 "환불 이력 보기"(DLG-S006 전환) 링크가 있고, 우측에 강조색 "확인" 버튼이 있습니다. "확인" 버튼은 다이얼로그를 닫고 DLG-S013의 부모 화면으로 복귀시킵니다.

## 5. 데이터 표시와 상태 폴링

다이얼로그는 DLG-S013이 반환한 응답 데이터를 그대로 표시하며 별도의 API 호출 없이 즉시 렌더링됩니다.

결제링크 카드 환불의 경우 PG webhook 응답이 즉시 도착하지 않을 수 있으므로, 다이얼로그는 5초 간격으로 자동 폴링을 수행해 PG 환불 상태가 "완료" 또는 "거절"로 전환되었는지 확인합니다. 폴링은 SAL-EXT-04 "결제링크 PG 응답 타임아웃 (60초+): 처리중 유지 + 자동 폴링" 정책에 따라 최대 60초간 진행되며, 60초 후에도 처리중이 유지되면 폴링이 중단되고 "PG 처리가 지연되고 있어요. SCR-S007에서 확인해주세요" 안내가 표시됩니다.

PG 환불 완료 상태로 전환되면 다이얼로그의 헤더 메시지가 "환불 처리가 완료되었어요"로 자동 갱신되고 체크 아이콘이 녹색으로 표시됩니다. PG 환불 거절로 전환되면 헤더가 "PG 환불이 거절되었어요" 빨강으로 변경되고 거절 사유와 익영업일 재시도 안내가 환불 수단 카드에 표시됩니다.

법인 회원 환불의 마이너스 세금계산서 자동 발행 상태도 동일하게 비동기로 처리되며, 발행 완료 시 안내 카드가 자동 갱신됩니다.

## 6. 확인·취소 동작과 부모 화면 복귀

확인 버튼을 누르면 다이얼로그가 즉시 닫히고 DLG-S013의 원래 부모 화면으로 복귀합니다. 부모 화면별로 다음 갱신이 일어납니다.

부모가 SCR-S007 환불 관리이면 환불 이력 목록에 새 환불 행이 최상단에 노출되고 요약 카드(이번 달 환불 총액·건수·평균 환불액·위약금 합계)가 갱신됩니다.

부모가 DLG-S001 매출 상세이면 매출 상세의 환불 이력 카드에 새 행이 추가되고 매출 상태가 "전체 환불 완료" 또는 "부분 환불"로 갱신됩니다.

부모가 SCR-S012 결제 취소·부분 환불이면 결제 건 검색 영역으로 복귀하면서 "환불 처리가 완료되었어요" 토스트가 표시됩니다.

부모가 DLG-S015 환불 요청이면 요청이 "처리 완료"로 전환되고 SCR-S007의 미처리 목록에서 제거됩니다.

ESC 키와 배경 클릭, X 닫기 버튼도 확인 버튼과 동일하게 동작합니다.

환불 영수증 다운로드 링크는 백그라운드에서 PDF 생성을 트리거하고, 생성 완료 시 즉시 다운로드가 시작됩니다. 다이얼로그를 닫더라도 다운로드는 계속 진행됩니다.

환불 이력 보기 링크는 현재 다이얼로그를 닫고 DLG-S006 환불 상세 다이얼로그로 전환합니다. 부모 화면 자체는 동일하게 유지되며 모달이 교체되는 방식입니다.

원 매출 보기 링크는 현재 다이얼로그를 닫고 DLG-S001 매출 상세 다이얼로그로 전환합니다.

마이너스 세금계산서 수동 발행 안내가 표시된 경우의 SAL-EXT-02 진입 링크는 새 탭에서 세금계산서 발행 화면을 열어 운영자가 즉시 수동 발행을 진행할 수 있게 합니다.

## 7. 화면 상태

다이얼로그는 다음 상태들을 가지며 각 상태마다 보이는 모습이 달라집니다.

처리 완료 상태는 환불 처리가 성공적으로 완료되고 PG webhook도 즉시 도착한 일반적인 상태로, 녹색 체크 아이콘과 "환불 처리가 완료되었어요" 메시지가 표시됩니다.

PG 환불 처리중 상태는 결제링크 카드 환불에서 PG webhook 응답이 아직 도착하지 않은 상태로, 노란 시계 아이콘과 "PG 환불을 처리 중입니다" 메시지가 표시되고 5초 간격 자동 폴링이 동작합니다.

PG 환불 완료 상태는 처리중에서 webhook이 도착해 PG 환불 완료로 전환된 상태로, 헤더가 자동 갱신됩니다.

PG 환불 거절 상태는 webhook 거절 응답이 도착한 상태로, 헤더가 빨강 "PG 환불이 거절되었어요"로 표시되고 거절 사유와 익영업일 재시도 안내가 표시됩니다.

PG 폴링 타임아웃 상태는 60초 폴링 후에도 처리중이 유지된 상태로, "PG 처리가 지연되고 있어요. SCR-S007에서 확인해주세요" 안내와 함께 폴링이 중단됩니다.

마이너스 세금계산서 자동 발행 완료 상태는 법인 회원 환불에 대한 SAL-EXT-02 자동 발행이 성공한 상태로, 녹색 안내 카드가 표시됩니다.

마이너스 세금계산서 자동 발행 실패 상태는 자동 발행이 실패해 수동 발행이 필요한 상태로, 빨강 안내와 SAL-EXT-02 진입 링크가 강조됩니다.

전체 취소 결과 상태는 처리 유형이 "전체 취소"였던 경우로, 부분 환불 비율 표시가 없고 "전체 취소" 배지만 표시됩니다.

부분 환불 결과 상태는 처리 유형이 "부분 환불"이었던 경우로, "부분 환불" 배지와 원결제 금액 대비 비율이 함께 표시됩니다.

환불 영수증 다운로드 중 상태는 PDF 생성이 진행 중인 상태로, 다운로드 링크에 작은 스피너가 표시됩니다.

## 8. 예외 처리

이 다이얼로그는 변경 액션이 없으므로 사용자 입력 오류는 발생하지 않습니다. 발생 가능한 예외는 주로 비동기 상태 전환 관련입니다.

PG webhook 거절 수신 시 헤더가 빨강 안내로 전환되고, 거절 사유 코드와 익영업일 재시도 안내가 환불 수단 카드에 표시됩니다. 권한이 매니저 이상이면 SAL-EXT-04 재시도 진입 링크가 활성화됩니다.

PG 60초 폴링 타임아웃 시 폴링이 중단되고 SCR-S007에서 추후 확인이 안내됩니다. 운영자는 다이얼로그를 닫고 환불 관리 화면에서 상태를 확인할 수 있습니다.

마이너스 세금계산서 자동 발행 실패 시 수동 발행 안내가 표시되며, SAL-EXT-02 진입 링크로 즉시 수동 발행 흐름에 들어갈 수 있습니다.

환불 영수증 PDF 생성 실패 시 "영수증 생성에 실패했어요" 토스트가 표시되고 자동 재시도가 1회 백그라운드에서 수행됩니다.

폴링 중 네트워크 오류가 발생하면 폴링이 일시 중단되고 다음 주기에 자동 재시도됩니다. 사용자에게는 별도 안내가 표시되지 않습니다.

부모 화면 복귀 시 부모가 더 이상 존재하지 않는 경우(예: 부모 화면이 다른 사용자에 의해 닫혔거나 회원이 삭제된 경우)에는 SCR-S007 환불 관리 페이지로 기본 복귀합니다.

다지점 RLS 누수가 감지되면 보안 이벤트가 발생하지만, 이 다이얼로그 자체의 표시는 그대로 유지됩니다(처리는 이미 완료된 상태이므로).

## 9. 권한별 처리

이 다이얼로그는 환불 처리에 진입한 권한자(superAdmin·primary·owner·manager·fc)에게만 자동으로 표시됩니다. 권한이 없는 계정은 DLG-S013에 진입조차 할 수 없으므로 이 다이얼로그도 표시되지 않습니다.

권한별 표시 차이는 다음과 같습니다. 슈퍼관리자·primary·owner·manager에게는 모든 후속 액션(환불 영수증 다운로드, 환불 이력 보기, 원 매출 보기, 마이너스 세금계산서 수동 발행 진입)이 활성화됩니다. FC에게는 환불 영수증 다운로드와 환불 이력 보기가 활성화되며, 마이너스 세금계산서 수동 발행 진입은 권한이 부족하므로 비활성화됩니다.

PG 환불 거절 상태에서의 재시도 진입은 매니저 이상에게만 활성화됩니다. FC는 거절 사유를 확인할 수만 있고 재시도는 매니저 이상에게 요청해야 합니다.

다지점 RLS 격리는 본사 통합 모드가 아닌 경우 자기 지점 환불만 표시되며, 이 다이얼로그가 표시되는 시점에는 이미 권한 검증이 통과된 상태이므로 추가 검증은 불필요합니다.

## 10. 운영 정책

이 다이얼로그는 SAL-EXT-04 운영 시나리오의 "처리 완료 후 DLG-S014가 자동으로 표시됩니다" 정책의 시각화이며, 환불 운영의 마지막 단계에서 운영자와 회원 모두에게 결과 인지를 보장합니다.

처리 완료 안내(녹색 체크 아이콘과 명확한 메시지)는 운영자가 회원과 통화하면서 즉시 결과를 음성으로 안내할 수 있도록 강한 시각적 피드백을 제공하는 정책의 결과입니다.

환불 금액 큰 폰트 강조 표시는 환불 결과에서 가장 중요한 정보(얼마가 환불되었는지)를 운영자가 한눈에 인식할 수 있도록 보장합니다.

결제링크 카드 환불의 자동 폴링은 SAL-EXT-04 "결제링크 카드 환불은 PG 환불 후 webhook 상태 갱신" 정책에 따라 동작하며, 운영자가 webhook 도착을 기다리기 위해 화면을 떠나지 않아도 되도록 자동화됩니다.

PG 폴링 60초 타임아웃은 SAL-EXT-04 "결제링크 PG 응답 타임아웃 (60초+): 처리중 유지 + 자동 폴링" 정책의 결과이며, 무한 폴링을 방지하고 운영자가 다른 업무로 이동할 수 있도록 합니다.

마이너스 세금계산서 자동 발행 안내는 SAL-EXT-04·SAL-EXT-02 연계 정책의 시각화이며, 자동 실패 시 수동 발행이 즉시 진행되도록 안내합니다.

환불 영수증 PDF 다운로드 자동 생성은 회원의 환불 증빙 요청에 운영자가 즉시 응대할 수 있도록 보장하는 정책의 결과입니다.

환불 이력 보기(DLG-S006) 진입 링크는 환불 처리 직후 운영자가 처리 결과의 상세 이력을 추가로 확인할 수 있도록 매끄러운 흐름을 제공합니다.

확인 버튼 클릭 시 부모 화면으로의 복귀는 환불 운영의 종결을 명확히 하는 정책이며, 다음 업무로의 전환을 자연스럽게 잇습니다.

이 다이얼로그는 별도의 감사 로그를 적재하지 않습니다. 환불 처리의 감사 로그는 DLG-S013 시점에 이미 적재되어 있으므로 중복 적재를 방지합니다. 단 사용자 후속 액션(환불 이력 보기 진입·원 매출 보기 진입·영수증 다운로드)은 각 후속 화면에서 별도로 로그가 기록됩니다.

대량/고액 환불 알림은 SAL-EXT-04 "100만원+/10건+: 본사 슈퍼관리자 알림" 정책에 따라 DLG-S013 처리 시점에 이미 발송되어 있으므로 이 다이얼로그에서는 알림 발송이 일어나지 않습니다.

이상의 정책은 환불 상세 결과 다이얼로그가 환불 운영의 마지막 인지 단계임을 보여줍니다. 정책이 바뀌면 이 문서도 함께 갱신되어야 합니다.

## 13. 핵심 디자인 요청사항

처리 완료 헤더는 다이얼로그의 시각적 주인공이며, 큰 녹색 체크 아이콘과 명확한 메시지로 운영자가 한눈에 환불 성공을 인식할 수 있어야 합니다. 환불이 완료되었다는 안도감과 명확성을 디자인으로 전달하는 것이 핵심입니다.

환불 금액 카드는 헤더 다음으로 강한 시각적 비중을 가져야 하며, 환불 금액 숫자가 가장 큰 폰트와 빨강 강조 색상으로 표시되어 운영자가 회원에게 음성으로 응대할 때 자료를 보지 않고도 금액을 즉시 읽을 수 있어야 합니다.

부분 환불 / 전체 취소 배지는 환불 금액 옆에 작은 칩으로 붙어 처리 유형을 명확히 구분합니다. 부분 환불의 경우 원결제 대비 비율이 보조 설명으로 자연스럽게 추가됩니다.

PG 환불 처리중 상태에서는 노란 시계 아이콘과 작은 스피너가 함께 표시되어 자동 폴링이 진행 중임을 시각적으로 알리고, 운영자가 무한 대기하지 않도록 진행감을 전달합니다.

PG 환불 거절 상태에서는 헤더가 빨강 톤으로 강하게 전환되며, 거절 사유가 환불 수단 카드 안에 명확히 표시되어 운영자가 즉시 다음 액션(재시도 또는 SCR-S007 확인)을 판단할 수 있게 합니다.

마이너스 세금계산서 자동 발행 안내는 법인 회원 환불에서만 등장하며, 자동 발행 성공은 녹색 안내 카드, 자동 실패는 빨강 안내 카드로 명확히 구분되어 운영자가 추가 액션이 필요한지 즉시 알 수 있게 합니다.

후속 액션 링크(환불 영수증 다운로드·환불 이력 보기·원 매출 보기)는 다이얼로그 하단 좌측에 차분한 텍스트 링크로 배치되어, 주요 액션(확인 버튼)과 시각적 위계가 분명히 구분됩니다.

확인 버튼은 강조색으로 활성화되어 다이얼로그를 닫고 부모 화면으로 복귀하는 종결 액션임을 명확히 전달합니다.

모바일에서는 풀너비 시트로 전환되며, 환불 금액 카드와 처리 완료 헤더가 화면 상단에 우선 표시됩니다. 확인 버튼은 화면 하단에 sticky로 부착됩니다.

DLG-S013에서 이 다이얼로그로의 자동 전환은 부드러운 모달 교체 애니메이션으로 진행되어, 운영자가 두 단계 흐름을 자연스럽게 따라가도록 합니다.

## 14. 운영 정책 (이 다이얼로그에 연결된 부분)

이 다이얼로그가 따르는 운영 정책은 환불 운영의 마지막 결과 인지 단계라는 역할에 집중되어 있습니다.

처리 완료 자동 표시는 SAL-EXT-04 "처리 완료 후 DLG-S014가 자동으로 표시됩니다" 정책의 시각화이며, 운영자가 별도로 결과 확인 화면을 찾지 않아도 즉시 결과를 인지할 수 있도록 보장합니다.

결제링크 카드 환불의 자동 폴링과 60초 타임아웃은 SAL-EXT-04 PG 환불 흐름 정책의 자동화이며, 운영자가 webhook을 직접 기다리지 않도록 합니다.

마이너스 세금계산서 자동 발행 안내는 회계 정합성 정책의 시각화이며, 자동 실패 시 수동 발행이 빠뜨려지지 않도록 강한 시각적 강조로 안내합니다.

환불 영수증 PDF 다운로드 자동 생성은 회원의 환불 증빙 요청에 운영자가 즉시 응대할 수 있도록 보장하는 정책의 결과입니다.

이 다이얼로그가 별도의 감사 로그를 적재하지 않는 것은 중복 적재 방지 정책의 결과이며, 환불 처리의 감사 로그는 DLG-S013 시점에 이미 적재되어 있습니다.

대량/고액 환불 알림(100만원+/일별 10건+)은 DLG-S013 시점에 이미 발송되어 있으므로 이 다이얼로그에서 추가 알림이 발생하지 않습니다.

부모 화면 복귀 시 갱신 동작은 운영 흐름의 자연스러운 종결을 위한 정책이며, 환불 처리가 부모 화면(SCR-S007·DLG-S001·SCR-S012·DLG-S015)의 상태에 즉시 반영되어 운영자가 다음 작업을 매끄럽게 이어갈 수 있게 합니다.

다지점 RLS 격리는 이 다이얼로그가 표시되는 시점에는 이미 권한 검증이 통과된 상태이므로 추가 검증 없이 표시됩니다.

이상의 정책은 환불 상세 결과 다이얼로그가 환불 운영의 마지막 인지·종결 단계임을 보여줍니다. 정책이 바뀌면 이 문서도 함께 갱신되어야 합니다.
