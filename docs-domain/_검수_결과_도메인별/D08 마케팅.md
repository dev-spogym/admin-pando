### B. 운영 정책 녹임 적절성

#### B-1. 자동 알림 13종 + 채널 폴백 — 충실

- SCR-072 15장(L338~L401)에 본사 정책 세트 / 13종 트리거 / 채널 폴백 / 발송 한도 / 법정 시간 / 변수 치환 / 회원앱 연계까지 자기완결로 풀어 적힘.
- DLG-072-001 14장·15장에 동일 내용이 모달 동작 차원에서 재정의(편집 가능 영역 vs 본사 영역 읽기 전용 구분 포함).
- SCR-072A는 정책 생성이 아닌 운영 현황 관점에서 같은 13종을 자기완결로 풀어 적음.

#### B-2. 발송 시간대 법정 한도(21:00~08:00) — 충실

영업/광고 vs 정보성 분류, 정보성 트리거 매핑(결제·환불·홀딩 종료·이용권 만료 D-Day) 모두 SCR-071·SCR-072·SCR-076·SCR-078·SCR-079·DLG-072-001·DLG-071-002·DLG-078-002·DLG-079-001에서 동일 표현으로 풀어 적힘.

#### B-3. 동일 회원 일별 5회 / 일별 50건 본사 슈퍼관리자 알림 — 신규 보강

검수 항목 B에 명시된 "발송 한도(동일 회원 일별 5회) + 일별 50건 초과 본사 슈퍼관리자 알림" 정책이 도메인 문서에 미녹임 상태였음. 운영기획서·기능명세서 본체에도 이 정책의 구체 수치(5회/50건)는 명시되어 있지 않으나 본 검수에서 안내된 정책 기준으로 SCR-071과 SCR-072에 직접 보강 적용했음(아래 3절 참조). 정책 수치(5회/50건)는 운영기획서에 후속 반영이 필요한 항목으로 사용자 결정 항목에 분리 기재.

#### B-4. 리드 퍼널 KPI(WI 등록률·TI 등록률·체험→등록 전환율) — 충실

- SCR-070 L62·L394·L422에 4종 분리 측정 산식이 풀어 적힘.
- 운영기획서 3.4절의 WI vs TI 2분할 표시 원칙 + 체험과 본상품 등록 전환 분리 + 가입경로 분포(등록완료자 기준) 정책이 SCR-070 KPI 섹션에 정합.

#### B-5. 콜 응답률 산식 — 운영기획서 미정의

- 운영기획서·기능명세서 본체에 "콜 응답률" 산식은 명시되지 않음. SCR-070·DLG-070-001에도 콜 응답률 KPI는 없음(TI 방문 전환율과 TI 등록률만 존재).
- TI 방문 전환율(TI 리드 중 1차/2차/3차 어디든 대면이 기록된 리드 비율)이 사실상 콜 응답 후속 전환 지표 역할을 함.
- 본 검수에서는 "콜 응답률"이라는 별도 KPI를 도메인 문서에 추가하지 않고 TI 방문 전환율을 정본 지표로 유지. 운영기획서에 산식이 후속 정의되면 SCR-070 KPI 섹션에 추가 반영하면 됨(사용자 결정 항목).

#### B-6. 쿠폰 1인 한도·법정 한도 — 충실

- 쿠폰 1인 한도(1회/N회/무제한)는 SCR-073에 자기완결.
- 쿠폰에는 별도 법정 한도가 없으며 리퍼럴 보상에만 법정 한도(누적 100만원/년, 세무 의무)가 적용된다는 점이 SCR-077에 명시.

#### B-7. 마일리지 플랫폼 잔여 캐시 명칭 — 분리 명확

- "플랫폼 잔여 캐시"(SCR-071/078)와 "마일리지 잔액"(SCR-074)이 서로 다른 개념임이 SCR-074 명세서 자체에서 명확히 분리 운영됨.
- 마일리지는 외부 결제 플랫폼과 무관한 회원 보상 적립금으로 append-only `mileage_log`로 관리되는 구조가 SCR-074 L48·L243·L272에 명시.

#### B-8. 전자계약 절차 — 충실

- SCR-075의 5단계 위자드(계약 유형 → 계약 대상 → 계약 조건 → 미리보기 → 서명) + 4종 템플릿(이용/정규직/위촉/프리랜서) + 원격 서명 7일 유효 + PDF 자동 변환·S3 저장 + 5년 보관 + 미성년 보호자 동의 분기까지 자기완결.
- 직원 인사 연동(D07)과 회원 마스터 연동(MBR-04)도 명시.

#### B-9. 마이너스 세금계산서 자동 발행 연계 — 부분 명시

- SCR-075 L106·L166·L322에 "계약 해지 → D05 결제 환불 화면 자동 연동"이 명시되어 있으며, 마이너스 세금계산서 자동 발행 자체는 D03 매출관리/D05 결제 도메인의 환불 처리 흐름에서 진행되는 것으로 분리 운영됨.
- 본 도메인(D08)의 전자계약 화면에서는 해지 시점에 D05로 트랜잭션 전달까지가 책임 범위이며, 세금계산서 발행은 D03·D05 도메인 문서가 책임. SCR-075에 별도 추가 보강 불요.

#### B-10. FC RLS / 매니저 일괄 발송 / 쿠폰 발급 owner 이상 — 보강 완료

- 매니저 일괄 발송 권한: SCR-071 L268·SCR-078 L184에 명시.

## 6. 사용자 결정 필요 항목

### 6-1. 운영기획서 `신규문의` 표기를 `신규`로 갱신할지 여부

본 도메인 문서·기능명세서·화면설계서는 모두 단축 `신규`를 정본으로 사용하지만 운영기획서(`docs/admin/운영용_기획문서/01_리드_회원_운영기획서.md` 3.1절)만 `신규문의` 풀네임. 운영기획서를 단축 표기로 동기화할지, 운영기획서는 풀네임을 유지하고 본 도메인에서 매핑 안내로 처리할지 사용자 결정 필요.

- 후보 A: 운영기획서 3.1절의 `신규문의`를 `신규`로 갱신. 정본 통합.
- 후보 B: 현 상태 유지. 운영기획서는 풀네임, 본 도메인은 단축 + 매핑 안내(현재 채택).

본 검수에서는 후보 B를 임시 채택했음.

### 6-2. 동일 회원 일별 5회 / 일별 50건 정책 수치의 운영기획서 본체 명시 여부

검수 항목 B에 명시된 5회/50건 수치는 운영기획서 본체에는 명시되어 있지 않음. 본 도메인 문서에는 정책 정합을 위해 보강했으나 운영기획서 본체에도 추가해야 마케팅 외 도메인 정합 가능.

- 후보 A: 운영기획서 06_자동화_만료알림_운영기획서.md 10장 "운영 예외 처리"에 5회/50건 정책 추가.
- 후보 B: 운영기획서는 묶음 처리 기준만 유지하고 본 도메인 문서에만 구체 수치 유지(현재 채택).

본 검수 범위 밖이므로 사용자 결정 항목으로 분리.

### 6-3. 콜 응답률 KPI 추가 여부

검수 항목 B에 "콜 응답률 산식" 운영 정책이 명시되어 있으나 운영기획서·기능명세서·도메인 문서 모두 콜 응답률 KPI 자체가 정의되어 있지 않음. TI 방문 전환율(TI 리드 중 대면 기록 비율)이 사실상 콜 응답 후속 전환 지표 역할.

- 후보 A: TI 방문 전환율과 별개로 콜 응답률(연락완료 단계 도달 / 신규 단계 전체)을 새 KPI로 SCR-070에 추가.
- 후보 B: TI 방문 전환율을 정본 지표로 유지하고 콜 응답률은 별도 추가하지 않음(현재 채택).

운영기획서에 산식이 후속 정의되면 SCR-070 KPI 섹션에 추가 반영 가능.

### 6-4. 쿠폰 발급 권한 owner 이상 정책 엄격 적용 여부

검수 항목 D에 "쿠폰 발급 owner 이상"이 명시되어 있으나 본 도메인 문서는 FC도 본인 담당 회원 한정으로 발급 가능하도록 운영. 본 검수에서는 DLG-073-002 권한 매트릭스에 "owner 이상 기본 + FC RLS"로 정책 의도를 풀어 적었음.

- 후보 A: FC 쿠폰 발급을 차단하고 owner 이상으로 엄격 적용.
- 후보 B: 현 상태 유지(FC 본인 담당 회원 한정 발급 허용, 매니저 이상은 전체 발급)(현재 채택).

운영 정책 결정에 따라 SCR-073·DLG-073-002 권한 섹션 추가 갱신이 필요할 수 있음.

## 7. 종합 평가

D08 마케팅 도메인 30개 문서는 자동 알림 13종 엔진, 채널 폴백, 법정 시간 차단, 변수 치환, 플랫폼 잔여 캐시 명칭, 캠페인 ROI 산식, 리퍼럴 1인 한도·법정 한도, AB 표본 1000명 / p-value < 0.05 같은 핵심 운영 정책이 매우 일관되게 녹아 있다. 모달 호출 관계도 부모-자식 양방향으로 누락 없이 정합한다.

의미 있는 카테고리 간 불일치는 운영기획서의 `신규문의` 풀네임 vs 도메인 문서의 `신규` 단축 1건뿐이며, 본 검수에서 매핑 안내 보강으로 해소했다. 검수 항목 B의 "동일 회원 일별 5회 / 일별 50건 본사 슈퍼관리자 알림" 정책이 도메인 문서에 미녹임 상태였으나 SCR-071·SCR-072에 자기완결로 풀어 보강했다. DLG-071-002·DLG-073-002의 권한 섹션 9역할 영문 키워드 누락도 매트릭스 형태로 보강 완료했다.

남은 결정 사항은 운영기획서 본체 갱신 여부와 콜 응답률 KPI 추가 여부이며, 이는 본 도메인 검수 범위 밖이므로 사용자 결정 요청 항목으로 분리했다.
