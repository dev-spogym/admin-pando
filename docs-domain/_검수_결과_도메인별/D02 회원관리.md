#### B-5. 본사 통합 모드 — 충실

#### B-6. 일괄 작업 권한 단계 (매니저+/owner+) — 일관

## 6. 사용자 결정 필요 항목

### 6-1. 기능명세서 MBR-01-03-01의 6서브탭 표기를 화면설계서 8탭에 맞춰 갱신할지 여부

본 도메인 문서에서는 화면설계서 정본을 따랐으나, 기능명세서(`docs/admin/기능명세서/D02-회원관리/MBR-01-회원목록/00-기본기능.md` L36, L98)는 여전히 6서브탭 표기. 기능명세서를 8탭으로 동기화할지, 압축 표기로 유지할지 사용자 결정 필요.

- 후보 A: 기능명세서를 8탭(전체·활성·만료·예정·임박·홀딩·미등록·정지)으로 갱신. 정본 통합.
- 후보 B: 현 상태 유지. 기능명세서는 압축 표기(6서브탭), 화면설계서·도메인 문서는 정본 8탭으로 분리 운영.

본 검수에서는 화면설계서/도메인 문서가 정본이고 기능명세서는 압축 요약임을 SCR-M001에 명시하는 방식으로 후보 B를 임시 채택했음.

### 6-2. 운영기획서 4.1의 `비활성` 항목 명칭 변경 여부

- 현행: 운영기획서는 `비활성`(탈퇴·장기 중단·관리 제외 회원).
- 본 도메인 문서: `정지`(운영자 강제 비활성) + 탈퇴·삭제 회원 보기 토글 별도 섹션으로 분리.
- 의미: 운영기획서의 `비활성`이 본 도메인의 `정지`와 일치하는지 아니면 `정지 + 탈퇴 + 삭제`의 상위 묶음 개념인지 명확하지 않음.

- 후보 A: 운영기획서 4.1 `비활성`을 `정지`로 명칭 변경 + 탈퇴·삭제는 별도 섹션으로 분리.
- 후보 B: 운영기획서는 운영 라이프사이클 상위 묶음을 가리키는 표현이므로 그대로 두고, 본 화면이 실무 8탭으로 분해해 표시한다는 매핑 안내만 유지.

본 검수에서는 후보 B를 임시 채택했고 매핑 안내를 SCR-M001에 추가함.

### 6-3. DLG-M007 폴더명·문서 제목·SCR 호출 라벨 표기 통일 여부

- 폴더명: `DLG-M007 취소확인 다이얼로그`
- 문서 내부 제목: `DLG-M007 작업 취소 확인 다이얼로그`
- SCR-M002·M003 호출 라벨: `DLG-M007 작업취소확인`

정합성 문제는 없으나 표기 가독성 차원에서 통일 여부 결정 필요.

- 후보 A: 모두 `작업 취소 확인`으로 통일 (가장 길고 명확).
- 후보 B: 모두 `취소 확인`으로 통일 (간결).
- 후보 C: 현 상태 유지 (폴더명은 짧게, 본문·호출 라벨은 풀네임).

본 검수에서는 후보 C를 유지함.

## 7. 종합 평가

D02 회원관리 도메인 40개 문서는 자동화 배치 시각, 세그먼트 7종 우선순위, PII 마스킹 정책, 감사 로그 기록 기준, 본사 통합 모드, 일괄 작업 권한 단계 같은 핵심 운영 정책이 매우 일관되게 녹아 있다. 모달 호출 관계도 부모-자식 양방향으로 누락 없이 정합한다.

유일한 의미 있는 카테고리 간 불일치는 회원 목록 상태 필터 탭의 항목 수(6 vs 8)이며, 본 검수에서 화면설계서/도메인 문서를 정본 8탭으로 정의하고 운영기획서·기능명세서와의 매핑 안내를 SCR-M001에 보강했다. 4개 다이얼로그(DLG-M007/M008/M010/M012)의 권한 섹션에 9역할 영문 키워드를 병기해 권한 매트릭스 표기 일관성도 회복했다.

남은 결정 사항은 기능명세서·운영기획서 본체 문서 갱신 여부이며, 이는 본 도메인 검수 범위 밖이므로 사용자 결정 요청 항목으로 분리했다.
