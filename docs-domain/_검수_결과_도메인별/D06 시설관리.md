## 0. 검수 요약

본 검수는 D06 시설관리 도메인(SCR 10건, DLG 19건)의 의미적 정합성을 카테고리 간 명칭·정책·모달 호출·권한 정책 4축으로 점검했다. 직전 작업에서 SCR-056의 장비 카테고리 라벨(`유산소/웨이트/GX/기타`)이 DLG-056-001의 정식 라벨(`유산소기구/웨이트기구/GX장비/기타`)과 어긋난 채 남아 있었음을 확인하여 이번 검수에서 명백한 라벨 불일치만 직접 보정하였다. 그 외 정책 항목은 운영기획서 04 및 계약코드 점검 08 기준으로 누락·왜곡 없이 녹아 있다.

### A-2. 장비 카테고리 4종 라벨 (SCR-056 vs DLG-056-001) — 이전 작업 미완료 보정

이전 작업 메모에 따르면 SCR-056 라벨 통일이 완료됐다고 했으나, 실제 본문에는 두 위치에 `유산소/웨이트/GX/기타` 약식 라벨이 그대로 남아 있었다. DLG-056-001은 `유산소기구/웨이트기구/GX장비/기타`로 일관되어 있어, SCR-056 본문(2건) + 점검 주기 표기(1건) 총 3개 위치를 DLG-056-001 기준으로 직접 보정하였다. 상세는 E. 직접 보정 내역 참조.

### A-3. RFID 발급·이력·삭제 정책

- 발급: SCR-052 / DLG-052-001 모두 RFID 리더 스캔 + 수동 입력(16자리 HEX 또는 테넌트 정의 형식) — UNIQUE 제약 + 형식 검증 일관
- 이력: SCR-052 / DLG-052-002 모두 최대 90일 범위 + 90일 초과는 데이터 웨어하우스 — 일관
- 삭제: SCR-052 / DLG-052-003 모두 매니저(owner/manager) 이상, 영구 삭제이되 감사 로그 보존 — 일관

### A-5. 발주 기준 (소모품)

운영기획서에는 명시되어 있지 않으나 SCR-057 / DLG-057-003 정책이 자체 완결:
- 안전 재고 미달 시 자동 `부족(low)` 상태 → NFR-19 알림(즉시 + 매일 09:00 재발송)
- 재고 0 시 `없음(empty)` + "발주 필요" 강조 → 매일 09:00 발주 권장 알림
- 자동 발주는 없음(운영자 수동 발주). 권장 수량은 "안전 재고 + 평균 출고량" 자동 계산
- 발주 대기 상태에서 입고 처리(전체 입고) 시 자동 해제

→ 의미적으로 일관. 자동 발주 트리거가 없는 정책은 SCR-057 9장·15장과 DLG-057-003 모두 동일.

### A-6. 청소 주기

- 일일 / 주간(요일 선택) / 월간(지정일 또는 지정 번째 요일) 3종 — SCR-058 / DLG-058-001 일관
- 정기 일정 자동 반복 생성 배치: 매일 00:00 — 양 문서 모두 명시
- 시간 초과 미완료 폴링: 1분 주기 — 양 문서 일관

## B. 운영 정책 녹임 적절성

운영기획서 04 시설·부가서비스의 핵심 정책이 SCR/DLG에 어떻게 녹아 있는지를 점검했다.

### B-1. 락커 자동 배정 정책

- 운영기획서 4.1 "락커 배정과 해제는 회원 상세에서도 진입 가능해야 한다" → SCR-050 3장 "회원 상세(SCR-M004)에서의 진입" 명시 (회원의 보유 락커 자동 검색)
- 키오스크 자동 배정 존(기본 A, B) → SCR-050 9장, 15장에 명시
- 정책 활성 테넌트에서 만료 경과 02:00 자동 회수 → SCR-050 9장 명시
- DLG-050-004(개별 배정) / DLG-050-006(일괄 배정 최대 5개) 모두 SCR-050 정책과 일치

### B-2. RFID 단일 회원 매핑

- 운영기획서 4.2 "카드 자체 상태와 회원 매핑 상태를 분리한다" → SCR-052 본문 "카드 자체 상태(활성/분실/해제)와 회원 매핑 상태를 분리해서 관리" 명시
- 회원 1명당 활성 카드 1개 기본, 테넌트 토글로 무제한 운영 가능 — SCR-052 15장 + DLG-052-001 16장 모두 동일
- 정책 위반 시 [기존 분실 후 재발급] / [추가 허용 권한자만] / [취소] 3선택지 — DLG-052-001 5장 + SCR-052 7장 동일하게 명시
- 분실 카드 외부 사용 시도 시 시도 로그 기록 + 운영자 즉시 알림 — SCR-052 9장 + 15장

### B-3. 장비 점검 주기 (월·분기·반기·연간)

- SCR-056 본문은 `월/분기/반기/연간` 표기, DLG-056-001은 `일 단위(30/90/180/365 퀵 선택)` 표기 — 의미적 동치이나 표기 차이가 있어 SCR-056에 등가 보강 주석 추가(E. 직접 보정 내역)
- 자동 갱신: 점검 등록 시 점검 주기에 따라 +30/90/180/365일 자동 계산 — SCR-056 9장 + DLG-056-002 일관

### B-4. 소모품 안전 재고 임계값

- 운영기획서에는 안전 재고 임계값이 명시되어 있지 않으나, 화면 정책으로 등록 시 필수 입력 + 1 이상 자연수 + 미달 시 자동 부족 전환 — SCR-057 15장 + DLG-057-001 16장 일관

### B-5. 청소 스케줄 시간 슬롯

- DLG-058-001: 예정 시간 HH:mm 형식, 운영 시간 내 권장 — 운영기획서에 명시된 시간 슬롯은 없으며 SCR-058 / DLG-058-001 모두 자유 입력 시간(HH:mm) 정책으로 일관

### B-6. 발주 자동 트리거

- A-5에서 정리한 바와 같이 자동 발주는 없으며, 부족·없음·발주 대기 상태 + 권장 수량 자동 계산만 제공. SCR-057 9장 "발주서 생성 자동화는 발주 생성 시 PDF 생성 + 이메일 발송"으로 발주서 생성 후 자동화는 일관

### B-7. 시즌 운영(여름/겨울 풀가동·비수기)

- 운영기획서 04 및 D06 SCR/DLG 모두 시즌 운영 정책을 명시한 영역이 없음. 화면별로 6장(버튼·아이콘·링크 액션) 및 15장(운영 정책)에 시즌 토글 또는 시즌별 가동률 카드는 노출되지 않음 — 운영기획서 04 자체에 정의가 없는 항목이므로 검수 대상 외로 본다(필요 시 별도 정책 정의가 선행되어야 함).

## F. 결론 및 권고

### F-1. 검수 결과 요약

- D06 시설관리 29개 README.md 의미적 정합성: **A·B·C·D 모두 양호**

### F-2. 권고 사항

1. **운영기획서 04 운동복 상태 정의** — 운영기획서는 5상태(`대여가능/대여중/세탁중/점검중/폐기예정`), SCR-055는 4상태(`대기/대여중/세탁중/파손`) + 폐기 액션으로 분해되어 있다. 둘 다 의미적 동치이나 운영진과 개발자의 혼선을 줄이려면 다음 갱신 시 SCR-055 본문에 "운영기획서 5상태와 화면 4상태+폐기 액션 매핑 표" 추가를 권고한다.
2. **시즌 운영(여름/겨울) 정책 신규 정의 필요** — 운영기획서 04 및 D06 SCR/DLG 어디에도 시즌별 풀가동·비수기 정책이 정의되어 있지 않다. 시설 가동률·소모품 발주 권장 수량·청소 주기에 시즌 변수가 도입된다면 운영기획서 04 5장 또는 별도 부속 문서로 추가 필요.
3. **장비 점검 주기 표기 일원화** — 이번 검수에서 SCR-056에 "일 단위 + 월·분기·반기·연간 등가 표기"로 보강했으나, 장기적으로는 DLG-056-001의 `일 단위`로 단일화하고 SCR-056 6장·15장의 `월/분기/반기/연간` 표기를 모두 일 단위로 통일하는 것이 좋다. 본 검수에서는 의미적 등가가 명확하여 본문 일부에 등가 표기를 남기는 선에서 마무리.
4. **SCR-056 / SCR-058에 `front` 키워드 명시** — 현재는 `FC · 스태프`로 묶여 있고 의미적으로는 9역할 모델과 일치하나, 다른 도메인과 표기 일관성을 위해 `프런트(front)`를 명시적으로 추가 표기하는 것이 향후 키워드 검증 스크립트 작성 시 유리하다(현 검수에서는 보정 대상 외).

### F-3. 검수 종료

이상으로 D06 시설관리 도메인 29개 문서의 의미적 검수를 마친다. 보정 1건 외에는 정책·모달·권한 정합성 모두 양호하며, 추가 작업은 위 권고 사항 4건에 한정된다.
