# D09 설정관리 도메인

작성일: 2026-05-22 · 버전: v1.0 · 상태: 정합화 완료

## 도메인 개요

D09 설정관리 도메인은 admin-pando 관리자 웹에서 센터를 운영하는 데 필요한 모든 설정과 정책을 한 자리에서 관리하는 영역입니다. 센터의 기본 정보·알림·테마·물품 같은 운영 메타데이터, 권한 템플릿과 커스텀 역할로 구성되는 RBAC, 본사가 정의한 자동화 정책 세트의 지점 적용, 키오스크 단말과 IoT 출입 게이트의 등록과 정책, 구독 결제와 청구 이력 관리, 공지사항·다국어·출석 관리 정책·데이터 백업/복원까지 운영 인프라 전반의 결정 도구를 모아 두고 있습니다.

이 도메인의 모든 화면은 다음 공통 원칙을 따릅니다.

미저장 변경 손실 방지(DLG-080-001) 패턴이 일관 적용되어 입력 화면에서 변경 손실 사고를 막습니다.

권한 정책에 따라 화면 진입과 액션이 단계적으로 제한됩니다(메뉴 숨김 → 버튼 hidden → 입력 비활성 → 백엔드 403 응답 → 감사 로그).

본사·지점 소유권 분리에 따라 본사는 전사 표준(정책 세트·권한 템플릿·공통 상품 마스터·알림 템플릿)을 정의하고, 지점은 본사가 허용한 범위 내에서 자기 환경에 맞춰 적용합니다.

모든 변경은 SCR-097 감사 로그에 비동기로 INSERT되어 5초 안에 조회 가능합니다.

저장 시 외부 면(회원앱·키오스크·IoT 기기·결제 PG·메시지 플랫폼)에 영향을 주는 변경은 atomic 트랜잭션 또는 push 동기화로 처리되며 부분 실패는 재시도 또는 자동 롤백됩니다.

## 화면 그룹과 운영 흐름

### 센터 운영 메타데이터 그룹

SCR-080 센터 설정은 센터명·로고·운영시간·VAT·알림 채널 토글·테마·물품 재고를 다루며, DLG-080-001 미저장 경고로 입력 손실을 막습니다. SCR-088 다국어 설정은 표시 언어·타임존·화폐·자동 번역을 다루며, SCR-082(키오스크 표시 언어)와 SCR-085(자동 번역)에 연계됩니다.

### 권한과 역할 그룹

SCR-081 권한 설정은 7종 기본 역할과 커스텀 역할의 9×5 매트릭스를 다루며, DLG-081-001 ~ DLG-081-006으로 초기화·충돌·생성·삭제·복사·영향 분석이 단계적으로 진행됩니다. SCR-087 커스텀 역할 생성은 SCR-081과 단일 source-of-truth로 동기화되며, DLG-087-001 재배정으로 권한 공백을 방지합니다.

### 본사 정책 적용 그룹

SCR-080A 지점 자동화 적용은 본사가 등록한 자동 알림 정책 세트를 지점이 선택·조정해 적용하는 화면이며, DLG-080A-001 정책 적용 확인으로 영향 범위(발송 대상·예상 비용·충돌 항목)를 사전 확인합니다. 본사 슈퍼관리자의 강제 배포 흐름도 이 모달이 처리합니다.

### 키오스크와 IoT 그룹

SCR-082 키오스크 설정은 출석 방식·화면 구성·기능 표시를 다루며 atomic push로 모든 키오스크에 즉시 반영됩니다. SCR-082A 키오스크 IoT 설정은 키오스크 본체에 부착되는 IoT 주변 장치(카메라·스캐너·키패드) 페어링을 다룹니다. SCR-083 IoT 출입 관리는 센터 출입 게이트(RFID·QR·얼굴·핀번호) 정책을 다루며 비정상 출입 시도 알림을 처리합니다. 모든 화면에서 DLG-080-001 미저장 경고가 공통 적용됩니다.

### 구독·결제 그룹

SCR-084 구독 결제 관리는 Pando 플랜과 결제 수단을 다루며 매니저 이하는 재무 정보 보호 정책에 따라 접근 차단됩니다. DLG-084-001 플랜 변경 확인은 업그레이드/다운그레이드 영향(차액·적용 시점·데이터 한도)을 사전 안내하고, DLG-084-002 구독 해지 확인은 데이터 보관(90일)·grace period 정책을 안내합니다.

### 공지와 출석 그룹

SCR-085 공지사항 관리는 카테고리·게시 대상·예약 발행·필독·자동 번역을 다루며 DLG-085-001 등록·수정과 DLG-085-002 삭제 확인이 호출됩니다. SCR-086 출석 관리 설정은 인정 시간·지각·자동 출석·정정 권한·보관 기간(법정 최소 12개월)을 다루며 SCR-083 IoT 연동에 의존합니다.

### 시스템 운영 그룹

SCR-089 데이터 백업·복원은 자동 백업과 시점 복원을 다루며, 복원은 슈퍼관리자 권한 또는 Owner(지점장)의 승인 워크플로로 제한됩니다. DLG-089-001 데이터 복원 확인은 영향 안내·트랜잭션 점검·복원 사유 입력을, DLG-089-002 백업 설정은 자동 백업 옵션 입력을 처리합니다.

## 외부 연계 화면

- SCR-097 감사 로그: 본 도메인의 모든 변경이 비동기 INSERT되어 5초 안에 조회됩니다.
- NFR-19 알림 센터: 미연결 기기·자동 백업 실패·비정상 출입·만료 알림·자동 번역 실패·미수금·결제 실패 등 운영자 알림을 일괄 처리합니다.
- 회원앱·키오스크·IoT 기기·PG·메시지 플랫폼: 본 도메인 저장 시점의 외부 push 대상이며 모두 atomic 트랜잭션으로 처리됩니다.
- SCR-060 직원 관리: SCR-081·SCR-087의 역할 매트릭스가 직원의 활성 세션에 적용됩니다.
- MKT-02 자동 알림: SCR-080A의 정책 적용 결과가 발송 큐에 반영됩니다.
- 본사 정책 라이브러리: 본사 슈퍼관리자가 정책 세트를 등록·관리하며 SCR-080A에서 지점이 선택·적용합니다.

## 문서 작성 원칙

본 도메인의 모든 화면/다이얼로그 문서는 다음 원칙으로 작성되었습니다.

자기완결성: 다른 문서를 함께 보지 않아도 한 장만으로 화면을 구현·운영할 수 있도록 작성됩니다.
