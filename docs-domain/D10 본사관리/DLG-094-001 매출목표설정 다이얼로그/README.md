## 2. 다이얼로그 개요와 호출 트리거

매출 목표 설정 다이얼로그는 본사 슈퍼관리자가 지점별 월 매출 목표를 한 번에 입력하거나 수정해, KPI 대시보드(SCR-094)의 매출 달성률 게이지가 실시간으로 갱신되도록 만드는 운영 액션 다이얼로그입니다. 전체 지점 일괄 입력과 지점별 개별 입력을 모두 지원하며, 입력 보조를 위해 전년 동기 실적이 참고용으로 표시되고, 1억 원을 초과하는 목표는 본사 슈퍼관리자 2차 승인 흐름이 자동 트리거됩니다. 매월 신규 월 시작 시점에 목표가 미설정된 지점은 전월 목표값을 초기값으로 제안받아 운영자가 그대로 저장하거나 수정할 수 있습니다.

호출 트리거는 두 가지입니다. 첫 번째는 KPI 대시보드(SCR-094)의 매출 게이지 카드 우측 [매출 목표 설정] 버튼 클릭이며, primary/superAdmin과 owner에게만 활성화됩니다. 두 번째는 매출 목표가 미설정된 상태(게이지 0% 고정 + "목표 미설정" 배지 표시)에서 안내 영역의 [목표 설정] 링크 클릭이며, 이 경로로 들어오면 다이얼로그가 자동으로 미설정 지점이 포커싱된 상태로 열립니다. 매니저 이하 권한자에게는 트리거 버튼·링크 자체가 hidden 처리되어 다이얼로그가 호출되지 않습니다.

## 3. 입력 필드와 UI 구성

다이얼로그는 가로 약 720px 폭의 모달로, 다수 지점의 목표 금액을 한 화면에서 비교 입력해야 하므로 표 구조가 가로로 충분히 확보된 형태입니다. 상단에는 "매출 목표 설정"이라는 제목과 X 닫기 버튼이 있고, 본문에는 적용 기간 선택, 입력 방식 토글, 지점별 입력 테이블, 입력 합계 카드가 차례로 배치되며 하단에는 [취소] 버튼과 [저장] 버튼이 우측 정렬로 배치됩니다.

적용 기간 선택 영역에는 두 가지 옵션이 라디오로 노출됩니다. "특정 월 지정"은 단일 월을 선택하는 단순 모드이며 기본 진입은 다음 달입니다. "기간 범위"는 시작 월부터 종료 월까지 동일 목표가 일괄 적용되는 모드이며, 분기·반기·연간 보고 주기에 맞춰 한 번에 설정할 때 사용됩니다. 적용 기간을 변경하면 우측에 해당 기간의 전년 동기 실적이 참고용으로 표시되어 입력 의사결정을 돕습니다.

입력 방식 토글은 "전체 일괄 / 개별 입력" 두 옵션입니다. 전체 일괄을 선택하면 단일 금액 입력란이 표시되고 이 값이 모든 지점에 동일하게 적용되는 미리보기 표가 노출됩니다. 개별 입력을 선택하면 지점별 입력 테이블이 활성화되며, 컬럼은 좌측부터 지점명, 현재 설정된 목표 금액(있는 경우), 전년 동기 실적(참고), 신규 목표 금액 입력란, 전월 대비 증감률(자동 계산) 순서입니다. 신규 지점(개설 3개월 미만)은 별도 섹션으로 분리 표시되며 "신규 지점" 배지와 함께 전년 동기 실적이 "-"로 표시됩니다.

목표 금액 입력란은 0 이상의 정수만 허용하며 천 단위 콤마가 자동 포맷됩니다. 입력값이 1억 원을 초과하면 입력란 옆에 노랑 경고 배지 "본사 승인 필요"가 즉시 표시되어 저장 시 승인 플로우가 트리거될 것임을 사전 안내합니다. 음수 입력 시 인라인 오류 "0 이상의 금액을 입력하세요"가 표시되고 [저장] 버튼이 비활성화됩니다.

테이블 하단에는 입력 합계 카드가 있습니다. 카드에는 전체 지점 합계 목표, 전월 합계 대비 증감(절댓값과 증감률 %), 전년 동기 합계 대비 증감이 함께 표시되어 운영자가 전사 관점에서 목표 수준의 적정성을 즉시 확인할 수 있습니다.

[저장] 버튼은 변경 사항이 있을 때만 활성화되며, 클릭 시 로딩 상태로 전환되어 중복 클릭이 차단됩니다. [취소], X 닫기, ESC, 배경 클릭은 모두 동일한 취소 동작이며 입력 도중인 경우 "변경 사항이 사라집니다. 닫으시겠습니까?" 확인을 한 번 더 묻습니다.

## 4. 검증 규칙

목표 금액은 0 이상의 정수만 허용되며, 음수 또는 소수점은 차단됩니다. 음수 입력 시 인라인 오류 "0 이상의 금액을 입력하세요"가 즉시 표시되고 [저장] 버튼이 비활성화됩니다. 입력값이 비어 있는 지점은 "미설정"으로 간주되어 KPI 게이지가 0% 고정 + "목표 미설정" 배지로 노출되며, 저장은 허용됩니다.

적용 기간이 "기간 범위"인 경우 시작 월이 종료 월보다 늦으면 인라인 오류 "시작 월이 종료 월보다 늦습니다"가 표시되고 [저장] 버튼이 비활성화됩니다. 기간 범위 최대 길이는 12개월이며 초과 시 인라인 오류로 안내됩니다.

1억 원을 초과하는 목표가 1건 이상 포함된 경우 [저장] 클릭 시 본사 슈퍼관리자 2차 승인 요청 모달이 인라인으로 표시되며, 슈퍼관리자가 승인하기 전까지는 대시보드 게이지에 반영되지 않고 해당 지점에 "승인 대기 중" 배지가 표시됩니다. 슈퍼관리자가 직접 입력한 경우에도 안전 장치로 동일한 승인 흐름이 적용됩니다.

owner(Owner(지점장))가 호출한 경우 본인 소속 지점만 입력 가능하며, 다른 지점의 입력란은 비활성화되고 회색 처리됩니다. 권한이 없는 지점에 직접 API로 저장을 시도하면 백엔드 403으로 차단되고 감사 로그에 권한 우회 시도가 기록됩니다.

## 5. 확인 / 취소 액션

[저장] 버튼을 누르면 다이얼로그가 로딩 상태로 전환되어 주요 버튼이 비활성화되고, 백엔드에 목표 저장 트랜잭션이 전송됩니다. 1억 원 초과 목표가 포함된 경우 트랜잭션 직전 본사 슈퍼관리자 2차 승인 요청 모달이 인라인으로 표시되며, 승인 대상자에게 알림 센터(NFR-19)를 통해 인앱 알림이 발송됩니다. 승인 전까지 해당 지점의 목표는 "승인 대기 중" 상태로 저장되고 게이지에는 반영되지 않습니다.

성공하면 다이얼로그가 닫히고 부모 화면(SCR-094)의 매출 게이지 카드와 지점별 비교 테이블이 즉시 갱신됩니다. 우측 상단에 "매출 목표가 저장되었어요" 성공 토스트가 표시되고, 1억 원 초과 목표가 포함된 경우에는 "승인 요청이 발송되었어요" 추가 토스트가 함께 표시됩니다. 저장 직후 KPI 캐시가 무효화되어 다음 요청 시 새 목표값으로 달성률이 재계산됩니다.

[취소], X 닫기, ESC, 배경 클릭은 모두 동일한 취소 동작이며 입력 도중인 경우 "변경 사항이 사라집니다. 닫으시겠습니까?" 확인 yes/no가 한 번 더 표시됩니다. 확정 시 변경 없이 다이얼로그가 닫히고 부모 화면이 그대로 유지됩니다.

## 6. 예외 처리

저장 트랜잭션 실패 시 모달이 닫히지 않고 "목표 저장에 실패했습니다. 입력값을 확인해 주세요" 토스트가 표시되며 입력값이 유지됩니다. 자동 재시도 1회 후 실패 시 사용자 액션을 기다립니다. 트랜잭션은 전체 롤백되어 부분 저장은 발생하지 않습니다.

다른 운영자가 같은 지점·기간의 목표를 동시에 편집한 경우 optimistic lock 위반이 발생하며 "다른 사용자가 수정 중입니다. 잠시 후 다시 시도해 주세요" 모달이 표시됩니다. 사용자는 최신 데이터를 새로고침한 뒤 다시 시도해야 합니다.

전년 동기 실적이 없는 신규 지점(개설 3개월 미만)은 참고 컬럼이 "-"로 표시되고 전년 대비 증감률 컬럼도 "-"로 표시됩니다. 입력 자체는 정상적으로 수행 가능합니다.

권한 없는 지점에 직접 API로 저장을 시도하면 백엔드 403으로 차단되고 "권한이 없어요" 토스트가 표시되며 다이얼로그가 자동 닫힙니다. 감사 로그에 권한 우회 시도가 기록됩니다.

1억 원 초과 목표가 포함되었지만 승인 대상 슈퍼관리자가 부재 중(예: 모든 슈퍼관리자 비활성 상태)인 경우 "승인 가능한 본사 슈퍼관리자가 없습니다" 안내가 표시되고 저장이 차단됩니다. 운영자는 일반 목표만 저장하거나 슈퍼관리자 복귀 후 재시도해야 합니다.

기간 범위 모드에서 시작 월이 이미 마감된 과거(예: 전월 이전)인 경우 경고 "이미 마감된 과거 월입니다"가 표시되며 운영자가 확인 후 진행할 수 있도록 yes/no 확인이 한 번 더 노출됩니다. 마감 후 변경된 목표는 KPI 추이 차트의 과거 데이터에는 영향을 주지 않고 최신 추이만 갱신됩니다.

## 7. 권한별 처리

본 다이얼로그는 superAdmin, primary, Owner(지점장)에게 호출 가능합니다. 슈퍼관리자와 primary는 전 지점 입력이 가능하며, owner는 자기 소속 지점만 입력 가능하고 다른 지점의 입력란은 비활성화·회색 처리됩니다.

매니저(manager), FC(fc), 트레이너(trainer), 스태프(staff), 프런트(front), 읽기 전용(readonly)은 본 다이얼로그를 호출할 수 없습니다. 부모 화면(SCR-094)의 [매출 목표 설정] 버튼이 이 권한자에게는 hidden 처리되며, 직접 URL 또는 콘솔 우회로 다이얼로그가 호출되더라도 백엔드 응답이 403으로 차단됩니다.

1억 원 초과 목표 입력 시 2차 승인 권한은 본사 superAdmin에게만 있습니다. primary와 owner가 1억 원 초과를 입력하면 승인 요청이 슈퍼관리자에게 발송되며, 슈퍼관리자가 직접 입력한 경우에도 안전 장치로 동일한 흐름이 적용됩니다.

권한 부족으로 차단된 경우의 사용자 경험은 단계별로 일관됩니다. 첫째, 부모 화면의 호출 버튼·링크가 hidden 처리됩니다. 둘째, 직접 URL 접근으로 다이얼로그까지 도달한 경우에는 백엔드 응답이 403이 되어 "권한이 없어요" 토스트가 표시되고 다이얼로그가 자동 닫힙니다. 셋째, 모든 권한 차단 이벤트는 감사 로그(SCR-097)에 actor_id·attempted_branches·attempted_action·timestamp로 기록되어 사후 추적이 가능합니다.

## 8. 운영 정책 (이 다이얼로그에 연결된 부분)

월별 목표 달성률 게이지는 본 다이얼로그에서 입력한 목표값이 없으면 비활성(N/A) 또는 0% 고정 + "목표 미설정" 배지로 표시됩니다. 매월 신규 월 시작 시 목표가 미설정된 지점은 전월 목표값을 초기값으로 제안받지만 자동 저장은 되지 않으며, 운영자가 명시적으로 [저장]을 눌러야 반영됩니다(월 목표 자동 복사 정책).

1억 원 초과 매출 목표는 본사 슈퍼관리자 2차 승인 후 반영됩니다. 승인 대기 중인 목표는 "승인 대기 중" 배지로 표시되며 게이지에는 직전 승인 완료 목표가 노출됩니다. 승인 흐름은 슈퍼관리자에게 알림 센터 인앱 알림이 즉시 발송되며 승인 완료 시 다시 알림으로 운영자에게 결과가 전달됩니다.

신규 지점(개설 3개월 미만)은 지점별 비교 테이블에서 별도 섹션으로 분리 표시되며, 본 다이얼로그에서도 별도 섹션으로 구분됩니다. 안정화(개설 91일 경과) 이후 자동으로 일반 비교 테이블에 편입되며, 이는 신규 지점 안정화 자동 전환 배치(매일 00:00)에 의해 처리됩니다.

전년 동기 실적은 입력 참고용으로만 표시되며 저장에는 영향을 주지 않습니다. 전년 동기 실적이 없는 신규 지점은 "-"로 표시되고, 운영자는 자체 판단으로 입력해야 합니다. 전월 대비 증감률은 자동 계산되며, 절댓값(원)과 증감률(%)이 함께 표기됩니다(예: `+120만 / +8.3%`).

지점별 비교 테이블의 색상 코딩 기준은 저장된 목표값을 기준으로 계산됩니다. 달성률 100% 이상은 초록, 80~99%는 노랑, 79% 이하는 빨강으로 표시되며, 목표 미설정 지점은 회색 처리됩니다. 비교 테이블의 기본 정렬은 달성률 낮은 순(미달 우선 식별)이며, 본 다이얼로그 저장 직후 게이지와 색상이 즉시 갱신됩니다.

목표 저장 시 KPI 캐시(Redis TTL 300초)가 무효화되어 다음 요청 시 새 목표값으로 달성률이 재계산됩니다. 일별 정산 배치(매일 03:00)는 전날까지 누적된 매출 데이터를 확정해 달성률 산출의 분자로 사용하며, 목표값(분모)은 본 다이얼로그에서 저장된 최신 값이 사용됩니다.

감사 로그 정책은 모든 목표 설정·수정 이벤트를 SCR-097 감사 로그에 기록합니다. 기록되는 필드는 `actor_id`(처리 운영자), `branch_ids[]`(대상 지점 목록), `action=KPI_TARGET_SET`, `target_period`(적용 기간), `before`(이전 목표값 배열), `after`(신규 목표값 배열), `approval_required`(1억 초과 여부), `timestamp`이며 5초 안에 감사 로그 화면에서 조회 가능해야 합니다. KPI 대시보드 접근 자체도 감사 로그에 기록됩니다.

owner 권한 정책은 본인 소속 지점만 입력 가능하며 다른 지점은 비활성화·회색 처리됩니다. 이는 데이터 격리(RLS) 정책의 일부이며, owner가 다른 지점의 입력을 시도하면 백엔드에서도 403으로 차단됩니다.

## 11. 핵심 디자인 요청사항

다이얼로그는 가로 약 720px 폭의 모달로 다수 지점 목표를 한 화면에서 비교 입력해야 하므로 표 구조가 가로로 충분히 확보되어 있어야 합니다. 데스크톱에서는 모든 컬럼이 한 줄에 들어오고, 태블릿에서는 가로 스크롤이 표 내부에서만 발생합니다.

적용 기간 선택은 라디오 그룹으로 시각적으로 명확히 구분되며, "기간 범위"를 선택하면 시작 월·종료 월 캘린더가 자연스럽게 펼쳐지는 슬라이드 다운 애니메이션이 적용됩니다. 입력 방식 토글("전체 일괄 / 개별 입력")은 우측에 함께 배치되어 한눈에 모드를 전환할 수 있어야 합니다.

지점별 입력 테이블은 행 간격을 충분히 넓게, 폰트 크기는 일반 텍스트보다 약간 크게 잡아 가독성을 우선합니다. 컬럼 정렬은 지점명·배지는 좌측 정렬, 금액(현재 목표·전년 실적·신규 목표 입력)은 우측 정렬, 증감률은 중앙 정렬로 통일됩니다. 신규 지점 섹션은 별도 헤더로 분리되어 시각적으로 구분됩니다.

목표 금액 입력란은 천 단위 콤마가 자동 포맷되며, 1억 원을 초과하면 입력란 옆에 노랑 "본사 승인 필요" 배지가 즉시 나타나고 입력란 자체에도 노랑 테두리 강조가 적용됩니다. 음수 입력 시 빨강 테두리와 함께 인라인 오류가 표시됩니다.

입력 합계 카드는 테이블 하단에 sticky로 고정되어 운영자가 표를 스크롤해도 항상 보이며, 전체 합계·전월 대비 증감·전년 동기 대비 증감이 동시에 노출됩니다. 증감 표시는 절댓값(원)과 증감률(%)이 한 줄에 함께 표기되며 양수는 초록, 음수는 빨강 계열로 색상이 분리됩니다.

[저장] 버튼은 주 액션 색상(브랜드 컬러)으로, [취소] 버튼은 보조 색상으로 분리되어 시각적 위계가 명확히 드러납니다. 1억 원 초과 목표가 포함된 경우 [저장] 버튼 옆에 작은 안내 아이콘이 나타나 호버 시 "본사 슈퍼관리자 승인이 필요합니다" 툴팁이 표시됩니다. 로딩 상태에서는 [저장] 버튼이 스피너로 전환되고 모든 입력 필드가 비활성화되어 사용자가 변경할 수 없게 차단됩니다. 성공 토스트는 우측 상단에 녹색 계열로 5초 표시되며 승인 대기가 포함된 경우 별도 토스트로 안내됩니다.
