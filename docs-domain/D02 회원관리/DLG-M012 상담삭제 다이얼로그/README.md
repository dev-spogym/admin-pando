## 2. 다이얼로그 목적

상담 기록 삭제 확인 다이얼로그는 등록된 상담 기록을 삭제하기 전 복구가 불가능함을 안내하고 최종 확인을 받는 모달입니다. 상담 기록은 회원 운영의 결재 근거이자 KPI 측정 자료이므로 잘못된 삭제를 막는 안전장치 역할을 합니다.

## 3. 부모 화면 호출 맥락

회원 상세(SCR-M004) 상담이력 탭의 특정 상담 행 우측에 있는 "삭제" 버튼으로 호출됩니다. 작성자 본인 + 상위 권한자에게만 삭제 버튼이 노출됩니다.

확인 성공 후 부모 화면의 상담이력 목록에서 해당 행이 즉시 제거됩니다.

## 4. 모달 구성요소

모달 상단에는 "상담 기록을 삭제하시겠습니까?"라는 제목과 함께 "삭제된 상담 기록은 복구할 수 없습니다"라는 경고 메시지가 표시됩니다.

삭제 대상 상담의 일시·유형·담당자가 미리보기로 표시됩니다.

[확인] 버튼과 [취소] 버튼이 하단에 있습니다.

## 5. 동작 흐름

[확인] 클릭 시 `DELETE /api/consultations/:id`가 호출됩니다.

성공 시 모달이 닫히고 부모 화면의 상담이력 목록에서 해당 행이 제거되며 토스트가 표시됩니다.

실패 시 에러 메시지가 표시되고 모달은 닫히지 않습니다.

[취소] 또는 ESC 또는 배경 클릭은 모달을 즉시 닫고 상담 기록을 유지합니다.

## 6. 권한별 처리

작성자 본인 + 상위 권한자만 삭제 가능합니다. FC가 작성한 상담은 FC 본인과 매니저 이상이 삭제할 수 있습니다.

권한이 없으면 부모 화면의 삭제 버튼이 hidden 처리됩니다.

## 7. 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 상담 미리보기 + 확인/취소 |
| 처리 중 | 버튼 비활성 + 로딩 |
| 완료 | 모달 닫기 + 행 제거 + 토스트 |

## 8. 데이터 흐름

`DELETE /api/consultations/:id` → Supabase `consultations` hard delete → SCR-097 감사 로그 INSERT.

## 9. 예외 처리

권한 부족(403)은 부모 화면에서 차단되지만 직접 API 호출 시 백엔드 403 + 감사 로그입니다.

이미 삭제된 상담은 404 + 부모 새로고침 안내입니다.

## 10. 운영 정책

작성자 권한 정책은 작성자 본인 + 상위 권한자만 삭제 가능합니다.

hard delete 정책은 상담은 복구 의미가 없는 데이터이므로 즉시 hard delete되며 감사 로그에만 이력이 남는 것입니다.

감사 로그 정책은 삭제 이벤트를 SCR-097에 기록합니다.
