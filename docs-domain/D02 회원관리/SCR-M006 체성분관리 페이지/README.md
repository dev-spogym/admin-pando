## 2. 화면 개요와 목적

체성분 관리 페이지는 특정 회원의 체성분(체중·골격근량·체지방률·BMI·기초대사량·체지방량·체수분) 변화 추이를 시계열 그래프와 측정 기록 표로 시각화하는 화면입니다. 트레이너와 FC가 회원의 운동·영양 개선 효과를 판정하고 재상담 또는 재계약의 근거 자료로 활용하는 핵심 도구입니다. InBody 외부 장비와 자동 연동되어 회원 카드 태그 측정값이 자동으로 등록되고, 운영자 수동 입력과 회원 본인 모바일 앱 자가 입력도 동일 데이터 소스에 함께 저장됩니다.

이 화면은 회원 상세(SCR-M004)의 체성분 탭과 동일 데이터 소스(`body_composition`)를 공유합니다. 따라서 본 화면에서 측정값을 추가·수정·삭제하면 회원 상세 체성분 탭에 즉시 반영되고, 회원 상세에서 변경한 내용도 본 화면에 즉시 반영됩니다. 한쪽에서만 보이는 데이터는 없으며 두 화면은 단일 진실 원천을 유지합니다.

운영 현장의 가장 흔한 시나리오는 트레이너가 PT 세션 직전에 회원의 최신 측정값과 변화 방향(체중·체지방률은 감소가 긍정·초록, 골격근량은 증가가 긍정·초록)을 확인하고 운동 강도를 즉시 조정하는 것입니다. FC가 재계약 상담을 진행할 때는 추이 그래프로 회원의 개선 효과를 시각적 근거로 제시해 재계약을 유도합니다. 회원 본인이 모바일 앱에서 가정용 체중계 기록을 자가 입력하면 운영자 화면에 `source=self` 라벨이 붙어 표시됩니다. InBody 장비 자동 수집된 측정값에는 `source=device` 라벨이 붙고, 운영자 수동 입력은 `source=manual`로 구분됩니다.

목표 설정(DLG-M017)으로 시작 체성분·목표 체성분·기간을 입력하면 그래프에 목표선이 overlay되어 진행률이 시각화됩니다. 회원당 활성 목표는 1개로 제한되며 새 목표 등록 시 기존 목표는 자동 종료(`status=replaced`) 처리됩니다.

## 3. 진입 경로와 인접 화면

체성분 관리 페이지에 들어오는 일반적인 경로는 두 가지입니다. 첫째, 사이드바 "회원관리 > 체성분 관리" 항목을 클릭하는 것이며 회원이 선택되지 않은 빈 상태로 진입합니다. 진입 후 상단 드롭다운에서 조회할 회원을 검색·선택해야 본문이 채워집니다. 둘째, 회원 상세(SCR-M004)의 체성분 탭에서 본 화면으로 진입하는 것이며 이 경우 URL 쿼리 파라미터 `memberId`가 자동으로 채워져 해당 회원이 미리 선택된 상태로 진입합니다.

이 화면에서 빠져나가는 인접 화면으로는 회원 요약 카드 클릭 시 SCR-M004 회원 상세로 이동, 본사 통합 모드에서 본사 권한자가 진입하는 SCR-I006 통합 체성분 화면(지점별 평균·개선률 비교), 종합평가 등록(DLG-M024) 시 직전 분기 체성분 추이가 자동 첨부되어 평가 근거로 사용되는 흐름이 있습니다.

## 4. 레이아웃과 UI 구성

체성분 관리 페이지는 위에서 아래로 차곡차곡 쌓이는 단일 컬럼 레이아웃입니다. 가장 위에는 페이지 헤더("체성분 관리"라는 타이틀과 함께 회원 선택 드롭다운)가 있고, 그 아래에 회원 요약 카드, 탭(측정 기록 / 추이 분석), 현재값 요약 카드 4개, 추이 그래프, 측정 기록 테이블이 차례로 배치됩니다.

헤더의 회원 선택 드롭다운은 회원 이름이나 연락처로 검색해 선택할 수 있습니다. 회원 상세에서 진입한 경우에는 해당 회원이 자동 선택된 상태로 표시되어 검색이 필요 없습니다. 슈퍼관리자·본사 최고관리자에게는 전체 브랜드 회원이, Owner(지점장)·매니저·FC에게는 소속 지점 회원이, 트레이너에게는 담당 회원만 검색 결과로 노출됩니다.

회원 요약 카드는 선택된 회원의 이름·현재 이용권·상태를 한 줄로 표시하며 클릭하면 회원 상세로 이동합니다. 카드 우측에 "측정 추가" 버튼과 "목표 설정" 버튼이 권한별로 노출됩니다.

탭 영역은 "측정 기록"과 "추이 분석" 두 가지 보기 전환을 제공합니다. 측정 기록 탭은 기본이며 현재값 요약 카드와 추이 그래프와 측정 기록 테이블이 함께 표시됩니다. 추이 분석 탭은 측정 기록 외 추가 분석 뷰(예: 월별 평균 변화량, 목표 달성률 분석)를 제공하는 선택적 화면입니다.

현재값 요약 카드 4개는 가로로 배치되며 첫 번째는 현재 체중, 두 번째는 골격근량, 세 번째는 체지방률, 네 번째는 BMI를 최신 측정값으로 표시합니다. 각 카드 아래에는 이전 측정값 대비 변화량이 증감 방향과 색상으로 표시됩니다. 체중·체지방률은 감소가 긍정(초록)이고 증가는 부정(빨강)이며, 골격근량은 증가가 긍정(초록)이고 감소는 부정(빨강)입니다. 측정 기록이 1건뿐이면 변화량은 표시되지 않습니다.

추이 그래프는 측정일을 x축, 수치를 y축으로 하는 꺾은선 그래프입니다. 체중(산호색)·골격근량(민트색)·체지방률(앰버색) 세 가지 지표를 각각 토글로 on/off 할 수 있으며 최소 1개는 항상 켜져 있어야 합니다. 그래프는 측정 기록이 2건 이상일 때만 표시되며 1건 이하면 "2건부터 추이 그래프가 표시됩니다" 안내가 그래프 자리에 표시됩니다. 활성 목표가 있는 경우 그래프에 시작점과 목표점을 잇는 직선 overlay와 진행률이 표시됩니다. 마우스 호버 시 해당 측정일의 모든 지표 수치가 툴팁으로 표시됩니다.

측정 기록 테이블은 그래프 아래에 배치됩니다. 컬럼은 좌측부터 측정일·체중·골격근량·체지방률·BMI·기초대사량·체수분·source(라벨: manual/device/self)·수정·삭제 순이며 최신 측정일 기준 내림차순으로 정렬됩니다. 각 행에 수정 버튼과 삭제 버튼이 권한과 시간 제한에 따라 활성/비활성으로 표시됩니다.

## 5. 측정 추가와 수정 흐름

측정 추가는 "측정 추가" 버튼을 누르면 DLG-M015 체성분 등록 다이얼로그가 열립니다. 측정일(기본값 오늘, 미래 차단)·체중(20~300kg)·골격근량(5~80kg)·체지방률(3~60%)·체수분(선택)을 입력하면 BMI·체지방량·기초대사량이 자동 계산됩니다. BMI는 체중과 회원 키 기반으로 계산되고, 기초대사량은 Mifflin-St Jeor 공식(체중·키·나이·성별)으로 계산됩니다. 체지방량은 체중 × (체지방률 / 100)입니다. 회원의 키가 미등록이면 BMI 계산이 불가능해 "키 정보 필요" 표시가 나오고 회원 등록·수정 화면(MBR-03) 진입 안내가 제공되지만 측정 자체는 가능합니다.

저장 버튼을 누르면 동일 일자에 이미 측정값이 있는지 확인합니다. 있으면 DLG-M016 덮어쓰기 다이얼로그가 호출되어 덮어쓰기/취소/시간 다르게 3선택지가 제공됩니다. 덮어쓰기 시 기존 레코드는 삭제 처리(이력 보존 안 함)되고 새 값이 INSERT됩니다.

수정은 측정 기록 테이블의 수정 버튼으로 호출되며 DLG-M015와 같은 폼이 기존 값으로 채워진 상태로 열립니다. FC·트레이너는 본인이 등록한 측정값에 한해 24시간 이내만 수정 가능하고, 매니저 이상은 시간 제한 없이 수정 가능합니다. 본인 등록 24시간이 초과되면 "본인 등록 24시간 이내만 수정 가능" 안내와 함께 수정 버튼이 readonly로 표시되며 매니저 이상에게 요청 안내가 제공됩니다.

삭제는 매니저 이상만 가능합니다. 측정 기록은 hard delete이며 삭제 이력은 SCR-097 감사 로그에 기록됩니다. FC·트레이너 화면에서는 삭제 버튼이 hidden 처리됩니다.

목표 설정은 회원 요약 카드 우측의 "목표 설정" 버튼으로 DLG-M017이 호출됩니다. 시작 체성분·목표 체성분·기간을 입력하고 저장하면 그래프에 목표선이 overlay됩니다. 회원당 활성 목표는 1개로 제한되며 새 목표 등록 시 기존 목표는 자동 종료됩니다.

CSV 내보내기는 매니저 이상만 가능하며 회원 요약 카드 우측 또는 페이지 헤더 메뉴에 "CSV 내보내기" 버튼이 표시됩니다. 1만 건 초과 시 "데이터가 너무 많아요. 기간을 좁혀주세요" 안내가 표시됩니다. CSV에는 source 컬럼이 포함되고 비식별 옵션(이름→이니셜)이 제공됩니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

헤더 회원 선택 드롭다운은 키보드 입력으로 이름·연락처 검색이 가능하며, 화살표 키로 결과 이동, Enter 키로 선택할 수 있습니다.

회원 요약 카드 본문 클릭은 SCR-M004 회원 상세로 이동합니다. 카드 우측의 "측정 추가" 버튼은 DLG-M015 호출, "목표 설정" 버튼은 DLG-M017 호출입니다. "CSV 내보내기"는 매니저 이상에게만 보이며 클릭 시 백그라운드 작업으로 CSV 생성이 시작되고 완료 시 알림 센터에 다운로드 링크가 푸시됩니다.

탭 영역의 "측정 기록"과 "추이 분석" 탭은 클릭으로 본문 전환됩니다. 측정 기록 탭이 기본 활성 상태입니다.

추이 그래프의 지표 토글(체중·골격근량·체지방률) 버튼은 각각 클릭으로 그래프에서 해당 지표 라인을 켜거나 끕니다. 모두 끄면 "지표를 1개 이상 선택해주세요" 안내가 그래프 자리에 표시됩니다.

측정 기록 테이블 각 행의 수정 버튼은 권한과 시간 조건을 만족하는 경우에만 활성화되며 클릭 시 DLG-M015가 기존 값으로 채워진 상태로 열립니다. 삭제 버튼은 매니저 이상에게만 보이며 클릭 시 삭제 확인 모달이 표시되고 확인 시 hard delete가 실행됩니다.

## 7. 호출되는 모달 동작

### 7-1. DLG-M015 체성분 등록 다이얼로그

체성분 등록 다이얼로그는 측정 추가 버튼이나 측정 기록 수정 버튼으로 호출됩니다. 모달 본문에는 측정일 캘린더(기본값 오늘, 미래 차단), 체중 입력(20~300kg), 골격근량 입력(5~80kg), 체지방률 입력(3~60%), 체수분 입력(선택)이 있습니다. 입력값에 따라 BMI·체지방량·기초대사량이 실시간 자동 계산되어 미리보기로 표시됩니다. 회원의 키가 미등록이면 BMI 계산이 불가능해 "키 정보 필요" 표시가 나오고, 성별·나이가 미등록이면 기초대사량 계산이 불가능합니다.

[저장] 버튼을 누르면 동일 일자 충돌 검증이 수행되며 충돌 시 DLG-M016이 자동 호출됩니다. 충돌이 없으면 INSERT가 완료되고 모달이 닫히면서 부모 화면의 차트·테이블·요약 카드가 즉시 갱신됩니다. [취소]는 변경 없이 모달을 닫습니다.

수정 모드에서는 기존 값이 미리 채워진 상태로 열리며 변경된 필드만 PATCH로 전송됩니다. FC·트레이너의 24시간 초과 수정 시도는 부모 화면에서 이미 차단되므로 모달이 열리지 않습니다.

### 7-2. DLG-M016 체성분 덮어쓰기 다이얼로그

체성분 덮어쓰기 다이얼로그는 DLG-M015 저장 시 동일 일자에 이미 측정값이 있는 경우 자동 호출됩니다. 모달 본문에는 기존 측정값 요약(체중·체지방률 등)이 표시되고, 덮어쓰기 / 취소 / 시간 다르게 3선택지가 제공됩니다.

덮어쓰기를 선택하면 기존 레코드가 삭제되고 새 값이 INSERT됩니다(이력 보존 안 함). 취소를 선택하면 모달이 닫히고 DLG-M015로 복귀해 입력값이 유지됩니다. 시간 다르게를 선택하면 같은 일자에 다른 시각으로 추가 레코드가 INSERT됩니다.

### 7-3. DLG-M017 목표 설정 다이얼로그

목표 설정 다이얼로그는 회원 요약 카드의 목표 설정 버튼으로 호출됩니다. 모달 본문에는 목표 체중·목표 체지방률·목표 골격근량 입력란과 목표 달성 기간(날짜 또는 개월 수), 메모 입력란이 있습니다. 회원에 활성 목표가 이미 있으면 기존 값이 미리 채워진 상태로 열립니다.

[저장] 버튼을 누르면 활성 목표가 INSERT 또는 UPDATE되며 기존 활성 목표가 있었다면 자동으로 `status=replaced`로 종료됩니다. 시작값보다 미래 목표값이 잘못된 방향(예: 체중 감소 목표인데 시작값보다 큰 목표값)이면 "목표값이 시작값과 같거나 동일 방향이어야 합니다" 인라인 에러가 표시되고 저장이 차단됩니다.

저장 성공 시 모달이 닫히고 부모 화면의 차트에 목표선 overlay가 즉시 표시됩니다. 회원에게 알림 push가 발송됩니다.

## 8. 토스트와 확인 팝업과 알럿

성공 토스트는 우측 상단에 녹색 톤으로 표시됩니다. "측정값이 저장되었어요", "목표가 설정되었어요", "CSV 다운로드가 시작되었어요" 같은 짧은 문구로 결과를 알려줍니다.

실패 토스트는 빨강 톤으로 표시되며 "측정값이 범위를 벗어났어요", "권한이 없어요", "본인 등록 24시간 이내만 수정 가능합니다", "다른 운영자가 동시에 측정값을 추가했어요" 같은 문구가 표시됩니다.

화면 진입 시 회원이 선택되지 않은 상태에서는 본문 영역에 "회원을 선택해주세요" 안내와 함께 드롭다운 강조 효과가 표시됩니다. 회원이 선택된 후 측정 기록이 0건이면 "측정 기록이 없어요" 빈 상태 + "첫 측정 등록하기" CTA 버튼이 표시됩니다.

InBody 장비 매칭 실패는 알림 센터로 별도 통보되며 "회원 카드를 인식하지 못했어요" 안내가 운영자에게 전달되고 수동 매칭 큐에 적재됩니다.

CSV 내보내기 1만 건 초과 시 "데이터가 너무 많아요. 기간을 좁혀주세요" 안내가 표시됩니다.

권한이 없는 계정(스태프·프런트·readonly)이 직접 URL로 진입하면 본문이 가려지고 "이 화면에 접근할 권한이 없습니다" 알럿 후 대시보드로 자동 이동됩니다.

## 9. 데이터 흐름과 외부 연동

화면 진입 시 회원이 선택되면 `GET /api/body-composition/:memberId`가 호출되어 회원의 모든 측정 기록과 활성 목표가 한 번에 로드됩니다. 응답에는 측정값 배열, 활성 목표, 회원의 키·나이·성별(자동 계산용), source별 카운트가 포함됩니다.

측정 추가는 `POST /api/body-composition`을 호출합니다. 요청 본문에는 회원 ID, 측정일, 체중·골격근량·체지방률·체수분, source(manual)가 포함됩니다. 동일 일자 충돌 시 백엔드가 409로 응답하고 클라이언트가 DLG-M016을 호출합니다.

측정 수정은 `PUT /api/body-composition/:id`를, 삭제는 `DELETE /api/body-composition/:id`를 호출합니다. 목표 설정은 `POST /api/body-composition/goal`을 호출합니다.

InBody 외부 장비 연동은 백엔드 `POST /api/inbody/sync` 엔드포인트로 들어오며, 외부 장비 API가 회원 카드 매칭 후 자동 INSERT를 수행합니다. 매칭 실패 시 수동 매칭 큐에 적재됩니다. 측정값에는 `source=device` 라벨이 자동 부여됩니다.

회원 본인 모바일 앱 자가 입력은 모바일 백엔드를 통해 `POST /api/body-composition`을 호출하며 `source=self` 라벨이 부여됩니다. 운영자 화면과 모바일 앱은 같은 데이터 소스를 공유합니다.

SCR-M004 회원 상세의 체성분 탭은 본 화면과 동일 데이터 소스 공유 정책에 따라 측정 INSERT/UPDATE/DELETE 시 즉시 동기화됩니다.

모든 측정 추가·수정·삭제·목표 설정은 SCR-097 감사 로그에 INSERT됩니다. actor·source·before/after가 기록됩니다.

회원 동의 시 측정 완료 후 카카오 알림톡으로 결과 카드가 발송됩니다(모바일 앱에서 동의 토글). 목표 달성/미달성 시 회원과 트레이너에게 양방향 알림이 발송됩니다. 종합평가(DLG-M024) 입력 시 직전 분기 체성분 추이가 자동 첨부됩니다.

본사 통합 모드에서는 본사 권한자가 SCR-I006 통합 체성분 화면으로 전 지점 회원의 체성분 통계를 비교할 수 있고, 매주 월요일 새벽 4시에 지점별 평균·개선률 집계 배치가 실행됩니다.

CSV 내보내기는 백그라운드 작업으로 처리되며 완료 시 알림 센터에 다운로드 링크가 푸시됩니다. CSV에는 source 컬럼이 포함되고 비식별 옵션 선택 시 이름이 이니셜로 마스킹됩니다.

화면에서 호출하는 주요 API: 회원 체성분 조회 `GET /api/body-composition/:memberId`, 측정 추가 `POST /api/body-composition`, 측정 수정 `PUT /api/body-composition/:id`, 측정 삭제 `DELETE /api/body-composition/:id`, 목표 설정 `POST /api/body-composition/goal`, InBody 동기화 `POST /api/inbody/sync`, CSV 내보내기 `GET /api/body-composition/export.csv`.

## 10. 화면 상태와 예외 처리

화면 상태는 다음과 같이 정의됩니다.

회원 미선택 상태는 사이드바 진입 직후 회원이 선택되지 않은 상태로 본문에 "회원을 선택해주세요" 안내가 표시됩니다. 회원 선택 + 측정 기록 0건 상태는 "측정 기록이 없어요" + "첫 측정 등록하기" CTA 버튼이 표시됩니다. 회원 선택 + 측정 기록 1건 상태는 그래프 hidden + "2건부터 추이가 표시됩니다" 안내 + 테이블만 노출입니다. 정상(측정 이력 2건 이상) 상태는 모든 카드 + 차트 + 테이블이 표시됩니다.

측정 추가 중 상태는 DLG-M015가 열린 상태이며 동일 일자 충돌 시 DLG-M016이 추가로 열립니다. 측정 범위 초과 상태는 입력값이 허용 범위를 벗어난 경우로 인라인 에러가 표시되고 저장이 차단됩니다.

모든 지표 토글 OFF 상태는 그래프 영역에 "지표를 1개 이상 선택해주세요" 표시가 나옵니다. 오류 상태는 데이터 조회 실패 시 오류 메시지 + 다시 시도 버튼이 표시됩니다.

예외 케이스별 처리는 다음과 같습니다. 회원 키 미등록 시 BMI 영역에 "키 정보 필요" 표시 + MBR-03 진입 링크가 제공되며 측정 자체는 가능합니다. 성별·나이 미등록 시 기초대사량 영역에 "성별/나이 정보 필요" 표시가 나옵니다. 측정값 범위 초과(체중 < 20 또는 > 300 등)는 인라인 빨강 + "체중은 20~300kg" 같은 안내가 표시되고 저장이 차단됩니다.

측정일 미래 날짜는 캘린더에서 비활성 처리되고 직접 입력 시 422로 거부됩니다. 동일 일자 충돌은 DLG-M016이 호출됩니다.

FC·트레이너의 24시간 초과 수정 시도는 "본인 등록 24시간 이내만 수정 가능" 안내가 표시되고 매니저 이상에게 요청 안내가 제공됩니다. FC·트레이너의 삭제·CSV 시도는 버튼 자체가 hidden 처리됩니다.

InBody 외부 장비 매칭 실패는 알림 센터에 "회원 카드를 인식하지 못했어요" 통보 + 수동 매칭 큐 적재로 처리됩니다. 외부 API 응답 지연(5초 timeout)은 운영자에게 알림이 발송되며 수동 입력 안내가 제공됩니다.

동시 측정 추가 충돌(409)은 덮어쓰기 안내 모달이 표시되며 새로고침 후 재시도하도록 안내됩니다. 목표 설정 시 시작값과 동일 방향이 아닌 목표값은 인라인 에러로 차단됩니다.

CSV 내보내기 1만 건 초과는 기간 필터 안내가 표시되며 작업이 시작되지 않습니다. 네트워크 끊김은 자동 재시도 1회와 localStorage 임시 저장으로 처리됩니다.

## 11. 권한별 처리

이 화면은 권한에 따라 진입 가능 여부와 가능한 액션이 모두 달라집니다.

슈퍼관리자(superAdmin)와 본사 최고관리자(primary)는 전체 브랜드 회원의 체성분을 조회·관리할 수 있습니다. 측정 추가·수정·삭제·목표 설정·CSV 내보내기·SCR-I006 통합 체성분 진입까지 모두 가능합니다.

Owner(지점장)·매니저(manager)는 소속 지점 회원의 체성분을 조회·관리할 수 있습니다. 측정 추가·수정·삭제·목표 설정·CSV 내보내기가 가능하며 시간 제한이 없습니다.

FC(fc, 피트니스 코치)는 소속 지점 회원을 조회할 수 있고 담당 회원이 기본 선택됩니다. 측정 추가가 가능하지만 수정은 본인이 등록한 측정값에 한해 24시간 이내만 가능합니다. 삭제와 CSV 내보내기는 불가능하며 해당 버튼이 hidden 처리됩니다.

트레이너(trainer)는 담당 회원만 조회·관리할 수 있습니다. 측정 추가가 가능하지만 수정은 본인 등록 24시간 이내만 가능하며 삭제·CSV는 불가능합니다.

스태프(staff)·프런트(front)·readonly는 이 화면에 진입할 수 없습니다. 직접 URL로 진입하면 접근 제한 알럿 후 대시보드로 자동 이동됩니다.

권한별 차단은 단계적으로 일관 적용됩니다. 사이드바·페이지 본문·백엔드 응답까지 4단계로 차단되며 모든 권한 차단 이벤트는 감사 로그에 기록됩니다.

## 14. 핵심 디자인 요청사항

체성분 관리 화면이 운영자에게 잘 작동하려면 다음 디자인 원칙이 시각적으로 명확해야 합니다.

현재값 요약 카드 4개는 동일 크기 동일 그리드로 배치되며 카드 안의 숫자는 가장 큰 폰트로, 라벨은 그 아래 작은 글씨로 배치합니다. 변화 방향 표시는 화살표 아이콘과 색상을 함께 사용해 색맹 운영자도 즉시 인식할 수 있어야 합니다. 체중·체지방률 감소와 골격근량 증가는 초록 + 위/아래 화살표, 반대 방향은 빨강 + 화살표로 구분합니다.

추이 그래프의 지표별 색상은 일관되어야 합니다. 체중은 산호색, 골격근량은 민트색, 체지방률은 앰버색으로 구분되며 토글 버튼도 각 라인 색상과 같은 톤으로 시각적 연관성을 보여줍니다. 활성 목표 overlay는 점선 또는 다른 톤의 라인으로 측정값 라인과 구분되어야 합니다.

측정 기록 테이블의 source 라벨(manual/device/self)은 작은 아이콘 또는 색상 배지로 표현되어 한눈에 출처를 식별할 수 있어야 합니다. manual은 회색, device는 파랑, self는 보라 같은 일관된 톤이 권장됩니다.

수정·삭제 버튼은 권한과 시간 조건에 따라 활성/비활성이 명확히 구분되어야 합니다. 비활성 시 회색 톤과 자물쇠 아이콘으로 차단 이유를 시각적으로 알리고 호버 시 툴팁으로 사유를 표시합니다.

빈 상태(측정 기록 0건)는 단순한 텍스트가 아니라 일러스트와 함께 "첫 측정 등록하기" CTA 버튼을 강조해 운영자가 즉시 첫 측정을 등록하도록 유도합니다.

모바일에서는 그래프가 가로 폭에 맞게 축소되고 테이블은 카드형 리스트로 전환됩니다. 카드 안에 측정일·체중·체지방률·골격근량이 위에, BMI·BMR·체수분이 아래에 표시됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

체성분 데이터는 회원의 건강 정보로 민감 PII에 해당합니다. 따라서 이 화면을 지탱하는 정책이 엄격합니다.

측정값 범위 정책(체중 20~300kg, 골격근량 5~80kg, 체지방률 3~60%)은 입력 오류와 비정상 데이터 차단을 위한 것입니다. 범위 외 입력은 422로 거부되어 잘못된 측정값이 차트와 통계를 왜곡하는 사고를 막습니다.

데이터 출처(source) 구분 정책은 운영자 수동 입력(manual) / InBody 장비 자동 수집(device) / 회원 자가 입력(self)을 별도로 표시해 데이터 신뢰도를 운영자가 판단할 수 있게 합니다. 자가 입력 분은 회원의 가정용 체중계 기록일 수 있어 정확도가 떨어질 수 있으므로 트레이너가 PT 강도를 조정할 때 device 출처를 우선 참고하도록 합니다.

변화 방향 색상 정책(체중·체지방률 감소가 긍정·초록, 골격근량 증가가 긍정·초록)은 회원 건강의 일반적 개선 방향에 따른 것입니다. 회원이 운동·영양 관리로 체중을 줄이거나 근육을 늘리는 일반적 목표에 부합합니다.

수정 권한과 시간 제한 정책(FC/트레이너는 본인 등록 24시간 이내만 수정 가능, 매니저 이상은 시간 제한 없음)은 측정 결과의 변경 가능성을 통제하기 위한 것입니다. 24시간이 지나면 트레이너가 사후에 측정값을 임의 수정하는 사고가 차단되어 데이터 신뢰성이 보장됩니다.

삭제 권한 정책(매니저 이상만 삭제 가능, 소프트 삭제 아닌 hard delete)은 체성분 데이터의 복구 의미가 없다는 판단에 따른 것입니다. 단 삭제 이력은 SCR-097 감사 로그에 기록되어 사후 추적이 가능합니다.

CSV 내보내기 권한 정책(매니저 이상만 가능, 비식별 옵션 제공)은 회원 건강정보가 외부로 누출되는 사고를 막기 위한 것입니다. FC·트레이너는 화면에서 조회만 가능하고 데이터를 외부로 가져갈 수 없습니다.

목표 설정 정책(회원당 활성 목표 1개, 새 목표 등록 시 기존 자동 종료)은 운영 명확성을 위한 것입니다. 여러 목표가 동시에 활성이면 진행률 표시가 혼란스러워지므로 단일 목표만 유지합니다.

체성분 탭 동기화 정책(SCR-M004 회원 상세의 체성분 탭과 동일 데이터 소스 공유)은 단일 진실 원천을 유지하기 위한 것입니다. 두 화면에서 보이는 데이터가 항상 같아야 운영자가 어디서 확인해도 일관된 정보를 받습니다.

InBody 자동 연동 정책은 외부 장비 API → 회원 카드 매칭 → 자동 INSERT이며 매칭 실패 시 수동 매칭 큐에 적재됩니다. 회원이 카드를 잘못 태그하거나 시스템에 미등록 카드를 사용한 경우 운영자가 수동으로 매칭해야 합니다.

종합평가(DLG-M024) 연계 정책은 분기 종합평가 입력 시 직전 분기 체성분 추이가 자동 첨부되는 것입니다. 트레이너가 종합평가를 작성할 때 회원의 체성분 변화를 평가 근거로 활용하도록 유도합니다.

본사 통합 모드(SCR-I006) 정책은 본사 권한자만 전 지점 통계를 비교할 수 있고 개별 측정 데이터는 RLS로 제어됩니다. 일반 지점 사용자는 자기 지점 회원만 볼 수 있습니다.

개인정보 보호 정책은 체성분 데이터를 민감 건강정보로 분류하며 CSV 내보내기 시 비식별 옵션(이름→이니셜)을 제공합니다. 내부 분석용 데이터 추출과 외부 공유용 데이터 추출을 구분합니다.

이상의 모든 정책은 이 화면을 구현하고 운영하는 사람이 별도 문서 없이 이 한 장으로 이해할 수 있도록 풀어 적었습니다. 정책이 바뀌면 이 문서가 함께 갱신되어야 하며, 코드 변경과 정책 변경은 항상 짝지어 진행됩니다.
