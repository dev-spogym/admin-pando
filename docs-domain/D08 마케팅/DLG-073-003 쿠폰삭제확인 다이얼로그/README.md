## 2. 다이얼로그 목적과 사용 맥락

쿠폰 삭제 확인 다이얼로그는 쿠폰을 삭제하기 전 최종 확인을 받는 모달입니다. 이미 발급된 쿠폰이 있는 경우 삭제 영향 범위를 미리 안내하며, 사용 이력이 있는 쿠폰은 hard delete가 차단되고 "중단(suspended)"으로 soft delete만 허용됩니다.

호출 트리거는 SCR-073의 행 [삭제] 버튼. FC 권한 계정에서는 버튼 hidden.

## 3. 다이얼로그 구성

모달 상단에는 "쿠폰 삭제" 제목 + 경고 아이콘.

안내 메시지: "이 쿠폰을 삭제하시겠습니까? 삭제된 쿠폰은 복구할 수 없습니다."

대상 쿠폰 요약 카드: 쿠폰명, 할인 내용, 유효 기간, 현재 상태가 표시되어 운영자가 삭제 대상을 정확히 확인할 수 있게 합니다.

발급 현황 경고 영역: 이미 발급된 쿠폰이 있을 경우 노랑 톤 박스로 "{인원수}명에게 발급된 쿠폰이 있습니다" + "삭제 시 미사용 쿠폰도 함께 무효화됩니다" 경고 표시.

사용 이력 경고: 사용 이력이 있는 쿠폰의 경우 빨강 톤 박스 + "사용 이력이 있어 hard delete가 차단됩니다. 대신 '중단(suspended)' 상태로 전환됩니다" 안내. 이 경우 모달의 액션 버튼이 "삭제" 대신 "중단으로 전환"으로 자동 변경됩니다.

모달 하단에는 위험 액션 버튼("삭제" 빨강 또는 "중단으로 전환" 주황)과 "취소" 버튼.

## 4. 액션과 부모 화면 변화

삭제 버튼 클릭 시 `DELETE /api/coupons/:id` API 호출. 사용 이력 없으면 hard delete 진행, 사용 이력 있으면 `status=suspended`로 soft delete.

성공 시 모달 닫힘 + 부모 화면에서 해당 쿠폰 행 제거(hard delete) 또는 상태 회색 톤 전환(suspended) + "쿠폰을 삭제했어요" 또는 "쿠폰을 중단으로 전환했어요" 토스트.

발급 수량 통계는 즉시 갱신되며, 이미 발급된 쿠폰의 미사용 분은 모두 무효화됩니다(회원의 쿠폰 보유 목록에서 제거).

중단으로 전환된 쿠폰은 신규 발급 차단되지만 기존 발급분은 정책에 따라 사용 가능(테넌트 설정).

취소·ESC·배경 클릭은 즉시 모달 닫힘 + 변경 없음.

## 5. 권한별 동작

슈퍼관리자·Owner(지점장): hard delete 및 중단 전환 가능.

매니저: 정책에 따라 가능(테넌트 설정). 기본은 가능.

FC: [삭제] 버튼 hidden. 다이얼로그 호출 차단.

트레이너·스태프·readonly: 부모 화면 접근 차단.

본사 쿠폰(`hq_owned=true`) 삭제는 슈퍼관리자만 가능. 지점 운영자에게는 [삭제] hidden.

## 6. 데이터 흐름

`DELETE /api/coupons/:id` 호출. 백엔드에서 사용 이력 자동 확인 후 hard/soft 분기.

사용 이력 있는 쿠폰의 soft delete는 `status=suspended` + `suspended_at` 컬럼 업데이트.

이미 발급된 회원의 미사용 쿠폰은 함께 무효화됩니다(`coupon_issue_log`의 invalidated 플래그 또는 status 변경).

감사 로그(SCR-097) INSERT: actor_id, coupon_id, action(delete 또는 suspend), reason(선택), timestamp.

캠페인(MKT-06)에 연결된 쿠폰의 삭제는 캠페인 운영에 영향을 주므로 추가 경고 표시 또는 차단(정책).

## 7. 예외 처리

권한 부족 → 부모 화면에서 [삭제] 버튼 hidden + 직접 API 호출 시 403.

사용 이력 있는 쿠폰 → hard delete 차단 + "중단으로 전환" 자동 안내.

캠페인 연결 쿠폰 → 추가 경고 "이 쿠폰은 캠페인 [N]에 연결되어 있습니다" + 진행 차단 또는 강제 진행(정책).

이미 만료된 쿠폰 → 만료 상태에서 삭제는 정상. 발급 현황 경고만 표시.

이미 중단된 쿠폰 → 중단 상태에서 추가 삭제 시도 시 hard delete 가능(사용 이력 있어도 강제 hard delete는 슈퍼관리자만 정책).

네트워크 오류 → 자동 재시도 1회 + 사용자 대기.

동시 처리 충돌 → 후행 처리 거절 + "이미 처리되었습니다" 안내.

## 8. 토스트와 확인 팝업

성공: "쿠폰을 삭제했어요" / "쿠폰을 중단으로 전환했어요" 녹색 5초.

실패: "권한이 없어요" / "캠페인에 연결되어 있어요" 빨강 톤.

추가 확인 없이 모달 자체가 최종 확인 단계.

## 10. 디자인 요청사항

모달 작은 사이즈 중앙. 배경 반투명.

경고 영역은 색상 톤으로 단계 구분: 노랑(발급 있음·사용 없음) / 빨강(사용 이력 있음 강제 중단).

액션 버튼은 상황에 따라 동적으로 변경: "삭제"(hard delete 가능) / "중단으로 전환"(사용 이력 있음).

대상 쿠폰 요약 카드는 모달 내부 강조 톤.

모바일 풀스크린.

## 11. 운영 정책

삭제 정책: 사용 이력 없으면 hard delete. 사용 이력 있으면 "중단(suspended)"으로 soft delete만 허용.

미사용 발급분 처리: hard delete 또는 중단 전환 시 이미 발급된 미사용 쿠폰도 함께 무효화. 회원의 쿠폰 보유 목록에서 제거.

중단된 쿠폰: 신규 발급 차단. 기존 발급분은 정책에 따라 사용 가능 또는 차단.

캠페인 연결 쿠폰: 추가 경고 또는 차단(정책).

권한: 슈퍼관리자/Owner(지점장) hard delete 가능. 매니저 정책에 따라. FC/트레이너/스태프/readonly 차단.

본사 쿠폰: 슈퍼관리자만 삭제 가능.

만료 후 보존: 만료 쿠폰은 90일 이상 보존(사용 이력 추적용). 90일 후 자동 아카이브(이 다이얼로그와 무관).

감사 로그: 삭제·중단 모두 SCR-097 기록.
