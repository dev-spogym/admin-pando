## 2. 화면 개요와 목적

캠페인 관리 페이지는 특정 목표(신규 회원 유치 / 재등록 유도 / 브랜드 인지도 향상 / VIP 보상 등)를 위한 마케팅 캠페인을 통합 생성·실행·실적 추적하는 화면입니다. 대상 회원 세그먼트(MBR-EXT-04 연계)를 지정하고 메시지(MKT-01) / 쿠폰(MKT-03) / 이벤트(MKT-07 리퍼럴) / AB 테스트(MKT-09)를 캠페인 단위로 묶어 도달 / 클릭 / 전환 / 매출 / ROI 지표를 자동 집계합니다.

캠페인 시나리오: 신규 유치(SNS 광고 + 환영 쿠폰 + 등록 감사 알림 패키지), 재등록 유도(만료 회원 세그먼트 + 10% 할인 쿠폰 + 만료 D-7 알림톡), VIP 보상(VIP 세그먼트 + 마일리지 보너스 + 감사 메시지), 브랜드 인지도(일반 회원 + SNS 콘텐츠 공유 이벤트), 계절 이벤트(신년·여름·연말 한정).

시작일 자동 활성 / 종료일 자동 종료 / ROI 자동 계산 / UTM 추적 / AB 테스트 연동까지 자동화되어 매니저가 캠페인 등록만 하면 나머지는 시스템이 처리합니다.

## 3. 진입 경로와 인접 화면

진입 경로: 사이드바 "마케팅 > 캠페인 관리", 대시보드의 마케팅 KPI 카드 클릭, 알림 센터의 캠페인 자동 활성/종료 알림.

인접 화면: 메시지 발송(SCR-071), 쿠폰 관리(SCR-073), 리퍼럴(SCR-077), AB 테스트(SCR-079), 회원 세그먼트(SCR-M005), 감사 로그(SCR-097).

## 4. 레이아웃과 UI 구성

페이지 헤더 좌측 "캠페인 관리" 타이틀, 우측 "+ 캠페인 생성"(DLG-076-001) 버튼.

상태 필터 탭: 전체 / 준비 / 진행 / 종료. URL 쿼리 파라미터 `status`로 반영.

검색·필터 바: 캠페인명 검색(디바운스 300ms), 목표 필터(신규 유치/재등록/인지도/VIP/기타), 기간 필터.

캠페인 목록 테이블: 캠페인명, 목표 배지, 대상 세그먼트(이름 또는 다중 조건 요약), 기간(시작~종료), 상태 배지(준비 파랑/진행 녹색/종료 회색), 실적 요약(도달/전환/ROI 한 줄), 행 액션([수정]/[삭제]/[실적]).

캠페인명 클릭 시 우측 실적 추적 패널 슬라이드 인. 패널 내부: 도달 수 / 클릭 수 / 전환 수 / 매출 / ROI / UTM별 분리 집계 / 시간대별 추이 그래프 / 연결된 메시지·쿠폰·이벤트 목록.

본사 통합 캠페인은 행 좌상단에 "본사" 배지 표시. 진행 중 캠페인은 ROI 컬럼이 실시간 갱신됨.

## 5. 캠페인 상태와 자동화

상태 3종: 준비(시작일 도래 전), 진행(시작일~종료일 사이), 종료(종료일 경과).

시작일 자동 활성: 매일 04:00 배치 + 시작일 00:00 트리거로 준비 → 진행 전환 + 연결된 메시지/쿠폰 자동 발송.

종료일 자동 종료: 매일 04:00 배치 + 종료일 24:00 트리거로 진행 → 종료 전환 + 결과 집계 + 메시지·쿠폰 발송 중단.

ROI 자동 계산: ROI = (캠페인 기간 매출 - 예산) / 예산 × 100. 매출은 UTM·쿠폰 매핑된 결제 합계. 5분 캐시.

UTM 추적: 외부 채널(SNS·인터넷·카톡) UTM 파라미터로 유입 분리 집계.

AB 테스트 연동(MKT-09): 캠페인 내 메시지/쿠폰 AB 진행 후 우수안 자동 적용 또는 수동 채택.

세그먼트 freeze 정책: 캠페인 시작 후 세그먼트 멤버 변동 시 신규 멤버 발송 또는 시작 시점 고정(테넌트 정책).

예산 초과 알림: 비용 누적 시 알림 + 발송 중단 옵션(`auto_pause_on_budget`).

## 6. 버튼·아이콘·링크 액션 전체 정의

"+ 캠페인 생성" 버튼: DLG-076-001 호출.

상태 필터 탭: 클릭 즉시 갱신.

캠페인명 클릭: 실적 패널 슬라이드 인.

행 [수정]: 진행 전 캠페인은 전체 수정 가능, 진행 중은 일부만(대상 추가·메시지 추가, 기존 메시지/쿠폰 변경 제한), 종료는 수정 불가.

행 [삭제]: DLG-076-002. 진행 전은 hard delete, 진행 중은 즉시 종료 + soft delete(결과 보존), 종료는 soft delete.

행 [실적]: 실적 패널 슬라이드 인(캠페인명 클릭과 동일).

실적 패널 내부의 UTM별 클릭은 그 UTM 필터로 매출/도달 갱신. 연결된 메시지/쿠폰/이벤트 클릭은 각 자원의 상세 화면으로 이동.

진행 중 캠페인 즉시 종료는 DLG-076-002에서 "즉시 종료 처리됩니다" 안내 후 진행.

## 7. 호출되는 모달 동작

### 7-1. DLG-076-001 캠페인 등록

본문: 캠페인명(필수, 1~50자), 목표(신규 유치/재등록/인지도/VIP 보상/기타 5종), 대상 세그먼트(MBR-EXT-04 다중 조건), 기간(시작/종료), 채널(SMS/카톡/푸시/쿠폰/이벤트 다중), 메시지·쿠폰 연결(MKT-01 메시지·MKT-03 쿠폰·MKT-07 리퍼럴·MKT-09 AB 선택), 예산(금액), UTM 파라미터(선택).

검증: 시작 > 종료 차단. 세그먼트 0명 차단. 메시지·쿠폰 미연결 차단(최소 1개 필요). 예산 0 이하 차단.

저장 시 준비 상태로 등록 + 시작일에 자동 활성.

### 7-2. DLG-076-002 캠페인 삭제 확인

본문: "이 캠페인을 삭제하시겠습니까?" + 진행 중 캠페인의 경우 "진행 중인 캠페인은 삭제 즉시 중단됩니다" 추가 경고.

확인 시 진행 전은 hard delete, 진행 중은 즉시 종료 + soft delete, 종료는 soft delete.

## 8. 토스트와 확인 팝업과 알럿

성공: "캠페인을 등록했어요", "캠페인을 수정했어요", "캠페인을 삭제했어요/즉시 종료했어요".

실패: "세그먼트가 비어있습니다", "메시지·쿠폰 연결이 필요합니다", "권한이 없어요".

확인 팝업: 진행 중 전체 수정 시도 시 "일부만 수정 가능" 안내.

알럿: 권한 없는 계정 접근 시 차단 화면.

예산 초과 알림: 비용 누적 임계 도달 시 운영자에게 알림 + 발송 중단 옵션 모달.

## 9. 데이터 흐름과 외부 연동

화면 진입 시 `GET /api/campaigns` 호출. 응답: 캠페인 배열 + 상태별 카운트.

캠페인 등록 `POST /api/campaigns`, 수정 `PUT /api/campaigns/:id`, 삭제 `DELETE /api/campaigns/:id`.

실적 조회 `GET /api/campaigns/:id/performance`. 5분 캐시.

시작일 자동 활성 배치: 매일 04:00 + 시작일 00:00. 준비 → 진행 + 메시지·쿠폰 자동 발송.

종료일 자동 종료 배치: 매일 04:00 + 종료일 24:00. 진행 → 종료 + 결과 집계 + 발송 중단.

메시지 자동 발송(MKT-01): 활성 시 또는 정기. 쿠폰 자동 발급(MKT-03): 활성 시 일괄. 리퍼럴 연동(MKT-07): 추천 코드 자동 발급. AB 연동(MKT-09): 무작위 분배 / 우수안 채택.

ROI 자동 계산: 결제/발송 webhook 트리거로 실시간 갱신 + 5분 캐시.

UTM 추적: 외부 채널 클릭 시 유입·전환·매출 분리 집계.

예산 초과 알림: 비용 누적 시 알림 + 발송 중단 옵션.

세그먼트 동기화(MBR-EXT-04): 정책에 따라 신규 발송 또는 시작 시점 고정.

자동 재시도(webhook): 1분/5분/30분 3회.

종료 후 아카이브: 종료일 + 90일 후 결과 영구 보존.

본사 통합 캠페인 동기화: 슈퍼관리자 등록 시 전 지점 즉시 노출.

가족 묶음(MBR-EXT-02): 그룹당 1명에게만 발송.

법정 시간 차단: 발송 시점 21~08시 광고 자동 차단(자동 알림 정보성 예외).

수신 거부/휴면 자동 제외: 발송 트리거 시.

등록·수정·삭제·자동 활성·자동 종료 SCR-097 감사 로그.

## 10. 화면 상태와 예외 처리

상태: 데이터 미연동(목업), 캠페인 없음(생성 CTA), 진행 중(실시간 실적), 종료.

예외: 시작 > 종료 인라인 에러. 세그먼트 0명 차단. 메시지·쿠폰 미연결 차단. 예산 0 이하 차단. 진행 중 전체 수정 시도 시 "일부만 수정 가능". 진행 중 삭제 시 즉시 종료 처리. 잔여 캐시 부족 시 발송 보류 + 운영자 알림. 연결 쿠폰 만료 시 "쿠폰 만료" + 발급 차단. 예산 초과 시 알림 + 발송 중단 옵션. 세그먼트 변동 시 정책 적용(신규 발송 또는 고정). AB 종료 시 우수안 자동 적용 또는 수동 채택. UTM 누락 시 "ROI 분리 불가" 안내. webhook 발송 실패 시 자동 재시도 3회. 종료 캠페인 재활성 차단. 본사 vs 지점 충돌 시 본사 우선 또는 둘 다(정책). 가족 묶음 옵션 그룹당 1명. 법정 시간 광고 차단(정보성 예외). 수신 거부/휴면 자동 제외. 동시 다중 캠페인 대상 시 모두 발송 또는 우선순위(정책).

```mermaid
    B -->|409 종료 캠페인 재활성| O[차단]
    B -->|409 본사 vs 지점 충돌| P[본사 우선 또는 둘 다]
    B -->|409 법정 시간 광고| Q[차단 (정보성 예외)]
    B -->|409 수신 거부/휴면| R[자동 제외]
```

## 14. 핵심 디자인 요청사항

상태 배지 색상: 준비 파랑, 진행 녹색, 종료 회색.

ROI 컬럼은 색상 강조: 100%+ 녹색, 50~100% 노랑, 50% 미만 회색, 마이너스 빨강.

본사 통합 캠페인은 행 좌상단 "본사" 배지.

실적 패널은 우측 슬라이드 인. 내부에 시간대별 추이 그래프(라인 차트) + UTM별 분리 막대 + 연결 자원 목록.

DLG-076-001 모달은 세그먼트 선택이 가장 중요하므로 다중 조건 빌더가 시각적으로 강조되어야 합니다. 예상 수신자 수가 실시간 표시.

예산 입력 필드는 천 단위 콤마 자동 표시.

진행 중 캠페인의 실적은 5분 간격으로 자동 갱신되며 마지막 갱신 시각이 표시됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

상태 3종: 준비 / 진행 / 종료. 시작일 자동 활성, 종료일 자동 종료.

진행 전 수정: 전체 수정 가능.

진행 중 수정: 일부만 가능(대상 추가·메시지 추가). 기존 메시지·쿠폰 변경 제한.

삭제 정책: 진행 전 hard delete. 진행 중 즉시 종료 + soft delete(결과 보존). 종료 soft delete.

ROI 자동 계산: ROI = (캠페인 기간 매출 - 예산) / 예산 × 100. 매출은 UTM·쿠폰 매핑된 결제 합계.

시작일·종료일 검증: 시작일 ≤ 종료일. 시작일 과거 시 즉시 활성 또는 차단(정책).

세그먼트 정책: MBR-EXT-04 다중 조건. 0명이면 저장 차단.

세그먼트 변동: 시작 후 멤버 변동 시 신규 발송 또는 시작 시점 고정(`segment_freeze` 정책).

연결 자원: 메시지(MKT-01) / 쿠폰(MKT-03) / 이벤트(MKT-07) / AB(MKT-09). 다중 연결 가능.

자동 발송: 시작일 자동 활성 시 연결된 메시지·쿠폰 자동 발송. 잔여 캐시 부족 시 보류.

예산 관리: 비용 누적 추적. 초과 시 알림 + 발송 중단 옵션(`auto_pause_on_budget`).

UTM 추적: 외부 채널 UTM 파라미터로 유입 분리 집계.

AB 테스트 연동(MKT-09): 우수안 자동 적용 또는 수동 채택.

법정 시간 차단: 21~08시 영업/광고 차단(자동 알림 정보성 예외).

수신 거부/휴면 자동 제외: 모든 캠페인 발송에 자동 적용.

가족 묶음 옵션(MBR-EXT-02): 그룹당 1명에게만 발송.

권한별 가시성: 슈퍼관리자 전 지점 + 본사 통합. 센터장/매니저 소속 지점 + 생성·수정·삭제·실적. FC/트레이너/스태프/readonly 차단.

캠페인명 정책: 1~50자.

목표 5종: 신규 유치 / 재등록 유도 / 브랜드 인지도 / VIP 보상 / 기타.

실적 캐시: 도달/클릭/전환/ROI 5분 캐시. 결제·발송 트리거 시 무효화.

캠페인 결과 보존: 종료 후 영구 보존 + 아카이브. 추후 분석·재사용 가능.

본사 통합 캠페인: 슈퍼관리자가 전 지점 일괄 등록. 지점에서 일부 조정(`hq_owned=true`).

변경 이력/감사 로그: 등록·수정·삭제·종료·자동 활성 모두 SCR-097 기록.

캠페인 동시 운영: 동일 회원이 다중 캠페인 대상일 경우 모두 발송 또는 우선순위 정책(테넌트 설정).

이상의 모든 정책은 별도 문서 없이 이 한 장만 보면 이해할 수 있도록 풀어 적었습니다.
