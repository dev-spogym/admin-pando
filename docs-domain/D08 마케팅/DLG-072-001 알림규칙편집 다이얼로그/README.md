## 2. 다이얼로그 목적과 사용 맥락

알림 규칙 편집 다이얼로그는 SCR-072 자동 알림 설정에서 특정 알림 규칙(만료 step D-7, 생일 축하, 장기 미방문 등)의 지점 적용 옵션·발송 채널·메시지 내용·발송 시각·발송 옵션을 세부 편집하는 모달입니다.

본사 정책 세트로 내려온 만료 step의 경우 본사 영역(기준일·트리거 조건)이 읽기 전용으로 표시되고, 지점 영역(채널·메시지·발송 시각·발송 옵션)만 편집할 수 있습니다. 지점 자체 운영 이벤트 규칙(생일·장기 미방문·등록 감사 등)은 발송 시점도 지점에서 직접 입력합니다.

호출 트리거는 두 가지입니다. SCR-072의 알림 카드 우상단 "상세 설정" 버튼 클릭, 그리고 DLG-072-002 알림 트리거 추가 다이얼로그에서 새 규칙을 등록한 직후 자동 전환.

## 3. 다이얼로그 구성

모달 상단에는 편집 중인 규칙 이름이 표시됩니다(예: "본사 만료 step D-20 알림", "장기 미방문 30일 알림", "생일 축하 알림"). 본사 필수 step의 경우 잠금 아이콘 + "본사 정책" 배지가 함께 표시됩니다.

발송 시점 설정 영역이 본문 최상단에 있습니다. 본사 소유 만료 step이면 기준일이 읽기 전용으로 표시되며(예: "본사 정책: 만료일 7일 전"), 회색 톤으로 편집 불가임이 시각적으로 명확합니다. 지점 자체 운영 이벤트 규칙이면 이벤트 기준 전·당일·후 숫자 입력이 활성화됩니다(예: "마지막 출석일 + N일", 30/60/90 등).

발송 채널 선택 영역이 다음 단계에 있습니다. 알림톡 / SMS / 앱 푸시 중 선택하며, 채널별 예상 비용(플랫폼 API 응답)이 옆에 작은 숫자로 표시됩니다. 폴백 규칙(알림톡 비친구 → SMS)도 옵션 토글로 제공됩니다.

플랫폼 연동 정보 영역은 채널 선택 옆에 별도 카드로 표시됩니다. 사용 중인 발신 프로필, 승인 템플릿 상태(알림톡인 경우), 최근 테스트 발송 결과가 표시됩니다. 미승인 템플릿이거나 발신 프로필 미설정이면 빨강 톤 경고가 추가됩니다.

발송 시각 영역에서는 시·분 단위 시각 설정이 가능합니다(예: 09:00). 24시간 형식 입력. 만료 step 같은 본사 정책에서도 발송 시각은 지점이 조정 가능합니다.

대상 조건 설정 영역에서는 상품군(정기권/PT/필라테스/골프), 회원 상태(활성/만료/홀딩), 예약 상태(있음/없음), 미수금 유무, 방문경로 등 발송 대상 세부 조건을 추가할 수 있습니다. 다중 조건 AND/OR 조합.

메시지 내용 영역에서는 textarea와 변수 삽입 버튼({회원명}/{만료일}/{잔여횟수}/{담당FC} 4종)이 함께 배치됩니다. 글자수 카운트는 채널별 한도와 함께 실시간 표시(SMS 90byte / LMS 2000byte / 알림톡 1000자). 금지어 포함 시 인라인 에러.

테스트 발송 영역에는 "테스트 발송" 버튼과 발송 번호 입력 필드(기본값: 운영자 본인 번호)가 있습니다. 클릭 시 본인 또는 지정 관리자 번호로 시범 발송 후 결과가 모달 안에 표시됩니다.

모달 하단에는 "저장" 버튼과 "취소" 버튼이 우측 정렬로 배치됩니다. 본사 필수 step에서 본사 영역을 편집하려고 시도하면 저장 차단 + 인라인 에러.

## 4. 검증과 저장 흐름

저장 검증 순서:

첫째, 발송 시각 형식 검증(HH:MM 24시간 형식). 잘못된 형식 시 인라인 에러.

둘째, 법정 시간 영업/광고 알림 검증. 영업/광고 알림(생일/미방문/등록 감사/첫 방문) 시각이 21~08시 범위면 "야간 광고 발송 불가" 인라인 에러. 정보성(결제·환불·홀딩 종료·만료 D-Day)은 예외.

셋째, 메시지 본문 글자수 검증. SMS 90byte 초과 시 LMS 자동 전환 안내, LMS 2000byte 초과 차단, 알림톡 1000자 초과 차단.

넷째, 금지어 포함 검증. 사전 등록된 금지어(도박·대출·성인 등) 포함 시 인라인 에러 "금지어 포함: {단어}" + 저장 차단.

다섯째, 알림톡 채널 선택 시 사전 승인 템플릿 검증. 미승인 시 "사전 승인 템플릿 필요" 안내 + SMS 자동 변경 권유.

여섯째, 본사 필수 step 영역 편집 시도 검증. 본사 영역(기준일·트리거 조건)을 변경하려고 하면 인라인 에러.

저장 성공 시 모달 자동 닫힘 + 부모 화면 알림 카드 갱신 + "상세 설정을 저장했어요" 토스트.

변경 사항은 다음 트리거부터 적용됩니다. 이미 큐에 등록된 발송은 기존 메시지로 발송됩니다.

저장 실패 시 입력값 유지 + 인라인 에러 또는 토스트. 자동 재시도 1회 후 사용자 액션 대기.

취소·ESC·배경 클릭은 변경 사항이 있으면 "변경 사항이 사라집니다. 닫으시겠습니까?" yes/no 확인.

## 5. 권한별 동작

슈퍼관리자·본사: 본사 step의 본사 영역(기준일·트리거 조건)도 편집 가능. 지점 운영 규칙은 모든 필드 편집.

센터장·매니저: 본사 step의 지점 영역(채널·메시지·시각·옵션)만 편집. 지점 운영 규칙은 전체 편집.

FC·트레이너·스태프·readonly: 다이얼로그 자체 접근 차단. 부모 화면(SCR-072) 접근 자체가 차단되어 있습니다.

본사 필수 step의 비활성 토글은 SCR-072에서 disabled. 이 다이얼로그에서도 별도의 활성/비활성 토글이 없고, 부모 화면에서 관리됩니다.

## 6. 데이터 흐름과 외부 연동

규칙 조회 `GET /api/auto-alerts/:id` (모달 호출 시 최신 데이터 로드).

저장 `PUT /api/auto-alerts/:id/settings` (channel, message, send_time, target_filter, options).

플랫폼 메타데이터 조회(발신 프로필·승인 템플릿·예상 비용) `GET /api/messages/platform-summary` (모달 호출 시 동기화).

테스트 발송 `POST /api/auto-alerts/:id/test` (test_phone). 운영자 본인 번호로 시범 발송 + 결과 즉시 표시.

본사 정책 조회 `GET /api/auto-alerts/headquarters-policy/:id` (본사 영역 읽기 전용 표시).

동시 편집 충돌은 optimistic lock으로 차단되며 후행 저장은 거절 + "다른 운영자가 편집 중" 안내.

저장 성공 시 변경 사항은 다음 트리거부터 적용됩니다. 이미 큐에 등록된 발송은 기존 메시지로 발송.

감사 로그(SCR-097) 비동기 INSERT: actor_id, rule_id, action(update), old_value(이전 settings), new_value(신규 settings), timestamp.

본사 step 정의 변경은 슈퍼관리자 권한에서만 가능하며 전 지점에 즉시 동기화 + 알림 센터 통지.

## 7. 예외 처리

발송 시각 형식 오류 → 인라인 에러.

법정 시간 광고 발송 → 인라인 에러 + 차단(정보성 예외).

글자수 초과 → 차단(SMS는 LMS 전환 안내, LMS·알림톡은 차단).

금지어 포함 → 인라인 에러 + 차단.

알림톡 미승인 템플릿 → 안내 + SMS 폴백 권유.

본사 필수 step 본사 영역 편집 시도 → 인라인 에러 + 차단(슈퍼관리자만 허용).

테스트 발송 실패 → 실패 사유 표시 + 재시도 가능.

플랫폼 메타데이터 조회 실패 → "발신 정보/예상 비용 조회 실패" + 재조회 안내.

플랫폼 잔여 캐시 부족 예상 → 노랑 경고 + 저장 가능하지만 발송 시점에 보류될 수 있음 안내.

동시 편집 충돌(409) → "다른 운영자가 편집 중" 모달 + 새로고침 안내.

권한 부족 → 다이얼로그 접근 자체 차단(부모 화면 차단).

## 8. 토스트와 확인 팝업

성공: "상세 설정을 저장했어요" / "테스트 발송 완료" 녹색 5초.

실패: "권한이 없어요" / "다른 운영자가 편집 중" / "플랫폼 조회 실패" 빨강 톤.

확인 팝업: 변경 사항 있는 모달 닫기 시도 시 yes/no 확인.

알럿: 권한 없는 직접 접근은 부모 화면에서 차단.

## 10. 디자인 요청사항

본사 영역(읽기 전용)은 회색 톤 + 잠금 아이콘으로 시각적으로 명확히 구분.

채널 선택 라디오 옆에 예상 비용(플랫폼 API 기준) 작은 숫자.

플랫폼 연동 정보 카드는 차분한 회색 톤. 미승인/미설정은 빨강 경고.

발송 시각 입력은 24시간 형식. HH:MM 자동 포맷.

메시지 textarea는 충분히 크게. 변수 삽입 버튼은 textarea 위에 가로 배치.

글자수 카운터는 textarea 우측 하단. 한도 초과 시 빨강 강조.

테스트 발송 영역은 본문 하단에 별도 카드로 배치. 결과 메시지는 카드 내부에 시각적으로 명확히.

저장 버튼은 강조 톤. 변경 사항 없을 때 비활성.

모바일에서는 모달이 풀스크린 자동 전환 + 필드 세로 스택.

## 11. 운영 정책

본사 영역 읽기 전용: 본사 소유 기준일·트리거 조건은 지점에서 편집 불가. 채널·메시지·발송 시각·발송 옵션만 지점에서 편집 가능.

발송 시점:
- 만료 step: 매일 04:00 일배치로 대상 회원 추출 + 설정 시각 발송
- 결제·환불·홀딩 종료: 이벤트 즉시
- 첫 방문: 출석 webhook 트리거

변수 치환: {회원명}/{만료일}/{잔여횟수}/{담당FC} 4종. 누락 회원 발송 제외 + 사유 기록.

플랫폼 기준 발송 가능 여부: 자동 알림도 일반 발송과 동일하게 플랫폼 잔여 캐시/발송 가능 여부 확인.

수신 거부/휴면 자동 제외.

법정 시간 차단: 영업/광고 알림(생일·미방문·등록 감사·첫 방문) 21~08시 차단. 정보성(결제·환불·홀딩 종료·만료 D-Day) 예외.

금지어 차단.

알림톡 사전 승인: 알림톡 채널 선택 시 사전 승인 템플릿 필요. 미승인 시 SMS 자동 폴백 또는 차단.

글자수 정책: SMS 90byte / LMS 2000byte / 알림톡 1000자. SMS 90byte 초과 시 자동 LMS 전환 안내. LMS·알림톡 한도 초과 시 차단.

테스트 발송: 운영자 본인 번호로 시범 발송. 실제 회원 발송과 별도 카운트.

메시지 변경 적용 시점: 저장 후 다음 트리거부터. 이미 큐 등록된 발송은 기존 메시지 유지.

본사 step 신규 추가 시 비활성 상태로 자동 추가 + 운영자 알림(SCR-072 노랑 배너).

권한별 가시성: 슈퍼관리자/본사 본사 영역 편집 가능. 센터장/매니저 지점 영역만. FC/트레이너/스태프/readonly 차단.
