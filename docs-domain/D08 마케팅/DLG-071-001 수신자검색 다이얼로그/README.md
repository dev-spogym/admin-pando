## 2. 다이얼로그 목적과 사용 맥락

수신자 검색 다이얼로그는 메시지 발송 시 수신자를 이름·연락처·이용권 상태 등 다양한 조건으로 검색해 발송 대상을 정밀하게 선택하는 팝업입니다. 부모 화면 SCR-071에서 조건 그룹(전체/활성/만료)을 사용하지 않고 개별 회원을 1:1 또는 1:N으로 선택해 보내야 할 때 이 다이얼로그를 호출합니다.

대표적 사용 맥락은 다음과 같습니다. 첫째, FC가 본인 담당 회원 5~10명에게 1:1 케어 메시지를 보낼 때 개별 검색으로 회원을 추가합니다. 둘째, 매니저가 특정 이벤트 참여자(예: VIP 동호회) 10~30명에게만 특별 메시지를 보낼 때 이름으로 일일이 검색해 추가합니다. 셋째, 만료 회원 그룹 발송에서 일부 회원만 제외하고 나머지에게 보낼 때(부정적 필터링은 어려우므로 직접 선택 방식 활용).

호출 트리거는 SCR-071의 수신자 선택 영역에서 "개별 검색" 라디오를 선택한 후 활성화되는 "대상 검색" 버튼 클릭입니다.

## 3. 다이얼로그 구성

모달 상단에는 "수신자 검색"이라는 제목과 함께 우측에 닫기(X) 버튼이 있습니다.

검색 입력 필드는 모달 본문 가장 위에 큼지막하게 배치됩니다. 이름 또는 연락처로 회원을 검색하며 디바운스 300ms가 적용되어 타이핑이 끝나면 자동으로 결과가 갱신됩니다. 최소 2자 이상 입력해야 검색이 시작되고 최대 50자까지 입력 가능합니다.

조건 필터 바가 검색 필드 아래에 배치됩니다. 이용권 상태(활성·만료·홀딩), 성별(전체·남·여), 회원 등급(VIP·일반·신규), 가입 기간(전체/30일 이상/1년 이상), 마지막 방문일(전체/이번 주/이번 달) 드롭다운이 가로로 나열됩니다. 필터 변경 시 결과 테이블이 즉시 갱신됩니다.

선택 도구 영역에는 "전체 선택" 체크박스(현재 페이지 전체), "선택 해제" 링크, 현재 선택된 회원 수 표시(예: "12명 선택됨")가 배치됩니다.

검색 결과 목록 테이블은 컬럼이 좌측부터 선택 체크박스, 회원 사진(작은 썸네일), 이름, 연락처(끝 4자리만 표시 또는 전체), 이용권 상태 배지, 회원 등급 배지, 마지막 방문일 순서로 배치됩니다.

페이지네이션 영역이 테이블 아래에 배치됩니다. 페이지당 20건, 페이지 번호 이동, 총 N건 표시.

모달 하단에는 "선택 완료(N명)" 버튼과 "취소" 버튼이 우측 정렬로 배치됩니다. 선택 완료 버튼은 선택된 회원이 1명 이상일 때만 활성화되며, 버튼 라벨에 선택된 수가 동적으로 표시됩니다.

## 4. 검색과 선택 흐름

검색 입력: 운영자가 이름 또는 연락처를 입력하면 300ms 디바운스 후 백엔드에 검색 요청. 결과 목록이 갱신됩니다.

필터 적용: 조건 필터 드롭다운 변경 시 즉시 결과 갱신. 검색어와 필터는 AND로 결합됩니다.

체크박스 선택: 개별 행 체크박스로 1명씩 추가, "전체 선택" 체크박스로 현재 페이지 일괄 추가. 선택은 페이지를 넘겨도 유지되어, 여러 페이지에서 회원을 모아 선택할 수 있습니다.

선택 완료: "선택 완료" 버튼 클릭 → 선택된 회원 ID 배열이 부모 화면의 수신자 칩 영역에 추가 + 모달 자동 닫힘.

취소: 변경 없이 모달 닫힘. 선택된 회원은 부모 화면에 반영되지 않습니다.

검색 결과 0건: "검색 결과가 없어요" 안내 + 필터 변경 권유.

검색어 2자 미만: 결과 영역에 "최소 2자 이상 입력해주세요" 안내. 검색 미실행.

검색어 50자 초과: 자동 잘림(50자까지만 인식).

## 5. 부모 화면 변화

선택 완료 시 부모 화면(SCR-071) 수신자 칩 영역에 선택된 회원이 칩 형태로 추가됩니다. 각 칩에는 회원 이름과 X 버튼이 있어 부모 화면에서 개별 제거가 가능합니다.

이미 부모 화면에 추가된 회원을 다시 선택하면 중복으로 추가되지 않고 기존 칩이 유지됩니다.

수신자 수가 갱신되면 채널별 예상 비용 카드가 즉시 재계산되어 운영자가 비용 변화를 확인할 수 있습니다.

가족 묶음 발송 옵션이 활성화된 경우, 추가된 회원 중 같은 가족 그룹 멤버가 있으면 그룹당 1명만 자동 선별되어 칩에 표시됩니다.

## 6. 권한별 동작

슈퍼관리자·본사·Owner(지점장)·매니저: 소속 지점의 모든 회원이 검색 결과에 표시됩니다.

FC: RLS(Row-Level Security)로 본인 담당 회원만 결과에 표시됩니다. 다른 FC 담당 회원은 검색되지 않습니다.

트레이너·스태프·readonly: 부모 화면 자체에 접근할 수 없습니다.

본사 통합 모드(슈퍼관리자만 활성)에서는 전 지점 회원이 검색되며, 결과 테이블에 "소속 지점" 컬럼이 추가로 표시됩니다.

## 7. 데이터 흐름과 외부 연동

검색 호출 `GET /api/messages/recipients?search=...&filters=...&page=...`. 응답: 회원 배열 + 페이지 정보 + 총 건수.

수신 거부·휴면 회원은 백엔드에서 자동 제외되어 검색 결과에 표시되지 않습니다(또는 비활성 표시로 노출 + 선택 차단).

회원 마스터의 `consent_marketing` 플래그가 false인 회원은 결과에서 제외됩니다.

선택된 회원 ID 배열은 부모 화면 상태로만 저장되고 별도 API 호출이 없습니다(발송 단계에서 사용).

캐시 정책: 같은 검색·필터 조건의 결과는 1분 캐시(서버 측). 사용자에게는 항상 최신 데이터가 보이도록 화면 진입 시 캐시 무효화.

본사 통합 모드 검색은 `branchId=all` 파라미터로 호출되며 응답에 소속 지점 정보 포함.

## 8. 예외 처리

검색어 2자 미만 → "최소 2자 이상 입력해주세요" 안내. 검색 미실행.

검색 결과 0건 → "검색 결과가 없어요" + 조건 변경 권유.

FC RLS 차단 → 본인 담당 외 회원 결과 미노출(투명 차단).

네트워크 오류 → 자동 재시도 1회 + 다시 시도 안내. 모달은 유지.

너무 많은 결과 (1만+ 건) → 페이지네이션으로 처리. 상위 N건만 노출되며 "결과가 너무 많아요, 조건을 좁혀주세요" 안내.

수신 거부/휴면 회원 → 자동 제외(투명).

권한 부족 → 다이얼로그 자체가 호출되지 않음(부모 화면 버튼 hidden).

## 9. 토스트와 확인 팝업

토스트는 일반적으로 표시되지 않습니다(선택은 즉시 부모 화면에 반영되고 토스트 없이 완료).

확인 팝업: 선택 도중 ESC 또는 배경 클릭으로 닫으려고 할 때 선택된 회원이 있으면 "선택을 취소하시겠습니까?" yes/no 확인.

알럿: 권한 없는 직접 접근은 부모 화면에서 차단.

## 11. 디자인 요청사항

모달은 화면 중앙 큰 사이즈(가로 800px+)로 표시. 데이터 테이블 가독성 확보.

검색 필드는 모달 본문 최상단에 큼지막하게 배치. 자동 포커스로 진입 시 즉시 타이핑 가능.

필터 드롭다운은 가로 나열. 모바일에서는 세로 스택.

결과 테이블은 호버 행 강조 + 체크박스 클릭 영역 확장으로 빠른 선택 가능.

선택 완료 버튼 라벨에는 동적으로 선택 수가 표시("선택 완료(N명)"). 0명일 때는 비활성.

선택된 회원이 여러 페이지에 걸쳐 있을 때 상단 도구 영역에 "총 N명 선택됨(현재 페이지 외 M명 포함)" 표시.

모바일에서는 모달이 풀스크린으로 자동 전환되고 테이블이 카드형 리스트로 변경.

## 12. 운영 정책

검색 디바운스 300ms / 최소 2자 / 최대 50자.

수신 거부 / 휴면 회원 자동 제외.

FC RLS: 본인 담당 회원만 검색 결과에 표시.

페이지당 20건. 1만+ 결과 시 페이지네이션 + 조건 좁힘 안내.

본사 통합 모드: 슈퍼관리자만 활성. 전 지점 검색 + 소속 지점 컬럼 노출.

선택은 페이지 넘겨도 유지. 부모 화면 적용은 "선택 완료" 클릭 시.

가족 묶음 발송 옵션 활성 시 그룹당 1명만 자동 선별.

권한별 가시성: 슈퍼관리자/Owner(지점장)/매니저 전체, FC 본인 담당, 트레이너/스태프/readonly 차단.
