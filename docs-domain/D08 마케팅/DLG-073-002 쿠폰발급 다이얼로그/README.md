## 2. 다이얼로그 목적과 사용 맥락

쿠폰 발급 다이얼로그는 생성된 쿠폰을 특정 회원 또는 회원 그룹에게 직접 발급하는 모달입니다. 개별 발급과 그룹 일괄 발급, 리드 그룹 발급(CRM-01 연계)을 모두 지원하며, 발급 메시지를 입력하면 알림톡/SMS/푸시 동시 발송이 자동으로 실행됩니다.

운영 시나리오: 신규 등록 회원 환영 쿠폰 일괄 발급, VIP 등급 보상 쿠폰 발급, 만료 회원 그룹 재등록 권유 쿠폰, 1:1 개별 사은 발급, 미전환 리드 재마케팅 쿠폰.

호출 트리거는 SCR-073의 행 [발급] 버튼 또는 SCR-M004 회원 상세의 "쿠폰 발급" 빠른 액션. 만료/중단 쿠폰 또는 발급 수량 도달 쿠폰에서는 [발급] 버튼이 비활성.

## 3. 다이얼로그 구성

모달 상단에는 "쿠폰 발급" 제목과 닫기(X) 버튼.

발급 쿠폰 정보 카드: 쿠폰명, 할인 내용(정액 5,000원 또는 정률 10%), 유효 기간이 상단에 요약. 발급 수량 한도와 잔여 발급 가능 수량 표시(예: "100매 중 잔여 47매").

발급 대상 선택 방식 라디오: 개별 회원 검색 / 조건 그룹 / 리드 그룹 3종.

조건 그룹 선택 시 드롭다운: 전체 회원 / 활성 회원 / 만료 회원 / VIP 등급 / 신규 등급 / 일반 등급 / 장기 미방문. 선택 즉시 예상 발급 수신자 수가 표시됩니다.

리드 그룹 선택 시 드롭다운: 전체 리드 / 30일 미전환 / 보류 / 등록완료 등 사전 정의 필터. CRM-01 리드 그룹 연계.

개별 회원 검색 시 검색 입력 필드(이름·연락처 디바운스 300ms) + 검색 결과 목록 + 선택 회원 칩 영역(개별 제거 가능).

발급 수량 확인 영역: 현재 선택된 발급 대상 수 / 잔여 발급 가능 수량 / 발급 후 잔여 표시.

발급 메시지 textarea(0~200자, 선택). 입력하면 알림톡/SMS/푸시 동시 발송 옵션이 활성화되며, 비워두면 알림 미발송으로 쿠폰만 보유 상태로 추가됩니다.

발송 채널 선택(메시지 입력 시): 알림톡(친구만) / SMS / 푸시(앱 설치 회원) 중 선택. 채널 자동 선택(알림톡 우선·SMS 폴백) 옵션.

모달 하단에는 "발급" 버튼(강조 톤)과 "취소" 버튼.

## 4. 발급 흐름과 부모 화면 변화

발급 검증 순서:

발급 대상 0명 → "발급 대상이 없어요" + 차단.

발급 수량 한도 초과(잔여 < 선택 수) → "발급 한도를 초과합니다(잔여 N매)" + 차단.

이미 보유 중인 회원 중복 발급 → "이미 보유 중인 회원 N명" 안내. 정책에 따라 차단(중복 금지) 또는 허용(중복 가능).

1인 사용 제한 도달 회원 → 발급은 가능하나 결제 시 적용 차단. 안내만 표시.

발급 메시지 200자 초과 → 인라인 에러 + 차단.

검증 통과 시 모달 로딩 → `POST /api/coupons/:id/issue` API → 응답 받아 모달 닫힘 + 부모 화면 갱신 + "N명에게 쿠폰을 발급했어요" 토스트.

발급 메시지 입력 시 알림톡/SMS/푸시 동시 발송이 자동 실행됩니다. 발송 실패 시 쿠폰 발급은 성공으로 유지하고 메시지만 재시도 큐(1분/5분/30분)에 등록.

부모 화면(SCR-073)의 해당 쿠폰 행의 발급 수가 즉시 갱신되며, 사용률은 발급 수가 증가했으므로 일시적으로 떨어집니다. 회원 상세(SCR-M004)에서는 발급된 회원의 쿠폰 보유 목록에 새 쿠폰이 추가됩니다.

## 5. 권한별 동작

9역할 영문 키워드 기준 발급 권한 매트릭스는 다음과 같습니다. 쿠폰 발급은 owner 이상이 기본 권한이지만, 본 시스템은 운영 편의를 위해 FC까지 발급 권한을 열어두되 RLS로 본인 담당 회원만 발급 대상이 되도록 제한합니다.

- 슈퍼관리자(`superAdmin`) · 본사 최고관리자(`primary`): 전 지점 회원·리드 대상 발급 + 본사 통합 쿠폰(`hq_owned=true`) 일괄 발급 가능.
- Owner(지점장)(`owner`): 자기 브랜드 소속 전 지점 회원 대상 발급 가능.
- 매니저(`manager`): 자기 지점 회원·리드 대상 발급 가능. 발급 한도·1인 사용 제한 등 정책은 owner와 동일하게 적용됩니다.
- FC(`fc`): 본인 담당 회원에게만 발급 가능(RLS 자동 필터). 그룹/리드 선택 시에도 검색 결과는 본인 담당 범위로 한정됩니다.
- 트레이너(`trainer`) · 스태프(`staff`) · 프런트(`front`) · 읽기 전용(`readonly`): 부모 화면(SCR-073) 접근 자체가 차단되어 본 다이얼로그가 호출되지 않습니다.

본사 통합 쿠폰의 발급은 슈퍼관리자가 본사 모드에서 전 지점 일괄 발급 가능. 지점 운영자는 자기 지점 회원에게만 발급. FC가 직접 URL 우회로 다른 FC 담당 회원을 발급 대상으로 지정해도 백엔드 응답이 403이 되어 차단되며, 모든 차단 이벤트는 SCR-097 감사 로그에 기록됩니다.

## 6. 데이터 흐름

발급 API `POST /api/coupons/:id/issue` (member_ids 배열 또는 group_filter, message, channel).

응답에 발급 성공/실패 결과가 회원별로 포함됩니다.

알림 발송은 MKT-01 메시지 발송 시스템과 연동되어 알림톡/SMS/푸시 자동 발송.

발송 실패 시 자동 재시도 큐 등록(1분/5분/30분).

쿠폰 발급 후 `coupon_issue_log` INSERT(coupon_id, member_id, issued_at, actor_id, message).

세그먼트 자동 갱신: 신규 쿠폰 보유 회원 세그먼트(MBR-EXT-04) 갱신.

SCR-097 감사 로그 INSERT.

## 7. 예외 처리

발급 대상 0명 → 차단.

발급 한도 초과 → 차단 + 잔여 안내.

이미 보유 중인 회원 중복 → 정책에 따라 차단/허용.

1인 사용 제한 도달 → 발급은 허용 + 결제 시 적용 차단 안내.

발급 메시지 200자 초과 → 인라인 에러.

메시지 발송 실패 → 쿠폰 발급 성공 + 메시지 재시도 3회.

만료/중단 쿠폰 발급 시도 → 부모 화면에서 버튼 비활성. 다이얼로그 호출 자체가 차단.

FC가 다른 FC 담당 회원 검색 → RLS 차단.

동시 발급 충돌(409) → 후행 발급 거절 + 새로고침 안내.

네트워크 오류 → 자동 재시도 1회.

## 8. 토스트와 확인 팝업

성공: "N명에게 쿠폰을 발급했어요" 녹색 5초. 메시지 발송 동시 진행 시 "쿠폰 발급 + 알림 발송 완료".

실패: "발급 한도 초과" / "이미 보유 중" / "권한이 없어요" 빨강 톤.

확인 팝업: 큰 수량 발급(예: 100명 이상) 시 "총 N명에게 발급합니다. 진행하시겠습니까?" yes/no 추가 확인.

## 10. 디자인 요청사항

발급 쿠폰 정보 카드는 모달 상단에 차분한 강조 톤으로 표시되어 발급 대상 쿠폰을 정확히 인지할 수 있게.

발급 대상 선택 라디오에 따라 본문 영역이 동적으로 변경(개별 검색 / 조건 그룹 / 리드 그룹).

발급 수량 표시는 진행률 바 형태로 시각화(예: 100매 중 53매 발급 완료, 잔여 47매).

발급 메시지 textarea는 글자수 카운터(0/200) 함께 표시.

발송 채널 선택은 메시지 입력 시에만 활성. 메시지가 비어있으면 채널 선택 영역 hidden.

발급 버튼은 강조 톤. 큰 수량 발급(100+) 시 추가 확인 모달.

모바일은 풀스크린 자동 전환.

## 11. 운영 정책

발급 대상 3종: 개별 회원 검색 / 조건 그룹(활성/만료/등급 등) / 리드 그룹(CRM-01).

발급 수량 한도: 쿠폰 생성 시 설정된 한도 적용. 한도 초과 시 차단.

이미 보유 중인 회원: 중복 발급 정책에 따라 차단 또는 허용.

1인 사용 제한 도달: 발급은 허용. 결제 시 적용 차단.

발급 메시지: 0~200자. 입력 시 알림톡/SMS/푸시 동시 발송 옵션. 비어있으면 알림 미발송.

채널 자동 선택: 알림톡 우선·SMS 폴백 옵션.

만료/중단 쿠폰 발급 시도: 부모 화면 버튼 비활성.

FC RLS: 본인 담당 회원만 검색.

발급 후 회원 상세에 쿠폰 보유 목록 즉시 반영.

감사 로그: 발급 SCR-097 기록(actor_id, coupon_id, member_id, action(issue), timestamp).

메시지 발송 실패: 쿠폰 발급 성공 + 메시지 재시도 3회.

세그먼트 자동 갱신: 신규 쿠폰 보유 회원 세그먼트(MBR-EXT-04) 갱신.

권한별: 슈퍼관리자/Owner(지점장)/매니저/FC 모두 발급 가능. FC는 본인 담당 한정.
