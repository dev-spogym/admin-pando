## 2. 다이얼로그 목적과 사용 맥락

캠페인 삭제 확인 다이얼로그는 캠페인을 삭제하기 전 최종 확인을 받는 모달입니다. 진행 중인 캠페인을 삭제할 경우 발송이 중단된다는 사실을 안내하며, 결과는 보존되어 추후 분석에 사용할 수 있도록 합니다.

호출 트리거는 SCR-076 행 [삭제] 버튼.

## 3. 다이얼로그 구성

모달 상단에는 "캠페인 삭제" 제목과 경고 아이콘.

안내 메시지: "이 캠페인을 삭제하시겠습니까?".

대상 캠페인 요약 카드: 캠페인명, 목표, 기간, 현재 상태, 실적 요약(도달/전환/ROI). 운영자가 삭제 대상을 정확히 확인할 수 있게 합니다.

상태별 안내:
- 준비 캠페인(진행 전): "삭제 시 영구 삭제됩니다(hard delete)" 안내. 시작 전이므로 영향 없음.
- 진행 중 캠페인: 빨강 톤 경고 "진행 중인 캠페인은 삭제 즉시 중단됩니다. 발송된 메시지/쿠폰은 회수되지 않습니다. 결과는 보존됩니다(soft delete)" 안내.
- 종료 캠페인: 노랑 톤 안내 "종료된 캠페인의 결과는 보존됩니다(soft delete)".

모달 하단에는 위험 액션 버튼("삭제" 빨강 또는 "즉시 종료" 주황 - 진행 중 한정)과 "취소" 버튼.

## 4. 액션과 부모 화면 변화

삭제 버튼 클릭 시 `DELETE /api/campaigns/:id` API 호출.

상태별 처리:
- 준비: hard delete. 부모 화면에서 행 제거.
- 진행 중: 즉시 종료 + soft delete. 부모 화면에서 상태가 "종료"로 변경되고 회색 톤. 결과 데이터 보존.
- 종료: soft delete. 부모 화면에서 사라지지만 데이터 보존(아카이브).

성공 시 모달 닫힘 + 토스트("캠페인을 삭제했어요" 또는 "캠페인을 즉시 종료했어요").

진행 중 캠페인 삭제 시 연결된 메시지/쿠폰 발송 중단, 자동 활성 큐 제거.

취소·ESC·배경 클릭은 즉시 모달 닫힘 + 변경 없음.

## 5. 권한별 동작

슈퍼관리자·Owner(지점장)·매니저: 삭제 가능.

FC·트레이너·스태프·readonly: 부모 화면 접근 차단.

본사 통합 캠페인 삭제는 슈퍼관리자만. 지점 운영자는 [삭제] 버튼 hidden.

## 6. 데이터 흐름

`DELETE /api/campaigns/:id` 호출.

진행 중 캠페인 삭제 시 연결된 메시지 발송 큐 제거 + 쿠폰 자동 발급 중단.

종료 처리 시 결과 집계 트리거(원래 종료일 도래 전이라도 즉시 집계).

감사 로그 SCR-097 INSERT: actor_id, campaign_id, action(delete 또는 force-end), timestamp.

종료 후 + 90일 자동 아카이브(매일 04:00 배치).

## 7. 예외 처리

권한 부족 → 부모 화면 버튼 hidden + 403.

이미 삭제된 캠페인 → "이미 처리되었습니다" 안내 + 모달 자동 닫힘.

동시 삭제 → last-write-wins 또는 후행 거절.

네트워크 오류 → 자동 재시도 1회.

본사 캠페인 지점 운영자 삭제 시도 → 차단.

## 8. 토스트와 확인 팝업

성공: "캠페인을 삭제했어요" / "캠페인을 즉시 종료했어요" 녹색 5초.

실패: "권한이 없어요" / "이미 처리되었습니다" 빨강 톤.

별도 추가 확인 없이 모달 자체가 최종 확인.

## 10. 디자인 요청사항

대상 캠페인 요약 카드는 강조 톤.

상태별 경고는 색상 톤으로 단계 구분: 준비(기본) / 진행 중(빨강) / 종료(노랑).

액션 버튼 라벨은 상태에 따라 동적 변경: "삭제" / "즉시 종료" / "삭제".

모바일 풀스크린.

## 11. 운영 정책

삭제 정책:
- 준비: hard delete.
- 진행 중: 즉시 종료 + soft delete(결과 보존).
- 종료: soft delete.

진행 중 삭제 시 발송 중단: 연결된 메시지/쿠폰 발송 큐 제거 + 쿠폰 자동 발급 중단.

종료 후 결과 보존: 90일 후 자동 아카이브.

본사 캠페인 삭제: 슈퍼관리자만.

권한: 슈퍼관리자/Owner(지점장)/매니저. FC/트레이너/스태프/readonly 차단.

감사 로그: SCR-097 기록.
