## 2. 다이얼로그 목적과 사용 맥락

알림 트리거 추가 다이얼로그는 SCR-072 자동 알림 설정에 아직 등록되지 않은 운영 이벤트를 트리거 라이브러리에서 골라 새 규칙으로 추가하는 모달입니다. 본사 필수 step 13종 외에 지점이 자체적으로 운영하고 싶은 이벤트(예: 노쇼 발생 알림, 출석 100회 달성 축하, 미수금 발생 안내)를 라이브러리에서 선택해 등록할 수 있습니다.

호출 트리거는 SCR-072의 알림 그룹별 하단 "+ 설정 추가" 버튼입니다. 그룹은 "고객 관련 알림", "상품 관련 알림", "예약/출석 관련 알림" 3개로 나뉘며, 각 그룹의 하단 버튼을 누르면 해당 그룹에 적합한 트리거가 우선 표시됩니다.

본사 필수 정책과 중복되는 트리거는 라이브러리에 추가 불가 상태로 표시되며, 이미 활성화된 트리거도 중복 추가 차단됩니다.

## 3. 다이얼로그 구성

모달 상단에는 "알림 트리거 추가"라는 제목과 우측 닫기(X) 버튼이 있습니다.

검색창이 모달 본문 상단에 큼지막하게 배치됩니다. 트리거명으로 검색하면 트리거 목록이 즉시 필터링됩니다. 디바운스 300ms.

본문은 3분할 레이아웃입니다.

좌측 카테고리 트리: 고객 / 상품 / 예약 / 출석 / 결제 / CRM 6개 그룹이 트리 형태로 배치됩니다. 각 그룹 안에 세부 트리거가 펼쳐집니다. 카테고리 선택 시 해당 카테고리의 트리거만 가운데 목록에 표시됩니다.

가운데 트리거 목록: 선택한 카테고리의 트리거가 카드 형태로 표시됩니다. 예시 트리거: 생일(고객), 장기 미방문(고객), 이용권 만료 D-N(상품), 예약 확정(예약), 예약 취소(예약), 노쇼 발생(예약), 출석 N회 달성(출석), 첫 방문(출석), 미수금 발생(결제), 재등록 대상 편입(CRM). 각 카드에는 트리거명·간단 설명·기본 변수가 한 줄로 요약됩니다. 이미 활성화된 트리거는 회색 톤 + "이미 활성화됨" 배지로 표시되어 클릭 시 중복 경고가 뜹니다. 본사 필수 정책과 중복되는 트리거는 잠금 아이콘 + "본사 정책으로 이미 운영 중" 배지로 표시되며 선택 불가.

우측 설명 패널: 가운데 목록에서 트리거를 선택하면 우측 패널에 상세 설명이 표시됩니다. 발생 조건(예: "회원의 마지막 출석일 + N일 경과"), 발송 시점 추천(기본값 + 권장 값), 사용 가능한 기본 변수({회원명}/{만료일}/{잔여횟수}/{담당FC}), 기본 채널(알림톡 또는 SMS), 본사 정책 중복 여부, 이미 활성화 여부.

모달 하단에는 "추가" 버튼과 "취소" 버튼이 우측 정렬로 배치됩니다. 추가 버튼은 트리거가 선택되어 있고 중복이 아닌 경우에만 활성화됩니다.

## 4. 트리거 추가 흐름과 부모 화면 변화

추가 버튼 클릭 시 선택한 트리거가 지점 규칙으로 INSERT됩니다. 새 규칙은 기본값(권장 채널·기본 시각·기본 메시지 템플릿)으로 생성되고, 초기 상태는 비활성(토글 OFF)으로 설정됩니다.

INSERT 직후 자동으로 DLG-072-001 알림 규칙 편집 다이얼로그로 전환됩니다. 운영자는 곧바로 세부 채널/메시지/시각을 편집한 후 토글 ON으로 활성화할 수 있습니다.

이 자동 전환 흐름은 운영자가 두 번의 모달 호출 없이 한 흐름으로 규칙 추가와 세부 편집을 완료하도록 설계되어 있습니다.

취소 버튼·ESC·배경 클릭은 추가 없이 모달 닫힘.

## 5. 비즈니스 규칙

본사 필수 정책 중복 트리거 차단: 본사 정책 세트로 이미 운영 중인 트리거(만료 D-7/D-3/D-1/D-Day/D+1 등)는 라이브러리에 표시되지만 잠금 상태로 선택 불가. 클릭 시 "이미 본사 정책으로 운영 중입니다. 기존 정책으로 이동" 안내 + SCR-072의 해당 카드로 스크롤 옵션.

동일 지점 중복 활성 차단: 이미 활성화된 트리거가 있으면 "이미 활성화되어 있어요" 중복 경고. 강제로 추가하려면 매니저 이상 권한 + 추가 확인 모달.

권한별 트리거 가시성: 운영자 권한 범위에 따라 일부 트리거가 라이브러리에 표시되지 않습니다. 예를 들어 결제 관련 트리거는 매니저 이상에게만 노출, CRM 관련 트리거는 마케팅 권한자에게만.

## 6. 권한별 동작

슈퍼관리자·본사: 모든 카테고리·모든 트리거 라이브러리 표시. 본사 필수 정책 트리거도 본사 모드로 등록 가능.

센터장·매니저: 지점 운영 카테고리·트리거 표시. 본사 필수 정책 트리거는 잠금 표시.

FC·트레이너·스태프·readonly: 다이얼로그 자체 접근 차단(부모 화면 차단).

## 7. 데이터 흐름과 외부 연동

트리거 라이브러리 조회 `GET /api/auto-alerts/triggers?category=...&search=...`. 응답: 트리거 배열 + 본사 정책 중복 여부 + 이미 활성화 여부.

새 규칙 추가 `POST /api/auto-alerts` (trigger_id, default_settings). 응답: 새 rule_id + 기본 settings.

추가 직후 DLG-072-001을 자동 호출하기 위해 클라이언트에서 후속 모달 전환을 처리합니다.

본사 정책 동기화는 매시간 배치 또는 본사 변경 webhook으로 갱신되어 라이브러리에 즉시 반영됩니다.

신규 규칙 추가는 SCR-097 감사 로그에 INSERT(actor_id, rule_id, action(create), trigger_id, timestamp).

## 8. 예외 처리

본사 필수 정책 중복 → "이미 본사 정책으로 운영 중" 안내 + 기존 정책 이동 옵션.

이미 활성화된 트리거 → "이미 활성화되어 있어요" 중복 경고 + 추가 확인(매니저+ 한정).

권한 부족 트리거 → 라이브러리에 미표시.

검색 결과 0건 → "검색 결과가 없어요" 안내 + 검색어 변경 권유.

네트워크 오류 → 자동 재시도 1회 + 사용자 대기.

새 규칙 추가 실패(500) → 재시도 안내. 모달 유지.

DLG-072-001 자동 전환 실패 → 토스트 "규칙이 추가되었지만 편집 화면 열기 실패. SCR-072에서 직접 편집해주세요" + 모달 닫힘.

## 9. 토스트와 확인 팝업

성공: "새 규칙을 추가했어요" + DLG-072-001로 자동 전환. 별도 토스트 없이 곧바로 편집.

실패: "본사 정책으로 이미 운영 중", "이미 활성화", "권한이 없어요" 빨강 톤.

확인 팝업: 활성화 중복 추가 시 "이미 활성화되어 있어요. 그래도 추가하시겠습니까?" yes/no(매니저+ 한정).

알럿: 권한 없는 직접 접근은 부모 화면에서 차단.

## 11. 디자인 요청사항

3분할 레이아웃(좌측 카테고리 트리 / 가운데 트리거 목록 / 우측 설명 패널)이 모달 본문에 깔끔하게 배치되어야 합니다. 데스크톱 기준 가로 1000px+ 모달.

본사 정책 중복 트리거는 잠금 아이콘 + 어두운 회색 톤으로 시각적으로 명확히 구분.

이미 활성화된 트리거는 회색 톤 + "활성화됨" 배지.

설명 패널은 차분한 톤. 발생 조건·발송 시점·변수·채널이 한 화면에 한눈에 보여야 합니다.

검색창은 모달 상단에 큼지막하게 배치. 자동 포커스로 진입 시 즉시 타이핑 가능.

카테고리 트리의 각 그룹은 아이콘(고객/상품/예약/출석/결제/CRM)으로 시각적 구분.

추가 버튼은 강조 톤. 트리거 선택 + 중복 없음 조건일 때만 활성.

DLG-072-001로 자동 전환되는 흐름은 사용자에게 명확히 인지되어야 합니다(짧은 transition 애니메이션).

모바일에서는 모달 풀스크린 + 3분할이 세로 스택으로 자동 전환.

## 12. 운영 정책

트리거 라이브러리: 본사 정책 트리거 + 지점 운영 트리거 통합 표시.

본사 정책 중복: 본사 필수 정책과 중복되는 트리거는 라이브러리에 추가 불가. 기존 정책으로 이동 안내.

동일 지점 중복: 이미 활성화된 트리거는 중복 추가 차단(매니저+는 강제 추가 가능).

권한별 트리거 가시성: 운영자 권한 범위에 따라 일부 트리거 숨김.

새 규칙 추가 → 비활성 상태로 INSERT + DLG-072-001 자동 전환.

DLG-072-001에서 세부 설정 + 활성화 → 다음 트리거부터 발송 시작.

신규 규칙 추가는 SCR-097 감사 로그 기록.

본사 정책 변경 webhook으로 라이브러리 실시간 갱신.

권한별 가시성: 슈퍼관리자/본사 전 카테고리. 센터장/매니저 지점 운영 카테고리. FC/트레이너/스태프/readonly 차단.

검색 디바운스 300ms. 최소 입력 없음(빈 값이면 전체 표시).

지원 트리거 카테고리: 고객(생일/미방문/등록 감사/첫 방문 환영), 상품(이용권 만료/홀딩 종료/결제 완료/환불 처리/미수금 발생/재등록 쿠폰 동봉), 예약(확정/취소/대기열 승격/노쇼), 출석(N회 달성/첫 방문), 결제(완료/환불), CRM(재등록 대상 편입).
