## 2. 다이얼로그 목적과 사용 맥락

적립 규칙 편집 다이얼로그는 마일리지 자동 적립 기준을 설정하는 모달입니다. 결제 금액 대비 적립률, 특별 이벤트 적립 조건(생일·첫 방문·목표 달성), 마일리지 소멸 정책, 사용 단위 등을 관리자가 직접 설정합니다.

운영 시나리오: 결제 자동 적립률 5% 설정(기본 1%), 생일 5,000점 이벤트 적립 추가, 소멸 정책 12개월 → 24개월 변경(기존 적립분은 기존 정책 유지), 사용 단위 1점=1원 → 1점=10원 변경.

호출 트리거는 SCR-074 페이지 헤더의 "적립 규칙 설정" 버튼. 슈퍼관리자·Owner(지점장)·매니저만 접근 가능.

## 3. 다이얼로그 구성

모달 상단에는 "적립 규칙 편집" 제목과 닫기(X) 버튼.

기본 적립률 영역: 결제 금액 100원당 적립되는 마일리지 포인트를 입력(예: 100원당 1포인트 = 1%). 0~10% 범위. 0% 입력 시 자동 적립 비활성, 10% 초과 시 인라인 에러.

최소 적립 결제 금액 영역: 마일리지 적립이 발생하는 최소 결제 금액(예: 5,000원 이상 결제만 적립). 0원 이상 정수.

특별 적립 조건 영역: 카드 형태로 트리거별 적립 설정.
- 생일 적립: 활성 토글 + 적립 포인트(예: 5,000점)
- 첫 방문 적립: 활성 토글 + 적립 포인트
- 목표 달성 적립(출석 100회·체중 감량 등): 활성 토글 + 적립 포인트
- 재등록 적립: 활성 토글 + 적립 포인트

마일리지 소멸 정책 영역: 마일리지 유효 기간 입력(개월 수). 기본 12개월. 무제한 옵션 토글. 변경 시 적용 시점 표시("변경된 정책은 변경 이후 적립분부터 적용됩니다. 기존 적립분은 기존 정책 유지").

사용 단위 영역: 1점 = N원 입력. 기본 1점=1원. 결제 화면 차감 단위에 반영. 변경 시 회원앱에도 즉시 반영되며 회원에게 알림 권유.

소멸 사전 알림 영역: 소멸 30일 전 회원 알림 토글(MKT-02 연계). 활성/비활성.

본사 통합 정책 영역(슈퍼관리자만): 본사 모드 토글 ON 시 전 지점 일괄 설정. 지점별 별도 설정 차단.

모달 하단에는 "저장" 버튼(강조)과 "취소" 버튼.

## 4. 검증과 저장 흐름

저장 검증 순서:

기본 적립률 0~10% 범위 검증. 외 값 시 인라인 에러.

최소 적립 결제 금액 0원 이상 검증.

특별 적립 포인트 0보다 큰 정수 검증. 0 이하 인라인 에러.

소멸 정책 1개월 이상 또는 무제한 검증.

사용 단위 0보다 큰 정수 검증.

검증 통과 시 `PUT /api/mileage/rules` API → 응답 받아 모달 닫힘 + 부모 화면 갱신 + "적립 규칙을 저장했어요" 토스트.

변경 사항은 다음 결제·이벤트부터 새 규칙 적용. 기존 적립분은 기존 정책 유지(테넌트 설정). 사용 단위 변경은 즉시 반영되며 회원앱에도 동기화.

본사 통합 모드 설정 변경은 슈퍼관리자만 가능하며 전 지점에 즉시 동기화 + 알림 센터 통지.

취소·ESC·배경 클릭은 변경 사항 있으면 "변경 사항이 사라집니다" yes/no 확인.

## 5. 권한별 동작

슈퍼관리자·본사: 본사 통합 정책 토글 활성. 전 지점 일괄 설정 가능.

Owner(지점장)·매니저: 소속 지점 적립 규칙 편집. 본사 통합 정책 토글 비활성.

FC·트레이너·스태프·readonly: 부모 화면 접근 차단.

## 6. 데이터 흐름

적립 규칙 조회 `GET /api/mileage/rules`.

적립 규칙 저장 `PUT /api/mileage/rules` (base_rate, min_amount, event_rules, expiry_months, point_unit, expiry_notice_enabled, hq_managed).

변경 사항은 다음 결제·이벤트부터 적용. 기존 적립분은 기존 정책 유지(테넌트 설정으로 일괄 갱신 옵션 가능).

본사 통합 정책 동기화: 슈퍼관리자 변경 시 전 지점 즉시 적용 + 알림 센터 통지.

회원앱 동기화: 사용 단위 변경 시 회원앱 즉시 반영.

감사 로그 INSERT: actor_id, action(update_rules), old_settings, new_settings, timestamp.

## 7. 예외 처리

기본 적립률 범위 외(0~10%) → 인라인 에러.

최소 적립 결제 금액 0원 미만 → 인라인 에러.

특별 적립 포인트 0 이하 → 인라인 에러.

소멸 정책 0개월 이하 → 인라인 에러.

사용 단위 0 이하 → 인라인 에러.

본사 통합 정책 비권한자 접근 → 토글 비활성(Owner(지점장)/매니저 화면에서는 표시 안 함).

동시 편집 충돌(409) → "다른 운영자가 편집 중" + 새로고침 안내.

네트워크 오류 → 자동 재시도 1회 + 사용자 대기.

본사 vs 지점 충돌 → 본사 정책 우선(슈퍼관리자가 본사 모드로 변경 시 지점 별도 설정 차단).

## 8. 토스트와 확인 팝업

성공: "적립 규칙을 저장했어요" 녹색 5초.

실패: "권한이 없어요" / "다른 운영자가 편집 중" 빨강 톤.

확인 팝업: 변경 사항 있는 모달 닫기 시 yes/no.

본사 통합 정책 토글 ON 시 "전 지점에 일괄 적용됩니다. 진행하시겠습니까?" 추가 확인 모달(슈퍼관리자만).

알럿: 권한 없는 직접 접근은 부모 화면에서 차단.

## 10. 디자인 요청사항

기본 적립률 입력은 슬라이더 + 숫자 입력 동시 지원(0~10% 범위).

특별 적립 조건은 카드형 토글 + 입력 영역으로 트리거별 명확히 구분.

소멸 정책은 개월 수 입력 + 무제한 토글. 변경 시 적용 시점 안내 박스.

사용 단위 입력은 "1점 = N원" 형태로 명확.

본사 통합 정책 토글은 슈퍼관리자에게만 표시. 강조 톤.

저장 버튼은 변경 사항 있을 때 강조 톤.

모바일 풀스크린.

## 11. 운영 정책

결제 자동 적립률: 0~10% 범위(기본 1%). 결제 금액 × 적립률 = 자동 적립.

최소 적립 결제 금액: 0원 이상 정수. 미만 결제는 적립 미발생.

특별 적립 조건: 생일/첫 방문/목표 달성/재등록 트리거별 활성/비활성 + 포인트 설정.

소멸 정책: 기본 12개월(테넌트 설정 변경 가능). FIFO 자동 소멸 매일 04:00 배치.

소멸 사전 알림: 30일 전 회원 알림(MKT-02 연계). 토글로 활성/비활성.

사용 단위: 기본 1점=1원(테넌트 설정). 결제 화면 차감 단위 반영.

변경 사항 적용 시점: 다음 결제·이벤트부터 신규 규칙 적용. 기존 적립분은 기존 정책 유지(테넌트 설정).

본사 통합 정책: 슈퍼관리자가 전 지점 일괄 설정. 지점별 별도 설정 차단.

생일 적립: 회원당 1년 1회 제한.

감사 로그: 적립 규칙 변경 SCR-097 기록.

권한: 슈퍼관리자/Owner(지점장)/매니저 가능. FC/트레이너/스태프/readonly 차단.
