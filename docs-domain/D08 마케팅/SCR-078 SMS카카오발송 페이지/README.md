## 2. 화면 개요와 목적

SMS/카카오 대량 발송 페이지는 대규모 회원(수만 명)에게 SMS / LMS / MMS / 카카오 알림톡을 대량으로 발송하고, 플랫폼에서 제공하는 발송 정보·예상 비용·사용량·실패 처리를 통합 확인하는 화면입니다. 개별 메시지 발송(SCR-071, MKT-01)과 달리 대용량 발송 전용 채널 설정 / 플랫폼 API 기반 예상 비용 확인 / 월별 사용량 현황 그래프 / 외부 API 비용 청구 근거에 특화됩니다.

운영 시나리오: 이벤트 일괄 발송(신년·기념일 등 전체 회원 수만 명 대상), 세그먼트별 대량 발송(VIP/일반/신규 등급, 활성/만료/홀딩, 지역, 가입 기간 다중 조건), 카카오→SMS 자동 폴백, 플랫폼 비용 즉시 반영(단가/과금 정책 변경 시 SCR-071/078/DLG-078-002 즉시 반영), NHN/Toast 외부 API 연동, 분할 처리 + 부분 실패(1만건 단위 분할 자동 재시도 3회), 법정 시간 차단, 수신 거부/휴면 자동 제외, 월별 사용량 그래프.

대량 발송은 비용이 크고 취소가 어렵기 때문에 DLG-078-002 발송 확인 단계에서 최종 검증을 받습니다.

## 3. 진입 경로와 인접 화면

진입 경로: 사이드바 "마케팅 > SMS/카카오 발송", 대시보드의 발송 KPI 카드, SCR-071 메시지 발송에서 "대량 발송으로 전환" 보조 링크.

인접 화면: 메시지 발송(SCR-071), 자동 알림(SCR-072), 센터 설정(SCR-080), 감사 로그(SCR-097), 외부 메시지 플랫폼 콘솔.

## 4. 레이아웃과 UI 구성

페이지 헤더 좌측 "SMS/카카오 대량 발송" 타이틀, 우측 "발송 이력 보기" 탭과 "외부 플랫폼 콘솔" 링크.

채널 현황 카드 4종이 가로 배치됩니다. SMS 발송 건수(이번 달), 카카오 알림톡 건수(이번 달), 이번 달 총 비용(플랫폼 집계 기준), 플랫폼 잔여 캐시(사용 가능).

플랫폼 연동 정보 패널이 채널 현황 카드 아래에 배치됩니다. 연동 플랫폼명, 발신 프로필(SMS 발신 번호 / 카카오 발신 프로필), 승인 템플릿 수(알림톡 사용 가능 템플릿), 최근 메타데이터 동기화 시각.

본문은 발송 작성 영역과 발송 이력 영역 두 가지로 분기됩니다. 탭으로 전환됩니다.

발송 작성 영역: 발송 대상 선택 버튼([발송 대상 선택] → DLG-078-001), 선택된 대상 요약(예상 수신자 수·세부 조건), 메시지 템플릿 선택(사전 등록 또는 직접 작성), 메시지 본문 textarea + 변수 삽입 버튼, 글자수 카운터, 발송 예약(즉시 또는 일시), 발송 채널 라디오(SMS/LMS/MMS/알림톡), 채널 자동 선택 토글(알림톡 우선·SMS 폴백), 예상 비용 카드(플랫폼 API 기준 실시간), "[발송]"(DLG-078-002 호출) 버튼.

MMS 모드일 때는 첨부 이미지 업로드 영역이 추가로 표시되며 최대 300KB 제한.

발송 이력 영역: 발송 일시, 채널 배지, 수신자 수, 성공/실패 건수, 비용, 행 액션([상세]/[재발송]) 컬럼. 행 [상세]는 수신자별 성공/실패 + 사유 패널. 행 [재발송]은 실패 건만/전체 재발송 옵션 모달.

비용 현황 그래프: 월별 발송 건수·비용 추이 시각화. 채널별 분리 라인 차트. 마케팅 예산 관리·회계 정산 근거.

## 5. 대량 발송 분할 처리 메커니즘

대량 발송은 1만건 단위로 분할 처리됩니다. 발송 큐에 등록 후 백엔드에서 1만건씩 나누어 외부 API에 전달.

부분 실패는 자동 재시도 3회(1분/5분/30분 간격). 최종 실패 시 운영자 알림 + 플랫폼 실제 비용 재조회.

NHN/Toast webhook으로 발송 결과 실시간 갱신. 외부 API 응답 지연 시 5분 후 플랫폼 결과 재조회.

외부 API 장애 시 발송 보류 + 큐 대기 + 복구 시 재개.

진행률 표시: 분할 처리 중 화면 상단에 진행률 바(예: "32,000 / 50,000 발송 완료")가 표시되어 운영자가 진행 상황을 확인 가능.

발송 중 사용자 취소 시도: 분할 처리 중에는 이미 발송된 부분은 차감 + 미발송 부분만 취소.

## 6. 버튼·아이콘·링크 액션 전체 정의

채널 현황 카드 4종 클릭 시 해당 통계 상세로 자동 스크롤(비용 그래프).

플랫폼 연동 정보 패널의 "외부 플랫폼 콘솔" 링크는 새 탭으로 NHN Cloud / Kakao Biz 콘솔 열기.

"[발송 대상 선택]" 버튼: DLG-078-001 호출.

메시지 템플릿 선택 드롭다운: 사전 등록 템플릿 또는 "직접 작성" 옵션. 직접 작성 시 textarea 활성.

변수 삽입 버튼({회원명}/{만료일}/{잔여횟수}/{담당FC}): 커서 위치에 변수 삽입.

발송 예약 라디오: 즉시 / 일시 예약. 일시 선택 시 날짜·시각 입력.

채널 라디오: SMS / LMS / MMS / 알림톡. MMS 선택 시 이미지 업로드 영역 표시.

채널 자동 선택 토글: 알림톡 우선·SMS 폴백 정책 활성화.

예상 비용 카드는 채널별 분리 합산. 잔여 캐시 부족 시 빨강 + 발송 비활성.

"[발송]" 버튼: DLG-078-002 호출. 비활성 조건은 수신자 0명·메시지 미입력·잔여 캐시 부족·법정 시간 광고·발신 번호 미인증·MMS 이미지 초과·금지어 포함 중 하나라도 해당.

발송 이력 행 [상세]: 수신자별 결과 패널 슬라이드 인. 실패 사유별 분류 표시.

발송 이력 행 [재발송]: 재발송 옵션 모달(실패 건만/전체) → 발송 작성 영역에 자동 채움.

비용 그래프의 채널 라인 클릭은 그 채널만 필터링.

페이지네이션 컨트롤: 발송 이력 페이지 이동.

## 7. 호출되는 모달 동작

### 7-1. DLG-078-001 발송 대상 선택

본문: 그룹 선택(전체 회원 / 활성 / 만료 / 특정 등급 / 장기 미방문 / 등급별 다중), 추가 조건 필터(성별 / 연령대 / 이용권 유형 / 마지막 방문일 범위 / 지역 시·구 / 가입 기간 30일 이상), 예상 수신자 수 실시간 표시(조건 변경 시 즉시 갱신).

확인 시 선택된 대상이 발송 작성 영역에 적용.

### 7-2. DLG-078-002 발송 확인

본문: 발송 요약(채널 / 수신자 수 / 메시지 내용 미리보기), 플랫폼 연동 정보(발신 프로필 / 승인 템플릿 / 최근 비용 조회 시각), 예상 비용(총합 + 발송 후 플랫폼 잔여 캐시 예상값), 발송 일시(즉시 또는 예약).

플랫폼 잔여 캐시가 부족하거나 비용 조회가 오래된 경우 경고 + 발송 버튼 비활성.

확인 시 발송 큐 등록 + 분할 처리 시작 + 진행률 표시 + 발송 이력 탭 자동 이동.

## 8. 토스트와 확인 팝업과 알럿

성공: "발송이 시작되었어요(N건)", "발송 예약 등록 완료", "발송 완료(성공 N / 실패 M)".

실패: "플랫폼 잔여 캐시 부족", "법정 시간 광고 발송 불가", "발신 번호 인증 필요", "MMS 이미지 크기 초과", "금지어 포함", "외부 API 장애로 발송 보류".

확인 팝업: DLG-078-002 발송 확인 자체가 최종 확인 다이얼로그.

알럿: 권한 없는 계정 접근 시 차단 화면.

운영 알림: 분할 처리 부분 실패 시 알림 센터로 운영자 알림.

## 9. 데이터 흐름과 외부 연동

화면 진입 시 플랫폼 메타데이터 조회 + 채널 현황 통계 조회.

발송 큐 등록 `POST /api/bulk-messages` (recipients, channel, content, schedule).

이력 조회 `GET /api/bulk-messages/history`.

비용 통계 조회 `GET /api/bulk-messages/cost-stats`.

플랫폼 메타 요약 `GET /api/bulk-messages/platform-summary`.

예상 비용 조회 `POST /api/bulk-messages/estimate`.

외부 API webhook(NHN/Toast): 발송 결과 실시간 갱신.

자동 재시도 큐: 1분/5분/30분 3회.

플랫폼 예상 비용 조회: 발송 대상/채널/메시지 변경 시 갱신.

플랫폼 실제 비용 재동기화: 발송 완료 후 실제 비용 보정.

발송 이력 90일 보관: 비용 청구 근거.

카카오→SMS 폴백: 알림톡 실패/비친구 시 정책에 따라 SMS 자동 발송.

플랫폼 메타데이터 갱신: 플랫폼 정책 변경 시 SCR-071/SCR-078/DLG-078-002 즉시 갱신.

분할 처리(1만건 단위): 분할 + 진행률 표시.

예약 발송 큐: cron 분 단위 트리거.

수신 거부/휴면 동기화: 회원 상태 변경 시 다음 발송 자동 제외.

발신 번호 인증 만료 알림: 사전 운영자 알림.

비용 그래프 집계 배치: 매일 04:00 월별 채널별 비용 집계.

회계 청구 매핑: 외부 API 청구서 수신 시 발송 이력과 매핑 + 정산.

외부 API 장애 큐 대기: 다운 시 발송 보류 + 복구 시 재개.

금지어 차단 동기화: 본사 금지어 사전 변경 시 즉시 반영.

발송/예약/메타데이터 재조회/재발송 모두 SCR-097 감사 로그.

## 10. 화면 상태와 예외 처리

상태: 데이터 미연동(목업) / 발송 대기(발송 버튼 활성) / 발송 중(진행률 표시) / 이력 없음(안내).

예외: 플랫폼 잔여 캐시 부족 빨강 경고 + 발송 비활성. 수신자 0명 비활성. 플랫폼 메타데이터 조회 실패 재조회 안내. 알림톡 비친구 자동 SMS 폴백(정책 ON) 또는 자동 제외(OFF). MMS 이미지 300KB+ 차단. 법정 시간 광고 발송 차단(정보성 예외). 수신 거부/휴면 자동 제외. 금지어 포함 차단. 알림톡 미승인 템플릿 SMS 폴백 권유. 분할 처리 부분 실패 자동 재시도 3회 + 최종 실패 알림 + 플랫폼 실제 비용 재조회. 외부 API 응답 지연 "결과 확인 중" + 5분 후 재조회. 예약 시점 잔여 캐시 부족 발송 보류 + 운영자 알림. 플랫폼 단가 변경 후 진행 중 발송은 발송 시점 플랫폼 응답 기준. 발송 중 취소 시도 분할 처리 일부 차감 + 미발송 부분 취소. 외부 API 장애 발송 보류 + 큐 대기 + 복구 시 재개. 카카오→SMS 폴백 OFF 시 비친구는 자동 제외만. 발신 번호 미인증 시스템 설정 이동. 지역·가입 기간 0건 비활성. 변수 데이터 누락 해당 회원 제외 + 사유 기록. 발송 이력 90일 경과 자동 아카이브. 글자수 초과 SMS→LMS 자동 전환 안내, LMS 2000byte 차단.

## 11. 권한별 처리

슈퍼관리자·본사: 전체 + 플랫폼 연동 정보 + 대량 발송·예약·이력 + 연동 상태 점검.

Owner(지점장)·매니저: 전체 채널 + 이력 + 대량 발송·예약.

FC·트레이너·스태프·readonly: 차단.

## 14. 핵심 디자인 요청사항

채널 현황 카드 4종은 가로 그리드. 잔여 캐시 부족은 빨강 강조.

플랫폼 연동 정보 패널은 차분한 회색 톤. "외부 플랫폼 콘솔" 링크는 명확한 강조.

채널 라디오 4종은 각 채널 옆에 예상 비용(플랫폼 API 기준) 작은 숫자.

예상 비용 카드는 채널별 분리 합산 + 발송 후 잔여 캐시 예상값 표시.

분할 처리 진행률 바는 화면 상단에 sticky로 표시. 백분율 + 절대 수량 동시 표시.

비용 그래프는 월별 추이 라인 차트 + 채널별 분리 색상. 호버 시 툴팁.

DLG-078-002 발송 확인 모달은 발송 요약을 가장 크게 표시. 잔여 캐시 부족 또는 비용 조회 오래된 경우 빨강 강조.

발송 이력 결과 배지: 발송 중 노랑, 성공 녹색, 일부 실패 주황, 전체 실패 빨강.

## 15. 운영 정책 (이 화면에 연결된 부분)

채널 4종: SMS / LMS / MMS / 카카오 알림톡. 예상 비용은 플랫폼 API에서 조회.

플랫폼 비용 즉시 반영: 플랫폼 단가/과금 정책 변경 시 SCR-071/078/DLG-078-002 비용 계산 즉시 반영.

플랫폼 단가 변경 후 진행 중 발송: 발송 시점 플랫폼 응답 기준 처리.

카카오→SMS 자동 폴백: 알림톡 비친구/실패 시 SMS 자동 발송(정책 토글). OFF 시 비친구 자동 제외.

분할 처리: 대량 발송 시 1만건 단위로 분할. 부분 실패 자동 재시도 3회.

자동 재시도: 1분/5분/30분 간격 3회. 최종 실패 시 운영자 알림 + 플랫폼 실제 비용 재조회.

외부 API webhook: NHN/Toast 발송 결과 webhook으로 실시간 갱신.

발송 이력 90일 보관: 비용 청구 근거. 90일 경과 시 자동 아카이브.

플랫폼 잔여 캐시 부족 차단: 발송 시점 캐시 < 예상 비용 시 차단 + 외부 플랫폼 충전 CTA.

법정 시간 차단: 영업/광고성 발송 21~08시 차단(정보통신망법). 정보성(결제·환불) 예외.

수신 거부/휴면 자동 제외: 모든 대량 발송에 자동 적용.

금지어 차단: 도박·대출·성인 등 사전 등록 금지어 포함 시 차단.

알림톡 사전 승인: 카카오 정책에 따라 사전 승인 템플릿만 발송. 미승인 시 SMS 폴백 또는 차단.

글자수 정책: SMS 90byte(한글 45자) → LMS 2000byte 자동 전환 / 알림톡 1000자.

MMS 첨부 이미지: 최대 300KB. 초과 시 차단.

발신 번호 인증: 사전 인증된 번호만 발신.

발송 대상 조건: 회원 등급(VIP/일반/신규) / 이용권 상태(활성/만료/홀딩) / 지역(시·구) / 가입 기간(기본 30일 이상). 다중 조합.

메시지 템플릿: 사전 등록 템플릿 또는 직접 작성. 변수 삽입 지원.

권한별 가시성: 슈퍼관리자 전체 + 플랫폼 연동 정보. Owner(지점장)·매니저 소속 지점 + 대량 발송·예약·이력. FC·트레이너·스태프·readonly 차단.

발송 결과 카운트: 성공·실패·미수신 분리 집계.

비용 그래프: 월별 채널별 발송 비용 추이.

플랫폼 비용 재동기화: 발송 완료 후 플랫폼 사용량 API로 실제 비용 재동기화.

회계 청구 매핑: 외부 API 청구서와 발송 이력 매핑. 정산 근거.

감사 로그: 발송 / 예약 / 재조회 / 재발송 모두 SCR-097 기록.
