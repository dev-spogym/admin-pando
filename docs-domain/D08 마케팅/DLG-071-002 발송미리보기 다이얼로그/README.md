## 2. 다이얼로그 목적과 사용 맥락

발송 미리보기 다이얼로그는 메시지를 실제로 발송하기 전에 수신자 화면에서 어떻게 보이는지 미리 확인하는 모달입니다. 변수(회원명·만료일·잔여횟수·담당FC)가 실제 값으로 치환된 최종 메시지 형태를 검토해 오발송을 방지합니다. 매니저는 대량 메시지를 보내기 전 마지막 검증으로, FC는 1:1 메시지의 톤을 점검하는 용도로 사용합니다.

호출 트리거는 SCR-071의 메시지 작성 영역 하단 "미리보기" 버튼 클릭입니다. 메시지 본문이 비어있거나 수신자가 없으면 미리보기 버튼이 비활성화되어 다이얼로그가 호출되지 않습니다.

## 3. 다이얼로그 구성

모달 상단에는 "발송 미리보기"라는 제목과 우측 닫기(X) 버튼이 있습니다.

채널별 미리보기 탭이 모달 본문 상단에 가로로 배치됩니다. 선택한 채널에 따라 알림톡 / SMS / 앱 푸시 탭이 표시되며, 채널 자동 선택 토글이 활성화된 경우(알림톡 우선·SMS 폴백) 알림톡 탭과 SMS 탭이 모두 노출되어 친구·비친구 각각의 메시지 형태를 동시에 확인할 수 있습니다.

알림톡 탭의 본문은 카카오톡 채팅창 모양의 UI로 표시됩니다. 발신 프로필 이름과 프로필 이미지가 상단에 있고, 메시지 말풍선 안에 변수가 치환된 본문이 들어갑니다. 가능하다면 카카오톡 실제 미리보기 모양과 유사하게 디자인되어 운영자가 회원이 받을 화면을 사실감 있게 인지할 수 있어야 합니다.

SMS 탭의 본문은 기본 문자 메시지 모양으로 표시됩니다. 발신 번호가 상단에 표시되고 본문은 일반 텍스트로 노출됩니다. LMS 전환된 경우 "LMS 메시지" 배지가 추가됩니다.

앱 푸시 탭의 본문은 모바일 푸시 알림 카드 모양입니다. 앱 아이콘과 앱 이름이 상단에 있고 메시지 제목과 본문이 카드 형태로 표시됩니다.

발송 대상 요약 영역이 미리보기 탭 아래에 배치됩니다. 수신자 수, 선택된 채널, 가족 묶음 옵션 활성 여부, 알림톡 비친구·앱 미설치·변수 데이터 누락으로 제외된 수신자 수가 한 줄로 요약됩니다(예: "총 234명 / 알림톡 187명 + SMS 폴백 47명 / 제외 12명").

플랫폼 발송 정보 카드가 다음 영역에 표시됩니다. 사용될 발신 프로필(SMS 발신 번호 또는 카카오 발신 프로필), 사용될 승인 템플릿(알림톡인 경우), 최근 비용 조회 시각이 표시됩니다.

예상 비용 카드는 모달 본문 하단에 배치됩니다. 수신자 수와 채널 기준으로 계산된 예상 발송 비용이 플랫폼 API 응답값으로 표시되며, 채널별 분리 합산 형태(예: "알림톡 187건 × 4.2원 = 785원 + SMS 47건 × 22원 = 1,034원 = 합계 1,819원")로 노출됩니다.

모달 하단 좌측에는 "수정" 버튼이 배치되어 미리보기를 닫고 SCR-071의 메시지 작성 영역으로 돌아갑니다. 우측에는 "발송" 버튼이 강조 톤으로 배치되어 미리보기를 확인하고 즉시 발송할 수 있게 합니다.

## 4. 미리보기 데이터와 변수 치환

미리보기에 표시되는 본문은 첫 번째 수신자의 데이터로 변수가 치환된 형태입니다. {회원명}, {만료일}, {잔여횟수}, {담당FC} 4종 변수가 실제 값으로 대체되어 운영자가 회원이 받을 실제 메시지를 정확히 확인할 수 있습니다.

여러 수신자 중 첫 번째 수신자를 자동으로 선택하지만, 다른 수신자의 미리보기도 볼 수 있도록 미리보기 영역 위에 작은 드롭다운("미리보기 대상: 회원A / 회원B / ...")이 제공되어 다른 수신자의 치환 결과로 전환할 수 있습니다.

변수 데이터 누락 수신자는 자동으로 제외되며, 발송 대상 요약에 "데이터 누락 N명 제외"로 표시됩니다. 누락 사유는 미리보기 하단에 작은 정보 박스로 표시됩니다(예: "{담당FC} 데이터 누락 12명: 담당 FC가 배정되지 않은 회원입니다").

알림톡 미승인 템플릿을 사용 중인 경우 미리보기 영역에 빨강 톤 경고 "이 메시지는 사전 승인 템플릿이 아닙니다. SMS로 폴백하거나 템플릿 승인 후 발송해주세요"가 표시되며 발송 버튼이 비활성화됩니다.

법정 시간(21:00~08:00) 영업/광고 발송 시도 시 노랑 톤 경고 "야간 광고성 메시지 발송 불가" + 예약 시각 변경 안내가 표시됩니다. 정보성 메시지는 예외.

## 5. 발송 흐름과 부모 화면 변화

"발송" 버튼 클릭 시 모달이 로딩 상태로 전환되고 즉시 발송 큐가 등록됩니다. 화면은 모달이 닫히면서 부모 화면(SCR-071)의 "발송 이력" 탭으로 자동 이동되며, 우측 상단에 "발송이 시작되었어요" 토스트가 표시됩니다.

발송 결과는 외부 플랫폼 webhook 또는 결과 조회 API로 실시간 갱신되어 발송 이력 행의 결과 배지가 자동 업데이트됩니다. 발송 중 노랑, 성공 녹색, 일부 실패 주황, 전체 실패 빨강.

"수정" 버튼 클릭 시 모달이 닫히고 SCR-071의 메시지 작성 영역으로 돌아갑니다. 입력값은 모두 유지됩니다.

취소·ESC·배경 클릭은 수정 버튼과 동일하게 미리보기를 닫고 작성 영역으로 돌아갑니다(별도 확인 없이).

## 6. 권한별 동작

이 다이얼로그는 부모 화면(SCR-071)에서 접근 가능한 모든 권한자가 사용할 수 있습니다. 발신 설정 변경 권한은 부모 화면에서 이미 검증되었으므로 미리보기 다이얼로그에서는 추가 권한 체크가 없습니다.

9역할 영문 키워드 기준 권한 매트릭스는 다음과 같습니다.

- 슈퍼관리자(`superAdmin`) · 본사 최고관리자(`primary`): 전 지점 수신자에 대해 미리보기 + 발송 가능. 본사 통합 모드에서 점주 그룹·전 지점 일괄 발송도 미리보기로 검증.
- Owner(지점장)(`owner`) · 매니저(`manager`): 소속 지점 회원·리드에 대해 미리보기 + 발송 가능.
- FC(`fc`): 본인 담당 회원에게만 미리보기 + 발송 가능. 부모 화면(SCR-071)의 수신자 검색에서 이미 RLS로 본인 담당만 결과로 노출되므로 미리보기 단계에서 추가 차단은 일어나지 않습니다.
- 트레이너(`trainer`) · 스태프(`staff`) · 읽기 전용(`readonly`): 부모 화면 접근 자체가 차단되어 미리보기 다이얼로그까지 도달하지 못합니다.
- 프런트(`front`): 마케팅 도메인 일반 접근은 차단되며 부모 화면 진입 시점에 hidden 처리됩니다.

권한 없는 계정의 직접 호출은 부모 화면 접근 차단으로 자동으로 막힙니다.

## 7. 데이터 흐름과 외부 연동

미리보기 다이얼로그 호출 시점에 첫 번째 수신자의 회원 데이터를 사용해 변수 치환이 수행됩니다(클라이언트 측 또는 백엔드 `GET /api/messages/preview` API).

예상 비용은 부모 화면에서 이미 조회된 값을 그대로 사용하지만, 미리보기 다이얼로그가 열린 시점에 1초 이내로 최신 값을 한 번 더 재조회합니다(`GET /api/messages/cost-estimate`). 변동 시 새 비용으로 갱신.

알림톡 템플릿 승인 상태는 플랫폼 API에서 조회되어 미승인 시 경고가 표시됩니다.

발송 버튼 클릭 시 `POST /api/messages`로 발송 큐 등록 + 부모 화면으로 결과 반영.

플랫폼 webhook 응답은 부모 화면(발송 이력 탭)에서 처리되며 이 다이얼로그는 닫혀 있습니다.

감사 로그는 발송 시점에 부모 화면에서 기록됩니다(이 다이얼로그 자체는 기록 액션이 없음).

## 8. 예외 처리

변수 데이터 누락 수신자 → 자동 제외 + 안내 박스 표시.

알림톡 미승인 템플릿 → 빨강 경고 + 발송 버튼 비활성.

법정 시간 영업/광고 발송 → 노랑 경고 + 발송 버튼 비활성(정보성 예외).

플랫폼 잔여 캐시 부족 → 미리보기 단계에서 빨강 경고 + 발송 버튼 비활성 + 외부 콘솔 충전 안내.

비용 조회 실패 → "비용을 불러오지 못했어요, 다시 시도해주세요" + 새로고침 버튼.

발신 번호 미인증 → "발신 번호 인증 필요" 경고 + 시스템 설정 이동 안내.

수신자 0명(필터 결과 모두 자동 제외 후) → "발송 가능한 수신자가 없어요, 조건을 변경해주세요" + 발송 버튼 비활성.

알림톡 비친구 정책 미설정 → 폴백 정책에 따라 SMS 자동 폴백 안내 또는 비친구 자동 제외 안내.

발송 큐 등록 실패(5xx) → 자동 재시도 1회 + 실패 시 토스트 + 모달 유지(사용자 다시 시도 가능).

## 9. 토스트와 확인 팝업

성공: "발송이 시작되었어요"가 부모 화면에서 표시됨(모달 자체는 토스트 없음).

실패: "발송 큐 등록 실패, 다시 시도해주세요" 등 빨강 토스트.

확인 팝업: 없음. 미리보기 자체가 검토 단계이므로 추가 확인 없이 [발송] 클릭이 곧 실행.

알럿: 권한 없는 직접 접근은 부모 화면에서 차단.

## 11. 디자인 요청사항

채널별 미리보기는 실제 수신 화면과 최대한 유사해야 합니다. 알림톡은 카카오톡 채팅창 모양, SMS는 기본 문자 모양, 앱 푸시는 모바일 푸시 카드 모양으로 운영자가 회원 입장에서 메시지를 시각화 할 수 있어야 합니다.

미리보기 대상 드롭다운은 작지만 명확하게 보여서 다른 수신자의 치환 결과로 빠르게 전환 가능해야 합니다.

발송 대상 요약은 한 줄에 핵심 정보(총 수신자·채널별 분배·제외 수)가 모두 들어가야 합니다.

플랫폼 발송 정보 카드는 차분한 회색 톤으로 본문 검토에 방해되지 않게.

예상 비용은 채널별 분리 합산이 시각적으로 명확히 보여야 합니다. 비용이 큰 경우 강조 톤으로 운영자가 인지하게 합니다.

경고 메시지(미승인 템플릿/법정 시간/잔여 캐시/발신 미인증)는 색상 톤으로 즉시 인지 가능해야 합니다.

발송 버튼은 강조 톤(녹색 또는 강조 색)으로 검토 후 즉시 실행 가능하다는 느낌을 줍니다.

수정 버튼은 회색 톤으로 작성 영역 복귀를 명확히 합니다.

모바일에서는 모달이 풀스크린으로 자동 전환되고 채널별 탭이 좌우 스와이프로 전환 가능.

## 12. 운영 정책

변수 치환: {회원명}/{만료일}/{잔여횟수}/{담당FC} 4종. 첫 번째 수신자 기준 미리보기.

미리보기 대상 변경: 작은 드롭다운으로 다른 수신자로 전환 가능.

변수 데이터 누락 수신자: 자동 제외 + 안내 박스.

알림톡 미승인 템플릿: 빨강 경고 + 발송 비활성.

법정 시간(21~08시) 광고: 노랑 경고 + 발송 비활성. 정보성 예외.

플랫폼 잔여 캐시 부족: 빨강 경고 + 발송 비활성 + 외부 콘솔 충전 안내.

발신 번호 미인증: 경고 + 발송 비활성 + 시스템 설정 이동.

수신자 0명: 안내 + 발송 비활성.

수신 거부/휴면 자동 제외(부모 화면에서 사전 처리).

비용 조회 실패 시 새로고침 가능.

발송 큐 등록 실패 시 자동 재시도 1회 + 실패 시 토스트 + 모달 유지.

권한: 부모 화면에서 이미 검증. 다이얼로그 자체 추가 권한 체크 없음.

가족 묶음 발송 옵션 활성 시 발송 대상 요약에 "가족 묶음 적용" 표시.

발송 시점 부모 화면 발송 이력 탭으로 자동 이동 + webhook 결과 실시간 갱신.

감사 로그는 부모 화면에서 기록(이 다이얼로그 자체는 기록 없음).
