## 2. 화면 개요와 목적

옷 락커 운영 관리 페이지는 출석과 연동되는 당일용 옷 락커를 실시간으로 운영하는 D11 통합운영 도메인의 운영 관리 화면입니다. 락커 그리드에서 사용 현황을 한눈에 파악하고, 출석 완료 후 미배정 상태인 회원에게 락커를 배정하거나, 사용 종료된 락커를 회수하거나, 고장·청소가 필요한 락커를 점검 상태로 전환하는 운영을 한 화면에서 처리합니다. 본 화면이 다루는 옷 락커는 출석 기반의 당일용 락커이며, 상품 계약 기반의 장기 배정 락커는 별도 화면(SCR-I005 고정 물품 락커 관리)에서 다룹니다.

이 화면이 다루는 운영 흐름은 매우 다양합니다. 평일 06:00 ~ 09:00 / 18:00 ~ 22:00 러시아워에 출석이 폭주하면서 미배정 락커 수가 누적되고, "미배정 대기" 카드가 강조되면 운영자가 패널을 열어 회원별로 DLG-I002로 빠르게 배정합니다. 키오스크 설정 SCR-I002의 락커 후처리 정책이 "자동 배정 시도"로 켜져 있으면 출석 직후 시스템이 자동 배정 존에서 빈 락커를 골라 자동 배정하고, 본 화면 그리드에는 "자동배정(번호)"로 즉시 반영됩니다. 마감 시간 임박 시 반납 지연 락커가 다수 누적되면 운영자가 "일괄 해제" 버튼으로 만료·반납 지연 락커를 한 번에 회수합니다. 고장이 발생한 락커는 운영자가 "고장 처리"로 점검 상태로 전환하고 정비 완료 후 "복구"로 정상 복귀시킵니다. 회원이 SCR-I001 통합 출석 관리에서 락커 배정 버튼을 누르면 본 화면을 거치지 않고 DLG-I002가 직접 호출되어 흐름이 끊기지 않게 합니다.

따라서 이 화면은 단순한 락커 그리드가 아니라, 키오스크 자동 배정 정책(SCR-I002 락커 후처리 탭) · 출석 미배정 회원 흐름(SCR-I001) · 락커 일괄 회수 · 고장·복구 라이프사이클 · 본사 통합 모드 운영까지 모두 반영된 락커 운영 허브로 동작해야 합니다.

## 3. 진입 경로와 인접 화면

옷 락커 운영 관리 페이지에 진입하는 경로는 여러 가지입니다.

첫 번째 경로는 사이드바입니다. 좌측 사이드바의 "통합운영" 메뉴 아래 "옷 락커 운영 관리" 항목을 클릭하면 진입하며, 기본 상태(필터 없음·상태 = 전체)로 시작합니다.

두 번째 경로는 SCR-I001 통합 출석 관리의 "미배정 락커" 통계 카드 클릭으로, 통합 출석 관리 화면에 머무르면서 미배정 패널이 열리는 흐름이 기본이지만, 그 패널 헤더의 "옷 락커 운영 관리로 이동" 링크를 누르면 본 화면으로 전환되면서 미배정 회원 패널이 열린 상태로 진입합니다.

세 번째 경로는 알림 센터(SCR-104)의 운영 알림 클릭입니다. "미배정 락커 임계 초과(10명 이상)"·"반납 지연 락커 다수 발생" 같은 알림이 떴을 때 클릭하면 해당 상태 필터가 적용된 상태로 진입합니다.

네 번째 경로는 대시보드 SCR-101의 시설 운영 카드 영역에서 락커 관련 카드를 클릭한 경우로, 본 화면이 새 탭으로 열리거나 같은 탭으로 이동합니다.

다섯 번째 경로는 SCR-I002 키오스크 설정의 락커 후처리 탭에서 "자동 배정 존 미리보기" 링크를 누른 경우로, 자동 배정 존에 속한 락커만 강조 표시된 상태로 진입합니다.

이 화면에서 빠져나가는 인접 화면으로는, 미배정 회원 패널의 회원명 클릭으로 진입하는 SCR-M004 회원 상세, 락커 후처리 정책 변경이 필요할 때 이동하는 SCR-I002 키오스크 설정, 고정 락커 운영으로 전환할 때 이동하는 SCR-I005 고정 물품 락커 관리, 일괄 해제 이력을 추적할 때 이동하는 SCR-097 감사 로그가 있습니다.

## 4. 레이아웃과 UI 구성

옷 락커 운영 관리 페이지는 상단 통계 카드 + 메인 락커 그리드 + 우측 미배정 회원 패널의 3단 레이아웃을 기본으로 합니다.

페이지 헤더 좌측에는 "옷 락커 운영 관리"라는 타이틀과 지점 컨텍스트 배지가 표시됩니다. 본사 통합 모드에서는 지점 선택 드롭다운이 활성화되어 다른 지점의 락커 현황을 조회할 수 있지만 변경 액션은 차단됩니다.

페이지 헤더 우측에는 "미배정 회원 보기", "일괄 해제" 두 버튼이 배치됩니다. "미배정 회원 보기" 토글은 우측 패널의 펼침·접힘을 제어하고, "일괄 해제" 버튼은 만료·반납 지연 락커를 한 번에 회수하는 액션입니다.

페이지 헤더 바로 아래에는 상단 통계 카드 4개가 가로로 배치됩니다. 첫 번째 카드는 "전체 락커 수"로 지점에 등록된 옷 락커 총 수량을 보여줍니다. 두 번째 카드는 "사용 중"으로 현재 배정된 락커 수를 보여주며, 클릭 시 상태 필터가 "사용 중"으로 적용됩니다. 세 번째 카드는 "미배정 대기"로 출석 완료 + 락커 미배정 인원 수를 보여주며, 클릭 시 우측 패널이 자동으로 펼쳐지고 강조 표시됩니다. 미배정 대기가 0이 아닐 때는 카드 자체가 주황 톤으로 약하게 강조됩니다. 네 번째 카드는 "점검 중"으로 고장·청소 처리된 락커 수를 보여주며, 클릭 시 상태 필터가 "점검 중"으로 적용됩니다.

통계 카드 아래에는 필터 바가 있습니다. 상태 필터(전체·빈 락커·사용 중·만료 임박·반납 지연·점검 중) 드롭다운, 락커 존 필터(전체·A존·B존·...) 드롭다운, 검색창(락커 번호·회원명)이 가로로 배치됩니다.

필터 바 아래에 메인 영역인 락커 그리드가 있습니다. 락커는 번호 순서로 격자 형태로 배치되며, 한 칸이 한 락커를 나타냅니다. 각 락커 칸에는 락커 번호와 상태 색상이 표시되고, 사용 중인 락커는 배정 회원의 이니셜 또는 짧은 이름이 작게 함께 표시됩니다.

락커 상태별 색상은 빈 락커(회색 빈 칸)·사용 중(녹색)·만료 임박(주황)·반납 지연(빨강)·점검 중(노랑+점검 아이콘)의 5종으로 분기됩니다. 색맹 운영자를 고려해 사용 중·점검 중에는 작은 아이콘이 색상과 함께 표시됩니다. 자동 배정 존에 속한 락커는 칸 좌측 상단에 작은 별표 아이콘이 표시되어 정책 영향을 받는 락커임을 알려줍니다.

락커 칸을 클릭하면 작은 정보 팝업이 락커 칸 옆에 펼쳐집니다. 빈 락커 클릭 시에는 "이 락커를 미배정 회원에게 배정하시겠습니까?" 안내와 회원 선택 드롭다운이 표시됩니다. 사용 중 락커 클릭 시에는 배정 회원 정보(이름·회원번호·출석 시각·회원권 유형)와 "회수"·"고장 처리" 버튼이 표시됩니다. 점검 중 락커 클릭 시에는 점검 사유·점검 시작 시각·"복구" 버튼이 표시됩니다.

화면 우측에는 미배정 회원 패널이 있습니다. 평소에는 접혀 있고, 헤더의 "미배정 회원 보기" 토글이나 "미배정 대기" 통계 카드를 누르면 슬라이드 인으로 펼쳐집니다. 패널 본문에는 출석 완료 + 옷 락커 미배정 회원 목록이 카드형 리스트로 표시되며, 각 카드에는 회원명, 출석 시각, 회원권 유형(일반·VIP 등), 고정 락커 보유 여부, "배정" 버튼이 표시됩니다. "배정" 버튼을 누르면 DLG-I002 옷락커배정 다이얼로그가 열립니다.

패널 상단에는 미배정 회원 수가 큰 글씨로 표시되어 운영자가 즉시 인지할 수 있게 합니다. 미배정 회원 수가 임계(예: 10명) 이상이면 패널 헤더가 주황 톤으로 강조됩니다.

## 5. 탭 구성과 탭별 동작

이 화면은 별도 탭이 없는 단일 그리드 뷰입니다. 대신 통계 카드 클릭과 필터 칩 조합으로 데이터를 좁혀 들어가는 방식을 사용합니다.

상태 필터는 6종(전체·빈 락커·사용 중·만료 임박·반납 지연·점검 중)이며, 운영자가 필터를 바꾸면 그리드에서 해당 상태에 속하지 않는 락커가 회색 톤으로 약하게 처리되어 시야에서 분리됩니다. 락커가 사라지지 않고 단지 시각적으로 분리되는 이유는 운영자가 락커 번호 위치를 기억하고 있기 때문에, 필터 적용으로 락커가 사라지면 공간 감각을 잃기 때문입니다.

존 필터는 락커 존(예: A존·B존·C존)을 선택해 그 존에 속한 락커만 강조합니다. 자동 배정 존(SCR-I002 락커 후처리 탭에서 정한)에 속한 락커는 별도 표시가 되어 운영자가 자동 배정 정책의 범위를 즉시 확인할 수 있습니다.

검색은 락커 번호 또는 회원명으로 검색하며, 결과가 있는 락커는 강조 표시되고 화면이 자동으로 해당 락커 위치로 스크롤됩니다.

## 6. 버튼·아이콘·링크 액션 전체 정의

이 화면의 모든 클릭 가능한 요소를 빠짐없이 정의합니다.

상단 통계 카드 4개는 모두 클릭 가능합니다. "사용 중", "점검 중" 카드는 상태 필터를 자동 적용하고, "미배정 대기" 카드는 우측 패널을 자동으로 펼치며, "전체 락커 수" 카드는 모든 필터를 초기화합니다.

페이지 헤더의 "미배정 회원 보기" 토글은 우측 패널을 펼치거나 접습니다.

페이지 헤더의 "일괄 해제" 버튼은 owner 이상에서만 활성화되며(매니저는 관리자 승인 필요), 누르면 "일괄 해제 대상 락커" 확인 모달이 뜹니다. 모달에는 만료(당일 마감 시간 도래)·반납 지연(퇴실 후 미반납) 상태인 락커 목록이 표시되고, 운영자가 확인하면 일괄 회수가 실행됩니다. 처리 결과는 결과 카드와 성공 토스트로 표시됩니다.

락커 그리드의 락커 칸을 클릭하면 작은 정보 팝업이 락커 옆에 펼쳐집니다. 빈 락커의 팝업은 "이 락커에 배정할 회원" 드롭다운(미배정 회원 목록)과 "배정" 버튼을 제공하며, "배정" 버튼을 누르면 DLG-I002가 호출됩니다.

사용 중 락커의 팝업은 배정 회원 정보와 "회수" / "고장 처리" / "회원 상세 이동" 세 버튼을 제공합니다. "회수" 버튼은 확인 모달 후 회원 연결을 제거하고 빈 락커로 전환합니다. "고장 처리" 버튼은 점검 사유 입력 모달을 띄운 뒤 점검 상태로 전환합니다. "회원 상세 이동"은 SCR-M004로 이동합니다.

점검 중 락커의 팝업은 점검 사유·점검 시작 시각·점검 담당자와 "복구" 버튼을 제공합니다. "복구" 버튼은 확인 모달 후 점검 상태를 해제하고 빈 락커로 전환합니다.

미배정 회원 패널의 각 회원 카드는 "배정" 버튼을 클릭하면 DLG-I002 옷락커배정 다이얼로그가 열립니다. 회원명을 클릭하면 SCR-M004 회원 상세로 이동합니다.

모든 변경 액션(배정·회수·고장 처리·복구·일괄 해제)은 클릭 후 응답이 돌아오기 전까지 자동으로 비활성화되어 더블클릭이 차단됩니다. 락커 그리드는 WebSocket으로 실시간 동기화되어, 다른 운영자가 같은 락커에 동시 변경을 시도하면 후행 요청이 optimistic lock 위반으로 거부되고 "다른 운영자가 동시에 변경했어요" 안내가 표시됩니다.

## 7. 호출되는 모달 동작

이 화면에서 호출되는 모달은 DLG-I002 옷락커배정 다이얼로그와 내부 확인 모달들입니다.

### 7-1. DLG-I002 옷 락커 배정 다이얼로그

옷 락커 배정 다이얼로그는 미배정 회원 패널의 "배정" 버튼이나 빈 락커 칸의 "배정" 버튼으로 호출됩니다. 모달 상단에는 "옷 락커 배정" 제목과 함께 대상 회원의 정보가 읽기 전용으로 표시됩니다. 회원명, 출석 시각, 회원권 유형, 고정 락커 보유 번호(있는 경우)가 한 줄로 노출됩니다.

본문에는 빈 락커 목록이 번호 순으로 그리드 형태로 표시됩니다. 빈 락커는 선택 가능, 사용 중 락커는 회색 처리되어 선택 불가, 점검 중 락커는 경고 색상으로 선택 불가 상태입니다. 운영자가 락커 번호를 클릭하면 선택 상태가 강조되고 하단의 "배정" 버튼이 활성화됩니다.

진입 경로에 따라 모달 동작이 약간 다릅니다. 미배정 회원 패널에서 진입한 경우 회원이 먼저 결정되어 있어 빈 락커만 고르면 됩니다. 빈 락커 칸에서 진입한 경우 락커가 먼저 결정되어 있어 모달에 미배정 회원 드롭다운이 추가로 표시되어 회원을 골라야 합니다.

확인을 누르면 모달이 로딩 상태가 되고 백엔드에 배정 요청이 전송됩니다. 성공하면 모달이 닫히고 본 화면의 락커 그리드가 즉시 갱신되어 해당 락커가 "사용 중"으로 전환되며, 미배정 회원 패널에서 해당 회원이 제거됩니다. SCR-I001 통합 출석 관리의 옷 락커 컬럼도 실시간 동기화되어 "수동배정(번호)"로 즉시 갱신됩니다.

빈 락커가 0개인 경우 모달 본문에 "배정 가능한 락커가 없습니다" 안내가 표시되며 "배정" 버튼이 비활성화됩니다.

권한 분기는 owner·manager·staff에서 락커 배정 가능, 강사·readonly는 진입 불가입니다.

### 7-2. 회수 확인 모달

회수 확인 모달은 사용 중 락커의 "회수" 버튼으로 호출됩니다. 모달 상단에 "이 락커를 회수하시겠습니까?" 제목과 함께 대상 락커 번호, 배정 회원명, 출석 시각이 표시됩니다. 회원의 출석 결과가 아직 "성공·미퇴실"이면 추가 안내 "회원이 아직 퇴실하지 않았습니다. 회수하면 락커 연결이 끊깁니다"가 노랑 톤으로 표시됩니다.

확인 시 회원 연결이 제거되고 락커가 "빈 락커" 상태로 전환됩니다. 회수 이력은 감사 로그에 기록됩니다. 취소 시 모달이 닫히고 변경이 일어나지 않습니다.

### 7-3. 고장 처리 모달

고장 처리 모달은 사용 중 또는 빈 락커의 "고장 처리" 버튼으로 호출됩니다. 모달에는 대상 락커 번호, 점검 사유 입력란(필수, 선택지: 고장·청소·기타·직접 입력), 점검 예상 완료 시각(선택) 입력란이 표시됩니다.

확인 시 락커가 "점검 중" 상태로 전환되고, 사용 중이던 락커였다면 회원 연결도 함께 제거됩니다. 점검 사유와 점검 담당자(현재 운영자)가 함께 저장되며 감사 로그에 기록됩니다.

### 7-4. 복구 모달

복구 모달은 점검 중 락커의 "복구" 버튼으로 호출됩니다. 모달에는 대상 락커 번호, 점검 사유, 점검 시작 시각, 복구 사유 입력란(선택)이 표시됩니다.

확인 시 락커가 "빈 락커" 상태로 전환되고, 복구 이력이 감사 로그에 기록됩니다.

### 7-5. 일괄 해제 모달

일괄 해제 모달은 헤더의 "일괄 해제" 버튼으로 호출됩니다. 모달 상단에 "일괄 해제 대상 락커" 제목과 함께 만료(당일 마감 시간 도래)·반납 지연(퇴실 후 미반납) 상태인 락커 목록이 카드형으로 표시됩니다. 각 카드에는 락커 번호, 배정 회원명, 출석 시각, 현재 상태가 표시되며, 운영자가 개별 해제하지 않을 락커는 체크박스로 제외할 수 있습니다.

확인 시 선택된 락커들이 일괄 회수되며, 결과 카드가 화면 중앙 하단에 머무릅니다. "성공 N건 / 실패 M건"이 표시되고 실패 사유가 카드별로 노출됩니다. owner 이상 권한이 필요하며 매니저는 관리자 승인을 거쳐야 합니다.

## 8. 토스트와 확인 팝업과 알럿

옷 락커 운영 관리 페이지에서 발생하는 모든 알림성 UI는 다음 패턴으로 동작합니다.

성공 토스트는 우측 상단에 녹색 계열로 5초간 표시되며, "락커가 배정되었습니다", "락커가 회수되었습니다", "락커가 점검 상태로 전환되었습니다", "락커가 정상 복구되었습니다", "N개 락커를 일괄 회수했어요" 같은 문구로 결과를 알려줍니다.

실패 토스트는 빨강 계열로 표시되며, "배정 가능한 락커가 없습니다", "이미 다른 운영자가 변경했어요", "회원이 락커 대상이 아닙니다", "권한이 없어요", "락커 상태가 변경되었습니다. 새로고침 후 다시 시도해주세요" 같은 문구가 표시됩니다.

경고 토스트는 노랑 계열로, "회원이 아직 퇴실하지 않았습니다. 회수하면 락커 연결이 끊깁니다" 같은 안내를 모달 내에서 표시합니다.

부분 결과 알림은 일괄 해제 작업 완료 시 결과 카드 형태로 화면 중앙 하단에 머무릅니다. "성공 N건 / 실패 M건"이 표시되고, 실패 락커별 사유(예: optimistic lock 위반·회원이 이미 다른 락커 사용 중)가 함께 노출됩니다.

확인 팝업은 회수·고장 처리·복구·일괄 해제·DLG-I002 배정의 각 액션에서 표시됩니다.

알럿은 권한 없는 계정이 URL로 접근했을 때 페이지 본문이 가려지고 "이 화면에 접근할 권한이 없습니다. 3초 후 대시보드로 이동합니다"라는 차단형 메시지로 표시됩니다.

## 9. 데이터 흐름과 외부 연동

이 화면은 키오스크·출석·고정 락커와 실시간 동기화되는 운영 화면입니다.

화면 진입 시 `GET /api/lockers/clothing`으로 지점의 모든 옷 락커 목록을 조회합니다. 응답에는 락커별 번호·존·상태·배정 회원·점검 사유가 포함됩니다. 통계 카드 카운트는 같은 응답에서 derive됩니다.

WebSocket으로 락커 상태 변화가 실시간 동기화됩니다. SCR-I001 통합 출석 관리에서 락커 배정이 발생하거나, 키오스크 자동 배정이 실행되거나, 다른 운영자가 락커를 변경하면 본 화면 그리드가 즉시 갱신됩니다.

락커 배정은 `POST /api/lockers/clothing/:id/assign`으로 호출되며, 본문에 회원 ID가 포함됩니다. 응답에는 갱신된 락커 상태와 SCR-I001의 옷 락커 컬럼 갱신 데이터가 함께 내려옵니다.

락커 회수는 `POST /api/lockers/clothing/:id/release`로 호출됩니다.

일괄 해제는 `POST /api/lockers/clothing/bulk-release`로 호출되며, 본문에 락커 ID 배열이 포함됩니다. 응답에는 성공/실패 결과 배열이 내려와 결과 카드에 표시됩니다.

키오스크 자동 배정은 SCR-I002 락커 후처리 탭의 "자동 배정 시도" 정책이 활성화된 경우 KIO-201 출석 결과 직후 시스템이 자동 실행합니다. 자동 배정 존(SCR-I002에서 정한)에서 빈 락커를 골라 회원에게 배정하고, 본 화면 그리드와 SCR-I001 옷 락커 컬럼에 "자동배정(번호)"로 즉시 반영됩니다. 자동 배정 실패 시(존에 빈 락커 없음)에는 미배정 상태로 떨어지고 키오스크에 SCR-I002의 미배정 안내 문구가 노출됩니다.

회원이 락커 대상인지 여부는 회원의 이용권에 따라 결정됩니다. 락커 대상이 아닌 회원에게는 옷 락커 컬럼이 "대상 아님"으로 표시되며 배정 시도가 차단됩니다.

미배정 락커 임계 초과는 NFR-19 알림 센터로 owner와 매니저에게 푸시됩니다. 기본 임계는 10명이며 지점별로 조정 가능합니다.

마감 시간 자동 회수는 SCR-I002의 마감 시간 자동 퇴실 정책과 연동됩니다. 운영 시간 종료 후 N분이 지나면 시스템이 자동으로 회원을 퇴실 처리하고 락커도 함께 회수합니다.

모든 배정·회수·고장·복구·일괄 해제는 SCR-097 감사 로그에 비동기로 INSERT됩니다. 기록 필드는 `actor_id`, `target_locker_id`, `action`, `before_state`, `after_state`, `member_id`(해당 시), `reason`, `timestamp`입니다.

화면에서 호출하는 주요 API 엔드포인트는 다음과 같습니다. 락커 목록 `GET /api/lockers/clothing`, 배정 `POST /api/lockers/clothing/:id/assign`, 회수 `POST /api/lockers/clothing/:id/release`, 일괄 해제 `POST /api/lockers/clothing/bulk-release`, 고장 처리 `POST /api/lockers/clothing/:id/break`, 복구 `POST /api/lockers/clothing/:id/repair`, 실시간 동기화 `WS /api/lockers/clothing/stream`.

## 10. 화면 상태와 예외 처리

옷 락커 운영 관리 페이지는 다음 상태들을 가집니다.

기본 운영 상태는 그리드와 통계 카드가 정상 표시되는 상태입니다. 모든 액션 버튼이 권한에 맞게 활성/비활성으로 동작합니다.

미배정 대기 있음 상태에서는 "미배정 대기" 통계 카드가 주황 톤으로 강조되고, 우측 패널 헤더에도 미배정 회원 수가 큰 글씨로 강조됩니다. 임계 초과(10명 이상) 시 패널이 자동으로 펼쳐집니다.

락커 전체 사용 중 상태에서는 그리드에 빈 락커가 0개이므로 "빈 락커 없음" 안내가 그리드 상단에 노란 배너로 표시됩니다.

일괄 처리 중 상태에서는 그리드 위에 진행 스피너 오버레이가 표시되고, 다른 일괄 작업 버튼이 모두 비활성화됩니다.

빈 상태(락커 미등록)는 지점에 옷 락커가 0개 등록된 경우이며, "등록된 락커가 없습니다" 안내와 시설 관리 화면 이동 링크가 표시됩니다.

본사 통합 모드 조회 전용 상태에서는 모든 변경 액션 버튼이 비활성화되고 "조회 전용 - 변경은 지점 owner" 안내가 표시됩니다.

권한 부족 상태(강사·readonly)에서는 모든 변경 액션이 차단되고 조회만 가능합니다.

예외 케이스별 처리는 다음과 같이 정의됩니다.

배정 가능한 빈 락커가 0개인 상태에서 배정 시도는 DLG-I002 모달 안에서 "배정 가능한 락커가 없습니다"로 표시되며 "배정" 버튼이 비활성화됩니다.

회원이 락커 대상이 아닌 경우(이용권에 락커 미포함) 배정 시도는 차단되고 "이 회원은 락커 대상이 아닙니다" 안내가 표시됩니다.

이미 다른 운영자가 같은 락커를 변경한 경우(optimistic lock 위반)는 후행 요청이 거부되고 "다른 운영자가 동시에 변경했어요" 안내와 함께 그리드가 즉시 새로고침됩니다.

자동 배정이 실패한 경우(자동 배정 존에 빈 락커 없음) 본 화면에는 미배정 상태로 표시되고, 키오스크에는 SCR-I002의 미배정 안내 문구가 노출됩니다.

회원이 이미 다른 락커를 사용 중인 상태에서 새 락커 배정을 시도하면 "이 회원은 이미 다른 락커를 사용 중입니다" 안내가 표시되고 차단됩니다.

매니저가 일괄 해제를 시도하면 "owner 승인 요청이 필요합니다" 안내와 함께 승인 요청 모달이 표시됩니다.

회원이 아직 퇴실하지 않은 상태에서 락커 회수를 시도하면 노란 경고 "회원이 아직 퇴실하지 않았습니다. 회수하면 락커 연결이 끊깁니다"가 표시되며, 운영자가 확인하면 진행됩니다.

점검 중 락커에 직접 배정을 시도하면 "점검 중 락커는 배정할 수 없습니다" 안내가 표시됩니다.

WebSocket 끊김 시 노란 배너 "실시간 동기화 끊김 - 30초 폴링으로 동작 중"이 표시됩니다.

마감 시간 자동 회수는 SCR-I002 정책에 따라 자동 실행되며, 결과가 본 화면에 실시간 반영됩니다.

## 11. 권한별 처리

이 화면은 권한에 따라 진입 가능 여부와 가능한 액션이 달라집니다.

슈퍼관리자·본사 최고관리자(primary)는 전 지점의 락커 현황을 조회만 가능하며, 본사 통합 모드에서는 변경 액션이 차단됩니다. 지점 선택 후에는 owner 권한으로 동작합니다.

센터장(owner)은 자기 지점의 모든 락커를 관리할 수 있습니다. 배정·회수·고장 처리·복구·일괄 해제·관리자 승인 처리까지 모든 액션이 가능합니다.

매니저(manager·프런트)는 자기 지점의 락커 배정·회수·고장 처리·복구가 가능하지만 일괄 해제는 owner 승인이 필요합니다. 일괄 해제 버튼을 누르면 승인 요청 모달이 자동 표시됩니다.

스태프(staff)는 자기 지점의 락커 배정·회수가 가능하며 고장 처리·복구·일괄 해제는 차단됩니다.

강사(trainer)와 읽기 전용(readonly)은 조회만 가능하며 모든 변경 액션이 차단됩니다.

본사 통합 모드의 본사 권한자는 변경 액션이 차단되고 "조회 전용" 안내가 표시됩니다.

권한 차단 이벤트는 모두 감사 로그에 기록됩니다.

## 14. 핵심 디자인 요청사항

락커 그리드는 한 락커가 한 칸으로 표시되며, 칸 크기가 너무 크지도 작지도 않아 한눈에 100 ~ 200개 락커가 들어오도록 설계합니다. 칸 안에는 락커 번호가 중앙에 표시되고, 사용 중일 때는 회원 이니셜이 함께 작게 표시되어 운영자가 누가 어디 있는지 즉시 파악합니다.

상태별 색상은 빈 락커(연한 회색)·사용 중(녹색)·만료 임박(주황)·반납 지연(빨강)·점검 중(노랑+망치 아이콘)으로 분기됩니다. 색맹 운영자를 고려해 점검 중에는 작은 망치 아이콘이 색상과 함께 표시됩니다. 자동 배정 존 락커는 칸 좌측 상단에 작은 별표가 표시됩니다.

상단 통계 카드 4개는 동일 크기·동일 그리드로 한눈에 비교 가능하게 배치되며, 미배정 대기가 0이 아닐 때는 주황 톤으로 약하게 강조되어 운영자의 시선을 끕니다.

우측 미배정 회원 패널은 부드러운 슬라이드 인으로 펼쳐지며, 본문 가로폭이 동시에 축소되는 애니메이션이 함께 일어납니다. 패널이 닫힐 때는 슬라이드 아웃과 본문 가로폭 확장이 동시에 일어납니다.

미배정 회원 카드는 한 줄에 회원명과 출석 시각, 그 아래 회원권 유형과 고정 락커 보유 여부, 우측에 "배정" 버튼이 배치되어 운영자가 카드 한 장만 봐도 의사결정이 가능합니다.

락커 칸 클릭 시의 정보 팝업은 락커 칸 옆에 작은 카드처럼 펼쳐지고, 다른 락커를 누르면 자동으로 닫히며 새 팝업이 열립니다.

일괄 해제 결과 카드는 화면 중앙 하단에 머무르며 성공·실패 숫자가 큰 글씨로 강조되고, 실패 락커별 사유가 카드별로 나열됩니다.

WebSocket 실시간 동기화 시 락커 상태 변화는 부드러운 색상 트랜지션으로 표현되며, 키오스크 자동 배정이 발생하면 해당 칸이 1.5초 동안 노랑 하이라이트로 강조되어 운영자가 자동 배정 결과를 즉시 인지합니다.

모바일에서는 그리드가 가로 스크롤로 전환되며 한 번에 보이는 락커 수가 줄어듭니다. 락커 칸 크기는 손가락 터치에 적합하도록 약간 커집니다.

진행 스피너와 로딩 스켈레톤은 다른 D11 화면과 동일한 톤으로 통일됩니다.

## 15. 운영 정책 (이 화면에 연결된 부분)

이 화면은 단순한 락커 그리드가 아니라 출석·키오스크·락커 운영의 정책 결정이 그대로 반영된 도구입니다.

옷 락커 정책의 핵심은 "출석 기반 당일용"이라는 것입니다. 회원이 출석을 완료한 시점에 락커 대상 여부가 판정되고, 마감 시간이 도래하면 자동 회수되어 다음 날 다른 회원이 같은 락커를 사용할 수 있게 합니다. 이는 상품 계약 기반의 장기 배정 락커(SCR-I005 고정 물품 락커 관리)와 명확히 분리되는 모델이며, 두 모델을 섞지 않는 것이 이 화면의 설계 원칙입니다.

자동 배정 정책은 SCR-I002 키오스크 설정의 락커 후처리 탭에서 결정됩니다. "출석만 완료"는 락커를 다루지 않는 모드, "수동 배정 대기"는 운영자가 본 화면에서 수동 배정하는 모드, "자동 배정 시도"는 키오스크가 출석 직후 자동 배정 존에서 빈 락커를 골라 배정하는 모드입니다. 자동 배정 실패 시에는 미배정 상태로 떨어지면서 키오스크에 SCR-I002의 미배정 안내 문구가 노출됩니다. 본 화면의 그리드는 이 정책 결과를 시각적으로 표현하는 곳이며, 정책 변경이 필요하면 SCR-I002로 이동해야 합니다.

배정 대상 정책은 회원의 이용권에 락커가 포함된 경우에만 락커 대상으로 판정합니다. 락커 미포함 이용권 회원은 옷 락커 컬럼이 "대상 아님"으로 표시되고 배정 시도가 차단됩니다.

일괄 해제 권한 정책은 owner 이상으로 한정되며, 매니저는 owner 승인 요청을 거쳐야 합니다. 운영 실수로 인한 대량 회수가 회원 경험에 큰 영향을 주기 때문에 권한이 단계적으로 제한됩니다.

회수 안전 정책은 회원이 아직 퇴실하지 않은 상태에서 회수 시도 시 노란 경고를 표시하고 운영자의 확인을 받습니다. 회원이 락커를 사용 중인 동안 회수가 되면 회원이 본인의 짐을 못 찾을 수 있으므로 안전망을 둡니다.

고장·복구 라이프사이클은 점검 사유와 점검 담당자가 함께 저장되어 사후 추적이 가능합니다. 점검 중 락커는 배정할 수 없고, 정비 완료 후 운영자가 명시적으로 "복구"를 눌러야 다시 사용 가능 상태로 전환됩니다.

마감 시간 자동 회수 정책은 SCR-I002 키오스크 설정의 마감 시간 자동 퇴실 정책과 연동됩니다. 운영 시간 종료 후 N분(기본 30분)이 지나면 시스템이 자동으로 회원을 퇴실 처리하고 락커도 함께 회수합니다. 자동 회수 결과는 본 화면에 실시간 반영되고 감사 로그에 기록됩니다.

미배정 락커 임계 초과 알림은 미배정 회원 수가 임계(기본 10명) 이상이 되면 NFR-19 알림 센터로 owner와 매니저에게 푸시됩니다. 러시아워에 미배정이 누적되는 상황을 즉시 인지해 대응할 수 있게 합니다.

이력 보존 정책은 회수 후에도 회원-락커 매핑 이력이 보존된다는 것입니다. 회원이 어느 락커를 언제 사용했는지 추후 조회가 가능하며, 분실·도난 같은 분쟁 시 근거 자료로 사용됩니다.

본사 통합 모드 정책은 본사 권한자가 전 지점 락커 현황을 조회만 할 수 있다는 것입니다. 락커 운영은 단말 상태와 회원 현장 상황에 직결되는 즉시성이 중요하므로 변경은 지점 owner가 직접 수행합니다.

감사 로그 정책은 모든 배정·회수·고장·복구·일괄 해제가 SCR-097에 비동기로 INSERT된다는 것입니다. `actor_id`, `target_locker_id`, `action`, `before_state`, `after_state`, `member_id`, `reason`, `timestamp`가 기록되어 운영 행위의 추적성을 보장합니다.

WebSocket 실시간 동기화 정책은 락커 상태 변화가 모든 운영자에게 동시에 보인다는 것입니다. 두 명의 운영자가 같은 락커를 동시에 변경하려고 하면 optimistic lock으로 후행 요청이 거부되어 데이터 무결성을 보장합니다.

이상의 모든 정책은 이 화면을 구현하고 운영하는 사람이 별도 문서 없이 이 한 장만 보면 이해할 수 있도록 풀어 적었습니다.
