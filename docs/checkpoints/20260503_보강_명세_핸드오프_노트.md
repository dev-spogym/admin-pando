## 보강된 화면·기능 명세 10건

### 1. 직원 상세 패널 (SCR-060 상세) — 직원관리.md:54

**상태**: 신규 명세
**핵심 화면 요소**:
- 담당 회원 목록 (이름·연락처·이용권 상태·마지막 출석일)
- 담당 스케줄 (이번 주·다음 주 수업 카드/리스트)
- 실적 요약 (수업 진행 건수, 신규/재등록 매출, OT 1·2 완료 수, NPS 평균)
- 근태 요약 (출근일·결근·지각)
- 인사 메모 (매니저·센터장 비공개)
- 헤더 액션: SCR-061 수정 / SCR-062 퇴사 처리 진입

**권한 분기**:
- 센터장·매니저: 모든 직원 + 인사 메모
- 직원 본인: 본인 정보 + 본인 실적·근태 (인사 메모 비공개)
- FC·트레이너·스태프: 동료 접근 차단

### 2. 회원 복구(Undelete) — 회원관리.md:198

**상태**: 신규 명세
**핵심 흐름**:
- 회원 목록 상단 "삭제·탈퇴 회원 보기" 토글
- 토글 ON → 삭제·탈퇴 회원 별도 섹션 표시
- 헤더 [복구] 버튼 + 확인 다이얼로그(DLG-M005 역연계)
- 권한: 센터장·매니저·슈퍼관리자만

### 4. 리드 상담 상세 패널 — 마케팅.md:46

**상태**: 신규 명세 (기존 등록/수정 다이얼로그 외 추가)
**핵심 화면 요소**:
- 리드 카드/행 클릭 시 상담 상세 패널 표시
- 메모 작성·수정·삭제
- 후속 액션 등록 (전화/방문/문자 예정)

### 5. 직원 근로계약 유형 추가 (SCR-075) — 마케팅.md:135

**상태**: 기존 회원 계약 화면에 직원 근로계약 유형 분기 추가
**핵심 흐름**:
- 계약 유형 선택: 회원 계약(이용권/PT/필라테스 등) 또는 직원 근로계약(정규직/위촉/프리랜서)
- 회원 계약 → 회원 검색
- 직원 근로계약 → 직원관리(SCR-060) 직원 검색

### 7. 상담 전환 분석 옵션 (SCR-099) — 본사관리.md:419

**상태**: 기존 리포트에 분석 옵션 추가
**핵심 흐름**:
- 리포트 상세 모달에 "상담 전환 분석" 옵션
- SCR-094 KPI 퍼널 데이터 재활용 (리드 유입 → 상담 완료 → 등록)
- 유입경로별 전환율 표시
- CSV 내보내기에 전환 분석 컬럼 포함

### 8. 역할 변경 영향 분석 다이얼로그 (SCR-081/SCR-087) — 설정관리.md:122

**상태**: 신규 명세
**핵심 흐름**:
- 권한 매트릭스 변경 또는 역할 삭제 시 사전 다이얼로그
- 영향 범위 표시: 배정 직원 수 + 그 직원이 담당하는 회원 수
- 확인 후 진행

### 9. 민감 기능 권한 제한 정책 — 설정관리.md:123

**상태**: 정책 명세
**민감 기능 6종**:
- 회원 영구 삭제
- 환불 처리
- 급여 확정·지급
- 슈퍼관리자 권한 부여/회수
- 데이터 복원
- 감사로그 내보내기

**규칙**: superAdmin 또는 primary(본사 최고관리자)만 수행 가능. 그 외 역할은 권한 부재 시 차단 다이얼로그(E02 권한없음 403) + 안내 메시지 표시.

## 핸드오프 시 안내 사항
