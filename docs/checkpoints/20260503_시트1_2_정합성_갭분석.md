## 2. 기획자 처리 권장 (R&R 내)

### 즉시 처리 가능
1. **SCR-102 ID 중복 해소** — 사이드바 네비게이션과 벤치마크 비교가 같은 SCR 번호 사용. 둘 중 하나를 다른 번호(예: SCR-103)로 재배정. 화면설계서·기능명세서·다이어그램 갱신.
2. **시트 3 매핑 누락 7건 추가** — 기획 SCR 7개를 시트 3에 행으로 추가 (라인 위치는 카테고리에 맞게).

### R&R 외 — 클라이언트 안내
3. **INF/DB/DOC-01~06 산출물** — 본 기획 계약 범위 외, 개발사가 작성·제공해야 할 영역. 클라이언트에 다음을 안내:
   - INF-01~08 인프라 가이드
   - DB-01~06 DB 스키마 설계서
   - DOC-01 시스템 아키텍처 / DOC-02 인프라·배포 / DOC-03 ERD / DOC-04 API 명세 / DOC-05 환경설정 / DOC-06 테스트 결과
   → 개발사에 별도 요청 권장

### R&R 경계
4. **DOC-07 운영자 매뉴얼** — 화면별 사용 가이드. 인수인계 시점에 화면설계서·기능명세서를 정제해 작성 가능 (기획 R&R 내).

## 3. 결론

- **계약 별첨1의 INF/DB/DOC-01~06**은 본 기획 계약 범위 외, 개발사 R&R. 기획자가 채울 수 없는 영역이므로 시트 3 누락은 정상이며 클라이언트에 안내 필요.
- **누락 SCR 7건**은 기획 산출물에 모두 명세되어 있고 시트 3 매핑만 빠짐. 기획자 R&R 내에서 해소 가능.
- **SCR-102 ID 중복**은 기획 R&R 내 정정 사항.
