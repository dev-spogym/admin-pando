## 1. 목적
DLG-S016의 주요 필드 검증 규칙을 표현한다.

## 2. 전제조건
- DLG-S016 열림 상태

## 3. 다이어그램

```mermaid
flowchart TD
    SUBMIT[발송 버튼 클릭] --> MEMBER_CHECK{회원 존재 여부}
    MEMBER_CHECK --> AMOUNT_CHECK{고정 금액 0 초과}
    MEMBER_CHECK --> ERR_MEMBER[회원 선택 필수]

    AMOUNT_CHECK --> CONTACT_CHECK{연락처 존재 여부}
    AMOUNT_CHECK --> ERR_AMOUNT[발송 금액 오류]

    CONTACT_CHECK --> EXPIRE_CHECK{만료일시 현재 이후\n기본 7일}
    CONTACT_CHECK --> ERR_CONTACT[연락처 필수]

    EXPIRE_CHECK --> ACTIVE_CHECK{활성 링크 존재 여부}
    EXPIRE_CHECK --> ERR_EXPIRE[만료일시 오류]

    ACTIVE_CHECK --> VALID[새 링크 생성 가능]
    ACTIVE_CHECK --> RESEND_MODE[같은 링크 재발송 또는\n강제 만료 후 새 링크 선택]

    classDef system fill:#EDE7F6,stroke:#5E35B2
    classDef success fill:#E8F5E9,stroke:#2E7D32,color:#1B5E20
    classDef error fill:#FFEBEE,stroke:#C62828,color:#B71C1C

    class MEMBER_CHECK,AMOUNT_CHECK,CONTACT_CHECK,EXPIRE_CHECK,ACTIVE_CHECK system
    class VALID,RESEND_MODE success
    class ERR_MEMBER,ERR_AMOUNT,ERR_CONTACT,ERR_EXPIRE error
```

## 4. 엣지 설명

| 출발 | 도착 | 설명 |
|------|------|------|
| MEMBER_CHECK | ERR_MEMBER | 회원 없는 링크 발송 불가 |
| CONTACT_CHECK | ERR_CONTACT | 연락처 필수 |
| ACTIVE_CHECK | RESEND_MODE | 활성 링크는 같은 링크 재발송 또는 강제 만료 후 새 링크 생성 선택 |
