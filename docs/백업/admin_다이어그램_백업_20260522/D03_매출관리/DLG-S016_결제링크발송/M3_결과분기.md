## 1. 목적
DLG-S016 발송 후 결과 분기를 표현한다.

## 2. 전제조건
- DLG-S016에서 발송 버튼 클릭

## 3. 다이어그램

```mermaid
flowchart TD
    SEND[링크 발송 요청] --> RESULT{발송 결과}

    RESULT -->|": 새 링크 발송 성공"|SENT[linkStatus=SENT\n매출/미수에 반영]
    RESULT -->|": 기존 링크 재발송 성공"|RESENT[동일 linkStatus 유지\n수신 채널만 재발송]
    RESULT -->|": 메시지 실패"|FAIL_MSG[발송 실패 토스트]
    RESULT -->|": 강제 만료 후 새 링크 생성"|EXPIRE_AND_NEW[기존 링크 EXPIRED\n새 링크 SENT]

    SENT --> FOLLOWUP{후속 처리}
    RESENT --> FOLLOWUP
    EXPIRE_AND_NEW --> FOLLOWUP
    FOLLOWUP -->|": 링크 결제 대기"|UNPAID[SCR-S008 미수금 관리 반영]
    FOLLOWUP -->|": 즉시 확인"|SALES[SCR-S001 매출 현황 반영]

    classDef system fill:#EDE7F6,stroke:#5E35B2
    classDef success fill:#E8F5E9,stroke:#2E7D32,color:#1B5E20
    classDef error fill:#FFEBEE,stroke:#C62828,color:#B71C1C

    class SEND,RESULT,FOLLOWUP system
    class SENT,RESENT,EXPIRE_AND_NEW,UNPAID,SALES success
    class FAIL_MSG error
```

## 4. 엣지 설명

| 출발 | 도착 | 설명 |
|------|------|------|
| RESULT | SENT | 새 링크 발송 성공 |
| RESULT | RESENT | 기존 활성 링크 재발송 |
| RESULT | EXPIRE_AND_NEW | 기존 링크 만료 후 새 링크 발송 |
| FOLLOWUP | UNPAID | 링크 결제 전 미수금 관리 대상 |
