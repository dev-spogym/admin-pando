## 1. 목적
SCR-S003의 현장 영수증 첨부 결제 등록과 결제링크 발송 시 오류 분기를 표현한다.

## 2. 전제조건
- DLG-S003에서 결제 완료 등록 클릭

## 3. 다이어그램

```mermaid
flowchart TD
    EXEC[현장 결제 등록 실행] --> RECEIPT_CHECK{영수증 첨부 확인}

    RECEIPT_CHECK -->|": 미첨부"|ERR_RECEIPT[영수증 파일을 첨부해주세요.]
    RECEIPT_CHECK -->|": 형식 오류"|ERR_RECEIPT_TYPE[이미지 또는 PDF만 첨부할 수 있어요.]
    RECEIPT_CHECK -->|": 통과"|AMOUNT_CHECK{금액 일치 확인}

    AMOUNT_CHECK -->|": 불일치"|ERR_AMOUNT[결제가격 + 포인트 사용액이\n장바구니 합계와 일치하지 않습니다.]
    AMOUNT_CHECK -->|": 일치"|POINT_CHECK{포인트 사용 여부}

    POINT_CHECK -->|": 사용함"|POINT_DEDUCT[포인트 차감]
    POINT_CHECK -->|": 사용 안 함"|SAVE_PAYMENT[payment 저장]
    POINT_DEDUCT -->|": 실패"|ERR_DEDUCT((포인트 차감에 실패했습니다.))
    POINT_DEDUCT -->|": 성공"|SAVE_PAYMENT

    SAVE_PAYMENT -->|": 200"|ISSUE_PASS[회원/이용권 등록 완료]
    SAVE_PAYMENT -->|": 500"|ERR_INSERT((결제 등록에 실패했습니다.))
    SAVE_PAYMENT -->|": 409"|ERR_DUP[중복 결제 오류-S004 표시]
    SAVE_PAYMENT -->|": Network"|ERR_NET[네트워크 오류\n재시도 안내]

    ISSUE_PASS --> POINT_ACCRUE[포인트 적립\n해당 시]
    POINT_ACCRUE -->|": 실패"|ERR_ACCRUE[적립 실패\n결제는 완료 처리]
    POINT_ACCRUE -->|": 성공 또는 미대상"|COMPLETE[결제완료 화면]

    LINK_EXEC[결제링크 발송 실행] --> LINK_CONTACT{연락처 유효성}
    LINK_CONTACT -->|": 누락"|ERR_CONTACT[회원 연락처가 필요합니다.]
    LINK_CONTACT -->|": 통과"|LINK_ACTIVE_CHECK{활성 링크 존재 여부}
    LINK_ACTIVE_CHECK -->|": 있음"|ERR_LINK_DUP[활성 결제링크가 이미 존재합니다.]
    LINK_ACTIVE_CHECK -->|": 없음"|LINK_SEND[메시지 발송]
    LINK_SEND -->|": 성공"|LINK_DONE[linkStatus=SENT]
    LINK_SEND -->|": 실패"|ERR_LINK_SEND[결제링크 발송에 실패했습니다.]

    ERR_INSERT --> SAVE_PAYMENT
    ERR_NET --> SAVE_PAYMENT

    classDef error fill:#FFEBEE,stroke:#C62828,color:#B71C1C
    classDef success fill:#E8F5E9,stroke:#2E7D32,color:#1B5E20
    classDef system fill:#EDE7F6,stroke:#5E35B2
    classDef warning fill:#FFF8E1,stroke:#F9A825,color:#F57F17

    class COMPLETE,LINK_DONE success
    class ERR_RECEIPT,ERR_RECEIPT_TYPE,ERR_AMOUNT,ERR_DEDUCT,ERR_INSERT,ERR_DUP,ERR_NET,ERR_CONTACT,ERR_LINK_DUP,ERR_LINK_SEND error
    class ERR_ACCRUE warning
    class EXEC,RECEIPT_CHECK,AMOUNT_CHECK,POINT_CHECK,POINT_DEDUCT,SAVE_PAYMENT,ISSUE_PASS,POINT_ACCRUE,LINK_EXEC,LINK_CONTACT,LINK_ACTIVE_CHECK,LINK_SEND system
```

## 4. 엣지 설명

| 출발 | 도착 | 설명 |
|------|------|------|
| RECEIPT_CHECK | ERR_RECEIPT | 영수증 파일 미첨부 |
| RECEIPT_CHECK | ERR_RECEIPT_TYPE | 지원하지 않는 파일 형식 |
| AMOUNT_CHECK | ERR_AMOUNT | 결제 총액 불일치 |
| POINT_DEDUCT | ERR_DEDUCT | 포인트 차감 실패 |
| SAVE_PAYMENT | ERR_INSERT | 결제 등록 저장 실패 |
| SAVE_PAYMENT | ERR_DUP | 409 중복 결제 |
| ISSUE_PASS | COMPLETE | 결제완료 + 회원/이용권 등록 완료 |
| LINK_CONTACT | ERR_CONTACT | 링크 발송 연락처 누락 |
| LINK_ACTIVE_CHECK | ERR_LINK_DUP | 기존 활성 링크 존재 |
