## 검증 규칙

| 검증 항목 | 통과 조건 | 실패 시 동작 |
|---|---|---|
| 영향 직원 수 계산 | 정상 응답 | 실패 시 다이얼로그 표시 + 진행 버튼 비활성, 재조회 안내 |
