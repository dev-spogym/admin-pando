# Client Gap Notes

## 목적
- 전체 TC를 전개한 뒤에도 문서상 구멍이 큰 항목을 별도 관리한다.

## 핵심 확인 포인트
- 홈 우선 카드 우선순위 충돌 시 어떤 배너가 최상단인지
- PT, OT, GX, Golf 예약 승인/즉시확정/대기전환 기준
- 결제 실패 후 주문 상태와 영수증 화면 노출 기준
- 알림 읽음 처리와 라우팅 후 복귀 지점
- 건강 데이터 연동 권한 거부/부분 허용/철회 이후 화면 정책
- 탈퇴 후 복구 가능 기간과 데이터 파기 기준
- kiosk와 app가 동시에 체크인/예약 이벤트를 보낼 때 충돌 처리

## 커버 대상
- 화면 35개를 모두 개별 문서로 분리했으므로, 추후 공백 판정은 화면 ID 기준으로 바로 역추적 가능
