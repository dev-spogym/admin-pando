# TC Guide

## 판정 상태

| 상태 | 의미 |
|---|---|
| Ready | 문서 기준으로 바로 테스트 가능 |
| Need-Design | 기획 정의가 모호해서 테스트 기준 확정 필요 |
| Need-Data | 테스트 데이터/정책 세팅 필요 |
| Need-Impl | 현재 구현이 없거나 부족해 TC는 있으나 실행 불가 |

## 분류 코드

| 코드 | 의미 |
|---|---|
| FLW | 핵심 플로우 |
| UI | 화면 구성 / 노출 |
| STA | 상태 전이 |
| ERR | 오류 / 예외 |
| RBAC | 권한 / 역할 |
| LINK | 화면 간 연결 |
| DATA | 계산 / 데이터 반영 |

## 공통 체크 포인트

| 항목 | 설명 |
|---|---|
| 진입 경로 | 홈, 마이페이지, 알림, 외부 링크 등 진입 출처별 분기 |
| 권한 | 회원 / 트레이너 / 골프강사 / FC / 스태프 / 비로그인 구분 |
| 상태 | 로딩, 빈 상태, 정상, 경고, 실패, 만료, 승인 대기, 완료, 취소 |
| 시간 규칙 | D-day, 취소 마감, 서명 만료, 동기화 지연, 노쇼 누적 |
| 데이터 반영 | 리스트, 상세, 배지, 알림, KPI, admin 연동 반영 방향 |
| 되돌리기 | 취소, 삭제, 연동 해제, 로그아웃, 뒤로가기 |

## TC 작성 포맷

| 컬럼 | 설명 |
|---|---|
| TC ID | 도메인-화면ID-순번 |
| 분류 | FLW / UI / STA / ERR / RBAC / LINK / DATA |
| 대상 | 화면 또는 기능 |
| 전제조건 | 계정 상태, 데이터 상태, 정책 상태 |
| 절차 | 실제 실행 순서 |
| 기대결과 | 화면, 상태, 데이터, 이동 결과 |
| 상태 | Ready / Need-Design / Need-Data / Need-Impl |

## E2E 자동화 우선 후보

- 로그인
- 회원 예약 생성 → 승인 대기 → 승인 완료 → 이력 반영
- PT / 골프 완료 → 차감 반영
- 상품 결제 → 주문/영수증 반영
- 회원 탈퇴 / 동의관리 / 건강데이터 연동 같은 위험 액션
- 트레이너 승인/거절
- FC 상담 등록 / 후속 조치
- 스태프 수동 출석
