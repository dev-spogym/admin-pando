# 회원앱 다이어그램

> 작성일: 2026-05-04
> 버전: 1.0
> 기준: `docs/client/APP-IA.md` v4.0, `docs/client/기능명세서/`, `docs/client/화면설계서/`, `plan/CheckList/회원앱리스트_2025_1228_요약.xlsx` (39항목)

회원앱 기획 docs를 시각적으로 보강하는 다이어그램 모음. admin 다이어그램(`docs/admin/다이어그램/`)과 동일 구조이며, 회원앱 도메인(member / trainer / golf_trainer / fc / staff)에 맞춰 작성한다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `00_사이트맵/` | 회원앱 IA 사이트맵 (member 전체 + 직원 모드) |
| `10_권한매트릭스/` | 5개 role 권한 매트릭스 + 역할별 journey |
| `20_상태전이도/` | 예약 / 이용권 / 주문 / 마일리지 상태 전이 |
| `30_시나리오_시퀀스/` | xlsx 39항목을 통합한 10개 핵심 시나리오 시퀀스 |
| `40_자동화/` | D-day 트리거 / AT-RISK 케어 / 마일리지 만료 자동화 |
| `50_에러_예외/` | 네트워크 / 서버 점검 / 권한 / 정원 / 차감 부족 등 예외 흐름 |
| `D12_회원앱/` | 도메인별 화면 흐름 다이어그램 (홈 / 예약 / 결제 / 리워드 / 시스템) |

## 다이어그램 작성 규칙

- 모든 다이어그램은 [Mermaid](https://mermaid.js.org/) 코드 블록으로 작성한다.
- 화면 ID는 `MA-XXX`, 기능 ID는 `MFN-XXX`로 표기한다.
- 상태는 `pending / confirmed / completed / cancelled` 등 영문 소문자 통일.
- role은 `member / trainer / golf_trainer / fc / staff` 통일.
- 색상 톤은 회원앱 디자인 시스템(primary 청록 #0E7C7B, success 초록, warning 주황, danger 빨강) 기준.
