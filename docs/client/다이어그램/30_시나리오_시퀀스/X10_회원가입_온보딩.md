# X10. 회원가입 / 온보딩 시나리오

> xlsx 항목: #36 계정 생성 (전화/이메일 인증 + 지점 선택), #37 운동 목적/성향, #38 통증/체형, #39 온보딩 요약 + 첫 루틴

CRM에 사전 등록된 회원이 앱 연동 5단계 → 운동 온보딩 3페이지 → 첫 루틴 제안 → 환영 슬라이드 → 홈 진입까지 완성하는 흐름.

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant CRM
    participant SMS

    Note over Member,App: 사전: CRM에 회원 정보 등록됨
    Member->>App: 앱 설치 → MA-001 → "앱 연동하기"
    App-->>Member: MA-002 1단계 - 연락처 입력
    Member->>App: 전화번호 또는 이메일
    App->>CRM: 일치 회원 조회

    alt CRM 일치
        CRM-->>App: 회원 데이터 + 가입 지점 목록
    else CRM 미등록
        App-->>Member: "등록되지 않은 회원입니다" + 1:1 문의(MA-153) 진입
    end

    App-->>Member: MA-002 2단계 - SMS 인증
    App->>SMS: 인증번호 발송 (3분 유효)
    SMS-->>Member: 6자리 OTP
    Member->>App: 인증번호 입력
    App->>SMS: 검증
    SMS-->>App: 검증 완료

    App-->>Member: MA-002 3단계 - 비밀번호 설정
    Member->>App: 8~16자 + 영문/숫자/특수문자

    App-->>Member: MA-002 4단계 - 가입 지점 선택
    alt 단일 지점
        App->>App: 자동 선택
    else 다중 지점
        Member->>App: 지점 카드 선택
    end

    App-->>Member: MA-002 5단계 - 약관 동의
    Member->>App: 필수 약관 + 선택 약관
    App->>API: 회원 계정 활성화

    Note over Member,App: 온보딩 자동 진입
    App-->>Member: MA-127 운동 온보딩 1페이지 (목적·성향)
    Member->>App: 운동 목적 (다중) + 성향 + 강도 + 선호 요일·시간

    App-->>Member: MA-127 2페이지 (통증·부상)
    Member->>App: 통증 부위 + 과거 부상 + 불편한 동작

    App-->>Member: MA-127 3페이지 (체형·집중)
    Member->>App: 체형 + 집중 부위
    Member->>App: "입력 완료"

    App->>API: 온보딩 데이터 저장
    API->>API: 첫 루틴 3종 산정 (목적/통증/균형형)
    API-->>App: 첫 루틴 카드 데이터
    App-->>Member: MA-128 온보딩 완료 (요약 + 첫 루틴 3종)

    Member->>App: 첫 루틴 카드 선택 → "트레이너에게 공유" 또는 "OT1 예약"

    alt OT1 예약
        Member->>App: MA-121 진입 (OT1 라디오 자동 선택)
    else 환영 슬라이드
        App-->>Member: MA-900 환영 4 슬라이드 (둘러보기 / 결제·예약 / 활동·리워드 / 메신저)
        Member->>App: "시작하기"
    end

    App-->>Member: MA-100 회원 홈 첫 진입
    App->>API: hasSeenWelcome=true 플래그 저장
```

## 입력 완료율 → 첫 루틴 정확도

| 입력 완료율 | 첫 루틴 정확도 | 안내 |
|---|---|---|
| 100% | 높음 | "당신에게 딱 맞는 루틴" |
| 80% | 중간 | "추가 입력 시 더 정확해져요" |
| 50% 미만 | 낮음 | "일반 추천 - 추가 입력 권장" |

## 온보딩 옵션 풀

| 항목 | 옵션 |
|---|---|
| 운동 목적 (다중) | 감량 / 근비대 / 체형교정 / 통증완화 / 체력증진 / 자세교정 / 재활 / 대회 준비 |
| 운동 성향 (단일) | 강하게 / 친절하게 / 조용한 운동 / 그룹 / 자율 |
| 강도 선호 | 저·중·고강도 |
| 통증 부위 | 목·어깨·등·허리·골반·무릎·발목·손목·팔꿈치·없음 |
| 과거 부상 | 디스크·회전근개·십자인대·발목인대·골절·수술·기타·없음 |
| 불편한 동작 | 스쿼트·데드리프트·푸쉬업·풀업·러닝·점프·회전·없음 |
| 체형 | 상체비만 / 하체비만 / 복부비만 / 마른비만 / 표준 / 근육형 |
| 집중 부위 | 복부·등·어깨·가슴·팔·엉덩이·다리·종아리 |
