# X01. 홈 진입 분기 시나리오

> xlsx 항목: #1 로그인, #2 PT 예약 바로가기, #3 GX 스케줄 바로가기, Golf 스케줄 바로가기, #4 포인트/배지 요약, #5 공지/이벤트 배너

회원이 앱을 켜고 로그인 → 홈에 진입할 때 회원 상황(만료 임박 / 온보딩 미완료 / AT-RISK / 신규 알림)에 따라 우선 카드를 결정해 노출하는 흐름.

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API as 백엔드 API
    participant Policy as 본사 정책 세트

    Member->>App: 앱 실행
    App->>App: 토큰 검증

    alt 토큰 유효
        App->>API: 홈 진입 (회원 ID)
    else 토큰 없음/만료
        App-->>Member: MA-001 로그인 화면
        Member->>App: 회원 탭 / 전화번호 + 비밀번호
        App->>API: 로그인 인증
        API-->>App: 토큰 발급 + role=member
    end

    par 홈 데이터 병렬 조회
        App->>API: 회원권 만료 D-day 조회
        App->>API: 온보딩 완료 여부 조회
        App->>API: 오늘 수업 + 알림 미읽음 조회
        App->>API: 마일리지 / 등급 / 배지 요약
        App->>API: 진행 중 공지 / 이벤트
    end

    API->>Policy: D-day 정책 / AT-RISK 기준 조회
    Policy-->>API: 본사 정책 세트 결과
    API-->>App: 홈 카드 데이터 일괄 응답

    App->>App: 우선 카드 결정 알고리즘
    Note over App: 우선순위 — D-1 > D-7 > D-14 > AT-RISK > 온보딩 미완료 > 일반

    App-->>Member: MA-100 회원 홈 표시
    Note over Member,App: 우선 배너 + 핵심 바로가기 + 마일리지/배지 요약 + 공지 배너 + 오늘 수업

    Member->>App: PT 예약 바로가기 탭
    App-->>Member: MA-121 수업 상세/예약 진입
```

## 우선 카드 결정 로직

| 조건 | 우선 카드 |
|---|---|
| 회원권 만료 D-1 또는 만료 후 | MA-138 재등록 추천 (danger 배너) |
| 만료 D-7 | MA-138 (warning) |
| 만료 D-14 | MA-138 (info) |
| 4주 미방문 (AT-RISK) | MA-138 + AT-RISK 메시지 |
| 운동 온보딩 미완료 | MA-127 진입 안내 |
| 알림 미읽음 N건 | 헤더 알림 배지만 강조 |
| 일반 | 핵심 바로가기 (PT / GX / Golf) + 오늘 수업 |
