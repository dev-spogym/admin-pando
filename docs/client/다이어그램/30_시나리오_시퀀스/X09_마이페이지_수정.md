# X09. 마이페이지 / 설정 시나리오

> xlsx 항목: #28 기본 정보 관리, #29 회원권/락커 만료일, #30 방문 히스토리, #31 PT/GX/필라테스 이력, #32 알림 설정, #33 개인정보·로그아웃

회원이 마이페이지에서 본인 정보 수정, 이용권 확인, 출석 분석, 알림 설정, 개인정보·약관·동의·탈퇴 등 마이페이지 허브를 사용하는 흐름.

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant SMS as SMS 인증
    participant Email as 이메일 인증

    Member->>App: MA-100 → 마이페이지 진입
    App->>API: 회원 프로필 + 등급 + 가입 정보 조회
    API-->>App: 회원 데이터
    App-->>Member: MA-130 마이페이지 (프로필 + 서비스 진입 그리드)

    par 서비스 진입 분기
        Member->>App: "이용권" → MA-131 (회원권 + PT/OT + 락커 + 부가옵션)
        Member->>App: "출석 이력" → MA-111 (4지표 + 캘린더 + 카테고리 도넛 + 분석 카드)
        Member->>App: "결제 내역" → MA-133
        Member->>App: "리워드" → MA-136 / MA-137
        Member->>App: "알림센터" → MA-150
        Member->>App: "설정" → MA-155
    end

    Note over Member,App: A. 기본 정보 수정 (이름)
    Member->>App: MA-130 → "프로필 편집" → 이름 수정
    App->>API: 이름 즉시 저장
    API-->>App: 저장 완료
    App-->>Member: 토스트 "변경 완료"

    Note over Member,App: B. 연락처 수정 (인증 필요)
    Member->>App: 연락처 수정 → 새 번호 입력
    App->>SMS: 인증번호 발송
    SMS-->>Member: SMS 6자리
    Member->>App: 인증번호 입력
    App->>API: 인증 + 연락처 변경 저장
    API-->>App: 변경 완료

    Note over Member,App: C. 이메일 수정
    Member->>App: 이메일 수정 → 새 메일 입력
    App->>Email: 이메일 인증 링크 발송
    Email-->>Member: 인증 메일
    Member->>Email: 링크 탭 → 인증
    Email-->>App: 인증 완료 콜백
    App->>API: 이메일 변경 저장

    Note over Member,App: D. 알림 설정
    Member->>App: MA-155 → 알림 카테고리 토글
    App->>API: 카테고리별 ON/OFF 저장
    Member->>App: 채널 칩 (앱 푸시 / SMS / 이메일) 다중 선택
    App->>API: 채널 저장
    Member->>App: 야간 차단 (22:00~07:00) ON
    App->>API: 야간 차단 저장

    Note over Member,App: E. 로그아웃
    Member->>App: MA-155 → 로그아웃
    App-->>Member: ConfirmDialog (기본 톤)
    Member->>App: 확인
    App->>App: 토큰 삭제
    App-->>Member: MA-001 로그인 화면
```

## 출석 분석 카드 (MA-111)

| 분석 | 표시 |
|---|---|
| 4지표 | 이번 달 출석 / 주간 평균 / 월간 평균 / 연속 출석 |
| 카테고리 비중 | PT / OT / GX / 필라테스 / Golf 도넛 (필라테스 별도 분리) |
| 출석 패턴 히트맵 | 요일 × 시간대 격자 |
| 분석 카드 | 가장 많이 참여한 클래스 / 자주 가는 시간대 / 전월 대비 +/- / 개근 진척률 |

## 락커 + 부가옵션 카드 (MA-131)

| 카드 | 내용 |
|---|---|
| 회원권 | 종류 + 시작일 + 만료일 + D-day |
| PT 잔여 | 총/사용/잔여 + 차감 이력 + 다음 예약 |
| OT 잔여 | OT1/OT2 분리 표시 |
| 락커 | 번호 + 만료일 + 연장 결제(MA-141) |
| 부가옵션 | 운동복 / 수건 / 사우나 ON-OFF + 잔여 + 만료 |
