# X06. 결제 / 영수증 플로우 시나리오

> xlsx 항목: #26 결제수단 선택·결제, #27 결제 내역 확인

회원이 상품/패키지/이용권을 결제하고 영수증을 확인하는 흐름. 단건/장바구니/재등록 분기 + 마일리지/쿠폰 적용.

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant PG as 토스페이먼츠
    participant Push

    Member->>App: MA-139 상품 상세 → "바로 결제"
    App-->>Member: MA-140 결제하기

    par 결제 화면 데이터 로드
        App->>API: 등록 결제수단 조회 (MA-405)
        App->>API: 사용 가능 쿠폰 자동 추천
        App->>API: 보유 마일리지 조회
        App->>API: 멤버십 등급 할인 계산
    end
    API-->>App: 결제 화면 표시

    Member->>App: 결제수단 선택 (카드 / 카카오페이)
    Member->>App: 쿠폰 선택 (자동 추천 또는 직접)
    Member->>App: 마일리지 입력 (100P 단위)
    App->>App: 합계 실시간 계산
    Member->>App: 결제 동의 + "결제하기"

    App->>PG: 결제 요청 (최종 결제액)
    PG-->>App: PG 결제 페이지
    Member->>PG: 카드 정보 + OTP
    PG->>PG: 결제 승인
    PG-->>App: 승인 번호 + 응답

    App->>API: 결제 완료 처리
    API->>API: 주문 OrderItem 생성 (status=pending)
    API->>API: 마일리지 차감 + 쿠폰 사용 처리
    API->>Push: 결제 완료 푸시 (수업·후기 카테고리)
    Push-->>Member: "결제 완료 - 영수증을 확인해주세요"

    App-->>Member: MA-142 영수증 자동 진입
    Note over Member,App: 명세 + 적립 마일리지 + 환불 정책 안내

    Member->>App: "주문 상세 보기"
    App-->>Member: MA-403 주문 상세 (4단계 timeline)
```

## 결제 합계 계산 순서

1. 상품 합계 (정가 × 수량)
2. 멤버십 등급 할인 적용 (BRONZE 0% ~ VVIP 20%)
3. 쿠폰 할인 적용 (1장만, 최소 결제액 검증)
4. 마일리지 차감 (100P 단위)
5. 최종 결제액 = 위 4단계 합산

## 관리자 발송 결제링크 (admin SCR-S016 → MA-140 재사용)

```mermaid
sequenceDiagram
    actor Staff as 직원
    participant AdminWeb
    participant Channel as SMS/카카오/이메일
    actor Member
    participant App
    participant API
    participant PG

    Staff->>AdminWeb: SCR-S016 → 회원/상품/금액/만료시점 입력 → 발송
    AdminWeb->>Channel: 결제링크 발송
    Channel-->>Member: "결제 안내 — 링크 클릭"
    Member->>App: 링크 탭 → MA-140 (결제링크 모드)
    App->>API: link_token 검증

    alt 유효
        API-->>App: 상품/금액/할인 = 직원 고정값 (편집 불가)
        App-->>Member: 회색 처리된 상품/금액 + 결제수단만 활성
        Member->>App: 결제수단 + 동의 → 결제하기
        App->>PG: 결제 요청
        PG-->>App: 승인
        App->>API: 결제 완료 + SCR-S016 status=completed
        API-->>App: MA-142 영수증 ("결제링크 결제" 출처 배지)
    else 만료 / 이미 결제됨
        API-->>App: 안내 + (이미 결제 시 영수증 직접 진입)
    end
```

**결제링크 핵심 정책**

- 회원이 변경 가능한 항목: 결제수단 선택 + 결제 동의
- 변경 불가: 상품 / 금액 / 할인 / 쿠폰 / 마일리지
- 만료: 직원이 admin에서 설정 (기본 24시간)
- 영수증: "결제링크 결제" 출처 배지 + 발송 직원 정보 노출

## 장바구니 다중 결제 (비례 분배)

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant PG

    Member->>App: MA-401 장바구니 → 항목 선택 → "결제하기"
    App->>App: 선택 항목 합계 계산
    App-->>Member: MA-140 결제하기 (합계 표시)
    Member->>App: 결제수단 + 쿠폰 + 마일리지 → 결제
    App->>PG: 결제 처리
    PG-->>App: 승인
    App->>API: 결제 완료 (다중 항목)
    API->>API: 비례 분배로 항목별 결제액 산출
    API->>API: 항목별 OrderItem 생성
    API-->>App: MA-402 주문 내역 자동 진입
```
