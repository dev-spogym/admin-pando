# X04. 체성분 / FMS 측정 확인 시나리오

> xlsx 항목: #10 인바디 리포트, #11 FMS/체형 리포트, #16 출석/참여 히스토리, #17 만족도 평가

회원이 OT2(FMS 측정) 또는 정기 측정 후 인바디·FMS 리포트를 확인하고, 트레이너 안내 메모를 함께 본다. 수업 후 만족도 평가 흐름 포함.

```mermaid
sequenceDiagram
    actor Member
    actor Trainer
    participant App as 회원앱
    participant TApp as 트레이너앱
    participant API

    Note over Trainer,API: 측정 입력 (트레이너)
    Trainer->>TApp: MA-222 회원 상세 → 체성분 입력
    TApp->>API: 측정 데이터 저장 (체중/체지방/근육량/BMI)
    Trainer->>TApp: FMS 7개 항목 점수 + 분석 메모
    TApp->>API: FMS 결과 저장
    API-->>App: 알림 발송 (수업·후기 카테고리)

    Note over Member,API: 회원이 측정 결과 확인
    App-->>Member: 푸시 "측정 결과가 도착했어요"
    Member->>App: 알림 탭 → MA-132 체성분/FMS
    App->>API: 인바디 + FMS 이력 조회
    API-->>App: 측정 이력 + 변화 그래프 + 코치 메모
    App-->>Member: 인바디 카드 + FMS 점수 + 코치 메모

    Member->>App: "출석 이력 보기"
    App-->>Member: MA-111 출석 이력 + 카테고리 비중 + 분석 카드

    Note over Member,App: 수업 종료 후 후기 작성
    Member->>App: MA-122 → 완료 카드 → "후기 작성"
    App-->>Member: MA-126 수업 후기/만족도
    Member->>App: 별점 + 태그 + 텍스트 입력
    App->>API: 후기 저장
    API->>API: 강사 NPS / 별점 평균 자동 갱신
    API-->>App: 적립 마일리지 (정책 1.8 단가)
    App-->>Member: 토스트 "후기 등록 + 100P 적립"
```

## FMS 점수 안내

| 총점 (0~21) | 분석 |
|---|---|
| 14점 이상 | 양호 (운동 강도 자유) |
| 11~13점 | 보통 (특정 동작 주의) |
| 10점 이하 | 주의 (코치 안내 필수) |

## 후기 → 적립 / 통계 반영

| 항목 | 결과 |
|---|---|
| 후기 작성 | 마일리지 100P 적립 (정책 1.8) |
| 별점 5점 / 텍스트 50자+ | 마일스톤 배지 후보 |
| 강사 NPS | 회원의 추천 의향 점수로 NPS 재계산 |
| 강사 별점 | 5점 평균 자동 갱신 |
