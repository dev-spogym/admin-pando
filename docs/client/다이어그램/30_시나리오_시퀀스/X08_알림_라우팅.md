# X08. 알림 / 라우팅 시나리오

> xlsx 항목: #34 모든 알림 보기, #35 알림 상세 액션

회원에게 발송되는 7개 카테고리 알림이 알림센터(MA-150)에 누적되고, 카드 탭 시 정의된 라우팅 표에 따라 대상 화면으로 이동하는 흐름.

```mermaid
sequenceDiagram
    participant Trigger as 트리거 시스템
    participant API
    participant Push
    actor Member
    participant App

    Note over Trigger,Member: 알림 발송 (예: 만료 D-7)
    Trigger->>API: 만료 D-7 회원 감지
    API->>API: 알림 카테고리 결정 (이용권, warning)
    API->>Push: 푸시 발송
    Push-->>Member: OS 푸시 "이번 주 만료 - 재등록 시 +10% 혜택"

    alt 푸시 직접 탭 (앱 외부)
        Member->>App: 푸시 알림 탭
        App->>App: 카테고리 라우팅 (이용권 → MA-138)
        App-->>Member: MA-138 재등록 추천 직진입
    else 알림센터 진입
        Member->>App: 헤더 알림 아이콘 탭
        App->>API: 알림 목록 조회 (전체/미읽음)
        API-->>App: 카테고리별 알림 카드
        App-->>Member: MA-150 알림센터

        Member->>App: 카테고리 칩으로 필터 (선택)
        Member->>App: 알림 카드 탭

        alt 예약 카테고리
            App-->>Member: MA-122 내 예약 진입
        else 이용권 카테고리
            App-->>Member: MA-131 또는 MA-138 진입
        else 리워드 카테고리
            App-->>Member: MA-136 / MA-137 / MA-500 진입
        else 공지 카테고리
            App-->>Member: MA-152 진입
        else AT-RISK 카테고리
            App-->>Member: MA-138 + MA-153 안내
        else 수업·후기 카테고리
            App-->>Member: MA-126 또는 MA-121 진입
        else 부가시설 카테고리
            App-->>Member: MA-131 또는 MA-151 진입
        end

        App->>API: 알림 읽음 처리
    end

    Note over Member,App: 자동 보관
    Note over App: 읽은 알림 7일 후 자동 보관
```

## 카테고리 → 화면 라우팅 매핑 (정책 1.10)

| 카테고리 | 색상 | 라우팅 대상 |
|----------|------|-------------|
| 예약 | primary | MA-122 |
| 이용권 | warning | MA-131 / MA-138 |
| 리워드 | success | MA-136 / MA-137 / MA-500 |
| 공지 | neutral | MA-152 |
| AT-RISK 케어 | danger | MA-138 / MA-153 |
| 수업·후기 | secondary | MA-121 / MA-126 |
| 부가시설 | info | MA-131 / MA-151 |

## 카테고리별 ON/OFF + 채널

```mermaid
graph LR
    Notify[알림 발송 트리거] --> Check{회원 설정 MA-155 확인}
    Check -->|카테고리 ON| Channel{발송 채널 확인}
    Check -->|카테고리 OFF| Skip[발송 차단]
    Channel -->|앱 푸시 ON| Push[OS 푸시 발송]
    Channel -->|SMS ON| SMS[SMS 발송]
    Channel -->|이메일 ON| Email[이메일 발송]
    Push --> Center[MA-150 알림센터에도 누적]
    SMS --> Center
    Email --> Center
    Center -->|AT-RISK OFF여도| Notice[알림센터 카드는 노출]
```
