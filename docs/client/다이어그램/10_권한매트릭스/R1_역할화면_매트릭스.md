## 핵심 정책

| 정책 | 내용 |
|---|---|
| 단일 역할 | 한 계정은 하나의 회원앱 role만 갖는다 |
| 데이터 접근 범위 | member: 본인 / trainer·golf_trainer·fc: 담당 회원 / staff: 전체 회원 (읽기) |
| 결제 권한 | member만 결제 가능 |
| 본인 정보 수정 | member 본인만 (다른 회원 수정 불가) |
| 직원 → 회원 진입 차단 | trainer / fc / staff 계정으로 회원 화면 진입 불가 |

```mermaid
graph LR
    R[role] --> Member[member]
    R --> Trainer[trainer]
    R --> Golf[golf_trainer]
    R --> FC[fc]
    R --> Staff[staff]

    Member --> M_Scope[본인 데이터만]
    Trainer --> T_Scope[담당 회원 + 본인 수업]
    Golf --> G_Scope[담당 회원 + 본인 수업 + 쌍방서명]
    FC --> F_Scope[담당 리드 + 만료 예정 회원]
    Staff --> S_Scope[전체 회원 읽기 + 수동 출석]
```
