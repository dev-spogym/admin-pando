# N5. 마켓플레이스 (둘러보기) 사이트맵

> 회원이 가입 외 센터를 탐색하는 멀티센터 도메인. 비로그인 일부 열람 가능.

```mermaid
graph TD
    Home[MA-300 둘러보기 홈] --> Around[MA-310 내 주변 센터]
    Home --> Cat[MA-311 카테고리 검색]
    Home --> CenterDetail[MA-312 센터 상세]
    Home --> Map[MA-313 지도 보기]

    Around --> CenterDetail
    Cat --> CenterDetail
    Map --> CenterDetail

    CenterDetail --> Trainer[MA-321 강사 상세 - 마켓]
    CenterDetail --> Scrap[MA-330 찜/스크랩]
    CenterDetail --> Messenger[MA-340 메신저 허브]
    CenterDetail --> Review[MA-351 센터 리뷰 목록]
    CenterDetail --> Pay[MA-400 결제 옵션]

    Home --> TrainerList[MA-320 강사 둘러보기]
    TrainerList --> Trainer

    Messenger --> Chat[MA-341 1:1 대화방]

    Review --> ReviewWrite[MA-350 센터 리뷰 작성]

    Pay --> Cart[MA-401 장바구니]
    Pay --> Checkout[MA-140 결제하기]
    Cart --> Checkout
    Checkout --> Order[MA-402 주문 내역]
    Order --> OrderDetail[MA-403 주문 상세]
    OrderDetail --> Refund[MA-404 환불 신청]
    OrderDetail --> PayMethod[MA-405 결제수단 관리]
```
