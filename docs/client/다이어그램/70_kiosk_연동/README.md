## 키오스크 측 대응 다이어그램

같은 시나리오의 키오스크 시점은 `../../../kiosk/다이어그램/70_client_연동/` 에 있다.

## 표기 규칙

- 회원앱 화면: `SCR-MA-NNN`
- 키오스크 화면: `KIO-NNN`
- admin 화면: `SCR-XXX`
- 직접 통신 없음(원칙): `client ↔ admin ↔ kiosk`
