# A3. 마일리지 만료 자동화

> 마지막 적립일 1년 미사용 시 마일리지 자동 만료. 만료 30일 전 알림 발송.

```mermaid
flowchart TD
    Cron[일배치 Cron] --> Query{회원 마일리지 조회}
    Query --> CheckLast{마지막 적립일 11개월 경과?}
    CheckLast -->|Yes| WarnPush[만료 30일 전 알림 발송]
    CheckLast -->|No| Skip[건너뛰기]

    Cron --> CheckExpire{마지막 적립일 1년 경과?}
    CheckExpire -->|Yes| Expire[마일리지 expired 처리]
    CheckExpire -->|No| Skip

    WarnPush --> NotifyCheck{회원 알림 설정}
    NotifyCheck -->|리워드 카테고리 ON| Push[푸시 + 알림센터]
    NotifyCheck -->|OFF| OnlyCenter[알림센터만]

    Expire --> Log[만료 이력 로그]
    Expire --> NotifyExpire[만료 완료 알림]
```

## 만료 정책

| 단계 | 트리거 | 동작 |
|---|---|---|
| 만료 30일 전 | 마지막 적립 후 11개월 | 회원에게 안내 알림 |
| 만료 시점 | 마지막 적립 후 12개월 | 미사용 마일리지 expired 처리 |
| 만료 후 | - | MA-136 보유에서 차감 + 만료 이력 표시 |

## 만료일 갱신 (재적립 시)

```mermaid
sequenceDiagram
    participant System
    actor Member
    participant API

    Note over Member,API: 만료 30일 전 알림 수신
    System->>Member: "마일리지 1,500P가 30일 후 만료돼요"

    alt 회원이 활동 (적립 이벤트)
        Member->>API: 운동 루틴 완료 / 출석 등
        API->>API: 마일리지 1P라도 추가 적립
        API->>API: 만료일 갱신 (1년 연장)
        API-->>Member: "마일리지 적립 + 만료일 갱신"
    else 회원 사용
        Member->>API: 결제 차감 / 굿즈 교환
        API->>API: 사용 마일리지 used 처리
    else 미사용 / 미적립
        Note over System: 30일 후 자동 만료
        System->>API: expired 처리
    end
```

## 알림 메시지 템플릿

| 단계 | 톤 | 메시지 |
|---|---|---|
| 만료 30일 전 | info | "마일리지 N,000P가 30일 후 만료돼요. 활용처를 확인해 보세요" |
| 만료 7일 전 | warning | "마일리지 N,000P가 곧 만료돼요" |
| 만료 완료 | neutral | "마일리지 N,000P가 만료되었어요" |
