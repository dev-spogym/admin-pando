# 60. admin ↔ client 연동 시퀀스

> 작성일: 2026-05-04
> 기준: `docs/admin/**` (관리자 시스템) ↔ `docs/client/**` (회원앱) 양방향 연동

회원앱(client, MA-*)이 관리자 시스템(admin, SCR-*)과 데이터·화면·정책·알림 측면에서 어떻게 연동되는지 시퀀스 다이어그램으로 정리한다. 회원앱 구축 시 admin 측 의존성 / 발생 이벤트 / 데이터 동기화 시점을 명확히 이해하기 위한 자료.

## 9개 핵심 연동 시나리오

| ID | 제목 | client (MA-*) | admin (SCR-*) | 핵심 |
|---|---|---|---|---|
| C1 | 회원가입 CRM 연동 | MA-001 / MA-002 | SCR-070 / SCR-M002 / SCR-061 | CRM 선등록 회원만 앱 연동 |
| C2 | QR 입장 출석 동기화 | MA-110 / MA-111 | SCR-086 / SCR-I001 / SCR-C014 | 회원 체크인 → admin 즉시 반영 |
| C3 | 예약 승인 차감 | MA-121 / MA-122 / MA-131 | SCR-C001 / C002 / C007 / C012 | 회원 예약 → 강사 승인 → 수업 완료 → 차감 |
| C4 | 결제 매출 집계 | MA-140 / MA-142 / MA-403 | SCR-S003 / S001 / S007 | 회원 결제 → admin 매출 즉시 집계 + 환불 승인 |
| C5 | 체성분 FMS 입력 | MA-132 | SCR-M006 / SCR-I006 (트레이너앱) | 트레이너 입력 → 회원 즉시 조회 |
| C6 | 이용권 D-day 트리거 | MA-131 / MA-138 | SCR-P001 / DLG-M003 / 본사 정책 세트 | admin 정책 세트 → D-14/7/1 자동 알림 |
| C7 | 알림 라우팅 | MA-150 / MA-155 | SCR-072 / SCR-076 / SCR-085 | admin 발송 → 회원 7카테고리 라우팅 |
| C8 | 탈퇴 복구 파기 | MA-158 | DLG-M005 / SCR-097 | 회원 탈퇴 → admin 운영 승인 → 90일 파기 |
| C9 | 건강 데이터 연동 동기화 | MA-159 / MA-132 | SCR-I007 / SCR-M004 | 회원 권한 허용 → 활동 요약 동기화 |

## 작성 규칙

- 모든 시퀀스는 Mermaid `sequenceDiagram` 사용
- 참여자: `Member` / `App(회원앱)` / `API` / `Admin Web` / `Trainer App` / `CRM DB` / `정책 세트` / `Push 시스템`
- 데이터 흐름은 화살표 + 메시지로 명시
- 각 시나리오 끝에 admin / client R&R 분리 표 첨부
