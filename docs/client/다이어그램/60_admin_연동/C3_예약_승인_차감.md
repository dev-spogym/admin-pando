# C3. 예약 → 승인 → 수업 완료 → 차감

> 회원앱(MA-121)에서 PT/OT/GX/Golf 예약 → admin 캘린더(SCR-C001) 즉시 반영 → 강사 승인 → 수업 완료 시점에 PT/OT 잔여 횟수가 admin(SCR-C007)에서 차감 → 회원앱(MA-131) 즉시 갱신.

## 주요 화면

| 시스템 | 화면 |
|---|---|
| client | MA-120/121/122/124 예약 + MA-131 잔여 회차 |
| admin | SCR-C001 수업 캘린더 / SCR-C002 수업 관리 / SCR-C007 횟수 관리 / SCR-C012 대기열 / SCR-C006 강사 근무 |

## 연동 시퀀스 — PT 승인형 예약

```mermaid
sequenceDiagram
    actor Member
    participant App as 회원앱
    participant API
    participant Realtime
    participant AdminWeb as Admin Web
    actor Trainer as 강사
    participant TApp as 트레이너앱
    participant Push

    Member->>App: MA-121 → PT 라디오 → 강사/시간 선택 → "예약 요청"
    App->>API: 예약 생성 (status=requested)
    API->>API: 정원 점검 atomic
    API-->>App: 승인 대기 상태

    par admin 즉시 반영
        API->>Realtime: reservation_created
        Realtime-->>AdminWeb: SCR-C001 캘린더에 승인 대기 카드 노출
        Realtime-->>TApp: 트레이너앱 승인 대기 큐 추가
    end

    API->>Push: 트레이너 푸시
    Push-->>Trainer: "회원 예약 요청"

    alt 트레이너 승인
        Trainer->>TApp: 승인
        TApp->>API: status=confirmed
        API->>Realtime: reservation_confirmed
        Realtime-->>App: MA-122 카드 confirmed로 갱신
        Realtime-->>AdminWeb: SCR-C001 캘린더 확정 색상 변경
        API->>Push: 회원 푸시 (예약 카테고리)
        Push-->>Member: "예약 확정"
    else 트레이너 거절
        Trainer->>TApp: 거절 + 사유
        TApp->>API: status=rejected
        API-->>App: 거절 알림 + 사유
    end

    Note over Member,Trainer: --- 수업일 ---
    Member->>App: MA-110 QR 입장 (수업 시작 30분 전~)
    App->>API: 출석 + 예약 status=in_progress

    Trainer->>TApp: 수업 시작
    Note over Trainer,TApp: 수업 진행
    Trainer->>TApp: 수업 완료 + 강사 서명 (PT/Golf 쌍방서명)
    TApp->>API: 수업 completed

    API->>API: PT 잔여 -1 (SCR-C007 횟수 차감)
    API->>Realtime: usage_decremented
    Realtime-->>App: MA-131 잔여 즉시 갱신 + MA-122 차감 표시
    Realtime-->>AdminWeb: SCR-M004 회원 상세 잔여 갱신 + SCR-S001 매출 통계 (PT 회당 단가)

    alt 잔여 ≤ 3
        API->>Push: 회원 푸시 (이용권 카테고리)
        Push-->>Member: "PT 잔여 3회"
    end
```

## 연동 시퀀스 — GX 정원형 + 대기열

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant Wait as 대기열 (SCR-C012)
    participant AdminWeb
    participant Push

    Member->>App: MA-121 → GX → "예약하기"
    API->>API: 정원 점검

    alt 정원 여유
        API-->>App: confirmed
    else 만석
        App-->>Member: "대기 등록" 활성
        Member->>App: 대기 등록
        API->>Wait: 대기열 추가 + 순번
        AdminWeb-->>AdminWeb: SCR-C012 대기열 관리 화면 갱신
    end

    Note over Wait,Member: 다른 회원 취소 시
    Wait->>API: 1순위 자동 확정
    API->>Push: 회원 푸시
    Push-->>Member: "대기 → 자동 확정"
```

## 데이터 동기화

| 데이터 | 소유 | client 표시 | admin 표시 |
|---|---|---|---|
| 예약 (status / 시간 / 강사) | 양방향 | MA-122 / MA-131 | SCR-C001 / SCR-C002 |
| PT/OT 잔여 횟수 | admin (SCR-C007) | MA-131 + MA-122 | SCR-C007 + SCR-M004 |
| 대기열 순번 | admin (SCR-C012) | MA-124 | SCR-C012 |
| 강사 NPS / 별점 (수업 후 후기 집계) | admin 통계 | MA-125 강사 상세 | SCR-C006 강사 근무 |

## R&R 분리

| 영역 | client | admin |
|---|---|---|
| 회원 예약 / 취소 | ✅ MA-121 | ✅ SCR-C002 (스태프 대신 등록) |
| 트레이너 승인 / 거절 | ❌ | ✅ 트레이너앱 SCR-C002 또는 SCR-C006 |
| 정원 / 대기 정책 | ❌ | ✅ 본사 정책 세트 |
| 횟수 차감 시점 (`completed`) | ❌ (결과만 표시) | ✅ SCR-C007 |
| 노쇼 페널티 | ❌ (조회만) | ✅ SCR-C008 |

## 정책 출처

- **취소 마감 시간** (수업 N시간 전): admin 본사 정책 세트
- **노쇼 누적 페널티** (1회 경고 / 3회 제한): admin 본사 정책 세트
- **PT/OT 차감 시점** (`수업 완료`만): admin 비즈니스 규칙
- **OT 무료 1회 자동 부여**: admin 등록 정책
