# C4. 결제 → admin 매출 집계 + 환불 승인 + 결제링크 발송

> 회원앱(MA-140)에서 결제하면 admin 매출 현황(SCR-S001/S003)에 즉시 집계되고, 회원이 환불 신청(MA-404)하면 admin 환불 관리(SCR-S007)에서 매니저/센터장이 승인한다. 추가로 직원이 admin SCR-S016에서 결제링크를 발송하면 회원이 MA-140 진입 → 편집 불가 모드로 결제 → MA-142 영수증 → MA-402/403 주문 자동 편입된다.

## 주요 화면

| 시스템 | 화면 |
|---|---|
| client | MA-134 / MA-138 / MA-140 / MA-141 / MA-142 / MA-401 / MA-403 / MA-404 / MA-405 |
| admin | SCR-S001 매출 현황 / SCR-S003 결제 처리 / SCR-S007 환불 관리 / SCR-S012 결제 취소 / SCR-S006 선수익금 / SCR-S016 결제링크 발송 |

## 연동 시퀀스 — 회원 결제

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    participant PG as 토스페이먼츠
    participant Realtime
    participant AdminWeb as Admin Web

    Member->>App: MA-140 결제 진입
    par 결제 화면 데이터 로드
        App->>API: 결제수단(MA-405) / 쿠폰(SCR-073) / 마일리지(SCR-074) / 등급 할인(SCR-M009) 조회
    end
    Member->>App: 결제수단 + 쿠폰 + 마일리지 + 동의
    App->>PG: 결제 요청
    PG-->>App: 승인
    App->>API: 결제 완료
    API->>API: OrderItem INSERT (status=pending)
    API->>API: 마일리지 차감 + 쿠폰 사용 처리
    API->>API: 매출 집계 (SCR-S001) + 회원 등급 누적액 갱신

    par 실시간 admin 반영
        API->>Realtime: payment_completed
        Realtime-->>AdminWeb: SCR-S001 매출 카드 즉시 +
        Realtime-->>AdminWeb: SCR-S003 결제 처리 목록 갱신
        Realtime-->>AdminWeb: SCR-094 KPI 매출 차트
        Realtime-->>AdminWeb: SCR-S006 선수익금 (기간형 상품)
    end

    App-->>Member: MA-142 영수증 자동 진입
```

## 연동 시퀀스 — 환불 신청 + admin 승인

```mermaid
sequenceDiagram
    actor Member
    participant App
    participant API
    actor Manager as 매니저/센터장
    participant AdminWeb
    participant PG
    participant Push

    Member->>App: MA-403 → "환불 신청" → MA-404
    Member->>App: 사유 + 추가 의견 + 동의
    App->>API: 환불 요청 (status=refund_requested)
    API->>API: 회차/기간 비율로 예상 환불액 산출
    API->>AdminWeb: SCR-S007 환불 관리 큐에 추가

    Note over Manager: admin 운영 승인 단계
    Manager->>AdminWeb: SCR-S007 → 환불 검토
    Manager->>AdminWeb: 승인 또는 반려

    alt 승인
        AdminWeb->>API: 환불 승인
        API->>PG: 환불 처리 (부분 또는 전체)
        PG-->>API: 환불 완료
        API->>API: OrderItem status=refunded + 마일리지 복원 + 매출 차감
        API->>Push: 회원 푸시
        Push-->>Member: "환불 완료 — 영수증 확인"
        App-->>Member: MA-403 timeline에 "환불 완료" 표시
    else 반려
        AdminWeb->>API: 반려 + 사유
        API->>Push: 회원 푸시 + 반려 사유
        Push-->>Member: "환불 반려 — 1:1 문의"
    end
```

## 연동 시퀀스 — 관리자 발송 결제링크

```mermaid
sequenceDiagram
    actor Staff as 직원 (FC/매니저)
    participant AdminWeb as Admin Web
    participant API
    participant Channel as SMS / 카카오 / 이메일
    actor Member
    participant App
    participant PG as 토스페이먼츠

    Note over Staff,AdminWeb: 직원이 결제링크 발송
    Staff->>AdminWeb: SCR-S016 결제링크 발송
    Staff->>AdminWeb: 회원 검색 + 상품/금액/할인 입력 + 만료시점 설정
    AdminWeb->>API: 결제링크 INSERT (status=sent, link_token, 만료시점)
    API->>Channel: 회원에게 SMS / 카카오 / 이메일 발송
    Channel-->>Member: "FitGenie 결제 안내 — 링크 클릭"

    Note over Member,App: 회원 진입
    Member->>App: 결제링크 탭 → MA-140 (결제링크 모드)
    App->>API: link_token 검증 + 만료 점검

    alt 유효
        API-->>App: 상품/금액/할인 = 직원 고정 값 + 회원 결제수단/마일리지 조회
        App-->>Member: 편집 불가 화면 (회색 영역) + 결제수단 선택 + "결제하기"
        Member->>App: 결제수단 선택 → 결제 동의 → 결제하기
        App->>PG: 결제 요청
        PG-->>App: 승인
        App->>API: 결제 완료
        API->>API: OrderItem INSERT + SCR-S016 결제링크 status=completed
        API->>API: 매출 집계 (SCR-S001) + 회원 등급 누적액 갱신
        API-->>App: MA-142 영수증 ("결제링크 결제" 출처 배지)
        App->>API: MA-402/403 주문 내역 자동 편입
    else 만료
        API-->>App: 만료 안내 + 1:1 문의 진입
    else 이미 결제 완료
        API-->>App: "이미 결제된 링크입니다" + MA-142 진입
    end
```

## 결제링크 정책

| 항목 | 정책 |
|---|---|
| 편집 가능 항목 | 결제수단 선택 + 결제 동의 (only) |
| 편집 불가 항목 | 상품 / 금액 / 할인 / 쿠폰 / 마일리지 |
| 만료 시점 | 직원이 admin에서 설정 (기본 24시간) |
| 결제 완료 후 | 동일 링크 재진입 시 영수증으로 라우팅 |
| OrderItem 편입 | 회원 결제와 동일 4단계 timeline |
| 영수증 표기 | "결제링크 결제" 출처 배지 + 발송 직원 정보 |

## 데이터 동기화

| 데이터 | 발생 | client 표시 | admin 표시 |
|---|---|---|---|
| OrderItem (결제 → timeline) | 회원 결제 즉시 | MA-402 / MA-403 | SCR-S003 |
| 결제링크 (link_token / status) | admin 발송 → 회원 결제 | MA-140 진입 / MA-142 영수증 | SCR-S016 발송 이력 |
| 매출 집계 | 결제 즉시 | (조회 X) | SCR-S001 / SCR-094 KPI |
| 마일리지 차감 | 결제 즉시 | MA-136 | SCR-074 |
| 쿠폰 사용 | 결제 즉시 | MA-135 | SCR-073 |
| 환불 (status / 비율) | admin 승인 후 | MA-403 / MA-142 | SCR-S007 / SCR-S012 |
| 회원 누적 결제액 | 결제 즉시 | MA-500 등급 진척 | SCR-M009 등급 관리 |

| 영역 | client | admin |

| 결제 | ✅ MA-140 | ✅ SCR-S003 (수기 결제) |

| 환불 승인 | ❌ | ✅ SCR-S007 (매니저/센터장) |

| 결제링크 진입 / 결제 | ✅ MA-140 (편집 불가 모드) | ❌ |

## 정책 출처

- **환불 비율** (회차형 잔여 비율 / 기간형 7일 100% / 30일 70% / 30일+ 30%): admin 본사 환불 정책
- **결제수단 종류** (카드 / 카카오페이 / 네이버페이): admin 결제 정책
- **마일리지 사용 단위** (100P): admin 마일리지 정책 (SCR-074)
