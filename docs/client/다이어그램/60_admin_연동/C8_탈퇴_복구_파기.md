# C8. 회원 탈퇴 → admin 운영 승인 → 90일 파기

> 회원이 회원앱(MA-158)에서 탈퇴 신청 → admin 회원 상세(DLG-M005)에서 운영 승인 → 즉시 비활성 + 90일 후 자동 파기. 90일 내 회원 복구(Undelete)도 가능.

## 주요 화면

| 시스템 | 화면 |
|---|---|
| client | MA-158 회원 탈퇴 / MA-001 (탈퇴 후 라우팅) |
| admin | DLG-M005 탈퇴 처리 다이얼로그 / SCR-M001 회원 목록 (삭제·탈퇴 회원 보기 토글) / SCR-097 감사 로그 |
| 자동화 | NFR-06 회원 탈퇴 90일 파기 (admin 자동화 크론) |

## 연동 시퀀스

```mermaid
sequenceDiagram
    actor Member
    participant App as 회원앱
    participant API
    actor Manager as 매니저/센터장
    participant AdminWeb as Admin Web
    participant Cron as 자동화 크론
    participant Audit as 감사 로그

    Note over Member,App: A. 회원 탈퇴 신청 (앱)
    Member->>App: MA-155 → "회원 탈퇴" → MA-158
    App->>API: 잔여 자산 조회 (잔여 회차 / 마일리지 / 진행 주문)
    API-->>App: 잔여 표시
    App-->>Member: 탈퇴 전 안내 카드 (환불 / 마일리지 소멸 / 주문 환불)
    Member->>App: 탈퇴 사유 + 추가 의견 + 동의 3건
    App->>API: 탈퇴 요청 (status=withdrawal_requested)
    API->>AdminWeb: DLG-M005 탈퇴 큐에 추가
    API->>Audit: 감사 로그 INSERT (탈퇴 신청)
    App-->>Member: "운영 승인 후 처리됩니다" + 자동 로그아웃 → MA-001

    Note over Manager,AdminWeb: B. admin 운영 승인
    Manager->>AdminWeb: SCR-M001 → 탈퇴 큐 → 회원 검토
    Manager->>AdminWeb: 잔여 회차 환불 처리 (SCR-S007 환불 관리)
    Manager->>AdminWeb: 마일리지 소멸 확인
    Manager->>AdminWeb: DLG-M005 → 탈퇴 승인

    AdminWeb->>API: 회원 status=withdrawn + 비활성
    API->>API: 마일리지 / 쿠폰 / 진행 예약 정리
    API->>Audit: 감사 로그 INSERT (탈퇴 승인 + 매니저 ID + 일시)
    API->>API: scheduled_purge_at = +90일 설정

    Note over Cron: C. 90일 후 자동 파기
    loop 매일 새벽
        Cron->>API: scheduled_purge_at <= 오늘 회원 조회
        API->>API: 개인정보 마스킹 + 영구 삭제
        API->>Audit: 감사 로그 INSERT (파기 완료)
        API-->>AdminWeb: SCR-M001 회원 목록에서 완전 제거
    end
```

## 연동 시퀀스 — 회원 복구 (Undelete)

```mermaid
sequenceDiagram
    actor Manager
    participant AdminWeb
    participant API
    participant Audit

    Note over Manager,AdminWeb: 90일 내 복구만 가능
    Manager->>AdminWeb: SCR-M001 → "삭제·탈퇴 회원 보기" 토글 ON
    AdminWeb-->>Manager: 탈퇴 회원 별도 섹션 표시
    Manager->>AdminWeb: 회원 선택 → DLG-M005 → "복구"
    AdminWeb-->>Manager: 복구 확인 다이얼로그
    Manager->>AdminWeb: 복구 확정
    AdminWeb->>API: status=active 복구
    API->>API: 회원 데이터 + 이용권 (만료 회수 가능 시) + 마일리지 복원 검토
    API->>Audit: 감사 로그 INSERT (복구 + 매니저 ID)
    API-->>AdminWeb: 회원 목록 일반 섹션으로 복귀

    Note over Manager: 회원이 다시 앱 로그인 가능
```

## 데이터 동기화

| 데이터 | 시점 | client 영향 | admin 영향 |
|---|---|---|---|
| 탈퇴 신청 | 회원 즉시 | 자동 로그아웃 + MA-001 | DLG-M005 큐 |
| 탈퇴 승인 | admin 매니저 | 로그인 차단 | SCR-M001 비활성 |
| 잔여 환불 | 매니저 처리 | 영수증에 환불 표시 | SCR-S007 환불 |
| 90일 파기 | 자동 크론 | (이미 차단) | SCR-M001 완전 제거 + 감사 로그 |
| 복구 | 매니저 90일 내 | 다시 로그인 가능 | 회원 active 복구 |

## R&R 분리

| 영역 | client | admin |
|---|---|---|
| 탈퇴 신청 | ✅ MA-158 | ❌ |
| 잔여 환불 처리 | ❌ | ✅ SCR-S007 |
| 탈퇴 승인 | ❌ | ✅ DLG-M005 (매니저/센터장) |
| 90일 파기 자동화 | ❌ | ✅ NFR-06 크론 |
| 회원 복구 | ❌ | ✅ DLG-M005 + 90일 내만 |
| 감사 로그 | ❌ (조회 X) | ✅ SCR-097 (append-only) |

## 정책 출처

- **탈퇴 신청 → 즉시 삭제 X / 운영 승인 후 처리**: admin 운영 정책
- **90일 파기 정책 (NFR-06)**: 본사 / 법적 보존 기간
- **복구 가능 기간**: 90일 내 (admin 운영 정책)
- **감사 로그 append-only**: admin 정책 (SCR-097)
