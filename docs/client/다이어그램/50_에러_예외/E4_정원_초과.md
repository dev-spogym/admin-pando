# E4. 정원 초과 / 대기 등록 예외

> 수업 정원 만석 시 예약 차단 + 대기 등록 유도. 동시 예약 충돌 atomic 처리.

```mermaid
flowchart TD
    Reserve[회원 예약 시도] --> CheckCapacity{정원 점검 atomic}
    CheckCapacity -->|여유| Confirm[예약 confirmed]
    CheckCapacity -->|만석| ShowWait[대기 등록 안내]

    ShowWait --> Choose{회원 선택}
    Choose -->|대기 등록| AddWait[대기열 추가 + 순번 N]
    Choose -->|취소| Cancel[이전 화면 복귀]

    AddWait --> ShowQueue[MA-124 대기 예약 관리 + 순번 표시]

    %% 자동 확정
    Other[다른 회원 취소 / 노쇼] --> Notify[대기 1순위 자동 확정]
    Notify --> PushMember[1순위 회원 푸시]
    Notify --> Update[예약 confirmed 변경]
```

## 동시 예약 충돌 처리

```mermaid
sequenceDiagram
    actor MemberA
    actor MemberB
    participant API
    participant DB

    par 동시 예약
        MemberA->>API: 예약 시도 (수업 ID)
        MemberB->>API: 예약 시도 (수업 ID)
    end

    API->>DB: SELECT FOR UPDATE (정원 카운터)
    DB-->>API: 잔여 1
    API->>DB: 잔여 -1, 예약 INSERT
    DB-->>API: 커밋

    Note over API: A 먼저 처리
    API-->>MemberA: 예약 확정

    API->>DB: SELECT FOR UPDATE
    DB-->>API: 잔여 0 (B 진입 시)
    API-->>MemberB: 정원 만석 → 대기 등록 안내
```

## 대기열 자동 확정 흐름

```mermaid
sequenceDiagram
    actor Other as 다른 회원
    participant API
    participant Wait as 대기열
    participant Push
    actor Member

    Other->>API: 예약 취소
    API->>API: 정원 -1 → 잔여 1 발생
    API->>Wait: 대기열 1순위 조회
    Wait-->>API: Member ID
    API->>API: Member 예약 confirmed 자동 변경
    API->>Push: Member에게 푸시 (예약 카테고리)
    Push-->>Member: "GX 예약이 자동 확정되었어요"
    Member->>App: 알림 탭 → MA-122 진입
```

## 화면 표시

| 상태 | 표시 |
|---|---|
| 정원 여유 | "예약하기" 활성 (primary) |
| 정원 만석 | "예약하기" 비활성 + "대기 등록" 활성 (warning) |
| 대기 1순위 | MA-124 카드 강조 + "다음 자리 확보 시 자동 확정" 안내 |
| 자동 확정 | 푸시 + MA-122 카드 강조 + 토스트 |

## 노쇼 페널티 누적

| 누적 | 처리 |
|---|---|
| 1회 | 경고 알림만 |
| 3회 | 예약 제한 (1주 / 2주, 센터 설정) |
| 면제 | 강사 수동 면제 가능 |
