# E2. 서버 점검 예외

> 서버 점검 모드(503 + maintenance) 시 회원에게 점검 시간 안내 + 보호 라우트 차단 흐름.

```mermaid
flowchart TD
    Request[API 호출] --> Status{응답 상태}
    Status -->|503 + maintenance| ShowMaint[MA-902 점검 안내 진입]
    Status -->|정상| Continue[정상 진행]

    ShowMaint --> Block[보호 라우트 차단]
    Block --> Allow{허용 라우트}
    Allow -->|MA-152 공지| Notice[공지 진입]
    Allow -->|MA-153 1:1 문의| Inquiry[문의 진입]
    Allow -->|기타| Blocked[차단 + 안내]

    ShowMaint --> Action{회원 액션}
    Action -->|공지 보러 가기| Notice
    Action -->|고객센터| Inquiry
    Action -->|닫기| Background[앱 백그라운드]
```

## 화면 구성 (MA-902)

| 영역 | 내용 |
|---|---|
| 일러스트 | 수리 / 점검 모티프 |
| 헤드라인 | "시스템 점검 중이에요" |
| 점검 정보 박스 | 점검 시간 (시작 ~ 종료), 점검 사유 (1~2줄), 예상 종료 시각 |
| 주요 CTA | "공지 보러 가기" → MA-152 |
| 보조 액션 | "고객센터" → MA-153 |
| 하단 | "점검이 끝나면 자동으로 이용 가능해집니다" |

## 차단 / 허용 라우트

| 라우트 | 점검 모드 |
|---|---|
| MA-100 / MA-110 / MA-120~ / 결제 / 예약 / 메신저 | 차단 |
| MA-152 공지사항 | 허용 |
| MA-153 1:1 문의 | 허용 |
| MA-902 점검 안내 | 기본 |

## 점검 시작 / 종료 흐름

```mermaid
sequenceDiagram
    participant Ops as 운영팀
    participant API
    actor Member
    participant App

    Note over Ops,API: 점검 시작
    Ops->>API: maintenance 모드 ON + 점검 시간 설정
    API-->>App: 다음 요청부터 503 + maintenance 응답
    App->>App: MA-902 자동 진입
    App-->>Member: 점검 안내 화면

    alt 회원이 화면 닫기
        Member->>App: 백그라운드 또는 앱 종료
    else 공지 / 문의
        Member->>App: 허용 라우트 진입
    end

    Note over Ops,API: 점검 종료
    Ops->>API: maintenance 모드 OFF
    Member->>App: 앱 다시 진입
    App->>API: 요청 → 정상 응답
    App-->>Member: 원래 화면 (홈 / 직전 화면) 자동 진입
```
