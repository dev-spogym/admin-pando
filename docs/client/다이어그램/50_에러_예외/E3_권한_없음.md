# E3. 권한 없음 / 비로그인 게이트

> 비로그인 회원이 보호 액션(결제 / 스크랩 / 리뷰 / 메신저 / 추천 코드 입력) 시도 시 LoginGateModal로 차단 + 로그인 유도.

```mermaid
flowchart TD
    Action[보호 액션 시도] --> Auth{로그인 여부}
    Auth -->|로그인| Allow[정상 진행]
    Auth -->|비로그인| ShowGate[LoginGateModal 표시]

    ShowGate --> Context{시도한 액션 컨텍스트}
    Context -->|결제| TextPay["결제는 회원 로그인 후 가능해요"]
    Context -->|스크랩| TextScrap["스크랩은 회원 로그인 후 가능해요"]
    Context -->|리뷰 작성| TextReview["리뷰는 회원 로그인 후 작성할 수 있어요"]
    Context -->|메신저| TextMsg["메신저는 회원 로그인 후 이용 가능해요"]

    ShowGate --> ChooseAction{회원 선택}
    ChooseAction -->|로그인| Login[MA-001 라우팅 + returnUrl 보존]
    ChooseAction -->|회원가입| SignUp[MA-002 진입]
    ChooseAction -->|닫기| Close[직전 컨텍스트 복귀]

    Login --> AfterAuth{인증 결과}
    AfterAuth -->|성공| Restore[returnUrl 자동 복귀 + 원 액션 실행]
    AfterAuth -->|실패| Login
```

## LoginGateModal 구성 (MFN-9C1)

| 영역 | 내용 |
|---|---|
| 일러스트 | 잠금 / 로그인 모티프 |
| 헤드라인 | "로그인이 필요한 기능이에요" |
| 보조 설명 | 컨텍스트별 동적 텍스트 |
| 듀얼 CTA | 로그인 (primary) + 회원가입 (보조) |
| 우상단 X | 닫기, 직전 컨텍스트 복귀 |

## returnUrl 보존 시나리오

```mermaid
sequenceDiagram
    actor Visitor
    participant App
    participant API

    Visitor->>App: MA-312 센터 상세 (비로그인 열람)
    Visitor->>App: "결제하기" CTA
    App-->>Visitor: LoginGateModal (결제 컨텍스트)
    Visitor->>App: "로그인"
    App->>App: returnUrl=/center/312/checkout 저장
    App-->>Visitor: MA-001 로그인 화면
    Visitor->>API: 인증
    API-->>App: 토큰
    App->>App: returnUrl 복원
    App-->>Visitor: MA-312 결제 진입 자동 복귀
```

## 회원앱 role 미스매치

직원 계정으로 회원 화면 진입 시도 시:
- `member` 전용 화면(MA-100/127/130 등) 접근 차단
- "직원 계정으로는 이 화면을 이용할 수 없습니다" 안내
- 직원 홈으로 라우팅
