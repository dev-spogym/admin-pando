# FitGenie 회원앱 화면설계서 — 공통 · 회원

> 작성일: 2026-05-04
> 버전: 3.1
> 문서 성격: 기획/퍼블리싱 기준 + 체크리스트 정합성 보강
> 기준: `APP-IA.md`, `기능명세서/01-공통-회원.md`

---

## 1. 문서 사용 원칙

- 이 문서는 `화면 기획 기준 문서`다.
- 각 화면은 회원이 이해해야 할 구조와 퍼블리싱 기준을 우선해 정리한다.
- 체크리스트 항목이 빠지지 않도록 `화면 ID ↔ 체크리스트` 연결을 명시한다.
- 기술 구현 방식, 파일 구조, 경로 정보는 이 문서 범위에서 제외한다.

## 2. 공통 화면

| 화면 ID | 화면명 | 목적 | 핵심 요소 |
|---|---|---|---|
| MA-001 | 로그인 | 회원 로그인 / 직원 로그인 분기 | 회원 전화번호 로그인, 직원 아이디 로그인, 직원 유형 선택 |
| MA-002 | 앱 가입 / 연동 | CRM 회원의 앱 연동 완료 | 이름/전화 확인, 휴대폰 인증, 비밀번호 설정 |

### 공통 정책 메모

- 회원 기본 생성은 CRM에서 이뤄진다.
- 앱에서는 `휴대폰 인증 기반 연동`으로 가입을 완료한다.
- 공개형 즉시 회원 생성은 현재 기본 시나리오가 아니다.
- 로그인은 `회원 로그인`과 `직원 로그인`으로 나뉜다.
- 직원 로그인은 `트레이너`, `FC`, `스태프` 직군 선택 후 아이디/비밀번호로 인증한다.
- `golf_trainer` 계정은 로그인 화면에서는 `트레이너` 계열로 묶어 진입한다.
- 회원은 트레이너의 가능 시간을 보고 PT/골프 레슨을 요청할 수 있다.
- 회원이 직접 만든 트레이너 대상 예약은 `트레이너 승인 대기`를 기본 상태로 한다.
- 트레이너가 자신의 스케줄에서 회원을 직접 지정해 일정을 만들면 즉시 확정으로 처리한다.

## 4. 핵심 화면 설계 요약

### 4.1 MA-001 로그인

**목적**

- 회원과 직원이 동일 앱 안에서 본인 역할에 맞는 로그인 경로로 진입한다.

**필수 요소**

- 상단 탭: 회원 로그인 / 직원 로그인
- 회원 입력: 전화번호, 비밀번호
- 직원 입력: 직원 유형(트레이너/FC/스태프), 아이디, 비밀번호
- 로그인 성공 후 역할별 기본 홈 이동
- 회원 전용 `앱 연동하기` 링크

### 4.2 MA-100 홈

**목적**

- 회원이 가장 자주 쓰는 `예약`, `출석`, `리워드`, `온보딩`, `공지`를 한 화면에서 본다.

**필수 요소**

- PT 예약 바로가기
- GX 스케줄 바로가기
- Golf 예약 바로가기
- 마일리지/배지 요약 카드
- 공지/이벤트 배너
- 오늘 수업 요약
- 이번 달 출석 요약
- 온보딩 또는 추천 루틴 카드

### 4.3 MA-121 수업 상세 / 예약

**목적**

- 예약 여부, 정원 현황, 강사 진입, 대기 등록 진입을 한 곳에서 처리한다.
- PT, OT1, OT2, GX, Golf 수업 유형별 분기 동작을 한 화면에서 처리한다.

**필수 요소**

- 수업 유형 라디오 / 탭: `PT / OT1 / OT2 / GX / Golf`
- 수업명, 시간, 장소, 강사
- 정원 / 잔여석
- 예약하기 / 예약취소
- 트레이너 승인 필요 시 예약 요청 상태
- 대기열 등록
- 강사 상세 보기

**수업 유형별 분기**

| 유형 | 표기 | 차감 안내 | 동작 |
|---|---|---|---|
| PT | "PT 정규 1회" | "수업 완료 시 PT 잔여 1회 차감" | 회원 자유 시간 선택 → 트레이너 승인 대기 |
| OT1 | "신규 1차 OT" | "OT 잔여 1회 차감 (없으면 무료 1회 자동)" | 등록 직후 즉시 확정, 30일 권장 안내 |
| OT2 | "2차 OT" | "OT 잔여 1회 차감, OT1 완료 후 진입" | OT1 미완료 시 비활성 + 안내 |
| GX | "GX 그룹 클래스" | "정원 자동 확정 / 만석 시 대기" | 정원 점검 → 즉시 확정 또는 대기열 |
| Golf | "골프 강사 / 타석" | 강사: 승인 대기 / 타석: 즉시 확정 | 강사 슬롯 또는 타석 선택 분기 |

**예외 / 빈 상태**

- OT2 진입 시 OT1 미완료: `1차 OT를 먼저 진행해주세요` + `OT1 예약하기` CTA
- OT/PT 잔여 0회: `잔여 회차가 없어요` + `재등록 추천(MA-138)` CTA
- 정원 만석: `대기 등록`만 활성

### 4.4 MA-122 내 예약 / 수업 이력

**목적**

- 회원이 내 수업 일정, 골프 예약 일정, 승인 대기 상태, 완료 이력을 한 화면에서 확인한다.

**필수 요소**

- 서비스 필터: 전체 / PT / GX / Golf
- 상태 필터: 승인 대기 / 확정 / 완료 / 취소
- 리스트 또는 캘린더 전환
- 트레이너명 / 수업일 / 시간 / 상태
- 후기 작성 진입

### 4.5 MA-123 Golf 예약 / 골프 강사 예약 / 타석 선택

**목적**

- 골프 회원이 `강사 레슨 예약`과 `타석 예약`을 하나의 화면 안에서 처리한다.

**필수 요소**

- 골프 강사 예약 탭
- 강사명 / 레슨명 / 시간대 / 타석 / 가격
- 내 골프 레슨 예약 목록 / 일정
- 골프 타석 예약 탭
- 타석 상태 표시, 만석 시 대기 등록
- 레슨권 / 이용권 구매 CTA

### 4.6 MA-124 대기 예약 관리

**목적**

- 회원이 대기 순번과 자동 확정 상태를 직접 확인하고 취소한다.

**필수 요소**

- 수업명, 일시, 강사
- 현재 순번
- 자동 확정 여부
- 대기 취소

### 4.7 MA-125 강사 상세

**목적**

- 예약 전 강사의 전문분야, NPS 만족도, 별점, 후기 요약, 가능 수업을 확인한다.

**필수 요소**

- 강사 프로필: 사진, 강사명, 경력, 자격증
- 전문분야 카테고리 칩 (다중): `다이어트 / 체형교정 / 통증관리 / 근비대 / 재활 / 자세교정 / 골프 스윙 / 골프 퍼팅 / 필라테스 / 요가`
- NPS 점수 카드: 0~100 점수 + 색상 분기 (70+ promoter / 30~69 passive / 30 미만 detractor)
- 별점 평균 (5점 만점) + 후기 수
- 최근 후기 요약 3건 (별점 + 한줄)
- 담당 수업 목록 (수업명, 유형, 정원, 다가오는 일정, 예약 가능 여부)
- 예약 가능한 시간대 요약
- 예약 요청 CTA

**예외 / 빈 상태**

- 후기 0건: `아직 후기가 없어요` + NPS/별점 영역 회색 처리
- 담당 수업 없음: `현재 담당 수업이 없어요` + 강사톡 진입 CTA

### 4.8 MA-126 수업 후기 / 만족도

**목적**

- 완료 수업에 대해 별점, 태그, 한줄 후기, 추천 의향을 받는다.

**필수 요소**

- 별점 1~5
- 빠른 태그
- 한줄 후기
- 추천 의향 점수

### 4.9 MA-127 ~ MA-128 온보딩

**목적**

- `운동 목적/성향`, `통증/체형 정보`, `첫 루틴 제안`을 단계별로 입력받는다.

**MA-127 단계 구성 (3페이지)**

| 페이지 | 입력 항목 | 옵션 풀 |
|---|---|---|
| 1 / 목적·성향 | 운동 목적 (다중), 운동 성향 (단일), 강도 선호 (단일), 선호 요일·시간 (다중) | 목적: 감량 / 근비대 / 체형교정 / 통증완화 / 체력증진 / 자세교정 / 재활 / 대회 준비 / 성향: 강하게 끌어주세요 / 친절하게 안내 / 조용한 운동 / 그룹 분위기 / 자율 운동 / 강도: 저·중·고강도 |
| 2 / 통증·부상 | 통증 부위 (다중), 과거 부상 (다중+직접 입력), 불편한 동작 (다중) | 부위: 목·어깨·등·허리·골반·무릎·발목·손목·팔꿈치·없음 / 부상: 디스크·회전근개·십자인대·발목인대·골절·수술·기타·없음 / 동작: 스쿼트·데드리프트·푸쉬업·풀업·러닝·점프·회전·없음 |
| 3 / 체형·집중 | 체형 (단일), 집중 부위 (다중) | 체형: 상체비만 / 하체비만 / 복부비만 / 마른비만 / 표준 / 근육형 / 집중: 복부·등·어깨·가슴·팔·엉덩이·다리·종아리 |

**필수 요소 (공통)**

- 진행 단계 인디케이터 (1/3 → 3/3)
- 각 페이지 상단 헤드라인 + 보조 설명
- 옵션 칩 (선택 시 active 상태)
- 하단 듀얼 CTA: `이전` (보조) + `다음 / 입력 완료` (primary)
- 우상단 `나중에 입력` 링크 (모든 페이지에서 노출)

**MA-128 — 온보딩 완료 / 첫 루틴**

- 입력 요약 카드 (목적·성향·통증·체형 4개 영역 요약)
- 입력 완료율 표시 (예: 80% — 정확도 안내 함께)
- 첫 루틴 카드 3종 제안 (예: `목적 맞춤형 / 통증 회복형 / 균형 강화형`)
- 카드 액션: `루틴 시작 / 트레이너에게 공유`
- 다음 단계 안내: `MA-100 홈으로 이동` 또는 `OT1 예약 진입`

### 4.10 MA-132 체성분 / FMS

**목적**

- 인바디와 FMS/체형 정보를 한 도메인 안에서 본다.

**필수 요소**

- 최근 체성분 요약
- 측정 이력
- FMS 총점
- 세부 항목 점수
- 코치 메모

### 4.11 MA-131 이용권 / 잔여 회차

**목적**

- 회원이 회원권 만료일, PT·OT 잔여 횟수, 락커, 부가옵션을 한 화면에서 확인한다.

**섹션 구성**

| 섹션 | 표시 정보 |
|---|---|
| 회원권 카드 | 회원권 종류 (헬스 자유이용 / 헬스+골프 / PT 통합 등), 시작일, 만료일, 만료까지 D-day |
| PT 잔여 카드 | 총 회차 / 사용 / 잔여, 최근 차감 일자, 다음 예약 예정 |
| OT 잔여 카드 | OT1·OT2 분리 표시 (잔여 / 완료 / 미진행), OT 추가권 구매 CTA |
| 락커 카드 | 락커 번호, 사용 시작일, 만료일, 만료 D-day, 연장 결제 CTA |
| 부가옵션 카드 | 운동복 (ON/OFF + 잔여 횟수), 수건 (ON/OFF + 잔여 횟수), 사우나 (ON/OFF + 잔여 횟수) |

**필수 요소**

- 차감 기준 안내 배너: `PT/OT 횟수는 수업 완료 시점에만 차감됩니다`
- 만료 D-14/D-7/D-1 트리거 시 상단 강조 배너 + `재등록 추천(MA-138)` CTA
- 각 카드별 액션: 예약 화면(MA-121) / 재등록 추천(MA-138) / 부가옵션 결제(MA-141)
- 비고 카드: `최근 차감 이력 5건` (수업명 + 일시 + 강사) → 더보기는 MA-122

**예외 / 빈 상태**

- 회원권 미보유: `회원권을 등록해 주세요` + 상품 스토어 진입
- PT/OT 잔여 0: 회색 카드 + `재등록 추천` 강조
- 락커 미사용: `락커 사용 안 함` + 락커 신청 CTA
- 만료 직전 (D-1): 카드 테두리 빨강 + 상단 알림 강조

### 4.14 MA-138 재등록 추천 플랜

**목적**

- 회원이 만료 D-14/D-7/D-1 트리거 시점 또는 직접 진입 시 추천 플랜 3종을 비교한다.

**상단 섹션 — D-day 트리거 표시**

| 트리거 시점 | 배너 톤 | 배너 문구 |
|---|---|---|
| D-14 | 보조 (info) | `회원권 만료 14일 전 — 미리 준비해 주세요` |
| D-7 | 강조 (warning) | `이번 주 만료 — 재등록 시 +10% 혜택` |
| D-1 | 위험 (danger) | `내일 만료 — 마지막 안내` |
| 임의 진입 | 기본 (neutral) | `이용권 추천 플랜을 확인해 보세요` |

**추천 플랜 3종 카드**

| 추천 유형 | 배지 | 표시 정보 |
|---|---|---|
| AI 추천 | `당신에게 딱 맞는 플랜` (primary) | 회원 활동 기반 산정 회차, 가격, 추천 사유 1줄 |
| 균형형 | `가장 많이 선택` (success) | 평균 기준 회차, 가격, 일반 혜택 |
| 경제형 | `가성비` (warning) | 최소 회차 + 최대 할인 적용, 가격, 절감액 |

**필수 요소**

- D-day 인디케이터 (만료까지 남은 일수, 큰 숫자)
- 추천 플랜 3종 카드 (가로 또는 세로 비교)
- 각 카드: 플랜명 / 회차(4 / 8 / 16) / 가격 / 단가 배수 / 혜택 리스트 / 추천 사유 / `이 플랜으로 결제` CTA
- 비교 표 (확장형) — 전체 플랜 가격, 회차, 1회 단가, 사용 기간 비교
- 마일리지 사용 가능액 미리보기
- `다른 상품 보기` → MA-134 상품 스토어 진입

**예외 / 빈 상태**

- 만료 D-14 이전 + 임의 진입: 배너 톤 neutral, 추천 플랜은 동일하게 노출
- 만료 후 + 미재등록: 배너 `만료된 회원권을 갱신해 주세요` + AT-RISK 케어 메시지 노출
- 회원 활동 데이터 0건: AI 추천 카드를 일반 추천으로 대체

**알림 연계**

- 정책 1.9의 D-14/D-7/D-1 푸시 트리거 시 본 화면 자동 진입 가능
- AT-RISK 케어 알림 (4주 미방문 / 만료 직후 미재등록) 시 진입

### 4.15 MA-150 알림센터

**목적**

- 7개 카테고리 알림을 한곳에 모으고, 카드 선택 시 정의된 라우팅 표에 따라 대상 화면으로 이동한다.

**필수 요소**

- 상단 헤더: `알림` 제목, `모두 읽음 처리` 버튼
- 탭: `전체 / 미읽음`
- 카테고리 필터 칩 (가로 스크롤): `예약 / 이용권 / 리워드 / 공지 / AT-RISK / 수업·후기 / 부가시설`
- 알림 카드:
  - 좌측 카테고리 아이콘 (색상 분기)
  - 중앙: 제목 1줄 + 본문 1줄 + 발생 시간
  - 우측: 미읽음 점 + 1차 액션 버튼 (카테고리별)
- 카드 클릭 → 라우팅 표에 따라 대상 화면 이동

**카테고리별 라우팅 매핑 (정책 1.10)**

| 카테고리 | 트리거 예시 | 1차 액션 버튼 | 라우팅 대상 |
|---|---|---|---|
| 예약 | 예약 확정 / 변경 / 노쇼 임박 | `예약 보기` | MA-122 |
| 이용권 | 만료 D-14/D-7/D-1, 잔여 ≤ 3 | `재등록 추천` | MA-138 |
| 리워드 | 마일리지 적립 / 배지 획득 / 등급 상승 | `리워드 보기` | MA-136 / MA-137 / MA-500 |
| 공지 | 센터 이벤트 / 휴무 / 공지 | `공지 보기` | MA-152 |
| AT-RISK | 4주 미방문 / 만료 후 미재등록 | `재등록 안내` | MA-138 |
| 수업·후기 | 수업 시작 30분 전 / 후기 요청 | `후기 작성` 또는 `수업 보기` | MA-126 / MA-121 |
| 부가시설 | 사우나 / 락커 / 굿즈 안내 | `이용권 보기` | MA-131 / MA-151 |

**예외 / 빈 상태**

- 알림 0건: `새로운 알림이 없어요` + 일러스트
- 카테고리 필터링 결과 0건: `이 카테고리 알림이 없어요`
- 미읽음 탭 0건: `모든 알림을 확인했어요`

**정책**

- 미읽음은 진하게 표기, 읽은 알림은 7일 후 자동 보관
- 알림 카드 좌우 스와이프: 우 → 읽음 처리, 좌 → 보관

### 4.17 MA-002 앱 가입 / 연동

**목적**

- CRM 등록 회원이 SMS 인증 + 비밀번호 설정 + 가입 지점 선택까지 5단계로 앱 연동을 완료한다.

**5단계 진행**

| 단계 | 화면 | 입력 |
|---|---|---|
| 1 | 연락처/이메일 입력 | 전화번호 또는 이메일 |
| 2 | SMS 인증 | 6자리 인증번호 (3분 유효, 30초 후 재발송) |
| 3 | 비밀번호 설정 | 8~16자 + 영문 + 숫자 + 특수문자 |
| 4 | 가입 지점 선택 | CRM 가입 지점 카드 리스트에서 1개 선택 (단일 지점 시 자동 선택) |
| 5 | 약관·동의 | 필수 약관 체크 + 선택 약관 |

**필수 요소**

- 단계 인디케이터 (1/5 → 5/5)
- 입력 필드 + 인증 버튼 (인증 결과 즉시 피드백)
- 비밀번호 강도 표시
- 지점 카드 (지점명 / 주소 / 가입일 / 회원번호)
- 약관 전체 동의 / 개별 동의 분리

**예외 / 빈 상태**

- CRM 미등록 연락처: `등록되지 않은 회원입니다 — 센터 문의(MA-153)` 진입 유도
- 인증 5회 실패: 10분 잠금 안내
- 가입 지점 0개: `가입 지점이 없습니다 — 센터 등록을 먼저 진행해주세요` 안내

**완료 후 흐름**

- 연동 완료 → MA-127 운동 온보딩 자동 진입 (1회 한정)
- 운동 온보딩 완료 → MA-900 환영 슬라이드 (선택)
- 환영 완료 → MA-100 홈 또는 MA-300 둘러보기 홈

**수정 불가 항목**

- 가입 지점 (`설정 → 지점 변경 신청`으로 별도 흐름)

- 가입일 (시스템)

**예외 / 빈 상태**

- 인증 실패: 인라인 에러 메시지
- 사진 업로드 실패: 토스트 + 재시도

### 4.19 MA-111 출석 이력

**목적**

- 회원이 본인 방문 / 수업 참여 이력을 일별 / 주간 / 월간으로 조회하고, 카테고리별 패턴을 분석한다.

**섹션 구성**

| 섹션 | 표시 정보 |
|---|---|
| 요약 카드 (4지표) | 이번 달 출석 일수, 주간 평균 빈도, 월간 평균 빈도, 연속 출석 기록 |
| 출석 캘린더 | 월간 캘린더 — 출석일 색칠, 카테고리별 도트 (PT/OT/GX/필라테스/Golf 색상 분기) |
| 카테고리 비중 | 도넛 차트 — PT / OT / GX / 필라테스 / Golf 참여 비중 |
| 출석 패턴 히트맵 | 요일 × 시간대 격자 — 자주 가는 시간대 강조 |
| 분석 카드 | (1) 가장 많이 참여한 클래스, (2) 가장 자주 가는 시간대, (3) 전월 대비 +/-, (4) 개근 보너스 진척률 |

**필수 요소**

- 기간 필터: `이번 주 / 이번 달 / 최근 3개월`
- 카테고리 필터: `전체 / PT / OT / GX / 필라테스 / Golf`
- 출석 카드 리스트 (날짜 / 카테고리 / 수업명 / 강사 / 체크인 시간)
- 더 보기 페이지네이션

**예외 / 빈 상태**

- 출석 0회: `아직 출석 이력이 없어요` + QR 체크인(MA-110) 안내
- 카테고리 0건: 도넛 차트 비활성 + 안내

### 4.20 MA-134 상품 스토어

**목적**

- 회원이 헬스 / PT / 골프 / OT / 부가옵션 상품을 카테고리·회차 옵션으로 탐색한다.

**상단 섹션 — AI 추천 플랜 3종 (가로 스크롤)**

| 추천 유형 | 표기 |
|---|---|
| AI 추천 | `당신에게 딱 맞는 플랜` 배지 + 회원 활동 기반 회차 |
| 균형형 | `가장 많이 선택` 배지 + 평균 기준 회차 |
| 경제형 | `가성비` 배지 + 최소 회차 + 최대 할인 |

**카테고리 탭**

- `헬스 / PT / 골프 이용권 / 골프 레슨 / OT 추가 / 부가옵션`

**상품 카드**

- 이미지, 상품명, 기본 회차 / 기간, 정가, 할인가, 혜택 태그
- 회차 옵션 칩 (PT 전용): `4회 (×1.0) / 8회 (×1.9) / 16회 (×3.5)`
- 멤버십 등급별 할인가 미리보기
- 마일리지 사용 가능액 표기 (예: `최대 5,000P 사용 가능`)

**필수 요소**

- 상단 검색 입력 + 정렬 (인기순 / 가격순 / 신상순)
- 추천 플랜 3종 가로 스크롤
- 카테고리 탭
- 상품 카드 그리드
- 카드 액션: `상품 상세(MA-139)` / `옵션 결제(MA-400)` / `장바구니 담기(MA-401)`

**예외 / 빈 상태**

- 카테고리 상품 0건: `이 카테고리 상품이 없어요`
- 비로그인: 상품 상세는 열람 가능, 결제 시 LoginGateModal
