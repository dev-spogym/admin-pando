## 화면 목적

회원이 본인 기본 정보를 조회·수정하고, 이용권 / 결제 / 체성분 / 리워드 / 활동 / 친구 초대 / 알림 / 설정 등 전체 회원 서비스 진입 허브 역할을 한다.

## 계정별 차이

회원 본인 정보만 조회/수정 가능. 가입 지점 변경 시 운영 승인 필요.

## 주요 UX 흐름

### A. 프로필 편집

1. MA-130 → `프로필 편집` 또는 항목 직접 탭
2. 항목별 수정 → 인증 필요 시 인증 단계
3. 저장 → 토스트 + 카드 갱신

### B. 서비스 진입

1. 그리드 카드 또는 시스템 리스트에서 메뉴 탭
2. 해당 화면으로 이동

### C. 로그아웃

1. 하단 로그아웃 → ConfirmDialog (기본 톤)
2. 확인 → 토큰 삭제 + MA-001 진입

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-M003 회원 수정 / SCR-M004 회원 상세 |
| 데이터 흐름 | 양방향 (회원 정보 조회 / 수정) |
| 정책 출처 | 수정 가능 항목 / 인증 필요 정책 = admin 본사 정책 (개인정보) |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**client → admin 영향**

- 회원이 수정한 정보(이름/연락처/이메일/성별/생년월일)는 SCR-M004에 즉시 반영
- SMS / 이메일 인증 후에만 적용 (admin 정책 준수)

**admin → client 영향**

- SCR-M003에서 회원 정보 수정 시 MA-130 즉시 갱신
- 가입 지점 변경 (SCR-M005)은 admin 승인 후 반영
