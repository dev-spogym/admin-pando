## 화면 목적

상품 스토어 / 옵션 결제 / 개인 결제 / 장바구니 / 재등록 추천 / **관리자 발송 결제링크**에서 진입한 결제 주문을 처리한다. 결제수단 선택, 마일리지 사용, 쿠폰 적용을 한 화면에서 처리하고 결제 완료 후 영수증(MA-142)으로 자동 진입한다.

결제링크 진입 시에는 동일한 화면을 사용하되 **상품 / 금액 / 할인 / 쿠폰 / 마일리지** 변경이 불가하며, 결제수단 선택과 결제 동의만 활성화된다.

## 주요 구성요소

### 주문 요약 카드 (상단)

| 항목 | 설명 |
|------|------|
| 상품 이미지 + 상품명 | 단건 또는 리스트 (장바구니 진입 시 다중) |
| 옵션 요약 | 강사 / 시간 / 회차 등 |
| 정가 | 큰 텍스트 |

### 결제수단 선택 섹션

| 결제수단 | 표시 |
|---------|------|
| 등록된 카드 | 카드사 로고 + 끝 4자리 + `기본` 배지 |
| 카카오페이 | 로고 + 활성 토글 |
| 네이버페이 | 로고 + 활성 토글 |
| `+ 결제수단 추가` | MA-405 진입 |

### 쿠폰 섹션

| 항목 | 설명 |
|------|------|
| 자동 추천 쿠폰 | 최대 할인 자동 적용 (1장) |
| 쿠폰 직접 선택 | MA-135 쿠폰함에서 선택 |
| 미사용 | 쿠폰 미적용 |

### 마일리지 사용 섹션

| 항목 | 설명 |
|------|------|
| 보유 마일리지 | 큰 숫자 |
| 사용 입력 | 100P 단위 입력 (전체 사용 버튼) |
| 차감 후 결제액 | 실시간 계산 |

### 합계 박스

| 항목 | 표시 |
|------|------|
| 상품 합계 | 정가 |
| 쿠폰 할인 | -금액 |
| 마일리지 사용 | -P (원으로 환산) |
| 멤버십 등급 할인 | -금액 |
| 최종 결제액 | 큰 강조 |

### 동의 / 결제 CTA

| 항목 | 설명 |
|------|------|
| 결제 동의 체크 | "결제 진행에 동의합니다" 필수 |
| 결제하기 CTA | 결제수단 + 동의 체크 시 활성 |

## 계정별 차이

회원 본인 결제. 비로그인 진입 시 LoginGateModal로 차단.

## 주요 UX 흐름

### A. 단건 결제

1. MA-139 / MA-138 / MA-141 → MA-140 진입
2. 결제수단 선택 + 쿠폰 + 마일리지
3. 동의 체크 → `결제하기` → PG 진입
4. 결제 완료 → MA-142 영수증 진입

### B. 장바구니 결제

1. MA-401 → 선택 항목 결제 → MA-140 진입
2. 다중 항목 합계 + 비례 분배 결제
3. 결제 완료 → MA-402 주문 내역 자동 진입

### C. 관리자 발송 결제링크 진입

1. 직원이 admin SCR-S016에서 결제링크 발송 (SMS / 카카오 / 이메일)
2. 회원이 링크 탭 → 회원앱 MA-140 자동 진입 (결제링크 모드)
3. 화면 표시:
   - 상품명 / 옵션 / 금액 = 직원 고정 값 (편집 불가, 회색 처리)
   - 할인 / 쿠폰 / 마일리지 = 비활성 + "결제링크 결제는 수정 불가" 안내
   - 결제수단 선택 + 결제 동의만 활성
4. 결제 완료 → MA-142 영수증 (링크결제 완료 표시) → MA-402/403 주문 내역 자동 편입

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-S003 결제 처리 / SCR-S016 결제링크 발송 / SCR-073 쿠폰 / SCR-074 마일리지 / SCR-M009 등급 |
| 데이터 흐름 | 양방향 (회원 결제 → admin 매출 / 쿠폰·마일리지 차감) + 단방향 (admin 결제링크 → 회원 진입) |
| 정책 출처 | 결제수단 종류 / 등급 할인 / 환불 비율 / 결제링크 편집 불가 정책 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**client → admin 영향**

- 결제 완료 → SCR-S003 즉시 등재 + SCR-S001 매출 집계
- 마일리지 / 쿠폰 차감 → SCR-074 / SCR-073 사용 이력
- 회원 누적 결제액 갱신 → SCR-M009 등급 재산정
- 결제링크 결제 완료 시 SCR-S016 발송 이력에 "완료" 상태 즉시 반영

**admin → client 영향**

- 결제수단 정책 / PG 변경 시 결제 화면 갱신
- SCR-S016에서 직원이 결제링크 발송 → 회원 SMS/카카오/이메일 + MA-140 진입 (결제링크 모드)
- 결제링크 만료 / 취소 시 MA-140 진입 차단 + 안내
