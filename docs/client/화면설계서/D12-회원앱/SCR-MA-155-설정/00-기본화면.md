## 화면 목적

회원이 7개 카테고리별 알림 ON/OFF 및 채널을 직접 설정하고, 야간 차단 / 약관 / 동의관리 / 회원 탈퇴 / 1:1 문의 / 앱 버전 / 로그아웃 등 시스템 메뉴를 한 허브에서 진입한다.

## 주요 구성요소

### 알림 카테고리 섹션 (7개 카드)

| 카테고리 | 보조 텍스트 | 기본값 |
|----------|-------------|--------|
| 예약 | 예약 확정 / 변경 / 노쇼 임박 알림 | ON |
| 이용권 | 만료 D-day, 잔여 회차 임박 알림 | ON |
| 리워드 | 마일리지 / 배지 / 등급 상승 알림 | ON |
| 공지 | 센터 이벤트, 휴무 안내 | ON |
| AT-RISK 케어 | 4주 미방문 / 만료 후 미재등록 케어 | ON |
| 수업·후기 | 수업 시작 30분 전 / 수업 후 후기 요청 | ON |
| 부가시설 | 사우나 / 락커 / 굿즈 만료·잔여 안내 | ON |

각 카드 구성:
- 카테고리명 + 설명 1줄
- ON/OFF 메인 스위치
- 채널 칩 (앱 푸시 / SMS / 이메일 다중 선택)

### 야간 차단 토글

| 항목 | 설명 |
|------|------|
| 야간 차단 | 22:00 ~ 07:00 푸시 차단 토글 (기본 OFF) |
| 안내 | "차단 시간에는 푸시가 보류됩니다" |

### 시스템 메뉴 리스트

| 메뉴 | 진입 |
|------|------|
| 약관 / 정책 | MA-156 |
| 동의관리 | MA-157 |
| 회원 탈퇴 | MA-158 |
| 1:1 문의 | MA-153 |
| 앱 버전 | 텍스트 (현재 버전 + 업데이트 알림) |
| 로그아웃 | 위험 톤 텍스트 버튼 |

## 계정별 차이

회원 본인 설정. AT-RISK 카테고리 OFF 시에도 MA-138 직접 진입은 가능.

## 주요 UX 흐름

1. MA-130 마이페이지 → 설정 진입
2. 카테고리별 메인 스위치 + 채널 칩 토글
3. 야간 차단 ON/OFF
4. 시스템 메뉴 리스트에서 약관 / 동의 / 탈퇴 / 문의 진입
5. 로그아웃 → ConfirmDialog → MA-001 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 모두 ON | 모든 카드 활성 |
| 일부 OFF | 해당 카드 회색 |
| 채널 미선택 | 메인 ON이어도 발송 채널 없음 안내 |
| 야간 차단 ON | 시간대 표시 강조 |
| 앱 업데이트 가능 | 버전 항목 우측 빨강 점 + `업데이트` 버튼 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-072 자동 알림 (발송 결정 정책) / SCR-M004 회원 상세 (조회) |
| 데이터 흐름 | 양방향 (회원 설정 변경 → admin 발송 결정 반영) |
| 정책 출처 | 7개 카테고리 / 야간 차단 / 채널 = 회원 본인 설정 (admin은 정책만) |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**client → admin 영향**

- 회원 카테고리 ON/OFF 변경 → SCR-072 발송 결정에서 즉시 반영
- 채널 (앱/SMS/이메일) 다중 선택 → 발송 채널 결정
- 회원 설정 이력은 SCR-M004 회원 상세에서 조회 가능 (admin은 변경 불가)
