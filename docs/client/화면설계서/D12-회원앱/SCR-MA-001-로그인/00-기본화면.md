## 화면 목적

회원 / 직원이 같은 앱 안에서 본인 역할에 맞는 로그인 경로로 진입한다. 회원은 전화번호+비밀번호, 직원(트레이너/FC/스태프)은 직군 선택 후 아이디+비밀번호로 인증한다.

## 주요 구성요소

### 상단 탭

| 탭 | 입력 |
|----|------|
| 회원 로그인 | 전화번호 + 비밀번호 |
| 직원 로그인 | 직원 유형(트레이너/FC/스태프) + 아이디 + 비밀번호 |

### 회원 로그인 입력

| 항목 | 설명 |
|------|------|
| 전화번호 | 010 자동 + 8자리 (포맷팅) |
| 비밀번호 | 8~16자 마스킹 입력 |
| 자동 로그인 | 체크박스 (기본 ON) |
| 로그인 CTA | 입력 완료 시 활성 |

### 직원 로그인 입력

| 항목 | 설명 |
|------|------|
| 직원 유형 라디오 | 트레이너(골프강사 포함) / FC / 스태프 |
| 아이디 | 직원 ID 입력 |
| 비밀번호 | 마스킹 입력 |
| 로그인 CTA | 입력 완료 시 활성 |

### 보조 액션

| 버튼 | 설명 |
|------|------|
| 앱 연동하기 | 회원 탭 전용. CRM 등록 후 첫 연동 회원이 진입 → MA-002 |
| 비밀번호 찾기 | SMS 인증 기반 비밀번호 재설정 진입 |
| 1:1 문의 | MA-153 진입 |

## 계정별 차이

| 역할 | 진입 화면 |
|------|-----------|
| member | MA-100 회원 홈 |
| trainer / golf_trainer | 트레이너 홈 (역할별 네비게이터) |
| fc | FC 홈 |
| staff | 스태프 홈 |

선택한 직원 유형과 실제 계정 role이 다르면 로그인되지 않는다.

## 주요 UX 흐름

1. 앱 진입 → MA-001 로그인 화면
2. 회원 탭 또는 직원 탭 선택
3. 입력 완료 → 로그인 CTA
4. 인증 성공 → 역할별 기본 홈 자동 이동
5. 인증 실패 → 인라인 에러 메시지 + 재시도

## 화면 상태

| 상태 | 설명 |
|------|------|
| 기본 (빈 입력) | 로그인 CTA 비활성 |
| 입력 중 | 필드 검증 + CTA 활성 |
| 인증 처리 중 | 로딩 인디케이터 |
| 인증 실패 | 인라인 에러 메시지 (계정 불일치 / 비밀번호 오류 / 잠금) |
| 5회 실패 | 10분 잠금 안내 |
| 인증 성공 | 역할별 홈 라우팅 |
| 자동 로그인 | 토큰 유효 시 로그인 화면 스킵 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-061 직원 등록 (직원 로그인) / SCR-097 감사 로그 |
| 데이터 흐름 | client → admin (로그인 시 감사 로그 INSERT) |
| 정책 출처 | 5회 실패 잠금 정책 = admin 본사 정책 / 직원 role 매핑 = SCR-061 |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**admin → client 영향**

- SCR-061에서 직원 계정 잠금 / 비활성 처리 시 회원앱 직원 로그인 차단
- SCR-080 센터 설정에서 회원 자동 로그아웃 타이머 정책 변경 시 즉시 반영
