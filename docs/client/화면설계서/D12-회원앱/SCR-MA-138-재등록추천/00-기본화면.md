## 화면 목적

회원의 이용권 만료 시점(D-14 / D-7 / D-1) 또는 회원의 임의 진입 시, 회원 활동 데이터를 기반으로 추천 플랜 3종(AI 추천 / 균형형 / 경제형)을 비교 노출하여 재등록 결제(MA-140)로 연결한다.

## 주요 구성요소

### 상단 D-day 트리거 배너

| 트리거 | 배너 톤 | 문구 |
|--------|---------|------|
| D-14 | info (보조) | "회원권 만료 14일 전 — 미리 준비해 주세요" |
| D-7 | warning (강조) | "이번 주 만료 — 재등록 시 +10% 혜택" |
| D-1 | danger (위험) | "내일 만료 — 마지막 안내" |
| 임의 진입 | neutral (기본) | "이용권 추천 플랜을 확인해 보세요" |
| 만료 후 | warning | "만료된 회원권을 갱신해 주세요" + AT-RISK 케어 메시지 |

### D-day 인디케이터

| 항목 | 설명 |
|------|------|
| 만료까지 남은 일수 | 큰 숫자 (예: D-7) |
| 만료 일자 | YYYY-MM-DD |
| 현재 회원권 | 종류 + 잔여 횟수 (PT/OT 분리) |

### 추천 플랜 3종 카드

| 추천 유형 | 배지 | 표시 정보 | 산정 기준 |
|-----------|------|-----------|-----------|
| AI 추천 | "당신에게 딱 맞는 플랜" (primary) | 회원 활동 기반 회차 + 카테고리 가중치 | 주 평균 PT 빈도 × 4주 |
| 균형형 | "가장 많이 선택" (success) | 평균 기준 회차 | 평균 PT 빈도 + 평균 활동 가중 |
| 경제형 | "가성비" (warning) | 최소 회차 + 최대 할인 | 최소 4회 + 할인 적용 |

각 카드 표시 정보:
- 플랜명
- 회차 (4 / 8 / 16)
- 가격 (정가 + 할인가)
- 단가 배수 표기 (×1.0 / ×1.9 / ×3.5)
- 추천 사유 1줄 (예: "주 2회 PT 활동에 맞춰요")
- 혜택 리스트 (마일리지 적립률, OT 추가, 무료 인바디 등)
- `이 플랜으로 결제(MA-140)` CTA

### 마일리지 사용 가능액 미리보기

현재 보유 마일리지 + 결제 시 차감 가능 금액 안내.

### 추가 액션

| 버튼 | 설명 |
|------|------|
| 다른 상품 보기 | MA-134 상품 스토어로 이동 |
| 만료 정보 보기 | MA-131 이용권/잔여 회차로 이동 |
| 닫기 | 이전 화면으로 돌아가기 |

## 계정별 차이

회원 본인만 진입 가능. AI 추천 카드는 회원 활동 데이터(주 평균 PT 빈도, 카테고리 가중치)가 있는 회원에게만 노출되며, 신규 회원은 일반 추천으로 대체된다.

## 주요 UX 흐름

### A. D-day 푸시 트리거 진입

1. 만료 D-14/D-7/D-1 시점 푸시 알림 수신
2. 알림 카드 탭 → MA-138 자동 진입 (해당 D-day 배너 표시)
3. 추천 플랜 3종 비교 → 한 카드 선택 → `이 플랜으로 결제` → MA-140 결제 화면

### B. 회원 임의 진입

1. MA-100 홈 또는 MA-131 이용권 화면에서 `재등록 추천` CTA
2. MA-138 진입 (배너 톤 neutral)
3. 추천 플랜 비교 → 결제

### C. 만료 후 AT-RISK 진입

1. 만료 후 4주 미재등록 회원에게 AT-RISK 케어 알림 발송
2. 알림 탭 → MA-138 진입 (만료 배너)
3. 재등록 결제 또는 1:1 문의(MA-153) 안내

| 만료 후 | warning 배너 + AT-RISK 케어 메시지 + 재등록 강조 |

| 추천 플랜 생성 중 | 카드 스켈레톤 |
| 생성 실패 | 일반 상품 스토어(MA-134) 진입 안내 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-099 리포트 / 본사 D-day 정책 / SCR-072 자동 알림 |
| 데이터 흐름 | admin → client (D-day 트리거 + 회원 활동 기반 추천 산정) |
| 정책 출처 | D-14/D-7/D-1 트리거 시점 / AI 추천 알고리즘 = admin |
| 연동 시나리오 | 60_admin_연동/C6_이용권_Dday_트리거 |

**admin → client 영향**

- 일배치 D-day 트리거 발동 → 푸시 + MA-138 진입 활성
- AT-RISK 케어 회원 식별 시 회원 + FC 양쪽 알림

**client → admin 영향**

- 회원 재등록 결제 → SCR-S001 매출 즉시 + D-day 트리거 종료
