## 화면 목적

회원이 가입 지점의 PT, OT, GX, 필라테스, Golf 수업 일정을 카테고리·요일·시간으로 탐색하고, 정원·잔여석·강사 정보를 확인하여 예약(MA-121) 진입한다.

## 주요 구성요소

### 상단 필터

| 항목 | 옵션 |
|------|------|
| 카테고리 탭 | 전체 / PT / OT / GX / 필라테스 / Golf |
| 날짜 캐러셀 | 오늘 ~ +14일 (가로 스크롤) |
| 시간대 칩 | 오전 / 낮 / 저녁 / 심야 |
| 강사 필터 | 강사 다중 선택 (모달) |
| 예약 가능만 | 토글 (만석 제외) |

### 수업 카드

| 항목 | 설명 |
|------|------|
| 시간 | 시작 - 종료 |
| 수업명 | 강사명 함께 표시 |
| 카테고리 칩 | PT/OT/GX/필라테스/Golf 색상 분기 |
| 정원 / 잔여석 | "12 / 15" + 진행 바 |
| 상태 칩 | 예약 가능 / 만석(대기 가능) / 마감 |
| 액션 | 수업 카드 탭 → MA-121 진입 |

### 추천 강사 섹션 (선택)

회원의 온보딩 정보 + 출석 패턴 기반으로 추천 강사 가로 스크롤. 강사 카드 → MA-125 진입.

### 빈 상태

| 상태 | 표시 |
|------|------|
| 해당 일 수업 없음 | "이 날짜에 수업이 없어요" + 다른 날짜 추천 |
| 카테고리 필터 0건 | "필터를 변경해 보세요" + 필터 해제 |

## 계정별 차이

회원 가입 지점의 수업만 표시. 마켓 둘러보기(MA-300)에서는 다른 센터 수업 탐색이 가능하다.

## 주요 UX 흐름

1. MA-100 홈 → `GX 스케줄 / PT 예약` 카드 → MA-120 진입
2. 카테고리 탭 + 날짜 선택
3. 시간대 / 강사 / 예약 가능만 필터로 좁힘
4. 수업 카드 탭 → MA-121 진입
5. 만석 카드는 "대기 등록" 액션 노출

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 카드 리스트 표시 |
| 만석 카드 강조 | "대기 등록" 보조 액션 |
| 마감 카드 | 회색 처리 + 액션 비활성 |
| 빈 상태 | 일러스트 + 다른 날짜 추천 |
| 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-C001 수업 캘린더 / SCR-C002 수업 관리 / SCR-C004 그룹 수업 템플릿 |
| 데이터 흐름 | admin → client (수업 일정 / 정원 / 강사 정보 조회) |
| 정책 출처 | 수업 등록·삭제 = admin SCR-C002, 회원은 조회만 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**admin → client 영향**

- SCR-C002에서 수업 등록/취소/시간 변경 시 회원 MA-120 즉시 갱신
- SCR-C006 강사 근무 변경 시 강사별 수업 목록 자동 업데이트
