## 화면 목적

회원이 센터 입장 시 본인 앱에 표시된 QR을 센터 키오스크/태블릿 스캐너에 보여주거나, 센터 QR을 회원 앱 카메라로 스캔하여 출석을 자동 기록한다.

## 주요 구성요소

### QR 표시 모드 (회원 → 센터)

| 항목 | 설명 |
|------|------|
| 회원 QR 코드 | 큰 정사각형 QR 이미지 (회원 ID + 시간 토큰 인코딩) |
| 갱신 타이머 | 60초마다 자동 갱신 (보안) |
| 회원 정보 | QR 하단에 회원명 / 회원번호 / 가입 지점 |
| 밝기 자동 최대 | 화면 진입 시 단말 밝기 최대 설정 |

### QR 스캔 모드 (센터 → 회원)

| 항목 | 설명 |
|------|------|
| 카메라 뷰 | 후면 카메라 자동 활성 |
| 스캔 가이드 박스 | 정사각형 가이드 + 안내 문구 |
| 손전등 토글 | 어두운 환경 보조 |
| 모드 전환 버튼 | 표시 모드 ↔ 스캔 모드 |

### 체크인 결과 토스트

| 결과 | 표시 |
|------|------|
| 성공 | 초록 체크 + "출석 완료 — HH:MM" + 햅틱 |
| 중복 | 회색 안내 + "이미 오늘 출석했어요" |
| 이용권 만료 | 경고 + "이용권을 확인해 주세요" + MA-131 진입 |
| 실패 | 빨강 안내 + 재시도 버튼 |

### 보조 액션

| 버튼 | 설명 |
|------|------|
| 출석 이력 보기 | MA-111 진입 |
| 수동 출석 도움 요청 | 스태프에게 도움 (1:1 문의 진입) |

## 계정별 차이

회원 본인만 QR 표시 가능. 회원이 본인 QR을 캡처하여 타인이 사용하는 것을 막기 위해 60초 갱신 + 시간 토큰 검증.

## 주요 UX 흐름

### A. 회원 QR 표시 (기본)

1. MA-100 홈 → QR 체크인 아이콘 또는 하단 탭 → MA-110 진입
2. 큰 QR + 회원 정보 표시
3. 센터 키오스크에 스캔
4. 성공 토스트 + 햅틱 + 출석 카운트 즉시 갱신
5. 자동으로 홈 또는 오늘 수업 카드로 복귀

### B. 회원 카메라로 센터 QR 스캔

1. MA-110 진입 후 `스캔하기` 토글
2. 카메라 권한 요청 (최초 1회)
3. 센터 QR을 가이드 박스에 위치
4. 자동 인식 → 성공 토스트

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-086 출석 관리(회원) / SCR-I001 통합 출석 / SCR-C014 출석 QR / SCR-082 키오스크 설정 (계약 외 #16) |
| 데이터 흐름 | client → admin (체크인 시 출석 INSERT 즉시) + Realtime 동기화 |
| 정책 출처 | 당일 중복 차단, 이용권 없는 회원 경고 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C2_QR체크인_출석동기화 |

**client → admin 영향**

- 체크인 즉시 SCR-086 출석 카운트 + SCR-094 KPI 갱신
- 이용권 만료/없음 회원 입장 시 SCR-I008 키오스크 운영 현황에 경고
- 수동 출석은 admin 측 스태프 화면(SCR-520) 전용
