# SCR-MA-110 QR 입장 — 키오스크 연동

본 화면은 회원이 회원앱에서 QR 코드를 발급받아 키오스크에 노출하는 채널 진입점이다. 키오스크 KIO-101이 본 QR을 카메라로 스캔해 회원을 식별한다.

## 흐름

```
[회원앱 SCR-MA-110에서 QR 발급]
        ↓
[회원이 키오스크 KIO-101 카메라에 QR 노출]
        ↓
[키오스크가 QR 스캔 → 토큰 디코딩]
        ↓
[admin이 토큰 검증 → 회원 식별]
        ↓
[KIO-201 출석 결과 모달 (성공/실패)]
        ↓
[회원앱 SCR-MA-111 출석이력에 즉시 반영]
```

## 회원앱 측 요건

| 항목 | 내용 |
|---|---|
| QR 토큰 형식 | 키오스크와 동일 디코딩 룰 |
| 유효 시간 | 60초 권장 (보안 목적) |
| 자동 재발급 | 만료 시 화면에서 자동 재발급 |
| 화면 밝기 | 발급 화면 동안 최대 밝기 권장 |
| 앱 미실행 시 | 푸시/단축아이콘으로 빠른 진입 가능해야 함 |

## 예외 처리

| 상황 | 회원앱 측 처리 | 키오스크 측 처리 |
|---|---|---|
| 토큰 만료 | 자동 재발급 | "QR이 만료되었습니다. 앱에서 재발급해주세요" |
| 토큰 위변조 | — | 실패 화면 |
| 미등록 회원 | — | 실패 화면 + 프런트 안내 |
| 키오스크 오프라인 | — | 토큰 검증 불가 → 실패 안내 (회원앱은 영향 없음) |

## 보안 고려

- QR 토큰에는 회원 PII를 직접 포함하지 않는다. 서버측 토큰 ↔ 회원 매핑만 사용.
- 토큰 재사용 방지(1회용) 또는 짧은 유효시간으로 도난 위험 최소화.
