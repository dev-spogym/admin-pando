## 화면 목적

회원이 본인 예약(승인 대기 / 확정 / 완료 / 취소)과 수업 이력을 카테고리별로 조회하고, 후기 작성, 예약 취소, 차감 이력 확인을 한 화면에서 처리한다.

## 주요 구성요소

### 상단 필터 / 탭

| 필터 | 옵션 |
|------|------|
| 서비스 탭 | 전체 / PT / OT / GX / Golf |
| 상태 필터 | 승인 대기 / 확정 / 완료 / 취소 |
| 보기 모드 | 리스트 / 캘린더 (전환 가능) |
| 기간 | 다가오는 / 지난 / 전체 |

### 예약 카드 (리스트 모드)

| 항목 | 설명 |
|------|------|
| 좌측 일자 | DD요일 + 시간 |
| 카테고리 칩 | PT/OT/GX/Golf 색상 분기 |
| 수업명 / 강사 | 클래스명 + 강사명 + MA-125 진입 |
| 상태 칩 | 승인 대기(warning) / 확정(success) / 완료(neutral) / 취소(error) |
| 액션 버튼 (상태별) | 승인 대기: 취소, 확정: 예약 취소, 완료: 후기 작성(MA-126), 취소: - |
| 잔여 차감 표시 (PT/OT) | 완료 시 "차감 1회 적용" |

### 캘린더 모드

| 항목 | 설명 |
|------|------|
| 월간 캘린더 | 예약일 색칠 + 상태별 도트 |
| 일자 탭 | 해당 일 예약 리스트 시트 |

### PT / OT 차감 이력 카드

| 항목 | 설명 |
|------|------|
| 최근 차감 5건 | 일자 + 수업명 + 강사 + 차감 결과 |
| 더보기 | MA-131 이용권 화면으로 이동 |
| 다음 예약 예정 | 다가오는 예약 일자 안내 |

### 빈 상태

| 상태 | 표시 |
|------|------|
| 예약 없음 | "예약된 수업이 없어요" + MA-120 진입 CTA |
| 필터 결과 0건 | "이 조건의 예약이 없어요" + 필터 해제 |

## 계정별 차이

회원 본인의 예약/이력만 조회 가능. 트레이너는 별도 트레이너 화면에서 회원 예약을 본다.

## 주요 UX 흐름

1. MA-100 홈 → `내 예약` 또는 마이페이지 → MA-122 진입
2. 서비스 탭 + 상태 필터로 좁힘
3. 카드 탭 → 수업 상세 모달 (또는 MA-121 진입)
4. 완료 카드 → `후기 작성(MA-126)` 진입
5. 확정 카드 → 취소 가능 기한 내 `예약 취소`
6. PT/OT 차감 이력 더보기 → MA-131 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 예약 있음 | 카드 리스트 표시 |
| 빈 상태 | 일러스트 + 예약하기 CTA |
| 캘린더 모드 | 월간 그리드 + 도트 |
| 승인 대기 | 카드 강조 표시 + 대기 시간 표시 |
| 취소 마감 후 | 취소 버튼 비활성 + 안내 |
| 로딩 | 스켈레톤 |
| 새로고침 (당겨서) | 상단 인디케이터 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-C001 / SCR-C002 / SCR-C016 예약목록 / SCR-C007 / SCR-C008 페널티 관리 |
| 데이터 흐름 | 양방향 (예약 상태 / 차감 / 노쇼) |
| 정책 출처 | 취소 마감 시간 / 노쇼 페널티 = admin 본사 정책 + 센터 설정 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**client → admin 영향**

- 회원 취소 → SCR-C016 예약 원장에 취소 처리 + SCR-C002 수업 현황 반영 + 대기열 1순위 자동 확정 트리거

**admin → client 영향**

- SCR-C007 수업 완료 처리 시 회원 MA-122 카드에 "차감 1회 적용" 즉시 표시
- SCR-C008 노쇼 페널티 누적 시 회원 MA-122 + 푸시 알림
- 키오스크 KIO-303 예약 조회도 동일한 SCR-C002/SCR-C016 원천을 읽는다. 단, 키오스크는 일반 수업 예약을 생성/변경하지 않고 조회만 한다.
