## 화면 목적

회원이 MA-127 온보딩 설문을 완료한 직후, 입력값 요약을 확인하고 회원에게 적합한 첫 루틴 3종을 제안받는다. 운동 시작 동기를 부여하고 OT1 예약 또는 트레이너 공유로 자연스럽게 연결한다.

## 주요 구성요소

### 입력 요약 카드 (4영역)

| 영역 | 표시 |
|------|------|
| 운동 목적 / 성향 | 다중 선택 칩 + 성향 1줄 |
| 통증 / 부상 | 통증 부위 + 과거 부상 + 불편한 동작 |
| 체형 / 집중 부위 | 체형 + 집중 부위 |
| 선호 요일·시간 | 요일 + 시간대 |

### 입력 완료율 표시

| 항목 | 설명 |
|------|------|
| 진척 바 | 0~100% |
| 정확도 안내 | "80% 입력 — 첫 루틴 정확도 높음" |
| 추가 입력 CTA | 미완료 항목 → MA-127 진입 |

### 첫 루틴 제안 카드 3종

| 추천 유형 | 설명 |
|-----------|------|
| 목적 맞춤형 | 운동 목적 기반 (감량 / 근비대 / 체형교정 등) |
| 통증 회복형 | 통증 부위 기반 안전 동작 위주 |
| 균형 강화형 | 부족한 부위 보강 + 전신 균형 |

각 카드 표시:
- 루틴명 + 추천 사유 1줄
- 운동 종목 5~7개 미리보기 (썸네일 + 이름)
- 예상 소요 시간
- 액션: `루틴 시작` / `트레이너에게 공유`

### 다음 단계 CTA

| 버튼 | 설명 |
|------|------|
| OT1 예약하기 | MA-121 진입 (OT1 라디오 자동 선택) |
| 홈으로 이동 | MA-100 진입 |
| 마켓 둘러보기 | MA-300 진입 |

## 계정별 차이

회원 본인만 진입. 트레이너에게 공유 시 트레이너 측 화면에 회원의 온보딩 정보 + 추천 루틴이 자동 표시된다.

## 주요 UX 흐름

1. MA-127 입력 완료 또는 `나중에 입력` → MA-128 자동 진입
2. 입력 요약 확인 + 완료율 확인
3. 첫 루틴 카드 비교 → 한 카드 선택
4. `루틴 시작` 또는 `트레이너에게 공유` 액션
5. 추가 단계 CTA로 OT1 예약 / 홈 / 마켓 이동

## 화면 상태

| 상태 | 설명 |
|------|------|
| 입력 100% | 모든 카드 활성 + 첫 루틴 정확도 높음 |
| 입력 50~80% | 추가 입력 CTA 강조 |
| 입력 50% 미만 | 첫 루틴 일반 추천으로 대체 + 추가 입력 권장 |
| 루틴 시작 | 루틴 상세 화면 진입 |
| 트레이너 공유 | 공유 완료 토스트 |
| 로딩 | 카드 스켈레톤 |

- SCR-C010 운동 프로그램 카탈로그 변경 시 첫 루틴 추천 자동 재산정
- 트레이너에게 공유 시 트레이너앱 + admin SCR-M004에 회원 온보딩 정보 동기화
