## 화면 목적

회원이 헬스 / PT / OT / 골프 / 부가옵션 상품을 카테고리·회차 옵션으로 탐색하고, AI 추천 플랜 3종 또는 일반 상품을 결제(MA-140) 진입한다. 회원 활동 데이터 기반 개인화 추천을 상단에 노출한다.

## 주요 구성요소

### 상단 검색 / 정렬

| 항목 | 옵션 |
|------|------|
| 검색 입력 | 상품명 / 강사명 / 키워드 |
| 정렬 | 인기순 / 가격순 (낮은/높은) / 신상순 |

### AI 추천 플랜 3종 (가로 스크롤, 상단)

| 추천 유형 | 배지 | 표시 |
|-----------|------|------|
| AI 추천 | "당신에게 딱 맞는 플랜" (primary) | 회원 활동 기반 회차 |
| 균형형 | "가장 많이 선택" (success) | 평균 기준 회차 |
| 경제형 | "가성비" (warning) | 최소 회차 + 최대 할인 |

### 카테고리 탭

`헬스 / PT / 골프 이용권 / 골프 레슨 / OT 추가 / 부가옵션`

### 상품 카드 그리드

| 항목 | 설명 |
|------|------|
| 썸네일 | 상품 이미지 |
| 상품명 | 큰 텍스트 |
| 기본 회차 / 기간 | "16회 · 4개월" |
| 정가 / 할인가 | 취소선 + 강조 |
| 혜택 태그 | "마일리지 +5%" / "OT 1회 무료" 등 |
| 회차 옵션 칩 (PT 전용) | 4회(×1.0) / 8회(×1.9) / 16회(×3.5) |
| 멤버십 등급 할인가 | 회원 등급별 미리보기 |
| 마일리지 사용 가능액 | "최대 5,000P 사용 가능" |

### 카드 액션

| 액션 | 설명 |
|------|------|
| 상품 상세 (MA-139) | 기본 액션 |
| 옵션 결제 (MA-400) | PT/그룹 레슨은 옵션 화면 진입 |
| 장바구니 담기 (MA-401) | 즉시 장바구니 추가 + 토스트 |
| 바로 결제 (MA-140) | 단순 이용권은 결제 직진입 |

## 계정별 차이

회원 본인 가입 지점의 상품 + 본사 통합 상품 조회. 멀티센터 마켓 상품은 MA-300 둘러보기에서 처리.

## 주요 UX 흐름

1. MA-100 홈 또는 MA-130 마이페이지 → 상품 스토어 진입
2. 상단 AI 추천 카드 가로 스크롤 → 한 카드 선택 → 결제
3. 카테고리 탭으로 일반 상품 탐색
4. PT 카드 → 회차 옵션 선택 → 옵션 결제 또는 장바구니
5. 단순 이용권 → 바로 결제

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 추천 + 카드 그리드 표시 |
| 신규 회원 (활동 0건) | AI 추천 → 일반 추천으로 대체 |
| 카테고리 0건 | "이 카테고리 상품이 없어요" |
| 검색 결과 0건 | "검색 결과가 없어요" + 카테고리 추천 |
| 비로그인 | 카드 조회 가능, 결제 시 LoginGateModal |
| 로딩 | 카드 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-P001~P008 상품 / SCR-P004 할인 / SCR-P005 카탈로그 |
| 데이터 흐름 | admin → client (상품 카탈로그 조회 + AI 추천 자동 생성) |
| 정책 출처 | PT 회차 옵션 (4/8/16회) / AI 추천 산정 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**admin → client 영향**

- SCR-P001~P008 상품 등록/수정/할인 변경 시 MA-134 즉시 갱신
- SCR-P008 시즌 가격 활성화 시 회원 화면 가격 자동 변경
- 회원 활동 기반 AI 추천 3종은 admin 알고리즘으로 산정
