## 화면 목적

회원이 가입한 센터의 운영 정보(주소 / 영업시간 / 연락처 / 시설 / 부가 서비스)를 한 화면에서 확인하고, 길찾기 / 전화 / 문의 진입을 지원한다.

## 주요 구성요소

### 센터 헤더

| 항목 | 설명 |
|------|------|
| 센터명 | 큰 텍스트 |
| 카테고리 | 헬스 / 골프 / 필라테스 등 |
| 별점 평균 | 5점 + 후기 수 |
| 대표 이미지 | 가로 스크롤 갤러리 |

### 운영 정보

| 항목 | 설명 |
|------|------|
| 영업시간 | 요일별 (오늘 강조) |
| 휴무일 | 정기 휴무 + 임시 휴무 |
| 운영 상태 칩 | 영업 중 / 곧 마감 / 영업 종료 |

### 위치 / 길찾기

| 항목 | 설명 |
|------|------|
| 주소 | 도로명 + 지번 |
| 지도 미리보기 | 지도 카드 (탭 시 외부 지도 앱 진입) |
| 길찾기 버튼 | 카카오맵 / 네이버맵 / Google Maps 선택 |

### 연락처

| 항목 | 설명 |
|------|------|
| 대표 전화 | 탭 시 전화 앱 |
| 1:1 문의 | MA-153 진입 |
| 카카오톡 | 카카오톡 채널 진입 |

### 시설 / 부가 서비스 카드

| 항목 | 설명 |
|------|------|
| 시설 태그 | 샤워실 / 사우나 / 락커 / 운동복 / 주차 / Wi-Fi 등 칩 |
| 부가 서비스 | 운동복 대여 / 수건 / 사우나 / 굿즈 등 (가격 + 신청 진입) |

### 트레이너 / 강사 섹션

소속 강사 가로 스크롤 카드 → 카드 탭 → MA-125 강사 상세 진입.

### 공지 / 이벤트 미니 배너

진행 중 공지 1~2건 → MA-152 공지사항 진입.

## 계정별 차이

회원이 가입한 센터 정보 조회. 마켓 둘러보기에서 다른 센터(MA-312)는 별도 화면.

## 주요 UX 흐름

1. MA-100 또는 MA-130 → 센터 정보 진입
2. 영업시간 / 위치 / 연락처 확인
3. 길찾기 → 외부 지도 앱
4. 시설 / 부가 서비스 확인 → 결제 진입(MA-141)
5. 강사 카드 → MA-125 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 영업 중 | 영업 상태 칩 초록 |
| 곧 마감 (1시간 전) | 칩 주황 |
| 영업 종료 | 칩 회색 |
| 휴무일 | 안내 배너 강조 |
| 강사 0명 | "현재 등록된 강사가 없어요" |
| 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-080 센터 설정 / SCR-092 지점 관리 |
| 데이터 흐름 | admin → client (센터 정보 조회) |
| 정책 출처 | 영업시간 / 휴무 / 시설 정보 = 센터 설정 (SCR-080) |
| 연동 시나리오 | (직접 시나리오 없음, 정적 데이터 조회) |

**admin → client 영향**

- SCR-080 센터 설정 변경 (영업시간 / 시설 / 부가 서비스) 시 MA-151 즉시 갱신
- SCR-092 지점 정보 변경 시 회원 표시 동기화
