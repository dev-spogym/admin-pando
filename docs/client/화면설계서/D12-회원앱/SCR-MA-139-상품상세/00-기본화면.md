## 화면 목적

회원이 상품 스토어(MA-134)에서 선택한 상품의 상세 정보(가격 / 회차 / 혜택 / 사용 안내 / 후기)를 확인하고, 옵션 결제(MA-400) 또는 장바구니(MA-401) 또는 바로 결제(MA-140)로 진입한다.

## 주요 구성요소

### 상품 헤더

| 항목 | 설명 |
|------|------|
| 메인 이미지 | 가로 스크롤 이미지 갤러리 |
| 카테고리 칩 | PT / 헬스 / 골프 / OT / 부가옵션 |
| 상품명 | 큰 텍스트 |
| 가격 | 정가 (취소선) + 할인가 (강조) |
| 멤버십 등급 할인가 | 회원 등급별 미리보기 |
| 마일리지 사용 가능액 | "최대 5,000P 사용 가능" |
| 별점 평균 + 후기 수 | 후기 섹션 진입 |

### 회차 / 옵션 칩 (상품에 따라)

PT 전용:
- 회차 옵션: 4회(×1.0) / 8회(×1.9) / 16회(×3.5)
- 강사 선택 (선택 시 MA-125 진입)

기간형 이용권:
- 1개월 / 3개월 / 6개월 / 12개월 옵션

### 혜택 / 구성 카드

| 항목 | 설명 |
|------|------|
| 포함 혜택 | "OT 1회 무료" / "마일리지 +5%" 등 |
| 사용 안내 | 시작일 / 만료 정책 / 차감 방식 |
| 환불 정책 요약 | "결제 후 7일 이내 100%, 30일 이내 70%" + MA-404 진입 |

### 강사 정보 카드 (강사형 상품 전용)

| 항목 | 설명 |
|------|------|
| 강사 사진 + 이름 | MA-125 진입 |
| 전문분야 칩 | 다중 선택 표시 |
| NPS / 별점 | 색상 분기 |
| 가능 시간대 | 다음 가능 슬롯 미리보기 |

### 후기 섹션

| 항목 | 설명 |
|------|------|
| 후기 평균 | 별점 + 후기 수 |
| 최근 후기 3건 | 회원명(마스킹) + 별점 + 한줄 |
| 모두 보기 | 후기 전체 화면 진입 |

### 하단 sticky CTA

| 버튼 | 동작 |
|------|------|
| 장바구니 담기 (보조) | MA-401 |
| 바로 결제 (primary) | 옵션 화면(MA-400) 또는 결제 화면(MA-140) |

## 계정별 차이

회원 본인의 등급 / 마일리지 / 활동 데이터 기반 가격 / 추천 표시.

## 주요 UX 흐름

1. MA-134 상품 카드 또는 추천 → MA-139 진입
2. 회차 옵션 / 강사 선택
3. 혜택 / 사용 안내 / 환불 정책 확인
4. 후기 확인
5. 장바구니 담기 또는 바로 결제

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 모든 섹션 활성 |
| 옵션 미선택 | 바로 결제 비활성 |
| 강사형 + 가능 시간 없음 | 다른 강사 선택 안내 |
| 후기 0건 | "아직 후기가 없어요" |
| 비로그인 + 결제 시도 | LoginGateModal |
| 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-P003 상품 상세 / SCR-P006 상품 비교 |
| 데이터 흐름 | admin → client (상품 정보 조회) |
| 정책 출처 | 환불 정책 / 회차 옵션 / 시즌 가격 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**admin → client 영향**

- SCR-P003 상품 정보 변경 시 MA-139 즉시 갱신
- SCR-061 강사 정보 변경 시 강사형 상품 카드 자동 반영
- SCR-C013 후기 신규 등록 시 별점 / 후기 평균 자동 갱신
