## 화면 목적

회원이 Android 하이브리드 앱에서 `Health Connect` 연동을 활성화하고, 수집 데이터 범위 / 권한 상태 / 최근 동기화 시각을 직접 관리한다. 연동된 데이터는 MA-132 체성분/FMS 화면과 admin SCR-I007 회원 건강 연동 요약에 활용된다.

## 주요 구성요소

### 연동 상태 카드

| 항목 | 설명 |
|------|------|
| 연동 상태 배지 | 연결됨 / 부분 권한 / 동기화 지연 / 미연결 / 미지원 |
| 최근 동기화 시각 | 마지막 수집 시각 |
| 최근 동기화 결과 | 정상 / 일부 누락 / 실패 |
| 소스 앱 | Samsung Health / Google Fit 등 최근 수집 소스 라벨 |

### 수집 데이터 범위

| 항목 | 설명 |
|------|------|
| 걸음수 | 최근 7일 / 30일 누적 활동량 |
| 이동 거리 | 일별 거리 합계 |
| 활동 kcal | 활동 에너지 요약 |
| 운동 세션 | 운동 종류 / 시작시각 / 종료시각 / 운동일수 |

### 제외 데이터 안내

| 항목 | 설명 |
|------|------|
| 미수집 범위 | 심박수 / 수면 / 체온 / 혈당 / 의료 데이터 |
| 안내 문구 | "운영·상담에 필요한 최소 활동 데이터만 연동해요" |

### 권한 / 동의 섹션

| 항목 | 설명 |
|------|------|
| 서비스 내 활용 동의 | 건강 요약 / 상담 / 개인화 추천 활용 안내 |
| OS 권한 상태 | 모두 허용 / 일부 허용 / 거부 |
| 권한 수정 | OS 권한 화면 다시 열기 |
| 연동 해제 | 새 수집 중단 + 기존 요약 보존 안내 |

### 액션

| 버튼 | 설명 |
|------|------|
| 연동 시작 | 최초 동의 + Health Connect 권한 요청 |
| 지금 동기화 | 즉시 재조회 + 최근 30일 요약 갱신 |
| 권한 다시 설정 | 부분 권한 / 거부 상태 복구 |
| 연동 해제 | ConfirmDialog 후 연결 해제 |

### 도움말 카드

| 항목 | 설명 |
|------|------|
| 지원 기기 | Android 하이브리드 앱만 지원 |
| 미지원 안내 | iOS는 센터 측정 데이터만 조회 가능 |
| 개인정보 안내 | 마케팅과 별개 동의, 언제든 철회 가능 |

## 계정별 차이

회원 본인만 관리. 트레이너 / FC / 스태프는 회원앱에서 이 화면에 진입하지 않는다.

## 주요 UX 흐름

1. MA-155 설정 → `건강 데이터 연동` 진입
2. 데이터 범위 / 활용 안내 확인 → `연동 시작`
3. 서비스 내 활용 동의 후 Health Connect 권한 요청
4. 권한 허용 → 최근 30일 요약 백필 → MA-132 / SCR-I007 즉시 반영
5. 부분 권한 또는 거부 → 누락 항목 안내 + `권한 다시 설정`
6. `지금 동기화` 또는 앱 재진입 시 최신 활동량 갱신
7. `연동 해제` → 신규 수집 중단, 기존 요약은 마지막 동기화 시점 기준으로 유지

| 지원하지 않는 기기 | "현재 기기에서는 지원하지 않아요" |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-I007 회원 건강 연동 요약 / SCR-M004 회원 상세 |
| 데이터 흐름 | client → admin (회원 동의 + 요약 동기화) |
| 정책 출처 | 데이터 최소수집 범위 / 지연 기준 / 활용 범위 = admin product policy |
| 연동 시나리오 | 60_admin_연동/C9_건강데이터_연동_동기화 |

**client → admin 영향**

- 회원이 연동 활성화 / 해제 → SCR-I007 상태 배지 즉시 갱신
- 최근 30일 활동 요약 동기화 → SCR-I007 활동량 / 운동일수 카드 갱신
- 부분 권한 / 지연 상태 → admin 상담 시 보조 상태로 표시

**admin → client 영향**

- 본사 정책에서 지원 범위가 변경되면 MA-159 안내 문구와 수집 항목이 갱신
- 센터가 건강 데이터 활용 기능을 비활성화한 경우 조회 전용 상태로 전환
