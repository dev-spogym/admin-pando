## 화면 목적

회원이 보유한 쿠폰을 사용 가능 / 사용 완료 / 만료 상태로 분리 조회하고, 쿠폰 등록(코드 입력) / 결제 화면 진입을 한 곳에서 처리한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 설명 |
|------|------|
| 제목 | "쿠폰함" |
| 우상단 | `+ 쿠폰 코드 등록` 버튼 |

### 탭

| 탭 | 표시 정보 |
|----|----------|
| 사용 가능 | 사용 가능 쿠폰 (만료 임박 정렬) |
| 사용 완료 | 이미 사용한 쿠폰 |
| 만료 | 만료된 쿠폰 (회색) |

### 쿠폰 카드

| 항목 | 설명 |
|------|------|
| 좌측 절취선 영역 | 할인율 / 할인액 (큰 숫자) |
| 쿠폰명 | 큰 텍스트 |
| 사용처 | 적용 가능 카테고리 (PT / 헬스 / 마켓 등) |
| 최소 결제액 | "30,000원 이상 결제 시 적용" |
| 만료 D-day | 만료 임박 시 빨강 |
| 발급일 | YYYY-MM-DD |
| 액션 | `결제하기 (MA-140 진입)` 또는 `상세 보기` |

### 쿠폰 코드 등록 모달

| 항목 | 설명 |
|------|------|
| 코드 입력 | 영문/숫자 조합 입력 |
| 등록 CTA | 검증 + 등록 |
| 안내 | "오프라인 행사 등에서 받은 쿠폰 코드를 입력하세요" |

### 빈 상태

"보유 쿠폰이 없어요" + 쿠폰 코드 등록 안내.

## 계정별 차이

회원 본인 쿠폰만 조회. 쿠폰은 운영팀이 발급하거나 마케팅 자동화로 자동 발급.

## 주요 UX 흐름

### A. 쿠폰 사용

1. MA-130 마이페이지 → 쿠폰함 진입
2. 사용 가능 탭에서 쿠폰 선택
3. `결제하기` → MA-140 결제 화면에 자동 적용

### B. 쿠폰 코드 등록

1. 우상단 `+ 쿠폰 코드 등록` 탭
2. 코드 입력 → 검증 → 사용 가능 탭에 추가

## 화면 상태

| 상태 | 설명 |
|------|------|
| 보유 있음 | 카드 리스트 표시 |
| 빈 상태 | 일러스트 + 등록 안내 |
| 만료 임박 (D-7 이하) | 카드 빨강 강조 |
| 사용 완료 | 카드 회색 + "사용 완료" 도장 |
| 만료 | 카드 회색 + "만료" 도장 |
| 코드 등록 실패 | 인라인 에러 (이미 사용 / 만료 / 잘못된 코드) |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-073 쿠폰 관리 |
| 데이터 흐름 | admin → client (쿠폰 발급 / 사용 / 만료) |
| 정책 출처 | 쿠폰 발급 / 만료 / 최소 결제액 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**admin → client 영향**

- SCR-073에서 쿠폰 발급 시 MA-135 사용 가능 탭에 즉시 추가
- 쿠폰 만료 시 자동 만료 탭으로 이동

**client → admin 영향**

- 회원이 결제(MA-140)에서 쿠폰 사용 시 SCR-073 사용 이력에 즉시 기록

- D12_회원앱/P3_쿠폰_사용_플로우 (쿠폰 등록 → 결제 적용 흐름)
