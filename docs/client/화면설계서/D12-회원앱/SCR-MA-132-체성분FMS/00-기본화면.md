## 화면 목적

회원이 본인 인바디 측정 이력과 FMS(Functional Movement Screen) / 체형 분석 결과를 한 화면에서 조회한다. 변화 그래프와 트레이너 안내 메모를 함께 제공하여 동기 부여 + 운동 방향 가이드한다.

## 주요 구성요소

### 인바디 섹션

| 항목 | 설명 |
|------|------|
| 최근 측정 카드 | 측정일 + 체중 / 체지방률 / 골격근량 / BMI |
| 이전 대비 변화 | 전월 / 첫 측정 대비 +/- 표기 |
| 변화 그래프 | 최근 6개월 라인 차트 (체중 / 체지방 / 골격근) |
| 측정 이력 리스트 | 일자 + 주요 지표 |
| 권장 범위 표시 | 표준 범위 표기 |

### FMS / 체형 섹션

| 항목 | 설명 |
|------|------|
| FMS 총점 | 0~21 점 + 색상 분기 |
| 세부 항목 점수 | 7개 동작 항목별 점수 (DSQT, HSQT 등) |
| 가동성 / 불균형 / 자세 문제 | 분석 결과 카드 |
| 권장 운동 / 주의사항 | 트레이너 안내 텍스트 |

### 코치 메모 섹션

| 항목 | 설명 |
|------|------|
| 트레이너 메모 | 측정 결과 기반 안내 |
| 메모 일자 + 작성자 | 트레이너 이름 |
| 다음 측정 권장일 | 자동 계산 (예: 4주 후) |

### 액션

| 버튼 | 설명 |
|------|------|
| 측정 예약 | OT1 / OT2 (체성분 + FMS 측정 포함) → MA-121 진입 |
| 트레이너에게 문의 | 강사톡 진입 (MA-340/341) |
| 결과 PDF 다운로드 | 측정 결과 출력 |

## 계정별 차이

회원 본인 데이터만 조회. 트레이너는 별도 화면에서 담당 회원 결과 입력/조회.

## 주요 UX 흐름

1. MA-100 홈 → `체성분 보기` 또는 마이페이지 → MA-132 진입
2. 인바디 최근 측정 + 변화 그래프 확인
3. FMS 점수 + 분석 결과 확인
4. 코치 메모 확인
5. 다음 측정 예약 또는 트레이너 문의 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 측정 이력 있음 | 모든 카드 활성 |
| 측정 0회 (신규) | 일러스트 + "첫 측정을 받아보세요" + OT1 예약 CTA |
| FMS 미측정 | FMS 섹션 회색 + OT2 예약 CTA |
| 코치 메모 없음 | "아직 코치 메모가 없어요" |
| 그래프 데이터 부족 | 최소 2회 측정 후 활성 |
| 로딩 | 카드 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-M006 체성분 / SCR-I006 통합 체성분 / SCR-I007 회원 건강 연동 |
| 데이터 흐름 | admin → client (트레이너 입력 → 회원 즉시 조회) |
| 정책 출처 | 측정 보상 마일리지 (100P) / 다음 측정 권장일 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C5_체성분_FMS_입력 |

**admin → client 영향**

- 트레이너가 SCR-M006에 입력 → MA-132 즉시 갱신 + 푸시 알림
- InBody 자동 연동 시 SCR-I006 검수 후 회원 노출 (계약 외 #16)
- FMS 점수 / 코치 메모 / 다음 측정 권장일 자동 계산
