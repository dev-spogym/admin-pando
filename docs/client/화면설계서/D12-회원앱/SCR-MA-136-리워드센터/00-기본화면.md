## 화면 목적

회원의 마일리지 보유 / 적립 내역 / 사용 내역 / 사용처를 한 화면에서 본다. 적립 트리거(루틴 완료, 출석 등)와 사용처(재등록 / 리커버리 / 굿즈 / 마켓 결제)를 명확히 안내한다.

## 주요 구성요소

### 상단 보유 카드

| 항목 | 설명 |
|------|------|
| 보유 마일리지 | 큰 숫자 |
| 만료 예정 (30일 내) | 회색 작은 숫자 + "30일 이내 만료" |
| 등급별 적립률 안내 | "VIP 등급 +20% 적립" 등 |

### 탭

| 탭 | 내용 |
|----|------|
| 적립 내역 | 트리거별 분류 |
| 사용 내역 | 사용처별 분류 |
| 적립 기준 | 트리거별 단가 카드 |
| 사용처 | 사용처별 카드 |

### 적립 내역 (트리거 분류)

| 트리거 | 단가 예시 |
|--------|-----------|
| 운동 루틴 완료 | 50P |
| 출석 5회 연속 | 200P |
| 체성분 측정 | 100P |
| 후기 작성 | 100P |
| 친구 초대 ① 가입 | 5,000P |
| 친구 초대 ② 첫 결제 | 5,000P |
| 친구 초대 ③ 첫 후기 | 3,000P |

각 항목 카드: 일자 + 트리거명 + 적립 P + 누적 P.

### 사용 내역 (사용처 분류)

| 사용처 | 차감 예시 |
|--------|-----------|
| 재등록 결제 차감 | -5,000P |
| 리커버리 결제 (스트레칭/사우나) | -1,000P |
| 굿즈 교환 | -3,000P |
| 마켓 결제 차감 | -2,000P |

각 항목 카드: 일자 + 사용처 + 차감 P + 잔여 P.

### 월별 그래프

최근 6개월 적립 / 사용 막대 차트.

### 적립 기준 카드 (탭)

각 트리거별 단가 안내 카드. 운영 정책 세트 기준.

### 사용처 카드 (탭)

| 사용처 | 진입 |
|--------|------|
| 재등록 결제 | MA-138 |
| 리커버리 (스트레칭/사우나) | MA-141 |
| 굿즈 교환 | (외부 운영 페이지) |
| 마켓 결제 | MA-140 |

## 계정별 차이

회원 본인 마일리지만 조회.

## 주요 UX 흐름

1. MA-130 마이페이지 → 리워드 센터 진입
2. 보유 카드 + 만료 임박 확인
3. 탭 전환으로 적립/사용 내역, 적립 기준, 사용처 확인
4. 사용처 카드 → 결제 화면 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 보유 있음 | 모든 카드 활성 |
| 보유 0P | "마일리지를 적립해 보세요" + 적립 기준 카드 강조 |
| 만료 임박 | 만료 카드 빨강 강조 |
| 적립 내역 0건 | "아직 적립 이력이 없어요" |
| 그래프 데이터 부족 | 최소 1개월 적립 후 활성 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-074 마일리지 관리 |
| 데이터 흐름 | 양방향 (적립 트리거 / 사용 차감) |
| 정책 출처 | 적립 단가 / 사용 단위 (100P) / 만료 (1년) = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**admin → client 영향**

- SCR-074에서 적립 단가 변경 시 즉시 반영
- 친구 초대 검증 완료 7일 후 적립 자동 처리

**client → admin 영향**

- 결제 시 마일리지 사용 → SCR-074 사용 이력 즉시 등재
- 만료 30일 전 알림 발송 자동화 (정책 1.10)
