## 화면 목적

회원이 서비스 이용약관 / 개인정보 처리방침 / 위치기반 서비스 약관 / 마케팅 수신 안내 등 운영 정책 문서를 조회 전용으로 확인한다.

## 주요 구성요소

### 약관 리스트

| 항목 | 종류 | 동의 상태 표시 |
|------|------|---------------|
| 서비스 이용약관 | 필수 | 동의 완료 (가입일 표기) |
| 개인정보 처리방침 | 필수 | 동의 완료 |
| 위치기반 서비스 약관 | 필수 (위치 기능 사용 시) | 동의 완료 / 미동의 |
| 마케팅 수신 안내 | 선택 | ON / OFF (MA-157에서 변경) |

각 항목 우측 화살표 → 약관 본문 페이지 진입.

### 약관 본문 페이지

| 항목 | 설명 |
|------|------|
| 헤더 | 약관명 + 시행일 |
| 본문 | 마크다운 렌더링 (조항별 Heading) |
| 목차 | 좌측 또는 상단 (긴 약관 시) |
| 변경 이력 | 하단에 과거 버전 보기 |
| 닫기 / 뒤로 | 이전 화면 복귀 |

### 약관 변경 알림 (조건부)

약관 개정 시 회원에게 푸시 + MA-156 진입 시 변경 안내 배너 노출. 필수 약관 변경 시 재동의 요구 (별도 모달).

## 계정별 차이

회원 본인 동의 이력 표시. 약관 본문은 모든 사용자 동일.

## 주요 UX 흐름

1. MA-155 설정 → `약관 / 정책` 진입
2. 리스트에서 약관 선택
3. 약관 본문 페이지에서 조회
4. 약관 변경 시 재동의 모달 자동 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 리스트 + 동의 상태 표시 |
| 약관 개정 | 상단 배너 + 해당 약관 강조 |
| 필수 약관 재동의 필요 | 모달 + 동의 시 통과 |
| 본문 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-080 센터 설정 (약관 영역) |
| 데이터 흐름 | admin → client (약관 본문 + 개정 알림) |
| 정책 출처 | 약관 본문 / 개정 시 재동의 필수 정책 = admin 본사 설정 |
| 연동 시나리오 | 60_admin_연동/C8_탈퇴_복구_파기 |

**admin → client 영향**

- SCR-080에서 약관 개정 시 MA-156 상단 배너 + 필수 약관 변경 시 재동의 모달
- 약관 본문은 즉시 갱신
