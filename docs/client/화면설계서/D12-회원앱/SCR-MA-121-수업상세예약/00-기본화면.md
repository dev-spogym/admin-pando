## 화면 목적

회원이 수업 정보(시간 / 강사 / 정원), 수업 유형 분기(PT / OT1 / OT2 / GX / Golf), 차감 안내를 확인하고 예약, 예약 취소, 대기 등록을 한 화면에서 처리한다.

## 주요 구성요소

### 수업 유형 라디오 / 탭

| 유형 | 표기 | 차감 안내 | 동작 |
|------|------|-----------|------|
| PT | "PT 정규 1회" | "수업 완료 시 PT 잔여 1회 차감" | 회원 자유 시간 → 트레이너 승인 대기 |
| OT1 | "신규 1차 OT" | "OT 잔여 1회 차감 (없으면 무료 1회 자동)" | 등록 직후 즉시 확정, 30일 권장 |
| OT2 | "2차 OT" | "OT 잔여 1회 차감, OT1 완료 후 진입" | OT1 미완료 시 비활성 |
| GX | "GX 그룹 클래스" | "정원 자동 확정 / 만석 시 대기" | 정원 점검 → 즉시 확정 또는 대기열 |
| Golf | "골프 강사 / 타석" | "강사: 승인 대기 / 타석: 즉시 확정" | 강사 슬롯 또는 타석 선택 분기 |

## 계정별 차이

회원 본인만 예약 가능. 회원 요청형 예약은 강사가 별도 화면에서 승인/거절한다.

## 주요 UX 흐름

### A. PT 예약 (승인형)

1. MA-120 → PT 카드 탭 → MA-121 진입
2. PT 라디오 선택 → 강사 가능 시간 슬롯 노출
3. 시간 선택 + 메모 입력 → `예약 요청` CTA
4. "트레이너 승인 대기" 상태로 생성 → MA-122에서 확인

### B. OT1 / OT2 예약

1. PT 카드 → OT1 라디오 선택 (OT2는 OT1 완료 후 활성)
2. 시간 선택 → `예약하기` (즉시 확정)
3. 예약 완료 토스트 + MA-122 진입

### C. GX 예약 (정원형)

1. GX 카드 → MA-121 진입
2. `예약하기` → 정원 즉시 점검 → 확정 또는 대기

### D. 정원 만석

1. 만석 카드 진입 → `대기 등록` 활성
2. 대기 신청 → MA-124 진입
3. 자리 발생 시 푸시 알림 + 자동 확정

### E. 예약 취소

1. 본인 예약 + 취소 가능 기한 내
2. `예약 취소` CTA → ConfirmDialog
3. 취소 처리 + 토스트 + 잔여 회차 갱신

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-C001 캘린더 / SCR-C002 수업 관리 / SCR-C007 횟수 관리 / SCR-C012 대기열 |
| 데이터 흐름 | 양방향 (회원 예약 → admin 캘린더 / admin 강사 승인 → 회원 알림) |
| 정책 출처 | PT/OT/GX 분기 + 차감 시점(`completed`만) = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**client → admin 영향**

- 회원 예약 요청(PT) → SCR-C001 캘린더에 승인 대기 카드 즉시 노출
- 트레이너 승인/거절은 트레이너앱(admin 도메인 미러)에서 처리

**admin → client 영향**

- SCR-C002에서 회원 예약 직접 등록/수정 시 회원 MA-121 즉시 반영
- SCR-C007 횟수 차감 정책 변경 시 차감 안내 즉시 갱신
