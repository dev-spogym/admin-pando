## 화면 목적

회원이 가장 자주 쓰는 예약 / 출석 / 리워드 / 온보딩 / 공지를 한 화면에서 진입한다. 만료 임박, 미완료 온보딩, 신규 알림 등 회원 상황에 따라 최우선 카드를 자동 노출한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 설명 |
|------|------|
| 회원 인사말 | "안녕하세요, OOO님" + 회원 등급 배지 |
| 알림 아이콘 | 미읽음 카운트 배지 (MA-150 진입) |
| 둘러보기 진입 | MA-300 마켓 둘러보기 진입 |

### 만료 / 미완료 우선 배너 (조건부 노출)

| 트리거 | 배너 |
|--------|------|
| 회원권 만료 D-14 / D-7 / D-1 | 색상 분기 + `재등록 추천(MA-138)` CTA |
| 온보딩 미완료 | "온보딩을 마저 입력해 주세요" + MA-127 진입 |
| AT-RISK (4주 미방문) | "오랜만이에요. 추천 플랜을 확인해 보세요" + MA-138 |

### 핵심 바로가기 (3 또는 4 그리드)

| 카드 | 설명 |
|------|------|
| PT 예약 바로가기 | 다음 PT 예약 또는 잔여 회차 안내 + MA-121 진입 |
| GX 스케줄 바로가기 | 오늘/이번 주 GX 요약 + MA-120 진입 |
| Golf 예약 바로가기 | 골프 예약 + MA-123 진입 |

### 오늘 수업 카드

| 항목 | 설명 |
|------|------|
| 오늘 예약 1~3건 | 시간 / 수업명 / 강사 / 위치 |
| 액션 | 예약 보기 / QR 체크인(MA-110) |
| 빈 상태 | "오늘 예약된 수업이 없어요" + 예약하기 CTA |

### 마일리지 / 배지 요약 카드

| 항목 | 설명 |
|------|------|
| 보유 마일리지 | 큰 숫자 + 만료 임박 안내 |
| 최근 획득 배지 | 1~3개 표시 + MA-137 진입 |
| 등급 진척률 | 다음 등급까지 진척 바 + MA-500 진입 |

### 공지 / 이벤트 배너

| 항목 | 설명 |
|------|------|
| 가로 스크롤 배너 | 진행 중 공지 / 이벤트 / 프로모션 |
| 액션 | 배너 탭 → 상세 페이지 이동 |

### 이번 달 출석 요약

| 항목 | 설명 |
|------|------|
| 출석 일수 + 전월 대비 | "이번 달 12회 (+3)" |
| 캘린더 미니뷰 | 출석일 색칠 |
| 더보기 | MA-111 진입 |

### 추천 루틴 / 온보딩 카드

| 항목 | 설명 |
|------|------|
| 첫 루틴 카드 | 온보딩 기반 추천 (MA-128) |
| 트레이너 추천 루틴 | 담당 트레이너가 보낸 루틴 |

## 계정별 차이

회원(member) 전용 홈. 트레이너 / FC / 스태프는 별도 홈 화면을 사용한다.

## 주요 UX 흐름

1. 로그인 성공 → MA-100 자동 진입
2. 우선 배너 (만료/온보딩/AT-RISK) 확인 → 해당 화면 진입
3. 핵심 바로가기로 빠른 예약 진입
4. 오늘 수업 → 출석 시간 직전에 QR 체크인
5. 마일리지/배지 카드 → 리워드 센터 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 신규 회원 | 온보딩 미완료 배너 + 둘러보기 안내 |
| 활성 회원 | 오늘 수업 + 마일리지 요약 |
| 만료 임박 | 우선 배너 강조 |
| 만료 후 | AT-RISK 케어 배너 |
| 알림 미읽음 | 헤더 배지 + 카드별 신규 표시 |
| 로딩 | 카드 스켈레톤 |
| 새로고침 (당겨서) | 상단 인디케이터 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-101 대시보드 통합 (admin 측 KPI 미러) |
| 데이터 흐름 | admin → client (만료/온보딩/AT-RISK 우선 카드 결정 데이터 조회) |
| 정책 출처 | 우선 카드 결정 = admin 본사 정책 세트 (D-day, AT-RISK 기준) |
| 연동 시나리오 | 60_admin_연동/C1, C6, C7 |

**admin → client 영향**

- SCR-072 자동 알림 트리거 발생 시 홈 우선 배너 노출
- SCR-085 공지 발행 시 홈 배너 즉시 갱신
- SCR-094 KPI에 출석 / 마일리지 / 등급 변화 즉시 동기화

- SCR-MA-121: 수업 상세 / 예약
- SCR-MA-138: 재등록 추천 (만료 배너)
- SCR-MA-150: 알림센터
- D12_회원앱/H1_홈진입_우선카드 (홈 진입 시 우선 카드 결정 흐름)
