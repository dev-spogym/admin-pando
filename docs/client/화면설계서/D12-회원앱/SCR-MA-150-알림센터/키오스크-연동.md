# SCR-MA-150 알림센터 — 키오스크 연동

본 화면은 회원이 받는 모든 알림의 허브다. 키오스크는 두 가지 흐름에서 본 화면으로 알림을 보낸다.

## 알림 발송 시나리오

### 1. 락커 번호 앱 발송 (KIO-203)

키오스크 출석 후 락커 번호 전달 방식이 `앱 발송`인 경우.

```
[KIO-201 출석 성공]
   ↓ 락커 자동 배정
[admin이 알림 발송 트리거]
   ↓
[SCR-MA-150 알림센터에 락커 카드 표시 + 푸시]
   ↓
[키오스크 KIO-203에는 "앱에서 확인해주세요"]
```

본 화면에서 표시해야 하는 락커 알림 카드 형식:

| 항목 | 내용 |
|---|---|
| 제목 | "오늘 락커 번호" |
| 본문 | 락커 번호 (큰 글자) |
| 위치 안내 | 존(zone) 정보 |
| 유효 시간 | 출석 시각 + 운영시간 |
| 우선순위 | 푸시 + 인앱 동시 표시 |
| 자동 정리 | 영업 종료 시 자동 만료 표시 |

### 2. 골프 예약 알림 (KIO-504 또는 자동 승격)

| 알림 종류 | 발생 트리거 |
|---|---|
| 예약 확정 | 키오스크 KIO-504 또는 회원앱 SCR-MA-123 |
| 대기 등록 완료 | 키오스크 KIO-504 또는 회원앱 |
| 대기 자동 승격 | admin 자동 처리 시 |
| 예약 취소 (운영자 사유) | admin 측 사유 입력 후 발송 |

## 회원앱 측 요건

| 항목 | 보완 사항 |
|---|---|
| 락커 알림 카드 형식 추가 | 위 표 기준 |
| 키오스크 출처 표시 | 알림 메타에 `source=kiosk` (옵션) |
| 미연동 회원 예외 | 앱 미설치/미로그인 회원은 키오스크가 다른 전달 방식으로 fallback |
| 전송 실패 처리 | 회원앱 발송 실패 시 admin이 키오스크에 즉시 통보 → 키오스크가 영수증/프런트 안내로 전환 |

## 발송 채널 분리

| 채널 | 용도 |
|---|---|
| 푸시 알림 | 즉시성, 잠금 화면에서도 보임 |
| 인앱 메시지 | 앱 진입 시 표시, 푸시 차단 사용자에게도 도달 |
| 알림함 카드 | 본 화면에 영구 적재 (만료 표시) |

세 채널은 같은 메시지를 다른 노출 방식으로 처리한다.
