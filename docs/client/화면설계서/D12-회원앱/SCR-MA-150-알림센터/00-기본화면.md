## 화면 목적

회원앱의 7개 카테고리 알림(예약 / 이용권 / 리워드 / 공지 / AT-RISK 케어 / 수업·후기 / 부가시설)을 통합 조회하고, 카드 선택 시 정의된 라우팅 표에 따라 대상 화면으로 즉시 이동한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 설명 |
|------|------|
| 제목 | "알림" |
| 우측 액션 | `모두 읽음 처리` 버튼 |
| 미읽음 카운트 배지 | 헤더 우상단 또는 탭 옆 표시 |

### 탭

| 탭 | 설명 |
|----|------|
| 전체 | 모든 알림 (읽음 + 미읽음) |
| 미읽음 | 미읽음 알림만 표시 |

### 카테고리 필터 칩 (가로 스크롤)

| 칩 | 색상 |
|----|------|
| 예약 | primary |
| 이용권 | warning |
| 리워드 | success |
| 공지 | neutral |
| AT-RISK | danger |
| 수업·후기 | secondary |
| 부가시설 | info |

### 알림 카드 구성

| 영역 | 표시 정보 |
|------|----------|
| 좌측 | 카테고리 아이콘 (색상 분기) |
| 중앙 상단 | 카테고리 칩 + 제목 1줄 |
| 중앙 본문 | 본문 1~2줄 요약 |
| 중앙 하단 | 발생 시간 (예: "5분 전" / "3시간 전" / "어제" / "MM-DD") |
| 우측 상단 | 미읽음 점 (●) |
| 우측 하단 | 1차 액션 버튼 (카테고리별, 텍스트 또는 화살표) |

### 카테고리별 라우팅 매핑 (정책 1.10)

| 카테고리 | 트리거 예시 | 1차 액션 | 라우팅 대상 |
|----------|-------------|----------|-------------|
| 예약 | 예약 확정 / 변경 / 노쇼 임박 | "예약 보기" | MA-122 내 예약 |
| 이용권 | 만료 D-14/D-7/D-1, 잔여 ≤ 3 | "재등록 추천" | MA-138 |
| 리워드 | 마일리지 적립 / 배지 획득 / 등급 상승 | "리워드 보기" | MA-136 / MA-137 / MA-500 |
| 공지 | 센터 이벤트 / 휴무 / 공지 | "공지 보기" | MA-152 |
| AT-RISK | 4주 미방문 / 만료 후 미재등록 | "재등록 안내" | MA-138 |
| 수업·후기 | 수업 시작 30분 전 / 후기 요청 | "후기 작성" 또는 "수업 보기" | MA-126 / MA-121 |
| 부가시설 | 사우나 / 락커 / 굿즈 만료 | "이용권 보기" | MA-131 / MA-151 |

### 스와이프 액션

| 방향 | 동작 |
|------|------|
| 우측 스와이프 | 읽음 처리 |
| 좌측 스와이프 | 보관 처리 (7일 후 자동 보관과 동일) |

## 계정별 차이

회원 본인의 알림만 조회 가능. 알림 발송 트리거는 운영(본사) 정책 세트 + 회원의 알림 설정(MA-155) ON/OFF 조합으로 결정된다.

## 주요 UX 흐름

### A. 일반 알림 확인

1. MA-100 홈 또는 메뉴에서 알림 아이콘 탭 → MA-150 진입
2. 전체 탭에서 알림 리스트 확인
3. 카테고리 칩으로 필터 (선택)
4. 알림 카드 탭 → 라우팅 표에 따라 대상 화면 이동
5. 자동 읽음 처리

### B. 미읽음만 확인

1. `미읽음` 탭 선택
2. 미읽음 알림 리스트 확인
3. `모두 읽음 처리` 버튼 → 일괄 읽음

### C. 푸시 알림에서 진입

1. OS 푸시 알림 수신 → 탭
2. 카테고리에 맞는 화면으로 다이렉트 라우팅 (MA-150 거치지 않음)
3. MA-150에서도 동일 알림은 자동 읽음 처리

### D. AT-RISK 케어 알림

1. 4주 미방문 회원에게 자동 발송
2. 카드 클릭 → MA-138 재등록 추천
3. 회원이 MA-155에서 AT-RISK 카테고리 OFF 시 푸시 차단되지만, 알림센터 카드는 노출됨

## 화면 상태

| 상태 | 설명 |
|------|------|
| 알림 있음 (전체) | 알림 카드 리스트 표시 |
| 미읽음 있음 | 진하게 강조 + 미읽음 점 |
| 빈 상태 (전체 0건) | 일러스트 + "새로운 알림이 없어요" |
| 빈 상태 (미읽음 0건) | "모든 알림을 확인했어요" |
| 빈 상태 (카테고리 필터 0건) | "이 카테고리 알림이 없어요" + 필터 해제 버튼 |
| 로딩 | 카드 스켈레톤 |
| 새로고침 (당겨서) | 상단 로딩 인디케이터 |
| 라우팅 실패 | "이동할 수 없는 알림입니다" 토스트 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-072 자동 알림 / SCR-076 캠페인 / SCR-085 공지 |
| 데이터 흐름 | admin → client (알림 발송) + client → admin (읽음 / 보관) |
| 정책 출처 | 7개 카테고리 라우팅 = 회원앱 정책 1.10 / 발송 트리거 = admin |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**admin → client 영향**

- SCR-072 모든 자동 알림 → 회원 카테고리 ON/OFF 판정 후 발송
- SCR-076 캠페인 메시지 → 회원 알림센터 누적
- SCR-085 공지 발행 → 공지 카테고리 알림

**client → admin 영향**

- 회원 OFF 설정 → SCR-072 발송 결정에서 즉시 반영

## 관련 다이어그램

- SCR-MA-138: 재등록 추천 (이용권 / AT-RISK 카테고리 라우팅)
- SCR-MA-122: 내 예약 (예약 카테고리 라우팅)
- SCR-MA-126: 수업 후기 (수업·후기 카테고리 라우팅)
- SCR-MA-131: 이용권 / 잔여 회차 (부가시설 카테고리 라우팅)
- SCR-MA-155: 설정 (알림 ON/OFF 채널 관리)
- 회원앱 정책 1.10 알림 카테고리 / 라우팅 정책 (기능명세서 01-공통-회원.md)
