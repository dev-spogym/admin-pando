## 화면 목적

회원이 필수 동의 상태(조회 전용)와 선택 동의(마케팅 SMS / 이메일 / 푸시) ON/OFF를 한 화면에서 관리한다. 최근 변경일을 함께 표시하여 이력 추적이 가능하다.

## 주요 구성요소

### 필수 동의 섹션 (조회 전용)

| 항목 | 표시 |
|------|------|
| 서비스 이용약관 | 동의 완료 + 동의일 |
| 개인정보 처리방침 | 동의 완료 + 동의일 |
| 위치기반 서비스 약관 | 동의 완료 + 동의일 |

각 항목 우측 화살표 → MA-156 약관 본문 진입.

### 선택 동의 섹션 (변경 가능)

| 항목 | 토글 | 보조 텍스트 |
|------|------|-------------|
| 마케팅 SMS 수신 | ON / OFF | 이벤트 / 프로모션 / 신상품 정보 |
| 마케팅 이메일 수신 | ON / OFF | 동일 |
| 마케팅 푸시 수신 | ON / OFF | 앱 푸시로 마케팅 안내 |

각 항목 변경 시:
- 즉시 저장
- 우측에 최근 변경일 표시
- 변경 토스트 ("마케팅 SMS 수신 ON / OFF")

### 안내 카드

| 항목 | 설명 |
|------|------|
| 마케팅 동의 효과 | "마케팅 동의 시 멤버 한정 혜택 / 이벤트 안내를 받을 수 있어요" |
| 동의 철회 | "언제든지 철회할 수 있고, 철회 후에도 서비스 이용에 영향 없어요" |

## 계정별 차이

회원 본인 동의만 관리. 필수 동의는 변경 불가 (탈퇴 외 방법 없음).

## 주요 UX 흐름

1. MA-155 설정 → `동의관리` 진입
2. 필수 동의 상태 확인
3. 선택 동의 토글 변경 → 즉시 저장 + 토스트
4. 약관 본문 진입 → MA-156

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 모든 항목 표시 |
| 변경 처리 중 | 토글 로딩 |
| 변경 실패 | 토스트 + 원래 상태 복원 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-080 센터 설정 (정책) / SCR-M004 회원 상세 (조회) |
| 데이터 흐름 | 양방향 (회원 선택 동의 변경 → admin 마케팅 발송 결정 반영) |
| 정책 출처 | 필수 동의 = 변경 불가 (탈퇴만) / 선택 동의 = 회원 본인 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**client → admin 영향**

- 회원이 마케팅 SMS / 이메일 / 푸시 동의 변경 → SCR-072 발송 결정 즉시 반영
- 변경 이력 SCR-M004 회원 상세에서 조회

**admin → client 영향**

- 새 약관 추가 시 회원에게 동의 요청 모달
