## 화면 목적

센터 운영 공지 / 이벤트 / 휴무 / 시스템 안내를 회원에게 카테고리별로 노출한다. 알림센터(MA-150)에서 공지 카테고리 탭 시 진입.

## 주요 구성요소

### 카테고리 탭

| 탭 | 설명 |
|----|------|
| 전체 | 모든 공지 |
| 운영 안내 | 영업시간 변경 / 휴무 / 시설 점검 |
| 이벤트 / 프로모션 | 행사 / 할인 / 친구 초대 캠페인 |
| 시스템 안내 | 약관 변경 / 앱 업데이트 |

### 공지 카드 리스트

| 항목 | 설명 |
|------|------|
| 카테고리 칩 | 색상 분기 |
| 제목 | 큰 텍스트 |
| 본문 미리보기 | 1~2줄 |
| 작성일 | YYYY-MM-DD |
| 미읽음 점 (●) | 진하게 강조 |
| 중요 마크 (📌) | 운영팀 지정 중요 공지 |

### 공지 상세 모달 / 페이지

| 항목 | 설명 |
|------|------|
| 카테고리 + 제목 | 헤더 |
| 본문 | 마크다운 또는 HTML 렌더링 |
| 첨부 이미지 | 가로 스크롤 |
| 작성일 + 작성자 | 운영팀 표기 |
| 관련 링크 | 외부 / 내부 화면 진입 (예: MA-138 재등록) |
| 공유 | ShareSheet 진입 |

### 빈 상태

"공지사항이 없어요" + 일러스트.

## 계정별 차이

회원이 가입한 센터 + 본사 공통 공지. 마켓 둘러보기에서는 다른 센터 공지 미노출.

## 주요 UX 흐름

1. MA-100 홈 배너 또는 MA-150 알림센터 → MA-152 진입
2. 카테고리 탭으로 좁힘
3. 공지 카드 탭 → 상세 모달
4. 관련 링크 → 해당 화면 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 공지 있음 | 카드 리스트 표시 |
| 미읽음 강조 | 진하게 |
| 중요 공지 | 상단 고정 |
| 빈 상태 | 일러스트 |
| 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-085 공지사항 관리 |
| 데이터 흐름 | admin → client (공지 발행) |
| 정책 출처 | 공지 카테고리 4종 (운영 안내 / 이벤트 / 시스템 / 기타) = admin 운영 분류 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**admin → client 영향**

- SCR-085 공지 발행 시 MA-152 즉시 + 공지 카테고리 알림 발송
- 중요 공지 (📌) 지정 시 상단 고정 + 홈 배너 (MA-100)
- 공지 수정/삭제 시 회원 화면 즉시 반영
