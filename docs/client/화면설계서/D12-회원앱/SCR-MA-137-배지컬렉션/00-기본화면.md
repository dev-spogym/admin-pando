## 화면 목적

회원이 본인 획득 배지와 미획득 배지(조건 안내)를 카테고리별로 조회한다. 배지 클릭 시 상세 모달에서 조건 / 진척률 / 보상 마일리지를 확인하고, 미획득 배지의 다음 단계를 인지한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 설명 |
|------|------|
| 제목 | "배지 컬렉션" |
| 획득 카운트 | "획득 12 / 30" + 진행 바 |

### 카테고리 칩

`전체 / 출석 / 수업 / 측정 / 리워드 / 친구 / 마일스톤 (활동 기반)`

### 배지 그리드 (2x4 또는 3x4)

획득 배지 (강조 색) / 미획득 배지 (회색) 분리.

| 항목 | 설명 |
|------|------|
| 배지 아이콘 | 카테고리별 색상 + 모양 |
| 배지명 | 짧은 라벨 |
| 획득 일자 (획득 시) | YYYY-MM-DD |
| 미획득 표시 | 회색 + 자물쇠 아이콘 |

### 배지 상세 모달

| 항목 | 설명 |
|------|------|
| 배지 일러스트 | 큰 이미지 |
| 배지명 | 큰 텍스트 |
| 조건 설명 | "PT 10회 완강 시 획득" |
| 진척률 | 진행 바 (예: 7/10) |
| 보상 마일리지 | 획득 시 적립되는 P |
| 획득 일자 (획득 시) | YYYY-MM-DD |
| 공유 버튼 (획득 시) | ShareSheet 진입 |

### 마일스톤 배지 (활동 기반 8종)

| 배지 | 조건 |
|------|------|
| 첫 PT 완주 | 첫 PT 수업 완료 |
| 10회 연속 출석 | 10일 연속 출석 |
| 첫 후기 | 첫 후기 작성 |
| 한 달 개근 | 한 달 빠짐 없이 출석 |
| 누적 결제 200만원 | 누적 결제액 200만원 도달 |
| 친구 초대 마스터 | 친구 5명 가입 |
| 얼리버드 | 오전 6시 이전 출석 10회 |
| 마라토너 | 누적 1년 회원 |

## 계정별 차이

회원 본인 배지만 조회. 활동 기반 마일스톤 배지는 자동 부여.

## 주요 UX 흐름

1. MA-130 또는 MA-136 → 배지 컬렉션 진입
2. 카테고리 칩으로 분류
3. 배지 탭 → 상세 모달
4. 미획득 배지 → 조건 + 진척률 확인
5. 획득 배지 → 공유 (ShareSheet)

## 화면 상태

| 상태 | 설명 |
|------|------|
| 획득 배지 있음 | 강조 색 표시 |
| 미획득 배지 | 회색 + 자물쇠 |
| 배지 0개 (신규) | "첫 배지를 획득해 보세요" + 조건 가이드 |
| 카테고리 0건 | "이 카테고리 배지가 없어요" |
