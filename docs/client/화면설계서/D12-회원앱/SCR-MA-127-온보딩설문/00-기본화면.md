## 화면 목적

회원이 앱 연동(MA-002) 직후 또는 첫 로그인 직후 운동 목적·성향, 통증·체형 정보, 선호 시간을 단계별(3페이지)로 입력하여 첫 루틴 제안과 FMS 리포트 정확도에 활용한다.

## 주요 구성요소

### 진행 인디케이터

| 항목 | 설명 |
|------|------|
| 단계 표시 | 1/3 → 2/3 → 3/3 (상단 진행 바 또는 점 인디케이터) |
| 페이지 헤드라인 | 각 페이지 상단에 1줄 헤드라인 + 보조 설명 |
| 우상단 링크 | `나중에 입력` (모든 페이지 노출, 클릭 시 MA-128 미완료 상태 진입) |

### 페이지 1 — 운동 목적·성향

| 항목 | 입력 방식 | 옵션 풀 |
|------|-----------|---------|
| 운동 목적 (다중 선택, 필수) | 칩 선택 | 감량 / 근비대 / 체형교정 / 통증완화 / 체력증진 / 자세교정 / 재활 / 대회 준비 |
| 운동 성향 (단일 선택) | 라디오 카드 | 강하게 끌어주세요 / 친절하게 안내 / 조용한 운동 / 그룹 분위기 / 자율 운동 |
| 강도 선호 (단일 선택) | 슬라이더 또는 라디오 | 저강도 / 중강도 / 고강도 |
| 선호 요일 (다중) | 요일 칩 7개 | 월~일 |
| 선호 시간대 (다중) | 시간 칩 | 오전 / 낮 / 저녁 / 심야 |

### 페이지 2 — 통증·부상

| 항목 | 입력 방식 | 옵션 풀 |
|------|-----------|---------|
| 통증 부위 (다중) | 인체 도식 + 칩 | 목 / 어깨 / 등 / 허리 / 골반 / 무릎 / 발목 / 손목 / 팔꿈치 / 없음 |
| 과거 부상 (다중 + 직접 입력) | 칩 + textarea | 디스크 / 회전근개 / 십자인대 / 발목인대 / 골절 / 수술 이력 / 기타 / 없음 |
| 불편한 동작 (다중) | 칩 | 스쿼트 / 데드리프트 / 푸쉬업 / 풀업 / 러닝 / 점프 / 회전 / 없음 |

### 페이지 3 — 체형·집중 부위

| 항목 | 입력 방식 | 옵션 풀 |
|------|-----------|---------|
| 체형 (단일) | 라디오 카드 | 상체비만 / 하체비만 / 복부비만 / 마른비만 / 표준 / 근육형 |
| 집중 부위 (다중) | 인체 도식 + 칩 | 복부 / 등 / 어깨 / 가슴 / 팔 / 엉덩이 / 다리 / 종아리 |

### 하단 CTA (공통)

| 버튼 | 표시 조건 | 설명 |
|------|-----------|------|
| 이전 | 2/3, 3/3 | 이전 페이지로 이동 |
| 다음 | 1/3, 2/3, 페이지 입력 완료 | 다음 페이지로 진행 |
| 입력 완료 | 3/3 + 필수 항목 입력 | MA-128 온보딩 완료 화면으로 이동 |
| 나중에 입력 | 항상 (우상단) | 미완료 상태로 MA-128 진입 (홈에 재안내 배너 표시) |

## 계정별 차이

회원 본인만 입력 가능. CRM 등록 회원의 첫 진입 또는 마이페이지에서 재진입한 회원이 작성한다.

## 주요 UX 흐름

1. MA-002 앱 연동 완료 → 자동 진입
2. 페이지 1 입력 → `다음`
3. 페이지 2 입력 → `다음`
4. 페이지 3 입력 → `입력 완료`
5. MA-128 온보딩 완료 화면 자동 이동
6. (선택) 우상단 `나중에 입력` 클릭 → 미완료 상태로 MA-128 이동, 홈에 `온보딩 마저 입력하기` 배너 노출

## 화면 상태

| 상태 | 설명 |
|------|------|
| 기본 (빈 입력) | 모든 옵션 미선택, 필수 항목 미충족 시 `다음` 비활성 |
| 입력 중 | 선택한 칩 active 강조, 필수 항목 충족 시 `다음` 활성 |
| 페이지 전환 중 | 슬라이드 애니메이션 |
| 입력 완료 | MA-128로 라우팅, 토스트 `입력이 저장되었어요` |
| 미완료 종료 | 입력값 임시 저장, 홈 배너 표시 |
| 재진입 | 기존 입력값 자동 복원 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-M004 회원 상세 (메모) / SCR-C010 운동 프로그램 권장 |
| 데이터 흐름 | client → admin (입력값 저장 + 권장 루틴 자동 생성) |
| 정책 출처 | 온보딩 입력 옵션 풀 = 회원앱 정책 / 운동 프로그램 매핑 = admin 알고리즘 |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**client → admin 영향**

- 입력 완료 시 SCR-M004 회원 상세 메모에 자동 기록
- 입력값 기반 SCR-C010 운동 프로그램 권장 자동 생성 (트레이너 검수 후 회원 노출)
