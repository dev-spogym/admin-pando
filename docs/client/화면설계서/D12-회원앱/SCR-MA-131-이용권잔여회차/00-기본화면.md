## 화면 목적

회원이 회원권 만료일, PT·OT 잔여 횟수, 락커 사용 정보, 부가옵션(운동복·수건·사우나) 상태를 한 화면에서 확인한다. 만료 D-day가 임박한 경우 재등록 추천(MA-138) 진입을 유도한다.

## 주요 구성요소

### 회원권 카드

| 항목 | 설명 |
|------|------|
| 회원권 종류 | 헬스 자유이용 / 헬스+골프 통합 / PT 통합 등 |
| 시작일 / 만료일 | 이용 시작 ~ 만료 |
| 만료 D-day | 큰 숫자 + 색상 분기 (D-14 정상 / D-7 강조 warning / D-1 위험 danger) |
| 만료 임박 배너 | D-14 이하 진입 시 상단 강조 배너 + `재등록 추천 보기(MA-138)` CTA |

### PT 잔여 카드

| 항목 | 설명 |
|------|------|
| 총 회차 / 사용 / 잔여 | 진행 바 + 숫자 |
| 최근 차감 일자 | YYYY-MM-DD HH:MM 형식 |
| 다음 예약 예정 | 예약된 PT가 있으면 일자/강사명 표시 |
| 차감 안내 | "PT 횟수는 수업 완료 시점에만 차감됩니다" |
| 액션 | `예약하기(MA-121)` / `최근 차감 이력 5건 보기 → MA-122` |

### OT 잔여 카드

| 항목 | 설명 |
|------|------|
| OT1 진행 상태 | 미진행 / 완료 (날짜) / 잔여 N회 |
| OT2 진행 상태 | 미진행 / 완료 (날짜) / 잔여 N회 |
| 분리 표기 | OT1 / OT2 항상 분리 |
| 액션 | OT1 미진행 → `OT1 예약(MA-121)`, OT1 완료 + OT2 미진행 → `OT2 예약`, OT 추가권 구매 → `MA-134` |

### 락커 카드

| 항목 | 설명 |
|------|------|
| 락커 번호 | 회원에게 배정된 락커 번호 |
| 사용 시작일 / 만료일 | 시작 ~ 만료 |
| 만료 D-day | 락커 만료까지 남은 일수 |
| 액션 | `연장 결제(MA-141)` |
| 미사용 시 | "락커 사용 안 함" + `락커 신청 → 센터 문의(MA-153)` 안내 |

### 부가옵션 카드

| 항목 | 설명 |
|------|------|
| 운동복 | ON/OFF + 잔여 회수 (있는 경우) + 만료일 |
| 수건 | ON/OFF + 잔여 회수 + 만료일 |
| 사우나 | ON/OFF + 잔여 회수 + 만료일 |
| 액션 | 각 옵션별 `연장/추가 결제(MA-141)` |

### 최근 차감 이력 카드 (선택)

최근 5건의 PT/OT 차감 이력을 카드 리스트로 표시. 더 보기 → MA-122 내 예약/수업 이력으로 이동.

## 계정별 차이

회원 앱 본인 계정의 이용권 정보만 조회 가능. 편집은 운영 관리자만 CRM에서 처리.

## 주요 UX 흐름

1. MA-100 홈 → `이용권 / 잔여 회차` 카드 탭 → MA-131 진입
2. 회원권 카드에서 만료 D-day 확인
3. 만료 임박 시 상단 배너 → `재등록 추천(MA-138)` 진입
4. PT/OT 잔여 카드에서 잔여 횟수 확인 → `예약하기(MA-121)` 진입
5. 락커 카드에서 만료 임박 시 → `연장 결제(MA-141)` 진입
6. 부가옵션 카드에서 잔여/만료 확인 → 추가 결제 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 | 모든 카드 활성 표시 |
| 만료 D-14 이하 | 회원권 카드 강조 + 상단 배너 |
| 만료 D-1 또는 만료됨 | 회원권 카드 빨강 테두리 + 우선 노출 |
| PT/OT 잔여 0 | 회색 카드 + `재등록 추천` CTA 강조 |
| 락커 미사용 | 락커 카드 회색 + `신청` 안내 |
| 부가옵션 0건 | "이용 중인 부가옵션이 없어요" 빈 상태 |
| 회원권 미보유 | 일러스트 + `회원권을 등록해 주세요` + `상품 스토어(MA-134)` CTA |
| 로딩 | 카드 스켈레톤 |
| 조회 실패 | 오류 안내 + 재시도 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-P001~003 상품 / SCR-M004 회원 상세 / DLG-M003·M004 홀딩 |
| 데이터 흐름 | 양방향 (홀딩 신청 / D-day 트리거) |
| 정책 출처 | D-14/D-7/D-1 트리거 / 홀딩 가능 기간 / 차감 시점 = admin 본사 정책 + 센터 설정 |
| 연동 시나리오 | 60_admin_연동/C6_이용권_Dday_트리거 |

**admin → client 영향**

- SCR-M002에서 이용권 부여 시 MA-131 카드 즉시 노출
- 본사 D-day 정책 변경 시 만료 트리거 시점 자동 반영
- DLG-M003 홀딩 등록 시 회원 화면에 홀딩 칩 즉시 표시

**client → admin 영향**

- 회원 홀딩 신청 → DLG-M003 큐 추가 → 매니저 승인 후 반영

## 관련 다이어그램
