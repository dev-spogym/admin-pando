# SCR-MA-123 골프예약상세 — 키오스크 연동

본 화면은 회원앱에서 회원이 골프 타석을 예약하는 흐름이다. 키오스크의 KIO-501 ~ KIO-504와 **동일 데이터 원천**(`admin/SCR-054-골프타석관리`)을 공유하며, 어느 채널에서 예약/취소해도 즉시 반영된다. 키오스크 예약 생성 기능은 골프 타석 예약에만 적용하고, 일반 수업은 KIO-303에서 admin `SCR-C002`/`SCR-C016` 기준으로 조회만 한다.

## 채널 비교

| 항목 | 회원앱 SCR-MA-123 | 키오스크 KIO-501~504 |
|---|---|---|
| 사용 환경 | 휴대폰, 충분한 시간 | 단말 앞 3분 이내 |
| 흐름 길이 | 더 풍부한 정보 노출 가능 | 축약된 셀프 예약 |
| 인증 | 앱 로그인 | 전화번호 또는 회원 QR |
| 결제 | 이용권 차감 (앱에서 직접 결제 가능) | 이용권 차감만 (현장 결제는 별도 흐름) |
| 대기 등록 | 가능 | 가능 |
| 자동 승격 알림 | 푸시 (SCR-MA-150) | 다음 진입 시 표시 |

## 동시 예약 충돌 방지

| 시나리오 | 처리 |
|---|---|
| 같은 회원이 동시 예약 시도 | admin 단일 검증으로 한 쪽만 성공 |
| 다른 회원이 같은 타석 동시 점유 시도 | 선착순 |
| 회원앱 예약 후 키오스크에서 취소 | 정상 (동일 데이터) |
| 키오스크 예약 후 회원앱에서 취소 | 정상 (동일 데이터) |

## 회원앱 측 요건 (키오스크와의 일관성)

| 항목 | 회원앱 보완 |
|---|---|
| 키오스크 출처 표시 (옵션) | 예약 행 메타에 `via=kiosk` 라벨로 회원이 어느 채널에서 예약했는지 확인 가능 |
| 시간 단위 일치 | 30분 또는 1시간 단위, admin 정책 따름 |
| 대기 등록 결과 | 회원앱과 키오스크 모두 같은 정보 (대기 순번 포함) |
| 자동 승격 알림 | SCR-MA-150 알림센터에 카드형 표시 |

## 알림 흐름

```
[키오스크 KIO-503에서 빈 자리 없음 → 대기 등록]
        ↓
[admin/SCR-054 대기열에 push]
        ↓ (시간 후 자리 발생)
[admin 자동 승격]
        ↓
[회원앱 SCR-MA-150 알림센터에 푸시 + 인앱]
        ↓
[회원은 회원앱 SCR-MA-123 또는 키오스크 KIO-303에서 확인]
```
