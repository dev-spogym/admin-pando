## 화면 목적

회원 본인의 방문 / 수업 참여 이력을 일별·주간·월간으로 조회하고, 카테고리별 참여 패턴(PT / OT / GX / 필라테스 / Golf)을 분석한다. 선호 클래스, 자주 가는 시간대 등 개인 인사이트를 제공한다.

## 주요 구성요소

### 4지표 요약 카드 (2x2 또는 가로 4)

| 지표 | 표시 |
|------|------|
| 이번 달 출석 일수 | 큰 숫자 + 전월 대비 +/- |
| 주간 평균 빈도 | 주 N회 |
| 월간 평균 빈도 | 월 N회 |
| 연속 출석 기록 | 최장 N일 / 현재 N일 |

### 출석 캘린더

| 항목 | 설명 |
|------|------|
| 월간 캘린더 | 출석일 색칠 |
| 카테고리 도트 | PT(파랑) / OT(보라) / GX(주황) / 필라테스(녹색) / Golf(초록) |
| 일자 탭 | 해당 일 출석/수업 상세 모달 |

### 카테고리 비중 도넛 차트

PT / OT / GX / 필라테스 / Golf 참여 비중 — 색상 매핑 고정. 필라테스는 GX 하위가 아닌 별도 카테고리로 분리 표시.

### 출석 패턴 히트맵

요일 × 시간대(7×4) 격자. 자주 가는 시간대 색상 강조.

### 분석 카드 4종

| 카드 | 표시 |
|------|------|
| 가장 많이 참여한 클래스 | 클래스명 + 참여 횟수 |
| 가장 자주 가는 시간대 | 요일 + 시간대 |
| 전월 대비 변화 | + / - 표기 |
| 개근 보너스 진척률 | 목표 일수 대비 진척 |

### 출석 카드 리스트

| 항목 | 설명 |
|------|------|
| 날짜 | YYYY-MM-DD |
| 카테고리 칩 | PT/OT/GX/필라테스/Golf |
| 수업명 / 강사 | 클래스명 + 강사명 |
| 체크인 시간 | HH:MM |

### 필터

| 필터 | 옵션 |
|------|------|
| 기간 | 이번 주 / 이번 달 / 최근 3개월 |
| 카테고리 | 전체 / PT / OT / GX / 필라테스 / Golf |

## 계정별 차이

회원 본인 이력만 조회 가능. 트레이너는 별도 트레이너 화면에서 담당 회원 출석 이력을 본다.

## 주요 UX 흐름

1. MA-100 홈 또는 마이페이지(MA-130) → 출석 이력 진입
2. 4지표 요약 + 캘린더 확인
3. 카테고리 비중 도넛 → 자기 운동 비중 파악
4. 히트맵으로 자주 가는 시간대 확인
5. 출석 카드 리스트 → 더보기 페이지네이션

## 화면 상태

| 상태 | 설명 |
|------|------|
| 정상 (이력 있음) | 모든 카드 활성 표시 |
| 출석 0회 | 일러스트 + "아직 출석 이력이 없어요" + QR 체크인 진입 |
| 카테고리 0건 | 도넛 차트 비활성 + 안내 |
| 필터 결과 0건 | "이 조건의 이력이 없어요" + 필터 해제 |
| 로딩 | 카드 스켈레톤 |
| 더보기 페이지네이션 | 무한 스크롤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-086 출석 관리 / SCR-094 KPI 대시보드 |
| 데이터 흐름 | admin → client (회원 본인 출석 데이터만 조회) |
| 정책 출처 | 출석 카테고리 분류 (PT/OT/GX/필라테스/Golf) = admin 운영 분류 |
| 연동 시나리오 | 60_admin_연동/C2_QR체크인_출석동기화 |

**admin → client 영향**

- SCR-086에서 수동 출석 추가 시 회원 MA-111에 즉시 반영
- SCR-094 KPI 정의(개근 보너스, 카테고리 비중)와 동일 산정식 사용
