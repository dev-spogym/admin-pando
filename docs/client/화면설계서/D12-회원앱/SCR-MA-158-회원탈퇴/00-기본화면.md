## 화면 목적

회원이 탈퇴 사유를 선택하고 탈퇴 요청을 접수한다. 즉시 삭제가 아니라 운영 승인 후 처리되는 단계로 정의되며, 탈퇴 전 잔여 회차 / 마일리지 / 미결제 환불 여부를 명확히 안내한다.

## 주요 구성요소

### 탈퇴 전 안내 카드

| 항목 | 설명 |
|------|------|
| 잔여 회차 | PT / OT / 골프 레슨 잔여 회차 (있으면 환불 안내) |
| 보유 마일리지 | 탈퇴 시 즉시 소멸 안내 |
| 진행 중 주문 | 환불 처리 안내 |
| 가입 지점 | 지점명 + "탈퇴 후 재가입은 센터 문의" |

### 탈퇴 사유 단일 선택

| 사유 | 설명 |
|------|------|
| 서비스 불만족 | 운영 / 시설 / 강사 등 |
| 이용 빈도 감소 | 운동 빈도 줄어듦 |
| 다른 센터 이용 | 타 센터로 이동 |
| 개인정보 우려 | 정보 보안 / 마케팅 등 |
| 기타 | 직접 입력 (textarea) |

### 추가 의견 (선택)

textarea 입력. 운영팀에 전달.

### 탈퇴 동의 체크박스

| 항목 | 설명 |
|------|------|
| 동의 1 | "탈퇴 시 보유 마일리지 / 쿠폰이 즉시 소멸함을 이해합니다" |
| 동의 2 | "탈퇴 후 동일 정보로 재가입은 센터 문의를 통해 진행함을 이해합니다" |
| 동의 3 | "잔여 회차는 별도 환불 정책에 따라 처리됨을 이해합니다" |

세 항목 모두 체크 시 탈퇴 CTA 활성.

### 탈퇴 CTA

| 버튼 | 동작 |
|------|------|
| 탈퇴 신청 | ConfirmDialog (위험 톤) → 확인 → 탈퇴 요청 접수 |
| 취소 | 이전 화면 복귀 |

### 처리 결과 안내

| 상태 | 표시 |
|------|------|
| 탈퇴 요청 접수 완료 | 일러스트 + "운영 승인 후 처리됩니다" + 처리 예상 기간 안내 |
| 자동 로그아웃 | 토큰 삭제 + MA-001 라우팅 |

## 계정별 차이

회원 본인만 탈퇴 신청 가능. 운영팀이 별도 승인 단계에서 최종 처리.

## 주요 UX 흐름

1. MA-155 설정 → `회원 탈퇴` 진입
2. 잔여 회차 / 마일리지 / 진행 주문 안내 카드 확인
3. 탈퇴 사유 단일 선택 (+ 추가 의견)
4. 동의 3개 체크 → 탈퇴 CTA 활성
5. 탈퇴 신청 → ConfirmDialog → 확인
6. 탈퇴 요청 접수 화면 + 자동 로그아웃

## 화면 상태

| 상태 | 설명 |
|------|------|
| 잔여 자산 있음 | 안내 카드 강조 (환불 안내 포함) |
| 진행 중 주문 있음 | 환불 처리 안내 |
| 동의 미체크 | 탈퇴 CTA 비활성 |
| 사유 미선택 | 탈퇴 CTA 비활성 |
| 탈퇴 요청 처리 중 | 로딩 + 백 버튼 비활성 |
| 탈퇴 요청 실패 | 토스트 + 재시도 |
| 탈퇴 요청 완료 | 결과 화면 + 자동 로그아웃 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | DLG-M005 탈퇴 처리 / SCR-097 감사 로그 / NFR-06 90일 파기 자동화 |
| 데이터 흐름 | client → admin (탈퇴 신청) + admin → client (승인 후 차단) |
| 정책 출처 | 운영 승인 필수 / 90일 후 파기 / 90일 내 복구 가능 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C8_탈퇴_복구_파기 |

**client → admin 영향**

- 회원 탈퇴 신청 → DLG-M005 큐 + SCR-097 감사 로그 INSERT

**admin → client 영향**

- 매니저 탈퇴 승인 → 회원 status=withdrawn + 자동 로그아웃
- 90일 후 NFR-06 자동 크론 → 개인정보 마스킹 + 영구 삭제
- 90일 내 admin 복구 (DLG-M005) 시 회원 active 복원
