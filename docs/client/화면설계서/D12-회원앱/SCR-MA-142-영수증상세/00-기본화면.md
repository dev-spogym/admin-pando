## 화면 목적

회원이 결제 완료 후 또는 결제 내역(MA-133)에서 영수증 상세 정보를 조회한다. 결제수단 / 사용 마일리지 / 쿠폰 / 정가 / 최종 결제액을 명세서 형식으로 보여주고, PDF 다운로드 / 공유를 지원한다. 관리자 발송 결제링크 결제(`SCR-S016`)도 동일 영수증 화면을 재사용하며 "결제링크 결제" 출처 배지를 함께 표시한다.

## 주요 구성요소

### 영수증 헤더

| 항목 | 설명 |
|------|------|
| 영수증 번호 | 고유 번호 |
| 결제 일시 | YYYY-MM-DD HH:MM |
| 결제 상태 | 결제 완료 / 환불 완료 / 부분 환불 |
| 가맹점 | 센터명 + 사업자 번호 |

### 상품 정보 카드

| 항목 | 설명 |
|------|------|
| 상품명 | 큰 텍스트 |
| 옵션 요약 | 강사 / 시간 / 회차 등 |
| 수량 | 단건 또는 다중 (장바구니 결제) |
| 정가 | 단가 + 합계 |

### 결제 내역 명세

| 항목 | 금액 |
|------|------|
| 상품 합계 | + 금액 |
| 쿠폰 할인 | - 금액 (쿠폰명 표시) |
| 마일리지 사용 | - 금액 (사용 P 표시) |
| 멤버십 등급 할인 | - 금액 |
| 최종 결제액 | 강조 표시 |

### 결제수단 정보

| 항목 | 설명 |
|------|------|
| 결제수단 | 카드사 + 끝 4자리 또는 페이 |
| 승인 번호 | PG 승인 번호 |
| 할부 개월 | 일시불 또는 N개월 |

### 적립 정보

| 항목 | 설명 |
|------|------|
| 마일리지 적립 | 적립 P + 등급 보너스 표시 |
| 적립 예정일 | 결제 후 N일 후 |

### 액션

| 버튼 | 설명 |
|------|------|
| PDF 다운로드 | 영수증 PDF 생성 + 저장 |
| 공유 | ShareSheet 진입 |
| 환불 신청 | MA-404 진입 (가능 상태일 때) |
| 주문 상세 보기 | MA-403 진입 |
| 닫기 | 이전 화면 복귀 |

## 계정별 차이

회원 본인 영수증만 조회.

## 주요 UX 흐름

1. MA-140 결제 완료 → MA-142 자동 진입
2. 또는 MA-133 결제 내역 → 카드 탭 → MA-142 진입
3. 명세 확인
4. PDF 다운로드 / 공유 / 환불 신청 / 주문 상세 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 결제 완료 | 모든 정보 표시 |
| 환불 완료 | "환불 완료" 도장 + 환불 일자 |
| 부분 환불 | 환불 금액 + 잔여 결제액 표시 |
| 환불 진행 중 | "환불 처리 중" 안내 |
| PDF 생성 중 | 로딩 인디케이터 |
| PDF 실패 | 토스트 + 재시도 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-S003 결제 처리 / SCR-S007 환불 관리 / SCR-S016 결제링크 발송 |
| 데이터 흐름 | admin → client (영수증 조회) |
| 정책 출처 | 영수증 PDF 양식 / 사업자 정보 = admin 본사 설정 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**admin → client 영향**

- SCR-S007 환불 승인 시 영수증에 "환불 완료" 도장 + 환불 일자 표시
- 회원이 환불 신청 시 SCR-S007 큐 추가 → 매니저 승인 후 처리
- SCR-S016 결제링크로 완료된 결제는 영수증 헤더에 "결제링크 결제" 출처 배지 + 발송 직원 정보 표시
