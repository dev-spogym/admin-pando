## 화면 목적

회원이 본인 결제 내역(이용권 / PT 패키지 / 골프 레슨 / 부가옵션 / 마켓 결제)을 월별로 조회하고, 영수증 진입 / 환불 신청 / 주문 상세 진입을 한 화면에서 처리한다.

## 주요 구성요소

### 상단 필터

| 필터 | 옵션 |
|------|------|
| 기간 | 이번 달 / 지난 3개월 / 지난 6개월 / 1년 / 사용자 지정 |
| 상품 카테고리 | 전체 / 이용권 / PT / 골프 / 부가옵션 / 마켓 |
| 결제 상태 | 전체 / 결제 완료 / 환불 진행 / 환불 완료 / 취소 |

### 월별 그룹 헤더

YYYY년 MM월 + 월 합계 결제액 + 월 환불액

### 결제 카드

| 항목 | 설명 |
|------|------|
| 결제일 | YYYY-MM-DD HH:MM |
| 상품명 + 옵션 요약 | "PT 16회 · 김도윤 강사" |
| 결제수단 | 카드사 + 끝 4자리 또는 페이 |
| 결제액 | 정가 + 할인가 |
| 사용 마일리지 / 쿠폰 | 차감 표기 |
| 상태 칩 | 완료(success) / 환불 진행(warning) / 환불 완료(neutral) / 취소(error) |
| 액션 | `영수증 보기(MA-142)` / `주문 상세(MA-403)` / `환불 신청(MA-404)` |

### 합계 요약 카드 (상단)

| 항목 | 설명 |
|------|------|
| 선택 기간 결제 합계 | 큰 숫자 |
| 환불 합계 | 회색 숫자 |
| 마일리지 적립 합계 | 마일리지 표기 |

### 빈 상태

"결제 내역이 없어요" + 상품 스토어(MA-134) 진입 CTA.

## 계정별 차이

회원 본인의 결제 내역만 조회.

## 주요 UX 흐름

1. 마이페이지(MA-130) → `결제 내역` 진입
2. 기간 / 카테고리 / 상태 필터로 좁힘
3. 결제 카드 탭 → `영수증` 또는 `주문 상세` 진입
4. 환불 가능 결제 → `환불 신청` → MA-404 진입

## 화면 상태

| 상태 | 설명 |
|------|------|
| 결제 있음 | 월별 그룹 카드 리스트 |
| 빈 상태 | 일러스트 + 스토어 진입 |
| 환불 진행 중 | 카드 강조 + 진행 상태 표시 |
| 필터 결과 0건 | "이 조건의 결제가 없어요" + 필터 해제 |
| 로딩 | 스켈레톤 |

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-S003 결제 처리 / SCR-S001 매출 현황 |
| 데이터 흐름 | admin → client (결제 이력 조회) |
| 정책 출처 | 환불 가능 기간 / 비율 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**client → admin 영향**

- 회원 결제 (MA-140) → SCR-S003에 즉시 등재 + SCR-S001 매출 집계

**admin → client 영향**

- SCR-S003에서 수기 결제 등록 시 MA-133에 즉시 반영
- SCR-S007 환불 승인 시 카드 상태 변경
