## 화면 목적

CRM에 사전 등록된 회원이 SMS 인증 + 비밀번호 설정 + 가입 지점 선택까지 5단계로 앱 연동을 완료한다. 공개형 자체 회원 생성이 아니라 CRM 연동 완성 단계다.

## 주요 구성요소

### 5단계 진행 인디케이터

| 단계 | 화면 | 입력 |
|------|------|------|
| 1 / 5 | 연락처 입력 | 전화번호 또는 이메일 |
| 2 / 5 | SMS 인증 | 6자리 인증번호 (3분 유효) |
| 3 / 5 | 비밀번호 설정 | 8~16자 + 영문 + 숫자 + 특수문자 |
| 4 / 5 | 가입 지점 선택 | CRM 가입 지점 카드 선택 |
| 5 / 5 | 약관·동의 | 필수 + 선택 동의 |

### 1단계 — 연락처 입력

| 항목 | 설명 |
|------|------|
| 전화번호 / 이메일 토글 | 회원이 등록한 식별자 선택 |
| 입력 필드 | 입력 즉시 형식 검증 |
| 다음 CTA | CRM 일치 확인 시 활성 |
| 안내 | "센터에 등록된 연락처 또는 이메일을 입력해 주세요" |

### 2단계 — SMS 인증

| 항목 | 설명 |
|------|------|
| 인증번호 입력 | 6자리 OTP 칸 |
| 타이머 | 3분 카운트다운 |
| 재발송 버튼 | 30초 후 활성 |
| 안내 | "인증번호가 오지 않으면 입력 정보를 다시 확인해 주세요" |

### 3단계 — 비밀번호 설정

| 항목 | 설명 |
|------|------|
| 비밀번호 | 8~16자 (마스킹 + 표시 토글) |
| 비밀번호 확인 | 일치 검증 |
| 강도 표시 | 약함 / 보통 / 강함 |
| 규칙 안내 | 영문 / 숫자 / 특수문자 충족 여부 체크 표시 |

### 4단계 — 가입 지점 선택

| 항목 | 설명 |
|------|------|
| 지점 카드 리스트 | CRM에 가입된 모든 지점 |
| 카드 표시 | 지점명 / 주소 / 가입일 / 회원번호 |
| 선택 | 단일 지점 시 자동 선택, 다중 지점 시 회원이 1개 선택 |
| 안내 | "가입 후에는 설정에서 변경 가능합니다" |

### 5단계 — 약관·동의

| 항목 | 설명 |
|------|------|
| 전체 동의 | 모든 동의 일괄 토글 |
| 필수 약관 | 서비스 / 개인정보 / 위치기반 (조회 + 동의) |
| 선택 약관 | 마케팅 SMS / 이메일 / 푸시 |
| 완료 CTA | 필수 약관 모두 동의 시 활성 |

## 계정별 차이

CRM에 사전 등록된 회원만 진입 가능. 미등록 연락처 입력 시 "등록되지 않은 회원입니다 — 센터 문의" 안내 + MA-153 진입 유도.

## 주요 UX 흐름

1. MA-001 로그인 화면 → `앱 연동하기` → MA-002 진입
2. 1단계 연락처 입력 → CRM 일치 확인 → 다음
3. 2단계 SMS 인증번호 입력 → 검증 → 다음
4. 3단계 비밀번호 설정 → 다음
5. 4단계 지점 선택 (단일 시 자동) → 다음
6. 5단계 약관 동의 → `연동 완료` CTA
7. MA-127 운동 온보딩으로 자동 진입 (1회 한정)
8. 운동 온보딩 완료 → MA-900 환영 슬라이드 → MA-100 홈

## admin 연동

| 항목 | 내용 |
|------|------|
| 연동 admin SCR | SCR-070 리드 관리 / SCR-M002 회원 등록 / SCR-M004 회원 상세 |
| 데이터 흐름 | admin → client (CRM 회원 데이터 조회) + client → admin (앱 연동 완료 플래그) |
| 정책 출처 | "CRM 선등록 회원만 앱 연동 가능" — admin 운영 정책 |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**admin → client 영향**

- SCR-M002에서 회원 등록 → 회원이 앱 연동 가능 (앱 연동 전 status=lead → active)
- SCR-M005 회원 이관 / 지점 변경 시 앱 가입 지점 선택 옵션 변경
- 회원 status=hold 또는 withdrawn 상태에서는 연동 차단

**client → admin 영향**

- 연동 완료 시 SCR-M004 회원 상세에 "앱 연동 완료 + app_linked_at" 배지 즉시 노출
- 연동 실패(CRM 미등록)는 SCR-153 1:1 문의 진입 안내
