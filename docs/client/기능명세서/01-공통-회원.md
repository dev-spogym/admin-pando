# FitGenie 회원앱 기능명세서 — 공통 · 회원

> 작성일: 2026-05-04
> 버전: 3.1
> 상태: 기획/퍼블리싱 기준 + 체크리스트 정합성 보강
> 범위: 공통 기능 + 회원 기능

---

## 1. 기본 정책

### 1.1 로그인 정책

- 공통 로그인 화면 `MA-001`은 `회원 로그인`과 `직원 로그인` 두 모드로 구성한다.
- 회원 로그인은 `전화번호 + 비밀번호`를 사용한다.
- 직원 로그인은 `아이디 + 비밀번호`를 사용하며, 로그인 전 `트레이너`, `FC`, `스태프` 중 직군을 먼저 선택한다.
- `golf_trainer` 계정은 로그인 화면에서는 `트레이너` 계열로 묶는다.
- 로그인 성공 후에는 회원, 트레이너 계열, FC, 스태프 각 역할에 맞는 기본 홈으로 이동한다.

### 1.2 회원가입 정책

- 회원 기본 생성은 `CRM`에서 이뤄진다.
- 앱에서는 `휴대폰 인증 + 비밀번호 설정`으로 연동을 완료한다.
- 체크리스트의 `회원가입`은 현재 기준에서 `CRM 선등록 + 모바일 앱 연동`으로 해석한다.

### 1.3 리워드 정책

- 체크리스트의 `포인트`는 `마일리지`로 통일한다.
- `포인트 사용`은 `마일리지 사용`으로 해석한다.
- `배지`는 회원앱 현재 범위에 포함한다.
- 리워드 도메인은 `쿠폰 + 마일리지 + 배지`로 정의한다.

### 1.4 결제 / 상품 정책

- PT 플랜 외에 `헬스장 이용권`, `골프장 이용권`, `골프 레슨권`, `재등록 플랜`을 같은 상품 도메인에서 다룬다.
- 회원은 `상품 스토어`, `개인 결제`, `관리자 발송 결제링크` 세 경로로 결제를 시작할 수 있다.
- 결제수단은 `카드`, `계좌이체`, `네이버페이`, `카카오페이`를 제공한다.
- 실제 PG가 없어도 `결제 화면`, `영수증`, `결제 내역` 퍼블리싱은 제공한다.
- 마일리지는 결제 단계에서 차감형 리워드로 사용할 수 있다.
- 결제링크 진입 시 상품 / 금액 / 할인은 직원이 고정한 값으로 노출한다.
- 결제링크 결제는 고객이 `쿠폰`, `마일리지`, `금액`, `할부 조건`을 수정할 수 없다.

### 1.5 온보딩 정책

- 앱 연동 직후 또는 첫 로그인 직후 회원은 온보딩 설문을 진행할 수 있다.
- 온보딩은 `운동 목적/성향`, `통증/체형 정보`, `첫 루틴 제안` 세 단계로 구성한다.
- FMS/체형 리포트는 온보딩 정보와 측정 데이터를 함께 참고한다.

### 1.6 개인정보 / 동의 / 탈퇴 정책

- 회원은 설정에서 `약관/정책`, `동의관리`, `회원 탈퇴` 화면으로 이동할 수 있다.
- 필수 약관은 조회 전용이고, 마케팅 수신 동의만 회원이 직접 변경한다.
- 탈퇴는 앱 내 즉시 삭제가 아니라 `탈퇴 요청 접수` 흐름으로 우선 정의한다.

### 1.7 수업 예약 / 승인 정책

- 회원은 공개 수업을 바로 예약할 수 있고, 트레이너의 개인 PT/골프 레슨 가능 시간을 보고 예약 요청할 수도 있다.
- 회원이 트레이너에게 직접 요청한 예약은 `트레이너 승인 대기` 상태로 생성한다.
- 트레이너가 자신의 캘린더에서 회원을 지정해 수업을 직접 생성하는 경우, 회원 추가 승인 없이 즉시 확정한다.
- 회원은 `내 예약 / 수업 이력`과 `이용권 / 잔여 회차`에서 승인 상태, PT 차감 완료 일자, 잔여 횟수, 다음 예약 예정 일자를 함께 확인할 수 있어야 한다.
- PT/골프 레슨 횟수는 예약 승인 또는 일정 확정만으로 차감되지 않고, `수업 완료(completed)` 시점에만 차감된다.
- 골프 레슨 예약은 예약 생성만 아니라 `내 골프 예약 일정` 확인까지 같은 도메인으로 본다.

### 1.7.1 PT / OT 수업 분기 정책

회원앱은 단순 PT 외에 신규 회원 진단·교정용 OT(Orientation Training) 1차·2차 세션을 별도 수업 유형으로 다룬다.

| 수업 유형 | 정의 | 횟수 차감 | 비고 |
|---|---|---|---|
| PT | 정규 1:1 트레이닝 (정가 패키지 차감) | PT 잔여 횟수에서 1회 차감 | 회원이 시간/강사 자유 선택 |
| OT1 | 신규 회원 1차 OT — 체성분 + 운동 목적 진단 | OT 잔여 횟수에서 1회 차감 (없으면 무료 1회 자동 부여) | 등록 시점 기준 30일 이내 권장 |
| OT2 | 2차 OT — FMS 측정 + 첫 루틴 시연 | OT 잔여 횟수에서 1회 차감 | OT1 완료 후 진입 가능 |

- 예약 화면(`MA-121`)은 수업 유형(PT / OT1 / OT2)을 선택할 수 있는 라디오 또는 탭 UI를 가진다.
- OT1/OT2는 트레이너 승인이 필수가 아니라 등록 직후 즉시 확정으로 처리한다 (등록 직후 빠르게 진단을 받게 하기 위함).
- OT1 완료 전까지 OT2 예약은 비활성 처리한다.
- OT 횟수가 회원 등록 시점에 자동 부여되는 경우, 마이페이지 `이용권 / 잔여 회차`(MA-131)에 PT와 OT를 분리 표시한다.

### 1.8 마일리지 적립 / 사용 정책

| 항목 | 내용 |
|---|---|
| 적립 트리거 | 회원의 활동 기반 자동 적립 — 운동 루틴 완료 / 출석 N회 연속 / 체성분 측정 / 스트레칭 이용 / 공개 후기 작성 / 친구 초대 단계 도달 |
| 적립 단가 | 운영 정책 세트 기준 (예: 루틴 완료 50P, 후기 작성 100P, 추천 단계 도달 ① 5,000P 등) — 본사 정책 세트로 관리 |
| 사용처 | 재등록 결제 시 차감 / 리커버리(스트레칭·사우나) 이용권 결제 / 굿즈 교환 / 마켓 결제(`MA-140`) 차감 |
| 사용 단위 | 100P 단위 차감 (정책 세트 기준) |
| 만료 정책 | 마지막 적립일 기준 1년 미사용 시 만료 (운영 정책으로 조정 가능) |
| 화면 노출 | `MA-136 리워드 센터`에서 적립/사용 내역 분리 탭, 월별 그래프, 적립 기준 안내, 사용처 카드 |

### 1.9 재등록 추천 플랜 트리거 정책

이용권 만료 전후 회원에게 추천 플랜 3종을 D-day 기준으로 자동 노출한다.

| 트리거 | 시점 | 노출 위치 | 알림 |
|---|---|---|---|
| D-14 | 만료 14일 전 | `MA-138` 첫 진입 + `MA-100` 홈 배너 + 푸시 1회 | "곧 만료돼요. 추천 플랜을 확인해보세요" |
| D-7 | 만료 7일 전 | `MA-138` 강조 + `MA-100` 홈 배너 + 푸시 1회 | "이번 주 만료. 재등록 시 혜택 +10%" |
| D-1 | 만료 1일 전 | `MA-138` 최우선 + `MA-100` 홈 배너 + 푸시 1회 | "내일 만료. 마지막 혜택 안내" |

- 추천 플랜은 회원 활동(주 평균 출석, 선호 카테고리)을 기반으로 3종(`AI 추천 / 균형형 / 경제형`)을 자동 생성한다.
- D-14/D-7/D-1 외 임의 시점에도 회원이 직접 `MA-138`에 진입하면 동일 추천 플랜을 조회할 수 있다.
- 본사 정책 세트로 D-day 기준은 변경 가능하며, 회원앱은 정책 결과만 표시한다(만료 알림 정책 소유권은 관리자 웹에 있음).

### 1.10 알림 카테고리 / 라우팅 정책

회원앱 알림센터(`MA-150`)와 알림 설정(`MA-155`)은 다음 7개 카테고리를 사용한다.

| 카테고리 | 트리거 예시 | 라우팅 대상 | 설정 가능 |
|---|---|---|---|
| 예약 | 예약 확정 / 예약 변경 / 노쇼 임박 | `MA-122 / MA-121 / MA-123` | ON/OFF |
| 이용권 | 만료 D-14/D-7/D-1, 잔여 횟수 ≤ 3 | `MA-131 / MA-138` | ON/OFF |
| 리워드 | 마일리지 적립 / 배지 획득 / 등급 상승 | `MA-136 / MA-137 / MA-500` | ON/OFF |
| 공지 | 센터 이벤트, 휴무, 일반 공지 | `MA-152` | ON/OFF |
| AT-RISK 케어 | 4주 미방문 / 만료 직후 미재등록 | `MA-138 / MA-153` | ON/OFF (FC 운영 알림) |
| 수업 / 후기 | 수업 시작 30분 전, 수업 후 후기 작성 요청 | `MA-121 / MA-126` | ON/OFF |
| 부가 시설 | 사우나 / 락커 / 굿즈 등 부가 시설 안내 | `MA-131 / MA-151` | ON/OFF |

- 회원은 `MA-155 설정`에서 7개 카테고리 각각의 푸시 ON/OFF 및 채널(앱 푸시 / SMS / 이메일)을 선택할 수 있다.
- 알림센터(`MA-150`)에서 알림 카드 클릭 시 위 라우팅 표에 따라 대상 화면으로 이동한다.
- AT-RISK 케어 알림은 FC 운영 트리거이며, 회원이 OFF한 경우에도 `MA-138 재등록 추천` 화면 자체는 직접 진입 가능하다.

### 1.11 PT 패키지 / AI 추천 플랜 정책

상품 스토어(`MA-134`) 및 재등록 추천(`MA-138`)에서 PT 상품은 다음 회차 옵션을 제공한다.

| 회차 옵션 | 단가 배수 | 권장 사용 기간 |
|---|---|---|
| 4회 | ×1.0 (기본 단가) | 1개월 체험형 |
| 8회 | ×1.9 (4회 단가 ×1.9) | 2개월 입문 |
| 16회 | ×3.5 (4회 단가 ×3.5) | 4개월 정규 |

추천 플랜 3종(`MA-138`)은 회원 활동을 기반으로 다음 기준으로 생성한다.

| 추천 유형 | 산정 기준 | 표기 |
|---|---|---|
| AI 추천 | 회원의 주 평균 PT 빈도 × 4주 + 카테고리 가중치 | "당신에게 딱 맞는 플랜" 배지 |
| 균형형 | 평균 PT 빈도 + 평균 활동 가중 | "가장 많이 선택" 배지 |
| 경제형 | 최소 회차 + 최대 할인 적용 | "가성비" 배지 |

3종 플랜은 가격, 회차, 추천 사유, 혜택을 카드로 비교하며, 회원은 한 카드를 선택해 결제(`MA-140`)로 진입한다.

### 1.12 admin 시스템 연동 정책

회원앱(client)은 admin(관리자 시스템)과 데이터·정책·알림 측면에서 양방향으로 연동된다. 회원앱은 본사 정책 세트의 결과만 표시하며, 정책 자체는 admin이 소유한다. 8개 핵심 연동 시나리오는 `다이어그램/60_admin_연동/C1~C8`에 정의되어 있다.

#### 1.12.1 데이터 소유 / 동기화 원칙

| 데이터 도메인 | 소유 | 동기화 방향 | 회원앱 표시 |
|---|---|---|---|
| 회원 기본 정보 | admin (CRM) | admin → client | MA-130 마이페이지 |
| 가입 지점 | admin | admin → client | MA-130 (변경 신청만) |
| 회원 등급 (BRONZE~VVIP) | admin (자동 산정) | admin → client | MA-500 / MA-130 |
| 이용권 (PT/OT/회원권/락커/부가) | admin | admin → client | MA-131 |
| 예약 / 수업 | 양방향 | 양방향 실시간 | MA-122 / MA-131 |
| 결제 / 환불 | 양방향 | 회원 결제 → admin / 환불은 admin 승인 → client | MA-133 / MA-140 / MA-403 / MA-404 |

| 알림 발송 / 수신 설정 | 양방향 | admin 발송 / client 설정 | MA-150 / MA-155 |
| 공지 / 이벤트 | admin | admin → client | MA-152 |

## 5. 기획 기준 메모

- `예약/대기/후기/알림/온보딩/배지/재등록 추천`은 회원 주요 흐름으로 유지한다.
- `골프 강사 예약`, `상품 스토어`, `개인 결제`, `결제하기`, `영수증`, `결제링크 결제`, `약관/동의/탈퇴`는 퍼블리싱 범위에 포함한다.
- `회원/직원 로그인 분기`, `트레이너 승인형 예약`, `골프 예약 일정 조회`, `PT 잔여횟수 + 차감 완료 이력`은 문서 기준 핵심 정책으로 유지한다.
- 운영 연동 상세나 시스템 구현 방식은 별도 기술 문서에서 관리한다.

## MFN Lv3 풀 세분화 매트릭스

> 핵심 Lv2 항목별 UI/액션/검증/상태 단위로 평균 3~5개 Lv3 분해. 본 매트릭스는 위의 Lv2 표와 일대일 대응되며, 각 코드의 마지막 두 자리(`-XX`)가 Lv3 순번이다.

### 일반 패턴

| 패턴 | Lv3 분해 예시 |
|---|---|
| 입력 폼 | 필드 입력 → 형식 검증 → 인라인 에러 → 저장 → 성공 토스트 |
| 카드 리스트 | 카드 렌더 → 카드 hover → 클릭 라우팅 → 빈 상태 |
| 결제 | 옵션 입력 → 합계 계산 → 동의 → PG 호출 → 성공/실패 |
| 인증 | OTP 발송 → 입력 → 검증 → 잠금 정책 (5회 실패) |
| 알림 | 트리거 → 카테고리 분류 → 회원 설정 매칭 → 발송 채널 → 푸시/SMS/이메일 → 알림센터 누적 → 라우팅 |
| 캘린더 | 월/주/일 토글 → 일자 클릭 → 시트 표시 → 이전/다음 |

### Lv3 일괄 적용 규칙

1. **로딩 상태** — `-XX-LOAD` (API 호출 중 스켈레톤 / 인디케이터)
2. **빈 상태** — `-XX-EMPTY` (결과 0건 일러스트 + 안내)
3. **실패 상태** — `-XX-FAIL` (재시도 진입)
4. **비로그인 게이트** — `-XX-AUTH` (LoginGateModal + returnUrl)
5. **네트워크 단절** — `-XX-NET` (캐시 카드 + 다시 시도)
6. **권한 부족** — `-XX-403` (직원/회원 role 분기 차단)
7. **확인 다이얼로그** — `-XX-CONF` (결정성 액션 직전 ConfirmDialog)
8. **푸시 토스트** — `-XX-TOAST` (비차단 결과 노출)

이 8개 일반 Lv3 규칙은 모든 MFN Lv2 항목에 자동 적용된다.
