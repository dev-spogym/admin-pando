## 기능 목적

만석 수업에 대기 신청한 목록을 회원 앱에서 조회·관리한다. 대기 순번·확정 전환 여부·알림을 확인하고 필요 시 대기 신청을 취소한다. 자리 발생 시 푸시 + 자동 확정 또는 수락 처리.

## 주요 구성요소

### 대기 예약 목록

| 컬럼 | 표시 |
|---|---|
| 수업명 | 대기 신청 수업 |
| 수업 일시 | 날짜 + 시작 시각 |
| 강사명 | 담당 강사 |
| 대기 순번 | 현재 순서 (예: 2번째) |
| 신청일 | 대기 신청일 |
| 상태 | 대기 중 / 확정 전환 / 취소됨 배지 |

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 대기 취소 | 대기 중 | ConfirmDialog → 취소 |
| 예약 확인 | 확정 전환 | MA-122 진입 |

### 알림 안내

대기 순번 변동 / 확정 전환 시 푸시 자동 발송.

## 비즈니스 규칙

1. 대기 신청은 만석 수업에서만 가능(MA-121 [대기 등록] 진입).
2. 대기 순번 변동 / 1순위 자동 확정 시 푸시 알림.
3. 다른 회원 취소로 자리 발생 → admin SCR-C012 정책에 따라 1순위 자동 확정.
4. 대기 중 상태에서만 [대기 취소] 가능, 확정 전환 후엔 일반 예약 취소(MFN-106).
5. 대기열 운영 정책(자동 확정 vs 수락 대기)은 센터 설정에 따라 결정.

| 항목 | 내용 |
