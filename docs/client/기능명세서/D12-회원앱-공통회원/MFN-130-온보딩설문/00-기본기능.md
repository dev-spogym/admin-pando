## 기능 목적

회원이 앱 연동(MA-002) 직후 또는 첫 로그인 직후 운동 목적·성향, 통증·체형 정보, 선호 시간을 3페이지로 입력한다. 입력값은 첫 루틴 제안(MA-128)과 FMS 리포트 정확도, 트레이너에 자동 공유되는 회원 인사이트의 기반이 된다.

## 주요 구성요소

### 진행 인디케이터

| 항목 | 설명 |
|---|---|
| 단계 표시 | 1/3 → 2/3 → 3/3 |
| 페이지 헤드라인 | 1줄 + 보조 설명 |
| 우상단 링크 | "나중에 입력" → MA-128 미완료 진입 |

### 페이지 1 — 운동 목적·성향

| 항목 | 입력 | 옵션 풀 |
|---|---|---|
| 운동 목적 (다중·필수) | 칩 | 감량 / 근비대 / 체형교정 / 통증완화 / 체력증진 / 자세교정 / 재활 / 대회 준비 |
| 운동 성향 (단일) | 라디오 카드 | 강하게 끌어주세요 / 친절하게 안내 / 조용한 운동 / 그룹 분위기 / 자율 운동 |
| 강도 선호 (단일) | 슬라이더 | 저 / 중 / 고 |
| 선호 요일 (다중) | 칩 | 월~일 |
| 선호 시간대 (다중) | 칩 | 오전 / 낮 / 저녁 / 심야 |

### 페이지 2 — 통증·부상

| 항목 | 입력 | 옵션 풀 |
|---|---|---|
| 통증 부위 (다중) | 인체 도식 + 칩 | 목/어깨/등/허리/골반/무릎/발목/손목/팔꿈치/없음 |
| 과거 부상 (다중 + 직접 입력) | 칩 + textarea | 디스크/회전근개/십자인대/발목인대/골절/수술 이력/기타/없음 |
| 불편한 동작 (다중) | 칩 | 스쿼트/데드리프트/푸쉬업/풀업/러닝/점프/회전/없음 |

### 페이지 3 — 체형·집중 부위

| 항목 | 입력 | 옵션 풀 |
|---|---|---|
| 체형 (단일) | 라디오 카드 | 상체비만/하체비만/복부비만/마른비만/표준/근육형 |
| 집중 부위 (다중) | 인체 도식 + 칩 | 복부/등/어깨/가슴/팔/엉덩이/다리/종아리 |

### 하단 CTA

| 버튼 | 조건 | 동작 |
|---|---|---|
| 이전 | 2/3, 3/3 | 이전 페이지 |
| 다음 | 1/3, 2/3 + 입력 완료 | 다음 페이지 |
| 입력 완료 | 3/3 + 필수 충족 | MA-128 진입 |
| 나중에 입력 | 항상 | 미완료 → MA-128, 홈 배너 |

## 권한 / RBAC (회원앱 role)

회원 본인만 입력 가능.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 빈 입력 | 다음 비활성 |
| 입력 중 | 칩 active 강조, 다음 활성 |
| 페이지 전환 중 | 슬라이드 애니메이션 |
| 입력 완료 | MA-128 라우팅 + 토스트 |
| 미완료 종료 | 임시 저장 + 홈 배너 |
| 재진입 | 기존 값 자동 복원 |

## 비즈니스 규칙

1. 회원 본인만 입력 가능, 1회만 자동 진입(앱 연동 직후).
2. 입력값 저장 시점은 [입력 완료] 또는 페이지 이동 직후 임시 저장.
3. "나중에 입력"은 미완료 상태로 MA-128 진입하며 홈에 "온보딩 마저 입력하기" 배너 노출.
4. 운동 목적은 필수 다중 선택, 나머지는 페이지별 필수 항목 다름.
5. 입력값은 admin SCR-M004 회원 상세 메모에 자동 기록되고, SCR-C010 운동 프로그램 권장 알고리즘 입력값으로 사용된다.
6. 마이페이지에서 재진입 가능하며 기존 입력값은 자동 복원된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-M004 회원 상세 / SCR-C010 운동 프로그램 |
| 데이터 흐름 | client → admin (입력값 저장 + 권장 루틴 자동 생성) |
| 정책 출처 | 옵션 풀 = 회원앱 정책 / 매핑 알고리즘 = admin |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**client → admin 영향**

- 입력 완료 → SCR-M004 회원 상세 메모 자동 기록
- 입력값 기반 SCR-C010 운동 프로그램 권장 자동 생성
