## 기능 목적

회원이 본인 기본 정보를 조회하고, 이용권 / 결제 / 체성분 / 리워드 / 활동 / 친구 초대 / 알림 / 설정 등 전체 회원 서비스로 진입하는 허브 화면이다. 프로필 카드 + 9종 서비스 진입 그리드 + 시스템 메뉴 리스트로 구성.

## 권한 / RBAC (회원앱 role)

회원 본인 정보 + 본인 진입 가능 메뉴만 표시. 트레이너/FC/스태프는 별도 홈을 사용한다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 프로필 + 모든 메뉴 |
| 사진 미설정 | 이니셜 아바타 |
| 새 알림 | 알림 메뉴에 미읽음 배지 |
| 새 쿠폰 / 마일리지 | 해당 메뉴 NEW 배지 |
| 로그인 만료 | 보호 액션 차단 + LoginGate |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 본 화면은 회원(member) 전용이며 트레이너/FC/스태프는 별도 화면 사용.
2. 9종 서비스 그리드의 NEW 배지는 admin 정책에 따라 결정(쿠폰 도착, 마일리지 적립, 새 배지 등).
3. 로그아웃은 ConfirmDialog 후 토큰 삭제 + MA-001 진입.
4. 가입 지점 변경 신청 중 상태가 있으면 프로필 카드에 "승인 대기 중" 배지.
5. 앱 버전이 admin 강제 업데이트 정책 미만이면 강제 업데이트 가이드(별도 화면)로 분기.
