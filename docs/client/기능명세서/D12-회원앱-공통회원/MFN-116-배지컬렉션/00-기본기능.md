## 기능 목적

회원이 본인 획득 배지와 미획득 배지(조건 안내)를 카테고리별로 조회한다. 배지 클릭 시 상세 모달에서 조건·진척률·보상 마일리지를 확인하고, 마일스톤 8종은 활동 기반 자동 부여된다.

## 주요 구성요소

### 상단 헤더

| 항목 | 표시 |
|---|---|
| 제목 | "배지 컬렉션" |
| 획득 카운트 | "획득 12 / 30" + 진행 바 |

### 카테고리 칩

전체 / 출석 / 수업 / 측정 / 리워드 / 친구 / 마일스톤(활동 기반).

### 배지 그리드 (2x4 또는 3x4)

획득(강조 색) / 미획득(회색) 분리.

| 항목 | 표시 |
|---|---|
| 배지 아이콘 | 카테고리별 색·모양 |
| 배지명 | 짧은 라벨 |
| 획득 일자 (획득 시) | YYYY-MM-DD |
| 미획득 표시 | 회색 + 자물쇠 |

### 배지 상세 모달

| 항목 | 표시 |
|---|---|
| 배지 일러스트 | 큰 이미지 |
| 배지명 | 큰 텍스트 |
| 조건 설명 | "PT 10회 완강 시 획득" |
| 진척률 | 진행 바 (예: 7/10) |
| 보상 마일리지 | 적립 P |
| 획득 일자 | (획득 시) |
| 공유 버튼 | (획득 시) ShareSheet |

### 마일스톤 배지 (활동 기반 8종)

| 배지 | 조건 |
|---|---|
| 첫 PT 완주 | 첫 PT 완료 |
| 10회 연속 출석 | 10일 연속 |
| 첫 후기 | 첫 후기 작성 |
| 한 달 개근 | 한 달 빠짐 없이 |
| 누적 결제 200만원 | 누적 200만원 |
| 친구 초대 마스터 | 친구 5명 가입 |
| 얼리버드 | 오전 6시 이전 출석 10회 |
| 마라토너 | 누적 1년 회원 |

## 권한 / RBAC (회원앱 role)

회원 본인 배지만 조회.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 획득 배지 있음 | 강조 색 |
| 미획득 배지 | 회색 + 자물쇠 |
| 배지 0개 (신규) | "첫 배지를 획득해 보세요" + 조건 가이드 |
| 카테고리 0건 | "이 카테고리 배지가 없어요" |

## 비즈니스 규칙

1. 회원 본인 배지만 조회 가능.
2. 활동 기반 마일스톤 배지(8종)는 admin SCR-094 KPI 활동 누적 감지 시 자동 부여.
3. 배지 카탈로그 변경(admin)은 본 화면에 즉시 반영.
4. 배지 획득 시 보상 마일리지가 자동 적립되고 푸시 알림이 발송된다.
5. 진척률은 admin 정책 결과를 그대로 표시.
6. 공유는 ShareSheet로 외부 SNS 공유 가능.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-074 (배지 정책) / SCR-094 KPI |
| 데이터 흐름 | admin → client (활동 기반 자동 부여) |
| 정책 출처 | 마일스톤 8종 조건 = admin 운영 정책 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |
