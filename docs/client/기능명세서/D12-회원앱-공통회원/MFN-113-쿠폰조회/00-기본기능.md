## 기능 목적

회원이 보유한 쿠폰을 사용 가능 / 사용 완료 / 만료 상태로 분리 조회하고, 쿠폰 코드 등록 + 결제 화면 진입을 한 곳에서 처리한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 표시 |
|---|---|
| 제목 | "쿠폰함" |
| 우상단 | [+ 쿠폰 코드 등록] |

### 탭

| 탭 | 표시 |
|---|---|
| 사용 가능 | 만료 임박 정렬 |
| 사용 완료 | 사용한 쿠폰 |
| 만료 | 회색 처리 |

### 쿠폰 카드

| 항목 | 표시 |
|---|---|
| 좌측 절취선 | 할인율 / 할인액 (큰 숫자) |
| 쿠폰명 | 큰 텍스트 |
| 사용처 | PT / 헬스 / 마켓 등 |
| 최소 결제액 | "30,000원 이상 결제 시 적용" |
| 만료 D-day | 임박 시 빨강 |
| 발급일 | YYYY-MM-DD |
| 액션 | [결제하기 → MA-140] / [상세 보기] |

### 쿠폰 코드 등록 모달

| 항목 | 설명 |
|---|---|
| 코드 입력 | 영문/숫자 |
| 등록 CTA | 검증 + 등록 |
| 안내 | "오프라인 행사 등에서 받은 쿠폰 코드를 입력하세요" |

## 권한 / RBAC (회원앱 role)

회원 본인 쿠폰만 조회. 쿠폰 발급은 admin 운영팀.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 보유 있음 | 카드 리스트 |
| 빈 상태 | 일러스트 + 등록 안내 |
| 만료 임박 (D-7 이하) | 빨강 강조 |
| 사용 완료 | 회색 + "사용 완료" 도장 |
| 만료 | 회색 + "만료" 도장 |
| 코드 등록 실패 | 인라인 에러 |

## 비즈니스 규칙

1. 회원 본인 쿠폰만 조회 가능.
2. 쿠폰 발급·만료·최소 결제액 정책은 admin SCR-073 쿠폰 관리에서 관리.
3. 쿠폰 만료 시 자동으로 만료 탭으로 이동.
4. 쿠폰 사용은 결제 화면(MA-140)에서 자동 추천 또는 직접 선택으로 적용된다.
5. 코드 등록 실패 사유는 "이미 사용 / 만료 / 잘못된 코드 / 기보유" 중 인라인으로 안내.
6. 쿠폰 사용 시 admin SCR-073 사용 이력에 즉시 기록.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-073 쿠폰 관리 |
| 데이터 흐름 | admin → client (발급/사용/만료) + client → admin (코드 등록·사용) |
| 정책 출처 | 발급·만료·최소 결제액 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |

**admin → client**: SCR-073 발급 시 사용 가능 탭 즉시 추가
**client → admin**: 결제 시 사용 → SCR-073 사용 이력 즉시 기록
