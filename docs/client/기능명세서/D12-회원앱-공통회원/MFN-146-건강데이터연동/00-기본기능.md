## 기능 목적

회원이 Android 하이브리드 앱에서 `Health Connect` 연동을 직접 활성화하고, 수집 데이터 범위 / 권한 상태 / 최근 동기화 시각을 관리한다. 연동된 활동 데이터는 MA-132 체성분/FMS 화면과 admin SCR-I007 회원 건강 연동 요약에 활용된다.

## 주요 구성요소

### 연동 상태 카드

| 항목 | 표시 |
|---|---|
| 상태 배지 | 연결됨 / 부분 권한 / 동기화 지연 / 미연결 / 미지원 |
| 최근 동기화 | 마지막 수집 시각 |
| 동기화 결과 | 정상 / 일부 누락 / 실패 |
| 소스 앱 | 최근 수집 소스 라벨 |

### 수집 데이터 범위

| 항목 | 표시 |
|---|---|
| 걸음수 | 최근 7일 / 30일 요약 |
| 이동 거리 | 일별 합계 |
| 활동 kcal | 최근 7일 활동 에너지 |
| 운동 세션 | 운동 종류 / 시작시각 / 종료시각 / 운동일수 |

### 제외 데이터 안내

| 항목 | 표시 |
|---|---|
| 미수집 범위 | 심박수 / 수면 / 체온 / 혈당 / 의료 데이터 |
| 안내 문구 | 최소 활동 데이터만 연동 |

### 권한 / 동의 섹션

| 항목 | 표시 |
|---|---|
| 서비스 내 활용 동의 | 건강 요약 / 상담 / 추천 활용 안내 |
| OS 권한 상태 | 모두 허용 / 일부 허용 / 거부 |
| 권한 다시 설정 | OS 권한 화면 진입 |
| 연동 해제 | 신규 수집 중단 + 기존 요약 유지 안내 |

### 액션

| 버튼 | 동작 |
|---|---|
| 연동 시작 | 최초 동의 + 권한 요청 |
| 지금 동기화 | 최근 30일 요약 재조회 |
| 권한 다시 설정 | 부분 권한 / 거부 복구 |
| 연동 해제 | ConfirmDialog 후 해제 |

## 권한 / RBAC (회원앱 role)

회원 본인만 관리. 타 회원의 건강 데이터 연동 상태를 조회하거나 변경할 수 없다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 미연결 | 소개 + 연동 시작 CTA |
| 권한 요청 중 | OS 시트 복귀 대기 |
| 연결됨 | 상태 카드 + 최근 요약 |
| 부분 권한 | 일부 항목 누락 안내 |
| 동기화 지연 | 72시간 이상 미수신 경고 |
| 동기화 실패 | 네트워크 / OS 오류 |
| 미지원 기기 | iOS 등 미지원 안내 |

## 비즈니스 규칙

1. Health Connect 연동은 Android 하이브리드 앱에서만 지원하며, iOS는 미지원 안내만 표시한다.
2. 건강 데이터 활용 동의는 마케팅 동의와 별개이며, 회원이 언제든지 해제할 수 있다.
3. v1 수집 범위는 걸음수 / 이동 거리 / 활동 kcal / 운동 세션으로 제한한다.
4. 심박수 / 수면 / 체온 / 혈당 / 의료 데이터는 수집하지 않는다.
5. 최초 연결 성공 시 최근 30일 요약을 백필한다.
6. 자동 동기화는 앱 포그라운드 재진입 시점과 회원의 수동 새로고침을 기준으로 수행한다.
7. 일부 권한만 허용된 경우 허용된 항목만 수집하고 상태는 `부분 권한`으로 표시한다.
8. 72시간 이상 신규 수집이 없으면 `동기화 지연` 상태로 표시한다.
9. 연동 해제 시 신규 수집은 중단되며, 기존 요약 데이터는 마지막 동기화 시점 기준으로 조회 가능하다.
10. Health Connect 활동량은 MA-132와 SCR-I007 요약 카드에 반영되며, 원본 상세 이벤트 로그는 운영자에게 직접 노출하지 않는다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-I007 회원 건강 연동 요약 / SCR-M004 회원 상세 |
| 데이터 흐름 | client → admin (동의 상태 + 활동 요약) |
| 정책 출처 | 데이터 범위 / 지연 기준 / 활용 범위 = admin product policy |
| 연동 시나리오 | 60_admin_연동/C9_건강데이터_연동_동기화 |
