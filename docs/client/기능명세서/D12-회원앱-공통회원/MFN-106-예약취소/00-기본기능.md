## 기능 목적

회원 본인 예약을 취소 가능 기한 내에서 취소한다. 취소 마감 후에는 노쇼 처리 안내를 표시하며, 취소 즉시 admin 캘린더에서 처리되고 대기열 1순위가 자동 확정된다.

## 주요 구성요소

| 진입점 | 설명 |
|---|---|
| MA-121 수업 상세 | 본인 예약 확인 후 [예약 취소] |
| MA-122 내 예약 | 카드 [예약 취소] 버튼 |

### ConfirmDialog 구조

| 항목 | 표시 |

| 안내 | 표시 |

| 결과 | 표시 |

## 비즈니스 규칙

1. 취소 마감 시간은 admin 본사 정책 + 센터 설정에 따라 결정된다(예: 수업 시작 N시간 전).
2. 마감 전 취소는 차감 없이 즉시 처리되며 잔여 회차에 영향을 주지 않는다.
3. 마감 후에는 취소 버튼이 비활성되며 미참여 시 자동으로 노쇼로 처리된다.
4. 노쇼 누적은 admin SCR-C008 페널티 관리에서 정책에 따라 적용된다.
5. 회원이 취소하면 admin SCR-C002 캘린더에서 자동 처리되며, 대기열(MA-124) 1순위가 자동 확정 트리거된다.
6. 자동 확정된 회원에게는 푸시 알림이 발송된다.
7. PT 승인 대기 상태의 예약 취소는 별도 페널티 없이 처리된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C001 캘린더 / SCR-C002 수업 관리 / SCR-C008 페널티 / SCR-C012 대기열 |
| 데이터 흐름 | 양방향 (회원 취소 → admin 캘린더 / 페널티 누적 → 회원 알림) |
| 정책 출처 | 취소 마감 시간 / 노쇼 페널티 = admin 본사 정책 + 센터 설정 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**client → admin 영향**

- 회원 취소 → SCR-C002 캘린더에서 자동 처리 + 대기열 1순위 자동 확정 트리거
- 페널티 누적 시 SCR-C008에 누적 카운트 갱신
