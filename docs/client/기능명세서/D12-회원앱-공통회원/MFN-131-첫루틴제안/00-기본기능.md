## 기능 목적

회원이 MA-127 온보딩 설문 완료 직후 입력값 요약을 확인하고 회원에게 적합한 첫 루틴 3종을 제안받는다. 운동 시작 동기를 부여하고 OT1 예약 또는 트레이너 공유로 자연스럽게 연결한다.

## 주요 구성요소

### 입력 요약 카드 (4영역)

| 영역 | 표시 |
|---|---|
| 운동 목적 / 성향 | 다중 칩 + 성향 1줄 |
| 통증 / 부상 | 통증 부위 + 과거 부상 + 불편한 동작 |
| 체형 / 집중 부위 | 체형 + 집중 부위 |
| 선호 요일·시간 | 요일 + 시간대 |

### 입력 완료율 표시

| 항목 | 설명 |
|---|---|
| 진척 바 | 0~100% |
| 정확도 안내 | "80% 입력 — 첫 루틴 정확도 높음" |
| 추가 입력 CTA | 미완료 항목 → MA-127 진입 |

### 첫 루틴 제안 카드 3종

| 추천 유형 | 설명 |
|---|---|
| 목적 맞춤형 | 운동 목적 기반 (감량 / 근비대 / 체형교정 등) |
| 통증 회복형 | 통증 부위 기반 안전 동작 위주 |
| 균형 강화형 | 부족한 부위 보강 + 전신 균형 |

각 카드 표시:

| 항목 | 표시 |
|---|---|
| 루틴명 | 이름 |
| 추천 사유 | 1줄 |
| 운동 종목 5~7개 | 썸네일 + 이름 |
| 예상 소요 시간 | 분 |
| 액션 | [루틴 시작] / [트레이너에게 공유] |

## 권한 / RBAC (회원앱 role)

회원 본인만 진입. 트레이너 공유 시 트레이너 측 화면에 회원 온보딩 정보 + 추천 루틴 자동 표시.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 입력 100% | 모든 카드 활성 + 정확도 높음 |
| 입력 50~80% | 추가 입력 CTA 강조 |
| 입력 50% 미만 | 일반 추천으로 대체 + 추가 입력 권장 |
| 루틴 시작 | 루틴 상세 진입 |
| 트레이너 공유 | 공유 완료 토스트 |
| 로딩 | 카드 스켈레톤 |

## 비즈니스 규칙

1. 본 화면은 MA-127 입력 완료 또는 "나중에 입력"으로 진입하며 회원 본인만 접근.
2. 첫 루틴 3종 추천 알고리즘은 admin SCR-C010 운동 프로그램 카탈로그 기반.
3. 입력 완료율이 50% 미만이면 일반 추천으로 대체된다.
4. 트레이너 공유 시 트레이너앱 + admin SCR-M004에 회원 온보딩 정보 동기화.
5. SCR-C010 운동 프로그램 카탈로그 변경 시 첫 루틴 추천이 자동 재산정된다.
6. OT1 예약 진입 시 MA-121에서 OT1 라디오가 자동 선택된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C010 운동 프로그램 / SCR-M004 회원 상세 |
| 데이터 흐름 | admin → client (첫 루틴 산정 결과 표시) + client → admin (트레이너 공유) |
| 정책 출처 | 첫 루틴 추천 알고리즘 = admin |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |
