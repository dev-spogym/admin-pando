## 기능 목적

회원이 수업 정보(시간/강사/정원)와 수업 유형 분기(PT / OT1 / OT2 / GX / Golf), 차감 안내를 확인하고 예약·예약 취소·대기 등록을 한 화면에서 처리한다. PT는 트레이너 승인형, OT1/OT2는 즉시 확정, GX는 정원 점검 후 확정 또는 대기.

## 주요 구성요소

### 수업 유형 라디오 / 탭

| 유형 | 표기 | 차감 | 동작 |
|---|---|---|---|
| PT | "PT 정규 1회" | 수업 완료 시 PT 잔여 1회 차감 | 트레이너 승인 대기 |
| OT1 | "신규 1차 OT" | OT 잔여 1회 (없으면 무료 1회 자동) | 즉시 확정, 30일 권장 |
| OT2 | "2차 OT" | OT 잔여 1회 (OT1 완료 후) | OT1 미완료 시 비활성 |
| GX | "GX 그룹 클래스" | 정원 자동 / 만석 시 대기 | 즉시 확정 또는 대기열 |
| Golf | "골프 강사 / 타석" | 강사: 승인 / 타석: 즉시 | 강사 슬롯 또는 타석 분기 |

### 수업 정보 섹션

| 항목 | 표시 |
|---|---|
| 수업명 | 큰 타이틀 |
| 일시 | 날짜 + 시작-종료 |
| 강사 | 사진 + 이름 + 별점 + MA-125 진입 |
| 장소 | 센터 내 위치 또는 룸 |
| 정원 / 잔여석 | 진행 바 + 숫자 |
| 수업 설명 / 준비물 | 텍스트 |

### 예약 옵션

| 항목 | 설명 |
|---|---|
| 시간대 선택 | PT/OT/Golf 강사: 강사 가능 시간 슬롯 |
| 타석 선택 | Golf 타석: 1~N번 카드 |
| 예약 메모 | 강사에게 보낼 메모 (선택) |

### 액션 버튼

| 버튼 | 표시 조건 | 동작 |
|---|---|---|
| 예약하기 | 정원 여유 + 잔여 회차 보유 | 즉시 확정 또는 승인 대기 |
| 예약 요청 | 트레이너 승인형 | 승인 대기 상태 생성 |
| 대기 등록 | 만석 | 대기열 등록 (MA-124) |
| 예약 취소 | 본인 예약 + 취소 가능 기한 | 취소 처리 (MFN-106) |

### 차감 안내 카드

| 항목 | 설명 |
|---|---|
| 차감 시점 | "PT/OT 횟수는 수업 완료 시점에만 차감됩니다" |
| 잔여 회차 | PT/OT 잔여 + MA-131 진입 |
| 차감 시뮬레이션 | "예약 후 잔여 5회 → 예약 5회 + 차감 0회" |

## 권한 / RBAC (회원앱 role)

회원 본인만 예약 가능. 회원 요청형 예약은 강사가 별도 화면에서 승인/거절.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정원 여유 | 예약하기 활성 |
| 정원 만석 | 대기 등록만 활성 |
| 트레이너 승인 필요 | "예약 요청" + 대기 안내 |
| OT2 + OT1 미완료 | "1차 OT 먼저" + OT1 예약 CTA |
| PT/OT 잔여 0 | "재등록 추천" CTA → MA-138 |
| 본인 예약 | 예약 취소 활성 |
| 취소 마감 후 | 비활성 + 노쇼 안내 |

## 비즈니스 규칙

1. PT/OT 차감 시점은 `수업 완료(completed)` 시점에 한한다.
2. OT2는 OT1 완료 회원에게만 활성된다.
3. PT는 트레이너 승인형, OT1/OT2는 즉시 확정, GX는 정원 점검 후 확정 또는 대기.
4. Golf는 강사 슬롯과 타석을 분기 선택(강사: 승인 대기, 타석: 즉시 확정).
5. PT/OT 잔여 0회 → 재등록 추천(MA-138) 안내.
6. 취소 가능 기한 내에서만 본인 예약 취소 가능, 마감 후 노쇼 처리.
7. admin SCR-C007 차감 정책 변경 시 차감 안내 즉시 갱신.
