## admin 연동

회원앱 동작은 admin 시스템과 양방향 연동된다. 자세한 매핑은 `01-공통-회원.md`의 정책 1.12 + 2.1 매핑 표 또는 `다이어그램/60_admin_연동/C1~C8`을 참조한다.

## 비즈니스 규칙

1. 회원 본인 데이터만 조회/수정 가능 (admin 정책 결과만 표시).
2. PT/OT 차감 시점은 `수업 완료(completed)` 시점에 한한다.
3. 만료 D-14/D-7/D-1 트리거는 admin 본사 정책 세트 결과를 따른다.
4. 마일리지 사용 단위는 100P, 만료는 1년 미사용 시.
5. 알림 7개 카테고리는 회원 설정(MA-155)과 admin 발송 정책 조합으로 결정.
