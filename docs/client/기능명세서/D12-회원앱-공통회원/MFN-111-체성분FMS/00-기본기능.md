## 기능 목적

회원이 본인 인바디 측정 이력과 FMS(Functional Movement Screen) / 체형 분석 결과를 한 화면에서 조회한다. Health Connect가 연결된 경우 최근 활동량까지 함께 제공하여 동기 부여 + 운동 방향 가이드를 강화한다.

## 주요 구성요소

### 인바디 섹션

| 항목 | 표시 |
|---|---|
| 최근 측정 카드 | 측정일 + 체중 / 체지방률 / 골격근량 / BMI |
| 이전 대비 변화 | 전월 / 첫 측정 대비 +/- |
| 변화 그래프 | 최근 6개월 라인 차트 (체중·체지방·골격근) |
| 측정 이력 리스트 | 일자 + 주요 지표 |
| 권장 범위 | 표준 범위 표기 |

### FMS / 체형 섹션

| 항목 | 표시 |
|---|---|
| FMS 총점 | 0~21점 + 색상 분기 |
| 세부 항목 점수 | 7개 동작 (DSQT, HSQT 등) |
| 가동성·불균형·자세 문제 | 분석 결과 카드 |
| 권장 운동·주의사항 | 트레이너 안내 |

### 코치 메모 섹션

| 항목 | 표시 |
|---|---|
| 트레이너 메모 | 측정 결과 기반 안내 |
| 메모 일자·작성자 | 트레이너 |
| 다음 측정 권장일 | 자동 계산 (예: 4주 후) |

### 건강 활동 섹션 (선택)

| 항목 | 표시 |
|---|---|
| 최근 7일 걸음수 | 일별 또는 합계 |
| 활동 kcal | 최근 7일 활동 에너지 |
| 운동일수 | 외부 운동 세션이 기록된 날짜 수 |
| 연동 상태 | 연결됨 / 부분 권한 / 동기화 지연 / 미연결 |

### 액션

| 버튼 | 동작 |
|---|---|
| 측정 예약 | OT1/OT2 (체성분 + FMS 포함) → MA-121 |
| 트레이너에게 문의 | 강사톡 (MA-340/341) |
| 결과 PDF 다운로드 | 측정 결과 출력 |

## 권한 / RBAC (회원앱 role)

회원 본인 데이터만 조회. 트레이너는 별도 화면에서 담당 회원 결과 입력/조회.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 측정 이력 있음 | 모든 카드 활성 |
| 측정 0회 (신규) | 일러스트 + "첫 측정을 받아보세요" + OT1 예약 |
| FMS 미측정 | FMS 섹션 회색 + OT2 예약 CTA |
| 코치 메모 없음 | "아직 코치 메모가 없어요" |
| Health Connect 미연결 | 활동 섹션 안내 카드 + MA-159 진입 |
| 부분 권한 | 일부 지표만 표시 |
| 동기화 지연 | 마지막 동기화 시각 강조 + 재동기화 CTA |
| 그래프 데이터 부족 | 최소 2회 측정 후 활성 |
| 로딩 | 카드 스켈레톤 |

## 비즈니스 규칙

1. 회원 본인 데이터만 조회 가능.
2. 화면에 노출되는 측정 데이터는 admin SCR-I006 통합 체성분 검수에서 확정된 데이터만.
3. 트레이너가 admin SCR-M006에 입력 시 MA-132 즉시 갱신 + 푸시 알림.
4. InBody 자동 연동 데이터는 SCR-I006 검수 완료 후 회원에게 노출.
5. 측정 보상 마일리지(100P)는 admin 본사 정책에 따라 자동 적립.
6. 다음 측정 권장일은 admin 알고리즘으로 자동 계산되며 푸시 알림 트리거.
7. FMS 점수는 7개 동작 항목 합산(0~21점) + 색상 분기.
8. Health Connect는 Android 하이브리드 앱에서만 지원되며, 최초 연결 시 최근 30일 요약을 백필한다.
9. Health Connect v1 수집 범위는 걸음수 / 이동 거리 / 활동 kcal / 운동 세션으로 제한하며 심박수 / 수면 / 의료 데이터는 수집하지 않는다.
10. 72시간 이상 신규 수집이 없으면 `동기화 지연` 상태로 표시한다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-M006 체성분 / SCR-I006 통합 체성분 / SCR-I007 회원 건강 연동 |
| 데이터 흐름 | admin → client (트레이너 입력 → 회원 즉시 조회), client → admin (건강 데이터 요약) |
| 정책 출처 | 측정 보상 100P / 다음 측정 권장일 / 건강 데이터 활용 범위 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C5_체성분_FMS_입력 / C9_건강데이터_연동_동기화 |
