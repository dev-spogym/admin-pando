## 기능 목적

회원이 7개 카테고리별 알림 ON/OFF 및 채널을 직접 설정하고, 야간 차단 / 건강 데이터 연동 / 약관 / 동의관리 / 회원 탈퇴 / 1:1 문의 / 앱 버전 / 로그아웃 등 시스템 메뉴를 한 허브에서 진입한다.

## 주요 구성요소

### 알림 카테고리 섹션 (7개 카드)

| 카테고리 | 보조 텍스트 | 기본값 |
|---|---|---|
| 예약 | 예약 확정/변경/노쇼 임박 | ON |
| 이용권 | 만료 D-day, 잔여 임박 | ON |
| 리워드 | 마일리지/배지/등급 상승 | ON |
| 공지 | 센터 이벤트, 휴무 | ON |
| AT-RISK 케어 | 4주 미방문 / 만료 후 미재등록 | ON |
| 수업·후기 | 수업 시작 30분 전 / 후기 요청 | ON |
| 부가시설 | 사우나/락커/굿즈 만료·잔여 | ON |

각 카드: 카테고리명 + 1줄 설명 / ON·OFF 메인 스위치 / 채널 칩(앱 푸시 / SMS / 이메일 다중).

### 야간 차단 토글

| 항목 | 설명 |
|---|---|
| 야간 차단 | 22:00~07:00 푸시 차단 (기본 OFF) |
| 안내 | "차단 시간에는 푸시가 보류됩니다" |

| 보조 텍스트 | 걸음수 / 활동 kcal / 운동 세션을 건강 요약에 반영 |
| 진입 | MA-159 |

## 권한 / RBAC (회원앱 role)

회원 본인 설정. AT-RISK OFF 시에도 MA-138 직접 진입은 가능.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 모두 ON | 모든 카드 활성 |
| 일부 OFF | 해당 카드 회색 |
| 채널 미선택 | 메인 ON이어도 발송 채널 없음 안내 |
| 야간 차단 ON | 시간대 강조 |
| 건강 데이터 미지원 | MA-159 행에 미지원 문구 |
| 앱 업데이트 가능 | 빨강 점 + [업데이트] |

## 비즈니스 규칙

1. 7개 카테고리 ON/OFF + 채널은 회원 본인 설정.
2. 메인 스위치 ON이어도 채널 0개면 발송되지 않으며 안내된다.
3. 야간 차단 시간(22-07)은 회원앱 기본 정책 고정, 시간대 변경은 admin 정책에 따라 향후 조정 가능.
4. 회원 OFF 변경은 admin SCR-072 발송 결정에 즉시 반영.
5. AT-RISK 카테고리 OFF 시 푸시 차단되지만 회원이 MA-138 직접 진입은 가능.
6. 변경 이력은 admin SCR-M004 회원 상세에서 조회 가능.
7. 건강 데이터 연동 상태는 MA-159의 최근 상태를 요약 표시하며, iOS에서는 미지원 문구로 대체한다.
8. 로그아웃은 ConfirmDialog 후 토큰 삭제 + MA-001 진입.
9. 앱 버전이 admin 강제 업데이트 정책 미만이면 강제 업데이트 가이드로 분기.
