## 기능 목적

회원 본인 예약(승인 대기 / 확정 / 완료 / 취소)과 수업 이력을 카테고리별로 조회하고, 후기 작성·예약 취소·차감 이력 확인을 한 화면에서 처리한다. 리스트 모드와 캘린더 모드를 자유 전환할 수 있다.

## 주요 구성요소

### 상단 필터 / 탭

| 필터 | 옵션 |
|---|---|
| 서비스 탭 | 전체 / PT / OT / GX / Golf |
| 상태 필터 | 승인 대기 / 확정 / 완료 / 취소 |
| 보기 모드 | 리스트 / 캘린더 |
| 기간 | 다가오는 / 지난 / 전체 |

### 예약 카드 (리스트 모드)

| 항목 | 표시 |
|---|---|
| 좌측 일자 | DD요일 + 시간 |
| 카테고리 칩 | PT/OT/GX/Golf 색상 분기 |
| 수업명 / 강사 | 클래스명 + 강사 + MA-125 진입 |
| 상태 칩 | 승인 대기(warning) / 확정(success) / 완료(neutral) / 취소(error) |
| 액션 (상태별) | 승인 대기: 취소 / 확정: 예약 취소 / 완료: 후기 작성(MA-126) / 취소: - |
| 잔여 차감 표시 | 완료 시 "차감 1회 적용" |

### 캘린더 모드

| 항목 | 표시 |
|---|---|
| 월간 캘린더 | 예약일 색칠 + 상태별 도트 |
| 일자 탭 | 해당 일 예약 리스트 시트 |

### PT / OT 차감 이력 카드

| 항목 | 표시 |
|---|---|
| 최근 차감 5건 | 일자 + 수업명 + 강사 + 차감 결과 |
| 더보기 | MA-131 진입 |
| 다음 예약 예정 | 다가오는 예약 일자 |

## 권한 / RBAC (회원앱 role)

회원 본인의 예약/이력만 조회. 트레이너는 별도 트레이너 화면에서 회원 예약을 본다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 예약 있음 | 카드 리스트 표시 |
| 빈 상태 | 일러스트 + 예약하기 → MA-120 |
| 캘린더 모드 | 월간 그리드 + 도트 |
| 승인 대기 | 카드 강조 + 대기 시간 |
| 취소 마감 후 | 취소 비활성 + 안내 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 회원 본인 예약/이력만 조회 가능.
2. 완료 카드 후기 작성 → MA-126 진입, 후기 작성 보상 마일리지(100P) 자동 적립.
3. PT/OT 차감 이력은 admin SCR-C007 차감 정책 결과 표시.
4. 노쇼 페널티 누적 시 admin SCR-C008 정책에 따라 푸시 + 카드 갱신.
5. 취소 마감 시간이 지난 확정 카드는 취소 버튼 비활성 + 안내.
6. 캘린더 도트 색상은 상태별 매핑(승인/확정/완료/취소).

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C001 / SCR-C002 / SCR-C007 / SCR-C008 페널티 |
| 데이터 흐름 | 양방향 (예약 상태 / 차감 / 노쇼) |
| 정책 출처 | 취소 마감 / 노쇼 페널티 = admin 본사 정책 + 센터 설정 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**client → admin**: 회원 취소 → SCR-C002 캘린더에서 처리 + 대기열 1순위 자동 확정
**admin → client**: SCR-C007 수업 완료 → MA-122 카드에 "차감 1회 적용" 즉시 표시
