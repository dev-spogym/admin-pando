## 기능 목적

회원이 센터 입장 시 본인 앱에 표시된 QR을 키오스크/태블릿 스캐너에 보여주거나, 센터 QR을 회원 앱 카메라로 스캔하여 출석을 자동 기록한다. QR은 60초마다 자동 갱신(보안)되며 햅틱 + 토스트로 결과를 즉시 알린다.

## 주요 구성요소

### QR 표시 모드 (회원 → 센터, 기본)

| 항목 | 설명 |
|---|---|
| 회원 QR | 큰 정사각형 (회원 ID + 시간 토큰) |
| 갱신 타이머 | 60초마다 자동 갱신 |
| 회원 정보 | 회원명 / 회원번호 / 가입 지점 |
| 밝기 자동 최대 | 화면 진입 시 단말 밝기 최대 |

### QR 스캔 모드 (센터 → 회원)

| 항목 | 설명 |
|---|---|
| 카메라 뷰 | 후면 카메라 자동 활성 |
| 가이드 박스 | 정사각형 + 안내 문구 |
| 손전등 토글 | 어두운 환경 보조 |
| 모드 전환 | 표시 ↔ 스캔 |

### 체크인 결과 토스트

| 결과 | 표시 |
|---|---|
| 성공 | 초록 체크 + "출석 완료 — HH:MM" + 햅틱 |
| 중복 | 회색 안내 + "이미 오늘 출석했어요" |
| 이용권 만료 | 경고 + "이용권을 확인해 주세요" → MA-131 |
| 실패 | 빨강 + 재시도 |

### 보조 액션

| 버튼 | 설명 |
|---|---|
| 출석 이력 보기 | MA-111 진입 |
| 수동 출석 도움 요청 | 1:1 문의 진입 |

## 비즈니스 규칙

1. QR은 회원 ID + 시간 토큰을 인코딩하며 60초마다 자동 갱신되어 캡처 도용을 차단한다.
2. 당일 동일 회원의 중복 체크인은 첫 1회만 출석으로 인정되고 이후는 "중복" 안내 표시.
3. 이용권이 만료되었거나 없는 회원은 출석은 기록되되 경고 표시 + MA-131 진입 안내.
4. 네트워크 단절 시 캐시된 QR을 표시하고, 복구 시 자동으로 출석 기록을 동기화한다.
5. 카메라 권한이 거부된 상태에서는 표시 모드만 사용 가능하다.
6. 직원(트레이너/FC/스태프) 출퇴근은 본 화면이 아니라 직원 전용 화면에서 처리한다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-086 출석 관리(회원) / SCR-I001 통합 출석 / SCR-C014 출석 QR / SCR-082 키오스크 설정 |
| 데이터 흐름 | client → admin (체크인 시 출석 INSERT 즉시 + Realtime 동기화) |
| 정책 출처 | 당일 중복 차단·이용권 없는 회원 경고 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C2_QR체크인_출석동기화 |

**client → admin 영향**

- 체크인 즉시 SCR-086 출석 카운트 + SCR-094 KPI 갱신
- 이용권 만료/없음 회원 입장 시 SCR-I008 키오스크 운영 현황에 경고
- 수동 출석은 admin 측 스태프 화면(SCR-520)에서만 처리
