## 기능 목적

회원 앱에서 강사의 프로필·전문분야 카테고리 칩·NPS 점수(색상 분기)·별점 평균·후기 요약·담당 수업·가능 시간을 조회하고, 예약 또는 대기 신청으로 바로 이동한다. 회원이 수업 예약 전 강사 정보를 확인하는 단계.

## 주요 구성요소

### 강사 프로필 섹션

| 항목 | 표시 |
|---|---|
| 프로필 사진 | 대표 이미지 |
| 강사명 | 이름 |
| 전문 분야 | 카테고리 태그 (필라테스/웨이트/골프 등) |
| 소개글 | 자기소개 / 철학 |
| 경력 | 주요 경력 |
| 자격증 | 보유 자격증 |
| NPS 점수 | 색상 분기 (높음/중간/낮음) |
| 별점 평균 | 자동 집계 |
| 후기 요약 3건 | 최근 후기 발췌 |

### 담당 수업 목록

| 항목 | 표시 |
|---|---|
| 수업명 | 이름 |
| 수업 유형 | 그룹 / 1:1 PT / 골프 레슨 |
| 정원 | 최대 인원 |
| 다가오는 일정 | 가장 가까운 수업 |
| 예약 가능 여부 | 잔여 자리 배지 |

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 예약하기 | 예약 가능 | MA-121 진입 |
| 대기 신청 | 만석 | 대기 등록 (MA-124) |

## 권한 / RBAC (회원앱 role)

회원 누구나 조회 가능. 편집은 admin SCR-061에서만.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정보 있음 | 프로필 + 담당 수업 |
| 담당 수업 없음 | "현재 담당 수업 없음" |
| 수업 만석 | "만석" 배지 + [대기 신청] |
| 로딩 | 스켈레톤 |
| 조회 실패 | 오류 + 재시도 |

## 비즈니스 규칙

1. 강사 프로필은 admin SCR-061 직원 등록에서 관리, 회원 앱은 조회만.
2. 별점·NPS는 admin SCR-C013 후기 등록 시 자동 재계산되어 본 화면에 반영.
3. 가능 시간대는 admin SCR-C006 강사 근무 변경 시 자동 갱신.
4. 골프강사(golf_trainer)도 일반 트레이너와 동일하게 본 화면에서 조회.
5. 만석 수업은 [대기 신청] 활성 → MA-124 진입.
6. NPS 색상 분기 정책은 회원앱 자체 정책(예: 70+ 녹색, 50+ 주황, 그 외 빨강).

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-061 직원 등록 / SCR-C006 강사 근무 / SCR-C013 평가 |
| 데이터 흐름 | admin → client (프로필 / NPS / 별점 자동 집계) |
| 정책 출처 | 전문분야 카테고리 = admin 표준 / NPS 색상 = 회원앱 정책 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |
