## 기능 목적

회원이 본인 기본 정보(이름·연락처·이메일·성별·생년월일·사진)를 마이페이지에서 조회하고 수정한다. 연락처는 SMS 인증, 이메일은 이메일 인증 후 적용되며, 가입 지점은 변경 신청만 가능하다.

## 주요 구성요소

### 프로필 카드 (상단)

| 항목 | 표시 |
|---|---|
| 프로필 사진 | 원형 + 카메라 아이콘으로 변경 진입 |
| 이름 | 큰 텍스트 |
| 가입 지점 | 지점명 + 변경 신청 진입 |
| 회원 등급 배지 | BRONZE / SILVER / GOLD / VIP / VVIP |
| 가입일 | YYYY-MM-DD |
| [프로필 편집] | 진입 |

### 기본 정보 섹션

| 항목 | 수정 가능 / 인증 |
|---|---|
| 이름 | 즉시 저장 |
| 연락처 | SMS 인증 필수 |
| 이메일 | 이메일 인증 필수 |
| 성별 | 선택 즉시 저장 |
| 생년월일 | 캘린더 즉시 저장 |
| 가입 지점 | 수정 불가 (별도 변경 신청) |

### 사진 변경

| 항목 | 동작 |
|---|---|
| 카메라 | 사진 촬영 |
| 갤러리 | 기존 사진 선택 |
| 기본 아바타로 | 이니셜 아바타 복원 |
| 업로드 처리 | 로딩 + 토스트 |

## 권한 / RBAC (회원앱 role)

회원 본인 정보만 조회/수정. 가입 지점 변경은 admin 승인 필수.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 카드 + 모든 메뉴 |
| 사진 미설정 | 이니셜 아바타 + 추가 안내 |
| 인증 진행 중 | 항목 로딩 |
| 인증 실패 | 인라인 에러 |
| 사진 업로드 실패 | 토스트 + 재시도 |
| 가입 지점 변경 신청 중 | "승인 대기 중" 배지 |

## 비즈니스 규칙

1. 본인 정보만 조회·수정 가능.
2. 연락처 변경은 SMS 인증 6자리 + 3분 유효 + 5회 실패 시 10분 잠금.
3. 이메일 변경은 이메일 인증 메일 링크 클릭으로 적용.
4. 가입 지점은 회원이 직접 수정 불가, 변경 신청 → admin SCR-M005 회원 이관 승인.
5. 회원이 수정한 정보는 admin SCR-M004 회원 상세에 즉시 반영.
6. admin SCR-M003에서 회원 정보 수정 시 MA-130 즉시 갱신.
7. 인증 정책(SMS 자릿수·유효시간·잠금)은 admin 본사 정책 + 센터 설정.
