## 기능 목적

회원이 강사 상세(MA-125)에서 가능 시간을 조회하고 시간대를 선택하여 PT 예약을 요청한다(`status=requested`). 트레이너가 별도 화면에서 승인/거절하며, 결과는 푸시 알림으로 회원에게 통보된다. PT의 자유 시간 예약 흐름의 핵심 액션.

## 주요 구성요소

### 강사 가능 시간 섹션 (MA-125 내)

| 항목 | 표시 |
|---|---|
| 일자 캐러셀 | 오늘 ~ +14일 |
| 시간 슬롯 | 30분 단위 |
| 가능 슬롯 | 활성 + 강조 |
| 마감 슬롯 | 회색 + "마감" 배지 |
| 휴무일 | 회색 + "휴무" |

### 시간 선택 + 메모 입력

| 항목 | 입력 |
|---|---|
| 선택 시간 | 슬롯 클릭 → 강조 |
| 예약 메모 | 트레이너 전달 메모 (선택, 최대 200자) |
| 수업 유형 자동 표기 | "PT 정규 1회" |
| 차감 안내 | "수업 완료 시점에 PT 잔여 1회 차감" |

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 예약 요청 | 시간 선택 + 잔여 회차 보유 | status=requested 생성 → MA-121 흐름 진입 |
| 닫기 | 항상 | 이전 화면 |

## 권한 / RBAC (회원앱 role)

회원 본인만 예약 요청. 트레이너 승인은 트레이너 측 화면에서 처리.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 시간 미선택 | 예약 요청 비활성 |
| 시간 선택됨 | 예약 요청 활성 |
| 잔여 0 | 비활성 + 재등록 추천 CTA |
| 요청 처리 중 | 로딩 |
| 요청 성공 | 토스트 + MA-122 승인 대기 카드 |
| 휴무일 | "휴무" 안내 |

## 비즈니스 규칙

1. PT 예약은 강사 승인형으로 동작하며 회원이 시간을 선택해 요청 → 트레이너가 승인/거절.
2. 가능 시간은 admin SCR-C006 강사 근무 + 캘린더 충돌 검증 결과.
3. 차감 시점은 수업 완료(`completed`)에 한정되며 예약·요청·확정 시점에는 차감되지 않는다.
4. PT 잔여 0회 → 재등록 추천(MA-138) 안내.
5. 강사 승인/거절 결과는 푸시 알림으로 즉시 회원에게 통보.
6. 본 기능은 강사 상세(MA-125)와 수업 상세 예약(MA-121) 양쪽에서 진입 가능.
7. 메모는 최대 200자, 트레이너에게 그대로 전달된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C001 캘린더 / SCR-C002 수업 관리 / SCR-C006 강사 근무 / SCR-C007 횟수 |
| 데이터 흐름 | client → admin (예약 요청) + admin → client (승인 결과) |
| 정책 출처 | 강사 승인 흐름 + 차감 시점 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |

**client → admin 영향**

- 예약 요청 → SCR-C001 캘린더에 승인 대기 카드 즉시 노출
- 트레이너 승인 → SCR-C002 캘린더에 확정 카드, 회원에게 푸시
