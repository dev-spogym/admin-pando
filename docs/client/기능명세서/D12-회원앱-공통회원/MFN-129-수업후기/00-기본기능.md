## 기능 목적

수업 완료 후 회원이 별점·태그·텍스트 후기를 작성하여 만족도를 표현한다. 관리자/강사는 후기를 수업 품질 개선에 활용하며, 회원에게는 후기 작성 보상 마일리지(100P)가 자동 적립된다.

## 주요 구성요소

### 수업 정보 표시 (읽기 전용)

| 항목 | 표시 |
|---|---|
| 수업명 | 이름 |
| 수업 일시 | 날짜 + 시간 |
| 강사명 | 담당 강사 |
| 강사 사진 | 소형 프로필 |

### 별점 입력 (필수)

5점 만점. 빈 별표 → 채워진 별표.

| 항목 | 설명 |
|---|---|
| 별점 | 1~5점 (필수) |
| 점수 설명 | "매우 만족" 등 |

### 후기 텍스트 (선택)

| 항목 | 설명 |
|---|---|
| 후기 내용 | 자유 텍스트 최대 500자 |
| 글자 수 | 현재/최대 실시간 |

### 태그 선택 (선택)

| 예시 |
|---|
| 설명이 친절해요 / 동작 교정을 잘 해줘요 / 시간 관리를 잘 해요 / 분위기가 좋아요 |

### 추천 의향 점수 (선택)

NPS 형식 0~10점.

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 후기 등록 | 별점 선택 완료 | 저장 + 마일리지 100P 적립 |
| 나중에 하기 | 항상 | 건너뛰기 (MA-122에서 재진입) |

## 권한 / RBAC (회원앱 role)

본인이 수강 완료한 수업만 작성 가능. 동일 수업 중복 작성 불가(수정만 가능).

## 화면 상태

| 상태 | 설명 |
|---|---|
| 별점 미선택 | 등록 비활성 |
| 별점 선택됨 | 등록 활성 |
| 텍스트 입력 중 | 글자 수 실시간 |
| 등록 성공 | 완료 화면 또는 토스트 |
| 등록 실패 | 오류 + 재시도 |
| 이미 작성됨 | "이미 작성한 후기" + 수정 버튼 |

## 비즈니스 규칙

1. 본인 수강 완료 수업에만 작성 가능.
2. 별점 필수, 텍스트·태그·NPS는 선택.
3. 동일 수업 중복 작성 불가, 수정만 가능.
4. 후기 등록 시 마일리지 100P 자동 적립 (admin 본사 정책).
5. 후기는 admin SCR-C013에 즉시 반영, 강사 NPS·별점 평균 자동 재계산 → SCR-094 KPI.
6. 텍스트 후기 최대 500자.
7. "나중에 하기"는 MA-122 카드에서 재진입 가능.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C013 평가 / SCR-074 마일리지 / SCR-094 KPI |
| 데이터 흐름 | client → admin (후기 → NPS·별점 자동 갱신, 마일리지 자동 적립) |
| 정책 출처 | 후기 보상 100P = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 |
