## 기능 목적

회원이 서비스 이용약관 / 개인정보 처리방침 / 위치기반 서비스 약관 / 마케팅 수신 안내 등 운영 정책 문서를 조회 전용으로 확인한다. 약관 개정 시 재동의 모달이 자동 진입된다.

## 주요 구성요소

### 약관 리스트

| 항목 | 종류 | 동의 상태 |
|---|---|---|
| 서비스 이용약관 | 필수 | 동의 완료 (가입일) |
| 개인정보 처리방침 | 필수 | 동의 완료 |
| 위치기반 서비스 약관 | 필수 (위치 기능 사용 시) | 동의 완료 / 미동의 |
| 마케팅 수신 안내 | 선택 | ON / OFF (MA-157에서 변경) |

각 항목 우측 화살표 → 약관 본문 페이지.

### 약관 본문 페이지

| 항목 | 표시 |
|---|---|
| 헤더 | 약관명 + 시행일 |
| 본문 | 마크다운 렌더링 (조항별 Heading) |
| 목차 | 좌측 또는 상단 (긴 약관 시) |
| 변경 이력 | 하단 과거 버전 보기 |
| 닫기 / 뒤로 | 이전 화면 |

### 약관 변경 알림 (조건부)

약관 개정 시 푸시 + MA-156 진입 시 변경 안내 배너. 필수 약관 변경 시 재동의 요구 모달.

## 권한 / RBAC (회원앱 role)

회원 본인 동의 이력 표시. 약관 본문은 모든 사용자 동일.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 리스트 + 동의 상태 |
| 약관 개정 | 상단 배너 + 강조 |
| 필수 약관 재동의 필요 | 모달 + 동의 시 통과 |
| 본문 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 약관 본문은 admin SCR-080 센터 설정에서 관리.
2. 약관 개정 시 푸시 알림 + MA-156 진입 시 상단 배너 노출.
3. 필수 약관 변경 시 재동의 모달이 자동 진입되며 동의해야 통과.
4. 마케팅 약관은 선택이며 MA-157 동의관리에서 변경 가능.
5. 위치기반 서비스 약관은 위치 기능 사용 시 필수 동의.
6. 약관 변경 이력(과거 버전)은 하단에서 조회 가능.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-080 센터 설정 (약관 영역) |
| 데이터 흐름 | admin → client (본문 + 개정 알림) |
| 정책 출처 | 본문 / 재동의 필수 = admin 본사 설정 |
| 연동 시나리오 | 60_admin_연동/C8_탈퇴_복구_파기 |
