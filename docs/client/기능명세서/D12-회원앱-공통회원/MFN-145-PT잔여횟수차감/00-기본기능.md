## 기능 목적

회원이 보유한 PT/OT 이용권의 총 회차·사용·잔여를 한 화면에서 조회하고 차감 일자 이력을 확인한다. 차감은 수업 완료(`completed`) 시점에 1회 차감되며, 예약·확정 시점에는 차감되지 않음을 명확히 안내한다.

## 주요 구성요소

### 이용권 요약 카드

| 항목 | 표시 |
|---|---|
| 이용권 종류 | PT 정규 / OT1 / OT2 |
| 총 회차 | 큰 숫자 |
| 사용 회차 | 누적 차감 횟수 |
| 잔여 회차 | 큰 숫자 + 색상 강조 |
| 만료일 | YYYY-MM-DD + D-day |

### 차감 시점 안내 카드

| 항목 | 표시 |
|---|---|
| 차감 시점 | "PT/OT 횟수는 수업 완료 시점에만 차감됩니다" |
| 시뮬레이션 | "이 예약 후 잔여 5회 → 예약 5회 + 차감 0회" |
| 안내 추가 | 노쇼 시에도 차감 정책 분기(센터 설정) |

### 차감 이력 리스트

| 컬럼 | 표시 |
|---|---|
| 일자 | YYYY-MM-DD |
| 수업명 | 클래스 |
| 강사 | 강사명 |
| 차감 결과 | 차감 1회 / 노쇼 차감 / 무차감 |
| 사유 | 수업 완료 / 노쇼 / 취소 |

### 다음 예약 예정

| 항목 | 표시 |
|---|---|
| 다음 예약 | 다가오는 예약 일시 |
| 이동 | MA-122 진입 |

### 재등록 / 추가 결제 CTA

| 조건 | CTA |
|---|---|
| 잔여 5회 미만 | "재등록 추천" → MA-138 |
| 잔여 0회 | "재등록 필요" 강조 + MA-138 |

## 권한 / RBAC (회원앱 role)

회원 본인 이용권만 조회. 트레이너는 별도 화면에서 담당 회원 이용권을 본다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 이용권 보유 | 요약 + 차감 이력 표시 |
| 잔여 5회 미만 | 색상 강조 + 재등록 CTA |
| 잔여 0회 | 강조 + 재등록 필요 |
| 만료 임박 | D-day 색상 분기 |
| 만료 후 | "이용권 만료" 안내 + 재등록 |
| 이용권 미보유 | "이용권이 없어요" + 마켓 진입 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. PT/OT 차감 시점은 수업 완료(`completed`)에 한하며 예약·요청·확정·취소 시점에는 차감되지 않는다.
2. 노쇼 시 차감 정책은 센터 설정(SCR-C008)에 따라 분기되며 본 화면에 안내된다.
3. 잔여 회차가 admin 본사 정책 임계값 미만이면 재등록 추천(MA-138) CTA가 노출된다.
4. 만료 임박 D-14/D-7/D-1 트리거 시 색상 분기 + 푸시 알림(admin SCR-072 자동 알림).
5. 차감 이력은 admin SCR-C007 횟수 관리와 동일 데이터를 표시한다.
6. 회원 본인 데이터만 조회 가능하며, 트레이너 별도 화면에서 담당 회원 이용권 조회 가능.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-C007 횟수 관리 / SCR-C008 페널티 / SCR-072 자동 알림 / SCR-138 재등록 |
| 데이터 흐름 | admin → client (잔여·차감 이력 / D-day 트리거) |
| 정책 출처 | 차감 시점·노쇼 차감·만료 D-day = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C3_예약_승인_차감 / C6_재등록 |

**admin → client 영향**

- SCR-C007 차감 정책 변경 시 차감 이력·시뮬레이션 즉시 갱신
- SCR-072 자동 알림 트리거 시 만료 임박 색상 + 푸시
- SCR-C008 페널티 누적 시 노쇼 차감 결과 표시
