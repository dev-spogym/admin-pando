## 기능 목적

회원의 이용권 만료 시점(D-14 / D-7 / D-1) 또는 회원의 임의 진입 시, 회원 활동 데이터 기반 추천 플랜 3종(AI 추천 / 균형형 / 경제형)을 비교 노출하여 재등록 결제(MA-140)로 연결한다.

## 주요 구성요소

### 상단 D-day 트리거 배너

| 트리거 | 톤 | 문구 |
|---|---|---|
| D-14 | info | "회원권 만료 14일 전 — 미리 준비해 주세요" |
| D-7 | warning | "이번 주 만료 — 재등록 시 +10% 혜택" |
| D-1 | danger | "내일 만료 — 마지막 안내" |
| 임의 진입 | neutral | "이용권 추천 플랜을 확인해 보세요" |
| 만료 후 | warning | "만료된 회원권을 갱신해 주세요" + AT-RISK 케어 |

### D-day 인디케이터

| 항목 | 표시 |
|---|---|
| 남은 일수 | 큰 숫자 (D-7) |
| 만료 일자 | YYYY-MM-DD |
| 현재 회원권 | 종류 + 잔여 (PT/OT 분리) |

### 추천 플랜 3종

| 추천 유형 | 배지 | 산정 기준 |
|---|---|---|
| AI 추천 | "당신에게 딱 맞는 플랜" (primary) | 주 평균 PT 빈도 × 4주 |
| 균형형 | "가장 많이 선택" (success) | 평균 + 활동 가중 |
| 경제형 | "가성비" (warning) | 최소 회차 + 최대 할인 |

각 카드: 플랜명 / 회차 / 정가 + 할인가 / 1회 단가 / 추천 사유 1줄 / 혜택 리스트 / [이 플랜으로 결제 → MA-140]

## 권한 / RBAC (회원앱 role)

회원 본인만 진입. AI 추천은 활동 데이터가 있는 회원에게만, 신규 회원은 일반 추천으로 대체.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 (D-14/D-7/D-1) | 해당 D-day 배너 + 추천 3종 |
| 임의 진입 | 기본 톤 |
| 만료 후 | warning + AT-RISK 케어 |
| 활동 데이터 0건 | AI → 일반 추천 대체 |
| 추천 생성 중 | 카드 스켈레톤 |
| 생성 실패 | MA-134 안내 |

## 비즈니스 규칙

1. D-14/D-7/D-1 트리거 시점은 admin 본사 정책 세트 결과를 따른다.
2. AI 추천 플랜은 회원 활동 데이터(주 평균 PT 빈도, 카테고리 가중치) 기반으로 산정.
3. 활동 데이터가 부족한 신규 회원은 일반 추천으로 대체.
4. AT-RISK(만료 후 4주 미재등록)는 회원 + FC 양쪽 알림.
5. 재등록 결제 완료 시 D-day 트리거가 자동 종료되고 회원권이 갱신된다.
6. 마일리지 사용 가능액은 보유 P × 1원 환산으로 미리보기에 표시.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-099 리포트 / 본사 D-day 정책 / SCR-072 자동 알림 |
| 데이터 흐름 | admin → client (D-day 트리거 + 추천 산정) |
| 정책 출처 | D-14/D-7/D-1 / AI 추천 알고리즘 = admin |
| 연동 시나리오 | 60_admin_연동/C6_이용권_Dday_트리거 |

**admin → client**: 일배치 D-day 트리거 → 푸시 + MA-138 활성, AT-RISK 식별 시 회원+FC 알림
**client → admin**: 재등록 결제 → SCR-S001 매출 즉시 + D-day 트리거 종료
