## 기능 목적

회원이 가입한 센터의 운영 정보(주소 / 영업시간 / 연락처 / 시설 / 부가 서비스 / 강사)를 한 화면에서 확인하고, 길찾기 / 전화 / 1:1 문의 / 카카오톡 채널 진입을 지원한다.

## 주요 구성요소

### 센터 헤더

| 항목 | 표시 |
|---|---|
| 센터명 | 큰 텍스트 |
| 카테고리 | 헬스 / 골프 / 필라테스 |
| 별점 평균 | 5점 + 후기 수 |
| 대표 이미지 | 가로 스크롤 갤러리 |

### 운영 정보

| 항목 | 표시 |
|---|---|
| 영업시간 | 요일별 (오늘 강조) |
| 휴무일 | 정기 + 임시 |
| 운영 상태 칩 | 영업 중 / 곧 마감 / 영업 종료 |

### 위치 / 길찾기

| 항목 | 표시 |
|---|---|
| 주소 | 도로명 + 지번 |
| 지도 미리보기 | 지도 카드 (탭 시 외부 지도 앱) |
| 길찾기 | 카카오맵 / 네이버맵 / Google Maps 선택 |

### 연락처

| 항목 | 동작 |
|---|---|
| 대표 전화 | 전화 앱 |
| 1:1 문의 | MA-153 |
| 카카오톡 | 카카오 채널 |

### 시설 / 부가 서비스 카드

| 항목 | 표시 |
|---|---|
| 시설 태그 | 샤워실 / 사우나 / 락커 / 운동복 / 주차 / Wi-Fi |
| 부가 서비스 | 운동복 / 수건 / 사우나 / 굿즈 (가격 + 신청 진입 → MA-141) |

### 트레이너 / 강사 섹션

소속 강사 가로 스크롤 카드 → 카드 탭 → MA-125.

### 공지 / 이벤트 미니 배너

진행 중 공지 1~2건 → MA-152.

## 권한 / RBAC (회원앱 role)

회원 가입 센터 정보 조회. 마켓 둘러보기에서 다른 센터(MA-312)는 별도.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 영업 중 | 칩 초록 |
| 곧 마감 (1시간 전) | 칩 주황 |
| 영업 종료 | 칩 회색 |
| 휴무일 | 안내 배너 |
| 강사 0명 | "현재 등록된 강사가 없어요" |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 회원 가입 센터 정보만 조회.
2. 운영 상태 칩은 현재 시각 기준 자동 산출(영업 중 / 곧 마감 / 종료).
3. 센터 정보는 admin SCR-080 센터 설정에서 관리, 변경 시 즉시 반영.
4. SCR-092 지점 정보 변경 시 회원 표시 동기화.
5. 부가 서비스 신청은 MA-141 개인 결제로 진입.
6. 강사 카드 정보는 admin SCR-061 + SCR-C006 + SCR-C013 결과를 종합.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-080 센터 설정 / SCR-092 지점 관리 |
| 데이터 흐름 | admin → client (정적 데이터 조회) |
| 정책 출처 | 영업시간 / 시설 / 부가 서비스 = SCR-080 |
| 연동 시나리오 | (직접 시나리오 없음) |
