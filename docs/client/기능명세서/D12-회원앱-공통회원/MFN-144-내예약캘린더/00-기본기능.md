## 기능 목적

월간 캘린더 + 일자 클릭 → 일별 예약 시트 + 카테고리별 도트 표시. 내 예약 / 수업 이력(MA-122)의 캘린더 모드로 동작하며, 시각적으로 예약 분포를 파악하고 일자 단위로 예약을 조회한다.

## 주요 구성요소

### 월간 캘린더

| 항목 | 표시 |
|---|---|
| 월 헤더 | YYYY-MM + 좌우 이동 화살표 |
| 요일 헤더 | 월~일 |
| 일자 셀 | 1~31 / 일자별 도트 |
| 오늘 표시 | 오늘 일자 강조 (테두리) |

### 카테고리 도트 (일자 셀)

| 카테고리 | 색상 |
|---|---|
| PT | 파랑 |
| OT | 보라 |
| GX | 주황 |
| 필라테스 | 녹색 |
| Golf | 초록 |

여러 예약이 있는 경우 도트 다중 표시.

### 일자 시트 (탭 시 노출)

| 항목 | 표시 |
|---|---|
| 일자 헤더 | YYYY-MM-DD 요일 |
| 예약 카드 리스트 | 시간 / 카테고리 / 수업명 / 강사 / 상태 |
| 카드 액션 | MA-121 수업 상세 또는 MA-123 골프 예약 상세 진입 |

### 보기 모드 전환

리스트 ↔ 캘린더 전환 (MA-122와 공유).

## 권한 / RBAC (회원앱 role)

회원 본인 예약만 표시.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 (예약 있음) | 캘린더 + 도트 + 시트 |
| 빈 상태 (해당 월) | "이 달 예약이 없어요" + 예약하기 |
| 일자 시트 0건 | 시트 내 "예약 없음" |
| 로딩 | 캘린더 스켈레톤 |
| 새로고침 | 상단 인디케이터 |

## 비즈니스 규칙

1. 카테고리 색상(PT 파랑 / OT 보라 / GX 주황 / 필라테스 녹색 / Golf 초록)은 admin과 고정 매핑된다.
2. 동일 일자에 여러 카테고리 예약이 있으면 도트가 다중 표시된다.
3. 일자 셀 탭 시 해당 일 예약 시트가 슬라이드 업으로 노출된다.
4. 예약 상태(승인 대기/확정/완료/취소) 색상 매핑은 MA-122 리스트 모드와 동일하다.
5. 골프 예약 카드 탭 시 MA-123 골프 예약 상세로, 그 외는 MA-121 수업 상세로 진입한다.
6. 본 화면은 MA-122의 캘린더 모드 변형이며, 데이터·정책 모두 MA-122와 공유한다.

| 항목 | 내용 |
