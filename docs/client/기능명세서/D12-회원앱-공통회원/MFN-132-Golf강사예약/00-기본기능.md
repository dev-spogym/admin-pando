## 기능 목적

회원이 골프 강사를 선택하여 가능 시간대 + 타석을 함께 선택하고 예약을 요청한다. 강사 승인형으로 동작하여 강사가 별도 화면에서 승인/거절하며, 회원에게는 푸시 알림으로 결과를 안내한다.

## 주요 구성요소

### 강사 선택 영역

| 항목 | 표시 |
|---|---|
| 강사 카드 | 사진 + 이름 + 별점 + 전문분야(골프) |
| 강사 상세 진입 | MA-125 |
| 가능 시간 미리보기 | 다음 가능 슬롯 |

### 가능 시간 슬롯

| 항목 | 표시 |
|---|---|
| 일자 캐러셀 | 오늘 ~ +14일 |
| 시간 슬롯 | 30분 단위, 강사 가능 시간만 활성 |
| 만석 슬롯 | 회색 처리 + "마감" 배지 |

### 타석 선택

| 항목 | 표시 |
|---|---|
| 타석 그리드 | 1~N번 |
| 사용 중 타석 | 회색 + 선택 불가 |
| 점검 중 타석 | 경고 + 선택 불가 |

### 레슨권 잔여 안내

| 항목 | 표시 |
|---|---|
| 레슨권 종류 | PT / 단체 등 |
| 잔여 회차 | 큰 숫자 |
| 부족 시 안내 | [레슨권 구매] CTA |

### 예약 메모

자유 텍스트, 강사에게 전달되는 메모.

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 예약 요청 | 강사 + 시간 + 타석 + 레슨권 보유 | status=requested 생성 |
| 닫기 | 항상 | 이전 화면 |

## 권한 / RBAC (회원앱 role)

회원 본인만 예약 요청 가능. 강사 승인은 강사 측 화면에서 처리.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 강사 미선택 | 가능 시간 영역 비활성 |
| 강사 선택 | 가능 시간 활성 |
| 시간 + 타석 선택 | 예약 요청 활성 |
| 레슨권 부족 | "예약 요청" 비활성 + 구매 CTA |
| 요청 처리 중 | 로딩 |
| 요청 성공 | 토스트 + MA-122 카드(승인 대기) |
| 요청 실패 | 빨강 + 재시도 |

## 비즈니스 규칙

1. 골프 강사 예약은 강사 승인형(`status=requested`)으로 동작한다.
2. 강사 가능 시간은 admin SCR-C006 강사 근무 + 골프 타석 충돌 검증 결과로 산출.
3. 레슨권 부족 시 [레슨권 구매] CTA로 결제 화면 진입.
4. 차감은 수업 완료(`completed`) 시점에 1회 차감되며 예약·확정 시점에는 차감되지 않는다.
5. 강사 승인/거절은 푸시 알림으로 회원에게 즉시 통보.
6. 타석은 일반 골프 타석 풀에서 선택되며 사용 중·점검 중은 선택 불가.
7. 골프 타석 단독 예약(강사 없음)은 MFN-126으로 분리 처리.

| 항목 | 내용 |
