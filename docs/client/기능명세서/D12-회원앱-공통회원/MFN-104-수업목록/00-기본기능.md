## 기능 목적

회원이 가입 지점의 PT/OT/GX/필라테스/Golf 수업 일정을 카테고리·요일·시간대·강사로 탐색하고, 정원·잔여석·강사 정보를 확인하여 수업 상세(MA-121) 또는 강사 상세(MA-125)로 진입한다.

## 주요 구성요소

### 상단 필터

| 항목 | 옵션 |
|---|---|
| 카테고리 탭 | 전체 / PT / OT / GX / 필라테스 / Golf |
| 날짜 캐러셀 | 오늘 ~ +14일 가로 스크롤 |
| 시간대 칩 | 오전 / 낮 / 저녁 / 심야 |
| 강사 필터 | 강사 다중 선택 (모달) |
| 예약 가능만 | 토글 (만석 제외) |

### 수업 카드

| 항목 | 표시 |
|---|---|
| 시간 | 시작 - 종료 |
| 수업명 | 강사명 함께 표시 |
| 카테고리 칩 | PT/OT/GX/필라테스/Golf 색상 분기 |
| 정원 / 잔여석 | "12 / 15" + 진행 바 |
| 상태 칩 | 예약 가능 / 만석(대기 가능) / 마감 |
| 액션 | 카드 탭 → MA-121 |

### 추천 강사 섹션 (선택)

회원의 온보딩 정보 + 출석 패턴 기반 추천 강사 가로 스크롤. 강사 카드 → MA-125 진입.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 카드 리스트 표시 |
| 만석 카드 | "대기 등록" 보조 액션 |
| 마감 카드 | 회색 처리 + 액션 비활성 |
| 빈 상태 | 일러스트 + 다른 날짜 추천 |

## 비즈니스 규칙

1. 본 화면은 회원 가입 지점 수업만 표시한다(다른 센터는 마켓 둘러보기 MA-300).
2. 만석 카드는 "대기 등록" 보조 액션을 노출하며 탭 시 MA-124로 연결.
3. 마감 시간이 지난 수업은 회색 처리 + 액션 비활성.
4. 추천 강사 섹션은 온보딩(MA-127) + 출석 패턴(MA-111) 기반 산출.
5. admin SCR-C002 수업 등록·취소·시간 변경 시 즉시 반영.
6. admin SCR-C006 강사 근무 변경 시 강사별 수업 목록 자동 갱신.
