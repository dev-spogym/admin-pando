## 기능 목적

회원이 상품 스토어(MA-134)에서 선택한 상품의 상세 정보(가격 / 회차 / 혜택 / 사용 안내 / 후기)를 확인하고 옵션 결제(MA-400) / 장바구니(MA-401) / 바로 결제(MA-140)로 진입한다. 강사형 상품은 강사 정보 카드를 함께 노출.

## 주요 구성요소

### 상품 헤더

| 항목 | 표시 |
|---|---|
| 메인 이미지 | 가로 스크롤 갤러리 |
| 카테고리 칩 | PT / 헬스 / 골프 / OT / 부가옵션 |
| 상품명 | 큰 텍스트 |
| 가격 | 정가 (취소선) + 할인가 (강조) |
| 등급 할인가 | 회원 등급별 미리보기 |
| 마일리지 사용 가능 | "최대 5,000P" |
| 별점 평균 + 후기 수 | 후기 섹션 진입 |

### 회차 / 옵션 칩

| 상품 유형 | 옵션 |
|---|---|
| PT 전용 | 회차(4/8/16) + 강사 선택(MA-125) |
| 기간형 이용권 | 1/3/6/12개월 |

### 혜택 / 구성 카드

| 항목 | 설명 |
|---|---|
| 포함 혜택 | "OT 1회 무료" / "마일리지 +5%" |
| 사용 안내 | 시작일 / 만료 정책 / 차감 방식 |
| 환불 정책 요약 | "결제 후 7일 100% / 30일 70%" + MA-404 |

### 강사 정보 카드 (강사형 전용)

| 항목 | 표시 |
|---|---|
| 강사 사진 + 이름 | MA-125 진입 |
| 전문분야 칩 | 다중 |
| NPS / 별점 | 색상 분기 |
| 가능 시간 미리보기 | 다음 슬롯 |

### 후기 섹션

| 항목 | 표시 |
|---|---|
| 후기 평균 | 별점 + 후기 수 |
| 최근 후기 3건 | 회원명(마스킹) + 별점 + 한줄 |
| 모두 보기 | 후기 전체 진입 |

## 권한 / RBAC (회원앱 role)

회원 본인의 등급 / 마일리지 / 활동 데이터 기반 가격·추천 표시.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 모든 섹션 활성 |
| 옵션 미선택 | 바로 결제 비활성 |
| 강사형 + 가능 시간 없음 | 다른 강사 선택 안내 |
| 후기 0건 | "아직 후기가 없어요" |
| 비로그인 + 결제 시도 | LoginGateModal |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. PT 회차 옵션 단가 배수(4×1.0 / 8×1.9 / 16×3.5)는 admin 본사 정책 고정.
2. 환불 정책(예: 7일 100% / 30일 70%)은 admin 본사 정책 + 센터 설정.
3. 강사형 상품은 강사 가능 시간이 없으면 다른 강사 선택 안내.
4. SCR-P003 상품 정보 변경 시 즉시 갱신.
5. SCR-061 강사 정보 변경 시 강사 카드 자동 반영.
6. SCR-C013 후기 신규 등록 시 별점 / 평균 자동 갱신.
7. 마일리지·등급 할인은 결제 단계(MA-140)에서 실제 적용된다.
8. 시즌 가격(SCR-P008)이 활성화되면 회원 화면 가격 자동 변경.
