## 기능 목적

회원이 가장 자주 쓰는 예약 / 출석 / 리워드 / 온보딩 / 공지를 한 화면에서 진입한다. 만료 임박, 미완료 온보딩, AT-RISK(4주 미방문) 등 회원 상황에 따라 최우선 카드를 자동 결정해 노출하여 적시 액션을 유도한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 설명 |
|---|---|
| 회원 인사말 | "안녕하세요, OOO님" + 회원 등급 배지 |
| 알림 아이콘 | 미읽음 카운트 배지 (MA-150 진입) |
| 둘러보기 진입 | MA-300 마켓 진입 |

### 만료 / 미완료 우선 배너 (조건부)

| 트리거 | 배너 |
|---|---|
| 만료 D-14 / D-7 / D-1 | 색상 분기 + [재등록 추천] CTA → MA-138 |
| 온보딩 미완료 | "온보딩을 마저 입력해 주세요" → MA-127 |
| AT-RISK (4주 미방문) | "오랜만이에요" + 추천 플랜 → MA-138 |

### 핵심 바로가기 (3~4 그리드)

| 카드 | 진입 |
|---|---|
| PT 예약 | 다음 예약 또는 잔여 회차 → MA-121 |
| GX 스케줄 | 오늘/이번 주 GX → MA-120 |
| Golf 예약 | 골프 예약 → MA-123 |

### 오늘 수업 카드

| 항목 | 설명 |
|---|---|
| 오늘 예약 1~3건 | 시간 / 수업명 / 강사 / 위치 |
| 액션 | 예약 보기 / QR 체크인(MA-110) |
| 빈 상태 | "오늘 예약된 수업이 없어요" + 예약하기 |

### 마일리지 / 배지 요약

| 항목 | 설명 |
|---|---|
| 보유 마일리지 | 큰 숫자 + 만료 임박 안내 |
| 최근 획득 배지 | 1~3개 (MA-137 진입) |
| 등급 진척률 | 다음 등급까지 진척 바 (MA-500) |

### 공지 / 이벤트 배너

가로 스크롤 배너. 진행 중인 공지·이벤트·프로모션. 탭하여 상세 페이지.

### 이번 달 출석 요약

| 항목 | 설명 |
|---|---|
| 출석 일수 + 전월 대비 | "이번 달 12회 (+3)" |
| 캘린더 미니뷰 | 출석일 색칠 |
| 더보기 | MA-111 진입 |

### 추천 루틴 / 온보딩 카드

| 카드 | 설명 |
|---|---|
| 첫 루틴 | 온보딩 기반 추천 (MA-128) |
| 트레이너 추천 루틴 | 담당 트레이너 발송 루틴 |

## 비즈니스 규칙

1. 우선 배너 결정은 admin 본사 정책 세트(D-14/D-7/D-1, AT-RISK 4주 기준)를 따른다.
2. 회원 status가 hold면 우선 배너에 hold 사유와 해제 안내가 노출된다.
3. 알림 미읽음 카운트는 MA-150 알림센터와 실시간 동기화된다.
4. 마일리지·배지·등급 진척률은 admin SCR-094 KPI 정의와 동일 산정식을 사용한다.
5. 공지 배너는 SCR-085 공지 발행 즉시 갱신된다.
6. 회원이 트레이너 변경 시 추천 루틴 카드가 새 트레이너 발송 루틴으로 갱신된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-101 대시보드 / SCR-072 자동 알림 / SCR-085 공지 / SCR-094 KPI |
| 데이터 흐름 | admin → client (우선 카드 결정 데이터) |
| 정책 출처 | D-day 트리거·AT-RISK·등급 산정 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C1, C6, C7 |

**admin → client 영향**

- SCR-072 자동 알림 트리거 발생 시 홈 우선 배너 노출
- SCR-085 공지 발행 시 홈 배너 즉시 갱신
- SCR-094 KPI 산정 결과(출석/마일리지/등급)와 즉시 동기화
