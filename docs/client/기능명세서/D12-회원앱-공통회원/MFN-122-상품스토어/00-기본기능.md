## 기능 목적

회원이 헬스 / PT / OT / 골프 / 부가옵션 상품을 카테고리·회차 옵션으로 탐색하고, AI 추천 플랜 3종 또는 일반 상품을 결제(MA-140)로 진입한다. 회원 활동 데이터 기반 개인화 추천이 상단에 노출된다.

## 주요 구성요소

### 상단 검색 / 정렬

| 항목 | 옵션 |
|---|---|
| 검색 입력 | 상품명 / 강사명 / 키워드 |
| 정렬 | 인기순 / 가격순(낮음/높음) / 신상순 |

### AI 추천 플랜 3종 (가로 스크롤, 상단)

| 추천 유형 | 배지 | 표시 |
|---|---|---|
| AI 추천 | "당신에게 딱 맞는 플랜" (primary) | 회원 활동 기반 |
| 균형형 | "가장 많이 선택" (success) | 평균 기준 |
| 경제형 | "가성비" (warning) | 최소 회차 + 최대 할인 |

### 카테고리 탭

헬스 / PT / 골프 이용권 / 골프 레슨 / OT 추가 / 부가옵션.

### 상품 카드 그리드

| 항목 | 표시 |
|---|---|
| 썸네일 | 상품 이미지 |
| 상품명 | 큰 텍스트 |
| 기본 회차 / 기간 | "16회 · 4개월" |
| 정가 / 할인가 | 취소선 + 강조 |
| 혜택 태그 | "마일리지 +5%" / "OT 1회 무료" |
| 회차 옵션 칩 (PT) | 4회(×1.0) / 8회(×1.9) / 16회(×3.5) |
| 등급 할인가 | 회원 등급별 미리보기 |
| 마일리지 사용 가능액 | "최대 5,000P" |

## 권한 / RBAC (회원앱 role)

회원 본인 가입 지점 + 본사 통합 상품 조회. 멀티센터 마켓은 MA-300에서.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 추천 + 카드 그리드 |
| 신규 회원 (활동 0건) | AI 추천 → 일반 추천 대체 |
| 카테고리 0건 | "이 카테고리 상품이 없어요" |
| 검색 결과 0건 | "검색 결과 없음" + 카테고리 추천 |
| 비로그인 | 카드 조회 가능, 결제 시 LoginGateModal |
| 로딩 | 카드 스켈레톤 |

## 비즈니스 규칙

1. 회원 가입 지점 + 본사 통합 상품을 조회한다.
2. AI 추천 3종은 활동 데이터 기반이며 신규 회원은 일반 추천으로 대체.
3. PT 회차 옵션은 4(×1.0)/8(×1.9)/16(×3.5) 단가 배수 고정.
4. admin SCR-P008 시즌 가격 활성화 시 회원 화면 가격이 자동 변경된다.
5. 상품 카드 액션 분기는 상품 유형에 따라 결정(단순 이용권은 바로 결제, PT/강사형은 옵션 결제).
6. 멀티센터 마켓 상품은 MA-300 둘러보기에서 별도 처리.
7. 마일리지·등급 할인은 admin SCR-074·SCR-M009 정책에 따라 자동 표시.
