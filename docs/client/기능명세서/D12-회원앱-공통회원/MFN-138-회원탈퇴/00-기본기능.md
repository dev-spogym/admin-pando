## 기능 목적

회원이 탈퇴 사유를 선택하고 탈퇴 요청을 접수한다. 즉시 삭제가 아니라 운영 승인 후 처리되는 단계로 정의되며, 탈퇴 전 잔여 회차 / 마일리지 / 미결제 환불 여부를 명확히 안내한다. 90일 후 NFR-06 자동 크론으로 영구 파기되며, 90일 내에는 admin 복구 가능.

## 주요 구성요소

### 탈퇴 전 안내 카드

| 항목 | 표시 |
|---|---|
| 잔여 회차 | PT/OT/골프 잔여 (있으면 환불 안내) |
| 보유 마일리지 | 즉시 소멸 안내 |
| 진행 중 주문 | 환불 처리 안내 |
| 가입 지점 | 지점명 + "재가입은 센터 문의" |

### 탈퇴 사유 단일 선택

| 사유 | 설명 |
|---|---|
| 서비스 불만족 | 운영 / 시설 / 강사 |
| 이용 빈도 감소 | 운동 빈도 줄어듦 |
| 다른 센터 이용 | 타 센터 이동 |
| 개인정보 우려 | 정보 보안 / 마케팅 |
| 기타 | 직접 입력 (textarea) |

### 추가 의견 (선택)

textarea, 운영팀 전달.

### 탈퇴 동의 체크박스 (3종)

| 동의 | 설명 |

## 권한 / RBAC (회원앱 role)

회원 본인만 신청. 운영팀이 별도 승인 단계에서 최종 처리.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 잔여 자산 있음 | 안내 강조 + 환불 안내 |
| 진행 중 주문 있음 | 환불 안내 |
| 동의 미체크 | CTA 비활성 |
| 사유 미선택 | CTA 비활성 |
| 처리 중 | 로딩 + 백 비활성 |
| 실패 | 토스트 + 재시도 |
| 완료 | 결과 화면 + 자동 로그아웃 |

## 비즈니스 규칙

1. 탈퇴는 즉시 처리가 아닌 admin 운영 승인(DLG-M005) 후 처리.
2. 잔여 회차는 별도 환불 정책에 따라 처리, 마일리지·쿠폰은 즉시 소멸.
3. 진행 중인 주문은 환불 처리 안내 + 운영팀 처리.
4. 매니저 승인 시 회원 status=withdrawn + 자동 로그아웃 + 모든 보호 액션 차단.
5. 탈퇴 후 90일 이내 admin DLG-M005를 통해 복구 가능 (status=active 복원).
6. 90일 경과 시 NFR-06 자동 크론으로 개인정보 마스킹 + 영구 삭제.
7. 탈퇴 신청 + 승인 + 복구 + 파기는 모두 admin SCR-097 감사 로그에 기록.
8. 탈퇴 후 동일 정보로 재가입은 센터 문의를 통해 진행한다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | DLG-M005 탈퇴 처리 / SCR-097 감사 로그 / NFR-06 90일 파기 |
| 데이터 흐름 | client → admin (탈퇴 신청) + admin → client (승인 후 차단) |
| 정책 출처 | 운영 승인 필수 / 90일 파기·복구 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C8_탈퇴_복구_파기 |

**client → admin**: 탈퇴 신청 → DLG-M005 큐 + SCR-097 감사 로그 INSERT
**admin → client**: 매니저 승인 → status=withdrawn + 자동 로그아웃 / 90일 후 NFR-06 영구 삭제 / 90일 내 복구 시 active 복원
