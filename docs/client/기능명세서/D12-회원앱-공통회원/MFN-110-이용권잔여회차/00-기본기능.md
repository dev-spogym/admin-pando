## 기능 목적

회원이 회원권 만료일, PT·OT 잔여 횟수, 락커 사용 정보, 부가옵션(운동복·수건·사우나) 상태를 5종 카드로 한 화면에서 확인한다. 만료 D-day가 임박한 경우 재등록 추천(MA-138) 진입을 유도한다.

## 주요 구성요소

### 회원권 카드

| 항목 | 표시 |
|---|---|
| 회원권 종류 | 헬스 자유 / 헬스+골프 / PT 통합 등 |
| 시작일 / 만료일 | 이용 시작 ~ 만료 |
| 만료 D-day | 큰 숫자 + 색상 분기 (D-14 정상 / D-7 warning / D-1 danger) |
| 만료 임박 배너 | D-14 이하 진입 시 상단 강조 + [재등록 추천] CTA → MA-138 |

### PT 잔여 카드

| 항목 | 표시 |
|---|---|
| 총 / 사용 / 잔여 | 진행 바 + 숫자 |
| 최근 차감 일자 | YYYY-MM-DD HH:MM |
| 다음 예약 예정 | 일자/강사 |
| 차감 안내 | "수업 완료 시점에만 차감" |
| 액션 | [예약하기 → MA-121] / [최근 차감 5건 → MA-122] |

### OT 잔여 카드

| 항목 | 표시 |
|---|---|
| OT1 진행 상태 | 미진행 / 완료(날짜) / 잔여 N회 |
| OT2 진행 상태 | 미진행 / 완료(날짜) / 잔여 N회 |
| 분리 표기 | OT1/OT2 항상 분리 |
| 액션 | OT1 → 미진행: 예약 / OT1 완료 + OT2 미진행: OT2 예약 / OT 추가권 → MA-134 |

### 락커 카드

| 항목 | 표시 |
|---|---|
| 락커 번호 | 배정 번호 |
| 사용 시작 / 만료 | 시작 ~ 만료 |
| 만료 D-day | 남은 일수 |
| 액션 | [연장 결제 → MA-141] |
| 미사용 시 | "락커 사용 안 함" + 신청 안내(MA-153) |

### 부가옵션 카드

| 옵션 | 표시 |
|---|---|
| 운동복 | ON/OFF + 잔여 회수 + 만료 |
| 수건 | ON/OFF + 잔여 회수 + 만료 |
| 사우나 | ON/OFF + 잔여 회수 + 만료 |
| 액션 | 옵션별 [연장/추가 결제 → MA-141] |

### 최근 차감 이력 카드 (선택)

최근 5건 PT/OT 차감 이력 → 더보기 MA-122.

## 권한 / RBAC (회원앱 role)

회원 본인 이용권만 조회. 편집은 운영 관리자(admin)만.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 모든 카드 활성 |
| 만료 D-14 이하 | 회원권 카드 강조 + 배너 |
| 만료 D-1 / 만료됨 | 빨강 테두리 + 우선 노출 |
| PT/OT 잔여 0 | 회색 + 재등록 추천 |
| 락커 미사용 | 회색 + 신청 안내 |
| 부가옵션 0건 | 빈 상태 |
| 회원권 미보유 | 일러스트 + 상품 스토어 CTA → MA-134 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 회원 본인 이용권만 조회 가능.
2. 만료 D-14/D-7/D-1 트리거는 admin 본사 정책 세트 결과를 따른다.
3. PT/OT 차감 시점은 수업 완료(`completed`)에 한한다.
4. PT 잔여 0 또는 만료 임박 시 재등록 추천(MA-138) CTA가 강조된다.
5. OT1/OT2는 항상 분리 표기, OT2는 OT1 완료 후에만 예약 가능.
6. 락커·부가옵션 만료는 카드별 D-day로 표시.
7. 홀딩 신청은 회원이 신청 → admin DLG-M003 큐 → 매니저 승인 후 반영.
8. admin SCR-M002에서 이용권 부여 시 MA-131에 즉시 노출.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-P001~003 상품 / SCR-M002 회원 등록 / SCR-M004 회원 상세 / DLG-M003·M004 홀딩 |
| 데이터 흐름 | 양방향 (홀딩 신청 / D-day 트리거) |
| 정책 출처 | D-14/D-7/D-1 / 홀딩 가능 기간 / 차감 시점 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C6_이용권_Dday_트리거 |

**admin → client 영향**

- SCR-M002 이용권 부여 → MA-131 카드 즉시 노출
- 본사 D-day 정책 변경 → 만료 트리거 시점 자동 반영
- DLG-M003 홀딩 등록 → 홀딩 칩 즉시 표시

**client → admin 영향**

- 회원 홀딩 신청 → DLG-M003 큐 추가
