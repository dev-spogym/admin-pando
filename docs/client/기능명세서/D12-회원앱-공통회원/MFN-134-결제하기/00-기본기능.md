## 기능 목적

상품 스토어 / 옵션 결제 / 개인 결제 / 장바구니 / 재등록 추천 / 관리자 발송 결제링크에서 진입한 결제 주문을 처리한다. 결제수단 선택, 마일리지 사용, 쿠폰 적용을 한 화면에서 처리하고 결제 완료 후 영수증(MA-142)으로 자동 진입한다. 결제링크 진입 시에는 상품/금액/할인/쿠폰/마일리지 변경이 불가하며 결제수단 선택과 결제 동의만 활성화된다.

## 주요 구성요소

### 주문 요약 카드 (상단)

| 항목 | 표시 |
|---|---|
| 상품 이미지 + 상품명 | 단건 또는 리스트 (장바구니 다중) |
| 옵션 요약 | 강사 / 시간 / 회차 |
| 정가 | 큰 텍스트 |

### 결제수단 선택

| 결제수단 | 표시 |
|---|---|
| 등록 카드 | 카드사 로고 + 끝 4자리 + "기본" 배지 |
| 카카오페이 | 로고 + 토글 |
| 네이버페이 | 로고 + 토글 |
| 결제수단 추가 | MA-405 진입 |

### 쿠폰 섹션

| 항목 | 표시 |
|---|---|
| 자동 추천 쿠폰 | 최대 할인 자동 적용 (1장) |
| 쿠폰 직접 선택 | MA-135 쿠폰함에서 |
| 미사용 | 쿠폰 미적용 |

### 마일리지 사용 섹션

| 항목 | 표시 |
|---|---|
| 보유 마일리지 | 큰 숫자 |
| 사용 입력 | 100P 단위 (전체 사용 버튼) |
| 차감 후 결제액 | 실시간 계산 |

### 합계 박스

| 항목 | 표시 |
|---|---|
| 상품 합계 | 정가 |
| 쿠폰 할인 | -금액 |
| 마일리지 사용 | -P (원 환산) |
| 멤버십 등급 할인 | -금액 |
| 최종 결제액 | 큰 강조 |

### 동의 / 결제 CTA

| 항목 | 설명 |
|---|---|
| 결제 동의 | "결제 진행에 동의합니다" 필수 |
| 결제하기 | 수단 + 동의 시 활성 |

### 결제링크 모드 표시

| 항목 | 표시 |
|---|---|
| 출처 배지 | "결제링크 결제" |
| 발송 직원 | 직원명 |
| 편집 비활성 안내 | "결제링크 결제는 수정 불가" |

## 비즈니스 규칙

1. 결제 후 MA-142 영수증으로 자동 진입한다.
2. 마일리지는 100P 단위로만 사용 가능하다.
3. 쿠폰은 자동 추천(최대 할인 1장) 또는 직접 선택, 최소 결제액 미달 시 자동 비활성.
4. 결제링크 모드에서는 상품/금액/쿠폰/마일리지 변경이 불가하며, 결제수단과 동의만 활성.
5. 결제링크가 만료되거나 취소된 경우 본 화면 진입이 차단되고 안내가 표시된다.
6. 결제 완료 시 admin SCR-S003 즉시 등재 + SCR-S001 매출 집계 + SCR-074 마일리지 적립 + SCR-073 쿠폰 차감 + SCR-M009 등급 재산정.
7. 결제수단 정책·PG 변경(admin)은 결제 화면에 즉시 반영된다.
8. 회원 누적 결제액에 따라 멤버십 등급 할인이 자동 적용된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-S003 결제 처리 / SCR-S016 결제링크 / SCR-073 쿠폰 / SCR-074 마일리지 / SCR-M009 등급 |
| 데이터 흐름 | 양방향 (회원 결제 → admin 매출) + 단방향 (결제링크 → 회원 진입) |
| 정책 출처 | 결제수단 / 등급 할인 / 환불 비율 / 결제링크 편집 불가 = admin 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**client → admin**

- 결제 완료 → SCR-S003 등재 + SCR-S001 매출 집계
- 마일리지/쿠폰 차감 → SCR-074/SCR-073 사용 이력
- 등급 재산정 → SCR-M009
- 결제링크 결제 완료 → SCR-S016 발송 이력 "완료" 즉시 반영

**admin → client**

- 결제수단 정책 변경 → 결제 화면 갱신
- SCR-S016 결제링크 발송 → SMS/카카오/이메일 + MA-140 진입
- 결제링크 만료/취소 → 진입 차단 + 안내
