## 기능 목적

결제 화면(MA-140)에서 보유 마일리지를 100P 단위로 입력하여 결제액을 차감한다. 차감 후 결제액을 실시간 계산하고 보유 초과 입력은 자동 차단되며, 차감 결과는 영수증과 admin 측에 즉시 반영된다.

## 주요 구성요소

### 마일리지 사용 섹션 (MA-140 내)

| 항목 | 표시 |
|---|---|
| 보유 마일리지 | 큰 숫자 |
| 사용 입력 | 숫자 입력 (100P 단위) |
| 전체 사용 | 1탭 보유액 전부 입력 |
| 차감 후 결제액 | 실시간 계산 |
| 안내 | "100P 단위로 사용 가능" / "1P = 1원" |

### 검증 / 에러 안내

| 케이스 | 안내 |
|---|---|
| 100P 단위 미달 | "100P 단위로 입력해 주세요" |
| 보유 초과 | 입력 즉시 보유 한도로 자동 보정 |
| 결제액 초과 | 결제액까지만 사용 가능 |

### 결제 완료 시

| 처리 | 설명 |
|---|---|
| 차감 | 결제 금액에서 사용 P × 1원 차감 |
| 영수증 | "마일리지 사용: -₩X (사용 P)" 표기 |
| admin 반영 | SCR-074 사용 이력 즉시 등재 |

## 권한 / RBAC (회원앱 role)

회원 본인 결제에서만 사용 가능.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 입력 활성 |
| 100P 미달 | 인라인 안내 |
| 보유 초과 | 자동 보정 |
| 결제액 초과 | 결제액까지만 |
| 결제 처리 중 | 입력 잠금 |
| 결제 실패 | 입력값 유지 |

## 비즈니스 규칙

1. 마일리지 사용 단위는 100P 고정.
2. 1P = 1원 환산.
3. 보유액 초과 시 자동으로 보유 한도까지 보정.
4. 결제액 초과 시 결제액까지만 사용 가능.
5. 결제 실패 시 마일리지는 차감되지 않으며, 성공 시점에만 차감.
6. 차감 결과는 admin SCR-074 사용 이력에 즉시 등재되고 영수증(MA-142)에 표시.
7. 결제링크 모드(MA-140)에서는 마일리지 사용이 비활성된다.
