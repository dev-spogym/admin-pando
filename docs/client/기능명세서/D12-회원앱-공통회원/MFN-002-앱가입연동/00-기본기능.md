## 기능 목적

CRM에 사전 등록된 회원이 SMS 인증 + 비밀번호 설정 + 가입 지점 선택 + 약관 동의까지 5단계로 앱 연동을 완료한다. 공개형 자체 회원 생성이 아니라 CRM 연동 완성 단계이며, 연동 직후 운동 온보딩(MA-127)으로 자동 진입한다.

## 주요 구성요소

### 5단계 진행 인디케이터

| 단계 | 화면 | 입력 |
|---|---|---|
| 1 / 5 | 연락처 입력 | 전화번호 또는 이메일 |
| 2 / 5 | SMS 인증 | 6자리 인증번호 (3분 유효) |
| 3 / 5 | 비밀번호 설정 | 8~16자 + 영문 + 숫자 + 특수문자 |
| 4 / 5 | 가입 지점 선택 | CRM 가입 지점 카드 |
| 5 / 5 | 약관·동의 | 필수 + 선택 동의 |

### 1단계 — 연락처 입력

| 항목 | 설명 |
|---|---|
| 전화번호 / 이메일 토글 | 회원 등록 식별자 선택 |
| 입력 필드 | 즉시 형식 검증 |
| 다음 CTA | CRM 일치 시 활성 |
| 안내 | "센터에 등록된 연락처 또는 이메일을 입력해 주세요" |

### 2단계 — SMS 인증

| 항목 | 설명 |
|---|---|
| 인증번호 | 6자리 OTP |
| 타이머 | 3분 카운트다운 |
| 재발송 | 30초 후 활성 |

### 3단계 — 비밀번호 설정

| 항목 | 설명 |
|---|---|
| 비밀번호 | 8~16자 (마스킹 + 표시 토글) |
| 비밀번호 확인 | 일치 검증 |
| 강도 표시 | 약함 / 보통 / 강함 |
| 규칙 안내 | 영문 / 숫자 / 특수문자 충족 체크 |

### 4단계 — 가입 지점 선택

| 항목 | 설명 |
|---|---|
| 지점 카드 | CRM 가입 모든 지점 |
| 카드 표시 | 지점명 / 주소 / 가입일 / 회원번호 |
| 선택 | 단일 시 자동, 다중 시 1개 선택 |
| 안내 | "가입 후 설정에서 변경 가능" |

### 5단계 — 약관·동의

| 항목 | 설명 |
|---|---|
| 전체 동의 | 일괄 토글 |
| 필수 약관 | 서비스 / 개인정보 / 위치기반 |
| 선택 약관 | 마케팅 SMS / 이메일 / 푸시 |
| 완료 CTA | 필수 약관 모두 동의 시 활성 |

## 권한 / RBAC (회원앱 role)

CRM에 사전 등록된 회원만 진입 가능. 직원 계정은 본 화면이 아니라 직원 탭 로그인(MA-001)으로 진입.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 1단계 입력 중 | 다음 CTA 비활성 |
| 1단계 CRM 미등록 | 인라인 에러 + 센터 문의 안내 |
| 2단계 인증 대기 | 타이머 카운트다운 |
| 2단계 5회 실패 | 10분 잠금 |
| 3단계 비밀번호 불일치 | 인라인 에러 |
| 4단계 지점 0개 | "가입 지점이 없습니다" |
| 5단계 필수 약관 미동의 | 완료 CTA 비활성 |
| 연동 완료 | 운동 온보딩 자동 라우팅 |

## 비즈니스 규칙

1. CRM에 사전 등록된 회원만 앱 연동이 가능하며, 미등록 연락처는 차단 후 1:1 문의로 안내한다.
2. SMS 인증번호 유효 시간은 3분이고, 재발송은 30초 경과 후 가능하다.
3. 5회 연속 인증 실패 시 10분 잠금이 적용된다.
4. 비밀번호는 8~16자 + 영문 + 숫자 + 특수문자 조합이 필수다.
5. 다중 지점에 가입된 회원은 1개 지점을 선택하며, 가입 후 설정에서 변경 가능하다.
6. 필수 약관(서비스/개인정보/위치기반) 미동의 시 완료 CTA가 비활성된다.
7. 회원 status가 hold 또는 withdrawn 상태면 연동이 차단된다.
8. 연동 완료 시점에 admin SCR-M004 회원 상세에 "앱 연동 완료 + app_linked_at" 배지가 즉시 노출된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-070 리드 관리 / SCR-M002 회원 등록 / SCR-M004 회원 상세 / SCR-M005 회원 이관 |
| 데이터 흐름 | admin → client (CRM 회원 데이터 조회) + client → admin (앱 연동 완료 플래그) |
| 정책 출처 | "CRM 선등록 회원만 앱 연동 가능" — admin 운영 정책 |
| 연동 시나리오 | 60_admin_연동/C1_회원가입_CRM연동 |

**admin → client 영향**

- SCR-M002에서 회원 등록 → 회원이 앱 연동 가능 (status=lead → active)
- SCR-M005 회원 이관 / 지점 변경 시 가입 지점 선택 옵션 변경
- 회원 status=hold / withdrawn 상태에서는 연동 차단

**client → admin 영향**

- 연동 완료 시 SCR-M004 회원 상세에 "앱 연동 완료" 배지 즉시 노출
- 연동 실패(CRM 미등록)는 SCR-153 1:1 문의 진입 안내
