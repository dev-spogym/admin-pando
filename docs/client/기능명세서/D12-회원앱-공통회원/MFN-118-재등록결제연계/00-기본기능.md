## 기능 목적

회원이 MA-138 재등록 추천에서 선택한 플랜을 MA-140 결제 화면으로 자동 연계하여 재등록을 완료한다. 결제 성공 시 D-day 트리거가 종료되고 회원권이 갱신되며, 잔여 PT/OT 회차가 합산 또는 신규 처리(상품 정책)된다.

## 주요 구성요소

### 진입점

| 진입점 | 설명 |
|---|---|
| MA-138 추천 플랜 | [이 플랜으로 결제] 카드 |
| 알림 푸시 | D-day 트리거 알림 → MA-138 → 결제 |
| 만료 후 AT-RISK | AT-RISK 케어 알림 → MA-138 |

### 결제 화면 진입 (MA-140)

| 항목 | 자동 셋업 |
|---|---|
| 상품 정보 | 추천 플랜 카드 그대로 |
| 쿠폰 | 자동 추천 쿠폰 적용 |
| 마일리지 | 보유 P 자동 표시 |
| 멤버십 등급 할인 | 자동 적용 |
| 결제 동의 / 결제하기 | 회원이 마무리 |

### 결제 성공 후 처리

| 처리 | 설명 |
|---|---|
| D-day 트리거 종료 | 만료 알림·홈 배너 자동 제거 |
| 회원권 갱신 | 시작일 + 만료일 갱신 (admin SCR-M002) |
| 잔여 회차 합산 / 신규 | 상품 정책에 따라 처리 |
| 영수증 진입 | MA-142 자동 진입 |
| 마일리지 적립 | 결제 후 N일 후 자동 |

회원 본인만 진입.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 결제 진입 | MA-140 자동 셋업 |
| 결제 처리 중 | 로딩 |
| 결제 성공 | D-day 종료 + MA-142 진입 |
| 결제 실패 | 재시도 + 다른 플랜 안내 |
| 회원권 갱신 완료 | 홈 배너 자동 제거 |

## 비즈니스 규칙

1. MA-138 카드 → MA-140 결제 → 성공 시 D-day 트리거 자동 종료.
2. 결제 성공 시 admin SCR-M002 회원권 갱신, SCR-S001 매출 즉시, SCR-M009 등급 재산정.
3. 잔여 PT/OT 회차 합산/신규 처리는 상품 정책(admin SCR-P001)에 따라 결정.
4. AT-RISK 케어 회원의 재등록은 별도 카테고리로 admin에 분류.
5. 결제 실패 시 다른 플랜 또는 재시도 안내.
6. 결제 완료 영수증(MA-142)에 "재등록" 카테고리 표시.
7. 마일리지·쿠폰·등급 할인은 결제 단계에서 자동 적용된다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-S003 / SCR-S001 / SCR-M002 회원권 / SCR-M009 등급 / SCR-072 자동 알림 |
| 데이터 흐름 | client → admin (결제 → 회원권 갱신 / D-day 종료) |
| 정책 출처 | 잔여 회차 합산/신규 정책 / 등급 산정 = admin |
| 연동 시나리오 | 60_admin_연동/C6_이용권_Dday_트리거 |

**client → admin**: 결제 성공 → SCR-M002 회원권 갱신 + SCR-S001 매출 + SCR-M009 등급 재산정 + D-day 트리거 종료
