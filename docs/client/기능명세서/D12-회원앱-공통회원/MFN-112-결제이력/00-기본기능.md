## 기능 목적

회원이 본인 결제 내역(이용권 / PT 패키지 / 골프 레슨 / 부가옵션 / 마켓 결제)을 월별로 조회하고, 영수증 진입 / 환불 신청 / 주문 상세 진입을 한 화면에서 처리한다.

## 주요 구성요소

### 상단 필터

| 필터 | 옵션 |
|---|---|
| 기간 | 이번 달 / 지난 3개월 / 6개월 / 1년 / 사용자 지정 |
| 상품 카테고리 | 전체 / 이용권 / PT / 골프 / 부가옵션 / 마켓 |
| 결제 상태 | 전체 / 결제 완료 / 환불 진행 / 환불 완료 / 취소 |

### 합계 요약 카드 (상단)

| 항목 | 표시 |
|---|---|
| 선택 기간 결제 합계 | 큰 숫자 |
| 환불 합계 | 회색 숫자 |
| 마일리지 적립 합계 | 마일리지 표기 |

### 월별 그룹 헤더

YYYY년 MM월 + 월 합계 결제액 + 월 환불액.

### 결제 카드

| 항목 | 표시 |
|---|---|
| 결제일 | YYYY-MM-DD HH:MM |
| 상품명 + 옵션 요약 | "PT 16회 · 김도윤 강사" |
| 결제수단 | 카드사 + 끝 4자리 또는 페이 |
| 결제액 | 정가 + 할인가 |
| 사용 마일리지 / 쿠폰 | 차감 표기 |
| 상태 칩 | 완료(success) / 환불 진행(warning) / 환불 완료(neutral) / 취소(error) |
| 액션 | [영수증 → MA-142] / [주문 상세 → MA-403] / [환불 신청 → MA-404] |

## 권한 / RBAC (회원앱 role)

회원 본인 결제 이력만 조회.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 결제 있음 | 월별 그룹 카드 |
| 빈 상태 | 일러스트 + 스토어 진입(MA-134) |
| 환불 진행 중 | 카드 강조 + 진행 상태 |
| 필터 결과 0건 | "이 조건의 결제 없음" + 필터 해제 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 회원 본인 결제 이력만 조회 가능.
2. 환불 가능 기간·환불 비율은 admin 본사 정책에 따른다.
3. 환불 신청은 회원 → admin SCR-S007 환불 관리 큐로 전달, 매니저 승인 후 처리.
4. admin SCR-S003 결제 처리에서 수기 결제 등록 시 MA-133에 즉시 반영.
5. 환불 승인 시 카드 상태가 "환불 진행" → "환불 완료"로 자동 전환되며 영수증에 반영.
6. 마일리지 적립은 admin 본사 정책에 따라 결제 후 N일 후 자동 적립.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-S003 결제 처리 / SCR-S001 매출 현황 / SCR-S007 환불 관리 |
| 데이터 흐름 | 양방향 (결제 / 환불) |
| 정책 출처 | 환불 가능 기간·비율 = admin 본사 정책 |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**client → admin**: 회원 결제 → SCR-S003 즉시 등재 + SCR-S001 매출 집계
**admin → client**: SCR-S007 환불 승인 → 카드 상태 변경
