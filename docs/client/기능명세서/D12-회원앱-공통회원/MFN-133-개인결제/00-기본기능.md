## 기능 목적

FC 안내나 현장 요청에 따라 회원이 정해진 상품이 아닌 개별 결제 항목(락커 연장 / 사우나 추가권 / 굿즈 등)을 직접 입력하여 결제한다. 추천 항목 카드 또는 직접 입력으로 결제 항목을 만든 뒤 MA-140 결제 화면으로 진입한다.

> **개인결제 vs 결제링크 구분**: 개인결제(MA-141)는 회원이 본인이 결제 항목을 만든다(모든 옵션 변경 가능). 결제링크(MA-140 진입)는 직원이 admin SCR-S016에서 만들어 발송한 항목으로 회원은 상품/금액/할인 변경 불가.

## 주요 구성요소

### 결제 유형 선택

| 유형 | 설명 |
|---|---|
| 추천 항목 선택 | 락커 / 운동복 / 수건 / 사우나 / 굿즈 등 미리 정의된 카드 |
| 직접 입력 | 상품명 + 금액 회원 직접 입력 |

### 추천 항목 카드 (8~10개)

| 카드 | 가격 |
|---|---|
| 락커 1개월 연장 | 30,000원 |
| 락커 3개월 연장 | 80,000원 |
| 운동복 추가 | 5,000원 |
| 수건 1회 추가 | 1,000원 |
| 사우나 1회 추가 | 5,000원 |
| 사우나 10회권 | 40,000원 |
| 헬스 굿즈 (셰이커) | 8,000원 |
| 단백질바 묶음 | 12,000원 |

### 직접 입력 폼

| 항목 | 설명 |
|---|---|
| 상품명 | 회원 직접 입력 |
| 금액 | 숫자 입력 + 콤마 자동 |
| 메모 (선택) | FC 안내 메모 |
| 주의 안내 | "결제 후 운영 승인 필요할 수 있습니다" |

### 하단 결제 CTA

선택 또는 입력 완료 시 활성 → MA-140 결제 진입.

## 권한 / RBAC (회원앱 role)

회원 본인 결제. FC가 회원 옆에서 안내하면서 사용 가능.

## 비즈니스 규칙

1. 추천 항목은 admin SCR-S003 매핑된 사전 정의 카테고리 (락커/사우나/굿즈/운동복 등) 결제로 자동 분류된다.
2. 직접 입력 결제는 admin SCR-S003에 미분류 카테고리로 등재되며 운영 검수가 필요할 수 있다.
3. 직접 입력 시 운영 승인 필요 여부 안내가 표시된다.
4. 본 화면은 결제 항목 작성 단계이며 실제 결제·합계·할인은 MA-140에서 처리된다.
5. 결제링크와 달리 본 화면에서는 회원이 모든 옵션을 변경할 수 있다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-S003 결제 처리 (수기 결제 미러) |
| 데이터 흐름 | client → admin (회원 임의 결제 → admin 매출) |
| 정책 출처 | 직접 입력 결제 운영 승인 정책 = admin |
| 연동 시나리오 | 60_admin_연동/C4_결제_매출_집계 |

**client → admin**

- 추천 항목 결제 → 자동 분류 (락커/사우나/굿즈/운동복)
- 직접 입력 결제 → 미분류 카테고리 + 운영 검수 큐
