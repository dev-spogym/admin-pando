## 기능 목적

회원이 골프 타석을 시간대별로 예약하고 상세 정보를 확인한다. 타석 상태 표시 + 타석 선택 + 시간대 + 만석 시 대기 등록 + 레슨권/이용권 구매 CTA + 내 골프 예약 일정. 강사 없이 타석만 이용하는 흐름은 즉시 확정.

## 주요 구성요소

### 타석 그리드

| 항목 | 표시 |
|---|---|
| 타석 번호 | 1~N번 |
| 상태 | 빈 / 사용 중 / 예약됨 / 점검 중 |
| 시간대 슬라이더 | 30분 단위 |

### 예약 정보 섹션 (예약 후)

| 항목 | 표시 |
|---|---|
| 예약 상태 | 확정 / 취소 / 대기 배지 |
| 예약 번호 | 고유 식별자 |
| 예약 일시 | 날짜 + 시작-종료 |
| 타석 번호 | 배정 타석 |
| 이용 시간 | 총 시간 (예: 1시간) |
| 이용권 | 차감 이용권 종류 + 잔여 |

### 이용 안내 섹션

| 항목 | 표시 |
|---|---|
| 센터 위치 | 타석 위치 |
| 준비물 | 필요 용품 |
| 주의사항 | 이용 규칙·취소 정책 |

### 취소 정책 안내

| 항목 | 설명 |
|---|---|
| 무료 취소 기한 | 예약일 X시간 전 |
| 유료 취소 기한 | 기한 후 이용권 차감 |

### 액션 버튼

| 버튼 | 조건 | 동작 |
|---|---|---|
| 예약하기 | 타석 빈 + 이용권 보유 | 즉시 확정 |
| 대기 등록 | 만석 | MA-124 진입 |
| 예약 취소 | 확정 + 취소 가능 기한 | 취소 처리 |
| 레슨권 구매 | 이용권 미보유 | 결제 진입 |

## 권한 / RBAC (회원앱 role)

회원 본인의 골프 예약만 조회·관리. 별도 계정 구분 없이 회원 단일 계정.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 예약 확정 (취소 가능) | 정보 + 취소 버튼 |
| 예약 확정 (취소 불가) | 정보만 표시 |
| 취소된 예약 | "취소된 예약입니다" |
| 이용 완료 | "이용이 완료된 예약입니다" |
| 만석 | 대기 등록만 활성 |
| 이용권 미보유 | 레슨권 구매 CTA |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 타석 예약은 강사 없이 즉시 확정되며, 강사 레슨은 MFN-132에서 처리.
2. 이용권 차감 시점은 이용 시작 시점이며, 무료 취소 기한 내 취소는 차감 없음.
3. 유료 취소 기한 후 취소는 이용권이 차감되거나 페널티 부과(센터 설정).
4. 만석 타석은 [대기 등록] → MA-124 진입.
5. 이용권 미보유 회원은 [레슨권 구매] CTA로 결제 화면 진입.
6. admin SCR-054 골프 타석 운영 변경 시 즉시 반영.

| 항목 | 내용 |
