## 기능 목적

회원앱의 7개 카테고리 알림(예약 / 이용권 / 리워드 / 공지 / AT-RISK / 수업·후기 / 부가시설)을 통합 조회하고, 카드 선택 시 정의된 라우팅 표에 따라 대상 화면으로 즉시 이동한다.

## 주요 구성요소

### 상단 헤더

| 항목 | 표시 |
|---|---|
| 제목 | "알림" |
| 우측 액션 | [모두 읽음 처리] |
| 미읽음 카운트 배지 | 헤더 우상단 |

### 탭

| 탭 | 설명 |
|---|---|
| 전체 | 모든 알림 |
| 미읽음 | 미읽음만 |

### 카테고리 필터 칩 (가로 스크롤)

| 칩 | 색상 |
|---|---|
| 예약 | primary |
| 이용권 | warning |
| 리워드 | success |
| 공지 | neutral |
| AT-RISK | danger |
| 수업·후기 | secondary |
| 부가시설 | info |

### 알림 카드

| 영역 | 표시 |
|---|---|
| 좌측 | 카테고리 아이콘 (색상) |
| 중앙 상단 | 카테고리 칩 + 제목 1줄 |
| 중앙 본문 | 본문 1~2줄 요약 |
| 중앙 하단 | 발생 시간 ("5분 전" / "어제" / "MM-DD") |
| 우측 상단 | 미읽음 점 |
| 우측 하단 | 1차 액션 버튼 |

### 카테고리별 라우팅 표 (정책 1.10)

| 카테고리 | 트리거 | 라우팅 |
|---|---|---|
| 예약 | 예약 확정/변경/노쇼 임박 | MA-122 |
| 이용권 | 만료 D-14/D-7/D-1, 잔여 ≤ 3 | MA-138 |
| 리워드 | 마일리지 / 배지 / 등급 상승 | MA-136 / MA-137 / MA-500 |
| 공지 | 센터 이벤트 / 휴무 | MA-152 |
| AT-RISK | 4주 미방문 / 만료 후 미재등록 | MA-138 |
| 수업·후기 | 수업 시작 30분 전 / 후기 요청 | MA-126 / MA-121 |
| 부가시설 | 사우나 / 락커 / 굿즈 만료 | MA-131 / MA-151 |

### 스와이프 액션

| 방향 | 동작 |
|---|---|
| 우측 | 읽음 처리 |
| 좌측 | 보관 처리 (7일 후 자동 보관과 동일) |

## 권한 / RBAC (회원앱 role)

회원 본인 알림만 조회. 발송 트리거는 admin 정책 + MA-155 회원 ON/OFF 조합 결정.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 알림 있음 | 카드 리스트 |
| 미읽음 강조 | 진하게 + 미읽음 점 |
| 빈 상태 (전체) | "새로운 알림이 없어요" |
| 빈 상태 (미읽음) | "모든 알림을 확인했어요" |
| 카테고리 필터 0건 | "이 카테고리 알림 없음" + 필터 해제 |
| 로딩 | 스켈레톤 |
| 라우팅 실패 | "이동할 수 없는 알림입니다" 토스트 |

## 비즈니스 규칙

1. 7개 카테고리 라우팅 매핑은 회원앱 정책 1.10 고정.
2. 발송 트리거는 admin SCR-072 자동 알림 + MA-155 회원 카테고리 ON/OFF 조합으로 결정.
3. AT-RISK 카테고리 OFF 시 푸시는 차단되지만 알림센터 카드는 노출.
4. OS 푸시 알림 탭 시 카테고리에 맞는 화면으로 다이렉트 라우팅(MA-150 미경유), MA-150에서도 자동 읽음.
5. 좌측 스와이프(보관)는 7일 후 자동 보관과 동일 동작.
6. SCR-085 공지 발행 → 공지 카테고리 알림 자동 발송.

| 항목 | 내용 |
