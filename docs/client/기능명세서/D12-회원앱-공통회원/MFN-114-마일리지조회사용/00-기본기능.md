## 기능 목적

회원의 마일리지 보유 / 적립 내역 / 사용 내역 / 사용처를 한 화면에서 본다. 적립 트리거(루틴 완료, 출석, 후기, 친구 초대 등)와 사용처(재등록 / 리커버리 / 굿즈 / 마켓 결제)를 명확히 안내하며 등급 보너스를 함께 표시한다.

## 주요 구성요소

### 상단 보유 카드

| 항목 | 표시 |
|---|---|
| 보유 마일리지 | 큰 숫자 |
| 만료 예정 (30일 내) | 회색 작은 숫자 + "30일 이내 만료" |
| 등급별 적립률 | "VIP +20% 적립" 등 |

### 탭

| 탭 | 내용 |
|---|---|
| 적립 내역 | 트리거별 분류 |
| 사용 내역 | 사용처별 분류 |
| 적립 기준 | 트리거별 단가 카드 |
| 사용처 | 사용처별 카드 |

### 적립 내역 (트리거 단가 예시)

| 트리거 | 단가 |
|---|---|
| 운동 루틴 완료 | 50P |
| 출석 5회 연속 | 200P |
| 체성분 측정 | 100P |
| 후기 작성 | 100P |
| 친구 초대 ① 가입 | 5,000P |
| 친구 초대 ② 첫 결제 | 5,000P |
| 친구 초대 ③ 첫 후기 | 3,000P |

각 항목 카드: 일자 + 트리거명 + 적립 P + 누적 P.

### 사용 내역 (사용처별)

| 사용처 | 차감 |
|---|---|
| 재등록 결제 | -P |
| 리커버리 (스트레칭/사우나) | -P |
| 굿즈 교환 | -P |
| 마켓 결제 | -P |

### 월별 그래프

최근 6개월 적립/사용 막대 차트.

### 적립 기준 카드 (탭)

각 트리거별 단가 안내. admin 운영 정책 세트 기준.

### 사용처 카드 (탭)

| 재등록 결제 | MA-138 |
| 리커버리 | MA-141 |
| 굿즈 교환 | (외부 운영) |
| 마켓 결제 | MA-140 |

## 권한 / RBAC (회원앱 role)

회원 본인 마일리지만 조회.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 보유 있음 | 모든 카드 활성 |
| 보유 0P | "마일리지를 적립해 보세요" + 적립 기준 강조 |
| 만료 임박 | 만료 카드 빨강 강조 |
| 적립 내역 0건 | "아직 적립 이력 없음" |
| 그래프 데이터 부족 | 최소 1개월 적립 후 활성 |

## 비즈니스 규칙

1. 회원 본인 마일리지만 조회 가능.
2. 마일리지 사용 단위는 100P, 만료는 1년 미사용 시.
3. 적립 단가는 admin SCR-074 마일리지 관리 정책에 따른다.
4. 친구 초대 적립은 단계별(가입 → 첫 결제 → 첫 후기) 검증 7일 후 자동 처리.
5. 등급별 적립률(VIP +20% 등)은 admin 본사 정책 기반.
6. 만료 30일 전 자동 알림(SCR-072) 발송.
