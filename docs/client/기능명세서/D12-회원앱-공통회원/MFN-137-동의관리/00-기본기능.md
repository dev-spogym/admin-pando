## 기능 목적

회원이 필수 동의 상태(조회 전용)와 선택 동의(마케팅 SMS / 이메일 / 푸시) ON/OFF를 한 화면에서 관리한다. 변경 즉시 저장되며, 최근 변경일이 함께 표시되어 이력 추적이 가능하다.

## 주요 구성요소

### 필수 동의 섹션 (조회 전용)

| 항목 | 표시 |
|---|---|
| 서비스 이용약관 | 동의 완료 + 동의일 |
| 개인정보 처리방침 | 동의 완료 + 동의일 |
| 위치기반 서비스 약관 | 동의 완료 + 동의일 |

각 항목 우측 화살표 → MA-156.

### 선택 동의 섹션 (변경 가능)

| 항목 | 토글 | 보조 텍스트 |
|---|---|---|
| 마케팅 SMS 수신 | ON/OFF | 이벤트/프로모션/신상품 |
| 마케팅 이메일 수신 | ON/OFF | 동일 |
| 마케팅 푸시 수신 | ON/OFF | 앱 푸시로 마케팅 |

각 변경 시: 즉시 저장 / 최근 변경일 표시 / 토스트.

### 안내 카드

| 항목 | 설명 |
|---|---|
| 마케팅 동의 효과 | "동의 시 멤버 한정 혜택 / 이벤트 안내" |
| 동의 철회 | "언제든 철회 가능, 서비스 이용에 영향 없음" |

## 권한 / RBAC (회원앱 role)

회원 본인 동의만 관리. 필수 동의는 변경 불가(탈퇴 외 방법 없음).

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 모든 항목 표시 |
| 변경 처리 중 | 토글 로딩 |
| 변경 실패 | 토스트 + 원래 상태 복원 |

## 비즈니스 규칙

1. 필수 동의는 변경 불가, 회원 탈퇴(MA-158)로만 철회 가능.
2. 선택 동의(마케팅 SMS/이메일/푸시) 변경 시 즉시 저장 + 변경일 갱신.
3. 회원 마케팅 동의 변경은 admin SCR-072 발송 결정에 즉시 반영.
4. 변경 이력은 admin SCR-M004 회원 상세에서 조회 가능.
5. 새 약관 추가 시 회원에게 동의 요청 모달 진입.
6. 동의 철회 시에도 서비스 이용에는 영향이 없다.

## admin 연동

| 항목 | 내용 |
|---|---|
| 연동 admin SCR | SCR-080 센터 설정 (정책) / SCR-M004 회원 상세 |
| 데이터 흐름 | 양방향 (선택 동의 → admin 발송 결정) |
| 정책 출처 | 필수 동의 변경 불가 / 선택 동의 = 회원 |
| 연동 시나리오 | 60_admin_연동/C7_알림_정책세트_라우팅 |
