# docs4 명세 ↔ 화면 정합성 감사 리포트

- 작성: 2026-05-29, `feature/docs4-sync` 브랜치
- 목적: Cmd+/ 화면설계서 패널(=docs4 명세)과 실제 화면의 불일치 식별. 개발자 혼동 제거.
- 방법: 도메인별 SCR마다 docs4 V1/V2 명세(UI구성/액션/핵심상태/권한/예외)와 page.tsx를 1:1 대조.
- 핵심 패턴: **docs4 이후 mock으로 새로 만든 화면은 정합성 높음. docs4 이전에 만들어진 실DB 연동 화면(회원목록·POS·결제·수업·근태·급여·리드·자동알림·권한·공지)이 옛 기준에 머물러 불일치 집중.**

> 주의: docs4는 읽기 전용. 이 리포트는 화면(src)을 명세에 맞추기 위한 작업 목록이다.

## High 심각도 (개발자 혼동 큼 / 핵심 구조 불일치) — 우선 처리

### D02 회원관리
- **SCR-M001 회원목록 상태탭**: 화면 6개(전체/활성/만료/미등록/홀딩/정지) vs 명세 8개(+예정/임박/탈퇴). '정지'는 명세상 상태값 아닌 플래그인데 탭으로 존재.
- **SCR-M001 세그먼트 자동판정**: 화면 자동분류 로직(신규=30일 등)이 명세 정의와 전부 상이.
- **SCR-M002 회원등록**: 화면은 결제 없이 등록 저장. 명세는 "첫 결제 완료=회원등록 확정"(결제 단계 필수).
- **SCR-M005 이관**: 명세의 귀속 재배정 표(소속/이용/매출귀속/정산/담당/인센티브) 누락.
- **SCR-M009 등급명**: 화면 VIP/VVIP vs 명세 플래티넘/다이아몬드.
- **SCR-M010 세그먼트**: 자동 5종 vs 명세 7종, 조건 빌더(AND/OR) 없음(단일 select).

### D03 매출관리
- **SCR-S002 POS 카테고리 탭**: 화면 이용권/PT/GX/기타 vs 명세 회원권/수강권/락커/운동복/일반.
- **SCR-S003 결제처리**: 혼합결제·상품별 배분·내부승인번호·VAN/POS·계약금/잔액/이용권개시·지점귀속 등 핵심 구조 대부분 미구현(단일 결제수단만).
- **SCR-S012 결제취소/부분환불**: 혼합결제 환불 분해표·수납행/상품환불 구분·복원요약 미구현. AppLayout 미적용(레이아웃 단독).

### D04 수업관리
- **SCR-C001 캘린더**: 강습세션유형(PT/GX/골프/기타) 축 전면 누락, EventType에 "골프" 없음/"개인레슨" 임의 추가. "스케줄 일괄변경" 버튼 동작 안 함.
- **SCR-C002 수업관리**: 화면이 "수업 목록 관리"가 아니라 "수업 정의 CRUD" 구조. 유형값(GROUP/PERSONAL/SEMI)·상태필터·예약현황 컬럼 불일치.
- **SCR-C005 그룹수업현황**: 운영 액션(정원조정·취소진입·회원명단) 전무, 조회 전용.
- **SCR-C007 횟수관리**: 역할 권한 분기 없이 조정/차감 버튼 상시 노출.
- **SCR-C008 페널티**: 명세는 "늦은취소 페널티 없음"인데 화면에 '지각취소' 유형 존재(정책 상충).
- **SCR-C009 일정요청**: 요청유형(변경/취소)·상태 6종 축이 화면(분류축/3종)과 근본적으로 다름.
- **SCR-C010 운동프로그램**: 회원 배정 기능 부재 + 수정 시 동작목록 유실 버그.

### D05 상품관리
- **SCR-P002 상품등록 상품구분**: 화면 레슨/이용/락커/판매 vs 명세 회원권/수강권/락커/운동복/일반.
- **SCR-P005/P006/P007/P008**: 카탈로그/비교/재고/시즌가 모두 seed·mock 스텁 — 명세의 분류축·동적선택·CRUD·검증·빈/로딩 상태 미구현. P008 등록/수정/삭제 무동작.

### D06 시설관리
- **SCR-055 상품재고관리**: 라우트(`/facility/inventory`) 자체 부재.
- **라우트 매핑 충돌**: docs4는 SCR-059를 `/rooms`로 명시하나 코드는 `/asset-management`, `/rooms`는 SCR-053 단독.
- **SCR-051 사물함배정**: 명세상 포함돼야 할 고정 물품 락커(SCR-I005) 탭 누락.
- **SCR-052 RFID**: 카드 목록 하드코딩(persist 안 됨), 형식/중복 검증 없음.
- **SCR-054 골프타석**: 타임테이블·월간 캘린더·예약상세 모달 미구현(실시간 보드만).

### D07 직원관리
- **SCR-064 급여관리**: 급여 정책 템플릿 패널(매출/수업 산식, DLG-064-003) 통째 누락. 컬럼(급여형태·수수료) 불일치. DLG-064-001 편집·확정취소 없음.
- **SCR-065 급여명세서**: 발송상태·발송일시·수신확인 컬럼 및 개별/일괄 발송·재발송·무효 기능 부재(이메일 "추후 지원").
- **SCR-063 근태**: 출처·보정이력 컬럼, 수동 보정 기능, 날짜별 조회 누락. 상태값 불일치.
- **SCR-062 퇴사**: 다중 직원 선택 불가(단일만).

### D08 마케팅
- **SCR-070 리드**: 가입경로 9종/문의유형 분리 불일치, 칸반 상태 라벨 임의변경, 회원전환 CTA 없음.
- **SCR-072 자동알림**: 본사 step/지점 step 구조(만료정책 3탭·본사필수ON잠금) 부재 — 평면 토글 13종. 권한 분기 없음.
- **SCR-072A 자동알림 운영현황**: 운영현황 탭(발송건수/성공률/실패사유) 자체가 없음.
- **SCR-075 전자계약**: 계약유형(회원/근로계약)·계약대상검색·템플릿·이력탭·원격서명 부재(현장 결제 위저드로 구현).

### D09 설정관리
- **SCR-081 권한설정**: 기본 역할 6종만(명세 8종 — superAdmin·trainer 누락). 6종 민감기능 식별·저장차단 미구현. owner 라벨 "센터장" vs 명세 "Owner(지점장)".
- **SCR-085 공지사항**: 게시 대상(역할)·게시 기간·상태 필터·키워드 검색·예약 발행 전면 누락.

### D11 통합운영
- **SCR-I004/I005 라우트↔화면 뒤바뀜**: `/clothing-locker`가 실제로는 고정 물품 락커(I005) 내용. 명세의 옷 락커 운영(I004: 당일 옷락커 그리드 + 미배정 회원 패널 + 출석 연동)은 어느 라우트에도 없음. (참고: 본 동기화 작업의 docs4Registry는 I004→/clothing, I005→/clothing-locker로 매핑했으나 docs4 명세 URL은 I004→/clothing-locker, I005→/locker/management)

## 권고
1. **High부터 도메인 단위로 화면을 명세에 맞춰 수정** (라벨/탭/상태/컬럼 정합 → 누락 UI 추가 → 권한·예외).
2. **라우트 매핑 불일치(D06 SCR-055/059, D11 I004/I005)는 별도 결정 필요** — docs4 명시 URL을 따를지, 현재 코드 라우트를 유지하고 docs4Registry 매핑만 정합화할지 정책 판단.
3. 일부 항목은 "명세가 앞서 있고 기능 자체가 미구현"(혼합결제, 본사 step, 급여 정책 템플릿 등) — 단순 퍼블리싱이 아니라 기능 개발 범위. V1/V2 범위 확정 후 진행.
