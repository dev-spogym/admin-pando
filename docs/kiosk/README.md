## 목적

`kiosk-pando`는 센터 입구에 설치되는 셀프 체크인 키오스크다. 회원은 출석, 락커 번호 확인, 이용권 조회, 골프 타석 예약, 공지 확인 등을 직접 처리하고, 직원/관리자도 동일 단말에서 출퇴근 인증과 운영 점검을 수행한다.

본 기획서는 `admin-pando`의 통합 운영 정책 중 키오스크에서 직접 노출되는 영역만 추려 키오스크 UX 기준으로 재구성한 문서다.

## ID 체계

| 범주 | 코드 | 설명 |
|---|---|---|
| 업무 코드 | `ATT` / `INF` / `GLF` / `PRK` / `ADM` / `SET` | 업무분류표 도메인 |
| 화면 코드 | `KIO-NNN` | 1xx 출석 · 2xx 결과 · 3xx 회원정보 · 4xx 관리자 · 5xx 골프 · 6xx 주차 · 7xx 매점/결제 |
| 그룹 폴더 | `A1` ~ `A7` | 화면설계서 그룹 (운영 흐름 기준) |

## 권한/역할 적용 원칙

- 키오스크 단말은 무인 상태로 동작하며, 인증 결과로 회원/직원/관리자 분기를 수행한다.
- **회원**: 전화번호 / QR / RFID / 얼굴 / 바코드 중 지점 설정값에 따라 인증
- **직원**: 같은 입력 화면에서 인증 결과로 자동 판별. 직원 출퇴근 허용 OFF 지점에서는 차단
- **관리자**: 숨김 진입 후 PIN 인증
- 관리자웹 권한 키(`superAdmin / primary / owner / manager / fc / staff / readonly`)와 별도로, 키오스크는 단말 단위 PIN으로 운영 권한을 분리한다.

## admin / client 와의 관계

키오스크는 admin이 정의한 통합 운영 정책의 **현장 실행 채널**이다. admin / client / 키오스크 기획서는 의도적으로 분리되어 있으며, 채널 간 연동 매핑은 `KIOSK-기획연계정의서.md` 단일 문서에서 관리한다.

| 영역 | 원천 채널 | 키오스크 역할 |
|---|---|---|
| 출석 정책 | `admin/화면설계서/D11-통합운영/SCR-I001-통합출석관리` | 단말 입력/결과 표시 |
| 키오스크 설정 | `admin/화면설계서/D11-통합운영/SCR-I002-키오스크설정` | 설정값 수신 |
| 통합운영 기능 | `admin/기능명세서/통합운영_IOT_헬스.md` | 운영 원칙 준수 |
| 골프 타석 운영 | `admin/화면설계서/D06-시설관리/SCR-054-골프타석관리` | 셀프 예약 채널 |
| 회원 골프 예약 | `client/화면설계서/D12-회원앱/SCR-MA-123-골프예약상세` | 동일 데이터 원천 |

## 권장 개발 우선순위

| 우선순위 | 범위 | 이유 |
|---|---|---|
| P0 | 얼굴 인식 출석 실연동 | 키오스크 본 기능 |
| P1 | 락커 번호 전달 3안 (영수증/앱/신발장 밴드) | 현장 운영 핵심 |
| P2 | 골프 타석 예약 | 셀프 서비스 확대 |
| P3 | 주차 등록 버튼 | 빌딩별 분기, 난이도 낮음 |
| P4 | 오프라인 큐/복구 | 운영 안정성 |
