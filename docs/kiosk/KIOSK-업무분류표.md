# kiosk-pando 업무분류표

> 문서 버전: v0.1
> 작성일: 2026-05-04
> 목적: `admin-pando` 기획 구조를 기준으로 `kiosk-pando`의 업무 범위와 신규 확장 범위를 코드형 목차로 정리

---

## 문서 기준

- 출석/키오스크 정책은 `admin-pando`의 통합운영 문서를 기준으로 정리한다.
- 현재 `kiosk-pando`에 구현된 화면은 비고에 `기존`으로 표시한다.
- 골프 타석 예약, 주차 등록은 본 문서 기준 `신규` 범위로 본다.

---

### 01. 출석 및 입장 관리 (ATT)

|---|---|---|

| ATT-01-04 | 얼굴 인식 결과로 회원 식별 | 외부 인식 엔진/API 연동 |
| ATT-02 | 다중 인증 체크인 | QR / RFID / 얼굴 / 전화번호 / 바코드 |

| ATT-03 | 출석 결과 처리 | 성공/실패 공통 |

| ATT-04-05 | 신발장 번호 안내 및 밴드 수령 유도 | 신규, 신발장-밴드-옷락커 동일번호 정책 |

| ATT-05 | 락커 번호 전달 방식 | 신규 |
