# kiosk-pando 업무분류표

> 문서 버전: v0.4
> 작성일: 2026-05-20
> 기준: 0508 기능코드 보존 + 0518 kiosk 변경표 반영

---

## 문서 기준

- 0508에 존재하던 기능코드는 기존 의미를 유지한다.
- 기능 의미가 바뀐 항목은 기존 코드를 재사용하지 않고 삭제+추가 또는 코드이동으로 처리한다.
- `KINF`는 0518 기준 `MBI`로 코드이동한다. 명칭과 의미가 같으므로 이동으로 본다.
- `ATT-05`, `SHP-01`, `SHP-02`, `KSET-01~06`은 0518 기준 삭제 범위로 본다.
- 설정값 원천은 kiosk 자체 `KSET`이 아니라 admin `SCR-082-키오스크설정`, `SCR-082A-키오스크 IoT 설정`, `SCR-083-IoT 출입 관리` 및 관련 운영 화면이다.

## 삭제/축소 처리

| 기존 코드 | 처리 | 사유 |
|---|---|---|
| ATT-05, ATT-05-01~03 | 삭제 | 락커 전달 방식은 ATT-04 후처리 하위 정책으로 흡수 |
