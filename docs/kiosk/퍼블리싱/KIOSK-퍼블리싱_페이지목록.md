# kiosk-pando 퍼블리싱 페이지목록

> 문서 버전: v0.1
> 작성일: 2026-05-04
> 목적: `kiosk-pando`를 퍼블리싱 관점에서 화면 단위로 분해해 작업 범위와 우선순위를 고정

---

## 1. 문서 기준

- 이 문서는 기획서를 퍼블리싱 가능한 페이지 목록으로 쪼갠 문서다.
- 실제 API, DB, 설정 키명은 다루지 않는다.
- `기존`은 현재 프로젝트에 UI가 있는 상태, `보강`은 UI는 있으나 상태/분기가 더 필요한 상태, `신규`는 아직 별도 퍼블리싱이 필요한 상태를 뜻한다.
- `상태형 화면`은 별도 route보다 기존 화면 안의 상태 분기로 처리하는 것을 우선 기준으로 삼는다.

---

## 2. 퍼블리싱 범위 요약

| 그룹 | 화면 수 | 상태 |
|---|---:|---|
| 메인/출석 | 7 | 기존 + 보강 |
| 결과/락커 전달 | 4 | 보강 |
| 회원 정보 | 5 | 기존 + 보강 |
| 골프 예약 | 4 | 신규 |
| 주차 등록 | 1 | 신규 |
| 관리자 | 2 | 기존 |
| 매점/결제 | 2 | 기존 |

## 3. 페이지 목록

### 3.1 메인 / 출석

| 화면 코드 | 구분 | 권장 경로 | 상태 | 목적 |
|---|---|---|---|---|
| KIO-001 | route | `/` | 기존 | 대기 화면, 체크인 수단 선택, 보조 메뉴 진입 |
| KIO-101 | route | `/check-in/qr` | 기존 | QR 체크인 |
| KIO-102 | route | `/check-in/rfid` | 기존 | RFID/NFC 체크인 |
| KIO-103 | route | `/check-in/face` | 보강 | 얼굴 인식 체크인 |
| KIO-104 | route | `/check-in/phone` | 기존 | 전화번호 체크인 |
| KIO-105 | route | `/check-in/barcode` | 기존 | 바코드 체크인 |

#### KIO-001 대기 화면

| 항목 | 내용 |
|---|---|
| 목적 | 첫 진입 화면에서 회원이 체크인 수단을 빠르게 선택한다 |
| 핵심 영역 | 좌측 로고/환영 문구/보조 메뉴, 우측 실시간 얼굴 인식 캠, 하단 QR/전화번호 체크인 도크, 공지 배너, 시계 바 |
| 필수 상태 | 설정 로딩, 정상, 키오스크 비활성, 공지 노출, 공지 없음 |
| 보강 포인트 | 얼굴 인식 가이드 프레임, 카메라 준비/차단/비활성 상태, 골프 예약 버튼, 주차 등록 버튼 |

#### KIO-101 ~ 105 체크인 화면 공통

| 항목 | 내용 |
|---|---|
| 목적 | 인증 수단별 체크인을 수행한다 |
| 공통 구조 | 상단 헤더, 중앙 인식 영역, 하단 안내 문구, dev 대체영역 또는 실제 장비 피드 |
| 필수 상태 | 대기중, 인식중, 성공 직전, 실패 재시도, 뒤로가기 |
| 퍼블리싱 기준 | QR/RFID/바코드/얼굴은 동일 스캔 레이아웃 계열로 맞춘다 |

#### KIO-104 전화번호 체크인 보강 포인트

| 항목 | 내용 |
|---|---|
| 목적 | 회원과 직원이 같은 숫자 입력 화면에서 체크인한다 |
| 처리 원칙 | 별도 직원 버튼 없이 인증 결과에서 회원/직원을 자동 판별 |
| 안내 문구 | `회원 또는 직원 전화번호를 입력해주세요` 기본안 |
| 예외 상태 | 직원 출퇴근 허용 OFF 시 동일 화면 흐름에서 차단 |

#### KIO-103 얼굴 인식 체크인 보강 포인트

| 추가 상태 | 설명 |
|---|---|
| 얼굴 탐지 대기 | 카메라 프레임 + "정면을 바라봐주세요" |
| 정지 판정 중 | 1~3초 카운트 또는 포커스 애니메이션 |
| 얼굴 포커싱 완료 | 얼굴 박스 강조 |
| 인식 실패 | 다시 정면을 바라봐달라는 안내 |
| 다중 얼굴 감지 | 한 명만 화면 앞에 서달라는 안내 |

#### KIO-201 출석 결과 화면

| 항목 | 내용 |
|---|---|
| 목적 | 출석 결과와 회원 정보를 모달형으로 보여주고 자동 복귀시킨다 |
| 핵심 영역 | 배경 오버레이, 성공/실패 헤더, 회원 사진, 시작일/종료일/이용상품/잔여정보, 락커/생일/만료임박 부가 정보, 복귀 카운트다운 |

| 예외 상태 | 전송 중, 전송 완료, 전송 실패, 프런트 문의 |

| 항목 | 내용 |
|---|---|

| 화면 요소 | 대형 번호, "해당 신발장에서 밴드를 꺼내주세요", "같은 번호 락커 사용" 보조 문구 |

## 4. 퍼블리싱 우선순위

| 우선순위 | 범위 | 비고 |
|---|---|---|
| P0 | KIO-001 ~ KIO-201 | 현재 출석 메인 흐름 고정 |
| P1 | KIO-202 ~ KIO-204 | 락커 번호 전달 3안 |
| P2 | KIO-301 ~ KIO-305 | 회원 조회 화면 정합화 |
| P3 | KIO-501 ~ KIO-504 | 골프 예약 신규 퍼블리싱 |

| P5 | KIO-401 ~ KIO-702 | 관리자/매점 보강 정리 |

## 5. 제외 범위

- 실제 API 연결
- 로컬 저장소/오프라인 큐
- 프린터/카메라/RFID/게이트 장비 드라이버 연동
- 앱 푸시 전송 구현
- 관리자 설정 저장 로직
