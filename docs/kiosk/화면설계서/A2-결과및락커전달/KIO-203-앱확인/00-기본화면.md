## 화면 목적

락커 번호 전달 방식이 `앱 발송`인 경우의 결과 상태. 락커 번호를 회원 앱으로 보냈음을 안내한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 메인 안내 | "앱에서 락커 번호를 확인해주세요" |
| 앱 전송 완료 배지 | 푸시 발송 상태 |
| 앱 미연동 예외 안내 | 앱 미사용 회원용 |
| 복귀 카운트다운 | 자동 복귀 타이머 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 전송 중 | 푸시 발송 처리 중 |
| 전송 완료 | "앱에서 확인해주세요" |
| 전송 실패 | 대체 안내 (영수증/프런트) |
| 앱 미연동 회원 | "앱이 연결되지 않은 회원입니다" + 대체 안내 |

## 주요 동작

1. KIO-201 성공 후 자동 진입
2. 회원 앱(client) 알림 채널로 푸시 발송
3. 발송 완료 → 안내 문구 → 자동 복귀
4. 발송 실패 → 즉시 대체 수단 전환 (권장: 영수증 → 프런트)

## 비즈니스 규칙

- 앱에서 확인해야 한다는 점이 즉시 이해되어야 한다.
- 앱 미연동 회원은 이 방식을 기본값으로 사용 불가, 별도 분기.
- 전송 실패 시 즉시 대체 수단으로 전환 (퍼블리싱 체크리스트 § 3.3).
- 앱 화면(client/SCR-MA-150)에는 락커 번호 + 유효 시간 + 사용 안내가 함께 표시되어야 한다.
