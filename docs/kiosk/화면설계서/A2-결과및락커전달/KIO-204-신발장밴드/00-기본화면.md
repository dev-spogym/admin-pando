## 화면 목적

락커 번호 전달 방식이 `신발장 밴드 수령`인 경우의 결과 상태. 신발장 번호를 크게 보여주고, 사용자는 해당 신발장에서 밴드를 꺼낸 뒤 같은 번호의 옷 락커를 사용한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 대형 번호 | 신발장 번호 (가장 큰 시각 요소) |
| 메인 안내 | "해당 신발장에서 밴드를 꺼내주세요" |
| 보조 안내 | "같은 번호 락커 사용" |
| 예외 안내 | 밴드 없음/번호 없음 |
| 복귀 카운트다운 | 자동 복귀 타이머 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 배정 완료 | 대형 번호 + 안내 |
| 번호 없음 | 배정 가능 신발장 없음 |
| 밴드 재고 없음 | 해당 번호 밴드 분실/누락 |
| 프런트 문의 | 예외 시 안내 |

## 주요 동작

1. KIO-201 성공 후 자동 진입
2. 신발장 번호 배정 또는 기존 매핑 번호 확정
3. 대형 번호 노출 → 자동 복귀
4. 번호 없음/밴드 재고 없음 → 프런트 문의 안내

## 비즈니스 규칙

- `신발장 번호 = 밴드 번호 = 옷 락커 번호` 1:1 매핑 필수.
- 번호 체계가 어긋나는 센터에는 적용 불가.
- 밴드 분실/반납 누락 시 해당 번호는 즉시 배정 불가로 전환 (admin/SCR-052 연동).
- "해당 신발장에서 밴드를 수령"과 "같은 번호 락커 사용"이 함께 보여야 한다.
