## 화면 목적

체크인 결과(성공/실패)를 모달형으로 표시하고, 정해진 시간 후 대기 화면으로 자동 복귀한다. 성공 시 회원 정보가 함께 노출되며, 락커 후처리 분기(KIO-202/203/204)로 이어진다. 센터 정책상 필요하면 회원앱 건강 데이터 연동 안내를 비차단 보조 문구로 함께 노출한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 배경 오버레이 | 대기 화면 위에 떠 있는 모달 형태 |
| 성공/실패 헤더 | 색·아이콘·문구로 구분 |
| 회원 사진 | 성공 시 노출 |
| 회원 정보 카드 | 시작일 / 종료일 / 이용 상품 / 잔여 정보 |
| 부가 정보 | 락커 정보 / 생일 / 만료 임박 등 |
| 건강 연동 안내 | 회원앱 MA-159 진입 유도 문구 또는 QR (조건부) |
| 복귀 카운트다운 | 화면 우측 상단 또는 하단 고정 위치 |

## 필수 상태

| 상태 | 자동 복귀 |
|---|---|
| 성공 모달 (회원) | 4초 |
| 직원 출퇴근 결과 | 4초 |
| 실패 (만료) | 7초 |
| 실패 (미등록) | 7초 |
| 실패 (중복) | 7초 |
| 실패 (직원 불가) | 7초 |
| 실패 (미수금 차단) | 7초 |
| 성공 + 건강 연동 안내 | 4초, 락커 후처리와 충돌 없이 표시 |
| 락커 로딩 | 표시 |
| 락커 후처리 분기 진입 | KIO-202/203/204로 전환 |

## 주요 동작

1. 인증 성공 → 입퇴장 기록 생성 + 출입문 5초 개방 + 성공 TTS
2. 회원 정보 모달 4초 노출
3. 락커 후처리 정책에 따라:
   - 출석만 완료 → 자동 복귀
   - 수동 배정 대기 → 안내 후 자동 복귀
   - 자동 배정 시도 → 락커 번호 전달 분기 (KIO-202/203/204)
4. 건강 데이터 연동 안내 정책 ON + 대상 회원이면 비차단 보조 문구 또는 QR 노출
5. 인증 실패 → 사유별 안내 + 7초 자동 복귀

## 비즈니스 규칙

- 성공은 전면 전환이 아니라 모달 형태로 표시한다.
- 회원 사진/시작일/종료일/이용상품/잔여 정보가 한눈에 읽혀야 한다.
- 회원명/직원명 표기 방식이 일관적이어야 한다.
- 복귀 카운트다운은 항상 같은 위치에 둔다.
- 락커 배정 진행 중 상태가 성공 모달과 충돌하지 않게 처리한다.
- 중복 체크인 방지: 10분.
- 출입문 개방 시간: 5초.
- 건강 데이터 연동 안내는 회원앱 미연동 회원이나 iOS 회원에게 노출하지 않는다.
