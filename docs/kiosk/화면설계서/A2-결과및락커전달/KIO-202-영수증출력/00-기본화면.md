## 화면 목적

락커 번호 전달 방식이 `종이 영수증 출력`인 경우의 결과 상태. 락커 번호가 영수증으로 출력되었음을 안내한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 락커 번호 강조 | 대형 텍스트 |
| 메인 안내 | "영수증을 가져가세요" |
| 프린터 아이콘 | 출력 진행/완료 표시 |
| 보조 안내 | 사용 안내 문구 |
| 복귀 카운트다운 | 자동 복귀 타이머 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 출력 중 | 프린터 동작 중, 진행 표시 |
| 출력 완료 | "영수증을 가져가세요" |
| 출력 실패 | 락커 번호 화면 임시 노출 + 프런트 문의 안내 |
| 재안내 | 재출력 요청 가능 시 안내 |

## 주요 동작

1. KIO-201 성공 후 자동 진입
2. 프린터 출력 트리거
3. 출력 완료 → 안내 문구 노출 → 자동 복귀
4. 출력 실패 → 화면에 락커 번호 표시 + 프런트 문의

## 비즈니스 규칙

- 락커 번호가 가장 먼저 보여야 한다.
- 영수증에 과도한 개인정보를 포함하지 않는다 (회원명 마스킹 또는 이름만).
- 출력 실패 시 키오스크 화면에 락커 번호를 임시 표시하고, 프런트 문의를 안내한다.
- 영수증 재출력은 관리자/프런트 예외 처리로 분리.
