## 화면 목적

본인 확인 후 회원이 보유한 이용권의 상태/만료일/잔여 정보를 표시한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 본인확인 키패드 | 전화번호 입력 (KINF-01) |
| 상태 카드 | 활성/만료/홀딩 등 |
| 만료일 표시 | YYYY-MM-DD + D-day |
| 잔여 정보 | 잔여 일수 또는 잔여 세션 수 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 대기 | 본인확인 입력 |
| 조회중 | 데이터 로딩 |
| 정상 데이터 | 이용권 카드 노출 |
| 데이터 없음 | "보유한 이용권이 없습니다" |
| 조회 실패 | 시스템 오류 안내 |

## 주요 동작

1. 본인확인 → 회원 식별
2. admin DB 조회 → 이용권 목록 표시
3. 자동 복귀 타이머 만료 → KIO-001 복귀

## 비즈니스 규칙

- 데이터 없음과 조회 실패는 같은 화면으로 보이지 않게 분리한다 (퍼블리싱 체크리스트 § 4.2).
- 상태/만료일/잔여 일수/횟수가 우선순위대로 보여야 한다.
- 데이터 원천은 client/SCR-MA-131과 동일.
