## 화면 목적

본인 확인 후 회원이 보유한 일반 수업 예약과 골프 예약 요약을 함께 표시한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 본인확인 키패드 | 전화번호 입력 |
| 예약 리스트 | 날짜순 정렬 |
| 상태 배지 | 예정/완료/취소 등 |
| 일반 수업 예약 행 | 수업명, 시간, 강사 |
| 골프 예약 행 (보강) | 타석 번호, 이용 시간, 예약 상태 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 대기 | 본인확인 입력 |
| 조회중 | 로딩 |
| 정상 데이터 | 예약 카드 리스트 |
| 데이터 없음 | "예약이 없습니다" |
| 조회 실패 | 시스템 오류 |

## 주요 동작

1. 본인확인 → 회원 식별
2. 일반 예약 + 골프 예약 통합 조회
3. 통합 리스트 노출

## 비즈니스 규칙

- 예약 상태 배지가 명확해야 한다.
- 일반 예약과 골프 예약이 섞여도 한 화면에서 읽혀야 한다.
- 골프 예약일 경우 타석 번호 자리를 별도로 확보 (퍼블리싱 체크리스트 § 4.3).
- 데이터 원천은 client/SCR-MA-122와 동일.
