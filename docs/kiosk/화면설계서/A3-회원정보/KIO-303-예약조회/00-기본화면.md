## 화면 목적

본인 확인 후 회원이 보유한 일반 수업 예약과 골프 예약 요약을 함께 표시한다. 일반 수업 예약은 admin `SCR-C002-수업관리`와 `SCR-C016-예약목록`을 기준으로 읽기 전용 표시하고, 골프 타석 예약은 admin `SCR-054-골프타석관리`에서 생성된 예약을 함께 보여준다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 본인확인 키패드 | 전화번호 입력 |
| 예약 리스트 | 날짜순 정렬 |
| 상태 배지 | 예정/완료/취소 등 |
| 일반 수업 예약 행 | 수업명, 시간, 강사 |
| 골프 예약 행 (보강) | 타석 번호, 이용 시간, 예약 상태 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 대기 | 본인확인 입력 |
| 조회중 | 로딩 |
| 정상 데이터 | 예약 카드 리스트 |
| 데이터 없음 | "예약이 없습니다" |
| 조회 실패 | 시스템 오류 |

## 주요 동작

1. 본인확인 → 회원 식별
2. 일반 수업 예약(SCR-C002/SCR-C016) + 골프 타석 예약(SCR-054) 통합 조회
3. 통합 리스트 노출

## 비즈니스 규칙

- 예약 상태 배지가 명확해야 한다.
- 일반 예약과 골프 예약이 섞여도 한 화면에서 읽혀야 한다.
- 골프 예약일 경우 타석 번호 자리를 별도로 확보 (퍼블리싱 체크리스트 § 4.3).
- 일반 PT/GX/OT 수업은 KIO-303에서 생성/변경하지 않고 조회만 한다.
- 키오스크에서 생성/대기 등록할 수 있는 예약은 KIO-501 ~ KIO-504의 골프 타석 예약만이다.
- 데이터 원천은 client/SCR-MA-122와 동일하며, 골프 상세는 client/SCR-MA-123과 동일한 예약 원장을 사용한다.
