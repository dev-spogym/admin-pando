## 화면 목적

본인 확인 후 오늘 배정된 락커 번호와 유효기한을 표시한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 본인확인 키패드 | 전화번호 입력 |
| 대형 락커 번호 | 한눈에 보이는 크기 |
| 존(zone)/유효기한 | 보조 표시 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 대기 | 본인확인 입력 |
| 배정 있음 | 대형 번호 + 유효기한 |
| 배정 없음 | "배정된 락커가 없습니다" |
| 조회 실패 | 시스템 오류 |

## 주요 동작

1. 본인확인 → 회원 식별
2. admin/SCR-051 조회
3. 결과 노출

## 비즈니스 규칙

- 락커 번호는 한눈에 보이는 크기여야 한다 (퍼블리싱 체크리스트 § 4.4).
- 배정 없음 상태 문구가 과도하게 허전하지 않게 처리.
