## 화면 목적

지점 공지를 표시한다. 본인 확인 없이 진입 가능.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 공지 카드 리스트 | 제목/날짜/요약 |
| 고정 공지 | 일반 공지보다 위 노출 |
| 본문 | 카드 클릭 시 상세 본문 |
| 자동 복귀 타이머 | 화면 우측 상단 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 공지 데이터 수신 |
| 데이터 있음 | 공지 카드 리스트 |
| 데이터 없음 | "등록된 공지가 없습니다" |

## 주요 동작

1. 진입 시 공지 데이터 로드
2. 고정 공지 우선 + 최신순 정렬
3. 카드 탭 → 본문 펼침
4. 자동 복귀 타이머 만료 → KIO-001

## 비즈니스 규칙

- 고정 공지가 일반 공지보다 먼저 노출되어야 한다 (퍼블리싱 체크리스트 § 4.5).
- 긴 공지 본문도 줄바꿈이 자연스럽게 처리되어야 한다.
- 공지 텍스트 원천은 admin/SCR-082.
