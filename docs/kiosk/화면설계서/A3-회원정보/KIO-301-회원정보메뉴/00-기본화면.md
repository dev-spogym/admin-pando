## 화면 목적

이용권/예약/락커/공지 등 정보성 기능으로 진입하는 허브 메뉴. 골프 예약/주차 등록 진입도 여기에 노출 가능.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 종료/뒤로 |
| 메인 카드 그리드 | 2x2 카드형 메뉴 (이용권/예약/락커/공지) |
| 추가 카드 | 골프 예약, 주차 등록 (설정 ON일 때) |
| 비활성 표시 | 기능 OFF 상태 시각 처리 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 설정 로딩 | admin 설정 수신 중 |
| 정상 | 카드 그리드 노출 |
| 기능 비활성 | 일부 카드 disabled 또는 숨김 |

## 주요 동작

1. 카드 탭 → 해당 화면으로 이동
   - 이용권 → KIO-302
   - 예약 → KIO-303
   - 락커 → KIO-304
   - 공지 → KIO-305
   - 골프 예약 → KIO-501
   - 주차 등록 → KIO-601

## 비즈니스 규칙

- 2x2 메뉴 카드의 크기와 간격이 균일해야 한다 (퍼블리싱 체크리스트 § 4.1).
- 비활성 기능은 눌러보지 않아도 비활성임을 알 수 있어야 한다.
- 메뉴 노출은 admin `SCR-I002-키오스크설정` 정책에 따른다.

## 연관 화면
