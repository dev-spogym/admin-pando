## 화면 목적

매점 장바구니의 결제 수단을 선택하고 결제를 완료한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 주문 내역 | 상품/수량/금액 |
| 결제 수단 카드 | 카드/현금/마일리지 등 |
| 결제 버튼 | 큰 CTA |
| 결과 영역 | 성공/실패 결과 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 결제 전 | 주문 내역 + 결제 수단 선택 대기 |
| 결제 중 | VAN 응답 대기 / 처리 중 |
| 결제 성공 | 성공 화면 + 영수증 안내 |
| 결제 실패 | 실패 사유 + 재시도/취소 |

## 주요 동작

1. 결제 수단 선택 (active 상태 명확)
2. 결제 버튼 → 결제 처리
3. 성공 → 영수증 출력 + 회원이면 client/SCR-MA-133에 반영
4. 실패 → 사유 안내 + 재시도

## 비즈니스 규칙

- 결제 수단 선택 카드의 active 상태가 눈에 띄어야 한다 (퍼블리싱 체크리스트 § 8).
- 결제 성공/실패 결과가 출석 결과(KIO-201)와 혼동되지 않아야 한다.
- VAN 연동/현장판매 데이터는 admin/SCR-S010 원천.
