## 화면 목적

회원/고객이 매점 상품을 보고 장바구니에 담는다. 결제는 KIO-702에서 진행.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 카테고리 탭 | 음료/식품/굿즈 등 |
| 상품 카드 그리드 | 이미지/이름/가격/담기 버튼 |
| 장바구니 패널 | 우측 또는 하단 고정 |
| 결제 진행 버튼 | 장바구니에 1개 이상일 때 활성 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 상품 있음 | 정상 그리드 |
| 장바구니 비어있음 | 결제 버튼 비활성 |
| 기능 비활성 진입 차단 | 매점 토글 OFF 시 화면 진입 자체 차단 |

## 주요 동작

1. 카테고리 선택 → 상품 그리드 갱신
2. 상품 카드 [담기] → 장바구니 추가
3. 장바구니 [수량 변경/삭제]
4. [결제하기] → KIO-702

## 비즈니스 규칙

- 상품 카드와 장바구니 패널의 우선순위가 명확해야 한다 (퍼블리싱 체크리스트 § 8).
- 매점 기능 토글 OFF 시 KIO-001/KIO-301에서 진입을 막는다.
- 상품 원천은 admin/SCR-P001 상품관리다.
- 장바구니 구성과 판매 상품/가격 확정 기준은 admin/SCR-S002 POS 판매와 맞춘다.

## 연관 화면

- KIO-001 또는 KIO-301
- KIO-702 (결제)
