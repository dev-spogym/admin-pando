## 화면 목적

기기 상태를 확인하고 운영 액션(설정 새로고침/연결 테스트/원격 문 열기/TTS 점검 등)을 수행한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 기기 정보 카드 | kioskId, branchId, version |
| 설정 정보 카드 | 현재 적용된 키오스크 설정 요약 |
| TTS 테스트 | 샘플 재생 버튼 |
| 운영 액션 버튼 | 설정 새로고침, 연결 테스트, 대기화면 미리보기 |
| 위험 액션 영역 | 원격 문 열기 (시각적으로 분리) |
| 토스트 영역 | 액션 결과 메시지 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 정상 | 모든 카드 노출, 액션 가능 |
| 연결 실패 | 서버/브리지 연결 실패 안내 |
| 문 열기 진행중 | 원격 문 열기 처리 중 |
| 새로고침 완료 | 설정 갱신 토스트 |

## 주요 동작

1. PIN 인증 통과 후 진입
2. 액션 버튼 탭 → 해당 액션 실행 → 토스트
3. 위험 액션(문 열기) 탭 → 확인 후 실행
4. 모든 액션은 감사 로그(ADM-04-02)로 적재

## 비즈니스 규칙

- 기기 정보, 설정 정보, 운영 액션의 3구획이 명확해야 한다 (퍼블리싱 체크리스트 § 7.2).
- 위험 액션은 시각적으로 분리되어야 한다.
- 토스트 메시지가 다른 정보 카드와 겹치지 않아야 한다.
- 모든 액션은 감사 로그로 적재.
