## 화면 목적

숨김 영역 터치 후 관리자 PIN을 입력해 운영 패널(KIO-402)에 진입한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | "관리자 진입" + 뒤로 |
| 4자리 점 표시 | 입력 길이 시각화 |
| 숫자 키패드 | 0~9, 삭제, 확인 |
| 오류 문구 | PIN 오류 시 표시 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 전 | 점 4개 비어있음 |
| 입력 중 | 점 채워짐 |
| 오류 | 빨간 점 + 오류 메시지 + 재입력 |
| 성공 전환 | KIO-402로 이동 |

## 주요 동작

1. 숨김 영역 N회 터치 → KIO-401 진입
2. 4자리 PIN 입력
3. 검증 → 성공 시 KIO-402, 실패 시 재입력
4. 일정 횟수 실패 시 일시 차단 또는 대기 화면 복귀

## 비즈니스 규칙

- 키패드는 회원용 입력 화면(KIO-104)과 비슷하되 관리자 톤으로 구분 (퍼블리싱 체크리스트 § 7.1).
- PIN 오류 메시지가 과도하게 위협적이지 않아야 한다.
- PIN 정책은 admin/SCR-081에서 관리.
