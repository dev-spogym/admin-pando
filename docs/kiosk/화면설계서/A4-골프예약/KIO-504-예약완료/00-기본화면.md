## 화면 목적

골프 예약 또는 대기 등록 결과를 안내하고 자동 복귀한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 결과 헤더 | 성공/실패 표시 |
| 예약 일시 | YYYY-MM-DD HH:mm |
| 타석 번호 | 대형 표시 |
| 이용 시간 | 시작-종료 |
| 예약 상태 | "예약 완료" 또는 "대기 등록 완료" |
| 안내 문구 | 회원 앱 알림 안내 등 |
| 복귀 카운트다운 | 자동 복귀 타이머 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 예약 완료 | 정상 확정 |
| 대기 등록 완료 | 대기열 등록 |
| 실패 | 시스템 오류 또는 정책 위반 |

## 주요 동작

1. KIO-503 확정 후 진입
2. admin/SCR-054에 예약 즉시 반영
3. 회원 앱(client/SCR-MA-150)으로 알림 발송
4. 자동 복귀 타이머 만료 → KIO-001

## 비즈니스 규칙

- 예약 완료와 대기 등록 완료가 다른 메시지로 구분되어야 한다 (퍼블리싱 체크리스트 § 5.4).
- 예약 일시, 타석 번호, 이용 시간이 빠르게 읽혀야 한다.
- admin 측 동기화는 즉시 처리.
