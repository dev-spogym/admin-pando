## 화면 목적

회원이 키오스크에서 골프 타석 예약을 시작하기 위한 진입 화면. 본인 인증 후 골프 이용권 보유 여부 / 예약 가능 시간 / 중복 예약 여부를 검증한다. 키오스크 예약 생성 기능은 골프 타석 예약에만 적용하며, 일반 수업 예약은 KIO-303에서 조회만 제공한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 인증 입력 | 전화번호 키패드 또는 회원 QR 스캔 |
| 이용권 안내 | 보유 골프 이용권 요약 |
| 운영 상태 안내 | 당일 예약 가능 여부, 현재 만석 여부, 대기열 운영 여부를 한 줄 요약으로 표시 |
| 예외 안내 | 이용권 없음/예약 불가 시 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 인증 대기 | 전화번호/QR 입력 대기 |
| 검증 중 | 이용권/시간/중복 검증 |
| 예약 가능 | KIO-502로 이동 |
| 예약 불가 (이용권 없음) | "골프 이용권이 없습니다" + 프런트 안내 |
| 예약 불가 (시간 외) | "현재는 예약이 불가합니다" |
| 예약 불가 (중복) | "이미 예약이 존재합니다" |

## 주요 동작

1. 인증 입력
2. 검증 통과 → KIO-502
3. 검증 실패 → 사유별 안내 + 자동 복귀

## 비즈니스 규칙

- 이용권 없음/중복 예약/예약 가능 시간 아님 예외가 분리되어야 한다 (퍼블리싱 체크리스트 § 5.1).
- 회원 인증 후 예약 가능/불가가 즉시 이해되어야 한다.
- 데이터 원천은 `docs4/V2/D06-시설관리/시설관리.md` SCR-054 + client/SCR-MA-123이다.
- 일반 PT/GX/OT 수업은 본 흐름에서 예약하지 않는다. 일반 수업의 조회 기준은 `docs4/V1/D04-수업관리/수업관리.md` SCR-C002/SCR-C016과 KIO-303이다.
- 센터가 오늘 만석 상태더라도 대기열 허용 정책이 있으면 "대기 예약 가능" 상태를 별도로 보여준다.

## 연관 화면

- KIO-001 또는 KIO-301 (진입 경로)
- KIO-502 (날짜/시간 선택)
