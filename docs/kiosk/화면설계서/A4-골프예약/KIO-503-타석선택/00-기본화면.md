## 화면 목적

선택한 시간대의 사용 가능 타석을 그리드로 보여주고, 회원이 타석을 선택해 예약을 확정한다. 만석일 경우 대기 예약으로 전환할 수 있다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 타석 그리드 | 실제 시설 배치 도면 기반 |
| 상태 배지 | 사용 가능 / 예약됨 / 점검 / 대기 가능 |
| 선택 정보 패널 | 선택 타석 + 담당 프로 + 이용 시간 + 차감 이용권 |
| 확정 버튼 | 즉시 예약 또는 대기 등록 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 사용 가능 | 활성 타석, 선택 가능 |
| 예약됨 | 다른 회원 점유 |
| 점검중 | 운영 점검 |
| 대기 가능 | 만석이지만 대기 등록 가능 |
| 대기 불가 | 만석 + 대기 마감 |

## 주요 동작

1. 타석 선택 → 선택 정보 패널 갱신
2. 확정 버튼:
   - 빈 타석 → 즉시 예약 확정
   - 만석 + 대기 허용 → 대기 등록
3. 결과 → KIO-504

## 비즈니스 규칙

- 타석 그리드가 실제 시설 느낌에 가깝게 보여야 한다.
- 사용 가능/예약/점검 상태가 색만으로 구분되지 않아야 한다 (텍스트/아이콘 동시 사용).
- 선택한 타석 요약 패널이 있어야 한다.
- 만석 시 대기 예약 버튼이 명확해야 한다 (퍼블리싱 체크리스트 § 5.3).
- 동일 시간대 중복 예약은 차단.

## 연관 화면
