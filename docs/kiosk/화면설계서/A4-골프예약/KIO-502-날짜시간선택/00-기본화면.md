## 화면 목적

예약 가능한 날짜와 시간대를 선택한다. 당일 우선 노출, 운영 정책에 따라 확장 가능.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 날짜 탭/카드 | 당일 우선, 향후 일자 |
| 시간대 슬롯 | 30분 또는 1시간 단위 |
| 잔여 좌석/타석 수 | 시간대별 표시 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 시간 슬롯 데이터 수신 |
| 예약 가능 | 슬롯 카드 활성 |
| 일부 마감 | 마감 슬롯 비활성 표시 |
| 전체 마감 | "예약 가능한 시간이 없습니다" |

## 주요 동작

1. 날짜 선택 → 시간 슬롯 갱신
2. 시간 슬롯 선택 → KIO-503

## 비즈니스 규칙

- 날짜와 시간 선택이 한 화면에서 헷갈리지 않게 분리 (퍼블리싱 체크리스트 § 5.2).
- 마감/예약 가능/대기 가능 상태 차이가 시각적으로 보여야 한다.
- 시간 단위는 admin 정책(SET-03-02)을 따른다.

## 연관 화면
