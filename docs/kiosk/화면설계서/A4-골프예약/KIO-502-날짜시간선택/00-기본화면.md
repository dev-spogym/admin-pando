## 화면 목적

예약 가능한 날짜와 시간대를 선택한다. 당일 우선 노출, 운영 정책에 따라 확장 가능. 레슨북식 운영 패턴을 반영해 일자별 가용 수량과 시간대별 만석/대기 가능 여부를 즉시 읽을 수 있어야 한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 날짜 탭/카드 | 당일 우선, 향후 일자 |
| 일자 요약 뱃지 | 날짜별 예약 가능 건수 또는 남은 타석 수 |
| 시간대 슬롯 | 30분 또는 1시간 단위 |
| 잔여 좌석/타석 수 | 시간대별 표시 |
| 상태 표기 | 예약 가능 / 일부 마감 / 만석 / 대기 가능 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 시간 슬롯 데이터 수신 |
| 예약 가능 | 슬롯 카드 활성 |
| 일부 마감 | 마감 슬롯 비활성 표시 |
| 전체 마감 | "예약 가능한 시간이 없습니다" |

## 주요 동작

1. 날짜 선택 → 시간 슬롯 갱신
2. 날짜 하단 뱃지로 가용량을 훑어본다.
3. 시간 슬롯 선택 → KIO-503

## 비즈니스 규칙

- 날짜와 시간 선택이 한 화면에서 헷갈리지 않게 분리 (퍼블리싱 체크리스트 § 5.2).
- 마감/예약 가능/대기 가능 상태 차이가 시각적으로 보여야 한다.
- 시간 단위는 admin 정책(admin SCR-I002)을 따른다.
- 일부 시간대만 만석이어도 동일 일자 안에서 대기 가능 슬롯을 구분해 보여준다.

## 연관 화면
