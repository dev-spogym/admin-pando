## 화면 목적

센터별 방식에 따라 주차 등록을 안내하거나 외부 시스템으로 연결한다. v1에서는 차량번호 입력 폼을 강제하지 않고 버튼/안내 중심으로 구성한다.

## 화면 유형 분기

| 코드 | 유형 | 설명 |
|---|---|---|
| 안내형 (`guide`) | 안내 문구 + 운영시간 팝업 | 가장 단순 |
| 외부 이동형 (`external_link`) | 외부 주차 등록 페이지 또는 웹뷰 | 빌딩 솔루션 연결 |
| 프런트 문의형 (`staff_call`) | 프런트 호출 또는 직원 문의 안내 | 수기 등록 센터 |

## 핵심 영역 (공통 뼈대)

| 영역 | 내용 |
|---|---|
| 상단 헤더 | 화면명, 뒤로 |
| 메인 영역 | 분기에 따라 안내문/링크/호출 버튼 |
| 보조 안내 | 운영 시간/대상 조건 |
| 복귀 카운트다운 | 자동 복귀 타이머 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 기본 안내 | 안내문 또는 버튼 노출 |
| 외부 페이지 이동 안내 | 웹뷰 호출 직전 또는 직후 |
| 미지원 안내 | "이 지점은 주차 등록을 지원하지 않습니다" |
| 외부 연결 실패 | 안내 + 프런트 문의 |

## 주요 동작

1. 화면 진입 시 admin 설정값에 따라 분기 결정
2. 분기별 메인 영역 렌더링
3. 외부 이동형 → 웹뷰 호출 → 일정 시간 후 자동 복귀

## 비즈니스 규칙

- 버튼만 있는 최소 버전도 어색하지 않아야 한다 (퍼블리싱 체크리스트 § 6).
- 같은 레이아웃 뼈대에서 3가지 유형을 모두 처리할 수 있어야 한다.
- 미지원 지점에서는 KIO-001/KIO-301에서 진입 자체를 막는 게 우선 (SET-04-01 OFF).
- v1에서는 차량번호 입력 폼을 강제하지 않는다.

## 연관 화면

- KIO-001 또는 KIO-301 (진입 경로)
- KIO-001 (자동 복귀)
