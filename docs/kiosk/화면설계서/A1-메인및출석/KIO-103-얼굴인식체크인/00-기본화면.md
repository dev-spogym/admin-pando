## 화면 목적

키오스크 카메라가 사용자 얼굴을 탐지하고, 정지 판정 후 얼굴 인식 엔진으로 회원을 식별한다. KIO-001 대기 화면의 우측 캠 영역과 동일 흐름이지만, 별도 화면으로 진입한 경우의 명세다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명 |
| 중앙 캠 영역 | 카메라 프레임 + 얼굴 박스 가이드 |
| 가이드 문구 | "정면을 바라봐주세요" |
| 정지 카운트 | 1~3초 카운트 또는 포커스 애니메이션 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 얼굴 탐지 대기 | 카메라 프레임만 노출 |
| 정지 판정 중 | 1~3초 카운트 진행 |
| 얼굴 포커싱 완료 | 얼굴 박스 강조 |
| 인식 중 | 엔진 호출 |
| 인식 성공 | KIO-201 전환 직전 |
| 인식 실패 | "다시 정면을 바라봐주세요" 안내 |
| 다중 얼굴 감지 | "한 명만 화면 앞에 서주세요" |
| 카메라 준비 중 | 카메라 로딩 |
| 카메라 접근 차단 | 권한 거부 안내 |

## 주요 동작

1. 진입 즉시 카메라 활성
2. 얼굴 탐지 → 정지 판정 (기본 2초)
3. 정지 확정 → 얼굴 인식 엔진 호출
4. 성공 → KIO-201, 실패 → 재대기 (3초 후)

## 비즈니스 규칙

- 정지 판정 시간은 KSET-02-01 설정값을 따른다 (1~3초).
- 다중 얼굴 감지 시 한 명만 화면 앞에 서달라는 안내를 우선 노출한다.
- 얼굴 인식 비활성화 시 (KSET-02-02) 메뉴 자체가 숨겨지므로 이 화면은 진입 불가.
- 인식 실패 후 과도한 연속 호출을 방지한다 (재대기 3초).

## 연관 화면

- KIO-001 (대기 화면 — 동일 캠 흐름)
- KIO-201 (출석 결과)
