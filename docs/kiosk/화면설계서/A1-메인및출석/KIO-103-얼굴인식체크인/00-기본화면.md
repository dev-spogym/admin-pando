## 화면 목적

키오스크 카메라가 사용자 얼굴을 탐지하고, 정지 판정 후 얼굴 인식 엔진으로 회원을 식별한다. KIO-001 대기 화면에서 입장하기를 선택한 뒤 얼굴 인식 수단으로 진입한 경우의 명세다.

화면은 장식용 얼굴 윤곽선/스캔 라인/과한 radial 배경을 쓰지 않는다. 실제 카메라 패널, 상태 배지, 짧은 안내문, 대체 인증 버튼만 남겨 스탠드형 단말에서 멀리서도 읽히는 단정한 운영 화면으로 구성한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명 |
| 중앙 캠 영역 | 어두운 카메라 패널 + 연결/인식 상태 배지 |
| 가이드 문구 | "정면을 바라봐주세요" |
| 정지 카운트 | 1~3초 카운트 또는 텍스트 상태 |
| 대체 인증 | QR/전화번호 인증 이동 버튼 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 얼굴 탐지 대기 | 카메라 프레임만 노출 |
| 정지 판정 중 | 1~3초 카운트 진행 |
| 얼굴 포커싱 완료 | 상태 배지와 안내문으로 완료 표시 |
| 인식 중 | 엔진 호출 |
| 인식 성공 | KIO-201 전환 직전 |
| 인식 실패 | "다시 정면을 바라봐주세요" 안내 |
| 다중 얼굴 감지 | "한 명만 화면 앞에 서주세요" |
| 카메라 준비 중 | 카메라 로딩 |
| 카메라 접근 차단 | 권한 거부 안내 |

## 주요 동작

1. 진입 즉시 카메라 활성
2. 얼굴 탐지 → 정지 판정 (기본 2초)
3. 정지 확정 → 얼굴 인식 엔진 호출
4. 성공 → KIO-201, 실패 → 재대기 (3초 후)

## 비즈니스 규칙

- 정지 판정 시간은 admin `SCR-082-키오스크설정`의 얼굴인식 정책을 따른다 (1~3초).
- 다중 얼굴 감지 시 한 명만 화면 앞에 서달라는 안내를 우선 노출한다.
- 얼굴 인식 비활성화 시 메뉴 자체가 숨겨지므로 이 화면은 진입 불가.
- 인식 실패 후 과도한 연속 호출을 방지한다 (재대기 3초).
- 얼굴 윤곽선 그림, 장식용 SVG, 스캔 라인 애니메이션은 사용하지 않는다.

## 연관 화면

- KIO-201 (출석 결과)
