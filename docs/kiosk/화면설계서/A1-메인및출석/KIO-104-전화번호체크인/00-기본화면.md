## 화면 목적

회원과 직원이 동일 입력 화면에서 전화번호를 입력하여 체크인한다. 인증 결과로 회원/직원을 자동 판별한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명 |
| 입력값 표시 | 입력 중인 전화번호 (가독성 큰 폰트) |
| 안내 문구 | "회원 또는 직원 전화번호를 입력해주세요" |
| 숫자 키패드 | 0~9, 초기화, 삭제, 확인 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 입력 전 | 키패드 대기 |
| 입력 중 | 입력값 표시 |
| 검증 중 | 확인 클릭 후 처리 |
| 회원 인증 성공 | KIO-201 회원 모달로 전환 |
| 직원 인증 성공 | KIO-201 직원 출퇴근 결과로 전환 |
| 직원 출퇴근 불가 | "직원 출퇴근 허용 OFF" 안내 |
| 인증 실패 | 미등록/오류 안내 + 재입력 |

## 주요 동작

1. 키패드로 전화번호 입력
2. 확인 → 회원 DB 조회
3. 회원/직원 자동 분기:
   - 회원 → 출석 흐름 + KIO-201 회원 모달
   - 직원 → `staffAttendance` 적재 + KIO-201 직원 결과
4. 미등록 → 실패 안내 + 재입력

## 비즈니스 규칙

- 별도 직원 버튼 없이 인증 결과에서 자동 판별 (퍼블리싱 체크리스트 § 2.4).
- 직원 출퇴근 허용 OFF 지점에서는 같은 흐름 안에서 차단 안내.
- 키패드와 입력값 표시는 멀리서도 읽을 수 있는 크기여야 한다.
- 회원/직원 공용이므로 안내 문구가 양쪽에 어색하지 않게 작성.
