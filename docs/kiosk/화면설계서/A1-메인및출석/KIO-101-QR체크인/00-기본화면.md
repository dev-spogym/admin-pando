## 화면 목적

회원앱(`client/SCR-MA-110`)에서 발급된 QR 코드를 키오스크 카메라로 스캔하여 회원을 식별하고 출석 처리한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명, 우측 균형 영역 |
| 중앙 인식 영역 | QR 스캔 프레임 + 가이드 라인 |
| 하단 안내 | "회원 앱의 QR 코드를 카메라에 비춰주세요" |
| dev 대체영역 | 장비 미연동 시 목업 입력 |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 대기중 | 스캔 대기, 가이드 노출 |
| 인식중 | 스캔 처리 진행 |
| 성공 직전 | KIO-201로 전환 직전 짧은 피드백 |
| 실패 재시도 | 인식 실패 시 안내 + 재대기 |
| 뒤로가기 | KIO-001로 복귀 |

## 주요 동작

1. 진입 즉시 카메라 활성, 스캔 대기
2. QR 인식 성공 → 회원 식별 → 출석 검증 → KIO-201
3. 인식 실패 → 재시도 안내 → 자동 재대기

## 비즈니스 규칙

- QR/RFID/바코드/얼굴 화면은 동일 스캔 레이아웃 계열로 맞춘다.
- 장비 미연동 상태에서도 목업 퍼블리싱이 자연스러워야 한다.
- 인식 실패 후 재시도 안내 문구 필수.
