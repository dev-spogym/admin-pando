## 화면 목적

회원이 보유한 바코드(예: 회원증 출력본, 앱 바코드 등)를 키오스크 스캐너에 인식시켜 출석 처리한다. 현재 타입 정의만 있고 상세 정책은 보강이 필요하다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명 |
| 중앙 인식 영역 | 바코드 스캔 프레임 |
| 하단 안내 | "바코드를 스캐너에 비춰주세요" |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 대기중 | 스캔 대기 |
| 인식중 | 처리 중 |
| 성공 직전 | KIO-201 전환 |
| 실패 재시도 | 미인식/매핑 없음 |

## 주요 동작

1. 스캐너 활성, 대기
2. 바코드 인식 → 회원 식별 → KIO-201
3. 매핑 없음/오류 → 재시도 안내

## 비즈니스 규칙

- QR 화면과 동일 스캔 레이아웃 계열로 맞춘다.
- 정책 보강 필요 영역(어떤 바코드를 받을 것인지, 발급/매핑 흐름)은 별도 합의 필요.

## 확정 필요

| 항목 | 메모 |
|---|---|
| 수용 바코드 종류 | EAN/Code128/회원앱 발급 등 |
| 회원 ↔ 바코드 매핑 위치 | admin 측 별도 화면 필요 여부 |

## 연관 화면
