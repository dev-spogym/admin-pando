## 화면 목적

회원/직원의 RFID 카드 또는 NFC 태그를 리더기에 태그하여 식별하고 출석 처리한다. 카드 매핑은 `admin/SCR-052-밴드카드관리`에서 관리한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 헤더 | `뒤로`, 화면명 |
| 중앙 인식 영역 | RFID 리더기 위치 가이드 + 아이콘 |
| 하단 안내 | "카드를 리더기에 가까이 대주세요" |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 대기중 | 카드 태그 대기 |
| 인식중 | 리더기 응답 처리 중 |
| 성공 직전 | KIO-201 전환 직전 |
| 실패 재시도 | 미등록/오류 |

## 주요 동작

1. 리더기 활성, 태그 대기
2. 카드 인식 → 회원/직원 식별 → KIO-201
3. 미등록 카드 → 실패 안내 + 재시도

## 비즈니스 규칙

- 장비 미연동 상태에서도 목업 화면이 자연스러워야 한다.
- 카드 매핑이 없는 카드는 실패 처리.

## 연관 화면

- KIO-001, KIO-201
