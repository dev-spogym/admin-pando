## 화면 목적

키오스크 첫 진입 화면. 회원이 입장/퇴장 흐름을 빠르게 선택하고, 보조 메뉴(회원정보/공지/골프/주차/직원출석)로 진입하는 허브 역할을 한다. 물리 스탠드형 키오스크 기준으로 상단 상태/공지, 중앙 안내와 입퇴장 CTA, 하단 보조 메뉴가 한 손 조작 범위 안에 들어오도록 구성한다.

첫 화면은 마케팅형 이미지 히어로가 아니라 운영형 시작 화면이다. 장식용 SVG/캐릭터 일러스트/과한 radial·gradient 배경을 쓰지 않고, 밝은 배경·큰 터치 카드·명확한 상태 배지 중심의 단정한 스타일을 기준으로 한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 상단 상태 영역 | 로고, 현재 시각, 네트워크/장비 연결 상태 |
| 중앙 안내 영역 | 입장/퇴장 안내 문구, 지점 공지 요약 |
| 주요 CTA 영역 | `입장하기`, `퇴장하기` 대형 버튼 2개 |
| 하단 보조 메뉴 | 예약 확인/사물함 번호/골프 입장·예약/주차 등록/직원출석 진입 버튼 |
| 상단 공지 배너 | 지점 공지가 있을 때만 노출 |
| 상단 시계 바 | 현재 시각 |
| 숨김 진입 영역 | 관리자 진입 (KIO-401) |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 설정 로딩 | admin 설정 수신 중 |
| 정상 | 모든 메뉴 정상 노출 |
| 키오스크 비활성 | 점검/영업 시간 외 안내 |
| 공지 노출 | 공지 배너 활성 |
| 공지 없음 | 배너 영역 미노출 (레이아웃 무너지지 않음) |
| 카메라 준비 중 | 얼굴 인식 캠 로딩 |
| 카메라 접근 차단 | 권한 거부 안내 |
| 얼굴 인식 비활성 | 얼굴 캠 영역 대체 (배너/안내) |

## 메뉴 노출 정책

각 보조 메뉴는 admin 설정값에 따라 동적으로 노출/숨김된다.

| 메뉴 | 정책 원천 | 비고 |
|---|---|---|
| 회원 정보 | admin/SCR-082 | KIO-301로 진입 |
| 공지사항 | admin/SCR-082 | KIO-305로 진입 |
| 골프 타석 예약 | admin/SCR-082 | KIO-501로 진입 |
| 주차 등록 | admin/SCR-082 | KIO-601로 진입 |
| 직원 출석 | (별도 토글) | 같은 인증 흐름 안에서 자동 분기 |

## 주요 동작

1. 사용자가 `입장하기` 탭 → admin 기본 인증 수단에 따라 KIO-103/KIO-101/KIO-104 중 하나로 이동
2. 사용자가 `퇴장하기` 탭 → 퇴장 모드의 인증 화면으로 이동
3. 얼굴 인식 자동 시작 정책이 켜져 있으면 카메라 앞 1~3초 정지 → 얼굴 인식 자동 트리거 (ATT-01)
4. 보조 메뉴 카드 탭 → 해당 화면으로 이동
5. 숨김 영역 N회 터치 → KIO-401로 진입

## 비즈니스 규칙

- 얼굴 인식 영역은 성인 사용자의 눈높이에 맞는 중앙 메인 시선 영역으로 유지한다.
- 기능이 꺼진 메뉴는 숨김 또는 비활성 처리 기준이 명확해야 한다 (퍼블리싱 체크리스트 § 2.1).
- 공지 배너 유무에 따라 상하 레이아웃이 무너지지 않아야 한다.
- 관리자 숨김 진입 영역은 일반 사용자에게 어색하게 보이지 않아야 한다.
- 첫 화면에는 장식용 인물 SVG, 가짜 회원 이미지, 이미지 히어로, 불필요한 스캔 연출을 넣지 않는다.
