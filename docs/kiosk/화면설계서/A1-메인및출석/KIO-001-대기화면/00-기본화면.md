## 화면 목적

키오스크 첫 진입 화면. 회원이 체크인 수단을 빠르게 선택하고, 보조 메뉴(회원정보/공지/골프/주차/직원출석)로 진입하는 허브 역할을 한다. 풀스크린 키오스크 기준으로 좌우 분할 레이아웃을 사용한다.

## 핵심 영역

| 영역 | 내용 |
|---|---|
| 좌측 패널 | 로고, 환영 문구, 보조 메뉴 카드 |
| 우측 메인 | 실시간 얼굴 인식 캠 (상시 ON) |
| 하단 도크 | `QR 입장`, `전화번호 입장` 메인 버튼 2개 |
| 상단 공지 배너 | 지점 공지가 있을 때만 노출 |
| 상단 시계 바 | 현재 시각 |
| 숨김 진입 영역 | 관리자 진입 (KIO-401) |

## 필수 상태

| 상태 | 설명 |
|---|---|
| 설정 로딩 | admin 설정 수신 중 |
| 정상 | 모든 메뉴 정상 노출 |
| 키오스크 비활성 | 점검/영업 시간 외 안내 |
| 공지 노출 | 공지 배너 활성 |
| 공지 없음 | 배너 영역 미노출 (레이아웃 무너지지 않음) |
| 카메라 준비 중 | 얼굴 인식 캠 로딩 |
| 카메라 접근 차단 | 권한 거부 안내 |
| 얼굴 인식 비활성 | 얼굴 캠 영역 대체 (배너/안내) |

## 메뉴 노출 정책

각 보조 메뉴는 admin 설정값에 따라 동적으로 노출/숨김된다.

| 메뉴 | 정책 원천 | 비고 |
|---|---|---|
| 회원 정보 | admin/SCR-I002 | KIO-301로 진입 |
| 공지사항 | admin/SCR-I002 | KIO-305로 진입 |
| 골프 타석 예약 | admin/SCR-I002 | KIO-501로 진입 |
| 주차 등록 | admin/SCR-I002 | KIO-601로 진입 |
| 직원 출석 | (별도 토글) | 같은 인증 흐름 안에서 자동 분기 |

## 주요 동작

1. 사용자가 카메라 앞 1~3초 정지 → 얼굴 인식 자동 트리거 (ATT-01)
2. 하단 `QR 입장` 탭 → KIO-101로 이동
3. 하단 `전화번호 입장` 탭 → KIO-104로 이동
4. 좌측 보조 메뉴 카드 탭 → 해당 화면으로 이동
5. 숨김 영역 N회 터치 → KIO-401로 진입

## 비즈니스 규칙

- 우측 캠 영역은 메인 시선 영역으로 유지한다.
- 기능이 꺼진 메뉴는 숨김 또는 비활성 처리 기준이 명확해야 한다 (퍼블리싱 체크리스트 § 2.1).
- 공지 배너 유무에 따라 상하 레이아웃이 무너지지 않아야 한다.
- 관리자 숨김 진입 영역은 일반 사용자에게 어색하게 보이지 않아야 한다.

## 연관 화면

- KIO-101 ~ KIO-105 (체크인 수단별)
- KIO-301 (회원 정보 메뉴)
- KIO-305 (공지사항)
- KIO-501 (골프 예약)
- KIO-601 (주차 등록)
- KIO-401 (관리자 PIN)
