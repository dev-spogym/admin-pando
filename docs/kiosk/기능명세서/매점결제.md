# 키오스크 — 매점 및 현장 결제 (SHP) 기능명세서

> **도메인**: SHP (Shop / 매점 및 현장 결제)
> **연관 화면**: KIO-701, KIO-702
> **작성일**: 2026-05-07
> **버전**: 0.1

---

## 1. 도메인 개요

키오스크에서 회원/고객이 매점 상품을 탐색하고 장바구니에 담은 뒤 현장에서 결제를 완료하는 흐름을 정의한다. 상품 원천과 결제 원장은 admin을 따르지만, 탐색/주문/결제 UX 자체는 키오스크 채널에서 별도로 설계한다. 상품/장바구니 기준은 `SCR-S002-POS판매`, 실제 결제완료 원장은 `SCR-S003-결제처리`로 분리한다.

## 2. 기능 목록

| 코드 | 기능 | 연관 화면 | 상태 |
|---|---|---|---|
| SHP-01 | 매점 상품 탐색 및 장바구니 | KIO-701 | 신규 정의 |
| SHP-02 | 매점 결제 처리 | KIO-702 | 신규 정의 |

---

## 3. SHP-01 매점 상품 탐색 및 장바구니

### 3.1 화면 목적

사용자가 카테고리별 상품을 탐색하고 장바구니를 구성한다. 매점 기능 토글이 OFF인 지점에서는 진입 자체를 차단한다.

### 3.2 주요 기능

- 카테고리 탭 전환
- 상품 카드 목록 표시
- 장바구니 담기 / 수량 변경 / 삭제
- 합계 금액 계산
- 결제 화면(KIO-702)으로 이동

### 3.3 비즈니스 규칙

- 상품 원천은 `admin/SCR-P001-상품관리`와 동일하다.
- 품절/비활성 상품은 목록에서 숨기거나 비활성 상태로 분리한다.
- 메뉴 노출은 `KSET-01-02` 토글에 종속된다.

---

## 4. SHP-02 매점 결제 처리

### 4.1 화면 목적

장바구니의 결제 수단을 선택하고 현장 결제를 완료한다. 성공/실패 결과는 출석 결과 화면과 혼동되지 않게 명확히 분리한다.

### 4.2 주요 기능

- 주문 내역 요약
- 결제 수단 선택
- 결제 요청 / 응답 처리
- 성공 시 영수증/결제내역 반영
- 실패 시 사유 안내 및 재시도

### 4.3 비즈니스 규칙

- 장바구니 상품/가격 컨텍스트는 `admin/SCR-S002-POS판매` 기준을 따른다.
- 결제 원장은 `admin/SCR-S003-결제처리`를 따른다.
- 결제 취소/부분 환불 정책은 `admin/SCR-S012-결제취소-부분환불` 기준을 참조한다.
- 회원 결제 성공 시 `client/SCR-MA-133-결제내역`과 동일한 원장으로 반영된다.
