# 키오스크 — 골프 타석 예약 (GLF) 기능명세서

> **도메인**: GLF (Golf Bay Reservation)
> **연관 화면**: KIO-501 ~ KIO-504
> **작성일**: 2026-05-04
> **버전**: 0.1
> **상태**: 신규 (P2)

---

## 1. 도메인 개요

관리자용 타석 현황 화면(`docs4/V2/D06-시설관리/시설관리.md` SCR-054)과 회원용 예약 상세 흐름(`client/SCR-MA-123-골프예약상세`)을 키오스크용 셀프 예약으로 축소 적용한다. 키오스크는 운영 관리 화면이 아니라 회원의 빠른 예약/대기 등록 채널이다. 키오스크에서 생성/대기 등록할 수 있는 예약은 골프 타석 예약으로 한정하며, 일반 PT/GX/OT 수업은 KIO-303에서 `docs4/V1/D04-수업관리/수업관리.md` SCR-C002/SCR-C016 기준으로 조회만 한다.

## 2. 채널 위치

| 채널 | 역할 |
|---|---|
| `admin` | 운영자가 타석/시간/대기를 직접 편집 (정책 원천) |
| `client` (회원앱) | 회원이 휴대폰에서 셀프 예약 (충분한 시간 흐름) |
| `kiosk` (본 채널) | 회원이 입구 단말에서 빠른 셀프 예약/대기 등록 (3분 안에 끝나는 흐름) |

같은 데이터 원천을 공유한다. 키오스크에서 확정한 예약은 admin 타석 현황에 즉시 반영된다.

## 4. GLF-01 골프 예약 진입

### 4.1 화면 목적

회원이 키오스크에서 셀프로 골프 타석 예약 흐름을 시작한다.

### 4.2 주요 기능

1. 사용자가 `골프 타석 예약` 버튼 탭 (KIO-001 또는 KIO-301에서 진입)
2. 전화번호 또는 회원 QR로 본인 인증
3. 시스템이 검증:
   - 골프 이용권 보유 여부
   - 예약 가능 시간 여부
   - 중복 예약 여부
4. 조건 충족 시 KIO-502로 이동

### 4.3 분기

| 검증 결과 | 처리 |
|---|---|
| 모두 통과 | 예약 가능 화면으로 이동 |
| 이용권 없음 | 예약 차단 + 프런트 문의 안내 |
| 예약 가능 시간 아님 | 안내 문구 표시 |
| 중복 예약 존재 | 중복 예약 차단 |

## 5. GLF-02 예약 가능 시간/타석 조회

### 5.1 KIO-502 날짜/시간 선택

| 항목 | 기본안 |
|---|---|
| 날짜 범위 | 당일 우선 노출, 운영 정책으로 확장 가능 |
| 시간 단위 | docs4 SCR-054 타임테이블 슬롯 기준 |
| 표시 정보 | 시간대별 남은 좌석/타석 수 |
| 상태 | 예약 가능 / 일부 마감 / 전체 마감 |

### 5.2 KIO-503 타석 선택

| 항목 | 기본안 |
|---|---|
| 타석 표시 | 사용 가능 / 예약됨 / 점검 / 대기 가능 |
| 그리드 형태 | 실제 시설 배치에 가깝게 |
| 색만으로 구분 X | 텍스트/아이콘 동시 사용 |
| 선택 정보 패널 | 담당 프로, 이용 시간, 차감 대상 이용권 |
| 대기 가능 여부 | 만석 시 대기 버튼 노출 |

## 6. GLF-03 골프 예약 처리

### 6.1 분기

| 상황 | 처리 |
|---|---|
| 빈 타석 있음 | 타석 선택 후 즉시 예약 확정 |
| 모든 타석 만석, 대기 허용 | 대기 예약으로 전환 |
| 이용권 없음 | 예약 차단 + 프런트 문의 안내 |
| 동일 시간대 예약 존재 | 중복 예약 차단 |

### 6.2 KIO-504 예약 완료 화면 표시 정보

- 예약 일시
- 타석 번호
- 이용 시간
- 예약 상태 (예약 완료 / 대기 등록 완료)
- 안내 문구

### 6.3 비즈니스 규칙

- 예약 완료와 대기 등록 완료는 다른 메시지로 구분한다.
- 결과 화면은 자동 복귀 타이머 적용.

---

## 7. GLF-04 운영 연동 원칙

- 키오스크 예약 데이터는 `docs4` SCR-054 타석 운영 데이터와 같은 원천을 사용한다.
- 예약 확정/취소/대기 승격은 관리자 타석 현황(`SCR-054`)에 즉시 반영한다.
- 대기열 자동 승격은 관리자 정책을 따르고, 키오스크는 결과만 표시한다.
- 회원 앱(`client/SCR-MA-150-알림센터`)으로 예약 결과 알림 발송.
