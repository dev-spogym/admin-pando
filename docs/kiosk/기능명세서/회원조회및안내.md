# 키오스크 — 회원 조회 및 안내 (MBI) 기능명세서

> **도메인**: MBI (Kiosk Information / 회원 조회 및 안내)
> **연관 화면**: KIO-301 ~ KIO-305
> **작성일**: 2026-05-04
> **버전**: 0.1

---

## 1. 도메인 개요

회원이 출석 외의 목적(이용권 잔여, 예약 확인, 락커 번호 조회, 공지 확인)으로 키오스크를 사용할 때의 흐름이다. 모든 조회는 본인 확인 이후에만 진행하며, 데이터 원천은 admin/client와 동일하다.

## 2. 본인 확인 원칙

- 전화번호 기반 본인 확인을 표준으로 한다 (이미 구현됨).
- 같은 인증 패턴을 모든 MBI 기능이 공유한다.
- 인증 정보는 단말 메모리에만 임시 보유하고, 화면 종료/자동 복귀 시 즉시 폐기한다.

---

## 3. 기능 목록

| 코드 | 기능 | 연관 화면 | 상태 |
|---|---|---|---|
| MBI-01 | 회원 본인 확인 | KIO-302 ~ 304 진입 전 | 기존 |
| MBI-02 | 이용권 조회 | KIO-302 | 기존 |
| MBI-03 | 예약 조회 | KIO-303 | 보강 |
| MBI-04 | 락커 조회 | KIO-304 | 기존 |
| MBI-05 | 공지사항 조회 | KIO-305 | 기존 |

---

## 4. MBI-01 회원 본인 확인

### 4.1 화면 목적

이용권/예약/락커 조회 진입 전 회원 본인을 식별한다.

### 4.2 주요 기능

- 숫자 키패드로 전화번호 입력
- 입력값 표시
- 초기화 / 삭제 / 확인 버튼
- 인증 실패 시 재입력 유도

### 4.3 비즈니스 규칙

- 인증 후 같은 회원으로 다른 INF 기능 이동 시 재인증 없이 통과 가능하지만, 자동 복귀 후 다시 진입하면 재인증한다.
- 자동 복귀 타이머가 만료되면 인증 정보를 폐기한다.

---

## 5. MBI-02 이용권 조회

### 5.1 화면 목적

본인 확인 후 회원이 보유한 이용권의 상태, 만료일, 잔여를 표시한다.

### 5.2 주요 기능

- 이용권 상태 카드 (활성/만료/홀딩 등)
- 만료일 표시
- 잔여 일수 또는 잔여 세션 수
- 데이터 없음/조회 실패 분리 표시

### 5.3 비즈니스 규칙

- 회원별 이용권 상태/만료/잔여 데이터는 `admin/SCR-M004-회원상세`의 이용권 탭과 동일하다.
- 상품 정의는 `admin/SCR-P001-상품관리` 기준을 따른다.
- 회원앱 표시는 `client/SCR-MA-131-이용권잔여회차`와 동일한 원천을 사용한다.
- 데이터 없음과 조회 실패는 같은 화면으로 보이지 않게 분리한다.

---

## 6. MBI-03 예약 조회

### 6.1 화면 목적

본인 확인 후 일반 수업 예약과 골프 예약 요약을 함께 본다.

### 6.2 주요 기능

- 예약 리스트 (날짜순 정렬)
- 예약 상태 배지 (예정/완료/취소 등)
- 일반 수업 예약 — 수업명, 시간, 강사
- 골프 예약 — **타석 번호, 이용 시간, 예약 상태** 추가 표시 (보강 포인트)

### 6.3 비즈니스 규칙

- 일반 예약과 골프 예약이 섞여도 한 화면에서 읽히는 구조여야 한다.
- 골프 예약일 경우 타석 번호 자리를 별도로 확보한다.
- 일반 수업 예약 데이터 원천: `admin/SCR-C002-수업관리`, `admin/SCR-C016-예약목록`, `client/SCR-MA-122-내예약수업이력`.
- 골프 타석 예약 데이터 원천: `admin/SCR-054-골프타석관리`, `client/SCR-MA-123-골프예약상세`.
- KIO-303은 조회 전용이다. 키오스크에서 생성/대기 등록 가능한 예약은 골프 타석 예약(KIO-501 ~ KIO-504)만 허용한다.

---

## 7. MBI-04 락커 조회

### 7.1 화면 목적

본인 확인 후 오늘 배정된 락커 번호와 유효기한을 표시한다.

### 7.2 주요 기능

- 대형 락커 번호 표시
- 존(zone)/유효기한 표시
- 배정 없음 상태 처리

### 7.3 비즈니스 규칙

- 데이터 원천은 `admin/SCR-050-락커관리`와 동일.
- 배정 없음 시 안내 문구가 과도하게 허전하지 않게 처리.

---

## 8. MBI-05 공지사항 조회

### 8.1 화면 목적

지점 공지를 읽는다. 본인 확인 없이 진입 가능.

### 8.2 주요 기능

- 공지 카드 리스트
- 고정 공지 우선 노출
- 최신순 정렬
- 자동 복귀 타이머

### 8.3 비즈니스 규칙

- 공지 텍스트 원천은 `admin/D08-마케팅/공지` 및 `admin/SCR-I002-키오스크설정`.
- 긴 공지 본문도 줄바꿈이 자연스럽게 처리.

---

## 9. 메뉴 노출 토글

회원 정보 메뉴(KIO-301)는 admin `SCR-I002-키오스크설정`의 메뉴 노출 정책에 따라 다음 항목을 토글할 수 있어야 한다.

- 회원 정보
- 공지사항
- 골프 타석 예약 (GLF로 분기)
- 주차 등록 (PRK로 분기)
