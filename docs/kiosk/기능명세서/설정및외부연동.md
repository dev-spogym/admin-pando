# 키오스크 — 설정 및 외부 연동 (SET) 기능명세서

> **도메인**: SET (Settings / 설정 및 외부 연동)
> **연관 화면**: 모든 화면의 정책/표시 토글
> **작성일**: 2026-05-04
> **버전**: 0.1

---

## 1. 도메인 개요

키오스크 단말이 admin에서 받아야 하는 설정값과 외부 장비/시스템 연동 정책을 정의한다. 본 문서는 기획/퍼블리싱 단계 기준이며, 실제 설정 키명, enum 값, DB 필드 설계는 범위에서 제외한다.

## 2. 정책 원천

| 영역 | 원천 화면 |
|---|---|
| 키오스크 설정 일반 | `admin/SCR-I002-키오스크설정` |
| 락커 정책 | `admin/SCR-050-락커관리` |
| 카드/밴드 매핑 | `admin/SCR-052-밴드카드관리` |
| 골프 정책 | `admin/SCR-054-골프타석관리` |
| 권한/PIN | `admin/SCR-081-권한설정` |

키오스크는 자체 영구 저장소를 두지 않고, admin 설정을 단말 메모리에 캐시한다.

## 3. 기능 목록

| 코드 | 기능 | 상태 |
|---|---|---|
| SET-01 | 관리자웹 키오스크 설정 연동 | 기존 구조 + 실API 필요 |
| SET-02 | 얼굴 인식 정책 설정 | 신규 보강 |
| SET-03 | 골프 예약 정책 설정 | 신규 |
| SET-04 | 주차 버튼 정책 설정 | 신규 |
| SET-05 | 오프라인 및 복구 정책 | 신규 보강 |

---

## 4. SET-01 관리자웹 키오스크 설정 연동

### 4.1 기능

- **SET-01-01 키오스크 기본 설정 로드**: 단말 부팅 또는 `ADM-03-01 설정 새로고침` 시 admin에서 설정 수신 (현재 mock).
- **SET-01-02 기능 토글별 메뉴 노출 제어**: 회원정보/예약/골프/주차/매점 등 메뉴 노출 여부.

### 4.2 비즈니스 규칙

- 설정 수신 실패 시 마지막으로 받은 캐시 값을 사용한다.
- 캐시도 없으면 안전 기본값으로 동작 (보조 메뉴 모두 숨김).

---

## 5. SET-02 얼굴 인식 정책 설정

### 5.1 설정 항목

| 코드 | 항목 | 기본안 |
|---|---|---|
| SET-02-01 | 정지 감지 시간 | 1~3초, 기본 2초 |
| SET-02-02 | 얼굴 인식 활성/비활성 | `useFaceRecognition` 확장 |
| SET-02-03 | 락커 번호 전달 방식 | 영수증 / 앱 / 신발장 밴드 중 1택 |

### 5.2 비즈니스 규칙

- 얼굴 인식 비활성화 시 KIO-103 메뉴 자체를 숨긴다.
- 정지 감지 시간 변경은 즉시 반영, 단말 재시작 불필요.
- 락커 번호 전달 방식 변경은 KIO-202/203/204 화면 분기에 그대로 영향.

---

## 6. SET-03 골프 예약 정책 설정

### 6.1 설정 항목

| 코드 | 항목 | 기본안 |
|---|---|---|
| SET-03-01 | 예약 기능 활성화 | OFF가 기본 |
| SET-03-02 | 예약 허용 범위/시간대 설정 | 당일 / 특정 일 수 / 특정 요일 |

### 6.2 비즈니스 규칙

- OFF면 KIO-001/KIO-301에서 골프 버튼을 숨긴다.
- 시간대/타석 마감 정책은 admin `SCR-054`를 따른다.

---

## 7. SET-04 주차 버튼 정책 설정

### 7.1 설정 항목

| 코드 | 항목 | 기본안 |
|---|---|---|
| SET-04-01 | 주차 기능 활성화 | OFF가 기본 |
| SET-04-02 | 처리 방식/링크/문구 | `external_link` / `guide` / `staff_call` 중 1택 |

### 7.2 비즈니스 규칙

- OFF면 KIO-001/KIO-301에서 주차 버튼을 숨긴다.
- 처리 방식별로 KIO-601 화면이 분기된다.

---

## 8. SET-05 오프라인 및 복구 정책

### 8.1 설정 항목

| 코드 | 항목 | 처리 |
|---|---|---|
| SET-05-01 | 출석/예약 실패 시 재시도 정책 | 로컬 큐 보유, 복구 즉시 admin 반영 |
| SET-05-02 | 장비 미연결 시 대체 안내 | 카메라/프린터/리더기 미연결 시 안내 화면 |
| SET-05-03 | 영수증/앱/신발장 실패 시 예외 처리 | 전달 방식별 복구 정책 |

### 8.2 비즈니스 규칙

- 키오스크는 자체 영구 저장소를 두지 않으나, **출석/예약 일시 단절 시 로컬 큐**는 보유할 수 있다.
- 복구 즉시 admin 원천으로 반영하고 큐를 비운다.
- 장비 미연결 상태에서도 화면 흐름이 어색하지 않게 안내 처리.

## 9. 추가 제안 설정 (확정 필요)

| 설정 묶음 | 설정 항목 |
|---|---|
| 출석 방식 설정 | 기본 출석 방식, 사용 가능한 인증 수단, 직원 출석 허용 여부 |
| 락커 후처리 설정 | 출석만 완료 / 수동 배정 대기 / 자동 배정 시도 |
| 락커 번호 전달 설정 | 영수증 / 앱 / 신발장 밴드 |
| 전달 실패 예외 설정 | 전달 실패 시 프런트 안내 여부, 보조 전달 방식 |
| 영수증 설정 | 출력 문구, 안내 문구, 재출력 허용 여부 |
| 앱 안내 설정 | 앱 안내 문구, 앱 미연동 회원 예외 처리 |
| 신발장 밴드 설정 | 동일 번호 정책 사용 여부, 밴드 분실/미반납 예외 처리 |
| 메뉴 노출 설정 | 회원 정보, 예약 조회, 골프 예약, 주차 등록, 매점/공지 노출 여부 |

이 목록은 admin `SCR-I002-키오스크설정`에 반영되어야 한다.

## 10. 외부 연동 대상

| 대상 | 연동 방식 | 상태 |
|---|---|---|
| 얼굴 인식 엔진 | 외부 SDK 또는 API | 미연동 |
| 영수증 프린터 | 시리얼/USB 드라이버 | 미연동 |
| 게이트(출입문) | 릴레이/네트워크 트리거 | 부분 |
| RFID 리더기 | 시리얼/USB | 부분 |
| 회원 앱 | admin 알림 채널 경유 (`client/SCR-MA-150`) | 정의됨, 구현 미정 |
| TTS 엔진 | 단말 내장 또는 외부 | 부분 |
