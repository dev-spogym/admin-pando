# 키오스크 — 주차 등록 (PRK) 기능명세서

> **도메인**: PRK (Parking Registration)
> **연관 화면**: KIO-601
> **작성일**: 2026-05-04
> **버전**: 0.1
> **상태**: 신규 (P3)

---

## 1. 도메인 개요

주차 등록은 빌딩마다 정책과 연동 방식이 다르다. v1에서는 공통 입력폼을 강제하지 않고, 버튼 중심의 최소 범위로 정의한다. 차량번호 입력/검증 로직은 공통화하지 않는다.

## 2. 채널 위치

주차는 센터 공통 기능이 아니라 **빌딩 종속 기능**이다. 따라서 admin이 정책 원천을 갖지만 데이터 모델은 키오스크에서 가볍게 끝난다.

| 채널 | 역할 |
|---|---|
| `admin` | 버튼 노출 여부, 처리 방식, 차량번호 입력 정책, 라벨/문구, 외부 링크 설정 |
| `kiosk` (본 채널) | 버튼 표시 + 분기 처리 (안내 / 외부 이동 / 프런트 호출) |
| `client` | 영향 없음 |

## 4. PRK-01 주차 등록 버튼 제공

### 4.1 화면 목적

홈 또는 정보 메뉴에 `주차 등록` 버튼을 노출한다.

### 4.2 주요 기능

- 버튼 노출 여부는 admin `SCR-I002-키오스크설정`의 주차 정책으로 제어한다.
- 버튼 라벨/안내 문구는 빌딩별 상이하므로 admin 설정값을 사용한다.

### 4.3 비즈니스 규칙

- 미지원 지점에서는 버튼 자체를 숨긴다.
- 빌딩 변경 시 라벨/링크만 교체할 수 있어야 한다.

---

## 5. PRK-02 주차 등록 처리 방식 분기

### 5.1 화면 목적

버튼 클릭 시 지점별 처리 방식에 따라 동작한다.

### 5.2 처리 방식

| 코드 | 방식 | 설명 | 권장도 |
|---|---|---|---|
| PRK-02-01 | `plate_last4` | 차량번호 뒤 4자리 입력 | 권장 |
| PRK-02-02 | `external_link` | 외부 주차 등록 페이지 또는 웹뷰 연결 | 대체 |
| PRK-02-03 | `guide` | 안내 문구/운영시간만 팝업 노출 | 기본 |
| PRK-02-04 | `staff_call` | 프런트 호출 또는 직원 문의 안내 | 대체 |

### 5.3 비즈니스 규칙

- 같은 화면 뼈대(KIO-601)에서 4가지 처리 방식을 모두 표시할 수 있어야 한다.
- 외부 링크 이동 후 키오스크는 일정 시간 후 자동으로 대기 화면으로 복귀한다.

---

## 6. PRK-03 운영 로그 및 예외 안내

### 6.1 예외 처리

| 상황 | 안내 |
|---|---|
| 등록 실패 | 사유 노출 + 재시도 또는 프런트 안내 |
| 미지원 빌딩 | "이 지점은 주차 등록을 지원하지 않습니다" |
| 외부 링크 연결 실패 | 안내 문구 + 프런트 문의 |

### 6.2 운영 로그

- 버튼 클릭 카운트 (옵션)
- 외부 링크 이동 실패 로그
- 프런트 호출 트리거 로그 (해당 분기일 때)

| 항목 | 현재 초안 |
