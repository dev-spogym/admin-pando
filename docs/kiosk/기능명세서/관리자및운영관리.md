# 키오스크 — 관리자 및 운영 관리 (ADM) 기능명세서

> **도메인**: ADM (Administration / 관리자 및 운영)
> **연관 화면**: KIO-401, KIO-402
> **작성일**: 2026-05-04
> **버전**: 0.1

---

## 1. 도메인 개요

키오스크 단말의 운영 점검과 예외 대응에 필요한 관리자 기능을 정의한다. 현재 구현된 관리자 패널은 현장 운영에 필요한 최소 기능을 이미 포함한다.

## 2. 권한 분리

키오스크는 무인 단말이므로 단말 단위 PIN으로 관리자 권한을 분리한다. 관리자웹 권한 키(`superAdmin / primary / owner / manager / fc / staff / readonly`)와 별개의 단말 PIN을 사용한다.

| 진입자 | 인증 | 가능 작업 |
|---|---|---|
| 일반 사용자 | 없음 | 일반 화면만 접근 |
| 관리자/운영자 | 숨김 진입 + PIN | 기기 정보, 운영 액션, 점검 도구 |

## 4. ADM-01 관리자 진입 인증

### 4.1 화면 목적

숨김 영역 터치로 관리자 화면에 진입해 PIN을 입력한다.

### 4.2 주요 기능

- 숨김 터치 영역에서 KIO-401로 진입
- 4자리 PIN 입력 (숫자 키패드)
- PIN 검증 → KIO-402 이동
- PIN 오류 시 재입력 유도

### 4.3 비즈니스 규칙

- 숨김 진입 영역은 일반 화면에서 어색하게 보이지 않아야 한다 (퍼블리싱 체크리스트 § 2.1).
- PIN 정책은 `admin/SCR-081-권한설정`에서 관리.
- 오류 메시지는 과도하게 위협적이지 않아야 한다.

---

## 5. ADM-02 기기 상태 확인

### 5.1 화면 목적

단말의 기본 정보와 연결 상태를 확인한다.

### 5.2 표시 항목

| 항목 | 설명 |
|---|---|
| `kioskId` | 단말 고유 ID |
| `branchId` | 소속 지점 ID |
| `version` | 현재 키오스크 버전 |
| 온라인 상태 | 서버/브리지 핑 결과 |

---

## 6. ADM-03 운영 제어 액션

### 6.1 액션 목록

| 코드 | 액션 | 설명 |
|---|---|---|
| ADM-03-01 | 설정 새로고침 | admin 설정 재반영 |
| ADM-03-02 | 연결 테스트 | 서버/브리지 상태 확인 |
| ADM-03-03 | 대기화면 미리보기 | 운영 확인 |
| ADM-03-04 | 원격 문 열기 | 예외 대응 (위험 액션) |

### 6.2 비즈니스 규칙

- 위험 액션(원격 문 열기)은 시각적으로 분리되어야 한다 (퍼블리싱 체크리스트 § 7.2).
- 모든 액션은 토스트 메시지로 결과를 표시한다.
- 토스트와 정보 카드가 겹치지 않게 배치한다.

---

## 7. ADM-04 운영 점검 도구

### 7.1 도구 목록

| 코드 | 도구 | 용도 |
|---|---|---|
| ADM-04-01 | TTS 샘플 재생 | 음성 출력 확인 |
| ADM-04-02 | 감사 로그 적재 | 로그인/문열기/재생 등 액션 이력 |

### 7.2 비즈니스 규칙

- 모든 관리자 액션은 감사 로그로 적재한다.
- 감사 로그는 admin 운영 로그로 동기화된다.
