# 골프 예약 상태 전이도

> 작성일: 2026-05-04
> 관련 화면: KIO-501, KIO-502, KIO-503, KIO-504

## 전체 상태

```mermaid
stateDiagram-v2
    [*] --> 진입
    진입 --> 인증중: 전화번호/QR 입력
    인증중 --> 검증중: 식별 성공
    검증중 --> 예약가능: 이용권 OK + 시간 OK + 중복 없음
    검증중 --> 예약불가_이용권: 골프 이용권 없음
    검증중 --> 예약불가_시간: 예약 가능 시간 외
    검증중 --> 예약불가_중복: 동일 시간대 예약 존재

    예약가능 --> 날짜선택
    날짜선택 --> 시간선택
    시간선택 --> 타석선택

    state 타석선택 {
        [*] --> 그리드조회
        그리드조회 --> 타석선택됨: 빈 타석 클릭
        그리드조회 --> 대기등록선택: 만석 + 대기 허용
    }

    타석선택 --> 확정중
    확정중 --> 예약완료: 즉시 예약
    확정중 --> 대기등록완료: 대기 등록
    확정중 --> 확정실패: 시스템 오류

    예약완료 --> 자동복귀
    대기등록완료 --> 자동복귀
    확정실패 --> 자동복귀
    예약불가_이용권 --> 자동복귀
    예약불가_시간 --> 자동복귀
    예약불가_중복 --> 자동복귀
    자동복귀 --> [*]
```

## 대기열 자동 승격 (admin 자동 처리)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant admin as admin/SCR-054
    participant clientapp as 회원앱

    kiosk->>admin: 대기 등록 (KIO-503/504)
    admin->>kiosk: 대기 순번 N
    Note over admin: 시간 경과, 빈 자리 발생
    admin->>admin: 자동 승격 (1순위)
    admin-->>clientapp: 승격 푸시 알림 (SCR-MA-150)
    Note over kiosk: 회원이 다음 진입 시
    kiosk->>admin: 예약 조회
    admin-->>kiosk: KIO-303에 승격된 예약 표시
```

## 화면 매핑

| 상태 | 화면 |
|---|---|
| 진입/인증중/검증중/예약불가_* | KIO-501 |
| 날짜선택/시간선택 | KIO-502 |
| 타석선택/대기등록선택 | KIO-503 |
| 예약완료/대기등록완료/확정실패 | KIO-504 |

## 채널 일관성

같은 회원이 회원앱과 키오스크에서 동시 시도해도 admin 단일 검증으로 결과가 일관된다.

| 상황 | 처리 |
|---|---|
| 회원앱 + 키오스크 동시 같은 슬롯 | 선착순, 다른 한 쪽은 `예약불가_중복` |
| 다른 회원이 같은 타석 동시 | 선착순 |
| 회원앱 예약 후 키오스크 취소 | 정상 (동일 데이터) |
