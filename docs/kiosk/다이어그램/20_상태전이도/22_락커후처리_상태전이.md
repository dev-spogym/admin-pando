# 락커 후처리 상태 전이도

> 작성일: 2026-05-04
> 관련 화면: KIO-201, KIO-202, KIO-203, KIO-204

## 전체 상태

```mermaid
stateDiagram-v2
    [*] --> 출석성공_회원
    출석성공_회원 --> 락커정책결정: 지점 운영 정책 조회

    락커정책결정 --> 출석만완료: 락커 후처리 없음
    락커정책결정 --> 수동배정대기: 프런트 배정 안내
    락커정책결정 --> 자동배정시도: 자동 배정 정책

    자동배정시도 --> 배정성공: 가용 락커 있음
    자동배정시도 --> 자동배정실패: 가용 락커 없음
    자동배정실패 --> 수동배정대기

    배정성공 --> 전달방식분기

    state 전달방식분기 <<choice>>
    전달방식분기 --> 영수증출력: receipt
    전달방식분기 --> 앱발송: app
    전달방식분기 --> 신발장밴드: band

    %% 영수증
    영수증출력 --> 영수증성공
    영수증출력 --> 영수증실패: 프린터 오류
    영수증실패 --> 임시번호표시
    영수증실패 --> 프런트안내

    %% 앱발송
    앱발송 --> 앱전송성공
    앱발송 --> 앱전송실패: 푸시 실패/미연동
    앱전송실패 --> 영수증fallback
    앱전송실패 --> 프런트안내

    %% 신발장 밴드
    신발장밴드 --> 신발장성공: 매핑 OK + 밴드 재고 OK
    신발장밴드 --> 신발장실패: 번호 없음 또는 밴드 분실
    신발장실패 --> 프런트안내

    %% 종료
    출석만완료 --> [*]
    수동배정대기 --> [*]
    영수증성공 --> [*]
    임시번호표시 --> [*]
    앱전송성공 --> [*]
    영수증fallback --> [*]
    신발장성공 --> [*]
    프런트안내 --> [*]
```

## 분기 결정 입력

| 입력 | 출처 | 영향 |
|---|---|---|
| 락커 후처리 정책 | admin/SCR-I002 | 출석만/수동/자동 |
| 자동 배정 존 | admin/SCR-050-락커관리 | 기본 A, B |
| 락커 번호 전달 방식 | admin/SCR-I002 | receipt / app / band |
| 전달 실패 fallback | admin/SCR-I002 | 영수증/프런트/없음 |
| 회원 앱 연동 여부 | client/SCR-MA-001 가입 연동 | app 방식 사용 가능 여부 |
| 밴드 재고 | admin/SCR-052-밴드카드관리 | band 방식 가용 여부 |
