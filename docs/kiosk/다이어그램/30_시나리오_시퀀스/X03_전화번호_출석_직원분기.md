# X03 전화번호 출석 — 회원/직원 자동 분기

> 작성일: 2026-05-04
> 관련 화면: KIO-104, KIO-201

## 시퀀스

```mermaid
sequenceDiagram
    actor 사용자 as 사용자(회원/직원)
    participant kiosk as 키오스크 KIO-104
    participant admin as admin
    participant 게이트 as 출입문

    사용자->>kiosk: 전화번호 입력 + 확인
    kiosk->>admin: 식별 요청 (전화번호)
    admin->>admin: 회원/직원 테이블 조회

    alt 회원
        admin-->>kiosk: 회원 ID + 이용권 + 락커 정책
        admin->>게이트: 출입문 5초 개방
        admin->>admin: 출석 이력 적재
        kiosk->>사용자: KIO-201 회원 모달 (4초)
    else 직원 + 출퇴근 허용
        admin-->>kiosk: 직원 ID + 직무
        admin->>admin: staffAttendance 적재
        kiosk->>사용자: KIO-201 직원 결과 (4초)
    else 직원 + 출퇴근 불허
        admin-->>kiosk: 직원 ID + 차단 신호
        kiosk->>사용자: KIO-201 "직원 출퇴근 불가" (7초)
    else 미식별
        admin-->>kiosk: 미식별
        kiosk->>사용자: KIO-201 미등록 (7초)
    end
```

## 분기 로직 핵심

| 입력 | 1차 조회 | 2차 검증 | 결과 |
|---|---|---|---|
| 전화번호 | 회원 매칭? | 이용권/미수금/중복 | 회원 분기 |
| 전화번호 | 직원 매칭? | `staffAttendance` 허용? | 직원 분기 |
| 전화번호 | 어디에도 없음 | — | 미식별 |

회원과 직원이 같은 번호를 쓸 일은 없다는 전제. 충돌 시 회원 우선.
