# X08 골프 예약 — 대기 등록 + 자동 승격 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-503 → KIO-504, 이후 client/SCR-MA-150

## 시퀀스 (만석 → 대기 등록)

```mermaid
sequenceDiagram
    actor 회원
    participant kiosk as 키오스크 KIO-503/504
    participant admin as admin/SCR-054
    participant clientapp as 회원앱

    회원->>kiosk: 모든 타석 만석 → "대기 등록" 버튼
    kiosk->>admin: 대기 등록 요청
    admin->>admin: 대기열 push (대기 순번 N)
    admin-->>kiosk: 순번 N
    kiosk->>회원: KIO-504 "대기 등록 완료 (대기 N번)" + 자동 복귀
```

## 시퀀스 (자동 승격)

```mermaid
sequenceDiagram
    participant admin as admin/SCR-054
    participant 알림 as 알림 채널
    participant clientapp as 회원앱
    actor 회원
    participant kiosk

    Note over admin: 시간 경과 — 빈 자리 발생 (다른 회원 취소 등)
    admin->>admin: 자동 승격 실행 (1순위)
    admin->>알림: 승격 푸시
    알림-->>clientapp: SCR-MA-150에 "대기에서 예약으로 승격" 카드
    회원->>clientapp: 알림 확인
    Note over 회원: 또는 키오스크 다음 진입 시
    회원->>kiosk: KIO-303 예약 조회
    kiosk->>admin: 예약 조회
    admin-->>kiosk: 승격된 예약 표시
```

## 자동 승격 정책 출처

자동 승격은 **admin 정책**이다. 키오스크는 결과만 표시하며 자체 대기열을 관리하지 않는다.

| 정책 항목 | 위치 |
|---|---|
| 자동 승격 활성/비활성 | admin/SCR-054 |
| 승격 우선순위 룰 | admin/SCR-054 |
| 승격 시 알림 채널 | admin 알림 채널 |
| 키오스크 채널 라벨 (옵션) | 예약 메타 `via=kiosk` |
