# X04 락커 번호 — 영수증 출력 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-201 → KIO-202

## 시퀀스 (정상 흐름)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant admin as admin
    participant 락커풀 as 락커 풀 (SCR-050)
    participant 프린터 as 영수증 프린터

    Note over kiosk: KIO-201 출석 성공 회원
    kiosk->>admin: 락커 자동 배정 요청
    admin->>락커풀: 가용 락커 검색 (존 A, B)
    락커풀-->>admin: 락커 번호
    admin-->>kiosk: 락커 번호 + 회원명 + 출석시각
    kiosk->>프린터: 영수증 출력 명령
    프린터-->>kiosk: 출력 완료
    kiosk->>사용자: KIO-202 "영수증을 가져가세요" (자동 복귀)
```

## 시퀀스 (출력 실패 fallback)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant 프린터 as 영수증 프린터
    participant 사용자

    kiosk->>프린터: 출력 명령
    프린터-->>kiosk: 오류 (용지없음/통신실패/잼)
    kiosk->>사용자: KIO-202 락커 번호 임시 표시 + "프런트 문의"
    Note over kiosk: 자동 복귀 후 운영 로그 적재
```

## 영수증 내용 (권장)

| 항목 | 표기 |
|---|---|
| 회원명 | 마스킹 또는 이름만 |
| 출석 시각 | YYYY-MM-DD HH:mm |
| 락커 번호 | 큰 숫자 |
| 안내 문구 | "체육관 이용 후 락커를 비워주세요" 등 |

영수증에 과도한 PII를 포함하지 않는다.
