# X01 얼굴 인식 출석 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-001, KIO-103, KIO-201

## 시퀀스

```mermaid
sequenceDiagram
    actor 회원 as 회원
    participant 캠 as 카메라
    participant kiosk as 키오스크 KIO-001/103
    participant 엔진 as 얼굴 인식 엔진
    participant admin as admin
    participant 게이트 as 출입문

    회원->>캠: 단말 앞에 도착
    캠->>kiosk: 얼굴 박스 탐지
    Note over kiosk: 정지 판정 시작 (기본 2초)
    kiosk->>kiosk: 1~3초 정지 카운트
    kiosk->>캠: 촬영 트리거
    캠-->>kiosk: 얼굴 이미지
    kiosk->>엔진: 얼굴 인식 요청
    엔진-->>kiosk: 회원 ID 또는 미식별

    alt 식별 성공
        kiosk->>admin: 출석 검증 요청 (회원 ID)
        admin-->>kiosk: 회원 정보 + 이용권 + 락커 정책
        admin->>게이트: 출입문 개방 명령
        게이트-->>admin: OK (5초 개방)
        kiosk->>회원: KIO-201 성공 모달 (4초)
        admin->>admin: 출석 이력 적재 + 회원앱 동기화
        kiosk->>kiosk: 락커 후처리 분기 (KIO-202/203/204)
    else 미식별 또는 실패
        kiosk->>회원: KIO-201 실패 (7초)
        kiosk->>kiosk: 3초 후 재대기
    end
```

## 다중 얼굴 감지 시

```mermaid
sequenceDiagram
    participant 캠 as 카메라
    participant kiosk as 키오스크

    캠->>kiosk: 다중 얼굴 탐지
    kiosk->>kiosk: 인식 보류
    kiosk-->>사용자: "한 명만 화면 앞에 서주세요" 안내
    Note over kiosk: 단일 얼굴 회복 시 재시작
```

## 핵심 타이머

| 단계 | 시간 |
|---|---|
| 정지 판정 | 1~3초 (기본 2초, admin SCR-I002) |
| 인식 실패 후 재대기 | 3초 |
| 출입문 개방 | 5초 |
| 성공 모달 자동 복귀 | 4초 |
| 실패 화면 자동 복귀 | 7초 |
