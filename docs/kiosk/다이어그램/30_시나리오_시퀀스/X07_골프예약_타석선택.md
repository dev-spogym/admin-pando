# X07 골프 예약 — 타석 선택 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-501 → KIO-502 → KIO-503 → KIO-504

## 시퀀스 (즉시 예약 성공)

```mermaid
sequenceDiagram
    actor 회원
    participant kiosk as 키오스크 KIO-501~504
    participant admin as admin/SCR-054
    participant clientapp as 회원앱 SCR-MA-150

    회원->>kiosk: KIO-001 "골프 예약" 탭
    kiosk->>회원: KIO-501 인증 화면
    회원->>kiosk: 전화번호 또는 QR 인증
    kiosk->>admin: 회원 식별 + 골프 이용권 검증
    admin-->>kiosk: 이용권 OK + 예약 가능
    kiosk->>회원: KIO-502 날짜/시간 선택
    회원->>kiosk: 날짜/시간 선택
    kiosk->>admin: 가용 타석 조회
    admin-->>kiosk: 타석 그리드 (사용가능/예약/점검)
    kiosk->>회원: KIO-503 타석 그리드 + 선택 정보 패널
    회원->>kiosk: 빈 타석 선택 + 확정
    kiosk->>admin: 예약 확정 요청
    admin->>admin: 중복/충돌 검증 + 이용권 차감
    admin-->>kiosk: 예약 ID
    admin-->>clientapp: 예약 알림 푸시 (SCR-MA-150)
    kiosk->>회원: KIO-504 "예약 완료" + 자동 복귀
```

|---|---|---|
