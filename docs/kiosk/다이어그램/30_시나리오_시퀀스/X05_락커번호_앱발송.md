# X05 락커 번호 — 회원앱 발송 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-201 → KIO-203, client/SCR-MA-150

## 시퀀스 (정상 흐름)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant admin as admin
    participant 락커풀 as 락커 풀 (SCR-050)
    participant 알림 as admin 알림 채널
    participant clientapp as 회원앱 SCR-MA-150
    actor 회원

    Note over kiosk: KIO-201 출석 성공
    kiosk->>admin: 락커 자동 배정 요청
    admin->>락커풀: 가용 락커 검색
    락커풀-->>admin: 락커 번호
    admin->>알림: 푸시 + 인앱 메시지 발송
    알림-->>clientapp: 락커 알림 카드 (번호 + 위치 + 유효시간)
    admin-->>kiosk: 발송 완료 신호
    kiosk->>사용자: KIO-203 "앱에서 확인해주세요"
    회원->>clientapp: 앱 진입 → 락커 번호 확인
```

## 시퀀스 (전송 실패 fallback)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant admin
    participant 알림 as 알림 채널

    kiosk->>admin: 락커 배정 요청
    admin->>알림: 푸시 발송
    알림-->>admin: 실패 (앱 미연동 / 발송 오류)
    admin-->>kiosk: 발송 실패 + 권장 fallback

    alt fallback = 영수증
        kiosk->>kiosk: KIO-202 영수증 출력으로 전환
    else fallback = 프런트
        kiosk->>사용자: KIO-203 "프런트 문의 안내"
    end
```

## 분기 입력

| 입력 | 출처 | 영향 |
|---|---|---|
| 회원 앱 연동 여부 | client/SCR-MA-002 가입 연동 | 앱 발송 가능 여부 |
| 푸시 토큰 유효성 | admin 알림 채널 | 발송 가능 여부 |
| fallback 정책 | admin/SCR-082 | 실패 시 어디로 |

## 회원앱 측 알림 카드 형식

| 항목 | 내용 |
|---|---|
| 제목 | "오늘 락커 번호" |
| 본문 | 락커 번호 (큰 숫자) |
| 위치 안내 | 존(zone) |
| 유효 시간 | 출석 시각 + 운영시간 |
| 자동 만료 | 영업 종료 시 |
