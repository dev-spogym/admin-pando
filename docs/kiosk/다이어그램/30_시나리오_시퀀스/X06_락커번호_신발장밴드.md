# X06 락커 번호 — 신발장 밴드 수령 시퀀스

> 작성일: 2026-05-04
> 관련 화면: KIO-201 → KIO-204

## 전제 조건

- 센터 운영 정책: `신발장 번호 = 밴드 번호 = 옷락커 번호` 1:1 매핑
- 밴드 재고/분실/반납은 admin/SCR-052에서 추적

## 시퀀스 (정상)

```mermaid
sequenceDiagram
    participant kiosk as 키오스크
    participant admin as admin
    participant 락커풀 as 락커 풀 (SCR-050)
    participant 밴드 as 밴드 재고 (SCR-052)

    Note over kiosk: KIO-201 출석 성공
    kiosk->>admin: 신발장/밴드 번호 배정 요청
    admin->>락커풀: 가용 옷락커 번호 N
    admin->>밴드: 밴드 N 재고 확인

    alt 밴드 N 재고 OK
        밴드-->>admin: 사용 가능
        admin-->>kiosk: 번호 N 확정
        kiosk->>사용자: KIO-204 대형 번호 N + "해당 신발장에서 밴드 수령"
    else 밴드 N 분실/누락
        밴드-->>admin: 배정 불가
        admin->>락커풀: 다음 가용 번호 검색
        Note over admin: 재시도 또는 프런트 안내
    end
```

## 시퀀스 (예외)

```mermaid
sequenceDiagram
    participant kiosk
    participant admin
    participant 사용자

    kiosk->>admin: 번호 배정 요청
    admin-->>kiosk: 가용 번호 없음 또는 밴드 재고 0
    kiosk->>사용자: KIO-204 "프런트 문의" 안내
    Note over admin: 운영 로그 적재
```

## 운영 원칙

- 동일번호 정책 토글 ON 인 센터에서만 이 방식을 활성화한다.
- 밴드 분실 시 해당 번호는 즉시 배정 불가로 전환되어야 한다 (SCR-052 정책).
- 회수/정상화 시 admin에서 재배정 가능 상태로 복원한다.
