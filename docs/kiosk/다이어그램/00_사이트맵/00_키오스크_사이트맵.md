# 키오스크 사이트맵

```mermaid
flowchart TD
    A0([앱 실행])
    A0 --> KIO001[KIO-001 대기 화면]

    %% 출석 진입
    KIO001 -->|QR| KIO101[KIO-101 QR 입장]
    KIO001 -->|RFID| KIO102[KIO-102 RFID 체크인]
    KIO001 -->|얼굴 인식| KIO103[KIO-103 얼굴 인식 입장]
    KIO001 -->|전화번호| KIO104[KIO-104 전화번호 입장]
    KIO001 -->|바코드| KIO105[KIO-105 바코드 체크인]

    %% 출석 결과
    KIO101 --> KIO201[KIO-201 출석 결과]
    KIO102 --> KIO201
    KIO103 --> KIO201
    KIO104 --> KIO201
    KIO105 --> KIO201

    %% 락커 후처리 분기
    KIO201 -->|영수증| KIO202[KIO-202 영수증 출력]
    KIO201 -->|앱 발송| KIO203[KIO-203 앱 확인]
    KIO201 -->|신발장 밴드| KIO204[KIO-204 신발장 밴드]
    KIO201 -->|자동 복귀| KIO001
    KIO202 --> KIO001
    KIO203 --> KIO001
    KIO204 --> KIO001

    %% 회원 정보 진입
    KIO001 -->|회원 정보| KIO301[KIO-301 회원 정보 메뉴]
    KIO301 --> KIO302[KIO-302 이용권 조회]
    KIO301 --> KIO303[KIO-303 예약 조회]
    KIO301 --> KIO304[KIO-304 락커 조회]
    KIO301 --> KIO305[KIO-305 공지사항]
    KIO302 --> KIO001
    KIO303 --> KIO001
    KIO304 --> KIO001
    KIO305 --> KIO001

    %% 골프 예약
    KIO001 -->|골프 예약| KIO501[KIO-501 골프 진입]
    KIO301 -->|골프 예약| KIO501
    KIO501 --> KIO502[KIO-502 날짜/시간]
    KIO502 --> KIO503[KIO-503 타석 선택]
    KIO503 --> KIO504[KIO-504 예약 완료]
    KIO504 --> KIO001

    %% 주차
    KIO001 -->|주차 등록| KIO601[KIO-601 주차 등록]
    KIO301 -->|주차 등록| KIO601
    KIO601 --> KIO001

    %% 관리자
    KIO001 -.숨김 진입.-> KIO401[KIO-401 관리자 PIN]
    KIO401 --> KIO402[KIO-402 관리자 패널]
    KIO402 -.종료.-> KIO001
```
