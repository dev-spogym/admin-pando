# 키오스크 다이어그램

> 작성일: 2026-05-04
> 버전: 0.1
> 목적: `kiosk-pando`의 화면 흐름 / 상태 전이 / 시퀀스 / 외부 연동을 시각화한다. 모든 다이어그램은 GitHub 호환 Mermaid 코드로 작성한다.

## 폴더 구조

| 폴더 | 내용 |
|---|---|
| `00_사이트맵` | 화면 코드(KIO-NNN) 전체 사이트맵 |
| `10_권한매트릭스` | 회원/직원/관리자 역할별 접근 가능 화면/액션 |
| `20_상태전이도` | 출석, 락커 후처리, 골프 예약 등 상태 머신 |
| `30_시나리오_시퀀스` | 주요 사용자 시나리오의 시퀀스 다이어그램 |
| `40_자동화` | 자동 복귀 / 자동 배정 / 자동 승격 등 시스템 자동 동작 |
| `50_에러_예외` | 인증 실패, 장비 오프라인 등 예외 흐름 |
| `60_admin_연동` | kiosk ↔ admin 채널 간 데이터/이벤트 흐름 |
| `70_client_연동` | kiosk ↔ 회원앱 채널 간 흐름 (QR, 락커 알림, 골프 알림) |

## 표기 규칙

- 화면 코드: `KIO-NNN` (예: `KIO-201`)
- admin 화면: `SCR-XXX` (예: `SCR-I001`)
- 회원앱 화면: `SCR-MA-NNN` (예: `SCR-MA-110`)
- 액터: 회원 / 직원 / 관리자 / 회원앱 / kiosk / admin / 외부장비

## admin/client와의 관계

- admin: `admin-pando/docs/admin/다이어그램/`
- client: `admin-pando/docs/client/다이어그램/`
- kiosk: 본 문서 (`admin-pando/docs/kiosk/다이어그램/`)

채널 간 연동 다이어그램은 `60_admin_연동`, `70_client_연동`에서 키오스크 시점으로 정리한다. 같은 시나리오의 admin/client 시점 다이어그램은 각 채널의 다이어그램 폴더에서 별도 관리한다.
