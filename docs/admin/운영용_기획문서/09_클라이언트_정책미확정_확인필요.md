# 클라이언트 정책 미확정 확인 필요

작성일: 2026-05-22

이 문서는 화면/기능 정의가 누락된 항목이 아니라, 고객사 운영 정책 또는 원천 데이터 해석이 확정되어야 자동화 기준을 고정할 수 있는 항목만 분리한다.

## 1. 결제 취소 / 부분 환불 자동 계산 정책

- 관련 화면: `SCR-S012 결제취소-부분환불`, `DLG-S013 환불처리`
- 관련 기능: `SAL-EXT-04 결제취소부분환불`
- 현재 구현 기준: 1차 구현에서는 자동 계산으로 단정하지 않고 담당자가 수기 입력한 값을 기록한다.
- 고객사 확인 필요:
  - 기간권 사용분 차감 기준: 일할, 월할, 회차별, 별도 위약 정책 중 무엇을 우선할지
  - PT/GX/수업권 사용분 차감 기준: 사용 횟수, 잔여 횟수, 출석 확정 기준 중 무엇을 기준으로 할지
  - 위약금 산정 기준: 고정 금액, 비율, 남은 기간/횟수 연동 여부
  - 기환불 누계 반영 기준: 동일 결제 건 기준인지, 동일 계약/이용권 묶음 기준인지
  - 혼합결제 환불 배분 순서: 카드/현금/계좌이체/포인트 중 어떤 수단부터 환불할지
  - 외부 POS/현금 환불 증빙 필수 여부와 승인자 권한

## 2. KPI 원천 데이터 산식 최종 확인

- 관련 화면: `SCR-094 KPI 대시보드`, `SCR-095 KPI 프리뷰보드`
- 관련 기능: `HQ-02 KPI대시보드`, `HQ-03 KPI센터`
- 현재 구현 기준:
  - OT 등록 전환율은 `등록 / OT 진행`으로 계산한다.
  - OT 이월률은 `이월 건수 / OT배정 인원 × 100`으로 계산한다.
- 고객사 확인 필요:
  - 기존 주간/월간 보고 시트의 등록률 셀이 `등록 / 신규` 구조로 해석되는 경우가 있어, CRM 대시보드 표준 산식과 기존 리포트 산식을 동일하게 맞출지 별도 표시할지 확인이 필요하다.
  - OT 이월률을 대시보드 표준대로 `OT배정 인원` 분모로 고정할지, 기존 운영 리포트에서 쓰던 별도 분모가 있는지 확인이 필요하다.

## 3. `trainer` 역할을 독립 RBAC로 둘지 여부

- 관련 화면: 회원관리 일부, 수업관리 대부분, 시설관리 일부, KPI/온보딩 일부
- 관련 기능: `AUTH-EXT-02 직원계정생명주기보안정책`, `SCR-081 권한 설정`, `10_권한매트릭스`
- 현재 구현 기준:
  - 화면별 상세 문서에서는 `트레이너`를 운영 페르소나로 분리해 담당 회원/담당 수업/담당 타석 등 제한 권한을 부여한다.
  - `10_권한매트릭스`의 기본 역할 표는 `superAdmin`, `primary`, `owner`, `manager`, `fc`, `staff`, `readonly` 7종을 기준으로 작성되어 있으며, 일부 문서에서는 `trainer`를 `fc` 계열 직무 또는 별도 템플릿 정책으로 표현한다.
- 고객사 확인 필요:
  - `trainer`를 `fc`와 별도 RBAC role로 저장할지, `fc` role 안의 직무/권한 템플릿으로 운영할지
  - 별도 role로 둘 경우 `SCR-081 권한 설정`과 역할×화면 매트릭스에 `trainer` 컬럼을 추가할지
  - `front`/`staff`도 별도 role인지, `staff` 하위 직무 템플릿인지
  - 담당 회원, 담당 수업, 담당 타석 같은 “본인 담당 범위”를 RLS 정책에 직접 반영할지, 화면/API 권한 필터로만 처리할지
