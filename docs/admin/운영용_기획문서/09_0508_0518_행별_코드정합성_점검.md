# 0508-0518 행별 코드 정합성 점검

점검일: 2026-05-20

## 기준

- 0508 기준: `2.기획_기능리스트_0508` 탭의 admin 코드/명칭
- 0518 기준: `3.CRM (admin)_제로스트_0518논의` 탭의 계약코드(D열) + 기획코드(F열)
- 계약 기준: `1.제로스트계약_기능리스트` 탭의 최초 계약코드
- 로컬 기준: `docs/admin/기능명세서/**/00-기본기능.md`, `docs/admin/화면설계서/**/00-기본화면.md`
- 핵심 원칙: 0508에 이미 존재한 코드는 같은 의미를 유지한다. 다른 의미가 들어가면 신규 번호를 발급한다.

## 결론

- HIGH/MED 항목은 아래 표 기준으로 조치 또는 시트 표기 확인이 필요하다.
- INFO 항목은 기획코드가 없는 계약/인프라성 행으로, 화면 기획코드 정합성 대상이 아니다.

## 조치 판단

- `IoT-01` / `IoT-02` 계열은 클라이언트가 지적한 코드 재사용 혼동이 실제로 남아 있다. 로컬 문서는 기존 0508 의미를 살려 `D09-설정관리/IoT-01-키오스크설정`, `D09-설정관리/IoT-02-IoT출입관리`로 복구했고, 신규 통합운영 기능은 `IoT-07`, `IoT-08`로 분리했다. 따라서 구글시트 0518의 `IoT-01-07`, `IoT-01-08`, `IoT-02-07`, `IoT-02-08` 중 통합운영 의미인 행은 각각 `IoT-07-*`, `IoT-08-*`로 바꾸는 것이 맞다.
- 0518 행 297의 `RSV-04 → IoT-01`은 계약코드 기준으로는 출결 처리 항목이므로 로컬 기준 대표 기획을 `IoT-07`로 둔다. `IoT-01`은 0508부터 키오스크 설정이었으므로 `RSV-04` 계약 alias를 붙이지 않는다.
- 0518 행 306의 `RSV-04 → SET-EXT-05`는 출결 처리 본기능이 아니라 출석 기준값 설정이다. 로컬에서는 `RSV-04` 계약 alias를 붙이지 않고 파생 설정으로 유지한다.
- `FAC-EXT-01-01~05`는 코드 자체는 0508에 존재하지만 0518 명칭이 괄호 설명으로 범위가 확장되어 유사도 경고가 발생했다. 기존 의미를 유지하는 상세 설명이면 코드 유지 가능하고, 골프/유료/계약 락커까지 별도 신규 기능으로 보는 판단이면 신규 코드가 필요하다.
- `IoT-03-08`은 0508의 "외부 연동"이 0518에서 "인바디·키오스크·heart beat"까지 구체화되었다. 단순 상세화면 코드 유지, 연동 대상이 별도 기능 범위면 신규 하위 코드 발급 대상이다.
- `DB`, `INF`, `COM`, `NFR`, `DOC` 등 INFO 행은 계약/인프라성 코드라 화면 기획코드와 1:1 매칭하지 않는다.
