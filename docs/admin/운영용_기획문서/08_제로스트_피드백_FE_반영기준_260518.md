## 개별 문서 반영 원칙

- `기획 반영 가능` 항목은 화면설계서에 탭, 필터, 버튼, 상세 패널, 모달, 빈 상태 중심으로 반영한다.
- `수기 입력/상태값으로 반영` 항목은 자동 계산, 자동 동기화, 외부 연동을 단정하지 않고 수기 입력 필드와 상태값으로 표현한다.
- `클라이언트 정책 질문만 남김` 항목은 화면 초안은 가능하더라도 산식, 기준값, 포함 범위는 질문 목록에만 남긴다.
- `backend/외부연동 범위라 제외` 항목은 화면설계서에 구현 상세를 넣지 않고 계약/개발 협의 범위로 분리한다.
