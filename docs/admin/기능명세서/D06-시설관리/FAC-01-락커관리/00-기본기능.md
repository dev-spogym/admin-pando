## 기능 목적

센터 내 모든 락커의 배정 현황과 상태를 한눈에 파악하고 관리하는 화면이다. 구역별(A/B/C) 그리드 배치도로 각 락커의 사용 여부·만료 임박·고장 상태를 시각적으로 확인하고, 회원 배정·이동·회수·고장 처리를 즉시 수행한다. 만료 임박 락커를 한 번에 일괄 해제하거나 여러 빈 락커를 한 명의 회원에게 일괄 배정하는 기능으로 운영 부담을 줄인다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 표시 |
|------|------|
| 전체 락커 수 | 합계 |
| 사용중 수 | status=in_use |
| 만료 임박 수 | 7일 이내 |
| 고장 수 | status=broken |

### 구역 탭

A구역 / B구역 / C구역 탭으로 분리.

### 락커 배치 그리드

실제 락커 배치와 동일한 격자.

| 상태 | 색상 |
|------|------|
| 사용중 | 파랑 |
| 만료 임박 (7일) | 주황 |
| 고장 | 빨강 |
| 빈 락커 | 회색 |

각 셀: 락커 번호 + 회원명(배정 시) + 남은 일수. 호버 시 [기록]/[이동]/[회수]/[배정]/[고장] 버튼.

### 색상 범례

하단 상태별 의미 표시.

### 검색창

락커 번호 또는 배정 회원명.

### 만료 임박 일괄 해제

탭 우측 [만료 임박 일괄 해제] → 선택 → DLG-050-007.

### 일괄 배정

[일괄 배정] → 빈 락커 다중 선택 → DLG-050-006 → 한 회원에게 동시 배정.

### 엑셀 다운로드

현재 락커 전체 현황 엑셀.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 구역 | 배정·이동·회수·고장·일괄·엑셀 |
| owner (센터장) | 전체 구역 | 배정·이동·회수·고장·일괄·엑셀 |
| manager | 전체 구역 | 배정·이동·회수·고장·일괄 |
| fc / 스태프 / 프런트 | 전체 구역 | 배정·회수·기록 (이동·일괄 불가) |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "시설관리 > 락커 관리" 진입
2. 현황 요약 카드 + A구역 그리드 기본 표시
3. 탭/검색으로 좁히기

**개별 배정**
1. 빈 락커 호버 → [배정] → DLG-050-004
2. 회원 검색 → 만료일 → 배정 완료

**회수**
1. 사용중 락커 호버 → [회수] → DLG-050-003
2. 확인 → 해제

**일괄 해제**
1. [만료 임박 일괄 해제] 클릭 → 안내 배너
2. 만료 임박 락커 클릭으로 선택
3. [일괄 해제 실행] → DLG-050-007

**일괄 배정**
1. [일괄 배정] 클릭 → 안내 배너
2. 빈 락커 클릭으로 선택
3. DLG-050-006 → 회원·만료일 → 동시 배정

## 비즈니스 규칙

1. 만료 임박 기준은 만료일까지 7일 이내이며 자동 감지된다.
2. 락커 이동 시 만료일은 유지된다.
3. 고장 락커는 배정 불가 처리되며 정상 토글 시 다시 배정 가능하다.
4. 일괄 배정 시 한 회원에게 다중 락커 배정이 가능하나 최대 N개 제한이 있다.
5. 회수·배정·이동·고장 처리 모두 감사 로그(SCR-097)에 기록된다.
6. 본사 통합 모드에서는 지점별 락커가 분리되어 관리된다.
