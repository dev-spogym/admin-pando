## 기능 목적

센터 내 모든 락커의 배정 현황과 상태를 한눈에 파악하고 관리하는 화면(SCR-050)이다. 구역별(A/B/C) 그리드 배치도로 각 락커의 사용 여부·만료 임박·고장 상태를 시각적으로 확인하고, 회원 배정·이동·회수·고장 처리를 즉시 수행한다. 만료 임박 락커를 한 번에 일괄 해제하거나 여러 빈 락커를 한 명의 회원에게 일괄 배정하는 기능으로 운영 부담을 줄인다.

운영 맥락:
- **신규 회원 등록 직후 락커 배정**: 회원 등록 후 즉시 가까운 빈 락커를 그리드에서 클릭하여 개별 배정 (DLG-050-004)
- **만료 임박 회원 일괄 회수**: 매월 말 만료 임박 7일 락커를 일괄 해제하여 운영 회의에서 처리 (DLG-050-007)
- **장기 결석 회원 락커 정리**: 회원 상태 점검 후 락커 회수 + 회원에게 알림 발송
- **부부·가족 인접 배정**: 일괄 배정으로 한 회원 또는 가족 그룹에게 인접 빈 락커 N개 동시 배정
- **고장 락커 격리**: 잠금 불량·키 분실 시 즉시 고장 토글로 배정 차단 + 수리 접수 (FAC-EXT-02 연계)
- **이용권 종료 자동 회수**: 이용권 만료 일자 도달 시 락커 자동 해제(또는 만료 임박 알림 후 회수)
- **스마트 락커 IoT 명령 실패 복구**: 게이트 잠금/해제 명령 실패 시 재시도 또는 수동 토글로 fallback

배정·이동·회수 시 회원에게 알림(NFR-19)이 발송되며, 고장·일괄 처리 모두 SCR-097 감사 로그에 기록된다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 표시 |
|------|------|
| 전체 락커 수 | 합계 |
| 사용중 수 | status=in_use |
| 만료 임박 수 | 7일 이내 |
| 고장 수 | status=broken |

### 구역 탭

A구역 / B구역 / C구역 탭으로 분리.

### 락커 배치 그리드

실제 락커 배치와 동일한 격자.

| 상태 | 색상 |
|------|------|
| 사용중 | 파랑 |
| 만료 임박 (7일) | 주황 |
| 고장 | 빨강 |
| 빈 락커 | 회색 |

각 셀: 락커 번호 + 회원명(배정 시) + 남은 일수. 호버 시 [기록]/[이동]/[회수]/[배정]/[고장] 버튼.

### 색상 범례

하단 상태별 의미 표시.

### 검색창

락커 번호 또는 배정 회원명.

### 만료 임박 일괄 해제

탭 우측 [만료 임박 일괄 해제] → 선택 → DLG-050-007.

### 일괄 배정

[일괄 배정] → 빈 락커 다중 선택 → DLG-050-006 → 한 회원에게 동시 배정.

### 엑셀 다운로드

현재 락커 전체 현황 엑셀.

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "시설관리 > 락커 관리" 진입
2. 현황 요약 카드 + A구역 그리드 기본 표시
3. 탭/검색으로 좁히기

**개별 배정**
1. 빈 락커 호버 → [배정] → DLG-050-004
2. 회원 검색 → 만료일 → 배정 완료

**회수**
1. 사용중 락커 호버 → [회수] → DLG-050-003
2. 확인 → 해제

**일괄 해제**
1. [만료 임박 일괄 해제] 클릭 → 안내 배너
2. 만료 임박 락커 클릭으로 선택
3. [일괄 해제 실행] → DLG-050-007

**일괄 배정**
1. [일괄 배정] 클릭 → 안내 배너
2. 빈 락커 클릭으로 선택
3. DLG-050-006 → 회원·만료일 → 동시 배정

### 분기·예외 흐름
- **이미 다른 락커를 보유한 회원에게 추가 배정 시도**: "해당 회원에게 이미 락커가 배정되어 있습니다" 안내 + 기존 락커 번호 노출 + [기존 회수 후 재배정] / [추가 허용(권한자만)] / [취소]
- **만료일 입력 누락**: 인라인 에러 "만료일을 선택해주세요" + 저장 차단
- **만료일이 과거 일자**: "과거 일자로 배정할 수 없습니다" + 저장 차단
- **고장 락커 배정 시도**: 고장 사선 셀 클릭 시 "고장 상태 락커는 배정할 수 없습니다. 먼저 정상으로 전환하세요" 안내
- **일괄 배정 중 다른 운영자가 동일 락커를 배정**: 락 충돌 감지 → "선택한 락커 중 일부가 이미 배정되었습니다" + 새로고침 + 재선택
- **일괄 해제 도중 회원 알림 발송 실패**: 락커 회수는 성공 처리, 알림은 NFR-19 재시도 큐에 등록
- **스마트 락커 IoT 명령 실패 (게이트 잠금/해제)**: 3회 재시도 → 실패 시 운영자에게 경고 + 수동 처리 가이드, 락커 상태는 DB 기준 유지
- **이동 시 대상 락커가 다른 구역**: 정상 이동 허용, 이동 이력에 from·to 구역 기록
- **N개 초과 일괄 배정 시도 (정책 한도)**: "한 회원에게 최대 N개까지만 배정 가능합니다" + 초과 차단
- **회원 탈퇴 후 잔여 락커**: 탈퇴 처리 시 자동 회수 + 알림 + 감사 로그
- **본사 통합 모드에서 다른 지점 락커 변경 시도**: 권한 없음 시 버튼 비활성, 권한 있음(슈퍼관리자)은 지점 컨텍스트 전환 후 처리

## 비즈니스 규칙

1. 만료 임박 기준은 만료일까지 7일 이내이며 자동 감지된다 (테넌트별 7~14일 조정 가능).
2. 만료 경과(만료일 < 오늘) 락커는 빨강 굵은 글씨로 표시되며 배치 자동 해제 대상이다.
3. 락커 이동 시 만료일은 그대로 유지된다 (이동은 위치 변경, 권리 이전이 아님).
4. 이동 이력은 from 락커번호 / to 락커번호 / 변경 시각 / 운영자 정보를 모두 기록한다.
5. 고장 락커는 배정 불가 처리되며 정상 토글 시 다시 배정 가능하다. 사용중 락커는 고장 토글 전 회수가 선행되어야 한다.
6. 일괄 배정은 한 회원에게 다중 락커 배정 가능하나 테넌트 정책으로 최대 N개(기본 5개) 제한된다.
7. 일괄 해제 시 만료 임박 모드는 7일 이내 락커만 선택 가능, 그 외 사용중 락커 선택 불가.
8. 회원 1명당 락커 보유 수 정책: 1개(기본) / 무제한(테넌트 토글) — 정책 위반 시 추가 배정 차단.
9. 회수·배정·이동·고장·일괄 처리 모두 감사 로그(SCR-097)에 actor / locker_id / member_id / before-after 상태로 기록된다.
10. 본사 통합 모드에서는 지점별 락커가 분리되어 관리되며 운영자는 자신이 권한 가진 지점의 락커만 변경 가능하다.
11. 회원 탈퇴·이관(MBR-04)·삭제 이벤트 시 보유 락커 자동 회수 + NFR-19 알림.
12. 이용권 만료 자동 회수 정책: 활성 시 이용권 만료일 도달 시 락커 자동 해제. 비활성 시 운영자 수동 회수.
13. 만료 임박 알림 발송: 만료일 D-7 / D-3 / D-1에 회원에게 알림 (NFR-19 + 모바일 푸시).
14. 스마트 락커(IoT) 연동 시 배정·회수·고장·이동 모두 게이트 잠금/해제 명령 호출. 명령 실패 시 3회 재시도 후 운영자에게 경고.
15. 스마트 락커 비활성 테넌트는 IoT 호출 없이 DB 상태만 변경한다.
16. 검색은 락커 번호 정확 매치 또는 회원명 부분 매치 (디바운스 300ms).
17. 권한별 가시성: 슈퍼관리자 / 센터장 / 매니저는 모든 락커 변경 가능. FC / 스태프 / 프런트는 배정·회수·기록 가능. 트레이너 / readonly는 조회만.
18. 엑셀 다운로드: 현재 적용된 구역·검색 필터 결과 그대로 다운로드. 파일명은 `락커현황_지점_YYYYMMDD.xlsx`.
19. 그리드 셀 색상 우선순위: 고장 > 만료 경과 > 만료 임박 > 사용중 > 빈 락커.
20. 호버 액션 버튼 노출은 락커 상태별로 다르다: 빈 락커 [배정] / 사용중 [기록]·[이동]·[회수]·[고장] / 고장 [기록]·[정상 전환].
21. 개별 배정·회수·이동·고장 처리는 단건 트랜잭션. 일괄 작업은 chunked 트랜잭션(부분 성공 처리).
22. 정원 초과 락커 등록 차단: 동일 구역·번호 중복 등록 불가, 등록은 별도 화면에서 처리(본 화면은 운영만).

| 기록 조회 결과 없음 | "기록이 없습니다" | - |
