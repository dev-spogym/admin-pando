## 기능 목적

센터에서 회원에게 대여하는 운동복의 재고 현황과 대여·반납·세탁·파손 상태를 관리하는 화면이다. QR 코드 스캔으로 대여와 반납을 빠르게 처리할 수 있으며, 운동복별 현재 상태와 대여 이력을 한눈에 파악할 수 있다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 내용 |
|------|------|
| 전체 운동복 수 | 합계 |
| 대기(사용 가능) | available |
| 대여중 | rented |
| 세탁중 | washing |

### 상태 탭

전체 / 대기 / 대여중 / 세탁중 / 파손 (각 탭 카운트 배지).

### 검색창

운동복 번호 또는 대여 회원명.

### 운동복 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 번호 | 운동복 번호 |
| 사이즈 | S/M/L/XL/XXL |
| 타입 | 상의/하의/세트 |
| 상태 배지 | 대기/대여중/세탁중/파손 |
| 대여 회원명 | 클릭 시 SCR-M004 |
| 대여일 | YYYY-MM-DD |
| 반납 예정일 | YYYY-MM-DD |
| 메모 | 부가 정보 |
| 액션 | 상태별 다른 버튼 |

#### 상태별 액션

| 현재 상태 | 버튼 |
|---|---|
| 대기 | [세탁] [파손] |
| 대여중 | [반납] [세탁] |
| 세탁중 | [세탁 완료] |
| 파손 | [복구] |

### QR 스캔

| 액션 | 동작 |
|------|------|
| QR 스캔 대여 | 빈 운동복 + 회원 검색 + [대여 확정] |
| QR 스캔 반납 | 대여중 운동복 + [반납 처리] |

### 운동복 등록

번호·사이즈·타입·메모 입력.

### 엑셀 다운로드

전체 운동복 현황.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 목록 | 등록·상태·QR·엑셀 |
| owner (센터장) | 전체 목록 | 등록·상태·QR·엑셀 |
| manager | 전체 목록 | 등록·상태·QR·엑셀 |
| fc / 스태프 / 프런트 | 전체 목록 | QR 대여·반납·상태 (등록 불가) |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**QR 대여**
1. 사이드바 → "시설관리 > 운동복 관리" 진입
2. [QR 스캔] → 코드 입력
3. 빈 운동복 조회 → 회원 검색 → [대여 확정]

**QR 반납**
1. [QR 스캔] → 코드 입력
2. 대여중 운동복 → [반납 처리]

**상태 직접 변경**
1. 행 액션 버튼 클릭 → 즉시 상태 변경

**운동복 등록**
1. [운동복 등록] → 번호·사이즈·타입 입력
2. 저장 → 목록 추가

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 테이블 스켈레톤 |
| 정상 | 목록 표시 |
| 빈 상태 | "운동복 데이터가 없습니다" |
| 대기 | 초록 배지 |
| 대여중 | 주황 배지 + 회원·일자 |
| 세탁중 | 회색 배지 |
| 파손 | 빨강 배지 |
| QR 조회 실패 | "해당 QR 코드의 운동복을 찾을 수 없습니다" |

## 비즈니스 규칙

1. QR 코드는 운동복별 고유값으로 등록 시 자동 생성된다.
2. 대여 시 반납 예정일은 자동 설정된다 (예: 당일 또는 + 1일).
3. 반납 시 운동복 상태가 "세탁중"으로 자동 전환된다.
4. 파손 처리된 운동복은 [복구] 액션으로 재사용 가능하며 폐기는 별도 처리한다.
5. 회원은 1인당 동시 대여 개수 제한이 있을 수 있다 (정책).
6. 모든 대여·반납·상태 변경은 감사 로그에 기록된다.
