## 기능 목적

센터에서 실제로 보유한 일반 재고 물품의 수량을 관리하는 기능이다. 관리 대상은 운동복, 수건, 세제, 소모품, 판매용 용품 등 센터가 실물로 보유하고 수량 확인이 필요한 품목이다.

D05 상품관리의 `운동복` 상품은 회원에게 청구하는 운동복 대여비/상품 비용을 등록하는 결제용 상품이다. D05에서 운동복 상품이 판매되거나 결제되어도 FAC-06의 재고 수량은 자동 차감하지 않는다. 실제 재고 수량 증감은 본 기능의 입고, 출고, 조정으로만 처리한다.

회원별 운동복 대여·반납, 세탁중, 파손, 복구 상태 관리는 v1 범위에서 사용하지 않는다. 운동복도 본 기능에서는 일반 재고 품목 중 하나로만 관리한다.

## 주요 구성요소

### 현황 요약 카드

| 카드 | 내용 |
|---|---|
| 전체 품목 수 | 관리 중인 재고 품목 수 |
| 정상 재고 | 현재 수량이 안전 재고 이상인 품목 수 |
| 부족 재고 | 현재 수량이 안전 재고 미만이고 0보다 큰 품목 수 |
| 품절 | 현재 수량이 0인 품목 수 |

### 상태 탭

전체 / 정상 / 부족 / 품절.

### 검색

품목명, 품목 코드, 분류명으로 검색한다.

### 상품 재고 목록 테이블

| 컬럼 | 설명 |
|---|---|
| 품목명 | 재고 품목 이름 |
| 분류 | 운동복 / 수건 / 소모품 / 판매용 용품 / 기타 |
| 현재 수량 | 현재 보유 수량 |
| 안전 재고 | 부족 판정 기준 수량 |
| 재고 상태 | 정상 / 부족 / 품절 |
| 최근 입고일 | 마지막 입고 처리일 |
| 최근 출고일 | 마지막 출고 처리일 |
| 담당자 | 최근 처리자 |
| 액션 | [입고] [출고] [조정] [이력] |

### 품목 등록

품목명, 분류, 단위, 안전 재고, 메모를 입력한다.

### 입고 처리

입고 수량, 입고일, 단가, 거래처, 비고를 입력하면 현재 수량이 증가한다.

### 출고 처리

출고 수량, 출고 사유, 출고일, 비고를 입력하면 현재 수량이 감소한다.

### 재고 조정

실사 후 실제 수량과 조정 사유를 입력하면 현재 수량이 보정된다.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 재고 목록 | 품목 등록·입고·출고·조정·이력 조회·엑셀 다운로드 |
| owner (센터장) | 소속 지점 재고 목록 | 품목 등록·입고·출고·조정·이력 조회·엑셀 다운로드 |
| manager | 소속 지점 재고 목록 | 품목 등록·입고·출고·조정·이력 조회·엑셀 다운로드 |
| fc / trainer / staff / readonly | 재고 현황 | 조회만 |

## 주요 UX 흐름

**재고 조회**
1. 사이드바 → 시설관리 > 상품 재고 관리 진입
2. 전체 재고 목록과 요약 카드 확인
3. 상태 탭, 검색으로 품목 필터링

**입고 처리**
1. 품목 행 [입고] 클릭
2. 입고 수량, 입고일, 단가, 거래처, 비고 입력
3. 저장 → 현재 수량 증가 + 이력 기록

**출고 처리**
1. 품목 행 [출고] 클릭
2. 출고 수량, 출고 사유, 출고일, 비고 입력
3. 저장 → 현재 수량 감소 + 이력 기록

**재고 조정**
1. 품목 행 [조정] 클릭
2. 실사 후 실제 수량과 조정 사유 입력
3. 저장 → 현재 수량 보정 + 이력 기록

## 비즈니스 규칙

1. D05 상품관리의 운동복 상품 결제는 FAC-06 재고 수량을 자동 차감하지 않는다.
2. FAC-06의 재고 수량 증감은 입고, 출고, 조정 액션으로만 발생한다.
3. 회원별 운동복 대여·반납·세탁·파손·복구 상태는 v1 범위에서 사용하지 않는다.
4. 운동복은 일반 재고 품목 중 하나로만 관리한다.
5. 현재 수량이 안전 재고보다 낮고 0보다 크면 부족 상태다.
6. 현재 수량이 0이면 품절 상태다.
7. 출고 수량은 현재 수량을 초과할 수 없다.
8. 출고 사유와 재고 조정 사유는 필수다.
9. 모든 입고·출고·조정은 처리자, 처리 시각, 변경 전후 수량, 사유와 함께 이력으로 남긴다.
10. 안전 재고 미설정 품목은 부족 알림을 발송하지 않지만 목록에서 설정 권유 배지를 표시한다.
11. superAdmin / primary는 전체 지점 재고를 조회·처리할 수 있고, owner / manager는 소속 지점 재고만 처리한다.
12. fc / trainer / staff / readonly는 조회만 가능하며 등록·입고·출고·조정 버튼을 볼 수 없다.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 품목 미등록 | "등록된 재고 품목이 없습니다" + [품목 등록] CTA | 등록 안내 |
| 품목명 중복 | 인라인 "동일 품목명이 이미 존재합니다" | 저장 차단 |
| 출고 수량 > 현재 수량 | 인라인 "현재 수량보다 많이 출고할 수 없습니다" | 저장 차단 |
| 출고 사유 미입력 | 인라인 "출고 사유를 선택해주세요" | 저장 차단 |
| 재고 조정 사유 미입력 | 인라인 "조정 사유를 입력해주세요" | 저장 차단 |
| 안전 재고 미설정 | 부족 알림 미발송 + 노랑 안내 | 저장 가능 |
| 권한 부족 | 입고·출고·조정·등록 버튼 hidden | - |
| 동시 수정 충돌 | "다른 사용자가 먼저 수정했습니다" | 최신 값 재로드 |
| 본사 통합 모드에서 지점 미선택 | "지점을 먼저 선택해주세요" | 지점 선택 유도 |

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| 부족 알림 | 입고·출고·조정 후 현재 수량 < 안전 재고 | 운영자에게 부족 재고 알림 |
| 품절 알림 | 현재 수량 = 0 | 운영자에게 품절 알림 |
| 입출고 이력 | 입고·출고·조정 저장 | 처리자, 처리 시각, 변경 전후 수량, 사유 기록 |
| D05 상품관리 | 운동복 대여비/상품 비용 결제 | FAC-06 재고 수량 자동 차감 없음 |
| 재고 KPI 배치 | 매일 04:00 | 부족·품절 품목 수 집계 |
