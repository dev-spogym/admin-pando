## 기능 목적

센터에서 사용하는 RFID 밴드와 카드를 등록·관리하고 회원 또는 직원과 연결하는 화면(SCR-052)이다. 회원이 락커·출입문·시설을 이용할 때 사용하는 RF 장치의 전체 발급 현황을 관리하며, 분실 신고·교체·삭제 처리를 수행한다. 카드 사용 이력 추적으로 보안 사고 발생 시 대응 가능하다.

운영 맥락:
- **신규 회원 카드 발급**: 회원 등록 직후 RFID 리더에 카드 스캔 → 회원 매핑 → 사물함 연결 → 즉시 사용 가능
- **회원 분실 신고 대응**: [분실] → 즉시 사용 차단 + 회원 알림 + 신규 카드 발급 (동일 회원 신규 등록)
- **직원용 출입 카드 발급**: 사용자 유형 "직원" → 직원 검색 → 출입 권한 카드 매핑
- **카드 손상 교체**: 기존 카드 분실(또는 삭제) 처리 → 신규 카드 발급으로 교체
- **사용 이력 보안 감사**: 보안 사고 발생 시 [이력] → 기간 선택 → 출입·락커·결제 이력 추적
- **연결 사물함 변경**: 회원 락커 변경 시 카드의 연결 사물함 정보 동기화
- **퇴직 직원 카드 회수**: 직원 퇴직 시 [삭제] → 영구 회수 + 권한 차단
- **본사 통합 모드 카드 발급**: 지점별 카드 분리 관리, 슈퍼관리자만 통합 조회

분실·등록·삭제·매핑 변경 모두 SCR-097 감사 로그에 기록되며, 카드 사용 이력은 90일 이상 보관된다.

## 주요 구성요소

### 현황 요약 카드 (3개)

| 카드 | 내용 |
|------|------|
| 전체 카드 수 | 합계 |
| 활성(사용중) | status=active |
| 미사용·해제·분실 합계 | 비활성 카드 |

### 검색 / 필터

- **검색**: 카드 번호 또는 회원명
- **상태 필터**: 활성 / 분실 / 해제

### 카드 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 순번 | 페이지 내 |
| 등록일 | YYYY-MM-DD |
| 카드 번호 | RFID UID |
| 연결 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 사용자 유형 | 회원 / 직원 |
| 상태 | 활성/분실/해제 배지 |
| 배정일 | YYYY-MM-DD |
| 연결 사물함 | 락커 번호 |
| 액션 | [이력] / [분실] / [수정] / [삭제] |

### 신규 등록 (DLG-052-001)

| 항목 | 입력 |
|------|------|
| 카드 번호 | 스캔 또는 수동 입력 |
| 사용자 유형 | 회원 / 직원 |
| 회원/직원 검색 | 자동완성 |
| 연결 사물함 | 선택 (옵션) |
| 비고 | textarea |

### 분실 처리

행 [분실] → 상태 "분실" 변경 + 회원 알림.

### 이력 조회 (DLG-052-002)

기간 선택 → 해당 카드의 사용 이력(출입·락커·결제 등).

### 삭제 (DLG-052-003)

영구 삭제 확인.

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "시설관리 > 밴드/카드 관리" 진입
2. [신규 등록] → DLG-052-001
3. 카드 번호 스캔 또는 수동 입력
4. 사용자 유형 → 회원 검색 → 사물함 연결(선택)
5. 저장 → 목록 추가

**분실 처리**
1. 행 [분실] → 상태 변경
2. 사용 차단 + 회원 알림

**이력 조회**
1. 행 [이력] → DLG-052-002
2. 기간 선택 → 사용 이력 표시

### 분기·예외 흐름
- **카드 번호 중복 등록 시도**: "동일 카드 번호가 이미 등록되어 있습니다" + 기존 매핑 정보 노출 + 등록 차단
- **RFID 리더 미연결 시 스캔 시도**: "리더 장치를 확인해주세요" + 수동 입력 가이드 노출
- **수동 입력 카드 번호 형식 오류**: 인라인 "올바른 형식이 아닙니다 (예: 16자리 HEX)"
- **회원 검색 0건**: "검색 결과가 없어요" + 회원 등록 안내
- **이미 카드 보유 회원에 추가 발급 시도**: "해당 회원은 이미 활성 카드를 보유 중입니다" + 기존 카드 노출 + [기존 분실 후 재발급]/[추가 허용 권한자]/[취소]
- **분실 처리된 카드 재사용 시도(외부)**: 출입·락커·결제 모두 차단 + 시도 로그 기록 + 운영자 알림
- **삭제 시도(권한 부족)**: 버튼 hidden 또는 "권한이 없습니다"
- **연결 사물함 변경 시 사물함 미존재**: "선택한 사물함이 존재하지 않습니다" + 재선택
- **이력 기간 90일 초과 조회**: "최대 90일 범위로 조회 가능합니다" + 기간 축소 안내
- **본사 통합 모드 다른 지점 카드 변경 시도**: 권한자 외 차단

## 비즈니스 규칙

1. RFID 카드 번호는 시스템 내 고유값으로 중복 등록 불가하다 (UNIQUE 제약).
2. 카드 번호 형식은 16자리 HEX(또는 테넌트 정의 형식), 형식 위반 시 등록 차단.
3. 카드 등록 방식은 RFID 리더 스캔(권장) 또는 수동 입력. 수동 입력은 형식 검증 통과 시에만 허용.
4. 사용자 유형은 "회원" / "직원" 중 단일 선택, 발급 후 변경 시 매핑 재설정 필요.
5. 분실 처리된 카드는 즉시 사용이 차단되며 출입·락커·결제·QR 어떤 시도에도 응답하지 않는다.
6. 분실 카드 재발급은 신규 등록으로 처리한다 (분실 카드는 영구 비활성).
7. 회원 1명당 활성 카드 보유 수 정책: 1개(기본) / 무제한(테넌트 토글). 정책 위반 시 차단.
8. 직원 1명당 활성 카드 보유 수: 1개(기본).
9. 연결 사물함은 선택 사항, 변경 시 카드-사물함 매핑이 즉시 갱신된다.
10. 카드 삭제는 manager+ 권한, 영구 삭제, 이력은 감사 로그에 보존.
11. 분실 → 삭제 시 분실 시각·삭제 시각 모두 이력 보존.
12. 분실 처리된 카드 재사용 시도(외부 출입 시도)는 시도 로그를 기록하고 운영자 알림.
13. 카드 사용 이력은 90일 이상 보관 (정책에 따라 1~3년 가능), 90일 초과 조회는 데이터 웨어하우스에서.
14. 이력 기간 선택은 최대 90일 범위, 그 이상은 별도 분석 화면.
15. 분실 처리 시 회원에게 NFR-19 알림 자동 발송 (앱 푸시 + SMS).
16. 권한별 가시성: 슈퍼관리자 / 센터장 / 매니저는 모든 작업. FC / 스태프 / 프런트는 등록·분실 가능, 삭제 불가. 트레이너 / readonly는 조회만.
17. 본사 통합 모드는 지점별 카드 분리 운영, 슈퍼관리자만 통합 조회 가능.
18. 모든 분실·삭제·등록·수정·이력 조회 처리는 감사 로그(SCR-097)에 actor·card_id·user_id·before-after 기록.
19. RFID 리더 연결 상태 표시: 화면 상단에 리더 연결 상태(녹색/빨강) 노출, 미연결 시 스캔 비활성.
20. 카드 번호 검색은 정확 매치, 회원명 검색은 부분 매치, 디바운스 300ms.
21. 상태 필터(활성/분실/해제) 변경 시 즉시 결과 갱신, URL 쿼리 파라미터 동기화.
22. 엑셀 다운로드 시 분실 카드 포함 여부 토글 옵션, 파일명 `RFID현황_지점_YYYYMMDD.xlsx`.
