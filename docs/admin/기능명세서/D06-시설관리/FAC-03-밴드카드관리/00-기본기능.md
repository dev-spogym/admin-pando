## 기능 목적

센터에서 사용하는 RFID 밴드와 카드를 등록·관리하고 회원 또는 직원과 연결하는 화면이다. 회원이 락커·출입문·시설을 이용할 때 사용하는 RF 장치의 전체 발급 현황을 관리하며, 분실 신고·교체·삭제 처리를 수행한다. 카드 사용 이력 추적으로 보안 사고 발생 시 대응 가능하다.

## 주요 구성요소

### 현황 요약 카드 (3개)

| 카드 | 내용 |
|------|------|
| 전체 카드 수 | 합계 |
| 활성(사용중) | status=active |
| 미사용·해제·분실 합계 | 비활성 카드 |

### 검색 / 필터

- **검색**: 카드 번호 또는 회원명
- **상태 필터**: 활성 / 분실 / 해제

### 카드 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 순번 | 페이지 내 |
| 등록일 | YYYY-MM-DD |
| 카드 번호 | RFID UID |
| 연결 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 사용자 유형 | 회원 / 직원 |
| 상태 | 활성/분실/해제 배지 |
| 배정일 | YYYY-MM-DD |
| 연결 사물함 | 락커 번호 |
| 액션 | [이력] / [분실] / [수정] / [삭제] |

### 신규 등록 (DLG-052-001)

| 항목 | 입력 |
|------|------|
| 카드 번호 | 스캔 또는 수동 입력 |
| 사용자 유형 | 회원 / 직원 |
| 회원/직원 검색 | 자동완성 |
| 연결 사물함 | 선택 (옵션) |
| 비고 | textarea |

### 분실 처리

행 [분실] → 상태 "분실" 변경 + 회원 알림.

### 이력 조회 (DLG-052-002)

기간 선택 → 해당 카드의 사용 이력(출입·락커·결제 등).

### 삭제 (DLG-052-003)

영구 삭제 확인.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 카드 + 이력 | 등록·수정·분실·삭제·이력 |
| owner (센터장) | 전체 카드 + 이력 | 등록·수정·분실·삭제·이력 |
| manager | 전체 카드 + 이력 | 등록·수정·분실·삭제·이력 |
| fc / 스태프 / 프런트 | 전체 카드 | 등록·분실 (삭제 불가) |
| 트레이너 / readonly | 목록 조회 | 변경 불가 |

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "시설관리 > 밴드/카드 관리" 진입
2. [신규 등록] → DLG-052-001
3. 카드 번호 스캔 또는 수동 입력
4. 사용자 유형 → 회원 검색 → 사물함 연결(선택)
5. 저장 → 목록 추가

**분실 처리**
1. 행 [분실] → 상태 변경
2. 사용 차단 + 회원 알림

**이력 조회**
1. 행 [이력] → DLG-052-002
2. 기간 선택 → 사용 이력 표시

## 비즈니스 규칙

1. RFID 카드 번호는 시스템 내 고유값으로 중복 등록 불가하다.
2. 분실 처리된 카드는 즉시 사용이 차단되며 출입·락커·결제에 사용할 수 없다.
3. 분실 카드 재발급은 신규 등록으로 처리한다.
4. 카드 삭제는 manager+만 가능하며 영구 삭제된다.
5. 모든 분실·삭제·등록 처리는 감사 로그(SCR-097)에 기록된다.
6. 카드 사용 이력은 90일 이상 보관된다.
