## 기능 목적

센터 내 운동 장비의 정기 점검 일정과 수리 이력을 관리하는 화면이다. 장비별로 다음 점검 예정일을 설정하고, 점검 완료 후 결과를 기록하며, 고장·수리 접수부터 완료까지의 이력을 추적한다. 점검이 지연되거나 수리가 필요한 장비를 한눈에 파악해 시설 안전을 유지한다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 내용 |
|------|------|
| 전체 장비 수 | 합계 |
| 점검 예정 (7일 이내) | 임박 |
| 수리 중 | repair |
| 정상 운영 | normal |

### 장비 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 장비명 | 이름 |
| 장비 유형 | 카테고리 |
| 설치 위치 | 룸·층 |
| 마지막 점검일 | YYYY-MM-DD |
| 다음 점검 예정일 | YYYY-MM-DD |
| 점검 주기 | 월/분기/연간 |
| 현재 상태 | 정상/점검 예정/수리중/고장 |
| 액션 | [점검 등록] / [수리 접수] / [수정] / [삭제] |

#### 강조 표시

| 조건 | 색상 |
|------|------|
| 7일 이내 점검 예정 | 주황 |
| 점검 기한 초과 | 빨강 + 경고 |
| 수리 중 | 빨강 |
| 고장 | 빨강 + "사용 금지" |

### 장비 등록 (DLG-056-001)

장비명·유형·위치·점검 주기 입력.

### 점검 등록 (DLG-056-002)

점검 결과·점검자·다음 예정일 입력.

### 수리 접수 (DLG-056-003)

증상·담당자·예상 완료일 입력. 완료 후 정상 복구.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 장비 + 이력 | 등록·수정·삭제·점검·수리 |
| owner (센터장) | 전체 장비 + 이력 | 등록·수정·삭제·점검·수리 |
| manager | 전체 장비 + 이력 | 점검·수리 (삭제 불가) |
| fc / 스태프 | 장비 목록 + 이력 | 점검 완료 기록 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "시설관리 > 장비 점검 일정" 진입
2. 다음 점검 예정일 기준 정렬
3. 임박 장비 우선 확인

**점검 등록**
1. 행 [점검 등록] → DLG-056-002
2. 점검 결과·다음 예정일 입력
3. 저장 → 상태 갱신

**수리 접수**
1. 행 [수리 접수] → DLG-056-003
2. 증상·담당자 입력 → 상태 "수리중"
3. 수리 완료 → 정상 복구

## 화면 상태

| 정상 운영 | 초록 배지 |

| 수리 중 | 빨강 + 접수일 |

| 장비 없음 | 안내 + 등록 CTA |

## 비즈니스 규칙

1. 다음 점검 예정일이 7일 이내인 장비는 자동 알림이 발송된다.
2. 점검 기한 초과 장비는 빨강으로 강조되어 즉시 조치 필요를 표시한다.
3. 수리중·고장 장비는 회원 사용 차단 안내가 표시된다.
4. 점검 완료 시 다음 점검 예정일이 점검 주기에 따라 자동 갱신된다.
5. 점검·수리 이력은 감사 로그에 기록되며 영구 보관된다.
6. 장비 삭제는 manager+만 가능하다.
