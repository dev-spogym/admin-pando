## 기능 목적

타석 등록(번호/장비) + 상태(사용/대기/유지보수) + 예약 동기화.

## Lv2 / Lv3 세분화 매트릭스

본 기능의 상세 Lv2/Lv3 분해는 도메인 통합본(`시설관리.md`)의 매트릭스를 따른다. 본 폴더 단위 파일은 frontmatter + 핵심 요약을 제공한다.

## 권한 / RBAC

| 역할 | 조회 | 등록·수정 | 삭제 | 일괄 액션 |
|---|:---:|:---:|:---:|:---:|
| primary / superAdmin | ✅ | ✅ | ✅ | ✅ |
| owner (센터장) | ✅ | ✅ | ✅ | ✅ |
| manager | ✅ | ✅ | 일부 제한 | ✅ |
| fc / staff | 일부 | 일부 | ❌ | 일부 |
| readonly | ❌ | ❌ | ❌ | ❌ |

> 도메인별 RBAC 세부는 도메인 통합본의 "계정 권한 요약" 표를 따른다.

## 주요 UX 흐름

1. 사이드바 → 해당 도메인 → 골프 타석 관리 진입
2. 대상 검색 / 필터 적용
3. 액션 수행 (등록 / 수정 / 삭제 / 일괄)
4. 확인 모달 → 처리 완료 토스트
5. 목록 / 상세로 복귀

## 화면 상태

| 상태 | 표시 |
|------|------|
| 정상 | 데이터 + 액션 활성 |
| 빈 상태 | 일러스트 + 안내 + 진입 CTA |
| 로딩 | 스켈레톤 |
| API 실패 | 토스트 + 재시도 |
| 권한 부족 | 액션 비활성 + 안내 |

## 비즈니스 규칙

1. 권한 미보유 시 접근 차단.
2. 처리 결과는 감사 로그(SCR-097)에 기록된다.
3. 본사 통합 모드에서는 회원/직원 실제 소속 지점(`branchId`) 기준으로 처리한다.
4. 검색 디바운스는 300ms 통일.
5. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는 것을 원칙으로 한다.
6. 도메인 통합본의 "주요 비즈니스 규칙" 절이 본 기능에도 적용된다.
