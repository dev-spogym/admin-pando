## 기능 목적

골프 연습장 내 타석의 실시간 이용 현황을 관리하는 화면이다. 타석별 사용자·프로·남은 이용 시간을 실시간으로 확인하고, 이용 시작·종료·타석 간 이동·점검 처리를 수행한다. 대기 중인 회원 목록과 자동 배정 기능으로 빈 타석이 생기면 다음 대기자에게 즉시 안내할 수 있다.

## 주요 구성요소

### 현황 요약 카드 (5개)

| 카드 | 내용 |
|------|------|
| 전체 타석 수 | 합계 |
| 사용중 | in_use |
| 대기(빈 타석) | available |
| 예약 | reserved |
| 대기열 인원 | 대기 큐 |

### 타석 그리드 (4열)

각 타석 카드.

| 항목 | 표시 |
|------|------|
| 타석 번호 | 1, 2, 3... |
| 상태 배지 | 대기/사용중/예약/점검 |
| 이용 회원명 | 사용중 시 |
| 담당 프로명 | 사용중 시 |
| 남은 시간 | 카운트다운 |
| 프로젝터 토글 | on/off |
| 액션 | [시작] / [종료] / [이동] / [점검] |

#### 상태 색상

| 상태 | 색상 |
|------|------|
| 대기 | 초록 |
| 사용중 | 파랑 |
| 예약 | 노랑 |
| 점검 | 회색 |

### 시간 종료 알림

남은 시간 0 → 화면 상단 경고 팝업 ("⏰ [타석명] 시간 종료! ([회원명])").

### 대기열 패널 (하단)

| 항목 | 표시 |
|------|------|
| 순서 번호 | 1, 2, 3... |
| 회원명 | 클릭 시 SCR-M004 |
| 대기 시작 시각 | HH:mm |
| 예상 대기 시간 | 분 |

타석 종료 시 첫 번째 대기자 자동 배정.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 타석 + 대기열 | 시작·종료·이동·점검·프로젝터 |
| owner (센터장) | 전체 타석 + 대기열 | 시작·종료·이동·점검·프로젝터 |
| manager | 전체 타석 + 대기열 | 시작·종료·이동·점검·프로젝터 |
| fc / 스태프 / 프런트 | 전체 타석 + 대기열 | 시작·종료·점검 |
| 트레이너 | 담당 타석 | 프로젝터 제어만 |
| readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**이용 시작**
1. 사이드바 → "시설관리 > 골프 타석" 진입
2. 빈 타석 [시작] → 회원명 입력
3. 타이머 카운트다운 시작

**이용 종료 + 자동 배정**
1. 사용중 타석 [종료] → 초기화
2. 대기열 1번 회원 자동 배정 + 알림

**타석 이동**
1. 사용중 [이동] → 대상 타석 선택
2. 회원·남은 시간 새 타석으로 이동

**점검**
1. 빈 타석 [점검] → 점검중
2. [점검 해제] → 정상 복구

## 화면 상태

| 상태 | 설명 |
|---|---|
| 대기 | 초록 + [시작] 활성 |
| 사용중 | 파랑 + 회원·프로·시간 |
| 예약 | 노랑 + 예약 회원 |
| 점검 | 회색 + [점검 해제] |
| 시간 종료 | 상단 경고 팝업 |
| 대기열 없음 | "대기 중인 회원이 없습니다" |

## 비즈니스 규칙

1. 타석 종료 시 대기열 1번 회원이 있으면 자동 배정되고 알림이 발송된다.
2. 타석 이동 시 회원 정보와 남은 시간이 그대로 새 타석으로 이전된다.
3. 점검중 타석은 시작·예약 불가하다.
4. 대기 시간이 길어지면 회원에게 알림이 발송된다 (예: 30분 이상).
5. 트레이너는 본인 담당 타석의 프로젝터만 제어할 수 있다.
6. 시간 종료 후 N분 경과 시 자동 종료 처리되고 대기열 자동 배정된다.
7. 처리 결과는 감사 로그에 기록된다.
