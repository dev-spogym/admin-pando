## 기능 목적

골프 연습장 내 타석의 실시간 이용 현황을 관리하는 화면(SCR-054)이다. 타석별 사용자·프로·남은 이용 시간을 실시간으로 확인하고, 이용 시작·종료·타석 간 이동·점검 처리를 수행한다. 대기 중인 회원 목록과 자동 배정 기능으로 빈 타석이 생기면 다음 대기자에게 즉시 안내할 수 있다.

운영 맥락:
- **회원 입장 시 즉시 시작**: 빈 타석 [시작] → 회원 검색 → 이용 시간 입력 → 타이머 즉시 카운트다운
- **시간 종료 자동 안내**: 카운트다운 0초 도달 시 상단 경고 팝업 + 회원에게 알림 → 운영자 종료 처리
- **대기열 자동 배정**: 사용중 타석 종료 시 대기열 1번 회원 자동 배정 + 즉시 알림 발송
- **타석 간 이동**: 회원 요청 시 [이동] → 대상 빈 타석 선택 → 회원·남은 시간 그대로 이전
- **타석 점검 격리**: 스크린·매트·프로젝터 고장 시 [점검] 토글 → 신규 시작 차단 + 수리 접수
- **프로젝터 제어**: 트레이너가 본인 담당 타석 프로젝터 ON/OFF 직접 제어 (강의 모드)
- **장기 대기 회원 케어**: 30분 이상 대기 회원에게 자동 알림 → 운영자 직접 안내
- **자동 종료 처리**: 시간 종료 후 N분 경과 시 자동 종료 + 대기열 자동 배정 (정책 활성 시)
- **본사 통합 모드 운영**: 골프 운영 지점만 노출, 지점별 분리 관리

이용 시작·종료·이동·점검·자동 배정 모두 SCR-097 감사 로그에 기록되며, 자동 배정·시간 종료·장기 대기는 NFR-19 알림으로 회원에게 자동 발송된다.

## 주요 UX 흐름

**이용 시작**
1. 사이드바 → "시설관리 > 골프 타석" 진입
2. 빈 타석 [시작] → 회원명 입력
3. 타이머 카운트다운 시작

**이용 종료 + 자동 배정**
1. 사용중 타석 [종료] → 초기화
2. 대기열 1번 회원 자동 배정 + 알림

**타석 이동**
1. 사용중 [이동] → 대상 타석 선택
2. 회원·남은 시간 새 타석으로 이동

**점검**
1. 빈 타석 [점검] → 점검중
2. [점검 해제] → 정상 복구

### 분기·예외 흐름
- **회원 검색 0건**: "검색 결과가 없어요" + 회원 등록 안내
- **이미 다른 타석 이용 중인 회원에 시작 시도**: "해당 회원은 이미 [타석명]에서 이용 중입니다" + 차단
- **점검중 타석 시작 시도**: 클릭 차단 + "점검중 타석은 시작 불가, 점검 해제 후 시도하세요"
- **이동 시 대상 타석이 점검중·사용중**: 대상 선택 가능 영역에 비활성 + "빈 타석만 선택 가능합니다"
- **이동 후 대상 타석에 다른 운영자가 동시 시작**: 락 충돌 → "선택한 타석이 이미 사용중입니다" + 새로고침
- **점검 해제 시도(권한 부족)**: 버튼 hidden 또는 비활성
- **사용중 타석 점검 토글 시도**: "사용중 타석은 종료 후 점검 처리 가능합니다" + 종료 안내
- **자동 종료 정책 비활성**: 시간 종료 후 자동 종료 발생 안 함, 운영자 수동 종료 필요
- **대기열 자동 배정 실패(회원 부재 등)**: 운영자 수동 배정 가이드 + 다음 대기자 자동 배정 시도
- **트레이너 프로젝터 제어 권한 부족**: 본인 담당 타석 외 토글 비활성
- **본사 통합 모드 다른 지점 변경**: 권한자 외 차단

| 상태 | 설명 |
|---|---|
| 대기 | 초록 + [시작] 활성 |
| 사용중 | 파랑 + 회원·프로·시간 |

## 비즈니스 규칙

1. 타석 그리드는 4열 격자로 표시, 타석 수에 따라 행 자동 확장.
2. 타석 상태는 대기(available) / 사용중(in_use) / 예약(reserved) / 점검(maintenance) 4종.
3. 이용 시작 시 회원 검색은 자동완성(이름·연락처·번호), 디바운스 300ms.
4. 이용 시간은 30분 / 1시간 / 2시간 / 사용자 정의 (테넌트 정책으로 단위 설정 가능).
5. 카운트다운은 1초 단위로 서버 시간 동기화하여 타석 카드에 실시간 표시.
6. 시간 종료(0초 도달) 시 화면 상단 경고 팝업: "⏰ [타석명] 시간 종료! ([회원명])".
7. 자동 종료 정책: 시간 종료 후 N분(기본 5분) 경과 시 자동 종료 + 대기열 자동 배정 (테넌트 토글로 활성화).
8. 타석 종료 시 대기열 1번 회원이 있으면 자동 배정되고 알림(NFR-19)이 발송된다.
9. 타석 이동 시 회원 정보·남은 시간·담당 프로 모두 새 타석으로 이전, 이동 이력 기록.
10. 점검중 타석은 시작·예약 불가, 점검 해제 후 정상 복구.
11. 사용중 타석 점검 토글은 종료 선행 필수 (강제 점검 옵션은 권한자만 + 강제 종료).
12. 대기열은 도착 순(FIFO) + 회원 우선순위(VIP/일반) 정책 옵션.
13. 대기 시간이 30분 이상이면 회원에게 알림 발송 (정책 한도 변경 가능).
14. 예상 대기 시간은 평균 사용 시간 기반으로 자동 계산하여 표시.
15. 트레이너는 본인 담당 타석의 프로젝터만 제어 가능, 매니저+는 모든 타석 제어.
16. 프로젝터 토글은 IoT 명령 호출, 실패 시 3회 재시도 후 운영자 알림.
17. 권한별 액션: 슈퍼관리자 / 센터장 / 매니저는 시작·종료·이동·점검·프로젝터. FC / 스태프 / 프런트는 시작·종료·점검(이동 불가). 트레이너는 담당 타석 프로젝터만. readonly는 조회만.
18. 본사 통합 모드는 골프 운영 지점만 노출, 지점별 분리 운영.
19. 모든 시작·종료·이동·점검·프로젝터·자동 배정 처리는 감사 로그(SCR-097)에 actor·bay_id·member_id·before-after 기록.
20. 강제 종료(점검 토글 시) 회원에게 NFR-19 알림 자동 발송.
21. 그리드 색상 우선순위: 점검 > 사용중 > 예약 > 대기.
22. 대기열 자동 배정 실패(회원 부재 등) 시 다음 대기자 자동 시도, 모두 실패 시 운영자 수동 가이드.
