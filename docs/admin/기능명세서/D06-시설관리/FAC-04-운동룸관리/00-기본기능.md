## 기능 목적

센터 내 운동룸(GX룸·PT룸·스피닝룸·필라테스룸 등)의 현황과 예약 슬롯을 관리하는 화면이다. 각 룸의 운영 상태를 확인하고, 오늘의 시간대별 예약 혼잡도를 시각적으로 파악할 수 있다. 새 운동룸을 등록하거나 기존 룸 정보를 수정·삭제하고, 운영 상태를 빠르게 전환할 수 있다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 내용 |
|------|------|
| 전체 룸 수 | 합계 |
| 운영중 | status=operating |
| 점검·고장·미사용 | 비운영 합계 |
| GX룸 / PT룸 | 유형별 카운트 |

### 뷰 전환 탭

카드 보기 / 목록 보기.

### 유형 필터

전체 / GX / PT / 스피닝 / 필라테스 / 기타.

### 카드 보기

각 룸 카드.

| 항목 | 표시 |
|------|------|
| 룸명 | 이름 |
| 유형 배지 | GX/PT/필라/스피닝 |
| 수용 인원 | 정원 |
| 게이트 | 출입구 정보 |
| 운영 상태 배지 | 운영중/점검중/고장 |
| 룸 설명 | 부가 |
| 오늘 예약 슬롯 바 | 07:00~20:00 |
| 액션 | [수정] / [삭제] / [⚙ 상태] |

#### 슬롯 바 색상

| 상태 | 색상 |
|------|------|
| 여유 | 초록 |
| 혼잡 | 주황 |
| 만석 | 빨강 |
| 빈 시간 | 회색 |

#### 운영 상태 전환 (⚙)

운영중 → 점검중 → 고장 → 운영중 순환.

### 목록 보기

테이블 형태로 룸 일괄 조회.

### 새 운동룸 등록 (DLG-053-001)

| 항목 | 입력 |
|------|------|
| 룸명 | 텍스트 (필수) |
| 유형 | GX/PT/스피닝/필라/기타 |
| 수용 인원 | 숫자 |
| 게이트 | 텍스트 |
| 룸 설명 | textarea |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 룸 | 등록·수정·삭제·상태 전환 |
| owner (센터장) | 전체 룸 | 등록·수정·삭제·상태 전환 |
| manager | 전체 룸 | 상태 전환·수정 (삭제 불가) |
| fc / 스태프 / 프런트 | 전체 룸 | 상태 전환만 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "시설관리 > 운동룸 관리" 진입
2. 카드 보기 기본 + 유형별 그룹
3. 유형 필터로 좁히기

**룸 등록**
1. [+ 새 운동룸 등록] → DLG-053-001
2. 정보 입력 → 저장

**룸 수정**
1. 카드 [수정] → DLG-053-001
2. 변경 → 저장

**룸 삭제**
1. 카드 [삭제] → DLG-053-002
2. 사용 중 일정 있으면 차단 → 종료

**상태 전환**
1. 카드 [⚙] 클릭
2. 운영중 → 점검중 → 고장 → 운영중 순환

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 스켈레톤 |
| 정상 | 카드 그룹 |
| 고장 | 빨강 강조 |
| 점검중 | 투명도 80% + 주황 + "예약 불가" |
| 룸 없음 | "등록된 운동룸이 없습니다" + 등록 CTA |

## 비즈니스 규칙

1. 점검중·고장 상태 룸은 신규 예약을 받을 수 없다.
2. 운영 상태 전환은 ⚙ 버튼으로 순환되며, 변경 시 즉시 캘린더(SCR-C001)에 반영된다.
3. 룸 삭제는 사용 중인 일정이 0건일 때만 가능하다.
4. 룸 변경 이력은 감사 로그(SCR-097)에 기록된다.
5. 예약 슬롯 바는 SCR-C001 캘린더의 룸별 예약 데이터를 실시간 반영한다.
