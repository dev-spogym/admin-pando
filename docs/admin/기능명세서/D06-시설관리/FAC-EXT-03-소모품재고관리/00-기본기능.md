## 기능 목적

샴푸·린스·바디워시·타월·비누 등 센터 운영에 필요한 소모품의 재고 현황을 관리하는 화면이다. 현재 재고 수량을 실시간으로 파악하고, 입고·출고를 기록하며, 재고가 기준 수량 이하로 떨어진 품목을 식별해 적시에 발주할 수 있도록 지원한다.

## 주요 구성요소

### 현황 요약 카드 (4개)

| 카드 | 내용 |
|------|------|
| 전체 품목 수 | 합계 |
| 재고 부족 품목 | 안전 재고 미달 |
| 이번 달 총 출고량 | 합계 |
| 발주 대기 건수 | pending |

### 재고 부족 알림 영역

기준 수량 이하 품목을 상단에 별도 강조 표시.

### 소모품 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 품목명 | 이름 |
| 카테고리 | 분류 |
| 단위 | 개/박스/리터 |
| 현재 재고 | 수량 |
| 안전 재고 | 최소 기준 |
| 최근 입고일 | YYYY-MM-DD |
| 최근 출고일 | YYYY-MM-DD |
| 재고 상태 | 정상/부족/없음/대기 배지 |
| 액션 | [입출고] / [발주] / [수정] / [삭제] |

### 소모품 등록 (DLG-057-001)

품목명·카테고리·단위·안전 재고 기준.

### 입출고 처리 (DLG-057-002)

| 탭 | 입력 |
|----|------|
| 입고 | 수량 / 공급업체 / 단가 / 일자 |
| 출고 | 수량 / 사용 사유 / 일자 |

### 발주 생성 (DLG-057-003)

부족 품목 → 발주 수량·공급업체 입력 → 발주서 생성.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 + 이력 | 등록·수정·삭제·입출고·발주 |
| owner (센터장) | 전체 + 이력 | 등록·수정·삭제·입출고·발주 |
| manager | 전체 + 이력 | 입출고·발주 (삭제 불가) |
| fc / 스태프 | 전체 + 이력 | 출고 기록 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**출고 기록**
1. 사이드바 → "시설관리 > 소모품 재고" 진입
2. 사용 시 행 [입출고] → 출고 탭 → 수량 입력 → 저장

**입고 기록**
1. 도착 시 [입출고] → 입고 탭 → 수량·공급업체·단가 → 저장

**발주 생성**
1. 부족 품목 [발주] → DLG-057-003
2. 발주 수량·공급업체 → 발주서 생성

**소모품 등록**
1. [소모품 등록] → DLG-057-001
2. 품목명·카테고리·단위·안전 재고 → 저장

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 재고 | 초록 배지 |
| 재고 부족 | 빨강 배지 |
| 재고 없음 | 빨강 + "발주 필요" |
| 발주 대기 | 주황 배지 |
| 품목 없음 | 안내 + 등록 CTA |

## 비즈니스 규칙

1. 안전 재고 기준 이하 품목은 자동으로 "부족" 상태로 표시되고 알림이 발송된다.
2. 재고 0 품목은 "발주 필요" 안내가 표시된다.
3. 발주서 생성 후 입고 처리 시 자동으로 발주 대기 상태가 해제된다.
4. 출고 사유는 분류별 통계(청소·시설·이벤트 등)로 집계된다.
5. 소모품 삭제는 manager+만 가능하며, 사용 중 품목은 비활성으로 전환된다.
6. 입출고·발주 이력은 감사 로그에 기록된다.
