## 기능 목적

샴푸·린스·바디워시·타월·비누 등 센터 운영에 필요한 소모품의 재고 현황을 관리하는 화면(SCR-057)이다. 현재 재고 수량을 실시간으로 파악하고, 입고·출고를 기록하며, 재고가 기준 수량 이하로 떨어진 품목을 식별해 적시에 발주할 수 있도록 지원한다.

운영 맥락:
- **신규 소모품 등록**: 운영 도입 시 [소모품 등록] → 품목명·카테고리·단위·안전 재고 입력
- **일일 출고 기록**: 사용 발생 시 [입출고] → 출고 탭 → 수량·사유 입력 → 재고 자동 차감
- **공급업체 입고 기록**: 입고 시 [입출고] → 입고 탭 → 수량·공급업체·단가·일자 입력
- **재고 부족 자동 알림**: 안전 재고 미달 시 자동 "부족" 상태 + 운영자 알림
- **발주 생성**: 부족 품목 [발주] → 발주 수량·공급업체 → 발주서 생성 → 입고 시 자동 해제
- **재고 0 긴급 조치**: 재고 0 품목은 "발주 필요" 강조, 즉시 발주 권유
- **출고 사유 통계**: 청소·시설·이벤트 등 분류별 통계로 운영 비용 분석
- **본사 통합 모드 운영**: 지점별 소모품 분리 운영, 슈퍼관리자만 통합 조회
- **소모품 폐지**: 사용 종료 품목 비활성 또는 삭제 (사용 중 품목은 비활성으로 자동 전환)

등록·입출고·발주·삭제 모두 SCR-097 감사 로그에 기록되며, 부족·발주 권장은 NFR-19 알림으로 운영자에게 자동 발송된다.

## 주요 UX 흐름

**출고 기록**
1. 사이드바 → "시설관리 > 소모품 재고" 진입
2. 사용 시 행 [입출고] → 출고 탭 → 수량 입력 → 저장

**입고 기록**
1. 도착 시 [입출고] → 입고 탭 → 수량·공급업체·단가 → 저장

**발주 생성**
1. 부족 품목 [발주] → DLG-057-003
2. 발주 수량·공급업체 → 발주서 생성

**소모품 등록**
1. [소모품 등록] → DLG-057-001
2. 품목명·카테고리·단위·안전 재고 → 저장

### 분기·예외 흐름
- **품목명 중복 등록**: 동일 지점 내 품목명 중복 시 인라인 "동일 품목명이 존재합니다" + 저장 차단
- **출고 수량 > 현재 재고**: 인라인 "현재 재고를 초과할 수 없습니다 (현재: N)" + 저장 차단
- **출고 사유 미선택**: 인라인 "출고 사유를 선택해주세요"
- **입고 수량 0 또는 음수**: 인라인 "입고 수량은 1 이상" + 저장 차단
- **안전 재고 0 입력 시도**: 인라인 "안전 재고는 1 이상" + 저장 차단
- **발주 생성 시 공급업체 미입력**: "공급업체를 입력해주세요" + 저장 차단
- **발주 대기 상태에서 재발주 시도**: 경고 "이미 발주 대기 중입니다" + [추가 발주]/[취소]
- **삭제 시 사용 중 품목**: 자동 비활성 전환 안내 (영구 삭제 대신 비활성)
- **권한 부족 액션**: 버튼 hidden 또는 비활성
- **본사 통합 모드 다른 지점 변경**: 권한자 외 차단

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 재고 | 초록 배지 |
| 재고 부족 | 빨강 배지 |
| 재고 없음 | 빨강 + "발주 필요" |
| 발주 대기 | 주황 배지 |
| 품목 없음 | 안내 + 등록 CTA |

## 비즈니스 규칙

1. 소모품 상태는 정상(normal) / 부족(low) / 없음(empty) / 발주 대기(pending) 4종.
2. 카테고리는 위생용품 / 청소도구 / 사무용품 / 운동기구 / 기타 (테넌트 정의 가능).
3. 단위는 개 / 박스 / 리터 / 미터 / kg 등 (테넌트 정의).
4. 안전 재고 기준은 등록 시 필수 입력, 1 이상.
5. 안전 재고 기준 이하 품목은 자동으로 "부족" 상태로 표시 + 운영자 알림 발송.
6. 재고 0 품목은 자동 "없음" 상태 + "발주 필요" 강조 표시.
7. 발주 대기 상태는 발주서 생성 후 입고 처리 시 자동 해제.
8. 입고 처리 시 입고 수량·공급업체·단가·일자 필수 입력, 단가는 비용 집계용.
9. 출고 처리 시 출고 수량·사유·일자 필수, 사유는 분류별 통계 활용.
10. 출고 수량 > 현재 재고 시 차단, 운영자 수동 조정 필요.
11. 출고 사유 분류: 청소 / 시설 / 이벤트 / 회원 제공 / 기타 (테넌트 정의).
12. 발주 생성 시 발주 수량·공급업체·예상 도착일 입력, 발주서는 PDF 또는 이메일 발송 옵션.
13. 발주 후 부분 입고 가능, 잔여 수량은 발주 대기 상태 유지.
14. 소모품 삭제는 manager+ 권한, 사용 중 품목은 비활성 전환(soft delete), 미사용 품목은 영구 삭제 가능.
15. 권한별 가시성: 슈퍼관리자 / 센터장은 모든 작업. 매니저는 입출고·발주 가능, 삭제 불가. FC / 스태프는 출고 기록만. 트레이너 / readonly는 조회만.
16. 본사 통합 모드는 지점별 소모품 분리 운영, 슈퍼관리자만 통합 조회.
17. 모든 등록·입출고·발주·삭제 처리는 감사 로그(SCR-097)에 actor·consumable_id·before-after 기록.
18. 부족 알림: 안전 재고 미달 시 즉시 + 매일 09:00 운영자에게 재발송.
19. 발주 권장 알림: 재고 0 품목 매일 09:00 운영자 알림.
20. 입출고 이력 보관: 영구 보존, 90일 초과는 별도 분석 화면.
21. 강조 색상 우선순위: 없음 > 부족 > 발주 대기 > 정상.
22. 엑셀 다운로드: 검색·필터 결과, 파일명 `소모품현황_지점_YYYYMMDD.xlsx`.

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `FAC-EXT-03`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-057`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-057-001 소모품등록, DLG-057-002 입출고처리, DLG-057-003 발주생성`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
