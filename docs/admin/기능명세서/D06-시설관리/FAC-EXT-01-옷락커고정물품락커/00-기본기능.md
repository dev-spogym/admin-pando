## 기능 목적

회원이 사용하는 옷 락커와 운영 고정 물품 락커를 분리해서 관리하는 화면이다. 옷 락커는 회원 개인 용도로 일/주/월 단위로 임대되며, 고정 물품 락커는 운영용 비품(청소 도구·소모품 등) 보관 전용으로 일반 회원 배정 대상에서 제외된다. 두 카테고리를 분리해서 관리해야 옷 락커 회수·재배정 효율과 운영 자산 관리가 동시에 가능해진다.

## 주요 구성요소

### 락커 유형 탭

옷 락커 / 고정 물품 락커 분리.

### 옷 락커

| 항목 | 설명 |
|------|------|
| 회원 배정 | FAC-01과 동일 흐름 |
| 임대 기간 | 일/주/월 단위 |
| 만료 알림 | 자동 |
| 일괄 해제 | 만료 임박 |

### 고정 물품 락커

| 항목 | 설명 |
|------|------|
| 사용 용도 | 청소 도구 / 비품 / 소모품 |
| 배정 대상 | 운영 직원 또는 비품 (회원 배정 차단) |
| 메모 | 보관 물품 명세 |
| 점검 주기 | 월간/분기 |

### 일괄 작업

탭별 일괄 회수·재배정.

### 엑셀 다운로드

탭별 현황 엑셀.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 | 등록·수정·삭제·일괄 |
| owner (센터장) | 전체 | 등록·수정·삭제·일괄 |
| manager | 전체 | 등록·수정·일괄 |
| fc / 스태프 / 프런트 | 전체 | 옷 락커 배정·회수 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**옷 락커 운영**
1. 사이드바 → "시설관리 > 옷 락커" 진입
2. 회원 배정 (FAC-01과 동일)
3. 만료 임박 시 알림 + 일괄 회수

**고정 물품 락커 운영**
1. "고정 물품 락커" 탭
2. 비품 등록 + 보관 물품 메모
3. 점검 주기에 따라 점검

## 비즈니스 규칙

1. 옷 락커와 고정 물품 락커는 분리 카테고리로 관리되며 회원 배정 대상이 다르다.
2. 고정 물품 락커는 회원 배정이 차단되며 운영 비품 전용이다.
3. 옷 락커 임대 기간은 일/주/월 단위로 차등 가격이 적용될 수 있다 (정책).
4. 고정 물품 락커는 점검 주기에 따라 보관 물품 검수가 진행된다.
5. 변경 이력은 감사 로그(SCR-097)에 기록된다.
