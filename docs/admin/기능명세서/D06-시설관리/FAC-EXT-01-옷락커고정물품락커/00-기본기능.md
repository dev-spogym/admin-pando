## 기능 목적

회원이 사용하는 옷 락커와 운영 고정 물품 락커를 분리해서 관리하는 화면(SCR-I004 / SCR-I005)이다. 옷 락커는 회원 개인 용도로 일/주/월 단위로 임대되며, 고정 물품 락커는 운영용 비품(청소 도구·소모품 등) 보관 전용으로 일반 회원 배정 대상에서 제외된다. 두 카테고리를 분리해서 관리해야 옷 락커 회수·재배정 효율과 운영 자산 관리가 동시에 가능해진다.

운영 맥락:
- **옷 락커 회원 임대**: 신규 회원 또는 기존 회원에 일/주/월 단위 임대, 만료 임박 시 알림
- **고정 물품 락커 등록**: 청소 도구·소모품 보관용 락커 등록, 회원 배정 차단 플래그
- **옷 락커 만료 일괄 회수**: 매월 말 만료 임박 옷 락커 일괄 회수 + 재배정
- **고정 물품 정기 검수**: 월간/분기 점검 주기에 맞춰 보관 물품 상태 확인
- **카테고리 혼용 방지**: 회원 임대 시 고정 물품 락커 노출 차단, 운영자가 의도하지 않은 카테고리 사용 방지
- **본사 통합 모드 운영**: 지점별 락커 분리, 슈퍼관리자만 통합 조회
- **임대 가격 정책 차등**: 일/주/월 단위별 차등 가격 적용 (정책)

옷 락커 임대·회수·이동·고장은 FAC-01 락커 관리 흐름을 따르며, 고정 물품 락커는 별도 등록·점검 흐름으로 운영된다. 모든 변경 이력은 SCR-097 감사 로그에 기록된다.

## 주요 UX 흐름

**옷 락커 운영**
1. 사이드바 → "시설관리 > 옷 락커" 진입
2. 회원 배정 (FAC-01과 동일)
3. 만료 임박 시 알림 + 일괄 회수

**고정 물품 락커 운영**
1. "고정 물품 락커" 탭
2. 비품 등록 + 보관 물품 메모
3. 점검 주기에 따라 점검

### 분기·예외 흐름
- **고정 물품 락커에 회원 배정 시도**: 카테고리 잠금으로 클릭 차단 + "고정 물품 락커는 회원 배정 불가합니다"
- **옷 락커 임대 기간 미선택**: 인라인 "임대 기간(일/주/월)을 선택해주세요" + 저장 차단
- **만료일 과거 입력**: 인라인 "과거 일자로 임대 불가" + 저장 차단
- **고정 물품 락커 점검 주기 누락**: "점검 주기를 선택해주세요" + 저장 차단
- **카테고리 변경 시도(옷 → 고정 물품)**: 경고 "카테고리 변경 시 기존 임대가 해제됩니다" + [계속] / [취소]
- **삭제 시 사용 중 임대 존재**: 모달 "사용 중 임대 N건이 있어 삭제할 수 없습니다" + [회수 후 재시도] / [취소]
- **고정 물품 락커 검수 미완료 알림**: 점검 주기 경과 시 운영자에게 알림 + 상단 강조
- **본사 통합 모드 다른 지점 변경**: 권한자 외 차단
- **옷 락커 일일 자동 회수(정책 활성)**: 일 단위 임대 22:00 자동 회수
- **고정 물품 락커 점검 이력 누적**: 점검 이력 무한 보존, 90일 이상 데이터는 별도 화면

## 비즈니스 규칙

1. 옷 락커와 고정 물품 락커는 분리 카테고리(category=clothing / equipment)로 관리되며 회원 배정 대상이 다르다.
2. 고정 물품 락커는 회원 배정이 차단되며(is_member_assignable=false) 운영 비품 전용이다.
3. 카테고리 잠금: 회원 임대 시 고정 물품 락커는 그리드·검색·추천 모두 노출 차단.
4. 옷 락커 임대 기간은 일(1일) / 주(7일) / 월(30일) 3가지 + 사용자 정의(테넌트 정책).
5. 일 단위 임대는 22:00 자동 회수 정책 적용 가능, 주/월 단위는 만료일 기준.
6. 임대 기간별 차등 가격 정책: 일 < 주 < 월 단위 가격 차등, 결제 모듈(SCR-PAY)과 연계.
7. 고정 물품 락커 점검 주기: 월간 / 분기(3개월) / 연간 중 선택, 점검 미실시 시 경고.
8. 점검 주기 경과 시 운영자에게 NFR-19 알림 발송, 상단 강조 표시.
9. 보관 물품 메모는 자유 입력(최대 500자), 검수 시 참고용.
10. 카테고리 변경(옷 ↔ 고정)은 권한자만 가능, 변경 시 기존 임대 자동 해제 + 경고.
11. 삭제는 사용 중 임대 0건일 때만 가능 (옷 락커 회수 또는 고정 물품 검수 종료 후).
12. 일괄 작업: 옷 락커는 만료 임박 일괄 해제 / 일괄 배정 가능, 고정 물품 락커는 일괄 점검 가능.
13. 옷 락커 만료 임박 알림: HQ-09 락커 만료 본사 정책 step + 해당 지점 센터장(owner)이 추가한 락커 만료 지점 step + 해당 지점 ON 상태 기준으로 회원에게 발송.
13-1. 락커 만료 지점 추가 step은 센터장(owner)만 SCR-072/SCR-080A에서 생성·수정·삭제할 수 있으며 해당 지점에만 적용된다.
14. 고정 물품 락커 점검 알림: HQ-09 시설 점검 정책 step + 해당 지점 ON 상태 기준으로 발송, 미완료 시 추가 알림.
15. 검색은 락커 번호 정확 매치 또는 회원명/물품명 부분 매치, 디바운스 300ms.
16. 권한별 가시성: 슈퍼관리자 / 센터장은 모든 작업. 매니저는 등록·수정·일괄 가능, 삭제 불가. FC / 스태프는 옷 락커 배정·회수만 가능. 트레이너 / readonly는 조회만.
17. 본사 통합 모드는 지점별 락커 분리 운영, 슈퍼관리자만 통합 조회.
18. 모든 등록·수정·삭제·일괄·점검 처리는 감사 로그(SCR-097)에 actor·locker_id·category·before-after 기록.
19. 엑셀 다운로드: 탭별(옷·고정) 분리 다운로드, 파일명 `옷락커현황_지점_YYYYMMDD.xlsx` / `고정물품락커현황_지점_YYYYMMDD.xlsx`.
20. 옷 락커 회수 시 SCR-097 감사 로그 + 회원 NFR-19 알림 동시 발송.
21. 고정 물품 락커 점검 이력은 점검자 / 점검일 / 점검 결과 / 보관 물품 상태 기록.
22. 카테고리는 락커 등록 시 결정, 변경은 권한자만 (운영 안정성).

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `FAC-EXT-01`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-I004 / SCR-I005`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
