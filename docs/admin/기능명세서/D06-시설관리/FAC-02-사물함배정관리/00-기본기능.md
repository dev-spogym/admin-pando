## 기능 목적

센터 내 일일 사물함·개인 사물함·골프 사물함의 실시간 이용 현황을 시각적 그리드로 보여주고, 회원을 검색해 빈 사물함에 즉시 배정할 수 있는 화면(SCR-051)이다. 일반 락커 관리(SCR-050)가 장기 배정 관리에 초점을 맞춘다면, 본 화면은 당일 또는 단기 보관용 사물함의 빠른 배정·해제에 최적화되어 있다. 추천 사물함 자동 표시로 운영자가 회원에게 즉시 안내할 수 있다.

운영 맥락:
- **방문 회원 즉시 배정**: 회원 입장 시 회원명 자동완성 → 추천 사물함 → [배정하기] 1초 처리
- **마감 시간 일괄 해제**: 일일 사물함 22시 자동 만료, 잔여 미반환은 운영자가 [만료 일괄 해제]로 강제 회수
- **시간 초과 회원 알림**: 만료 시각 경과 시 깜빡이 표시 + 회원에게 알림 발송, 운영자 즉시 인지
- **골프 사물함 동시 운영**: 골프 타석 이용자에게 골프 사물함 별도 배정 (FAC-05 연계)
- **상태 비정상 사물함 격리**: 잠금 불량 시 클릭 차단 + 점검 등록(FAC-EXT-02)
- **단기 사물함 추가 등록**: 새 사물함 도입 시 manager+ 권한으로 번호 자동 부여 등록
- **본사 통합 모드 지점별 운영**: 지점 선택으로 해당 지점 사물함만 표시

배정·해제·일괄 처리 모두 SCR-097 감사 로그에 기록되며, 시간 초과·해제 시 NFR-19 알림이 회원에게 자동 발송된다.

## 주요 UX 흐름

**빠른 배정**
1. 사이드바 → "시설관리 > 사물함 배정" 진입
2. 일일 사물함 탭 기본 표시
3. 회원 검색 자동완성 → 선택
4. 추천 사물함 자동 또는 그리드 직접 클릭
5. 만료일 확인 → [배정하기] → 성공 메시지

**일괄 해제**
1. [만료 사물함 일괄 해제] 활성 시 클릭
2. 시간 초과 사물함 일괄 해제

### 분기·예외 흐름
- **회원 미선택 상태에서 [배정하기] 클릭**: 버튼 비활성, 인라인 안내 "회원을 먼저 선택해주세요"
- **빈 사물함 0개**: "사용 가능한 사물함 없음" + 추천 영역 hidden, [배정하기] 비활성
- **이미 사물함 보유 회원 추가 배정 시도**: "해당 회원에게 이미 사물함이 배정되어 있습니다" + 기존 번호 노출 + [기존 회수 후 재배정]/[추가 허용 권한자]/[취소]
- **상태 비정상 사물함 클릭**: 클릭 차단, 토스트 "상태 비정상 사물함은 배정할 수 없습니다. 점검 후 사용하세요"
- **만료일 과거 입력**: 인라인 "과거 일자로 배정할 수 없습니다" + 저장 차단
- **일괄 해제 시 시간 초과 0개**: 버튼 비활성 또는 "해제 대상 없음" 안내
- **탭 전환 중 회원 선택 유지**: 회원 선택은 유지되며 탭별 추천 사물함만 재계산
- **동시 배정 충돌 (다른 운영자)**: 락 충돌 → "선택한 사물함이 이미 배정되었습니다" + 재추천
- **시간 초과 회원이 직접 회수 신청**: 자동 회수 + 알림 발송, 운영자 그리드에서 깜빡임 제거
- **본사 통합 모드 다른 지점 사물함 배정 시도**: 지점 컨텍스트 미일치 시 차단

## 비즈니스 규칙

1. 추천 사물함은 사용 가능 상태 중 번호가 가장 작은 것이 자동 표시된다 (실시간).
2. 운영자가 그리드에서 다른 빈 사물함을 클릭하면 추천 영역 값이 갱신된다 (수동 우선).
3. 회원 검색은 이름·연락처·회원 번호 자동완성, 디바운스 300ms, 최소 2자 입력.
4. 만료일 기본값: 일일 사물함 = 당일 22:00 / 개인 사물함 = 오늘 + 3개월 / 골프 사물함 = 당일 22:00 (테넌트 정책 변경 가능).
5. 만료일 변경은 운영자 권한 내에서 자유롭게 가능, 단 과거 일자 차단.
6. 시간 초과(overtime) 상태는 만료 시점 경과 후 1분 이내 자동 갱신되어 그리드에 깜빡임으로 표시된다.
7. 상태 비정상(error) 사물함은 클릭 배정 차단, 점검 등록 후에만 정상 전환 가능.
8. 일일 사물함은 22:00에 배치 자동 만료 처리, 개인 사물함은 만료일 기준, 골프 사물함은 22:00.
9. 회원 1명당 사물함 보유 수 정책: 일일 사물함 1개 / 개인 사물함 1개 / 골프 사물함 1개 (기본). 정책 위반 시 차단.
10. 추천 사물함 미사용 시(직접 클릭) 운영자 의도 우선, 추천값은 무시.
11. 시간 초과 사물함 일괄 해제는 한 번에 최대 100개 처리, 그 이상은 chunked 백그라운드 처리.
12. 일괄 해제 시 회원 알림은 NFR-19로 발송 (시간 초과 알림은 별도 자동 발송).
13. 사물함 추가는 manager+ 권한, 번호 자동 부여(가장 큰 번호 + 1) 또는 수동 지정.
14. 권한별 가시성: 슈퍼관리자 / 센터장 / 매니저는 등록·삭제·일괄 처리 가능. FC / 스태프 / 프런트는 배정·해제만 가능. 트레이너 / readonly는 조회만.
15. 모든 배정·해제·일괄·추가 처리는 감사 로그(SCR-097)에 actor·locker_id·member_id·before-after 기록.
16. 본사 통합 모드는 지점별 사물함 분리 운영, 지점 컨텍스트 일치 시에만 변경 가능.
17. 엑셀 다운로드: 현재 탭과 검색 필터 적용 결과, 파일명 `사물함현황_지점_탭_YYYYMMDD.xlsx`.
18. 시간 초과 자동 알림: 만료 시각 도달 시 회원에게 푸시 + 회수 안내 메시지 발송.
19. 그리드 색상 우선순위: error > overtime > in_use > available.
20. 사물함 번호는 같은 유형 탭 내 고유, 다른 탭 간 중복 가능 (예: 일일 1번 / 골프 1번 공존).

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| SCR-097 감사 로그 | 배정·해제·일괄·추가·삭제 | actor·locker_id·member_id·before-after INSERT |
| 일일 사물함 22:00 자동 만료 배치 | 매일 22:00 | overtime 상태 갱신 + 일괄 회수(정책 활성 시) + 알림 |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `FAC-02`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-051`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
