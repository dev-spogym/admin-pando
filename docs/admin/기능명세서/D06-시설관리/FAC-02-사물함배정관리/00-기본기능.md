## 기능 목적

센터 내 일일 사물함·개인 사물함·골프 사물함의 실시간 이용 현황을 시각적 그리드로 보여주고, 회원을 검색해 빈 사물함에 즉시 배정할 수 있는 화면이다. 일반 락커 관리(SCR-050)가 장기 배정 관리에 초점을 맞춘다면, 본 화면은 당일 또는 단기 보관용 사물함의 빠른 배정·해제에 최적화되어 있다. 추천 사물함 자동 표시로 운영자가 회원에게 즉시 안내할 수 있다.

## 주요 구성요소

### 현황 요약 카드 (5개)

| 카드 | 내용 |
|------|------|
| 총 사물함 수 | 합계 |
| 사용 가능 | available |
| 사용중 | in_use |
| 시간 초과 | overtime |
| 상태 비정상 | error |

### 사물함 유형 탭

일일 사물함 / 개인 사물함 / 골프 사물함. 각 탭에 카운트 배지.

### 회원 배정 패널

| 항목 | 설명 |
|------|------|
| 회원 검색 | 자동완성 (이름·번호·연락처) |
| 추천 사물함 | 사용 가능 중 가장 작은 번호 자동 추천 |
| 만료일 | 기본 오늘 + 3개월 |
| [배정하기] | 회원·사물함 선택 시 활성 |

### 사물함 그리드

| 상태 | 색상 / 동작 |
|------|----------|
| 빈 사물함 | 클릭 시 배정 대상 선택 |
| 사용중 | 파랑 |
| 시간 초과 | 주황 + 깜빡임 |
| 상태 비정상 | 빨강 + 클릭 불가 |

### 만료 사물함 일괄 해제

시간 초과 사물함 한 번에 해제.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 탭 | 배정·해제·일괄·추가·엑셀 |
| owner (센터장) | 전체 탭 | 배정·해제·일괄·추가·엑셀 |
| manager | 전체 탭 | 배정·해제·일괄·추가·엑셀 |
| fc / 스태프 / 프런트 | 전체 탭 | 배정·해제 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**빠른 배정**
1. 사이드바 → "시설관리 > 사물함 배정" 진입
2. 일일 사물함 탭 기본 표시
3. 회원 검색 자동완성 → 선택
4. 추천 사물함 자동 또는 그리드 직접 클릭
5. 만료일 확인 → [배정하기] → 성공 메시지

**일괄 해제**
1. [만료 사물함 일괄 해제] 활성 시 클릭
2. 시간 초과 사물함 일괄 해제

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 스켈레톤 |
| 정상 | 탭 그리드 + 패널 |
| 배정 성공 | 3초 메시지 |
| 시간 초과 | 주황 + 깜빡임 |
| 상태 비정상 | 빨강 X + 클릭 불가 |
| 사용 가능 없음 | "사용 가능한 사물함 없음" |

## 비즈니스 규칙

1. 추천 사물함은 사용 가능 중 번호가 가장 작은 것으로 자동 표시된다.
2. 만료일 기본값은 오늘로부터 3개월 후이며 변경 가능하다.
3. 시간 초과(overtime) 상태는 만료 시점 경과 후 자동 표시된다.
4. 상태 비정상 사물함은 클릭으로 배정할 수 없다.
5. 일일 사물함은 당일 22시 자동 만료, 개인 사물함은 만료일 기준이다.
6. 일괄 해제 시 처리 결과는 감사 로그에 기록된다.
