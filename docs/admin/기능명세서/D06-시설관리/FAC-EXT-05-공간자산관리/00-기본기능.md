## 기능 목적

룸과 골프 타석 같은 공간 자산을 통합 운영하는 화면이다. 운영자가 공간 자산의 사용 상태와 예약 상황을 카드 단위로 즉시 파악하고, 상태 변경·예약 현황을 한 곳에서 확인할 수 있다. 운동룸 관리(FAC-04)와 골프 타석 관리(FAC-05)의 상위 통합 뷰로 작동한다.

## 주요 구성요소

### 자산 카드 그리드

자산별 카드 표시.

| 항목 | 표시 |
|------|------|
| 자산명 | 룸명 / 타석 번호 |
| 유형 | 룸 (GX/PT/스피닝/필라) / 타석 |
| 상태 배지 | 사용중 / 대기 / 점검 / 고장 |
| 현재 사용자 | 사용중 시 |
| 오늘 예약 슬롯 | 시각화 |
| 액션 | [상세] / [상태 변경] |

### 상태 변경

자산별 상태 토글 (사용중 / 대기 / 점검 / 고장).

### 예약 현황 확인

자산 클릭 → 오늘 + 이번 주 예약 일정 패널.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 자산 | 등록·수정·삭제·상태 |
| owner (센터장) | 전체 자산 | 등록·수정·상태 |
| manager | 전체 자산 | 상태 변경·예약 확인 |
| fc / 스태프 | 전체 자산 조회 | 상태 변경 (룸·타석 한정) |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "시설관리 > 공간 자산 관리" 진입
2. 자산 카드 그리드 한 화면 표시
3. 상태 색상으로 즉시 인식

**상태 변경**
1. 자산 카드 [상태 변경] 클릭
2. 상태 선택 → 사유 입력 → 저장
3. 캘린더(SCR-C001) 자동 반영

**예약 현황 확인**
1. 자산 카드 클릭 → 우측 패널
2. 오늘 + 이번 주 예약 일정 표시

## 화면 상태

| 상태 | 설명 |
|---|---|
| 사용중 | 파랑 카드 |
| 대기 | 초록 카드 |
| 점검 | 주황 카드 |
| 고장 | 빨강 카드 |
| 자산 없음 | 안내 + 등록 CTA |

## 비즈니스 규칙

1. 본 화면은 운동룸(FAC-04)과 골프 타석(FAC-05)의 상위 통합 뷰로 두 도메인 데이터를 모두 표시한다.
2. 상태 변경은 즉시 캘린더 + 예약 시스템에 반영된다.
3. 점검·고장 상태 자산은 신규 예약을 받지 못한다.
4. 카드 단위에서 상태가 즉시 읽혀야 한다는 퍼블리싱 포인트를 따른다.
5. 변경 이력은 감사 로그에 기록된다.
