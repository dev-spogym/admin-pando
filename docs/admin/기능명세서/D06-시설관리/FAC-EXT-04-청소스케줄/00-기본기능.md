## 기능 목적

센터 내 구역별 청소 담당자와 정기 청소 일정을 관리하는 화면(SCR-058)이다. 오늘의 청소 완료 여부를 체크하고, 정기 청소(주간·월간) 일정을 등록하며, 청소 완료 이력을 기록한다. 담당자별 청소 현황을 파악해 시설 위생 관리의 누락을 방지한다.

운영 맥락:
- **일일 청소 진행**: 담당자가 오늘 청소 완료 후 체크 → 시간 자동 기록
- **정기 청소 일정 등록**: 주간(월·수·금) / 월간(매월 지정일) 정기 일정 등록 → 자동 반복 생성
- **시간 초과 미완료 강조**: 예정 시간 경과 후 미완료 구역 빨강 강조 → 운영자 즉시 인지
- **담당자 미지정 강조**: 담당자 없는 구역 상단 강조 → 즉시 배정 유도
- **전체 완료 축하**: 모든 구역 완료 시 100% + 축하 메시지 → 팀 사기 진작
- **담당자별 통계 분석**: 직원별 청소 완료율 집계 → 인사 평가 활용
- **이력 조회로 위생 감사**: 보건 점검 등 외부 감사 시 청소 이력 제출
- **본사 통합 모드 운영**: 지점별 일정 분리, 슈퍼관리자만 통합 조회
- **소모품 자동 출고 연계**: 청소 완료 시 사용 소모품 자동 출고(FAC-EXT-03 연계, 정책 옵션)

스케줄 등록·완료·수정·삭제 모두 SCR-097 감사 로그에 기록되며, 시간 초과·담당자 미지정·정기 일정 자동 생성은 NFR-19 알림으로 운영자에게 자동 발송된다.

### 오늘의 청소 현황 카드 (4개)

| 카드 | 내용 |
|------|------|
| 오늘 전체 구역 수 | 예정 |
| 완료 구역 수 | 완료 |
| 미완료 구역 수 | 미완료 |
| 완료율 | % |

### 청소 구역 체크리스트

| 컬럼 | 설명 |
|------|------|
| 구역명 | 헬스장/탈의실/샤워실 등 |
| 청소 유형 | 일일 / 정기 |
| 담당자 | 클릭 시 STF-02 |
| 예정 시간 | HH:mm |
| 완료 체크박스 | 클릭 시 자동 시간 |
| 완료 시간 | HH:mm |

### 정기 청소 일정 캘린더·목록

주간·월간 정기 일정 달력 또는 목록 뷰.

### 청소 스케줄 등록 (DLG-058-001)

| 입력 | 설명 |
|------|------|
| 구역명 | 텍스트 (필수) |
| 청소 유형 | 일일 / 주간 / 월간 |
| 담당자 | 직원 검색 |
| 주기 | 월~일 / 매월 지정일 |
| 예정 시간 | HH:mm |

### 이력 조회

기간별 완료 이력 + 담당자 통계.

## 주요 UX 흐름

**일일 운영**
1. 사이드바 → "시설관리 > 청소 스케줄" 진입
2. 오늘 현황 카드 + 체크리스트
3. 청소 완료 후 체크 → 시간 자동 기록

**스케줄 등록**
1. [청소 스케줄 등록] → DLG-058-001
2. 구역·유형·담당자·주기·시간 입력
3. 저장 → 일정 추가

**이력 조회**
1. 기간 선택 → 완료 이력 + 통계

### 분기·예외 흐름
- **본인 담당 외 구역 체크 시도**: "본인 담당 구역만 체크 가능합니다" + 차단 (manager+는 모든 구역 체크 가능)
- **이미 완료된 구역 재체크 시도**: 토스트 "이미 완료 처리된 구역입니다" + 변경 차단 (취소는 권한자만)
- **완료 취소 시도(권한 부족)**: 버튼 hidden, 매니저+에게 요청 안내
- **구역명 중복 등록**: 동일 지점 내 구역명 중복 시 인라인 "동일 구역명 존재" + 저장 차단
- **담당자 미지정 등록 시도**: 경고 "담당자 미지정으로 저장할까요?" + [확인] / [담당자 지정] 옵션
- **예정 시간 미입력**: 인라인 "예정 시간을 입력해주세요" + 저장 차단
- **정기 일정 주기 미선택**: 인라인 "주기를 선택해주세요" + 저장 차단
- **시간 초과 후 완료 처리**: 정상 완료 처리, 단 "지연 완료" 표시 + 통계 반영
- **담당자 변경 시 진행 중 일정**: 경고 "기존 담당자 진행 중인 일정이 있습니다" + [계속] / [취소]
- **본사 통합 모드 다른 지점 변경**: 권한자 외 차단

## 비즈니스 규칙

1. 청소 유형은 일일 / 주간 / 월간 3종, 등록 시 단일 선택.
2. 청소 주기 정책: 일일은 매일 / 주간은 요일 선택(다중) / 월간은 매월 지정일 또는 지정 번째 요일.
3. 구역명은 동일 지점 내 고유, 중복 등록 차단.
4. 담당자는 직원 검색으로 지정, 미지정 시 경고 + 상단 강조 (저장 가능).
5. 예정 시간은 HH:mm 형식 필수 입력, 운영 시간 내 권장.
6. 완료 체크 시 현재 시간이 완료 시간으로 자동 기록 (운영자 수동 변경 불가, 권한자만 정정).
7. 예정 시간 경과 후 미완료 구역은 빨강으로 강조, 시간 초과 알림 운영자 발송.
8. 시간 초과 후 완료 처리 시 "지연 완료" 표시, 통계는 정상 완료와 분리 집계.
9. 담당자는 본인 담당 구역만 체크 가능, manager+는 모든 구역 체크 가능.
10. 완료 취소(체크 해제)는 manager+ 권한만, 일반 담당자는 한 번 완료한 구역 변경 불가.
11. 정기 청소 일정은 매일 자정에 자동 반복 생성 (등록된 주기 기반).
12. 정기 일정 변경 시 미래 분만 영향, 과거 이력은 유지.
13. 정기 일정 삭제 시 미래 인스턴스 모두 삭제, 과거 이력은 유지.
14. 완료 이력은 90일 이상 보관, 담당자별 통계 활용.
15. 담당자 변경 시 진행 중 일정 영향 경고, 운영자 확인 후 적용.
16. 권한별 가시성: 슈퍼관리자 / 센터장은 등록·수정·삭제·담당자 지정·완료. 매니저는 등록·완료 체크. FC / 스태프는 담당 구역 완료 체크만. 트레이너 / readonly는 조회만.
17. 본사 통합 모드는 지점별 일정 분리, 슈퍼관리자만 통합 조회.
18. 모든 등록·완료·수정·삭제 처리는 감사 로그(SCR-097)에 actor·schedule_id·completion_time·before-after 기록.
19. 알림: 시간 초과 미완료 발생 시 운영자 + 담당자에게 NFR-19 알림.
20. 담당자 미지정 알림: 정기 일정에 담당자 없는 경우 매일 09:00 운영자 알림.
21. FAC-EXT-03 소모품 출고 연계: 청소 완료 시 사용 소모품 자동 출고 옵션 (테넌트 정책).
22. 전체 완료 시 100% + 축하 메시지 표시, 모든 구역 완료 인지를 시각적 피드백으로 제공.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `FAC-EXT-04`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-058`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-058-001 청소스케줄등록`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
