## 기능 목적

센터 내 구역별 청소 담당자와 정기 청소 일정을 관리하는 화면이다. 오늘의 청소 완료 여부를 체크하고, 정기 청소(주간·월간) 일정을 등록하며, 청소 완료 이력을 기록한다. 담당자별 청소 현황을 파악해 시설 위생 관리의 누락을 방지한다.

## 주요 구성요소

### 오늘의 청소 현황 카드 (4개)

| 카드 | 내용 |
|------|------|
| 오늘 전체 구역 수 | 예정 |
| 완료 구역 수 | 완료 |
| 미완료 구역 수 | 미완료 |
| 완료율 | % |

### 청소 구역 체크리스트

| 컬럼 | 설명 |
|------|------|
| 구역명 | 헬스장/탈의실/샤워실 등 |
| 청소 유형 | 일일 / 정기 |
| 담당자 | 클릭 시 STF-02 |
| 예정 시간 | HH:mm |
| 완료 체크박스 | 클릭 시 자동 시간 |
| 완료 시간 | HH:mm |

### 정기 청소 일정 캘린더·목록

주간·월간 정기 일정 달력 또는 목록 뷰.

### 청소 스케줄 등록 (DLG-058-001)

| 입력 | 설명 |
|------|------|
| 구역명 | 텍스트 (필수) |
| 청소 유형 | 일일 / 주간 / 월간 |
| 담당자 | 직원 검색 |
| 주기 | 월~일 / 매월 N일 |
| 예정 시간 | HH:mm |

### 이력 조회

기간별 완료 이력 + 담당자 통계.

### 강조 표시

| 조건 | 표시 |
|------|------|
| 완료 | 초록 체크 + 시간, 행 옅은 초록 |
| 미완료 | 빈 체크박스 |
| 시간 초과 미완료 | 빨강 강조 |
| 담당자 미지정 | 상단 강조 |
| 전체 완료 | 100% + 축하 메시지 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 + 이력 | 등록·수정·삭제·담당자 지정·완료 |
| owner (센터장) | 전체 + 이력 | 등록·수정·삭제·담당자 지정·완료 |
| manager | 전체 + 이력 | 등록·완료 체크 |
| fc / 스태프 | 담당 구역 | 담당 구역 완료 체크 |
| 트레이너 / readonly | 현황 조회 | 변경 불가 |

## 주요 UX 흐름

**일일 운영**
1. 사이드바 → "시설관리 > 청소 스케줄" 진입
2. 오늘 현황 카드 + 체크리스트
3. 청소 완료 후 체크 → 시간 자동 기록

**스케줄 등록**
1. [청소 스케줄 등록] → DLG-058-001
2. 구역·유형·담당자·주기·시간 입력
3. 저장 → 일정 추가

**이력 조회**
1. 기간 선택 → 완료 이력 + 통계

## 화면 상태

| 상태 | 설명 |
|---|---|
| 완료 | 초록 체크 + 시간 |
| 미완료 | 빈 체크박스 |
| 시간 초과 | 빨강 강조 |
| 오늘 일정 없음 | "오늘 예정된 청소 일정이 없습니다" |
| 전체 완료 | 100% + 축하 메시지 |

## 비즈니스 규칙

1. 완료 체크 시 완료 시간이 자동 기록된다.
2. 예정 시간 경과 후 미완료 구역은 빨강으로 강조된다.
3. 담당자는 본인 담당 구역만 체크 가능하며, manager+는 모든 구역 체크 가능하다.
4. 정기 청소 일정은 자동으로 매주/매월 반복 생성된다.
5. 완료 이력은 90일 이상 보관되며 담당자별 통계에 활용된다.
6. 처리 결과는 감사 로그에 기록된다.
