## 기능 목적

특정 목표(신규 회원 유치 / 재등록 유도 / 브랜드 인지도 향상 / VIP 보상 등)를 위한 마케팅 캠페인을 통합 생성·실행·실적 추적하는 화면이다. 대상 회원 세그먼트(MBR-09 연계)를 지정하고 메시지(MKT-01) / 쿠폰(MKT-03) / 이벤트(MKT-07 리퍼럴) / AB 테스트(MKT-09)를 캠페인 단위로 묶어 도달 / 클릭 / 전환 / 매출 / ROI 지표를 자동 집계한다.

운영 맥락:
- **신규 유치 캠페인**: 일반인 대상 SNS 광고 + 5,000원 환영 쿠폰 + 등록 감사 알림톡 패키지
- **재등록 유도 캠페인**: 만료 회원 세그먼트 + 10% 할인 쿠폰 + 만료 D-7 알림톡
- **VIP 보상 캠페인**: VIP 등급 세그먼트 + 마일리지 보너스 + 감사 메시지
- **브랜드 인지도 캠페인**: 일반 회원 + SNS 콘텐츠 공유 이벤트
- **계절 이벤트**: 신년·여름·연말 한정 캠페인
- **시작일 자동 활성**: 등록 시 시작일 도래하면 자동 활성, 메시지·쿠폰 자동 발송
- **종료일 자동 종료**: 종료일 경과 시 자동 종료, 결과 분석 단계 진입
- **ROI 자동 계산**: (캠페인 기간 매출 - 예산) / 예산 × 100, 실시간 갱신
- **UTM 추적**: 외부 채널(SNS·인터넷 광고) UTM 파라미터로 유입 추적
- **AB 테스트 연동 (MKT-09)**: 캠페인 내 메시지·쿠폰 AB 비교 후 우수안 자동 적용

캠페인 목록 + DLG-076-001 등록 + 실적 패널 + DLG-076-002 삭제 위자드로 통합 관리한다.

## 주요 UX 흐름

### 캠페인 생성 흐름
1. 사이드바 → "마케팅 > 캠페인 관리" 진입
2. [캠페인 생성] → DLG-076-001
3. 캠페인명 + 목표(신규 유치/재등록/인지도/VIP 보상/기타) + 대상 세그먼트(MBR-09 다중 조건) + 기간(시작~종료) + 채널(SMS/카톡/푸시/쿠폰/이벤트 다중) + 메시지·쿠폰 연결 + 예산 입력
4. 저장 → 준비 상태로 등록

### 시작일 자동 활성 흐름
1. 매일 04:00 배치 또는 시작일 00:00 트리거
2. 시작일 도래 캠페인 → "진행" 상태로 전환
3. 연결된 메시지·쿠폰 자동 발송 시작
4. 실적 카운트 시작

### 진행 중 모니터링 흐름
1. 캠페인 행 [실적] → 실적 패널
2. 도달 수 / 클릭 수 / 전환 수 / ROI 실시간 표시
3. UTM 추적 시 외부 채널별 분리 집계

### 종료일 자동 종료 흐름
1. 매일 04:00 배치 또는 종료일 24:00 트리거
2. 종료일 경과 캠페인 → "종료" 상태로 전환
3. 메시지·쿠폰 발송 중단
4. 최종 결과 집계 + 아카이브

### 분기·예외 흐름
- **시작일 > 종료일**: 인라인 에러 + 저장 차단
- **시작일이 과거**: 즉시 활성 또는 인라인 에러 (정책)
- **세그먼트 0명**: "대상 회원이 없습니다" 안내 + 저장 차단
- **연결 메시지·쿠폰 미선택**: "최소 1개 이상 연결 필요" + 저장 차단
- **예산 0 이하**: 인라인 에러
- **진행 중 캠페인 전체 수정 시도**: "진행 중 캠페인은 일부만 수정 가능 (대상 추가, 메시지 수정 제한)" 안내
- **진행 중 캠페인 삭제**: DLG-076-002 → "즉시 종료 처리됩니다" 안내 → 확인
- **시작일 자동 활성 시 잔여 포인트 부족**: 발송 보류 + 운영자 알림 + 충전 후 재시도
- **연결 쿠폰 만료**: 캠페인 시작 시 쿠폰 만료 시 발급 차단 + 알림
- **예산 초과**: 비용이 예산 초과 시 알림 + 발송 중단 옵션 (정책)
- **세그먼트 변경 (MBR-09)**: 캠페인 시작 후 세그먼트 멤버 변동 시 신규 멤버 발송 또는 시작 시점 고정 (정책)
- **AB 테스트 연동 (MKT-09)**: AB 테스트 진행 중 캠페인 종료 시 우수안 자동 적용 또는 수동 채택
- **UTM 파라미터 누락**: 외부 채널 ROI 분리 집계 안 됨 + 안내
- **캠페인 메시지 발송 webhook 실패**: 자동 재시도 3회 + 운영자 알림
- **종료된 캠페인 재활성**: 차단 (새 캠페인 등록만)
- **삭제 권한 부족**: 버튼 hidden
- **본사 캠페인 vs 지점 캠페인 충돌**: 본사 우선 또는 둘 다 발송 (정책)
- **가족 그룹 묶음 발송 (MBR-07)**: 캠페인에 가족 묶음 옵션 적용 시 그룹당 1명에게만 발송
- **법정 시간 발송 차단**: 21~08시 영업/광고 자동 차단 (캠페인도 동일)
- **수신 거부 / 휴면 회원 자동 제외**: 모든 캠페인 발송에 자동 적용

## 비즈니스 규칙

1. **상태 3종**: 준비 / 진행 / 종료. 시작일 자동 활성, 종료일 자동 종료.
2. **진행 전 수정**: 전체 수정 가능 (모든 항목).
3. **진행 중 수정**: 일부만 가능 (대상 추가, 메시지 추가). 기존 메시지·쿠폰 변경 제한.
4. **삭제 정책**: 진행 전 캠페인은 hard delete. 진행 중 캠페인은 즉시 종료 + soft delete (결과 보존).
5. **ROI 자동 계산**: ROI = (캠페인 기간 매출 - 예산) / 예산 × 100. 매출은 UTM·쿠폰 매핑된 결제 합계.
6. **시작일·종료일 검증**: 시작일 ≤ 종료일. 시작일 과거 시 즉시 활성 또는 차단 (정책).
7. **세그먼트 정책**: MBR-09 다중 조건 사용. 세그먼트 0명이면 저장 차단.
8. **세그먼트 변동**: 캠페인 시작 후 세그먼트 멤버 변동 시 신규 멤버 발송 또는 시작 시점 고정 (`segment_freeze` 정책).
9. **연결 자원**: 메시지(MKT-01) / 쿠폰(MKT-03) / 이벤트(MKT-07) / AB 테스트(MKT-09). 다중 연결 가능.
10. **자동 발송**: 시작일 자동 활성 시 연결된 메시지·쿠폰 자동 발송. 잔여 포인트 부족 시 보류.
11. **예산 관리**: 비용 누적 추적. 예산 초과 시 알림 + 발송 중단 옵션 (`auto_pause_on_budget`).
12. **UTM 추적**: 외부 채널 (SNS·인터넷·카톡) UTM 파라미터로 유입 분리 집계.
13. **AB 테스트 연동 (MKT-09)**: 캠페인 내 메시지·쿠폰 AB 진행 후 우수안 자동 적용 또는 수동 채택.
14. **법정 시간 차단**: 21~08시 영업/광고 발송 차단 (자동 알림 정보성 예외).
15. **수신 거부 / 휴면 자동 제외**: 모든 캠페인 발송에 자동 적용.
16. **가족 묶음 옵션 (MBR-07)**: 캠페인에 가족 묶음 활성 시 그룹당 1명에게만 발송.
17. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 캠페인 + 본사 통합 캠페인
    - 센터장 / 매니저: 소속 지점 캠페인 + 생성·수정·삭제·실적
    - FC / 트레이너 / 스태프 / readonly: 차단
18. **캠페인명 정책**: 1~50자.
19. **목표 5종**: 신규 유치 / 재등록 유도 / 브랜드 인지도 / VIP 보상 / 기타.
20. **실적 캐시**: 도달 / 클릭 / 전환 / ROI 5분 캐시. 결제·발송 트리거 시 무효화.
21. **캠페인 결과 보존**: 종료 후 영구 보존 + 아카이브. 추후 분석·재사용 가능.
22. **본사 통합 캠페인**: 슈퍼관리자가 전 지점 일괄 등록. 지점에서 일부 조정 (`hq_owned=true`).
23. **변경 이력 / 감사 로그**: 등록·수정·삭제·종료·자동 활성 모두 SCR-097 기록.
24. **캠페인 동시 운영**: 동일 회원이 다중 캠페인 대상일 경우 모두 발송 또는 우선순위 정책 (테넌트 설정).
