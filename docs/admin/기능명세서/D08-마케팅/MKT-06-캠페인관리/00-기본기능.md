## 기능 목적

특정 목표(신규 회원 유치, 재등록 유도, 브랜드 인지도 향상 등)를 위한 마케팅 캠페인을 생성하고 실적을 추적하는 화면이다. 대상 회원 세그먼트를 지정하고 메시지·쿠폰·이벤트를 캠페인 단위로 묶어 통합 관리한다. ROI 분석으로 캠페인 효과를 정량화한다.

## 주요 UX 흐름

**캠페인 생성**
1. 사이드바 → "마케팅 > 캠페인 관리" 진입
2. [캠페인 생성] → DLG-076-001
3. 목표·세그먼트·기간·채널·메시지·쿠폰 설정
4. 저장 → 준비 상태

**진행 모니터링**
1. 시작일 자동 활성 → 메시지·쿠폰 자동 발송
2. 실적 패널에서 실시간 모니터링
3. ROI 추적

**종료 분석**
1. 종료일 자동 종료
2. 결과 분석 → 다음 캠페인 전략 반영

## 화면 상태

| 상태 | 설명 |
|---|---|
| 데이터 미연동 | 목업 표시 |
| 캠페인 없음 | 안내 + 생성 CTA |
| 진행 중 | 실시간 실적 |
| 종료 | 회색 + 결과 |

## 비즈니스 규칙

1. 캠페인은 시작일 자동 활성, 종료일 자동 종료된다.
2. 진행 전 캠페인은 전체 수정 가능하나, 진행 중에는 일부만 변경 가능하다 (대상 추가, 메시지 수정 제한).
3. 캠페인 삭제 시 진행 중인 캠페인은 즉시 종료 처리된다.
4. ROI = (캠페인 기간 매출 - 예산) / 예산 × 100 으로 계산한다.
5. 메시지·쿠폰·이벤트가 캠페인에 연결되면 통합 추적된다.
6. 변경 이력은 감사 로그에 기록된다.
