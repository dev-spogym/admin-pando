## 기능 목적

아직 회원으로 등록되지 않은 잠재 고객(문의·상담 대상)을 등록하고, 상담 단계별 진행 상황을 추적해 회원 전환율을 높이는 마케팅 도메인의 핵심 화면이다. FC는 담당 리드의 후속 상담을 관리하고, 매니저는 전체 리드 전환율을 모니터링한다. 칸반 DnD로 상담 단계를 직관적으로 변경하고 상담 상세 패널에서 메모·후속 액션·이력을 한 화면에서 처리한다.

## 주요 구성요소

### 요약 지표 카드 (5개)

| 카드 | 내용 |
|------|------|
| 전체 리드 수 | 합계 |
| 등록 전환 수 | 등록완료 카운트 |
| 전환율 | 등록완료 / 전체 |
| 대기 중 | 신규 + 연락완료 |
| 미전환율 | 미전환 / 전체 |

### 상태별 분포 카드 (7종)

신규 / 연락완료 / 상담예정 / 방문완료 / 등록완료 / 미전환 / 보류. 0건 상태는 숨김.

### 필터

| 필터 | 옵션 |
|------|------|
| 상태 | 7종 (다중) |
| 유입경로 | 간판 / 인터넷 / 전단지 / 추천 / SNS / 카카오톡 / 전화문의 / 방문 / 기타 |
| 문의 유형 | WI(방문) / TI(전화문의) / 체험 / 일일입장 |

### 뷰 전환

목록 뷰(테이블) ↔ 칸반 뷰(상태별 컬럼).

### 리드 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 문의일 | YYYY-MM-DD |
| 이름 | 클릭 시 상세 패널 |
| 연락처 | 010 자동 |
| 유입경로 | 9종 |
| 상담 단계 | 7종 배지 |
| 담당 FC | 클릭 시 STF-02 |
| 후속 예정일 | YYYY-MM-DD |
| 메모 | 미리보기 |
| 액션 | [수정] / [삭제] |

### 상담 방식 컬럼

외부 `[신규DB]` N/R/V열의 1차·2차·3차 상담 방식. 값은 `대면`, `유선`, `부재` 제한.

### 칸반 뷰

상태 컬럼 배치 + DnD 단계 변경. 카드 이동 시 단계 변경 이력 자동 기록.

### 상담 상세 패널

리드 카드/행 클릭 → 우측 패널 슬라이드.

| 영역 | 기능 |
|------|------|
| 메모 | 작성·수정·삭제 |
| 후속 액션 등록 | 전화/방문/문자 예정 + 일정 |
| 단계 변경 이력 | 타임라인 |

### 리드 등록

[+ 리드 등록] → DLG-070-001.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 리드 | 등록·수정·삭제·상태·칸반 |
| owner (센터장) | 소속 센터 전체 리드 | 등록·수정·삭제·상태·칸반 |
| manager | 소속 센터 전체 리드 | 등록·수정·삭제·상태·칸반 |
| fc | 소속 센터 전체 (담당 우선) | 등록·수정·상태 (삭제 불가) |
| 트레이너 / 스태프 | 접근 제한 | 마케팅 도메인 ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**리드 조회 + 칸반 운영**
1. 사이드바 → "마케팅 > 리드 관리" 진입
2. 요약 카드 + 상태 분포로 현황 파악
3. 칸반 뷰 전환 → 카드 DnD로 상태 변경
4. 카드 클릭 → 상담 상세 패널

**리드 등록**
1. [+ 리드 등록] → DLG-070-001
2. 정보 입력 → 저장

**상담 처리**
1. 리드 클릭 → 상세 패널
2. 메모 작성 + 후속 액션 등록
3. 칸반에서 단계 변경

**리드 삭제**
1. 행 [삭제] → DLG-070-002
2. 확인 → 삭제

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 스켈레톤 |
| 정상 | 테이블 또는 칸반 |
| 리드 없음 | "등록된 리드가 없습니다" |
| 검색 결과 없음 | 안내 |
| 칸반 열 비어있음 | "없음" |

## 비즈니스 규칙

1. 상담 단계는 신규/연락완료/상담예정/방문완료/등록완료/미전환/보류 7종으로 고정한다.
2. 등록완료로 변경되면 전환율 통계에 자동 반영된다.
3. 칸반 DnD로 단계 변경 시 변경 이력이 자동 기록된다.
4. 문의 유형은 외부 `[신규DB]` 매핑 값으로 저장되며, 화면 라벨 `방문`은 `WI`, `전화문의`는 `TI`로 매핑한다.
5. 상담 방식 값은 `대면`/`유선`/`부재` 3종으로 제한된다.
6. FC는 본인 담당 리드를 우선 표시하지만 소속 센터 전체 리드는 조회·수정 가능하다.
7. 회원 전환 시 회원 마스터(MBR)에 자동 등록되며 리드와 매핑된다.
