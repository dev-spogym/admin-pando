## 기능 목적

기존 회원이 지인을 추천해 새 회원을 유치하면 추천인과 피추천인 모두에게 혜택을 제공하는 리퍼럴(회원 추천) 프로그램을 설정하고 실적을 관리하는 화면이다. 구전 마케팅을 체계화해 신규 회원 유치 비용을 절감한다.

## 주요 구성요소

### 리퍼럴 이벤트 목록

| 컬럼 | 설명 |
|------|------|
| 이벤트명 | 이름 |
| 추천인 혜택 | 마일리지/쿠폰/할인 |
| 피추천인 혜택 | 마일리지/쿠폰/할인 |
| 기간 | 시작 ~ 종료 |
| 참여 수 | 추천 건수 |
| 상태 | 준비 / 진행 / 종료 |

| 항목 | 입력 |
|------|------|

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |

| owner (센터장) | 전체 이벤트 + 실적 | 등록·수정·삭제·실적 |

## 주요 UX 흐름

**이벤트 등록**
1. 사이드바 → "마케팅 > 리퍼럴 프로그램" 진입
2. [이벤트 등록] → DLG-077-001
3. 양방향 혜택·추천 코드·기간 설정
4. 저장 → 회원앱에 코드 발급

**실적 모니터링**
1. 추천 이력 목록에서 실시간 모니터링
2. 미지급 혜택 처리

**이벤트 삭제**
1. [삭제] → DLG-077-002

## 비즈니스 규칙

1. 추천 코드는 회원앱에서 회원별 고유값으로 자동 발급된다.
2. 피추천인 등록 시 자동으로 매칭되어 양방향 혜택이 지급된다.
3. 1인당 최대 추천 횟수 제한이 설정 가능하다.
4. 혜택은 마일리지·쿠폰·할인 중 선택 가능하며 자동 지급된다.
5. 이벤트 종료 후에도 진행 중이던 추천은 정상 처리된다.
6. 모든 추천·전환·지급은 감사 로그에 기록된다.
