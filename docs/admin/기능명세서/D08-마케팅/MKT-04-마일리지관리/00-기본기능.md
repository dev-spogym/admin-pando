## 기능 목적

회원별 마일리지 잔액과 적립·차감·소멸 이력을 조회하고, 적립 규칙(결제 적립률·이벤트 적립·소멸 정책·사용 단위)을 설정하는 화면이다. 마일리지는 회원의 재방문을 유도하고 충성도를 높이는 리텐션 도구로, 결제 금액 대비 자동 적립과 운영자의 수동 조정으로 유연하게 운영한다. 가족 회원(MBR-07) 간 합산 사용으로 가족 단위 마케팅도 지원한다.

운영 맥락:
- **결제 자동 적립**: 결제 webhook 트리거로 결제 금액의 N% 자동 적립 (테넌트 정책)
- **이벤트 적립**: 생일·재등록·첫 출석·이벤트 참여 시 정액·정률 적립
- **수동 적립 / 차감**: 운영자가 사유 입력하여 임의 조정 (보상·실수 정정·사은품 차감)
- **소멸 정책**: 적립 후 N개월 자동 소멸 (FIFO), 소멸 30일 전 회원 알림
- **사용 단위**: 1점 = N원으로 결제 시 차감 (예: 1점 = 1원, 100점 = 100원)
- **가족 합산 사용 (MBR-07)**: 부모 마일리지 → 자녀 결제 사용 (테넌트 활성 시)
- **회원앱 잔액·이력 노출**: 회원 본인이 회원앱에서 조회
- **소멸 예정 30일 카드**: 운영자가 소멸 임박 회원 케어
- **엑셀 내보내기**: 마일리지 이력 전체 다운로드 (감사·정산 용)
- **append-only 이력**: 적립·차감·소멸·환불 모두 append-only 기록, 감사 추적 가능

요약 카드(총 발행/총 사용/소멸 예정/현재 잔액) + 회원별 테이블 + 이력 패널 + DLG-074-001 적립 규칙 + DLG-074-002 수동 적립/차감 위자드로 구성된다.

## 주요 UX 흐름

### 조회 흐름
1. 사이드바 → "마케팅 > 마일리지 관리" 진입
2. 요약 카드 4종(총 발행/총 사용/소멸 예정/현재 잔액)으로 현황 파악
3. 검색(이름·연락처·디바운스 300ms) 또는 회원 테이블 선택
4. 회원 클릭 → 우측 이력 패널 (날짜·구분·금액·사유·처리자)

### 수동 적립·차감 흐름
1. 행 [수동 조정] → DLG-074-002
2. 조정 유형(적립/차감) + 금액(필수) + 사유(필수) + 비고(선택) 입력
3. 저장 → 잔액 즉시 갱신 + 이력 INSERT (`mileage_log`) + 처리자(`actor_id`) 자동 기록

### 적립 규칙 설정 흐름
1. [적립 규칙 설정] → DLG-074-001
2. 결제 적립률(%) + 이벤트 적립(생일·재등록 등) + 소멸 정책(N개월) + 사용 단위(1점=N원) 입력
3. 저장 → 즉시 적용 (다음 결제·이벤트부터)

### 자동 적립 흐름 (결제)
1. 결제 webhook 수신
2. 적립률 × 결제 금액 = 적립 마일리지 계산
3. `mileage_log` INSERT (구분 적립, 사유 결제) + 잔액 +N
4. 회원 알림 발송 (정책 활성 시)

### 자동 소멸 흐름
1. 매일 04:00 배치
2. 적립일 + 소멸 기간 경과 마일리지 추출 (FIFO)
3. `mileage_log` INSERT (구분 소멸) + 잔액 -N
4. 소멸 30일 전 회원 알림 발송 (사전)

### 분기·예외 흐름
- **잔액 부족 차감 시도**: "잔액 부족, 현재 잔액 N점" + 차감 차단 또는 마이너스 허용 (정책)
- **수동 적립/차감 사유 미입력**: 인라인 "사유는 필수입니다" + 저장 차단
- **금액 0 이하**: 인라인 "0보다 큰 금액" + 저장 차단
- **소멸 예정 마일리지 사용**: FIFO 우선 사용 (오래된 마일리지부터 차감) → 소멸 카운트 감소
- **결제 환불 시 적립 회수**: 환불 webhook 트리거 → 환불 금액에 비례한 마일리지 자동 차감 (FIFO 역순)
- **회원 환불 후 잔액 부족**: 마이너스 잔액 허용 (정책) 또는 차감 한도 처리
- **가족 합산 비활성 테넌트**: 가족 합산 카드 hidden + 부모→자녀 사용 차단
- **회원 탈퇴 시 마일리지 처리**: 정책에 따라 잔액 소멸 또는 가족 그룹 양도 (MBR-07)
- **회원 병합 시 마일리지 처리**: 부 계정 마일리지 → 주 계정으로 합산
- **회원 이관 시 마일리지 처리**: 마일리지 함께 이관 (지점 간 정산 포함)
- **소멸 정책 변경 시 기존 마일리지**: 정책 변경 시점부터 적용, 기존 적립분은 기존 정책 유지 (정책)
- **이벤트 적립 중복 (같은 생일 두 번 적립)**: 회원당 1년 1회 제한
- **FC 수동 조정 시도**: 버튼 hidden (조회만 가능)
- **수동 차감 시 잔액 음수**: "잔액 미달, 차감 가능 금액 N점" 또는 마이너스 허용
- **append-only 이력 수정 시도**: "이력은 수정 불가, 보정 INSERT만 가능" 안내
- **엑셀 다운로드 100만건 초과**: 분할 다운로드 안내 또는 비동기 처리
- **사용 단위 변경 시 회원 화면 표시**: 즉시 반영, 회원 알림 권유
- **가족 합산 잔액 분리 시 (MBR-07 그룹 분리)**: 운영자 수동 조정 필요 알림
- **소멸 알림 발송 실패**: 자동 재시도 3회 + 운영자 알림

## 비즈니스 규칙

1. **결제 자동 적립**: 결제 webhook 트리거로 결제 금액 × 적립률 = 자동 적립. 정책 활성 시.
2. **이벤트 적립**: 생일 / 재등록 / 첫 출석 / 이벤트 참여 등 트리거별 정액·정률 적립. 회원당 1년 1회 제한 (생일).
3. **수동 적립 / 차감**: 운영자 임의 조정. 사유(필수) + 비고(선택) + 처리자(`actor_id`) 자동 기록.
4. **소멸 정책**: 적립일 + N개월 (테넌트 설정, 기본 12개월) FIFO 자동 소멸. 매일 04:00 배치.
5. **소멸 사전 알림**: 소멸 30일 전 회원 알림 발송 (MKT-02 연계).
6. **사용 단위**: 1점 = N원 (테넌트 설정, 기본 1점=1원). 결제 화면 차감 단위에 반영.
7. **append-only 이력**: 적립·차감·소멸·환불 모두 INSERT only. 수정·삭제 불가. 보정은 새 INSERT.
8. **잔액 부족 정책**: 차감 시 잔액 부족 시 차단 또는 마이너스 허용 (테넌트 정책).
9. **금액 검증**: 0보다 큰 정수. 0 이하 또는 소수 입력 차단.
10. **사유 정책**: 1~200자. 미입력 시 저장 차단.
11. **결제 환불 시 적립 회수**: 환불 webhook 트리거 → 환불 금액에 비례한 마일리지 자동 차감 (FIFO 역순). 잔액 부족 시 마이너스 허용 (정책).
12. **가족 합산 사용 (MBR-07)**: 테넌트 정책 활성 시 가족 그룹 멤버 마일리지 합산 사용 가능. 그룹 분리 시 수동 조정 필요.
13. **회원 탈퇴 시 처리**: 정책에 따라 잔액 소멸 또는 가족 그룹 양도. 이력은 보존.
14. **회원 병합 (MBR-06)**: 부 계정 마일리지 → 주 계정으로 합산. 이력 모두 이관.
15. **회원 이관 (MBR-04)**: 마일리지 함께 이관. 지점 간 정산 포함.
16. **소멸 정책 변경**: 변경 시점부터 신규 적립분에 적용. 기존 적립분은 기존 정책 유지 (테넌트 설정).
17. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 마일리지 + 적립·차감·규칙·엑셀
    - 센터장 / 매니저: 소속 지점 마일리지 + 수동 적립·차감·규칙·엑셀
    - FC: 담당 회원 이력 조회만 (수동 조정 불가)
    - 회원 본인: 회원앱에서 잔액·이력 조회
    - 트레이너 / 스태프 / readonly: 차단
18. **요약 카드 갱신**: 총 발행 / 총 사용 / 소멸 예정 / 현재 잔액. 5분 캐시.
19. **소멸 예정 카드 기준**: 30일 이내 소멸 예정 마일리지 합계.
20. **엑셀 내보내기**: 마일리지 이력 전체 다운로드 (감사·정산용). 100만건 초과 시 분할 또는 비동기 처리.
21. **본사 통합 정책**: 슈퍼관리자가 전 지점 적립률·소멸 정책 일괄 설정 가능 (테넌트 모드).
22. **append-only 이력 컬럼**: `mileage_log`(id, member_id, type[적립/사용/차감/소멸/환불], amount, reason, actor_id, ts, source[결제/이벤트/수동]).
23. **감사 로그**: 적립 규칙 변경·수동 적립·수동 차감·엑셀 다운로드 모두 SCR-097 기록.
24. **회원앱 노출**: 잔액 + 이력 + 소멸 예정 알림 + 사용 가능 상품 안내.

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| SCR-097 히스토리 로그 | 적립 규칙 변경·수동 적립·수동 차감·엑셀 | actor·member_id·action INSERT |

| 소멸 30일 전 알림 | 매일 04:00 | 회원 알림 발송 (MKT-02 연계) |
| 이벤트 적립 (생일) | MKT-02 생일 트리거 | 자동 적립 + 메시지 발송 |
| 이벤트 적립 (재등록) | 재등록 트랜잭션 | 자동 적립 |

| 가족 합산 사용 (MBR-07) | 결제 시 합산 옵션 | 가족 그룹 잔액 합산에서 차감 |
| 회원 병합 (MBR-06) | 병합 트랜잭션 | 부 계정 마일리지 → 주 계정 합산 |
| 회원 이관 (MBR-04) | 이관 트랜잭션 | 마일리지 + 이력 이관 + 지점 간 정산 |
| 회원 탈퇴 처리 | 탈퇴 트랜잭션 | 정책에 따라 소멸 또는 가족 양도 |

| 회원앱 잔액 동기화 | 잔액 변경 시 | 회원앱 즉시 반영 |
| 본사 통합 정책 동기화 | 슈퍼관리자 변경 | 전 지점 즉시 적용 |

| 엑셀 비동기 처리 | 100만건 초과 다운로드 | 백그라운드 잡 + 완료 알림 |
