## 기능 목적

회원별 마일리지 잔액과 적립·차감 이력을 조회하고, 적립 규칙을 설정하는 화면이다. 마일리지는 회원의 재방문을 유도하고 충성도를 높이는 리텐션 도구로 활용된다. 결제 금액 대비 자동 적립과 운영자의 수동 조정으로 유연하게 운영한다.

## 주요 구성요소

| 소멸 예정 | 30일 이내 |
| 현재 유통 잔액 | 활성 잔액 |

### 검색 / 필터

이름·연락처 통합 검색.

### 이력 패널

회원 선택 시 우측 패널.

| 컬럼 | 설명 |
|------|------|
| 날짜 | YYYY-MM-DD HH:mm |
| 구분 | 적립 / 사용 / 차감 / 소멸 |
| 금액 | +/- |
| 사유 | 결제·이벤트·수동 조정 |
| 처리자 | 자동 또는 직원명 |

### 수동 적립 / 차감 (DLG-074-002)

| 입력 | 설명 |
|------|------|
| 조정 유형 | 적립 / 차감 |
| 금액 | 숫자 |
| 사유 | 텍스트 (필수) |
| 비고 | textarea |

### 적립 규칙 설정 (DLG-074-001)

| 항목 | 입력 |
|------|------|
| 결제 적립률 | % |
| 이벤트 적립 | 생일·재등록 등 |
| 소멸 정책 | N개월 후 자동 소멸 |
| 사용 단위 | 1점 = N원 |

### 엑셀 내보내기

마일리지 이력 전체 다운로드.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 회원 마일리지 | 적립·차감·규칙·엑셀 |
| owner (센터장) | 전체 회원 마일리지 | 수동 적립·차감·규칙·엑셀 |
| manager | 전체 회원 마일리지 | 수동 적립·차감·엑셀 |
| fc | 담당 회원 마일리지 | 이력 조회 (수동 조정 불가) |
| 회원 본인 | 본인 잔액·이력 | 회원앱 조회 |
| 트레이너 / 스태프 | 접근 제한 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**조회**
1. 사이드바 → "마케팅 > 마일리지 관리" 진입
2. 요약 카드로 현황 파악
3. 회원 검색 또는 테이블 선택 → 이력 패널

**수동 적립·차감**
1. 행 [수동 조정] → DLG-074-002
2. 유형·금액·사유 입력
3. 저장 → 잔액 갱신 + 이력 추가

**적립 규칙 설정**
1. [적립 규칙 설정] → DLG-074-001
2. 적립률·이벤트·소멸 정책 입력
3. 저장 → 자동 적용

## 비즈니스 규칙

1. 결제 시 자동 적립률에 따라 마일리지가 자동 적립된다.
2. 수동 적립·차감 시 사유 입력은 필수이며 처리자가 자동 기록된다.
3. 마일리지는 설정된 N개월 후 자동 소멸되며 소멸 30일 전 회원 알림이 발송된다.
4. 사용 단위는 1점 = N원으로 설정 가능하며 결제 시 차감된다.
5. FC는 담당 회원의 이력만 조회 가능하며 수동 조정은 불가하다.
6. 모든 적립·차감·소멸 이력은 append-only로 기록되며 감사 로그에 저장된다.
7. 회원 본인은 회원앱에서 잔액과 이력을 조회할 수 있다.
