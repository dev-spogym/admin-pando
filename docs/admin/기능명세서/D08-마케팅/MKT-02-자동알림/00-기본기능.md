## 기능 목적

본사 정책 세트로 내려온 만료 step과, 생일·장기 미방문 같은 지점 운영 이벤트 알림을 관리하는 화면이다. 지점은 본사 기준 step을 따르면서 허용된 범위 안에서 운영용 알림 정책을 적용한다. 자동 알림으로 운영 부담을 줄이고 회원 리텐션을 높인다.

## 주요 구성요소

### 고객 관련 알림 목록

| 알림 유형 | 설명 |
|---|---|
| 만료 step | 본사 정책 (D-7 / D-3 / D-1 / D-Day / D+1) |
| 생일 축하 | 매년 생일 |
| 장기 미방문 | 30/60/90일 |
| 등록 감사 | 신규 등록 회원 |
| 첫 방문 환영 | 첫 출석 |

### 상품 관련 알림 목록

| 알림 유형 | 설명 |
|---|---|
| 이용권 만료 당일 | D-Day |
| 홀딩 종료 | 자동 재개 |
| 결제 완료 | 즉시 |
| 환불 처리 | 즉시 |

### 규칙별 토글 스위치

각 규칙 활성/비활성 토글. 본사 `필수` step은 비활성화 차단.

### 상세 설정 (DLG-072-001)

| 영역 | 편집 가능 |
|------|---------|
| 본사 소유 기준일 | 읽기 전용 |
| 채널 | 지점 조정 가능 |
| 메시지 내용 | 지점 조정 가능 |
| 발송 시각 | 지점 조정 가능 |
| 발송 옵션 | 지점 조정 가능 |

### 전체 자동 알림 ON/OFF

상단 토글로 모든 알림 일괄 활성/비활성.

## 주요 UX 흐름

**본사 step 운영**
1. 사이드바 → "마케팅 > 자동 알림 설정" 진입
2. 본사 step 확인 (필수 step은 비활성 불가)
3. 채널·메시지·발송 시각 지점 조정

**지점 운영 알림**
1. 생일·장기 미방문 등 토글 활성
2. [상세 설정] → DLG-072-001
3. 채널·메시지 편집 → 저장

**일시 중단**
1. 전체 ON/OFF 토글 OFF
2. 모든 알림 일시 중단

## 화면 상태

| 상태 | 설명 |
|---|---|
| 알림 활성 | 토글 ON |
| 알림 비활성 | 토글 OFF, 회색 |
| 전체 비활성 | 모든 규칙 일시 중단 |
| 본사 필수 | 토글 잠금 |

## 비즈니스 규칙

1. 본사 정책 세트로 내려온 만료 step은 지점에서 비활성화할 수 없다 (필수 step).
2. 본사 소유 기준일은 읽기 전용으로 표시되며 지점은 채널·메시지·발송 시각만 조정할 수 있다.
3. 자동 알림은 조건 충족 시 즉시 또는 설정된 시각에 자동 발송된다.
4. 발송 결과는 SCR-071 메시지 발송 이력에 기록된다.
5. 전체 자동 알림 OFF 시에도 본사 필수 step은 별도 처리될 수 있다 (정책).
6. 상세 설정 변경 이력은 감사 로그에 기록된다.
