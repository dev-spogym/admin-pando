## 기능 목적

회원 이용 계약서 또는 직원 근로계약서를 전자 방식으로 작성·서명·이력 관리하는 5단계 위자드 화면이다. 종이 계약 없이 태블릿(직접 서명) 또는 모바일(원격 서명 링크)에서 서명을 받고, PDF 자동 변환·이메일 / 앱 재전송 / 회원 상세·직원 상세 연동으로 통합 관리한다. 회원 계약과 직원 근로계약 4종 템플릿(이용 / 정규직 / 위촉 / 프리랜서)을 자동 분기해 운영 효율을 높인다.

운영 맥락:
- **신규 회원 이용 계약**: 등록 시 PT·이용권 계약서 태블릿 즉석 서명 → 회원 마스터 자동 연결
- **PT 패키지 계약**: PT 회원과 트레이너 / 위촉 강사가 별도 PT 계약 체결
- **원격 서명 (회원 부재)**: 결제만 하고 회원이 부재한 경우 SMS·카톡으로 서명 링크 발송 → 회원 디바이스 서명
- **직원 정규직 입사**: 정규직 근로계약서 작성 → 인사 도메인 STF-02에 자동 연동
- **위촉 강사 계약**: 강사 위촉 계약서 (수수료·정산 조건 포함)
- **프리랜서 계약**: 프리랜서 계약서 (단기·프로젝트 단위)
- **계약서 재발송**: 회원이 분실한 경우 이메일·앱으로 재전송
- **계약 이력 조회**: 회원 / 직원 상세 화면에서 과거 계약서 모두 조회
- **5단계 위자드**: 회원→상품→조건→서명→완료 (회원 계약) / 직원→템플릿→조건→서명→완료 (근로계약)
- **PDF 자동 변환**: 서명 완료 시 자동 PDF 변환 + S3 저장 + 다운로드 가능

서명 완료 시점부터 정식 효력을 가지며, 서명 전 데이터는 임시 저장만 가능하다.

| 항목 | 설명 |

### 전자 서명 패널

| 모드 | 설명 |
|------|------|
| 화면 직접 서명 | 태블릿/마우스 |
| 원격 서명 링크 | SMS/카톡 발송 → 회원 디바이스 서명 |

완료 계약서 → 이메일 또는 앱 재전송.

## 주요 UX 흐름

### 회원 이용 계약 5단계 위자드 흐름
1. 사이드바 → "마케팅 > 전자 계약" 진입
2. 1단계: 계약 유형 → 회원 계약
3. 2단계: 회원 검색 (SCR-M001) → 회원 선택
4. 3단계: 이용 서비스(상품·이용권) + 계약 기간(시작~종료) + 금액 + 결제 조건(일시불/분납) + 특약 사항 입력
5. 4단계: 계약서 미리보기 (변수 치환된 전문)
6. 5단계: 전자 서명
   - 화면 직접 서명 (태블릿/마우스 패드)
   - 원격 서명 링크 (SMS/카톡 발송)
7. 서명 완료 → 자동 PDF 변환 + S3 저장 + 회원 상세(SCR-M004) 연동 + 감사 로그 기록

### 직원 근로계약 5단계 위자드 흐름
1. 1단계: 계약 유형 → 직원 근로계약
2. 2단계: 직원 검색 (SCR-060) → 직원 선택 + 근로 형태(정규직/위촉/프리랜서)
3. 3단계: 템플릿 자동 분기 + 계약 기간 + 보수·수수료 + 근로 조건 + 특약 사항
4. 4단계: 미리보기
5. 5단계: 서명 (직접 또는 원격)
6. 완료 → STF-02 직원 상세 연동 + 인사 도메인(D07) 등록

### 원격 서명 흐름
1. 서명 단계에서 [원격 서명 링크 발송] 선택
2. 발송 채널(SMS / 카톡) + 발송 번호 확인
3. 발송 → 7일 유효 링크 + 서명 대기 상태
4. 회원이 링크 클릭 → 계약 내용 확인 → 서명 → 자동 저장
5. 운영자에게 완료 알림

### 이력 조회 / 재발송 흐름
1. "계약 이력" 탭
2. 검색 (회원명·직원명·날짜·유형·서명 상태)
3. 행 클릭 → 계약서 PDF 다운로드
4. [재발송] → 이메일 또는 앱 선택 → 발송

### 분기·예외 흐름
- **회원 검색 결과 0건**: "검색 결과 없음" + 회원 등록 안내
- **직원 검색 결과 0건**: 직원 등록 안내
- **계약 기간 시작 > 종료**: 인라인 "시작일이 종료일보다 늦을 수 없습니다" + 저장 차단
- **금액 0 이하**: 인라인 에러 + 저장 차단
- **분납 조건 미입력**: 분납 횟수·주기 입력 누락 시 저장 차단
- **서명 미완료 → 정식 저장 시도**: "서명이 필요합니다" + 정식 저장 차단 (임시 저장만)
- **원격 서명 링크 7일 만료**: 자동 만료 + 운영자 알림 + 재발송 옵션
- **원격 서명 링크 SMS 발송 실패**: 자동 재시도 3회 + 카톡 폴백
- **서명 후 계약 수정 시도**: "서명된 계약은 수정 불가, 해지 후 재계약" 안내
- **태블릿 서명 끊김**: 임시 저장 자동 + 재진입 시 이어서
- **PDF 변환 실패**: 자동 재시도 3회 + 운영자 알림 + 임시 보관
- **회원/직원 부재로 작성 중단**: 임시 저장 (24시간 보관) + 자동 알림
- **계약 해지**: 해지 사유 입력 → 해지 처리 (원본 보존 + 해지 이력 추가)
- **본사 표준 템플릿 변경**: 신규 계약부터 적용, 기존 서명 계약은 기존 템플릿 유지
- **서명 대기 중 회원 정보 변경**: 변경 사항 미반영 (서명 시점 데이터 고정)
- **위촉 / 프리랜서 수수료 정산 조건**: 별도 입력 영역 + 검증
- **인사 도메인(D07) 동기화 실패**: 자동 재시도 + 운영자 알림
- **회원 탈퇴 / 직원 퇴사 후 계약 조회**: 이력 보존 + 조회 가능 (개인정보보호 정책에 따라 제한)
- **태블릿 직접 서명 사용자가 미성년**: 보호자 동의 추가 필요 + 보호자 서명 분기

## 비즈니스 규칙

1. **5단계 위자드**: 회원 계약 (회원→상품→조건→서명→완료) / 직원 근로계약 (직원→템플릿→조건→서명→완료). 단계 건너뛰기 차단.
2. **템플릿 4종 자동 분기**: 회원 이용 / 정규직 / 위촉 / 프리랜서. 템플릿 자동 로드.
3. **서명 완료 후 정식 저장**: 서명 전 데이터는 임시 저장만 가능, 효력 없음. 서명 완료 시점부터 정식 효력.
4. **임시 저장 보관**: 24시간 보관. 24시간 경과 시 자동 삭제 + 알림.
5. **원격 서명 링크**: SMS / 카톡 발송. 7일 유효. 만료 시 자동 무효 + 재발송 옵션.
6. **태블릿 직접 서명**: 화면 좌표 기반 서명 데이터 + 서명 시각 기록.
7. **PDF 자동 변환**: 서명 완료 시 자동 PDF 변환 + S3 저장. 변환 실패 시 자동 재시도 3회.
8. **회원 마스터 연동**: 회원 계약 완료 시 SCR-M004 연동 + 이용권 자동 등록 (정책 활성 시).
9. **직원 인사 연동**: 직원 근로계약 완료 시 STF-02 + 인사 도메인(D07) 자동 등록.
10. **서명 후 수정 차단**: 서명된 계약은 수정 불가. 해지 후 재계약만 가능.
11. **계약 해지**: 해지 사유 입력 → 원본 보존 + 해지 이력 추가. 환불 처리는 별도 (D05 결제).
12. **본사 표준 템플릿**: 슈퍼관리자만 정의 가능. 변경 시 신규 계약부터 적용.
13. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 계약 + 본사 템플릿 정의
    - 센터장 / 매니저: 소속 지점 계약 + 작성·서명·재발송
    - FC: 본인 담당 회원 계약만 작성·서명
    - 트레이너 / 스태프: 차단 (트레이너는 본인 PT 계약만 조회)
    - readonly: 차단
14. **금액 검증**: 0보다 큰 정수. 천 단위 콤마 표시.
15. **계약 기간 검증**: 시작일 ≤ 종료일. 1년 이상 또는 무기한 옵션.
16. **분납 조건**: 일시불 또는 분납. 분납 시 횟수·주기 입력 필수.
17. **특약 사항**: 0~2000자. 자유 텍스트.
18. **재발송 정책**: 이메일 / 앱 / SMS 다중 채널. 재발송 횟수 제한 (1일 5회).
19. **계약 이력 보관**: 계약 종료 후 5년 이상 보관 (법정 의무). 5년 후 아카이브.
20. **개인정보 처리**: 서명 후 회원 / 직원 개인정보는 계약서에만 보관. 외부 노출 차단.
21. **미성년 회원 계약**: 보호자 동의 추가 필요 + 보호자 서명 분기.
22. **위촉 / 프리랜서 수수료**: 별도 정산 조건 입력. 월별 정산 또는 건당 정산.
23. **감사 로그**: 작성·서명·재발송·해지 모두 SCR-097 기록 (`actor_id`, `contract_id`, `member_id` 또는 `staff_id`, `action`).
24. **계약서 다운로드 권한**: 회원/직원 본인 + 운영자만. 외부 공유 시 워터마크 + 다운로드 추적.

## 관련 화면 / 다이얼로그 / API

- **연계 화면**: SCR-075 / SCR-M004 회원 상세 / STF-02 직원 상세 / SCR-071 메시지 (서명 링크 발송)
- **API 기준**: `GET /api/contracts` / `POST /api/contracts` / `POST /api/contracts/:id/sign` / `POST /api/contracts/:id/send-remote-sign` / `POST /api/contracts/:id/resend` / `GET /api/contracts/templates`

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MKT-05`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-075`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
