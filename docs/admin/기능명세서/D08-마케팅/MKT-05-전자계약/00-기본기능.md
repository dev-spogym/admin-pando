## 기능 목적

회원과의 이용 계약서 또는 직원과의 근로계약서를 전자 방식으로 작성하고 서명까지 완료하는 화면이다. 종이 계약 없이 태블릿 또는 모바일에서 전자 서명을 받을 수 있으며, 완료된 계약서는 이력으로 저장되어 언제든지 다시 조회할 수 있다. 회원 계약과 직원 근로계약을 통합 관리해 운영 효율을 높인다.

## 주요 구성요소

### 계약 유형 선택

| 유형 | 세부 |
|------|------|
| 회원 계약 | 이용권 / PT / 필라테스 등 |
| 직원 근로계약 | 정규직 근로 / 강사 위촉 / 프리랜서 |

### 계약 대상 선택

| 유형 | 검색 |
|------|------|
| 회원 계약 | 회원 검색 (SCR-M001) |
| 직원 근로계약 | 직원 검색 (SCR-060) |

### 계약 템플릿 자동 분기

| 유형 | 템플릿 |
|------|------|
| 회원 이용 계약 | 이용 계약서 |
| 정규직 | 근로계약서 |
| 위촉 | 위촉계약서 |
| 프리랜서 | 프리랜서 계약서 |

### 계약 내용 입력

| 항목 | 설명 |
|------|------|
| 계약 기간 | 시작 ~ 종료 |
| 이용 서비스 | 상품·이용권 |
| 금액 | 천 단위 |
| 결제 조건 | 일시불 / 분납 |
| 특약 사항 | textarea |

### 계약서 미리보기

입력된 정보가 반영된 계약서 전문 화면 확인.

### 전자 서명 패널

| 모드 | 설명 |
|------|------|
| 화면 직접 서명 | 태블릿/마우스 |
| 원격 서명 링크 | SMS/카톡 발송 → 회원 디바이스 서명 |

### 계약 이력 탭

이전 계약 목록 (날짜·유형·회원명·서명 상태 컬럼).

### 계약서 재발송

완료 계약서 → 이메일 또는 앱 재전송.

## 주요 UX 흐름

**회원 계약**
1. 사이드바 → "마케팅 > 전자 계약" 진입
2. 회원 계약 유형 선택 → 회원 검색
3. 계약 내용 입력 → 미리보기
4. 태블릿 서명 또는 원격 링크 발송
5. 서명 완료 → 자동 저장

**직원 근로계약**
1. 직원 근로계약 유형 선택 → 직원 검색
2. 근로계약서 템플릿 자동 로드
3. 계약 내용 입력 → 서명

**이력 조회**
1. "계약 이력" 탭
2. 검색·필터로 조회
3. 재발송 또는 다운로드

## 화면 상태

| 상태 | 설명 |
|---|---|
| 작성 중 | 입력 단계 |
| 서명 대기 | 서명 전 미저장 |
| 서명 완료 | 자동 저장 + 이력 |
| 이력 없음 | 안내 |
| 원격 서명 대기 | 링크 발송 후 대기 |

## 비즈니스 규칙

1. 계약서는 서명 완료 후에만 정식 저장된다.
2. 원격 서명 링크는 발송 후 7일간 유효하다.
3. 직원 근로계약서는 인사 도메인(D07)에 함께 연동되어 STF-02 직원 상세에서 조회 가능하다.
4. 회원 계약서는 회원 마스터(SCR-M004)에 연동되어 회원 상세에서 조회 가능하다.
5. 완료된 계약서는 PDF로 자동 변환되어 이메일·앱 재발송이 가능하다.
6. 계약 작성·서명·재발송 이력은 감사 로그에 기록된다.
