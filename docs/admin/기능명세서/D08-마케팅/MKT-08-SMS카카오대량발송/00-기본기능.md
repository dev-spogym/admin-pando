## 기능 목적

대규모 회원에게 SMS / LMS / MMS / 카카오 알림톡을 대량으로 발송하고, 채널별 단가·잔여 포인트·비용 현황·실패 처리를 통합 관리하는 화면이다. 개별 메시지 발송(SCR-071, MKT-01)과 달리 대용량 발송 전용 채널 설정 / 슈퍼관리자 단가 관리 / 월별 비용 현황 그래프 / 외부 API 비용 청구 근거에 특화된다.

운영 맥락:
- **이벤트 일괄 발송**: 신년·기념일 등 전체 회원 (수만명) 대상 SMS·카카오 일괄 발송
- **세그먼트별 대량 발송**: VIP / 일반 / 신규 등급 / 활성·만료·홀딩 / 지역(시·구) / 가입 기간(N일 이상) 다중 조건
- **카카오→SMS 자동 폴백**: 알림톡 비친구·미수신 시 SMS로 자동 폴백 (정책)
- **단가 즉시 반영**: 슈퍼관리자가 채널별 단가 변경 시 SCR-071 / SCR-078 / DLG-078-002 비용 계산에 즉시 반영
- **NHN/Toast 외부 API 연동**: 발송 webhook으로 실시간 결과 갱신, 90일 이상 이력 보존 (비용 청구 근거)
- **분할 처리 + 부분 실패**: 대량 발송은 분할 처리 (1만건 단위), 부분 실패는 자동 재시도 3회
- **법정 시간 차단**: 영업/광고 21~08시 차단, 정보성 예외
- **수신 거부 / 휴면 자동 제외**: 모든 대량 발송에 자동 적용
- **월별 비용 그래프**: 월별 채널별 발송 비용 추이 시각화 → 마케팅 예산 관리

채널 현황 카드(4종) + DLG-078-001 발송 대상 + 메시지 작성 + DLG-078-002 발송 확인 + 발송 이력 + 비용 그래프 + 단가 설정(슈퍼관리자) 위자드로 구성된다.

| 수신자 수 | 카운트 |
| 성공 / 실패 건수 | 결과 |

### 비용 현황 그래프

### 채널별 단가 설정 (슈퍼관리자 전용)

|------|------|
| SMS | 1건당 |
| LMS | 1건당 |
| MMS | 1건당 |
| 카카오 알림톡 | 1건당 |

단가 변경 즉시 SCR-071 / SCR-078 비용 계산과 DLG-078-002 합계에 반영.

## 주요 UX 흐름

### 대량 발송 흐름
1. 사이드바 → "마케팅 > SMS/카카오 발송" 진입
2. 채널 현황 카드 4종(SMS / 카카오 / 이번 달 비용 / 잔여 포인트) 확인
3. [발송 대상 선택] → DLG-078-001 (회원 등급 / 이용권 상태 / 지역 / 가입 기간 다중 조건)
4. 메시지 템플릿 선택 또는 직접 작성 (변수 삽입 지원)
5. 발송 예약 (즉시 또는 특정 일시)
6. [발송] → DLG-078-002 최종 확인 (수신자 수 + 비용 + 단가 합계)
7. 확인 → 분할 처리 시작 (1만건 단위) + 진행률 표시
8. NHN/Toast webhook으로 실시간 결과 갱신
9. 완료 → 발송 이력 저장 + 운영자 알림

### 단가 설정 흐름 (슈퍼관리자)
1. 시스템 설정 영역 → 채널별 단가 메뉴 (또는 SCR-078 내 단가 영역)
2. SMS / LMS / MMS / 카카오 알림톡 4종 단가 입력
3. 저장 → 즉시 SCR-071 / SCR-078 / DLG-078-002 비용 계산에 반영
4. 감사 로그 기록 + 운영자 알림

### 발송 이력 / 재발송 흐름
1. 발송 이력 목록 (발송 일시·채널·수신자 수·성공/실패·비용)
2. 행 클릭 → 수신자별 상세 (성공/실패 + 사유)
3. 실패 건 [재발송] → 재발송 다이얼로그 → 비용 차감 + 발송

### 비용 그래프 흐름
1. 비용 현황 그래프 영역
2. 월별 추이 (채널별 분리)
3. 마케팅 예산 관리 / 회계 정산 근거

### 분기·예외 흐름
- **잔여 포인트 < 예상 비용**: 빨강 경고 + 발송 비활성 + [포인트 충전] CTA
- **수신자 0명**: 발송 비활성 + "수신자가 없습니다"
- **단가 미설정 (시스템 설정 누락)**: "단가가 설정되지 않았습니다" + 슈퍼관리자에게 안내
- **카카오 알림톡 비친구 포함**: 자동 SMS 폴백 (정책 활성) 또는 "비친구 N명 제외" 안내
- **MMS 첨부 이미지 크기 초과 (300KB)**: "이미지 크기 초과" + 차단
- **법정 시간 (21~08시) 광고 발송**: "야간 광고 발송 불가" 모달 + 차단 (정보성 예외)
- **수신 거부 / 휴면 자동 제외**: 자동 제외 + "N명 제외" 안내
- **금지어 포함**: "금지어 포함: {단어}" 차단
- **알림톡 미승인 템플릿**: "사전 승인 템플릿 필요" + SMS 폴백 권유
- **분할 처리 부분 실패**: 자동 재시도 3회 + 최종 실패 알림 + 포인트 환급
- **외부 API 응답 지연**: "결과 확인 중" 표시 + 5분 후 새로고침
- **예약 발송 시점 포인트 부족**: 발송 보류 + 운영자 알림
- **단가 변경 후 진행 중 발송**: 발송 시점 단가로 차감 (변경 전 단가)
- **발송 중 사용자 취소 시도**: 분할 처리 중에는 일부 차감 + 미발송 부분 취소
- **외부 API 장애 (NHN/Toast 다운)**: 발송 보류 + 큐 대기 + 복구 시 재개
- **카카오→SMS 폴백 정책 OFF**: 비친구는 자동 제외만
- **발신 번호 미인증**: "발신 번호 인증 필요" + 시스템 설정 이동
- **지역·가입 기간 0건**: "조건에 맞는 회원이 없습니다" + 발송 비활성
- **변수 데이터 누락**: 해당 회원 발송 제외 + 사유 기록
- **발송 이력 90일 경과**: 자동 아카이브 (비용 청구 근거 보존)
- **글자수 초과**: SMS→LMS 자동 전환 + 단가 변경 안내, LMS 2000byte 초과 시 차단

## 비즈니스 규칙

1. **채널 4종**: SMS / LMS / MMS / 카카오 알림톡. 슈퍼관리자가 단가 설정.
2. **단가 즉시 반영**: 슈퍼관리자 단가 변경 시 SCR-071 / SCR-078 / DLG-078-002 비용 계산에 즉시 반영.
3. **단가 변경 후 진행 중 발송**: 발송 시점 단가로 차감 (변경 전 단가 적용).
4. **카카오→SMS 자동 폴백**: 알림톡 비친구·실패 시 SMS 자동 발송 (정책 토글). OFF 시 비친구 자동 제외.
5. **분할 처리**: 대량 발송 시 1만건 단위로 분할. 부분 실패는 자동 재시도 3회.
6. **자동 재시도**: 1분/5분/30분 간격 3회. 최종 실패 시 운영자 알림 + 포인트 환급.
7. **외부 API webhook**: NHN/Toast 발송 결과 webhook으로 실시간 갱신 (성공/실패/일부 실패).
8. **발송 이력 90일 보관**: 비용 청구 근거로 사용. 90일 경과 시 자동 아카이브.
9. **잔여 포인트 부족 차단**: 발송 시점 포인트 < 예상 비용 시 차단 + [포인트 충전] CTA.
10. **법정 시간 차단**: 영업/광고성 발송 21~08시 차단(정보통신망법). 정보성(결제·환불) 예외.
11. **수신 거부 / 휴면 자동 제외**: 모든 대량 발송에 자동 적용.
12. **금지어 차단**: 도박·대출·성인 등 사전 등록 금지어 포함 시 차단.
13. **알림톡 사전 승인**: 카카오 정책에 따라 사전 승인 템플릿만 발송. 미승인 시 SMS 폴백 또는 차단.
14. **글자수 정책**: SMS 90byte (한글 45자) → LMS 2000byte 자동 전환 / 알림톡 1000자.
15. **MMS 첨부 이미지**: 최대 300KB. 초과 시 차단.
16. **발신 번호 인증**: 사전 인증된 번호만 발신 가능.
17. **발송 대상 조건**: 회원 등급(VIP/일반/신규) / 이용권 상태(활성/만료/홀딩) / 지역(시·구) / 가입 기간(N일 이상). 다중 조합.
18. **메시지 템플릿**: 사전 등록 템플릿 또는 직접 작성. 변수 삽입 지원.
19. **권한별 가시성**:
    - 슈퍼관리자: 전체 발송 + 이력 + 단가 설정
    - 센터장 / 매니저: 소속 지점 대량 발송 + 예약 + 이력
    - FC / 트레이너 / 스태프 / readonly: 차단
20. **발송 결과 카운트**: 성공·실패·미수신 분리 집계. 실패 사유별 통계.
21. **비용 그래프**: 월별 채널별 발송 비용 추이. 마케팅 예산 관리.
22. **포인트 환급**: 최종 실패 건은 자동 환급. 환급 이력 기록.
23. **회계 청구 매핑**: 외부 API 청구서와 발송 이력 매핑. 정산 근거.
24. **감사 로그**: 발송 / 예약 / 단가 변경 / 재발송 모두 SCR-097 기록.
