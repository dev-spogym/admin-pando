## 기능 목적

대규모 회원에게 SMS 또는 카카오 알림톡을 대량으로 발송하고, 발송 채널을 통합 관리하며 비용 현황을 추적하는 화면이다. 개별 메시지 발송(SCR-071)과 달리 대용량 발송 전용 채널 설정과 발송 이력 관리에 특화된다. 슈퍼관리자는 채널별 단가를 설정해 비용 정책을 관리한다.

## 주요 구성요소

### 채널 현황 카드 (4개)

| 카드 | 내용 |
|------|------|
| SMS 발송 건수 | 이번 달 |
| 카카오 알림톡 건수 | 이번 달 |
| 이번 달 총 비용 | 천 단위 |
| 잔여 포인트 | 사용 가능 |

### 발송 대상 선택 (DLG-078-001)

| 옵션 | 설명 |
|------|------|
| 회원 등급 | VIP/일반/신규 |
| 이용권 상태 | 활성/만료/홀딩 |
| 지역 | 시·구 |
| 가입 기간 | N일 이상 |

### 메시지 템플릿 선택

사전 등록 템플릿 또는 직접 작성. 변수 삽입 지원.

### 발송 예약

즉시 / 특정 일시.

### 발송 확인 (DLG-078-002)

최종 발송 전 수신자 수 + 비용 + 단가 합계 확인.

### 발송 이력 목록

| 컬럼 | 설명 |
|------|------|
| 발송 일시 | YYYY-MM-DD HH:mm |
| 채널 | SMS/LMS/MMS/카톡 |
| 수신자 수 | 카운트 |
| 성공 / 실패 건수 | 결과 |
| 비용 | 천 단위 |

### 비용 현황 그래프

월별 발송 비용 추이 시각화.

### 채널별 단가 설정 (슈퍼관리자 전용)

| 채널 | 단가 |
|------|------|
| SMS | 1건당 |
| LMS | 1건당 |
| MMS | 1건당 |
| 카카오 알림톡 | 1건당 |

단가 변경 즉시 SCR-071 / SCR-078 비용 계산과 DLG-078-002 합계에 반영.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 + 단가 설정 | 대량 발송·예약·이력·단가 |
| owner (센터장) | 전체 채널 + 이력 | 대량 발송·예약·이력 |
| manager | 전체 채널 + 이력 | 대량 발송·예약·이력 |
| fc / 트레이너 / 스태프 | 접근 제한 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**대량 발송**
1. 사이드바 → "마케팅 > SMS/카카오 발송" 진입
2. [발송 대상 선택] → DLG-078-001
3. 메시지 작성 또는 템플릿 선택
4. 발송 예약 (즉시 또는 일시)
5. [발송] → DLG-078-002 최종 확인
6. 발송 → 진행률 표시 → 이력 저장

**단가 설정 (슈퍼관리자)**
1. 시스템 설정 영역 → 채널별 단가
2. 4종 채널 단가 입력
3. 즉시 반영

## 비즈니스 규칙

1. 채널별 단가는 슈퍼관리자만 설정할 수 있으며, 변경 즉시 모든 발송 비용 계산에 반영된다.
2. 카카오 알림톡 실패 시 SMS로 자동 폴백되도록 설정 가능하다 (정책).
3. 대량 발송 시 분할 처리되어 부분 실패가 발생할 수 있다 (재시도 지원).
4. 발송 이력은 90일 이상 보관되며 비용 청구 근거로 사용된다.
5. 잔여 포인트가 부족하면 발송이 차단된다.
6. 발송 결과는 webhook으로 실시간 갱신된다.
