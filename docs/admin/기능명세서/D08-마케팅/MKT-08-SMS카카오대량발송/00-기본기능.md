## 기능 목적

대규모 회원에게 SMS / LMS / MMS / 카카오 알림톡을 대량으로 발송하고, 플랫폼에서 제공하는 발송 정보·예상 비용·사용량·실패 처리를 통합 확인하는 화면이다. 개별 메시지 발송(SCR-071, MKT-01)과 달리 대용량 발송 전용 채널 설정 / 플랫폼 API 기반 예상 비용 확인 / 월별 사용량 현황 그래프 / 외부 API 비용 청구 근거에 특화된다.

운영 맥락:
- **이벤트 일괄 발송**: 신년·기념일 등 전체 회원 (수만명) 대상 SMS·카카오 일괄 발송
- **세그먼트별 대량 발송**: VIP / 일반 / 신규 등급 / 활성·만료·홀딩 / 지역(시·구) / 가입 기간(기본 30일 이상) 다중 조건
- **카카오 비친구 처리**: 알림톡 비친구·미수신 대상은 제외 카운트로 표시한다. SMS는 운영자가 SMS/LMS 채널을 명시 선택한 경우에만 별도 발송한다.
- **플랫폼 비용 즉시 반영**: 플랫폼 단가/과금 정책 변경 시 SCR-071 / SCR-078 / DLG-078-002 예상 비용 계산에 즉시 반영
- **NHN/Toast 외부 API 연동**: 발송 webhook으로 실시간 결과 갱신, 90일 이상 이력 보존 (비용 청구 근거)
- **분할 처리 + 부분 실패**: 대량 발송은 분할 처리 (1만건 단위), 부분 실패는 자동 재시도 3회
- **법정 시간 차단**: 영업/광고 21~08시 차단, 정보성 예외
- **수신 거부 / 휴면 자동 제외**: 모든 대량 발송에 자동 적용
- **월별 사용량 그래프**: 월별 채널별 발송 건수·비용 추이 시각화 → 마케팅 예산 관리

채널 현황 카드(4종) + DLG-078-001 발송 대상 + 메시지 작성 + DLG-078-002 발송 확인 + 발송 이력 + 사용량 그래프 + 플랫폼 연동 정보 패널로 구성된다.

## 메시지 플랫폼 연동 원칙

- SMS/알림톡/MMS 단가와 잔여 캐시/크레딧은 관리자에서 수기 관리하지 않고 메시지 플랫폼 API에서 조회한다.
- 관리자 화면은 발신 프로필, 승인 템플릿 수, 예상 비용, 잔여 캐시, 최근 동기화 시각만 표시한다.
- 대량 발송의 최종 비용·성공/실패 건수·청구 근거는 플랫폼 응답값을 기준으로 정산한다.

## 주요 UX 흐름

### 대량 발송 흐름
1. 사이드바 → "마케팅 > SMS/카카오 발송" 진입
2. 채널 현황 카드 4종(SMS / 카카오 / 이번 달 비용 / 플랫폼 잔여 캐시) 확인
3. [발송 대상 선택] → DLG-078-001 (회원 등급 / 이용권 상태 / 지역 / 가입 기간 다중 조건)
4. 메시지 템플릿 선택 또는 직접 작성 (변수 삽입 지원)
5. 발송 예약 (즉시 또는 특정 일시)
6. [발송] → DLG-078-002 최종 확인 (수신자 수 + 플랫폼 예상 비용 + 발신 프로필/템플릿 상태)
7. 확인 → 분할 처리 시작 (1만건 단위) + 진행률 표시
8. NHN/Toast webhook으로 실시간 결과 갱신
9. 완료 → 발송 이력 저장 + 운영자 알림

### 플랫폼 연동 정보 확인 흐름
1. 화면 진입 시 플랫폼 메타데이터 조회
2. SMS / LMS / MMS / 카카오 알림톡 발신 프로필·승인 템플릿·예상 비용 기준 로드
3. 발송 대상/채널/메시지 변경 시 예상 비용 재조회
4. 조회 결과를 DLG-078-002와 이력·그래프에 반영

### 발송 이력 / 재발송 흐름
1. 발송 이력 목록 (발송 일시·채널·수신자 수·성공/실패·비용)
2. 행 클릭 → 수신자별 상세 (성공/실패 + 사유)
3. 실패 건 [재발송] → 재발송 다이얼로그 → 비용 차감 + 발송

### 비용 그래프 흐름
1. 비용 현황 그래프 영역
2. 월별 추이 (채널별 분리)
3. 마케팅 예산 관리 / 회계 정산 근거

### 분기·예외 흐름
- **플랫폼 잔여 캐시 < 예상 비용**: 빨강 경고 + 발송 비활성 + 외부 플랫폼 충전 링크
- **수신자 0명**: 발송 비활성 + "수신자가 없습니다"
- **플랫폼 메타데이터 조회 실패**: "발신 정보/예상 비용을 불러오지 못했습니다" + 재조회 안내
- **카카오 알림톡 비친구 포함**: "비친구 {인원수}명 제외" 안내. SMS 발송은 별도 채널 선택 시에만 가능
- **MMS 첨부 이미지 크기 초과 (300KB)**: "이미지 크기 초과" + 차단
- **법정 시간 (21~08시) 광고 발송**: "야간 광고 발송 불가" 모달 + 차단 (정보성 예외)
- **수신 거부 / 휴면 자동 제외**: 자동 제외 + "{인원수}명 제외" 안내
- **금지어 포함**: "금지어 포함: {단어}" 차단
- **알림톡 미승인 템플릿**: "사전 승인 템플릿 필요" + 저장/발송 차단
- **분할 처리 부분 실패**: 자동 재시도 3회 + 최종 실패 알림 + 플랫폼 실제 비용 재조회
- **외부 API 응답 지연**: "결과 확인 중" 표시 + 5분 후 새로고침
- **예약 발송 시점 플랫폼 잔여 캐시 부족**: 발송 보류 + 운영자 알림
- **플랫폼 단가 변경 후 진행 중 발송**: 발송 시점 플랫폼 응답 기준으로 처리
- **발송 중 사용자 취소 시도**: 분할 처리 중에는 일부 차감 + 미발송 부분 취소
- **외부 API 장애 (NHN/Toast 다운)**: 발송 보류 + 큐 대기 + 복구 시 재개
- **알림톡 비친구 처리**: 비친구는 자동 제외만 수행하며 SMS로 자동 전환하지 않는다
- **발신 번호 미인증**: "발신 번호 인증 필요" + 시스템 설정 이동
- **지역·가입 기간 0건**: "조건에 맞는 회원이 없습니다" + 발송 비활성
- **변수 데이터 누락**: 해당 회원 발송 제외 + 사유 기록
- **발송 이력 90일 경과**: 자동 아카이브 (비용 청구 근거 보존)
- **글자수 초과**: SMS→LMS 자동 전환 + 단가 변경 안내, LMS 2000byte 초과 시 차단

1. **채널 4종**: SMS / LMS / MMS / 카카오 알림톡. 예상 비용은 플랫폼 API에서 조회한다.
2. **플랫폼 비용 즉시 반영**: 플랫폼 단가/과금 정책 변경 시 SCR-071 / SCR-078 / DLG-078-002 비용 계산에 즉시 반영된다.
3. **플랫폼 단가 변경 후 진행 중 발송**: 발송 시점 플랫폼 응답 기준으로 처리한다.
4. **SMS 자동 전환 미사용**: 알림톡 비친구·실패 시 SMS로 자동 전환하지 않는다. 비친구는 제외 카운트로 표시하고, SMS 발송은 운영자가 SMS/LMS 채널을 별도 선택한 경우에만 수행한다.
5. **분할 처리**: 대량 발송 시 1만건 단위로 분할. 부분 실패는 자동 재시도 3회.
6. **자동 재시도**: 1분/5분/30분 간격 3회. 최종 실패 시 운영자 알림 + 플랫폼 실제 비용 재조회.
7. **외부 API webhook**: NHN/Toast 발송 결과 webhook으로 실시간 갱신 (성공/실패/일부 실패).
8. **발송 이력 90일 보관**: 비용 청구 근거로 사용. 90일 경과 시 자동 아카이브.
9. **플랫폼 잔여 캐시 부족 차단**: 발송 시점 플랫폼 잔여 캐시 < 예상 비용 시 차단 + 외부 플랫폼 충전 CTA.
10. **법정 시간 차단**: 영업/광고성 발송 21~08시 차단(정보통신망법). 정보성(결제·환불) 예외.
11. **수신 거부 / 휴면 자동 제외**: 모든 대량 발송에 자동 적용.
12. **금지어 차단**: 도박·대출·성인 등 사전 등록 금지어 포함 시 차단.
13. **알림톡 사전 승인**: 카카오 정책에 따라 사전 승인 템플릿만 발송. 미승인 시 저장 또는 발송을 차단한다.
14. **글자수 정책**: SMS 90byte (한글 45자) → LMS 2000byte 자동 전환 / 알림톡 1000자.
15. **MMS 첨부 이미지**: 최대 300KB. 초과 시 차단.
16. **발신 번호 인증**: 사전 인증된 번호만 발신 가능.
17. **발송 대상 조건**: 회원 등급(VIP/일반/신규) / 이용권 상태(활성/만료/홀딩) / 지역(시·구) / 가입 기간(기본 30일 이상). 다중 조합.
18. **메시지 템플릿**: 사전 등록 템플릿 또는 직접 작성. 변수 삽입 지원.
19. **권한별 가시성**:
    - 슈퍼관리자: 전체 발송 + 이력 + 플랫폼 연동 정보 조회
    - 센터장 / 매니저: 소속 지점 대량 발송 + 예약 + 이력
    - FC / 트레이너 / 스태프 / readonly: 차단
20. **발송 결과 카운트**: 성공·실패·미수신 분리 집계. 실패 사유별 통계.
21. **비용 그래프**: 월별 채널별 발송 비용 추이. 마케팅 예산 관리.
22. **플랫폼 비용 재동기화**: 발송 완료 후 플랫폼 사용량 API로 실제 비용을 재동기화한다.
23. **회계 청구 매핑**: 외부 API 청구서와 발송 이력 매핑. 정산 근거.
24. **감사 로그**: 발송 / 예약 / 재조회 / 재발송 모두 SCR-097 기록.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MKT-08`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-078`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-078-001 발송대상선택, DLG-078-002 발송확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
