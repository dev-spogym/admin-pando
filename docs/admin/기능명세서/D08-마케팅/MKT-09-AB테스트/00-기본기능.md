## 기능 목적

두 가지 버전(A안 / B안)의 메시지나 쿠폰 중 어느 것이 더 효과적인지 비교 실험하는 A/B 테스트를 설정·진행·결과 분석하는 화면이다. 무작위 분배·통계적 유의성 검증·승리 자동 판정·승리 버전 정식 캠페인(MKT-06) 자동 변환으로 데이터 기반 마케팅 전략 최적화를 지원한다. 정성적 추측이 아닌 정량 지표(도달 / 클릭율 / 전환율 / 매출 기여)로 의사결정한다.

운영 맥락:
- **메시지 카피 비교**: 동일 쿠폰 안내를 A안 "10% 할인"·B안 "특가 이벤트" 카피 비교
- **쿠폰 가치 비교**: 정액 5,000원·정률 10% 중 어느 것이 전환율↑인지 비교
- **이미지 비교**: MMS 이미지 A안·B안 비교
- **발송 시간대 비교**: 12:30·19:00 발송 시점 비교
- **무작위 50:50 분배**: 동일 세그먼트를 무작위로 양분
- **편향 분배 70:30**: 우세안 추정 시 보수적 편향
- **통계적 유의성 검증**: 최소 표본 수(예: 1000명) 도달 후 p-value 계산
- **승리 자동 판정**: 종료 후 통계 검증 통과한 버전 자동 우승
- **동률 시 수동 채택**: 통계적으로 동일하면 운영자가 수동 선택
- **MKT-06 캠페인 자동 변환**: 우승안을 정식 캠페인으로 1클릭 전환

테스트 목록 + DLG-079-001 등록 + 결과 비교 패널 + 승리 채택 + DLG-079-002 삭제 위자드로 구성된다.

## 주요 UX 흐름

### 테스트 등록 흐름
1. 사이드바 → "마케팅 > A/B 테스트" 진입
2. [테스트 등록] → DLG-079-001
3. 테스트명 + 유형(메시지/쿠폰) + A안 내용 + B안 내용 + 대상 비율(50:50/70:30/기타) + 대상 인원(무작위 분배) + 기간(시작~종료) + 승리 기준(클릭율/전환율/매출) 입력
4. 저장 → 준비 상태로 등록

### 테스트 진행 흐름
1. 시작일 자동 활성 (매일 04:00 배치)
2. 대상 인원 → 무작위 분배 (A안 N명 / B안 M명)
3. 각 버전 발송 (메시지 또는 쿠폰)
4. 실시간 지표 수집 (도달·클릭·전환·매출)
5. 동일 회원은 한 버전만 받음 (중복 노출 차단)

### 결과 분석 / 승리 채택 흐름
1. 종료일 자동 종료 (매일 04:00 배치)
2. 결과 비교 패널 (A안·B안 4종 지표 나란히 표시)
3. 통계적 유의성 검증 (p-value < 0.05)
4. 승리 자동 판정 (유의성 통과 시) 또는 "동일" 표시 (통과 실패)
5. 승리 버전 채택 → MKT-06 캠페인 자동 변환 옵션 (1클릭)
6. 변환 시 캠페인 등록 화면 자동 입력 + 검토 후 활성

### 강제 종료 흐름
1. 결과 명확 시 [강제 종료]
2. 확인 모달 + 통계 검증 (표본 부족 경고 가능)
3. 종료 → 우승안 채택 또는 동률 처리

### 분기·예외 흐름
- **A안 / B안 동일 내용**: "내용이 다른 두 버전 필요" 인라인 에러 + 저장 차단
- **대상 비율 합계 ≠ 100%**: "A+B = 100%" 검증 + 저장 차단
- **시작일 > 종료일**: 인라인 에러
- **대상 인원 0명**: "대상 회원이 없습니다" + 저장 차단
- **승리 기준 미선택**: "승리 기준 필수" + 저장 차단
- **표본 수 부족 (1000명 이하)**: "통계적 유의성 미달" 경고 + 결과 신뢰도 안내
- **통계적 동률**: "동일" 표시 + 운영자 수동 선택 모달
- **진행 중 수정 시도**: "진행 중 테스트는 수정 불가" 차단
- **종료 전 강제 종료**: 표본 부족 경고 + 확인 후 종료
- **잔여 포인트 부족**: 발송 보류 + 운영자 알림
- **회원 중복 노출 차단**: 동일 회원이 다른 AB 테스트 중에도 노출되면 1개만 (정책)
- **AB 테스트 + 캠페인 동시 발송**: 캠페인 메시지 우선 또는 AB 우선 (정책)
- **승리안 캠페인 변환 시 검토 필요**: 자동 변환 후 운영자 검토 필수 (즉시 활성 차단)
- **테스트 삭제 (진행 중)**: 즉시 종료 + 결과 보존
- **테스트 삭제 (종료 후)**: 결과 영구 보존 + soft delete
- **외부 API 발송 실패 (B안만)**: 양쪽 표본 차이 발생 시 결과 신뢰도 경고
- **변수 데이터 누락 (A안만)**: 발송 제외 + 결과 영향 안내
- **수신 거부 / 휴면 자동 제외**: 양쪽 동일하게 자동 제외
- **법정 시간 차단**: 양쪽 동일하게 21~08시 차단
- **본사 vs 지점 AB 테스트 충돌**: 본사 우선 또는 둘 다 진행 (정책)
- **승리 기준 변경 시도 (진행 중)**: 차단

## 비즈니스 규칙

1. **상태 3종**: 준비 / 진행 / 완료. 시작일 자동 활성, 종료일 자동 종료.
2. **유형 2종**: 메시지 / 쿠폰. 메시지는 텍스트·이미지·발송 시간, 쿠폰은 정액·정률·금액·기간 비교.
3. **무작위 분배**: 대상 인원을 비율(50:50/70:30/기타)에 따라 무작위 분배. 동일 회원은 한 버전만 받음 (중복 노출 차단).
4. **대상 비율 검증**: A + B = 100%. 합계 불일치 시 저장 차단.
5. **표본 수 정책**: 최소 1000명 권장. 미달 시 "통계적 유의성 미달" 경고 (결과는 표시).
6. **통계적 유의성**: p-value < 0.05 검증. 통과 시 승리 자동 판정, 미통과 시 "동일".
7. **승리 기준 3종**: 클릭율 / 전환율 / 매출 기여. 등록 시 1개 선택. 진행 중 변경 차단.
8. **결과 비교 4종 지표**: 도달 수 / 클릭율 / 전환율 / 매출 기여. 실시간 갱신.
9. **승리 자동 판정**: 종료 후 자동 통계 검증 + 우승안 표시.
10. **동률 시 수동 채택**: 통계적 동일 또는 표본 부족 시 운영자 수동 선택.
11. **승리 채택 시 캠페인 변환 (MKT-06)**: 1클릭 변환 + 운영자 검토 필수 (즉시 활성 차단).
12. **진행 중 수정 차단**: 진행 중 테스트는 일체 수정 차단 (강제 종료만 가능).
13. **강제 종료**: 결과 명확 시 종료 전 종료 가능. 표본 부족 경고 + 확인.
14. **삭제 정책**: 진행 전 hard delete. 진행 중·종료는 soft delete (결과 보존).
15. **AB 동일 내용 차단**: A안·B안 내용이 동일하면 저장 차단.
16. **회원 중복 노출 정책**: 다중 AB 테스트 동시 진행 시 동일 회원 1개만 (정책).
17. **법정 시간 차단**: 양쪽 동일하게 21~08시 차단.
18. **수신 거부 / 휴면 자동 제외**: 양쪽 동일 적용.
19. **잔여 포인트 부족 처리**: 발송 보류 + 운영자 알림.
20. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 테스트 + 본사 통합
    - 센터장 / 매니저: 소속 지점 테스트 + 등록·삭제·결과·채택
    - FC / 트레이너 / 스태프 / readonly: 차단
21. **결과 영구 보존**: 종료 후 결과 영구 보존 (학습·재활용).
22. **본사 통합 AB 테스트**: 슈퍼관리자가 전 지점 일괄 테스트.
23. **외부 API 발송 실패 시 결과 신뢰도**: 양쪽 표본 차이 발생 시 경고 표시.
24. **감사 로그**: 등록·강제 종료·결과 채택·캠페인 변환·삭제 모두 SCR-097 기록.
