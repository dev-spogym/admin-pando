## 기능 목적

두 가지 버전의 메시지나 쿠폰 중 어느 것이 더 효과적인지 비교 실험하는 A/B 테스트를 설정하고 결과를 분석하는 화면이다. 데이터 기반으로 마케팅 전략을 최적화하며 정성적 추측이 아닌 정량 지표(클릭율·전환율·매출 기여)로 의사결정을 지원한다.

## 주요 구성요소

### A/B 테스트 목록

| 컬럼 | 설명 |
|------|------|
| 테스트명 | 이름 |
| 유형 | 메시지 / 쿠폰 |
| 기간 | 시작 ~ 종료 |
| 상태 | 준비 / 진행 / 완료 |
| 승리 버전 | A안 / B안 / 동일 |
| 액션 | [상세] / [삭제] |

### 테스트 등록 (DLG-079-001)

| 항목 | 입력 |
|------|------|
| 테스트명 | 텍스트 |
| 유형 | 메시지 / 쿠폰 |
| A안 내용 | 텍스트·이미지 |
| B안 내용 | 텍스트·이미지 |
| 대상 비율 | A:B = 50:50 / 70:30 |
| 대상 인원 | 무작위 분배 |
| 기간 | 시작 ~ 종료 |
| 승리 기준 | 클릭율 / 전환율 / 매출 |

### 결과 비교 패널

A안과 B안 나란히 비교.

| 지표 | A안 | B안 |
|------|----|----|
| 도달 수 | N | N |
| 클릭율 | % | % |
| 전환율 | % | % |
| 매출 기여 | 천 단위 | 천 단위 |

### 승리 버전 채택

결과 분석 후 승리 버전을 정식 캠페인에 적용.

### 테스트 삭제 (DLG-079-002)

삭제 확인.

## 주요 UX 흐름

**테스트 등록**
1. 사이드바 → "마케팅 > A/B 테스트" 진입
2. [테스트 등록] → DLG-079-001
3. 유형·A안·B안·대상 비율·기간·승리 기준 입력
4. 저장 → 준비 상태

**테스트 진행**
1. 시작일 자동 활성
2. 무작위 분배된 수신자에게 각 버전 발송
3. 실시간 지표 추적

**결과 분석**
1. 종료 후 결과 비교 패널
2. 통계적 유의성 검증
3. 승리 버전 채택 → 정식 캠페인

## 비즈니스 규칙

1. A/B 테스트 대상은 무작위 분배되며 동일 회원은 한 버전만 받는다.
2. 통계적 유의성 검증을 통해 승리 판정의 신뢰성을 확인한다 (최소 표본 수 필요).
3. 기간 종료 후에만 승리 버전을 채택할 수 있다.
4. 동일 결과인 경우 "동일" 표시되며 운영자가 수동 선택한다.
5. 승리 버전 채택 시 정식 캠페인(MKT-06)으로 자동 변환할 수 있다.
6. 변경 이력은 감사 로그에 기록된다.
