## 기능 목적

회원에게 SMS, 카카오 알림톡, 앱 푸시 메시지를 직접 작성해 발송하고, 발송 이력을 관리하는 화면이다. 수신자를 조건별로 선택하고 예약 발송도 설정할 수 있어 회원 소통의 핵심 창구 역할을 한다. 잔여 포인트 기반 비용 차감과 변수 삽입(회원명·만료일)으로 개인화된 메시지를 효율적으로 전송한다.

## 주요 구성요소

### 탭 전환

메시지 전송 / 발송 이력.

### 보유 포인트 표시

상단에 잔여 포인트 표시. 부족 시 경고.

### 발신 설정

발신 번호 선택 + 카카오 알림톡 활성 토글.

### 수신자 선택

| 옵션 | 설명 |
|------|------|
| 전체 회원 | 일괄 |
| 활성 회원 | active만 |
| 만료 회원 | expired만 |
| 개별 검색 | DLG-071-001 |
| 리드 그룹 | CRM-01 리드 |

### 발송 채널 선택

| 채널 | 비용 |
|------|------|
| 알림톡 | 저렴 (카카오 친구) |
| SMS·LMS | 중간 |
| 앱 푸시 | 무료 (앱 회원) |

### 예상 비용 안내

선택 수신자 수 × 채널 단가 → 실시간 표시.

### 메시지 작성

자유 텍스트 + 변수 삽입.

| 변수 | 설명 |
|------|------|
| {회원명} | 회원 이름 |
| {만료일} | 이용권 만료일 |
| {잔여횟수} | PT 잔여 횟수 |
| {담당FC} | 담당 FC |

### 발송 미리보기 (DLG-071-002)

수신자 화면 형태로 미리 확인.

### 발송 / 예약 발송

즉시 또는 원하는 일시에 예약.

### 발송 이력 테이블

| 컬럼 | 설명 |
|------|------|
| 발송 일시 | YYYY-MM-DD HH:mm |
| 채널 | 알림톡/SMS/푸시 |
| 수신자 수 | 카운트 |
| 내용 요약 | 첫 30자 |
| 발송 결과 | 성공/실패/일부 실패 |
| 액션 | [상세] |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 발송 + 이력 | 메시지·발신 설정·예약 |
| owner (센터장) | 전체 발송 + 이력 | 메시지·발신 설정·예약 |
| manager | 전체 발송 + 이력 | 메시지·발신 설정·예약 |
| fc | 메시지 전송 탭 | 담당 회원 발송 (발신 설정 불가) |
| 트레이너 / 스태프 | 접근 제한 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**즉시 발송**
1. 사이드바 → "마케팅 > 메시지 발송" 진입
2. 수신자 선택 (조건 그룹 / 개별 / 리드)
3. 채널 선택 → 예상 비용 표시
4. 메시지 작성 + 변수 삽입
5. [미리보기] → DLG-071-002
6. [발송] → 처리 → 이력 자동 이동

**예약 발송**
1. 동일 흐름 + [예약 발송]
2. 일시 선택 → 예약 등록
3. 예약 시점 자동 발송

**이력 조회**
1. "발송 이력" 탭
2. 발송 결과 + 상세 확인

## 비즈니스 규칙

1. 메시지 발송 시 잔여 포인트에서 자동 차감되며 부족 시 발송 차단된다.
2. 카카오 알림톡은 카카오 채널 친구 회원에게만 발송 가능하다.
3. 앱 푸시는 회원앱 설치 회원에만 발송되며 무료이다.
4. 변수 삽입 시 수신자별로 자동 치환된다.
5. 예약 발송은 분 단위로 설정 가능하며 발송 5분 전 취소 가능하다.
6. FC는 본인 담당 회원에게만 발송 가능하며 발신 설정은 변경할 수 없다.
7. 발송 결과는 90일 이상 보관되며 감사 로그에 기록된다.
