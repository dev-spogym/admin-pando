## 기능 목적

할인 쿠폰을 생성·관리하고 특정 회원 또는 그룹에게 발급하는 화면이다. 쿠폰별 발급 현황과 사용률 통계를 통해 쿠폰 마케팅 효과를 파악하고 운영 전략을 조정한다. 정액·정률, 유효 기간, 발급 수량 제한, 1인 사용 제한 설정으로 다양한 마케팅 시나리오를 지원한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 내용 |
|------|------|
| 전체 쿠폰 수 | 합계 |
| 발급 건수 | 누적 |
| 사용 건수 | 사용 누적 |
| 평균 사용률 | 사용/발급 |

활성 / 만료 / 중단 필터.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 쿠폰 | 생성·수정·삭제·발급 |
| owner (센터장) | 소속 센터 쿠폰 | 생성·수정·삭제·발급 |
| manager | 소속 센터 쿠폰 | 생성·수정·발급 |
| fc | 쿠폰 목록 | 발급만 (생성·삭제 불가) |
| 트레이너 / 스태프 | 접근 제한 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**쿠폰 생성**
1. 사이드바 → "마케팅 > 쿠폰 관리" 진입
2. [쿠폰 생성] → DLG-073-001
3. 이름·유형·값·기간·제한·적용 상품 입력
4. 저장 → 목록 추가

**쿠폰 발급**
1. 행 [발급] → DLG-073-002
2. 회원/그룹/등급 선택 + 메시지
3. 발급 → 회원 알림

**쿠폰 삭제**
1. 행 [삭제] → DLG-073-003
2. 사용 중 안내 → 확인

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 스켈레톤 |
| 정상 | 목록 |
| 쿠폰 없음 | "등록된 쿠폰이 없습니다" + 생성 CTA |
| 만료 쿠폰 | "만료" 배지 + 발급 비활성 |

## 비즈니스 규칙

1. 정액 쿠폰은 0 초과 금액, 정률 쿠폰은 1~100% 범위로 검증한다.
2. 유효 기간 만료 시 자동 "만료" 상태로 전환되고 신규 발급이 차단된다.
3. 발급 수량 제한 도달 시 더 이상 발급되지 않는다.
4. 1인 사용 제한 적용 시 한 회원이 동일 쿠폰을 N회만 사용할 수 있다.
5. 쿠폰 사용 시 결제 시 자동 차감되며 사용률 통계에 반영된다.
6. 삭제는 사용 이력이 없는 쿠폰만 가능하며, 사용 중 쿠폰은 "중단"으로 전환된다.
7. 모든 발급·사용은 감사 로그에 기록된다.
