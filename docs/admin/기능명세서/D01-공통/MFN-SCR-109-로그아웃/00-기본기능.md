## 기능 목적

운영자가 업무를 마치거나 다른 계정으로 전환이 필요할 때, 현재 세션을 안전하게 종료하고 로그인 화면으로 이동하는 흐름이다. 실수로 로그아웃 버튼을 누르는 경우를 방지하기 위해 DLG-001(로그아웃 확인) 다이얼로그를 경유하며, 확인 후에만 세션이 종료된다.

로그아웃 완료 시 클라이언트 측 토큰·캐시 데이터를 모두 초기화하여 다음 사용자가 잔류 데이터에 접근하지 못하도록 보안 처리한다.

## 주요 구성요소

### 로그아웃 진입 요소

| 진입 위치 | 요소 |
|---------|------|
| 사이드바 하단 | 로그아웃 버튼 |
| 상단 프로필 메뉴 | 프로필 아이콘 클릭 → 드롭다운 → 로그아웃 항목 |
| SCR-105 프로필/계정 | 로그아웃 버튼 |

### 로그아웃 확인 다이얼로그 (DLG-001)

| 요소 | 동작 |
|------|------|
| 확인 메시지 | "로그아웃 하시겠습니까?" |
| 로그아웃 확인 버튼 | 세션 종료 처리 시작 |
| 취소 버튼 | 다이얼로그 닫기, 현재 화면 유지 |

### 처리 흐름

1. 로그아웃 버튼 클릭 → DLG-001 표시
2. 확인 클릭 → 버튼 비활성 + 로딩 처리
3. API 호출로 서버 측 세션 무효화
4. 클라이언트 측 토큰·캐시 초기화
5. SCR-100 로그인 화면으로 자동 이동

## 주요 이벤트 / 자동화

- **세션 만료 자동 로그아웃**: 비활동 세션이 만료되면 DLG-000(세션 만료 다이얼로그)이 표시되고, 재로그인 없이 일정 시간 경과 시 자동으로 로그인 화면으로 이동한다.
- **보안 초기화**: 로그아웃 시 클라이언트에 저장된 모든 인증 토큰과 민감 데이터가 초기화되어 세션 잔류를 방지한다.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MFN-SCR-109`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-109`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-001-로그아웃확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
