## 기능 목적

로그인 직후 관리자가 가장 먼저 마주하는 통합 현황 화면이다. 오늘의 출석 수, 당일 매출, 만료 예정 회원 수 등 핵심 운영 수치를 카드 형태로 한눈에 확인하고, 수업·회원·매출 위젯을 통해 즉시 조치가 필요한 사안을 식별한다. 빠른 액션 버튼으로 회원 등록·결제 처리 같은 주요 업무를 즉시 시작할 수 있어, 별도의 탐색 없이 하루 운영을 시작하는 허브 역할을 한다.

계정 역할에 따라 표시되는 정보 범위와 가능한 액션이 달라진다. 슈퍼관리자는 상단 지점 필터를 통해 전체 지점 현황을 전환하며 조회할 수 있고, FC·스태프는 오늘 일정과 출석 현황만 읽기 전용으로 조회한다. D10의 SCR-090(본사 대시보드)과는 별개의 화면으로, SCR-101은 공통 레이아웃 진입 직후의 통합 뷰를 담당한다.

## 주요 구성요소

### 오늘의 핵심 수치 요약 카드

| 카드 | 표시 내용 | 클릭 동작 |
|------|----------|-----------|
| 오늘 출석 | 당일 출석 완료 인원 수 | 출석 관리 화면 진입 |
| 당일 매출 | 당일 누적 매출액 (천 단위 구분) | 매출 현황 화면 진입 |
| 만료 예정 회원 | 30일 이내 이용권 만료 예정 인원 | 회원 목록 (만료 임박 필터) 진입 |
| 이번 달 신규 등록 | 당월 신규 등록 회원 수 | 회원 목록 (신규 필터) 진입 |

### 수업 현황 위젯

- 오늘 수업 일정 목록 (시간·수업명·강사·예약 인원 / 정원)
- 예약 현황 진행률 바
- [전체보기] 링크 → 수업 캘린더 진입

### 회원 현황 위젯

- 신규 등록 회원 목록 (최근 5명)
- 만료 예정 회원 목록 (D-7 이내)
- 각 항목 클릭 → 회원 상세(SCR-M004) 진입

### 실시간 출석 확인 카드

- 키오스크 QR, 앱 QR, RFID/밴드, 얼굴인식, 수동 출석 이벤트를 동일한 카드 목록에 표시한다.
- 데스크톱 기준 최대 10개를 유지하며, 초과 시 가장 오래된 출석 카드부터 제거한다.
- 동일 회원은 첫 출석 후 2시간 이내 재출석 시 중복 카드를 생성하지 않는다.
- 회원 사진이 있으면 사진을 표시하고, 없으면 기본 아바타와 "사진 필요" 태그를 표시한다.
- 카드에는 회원명, 회원번호, 성별/나이, 이용권명, 만료일, 출석 시각, 출석 채널, 주의 태그를 표시한다.
- 만료 임박 태그는 본사 자동화 정책 또는 지점 키오스크 출입 규칙의 만료 안내 기준일을 따른다.
- 신규 출석 이벤트 수신 시 카드가 짧게 강조되고 알림음과 토스트가 표시된다.
- 카드 클릭 시 회원 상세(SCR-M004) 기본정보 탭으로 이동한다.

### 매출 현황 위젯

- 당월 누적 매출 추이 (선 또는 막대 차트)
- 전월 대비 증감률 표시
- [전체보기] 링크 → 매출 현황 화면 진입

### 빠른 액션 버튼

| 버튼 | 동작 | 노출 권한 |
|------|------|-----------|
| 회원 등록 | 회원 등록 화면(SCR-M002) 진입 | owner, manager, staff, superAdmin, primary |
| 결제 처리 | 결제 처리 화면 진입 | owner, manager, fc, superAdmin, primary |
| 수업 추가 | 수업 등록 화면 진입 | owner, manager, superAdmin, primary |

### 지점 필터 (슈퍼관리자 전용)

- 상단 드롭다운으로 조회할 지점 전환
- 전환 시 모든 위젯 데이터 재조회

### 엑셀 내보내기 버튼

- 현재 대시보드 요약 데이터 다운로드
- 노출 권한: superAdmin, primary, owner, manager

## 주요 이벤트 / 자동화

- **로그인 직후 자동 진입**: 인증 성공 시 역할 판정 후 이 화면 또는 지정 화면으로 자동 이동.
- **위젯 데이터 갱신**: 대시보드 진입 시 최신 데이터를 fetch하며, 실시간 또는 5분 캐시 기반으로 갱신된다.
- **만료 임박 자동 감지**: 30일 이내 만료 예정 회원은 별도 위젯에 자동 집계되어 FC·매니저가 즉시 확인할 수 있다.
- **출석 확인 실시간 반영**: 키오스크·QR·RFID·얼굴인식·수동 출석 이벤트가 들어오면 FC 확인 카드에 즉시 반영한다.
- **사진 보완 알림**: 프로필 사진이 없는 회원의 첫 출석 카드가 생성되면 FC에게 현장 사진 촬영 필요 토스트를 표시한다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 데이터 로드 실패 | 위젯별 오류 안내 + 재시도 버튼 |
| 오늘 수업 없음 | "오늘 등록된 수업이 없습니다" 빈 상태 표시 |
| 오늘 매출 0원 | 0원으로 표시, 빈 상태 처리 불필요 |
| 신규 센터 (전체 데이터 없음) | 위젯별 "데이터가 없습니다" + 등록 유도 CTA |
| 지점 필터 전환 중 로딩 | 전환 중 스켈레톤 표시 |
| 권한 없는 메뉴 클릭 | 접근 제한 안내 또는 버튼 미노출 |
| 오프라인 | 네트워크 단절 배너 + 마지막 캐시 데이터 표시 |
| 출석 카드 10개 초과 | 가장 오래된 카드 제거 |
| 동일 회원 2시간 내 재출석 | 새 카드 생성 안 함 |
| 사진 미등록 | 기본 아바타 + 사진 촬영 필요 토스트 |
| 만료/미수 주의 | 카드 경고 색상 + 주의 태그 표시 |

## 연관 문서

- 화면설계서: SCR-101-대시보드통합
- 관련 기능: SCR-102-사이드바네비게이션 (진입 경로), SCR-103-글로벌검색 (상단 공통), SCR-104-알림센터 (상단 공통)
- D10 도메인: DASH-01-대시보드 (SCR-090 본사 대시보드, 별개 화면)

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MFN-SCR-101`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-101`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
