## 기능 목적

어느 화면에서든 상단 검색창 또는 단축키(Cmd+K / Ctrl+K)를 통해 회원·직원·수업·상품을 즉시 검색할 수 있는 통합 검색 기능이다. 사이드바 탐색 없이 원하는 데이터로 직접 진입할 수 있어, 특히 회원 이름을 알고 있는 FC·스태프의 빠른 업무 처리를 지원한다.

검색 결과는 카테고리별로 구분되어 표시되며, 항목 클릭 시 해당 상세 화면으로 직접 이동한다. 최근 검색어 목록이 저장되어 반복 검색을 줄이고, 역할에 따라 검색 가능한 데이터 범위가 제한된다.

## 주요 구성요소

### 검색 진입 요소

| 요소 | 동작 |
|------|------|
| 상단 검색 아이콘/바 | 클릭 시 검색 오버레이 열림 |
| Cmd+K (Mac) / Ctrl+K (Windows) | 어느 화면에서든 검색 오버레이 즉시 열림 |

### 검색 오버레이 구성

| 영역 | 설명 |
|------|------|
| 검색 입력창 | 자동 포커스, placeholder="회원, 직원, 수업, 상품 검색" |
| 최근 검색어 | 오버레이 열림 초기 상태, 최대 5개 표시 |
| 검색 결과 드롭다운 | 카테고리별 구분 (회원 / 직원 / 수업 / 상품) |
| 결과 없음 안내 | 검색 결과가 없을 때 "검색 결과가 없습니다" 표시 |

### 검색 결과 카테고리

| 카테고리 | 표시 항목 | 클릭 이동 |
|---------|----------|-----------|
| 회원 | 회원명, 연락처, 상태 배지 | 회원 상세(SCR-M004) |
| 직원 | 직원명, 역할, 소속 지점 | 직원 상세 화면 |
| 수업 | 수업명, 강사, 일정 | 수업 상세 또는 캘린더 |
| 상품 | 상품명, 유형, 가격 | 상품 상세 화면 |

각 카테고리 최대 3~5개 결과 표시, 더보기 클릭 시 해당 목록 화면으로 이동.

## 권한

| 역할 | 검색 가능 범위 |
|---|---|
| superAdmin | 전체 지점 회원·직원·수업·상품 |
| primary | 소속 브랜드 전체 지점 데이터 |
| owner | 소속 지점 데이터만 |
| manager | 소속 지점 데이터만 |
| fc | 소속 지점 회원·수업만 (직원·상품 제외 가능) |
| staff | 소속 지점 회원·수업만 |
| trainer | 담당 회원 및 수업만 |
| readonly | 소속 지점 조회 전용 |

## 주요 이벤트 / 자동화

- **최근 검색어 자동 저장**: 검색 결과 항목 클릭 시 해당 검색어가 localStorage에 자동 저장되어 다음 검색 시 표시된다.
- **디바운스 처리**: 입력 후 300ms 대기 후 API를 호출하여 불필요한 네트워크 요청을 최소화한다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 검색어 2자 미만 | 결과 표시 안 함, 최근 검색어 유지 |
| 결과 없음 | "검색 결과가 없습니다" 안내 |
| API 오류 | "검색 중 오류가 발생했습니다. 다시 시도해주세요" |
| 오프라인 | 오프라인 안내, 검색 비활성 |
| 권한 없는 카테고리 | 해당 카테고리 섹션 미노출 |
