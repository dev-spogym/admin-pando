## 기능 목적

회원 만료 예정, 수업 취소, 결제 완료 등 운영 중 발생하는 주요 이벤트를 실시간으로 수신하고, 알림 패널에서 한눈에 확인하는 기능이다. 미읽음 알림 수가 아이콘 배지로 상시 표시되어, 담당자가 어느 화면에 있어도 새 이벤트를 즉시 인지할 수 있다.

알림 항목을 클릭하면 관련 화면으로 직접 이동하고 읽음 처리가 동시에 이루어진다. 역할에 따라 받는 알림 유형과 관리 가능한 액션이 다르며, 슈퍼관리자·본사 관리자는 전체 읽음·전체 삭제 권한을 갖는다.

## 주요 구성요소

### 상단 알림 아이콘

| 상태 | 표시 방식 |
|------|-----------|
| 미읽음 있음 | 아이콘 + 미읽음 수 숫자 배지 (최대 99+) |
| 전부 읽음 | 아이콘만 (배지 없음) |

### 알림 패널

- 상단 알림 아이콘 클릭 시 우측 또는 하단 패널로 열림
- 알림 목록: 최신순 정렬
- ESC 또는 바깥 클릭으로 닫힘

### 알림 항목 구성

| 요소 | 설명 |
|------|------|
| 알림 유형 아이콘 | 유형별 아이콘 (회원/결제/수업/시스템) |
| 알림 내용 요약 | 한 줄 요약 텍스트 |
| 발생 시각 | "3분 전", "오늘 오전 9:30" 형식 |
| 읽음/미읽음 표시 | 미읽음 항목 강조 표시 (점 또는 배경색) |
| 개별 읽음 처리 | 클릭 시 읽음 처리 |
| 개별 삭제 | 항목 우측 삭제 버튼 |

### 주요 알림 유형

| 알림 유형 | 예시 | 이동 화면 |
|---------|------|----------|
| 회원 만료 예정 | "홍길동 회원 이용권이 3일 후 만료됩니다" | 회원 상세(SCR-M004) |
| 결제 완료 | "김철수 회원 결제가 완료되었습니다" | 결제 이력 화면 |
| 수업 취소 | "오전 10시 필라테스 수업이 취소되었습니다" | 수업 캘린더 |
| 시스템 공지 | "시스템 점검이 예정되어 있습니다" | 공지 상세 또는 없음 |

### 일괄 관리 버튼

| 버튼 | 동작 | 노출 권한 |
|------|------|-----------|
| 전체 읽음 처리 | 모든 미읽음 알림 일괄 읽음 처리 | 전체 역할 |
| 전체 삭제 | 모든 알림 삭제 | owner, manager, superAdmin, primary |
| 알림 설정 바로가기 | 알림 설정 화면 진입 | 전체 역할 |

## 권한

| 역할 | 받는 알림 종류 | 가능한 관리 액션 |
|---|---|---|
| superAdmin | 전체 지점 시스템 알림 + 운영 알림 | 전체 읽음, 전체 삭제, 설정 |
| primary | 소속 브랜드 전체 지점 알림 | 전체 읽음, 전체 삭제, 설정 |
| owner | 소속 지점 운영 알림 | 전체 읽음, 전체 삭제, 설정 |
| manager | 소속 지점 운영 알림 | 전체 읽음, 전체 삭제, 설정 |
| fc | 담당 수업·회원 관련 알림 | 개별 읽음, 개별 삭제만 |
| staff | 출석·회원 관련 알림 | 개별 읽음, 개별 삭제만 |
| trainer | 담당 수업 관련 알림 | 개별 읽음, 개별 삭제만 |
| readonly | 조회 전용 알림 | 개별 읽음만 |

## 주요 이벤트 / 자동화

- **실시간 알림 수신**: WebSocket 또는 SSE(Server-Sent Events)를 통해 서버 이벤트 발생 즉시 클라이언트에 푸시된다.
- **배지 자동 갱신**: 새 알림 수신 시 아이콘 배지 카운트가 즉시 증가하며, 전체 읽음 처리 시 배지가 사라진다.
- **세션 만료 알림**: 세션이 만료 임박할 경우 알림 패널을 통해 별도 안내가 표시될 수 있다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 알림 없음 | "새 알림이 없습니다" 빈 상태 표시 |
| 알림 로드 실패 | 패널 내 오류 안내 + 재시도 버튼 |
| 전체 삭제 실패 | "삭제 중 오류가 발생했습니다" 토스트 안내 |
| 실시간 연결 끊김 | 재연결 시도, 재연결 실패 시 수동 새로고침 유도 |
| 권한 없는 삭제 시도 | 전체 삭제 버튼 미노출 처리로 사전 차단 |
