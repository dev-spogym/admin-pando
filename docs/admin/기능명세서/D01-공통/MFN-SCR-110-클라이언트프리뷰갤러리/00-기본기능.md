## 기능 목적

외부 클라이언트가 FitGenie CRM 계정 없이 퍼블리싱된 화면을 확인할 수 있도록 공개 갤러리 진입점을 제공한다. 내부 검수용 `/publishing`과 동일한 화면 카탈로그를 사용하되, 공개 화면에서는 로그인 가드와 CRM 운영 레이아웃을 제거하고 preview 모드 화면만 iframe으로 보여준다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 공개 개요 | `/client-preview`에서 전체 퍼블리싱 카테고리와 화면 수 표시 |
| 공개 카테고리 | `/client-preview/{category}`에서 도메인별 화면 목록 표시 |
| 화면 검색 | 화면명, route, 설명으로 목록 필터링 |
| 타입 필터 | 대시보드, 목록/운영, 입력/설정, 상세/확인, 진입 화면 기준 필터 |
| iframe 프리뷰 | 선택 화면의 `preview=1` URL 렌더링 |
| 새 탭 보기 | 선택 화면을 `preview=1` 상태로 새 탭에서 열기 |

## 노출 정책

- 공개 갤러리는 `AppLayout`을 사용하지 않는다.
- 공개 갤러리의 화면 이동 링크는 `/client-preview` prefix를 유지한다.
- 클라이언트 공개 화면에서는 내부 개발 가이드, 기능명세 파일 경로, 실제 운영 라우트 직접 열기를 숨긴다.
- iframe과 새 탭 링크는 항상 `preview=1` URL을 사용한다.
- 실데이터 검수 목적이 아니라 퍼블리싱 형태와 화면 상태 검토 목적이다.
- 배포 헤더는 같은 origin iframe을 허용해야 한다. `X-Frame-Options: DENY`는 `/client-preview` 내부 iframe을 차단하므로 `SAMEORIGIN`과 `frame-ancestors 'self'` 조합을 사용한다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 존재하지 않는 category | 404 처리 |
| `screen` query 없음 | 카테고리 첫 화면 자동 선택 |
| 필터 결과 없음 | 빈 상태 안내 표시 |
| preview 화면 로딩 실패 | iframe 영역에서 브라우저 기본 오류 표시, 새 탭 보기로 재확인 가능 |
