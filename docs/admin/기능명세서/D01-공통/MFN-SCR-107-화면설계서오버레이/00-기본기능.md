## 기능 목적

개발·기획·QA 팀원이 실제 운영 화면을 보면서 해당 화면의 기획 의도와 화면 설계 내용을 즉시 참조할 수 있도록, 우측에서 슬라이드 인되는 오버레이 패널이다. 별도 문서 탭을 열지 않고도 Cmd+/ (Mac) 또는 Ctrl+/ (Windows) 단축키 한 번으로 현재 화면의 기능명세·화면설계서를 확인할 수 있어, 개발 중 설계 이해도를 높이고 커뮤니케이션 비용을 줄인다.

고객사 담당자가 시스템 시연 중 기획 내용을 바로 확인하거나, 신규 직원이 화면 기능을 파악할 때도 활용된다. 이 기능은 운영 데이터에 영향을 주지 않는 순수 참조용 개발 도구이다.

## 주요 구성요소

### 오버레이 진입

| 요소 | 동작 |
|------|------|
| Cmd+/ (Mac) | 어느 화면에서든 오버레이 즉시 열기 |
| Ctrl+/ (Windows) | 어느 화면에서든 오버레이 즉시 열기 |
| 재입력 시 닫힘 | 동일 단축키 재입력 시 패널 닫힘 |

### 오버레이 패널 구성

| 영역 | 설명 |
|------|------|
| 화면명 + 카테고리 배지 | 현재 화면의 ID(예: SCR-100)와 도메인 배지 표시 |
| 탭 전환 | 기능명세 탭 / 화면설계 탭 |
| 섹션별 아코디언 | 각 섹션을 접기/펼치기 가능, 현재 화면 관련 섹션 자동 강조 |
| 내부 검색 | Ctrl+F로 패널 내 텍스트 검색 |
| 읽기 진행률 표시바 | 스크롤 위치 기반 진행률 표시 |
| 전체보기 버튼 | 패널을 전체 화면으로 확장 |
| 닫기 버튼 | 패널 닫기 (ESC 키와 동일) |

### 탭별 내용

| 탭 | 표시 내용 |
|----|----------|
| 기능명세 탭 | 현재 화면의 기능 목적, Lv2/Lv3 매트릭스, 권한, 비즈니스 규칙 등 |
| 화면설계 탭 | 화면 상태별 설계 내용, UI 구성요소 설명, UX 흐름 |

## 주요 이벤트 / 자동화

- **현재 화면 자동 감지**: 라우터 경로를 기반으로 해당 화면의 문서를 자동으로 매핑하여 표시한다. 경로 변경 시 패널이 열려 있으면 새 화면의 문서로 자동 전환된다.
- **단축키 글로벌 등록**: Cmd+K(글로벌 검색)와 충돌하지 않도록 Cmd+/로 별도 등록된다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 해당 화면 문서 미존재 | "해당 화면의 문서를 준비 중입니다" 안내 표시 |
| 문서 로딩 실패 | "문서를 불러오지 못했습니다. 다시 시도해주세요" + 재시도 버튼 |
| 단축키 충돌 | 다른 입력 필드에 포커스된 상태에서는 단축키 무시 |
| 오프라인 | 마지막 캐시된 문서 표시 또는 오프라인 안내 |
