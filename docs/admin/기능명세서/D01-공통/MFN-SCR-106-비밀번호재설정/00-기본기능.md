## 기능 목적

비밀번호를 분실하거나 변경해야 하는 관리자가 이메일 인증을 통해 새 비밀번호를 안전하게 설정하는 화면이다. 로그인 화면에서 진입하는 비로그인 경로와, 프로필/계정 설정(SCR-105)에서 진입하는 로그인 상태 경로 두 가지를 지원한다.

3단계 스텝(이메일 입력 → 인증 메일 확인 안내 → 새 비밀번호 설정)으로 구성되어 있으며, 각 단계별로 명확한 안내 메시지와 오류 처리를 제공한다. 인증 링크는 일정 시간(30분) 내에 사용해야 하며, 변경 완료 후 로그인 화면으로 자동 이동한다.

## 주요 구성요소

### 1단계 — 이메일 입력

| 요소 | 설명 |
|------|------|
| 이메일 입력란 | 가입 시 사용한 이메일 입력, autofocus |
| 인증 메일 발송 버튼 | 입력한 이메일로 재설정 링크 발송 |
| 로그인 화면으로 돌아가기 링크 | SCR-100 로그인 화면으로 이동 |

### 2단계 — 인증 메일 확인 안내

| 요소 | 설명 |
|------|------|
| 발송 완료 안내 메시지 | "입력하신 이메일로 재설정 링크를 발송했습니다" |
| 이메일 재발송 버튼 | 쿨다운(60초) 후 재발송 허용 |
| 로그인 화면으로 돌아가기 링크 | SCR-100 이동 |

### 3단계 — 새 비밀번호 설정

이메일 링크 클릭 후 진입하는 단계로, URL에 포함된 토큰으로 인증한다.

| 요소 | 설명 |
|------|------|
| 새 비밀번호 입력란 | masked, 표시/숨김 토글, 비밀번호 강도 표시 |
| 새 비밀번호 확인 입력란 | 동일 값 여부 실시간 검증 |
| 비밀번호 규칙 안내 | 최소 8자, 영문+숫자+특수문자 조합 |
| 변경 완료 버튼 | 새 비밀번호 저장, 완료 후 SCR-100 이동 |

## 주요 이벤트 / 자동화

- **인증 링크 만료 타이머**: 발송된 재설정 링크는 30분 후 자동 만료되며, 만료 후 접근 시 안내 화면이 표시된다.
- **변경 완료 후 자동 이동**: 새 비밀번호 저장 완료 시 기존 세션을 모두 무효화하고 SCR-100 로그인 화면으로 자동 이동한다.
- **재발송 쿨다운**: 인증 메일 재발송은 60초 쿨다운 이후에만 허용되어 남용을 방지한다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 이메일 형식 오류 | "올바른 이메일 형식을 입력해주세요" 인라인 오류 |
| 존재하지 않는 이메일 | 보안상 "발송 완료" 메시지로 동일 표시 |
| 인증 링크 만료 | "재설정 링크가 만료되었습니다. 다시 요청해주세요" + 재발송 버튼 |
| 이미 사용된 링크 | "이미 사용된 링크입니다. 다시 요청해주세요" |
| 새 비밀번호 규칙 미충족 | 규칙별 인라인 오류 표시 |
| 비밀번호 확인 불일치 | "비밀번호가 일치하지 않습니다" 인라인 오류 |
| 최근 비밀번호 재사용 | "최근에 사용한 비밀번호는 사용할 수 없습니다" |
| API 서버 오류 | "일시적 오류가 발생했습니다. 잠시 후 다시 시도해주세요" |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MFN-SCR-106`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-106`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
