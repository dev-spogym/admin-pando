## 기능 목적

삭제 동작 직전에 사용자 의사를 한 번 더 확인하는 공통 보호 다이얼로그다. 삭제 이후 복구 불가 또는 연쇄 영향이 있는 작업에 대해, 실수 클릭으로 인한 데이터 손상을 방지한다.

## 주요 구성요소

- 삭제 경고 메시지
- 대상 항목명 표시
- 삭제 버튼
- 취소 버튼

## 비즈니스 규칙

- destructive action 전에는 반드시 선행 표시한다.
- 대상명이 있으면 다이얼로그 본문에 함께 노출한다.
- 도메인별 전용 삭제 다이얼로그가 없는 경우 공통 확인창으로 사용한다.

## 연계 산출물

- 연계 다이얼로그: `DLG-003 삭제확인`

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `DLG-003`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `연계 화면 없음 또는 본문 참조`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-003 삭제확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
