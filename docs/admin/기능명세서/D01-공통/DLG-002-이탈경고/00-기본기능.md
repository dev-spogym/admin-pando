## 기능 목적

등록/수정형 화면에서 저장하지 않은 변경사항이 있는 상태로 이탈하려 할 때, 데이터 유실을 막기 위해 표시하는 공통 경고 다이얼로그다. 사용자는 현재 화면에 머물지, 변경사항을 버리고 이동할지 명확히 선택해야 한다.

## 주요 구성요소

- 경고 메시지
- 나가기 버튼
- 계속 편집 버튼

## 비즈니스 규칙

- dirty 상태가 없으면 표시하지 않는다.
- 경고 확인 없이 라우트 이동을 허용하지 않는다.
- 공통 다이얼로그지만 최초 정합 기준 화면은 `SCR-105` 프로필 계정으로 둔다.

## 연계 산출물

- 연계 다이얼로그: `DLG-002 이탈경고`
- 대표 연계 화면: `SCR-105 프로필계정`
