## 기능 목적

존재하지 않는 페이지 접근(404), 권한 없는 화면 접근(403), 서버 오류(500), 서비스 점검(503) 등 비정상적인 접근이나 시스템 오류가 발생했을 때, 사용자가 상황을 이해하고 정상 화면으로 복귀할 수 있도록 안내하는 공통 오류 화면이다.

오류 유형에 따라 제목·설명 메시지·아이콘이 분기되며, 대시보드로 돌아가기 버튼과 이전 화면 복귀 링크를 제공하여 운영자의 업무 중단을 최소화한다. 특히 403 오류는 RBAC 기반 접근 제어의 최종 방어선으로, 권한 없는 URL 직접 접근 시 이 화면으로 리다이렉트된다.

## 주요 구성요소

### 오류 유형별 표시 내용

| 오류 코드 | 아이콘 | 제목 | 설명 메시지 | 복구 액션 |
|---------|--------|------|------------|-----------|
| 404 | 돋보기/물음표 | 페이지를 찾을 수 없습니다 | 주소를 다시 확인해주세요 | 대시보드로 이동 |
| 403 | 자물쇠 | 접근 권한이 없습니다 | 관리자에게 문의하세요 | 대시보드로 이동 |
| 500 | 경고 삼각형 | 일시적인 오류가 발생했습니다 | 잠시 후 다시 시도해주세요 | 대시보드로 이동 + 재시도 |
| 503 | 도구/공사 | 서비스 점검 중입니다 | 점검 완료 후 이용 가능합니다 | 점검 완료 후 안내 |

### 공통 액션 버튼

| 버튼 | 동작 |
|------|------|
| 대시보드로 돌아가기 | SCR-101 통합 대시보드로 이동 |
| 이전 화면으로 돌아가기 | 브라우저 히스토리 뒤로가기 |

> 에러 페이지 자체는 모든 역할에서 동일하게 표시되나, 오류 코드와 역할에 따라 메시지와 복구 버튼 동작이 분기된다.

## 주요 이벤트 / 자동화

- **자동 리다이렉트**: 라우터에서 매칭되지 않는 경로는 404 에러 페이지로 자동 이동한다.
- **RBAC 403 리다이렉트**: 권한 없는 경로에 직접 접근하면 403 에러 페이지로 리다이렉트되며, 사이드바에서는 해당 메뉴가 미노출된다.
- **오류 로그 자동 기록**: 500 오류 발생 시 오류 내용이 감사 로그에 자동으로 기록되어 운영팀이 추적할 수 있다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 로그인 세션 없는 상태의 403 | 로그인 화면으로 이동 유도 |
| 503 점검 종료 시각 미정 | "점검 완료 후 이용 가능합니다" 메시지만 표시 |
| 에러 페이지 자체 로드 실패 | 브라우저 기본 오류 화면으로 fallback |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `MFN-SCR-108`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-108`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
