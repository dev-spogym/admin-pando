## 기능 목적

현재 로그인한 관리자 본인의 개인 정보를 조회하고 수정하는 화면이다. 이름·연락처 같은 기본 정보 변경, 프로필 사진 업로드, 2단계 인증(2FA) 활성화/비활성화, 비밀번호 변경 연결, 로그아웃까지 계정과 관련된 개인 관리 기능을 한 곳에서 처리할 수 있다.

이메일은 계정 식별자이므로 수정이 불가하며, 역할(role)과 소속 지점은 관리자(슈퍼관리자·센터장)만 변경할 수 있어 일반 계정에서는 읽기 전용으로 표시된다. 수정 사항 저장 시 DLG-004(저장 확인) 다이얼로그를 통해 실수를 방지한다.

## 주요 구성요소

### 프로필 사진 영역

| 요소 | 동작 |
|------|------|
| 현재 프로필 사진 | 원형 표시, 없으면 이니셜 아바타 |
| 사진 변경 버튼 | 이미지 파일 선택 (jpg, png, gif, 최대 5MB) |
| 사진 삭제 버튼 | 기본 아바타로 초기화 |

### 기본 정보 필드

| 필드 | 편집 가능 여부 | 설명 |
|------|---------------|------|
| 이름 | 가능 (전체) | 한/영 모두 허용, 최대 20자 |
| 이메일 | 불가 (읽기 전용) | 계정 식별자, 변경 불가 |
| 연락처 | 가능 (전체) | 숫자 + 자동 하이픈 포맷 |
| 소속 지점명 | 불가 (일반 계정) | superAdmin만 변경 가능 |
| 역할/직책 | 불가 (일반 계정) | superAdmin·owner만 변경 가능 |

### 보안 설정

| 기능 | 동작 |
|------|------|
| 비밀번호 변경 버튼 | SCR-106 비밀번호 재설정 화면으로 이동 |
| 2FA 활성화 | 2단계 인증 설정 ON/OFF 토글, 활성화 시 QR코드 발급 프로세스 진행 |

### 액션 버튼

| 버튼 | 동작 |
|------|------|
| 저장 | DLG-004 저장 확인 → 변경 사항 저장 |
| 로그아웃 | SCR-109 로그아웃 처리 (DLG-001 확인 포함) |

## 주요 이벤트 / 자동화

- **프로필 사진 즉시 반영**: 사진 변경 저장 완료 시 상단 헤더의 프로필 아이콘이 즉시 갱신된다.
- **2FA 활성화 프로세스**: 2FA 토글 ON 시 OTP 앱과의 QR코드 연동 단계가 별도 모달로 진행되며, 확인 코드 입력으로 완료된다.
- **세션 갱신**: 이름 변경 저장 시 JWT 내 name claim이 갱신되어 상단 표시명이 즉시 바뀐다.

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 이름 빈값 제출 | "이름을 입력해주세요" 인라인 오류 |
| 연락처 형식 오류 | "올바른 연락처 형식을 입력해주세요" 인라인 오류 |
| 이미지 용량 초과 | "5MB 이하 이미지를 선택해주세요" 오류 안내 |
| 이미지 형식 불일치 | "jpg, png, gif 형식만 지원합니다" 오류 안내 |
| 2FA 확인 코드 불일치 | "인증 코드가 올바르지 않습니다" 인라인 오류 |
| 저장 API 실패 | "저장 중 오류가 발생했습니다. 다시 시도해주세요" 토스트 |
| 미저장 상태 이탈 | DLG-002 이탈 경고 다이얼로그 표시 |
