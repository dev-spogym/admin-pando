## 기능 목적

센터 운영에 필요한 기본 정보를 한 곳에서 관리하는 설정 허브 화면이다. 센터명·주소·연락처 등 기본정보, 알림 수신 방식, 화면 테마, 물품 재고를 4개 탭으로 구분하여 관리한다. 미저장 변경 사항을 감지해 탭 이동 시 손실을 방지한다.

## 주요 구성요소

### 기본정보 탭

| 항목 | 입력 |
|------|------|
| 센터 로고 | 이미지 업로드 |
| 센터명 | 텍스트 (필수) |
| 사업자등록번호 | 10자리 |
| 센터 소개 | textarea |
| 대표 연락처 | 010 자동 |
| 주소 | 검색 버튼 |
| 업종 | 11종 다중 선택 (헬스/필라/PT샵/골프/요가 등) |
| 평일 운영시간 | 오픈~마감 |
| 주말 운영시간 | 오픈~마감 |

### 알림설정 탭

| 채널 | 항목 |
|------|------|
| 앱 푸시 | 입장/만료/결제/수업 예약·취소 |
| 이메일 | 주간 리포트, 만료 예정 |
| SMS | 결제 완료, 만료 임박 |

### 테마설정 탭

| 항목 | 옵션 |
|------|------|
| 화면 모드 | 라이트 / 다크 / 시스템 |
| 메인 컬러 | 색상 선택 |
| 보조 컬러 | 색상 선택 |
| 글자 크기 | 작게 / 기본 / 크게 |

### 물품 관리 탭

| 항목 | 입력 |
|------|------|
| 수건 대·소 | 재고 수량 |
| 운동복 상·하의 | 재고 수량 |
| 1일 발급 한도 | 숫자 |
| 잔여 수량 | 자동 |

### 저장 버튼

변경 사항이 있을 때만 활성화. 미저장 + 탭 이동 시 DLG-080-001.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 탭 | 조회·수정 |
| owner (센터장) | 전체 탭 | 조회·수정 |
| manager | 알림설정 탭 | 조회만 |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "설정 > 센터 설정" 진입
2. 저장된 설정값을 각 탭에 표시
3. 정보 수정 → 저장 버튼 활성
4. [저장] → 완료 메시지 (3초)
5. 탭 이동 시 미저장 변경 → DLG-080-001
6. 주소 검색 → 팝업 → 자동 입력

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 저장값 표시, 저장 버튼 비활성 |
| 수정 중 | 저장 버튼 활성 + "저장되지 않은 변경사항" |
| 저장 중 | 버튼 비활성 |
| 저장 완료 | 메시지 (3초) |
| 탭 이동 경고 | DLG-080-001 |

## 비즈니스 규칙

1. 센터명은 필수이며 빈 값 저장 불가하다.
2. 사업자등록번호는 10자리 형식 검증 후 저장된다.
3. 미저장 변경 사항이 있을 때 탭 이동 시 DLG-080-001 경고가 표시된다.
4. 알림 토글 변경은 즉시 적용되지 않고 저장 후 반영된다.
5. 매니저는 알림설정 탭만 조회 가능하며 수정 불가하다.
6. 변경 이력은 감사 로그(SCR-097)에 기록된다.
