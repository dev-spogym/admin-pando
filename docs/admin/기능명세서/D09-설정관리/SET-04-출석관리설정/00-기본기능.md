## 기능 목적

회원의 출석을 인정하는 기준과 자동 처리 규칙을 설정하는 화면이다. 출석 인정 시간대, 지각 판단 기준, 자동 출석 처리 조건 등을 센터 운영 방침에 맞게 구성한다. IoT 출입 기록과 연동해 자동 출석 인정도 가능하다.

## 주요 구성요소

### 출석 인정 시간 설정

| 항목 | 입력 |
|------|------|
| 출석 인정 시작 | 수업 시작 N분 전부터 |
| 출석 인정 마감 | 수업 시작 N분 후까지 |
| 주말/공휴일 출석 | 토글 |

### 지각 기준 설정

| 항목 | 입력 |
|------|------|
| 지각 판단 시간 | 수업 시작 후 N분 |
| 지각 누적 알림 | N회 초과 시 |

### 자동 출석 규칙

| 항목 | 입력 |
|------|------|
| 자동 출석 처리 | 토글 (IoT 기반) |
| 자유 이용 출석 | 토글 |
| 동일 회원 중복 처리 | 첫 입장만 / 매 입장 |

### 출석 기록 보관

| 항목 | 입력 |
|------|------|
| 보관 기간 | 개월 단위 |

### 저장 / 미저장 경고

DLG-080-001.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 설정 | 조회·수정 |
| owner (센터장) | 소속 지점 설정 | 조회·수정 |
| manager | 전체 설정 | 조회만 |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "설정 > 출석 관리 설정" 진입
2. 저장된 설정값 표시
3. 항목 변경 → 저장 활성
4. 자동 출석 활성 시 IoT 연동 안내
5. [저장] → 즉시 반영
6. 미저장 + 이탈 → DLG-080-001

## 비즈니스 규칙

1. 출석 인정 시작은 수업 시작 N분 전부터 적용된다 (운영 정책).
2. 자동 출석은 IoT 출입 기록 기반이며 IoT(SCR-083) 미연결 시 안내된다.
3. 동일 회원 중복 처리 방식은 "첫 입장만" 또는 "매 입장마다" 선택 가능하다.
4. 출석 이력 보관 기간은 법정 최소(예: 1년) 이상이어야 한다.
5. 지각 누적 알림은 회원·관리자 양측에 발송된다.
6. 변경 이력은 감사 로그에 기록된다.
