## 기능 목적

센터 내 공지사항을 작성·수정·삭제하고 게시 대상과 게시 기간을 설정하는 화면이다. 전체 직원 공지, 특정 역할 대상 공지 등 수신 대상을 구분하여 필요한 정보를 원하는 시점에 전달한다. 중요 공지는 별도 표시되어 우선순위를 명확히 한다.

운영 맥락:
- **센터 리모델링·임시 휴관 공지**: 기간형 공지 + 상단 고정(중요) + 회원앱 노출 ON → 전 회원에게 즉시 인지
- **긴급 안전 공지**: 긴급 카테고리 선택 + 게시 즉시 푸시 발송 + 필독 처리 → 회원 확인 완료율 추적
- **이벤트 사전 예약 발행**: 이벤트 시작 D-7 예약 발행 설정 → 자동 게시 + 종료일 자동 비공개
- **외국인 회원 다국어 공지**: 자동 번역(SET-05 연계) ON → 한국어 원문 저장 + 영/일/중 번역본 자동 생성
- **직원 내부 공지 (회원 비노출)**: 게시 대상 "직원", 회원앱 노출 OFF → 매니저·트레이너 전용 공지
- **역할별 맞춤 공지**: PT 트레이너 대상 "수업 준비 사항", 스태프 대상 "결제 안내" 등 역할 지정 발송
- **만료 공지 자동 정리**: 종료일 경과 시 상태 자동 "종료" 전환 → 회원앱·키오스크에서 자동 숨김

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |

| primary / superAdmin | 전체 지점 공지 | 작성·수정·삭제 |
| owner (센터장) | 소속 지점 공지 | 작성·수정·삭제 |

## 주요 UX 흐름

**공지 등록**

3. 카테고리·제목·내용·대상·기간·중요·회원앱 입력
4. 저장 → 목록 추가

**공지 수정**
1. 행 [수정] → DLG-085-001 채워진 폼
2. 정보 변경 → 저장

**공지 삭제**
1. 행 [삭제] → DLG-085-002
2. 확인 → 삭제

### 분기·예외 흐름

- **게시 중 공지 대상 축소 시도**: "게시 중인 공지의 대상 범위는 축소할 수 없습니다" 인라인 안내, 대상 추가만 허용
- **상단 고정 공지 최대 개수 초과**: 상단 고정은 동시 최대 3개. 초과 시도 시 "이미 3개의 공지가 상단 고정되어 있습니다" 모달 + 기존 고정 해제 선택 유도
- **예약 발행 시각이 현재보다 과거**: 저장 시 "예약 발행 시각을 미래로 설정해주세요" 인라인 에러, 저장 차단
- **종료일이 시작일보다 앞선 경우**: "종료일은 시작일 이후여야 합니다" 인라인 에러, 저장 차단
- **게시 중 공지 즉시 삭제 시도**: "게시 중인 공지는 먼저 종료 처리 후 삭제 가능합니다" 안내, 또는 종료 처리 + 삭제 2단계 선택 제공
- **푸시 발송 대상 미설정**: 게시 대상이 "직원"인데 푸시 발송 ON → "직원 대상 공지는 앱 푸시가 지원되지 않습니다" 안내
- **첨부 파일 용량 초과**: 이미지 5MB / PDF 20MB 초과 시 "파일 크기를 초과했습니다" 인라인 에러
- **자동 번역 실패 (외부 API 오류)**: "번역 서비스 오류 — 한국어 원문으로 게시됩니다" 토스트, 원문 유지 게시
- **필독 처리 공지 확인율 조회**: 공지 상세 → "필독 완료 {인원수}명 / 전체 {전체인원수}명" 요약 카드 + 미확인 회원 목록 export
- **만료 자동 비공개 배치 실패**: 배치 재실행 알림 + 운영자 수동 종료 처리 안내
- **공지 동시 수정 충돌**: 최종 저장자 우선 반영, 이전 편집자에게 "변경 사항이 덮어씌워졌습니다" 알림

## 비즈니스 규칙

1. 게시 기간은 시작일 자동 활성, 종료일 자동 종료된다.
2. 중요(상단 고정) 표시된 공지는 회원앱·관리자 화면에서 상단 고정 표시된다. 동시 최대 3개.
3. 회원앱 노출 토글이 활성된 공지만 회원앱에 표시된다.
4. 매니저는 공지 작성·수정은 가능하나 삭제는 할 수 없다.
5. 공지 게시 대상은 게시 중에는 일부만 변경 가능하다 (대상 추가만 허용, 축소 제한).
6. 작성·수정·삭제 이력은 감사 로그에 기록된다.
7. **예약 발행**: 지정 날짜·시각에 자동으로 "게시 중" 상태 전환. 발행 전 취소 가능.
8. **푸시 발송**: 게시 즉시 또는 예약 발행 시각에 수신 대상에게 앱 푸시 발송. 직원 대상 공지는 앱 푸시 미지원.
9. **필독 처리**: 필독 ON 공지는 회원 앱에서 확인 전까지 팝업 표시. 관리자 화면에서 확인 완료율 집계.
10. **다국어 자동 번역**: SET-05 자동 번역 ON 시 공지 저장 즉시 외부 번역 API 호출. 실패 시 한국어 원문으로 fallback 게시.
11. **이미지 첨부**: 최대 5MB, JPG·PNG·GIF. PDF: 최대 20MB. 공지당 첨부 최대 5개.
12. **만료 자동 비공개**: 종료일 자정 배치로 상태 "종료" 전환 + 회원앱·키오스크에서 자동 숨김.
13. **삭제 후 복구 불가**: 삭제된 공지는 복구 불가. 감사 로그에는 제목·삭제자·삭제일만 보관.
14. **게시 중 즉시 삭제 제한**: 게시 중인 공지는 종료 처리 후 삭제 가능 (UX 보호 정책).
15. **superAdmin 전 지점 공지**: superAdmin은 "전체 지점" 선택 시 모든 지점 회원앱에 동일 공지 배포.
16. **역할별 노출**: 게시 대상 "특정 역할" 선택 시 해당 역할 계정 로그인 시에만 공지 표시.
17. **키오스크 노출 연계**: 회원앱 노출 ON + 키오스크 설정(SCR-082) 공지 노출 토글 ON 시 키오스크 화면에도 표시.
18. **공지 제목 최대 길이**: 100자. 내용: 리치 텍스트 최대 10,000자.
19. **감사 로그 기록 항목**: 공지 ID·제목·카테고리·게시 대상·게시 기간·작성자·변경 유형(등록/수정/삭제) 저장.
20. **게시 중 공지 수정 시 수정 이력 보관**: 수정 전 원문은 히스토리 테이블에 버전 관리 (최대 10버전).
21. **상단 고정 우선순위**: 같은 지점 내 복수 고정 공지는 최신 등록 순 우선 표시.
22. **필독 미확인 회원 알림**: 필독 공지 게시 후 24시간 경과 시 미확인 회원에게 재푸시 발송 (1회).

## 관련 화면 / 다이얼로그 / API

- **연계 화면**: SCR-085 / 회원앱 공지 화면 / 키오스크 공지 (SCR-082)
- **연계 다이얼로그**: DLG-085-001 공지등록수정 / DLG-085-002 공지삭제확인
- **API 기준**: `GET /api/notices` / `POST /api/notices` / `PUT /api/notices/:id` / `DELETE /api/notices/:id` / `GET /api/notices/:id` / `POST /api/notices/:id/upload` / `POST /api/notices/:id/push` / `GET /api/notices/:id/read-status`

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `SET-EXT-04`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-085`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-085-001 공지등록수정, DLG-085-002 공지삭제확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
