## 기능 목적

기본 제공 역할(최고관리자·센터장·매니저 등) 외에 센터 운영 특성에 맞는 맞춤형 역할을 생성·관리하는 화면이다. 역할 이름과 설명을 정의하고, 필요한 권한 조합을 직접 구성한다. 기본 역할로는 표현하기 어려운 운영 시나리오(예: 보조 매니저, 시간제 강사 등)를 반영할 수 있다.

## 주요 구성요소

### 커스텀 역할 목록

| 컬럼 | 설명 |
|------|------|
| 역할명 | 이름 |
| 설명 | 부가 |
| 배정 직원 수 | 카운트 |
| 생성일 | YYYY-MM-DD |
| 액션 | [수정] / [삭제] |

[+ 새 역할 만들기].

### 역할 생성 / 수정 폼

| 항목 | 입력 |
|------|------|
| 역할 이름 | 텍스트 (필수) |
| 역할 설명 | textarea |
| 권한 복사 베이스 | 기존 역할에서 복사 (선택) |
| 권한 매트릭스 | SCR-081과 동일 구조 |

### 역할 배정 현황

해당 역할 배정 직원 목록 미리보기.

### 역할 삭제 재배정 (DLG-087-001)

삭제 시 배정 직원이 있으면 다른 역할로 재배정.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 커스텀 역할 | 생성·수정·삭제 |
| owner (센터장) | 소속 지점 커스텀 역할 | 생성·수정·삭제 |
| manager | 접근 불가 | ❌ |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**새 역할 생성**
1. 사이드바 → "설정 > 커스텀 역할 생성" 진입
2. [+ 새 역할 만들기]
3. 이름·설명 입력
4. 복사 베이스 선택 (선택)
5. 권한 매트릭스 구성
6. 저장 → 목록 추가 + SCR-081에서 선택 가능

**역할 수정**
1. 행 [수정] → 채워진 폼
2. 권한 변경 → 저장

**역할 삭제**
1. 행 [삭제]
2. 배정 직원 있으면 DLG-087-001 재배정
3. 다른 역할 선택 → 일괄 재배정 → 삭제

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 역할 목록 |
| 역할 없음 | 안내 + 생성 CTA |
| 생성 폼 | 새 역할 작성 중 |
| 수정 폼 | 기존 역할 수정 중 |
| 저장 완료 | 메시지 + 목록 복귀 |

## 비즈니스 규칙

1. 커스텀 역할 이름은 기본 역할명과 중복 불가하다.
2. 권한 복사 베이스 선택 시 선택 역할의 권한이 매트릭스에 자동 로드된다.
3. 역할 삭제 시 배정 직원이 있으면 재배정 후 삭제 가능하다.
4. 커스텀 역할은 SCR-081 권한 설정에서 동일하게 편집된다 (해당 화면에서도 수정 가능).
5. 권한 변경 시 영향 분석이 표시된다.
6. 변경 이력은 감사 로그에 기록된다.
