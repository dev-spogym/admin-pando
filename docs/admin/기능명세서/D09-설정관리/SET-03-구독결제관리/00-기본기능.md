## 기능 목적

센터가 현재 이용 중인 Pando 서비스 구독 플랜과 결제 수단을 확인하고 관리하는 화면이다. 플랜 업그레이드·다운그레이드, 결제 수단 변경, 과거 청구 이력 조회를 처리한다. 비즈니스 운영의 핵심 인프라이므로 변경 시 명확한 안내가 필수다.

운영 맥락:
- **신규 센터 온보딩**: 무료 체험 기간 종료 전 플랜 선택 → 결제 수단 등록 → 자동 갱신 활성
- **성장 센터 업그레이드**: 회원 수 한도 초과 임박 시 상위 플랜 업그레이드 → 즉시 적용 + 잔여 기간 일할 차액 청구
- **비용 절감 다운그레이드**: 비수기 회원 감소 후 하위 플랜 다운그레이드 → 데이터 한도 초과 여부 사전 확인
- **결제 실패 grace period 관리**: 결제 수단 만료 등으로 자동 갱신 실패 → grace period(7일) 내 수단 교체 유도
- **구독 해지 후 재가입**: 해지 → 데이터 보관 기간(90일) 내 재가입 시 기존 데이터 복구 여부 확인
- **프랜차이즈 본사 다중 지점 관리**: 본사 superAdmin이 지점별 구독 상태 일괄 조회 + 플랜 일괄 변경 요청
- **부가세(VAT) 포함 청구 이력 확인**: 세금계산서 발행 요청·영수증 PDF 다운로드 for 경비 처리

### 플랜 변경 확인 (DLG-084-001)

변경 후 요금 차액 안내 + 적용 시점 + 다운그레이드 시 데이터 한도 초과 경고.

해지 시 만료 일시 + 데이터 보관 정책 안내 + grace period 경고.

## 주요 UX 흐름

**현황 조회**
1. 사이드바 → "설정 > 구독 결제 관리" 진입
2. 현재 구독 정보 + 청구 이력 자동 로드

**플랜 변경**
1. [플랜 변경] 또는 카드 [이 플랜으로 변경]
2. DLG-084-001 → 차액·적용 시점 확인
3. 확정 → 변경 처리

**결제 수단 변경**
1. [결제 수단 변경] → PG 연동 페이지
2. 새 카드 등록 → 자동 갱신

**구독 해지**
1. [구독 해지] → DLG-084-002
2. 만료 일시 + 데이터 보관 안내 확인
3. 확정 → 해지 처리

**영수증 다운로드**
1. 청구 이력 행 [PDF]
2. PDF 자동 다운로드

### 분기·예외 흐름

- **업그레이드 즉시 적용 + 일할 계산**: 당일 기준 잔여 일수 × 플랜 간 일일 단가 차액 → 즉시 추가 청구
- **다운그레이드 데이터 한도 초과**: 현재 회원 수·데이터 용량이 하위 플랜 한도 초과 시 DLG-084-001에서 경고 + "[지금 초과 데이터 정리하기]" 링크 노출, 미정리 시에도 다음 결제일 이후 자동 초과 삭제(정책 공지)
- **결제 실패 grace period**: 자동 갱신 실패 시 7일 grace period 부여, 7일 내 수단 교체 시 소급 처리, 7일 초과 시 서비스 일시 정지 + "일시 정지" 배너 노출
- **grace period 중 플랜 변경 시도**: 결제 수단 미등록 상태 → 플랜 변경 버튼 disabled + "결제 수단을 먼저 등록해주세요" 인라인 안내
- **결제 수단 삭제 시 등록된 수단이 1개뿐**: "구독 중에는 최소 1개의 결제 수단이 필요합니다" 모달, 삭제 차단
- **구독 해지 → 재가입 (90일 이내)**: 재가입 시 "이전 데이터를 복구하시겠습니까?" 프롬프트 → 복구 or 신규 시작 선택
- **구독 해지 → 재가입 (90일 초과)**: 데이터 이미 삭제됨 안내 + 신규 시작 강제
- **VAT 별도 플랜**: 표시 금액 + 부가세 10% 합산 표기. 사업자 등록 여부에 따라 세금계산서 자동 발행
- **청구 이력 영수증 생성 실패**: "PDF 생성에 실패했습니다. 잠시 후 다시 시도해주세요" 토스트 + 재시도 링크
- **미수 상태 7일 경과 후 서비스 정지**: 상단 전역 배너 "서비스가 일시 정지되었습니다 — 결제 수단을 확인해주세요" (설정 외 모든 화면에 노출)
- **PG 연동 페이지 팝업 차단**: "팝업 차단 해제 안내" 모달
- **플랜 변경 중 동시 접속 충돌**: 최종 저장자 우선 반영, 이전 사용자에게 "변경 사항이 이미 적용되었습니다" 알림

## 비즈니스 규칙

1. 플랜 업그레이드 시 즉시 적용되며 잔여 기간 차액이 일할 계산된다.
2. 플랜 다운그레이드 시 다음 결제일부터 적용된다.
3. 구독 해지 시 만료일까지 서비스 이용 가능하며 만료 후 데이터는 90일 보관 후 자동 삭제된다.
4. 결제 수단 변경은 PG사 연동 페이지에서 처리되며 보안 정책을 따른다.
5. 청구 이력은 영구 보관되며 영수증은 PDF로 발급된다.
6. 매니저 이하는 구독 정보에 접근할 수 없다 (재무 정보 보호).
7. 변경 이력은 감사 로그에 기록된다.
8. **자동 갱신**: 매 결제 예정일 00:00 KST에 등록된 결제 수단으로 자동 청구된다.
9. **결제 실패 grace period**: 결제 실패 시 7일 유예 기간 부여. 7일 이내 수단 교체 시 소급 갱신, 초과 시 서비스 일시 정지.
10. **미수 처리**: grace period 초과 후 서비스 정지 상태로 전환. 미수금 납부 확인 후 서비스 즉시 복구.
11. **VAT**: 청구 금액은 공급가 + 부가세 10% 합산 표기. 사업자 등록 고객은 세금계산서 자동 발행.
12. **환급·일할 계산**: 업그레이드 시 일할 차액 즉시 청구. 다운그레이드 시 선납 차액 환급 없음(다음 결제일 이후 낮은 금액으로 갱신).
13. **다운그레이드 데이터 한도 초과**: 다운그레이드 확정 전 현재 회원 수·데이터 용량 vs 하위 플랜 한도 비교, 초과 시 경고 노출.
14. **결제 수단 최소 1개 보장**: 구독 중 결제 수단이 1개뿐인 경우 삭제 차단.
15. **재가입 데이터 복구 기간**: 해지 후 90일 이내 재가입 시 기존 데이터 복구 선택 가능. 90일 초과 시 신규 시작.
16. **플랜별 회원 수 한도**: 플랜 카드에 회원 수 한도 명시. 현재 회원 수가 하위 플랜 한도 초과 시 해당 플랜 선택 불가 또는 경고.
17. **청구 이력 기간 보관**: 청구 이력(invoice)은 법적 보관 의무(5년) 준수, 영구 삭제 불가.
18. **다중 지점 구독**: superAdmin은 지점별 구독 상태를 조회 가능. 개별 지점 과금은 지점 단위로 독립 청구.
19. **플랜 변경 이력**: DLG-084-001 확정 시 `subscription_change_log` 테이블에 이전 플랜·신규 플랜·변경일·실행자 저장.
20. **PG 결제 토큰 보안**: 카드 정보는 PG사 측에 토큰으로만 저장. Pando 서버에는 카드 마지막 4자리·카드사만 보관.
21. **구독 해지 쿨다운**: 해지 후 동일 결제 수단으로 당일 재가입 시 PG 이중 청구 방지 로직 적용.
22. **플랜 없음 상태**: 체험 기간 미설정 또는 해지 완료 후 → 설정 화면 외 일부 기능 접근 차단 + 플랜 선택 안내 오버레이.

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| 자동 갱신 배치 | 매 결제 예정일 00:00 KST | 등록된 PG 토큰으로 자동 청구, 성공 시 이력 INSERT |
| 결제 실패 알림 | 자동 갱신 실패 이벤트 | 센터장에게 이메일·SMS·앱 푸시 발송 (grace period D-day 포함) |
| grace period 만료 배치 | 결제 실패 후 7일 경과 | 서비스 상태 → "일시 정지" 전환, 전역 배너 활성 |
| 미수 복구 이벤트 | 결제 수단 교체 + 재결제 성공 | 서비스 상태 → "정상" 복구, 배너 해제 |
| 데이터 삭제 배치 | 구독 해지 후 90일 경과 | 센터 데이터 영구 삭제 (삭제 7일 전 경고 메일) |
| 세금계산서 자동 발행 | 결제 성공 이벤트 (사업자 등록 고객) | 국세청 전자 세금계산서 API 전송 |
| 플랜 한도 임박 알림 | 회원 수 플랜 한도 90% 도달 | 센터장에게 업그레이드 권유 알림 |
| SCR-097 감사 로그 | 플랜 변경·해지·결제 수단 변경 | actor·before·after·timestamp INSERT |
| 체험 종료 알림 배치 | 무료 체험 만료 D-7, D-3, D-1 | 플랜 선택 유도 이메일 + 앱 알림 |
| 다운그레이드 데이터 초과 정리 배치 | 다운그레이드 적용일 자정 | 한도 초과 데이터(비활성 회원 우선) 자동 아카이빙 + 운영자 리포트 |

## 관련 화면 / 다이얼로그 / API

- **연계 다이얼로그**: DLG-084-001 플랜변경확인 / DLG-084-002 구독해지확인

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `SET-03`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-084`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-084-001 플랜변경확인, DLG-084-002 구독해지확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
