## 기능 목적

지점이 본사에서 등록한 정책 세트를 선택해 자동화 알림을 적용하는 화면이다. 지점은 새 정책 세트를 만들지 않고 본사 표준 정책을 따르되, 본사가 허용한 범위 안에서 스텝 on/off를 조정한다. 단순 토글 목록이 아니라 현재 적용 중인 정책 요약을 먼저 보여주어 운영자가 즉시 상황을 파악할 수 있도록 한다.

운영 맥락:
- **신규 지점 오픈 온보딩**: 본사에서 표준 정책 세트 선택 → 지점 담당자가 스텝 ON/OFF 조정 → 테스트 발송 후 즉시 적용
- **프랜차이즈 전국 통일 정책 배포**: superAdmin이 모든 지점에 동일 정책 세트 강제 적용 → 지점은 허용된 스텝만 조정
- **계절별 정책 전환**: 성수기·비수기마다 본사 정책 세트 전환 → 지점은 다음 결제일 전후 알림 스텝 조정
- **정책 충돌 시 우선순위 결정**: 본사 필수 스텝과 지점 조정 스텝이 충돌 시 본사 필수 스텝 우선 + 충돌 경고
- **시뮬레이션으로 사전 검증**: 정책 적용 전 "시뮬레이션" 모드로 발송 대상 회원 수·발송 예상 시각 미리 확인
- **정책 적용 후 롤백**: 잘못된 정책 적용 시 이전 정책으로 즉시 롤백 (24시간 이내)
- **감사 목적 정책 이력 조회**: 정책 변경 이력(언제·누가·어느 세트로 변경)을 감사 로그에서 추적

## 주요 구성요소

### 정책 요약 카드 (PolicySummaryCards)

현재 적용 중인 정책 세트를 상품군별로 요약 표시.

### 상품군 탭 (ScopeTabs)

이용권 / PT / GX / 락커 등 상품군별 분리.

### 정책 선택 (PolicySelector)

본사 등록 정책 세트 드롭다운.

### 스텝 테이블 (StepTable)

상품군 × 스텝 × 채널 3단 구조.

| 컬럼 | 설명 |
|------|------|
| 스텝 | D-7 / D-3 / D-1 / D-Day / D+1 |
| 채널 | SMS / 카톡 / 푸시 |
| 활성 | 토글 (허용된 스텝만) |
| 발송 시각 | 본사 정책 또는 지점 조정 |
| 메시지 미리보기 | 본사 템플릿 |
| 테스트 발송 | [발송] |

### 시뮬레이션 패널

정책 적용 전 발송 대상 회원 수·발송 예상 시각 미리보기.

### 롤백 버튼

마지막 정책 변경 후 24시간 이내 이전 정책으로 즉시 복구.

### 액션 푸터 (ActionFooter)

[시뮬레이션] / [적용 저장] / [취소] 버튼.

### 정책 적용 확인 (DLG-080A-001)

저장 시 영향 범위(대상 회원 수·스텝 수·채널) 확인.

## 주요 UX 흐름

1. 사이드바 → "설정 > 지점 자동화 적용" 진입
2. 정책 요약 카드로 현재 적용 정책 즉시 파악
3. 상품군 탭 선택 → 정책 세트 드롭다운
4. 스텝 테이블에서 허용된 스텝만 토글 조정
5. [테스트 발송]으로 메시지 미리보기
6. [시뮬레이션]으로 발송 대상 사전 확인
7. [적용 저장] → DLG-080A-001 → 즉시 반영

### 분기·예외 흐름

- **본사 필수 스텝 OFF 시도**: 해당 토글 disabled + 자물쇠 아이콘 표시, 호버 시 "본사 필수 스텝으로 변경 불가" 툴팁
- **정책 세트 0개 (본사 미등록)**: 드롭다운 비활성 + "본사에서 등록된 정책 세트가 없습니다. 본사 관리자에게 문의해주세요" 안내
- **정책 충돌 감지**: 지점 조정 스텝과 본사 필수 스텝 충돌 시 충돌 행에 빨간 경고 배지 + DLG-080A-001 저장 전 충돌 목록 표시
- **테스트 발송 실패 (채널 오류)**: "테스트 발송에 실패했습니다. 채널 설정을 확인해주세요" 토스트 + 채널 설정 링크
- **시뮬레이션 결과 0명**: "발송 대상 회원이 없습니다. 정책 조건을 확인해주세요" 안내
- **적용 저장 중 네트워크 오류**: "저장에 실패했습니다. 재시도해주세요" 토스트, 저장 전 상태 유지
- **롤백 24시간 초과**: 롤백 버튼 비활성 + "롤백 가능 시간(24시간)이 초과되었습니다" 툴팁
- **superAdmin 전체 지점 강제 배포 후 개별 지점 조정**: 강제 배포 후 허용된 스텝 범위 내에서 개별 지점 재조정 가능. 강제 배포로 초기화된 항목은 배포 기록에 표시
- **동시 설정 변경 충돌 (두 관리자 동시 접근)**: 최종 저장자 우선 반영, 이전 사용자에게 "설정이 변경되었습니다. 새로고침 후 재시도" 알림
- **정책 세트 본사 업데이트 시 지점 적용 정책과 불일치**: "적용 중인 정책 세트가 업데이트되었습니다. 재검토 후 다시 적용해주세요" 배너 노출

## 비즈니스 규칙

1. 지점은 새 정책 세트를 만들지 않으며 본사 등록 세트만 선택 적용한다.
2. 지점은 본사가 허용한 스텝만 끌 수 있으며 본사 필수 스텝은 잠금된다.
3. 지점은 정책 템플릿 본문을 수정하지 않으며 채널·발송 시각만 조정 가능하다.
4. 정책 요약은 토글 목록보다 먼저 표시되어 운영자가 현재 상태를 즉시 파악할 수 있어야 한다.
5. 스텝·채널·발송 시각의 3단 구조가 명확히 읽혀야 한다.
6. 적용 저장은 즉시 반영되며 자동 알림(MKT-02)에 반영된다.
7. 변경 이력은 감사 로그에 기록된다.
8. **필수 스텝 잠금**: 본사가 "필수" 지정한 스텝은 지점에서 OFF 불가. 토글 disabled + 자물쇠 아이콘.
9. **정책 충돌 처리**: 지점 조정값과 본사 필수값 충돌 시 본사 필수값 우선. 저장 전 충돌 목록 명시.
10. **시뮬레이션 모드**: 적용 전 발송 대상 회원 수·채널별 발송 건수·예상 발송 시각 미리보기. 실제 발송 없음.
11. **테스트 발송**: 운영자 본인 계정(등록 전화번호·카톡·이메일)으로만 발송. 실제 회원 발송 아님.
12. **롤백 정책**: 정책 적용 후 24시간 이내에만 이전 정책으로 즉시 롤백 가능. 24시간 초과 시 신규 변경으로 재적용해야 함.
13. **superAdmin 강제 배포**: superAdmin은 모든 지점에 동일 정책 세트 강제 배포 가능. 배포 후 기존 지점별 커스텀 스텝 초기화, 허용 범위 내 재조정 가능.
14. **정책 세트 본사 업데이트**: 본사가 적용 중인 정책 세트 내용 업데이트 시 지점 화면에 "정책 세트 업데이트됨" 배너 노출, 재확인 및 재적용 유도.
15. **발송 채널 비용**: SMS·카톡 채널은 발송 건당 비용 발생. 시뮬레이션 화면에 예상 발송 건수·비용 안내.
16. **적용 즉시 반영 범위**: 저장 즉시 이후 발생하는 만료·결제 이벤트부터 적용. 이미 큐에 들어간 발송 건은 이전 정책 유지.
17. **감사 로그 기록 항목**: 지점 ID, 변경 전 정책 세트 ID, 변경 후 정책 세트 ID, 스텝 ON/OFF 변경 내역, actor, timestamp.
18. **정책 세트 없음 처리**: 본사 등록 정책 세트가 0개일 때 지점은 정책 선택 불가. 자동화 알림 미발송 상태 유지.
19. **동시 접근 제어**: 동일 지점 설정을 두 관리자가 동시 수정 시 최종 저장자 우선, 선행 편집자에게 경고.
20. **채널 발송 실패 재시도**: 발송 실패 시 30분 간격 최대 3회 재시도. 3회 모두 실패 시 운영자에게 발송 실패 알림.

| 정책 충돌 감지 | 충돌 행 빨간 배지 + DLG-080A-001 충돌 목록 | 본사 필수값으로 강제 해결 |

| 정책 세트 본사 업데이트됨 | "정책 세트 업데이트됨" 배너 | 재확인·재적용 유도 |

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| MKT-02 자동 알림 | 정책 저장 이벤트 | 이후 만료·결제 이벤트 발생 시 새 정책 스텝·채널 기준으로 알림 발송 |
| 발송 큐 (SMS/카톡/푸시) | 스텝 조건 충족 이벤트 (만료 D-7 등) | 활성 채널로 발송 큐 생성, 실패 시 30분 간격 최대 3회 재시도 |

| SCR-097 감사 로그 | 정책 변경·롤백 이벤트 | 지점 ID·전후 정책 세트 ID·스텝 변경 내역·actor·timestamp INSERT |
| superAdmin 강제 배포 이벤트 | superAdmin 배포 저장 | 모든 대상 지점 정책 일괄 덮어쓰기, 각 지점 화면에 갱신 알림 |
| 롤백 만료 배치 | 정책 적용 후 24시간 경과 | 롤백 버튼 비활성, 롤백 가능 상태 종료 기록 |
| 본사 정책 세트 업데이트 이벤트 | 본사 정책 세트 수정 저장 | 해당 세트 적용 중인 지점 화면에 "업데이트됨" 배너 발생 |
| 시뮬레이션 API 호출 | [시뮬레이션] 버튼 클릭 | 현재 스텝 조건 기준 발송 대상 회원 쿼리·채널별 건수 계산·예상 시각 산출 (실발송 없음) |
| 발송 비용 예측 | 시뮬레이션 실행 | SMS·카톡 단가 기준 예상 비용 계산 |
| 정책 적용 알림 (지점 담당자) | superAdmin 강제 배포 이벤트 | 해당 지점 센터장·매니저에게 "본사 정책이 적용되었습니다" 앱 알림 |
