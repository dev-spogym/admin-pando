## 기능 목적

지점이 본사에서 등록한 정책 세트를 선택해 자동화 알림을 적용하는 화면이다. 지점은 새 정책 세트를 만들지 않고 본사 표준 정책을 따르되, 본사가 허용한 범위 안에서 스텝 on/off를 조정한다. 단순 토글 목록이 아니라 현재 적용 중인 정책 요약을 먼저 보여주어 운영자가 즉시 상황을 파악할 수 있도록 한다.

## 주요 구성요소

### 정책 요약 카드 (PolicySummaryCards)

현재 적용 중인 정책 세트를 상품군별로 요약 표시.

### 상품군 탭 (ScopeTabs)

이용권 / PT / GX / 락커 등 상품군별 분리.

### 정책 선택 (PolicySelector)

본사 등록 정책 세트 드롭다운.

### 스텝 테이블 (StepTable)

상품군 × 스텝 × 채널 3단 구조.

| 컬럼 | 설명 |
|------|------|
| 스텝 | D-7 / D-3 / D-1 / D-Day / D+1 |
| 채널 | SMS / 카톡 / 푸시 |
| 활성 | 토글 (허용된 스텝만) |
| 발송 시각 | 본사 정책 또는 지점 조정 |
| 메시지 미리보기 | 본사 템플릿 |
| 테스트 발송 | [발송] |

### 액션 푸터 (ActionFooter)

[적용 저장] / [취소] 버튼.

### 정책 적용 확인 (DLG-080A-001)

저장 시 영향 범위 확인.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 + 본사 정책 | 정책 세트 등록·지점 적용 |
| owner (센터장) | 본사 정책 + 지점 적용 | 정책 선택·스텝 토글·테스트 |
| manager | 본사 정책 + 지점 적용 | 정책 선택·스텝 토글·테스트 |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "설정 > 지점 자동화 적용" 진입
2. 정책 요약 카드로 현재 적용 정책 즉시 파악
3. 상품군 탭 선택 → 정책 세트 드롭다운
4. 스텝 테이블에서 허용된 스텝만 토글 조정
5. [테스트 발송]으로 메시지 미리보기
6. [적용 저장] → DLG-080A-001 → 즉시 반영

## 비즈니스 규칙

1. 지점은 새 정책 세트를 만들지 않으며 본사 등록 세트만 선택 적용한다.
2. 지점은 본사가 허용한 스텝만 끌 수 있으며 본사 필수 스텝은 잠금된다.
3. 지점은 정책 템플릿 본문을 수정하지 않으며 채널·발송 시각만 조정 가능하다.
4. 정책 요약은 토글 목록보다 먼저 표시되어 운영자가 현재 상태를 즉시 파악할 수 있어야 한다.
5. 스텝·채널·발송 시각의 3단 구조가 명확히 읽혀야 한다.
6. 적용 저장은 즉시 반영되며 자동 알림(MKT-02)에 반영된다.
7. 변경 이력은 감사 로그에 기록된다.
