## 기능 목적

관리자웹의 권한 템플릿(역할)별로 메뉴 접근·기능 사용 권한을 9개 메뉴 그룹 × 5종 권한(접근/조회/생성/수정/삭제) 매트릭스로 한눈에 조정하는 화면(SCR-081)이다. 직원관리에서 등록하는 직무(트레이너·골프강사·프런트)와는 별도로, 기본 제공 7종 권한 템플릿(superAdmin/primary/owner/manager/fc/staff/readonly)과 SCR-087에서 만든 커스텀 역할의 권한을 직접 편집한다. 각 재직 직원은 로그인 계정과 1:1로 연결되며, 그 로그인 계정은 반드시 정확히 하나의 권한 템플릿에 연결된다. 6종 민감 기능(회원 영구 삭제·환불 처리·급여 확정·슈퍼관리자 권한 부여/회수·데이터 복원·감사로그 내보내기)은 별도로 표기되며 superAdmin/primary 외 역할에 부여 시 경고된다.

운영 맥락:
- **신규 매니저 영입 시 권한 점검**: 신규 매니저가 회원 영구 삭제·환불 권한이 활성인지 확인 후 회수 → 사고 사전 차단
- **직원 사고 발생 후 권한 즉시 잠금**: 특정 역할의 위험 메뉴 일괄 거부 → 사후 영향 분석으로 담당 회원 인계 처리
- **본사 정책 변경에 따른 일괄 권한 조정**: 환불 권한을 owner로 한정 → DLG-081-006 영향 분석에서 매니저 12명 영향 확인 후 진행
- **커스텀 역할 권한 수정**: SCR-087에서 만든 "보조 매니저" 역할의 매출 메뉴 권한 회수 → 즉시 반영
- **신규 메뉴 출시에 따른 일괄 부여**: 신규 메뉴 그룹 추가 시 [전체 허용]로 owner·manager에 한꺼번에 권한 부여
- **권한 충돌 정리**: "삭제 있는데 수정 없음" 같은 모순 자동 감지 → DLG-081-002에서 정리 후 저장
- **권한 초기화 (DLG-081-001)**: 잘못 변경한 역할을 마지막 저장 상태로 복원
- **역할 삭제 시 직원 재배정**: DLG-081-006으로 영향 12명 확인 → DLG-081-004에서 다른 역할로 일괄 재배정 후 삭제

권한 변경은 운영 안전이 핵심이므로 DLG-081-006 영향 분석을 저장 직전에 강제 노출, 충돌 감지 시 DLG-081-002로 추가 확인, 6종 민감 기능은 변경 시 별도 강조한다. 모든 변경은 SCR-097 감사 로그에 actor·역할·변경 전후 스냅샷이 INSERT 되며, 배정된 직원의 활성 세션에는 다음 refresh 또는 강제 만료 시점부터 변경된 권한이 반영된다.

## 주요 구성요소

### 권한 템플릿/역할 목록 패널 (좌측)

| 기본 템플릿 | 설명 |
|------|------|
| superAdmin | 슈퍼관리자 (모든 권한 고정) |
| primary | 본사 최고관리자 |
| owner | 센터장 |
| manager | 매니저 |
| fc | FC |
| staff | 스태프 |
| readonly | 조회전용 |

> `트레이너`, `골프강사`, `프런트`는 직원 직무값으로 분리 관리. 커스텀 역할은 SCR-087에서 생성 후 본 화면 좌측 패널에 함께 표시.

각 카드: 배정 직원 수 · 연결된 로그인 계정 수 · [+ 새 역할] / [복사] / [삭제] 액션.

### 권한 매트릭스 패널 (우측)

선택 역할의 9개 메뉴 그룹별 권한 표시.

| 메뉴 그룹 | 권한 항목 |
|----------|---------|
| 회원 / 수업 / 매출 / 상품 / 직원 / 급여 / 시설 / 메시지 / 설정 (9그룹) | 접근 / 조회 / 생성 / 수정 / 삭제 (5종) |

[전체 허용] / [전체 거부] 버튼 + 권한 충돌 감지 경고 영역.

### 상단 액션

- [초기화] (DLG-081-001 마지막 저장 상태로)
- [변경 사항 저장] (변경 시 활성)

## 주요 UX 흐름

### 권한 수정 흐름
1. 사이드바 → "설정 > 권한 설정" 진입 → 좌측 첫 번째 템플릿(`superAdmin`) 자동 선택, 매트릭스 잠금 표시
2. 좌측 카드에서 편집 대상 역할 선택 → 우측 매트릭스 표시
3. 메뉴 그룹별 5종 권한 체크박스 변경 → 충돌 실시간 감지(예: 삭제 활성인데 수정 비활성)
4. 6종 민감 기능 체크 시 경고 색·아이콘 강조 (superAdmin/primary 외)
5. [변경 사항 저장] 클릭 → 배정 직원 1명 이상이면 DLG-081-006 영향 분석 (영향 직원·담당 회원 수, before/after 차이)
6. [그대로 진행] → 충돌 있으면 DLG-081-002 추가 표시 (충돌 무시 저장 / 취소 후 수정)
7. 최종 저장 → 즉시 반영 + 메시지(3초) + 감사 로그 INSERT

### 역할 생성 흐름
1. 좌측 [+ 새 역할] → DLG-081-003
2. 이름 입력 + 복사 베이스 선택(선택)
3. 매트릭스 편집 → 저장 → 좌측 목록 추가

### 역할 삭제 흐름
1. 카드 [삭제] → DLG-081-006 영향 분석
2. 영향 직원 ≥ 1명이면 재배정 역할 선택 강제
3. DLG-081-004 → 재배정 + 삭제 → 좌측 목록에서 제거

### 분기·예외 흐름
- **superAdmin 선택**: 매트릭스 전체 체크박스 비활성·읽기 전용·저장 버튼 hidden
- **권한 충돌 감지(삭제↔수정·생성↔접근)**: 인라인 경고 + 저장 시 DLG-081-002, [그대로 저장] / [돌아가서 수정]
- **민감 기능 체크 (superAdmin/primary 외)**: 인라인 강조 + 저장 시 별도 강조 카드 노출
- **배정 직원 0명 역할 변경**: DLG-081-006에서 "영향 없음" 안내 + [그대로 진행] 빠른 통과
- **역할 삭제 시 배정 직원 ≥ 1명**: 재배정 역할 선택 필수, 미선택 시 [삭제] 비활성
- **역할 삭제 시 담당 회원 ≥ 1명**: DLG-081-006에서 "담당 회원 합계 N명 재배정 필요" 표시
- **저장 중 다른 사용자가 같은 역할 동시 편집**: 충돌 감지 시 "다른 사용자가 변경 중" → 새로고침 권유
- **권한 변경 후 [초기화]**: DLG-081-001 → 마지막 저장 상태로 복원, 미저장 변경 폐기
- **수정 중 페이지 이탈**: 미저장 변경 경고(DLG-080-001 패턴)
- **owner가 다른 지점 역할 편집 시도**: 카드 자체 hidden (RLS branchId 필터)

## 비즈니스 규칙

1. `superAdmin` 권한 템플릿은 모든 권한이 고정·수정 불가하다.
2. 트레이너·골프강사·프런트는 직원 직무값이며 권한 템플릿 패널에 노출되지 않는다.
3. 6종 민감 기능(회원 영구 삭제·환불 처리·급여 확정·슈퍼관리자 권한 부여/회수·데이터 복원·감사로그 내보내기)은 superAdmin/primary 외 역할에 부여 시 인라인 경고 + 저장 시 별도 강조된다.
4. 권한 변경 시 배정 직원 ≥ 1명이면 DLG-081-006 영향 분석이 저장 전에 강제 표시된다.
5. 역할 삭제 시 배정 직원 ≥ 1명이면 재배정 역할 선택 후에만 삭제 가능하다.
6. 권한 충돌(예: 삭제 활성·수정 비활성)이 있으면 DLG-081-002 충돌 경고가 표시되며 [그대로 저장] / [수정] 선택 가능하다.
7. 메뉴 그룹은 9종(회원·수업·매출·상품·직원·급여·시설·메시지·설정)이며 각 5종 권한(접근·조회·생성·수정·삭제)으로 구성된다.
8. [전체 허용] / [전체 거부]는 매트릭스 전체에 적용되며 superAdmin은 적용 차단된다.
9. 데이터 스코프는 RLS branchId 기반이며 owner는 소속 지점 역할만 편집 가능하다.
10. **superAdmin / primary 권한 부여**: superAdmin 부여는 superAdmin만 가능, primary 부여는 superAdmin/primary만 가능.
11. **역할 변경 즉시 반영**: 저장 시 해당 역할 배정 직원의 활성 세션에 다음 페이지 로드부터 신규 권한이 적용된다.
12. **권한 변경 이력**: SCR-097 감사 로그에 actor·역할 ID·변경 전/후 스냅샷·timestamp가 INSERT 된다.
12-1. **직원-권한 연결 규칙**: 활성 직원의 로그인 계정은 반드시 하나의 권한 템플릿을 가져야 하며, `권한 없음` 상태로 저장할 수 없다.
13. **충돌 정의**: 삭제 활성·수정 비활성 / 생성 활성·접근 비활성 / 수정 활성·조회 비활성 등 6종 패턴.
14. **초기화 (DLG-081-001)**: 마지막 저장 상태로 복원, 진행 중 미저장 변경은 폐기.
15. **역할 복사**: DLG-081-005에서 새 이름 입력 + 권한 그대로 복사, 배정 직원은 복사되지 않음.
16. **owner 역할 자체 편집**: owner가 자신의 역할 권한을 회수하면 본인 권한 즉시 박탈되므로 경고 + 확인 필수.
17. **본사·지점 권한 분리**: superAdmin/primary는 전 지점 역할 편집, owner는 소속 지점 역할만 편집.
18. **민감 기능 조합 차단 옵션**: 테넌트 정책으로 manager 이하에 민감 기능 부여 자체를 차단 가능 (체크박스 비활성).
19. **변경 사항 미저장 + 페이지 이탈**: 브라우저 leave 이벤트로 경고 + 이동 차단.
20. **동시 편집 lock**: 같은 역할을 다른 운영자가 편집 중이면 30초 lock + 사용자명 표시.
21. **DLG-081-006 영향 분석 정보**: 배정 직원 수·담당 회원 합계·영향 직원 목록(5명 미리보기 + 더보기)·before/after 권한 차이.
22. **권한 변경에 의한 직원 KPI/실적 영향**: 별도 영향 없음 (실적 데이터는 권한과 무관, 권한은 화면 접근 제어).
23. **역할 삭제 시 계정 보호**: 배정 직원이 1명이라도 있으면 재배정 없는 역할 삭제는 불가하다.
