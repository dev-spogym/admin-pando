## 기능 목적

센터가 현재 이용 중인 Pando 서비스 구독 플랜과 결제 수단을 확인하고 관리하는 화면이다. 플랜 업그레이드·다운그레이드, 결제 수단 변경, 과거 청구 이력 조회를 처리한다. 비즈니스 운영의 핵심 인프라이므로 변경 시 명확한 안내가 필수다.

## 주요 구성요소

### 현재 구독 정보

| 항목 | 표시 |
|------|------|
| 현재 플랜명 | 이름 |
| 주요 혜택 요약 | 5~10개 |
| 다음 결제 예정일 | YYYY-MM-DD |
| 다음 결제 금액 | 천 단위 |
| 액션 | [플랜 변경] / [구독 해지] |

### 플랜 비교 섹션

이용 가능한 전체 플랜 카드 형태.

| 항목 | 표시 |
|------|------|
| 플랜 카드 | 포함 기능 / 월 요금 / 회원 수 한도 |
| 현재 플랜 강조 | 배지 |
| 타 플랜 선택 | [이 플랜으로 변경] |

### 결제 수단 관리

| 항목 | 표시 |
|------|------|
| 카드사 | 등록 카드 |
| 카드번호 마지막 4자리 | **** **** **** 1234 |
| 유효기간 | MM/YY |
| 액션 | [결제 수단 변경] / [삭제] |

### 청구 이력

| 컬럼 | 설명 |
|------|------|
| 날짜 | YYYY-MM-DD |
| 플랜명 | 이름 |
| 금액 | 천 단위 |
| 상태 | 결제 완료 / 실패 / 환불 |
| 영수증 | [PDF 다운로드] |

기간 필터: 최근 3개월 / 6개월 / 1년.

### 플랜 변경 확인 (DLG-084-001)

변경 후 요금 차액 안내.

### 구독 해지 확인 (DLG-084-002)

해지 시 만료 일시 + 데이터 보관 정책 안내.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 구독 정보 | 조회·관리·해지 |
| owner (센터장) | 소속 지점 구독 | 조회·관리·해지 |
| manager | 접근 불가 | ❌ |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**현황 조회**
1. 사이드바 → "설정 > 구독 결제 관리" 진입
2. 현재 구독 정보 + 청구 이력 자동 로드

**플랜 변경**
1. [플랜 변경] 또는 카드 [이 플랜으로 변경]
2. DLG-084-001 → 차액·적용 시점 확인
3. 확정 → 변경 처리

**결제 수단 변경**
1. [결제 수단 변경] → PG 연동 페이지
2. 새 카드 등록 → 자동 갱신

**구독 해지**
1. [구독 해지] → DLG-084-002
2. 만료 일시 + 데이터 보관 안내 확인
3. 확정 → 해지 처리

**영수증 다운로드**
1. 청구 이력 행 [PDF]
2. PDF 자동 다운로드

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 구독 정보 + 이력 |
| 로딩 | 스켈레톤 |
| 플랜 없음 | 플랜 선택 안내 |
| 결제 수단 없음 | 등록 안내 |
| 해지 완료 | 해지 메시지 + 만료일 |

## 비즈니스 규칙

1. 플랜 업그레이드 시 즉시 적용되며 잔여 기간 차액이 일할 계산된다.
2. 플랜 다운그레이드 시 다음 결제일부터 적용된다.
3. 구독 해지 시 만료일까지 서비스 이용 가능하며 만료 후 데이터는 N개월 보관된다.
4. 결제 수단 변경은 PG사 연동 페이지에서 처리되며 보안 정책을 따른다.
5. 청구 이력은 영구 보관되며 영수증은 PDF로 발급된다.
6. 매니저 이하는 구독 정보에 접근할 수 없다 (재무 정보 보호).
7. 변경 이력은 감사 로그에 기록된다.
