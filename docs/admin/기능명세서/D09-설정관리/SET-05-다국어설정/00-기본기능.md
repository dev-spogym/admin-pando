## 기능 목적

시스템 전체에서 사용하는 언어와 국가·지역 관련 표시 형식을 설정하는 화면이다. 외국인 회원이 많은 센터나 해외 지점 운영 시 관리자 화면과 키오스크 화면의 표시 언어를 다르게 구성할 수 있다. 자동 번역 기능으로 공지사항 다국어 운영 부담을 줄인다.

운영 맥락:
- **외국인 회원 다수 센터**: 키오스크 언어에 영어·일본어 추가 → 외국인 회원이 모국어로 체크인·결제 가능
- **해외 지점 개설**: 타임존·화폐·날짜 형식을 현지 기준으로 전환 → 매출 리포트·청구 이력 현지화
- **관리자·키오스크 언어 분리 운영**: 관리자 화면은 한국어 유지, 키오스크만 영어·중국어 복수 노출
- **공지사항 자동 번역**: 한국어 원문 작성 후 자동 번역 ON → 영·일·중 번역본 즉시 생성, 수동 번역 부담 제거
- **타임존 변경 후 스케줄 정합성 확인**: 타임존 변경 시 기존 예약 수업 시각이 새 타임존 기준으로 재표시 → 혼선 방지 안내
- **텍스트 길이 깨짐 방지**: 일부 언어(독일어·아랍어)의 번역 문자열이 UI 레이아웃을 초과할 수 있어 언어별 키오스크 미리보기 제공
- **번역 부족(미번역 키) fallback 처리**: 일부 i18n 키에 번역 데이터 없을 시 한국어 원문으로 자동 fallback

## 주요 구성요소

### 시스템 언어 설정

| 항목 | 옵션 |
|------|------|
| 관리자 화면 언어 | 한국어 / 영어 / 일본어 / 중국어 간체 |
| 키오스크 화면 언어 | 위와 동일 (복수 선택) |
| 키오스크 기본 언어 | 활성 중 1개 |
| 키오스크 언어 전환 버튼 | 표시 / 숨김 |

### 국가·지역 설정

| 항목 | 옵션 |
|------|------|
| 날짜 표시 형식 | YYYY-MM-DD / MM/DD/YYYY / DD/MM/YYYY |
| 시간 표시 형식 | 24시간제 / 12시간제 |
| 화폐 단위 | ₩ / $ / ¥ 등 |
| 시간대 | UTC ~ Asia/Seoul 등 |

### 자동 번역 설정

| 항목 | 옵션 |
|------|------|
| 공지사항 자동 번역 | 토글 (외부 번역 서비스) |
| 번역 대상 언어 | 활성 키오스크 언어 기준 자동 선택 |
| 번역 부족 시 fallback | 한국어 원문 표시 |

### 키오스크 언어 미리보기

선택 언어별 키오스크 주요 화면 미리보기 (텍스트 길이 검증용).

## 주요 UX 흐름

**언어 변경**
1. 사이드바 → "설정 > 다국어 설정" 진입
2. 관리자 화면 언어 변경 → 저장 → 화면 즉시 전환
3. 키오스크 언어 변경 → 저장 → 키오스크 기기 즉시 반영

**지역 설정**
1. 날짜·시간·화폐·시간대 변경
2. [저장] → 시스템 전체 적용

**자동 번역**
1. 자동 번역 토글 ON → 외부 번역 서비스 연동
2. 공지 작성 시 자동 다국어 생성

### 분기·예외 흐름

- **키오스크 기본 언어 비활성화 시도**: 기본 언어로 지정된 언어를 활성 목록에서 제거하려 할 때 "기본 언어는 비활성화할 수 없습니다. 먼저 기본 언어를 변경해주세요" 인라인 에러
- **키오스크 활성 언어 전체 제거 시도**: 최소 1개 언어 유지 강제, "키오스크에는 최소 1개 이상의 언어가 필요합니다" 에러
- **타임존 변경 시 기존 예약 수업 혼선 경고**: "타임존 변경 시 기존 예약 수업의 표시 시각이 변경됩니다. 실제 UTC 시각은 유지됩니다" 확인 모달 (확인 후 저장)
- **자동 번역 API 쿼터 초과**: "번역 API 사용 한도를 초과했습니다. 원문으로 게시됩니다" 토스트 + 한국어 fallback
- **번역 부족 키(i18n 미번역)**: 해당 텍스트는 한국어 원문으로 fallback 표시. 관리자 화면에 "번역 부족 언어: N개 키" 경고 배지 노출
- **텍스트 길이 초과 (UI 깨짐)**: 키오스크 미리보기에서 특정 언어 문자열이 컨테이너 너비 초과 시 해당 언어 배지에 노랑 경고 아이콘 + "레이아웃 검토 필요" 안내
- **관리자 화면 언어 변경 저장 직후 UX**: 저장 즉시 페이지 전체 리로드, 이전 미저장 작업 있으면 DLG-080-001 선처리
- **화폐 단위 변경의 데이터 영향 안내**: "화폐 단위 변경은 표시에만 영향을 미치며 저장된 금액 데이터는 변경되지 않습니다" 인라인 안내
- **자동 번역 OFF 전환 시 기존 번역본 처리**: "자동 번역을 끄면 기존 번역본은 유지되나 이후 신규 공지는 번역되지 않습니다" 확인 모달
- **동시 설정 변경 충돌**: 최종 저장자 우선 반영, 이전 사용자에게 "다른 관리자가 설정을 변경했습니다" 알림

## 비즈니스 규칙

1. 관리자 화면 언어 변경 시 저장 즉시 화면 전체가 선택 언어로 전환된다 (페이지 리로드).
2. 키오스크 언어 변경 시 연결된 모든 키오스크에 즉시 반영된다.
3. 키오스크 기본 언어는 활성된 언어 중 1개 필수 지정한다.
4. 화폐 단위 변경은 매출·결제 화면 표시에만 영향을 주고 저장 데이터(숫자값)는 변경되지 않는다.
5. 자동 번역은 외부 서비스(Google Translate 등) API 사용량에 따라 비용이 발생할 수 있다.
6. 변경 이력은 감사 로그에 기록된다.
7. **키오스크 최소 언어**: 활성 키오스크 언어는 최소 1개 이상 유지. 전체 제거 차단.
8. **기본 언어 보호**: 키오스크 기본 언어로 지정된 언어는 활성 목록에서 제거 불가. 먼저 기본 언어 변경 필요.
9. **타임존 적용 범위**: 타임존 변경은 표시 계층(UI)에만 적용. 모든 시각 데이터는 UTC로 저장, 조회 시 설정 타임존으로 변환 표시.
10. **번역 부족 fallback**: i18n 키에 번역 데이터 없을 시 한국어 원문으로 자동 fallback. 관리자 화면에 미번역 키 수 경고 배지 노출.
11. **텍스트 길이 검증**: 키오스크 미리보기에서 번역 문자열이 UI 컨테이너 너비 초과 시 경고. 강제 차단은 아님.
12. **자동 번역 대상**: 활성 키오스크 언어(한국어 제외) 전체에 번역 적용. 번역 결과는 공지 레코드에 언어별 컬럼으로 저장.
13. **번역 API 쿼터 초과 처리**: 일일 번역 쿼터 초과 시 자동 번역 실패, 한국어 원문 fallback 게시. 운영자에게 쿼터 소진 알림.
14. **관리자 언어 변경 전 미저장 작업 처리**: 관리자 언어 변경 저장 전 미저장 작업이 있으면 DLG-080-001 먼저 표시.
15. **키오스크 언어 전환 버튼**: 표시 설정 시 키오스크 메인 화면에 언어 선택 버튼 노출. 숨김 설정 시 기본 언어 고정.
16. **superAdmin 전 지점 언어 강제 지정**: superAdmin은 모든 지점의 키오스크 기본 언어를 일괄 지정 가능.
17. **화폐 기호 + 금액 표시 순서**: 화폐 단위별 기호 위치(앞/뒤) 및 천 단위 구분자(,/.)를 locale에 맞게 자동 적용.
18. **감사 로그 기록 항목**: 변경 항목(언어/타임존/화폐/날짜형식), 변경 전·후값, actor, timestamp 저장.
