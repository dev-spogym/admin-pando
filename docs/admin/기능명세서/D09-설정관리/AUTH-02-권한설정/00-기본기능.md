## 기능 목적

관리자웹의 권한 템플릿별로 메뉴 접근 및 기능 사용 권한을 설정하는 화면이다. 직원관리에서 등록하는 직무(트레이너·골프강사·프런트)와는 별도로, 기본 제공 권한 템플릿과 센터 맞춤형 역할을 추가하고 각 역할이 어떤 메뉴에서 무엇을 할 수 있는지를 매트릭스 형태로 한눈에 확인하고 조정한다. 민감 기능은 별도 표기되어 권한 부여 시 경고된다.

## 주요 구성요소

### 권한 템플릿/역할 목록 패널 (좌측)

| 기본 템플릿 | 설명 |
|------|------|
| superAdmin | 슈퍼관리자 (모든 권한 고정) |
| primary | 본사 최고관리자 |
| owner | 센터장 |
| manager | 매니저 |
| fc | FC |
| staff | 스태프 |
| readonly | 조회전용 |

> `트레이너`, `골프강사`, `프런트`는 직원 직무값으로 분리 관리.

각 카드에 배정 직원 수 표시 + [+ 새 역할] / [복사] / [삭제] 액션.

### 권한 매트릭스 패널 (우측)

선택 역할의 메뉴 그룹별 권한 표시.

| 메뉴 그룹 | 권한 항목 |
|----------|---------|
| 회원 / 수업 / 매출 / 상품 / 직원 / 급여 / 시설 / 메시지 / 설정 (9그룹) | 접근 / 조회 / 생성 / 수정 / 삭제 (5종) |

[전체 허용] / [전체 거부] 버튼 + 권한 충돌 감지 경고.

### 상단 액션

- [초기화] (DLG-081-001)
- [변경 사항 저장] (변경 시 활성)

### 민감 기능 식별 표기

| 민감 기능 | 표기 |
|---|---|
| 회원 영구 삭제 | 아이콘 + 강조 |
| 환불 처리 | 아이콘 + 강조 |
| 급여 확정·지급 | 아이콘 + 강조 |
| 슈퍼관리자 권한 부여/회수 | 아이콘 + 강조 |
| 데이터 복원 | 아이콘 + 강조 |
| 감사로그 내보내기 | 아이콘 + 강조 |

`superAdmin` 또는 `primary` 외 역할에서 체크 시 경고 표시.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 역할 | 권한 수정·역할 생성·삭제 |
| owner (센터장) | 소속 지점 역할 | 권한 수정·역할 생성·삭제 |
| manager | 접근 불가 | ❌ |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**권한 수정**
1. 사이드바 → "설정 > 권한 설정" 진입
2. 좌측 역할 카드 선택 → 우측 매트릭스
3. 체크박스 변경 → 충돌 실시간 감지
4. [저장] → DLG-081-006 영향 분석 (배정 1명 이상 시)
5. 충돌 있으면 DLG-081-002 추가 표시
6. 저장 → 즉시 반영

**역할 생성**
1. [+ 새 역할] → DLG-081-003
2. 이름 + 복사 베이스 선택
3. 권한 매트릭스 편집

**역할 삭제**
1. [삭제] → DLG-081-006 영향 분석
2. 재배정 역할 선택
3. DLG-081-004 → 삭제

## 비즈니스 규칙

1. `superAdmin` 권한 템플릿은 모든 권한이 고정으로 수정 불가하다.
2. 트레이너·골프강사·프런트는 직원 직무값이며 권한 템플릿이 아니다.
3. 6종 민감 기능은 `superAdmin`/`primary` 외 역할에 부여 시 경고된다.
4. 역할 변경 시 배정 직원 1명 이상이면 영향 분석(DLG-081-006)이 먼저 표시된다.
5. 역할 삭제 시 배정된 직원·담당 회원이 있으면 재배정 후 삭제 가능하다.
6. 권한 충돌이 있으면 저장 전에 충돌 경고 다이얼로그(DLG-081-002)가 표시된다.
7. 권한 변경 이력은 감사 로그에 기록된다.
