## 기능 목적

센터에 설치된 IoT 출입 장치를 등록·관리하고 출입 방식을 설정하는 화면이다. 밴드, QR코드, 얼굴 인식 등 다양한 출입 수단의 활성화 여부와 연결된 기기 상태를 한눈에 파악하고 제어한다. 비정상 출입 시도 알림으로 보안 관리도 강화한다.

## 주요 구성요소

### 연결 기기 현황

| 컬럼 | 설명 |
|------|------|
| 기기명 | 이름 |
| 설치 위치 | 1층 입구 등 |
| 연결 상태 | 정상 / 오프라인 / 오류 |
| 마지막 통신 시각 | YYYY-MM-DD HH:mm |
| 액션 | [재연결] |

[+ 새 기기 등록].

### 출입 방식 설정

| 수단 | 활성 |
|------|------|
| 스마트 밴드 (RFID) | ON/OFF |
| QR코드 스캔 | ON/OFF |
| 얼굴 인식 | ON/OFF |
| 핀번호 입력 | ON/OFF |

| 항목 | 설정 |
|------|------|
| 중복 출입 방지 시간 | 동일 회원 재입장 간격 |
| 출입 이력 보관 기간 | 30일/90일/1년/영구 |

### 출입 알림 설정

| 알림 | 토글 |
|------|------|
| 입장 알림 (회원앱 푸시) | ON/OFF |
| 퇴장 알림 (회원앱 푸시) | ON/OFF |
| 비정상 출입 시도 알림 (관리자) | ON/OFF |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 기기 | 조회·설정·등록 |
| owner (센터장) | 소속 지점 기기 | 조회·설정·등록 |
| manager | 기기 연결 상태 | 조회만 |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**기본 운영**
1. 사이드바 → "설정 > IoT 출입 관리" 진입
2. 기기 목록 + 연결 상태 자동 로드
3. 오프라인 기기 [재연결] 시도

**기기 등록**
1. [+ 새 기기 등록]
2. 기기 코드 + 설치 위치 입력
3. 연결 시도 → 성공 시 목록 추가

**출입 방식 변경**
1. 4종 수단 토글
2. 중복 방지·보관 기간 설정
3. [저장] → 모든 기기 즉시 반영

## 비즈니스 규칙

1. 출입 수단은 최소 1개 활성 필수이며 모두 비활성 저장 차단된다.
2. 중복 출입 방지 시간은 동일 회원의 연속 입장을 차단해 어뷰징을 방지한다.
3. 출입 이력 보관 기간은 법정 최소 기간(30일) 이상이어야 한다.
4. 비정상 출입 시도(미등록 카드, 만료 회원 등)는 관리자에게 즉시 알림된다.
5. 오프라인 기기는 자동 재연결 시도되며 N분 이상 지속 시 관리자 알림된다.
6. 변경 이력은 감사 로그에 기록된다.
