## 기능 목적

센터 입구에 설치된 키오스크 화면의 구성과 동작 방식을 설정하는 화면(SCR-082)이다. 회원이 키오스크에서 출석 체크를 하는 방식(QR/회원번호/얼굴 인식 3종, 다중 가능), 화면에 표시할 메시지·배경·로고, 사용 가능한 기능 4종(이용권 잔여·수업 예약·락커·공지) 토글을 관리한다. 미리보기로 변경 사항이 실시간 반영되어 운영자가 결과를 즉시 확인하며, 저장 시 연결된 모든 키오스크 기기에 즉시 push 된다. 미저장 변경 + 페이지 이탈 시 DLG-080-001로 손실을 방지한다.

운영 맥락:
- **신규 오픈 센터 키오스크 초기 설정**: 출석 방식 QR + 얼굴 인식 활성 → 환영 메시지 + 로고 업로드 → 미리보기 확인 → 저장
- **계절 캠페인 환영 메시지 변경**: "여름 PT 30% 할인 진행 중!" 메시지 임시 적용 → 캠페인 종료 시 복원
- **얼굴 인식 카메라 추가 후 활성**: SCR-083에서 얼굴 인식 카메라 연결 확인 → SCR-082에서 얼굴 인식 활성 → 즉시 반영
- **외국인 회원 비중 증가에 따른 다국어 추가**: SET-05 다국어 설정에서 영어·중국어 활성 → SCR-082 키오스크 표시 언어 다중 선택
- **회원앱 출시에 따른 기능 단순화**: 키오스크의 이용권 조회·수업 예약 OFF → 회원앱 사용 유도
- **키오스크 미연결 상태 운영**: 키오스크 기기가 모두 오프라인 시에도 설정은 가능하나 적용은 연결 시점에 보류
- **카메라 고장으로 얼굴 인식 일시 비활성**: 얼굴 인식 OFF → QR/회원번호만 활성 → 수리 후 재활성
- **공지 캠페인 키오스크 노출**: SET-EXT-04 공지 등록 + 키오스크 공지사항 조회 ON → 회원에게 자연스럽게 노출

저장 시점에 연결된 모든 키오스크 기기에 MQTT/WebSocket 신호로 push 되며 미연결 기기는 다음 connect 시점에 동기화된다. 변경 이력은 SCR-097 감사 로그에 기록된다.

## 주요 구성요소

### 출석 방식 설정

| 옵션 | 설명 |
|------|------|

## 주요 UX 흐름

### 기본 설정 흐름
1. 사이드바 → "설정 > 키오스크 설정" 진입 → 저장값 자동 로드
2. 출석 방식·화면 구성·기능 표시 변경 → 미리보기 실시간 갱신
3. 저장 버튼 활성 + "저장되지 않은 변경 사항" 배지
4. [저장] → 연결된 모든 키오스크 기기에 push → 메시지(3초)
5. 미저장 + 페이지 이탈 → DLG-080-001 (저장/이탈/취소)

### 분기·예외 흐름
- **출석 방식 모두 비활성 저장 시도**: "최소 1개 출석 방식 활성 필수" 인라인 + 저장 차단
- **기본 출석 방식 미지정**: 활성 방식 중 1개 선택 강제 + 저장 차단
- **얼굴 인식 활성 시 카메라 미등록**: SCR-083 연결 안내 + 저장 후 동작 시 fallback 메시지
- **이미지 배경 5MB 초과**: "5MB 이내 업로드" 인라인 + 업로드 차단
- **이미지 형식 불일치 (PNG/JPG 외)**: "지원하지 않는 형식" + 차단
- **환영 메시지 100자 초과**: 인라인 + 저장 차단
- **`{회원명}` 변수 외 임의 변수**: "지원하지 않는 변수" 경고 + 텍스트 그대로 표시
- **표시 언어 SET-05 미활성 언어 선택**: SET-05 활성 언어 안내 + 차단
- **키오스크 미연결 상태 저장**: "연결된 키오스크 없음" 안내 + 저장은 가능, 연결 시점 자동 동기화
- **저장 push 실패 (일부 기기)**: "N개 기기 동기화 실패" 경고 + 재시도 버튼

## 비즈니스 규칙

1. 출석 방식은 최소 1개 활성 필수이며 모두 비활성 저장 차단된다.
2. 기본 출석 방식은 활성된 방식 중 1개 선택 필수이다.
3. 환영 메시지의 `{회원명}` 변수는 출석 시 회원 이름으로 자동 치환되며 그 외 변수는 텍스트 그대로 표시된다.
4. 저장 시 연결된 모든 키오스크 기기에 MQTT/WebSocket으로 push 된다.
5. 키오스크 미연결 상태에서도 설정 가능하나 적용은 connect 시점에 동기화된다.
6. 변경 이력은 SCR-097 감사 로그에 기록된다.
7. **표시 언어 정책**: SET-05 다국어 설정에서 활성된 언어 중 키오스크용으로 다중 선택 가능, 기본 언어 1개 필수.
8. **얼굴 인식 활성 조건**: SCR-083 IoT 출입 관리에 얼굴 인식 카메라 ≥ 1대 등록·정상 상태 필수, 미충족 시 저장은 가능하나 동작 시 fallback.
9. **이미지 배경 정책**: PNG/JPG ≤ 5MB, 권장 1080×1920 (세로 키오스크) / 1920×1080 (가로 키오스크).
10. **메시지 길이**: 환영 메시지·완료 메시지 각 100자 이내.
11. **기능 표시 4종**: 이용권 잔여 조회·수업 예약 조회·락커 번호 확인·공지사항 조회 (모두 비활성 가능).
12. **미저장 변경 + 페이지 이탈**: DLG-080-001 강제 표시 (브라우저 leave 이벤트).
13. **저장 push 실패 정책**: 부분 실패 시 실패 기기 목록 표시 + 재시도 버튼, 전체 실패 시 저장 자체 롤백.
14. **권한 정책**: 매니저는 조회만 가능, owner는 소속 지점만 RLS branchId 필터, primary/superAdmin은 전 지점.
15. **DLG-080-001 미저장 경고**: 저장/이탈/취소 3 옵션, 저장 선택 시 자동 저장 후 이탈.
16. **공지사항 조회 ON**: SET-EXT-04 회원앱 노출 공지 + 키오스크 공지 게시 대상 공지가 노출됨.
17. **이용권 잔여 조회 ON**: 회원 본인 카드 정보 노출, 개인정보 정책 준수 필수.
18. **수업 예약 조회 ON**: D03 수업 예약 기능 연동, 키오스크에서 예약·취소 가능 여부는 정책 토글.
19. **락커 번호 확인 ON**: D02 락커 정보 매핑 필수.
20. **저장 시점 동기화 트랜잭션**: DB 저장 + 기기 push가 atomic 처리, 한쪽 실패 시 롤백.
