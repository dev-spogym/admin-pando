## 기능 목적

센터 내 공지사항을 작성·수정·삭제하고 게시 대상과 게시 기간을 설정하는 화면이다. 전체 직원 공지, 특정 역할 대상 공지 등 수신 대상을 구분하여 필요한 정보를 원하는 시점에 전달한다. 중요 공지는 별도 표시되어 우선순위를 명확히 한다.

## 주요 구성요소

### 공지 목록

| 컬럼 | 설명 |
|------|------|
| 제목 | 클릭 시 미리보기 |
| 게시 대상 | 전체 / 직원 / 회원 / 특정 역할 |
| 게시 기간 | 시작 ~ 종료 |
| 게시 상태 | 예정 / 게시 중 / 종료 |
| 작성자 | 직원명 |
| 작성일 | YYYY-MM-DD |
| 액션 | [수정] / [삭제] |

### 상태 필터 탭

전체 / 게시 중 / 예정 / 종료.

### 키워드 검색

제목 기준 검색.

| 항목 | 입력 |
|------|------|
| 카테고리 | 4종 (운영/이벤트/시설/긴급) |
| 제목 | 텍스트 (필수) |
| 내용 | 리치 텍스트 |
| 게시 대상 | 전체/직원/회원/특정 역할 |
| 게시 기간 | 시작 ~ 종료 |
| 중요 표시 (📌) | 토글 |
| 회원앱 노출 | 토글 |
| 첨부 파일 | 이미지/PDF |

### 공지 삭제 (DLG-085-002)

삭제 확인.

### 공지 상세 미리보기

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 공지 | 작성·수정·삭제 |
| owner (센터장) | 소속 지점 공지 | 작성·수정·삭제 |
| manager | 소속 지점 공지 | 작성·수정 (삭제 불가) |
| fc / 트레이너 / 스태프 | 수신 대상 공지 | 조회만 |
| readonly | 수신 대상 공지 | 조회만 |

## 주요 UX 흐름

**공지 등록**
1. 사이드바 → "설정 > 공지사항 관리" 진입
2. [공지 등록] → DLG-085-001
3. 카테고리·제목·내용·대상·기간·중요·회원앱 입력
4. 저장 → 목록 추가

**공지 수정**
1. 행 [수정] → DLG-085-001 채워진 폼
2. 정보 변경 → 저장

**공지 삭제**
1. 행 [삭제] → DLG-085-002
2. 확인 → 삭제

## 비즈니스 규칙

1. 게시 기간은 시작일 자동 활성, 종료일 자동 종료된다.
2. 중요(📌) 표시된 공지는 회원앱·관리자 화면에서 상단 고정 표시된다.
3. 회원앱 노출 토글이 활성된 공지만 회원앱에 표시된다.
4. 매니저는 공지 작성·수정은 가능하나 삭제는 할 수 없다.
5. 공지 게시 대상은 게시 중에는 일부만 변경 가능하다 (대상 추가는 가능, 축소 제한).
6. 작성·수정·삭제 이력은 감사 로그에 기록된다.
