## 기능 목적

센터 입구에 설치된 키오스크 화면의 구성과 동작 방식을 설정하는 화면이다. 회원이 키오스크를 통해 출석 체크를 하는 방식, 화면에 표시할 메시지와 배경, 사용 가능한 기능 항목을 관리한다. 미리보기로 변경 사항이 실시간 반영되어 운영자가 결과를 즉시 확인한다.

## 주요 구성요소

### 출석 방식 설정

| 옵션 | 설명 |
|------|------|
| QR코드 | 회원 QR 스캔 |
| 회원번호 입력 | 키패드 |
| 얼굴 인식 | 카메라 |
| 기본 출석 방식 | 첫 화면 표시 |

복수 선택 가능, 기본 방식 1개 지정.

### 화면 구성 설정

| 항목 | 입력 |
|------|------|
| 표시 언어 | 한국어/영어/중국어/일본어 |
| 대기 화면 배경 | 이미지 또는 색상 |
| 센터 로고 표시 | 토글 |
| 환영 메시지 | 텍스트 + 변수 (회원명) |
| 출석 완료 메시지 | 텍스트 |

### 기능 표시 설정

| 기능 | 토글 |
|------|------|
| 이용권 잔여 조회 | ON/OFF |
| 수업 예약 조회 | ON/OFF |
| 락커 번호 확인 | ON/OFF |
| 공지사항 조회 | ON/OFF |

### 미리보기

설정값 기준 키오스크 화면 시뮬레이션.

### 저장 / 미저장 경고

DLG-080-001 미저장 변경 시 페이지 이탈 경고.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 설정 | 조회·수정 |
| owner (센터장) | 소속 지점 키오스크 | 조회·수정 |
| manager | 전체 설정 | 조회만 |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "설정 > 키오스크 설정" 진입
2. 저장된 설정값 표시
3. 항목 변경 → 미리보기 실시간 갱신
4. [저장] → 키오스크 기기 즉시 반영
5. 미저장 + 페이지 이탈 → DLG-080-001

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 저장값 표시 |
| 수정 중 | 저장 활성 + 미리보기 반영 |
| 저장 중 | 버튼 비활성 |
| 저장 완료 | 메시지 |
| 키오스크 미연결 | "연결된 키오스크 기기가 없습니다" |

## 비즈니스 규칙

1. 출석 방식은 최소 1개 활성 필수이며 모두 비활성 저장 차단된다.
2. 기본 출석 방식은 활성된 방식 중 1개 선택 필수이다.
3. 환영 메시지의 `{회원명}` 변수는 출석 시 자동 치환된다.
4. 저장 시 연결된 모든 키오스크 기기에 즉시 반영된다.
5. 키오스크 미연결 상태에서는 설정 가능하나 적용은 연결 시점 후 처리된다.
6. 변경 이력은 감사 로그에 기록된다.
