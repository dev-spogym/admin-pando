## 기능 목적

센터 운영 데이터의 백업 주기를 설정하고, 수동 백업을 실행하며, 이전 백업 시점으로 복원하는 화면이다. 데이터 손실 사고에 대비한 안전망으로 운영되며, 복원 이력을 통해 과거 복원 내역을 추적할 수 있다.

## 주요 구성요소

### 자동 백업 설정

| 항목 | 옵션 |
|------|------|
| 자동 백업 활성 | 토글 |
| 백업 주기 | 매일 / 매주 / 매월 |
| 백업 실행 시각 | HH:mm |
| 보관 기간 | 30일 / 90일 / 180일 / 무제한 |
| 액션 | [백업 설정] → DLG-089-002 |

### 수동 백업

| 항목 | 동작 |
|------|------|
| 지금 백업 실행 | 즉시 백업 |
| 마지막 백업 일시 | YYYY-MM-DD HH:mm |
| 최신 백업 다운로드 | 파일 |

### 백업 이력

| 컬럼 | 설명 |
|------|------|
| 백업 일시 | YYYY-MM-DD HH:mm |
| 데이터 크기 | MB/GB |
| 백업 방식 | 자동 / 수동 |
| 상태 | 성공 / 실패 |
| 액션 | [복원] / [다운로드] |

기간 필터: 오늘 / 이번 주 / 이번 달 / 사용자 지정.

### 복원 이력

| 컬럼 | 설명 |
|------|------|
| 복원 일시 | YYYY-MM-DD HH:mm |
| 복원 백업 시점 | YYYY-MM-DD |
| 실행자 | 직원명 |

기간 필터: 동일 4종.

### 데이터 복원 확인 (DLG-089-001)

복원 최종 확인 + 영향 안내.

### 백업 설정 (DLG-089-002)

자동 백업 상세 설정.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 설정 | 백업·복원·다운로드 |
| owner (센터장) | 소속 지점 백업 | 수동 백업 (복원은 슈퍼관리자 승인) |
| manager | 접근 불가 | ❌ |
| fc / 트레이너 / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**자동 백업 설정**
1. 사이드바 → "설정 > 데이터 백업·복원" 진입
2. [백업 설정] → DLG-089-002
3. 주기·시각·보관 기간 입력
4. 저장 → 자동 실행 시작

**수동 백업**
1. [지금 백업 실행]
2. 진행 표시 → 완료 → 이력 추가

**시점 복원**
1. 이력 행 [복원] → DLG-089-001
2. 영향 안내 확인 → 복원 시작
3. 시스템 재시작 → 선택 시점 데이터로 전환

**다운로드**
1. 행 [다운로드] → 권한 검증
2. 백업 파일 다운로드

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 자동 설정 + 이력 |
| 백업 진행 중 | 진행 표시 + 버튼 비활성 |
| 백업 완료 | 메시지 + 이력 갱신 |
| 복원 진행 중 | 화면 전체 처리 중 |
| 이력 없음 | 안내 |

## 비즈니스 규칙

1. 자동 백업은 설정된 주기·시각에 자동 실행되며 보관 기간 경과 시 자동 삭제된다.
2. 수동 백업은 즉시 실행되며 자동 백업과 별도 보관된다.
3. 복원은 슈퍼관리자 권한 또는 센터장의 슈퍼관리자 승인 후 실행 가능하다 (오작동 방지).
4. 복원 시 시스템이 재시작되며 진행 중인 작업이 중단될 수 있다.
5. 백업 파일은 암호화되어 저장되며 다운로드 시에도 권한 검증이 필요하다.
6. 모든 백업·복원 이력은 감사 로그에 기록된다.
