## 기능 목적

원하는 기간과 항목을 선택하여 운영 보고서를 생성하고 엑셀 또는 PDF로 내보내는 화면이다. 정기 보고, 경영진 보고, 고객 제출용 등 다양한 목적의 리포트를 맞춤 생성하며, 상담 전환 분석 옵션을 활성화하면 KPI 퍼널(SCR-094)과 연계된 리드→상담→등록 단계별 전환 데이터까지 포함된다.

## 주요 구성요소

### 리포트 설정 패널

| 항목 | 입력/선택 |
|------|------|
| 리포트 유형 | 매출 / 회원 현황 / 출석 / 수업 / 종합 (5종) |
| 조회 기간 | 날짜 범위 직접 입력 또는 빠른 선택(이번 주 / 이번 달 / 이번 분기 / 이번 해) |
| 대상 지점 | 전체 또는 특정 지점 복수 선택 |
| 포함 항목 | 체크박스로 세부 항목 선택 |
| 상담 전환 분석 | 체크박스 (활성화 시 KPI 퍼널 데이터 추가) |
| 리포트 생성 | 버튼 |

### 리포트 미리보기

| 영역 | 표시 |
|------|------|
| 본문 | 생성된 리포트 내용 |
| 페이지 네비게이션 | 다중 페이지 리포트 시 페이지 이동 |

### 내보내기

| 버튼 | 동작 |
|------|------|
| 엑셀 다운로드 | .xlsx 다운로드 |
| PDF 다운로드 | .pdf 다운로드 |
| 인쇄 | 브라우저 인쇄 |

### 생성 이력

| 컬럼 | 표시 |
|------|------|
| 일시 | YYYY-MM-DD HH:mm |
| 유형 | 매출/회원/출석/수업/종합 |
| 생성자 | 직원명 |
| 액션 | [다운로드] |

### 상담 전환 분석 (옵션 활성 시)

| 영역 | 표시 |
|------|------|
| 단계별 전환율 | 리드 유입 → 상담 완료 → 회원 등록 |
| 유입경로별 전환율 | 채널별 |
| 미리보기 추가 표시 | 표/그래프 |
| CSV·엑셀 컬럼 추가 | 전환 분석 컬럼 자동 포함 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 리포트 | 모든 유형 생성·내보내기·이력 조회 |
| owner (센터장) | 소속 지점 리포트 | 소속 지점 데이터 한정 생성·내보내기 |
| manager | 접근 불가 | — |
| fc / 트레이너 / 스태프 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**리포트 생성**
1. 사이드바 → "본사관리 > 리포트" 진입
2. 리포트 유형·기간·지점·포함 항목 선택
3. (선택) 상담 전환 분석 체크
4. [리포트 생성] → 생성 처리 표시 → 미리보기 표시

**내보내기**
1. 미리보기 확인
2. [엑셀] / [PDF] / [인쇄] 중 선택
3. 다운로드 처리 표시 → 완료 토스트

**과거 리포트 재조회**
1. 생성 이력 목록 확인
2. [다운로드] 클릭 → 파일 재다운로드

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 | 리포트 설정 패널만 표시, 미리보기 비어있음 |
| 생성 중 | 리포트 생성 처리 중 (처리 표시) |
| 생성 완료 | 미리보기 표시, 내보내기 버튼 활성 |
| 내보내기 처리 중 | 다운로드 버튼 처리 표시 |
| 데이터 없음 | 선택 조건에 해당 데이터 없음 안내 |
| 권한 부족 | 매니저 이하 접근 차단 안내 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. 센터장은 본인 소속 지점(`branchId`) 데이터로만 리포트를 생성할 수 있다.
3. 엑셀 다운로드는 현재 미리보기 페이지와 무관하게 선택 조건 전체 데이터를 내려받는다.
4. 상담 전환 분석 옵션 활성 시 KPI 센터(HQ-04) 퍼널 데이터를 출처로 사용한다.
5. 생성된 리포트는 일정 기간 생성 이력에 보관되며 동일 권한 범위 내에서 재다운로드 가능하다.
6. 리포트 생성·다운로드는 감사 로그(SCR-097)에 기록된다.
7. PDF·인쇄 출력 시 헤더에 지점명·기간·생성 일시·생성자가 자동 삽입된다.

## 관련 화면 / API
