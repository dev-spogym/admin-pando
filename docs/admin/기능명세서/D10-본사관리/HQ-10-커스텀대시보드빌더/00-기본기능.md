## 기능 목적

위젯을 드래그앤드롭 방식으로 배치하여 자신만의 대시보드를 구성하는 화면이다. 자주 확인하는 지표·정보를 원하는 레이아웃으로 배치하여 업무 효율을 높이며, 여러 레이아웃 프리셋을 저장·불러오기로 관리한다.

운영 맥락:
- **본사 경영진 조조 보고용 레이아웃**: CFO가 매일 아침 전사 매출·신규 회원 수·이탈률 위젯 3종을 상단에 배치한 전용 프리셋을 로드하여 일일 브리핑에 활용한다.
- **센터장 지점 운영 현황 한눈 파악**: 소속 지점의 오늘 출석·미납 회원·이번 주 수업 현황 위젯을 2열 레이아웃으로 구성하여 출근 즉시 확인한다.
- **본사 운영팀 전사 공유 대시보드 배포**: superAdmin이 공통 레이아웃을 "전사 공유"로 설정하면 모든 owner 계정의 기본 대시보드에 반영된다.
- **지표 탭 분리 운영**: 매출·회원·출석을 별도 탭으로 분리하여 목적별로 빠르게 전환할 수 있다. 각 탭은 독립 레이아웃으로 저장된다.
- **위젯 자동 갱신 주기 설정**: 실시간성이 중요한 체크인 위젯은 30초마다, 매출 집계 위젯은 10분마다 갱신 주기를 개별 설정하여 서버 부하를 최적화한다.
- **캐시 기반 빠른 로드**: 대형 데이터 위젯은 캐시(최대 5분)를 적용하여 대시보드 진입 시 지연을 최소화한다.
- **레이아웃 초기화 후 재구성**: 팀 교체·역할 변경 시 기본값 초기화 후 새 역할에 맞는 위젯 세트를 처음부터 구성한다.

## 주요 구성요소

### 위젯 라이브러리 패널 (좌측)

| 항목 | 표시 |
|------|------|
| 카테고리 | 매출 / 회원 / 출석 / 수업 / 공지 / 할 일 등 |
| 위젯 카드 | 썸네일 미리보기 + 위젯명 |
| 검색 | 위젯명 검색 입력 |

### 캔버스 영역 (우측)

| 항목 | 동작 |
|------|------|
| 위젯 배치 | 드래그앤드롭으로 캔버스에 배치 |
| 위젯 이동 | 드래그로 위치 이동 |
| 위젯 크기 조절 | 모서리 드래그 |
| 위젯 설정 버튼 | 위젯 내 표시 기간·지점 등 세부 설정 |
| 위젯 제거 버튼 | 캔버스에서 제거 |

### 레이아웃 옵션

| 옵션 | 표시 |
|------|------|
| 그리드 열 수 | 2 / 3 / 4열 선택 |
| 그리드 선 표시 | 표시 / 숨김 토글 |

### 저장 및 관리

| 항목 | 동작 |
|------|------|
| 저장 | 현재 레이아웃 저장 |
| 불러오기 | 저장된 레이아웃 선택 |
| 기본값 초기화 | 기본 레이아웃 복원 |
| 이름 지정 저장 | 여러 레이아웃 프리셋 관리 |

## 분기·예외 흐름

- **위젯 최대 개수 초과 시 추가 시도**: "캔버스에 추가할 수 있는 위젯 수를 초과했습니다(최대 N개)" 토스트, 추가 차단.
- **저장 안 된 상태에서 화면 이탈**: "저장되지 않은 변경 사항이 있습니다" 확인 다이얼로그 → [저장 후 이동] / [그냥 이동] / [취소].
- **[기본값 초기화] 실행 시**: "현재 레이아웃이 기본 레이아웃으로 초기화됩니다. 복구할 수 없습니다" 확인 다이얼로그 → 확정 후 복원.
- **위젯 데이터 로드 실패(개별 위젯)**: 해당 위젯 카드에 "데이터를 불러오지 못했습니다 [재시도]" 표시. 나머지 위젯은 정상 표시.
- **전사 공유 레이아웃 수정 시도(owner 계정)**: 공유 레이아웃은 읽기 전용. "본사에서 배포한 레이아웃은 수정할 수 없습니다" 안내, 별도 복사 후 편집 유도.
- **동일 위젯 중복 추가 시도**: 동일 위젯 2개 배치 허용 여부는 위젯 타입별 정책에 따라 결정. 허용 안 되는 위젯은 "이미 추가된 위젯입니다" 토스트.
- **프리셋 이름 중복 저장**: "같은 이름의 레이아웃이 이미 있습니다. 덮어쓰시겠습니까?" 확인 다이얼로그.
- **센터장이 본사 전용 위젯 드래그 시도**: 위젯 라이브러리에서 권한 외 위젯 숨김 처리. 드래그 자체 불가.
- **캐시 만료 전 수동 새로고침**: 전체 새로고침 버튼 클릭 시 캐시 무효화 후 즉시 재요청.
- **빈 캔버스 상태**: "위젯을 추가하여 대시보드를 구성해보세요" 안내 + 위젯 라이브러리 강조.
- **레이아웃 불러오기 중 손상된 프리셋**: "레이아웃을 불러올 수 없습니다" 오류 + 기본 레이아웃으로 폴백.

## 주요 UX 흐름

**레이아웃 편집**
1. 사이드바 → "본사관리 > 커스텀 대시보드 빌더" 진입
2. 저장된 레이아웃 자동 로드
3. 좌측 라이브러리에서 위젯 드래그 → 캔버스 배치
4. 위젯 이동·크기 조절·설정
5. [저장] → 대시보드 즉시 반영

**프리셋 관리**
1. 레이아웃 이름 입력 → [저장]
2. [불러오기] → 저장된 레이아웃 선택
3. 캔버스에 반영 후 추가 편집

**기본값 초기화**
1. [기본값으로 초기화] → 확인 다이얼로그
2. 확정 → 기본 레이아웃 복원

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다. 403 처리.
2. 센터장은 본인 소속 지점 관련 위젯만 라이브러리에 표시된다. 전사 집계 위젯은 superAdmin / primary 전용.
3. 그리드 열 수는 2/3/4열만 선택 가능하며, 위젯 크기는 그리드에 스냅된다. 자유 픽셀 크기 조절 불가.
4. **위젯 최대 개수**: 캔버스당 최대 20개. 초과 시 추가 차단. (운영 정책에 따라 변경 가능.)
5. **레이아웃 프리셋**: 계정별 최대 10개 저장 가능. 초과 시 기존 프리셋 삭제 후 저장 가능.
6. **전사 공유 레이아웃**: superAdmin만 생성 가능. 공유된 레이아웃은 owner 계정에서 읽기 전용으로 표시. 복사(Copy) 후 개인 편집 가능.
7. **탭 분리**: 대시보드 내 탭을 최대 5개까지 생성 가능. 각 탭은 독립 레이아웃으로 저장·관리된다.
8. **위젯 자동 갱신 주기**: 위젯별 갱신 주기 설정 가능(10초 / 30초 / 1분 / 5분 / 수동). 기본값은 5분.
9. **캐시 정책**: 데이터 위젯은 설정된 갱신 주기를 캐시 TTL로 사용. 수동 새로고침 시 캐시 즉시 무효화.
10. **저장 미완료 이탈 경고**: 변경 사항이 저장되지 않은 상태에서 화면 이탈 시 확인 다이얼로그 표시.
11. **기본값 초기화**: 현재 편집 레이아웃을 시스템 기본 레이아웃으로 복원. 복구 불가 조건으로 확인 다이얼로그 필수.
12. **저장 즉시 반영**: 저장 시점에 메인 대시보드(SCR-090 등)에 즉시 반영된다.
13. **차트 종류**: 위젯별 지원 차트 타입(막대/선/도넛/숫자 카드/테이블) 중 선택 가능. 위젯 설정 패널에서 전환.
14. **중복 위젯**: 동일 위젯의 복수 배치 허용 여부는 위젯 타입별 설정에 따른다. 기본적으로 동일 위젯 1개 제한.
15. **손상 프리셋 폴백**: 불러오기 시 손상된 레이아웃은 기본 레이아웃으로 자동 폴백.
16. **레이아웃 내보내기**: 현재 대시보드 캔버스를 PNG / PDF로 내보낼 수 있다. 내보내기 시 실시간 데이터 스냅샷이 포함된다.
17. **권한별 위젯 가시성**: 위젯 라이브러리는 계정 권한 기반 필터링. 권한 외 위젯은 숨김 처리(드래그 불가).
18. **감사 로그**: 전사 공유 레이아웃 생성·수정·삭제는 SCR-097에 기록. 개인 레이아웃 변경은 미기록.

| 프리셋 최대 개수 초과 저장 | "프리셋을 더 이상 저장할 수 없습니다(최대 10개)" | 기존 프리셋 삭제 후 재시도 안내 |
| 프리셋 이름 중복 | "같은 이름의 레이아웃이 이미 있습니다. 덮어쓰시겠습니까?" | 확인 시 덮어쓰기, 취소 시 새 이름 입력 |
| 전사 공유 레이아웃 수정 시도(owner) | "본사에서 배포한 레이아웃은 수정할 수 없습니다" | 복사 후 편집 유도 |
| 권한 외 위젯 드래그 시도 | 라이브러리에서 해당 위젯 숨김 | 드래그 자체 불가 |
| 손상된 프리셋 불러오기 | "레이아웃을 불러올 수 없습니다" 오류 | 기본 레이아웃 자동 폴백 |
| 기본값 초기화 확인 미완료 | 초기화 미실행 | 확인 다이얼로그 취소 처리 |
| 탭 최대 개수 초과 | "탭은 최대 5개까지 생성할 수 있습니다" | 탭 추가 차단 |
| 동일 위젯 중복 추가 (제한 위젯) | 토스트 "이미 추가된 위젯입니다" | 추가 차단 |
| 네트워크 오류로 저장 실패 | 토스트 "저장에 실패했습니다. 다시 시도해주세요" | 편집 내용 로컬 유지 |
| 매니저 이하 접근 | 403 화면 | 접근 불가 안내 |

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| SCR-097 감사 로그 | 전사 공유 레이아웃 생성·수정·삭제 | `layout_id`, `actor_id`, `action`, `shared_scope` INSERT |
| 메인 대시보드(SCR-090) | 레이아웃 저장 | 저장 즉시 대시보드 반영 (캐시 무효화) |
| 위젯 자동 갱신 스케줄러 | 설정된 갱신 주기 도달 | 해당 위젯 데이터 API 재호출, 캐시 갱신 |
| 전사 공유 레이아웃 배포 이벤트 | superAdmin [전사 공유] 저장 | 전체 owner 계정 기본 대시보드 레이아웃 교체 트리거 |
| 캐시 무효화 이벤트 | 수동 새로고침 버튼 클릭 | 전체 위젯 캐시 즉시 만료 + 재요청 |
| 레이아웃 내보내기 배치 | [PNG/PDF 내보내기] 클릭 | 캔버스 스냅샷 + 실시간 데이터 취합 후 파일 생성 다운로드 |
| 손상 프리셋 감지 배치 | 불러오기 시 | JSON 스키마 검증 → 실패 시 기본 레이아웃 폴백 + 오류 로그 |
| NFR-19 알림 센터 | 전사 공유 레이아웃 배포 완료 | 대상 owner 계정 인앱 알림 "대시보드 레이아웃이 업데이트되었습니다" |
| 프리셋 FIFO 관리 배치 | 프리셋 최대 한도 초과 저장 시도 | 사용자에게 기존 프리셋 삭제 요청 (자동 삭제 안 함) |
