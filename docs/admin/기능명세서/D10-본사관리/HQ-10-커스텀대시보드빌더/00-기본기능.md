## 기능 목적

위젯을 드래그앤드롭 방식으로 배치하여 자신만의 대시보드를 구성하는 화면이다. 자주 확인하는 지표·정보를 원하는 레이아웃으로 배치하여 업무 효율을 높이며, 여러 레이아웃 프리셋을 저장·불러오기로 관리한다.

## 주요 구성요소

### 위젯 라이브러리 패널 (좌측)

| 항목 | 표시 |
|------|------|
| 카테고리 | 매출 / 회원 / 출석 / 수업 / 공지 / 할 일 등 |
| 위젯 카드 | 썸네일 미리보기 + 위젯명 |
| 검색 | 위젯명 검색 입력 |

### 캔버스 영역 (우측)

| 항목 | 동작 |
|------|------|
| 위젯 배치 | 드래그앤드롭으로 캔버스에 배치 |
| 위젯 이동 | 드래그로 위치 이동 |
| 위젯 크기 조절 | 모서리 드래그 |
| 위젯 설정 버튼 | 위젯 내 표시 기간·지점 등 세부 설정 |
| 위젯 제거 버튼 | 캔버스에서 제거 |

### 레이아웃 옵션

| 옵션 | 표시 |
|------|------|
| 그리드 열 수 | 2 / 3 / 4열 선택 |
| 그리드 선 표시 | 표시 / 숨김 토글 |

### 저장 및 관리

| 항목 | 동작 |
|------|------|
| 저장 | 현재 레이아웃 저장 |
| 불러오기 | 저장된 레이아웃 선택 |
| 기본값 초기화 | 기본 레이아웃 복원 |
| 이름 지정 저장 | 여러 레이아웃 프리셋 관리 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 위젯 라이브러리 | 레이아웃 구성·저장·공유 |
| owner (센터장) | 지점 관련 위젯 | 레이아웃 구성·저장 |
| manager | 접근 불가 | — |
| fc / 트레이너 / 스태프 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**레이아웃 편집**
1. 사이드바 → "본사관리 > 커스텀 대시보드 빌더" 진입
2. 저장된 레이아웃 자동 로드
3. 좌측 라이브러리에서 위젯 드래그 → 캔버스 배치
4. 위젯 이동·크기 조절·설정
5. [저장] → 대시보드 즉시 반영

**프리셋 관리**
1. 레이아웃 이름 입력 → [저장]
2. [불러오기] → 저장된 레이아웃 선택
3. 캔버스에 반영 후 추가 편집

**기본값 초기화**
1. [기본값으로 초기화] → 확인 다이얼로그
2. 확정 → 기본 레이아웃 복원

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 저장된 레이아웃 편집 모드 |
| 위젯 드래그 중 | 드래그 대상 위젯 강조, 배치 가능 위치 표시 |
| 수정 중 | 변경 사항 있을 때 저장 버튼 활성 |
| 저장 완료 | 완료 메시지 후 대시보드 반영 |
| 빈 캔버스 | 위젯 추가 안내 |
| 권한 부족 | 매니저 이하 접근 차단 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. 센터장은 본인 소속 지점 관련 위젯만 라이브러리에 표시된다.
3. 그리드 열 수는 2/3/4열만 선택 가능하며, 위젯 크기는 그리드에 스냅된다.
4. 저장된 레이아웃은 사용자 계정별로 관리되며, superAdmin은 전사 공유 옵션을 사용할 수 있다.
5. [기본값으로 초기화]는 현재 편집 중인 레이아웃을 시스템 기본 레이아웃으로 복원한다.
6. 변경 사항이 저장되지 않은 상태에서 화면 이탈 시 경고 다이얼로그가 표시된다.
7. 저장 시점에 메인 대시보드(SCR-090 등)에 즉시 반영된다.
