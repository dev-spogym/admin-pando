## 기능 목적

신규 회원의 초기 정착 과정을 단계별로 추적하는 화면이다. 리드 유입부터 등록, 초기 출석 정착까지의 퍼널과 이탈 위험 회원을 조기에 파악하여 적절한 후속 조치를 취할 수 있도록 지원한다. 신규 회원의 7일/30일 정착이 장기 유지율을 결정한다는 운영 통찰을 반영한다.

## 주요 구성요소

### 프리-온보딩 KPI

| 지표 | 설명 |
|------|------|
| 이번 달 신규 리드 수 | 합계 |
| 연락 완료 건수 | 1차 응답 |
| 방문 완료 건수 | 대면 상담 |
| 등록 전환 건수 | 회원 등록 |
| 리드 전환율 | 등록/리드 |
| WI vs TI 건수 | 분리 |

### 신규 유치 KPI

| 지표 | 설명 |
|------|------|
| 이번 달 신규 등록 회원 | 합계 |
| 리드 누락률 | 처리 안 된 리드 |
| 회원소개 유입 비중 | 추천 비율 |
| 가입경로 분포 | 등록자 기준 |

### 신규 안정 KPI

| 지표 | 설명 |
|------|------|
| 7일 이용률 | 등록 7일 이내 2회 이상 |
| 30일 활동률 | 등록 30일 이내 4회 이상 |
| PT 체험 참여율 | 체험 비율 |
| 체험 → 등록 전환율 | 체험자 중 본상품 등록 |
| 일일입장 → 회원 전환율 | 일일 입장자 등록 비율 |
| GX 첫 참여율 | GX 시도 비율 |
| 초기 이탈 회원 수 | 등록 N일 이내 미출석 |

### 상담/가입 경로 분포

`[주간월간보고]` I10:Q10 등록자 기준 분포 막대 차트.
- WI 상세 (R10:Z10): 간판/블로그/인스타/당근/지역카페/현수막/전단지/회원소개/기타
- TI 상세 (AA10:AI10): 동일 순서 유지

### 온보딩 단계 진행률

가입 → 초기 상담 → 체성분 측정 → 프로그램 배정 → 첫 수업 완료 (5단계 진행률 막대).

### 신규 회원 목록

| 컬럼 | 설명 |
|------|------|
| 등록일 | YYYY-MM-DD |
| 경과일 | N일 |
| 방문 횟수 | 카운트 |
| PT 체험 완료 | O/X |
| GX 참여 | O/X |
| 온보딩 상태 | 정상/주의/이탈 위험 |

이탈 위험은 별도 섹션 강조.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 선택 지점 온보딩 | 지점 전환·조회 |
| owner / 지점 관리자 | 소속 지점 | 조회 |
| fc | 담당 리드·신규 회원 | 후속 상담 확인 |
| 트레이너 | 체험·첫 수업 회원 | 체험 후속 조치 |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

1. 사이드바 → "본사관리 > 온보딩 대시보드" 진입
2. 이번 달 신규 회원 온보딩 자동 조회
3. KPI 카드 → 리드 유입·방문·등록·정착 확인
4. 가입 경로 분포 → 효과적 채널 식별
5. 체험·일일입장 전환율 → 비용성 유입 회수 판단
6. 이탈 위험 섹션 자동 표시 시 후속 조치
7. 신규 회원 테이블에서 색상으로 상태 구분

## 비즈니스 규칙

1. 7일 이용률 = 등록 후 7일 이내 2회 이상 출석한 신규 회원 비율.
2. 30일 활동률 = 등록 후 30일 이내 4회 이상 출석한 신규 회원 비율.
3. 체험 참여율과 체험 → 등록 전환율은 별도 지표 (앞단 vs 뒷단).
4. 일일입장 → 회원 전환율은 일일 입장 고객 중 회원 등록 비율.
5. 가입경로 분포는 `[신규DB]` A열 `등록` + D/E열 기준 등록자 기준.
6. 회원소개 유입 비중은 `[신규DB]` D열 `상세 경로1=회원소개` 비율.
7. 이탈 위험 기준은 등록 후 N일 미출석 또는 일정 횟수 미만 출석으로 정의된다.
8. WI/TI 표기는 `방문 문의`/`전화 문의`로 통일.
