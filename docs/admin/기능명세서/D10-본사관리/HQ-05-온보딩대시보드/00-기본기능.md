## 기능 목적

신규 회원의 초기 정착 과정을 단계별로 추적하는 화면이다. 리드 유입부터 등록, 초기 출석 정착까지의 퍼널과 이탈 위험 회원을 조기에 파악하여 적절한 후속 조치를 취할 수 있도록 지원한다. 신규 회원의 7일/30일 정착이 장기 유지율을 결정한다는 운영 통찰을 반영한다.

운영 맥락:
- **본사 superAdmin 신규 유치 현황 점검**: 전체 지점 신규 리드 수·전환율 비교 → 채널별 ROI 분석
- **owner(센터장) 이달 신규 회원 정착 확인**: 7일/30일 활동률 + 온보딩 5단계 진행률 → 이탈 위험 회원 조기 대응
- **FC 리드 누락률 점검**: 프리-온보딩 KPI → 연락 미완료 리드 식별 → 즉시 콜 처리
- **트레이너 체험 후속 조치**: PT 체험 참여율·체험→등록 전환율 → 미등록 체험자 후속 상담 제안
- **이탈 위험 자동 감지 후 코칭**: 등록 7일 내 1회 이하 출석 → 이탈 위험 섹션 자동 표시 → FC 자동 코칭 알림
- **가입 경로 채널 효율 분석**: WI/TI 상세 분포(9종) → 비효율 채널 광고 예산 조정
- **D-3 이탈 위험 자동 메시지**: 등록 후 3일 미출석 회원 → 자동 문자 발송

### 상담/가입 경로 분포

`[주간월간보고]` I10:Q10 등록자 기준 분포 막대 차트.
- WI 상세 (R10:Z10): 간판/블로그/인스타/당근/지역카페/현수막/전단지/회원소개/기타
- TI 상세 (AA10:AI10): 동일 순서 유지

## 비즈니스 규칙

1. 7일 이용률 = 등록 후 7일 이내 2회 이상 출석한 신규 회원 비율.
2. 30일 활동률 = 등록 후 30일 이내 4회 이상 출석한 신규 회원 비율.
3. 체험 참여율과 체험 → 등록 전환율은 별도 지표 (앞단 vs 뒷단).
4. 일일입장 → 회원 전환율은 일일 입장 고객 중 회원 등록 비율.
5. 가입경로 분포는 `[신규DB]` A열 `등록` + D/E열 기준 등록자 기준.
6. 회원소개 유입 비중은 `[신규DB]` D열 `상세 경로1=회원소개` 비율.
7. 이탈 위험 기준은 등록 후 7일 이내 1회 이하 출석으로 정의한다.
8. WI/TI 표기는 `방문 문의`/`전화 문의`로 통일.
9. 온보딩 5단계(가입→초기 상담→체성분 측정→프로그램 배정→첫 수업 완료)는 순서대로 진행되며 역순 마킹 불가.
10. 프리-온보딩 단계는 "등록 전 리드" 대상이며, 신규 유치/신규 안정 단계는 "등록 후 회원" 대상이다.
11. WI 상세 9종: 간판/블로그/인스타/당근/지역카페/현수막/전단지/회원소개/기타. TI도 동일 9종.
12. D-3 자동 메시지는 등록일 기준 3일 후 00:00에 배치로 발송한다.
13. 체험 → 등록 전환율 집계 기간은 체험일 기준 30일 이내 등록 완료 여부이다.
14. 이탈 위험 섹션은 해당 회원 존재 시 자동 표시, 0명이면 섹션 숨김 처리한다.
15. 가입경로 분포 차트는 `[주간월간보고]` I10:Q10 등록자 기준 분포이며 월간 집계 기준이다.
16. 자동 코칭 알림은 이탈 위험 회원 감지 시 담당 FC에게 앱 푸시 + 문자로 발송한다.
17. 신규 회원 목록 온보딩 상태: 정상(초록)/주의(노랑)/이탈 위험(빨강) 3단계.
18. 리드 누락률 = 해당 월 신규 리드 중 A열 상태가 `미처리`인 건수 비율.
19. 일일입장 전환율 분모는 일일입장권 결제 건수 기준 (동일인 중복 방문 포함).
20. 초기 이탈 회원 수는 등록 후 30일 이내에 출석 0회인 회원 카운트이다.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `HQ-05`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-096`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
