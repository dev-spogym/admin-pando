## 기능 목적

핵심 성과 지표(KPI)의 달성 현황을 시각화하여 목표 대비 실적을 한눈에 파악하는 화면이다. 지점별·기간별 목표 설정과 달성률을 비교하여 운영 방향 결정을 지원한다. 상담 퍼널, 재등록, OT, GX 세부 종목, 강습 세션 등 다양한 KPI를 통합 관리한다.

## 주요 구성요소

### KPI 카드 영역

| KPI 카테고리 | 항목 |
|------|------|
| 매출 | 매출 목표 대비 달성률 (게이지) |
| 신규 회원 | 목표 대비 달성률 |
| 출석률 | 목표 대비 달성률 |
| 회원 유지율 | 목표 대비 달성률 |
| GX 수업 (#19~#22) | 수업 건수 / 예약 / 출석 / 출석률 |
| 강습세션수 | PT/필라/스트레칭/테라피 4종 |
| 상담 퍼널 | WI vs TI / TI 방문 전환율 / TI 등록률 / WI 등록률 |
| 재등록 | 재등록 상담 완료 / 재등록 성공률 |
| OT 운영 | 강습 OT / 골프 OT / 등록 전환율 / 거부율 / 이월률 / 체험→등록률 |

각 카드에 전월 대비 증감 표시.

### 상담/퍼널 세분화

WI(방문 문의) vs TI(전화 문의) 분리 표시. TI 방문 전환율 + WI/TI 등록률.

### 재등록 / 이탈 회복 KPI

`[재등록DB]` B열 상담결과 기반 집계.

### GX 세부 종목 분포

요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX기타 6종 분포 차트. 인기 종목 = 증설, 비인기 = 폐지 후보.

### OT / 수업 운영 KPI

강습 OT / 골프 OT / 등록 전환율 / 거부율(거부+보류) / 이월률 / 체험→등록률.

### 강습 세션 유형별 운영 KPI

PT / 필라테스 / 스트레칭 / 테라피 4종 카드 또는 누적 막대.

### 목표 달성 추이 차트

월별 KPI 달성률 추이 + 목표선 100%.

### 지점별 KPI 비교 테이블

색상 구분: 초과(초록) / 근접(노랑) / 미달(빨강).

### 매출 목표 설정 (DLG-094-001)

지점별 월 매출 목표.

## 비즈니스 규칙

1. 강습 세션 유형은 PT/필라테스/스트레칭/테라피 4종 고정. 화면 축약 표기 가능 (P.T, 필라).
2. 강습세션수는 수업/출석/일정 원장의 세션 유형별 완료 수업수로 산출하며, 외부 시트는 검산용이다.
3. GX 세부 종목은 상품 마스터 `category=GX` + `subCategory` 6종 고정.
4. 상담 채널 원천은 `[신규DB]` C열 (`WI=방문`, `TI=전화문의`, `체험`, `일일입장`).
5. 상담 방식은 `대면`/`유선`/`부재` 3종으로 제한된다.
6. TI 방문 전환율은 TI 문의 중 N/R/V열 중 하나 이상이 `대면`인 건이다.
7. 재등록 성공률 = `[재등록DB]` B열 등록 ÷ (등록+확정+예상+관리+실패).
8. OT 거부율은 `거부+보류`를 함께 집계한다 (툴팁 명시).
9. OT 이월률 분모는 우선 OT배정 인원으로 기록 (산식 추후 확정 필요).
10. OT 등록 전환율은 `등록 / OT 진행`이며 PT 완료율과 합산하지 않는다.
