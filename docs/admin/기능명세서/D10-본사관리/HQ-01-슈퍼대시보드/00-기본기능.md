## 기능 목적

슈퍼관리자 전용 화면으로, 전체 지점의 통합 KPI와 지점별 상세 현황을 한 화면에서 파악한다. 지점 전환 기능을 통해 특정 지점 관리 모드로 빠르게 진입할 수 있다. 본사 임원이 전사 운영을 한눈에 보고 의사결정할 수 있는 지휘 통제실 역할을 한다.

## 주요 구성요소

### 전사 통합 KPI 카드 (7종)

| 카드 | 표시 |
|------|------|
| 전체 회원 수 | 전월 대비 증감률 |
| 전체 매출 | 전월 대비 증감률 |
| 전체 출석 수 | 전일 대비 증감률 |
| 전체 직원 수 | 합계 |
| 이번 달 신규 회원 | 합계 |
| 만료 예정 회원 (30일) | 카운트 |
| 만료 회원 수 | 카운트 |

### 지점별 현황 카드

각 지점마다 카드.

| 항목 | 표시 |
|------|------|
| 지점명 | 이름 |
| 활성 회원 수 | 카운트 |

| 월 매출 | 천 단위 |
| 만료 회원 수 | 카운트 |
| 오늘 출석 수 | 카운트 |
| 운영 상태 배지 | 운영 / 휴업 / 폐점 |
| 액션 | [지점 전환] / [지점 상세] |

### 최근 히스토리 로그

시스템 전체 최근 10건 주요 활동 이력.

### 상단 액션

수동 새로고침.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 통합 + 지점 카드 | 지점 전환·상세·새로고침 |
| owner / manager / fc / 트레이너 / 스태프 | 접근 불가 안내 | 본사 대시보드로 이동 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 슈퍼관리자 로그인 → 화면 진입
2. 전체 지점 데이터 자동 로드 → 스켈레톤 → 수치 전환
3. KPI 카드 + 지점별 카드 확인
4. [지점 전환] 클릭 → 해당 지점 모드 → 본사 대시보드
5. [지점 상세] → 지점 정보 페이지
6. 슈퍼관리자 외 접근 시 권한 안내

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | KPI + 지점 카드 |
| 로딩 | 스켈레톤 |
| 권한 없음 | 안내 + 본사 대시보드 이동 |
| 지점 없음 | 지점 등록 안내 |

## 비즈니스 규칙

1. 본 화면은 슈퍼관리자(`superAdmin`/`primary`) 전용이며 외 권한은 접근 차단된다.
2. 증감률은 전월(매출·회원) 또는 전일(출석) 대비 계산되며, 양수 초록 ↑ / 음수 빨강 ↓ 표시된다.
3. 지점 전환 시 모드가 변경되고 해당 지점 본사 대시보드로 이동한다.
4. 지점 카드의 운영 상태는 SCR-092 지점 관리에서 설정된 값을 따른다.
5. 데이터는 5분 캐시로 갱신되며 수동 새로고침으로 즉시 갱신 가능하다.
6. 모든 지점 전환은 감사 로그에 기록된다.
