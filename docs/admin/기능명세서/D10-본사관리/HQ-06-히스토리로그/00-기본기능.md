## 기능 목적

시스템 내에서 발생한 주요 작업 이력을 기록하고 조회하는 화면이다. 누가, 언제, 무엇을 했는지 추적하여 보안 감사, 문제 발생 시 원인 파악, 운영 투명성 확보에 활용한다. 시스템 전반의 모든 변경 이력이 모이는 중앙 감사 추적 도구.

## 주요 구성요소

### 로그 목록

| 컬럼 | 설명 |
|------|------|
| 작업 일시 | YYYY-MM-DD HH:mm:ss |
| 작업자 | 이름·계정 |
| 지점명 | 소속 지점 |
| 작업 유형 | 분류 |
| 작업 대상 | 회원/직원/결제 등 |
| 작업 상세 | 변경 전·후 값 |
| 액션 | [상세] / [펼침] |

### 작업 유형 분류

| 유형 | 예시 |
|------|------|
| 로그인 | 로그인/로그아웃/잠금 |
| 회원 관리 | 등록/수정/탈퇴 |
| 결제 | 결제/환불/취소 |
| 설정 변경 | 권한/알림/IoT |
| 권한 변경 | 역할 부여/회수 |
| 데이터 삭제 | 삭제/복원 |
| 일괄 작업 | 일괄 처리 |
| API 호출 | 외부 시스템 |

### 검색 및 필터

| 항목 | 입력 |
|------|------|
| 작업자 | 이름/계정 |
| 지점 | 드롭다운 |
| 작업 유형 | 다중 선택 |
| 조회 기간 | 날짜 범위 |

### 행 클릭 → 상세

작업 상세 내용 (변경 전·후 값) 펼침 또는 상세 패널.

### 내보내기

엑셀 다운로드 (현재 필터 기준).

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 로그 | 필터·내보내기 |
| owner (센터장) | 소속 지점 로그 | 필터·내보내기 |
| manager 이하 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "본사관리 > 히스토리 로그" 진입
2. 최근 7일 로그 자동 표시
3. 필터 변경 → 로그 갱신
4. 행 클릭 → 변경 전·후 상세
5. [엑셀 다운로드] → 현재 필터 데이터

## 비즈니스 규칙

1. 모든 시스템 액션(회원/결제/설정/권한/삭제 등)은 자동으로 감사 로그에 기록된다.
2. 로그는 append-only로 변경 불가하며 영구 보관된다.
3. 감사 로그 내보내기는 슈퍼관리자/센터장만 가능하며 별도 감사 로그에 기록된다 (메타 감사).
4. 작업 상세에는 변경 전·후 값이 모두 기록되어 복구 참고에 활용된다.
5. IP·디바이스 정보가 함께 기록되어 보안 분석에 사용된다.
6. 매니저 이하는 감사 로그 접근이 차단된다 (보안 정책).
7. 민감 데이터(비밀번호 등)는 마스킹 처리되어 기록된다.
