## 기능 목적

시스템 내에서 발생한 주요 작업 이력을 기록하고 조회하는 화면이다. 누가, 언제, 무엇을 했는지 추적하여 보안 감사, 문제 발생 시 원인 파악, 운영 투명성 확보에 활용한다. 시스템 전반의 모든 변경 이력이 모이는 중앙 감사 추적 도구.

운영 맥락:
- **본사 superAdmin 보안 감사**: 특정 기간·사용자 필터 → 권한 변경·데이터 삭제 이력 확인 → 이상 패턴 감지
- **owner(센터장) 직원 업무 추적**: 소속 지점 필터 → 직원별 결제·회원 수정 이력 조회 → 책임 소재 파악
- **문제 발생 시 원인 추적**: 결제 오류 신고 시 → 해당 회원 + 기간 필터 → 변경 전·후 값 확인 → 복구 참고
- **권한 변경 감사**: 역할 부여·회수 이력 조회 → 불법 권한 상승 감지
- **민감 액션 필수 추적**: 데이터 삭제·일괄 처리·API 호출은 민감 액션으로 분류, 반드시 로그 기록
- **규정 준수 자료 제출**: CSV 내보내기 → 외부 감사 기관 제출용 자료 생성
- **개인정보 처리 내역 확인**: 90일 경과 로그 익명화 처리 여부 확인 + 5년 보관 정책 준수 점검

| 2 | owner(센터장) | 직원 결제 오류 신고 | 지점 필터 + 작업자 검색 + "결제" 유형 + 기간 필터 | 결제 변경 전·후 값 확인 → 오류 원인 파악 |
| 3 | 본사 superAdmin | 데이터 삭제 감사 | "데이터 삭제" 유형 필터 → 최근 30일 | 삭제 대상·삭제자·IP 확인 → 승인 여부 검토 |
| 4 | 본사 superAdmin | 외부 감사 자료 준비 | 기간 필터 설정 → CSV 내보내기 | 감사 기관 제출용 CSV 생성 |

| 8 | owner(센터장) | 로그인 이상 의심 | 특정 직원 + "로그인" 유형 + 기간 필터 | 로그인/로그아웃/잠금 이력 확인 → 이상 접근 식별 |
| 9 | 본사 superAdmin | 일괄 처리 후 점검 | "일괄 작업" 유형 필터 | 일괄 처리 대상·처리자·결과 확인 |
| 10 | 본사 superAdmin | 5년 보관 정책 점검 | 오래된 기간 조회 → 보관 여부 확인 | 5년 이내 데이터 정상 보관 확인 |

## 주요 구성요소

| 컬럼 | 설명 |

| 유형 | 예시 |

| 항목 | 입력 |
|------|------|

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 로그 | 필터·내보내기 |
| owner (센터장) | 소속 지점 로그 | 필터·내보내기 |
| manager 이하 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 비즈니스 규칙

1. 모든 시스템 액션(회원/결제/설정/권한/삭제 등)은 자동으로 감사 로그에 기록된다.
2. 로그는 append-only로 변경·삭제 불가이며 DB 트리거로 변조 차단한다.
3. 감사 로그 내보내기는 슈퍼관리자/센터장만 가능하며 내보내기 행위 자체도 별도 감사 로그에 기록된다 (메타 감사).
4. 작업 상세에는 변경 전·후 값이 모두 기록되어 복구 참고에 활용된다.
5. IP·디바이스 정보가 함께 기록되어 보안 분석에 사용된다.
6. 매니저 이하는 감사 로그 접근이 차단된다 (보안 정책).
7. 민감 데이터(비밀번호·카드번호 등)는 기록 시점에 자동 마스킹 처리되어 저장된다 (복호화 불가).
8. 로그 보관 기간은 5년이며 5년 경과 데이터는 별도 아카이브 스토리지로 이관 후 운영 DB에서 삭제한다.
9. 등록 후 90일 경과 로그는 개인정보 보호 정책에 따라 작업자 이름·계정을 익명화 처리한다.
10. 페이지네이션 단위는 20건/페이지 고정이다.
11. 민감 액션(데이터 삭제·권한 변경·일괄 처리·API 호출)은 필수 로그 대상으로 기록 누락 시 시스템 알림을 발송한다.
12. CSV 내보내기는 현재 필터 기준 전체 데이터를 포함하며 페이지 단위가 아니다.
13. 로그 목록 기본 정렬은 작업 일시 내림차순(최신 순)이다.
14. 작업 유형 다중 필터 선택 시 OR 조건으로 검색한다.
15. 10만건 초과 CSV 내보내기는 비동기 생성 후 이메일로 다운로드 링크를 발송한다.
16. 감사 로그 자체의 조회·내보내기 행위도 감사 로그에 기록된다 (재귀 감사 1depth).
17. IP 기록은 요청 헤더 X-Forwarded-For 기준이며 프록시 환경을 고려한다.
18. 로그 상세 패널에는 변경 전·후 값, IP, 디바이스, 세션 ID가 표시된다.
