## 기능 목적

회원 대상 NPS(순추천지수) 설문 결과를 조회하고 분석하는 화면이다. 회원 만족도 추이를 파악하고, 부정적 피드백을 빠르게 식별하여 서비스 개선에 활용한다. 설문 발송 주기·대상도 본 화면에서 관리한다.

운영 맥락:
- **월간 만족도 추이 모니터링**: 본사 CX팀이 매월 초 전월 NPS 점수·추이를 확인하여 서비스 개선 우선순위를 설정한다.
- **비추천자 즉각 후속 대응**: 0~6점 비추천 응답이 접수되면 담당 FC에게 자동 알림이 발송되고, 24시간 내 개인 연락을 통해 불만을 해소한다.
- **지점별 NPS 격차 분석**: superAdmin이 지점별 NPS를 비교하여 하위 지점을 식별하고, 서비스 교육 대상 지점을 선별한다.
- **세그먼트별 NPS 심화 분석**: 이용권 종류·가입 기간·연령대별 NPS를 분리 집계하여 특정 세그먼트의 불만 원인을 파악한다.
- **키워드 기반 개선 과제 도출**: 자유 의견 키워드 클라우드에서 반복 등장하는 부정 키워드(예: "락커", "청결")를 클릭하여 관련 응답을 일괄 검토한다.
- **발송 채널 최적화**: SMS·카카오·앱푸시 채널별 응답률을 비교하여 응답률이 높은 채널로 발송 설정을 조정한다.
- **익명 응답 정책 준수**: 응답자 식별 정보는 운영 권한자(owner 이상)에게만 노출되며, FC·매니저는 점수·의견만 확인한다.

## 주요 구성요소

### NPS 요약 카드

| 항목 | 표시 |
|------|------|
| 전체 NPS 점수 | -100 ~ +100 |
| 응답자 분류 비율 | 추천자 / 중립자 / 비추천자 |
| 전기간 대비 변화 | NPS 점수 증감 |

### NPS 추이 차트

| 영역 | 표시 |
|------|------|
| NPS 점수 변화 | 기간별 선 차트 |
| 응답자 수 추이 | 기간별 응답 수 |

### 응답 분포

| 영역 | 표시 |
|------|------|
| 점수별 응답 수 | 0~10 막대 차트 |
| 지점별 NPS 비교 | 지점별 점수 테이블 |

### 응답 목록

| 컬럼 | 표시 |
|------|------|
| 점수 | 0~10 |
| 응답일 | YYYY-MM-DD |
| 자유 의견 | 텍스트 |
| 회원 정보 | 회원명/연락처 |

| 필터 | 옵션 |
|------|------|
| 점수 범위 | 추천자(9~10) / 중립(7~8) / 비추천(0~6) |
| 키워드 | 자유 의견 키워드 클라우드 클릭 필터 |

### 자유 의견 키워드 분석

자주 등장하는 키워드 태그 클라우드 → 클릭 시 해당 키워드 포함 응답만 필터링.

### 설문 발송 관리

| 항목 | 입력/선택 |
|------|------|
| 발송 주기 | 월 1회 / 분기 1회 |
| 발송 대상 | 활성 회원 전체 / 특정 이용권 보유 회원 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |

## 분기·예외 흐름

- **선택 기간 내 응답 없음**: "선택한 기간에 응답이 없습니다" 안내, 차트·목록 영역 빈 상태 표시.
- **설문 발송 이력 없음**: "발송 이력이 없습니다. 설문을 설정하고 발송해보세요" CTA 안내.
- **즉시 발송 확인 다이얼로그**: [즉시 발송] 클릭 → "N명에게 즉시 발송됩니다. 계속하시겠습니까?" 확인 → 확정 시 발송.
- **발송 대상 0명**: "발송 대상 회원이 없습니다. 발송 조건을 확인해주세요" 발송 차단.
- **엑셀 다운로드 시 필터와 무관하게 전체 응답 포함**: 다운로드 전 "선택 기간 전체 응답이 다운로드됩니다" 안내 팝업.
- **낮은 점수(0~3) 응답 접수 시 자동 알림**: 담당 owner·FC에게 즉시 인앱 알림 발송. 알림 발송 실패 시 재시도 3회.
- **키워드 클라우드 데이터 부족(자유 의견 10건 미만)**: "키워드 분석에 필요한 응답이 부족합니다" 안내, 클라우드 미노출.
- **지점별 NPS 비교 시 특정 지점 응답 0건**: 해당 지점 "-" 표시, 전체 평균 산출에서 제외.
- **발송 주기 변경 저장 후 기존 스케줄 충돌**: "기존 발송 스케줄이 새 주기로 교체됩니다" 확인 다이얼로그.
- **센터장이 타 지점 응답 접근 시도**: RLS 차단, 소속 지점 응답만 노출.
- **매니저 이하 접근**: 403 화면.
- **응답자 식별 정보 FC 노출 시도**: 점수·의견만 표시, 회원명·연락처 숨김(권한 레벨 미달).

## 주요 UX 흐름

**NPS 결과 조회**
1. 사이드바 → "본사관리 > NPS 설문" 진입
2. 최근 분기 기준 NPS 결과 자동 로드
3. 요약 카드·추이 차트·응답 분포 확인

**기간/필터 변경**
1. 기간 필터 변경 → NPS 점수·차트 자동 갱신
2. 비추천자 필터 → 비추천 응답만 표시 → 빠른 대응

**키워드 기반 분석**
1. 자유 의견 키워드 클라우드에서 키워드 클릭
2. 해당 키워드 포함 응답 목록 필터링
3. 회원 상세 연계 케어

**설문 발송 설정**
1. 발송 관리 패널 → 주기·대상 설정
2. 저장 → 자동 발송 스케줄 적용

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | NPS 요약 + 추이 + 응답 목록 표시 |
| 로딩 | 데이터 불러오는 중 (스켈레톤) |
| 응답 없음 | 선택 기간에 응답 없음 안내 |
| 설문 미발송 | 발송 이력 없음 → 설문 설정 안내 CTA |
| 권한 부족 | 매니저 이하 접근 차단 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다. 403 처리.
2. **NPS 점수 공식**: (추천자 비율 - 비추천자 비율) × 100. 범위 -100 ~ +100. 시스템 자동 산출.
3. **점수 분류 고정**: 추천자(9~10) / 중립(7~8) / 비추천(0~6). 변경 불가.
4. **익명 응답 정책**: 응답자 회원명·연락처는 owner 이상 권한에서만 노출. FC·매니저는 점수·의견만 확인 가능.
5. **키워드 분석 조건**: 자유 의견 응답 10건 이상 시 키워드 클라우드 활성화. 미만 시 "응답 부족" 안내.
6. **키워드 추출 방식**: 형태소 분석 + 빈도 기반. 불용어(은/는/이/가 등) 자동 제거.
7. **발송 주기**: 월 1회 / 분기 1회 선택. 발송 시점은 설정일 기준 다음 주기 시작일 자정.
8. **발송 채널**: SMS / 카카오 / 앱푸시 중 선택. 채널별 응답률 통계 제공.
9. **즉시 발송**: 스케줄 외 즉시 발송 가능. 확인 다이얼로그 필수. 발송 대상 0명 시 차단.
10. **발송 대상**: 활성 회원 전체 / 특정 이용권 보유 회원 중 선택. 발송 전 대상 수 미리보기 제공.
11. **낮은 점수 자동 알림**: 0~3점 응답 접수 시 담당 owner·FC에게 즉시 인앱 알림. 알림 실패 시 재시도 3회.
12. **세그먼트별 NPS**: 이용권 종류·가입 기간·연령대 필터 적용 시 해당 세그먼트 NPS 독립 산출.
13. **지점별 NPS 비교**: 응답 0건 지점은 "-" 표시, 전체 평균 산출 제외.
14. **엑셀 다운로드**: 현재 필터와 무관하게 선택 기간 전체 응답 다운로드. 다운로드 전 안내 팝업 필수.
15. **발송 스케줄 충돌**: 주기 변경 시 기존 스케줄 교체 확인 다이얼로그.
16. **후속 조치 등록**: 비추천 응답에 담당자가 후속 조치 내용을 텍스트로 기록 가능. 기록 후 "처리 완료" 배지 표시.
17. **감사 로그**: 설문 발송·설정 변경·후속 조치 등록 SCR-097 기록. `actor_id`, `branch_id`, `action`, `target_count` 저장.
18. **PDF 내보내기**: 요약 카드·추이 차트·지점별 비교·키워드 클라우드 포함. 헤더에 기간·생성자·생성일 자동 삽입.
19. **응답 보존 기간**: 응답 데이터는 3년 보존. 이후 자동 익명화 처리.
20. **중복 응답 방지**: 동일 회원이 동일 발송 건에 중복 응답 불가. 최초 응답만 유효.
