## 기능 목적

회원 대상 NPS(순추천지수) 설문 결과를 조회하고 분석하는 화면이다. 회원 만족도 추이를 파악하고, 부정적 피드백을 빠르게 식별하여 서비스 개선에 활용한다. 설문 발송 주기·대상도 본 화면에서 관리한다.

## 주요 구성요소

### NPS 요약 카드

| 항목 | 표시 |
|------|------|
| 전체 NPS 점수 | -100 ~ +100 |
| 응답자 분류 비율 | 추천자 / 중립자 / 비추천자 |
| 전기간 대비 변화 | NPS 점수 증감 |

### NPS 추이 차트

| 영역 | 표시 |
|------|------|
| NPS 점수 변화 | 기간별 선 차트 |
| 응답자 수 추이 | 기간별 응답 수 |

### 응답 분포

| 영역 | 표시 |
|------|------|
| 점수별 응답 수 | 0~10 막대 차트 |
| 지점별 NPS 비교 | 지점별 점수 테이블 |

### 응답 목록

| 컬럼 | 표시 |
|------|------|
| 점수 | 0~10 |
| 응답일 | YYYY-MM-DD |
| 자유 의견 | 텍스트 |
| 회원 정보 | 회원명/연락처 |

| 필터 | 옵션 |
|------|------|
| 점수 범위 | 추천자(9~10) / 중립(7~8) / 비추천(0~6) |
| 키워드 | 자유 의견 키워드 클라우드 클릭 필터 |

### 자유 의견 키워드 분석

자주 등장하는 키워드 태그 클라우드 → 클릭 시 해당 키워드 포함 응답만 필터링.

### 설문 발송 관리

| 항목 | 입력/선택 |
|------|------|
| 발송 주기 | 월 1회 / 분기 1회 |
| 발송 대상 | 활성 회원 전체 / 특정 이용권 보유 회원 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 NPS 통합 + 지점별 비교 | 설문 발송 설정·내보내기 |
| owner (센터장) | 소속 지점 NPS 결과 | 설문 발송 설정 |

## 주요 UX 흐름

**NPS 결과 조회**
1. 사이드바 → "본사관리 > NPS 설문" 진입
2. 최근 분기 기준 NPS 결과 자동 로드
3. 요약 카드·추이 차트·응답 분포 확인

**기간/필터 변경**
1. 기간 필터 변경 → NPS 점수·차트 자동 갱신
2. 비추천자 필터 → 비추천 응답만 표시 → 빠른 대응

**키워드 기반 분석**
1. 자유 의견 키워드 클라우드에서 키워드 클릭
2. 해당 키워드 포함 응답 목록 필터링
3. 회원 상세 연계 케어

**설문 발송 설정**
1. 발송 관리 패널 → 주기·대상 설정
2. 저장 → 자동 발송 스케줄 적용

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | NPS 요약 + 추이 + 응답 목록 표시 |
| 로딩 | 데이터 불러오는 중 (스켈레톤) |
| 응답 없음 | 선택 기간에 응답 없음 안내 |
| 설문 미발송 | 발송 이력 없음 → 설문 설정 안내 CTA |
| 권한 부족 | 매니저 이하 접근 차단 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. NPS 점수는 (추천자 비율 - 비추천자 비율) × 100 공식으로 자동 산출된다.
3. 점수 분류는 추천자(9~10) / 중립(7~8) / 비추천(0~6) 기준으로 고정된다.
4. 센터장은 본인 소속 지점(`branchId`) 응답 결과만 조회·관리할 수 있다.
5. 자유 의견 키워드 분석은 형태소·빈도 기반으로 자동 추출된다.
6. 설문 발송 주기와 발송 대상은 지점 단위로 설정 가능하며, 발송 시점은 시스템 스케줄러에 의해 자동 처리된다.
7. 설문 응답·발송·설정 변경은 감사 로그(SCR-097)에 기록된다.
8. 응답 데이터 엑셀 다운로드는 현재 필터 조건과 무관하게 선택 기간 전체 응답을 내려받는다.
