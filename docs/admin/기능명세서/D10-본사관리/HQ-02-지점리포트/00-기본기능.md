## 기능 목적

지점별 매출, 회원, 수업 성과를 비교 분석하는 리포트 화면이다. 지점 간 성과 차이를 시각적으로 파악하고, 기간별 추이를 확인하여 운영 전략 수립에 활용한다. 엑셀·PDF 내보내기로 본사 임원 보고 자료를 즉시 생성할 수 있다.

## 주요 구성요소

### 필터 및 기간 선택

| 항목 | 옵션 |
|------|------|
| 조회 기간 | 주간/월간/분기/연간/직접 입력 |
| 지점 선택 | 전체 / 특정 지점 복수 |
| 비교 기준 | 전기간 대비 / 지점 간 비교 |

### 매출 성과 섹션

- 지점별 총 매출 비교 차트 (막대)
- 지점별 매출 순위 테이블
- 목표 달성률 표시

### 회원 성과 섹션

- 지점별 신규/활성/이탈 회원 비교
- 회원 유지율 차트

### 수업 성과 섹션

- 지점별 수업 운영 횟수 / 예약율 / 출석율 비교
- 인기 수업 유형 분석

### 내보내기

- 엑셀 다운로드
- PDF 다운로드

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 성과 | 필터·내보내기 |
| owner (센터장) | 소속 지점 데이터 | 기간 필터·내보내기 |
| manager 이하 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "본사관리 > 지점 리포트" 진입
2. 당월 전체 지점 성과 자동 로드
3. 기간/지점 필터 변경 → 차트·테이블 갱신
4. 매출/회원/수업 섹션별 비교
5. [엑셀] 또는 [PDF] 다운로드 → 현재 필터 데이터

## 비즈니스 규칙

1. 매출 집계 기준은 매출관리.md를 따른다 (담당자별 / 지점별 / 본사 통합).
2. 회원 유지율 = 기간 종료 시점 활성 회원 / 기간 시작 시점 회원 × 100.
3. 출석율 = 출석 / 예약 × 100, 노쇼는 출석에서 제외한다.
4. 목표 달성률은 SCR-S011 매출 예측에서 설정한 목표를 사용한다.
5. 센터장은 소속 지점만 조회 가능하며 타 지점 비교는 슈퍼관리자만 가능하다.
6. 엑셀·PDF 다운로드는 현재 필터 조건이 그대로 반영된다.
7. 다운로드는 감사 로그에 기록된다.
