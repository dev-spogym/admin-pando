## 기능 목적

원하는 기간과 항목을 선택하여 운영 보고서를 생성하고 엑셀 또는 PDF로 내보내는 화면이다. 정기 보고, 경영진 보고, 고객 제출용 등 다양한 목적의 리포트를 맞춤 생성하며, 상담 전환 분석 옵션을 활성화하면 KPI 퍼널(SCR-094)과 연계된 리드→상담→등록 단계별 전환 데이터까지 포함된다.

운영 맥락:
- **본사 임원 월간 보고**: 매월 종합 리포트 자동 생성 → PDF 다운로드 → 임원 이메일 발송
- **센터장 분기 성과 보고**: 분기 매출·회원 현황 리포트 → 본사 제출용 PDF 생성
- **연간 KPI 결산**: 연간 종합 리포트 → 작년 대비 비교 포함 → 경영진 한 페이지 임원 보고용
- **외부 감사 자료 제출**: 특정 기간 매출·결제 리포트 → CSV 생성 → 외부 제출
- **상담 전환 분석 포함 보고**: 상담 전환 분석 옵션 활성화 → KPI 퍼널 데이터 포함 → 마케팅 채널 효율 보고
- **과거 리포트 재다운로드**: 생성 이력에서 이전 리포트 재다운로드 → 동일 권한 범위 내
- **수동 생성 + 자동 생성 병행**: 월/분기/연간 정기 자동 생성 + 필요 시 수동 생성

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 리포트 | 모든 유형 생성·내보내기·이력 조회 |
| owner (센터장) | 소속 지점 리포트 | 소속 지점 데이터 한정 생성·내보내기 |
| manager | 접근 불가 | — |
| fc / 트레이너 / 스태프 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**리포트 생성**
1. 사이드바 → "본사관리 > 리포트" 진입
2. 리포트 유형·기간·지점·포함 항목 선택
3. (선택) 상담 전환 분석 체크
4. [리포트 생성] → 생성 처리 표시 → 미리보기 표시

**내보내기**
1. 미리보기 확인
2. [엑셀] / [PDF] / [인쇄] 중 선택
3. 다운로드 처리 표시 → 완료 토스트

**과거 리포트 재조회**
1. 생성 이력 목록 확인
2. [다운로드] 클릭 → 파일 재다운로드

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. 센터장은 본인 소속 지점(`branchId`) 데이터로만 리포트를 생성할 수 있다.
3. 엑셀 다운로드는 현재 미리보기 페이지와 무관하게 선택 조건 전체 데이터를 내려받는다.
4. 상담 전환 분석 옵션 활성 시 KPI 센터(HQ-03) 퍼널 데이터를 출처로 사용한다.
5. 생성된 리포트는 일정 기간 생성 이력에 보관되며 동일 권한 범위 내에서 재다운로드 가능하다.
6. 리포트 생성·다운로드는 감사 로그(SCR-097)에 기록된다.
7. PDF·인쇄 출력 시 헤더에 지점명·기간·생성 일시·생성자가 자동 삽입된다.
8. 월간 리포트는 매월 1일 00:00에 전월 데이터 기준으로 자동 생성된다.
9. 분기 리포트는 분기 종료 익일 00:00에 자동 생성된다.
10. 연간 리포트는 매년 1월 1일 00:00에 전년도 기준으로 자동 생성된다.
11. 자동 생성 리포트는 superAdmin 및 해당 지점 owner에게 이메일로 자동 발송된다.
12. 임원 보고용 한 페이지 요약은 "종합" 유형 + 연간/분기 기간 선택 시 옵션으로 제공된다.
13. 작년 동기 대비 비교는 매출·회원·출석 3종 지표에 적용된다.
14. 리포트 생성 이력 보관 기간은 1년이며 1년 경과 이력은 자동 삭제된다.
15. 일일 다운로드 한도는 계정당 50건으로 제한한다 (보안 정책).
16. 수동 생성 리포트와 자동 생성 리포트는 이력에서 구분 표시된다 ("수동"/"자동" 배지).
17. 상담 전환 분석 옵션은 "종합" 유형에서만 활성화 가능하다.
18. 다중 지점 선택 시 리포트 내 지점별 비교 섹션이 자동 추가된다.
19. PDF 헤더 자동 삽입 항목: 지점명·조회 기간·생성 일시·생성자명·리포트 유형.
20. 리포트 생성 소요 시간이 30초 초과 시 비동기 처리로 자동 전환된다.
21. CSV 내보내기는 엑셀과 동일 데이터 소스이며 헤더 행이 포함된다.
