## 기능 목적

유사한 규모·업종의 다른 센터와 자사 지점의 KPI를 익명으로 비교 분석하는 화면이다. 업계 평균·상위 25% 대비 우리 센터의 위치를 파악하여 강점/개선 여지를 도출하고 경쟁력 강화 전략 수립에 활용한다.

운영 맥락:
- **분기 전략 회의 벤치마크 보고**: 본사 전략팀이 분기별 매출·회원 유지율을 동급 규모 센터 대비 분석하여 임원 보고서에 활용한다.
- **신규 지점 경쟁력 진단**: 신규 오픈 6개월 차 센터장이 동급 규모 센터 평균 대비 출석률·신규 회원 수를 확인하여 초기 운영 전략을 보정한다.
- **상위 25% 진입 목표 설정**: 현재 상위 40% 지점이 상위 25% 기준치를 목표로 삼아 개선 액션 플랜을 수립한다.
- **익명 비교로 경쟁사 노출 방지**: 비교 대상 센터의 식별 정보를 공개하지 않으면서도 객관적 수치 비교를 제공한다.
- **전월 대비 추이 검토**: 이번 달 벤치마크 결과와 전월 결과를 나란히 확인하여 개선 여부를 추적한다.
- **데이터 부족 시 비교 보류**: 동급 그룹 샘플이 임계치 미만이면 결과를 노출하지 않아 통계적 신뢰성을 보호한다.
- **PDF 보고서 배포**: 분석 결과를 PDF로 내보내어 본사·지점 간 공유 및 외부 보고에 활용한다.

## 운영 시나리오 (페르소나 × 트리거 × 결과)

| 페르소나 | 사용 맥락 | 행동 | 기대 결과 |
|---|---|---|---|
| 본사 전략팀 | 분기 임원 보고 준비 | 규모·업종·지표(매출·유지율) 선택 → 분기 기준 분석 실행 → PDF 내보내기 | 업계 대비 백분위 + 강점/개선 항목 담긴 보고서 생성 |

| 본사 운영팀 | 전월 대비 개선 추이 추적 | 이번 달 분석 결과 + 전월 결과 나란히 비교 | 개선 여부 시각적 확인, 지속 모니터링 |
| 센터장 | 익명 비교 신뢰성 확인 | 비교 대상 센터 익명 처리 여부 확인 | 식별 정보 미노출 확인, 경쟁사 정보 보호 |

## 분기·예외 흐름

- **비교 샘플 부족(동급 센터 임계치 미만)**: 분석 실행 시 차트 미노출, "비교 가능한 동일 규모·업종 센터 데이터가 부족합니다. 비교 기준을 완화해보세요" 안내.
- **지표 미선택 상태에서 분석 실행**: "비교 지표를 1개 이상 선택해주세요" 인라인 오류, 분석 차단.
- **센터장이 타 지점 데이터 조회 시도**: RLS로 소속 지점 데이터만 노출. 비교 기준점은 본인 지점으로 고정.
- **분석 실행 중 타임아웃(30초 초과)**: "데이터 수집에 시간이 걸리고 있습니다. 잠시 후 다시 시도해주세요" 안내 + 재시도 버튼.
- **PDF 내보내기 실패**: 토스트 "PDF 생성에 실패했습니다. 다시 시도해주세요".
- **전월 대비 데이터 없음**: 전월 비교 컬럼 "데이터 없음" 표시, 현재 결과는 정상 표시.
- **익명 모드 위반 시도(직접 API 호출 등)**: 서버 측에서 센터 식별자 제거 처리. 화면 레벨 추가 차단 불필요.
- **매니저 이하 접근 시도**: 403 화면 노출.
- **분석 결과 0개 지표 선택**: 지표 선택 후 분석 가능 안내.
- **PDF 헤더 자동 삽입 누락 방지**: 비교 기준·기간·생성 일시·생성자 미포함 시 PDF 생성 차단.

## 주요 UX 흐름

**벤치마크 분석 실행**
1. 사이드바 → "본사관리 > 벤치마크 비교" 진입
2. 센터 규모·업종·지표·기간 선택
3. [분석 실행] → 데이터 수집 처리 표시
4. 차트 + 인사이트 요약 표시

**인사이트 검토**
1. 강점 지표 / 개선 필요 지표 확인
2. 권장 액션 아이템 검토
3. 필요 시 [PDF 다운로드]

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다. 403 처리.
2. **익명 처리 정책**: 비교 데이터는 서버 측에서 센터 식별자(이름·주소·사업자번호)를 제거한 후 제공한다. 화면에 타 센터 명칭 미노출.
3. **동급 그룹화 기준**: 규모(소/중/대 = 회원 수 기준)와 업종(헬스/필라테스/PT샵 등)을 조합한 풀(pool)로 그룹화한다.
4. **샘플 임계치**: 동급 그룹 내 비교 가능 센터 수가 5개 미만이면 결과를 노출하지 않는다. 안내 메시지와 함께 기준 완화 권고.
5. **백분위 산출**: 선택된 규모·업종 풀 내에서 산출. 풀 외 센터는 제외된다.
6. **상위 25% 기준선**: 풀 내 상위 사분위(Q3) 값으로 자동 계산. 지표별 독립 산출.
7. **전월 대비 표시**: 동일 조건으로 전월 분석이 존재하면 증감 화살표·수치 표시. 전월 데이터 없으면 "-" 표시.
8. **센터장 지점 고정**: 센터장은 본인 소속 지점(`branchId`)을 기준점으로만 비교 가능. 타 지점 데이터 RLS 차단.
9. **superAdmin 복수 지점 비교**: superAdmin은 복수 지점을 선택하여 지점별 결과를 나란히 비교 가능.
10. **PDF 헤더 자동 삽입**: 비교 기준(규모·업종·지표)·기간·생성 일시·생성자 미포함 시 PDF 생성 차단.
11. **분석 결과 캐시**: 동일 조건(규모·업종·지표·기간) 재실행 시 1시간 내 캐시 결과 반환. 강제 새로고침 옵션 제공.
12. **개선 여지 하이라이트 기준**: 업계 평균 대비 20% 이상 미달 지표를 자동으로 하이라이트 처리.
13. **액션 아이템 자동 제안**: 하이라이트된 지표에 대해 시스템 정의 액션 아이템(텍스트)을 자동 노출. 커스텀 편집 불가.
14. **분석 실행 타임아웃**: 30초 초과 시 타임아웃 안내 + 재시도 버튼.
15. **감사 로그**: 분석 실행·PDF 내보내기 모두 SCR-097에 기록. `actor_id`, `branch_id`, `criteria`, `executed_at` 저장.
16. **데이터 갱신 주기**: 벤치마크 풀 데이터는 매월 1일 03:00 배치로 갱신. 실시간 갱신 미지원.
17. **지표 다중 선택**: 비교 지표는 최대 6개까지 동시 선택 가능. 초과 시 추가 선택 차단.
18. **결과 유효 기간 표시**: 결과 화면 상단에 "데이터 기준일: YYYY-MM-DD" 표시.

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `HQ-11`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-H1003`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
