## 기능 목적

유사한 규모·업종의 다른 센터와 자사 지점의 KPI를 익명으로 비교 분석하는 화면이다. 업계 평균·상위 25% 대비 우리 센터의 위치를 파악하여 강점/개선 여지를 도출하고 경쟁력 강화 전략 수립에 활용한다.

## 주요 구성요소

### 비교 기준 설정

| 항목 | 입력/선택 |
|------|------|
| 비교 대상 센터 규모 | 회원 수 기준 소 / 중 / 대 |
| 비교 대상 업종 | 헬스 / 필라테스 / PT샵 등 |
| 비교 지표 | 매출 / 회원 유지율 / 출석율 / 신규 회원 등 |
| 기간 | 월간 / 분기 / 연간 |
| 분석 실행 | 버튼 |

### 벤치마크 차트

| 영역 | 표시 |
|------|------|
| 비교 막대 차트 | 우리 지점 vs 업계 평균 vs 상위 25% |
| 백분위 표시 | 지표별 우리 지점 위치 (예: "상위 35%") |
| 강조 표시 | 개선 여지가 큰 지표 하이라이트 |

### 인사이트 요약

| 항목 | 표시 |
|------|------|
| 강점 지표 | 업계 평균 대비 우수 항목 목록 |
| 개선 필요 지표 | 업계 평균 대비 미달 항목 목록 |
| 액션 아이템 | 개선을 위한 권장 액션 제안 |

### 내보내기

| 버튼 | 동작 |
|------|------|
| PDF 다운로드 | 결과 PDF 저장 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 벤치마크 비교 | 비교 기준 설정·내보내기 |
| owner (센터장) | 소속 지점 벤치마크 | 비교 기준 설정 |
| manager | 접근 불가 | — |
| fc / 트레이너 / 스태프 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**벤치마크 분석 실행**
1. 사이드바 → "본사관리 > 벤치마크 비교" 진입
2. 센터 규모·업종·지표·기간 선택
3. [분석 실행] → 데이터 수집 처리 표시
4. 차트 + 인사이트 요약 표시

**인사이트 검토**
1. 강점 지표 / 개선 필요 지표 확인
2. 권장 액션 아이템 검토
3. 필요 시 [PDF 다운로드]

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 | 비교 기준 설정 패널 표시, 차트 비어있음 |
| 로딩 | 벤치마크 데이터 수집 중 (처리 표시) |
| 결과 표시 | 차트 및 인사이트 표시 |
| 데이터 부족 | 비교 가능한 동일 규모 센터 데이터 부족 안내 |
| 권한 부족 | 매니저 이하 접근 차단 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. 비교 데이터는 익명 처리되어 다른 센터의 식별 정보는 공개되지 않는다.
3. 비교 가능한 동일 규모·업종 센터가 일정 수 미만일 경우 결과를 표시하지 않고 데이터 부족 안내를 제공한다.
4. 센터장은 본인 소속 지점(`branchId`) 데이터를 기준으로만 비교가 가능하다.
5. 백분위와 상위 25% 기준은 선택된 규모·업종 풀(pool) 내에서 산출된다.
6. PDF 내보내기 시 비교 기준·기간·생성 일시·생성자가 헤더에 자동 삽입된다.
7. 분석 실행 및 PDF 내보내기는 감사 로그(SCR-097)에 기록된다.
