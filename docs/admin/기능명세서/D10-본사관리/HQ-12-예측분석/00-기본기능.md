## 기능 목적

AI 기반 분석을 활용하여 향후 매출·신규 회원·이탈·출석율 등을 예측하는 화면이다. 과거 데이터 패턴을 학습하여 미래 운영 계획 수립과 선제적 대응(이탈 위험 회원 케어 등)에 활용한다.

## 주요 구성요소

### 예측 항목 선택

| 항목 | 입력/선택 |
|------|------|
| 예측 지표 | 매출 / 신규 회원 수 / 이탈 회원 수 / 출석율 |
| 예측 기간 | 향후 1개월 / 3개월 / 6개월 / 12개월 |
| 대상 지점 | 단일/복수 지점 선택 |
| 예측 실행 | 버튼 |

### 예측 결과 차트

| 영역 | 표시 |
|------|------|
| 통합 선 차트 | 과거 실적 + 예측 값 (예측 구간은 점선·밴드) |
| 신뢰 구간 | 낙관 / 기본 / 보수 시나리오 밴드 |
| 학습 데이터 기간 | 예측 근거 데이터 기간 안내 |
| 툴팁 | 시점 마우스 오버 시 예측 수치·신뢰 구간 |

### 예측 인사이트

| 항목 | 표시 |
|------|------|
| 예측 근거 요인 | 계절성 / 최근 추이 / 이벤트 영향 등 |
| 이탈 위험 회원 목록 | 회원 이름 + 이탈 위험도 수치 |
| 권장 대응 액션 | 회원 케어·마케팅 등 액션 제안 |

### 시나리오 비교

| 시나리오 | 표시 |
|------|------|
| 낙관 | 예측 수치 |
| 기본 | 예측 수치 |
| 보수 | 예측 수치 |

## 주요 UX 흐름

**예측 실행**
1. 사이드바 → "본사관리 > 예측 분석" 진입
2. 예측 지표·기간·지점 선택
3. [예측 실행] → AI 처리 표시 (예상 처리 시간 안내)
4. 결과 차트 + 인사이트 + 시나리오 표시

**결과 분석**
1. 차트 마우스 오버 → 시점별 예측 수치·신뢰 구간 툴팁
2. 시나리오 비교 테이블 검토
3. 예측 근거 요인 확인

**이탈 위험 회원 케어**
1. 이탈 위험 회원 목록 확인
2. 회원명 클릭 → 회원 상세 화면 이동
3. 권장 대응 액션 적용

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 | 예측 항목 설정 패널 표시 |
| 분석 중 | AI 처리 중 표시 (처리 시간 안내 포함) |
| 결과 표시 | 예측 차트 + 인사이트 + 시나리오 |
| 데이터 부족 | 학습 최소 데이터 부족 안내 (예: "6개월 이상의 데이터가 필요합니다") |
| 권한 부족 | 매니저 이하 접근 차단 |

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다.
2. 학습에 필요한 최소 과거 데이터 기간(예: 6개월)을 충족하지 못하면 예측을 수행하지 않고 안내한다.
3. 예측 결과는 낙관/기본/보수 3개 시나리오로 함께 제공된다.
4. 센터장은 본인 소속 지점(`branchId`) 데이터로만 예측을 실행할 수 있다.
5. 이탈 위험 회원 목록은 위험도 임계값 기준으로 필터되며, 회원명 클릭 시 회원 상세 화면으로 이동한다.
6. 예측 결과는 학습 시점의 데이터 스냅샷에 기반하므로, 최신 데이터 반영을 위해서는 재실행이 필요하다.
7. 예측 실행 및 PDF 내보내기는 감사 로그(SCR-097)에 기록된다.
