## 기능 목적

오늘 처리해야 할 업무 목록을 관리하는 화면이다. 직원 개인별 또는 지점 공유 할 일을 등록·수정·완료 체크하여 일일 업무를 체계적으로 관리한다. KPI 센터(HQ-04) 액션 큐와 연동되어 자동 생성된 액션도 본 화면에서 처리한다.

## 주요 구성요소

### 오늘의 할 일 목록

| 항목 | 표시 |
|------|------|
| 제목 | 텍스트 |
| 우선순위 배지 | 높음/보통/낮음 |
| 담당자 | 직원명 |
| 마감 시각 | HH:mm |
| 완료 체크박스 | 클릭 시 취소선 |
| 액션 | [수정] / [삭제] |

### 상단 액션

[+ 할 일 추가] → DLG-098-001.

### 진행 현황 요약

| 카드 | 표시 |
|------|------|
| 전체 항목 | 카운트 |
| 완료 항목 | 카운트 |
| 미완료 항목 | 카운트 |
| 완료율 | 프로그레스 바 |

### 필터 탭

전체 / 미완료 / 완료.

### 태스크 추가 (DLG-098-001)

| 입력 | 설명 |
|------|------|
| 제목 | 텍스트 (필수) |
| 우선순위 | 높음/보통/낮음 |
| 담당자 | 직원 검색 (다중) |
| 마감 시각 | HH:mm |
| 메모 | textarea |
| 공유 범위 | 개인 / 지점 |

### 태스크 상세 수정 (DLG-098-002)

채워진 폼 + 수정.

### KPI 센터 액션 연동

KPI 센터(HQ-04)에서 자동 생성된 액션이 본 화면에 자동 추가됨.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 할 일 | 추가·수정·삭제·완료 |
| owner (센터장) | 소속 지점 할 일 | 추가·수정·삭제·완료 |
| manager | 본인 담당 항목 | 본인 항목 완료 |
| fc / 트레이너 / 스태프 | 본인 담당 항목 | 본인 항목 완료 |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

**할 일 조회**
1. 사이드바 → "본사관리 > Today Tasks" 진입
2. 오늘 날짜 기준 할 일 목록
3. 진행 현황 요약 카드 확인

**할 일 추가**
1. [+ 할 일 추가] → DLG-098-001
2. 제목·우선순위·담당자·마감 입력
3. 저장 → 목록 추가

**완료 처리**
1. 체크박스 클릭 → 취소선 + 완료 배지
2. 완료율 갱신

**수정 / 삭제**
1. [수정] → DLG-098-002
2. [삭제] → 확인 → 제거

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 오늘 할 일 목록 |
| 전체 완료 | 축하 메시지 |
| 목록 없음 | 추가 안내 |

## 비즈니스 규칙

1. 오늘 날짜가 변경되면 자동으로 새 할 일 목록이 표시된다.
2. 미완료 항목은 다음 날로 자동 이월되지 않으며 별도 알림으로 안내된다.
3. KPI 센터(HQ-04) 액션 큐에서 자동 생성된 액션은 우선순위 "높음"으로 자동 추가된다.
4. 매니저 이하는 본인이 담당자인 항목만 완료 처리 가능하다.
5. 공유 범위 "지점"으로 등록된 할 일은 같은 지점 직원 모두에게 표시된다.
6. 변경·완료 이력은 감사 로그에 기록된다.
