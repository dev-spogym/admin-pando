## 기능 목적

AI 기반 분석을 활용하여 향후 매출·신규 회원·이탈·출석율 등을 예측하는 화면이다. 과거 데이터 패턴을 학습하여 미래 운영 계획 수립과 선제적 대응(이탈 위험 회원 케어 등)에 활용한다.

운영 맥락:
- **CFO 분기 매출 예측 보고**: CFO가 분기 시작 전 향후 3개월 매출 예측(낙관/기본/보수 시나리오)을 확인하여 이사회 보고서에 활용한다.
- **이탈 위험 회원 선제 케어**: 운영팀이 이탈 위험도 임계값 이상 회원 목록을 주간 단위로 확인하고, FC에게 케어 액션을 배정한다.
- **신규 회원 유입 예측으로 스태프 스케줄링**: 향후 1개월 신규 회원 수 예측을 근거로 상담 스태프 인력 계획을 수립한다.
- **모델 재학습 주기 관리**: 데이터 적재량이 일정 수준을 넘으면 자동 재학습 트리거가 발동되고, 관리자가 재학습 완료 알림을 확인한다.
- **예측 정확도 모니터링**: 이전 예측값과 실제값을 비교하여 모델 정확도(MAPE 등)를 정기 검토하고, 정확도 저하 시 재학습을 수동 트리거한다.
- **신규 지점 데이터 부족 대응**: 오픈 6개월 미만 지점은 학습 데이터 부족 안내를 수신하고, 유사 규모 지점 집계 데이터로 보완 예측을 제공한다.
- **임계 알림 자동 발송**: 이탈 위험 회원 수가 전주 대비 20% 이상 급증하면 운영팀에 자동 알림이 발송되어 즉각 대응을 유도한다.

## 주요 구성요소

### 예측 항목 선택

| 항목 | 입력/선택 |
|------|------|
| 예측 지표 | 매출 / 신규 회원 수 / 이탈 회원 수 / 출석율 |
| 예측 기간 | 향후 1개월 / 3개월 / 6개월 / 12개월 |
| 대상 지점 | 단일/복수 지점 선택 |
| 예측 실행 | 버튼 |

### 예측 결과 차트

| 영역 | 표시 |
|------|------|
| 통합 선 차트 | 과거 실적 + 예측 값 (예측 구간은 점선·밴드) |
| 신뢰 구간 | 낙관 / 기본 / 보수 시나리오 밴드 |
| 학습 데이터 기간 | 예측 근거 데이터 기간 안내 |
| 툴팁 | 시점 마우스 오버 시 예측 수치·신뢰 구간 |

### 예측 인사이트

| 항목 | 표시 |
|------|------|
| 예측 근거 요인 | 계절성 / 최근 추이 / 이벤트 영향 등 |
| 이탈 위험 회원 목록 | 회원 이름 + 이탈 위험도 수치 |
| 권장 대응 액션 | 회원 케어·마케팅 등 액션 제안 |

#### 예측 인사이트 생성 기준

| 항목 | 기준 |
|---|---|
| 생성 주체 | 시스템이 자동 생성한다. 운영자, FC, 트레이너가 인사이트 문구를 직접 작성하지 않는다. |
| 생성 시점 | 사용자가 [예측 실행]을 눌러 예측 결과가 생성되는 시점에 선택 지표·기간·지점·데이터 기준일 스냅샷으로 생성한다. |
| 재생성 기준 | 사용자가 [재실행]하면 기존 인사이트를 덮어쓰고 최신 데이터 기준일로 다시 생성한다. |
| 이탈 위험 목록 기본 갱신 | 매일 06:00 전일 기준으로 위험도를 재산출해 목록을 갱신한다. 사용자가 `이탈 회원 수` 예측을 실행하면 선택 지점 기준 최신 목록을 조회해 표시한다. |
| 사람이 수정 가능한 범위 | 인사이트 문구 자체는 수정하지 않는다. 사용자는 회원 상세 이동, PDF 내보내기, 담당자 케어 배정 또는 수동 후속 조치만 수행한다. |

#### 근거 요인 설명 기준

시스템은 예측 결과에 영향을 준 신호 중 영향도가 큰 요인을 최대 3개까지 표시한다. 각 요인은 `요인명`, `영향 방향`, `근거 수치`, `기준 기간`을 함께 표시한다.

| 요인 유형 | 표시 예시 | 사용 조건 |
|---|---|---|
| 최근 출석 감소 | 최근 30일 출석 0회, 이전 30일 대비 -4회 | 출석 또는 이탈 예측에서 방문/출석 감소가 감지된 경우 |
| 이용권 만료 임박 | 이용권 만료 D-7 | 회원 이용권 만료 step 대상이거나 만료일이 가까운 경우 |
| 재등록 지연 | 만료 후 14일 경과, 재등록 결제 없음 | 만료 후 재결제가 없는 경우 |
| 상담 미응답 | 최근 상담 요청 2건 미응답 | 상담/재등록 케어 이력이 있으나 응답이 없는 경우 |
| 예약 취소·노쇼 증가 | 최근 30일 노쇼 2회 | 예약 취소 또는 노쇼가 반복된 경우 |
| 매출·회원 추세 변화 | 전월 대비 매출 -12% | 매출·신규 회원 예측에서 최근 추세가 악화된 경우 |
| 계절성 | 전년 동월 평균 대비 하락 구간 | 과거 같은 월/시즌 패턴이 반복되는 경우 |

#### 이탈 위험 회원 목록 기준

| 컬럼 | 표시 기준 |
|---|---|
| 회원명 | 회원 상세로 이동 가능한 텍스트 |
| 소속 지점 | 회원의 현재 소속 지점 |
| 담당자 | 담당 FC 또는 현재 관리 담당자 |
| 위험도 | 0~100점으로 표시. 내부 위험도 점수 0.7 이상이면 목록에 노출 |
| 주요 근거 | 출석 감소, 만료 임박, 상담 미응답 등 상위 근거 1~3개 |
| 마지막 방문일 | 마지막 출석/입장/수업 참여일 |
| 이용권 만료일 | 현재 활성 이용권의 만료일 |
| 권장 대응 액션 | 아래 액션 매핑 기준에 따른 추천 액션 |
| 상태 | 미처리 / 케어 배정 / 처리 완료 |

정렬 기본값은 `위험도 높은 순`이며, 위험도가 같으면 `이용권 만료일이 가까운 순`으로 정렬한다.

#### 권장 대응 액션 생성 기준

권장 대응 액션은 시스템이 근거 요인에 따라 고정 규칙으로 제안한다. 자동 메시지 발송, 자동 할인 적용, 자동 회원 상태 변경은 하지 않는다. 운영자가 액션을 확인한 뒤 회원 상세 이동 또는 담당자 케어 배정으로 수동 처리한다.

| 주요 근거 | 권장 대응 액션 |
|---|---|
| 최근 30일 출석 없음 | 재방문 안내 연락 |
| 이용권 만료 D-30/D-14/D-7/D-Day step 대상 | 재등록 상담 예약 제안 |
| 만료 후 재결제 없음 | 재등록 후속 상담 |
| 상담 미응답 | 담당자 재연락 태스크 생성 |
| 예약 취소·노쇼 반복 | 노쇼 사유 확인 및 일정 재조정 |
| 미수금 또는 결제기한 경과 | 결제 안내 후속 조치 |
| 위험도 90점 이상 | owner 또는 manager 확인 대상 표시 |

### 시나리오 비교

HQ-EXT-03-06 시나리오 비교 테이블은 별도 입력·편집 기능이 아니라, 같은 예측 실행 결과를 `낙관 / 기본 / 보수` 3개 시나리오로 나누어 읽기 전용 표로 비교하는 결과 영역이다. 사용자가 표 안에서 값을 수정하거나 시나리오를 직접 생성하지 않는다.

| 컬럼 | 표시 기준 |
|------|------|
| 시나리오 | 낙관 / 기본 / 보수 3개 행으로 고정 표시 |
| 예측 기준값 | 선택한 예측 지표의 예측 종료 시점 값. 예: 향후 3개월 매출 예측이면 3개월 뒤 예상 매출 |
| 시작 대비 증감 | 예측 기준값과 현재 기준값의 차이. 금액/인원/건수/비율 지표에 맞는 단위로 표시 |
| 증감률 | 시작 대비 증감 ÷ 현재 기준값 × 100 |
| 신뢰 구간 | 해당 시나리오의 하한~상한 범위. 차트의 예측 밴드와 같은 값 |
| 주요 해석 | 시스템 자동 생성 짧은 문구. 예: `보수 시나리오에서도 목표 대비 90% 이상 유지` |

| 시나리오 | 산출 의미 |
|------|------|
| 낙관 | 예측 밴드의 상단값 또는 긍정 조건을 반영한 상향 전망 |
| 기본 | 모델의 중앙 예측값 |
| 보수 | 예측 밴드의 하단값 또는 부정 조건을 반영한 하향 전망 |

표의 행 클릭 기능은 제공하지 않는다. 차트와 표는 같은 예측 결과를 서로 다른 형태로 보여주는 것이며, 표는 PDF 내보내기 대상에 포함된다.

## 운영 시나리오 (페르소나 × 트리거 × 결과)

| 페르소나 | 사용 맥락 | 행동 | 기대 결과 |
|---|---|---|---|
| 본사 CFO | 분기 이사회 보고 준비 | 매출 지표·향후 3개월·전사 선택 → 예측 실행 → PDF 내보내기 | 낙관/기본/보수 시나리오 담긴 분기 예측 보고서 생성 |
| 본사 운영팀 | 이탈 위험 회원 주간 케어 | 이탈 회원 수·향후 1개월 → 실행 → 위험 목록 확인 → 회원명 클릭 → FC 케어 배정 | 이탈 위험 회원 식별 및 선제 대응 액션 배정 |
| 센터장 | 신규 회원 유입 예측 기반 스태프 계획 | 신규 회원 수·1개월 → 소속 지점 → 실행 | 향후 입회 예상 수치 확인, 상담 인력 스케줄 조정 근거 확보 |
| 본사 운영팀 | 모델 정확도 저하 감지 시 수동 재학습 | 정확도 패널 확인 → 임계 이하 → [재학습 요청] 클릭 | 재학습 배치 큐 등록, 완료 후 알림 수신 |
| 본사 운영팀 | 이탈 위험 급증 임계 알림 수신 | 알림 수신 → 예측 분석 진입 → 이탈 목록 확인 | 급증 원인 파악 및 즉각 케어 대응 |
| 센터장 | 신규 지점 데이터 부족 안내 수신 | 6개월 미만 지점 선택 → 예측 실행 → 데이터 부족 안내 | 유사 규모 집계 보완 예측 확인 또는 데이터 충분 시까지 대기 |
| 본사 superAdmin | 전사 복수 지점 비교 예측 | 매출 지표·3개월·복수 지점 선택 → 실행 | 지점별 예측값 나란히 비교, 상위/하위 지점 식별 |
| 본사 운영팀 | 예측 결과 재실행(최신 데이터 반영) | 기존 결과 확인 → [재실행] → 최신 스냅샷 기반 새 결과 | 최신 데이터 반영된 예측값 갱신 |

## 분기·예외 흐름

- **학습 최소 데이터 미충족(6개월 미만)**: "예측에 필요한 데이터가 부족합니다(최소 6개월). 유사 규모 지점 집계로 보완 예측을 제공합니다" 안내. 보완 예측 가능 시 노출, 불가 시 미노출.
- **예측 실행 중 타임아웃(60초 초과)**: "AI 분석에 시간이 걸리고 있습니다. 완료 후 알림을 드리겠습니다" → 백그라운드 처리 전환 + 완료 알림.
- **이탈 위험 회원 목록 0건**: "현재 이탈 위험 회원이 없습니다" 안내. 목록 영역 숨김.
- **센터장이 타 지점 선택 시도**: RLS로 소속 지점만 노출. 타 지점 선택 UI 숨김.
- **모델 재학습 중 예측 실행 시도**: "모델 재학습 중입니다. 완료 후 재실행해주세요" 안내. 실행 버튼 비활성.
- **신뢰 구간 시나리오 중 보수 > 기본 역전 이상값**: 시스템 경고 배너 "예측 신뢰 구간에 이상이 감지되었습니다. 모델 재학습을 권장합니다".
- **PDF 내보내기 실패**: 토스트 "PDF 생성에 실패했습니다. 다시 시도해주세요".
- **이탈 위험 회원 클릭 → 회원 상세 이동 시 해당 회원 삭제됨**: "이미 탈퇴한 회원입니다" 안내 + 목록 갱신.
- **복수 지점 선택 없이 실행(superAdmin)**: "지점을 1개 이상 선택해주세요" 인라인 오류.
- **예측 지표 미선택**: "예측 지표를 선택해주세요" 인라인 오류, 실행 차단.
- **매니저 이하 접근**: 403 화면.

## 비즈니스 규칙

1. 매니저 이하 계정은 본 화면 접근이 차단된다. 403 처리.
2. **학습 최소 데이터 기간**: 6개월 이상의 과거 데이터가 있어야 예측 실행 가능. 미충족 시 유사 규모 지점 집계 보완 예측 제공(가능한 경우).
3. **예측 모델**: 선형 회귀 + 계절성 분해(시계열 회귀 모델) 사용. 지표별 독립 모델 적용.
4. **3개 시나리오 필수 제공**: 예측 결과는 낙관/기본/보수 시나리오를 항상 함께 제공한다. 단일 수치만 노출 금지.
5. **신뢰 구간 표시**: 예측 차트에 95% 신뢰 구간 밴드를 함께 표시한다.
6. **모델 갱신 주기**: 자동 재학습은 신규 데이터 누적량이 이전 학습 대비 10% 이상 증가 시 트리거. 최소 갱신 주기는 주 1회.
7. **수동 재학습**: 운영팀이 [재학습 요청] 버튼으로 수동 트리거 가능. 재학습 중 예측 실행 차단.
8. **모델 정확도 표시**: MAPE(평균 절대 백분율 오차) 기준. 정확도 20% 초과 시 "모델 재학습을 권장합니다" 경고 배너.
9. **이탈 위험 임계값**: 위험도 점수 0.7 이상 회원을 이탈 위험 목록에 노출. 임계값은 운영 정책에 따라 조정 가능.
10. **이탈 위험 급증 알림**: 이탈 위험 회원 수가 전주 대비 20% 이상 증가 시 운영팀 자동 알림 발송.
11. **센터장 지점 고정**: 센터장은 소속 지점(`branchId`)으로만 예측 실행 가능. RLS 적용.
12. **superAdmin 복수 지점 예측**: 복수 지점 선택 시 지점별 독립 예측 결과를 나란히 표시.
13. **데이터 스냅샷 기반**: 예측 결과는 실행 시점 스냅샷 기반. 최신 데이터 반영을 위해 재실행 필요. 결과 화면에 "데이터 기준일: YYYY-MM-DD HH:mm" 표시.
14. **예측 실행 타임아웃**: 60초 초과 시 백그라운드 처리 전환, 완료 후 인앱 알림.
15. **PDF 내보내기**: 차트 스냅샷 + 시나리오 수치 + 이탈 위험 목록 + 생성 메타 포함. 내보내기 실패 시 재시도 안내.
16. **감사 로그**: 예측 실행·재학습 요청·PDF 내보내기 SCR-097 기록. `actor_id`, `branch_ids`, `metric`, `period`, `executed_at` 저장.
17. **신규 지점 보완 예측 표시**: 학습 데이터 부족 지점에 유사 규모 집계 보완 예측 노출 시 "참고용 보완 예측입니다" 워터마크 표시.
18. **CFO 분기 보고서 템플릿**: PDF 내보내기 시 CFO 보고서 전용 템플릿(표지·요약·시나리오 테이블·이탈 목록) 선택 옵션 제공.
19. **인사이트 자동 생성**: HQ-EXT-03-05 인사이트는 예측 실행 완료 시 시스템이 자동 생성한다. 운영자는 인사이트 내용을 직접 작성·수정하지 않는다.
20. **권장 액션 제한**: 권장 대응 액션은 제안 표시만 수행하며 자동 메시지 발송, 자동 쿠폰/할인 적용, 자동 회원 상태 변경을 하지 않는다.
