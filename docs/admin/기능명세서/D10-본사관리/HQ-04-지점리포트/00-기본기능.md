## 기능 목적

본사 슈퍼관리자(전 지점) 또는 센터장(소속 지점)이 매출·회원·수업 3개 도메인의 성과를 다중 지점·다양한 기간(주간/월간/분기/연간/직접 입력)으로 비교하고 엑셀·PDF로 내보내는 리포트 화면(SCR-093)이다. 본사 임원 보고용·월말 결산용·내부 자원 배분용 보고 자료의 단일 진입점이며, 매출 순위·목표 달성률·회원 유지율·예약율·출석율·인기 수업까지 통합 비교한다. 다운로드는 감사 로그(SCR-097)에 기록되어 본사 정보 외부 유출 추적이 가능하다.

운영 맥락:
- **월말 본사 정기 보고**: 슈퍼관리자가 지난 달 전 지점 매출 비교 → PDF 다운로드 → 임원 회의 자료
- **분기 KPI 회의**: 분기 매출·회원 유지율·인기 수업 분석 → 차기 분기 전략 수립
- **위기 지점 진단**: 매출 하위 지점 + 회원 이탈 상위 지점 식별 → 본사 지원 의사결정
- **지점 간 best practice 공유**: 우수 지점 운영 방식 분석 → 평균 이하 지점에 전파
- **신규 지점 정착 추적**: 오픈 {개수}개월 차 매출 추이 → 정착 속도 평가
- **연간 결산**: 12개월 누적 데이터 → 연간 보고서 생성 → 가맹/직영 비교
- **센터장 본인 지점 성과 점검**: 소속 지점 데이터로 자가 진단 → 운영 액션
- **이탈 회원 패턴 분석**: 회원 유지율 낮은 지점 → 이탈 원인 추적 → HQ-EXT-03 예측 진입

## 주요 구성요소

### 필터 및 기간 선택

| 항목 | 옵션 |
|------|------|
| 조회 기간 | 주간/월간/분기/연간/직접 입력 |

| 비교 기준 | 전기간 대비 / 지점 간 비교 |

### 매출 성과 섹션

- 지점별 총 매출 비교 차트 (막대)
- 지점별 매출 순위 테이블
- 목표 달성률 표시

### 회원 성과 섹션

- 지점별 신규/활성/이탈 회원 비교
- 회원 유지율 차트

### 수업 성과 섹션

- 지점별 수업 운영 횟수 / 예약율 / 출석율 비교
- 인기 수업 유형 분석

#### 인기 수업 정의

인기 수업은 조회 기간 내 "예약율과 출석율이 모두 높은 수업 유형"으로 산정한다.

| 항목 | 기준 |
|------|------|
| 대상 | 운영 완료된 수업 유형 |
| 제외 | 취소 수업, 정원 미설정 수업, 운영 횟수 3회 미만, 예약 인원 합계 10명 미만 |
| 예약율 | 예약 인원 합계 / 정원 합계 × 100 |
| 출석율 | 출석 인원 합계 / 예약 인원 합계 × 100 |
| 인기 점수 | 예약율 50% + 출석율 50% |
| 표시 | 상위 5개 수업 유형 + 점수/예약율/출석율/운영 횟수 |
| 동점 | 출석 인원 합계 → 운영 횟수 → 가나다순 |

## 주요 UX 흐름

1. 사이드바 → "본사관리 > 지점 리포트" 진입
2. 당월 전체 지점 성과 자동 로드 (스켈레톤 → 수치 전환)
3. 기간/지점/비교 기준 필터 변경 → 차트·테이블 자동 갱신
4. 매출/회원/수업 섹션별 비교 + 정렬
5. [엑셀] 또는 [PDF] 다운로드 → 현재 필터 데이터 → 감사 로그

### 분기·예외 흐름
- **owner 진입 시**: 소속 지점 자동 필터, 다른 지점 선택 불가
- **다중 지점 미선택**: "비교할 지점을 1개 이상 선택해주세요" 안내
- **데이터 없음**: "선택 기간/지점에 해당 데이터가 없습니다" + 필터 조정 안내
- **목표 미설정 지점**: 목표 달성률 "—" 표시 + 안내
- **다운로드 처리 중**: 버튼 로딩 + 진행률 토스트(대용량 시)
- **다운로드 실패**: "다운로드 실패, 다시 시도해주세요" + 재시도
- **권한 부족 매니저 이하**: 화면 진입 차단 + 본사 대시보드 자동 이동
- **신규 지점 첫 달**: 비교 데이터 부족 → "신규 지점은 오픈 30일 후부터 비교 가능"
- **휴업/폐점 지점**: 비교에서 자동 제외 또는 별도 표시 토글
- **대용량 다운로드**: 비동기 처리 + 완료 시 알림 센터로 알림

## 비즈니스 규칙

1. **매출 집계 기준**: 매출관리.md(SCR-S004) 표준 따름. 담당자별 / 지점별 / 본사 통합 동일.
2. **회원 유지율**: 기간 종료 시점 활성 회원 / 기간 시작 시점 회원 × 100. 신규 등록 회원 별도 표시.
3. **출석율**: 출석 / 예약 × 100. 노쇼는 출석에서 제외. 취소는 분모에서 제외.
4. **예약율**: 예약 / 정원 × 100. 정원 미설정 수업은 제외.
5. **목표 달성률**: SCR-S011(매출 예측) 또는 HQ-02(KPI 대시보드)에서 설정한 월 매출 목표 사용. 목표 미설정 시 "—" 표시.
6. **owner 권한 제한**: 소속 지점만 조회. 타 지점 비교는 슈퍼관리자만 가능. 필터에 다른 지점 미노출.
7. **manager 이하**: 본 화면 접근 차단.
8. **다운로드 필터 일관성**: 엑셀·PDF는 현재 화면 필터 조건 그대로 반영. 미리보기 페이지와 무관.
9. **감사 로그 필수**: 다운로드(엑셀/PDF) 모두 actor·필터 조건·생성 일시 기록.
10. **신규 지점 정착 기준**: 오픈 후 30일 미만은 비교 데이터 부족 표시.
11. **휴업/폐점 지점**: 기본 비교에서 제외 토글. 폐점은 데이터 보관 기간 내만 표시.
12. **인기 수업 분석**: 예약율 50% + 출석율 50% 가중. 종목별 분포. 운영 횟수 3회 미만 또는 예약 인원 10명 미만은 표본 부족으로 제외.
13. **차트 타입**: 막대(비교), 선(추이), 도넛(분포). 사용자 토글 가능.
14. **정렬**: 매출/회원 수/유지율 순. 오름/내림 토글.
15. **다중 지점 비교**: 기본 최대 10개 지점까지 선택 가능. 엔터프라이즈 라이선스는 30개까지 확장 가능.
16. **PDF 헤더 자동 삽입**: 지점명·기간·필터 조건·생성 일시·생성자 자동.
17. **엑셀 시트 분리**: 매출/회원/수업 시트 분리. 종합 시트 추가.
18. **대용량 다운로드 비동기**: 1만 건 이상 시 비동기 처리 + 완료 알림.
19. **개인정보 처리**: 다운로드 파일에 회원명·연락처는 마스킹 정책 적용 가능.
20. **데이터 갱신 주기**: 일별 03:00 배치 + 매시간 매출 갱신. 화면은 5분 캐시.
