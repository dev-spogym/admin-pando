## 기능 목적

본사 슈퍼관리자(전 지점) 또는 센터장(소속 지점)이 24종 이상의 핵심 성과 지표(KPI)를 매출·신규/유지·OT/체험·GX 종목·강습 세션·상담 퍼널·재등록 카테고리로 통합 시각화하고 목표(DLG-094-001)와 비교 분석하는 화면(SCR-094)이다. 게이지 차트로 매출 목표 달성률을 직관 표시하고, WI(방문 문의) vs TI(전화 문의) 분리 + TI 방문 전환율로 상담 병목을 식별하며, OT 등록 전환율·거부율(거부+보류)·이월률·체험→등록률 등 운영 정밀 지표까지 표시한다. 지점별 비교 테이블의 색상 코딩(초과 초록 / 근접 노랑 / 미달 빨강)으로 즉시 위기 지점 식별이 가능하다.

운영 맥락:
- **본사 임원 매월 KPI 점검**: 24종 KPI 게이지 + 추이 차트로 월간 달성률 점검 → 미달 지점 액션
- **매출 목표 설정**: DLG-094-001 → 지점별 월 목표 입력 → 다음 달 달성률 추적
- **상담 퍼널 병목 진단**: TI/WI 분리 → TI 방문 전환율 낮으면 콜 스크립트 개선
- **재등록 위기 진단**: 재등록 성공률 낮은 지점 → FC 보드(HQ-03) 진입 → 액션 큐
- **GX 종목 운영 의사결정**: 6종 분포 차트 → 비인기 종목 폐지 + 인기 종목 증설
- **OT 운영 진단**: 강습/골프 OT 분리 + 거부율(거부+보류) → 트레이너 배정 조정
- **연간 KPI 회의 자료**: 월별 달성률 추이 차트 → 분기/연간 종합 보고
- **신규 지점 KPI 안정화**: 신규 지점 첫 3개월은 별도 표시, 안정화 후 일반 비교

### 상담/퍼널 세분화

WI(방문 문의) vs TI(전화 문의) 분리 표시. TI 방문 전환율 + WI/TI 등록률.

### 재등록 / 이탈 회복 KPI

`[재등록DB]` B열 상담결과 기반 집계.

### GX 세부 종목 분포

요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX기타 6종 분포 차트. 인기 종목 = 증설, 비인기 = 폐지 후보.

### OT / 수업 운영 KPI

강습 OT / 골프 OT / 등록 전환율 / 거부율(거부+보류) / 이월률 / 체험→등록률.

### 강습 세션 유형별 운영 KPI

PT / 필라테스 / 스트레칭 / 테라피 4종 카드 또는 누적 막대.

### 목표 달성 추이 차트

월별 KPI 달성률 추이 + 목표선 100%.

### 지점별 KPI 비교 테이블

색상 구분: 초과(초록) / 근접(노랑) / 미달(빨강).

### 매출 목표 설정 (DLG-094-001)

지점별 월 매출 목표.

## 비즈니스 규칙

1. 강습 세션 유형은 PT/필라테스/스트레칭/테라피 4종 고정. 화면 축약 표기 가능 (P.T, 필라).
2. 강습세션수는 수업/출석/일정 원장의 세션 유형별 완료 수업수로 산출하며, 외부 시트는 검산용이다.
3. GX 세부 종목은 상품 마스터 `category=GX` + `subCategory` 6종 고정.
4. 상담 채널 원천은 `[신규DB]` C열 (`WI=방문`, `TI=전화문의`, `체험`, `일일입장`).
5. 상담 방식은 `대면`/`유선`/`부재` 3종으로 제한된다.
6. TI 방문 전환율은 TI 문의 중 N/R/V열 중 하나 이상이 `대면`인 건이다.
7. 재등록 성공률 = `[재등록DB]` B열 등록 ÷ (등록+확정+예상+관리+실패).
8. OT 거부율은 `거부+보류`를 함께 집계한다 (툴팁 명시).
9. OT 이월률은 `이월 건수 / OT배정 인원 × 100`으로 산출한다.
10. OT 등록 전환율은 `등록 / OT 진행`이며 PT 완료율과 합산하지 않는다.
11. 매출 4종 지표(총매출/PT매출/이용권매출/기타매출)는 `[매출종합]` F열 결제금액 기준으로 산출한다.
12. 지점별 비교 테이블 색상 기준: 달성률 100% 이상 = 초록, 80~99% = 노랑, 79% 이하 = 빨강.
13. KPI 카드 데이터는 5분 캐시 적용 (실시간 아님). 매시간 배치로 정산 데이터 갱신.
14. 일별 정산 배치는 매일 03:00 실행. 전날까지 누적 데이터 확정 처리.
15. 월별 목표 달성률 게이지는 DLG-094-001에서 입력한 목표값이 없으면 비활성(N/A) 표시.
16. 1억원 초과 매출 목표는 본사 슈퍼관리자 2차 승인 후 반영된다.
17. 신규 지점(개설 3개월 미만)은 지점별 비교 테이블에서 별도 섹션으로 분리 표시한다.
18. 코호트 데이터(신규 회원 유지율)는 등록 월 기준 3개월 추적값이다.
19. 상담 퍼널 단계 전환율은 직전 단계 인원 대비 비율로 산출한다 (누적 대비 아님).
20. KPI 대시보드 접근 로그는 감사 로그(SCR-097)에 자동 기록된다.
21. 지점 행 클릭 시 SCR-093(지점 리포트)으로 이동하며 해당 지점 ID가 파라미터로 전달된다.
22. 비교 테이블 정렬 기준: 기본값은 달성률 낮은 순(미달 우선 식별).
23. 매출 목표 설정 권한은 primary/superAdmin 및 owner 계정으로 제한한다.
24. 전월 대비 증감은 절댓값 + 증감률(%) 모두 표기한다 (예: +120만 / +8.3%).
25. 배치 실패 시 전일 확정 데이터를 표시하며 상단 배너에 기준 시각을 명시한다.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `HQ-02`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-094`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-094-001 매출목표설정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
