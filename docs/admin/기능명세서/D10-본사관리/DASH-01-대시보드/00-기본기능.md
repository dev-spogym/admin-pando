## 기능 목적

로그인 직후 가장 먼저 진입하는 화면으로, 현재 지점의 운영 현황을 한눈에 파악한다. 회원 현황, 매출, 출석, 주의 대상 회원(만료 예정·생일자·미수금·홀딩), 최근 활동 이력을 종합적으로 표시해 운영자가 즉시 대응할 액션을 식별할 수 있도록 한다.

## 주요 구성요소

### 핵심 지표 요약 카드 (5개)

| 카드 | 표시 |
|------|------|
| 전체 회원 수 | 합계 |
| 활성 회원 수 | 활성 |
| 만료 예정 (30일 이내) | 카운트 |
| 오늘 출석 수 | 합계 |
| 이번 달 매출 | 천 단위 |

### 분포 차트

- 회원 성별 분포 (원형)
- 회원 연령대 분포 (막대)

### 추이 차트

- 월별 매출 추이 (선 또는 막대)
- 주간 출석 현황 (막대)

### 주의 대상 위젯 (4종)

| 위젯 | 내용 |
|------|------|
| 오늘 생일 회원 | 명단 |
| 미수금 발생 회원 | 명단 + 금액 |
| 홀딩 중 회원 | 명단 + 기간 |
| 만료 임박 회원 | 명단 + 만료일 |

각 위젯에 [전체보기] 링크.

### 최근 활동 로그

최근 시스템 활동 이력 요약 (누가 무엇을 했는지).

### 상단 액션

- 수동 새로고침 버튼
- 첫 방문 시 환영 배너 (닫기 버튼)

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 선택 지점 대시보드 | 새로고침·회원 상세 |
| owner (센터장) | 소속 지점 대시보드 | 새로고침·회원 상세 |
| manager | 소속 지점 대시보드 | 새로고침·회원 상세 |
| fc / 직원 | 소속 지점 대시보드 | 새로고침·회원 상세 |
| readonly | 대시보드 조회 | 조회만 |

## 주요 UX 흐름

1. 로그인 완료 시 자동 진입
2. 첫 방문 시 환영 배너 표시
3. 데이터 로딩 → 스켈레톤 → 실제 수치 전환
4. 위젯 회원명 클릭 → SCR-M004
5. 위젯 [전체보기] → 해당 메뉴 화면

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 카드·차트·위젯 표시 |
| 로딩 | 스켈레톤 |
| 첫 방문 | 환영 배너 |
| 데이터 없음 | 위젯별 안내 |
| 오류 | 재시도 안내 |

## 비즈니스 규칙

1. 만료 임박 기준은 30일 이내이며 자동 감지된다.
2. 위젯 데이터는 실시간 또는 5분 캐시로 갱신된다.
3. 슈퍼관리자는 지점 전환 후 해당 지점의 본사 대시보드를 본다.
4. 환영 배너는 사용자별 1회 표시 후 자동 숨김된다.
5. 매출 집계 기준은 매출관리.md를 따른다.
