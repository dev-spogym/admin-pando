## 기능 목적

로그인 직후 가장 먼저 진입하는 메인 대시보드(SCR-090)로, 현재 지점의 일일 운영 현황을 한눈에 파악하고 즉시 대응할 액션을 식별하는 운영 컨트롤 타워다. 핵심 지표 5종(전체/활성/만료 임박/오늘 출석/이번 달 매출), 회원 분포(성별·연령), 추이(월별 매출·주간 출석), 주의 대상 위젯 4종(생일·미수금·홀딩·만료 임박), 최근 활동 로그를 종합 표시한다. 본사 슈퍼관리자가 지점 전환(HQ-01)으로 진입한 경우 해당 지점 컨텍스트로 표시되며, 센터장·매니저는 소속 지점만 본다.

운영 맥락:
- **센터장 출근 직후 1차 점검**: 로그인 → 대시보드 → 오늘 출석·미수금·만료 임박 회원 즉시 확인 → 액션 큐 진입(HQ-06)
- **매니저 일일 회원 케어**: 만료 임박 위젯 → 회원명 클릭 → SCR-M004 → 재등록 상담 발송
- **FC 생일자 케어**: 생일 위젯 → 메시지 발송 (SCR-071) 자동 연동
- **본사 슈퍼관리자 지점 전환 후 점검**: HQ-01 → 지점 전환 → 본사 대시보드 → 해당 지점 운영 상태 파악
- **저녁 마감 시점 매출·출석 확인**: 이번 달 매출·오늘 출석 카드 + 주간 출석 차트로 일일 마감 점검
- **첫 방문 신규 사용자**: 환영 배너 + 가이드 → 사용자별 1회 표시
- **분포 분석으로 마케팅 전략 도출**: 성별·연령대 분포 → 타겟 세그먼트 식별
- **위기 신호 감지**: 미수금 위젯 급증 시 결제 시스템 점검 또는 일괄 미수 처리

## 주요 UX 흐름

1. 로그인 완료 시 자동 진입
2. 첫 방문 시 환영 배너 표시 (사용자별 1회)
3. 데이터 로딩 → 스켈레톤 → 실제 수치 전환 (5분 캐시 또는 실시간)
4. 위젯 회원명 클릭 → SCR-M004 회원 상세
5. 위젯 [전체보기] → 해당 메뉴 화면(만료 임박 → SCR-M013, 미수금 → SCR-S009)
6. [수동 새로고침] → 5분 캐시 무시하고 즉시 재조회
7. 위젯 데이터 없음 → "오늘 N건 없음" 안내

### 분기·예외 흐름
- **데이터 없음 (신규 지점)**: 모든 카드 0 + "데이터를 수집 중입니다" 안내
- **위젯 일부 데이터 없음**: 해당 위젯만 "오늘 생일자가 없어요" 등 빈 상태 안내, 다른 위젯은 정상
- **API 오류**: 카드별 재시도 버튼 + 토스트 "일시 오류, 잠시 후 다시 시도해주세요"
- **5분 캐시 만료**: 자동 재조회, 수동 새로고침 시 즉시 갱신
- **본사 모드 vs 지점 모드**: 본사 슈퍼관리자가 지점 전환 시 컨텍스트 헤더 변경
- **권한 부족 readonly**: 회원 상세 진입 차단 (조회만)
- **첫 방문 환영 배너 닫기**: 닫기 후 재로그인해도 표시 안 함 (사용자별 플래그)
- **만료 임박 위젯 0건**: "만료 임박 회원이 없어요" + 위젯 숨기지 않음(상태 명확화)
- **미수금 위젯 급증**: 이상 감지 시 빨강 강조 + 알림 토스트
- **분포 차트 데이터 부족**: "최소 N명 이상 데이터 필요" 안내

## 비즈니스 규칙

1. **만료 임박 기준**: 30일 이내. 시스템 설정에서 7/14/30/60일로 변경 가능.
2. **위젯 캐시**: 5분 캐시 기본. 수동 새로고침 시 즉시 갱신. 큰 지점은 10분.
3. **본사 모드 vs 지점 모드**: 슈퍼관리자가 지점 전환 시 해당 지점 컨텍스트로 표시. RLS는 그대로 우회.
4. **환영 배너 정책**: 사용자별 1회 표시. 닫기 후 `welcomed_at` 플래그 저장.
5. **매출 집계 기준**: 매출관리.md(SCR-S004) 표준 따름. 세금 포함/미포함 정책 동일.
6. **활성 회원 정의**: 유효 이용권 보유 + 탈퇴 안 된 회원. 홀딩 중도 활성 포함(정책에 따라 분리 가능).
7. **만료 임박 vs 만료 회원**: 만료 임박 = 30일 이내, 만료 = 이미 만료. 분리 표시.
8. **오늘 출석 수**: 오늘 00:00~23:59 출입 기록 합계. 중복 출입은 1회만 카운트(정책).
9. **이번 달 매출**: 1일 ~ 오늘까지 결제 합계. 환불 차감.
10. **미수금 위젯**: 결제 미완료 + 만료일 경과 회원. 금액 합계 표시.
11. **홀딩 위젯**: 현재 홀딩 상태 회원. 홀딩 종료일 임박 정렬.
12. **생일 위젯**: 오늘 생일 + 이번 주 생일 토글. 음력 생일 옵션.
13. **분포 차트**: 활성 회원 기준. 성별 미입력 회원은 "미상" 분류.
14. **추이 차트**: 월별 매출 12개월, 주간 출석 8주. 기간 변경 옵션.
15. **권한별 가시성**: 슈퍼는 전 지점, owner/manager/fc/staff는 소속 지점만.
16. **readonly 권한**: 회원 상세 진입 차단, 위젯 조회만.
17. **수동 새로고침 권한**: 모든 권한 가능 (캐시 무시).
18. **이상 감지 알림**: 미수금 위젯 전일 대비 N% 이상 급증 시 빨강 강조 + 토스트.
19. **회원 상세 진입 시 권한 체크**: RLS로 차단된 회원은 위젯에 표시 안 됨.
20. **위젯 클릭 추적**: 사용 빈도 분석을 위해 클릭 이벤트 수집(개인정보 제외).
