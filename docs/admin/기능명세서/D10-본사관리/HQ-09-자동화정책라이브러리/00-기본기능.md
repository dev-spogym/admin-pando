## 기능 목적

본사가 전사 자동화 정책 세트를 관리하는 화면이다. 만료 알림·운영 자동화 정책을 세트 단위로 생성·수정·중지하고, 정책별 스텝(기준일·채널·템플릿·필수 여부)을 라이브러리화하여 지점에 적용한다. 고정 D-day 대신 본사가 입력한 기준일 step 리스트 구조를 사용한다.

## 주요 UX 흐름

**정책 세트 조회**
1. 사이드바 → "본사관리 > 자동화 정책 라이브러리" 진입
2. 정책 세트 카드 + 테이블 확인
3. 카드 또는 행 선택 → 우측 스텝 미리보기·사용 현황 패널 갱신

**정책 세트 신규 등록**
1. [+ 정책 세트] → DLG-100-001
2. 기본정보(이름·범위·사용 상태·기본 여부) 입력
3. 스텝 리스트 추가 (기준일·채널·템플릿·필수)
4. 지점 수정 허용 범위 설정
5. 저장 → 카드/테이블에 추가

**정책 수정**
1. 카드/테이블 [편집] → DLG-100-001 (기존 값 채워짐)
2. 정보·스텝 변경
3. 저장 → 영향 범위 고지 → 확정 시 적용

**사용 중지**
1. [중지] → 확인 다이얼로그
2. 신규 적용 차단 + 기존 사용 지점 영향 범위 고지
3. 확정 → 카드 상태 "중지"로 변경

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 정책 세트 카드 + 테이블 + 미리보기 |
| 빈 상태 | 정책 세트 없음 → [+ 정책 세트] CTA |
| 편집 중 | DLG-100-001 열림 |
| 검증 실패 | 정책명 필수 / 스텝 0개 / 기준일 중복 경고 표시 |
| 중지된 정책 | 카드 흐림 처리 + "중지" 배지 |
| 권한 부족 | superAdmin / primary 외 접근 차단 |

## 비즈니스 규칙

1. 본 화면은 superAdmin / primary 계정만 접근 가능하다.
2. 고정 D-day 대신 본사가 입력한 기준일 step 리스트 구조를 사용한다.
3. 정책명은 필수, 스텝은 최소 1개 이상이 등록되어야 한다.
4. 동일 정책 세트 내 기준일 중복 시 경고 표시 후 사용자 확인이 필요하다.
5. 사용 중지된 정책은 신규 적용만 차단되고 기존 사용 지점은 그대로 동작하되, 영향 범위가 고지된다.
6. 지점 수정 허용 범위에 따라 지점 단위 정책 수정 권한이 달라진다(토글/채널만/변경불가).
7. 모든 정책 변경은 감사 로그(SCR-097)에 기록된다.
8. 기본 정책으로 지정된 세트는 신규 지점 등록 시 자동 적용된다.
