## 기능 목적

전체 지점의 현황을 조회하고, 신규 지점을 등록하거나 기존 지점의 상태를 변경하는 화면이다. 지점 간 통합 성과 비교를 통해 어느 지점이 잘 운영되고 있는지, 어느 지점이 지원이 필요한지 파악한다. 본사 차원의 인사·자원 배분 의사결정 자료로 활용된다.

## 주요 구성요소

### 지점 목록

| 컬럼 | 설명 |
|------|------|
| 지점명 | 이름 |
| 지점 코드 | 고유 ID |
| 주소 | 위치 |
| 연락처 | 010 자동 |
| 회원 수 | 활성 카운트 |
| 직원 수 | 카운트 |
| 운영 상태 | 운영 중 / 임시휴업 / 폐점 |
| 등록일 | YYYY-MM-DD |
| 액션 | [수정] / [비활성화] |

### 검색 / 필터

- 지점명 / 주소 키워드
- 운영 상태 (전체 / 운영 / 휴업 / 폐점)

### 신규 지점 등록 (DLG-092-001)

| 항목 | 입력 |
|------|------|
| 지점명 | 텍스트 (필수) |
| 지점 코드 | 자동 또는 수동 |
| 주소 | 주소 검색 |
| 연락처 | 010 |
| 운영 시작일 | 캘린더 |
| 초기 센터장 | 직원 검색 |
| 정책 세트 적용 | 본사 표준 |

### 비활성화 확인 (DLG-092-002)

비활성화 시 진행 중 회원·직원·예약 영향 안내.

### 통합 현황 비교 탭

지점별 회원 수 / 매출 / 출석률을 기간(월간/주간/연간)으로 비교.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 | 등록·수정·비활성·비교 |
| owner (센터장) | 소속 지점 | 소속 지점 정보 수정 |
| manager 이하 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**지점 조회**
1. 사이드바 → "본사관리 > 지점 관리" 진입
2. 전체 지점 목록 자동 로드
3. 검색·필터로 좁히기

**신규 등록**
1. [신규 지점 등록] → DLG-092-001
2. 지점명·코드·주소·연락처·운영 시작일·초기 센터장 입력
3. 정책 세트 적용 → 저장
4. 목록 추가

**비활성화**
1. [비활성화] → DLG-092-002
2. 진행 중 회원·예약 영향 안내
3. 확인 → 운영 상태 변경

**통합 비교**
1. "통합 현황 비교" 탭
2. 기간 선택 → 차트·테이블

## 비즈니스 규칙

1. 지점 코드는 시스템 내 고유값으로 중복 등록 불가하다.
2. 비활성화 시 진행 중 회원·직원·예약은 유지되며 신규 등록만 차단된다 (운영 정책).
3. 폐점 처리 시 데이터는 N개월 보관 후 아카이브된다.
4. 초기 센터장은 직원관리(STF)에서 등록된 직원만 매핑 가능하다.
5. 정책 세트 적용 시 본사 표준이 기본이며 지점별 커스터마이징은 SCR-080A에서 수행한다.
6. 지점 등록·수정·비활성화 이력은 감사 로그에 기록된다.
7. 매니저 이하는 지점 관리 화면에 접근할 수 없다.
