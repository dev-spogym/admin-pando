## 기능 목적

역할별로 맞춤화된 KPI 보드를 제공하는 종합 센터 화면이다. 본사, 지점, FC, 트레이너, 운영 5가지 관점에서 핵심 지표, 우선 업무 큐, 성과 랭킹, 단계별 퍼널, 데이터 인사이트를 한 화면에서 확인하고 바로 실행 화면으로 이동한다. 단순 조회를 넘어 즉시 액션 가능한 운영 지휘 도구.

운영 맥락:
- **본사 superAdmin 전체 현황 파악**: 5개 보드 자유 전환 → 지점별 FC 퍼널·트레이너 OT 전환율 비교 → 미달 지점 즉시 드릴다운
- **owner(센터장) 일일 점검**: 지점 보드 자동 선택 → 핵심 4종 카드 + 액션 큐 → 오늘 처리 우선순위 파악
- **FC 상담 병목 자가 점검**: FC 보드 진입 → TI/WI 분리 퍼널 → 미방문·미등록 액션 큐 → 리드 관리 화면 이동
- **트레이너 OT 실적 확인**: 트레이너 보드 → OT 배정·전환율·1·2차 완료 현황 → 미등록 체험자 후속 조치
- **매니저 운영 보드 확인**: 운영 보드 → 출석·미수금·노쇼 현황 → 당일 처리 액션
- **역할 변경 직후 즉시 반영**: 관리자가 FC→트레이너 역할 변경 → 다음 로그인 시 보드 자동 전환
- **데이터 인사이트로 원인 파악**: 전환율 급락 시 인사이트 패널 → 원인 코멘트 + 다음 액션 3개 제시

## 주요 구성요소

### 역할별 보드 탭 (5종)

본사 / 지점 / FC / 트레이너 / 운영. 로그인 역할에 맞는 보드 기본 선택.

### 핵심 지표 카드 (4개씩)

| 보드 | 핵심 지표 |
|------|---------|
| FC 보드 | 신규 리드 / TI 방문 전환율 / WI 등록률 / TI 등록률 |
| 지점/FC | 재등록 상담 완료 / 재등록 성공률 (보조) |
| 트레이너 | OT 배정 합계 / OT 등록 전환율 / OT 체험→등록률 / OT 1·2차 완료·예정 |

### FC 상담 퍼널

리드 유입 → 첫 응답 → 대면 상담/방문 → 등록 완료 단계.

### 액션 큐

오늘 처리 우선 업무 (긴급/우선/일반/완료가능).

| 보드 | 우선 액션 |
|------|---------|
| FC | 전화 문의 후 미방문 / 방문 후 미등록 / 상담 결과 미기입 / 만료 예정 재등록 |
| 트레이너 | OT 1차 예정 / OT 2차 예정 / OT 완료 후 미등록 / 체험 후 미등록 |

### 랭킹 / 리스트 패널

본사·지점은 성과 랭킹, FC·트레이너는 처리 리스트.

### 재등록 파이프라인

상담 완료 / 성공률 / 만료 예정 재등록 상담 액션.

### 담당자 성과 (개인 KPI)

| 역할 | 비교 지표 |
|------|---------|
| 트레이너 | OT 배정 / 신규 매출 / 재등록 매출 / 등록 전환율 / 체험→등록률 |
| FC | 상담 건수 / 상담 → 등록 전환율 |
| 골프 프로 | `[매출종합]` 골프매출 등록강사별 |

### 트레이너 OT 보드

OT 등록 전환율 / 체험→등록률 / 1·2차 완료·예정 위젯 / 거절 (거부+보류).

### 데이터 인사이트

원인 + 다음 액션 3개 이내 코멘트. 데이터 없으면 "실데이터 연동 필요" 안내.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 보드 | 모든 탭 전환·전 지점 |
| owner / 지점 관리자 | 소속 지점 보드 | 지점/FC/운영 보드 |
| fc | FC 보드 | 담당 리드·액션 큐 |
| 트레이너 | 트레이너 보드 | 담당 수업/회원 KPI |
| 스태프 | 운영 보드 | 출석·미수·운영 액션 |
| readonly | 보드 조회 | 조회만 |

## 주요 UX 흐름

1. 사이드바 → "본사관리 > KPI 센터" 진입
2. 역할 기반 보드 자동 선택
3. 핵심 지표 카드 + 액션 큐 확인
4. FC 보드: TI/WI 분리 → 병목 식별
5. 액션 큐 클릭 → 처리 실행 화면 이동
6. 바로가기로 Today Tasks/매출/회원 이동

## 비즈니스 규칙

1. WI(Walk In) = 방문 문의, TI(Telephone Inquiry) = 전화 문의로 통일 표기.
2. 상담 방식은 `대면`/`유선`/`부재` 3종 제한.
3. TI 방문 전환은 TI 문의 중 1·2·3차 상담 방식에 `대면` 기록된 건이다.
4. 트레이너 OT 등록 전환율은 PT 완료율과 합산 금지 (별도 운영 KPI).
5. OT 이월률은 `이월 건수 / OT배정 인원 × 100`으로 산출한다.
6. 트레이너별 OT 배정은 `[강습업무보고]` E열을 기준으로 한다.
7. 트레이너별 신규/재등록 매출은 `[매출종합]`이 공식 원천이며 `[강습업무보고]` J·K열은 검산 보조.
8. FC별 상담 → 등록 전환율 = A열 `등록` ÷ A열 `등록+관리+실패`.
9. 골프 프로 매출은 `[매출종합]` 골프매출 K열 등록강사 + F열 결제금액 기준.
10. 환불 → 재결제 복귀율은 본 화면에 추가하지 않는다.
11. 보드 탭 기본 선택은 로그인 계정의 역할(role) 필드 기반이며 세션 동안 수동 전환 가능하다.
12. 보드 레이아웃 freeze는 본사 superAdmin만 설정 가능하며, freeze 중 탭 전환은 해제 확인 필요.
13. 데이터 인사이트 코멘트는 원인 + 다음 액션 최대 3개로 제한한다.
14. 실데이터 미연동 카드는 "연동 필요" 상태로 표시하며 기능 오류로 처리하지 않는다.
15. 액션 큐 우선순위 4단계: 긴급(빨강) > 우선(주황) > 일반(파랑) > 완료가능(회색).
16. 액션 큐 완료 처리는 Today Tasks(HQ-06)와 양방향 동기화된다.
17. FC 상담 퍼널 4단계: 리드 유입 → 첫 응답 → 대면 상담/방문 → 등록 완료.
18. 역할 변경(권한 수정) 후 KPI센터 재진입 시 보드가 즉시 갱신된다.
19. 바로가기 링크(Today Tasks/매출/회원/자동알림)는 모든 보드에서 공통 표시된다.
20. KPI 센터 보드 데이터는 5분 캐시 적용 (HQ-02 대시보드와 동일 캐시 레이어 공유).
21. 트레이너 보드의 OT 1·2차 완료·예정 위젯은 오늘 날짜 기준으로 자동 필터된다.
22. 랭킹 패널 정렬 기준: 본사·지점은 달성률 높은 순, FC·트레이너는 처리 건수 많은 순.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `HQ-03`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-095`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
