## 기능 목적

노쇼(무단 불참) 또는 늦은 취소로 인해 회원에게 부과된 페널티 현황을 조회하고, 페널티 정책을 설정하는 화면이다. 페널티를 통해 무단 결석을 억제하고 수업 자리가 낭비되지 않도록 운영 규율을 유지한다. 자동 페널티 정책으로 운영 부담을 줄이고, 부당한 페널티는 관리자가 수동 해제할 수 있다.

## 주요 구성요소

### 탭 구조

페널티 현황 / 정책 설정 2개 탭.

### 페널티 현황 탭

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 페널티 유형 | 노쇼 / 늦은 취소 |
| 부과일 | YYYY-MM-DD HH:mm |
| 해당 수업 | 수업명 + 일시 |
| 페널티 내용 | 예약 제한 N일 / 횟수 차감 N회 |
| 상태 | 적용 중 / 해제 |
| 액션 | [해제] |

#### 페널티 현황 액션

- **회원 검색 필터**
- **유형 필터**: 노쇼 / 늦은 취소
- **상태 필터**: 적용 중 / 해제
- **수동 등록 버튼**: [+ 페널티 등록] → DLG-C014
- **해제 버튼**: 행별 [해제] → 확인 → 해제

### 정책 설정 탭

| 항목 | 입력 |
|------|------|
| 자동 페널티 토글 | ON / OFF |
| 자동 페널티 규칙 | DLG-C015 |
| 늦은 취소 기준 시간 | 예: 수업 시작 2시간 전 |
| 페널티 내용 | 예약 제한 N일 / 횟수 차감 N회 |
| 노쇼/취소 정책 | DLG-C007 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 페널티 + 정책 | 등록·해제·정책 변경 |
| owner (센터장) | 전체 페널티 + 정책 | 등록·해제·정책 변경 |
| manager | 전체 페널티 + 정책 | 등록·해제·정책 변경 |
| 트레이너 | 담당 회원 페널티 | 조회만 |
| fc / 스태프 | 전체 페널티 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**페널티 조회**
1. SCR-C001 → "페널티 관리" 탭 또는 `/penalties` 직접 진입
2. 페널티 현황 탭 → 회원·유형·상태 필터
3. 적용 중인 페널티 목록 확인

**수동 페널티 부과**
1. [+ 페널티 등록] → DLG-C014
2. 회원 선택 + 사유 + 페널티 내용 입력
3. 저장 → 즉시 적용

**페널티 해제**
1. 행 [해제] → 확인
2. 해제 사유 입력
3. 상태 변경 + 회원 알림

**자동 정책 설정**
1. 정책 설정 탭 → 자동 페널티 토글
2. DLG-C015에서 규칙 설정
3. 늦은 취소 기준·페널티 내용 저장

## 비즈니스 규칙

1. 자동 페널티 활성 시 노쇼 또는 늦은 취소 발생 즉시 페널티가 부과된다.
2. 늦은 취소 기준 시간(기본 2시간)은 정책에서 변경 가능하며 수업별로 다르게 설정할 수 있다.
3. 페널티 내용은 예약 제한 일수 또는 횟수 차감으로 구성되며 복합 적용도 가능하다.
4. 1회 노쇼는 경고, 누적 3회 시 예약 제한 등 단계별 정책을 설정할 수 있다.
5. 부당한 페널티는 manager+가 수동 해제할 수 있으며 해제 사유는 필수이다.
6. 페널티 부과·해제는 회원에게 자동 알림이 전송되고 감사 로그(SCR-097)에 기록된다.
7. 노쇼/취소 정책(DLG-C007)은 회원앱에 표시되어 회원이 사전 인지할 수 있다.
