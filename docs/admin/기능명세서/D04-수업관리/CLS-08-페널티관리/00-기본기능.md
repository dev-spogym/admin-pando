## 기능 목적

노쇼(무단 불참) 또는 늦은 취소로 인해 회원에게 부과된 페널티 현황을 조회하고, 페널티 정책을 설정하는 화면이다. 페널티를 통해 무단 결석을 억제하고 수업 자리가 낭비되지 않도록 운영 규율을 유지한다. 자동 페널티 정책으로 운영 부담을 줄이고, 부당한 페널티는 관리자가 수동 해제할 수 있다.

운영 맥락:
- **노쇼 다발 회원 단계별 페널티**: 1회 경고 → 누적 3회 예약 제한 7일 → 누적 5회 PT 횟수 1회 차감.
- **부당 페널티 해제**: 회원의 의료 사유로 노쇼 발생 → 운영자 검토 후 [해제] + 사유 "의료 사유".
- **자동 페널티 크론 (A05)**: 매분 노쇼 자동 부과, 늦은 취소 자동 부과 → 운영자 부담 최소화.
- **수업별 정책 차이**: PT는 노쇼 1회당 횟수 차감, GX는 예약 제한만 → 수업별 차등 정책.
- **회원 분쟁 대응**: 페널티 부과 사유 + 처리자 + 시각 기록 → 분쟁 시 증빙.
- **노쇼/취소 정책 회원앱 표시 (DLG-C007)**: 사전 인지 → 페널티 분쟁 감소.
- **신규 회원 페널티 면제**: 첫 노쇼는 경고만 (정책 활성 시).
- **본사 페널티 정책 표준화**: 본사가 표준 정책 배포 → 지점은 변경 불가/허용 옵션.

## 주요 구성요소

### 탭 구조

페널티 현황 / 정책 설정 2개 탭.

### 페널티 현황 탭

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 페널티 유형 | 노쇼 / 늦은 취소 |

| 해당 수업 | 수업명 + 일시 |
| 페널티 내용 | 예약 제한 N일 / 횟수 차감 N회 |
| 상태 | 적용 중 / 해제 |
| 액션 | [해제] |

#### 페널티 현황 액션

- **회원 검색 필터**
- **유형 필터**: 노쇼 / 늦은 취소
- **상태 필터**: 적용 중 / 해제
- **수동 등록 버튼**: [+ 페널티 등록] → DLG-C014
- **해제 버튼**: 행별 [해제] → 확인 → 해제

## 주요 UX 흐름

**페널티 조회**
1. SCR-C001 → "페널티 관리" 탭 또는 `/penalties` 직접 진입
2. 페널티 현황 탭 → 회원 검색·유형·상태·기간 필터
3. 적용 중·해제 페널티 목록 확인

**수동 페널티 부과 (DLG-C014)**
1. [+ 페널티 등록] → DLG-C014
2. 회원 선택 + 페널티 유형 (노쇼/늦은 취소/기타) + 사유 + 페널티 내용 입력
3. 저장 → 즉시 적용 + 회원 알림 발송

**페널티 해제**
1. 행 [해제] → 해제 사유 입력 (필수)
2. 상태 "적용 중" → "해제" 변경 + 회원 알림
3. 페널티가 횟수 차감이었다면 횟수 자동 복구 (CLS-07)

**자동 정책 설정 (DLG-C015)**
1. 정책 설정 탭 → 자동 페널티 토글
2. DLG-C015에서 단계별 규칙 (1회/3회/5회 등)
3. 늦은 취소 기준·페널티 내용 저장
4. DLG-C007 노쇼/취소 정책은 회원앱에 자동 노출

### 분기 · 예외 · 롤백
- **자동 부과 후 부당 검토**: [해제] + 사유 → 페널티 해제 + 횟수 복구 (해당 시)
- **단계별 정책 적용**: 누적 카운트 기반 → 카운트는 정책에 따라 30일/90일/영구
- **수동 부과 시 사유 미입력**: 인라인 에러 + 저장 차단
- **해제 사유 미입력**: 차단
- **페널티 적용 중 회원 예약 시도**: 예약 제한 활성 시 회원앱 예약 차단 + 안내
- **횟수 차감 페널티 vs 잔여 0**: 차감 차단 → 다음 결제 후 차감 옵션 (정책에 따라)
- **본사 표준 정책 활성 시 지점 변경 시도**: 차단 + 안내

## 비즈니스 규칙

1. 자동 페널티 활성 시 노쇼 또는 늦은 취소 발생 즉시 페널티가 부과된다.
2. **늦은 취소 기준 시간**: 기본 2시간 (수업 시작 N시간 전 이내 취소). 수업별로 다르게 설정 가능.
3. **페널티 내용 종류**: 예약 제한 N일 / PT 횟수 차감 N회 / 둘 다 복합. 경고만(0일/0회)도 가능.
4. **단계별 정책**: 1회 경고, 누적 3회 예약 제한 7일, 누적 5회 횟수 차감 등. 누적 기간 정책 (30/90/영구).
5. **수동 해제 권한**: manager+, 해제 사유 필수.
6. **사유 필수**: 수동 부과·해제 모두 사유 텍스트(최소 5자) 필수.
7. **부과·해제 알림**: 회원에게 자동 알림 (NFR-19) + 감사 로그(SCR-097).
8. **노쇼/취소 정책 (DLG-C007)**: 회원앱에 자동 노출 → 사전 인지.
9. **수업별 차등 정책**: PT/GX/필라테스 등 수업 유형별 페널티 차등 가능.
10. **횟수 차감 → 잔여 부족**: 차감 시 잔여 0 시 다음 결제 후 차감 옵션 (정책에 따라 즉시 차단 또는 보류).
11. **예약 제한 적용 회원 예약 차단**: 회원앱 + 운영자 등록 모두 차단 + 페널티 만료 후 자동 해제.
12. **자동 페널티 크론 (A05)**: 매분 실행. 노쇼·늦은 취소 자동 부과.
13. **출석 정정 시 자동 해제**: 노쇼 → 출석 정정(CLS-02) 시 자동 페널티 자동 해제 + 횟수 복구.
14. **본사 표준 정책**: 활성 시 지점 변경 차단, 비활성 시 지점 자율.
15. **신규 회원 면제 정책**: 활성 시 첫 노쇼는 경고만 (정책에 따라).
16. **페널티 누적 카운트 정책**: 30일/90일/영구 윈도우 — 본사 결정.
17. **권한**: manager+ 등록·해제·정책 변경, 트레이너 본인 담당 회원 조회만, FC 조회만.
18. **본사 통합 모드**: 지점 컬럼 + 전 지점 합산.
19. **데이터 보관**: 페널티 이력 영구 보관 (분쟁 대응).
20. **트레이너 알림**: 담당 회원 페널티 부과 시 트레이너에게도 알림 (정책에 따라).
21. **회원앱 표시**: 적용 중 페널티는 회원앱 마이페이지에 표시.
