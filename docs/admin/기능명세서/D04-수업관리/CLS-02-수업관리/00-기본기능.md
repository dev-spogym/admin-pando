## 기능 목적

등록된 수업 전체를 목록으로 조회하고 상태별로 필터링하는 화면이다. 개별 수업의 출석 현황을 확인하고 수업 정보를 수정하거나 취소 처리할 수 있다. 캘린더 뷰(SCR-C001)의 보조 화면으로, 목록 기반의 정밀한 수업 관리가 필요할 때 사용한다. 강습 세션은 KPI 집계를 위해 PT / 필라테스 / 스트레칭 / 테라피 세션 유형을 함께 표시한다.

## 주요 구성요소

### 탭 내비게이션

수업 캘린더와 동일한 탭 구조 (일정표 / 수업 관리 / 횟수 관리 / 페널티 / 유효 수업 목록). 현재 탭 "수업 관리" 활성.

### 필터 바

| 필터 | 설명 |
|------|------|
| 강사 | 드롭다운 |
| 장소 | 드롭다운 |
| 강습 세션 유형 | PT / 필라테스 / 스트레칭 / 테라피 |

### 상태 필터 버튼

전체 / 예정 / 진행중 / 완료 / 취소 토글 (단일).

### 수업 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 수업명 | 클릭 시 DLG-C003 |
| 유형 | PT / GX / 개인레슨 / 기타 |
| 강습 세션 유형 | PT / 필라테스 / 스트레칭 / 테라피 |
| 강사 | 담당 강사명 |
| 장소 | 룸 / 스튜디오 |
| 날짜·시간 | YYYY-MM-DD HH:mm |
| 예약 현황 | 현재 / 정원 |
| 상태 배지 | 예정·진행중·완료·취소 |
| 출석 / 노쇼 | 카운트 표시 |

### 행 클릭 → DLG-C003

수업 등록/수정 다이얼로그. 완료된 수업은 DLG-C005 수업 기록 상세 + DLG-C006 서명 표시.

### 수업 등록 버튼

상단 우측 [+ 수업 등록] → DLG-C003 진입.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 수업 | 등록·수정·취소·출석 |
| owner (센터장) | 전체 수업 | 등록·수정·취소·출석 |
| manager | 전체 수업 | 등록·수정·취소·출석 |
| 트레이너 | 본인 담당 수업 | 담당 수업 수정·출석 |
| fc / 스태프 | 전체 조회 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**수업 조회 + 수정**
1. SCR-C001 → "수업 관리" 탭 또는 `/lessons` 직접 진입
2. 강사·장소 필터 + 상태 버튼으로 좁히기
3. 수업 행 클릭 → DLG-C003 정보 확인·수정
4. 저장 → 토스트 + 목록 갱신

**완료 수업 기록 확인**
1. 완료 상태 행 클릭 → DLG-C005
2. 출석·서명 기록 확인

**수업 취소**
1. 행 → [취소] → 사유 입력 → 확인
2. 회원 알림 자동 발송

## 화면 상태

| 상태 | 설명 |
|---|---|
| 전체 목록 | 필터 없이 전체 수업 |
| 상태 필터 적용 | 예정·진행중·완료·취소 중 하나 |
| 검색 결과 없음 | "조건에 맞는 수업이 없어요" |
| 로딩 | 스켈레톤 |
| 처리 중 | 버튼 로딩 |

## 비즈니스 규칙

1. `수업 유형`은 화면 운영 분류이며, `강습 세션 유형`은 KPI 산출용 세부 분류이다.
2. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정하며, 본사 KPI 대시보드의 강습세션수 집계 원천이다.
3. 수업 완료 시 회원의 PT 횟수가 자동 차감된다 (CLS-07 횟수 관리 연동).
4. 수업 취소 시 회원에게 알림이 자동 발송되고 PT 횟수는 복구된다.
5. 노쇼 처리는 자동 페널티 정책(CLS-08)에 따라 페널티가 부과될 수 있다.
6. 트레이너는 본인 담당 수업만 수정 가능하다.
