## 기능 목적

PT 이용권을 보유한 회원의 잔여 수업 횟수를 조회하고, 필요 시 횟수를 수동으로 조정하는 화면이다. 수업 진행 후 자동 차감되지 않은 경우나, 환불·보상·오류 정정이 필요한 경우 관리자가 직접 횟수를 추가하거나 차감한다. 차감 이력은 모두 기록되어 회원 분쟁 시 증빙으로 활용된다.

## 주요 구성요소

### 회원 검색

이름 또는 전화번호 통합 검색 (디바운스 300ms).

### 회원 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 회원 상세 |
| 연락처 | 010 자동 |
| 이용권명 | PT 10회 / OT 2회 등 |
| 구매 횟수 | 총 구매 |
| 사용 횟수 | 차감 누적 |
| 잔여 횟수 | 구매 - 사용 |
| 만료일 | YYYY-MM-DD |
| 액션 | [조정] / [이력] |

### 잔여 강조

| 잔여 | 색상 |
|------|------|
| 0회 | 빨강 |
| 1~3회 | 주황 |
| 4회 이상 | 기본 |

### 횟수 조정 (DLG-C012)

| 항목 | 입력 |
|------|------|
| 조정 유형 | 추가 / 차감 |
| 조정 횟수 | 숫자 |
| 사유 | 환불·보상·오류 정정 등 (필수) |
| 비고 | textarea (선택) |

### 차감 이력 (DLG-C013)

| 컬럼 | 설명 |
|------|------|
| 일시 | YYYY-MM-DD HH:mm |
| 변경 유형 | 자동 차감 / 수동 조정 / 환불 복구 |
| 수업명 | 자동 차감인 경우 |
| 변경 횟수 | +/- |
| 잔여 | 변경 후 |
| 처리자 | 작성자 |
| 사유 | 메모 |

### 필터

| 필터 | 설명 |
|------|------|
| 잔여 횟수 부족 | 3회 이하만 |
| 만료 임박 | 7일 이내 |
| 이용권 종류 | PT / OT |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 회원 횟수 | 조정·이력 |
| owner (센터장) | 전체 회원 횟수 | 조정·이력 |
| manager | 전체 회원 횟수 | 조정·이력 |
| 트레이너 | 담당 회원 횟수 | 이력 조회만 (조정 불가) |
| fc / 스태프 | 전체 회원 횟수 | 조회·이력 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**잔여 조회**
1. SCR-C001 → "횟수 관리" 탭 또는 `/lesson-counts` 직접 진입
2. 회원 검색 또는 잔여 부족 필터
3. 잔여·만료일 확인

**횟수 조정**
1. 회원 행 [조정] → DLG-C012
2. 추가/차감 선택 + 횟수 + 사유 입력
3. 저장 → 잔여 갱신 + 이력 추가

**차감 이력 확인**
1. 회원 행 [이력] → DLG-C013
2. 자동/수동/환불 구분 + 처리자 확인

## 비즈니스 규칙

1. 수업 완료 시 회원의 PT 횟수가 자동 차감된다 (CLS-02 수업 관리 연동).
2. 환불 처리 시 잔여 횟수가 자동 복구된다.
3. 수동 조정은 manager+만 가능하며 사유 입력은 필수이다.
4. 모든 차감·조정 이력은 append-only로 기록되며 감사 로그(SCR-097)에 기록된다.
5. 트레이너는 담당 회원의 이력만 조회 가능하며 조정은 불가하다.
6. 만료 7일 이내 이용권은 주황 배지로 강조되어 회원 안내(MKT)와 연동될 수 있다.
