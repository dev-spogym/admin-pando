## 기능 목적

PT 이용권을 보유한 회원의 잔여 수업 횟수를 조회하고, 필요 시 횟수를 수동으로 조정하는 화면이다. 수업 진행 후 자동 차감되지 않은 경우나, 환불·보상·오류 정정이 필요한 경우 관리자가 직접 횟수를 추가하거나 차감한다. 차감 이력은 모두 기록되어 회원 분쟁 시 증빙으로 활용된다.

운영 맥락:
- **수업 시스템 오류 보상**: 시스템 장애로 회원이 수업을 못 받음 → 횟수 +1 보상 (사유 "시스템 오류 보상").
- **출석 정정에 따른 차감 정정**: 출석 처리 후 잘못 처리된 것 발견 → 횟수 +1 복구 (사유 "오류 정정").
- **회원 환불 처리 (CLS-02 → SCR-S007)**: 잔여 횟수만큼 환불 → 잔여 0으로 차감 (자동).
- **회원 횟수 부족 안내 마케팅 (MKT)**: 잔여 3회 이하 회원 추출 → 재구매 마케팅.
- **만료 임박 회원 안내**: 만료 7일 이내 → 회원에게 알림 + FC 응대.
- **회원 분쟁 대응**: DLG-C013 차감 이력 → 자동/수동/환불 구분 + 처리자 + 사유 → 분쟁 증빙.
- **PT 횟수 양도 (정책 활성 시)**: 친구·가족에게 일부 횟수 양도 → 차감 + 추가 동시 처리.
- **트레이너 본인 회원 잔여 점검**: 담당 회원 잔여 확인 → 다음 수업 일정 안내.

## 주요 UX 흐름

**잔여 조회**
1. SCR-C001 → "횟수 관리" 탭 또는 `/lesson-counts` 직접 진입
2. 회원 검색(이름/연락처, 디바운스 300ms) 또는 잔여 부족·만료 임박 필터
3. 잔여·만료일·이용권명 확인 + 색상 강조 (잔여 0 빨강, 1~3 주황)

**횟수 조정 (DLG-C012)**
1. 회원 행 [조정] → DLG-C012
2. 추가/차감 선택 + 횟수 + 사유 입력 (필수, 최소 5자)
3. 변경 미리보기 (현재 잔여 → 변경 후 잔여)
4. 저장 → 잔여 갱신 + 이력 자동 추가 + 회원 알림 (선택)

**차감 이력 확인 (DLG-C013)**
1. 회원 행 [이력] → DLG-C013
2. 시간순 정렬 + 변경 유형 필터 (자동/수동/환불)
3. 처리자·사유·수업명·전후 잔여 확인

### 분기 · 예외 · 롤백
- **차감으로 잔여 음수 발생 시도**: "잔여가 부족해요" 차단 → 환불 화면 안내
- **사유 미입력 / 5자 미만**: 인라인 에러 + 저장 차단
- **트레이너 조정 시도**: 버튼 hidden, 이력 조회만
- **이용권 만료 후 조정**: 만료된 이용권은 조정 차단 (정책에 따라 보상 추가만 허용)
- **자동 차감 중복 발생**: 멱등성 키(lesson_id)로 중복 차단
- **환불 후 자동 복구 vs 수동 차감 충돌**: 환불 트랜잭션 락 + 사유 자동 기록
- **append-only 정책**: 이력은 삭제 불가, 정정은 새 이력 추가 (역방향 조정)

## 비즈니스 규칙

1. 수업 완료(출석 처리) 시 회원의 PT 횟수가 자동 차감된다 (CLS-02 수업 관리 연동).
2. 환불 처리 시 잔여 횟수가 자동 복구된다 (SCR-S007 연동).
3. **수동 조정 권한**: manager+만 가능, 트레이너는 이력 조회만.
4. **사유 필수**: 모든 수동 조정에 사유 텍스트(최소 5자) 입력 필수.
5. **append-only 이력**: 차감·조정 이력은 모두 append-only로 기록, 삭제 불가 (정정은 역방향 추가).
6. 모든 차감·조정 이력은 감사 로그(SCR-097)에 기록된다.
7. **트레이너 권한**: 담당 회원 이력 조회만, 조정 불가.
8. **만료 임박 정의**: 만료일 - 7일 이내, 주황 배지 + 회원 안내(MKT) 연동.
9. **잔여 음수 방지**: 차감으로 잔여 음수 발생 시 차단.
10. **만료된 이용권 조정 정책**: 차감 차단, 추가는 정책에 따라 허용 (보상 등).
11. **멱등성 키**: 자동 차감은 `lesson_id` 기준 멱등성 → 중복 차감 방지.
12. **변경 유형 분류**: 자동 차감 / 수동 조정(추가) / 수동 조정(차감) / 환불 복구 / 양도.
13. **회원 알림 옵션**: 조정 시 회원 알림 발송 여부 선택 (기본 ON, manager+ OFF 가능).
14. **잔여 색상**: 0 빨강, 1~3 주황, 4+ 기본.
15. **만료일 정책**: 이용권 발급 시 결정 (예: 6개월), 잔여 0이어도 만료 전까지 추가 결제로 연장 가능.
16. **양도 정책 (테넌트별)**: 활성 시 회원 간 양도 가능 (한쪽 차감 + 다른 쪽 추가, 트랜잭션).
17. **차감 이력 보관 기간**: 영구 (분쟁 대응).
18. **본사 통합 모드**: superAdmin/primary는 지점 컬럼 + 전 지점 합산.
19. **검색 정규화**: 연락처는 하이픈 제거 후 비교.
20. **회원 상세 점프**: 회원명 클릭 → SCR-M004 회원 상세.
21. **DLG-C013 정렬**: 시간 역순 (최신 우선), 컬럼 클릭 정렬 가능.
