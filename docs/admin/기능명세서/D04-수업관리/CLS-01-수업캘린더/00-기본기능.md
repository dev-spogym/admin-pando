## 기능 목적

PT 및 그룹 수업 전체 일정을 캘린더 형태로 한눈에 파악하는 메인 수업 관리 화면이다. 월·주·일·목록(list) 뷰를 자유롭게 전환하며 수업 유형과 강사를 색상으로 구분해 일정을 직관적으로 확인하고, 빈 슬롯 클릭 또는 드래그&드롭으로 빠르게 수업을 등록·수정한다. 강습 세션은 KPI 집계를 위해 PT / 필라테스 / 스트레칭 / 테라피 4종 세션 유형을 함께 관리하며, 본사 KPI 대시보드의 강습세션수 집계 원천이 된다.

운영 맥락:
- **센터장(owner) 아침 일정 점검**: 출근 직후 일 뷰로 당일 강사·룸 충돌·미승인 일정·OT 신규를 5분 안에 일괄 점검 후 재배정 결정.
- **매니저 주간 시간표 운영**: 주 뷰에서 강사별 색상으로 부하 편중 식별 → 빈 시간대 GX 추가 개설, 한산 시간대 통합·취소 검토.
- **트레이너 본인 일정 관리**: DnD로 회원 요청 시간 변경 즉시 반영, 충돌 시 즉시 경고로 잘못된 약속 차단.
- **FC 신규 회원 OT 슬롯 확인**: 일·주 뷰에서 강사별 OT 빈 슬롯 확인 → DLG-C001로 OT 등록.
- **본사 슈퍼관리자 통합 모니터링**: 전 지점 캘린더(통합 모드) → 강습세션수 KPI(SCR-D003) 원천 검증.
- **휴관일·공휴일 운영**: 일괄 변경(DLG-C004)으로 해당 일자 수업 취소/이동 일괄 처리.
- **강사 결근·휴가 발생 시 대체**: 미승인 배너 + 일괄 변경으로 대체 강사 일괄 배정.
- **회원앱 예약 충돌 확인**: 회원앱 예약이 강사·룸 충돌을 만들면 캘린더에서 즉시 빨간 경고 → 운영자 조정.

KPI 정의 원칙: 화면 표시 축약(P.T·필라)와 무관하게 저장·집계는 4종 고정값(PT / 필라테스 / 스트레칭 / 테라피)을 사용해 본사 KPI 대시보드의 강습세션수와 1:1 매칭한다.

## 주요 구성요소

### 뷰 전환 탭

월 / 주 / 일 / 목록(list) 4개 뷰. 뷰 전환 시 캘린더 표시 밀도와 인터랙션이 달라진다.

### 상단 액션 버튼

| 버튼 | 동작 |
|------|------|
| 스케줄 일괄 변경 | DLG-C004 진입 |
| 수업 등록 | DLG-C001 진입 |

### 탭 내비게이션

일정표 / 수업 관리(SCR-C002) / 횟수 관리(SCR-C007) / 페널티 관리(SCR-C008, 건수 배지) / 유효 수업 목록(SCR-C011).

### 필터 바

| 필터 | 설명 |
|------|------|
| 강사 | 드롭다운 (단일) |
| 수업명 | 드롭다운 (단일) |
| 정원 상태 | 전체 / 여유 / 마감 토글 |
| 분류 멀티필터 | 상담·OT·체성분·방문·수업·PT·기타 (다중) |
| 강습 세션 유형 | PT / 필라테스 / 스트레칭 / 테라피 (다중) |

### 색상 범례

화면 하단에 강사별·수업 유형별·강습 세션 유형별·분류별 색상 칩 표시.

### 캘린더 영역

- 수업 블록 클릭 → DLG-C002 일정 상세
- 빈 슬롯 클릭 → DLG-C001 수업 등록
- 드래그&드롭 → 시간 이동
- 블록 하단 핸들 드래그 → 시간 연장

### 우측 패널

선택한 날짜의 수업 목록 카드 (수업명·강사·시간·예약 현황·정원 바).

### 미승인 일정 알림 배너

미승인 일정이 있을 때 상단에 주황색 경고 배너 + 건수.

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "수업관리 > 캘린더" 진입 → 이번 달 월 뷰
2. 뷰 전환 (월/주/일/목록) — 일 뷰는 시간 그리드(05:00~23:00, 30분 단위) 표시
3. 강사·수업명·분류·세션 유형 필터로 좁히기 → 색상 범례에 잔여 그룹만 노출
4. 우측 패널에서 날짜별 카드(예약 현황·정원 바) 확인 + 회원 클릭 시 SCR-M004 점프

**수업 등록 (빈 슬롯 → DLG-C001)**
1. 빈 슬롯 클릭 → 시작 시간 자동 채움
2. 수업 유형·강사·장소·정원·세션 유형 4종 입력
3. 충돌 검증 통과 시 저장, 회원 예약 즉시 가능
4. 미승인 정책 활성 테넌트면 상태 "미승인" → 센터장 승인 후 활성

**수업 수정 (DnD)**
1. 블록 드래그 → 5분 단위 스냅 → 임시 위치 표시
2. 드롭 직전 충돌 검사 (강사·장소·회원 중복) → 빨강이면 "충돌이 발생했습니다" 모달 + [원위치 복원]
3. 통과 시 저장 → 회원·강사 알림 발송
4. 실패 시 원위치 자동 롤백 + 오류 토스트

**시간 연장 (핸들 드래그)**
1. 블록 하단 핸들 드래그 → 종료 시간 5분 단위 변경
2. 다음 수업과 겹치면 빨강 + 차단

**일괄 변경 (DLG-C004)**
1. [스케줄 일괄 변경] → 기간·강사·요일 선택
2. 변경 항목(강사/시간/장소/취소) 선택 → 미리보기에서 충돌 강조
3. 적용 → 백그라운드 잡 처리, 진행률 토스트
4. 완료 후 캘린더 갱신 + 알림 발송

### 분기 · 예외 · 롤백
- **DnD 중 페이지 이탈**: 변경 미확정 → 자동 원위치 + "변경이 취소되었어요" 토스트
- **저장 도중 네트워크 오류**: 5초 retry 1회 → 실패 시 원위치 복원, 변경사항 로컬 보관 + 재시도 모달
- **트레이너가 타 강사 블록 DnD 시도**: 드래그 시작 차단 + 툴팁 "본인 담당 수업만 변경할 수 있어요"
- **블록 클릭 vs DnD 오작동 (4px 임계)**: 4px 미만 이동은 클릭 처리, 이상은 DnD
- **정원 초과한 회원 예약 + 시간 이동**: 변경 후에도 정원 검증 통과 시만 저장
- **본사 통합 모드에서 지점 간 강사 이동 시도**: "지점이 다른 강사로 변경할 수 없어요" 차단
- **이미 완료(attended) 처리된 수업 DnD**: 차단 + "완료된 수업은 이동할 수 없어요"
- **회원 결제 미수금 수업 취소 일괄**: 결제 환불 처리 미수행 경고 + 결제 화면 이동 안내

## 비즈니스 규칙

1. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정한다.
2. 화면 표시는 PT→P.T, 필라테스→필라로 축약 가능하지만 저장·집계 기준값은 고정 4종을 사용한다.
3. 강습 세션수 KPI는 본 화면과 수업 등록 다이얼로그에서 관리되는 세션 유형을 공식 원천으로 집계한다.
4. **강사 충돌 감지**: 동일 강사가 동일 시간대(겹침 1초 이상)에 다른 수업 배정 시 충돌로 판정 + 저장 차단.
5. **장소 충돌 감지**: 동일 룸·스튜디오에 동시간대 수업 2건 이상 시 충돌 차단. 단 정원 0인 휴식 슬롯은 예외.
6. **회원 중복 예약 방지**: 동일 회원이 동일 시간대 다른 수업에 예약된 경우 신규 예약 차단.
7. 트레이너는 본인 담당 수업만 등록·수정 가능하며 타 강사 일정은 조회만 가능하다.
8. **DnD 5분 스냅**: 시간 이동은 5분 단위로 스냅, 핸들 연장도 5분 단위.
9. **DnD 4px 임계**: 4px 미만 마우스 이동은 클릭으로 처리, 이상은 DnD.
10. **드래그 차단 조건**: 완료(attended)·취소(cancelled) 상태는 DnD 차단, 미승인 상태는 가능.
11. **미승인 일정**: 테넌트 정책 활성 시 신규 등록은 "미승인" 상태로 시작 → 센터장(owner) 이상 승인 후 활성. 미승인 건수는 상단 배너 표시.
12. **일괄 변경 트랜잭션**: 일괄 변경은 비동기 백그라운드 잡으로 처리, 일부 실패 시에도 성공분은 유지하고 실패 목록 별도 표시.
13. **회원 알림 자동 발송**: 수업 시간 변경·취소·강사 변경 시 예약 회원에게 자동 알림 (NFR-19).
14. **공휴일 처리**: 일괄 변경에서 공휴일 사유 선택 시 이벤트 메타에 "휴관" 태그.
15. **본사 통합 모드**: 슈퍼관리자/본사 최고관리자만 지점 컬럼 노출 + 전 지점 캘린더 표시.
16. **색상 우선순위**: 강사별 → 세션 유형별 → 분류별 순으로 색상 적용. 사용자가 범례 토글로 변경 가능.
17. **목록(list) 뷰 정렬**: 기본 시작시간 오름차순, 컬럼 클릭 시 정렬 변경.
18. **시간 단위 정책**: 수업 최소 길이 30분, 최대 240분 (4시간). 핸들 연장도 이 범위 내.
19. **감사 로그**: 등록·수정·삭제·일괄 변경·승인·DnD 모두 SCR-097에 기록 (actor, before, after, reason).
20. **뷰 상태 영속화**: 뷰 모드·필터·날짜는 URL 쿼리스트링에 보존 → 새로고침/공유 가능.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 강사 충돌 | 빨강 강조 + 모달 "강사 일정이 겹쳐요" | 저장 차단 |
| 장소(룸) 충돌 | 빨강 강조 + 모달 "장소가 사용 중이에요" | 저장 차단 |
| 회원 중복 예약 | 회원별 빨강 배지 + 안내 | 예약 추가 차단 |
| 트레이너 권한 위반 | 타 강사 블록 회색 + 툴팁 | DnD 차단 |
| 완료된 수업 DnD | "완료된 수업은 이동할 수 없어요" | DnD 차단 |
| 정원 초과 시간 변경 | "정원을 초과한 예약이 있어요" | 정원 조정 후 재시도 |
| DnD 도중 네트워크 오류 | 토스트 + 자동 retry 1회 | 실패 시 원위치 복원 |
| 일괄 변경 부분 실패 | 성공/실패 카운트 + 실패 목록 모달 | 실패 건만 재시도 가능 |
| 미승인 일정 일괄 승인 권한 부족 | 버튼 hidden | - |
| 빈 슬롯 클릭 시 영업 종료 시간 초과 | "운영 시간 외에는 등록할 수 없어요" | 운영 시간 조정 안내 |
| 휴관일 캘린더에 등록 시도 | "휴관일에는 등록할 수 없어요" | 휴관일 해제 후 가능 |
| 본사 통합 모드에서 지점 간 강사 이동 | "지점이 다른 강사로 변경할 수 없어요" | 차단 |
| 회원앱 예약과 운영자 등록 충돌 (race) | 마지막 저장이 우선, 앞 예약은 충돌 알림 | 운영자 수동 정정 |
| 캘린더 데이터 로드 실패 | 스켈레톤 + 재시도 버튼 | 재호출 |
| 외부 캘린더 동기화 오류 (구글 등) | 동기화 실패 배지 | 동기화 화면(NFR)으로 이동 |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-01`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C001`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-C001 수업등록수정_캘린더, DLG-C002 일정상세, DLG-C004 일괄변경`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
