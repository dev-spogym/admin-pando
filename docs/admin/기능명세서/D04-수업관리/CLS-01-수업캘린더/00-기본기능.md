## 기능 목적

PT 및 그룹 수업 전체 일정을 캘린더 형태로 한눈에 파악하는 메인 수업 관리 화면이다. 월·주·일·목록(list) 뷰를 자유롭게 전환하며 수업 유형과 강사를 색상으로 구분해 일정을 직관적으로 확인하고, 빈 슬롯 클릭 또는 드래그&드롭으로 빠르게 수업을 등록·수정한다. 강습 세션은 KPI 집계를 위해 PT / 필라테스 / 스트레칭 / 테라피 4종 세션 유형을 함께 관리하며, 본사 KPI 대시보드의 강습세션수 집계 원천이 된다.

## 주요 구성요소

### 뷰 전환 탭

월 / 주 / 일 / 목록(list) 4개 뷰. 뷰 전환 시 캘린더 표시 밀도와 인터랙션이 달라진다.

### 상단 액션 버튼

| 버튼 | 동작 |
|------|------|
| 스케줄 일괄 변경 | DLG-C004 진입 |
| 수업 등록 | DLG-C001 진입 |

### 탭 내비게이션

일정표 / 수업 관리(SCR-C002) / 횟수 관리(SCR-C007) / 페널티 관리(SCR-C008, 건수 배지) / 유효 수업 목록(SCR-C011).

### 필터 바

| 필터 | 설명 |
|------|------|
| 강사 | 드롭다운 (단일) |
| 수업명 | 드롭다운 (단일) |
| 정원 상태 | 전체 / 여유 / 마감 토글 |
| 분류 멀티필터 | 상담·OT·체성분·방문·수업·PT·기타 (다중) |
| 강습 세션 유형 | PT / 필라테스 / 스트레칭 / 테라피 (다중) |

### 색상 범례

화면 하단에 강사별·수업 유형별·강습 세션 유형별·분류별 색상 칩 표시.

### 캘린더 영역

- 수업 블록 클릭 → DLG-C002 일정 상세
- 빈 슬롯 클릭 → DLG-C001 수업 등록
- 드래그&드롭 → 시간 이동
- 블록 하단 핸들 드래그 → 시간 연장

### 우측 패널

선택한 날짜의 수업 목록 카드 (수업명·강사·시간·예약 현황·정원 바).

### 미승인 일정 알림 배너

미승인 일정이 있을 때 상단에 주황색 경고 배너 + 건수.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 캘린더 | 등록·수정·삭제·일괄·승인 |
| owner (센터장) | 전체 강사 일정 | 등록·수정·삭제·일괄·미승인 승인 |

| 트레이너 | 전체 조회 + 본인 담당 강조 | 담당 수업 등록·수정·DnD |
| fc / 스태프 | 전체 일정 조회 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**기본 조회**
1. 사이드바 → "수업관리 > 캘린더" 진입 → 이번 달 월 뷰
2. 뷰 전환 (월/주/일/목록)
3. 강사·수업명·분류 필터로 좁히기
4. 우측 패널에서 날짜별 카드 확인

**수업 등록·수정**
1. 빈 슬롯 클릭 또는 [수업 등록] → DLG-C001
2. 또는 수업 블록 클릭 → DLG-C002 → 수정 진입
3. 드래그로 시간 이동, 핸들로 길이 변경
4. 충돌 시 경고 + 저장 차단

**일괄 변경**
1. [스케줄 일괄 변경] → DLG-C004
2. 강사·시간·장소 변경 → 적용

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 (월 뷰) | 이번 달 + 일별 최대 3건 + 더보기 |
| 필터 적용 | 조건 매칭 일정만 |
| 빈 일정 | "이 기간에 수업이 없어요" |
| 미승인 존재 | 주황 배너 + 건수 |
| 드래그 중 | 반투명 이동 피드백 |
| 시간 충돌 | 경고 + 저장 차단 |

## 비즈니스 규칙

1. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정한다.
2. 화면 표시는 PT→P.T, 필라테스→필라로 축약 가능하지만 저장·집계 기준값은 고정 4종을 사용한다.
3. 강습 세션수 KPI는 본 화면과 수업 등록 다이얼로그에서 관리되는 세션 유형을 공식 원천으로 집계한다.
4. 강사·장소 동시간대 중복 시 충돌로 감지하고 저장을 차단한다.
5. 트레이너는 본인 담당 수업만 등록·수정 가능하며 타 강사 일정은 조회만 가능하다.
6. DnD 시간 이동은 5분 단위로 스냅된다.
