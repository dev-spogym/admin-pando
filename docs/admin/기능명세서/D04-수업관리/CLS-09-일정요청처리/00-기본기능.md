## 기능 목적

회원이 회원앱에서 요청한 수업 변경·취소 요청을 관리자가 검토하고 수락 또는 거절하는 화면이다. 회원이 직접 수업을 취소하거나 다른 일정으로 변경하고 싶을 때 요청을 보내면, 센터 관리자가 이 화면에서 일괄 처리한다. 취소 요청에 대해서는 대안 일정을 제시해 회원 만족도와 매출을 모두 지킬 수 있다.

## 주요 구성요소

### 요청 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 요청 유형 | 변경 / 취소 |
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 원래 수업 | 수업명·일시·강사 |
| 요청 내용 | 변경: 희망 일시 / 취소: 사유 |
| 요청 일시 | YYYY-MM-DD HH:mm |
| 처리 상태 | 대기 / 수락 / 거절 |
| 액션 | [수락] / [거절] / [대안] |

### 필터

| 필터 | 설명 |
|------|------|
| 요청 유형 | 전체 / 변경 / 취소 |
| 처리 상태 | 전체 / 대기 / 처리 완료 |
| 기간 | 요청일 범위 |

### 수락 버튼

요청 수락 → 수업 일정 자동 변경(변경 요청) 또는 취소 처리(취소 요청) → 회원 알림 발송.

### 거절 버튼

거절 사유 입력 → 회원에게 거절 안내 알림 발송.

### 대안 일정 제시 (DLG-C016)

취소 요청 시 [대안 제시] 버튼으로 대안 일정 제안 다이얼로그.

| 항목 | 입력 |
|------|------|
| 대안 일시 | 캘린더 + 시간 (최대 3개) |
| 대안 강사 | 동일 또는 다른 강사 |
| 메시지 | 회원 안내 메시지 |

### 미처리 배지

상단 탭 내비게이션에 미처리 요청 건수 배지.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 요청 | 수락·거절·대안 |
| owner (센터장) | 전체 요청 | 수락·거절·대안 |
| manager | 전체 요청 | 수락·거절·대안 |
| 트레이너 | 담당 수업 요청 | 수락·거절 (담당만) |
| fc / 스태프 | 전체 요청 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**일반 처리**
1. 사이드바 → "수업관리 > 일정 요청 처리" 진입
2. 대기 요청 필터로 미처리 우선 확인
3. 요청 내용 검토 → [수락] 또는 [거절]
4. 수락 시 일정 자동 변경 + 회원 알림
5. 거절 시 사유 입력 + 회원 안내

**대안 제시 (취소 요청)**
1. 취소 요청 → [대안 제시]
2. DLG-C016에서 대안 일시·강사 선택
3. 회원 알림 발송 → 응답 대기
4. 회원 수락 시 일정 변경, 거절 시 취소 처리

## 화면 상태

| 상태 | 설명 |
|---|---|
| 대기 요청 있음 | 상단 건수 배지 |
| 대기 요청 없음 | "처리할 요청이 없어요" |
| 처리 완료 목록 | 수락·거절 이력 |
| 처리 중 | 버튼 로딩 |

## 비즈니스 규칙

1. 수락 시 수업 일정이 즉시 변경 또는 취소되며 강사 캘린더에 자동 반영된다.
2. 거절 시 거절 사유 입력은 필수이며 회원에게 알림이 발송된다.
3. 대안 일정 제시는 취소 요청에 한해 제공되며 회원이 수락·거절을 선택할 수 있다.
4. 트레이너는 본인 담당 수업 요청만 처리할 수 있다.
5. 수업 시작 전 변경/취소 가능 시간은 노쇼/취소 정책(DLG-C007)을 따른다.
6. 처리 결과는 감사 로그(SCR-097)에 기록된다.
