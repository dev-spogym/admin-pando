## 기능 목적

강사별 수업 배정 현황과 근무 시간을 요약해 파악하는 화면이다. 특정 기간 동안 각 강사가 몇 건의 수업을 담당하고 총 몇 시간을 근무했는지 확인하고, 업무 부담이 편중된 강사가 없는지 점검한다. OT(오리엔테이션) 배정·진행·완료 현황을 함께 표시해 영업 파이프라인 관리도 지원한다. 본사 KPI 대시보드의 강습세션수와 트레이너별 OT 배정 합계의 원천 데이터를 제공한다.

운영 맥락:
- **센터장 월간 인사 평가**: 강사별 수업 건수·근무 시간·출석 처리 완료율 종합 점검 → 인센티브·평가 자료.
- **매니저 OT 배정 재조정**: OT1 예정 다수 트레이너에게 OT 배정 줄이고 한산한 트레이너에게 재분배.
- **본사 슈퍼관리자 KPI 검증**: 트레이너별 OT 배정 합계 → SCR-094 KPI 대시보드와 1:1 매칭 검증.
- **트레이너 본인 근무 기록**: 본인 모드로 진입 → 근무 시간·OT 진행 확인.
- **급여 정산 (SCR-064)**: 본 화면 데이터 → 급여 시간 합산 원천 → 엑셀 다운로드.
- **수업 없는 강사 식별**: 회색 처리 강사 식별 → 휴직·신규 입사·계약 종료 확인 후 적절 조치.
- **OT 거절·이월 추적**: 거절 다발 트레이너 → 영업 OT 매칭 개선 (왜 거절되는지 분석).

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 강사 근무 현황" 진입 → 기본 이번 주
2. 기간 필터(주간/월간/사용자 지정)로 조회 범위 설정
3. 요약 통계 카드(평균 근무 시간 / 최다 강사 / 수업 없는 강사) 확인
4. 강사별 수업 건수·근무 시간·OT 현황(배정·완료·예정·거절·이월) 확인
5. OT1/OT2 예정자가 많은 강사 식별 → 배정 재조정 검토
6. 강사 행 클릭 → DLG-C010 상세 (담당 수업 + OT 상세 + 기본 정보)
7. 업무 편중 강사 식별 → 캘린더(SCR-C001)에서 재배정
8. [엑셀 내보내기] → 급여 정산(SCR-064) 자료

### 분기 · 예외 · 롤백
- **트레이너 권한**: 본인 근무 현황만 노출, 타 강사 카드 hidden
- **수업 없는 강사 회색 처리**: 클릭 시 DLG-C010 진입은 가능 (조회만)
- **퇴사 강사 데이터**: 기간 내 수업 있으면 표시 + "퇴사" 라벨, 0건이면 미노출
- **OT 데이터 누락**: 강습업무보고/OT관리 데이터 미동기화 시 안내 + 직접 입력 안내
- **본사 통합 모드 권한 부족**: 지점 컬럼 hidden

## 비즈니스 규칙

1. OT 지표는 정규 PT 수업 완료율과 분리해 영업 파이프라인 지표로 표시한다.
2. O.T 배정 합계는 트레이너별 업무 부하 균형을 보기 위한 개인 KPI이며, 본사 KPI 센터의 트레이너별 OT 배정 합계와 동일 원천을 사용한다.
3. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정하며, 트레이너별 수업수와 본사 KPI 대시보드의 강습세션수 산출 기준이다.
4. OT 등록 전환율은 본사 KPI 표준 `등록 / OT 진행`을 따른다.
5. OT 거절 건은 `거부+보류`를 함께 집계했음을 화면 툴팁/설명에 명시한다.
6. OT 이월률은 `이월 건수 / OT배정 인원 × 100`으로 확정한다. `OT 진행` 기준 이월률은 보조 분석이 필요할 때 별도 지표로 추가한다.
7. 트레이너는 본인 근무 현황만 볼 수 있다.
8. **근무 시간 합산**: 수업 시간(시작~종료) 합산. 휴식·이동 시간 제외, 정책에 따라 OT 시간 포함/제외.
9. **출석 처리 완료율**: 처리한 출석/노쇼 건수 / 종료된 수업 건수 × 100. 100% 미만은 강조.
10. **수업 유형별 분포**: PT/GX/개인레슨/기타 카운트, 시각화는 막대.
11. **세션 유형별 분포**: PT/필라테스/스트레칭/테라피 4종 — KPI 정합성.
12. **OT 데이터 원천**: `[강습업무보고]` E/F/G열 + `[OT관리-강습]` Q/T/V열, 동기화 주기 1시간.
13. **퇴사 강사 처리**: 기간 내 수업 1건 이상이면 표시 + "퇴사" 라벨, 0건이면 미노출.
14. **수업 없는 강사 표시**: 0건 회색, 클릭 시 DLG-C010 진입 (사유 확인용).
15. **본인 모드 자동 적용**: 트레이너 로그인 시 본인 카드만 표시.
16. **엑셀 내보내기 권한**: owner+ 가능, 매니저는 본 화면 조회만.
17. **본사 통합 모드**: 지점 컬럼 노출 + 지점별 평균.
18. **데이터 캐시**: 1시간 캐시, [새로고침] 즉시 갱신.
19. **OT 워크플로우**: 배정 → 1차 (Q열) → 2차 (T열) → 등록(전환) 또는 거절·보류·이월(V열).
20. **감사 로그**: 본 화면은 조회 전용, 데이터 변경은 OT 관리 화면에서 → 변경 이력 그쪽에 기록.

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-06`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C006`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-C010 강사상세`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
