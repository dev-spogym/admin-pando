## 기능 목적

강사별 수업 배정 현황과 근무 시간을 요약해 파악하는 화면이다. 특정 기간 동안 각 강사가 몇 건의 수업을 담당하고 총 몇 시간을 근무했는지 확인하고, 업무 부담이 편중된 강사가 없는지 점검한다. OT(오리엔테이션) 배정·진행·완료 현황을 함께 표시해 영업 파이프라인 관리도 지원한다. 본사 KPI 대시보드의 강습세션수와 트레이너별 OT 배정 합계의 원천 데이터를 제공한다.

## 주요 구성요소

### 기간 필터

주간 / 월간 / 사용자 지정.

### 강사 목록 (카드/테이블)

| 컬럼 | 설명 |
|------|------|
| 강사명 | 클릭 시 DLG-C010 |
| 역할 | 트레이너/GX 강사 등 |
| 담당 수업 건수 | 기간 내 합계 |
| 총 근무 시간 | 수업 시간 합산 |
| 수업 유형별 분포 | PT/GX/개인레슨/기타 |
| 강습 세션 유형별 분포 | PT/필라테스/스트레칭/테라피 |
| 출석 처리 완료율 | 완료/전체 |

### OT 운영 요약

| 항목 | 출처 / 계산 |
|------|-----------|
| O.T 배정 합계 | `[강습업무보고]` 주간보고 E열 |
| O.T 1 완료 | `[강습업무보고]` F / `[OT관리-강습]` Q열 (진행=완료) |
| O.T 2 완료 | `[강습업무보고]` G / `[OT관리-강습]` T열 (진행=완료) |
| O.T 1 예정 | `[OT관리-강습]` Q열 (진행=예정) |
| O.T 2 예정 | `[OT관리-강습]` T열 (1차 완료 후 예정) |
| OT 거절 | `[OT관리-강습]` V열 (거부+보류 합산) |
| OT 이월 | `[OT관리-강습]` V열 (등록여부=이월) |

### 강사 행 클릭 → DLG-C010

담당 수업 목록 + OT 상세 + 기본 정보.

### 강사별 색상 구분

캘린더(SCR-C001)와 동일한 색상 코드 적용.

### 요약 통계

평균 근무 시간 / 최다 수업 강사 / 수업 없는 강사 등 상단 요약 카드.

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 강사 근무 현황" 진입
2. 기간 필터로 조회 범위 설정
3. 강사별 수업 건수·근무 시간·OT 현황 확인
4. OT1/OT2 예정자가 많은 강사 식별 → 배정 재조정 검토
5. 강사 행 클릭 → DLG-C010 상세 (담당 수업 + OT)
6. 업무 편중 강사 식별 → 캘린더(SCR-C001)에서 재배정

## 비즈니스 규칙

1. OT 지표는 정규 PT 수업 완료율과 분리해 영업 파이프라인 지표로 표시한다.
2. O.T 배정 합계는 트레이너별 업무 부하 균형을 보기 위한 개인 KPI이며, 본사 KPI 센터의 트레이너별 OT 배정 합계와 동일 원천을 사용한다.
3. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정하며, 트레이너별 수업수와 본사 KPI 대시보드의 강습세션수 산출 기준이다.
4. OT 등록 전환율은 본사 KPI 표준 `등록 / OT 진행`을 따른다.
5. OT 거절 건은 `거부+보류`를 함께 집계했음을 화면 툴팁/설명에 명시한다.
6. OT 이월률 분모는 우선 `OT배정 인원`으로 기록하며, `OT 진행` 기준과 구분이 필요한 산식은 추후 확정한다.
7. 트레이너는 본인 근무 현황만 볼 수 있다.
