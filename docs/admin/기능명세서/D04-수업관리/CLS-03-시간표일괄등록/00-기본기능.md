## 기능 목적

반복되는 수업 일정을 한 번에 대량으로 등록하는 화면이다. 매주 같은 요일·시간에 열리는 그룹 수업이나 PT 일정을 개별 등록하는 번거로움 없이, 기간·요일·시간·강사·장소를 설정하면 지정된 기간 동안의 일정이 자동으로 생성된다. 충돌 검증과 미리보기를 통해 운영자가 등록 전 결과를 정확히 파악할 수 있다.

## 주요 구성요소

### 기간 설정

시작일 ~ 종료일 (달력 피커).

### 요일 선택

월~일 토글 버튼 (다중 선택).

### 시간 설정

시작 시간 ~ 종료 시간 (30분 단위 드롭다운).

### 수업 선택

등록된 수업 템플릿(SCR-C004) 드롭다운. 수업명·유형·정원 자동 연동.

### 강사 배정

담당 강사 드롭다운.

### 장소 설정

룸·장소 드롭다운.

### 정원 입력

최대 예약 인원 (템플릿 기본값 자동 채움).

### 예외 날짜 제외

공휴일·휴관일 등 특정 날짜 제외 처리.

### 미리보기 영역

생성될 일정 건수 + 날짜 목록을 등록 전에 표시.

| 표시 | 설명 |
|------|------|
| 총 생성 건수 | 예: "총 24건의 일정이 생성됩니다" |
| 날짜 목록 | 생성될 모든 날짜 |
| 충돌 경고 | 기존 일정과 겹치는 날짜 |

### 일괄 생성 버튼

[일괄 생성] → DLG-C008 최종 확인 → 처리.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |

| primary / superAdmin | 전체 옵션 | 일괄 등록 실행 |
| owner (센터장) | 전체 강사·수업 옵션 | 일괄 등록 실행 |

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 시간표 일괄 등록" 진입
2. 기간 (시작일~종료일) 선택
3. 요일 다중 선택 (월~일)
4. 시작·종료 시간 설정
5. 수업 템플릿 + 강사 + 장소 선택
6. 제외할 날짜 추가 (공휴일 등)
7. 미리보기에서 생성 건수·충돌 확인
8. [일괄 생성] → DLG-C008 → 확인 → 처리
9. 캘린더(SCR-C001)로 자동 이동

## 비즈니스 규칙

1. 강사·장소 동시간대 중복은 충돌로 감지하며, 충돌 일정은 미리보기에서 강조 표시한다.
2. 충돌이 있어도 등록 자체는 가능하나 사용자 확인이 필요하다 (선택적 제외).
3. 공휴일 자동 제외 옵션 활성 시 정부 공휴일 데이터 기준으로 제외한다.
4. 트레이너는 본인 이름만 강사로 선택할 수 있다.
5. 일괄 생성된 일정은 개별 수업과 동일하게 캘린더 + 수업 관리에서 수정 가능하다.
6. 일괄 등록 결과는 감사 로그(SCR-097)에 기록된다.
