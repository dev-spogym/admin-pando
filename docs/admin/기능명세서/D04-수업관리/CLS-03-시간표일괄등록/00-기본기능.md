## 기능 목적

반복되는 수업 일정을 한 번에 대량으로 등록하는 화면이다. 매주 같은 요일·시간에 열리는 그룹 수업이나 PT 일정을 개별 등록하는 번거로움 없이, 기간·요일·시간·강사·장소를 설정하면 지정된 기간 동안의 일정이 자동으로 생성된다. 충돌 검증과 미리보기를 통해 운영자가 등록 전 결과를 정확히 파악할 수 있다.

운영 맥락:
- **분기 시간표 개편**: 매니저가 분기 시작 전(예: 4월/7월/10월/1월) 신규 GX 시간표를 3개월치 일괄 등록.
- **신규 강사 입사**: 입사일~계약 종료일 사이 본인 담당 시간표를 강사가 직접 일괄 등록.
- **공휴일 자동 제외**: 정부 공휴일·휴관일을 제외하고 등록 → 휴관일 잘못 등록으로 인한 운영 혼선 방지.
- **수업 폐강 후 재개**: 잠시 중단된 GX를 다시 열 때 기존 템플릿 + 일괄 등록으로 빠르게 복원.
- **트레이너 신규 시간대 추가**: 본인 비는 시간대 PT 슬롯 일괄 등록 → 회원앱 예약 가능.
- **반복 수업 일괄 변경 vs 일괄 등록**: 일괄 등록은 신규 생성 전용, 기존 변경은 DLG-C004 일괄 변경 사용.

본 화면은 일괄 등록 전용이며, 등록 후 개별 수정·취소는 캘린더(SCR-C001)·수업 관리(SCR-C002)에서 수행한다.

## 주요 구성요소

### 기간 설정

시작일 ~ 종료일 (달력 피커).

### 요일 선택

월~일 토글 버튼 (다중 선택).

### 시간 설정

시작 시간 ~ 종료 시간 (30분 단위 드롭다운).

### 수업 선택

등록된 수업 템플릿(SCR-C004) 드롭다운. 수업명·유형·정원 자동 연동.

### 강사 배정

담당 강사 드롭다운.

### 장소 설정

룸·장소 드롭다운.

### 정원 입력

최대 예약 인원 (템플릿 기본값 자동 채움).

### 예외 날짜 제외

공휴일·휴관일 등 특정 날짜 제외 처리.

### 미리보기 영역

생성될 일정 건수 + 날짜 목록을 등록 전에 표시.

| 표시 | 설명 |
|------|------|
| 총 생성 건수 | 예: "총 24건의 일정이 생성됩니다" |
| 날짜 목록 | 생성될 모든 날짜 |
| 충돌 경고 | 기존 일정과 겹치는 날짜 |

### 일괄 생성 버튼

[일괄 생성] → DLG-C008 최종 확인 → 처리.

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 시간표 일괄 등록" 진입
2. 기간 (시작일~종료일) 선택 → 시작 ≤ 종료 검증
3. 요일 다중 선택 (월~일)
4. 시작·종료 시간 설정 (30분 단위)
5. 수업 템플릿(SCR-C004) 선택 → 정원·유형·세션 유형 자동 채움
6. 강사·장소 배정 → 트레이너는 본인만 선택 가능
7. 공휴일 자동 제외 토글 ON + 사용자 제외 날짜 추가
8. 미리보기 갱신 → 총 건수, 날짜 목록, 충돌 목록 확인
9. 충돌 항목 선택 제외 또는 무시
10. [일괄 생성] → DLG-C008 최종 확인 (총 N건, 제외 M건, 충돌 K건) → 처리
11. 백그라운드 잡 진행률 토스트 + 완료 시 캘린더(SCR-C001) 자동 이동

### 분기 · 예외 · 롤백
- **시작일 > 종료일**: 인라인 에러 + 미리보기 비활성
- **요일 미선택**: "최소 한 요일을 선택해주세요"
- **시작 시간 ≥ 종료 시간**: 인라인 에러
- **템플릿 미선택**: 미리보기 비활성 + 강사·정원 자동 채움 차단
- **충돌 발생 시 선택적 등록**: 미리보기에서 충돌 항목 체크박스 → 해제 시 등록 제외
- **운영 시간 외 시간 설정**: 영업 시간 벗어남 경고 (강제 차단 아님, 정책에 따라)
- **백그라운드 잡 부분 실패**: 성공 N건 등록 + 실패 M건 목록 모달 + 실패 건만 재시도
- **잡 진행 중 페이지 이탈**: 백그라운드 계속 진행, 완료 시 알림 발송
- **동일 조건 중복 실행 (멱등성)**: 이미 등록된 슬롯은 skip + 안내
- **공휴일 데이터 미동기화**: 자동 제외 토글 비활성 + 안내 "공휴일 데이터를 가져올 수 없어요"

## 비즈니스 규칙

1. 강사·장소 동시간대 중복은 충돌로 감지하며, 충돌 일정은 미리보기에서 강조 표시한다.
2. 충돌이 있어도 등록 자체는 가능하나 사용자 확인이 필요하다 (선택적 제외).
3. **공휴일 자동 제외**: 옵션 활성 시 정부 공휴일 API 데이터 기준으로 제외, API 실패 시 토글 비활성.
4. **사용자 제외 날짜**: 워크샵·휴관일 등 자체 제외 추가 가능, 다중 선택 + 삭제 가능.
5. 트레이너는 본인 이름만 강사로 선택할 수 있다.
6. **시간 단위**: 시작·종료 시간은 30분 단위로 설정. 수업 길이 30분 ~ 240분 범위.
7. **기간 한도**: 기간 최대 12개월(365일). 초과 시 차단.
8. **요일 다중 선택**: 월~일 중 1개 이상 필수.
9. **템플릿 자동 연동**: 템플릿 선택 시 정원·유형·세션 유형 자동 채움, 사용자 변경 가능.
10. **세션 유형 4종 고정**: PT / 필라테스 / 스트레칭 / 테라피 — KPI 집계 원천.
11. **백그라운드 잡 처리**: 100건 초과 시 백그라운드 비동기 처리, 진행률 + 완료 알림.
12. **멱등성**: 동일 조건(강사·시간·장소·날짜) 중복 실행 시 skip + 안내.
13. **부분 실패 처리**: 일부 충돌·오류로 실패해도 성공분은 유지, 실패 목록 별도 표시.
14. **롤백 정책**: 일괄 등록 후 [전체 취소] 버튼 — 30분 이내 일괄 롤백 가능 (그 이후는 개별 취소).
15. **권한**: manager+ 일괄 등록, 트레이너 본인 담당만, FC/스태프는 접근 불가.
16. **본사 통합 모드**: 슈퍼관리자/본사 최고관리자는 지점 다중 선택 일괄 등록 가능.
17. **운영 시간 외 경고**: 영업 시간(예: 06:00~22:00) 벗어나면 경고 (정책에 따라 차단 가능).
18. **회원 알림**: 일괄 등록은 회원 알림 미발송 (신규 슬롯이며 예약 회원이 없으므로).
19. **감사 로그**: 일괄 등록 결과(총 건수·성공·실패·제외)는 SCR-097에 batch_id로 기록.
20. **회원앱 노출**: 등록 즉시 회원앱 예약 가능 (단 미승인 정책 활성 시 승인 후 노출).

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-03`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C003`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-C008 일괄생성확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
