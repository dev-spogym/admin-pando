## 기능 목적

수업별 예약 회원의 출석 상태, 수업 완료 상태, 서명/확인 누락 상태, 노쇼 처리 상태를 운영자가 확인하고 보정하는 기능이다.

본 기능은 **수업용 QR 인증 기능이 아니다.** QR은 회원의 지점 입/출입 확인에 사용하는 수단이며, 수업 출석이나 수업 완료 인증에는 사용하지 않는다. 입/출입 QR 발급·갱신·인증·기기 연동은 D11 통합운영 및 D09 설정관리 범위에서 관리하고, D04 수업관리에서는 수업 운영 참고 신호로만 조회한다.

운영 맥락:
- **수업 선택**: 오늘 또는 선택 날짜의 예약 확정 수업을 선택한다.
- **출석 등록**: 트레이너 또는 권한자가 수업별 회원 출석을 수동으로 처리한다.
- **실시간 현황**: 예약/출석/미처리/서명 누락/노쇼 상태를 수업별로 확인한다.
- **수동 보정**: 출석 누락, 오처리, 노쇼 정정이 필요한 경우 권한자가 사유를 남기고 보정한다.
- **서명/확인 누락 후속**: 수업 종료 후 트레이너와 회원의 서명/확인이 누락되면 트레이너가 회원에게 회원앱 Push 서명 요청을 보낸다. 회원이 앱에서 수업 정보를 확인하고 [확인]을 누르면 수업 완료로 처리한다.
- **노쇼 자동 처리**: 노쇼는 현재 수업 출석 정책을 따른다. 출석 인정 마감 + 지점 노쇼 판단 유예 N분 후 미처리 회원을 자동 노쇼 대상으로 본다.

## 주요 구성요소

### 수업 선택

오늘 또는 선택 날짜의 진행 예정/진행중/종료 수업 목록에서 출석·완료 처리 대상 수업을 선택한다.

### 출석/완료 현황 패널

| 항목 | 표시 |
|---|---|
| 예약 인원 | 해당 수업의 예약 확정 인원 |
| 출석 처리 | 출석으로 처리된 회원 수 |
| 미처리 | 아직 출석/결석/노쇼가 확정되지 않은 회원 수 |
| 서명/확인 누락 | 수업 완료 근거가 아직 없는 회원 수 |
| 노쇼 | 정책상 노쇼 처리된 회원 수 |

### 수동 출석/완료 처리

회원명 또는 예약 목록에서 대상을 선택해 출석, 결석, 노쇼, 수업 완료 상태를 처리한다. 변경 시 처리자와 사유를 남긴다.

### 서명 요청

수업 종료 후 서명/확인이 누락된 경우 트레이너가 회원에게 회원앱 Push를 발송한다. 회원앱에는 수업명, 일시, 담당 트레이너, 확인 버튼이 표시된다. 회원이 확인하면 수업 완료 상태가 된다.

### QR 범위 안내

D04 수업관리에서는 QR 발급, QR 갱신, 카메라 스캔, QR 위변조 검증을 구현하지 않는다. 입/출입 QR은 D11 통합운영과 D09 설정관리에서 관리한다.

## 주요 UX 흐름

**수업 출석/완료 처리**
1. 수업 출석/완료 현황 화면 진입
2. 날짜·강사·수업 상태로 대상 수업 필터링
3. 수업 선택 → 예약 회원별 출석/미처리/서명 누락/노쇼 상태 확인
4. 출석 처리 또는 수동 정정 실행
5. PT 횟수 차감 및 수업 기록 상태 갱신

**서명/확인 누락 후속**
1. 수업 종료 후 서명/확인 누락 배지 확인
2. 트레이너가 [서명 요청 Push] 클릭
3. 회원앱에 수업명, 일시, 담당 트레이너, 확인 버튼 표시
4. 회원이 [확인] 클릭
5. 수업 완료 상태로 전환하고 처리 시각을 기록

**자동 노쇼 처리**
1. 출석 인정 마감 시각 + 지점 노쇼 판단 유예 N분 도달
2. 출석·결석·완료가 확정되지 않은 예약 회원을 노쇼 후보로 식별
3. CLS-08 정책에 따라 자동 노쇼 및 페널티 처리
4. 이후 정정 시 정정 사유와 처리자를 기록하고 페널티를 자동 해제한다.

## 비즈니스 규칙

1. D04 수업관리에서는 수업 출석을 QR 스캔으로 처리하지 않는다.
2. 입/출입 QR은 지점 출입 기록이며, 수업 출석/완료의 직접 인증 수단이 아니다.
3. 입/출입 기록은 분쟁 대응 시 참고값으로만 표시할 수 있다.
4. 출석 처리 시 PT 이용권 횟수 차감은 CLS-07 기준을 따른다.
5. 출석 처리 멱등성은 예약이 있으면 `booking_id`, 예약 없는 수동 처리라면 동일 회원·수업 조합 기준으로 1회만 처리한다.
6. 서명/확인 누락 Push는 트레이너가 본인 담당 수업에 대해서만 발송할 수 있다.
7. 회원앱 확인 버튼을 누르면 수업 완료 상태가 된다.
8. Push 발송 실패 시 실패 상태를 표시하고 트레이너가 재발송할 수 있도록 한다.
9. FC/staff는 SCR-C014/CLS-14 안에서 출석 처리 보조만 가능하다. 서명 요청 Push 발송, 수업 완료 처리, 노쇼 정정은 불가하다.
10. 자동 노쇼 기준은 출석 인정 마감 + 지점 노쇼 판단 유예 N분을 따른다.
11. 노쇼 정정 시 CLS-08 페널티가 자동 해제된다.
12. 모든 출석/완료/노쇼/정정 액션은 처리자, 처리시각, 사유를 감사 로그로 남긴다.
13. QR 발급, QR 갱신, QR 만료, QR 위변조 차단, 카메라 권한 처리는 본 기능에서 제외한다.

## 관련 화면 / 다이얼로그

- **연계 화면**: SCR-C014 수업 출석/완료 확인 / SCR-C011 유효 수업 목록 / SCR-C008 페널티 관리
- **연계 다이얼로그**: DLG-C005 수업기록상세 / DLG-C006 서명
- **QR 관련 범위**: 입/출입 QR은 D11 통합운영 및 D09 설정관리 기준을 따른다.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-14`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C014`를 기준으로 확인합니다.
3. 서명/확인 누락 후속 흐름은 `DLG-C006`을 함께 확인합니다.
4. 노쇼 기준은 `CLS-08`과 지점 출석 인정/노쇼 유예 정책을 같이 적용합니다.
5. 입/출입 QR은 본 기능에서 구현하지 않고 D11/D09 범위를 따른다.
