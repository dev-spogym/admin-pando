## 기능 목적

회원이 QR 코드를 스캔해 수업 출석을 직접 처리할 수 있도록 하는 화면이다. 강사나 스태프가 일일이 출석 처리하는 대신, 회원이 수업 시작 전 QR 체크인 화면에서 자신의 QR 코드를 스캔해 자동으로 출석 등록이 완료된다. 프런트 데스크 태블릿 또는 셀프 키오스크에 설치해 운영 부담을 크게 줄일 수 있다. 실시간 출석 현황도 본 화면에서 모니터링한다.

## 주요 구성요소

### QR 스캔 영역

카메라 기반 QR 코드 스캔 UI (또는 태블릿 셀프 설치형).

### 수업 선택

현재 진행 중이거나 곧 시작할 수업 목록에서 체크인 대상 수업 선택. 수업 시작 30분 전~종료 시점까지 노출.

### 실시간 출석 현황 패널

| 항목 | 표시 |
|------|------|
| 총 예약 인원 | 정원 기준 |
| 출석 완료 | 체크인 카운트 |
| 미출석 | 잔여 미체크인 |
| 출석한 회원 목록 | 이름 + 체크인 시각 |

### 수동 체크인

QR 스캔 실패 시 회원명 또는 연락처 검색으로 수동 처리.

### 체크인 완료 피드백

스캔 성공 시 회원명·수업명 표시 + 성공 사운드/진동.

### QR 발급/갱신

회원별 QR 코드 발급 및 정기 갱신 (보안). 회원앱에서 본인 QR 표시.

## 주요 UX 흐름

**셀프 체크인**
1. 프런트 데스크 태블릿 또는 키오스크에 QR 체크인 화면 진입
2. 진행 예정 수업 자동 표시
3. 회원이 본인 QR 스캔 → 자동 출석 + 성공 피드백
4. 실시간 패널에서 체크인 카운트 갱신

**수동 체크인**
1. QR 스캔 실패 → [수동 체크인]
2. 회원명/연락처 검색
3. 회원 선택 → 출석 처리

**자동 노쇼**
1. 수업 종료 시점에 미체크인 회원 식별
2. 정책에 따라 자동 노쇼 처리
3. 자동 페널티 부과 (CLS-08)

## 화면 상태

| 상태 | 설명 |
|---|---|
| 대기 중 | QR 스캔 대기, 카메라 활성 |
| 스캔 성공 | 회원명·수업명 + 성공 피드백 |
| 스캔 실패 | "다시 스캔해주세요" |
| 수업 없음 | "예정된 수업이 없어요" |
| 만석 처리 | "정원이 초과되었습니다" |
| 이용권 만료 | "이용권이 만료되었습니다" |

## 비즈니스 규칙

1. QR 코드는 회원별 고유값이며 정기 갱신(예: 7일)으로 보안을 유지한다.
2. 체크인은 수업 시작 30분 전부터 종료 시점까지 가능하다.
3. 출석 시 PT 이용권 횟수가 자동 차감된다.
4. 정원 초과 시 체크인이 차단되고 안내가 표시된다.
5. 이용권 만료 회원은 체크인이 차단된다.
6. 수업 종료 시점 미체크인 회원은 정책에 따라 자동 노쇼 처리되며 자동 페널티가 부과될 수 있다.
7. QR 위·변조 시도는 감사 로그에 기록되고 차단된다.
