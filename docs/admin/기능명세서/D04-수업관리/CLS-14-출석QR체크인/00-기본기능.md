## 기능 목적

회원이 QR 코드를 스캔해 수업 출석을 직접 처리할 수 있도록 하는 화면이다. 강사나 스태프가 일일이 출석 처리하는 대신, 회원이 수업 시작 전 QR 체크인 화면에서 자신의 QR 코드를 스캔해 자동으로 출석 등록이 완료된다. 프런트 데스크 태블릿 또는 셀프 키오스크에 설치해 운영 부담을 크게 줄일 수 있다. 실시간 출석 현황도 본 화면에서 모니터링한다.

운영 맥락:
- **셀프 체크인 (키오스크)**: 회원이 수업 시작 30분 전 QR 스캔 → 자동 출석 + PT 차감.
- **수동 체크인 (스캔 실패)**: QR 인식 실패 시 회원명/연락처 검색 → 수동 처리.
- **실시간 출석 현황 모니터링**: 강사가 본인 수업 패널에서 출석 카운트 실시간 확인.
- **자동 노쇼 처리 (CLS-08 연계)**: 수업 종료 시점 미체크인 → 자동 노쇼 + 페널티.
- **QR 위변조 방지**: 회원별 고유 QR + 7일 정기 갱신 + 위변조 시도 로그.
- **이용권 만료/페널티 회원 차단**: 체크인 시점 검증 → 만료/페널티 시 차단 + 안내.
- **정원 초과 차단**: 정원 도달 시 추가 체크인 차단 + 대기열 안내.
- **#16 IoT 키오스크 연계**: 키오스크 디바이스에 본 화면 설치 → 카드/태그 인식 옵션.

## 주요 구성요소

### QR 스캔 영역

카메라 기반 QR 코드 스캔 UI (또는 태블릿 셀프 설치형).

### 수업 선택

현재 진행 중이거나 곧 시작할 수업 목록에서 체크인 대상 수업 선택. 수업 시작 30분 전~종료 시점까지 노출.

### 실시간 출석 현황 패널

| 항목 | 표시 |
|------|------|
| 총 예약 인원 | 정원 기준 |
| 출석 완료 | 체크인 카운트 |
| 미출석 | 잔여 미체크인 |
| 출석한 회원 목록 | 이름 + 체크인 시각 |

### 수동 체크인

QR 스캔 실패 시 회원명 또는 연락처 검색으로 수동 처리.

### 체크인 완료 피드백

스캔 성공 시 회원명·수업명 표시 + 성공 사운드/진동.

### QR 발급/갱신

회원별 QR 코드 발급 및 정기 갱신 (보안). 회원앱에서 본인 QR 표시.

## 주요 UX 흐름

**셀프 체크인**
1. 프런트 데스크 태블릿 또는 키오스크에 QR 체크인 화면 진입
2. 진행 예정 수업 자동 표시 (시작 30분 전~종료까지)
3. 회원이 본인 QR 스캔 → 회원·이용권·정원·페널티 검증 → 자동 출석 + 성공 피드백 (사운드/진동/회원명+수업명 표시)
4. 실시간 패널에서 체크인 카운트 + 출석 회원 목록 갱신
5. PT 이용권 횟수 자동 차감 (CLS-07)

**수동 체크인**
1. QR 스캔 실패 또는 회원이 QR 미보유 → [수동 체크인]
2. 회원명/연락처 검색
3. 회원 선택 → 검증 통과 → 출석 처리

**자동 노쇼 처리 (A05 크론)**
1. 수업 종료 시점 + 30분 도달
2. 미체크인 회원 식별 → 자동 노쇼 처리
3. 자동 페널티 부과 (CLS-08)

**QR 갱신**
1. 회원 QR 7일 만료 → 자동 갱신 잡
2. 회원앱에 신규 QR 표시

## 비즈니스 규칙

1. QR 코드는 회원별 고유값이며 정기 갱신(7일)으로 보안을 유지한다.
2. **체크인 시간 윈도우**: 수업 시작 30분 전부터 종료 시점까지 가능.
3. 출석 시 PT 이용권 횟수가 자동 차감된다 (CLS-07, 멱등성 키 기반).
4. 정원 초과 시 체크인이 차단되고 안내가 표시된다.
5. 이용권 만료 회원은 체크인이 차단된다.
6. **자동 노쇼 (A05)**: 수업 종료 시점 + 30분 후 미체크인 → 자동 노쇼 + 페널티 (CLS-08).
7. **QR 위·변조 시도**: 감사 로그에 기록 + 차단 + owner+ 보안 알림.
8. **페널티 적용 중 회원**: 체크인 차단 + 안내.
9. **QR 갱신 정책**: 7일 만료 자동 갱신, 회원앱에 신규 QR 표시.
10. **키오스크 모드**: 셀프 설치형 — 특정 수업 고정 또는 자동 전환.
11. **수동 체크인 권한**: FC/스태프/manager+ 가능, 트레이너는 본인 담당만.
12. **멱등성**: QR + 수동 체크인 동일 회원·수업 조합 중복 시 1회만 처리.
13. **실시간 갱신**: 출석 카운트·명단은 WebSocket 또는 5초 폴링.
14. **회원 검증 항목**: 회원 활성 / 이용권 유효 / 페널티 미적용 / 예약 확정 / 정원 미초과.
15. **사운드/진동 피드백**: 성공/실패 구분, 키오스크 음소거 옵션.
16. **출석 ↔ 유효 수업 목록 (CLS-11) 동기화**: 본 화면 출석 → CLS-11 자동 갱신.
17. **카메라 권한 처리**: 권한 거부 시 수동 체크인 안내.
18. **권한**: manager+ QR 관리·수동 체크인, FC/스태프 수동 체크인, 트레이너 본인 담당만.
19. **본사 통합 모드**: 지점별 QR 관리 분리 (지점 간 QR 호환 안 됨).
20. **#16 IoT 연계**: 키오스크 디바이스에 본 화면 임베드, 카드/태그 인식 옵션.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-14`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C014`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
