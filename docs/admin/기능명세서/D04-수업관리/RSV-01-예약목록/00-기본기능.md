## 기능 목적

전체 수업 예약을 예약 1건 단위로 조회·검색·필터링하는 예약 원장 화면이다. 관리자는 회원 문의, 예약 취소 확인, 출석·노쇼 처리 현황을 한 화면에서 확인하고 필요한 후속 처리를 수행한다. 캘린더(SCR-C001)·수업 관리(SCR-C002)와 달리 예약 1건 = 1행 단위로 표시되어 회원별·예약별 상세 검색·관리가 가능하다.

운영 맥락:
- **회원 문의 응대 (FC)**: "예약했나요?" 회원 검색 → 예약 1건 단위 확인 → 취소 사유·재예약 안내.
- **매니저 일·주간 정산**: 상태별 카운트 → 출석/노쇼/취소 비율 분석.
- **트레이너 본인 담당 예약 모니터링**: 본인 담당 수업 예약자 목록 → 출석/노쇼 처리.
- **본사 슈퍼관리자 전 지점 통합 분석**: 통합 모드 + 지점 컬럼 → 전 지점 예약 비교.
- **회원 분쟁 대응**: 처리자·처리일시 + 취소 사유 이력 → 분쟁 증빙.
- **중복 예약 의심 감지**: 동일 회원 동일 수업 중복 예약 → 경고 배지.
- **노쇼 카운트 검증**: 본 화면 노쇼 카운트 vs CLS-08 페널티 정합성.
- **엑셀 내보내기 정산**: 분기 정산 자료 다운로드.

## 주요 구성요소

### 요약 카드

| 카드 | 표시 |
|------|------|
| 전체 예약 | 기간 내 합계 |
| 예약 완료 | status=booked |
| 출석 완료 | status=attended |
| 취소·노쇼 | status=cancelled/noshow |
| 대기 | status=waiting |

### 필터 바

| 필터 | 설명 |
|------|------|
| 기간 | 수업일 기본, 예약일로 전환 가능 |
| 수업 | 수업명/유형 선택 |
| 강사 | 담당 강사 |
| 상태 | 예약완료/출석완료/취소/노쇼/대기 |
| 지점 | 본사 통합 모드만 노출 |

### 검색 입력

회원명 또는 연락처 (디바운스 300ms). 연락처는 하이픈 제거 후 비교.

| 컬럼 | 설명 |
|------|------|
| 예약일시 | YYYY-MM-DD HH:mm |
| 수업일시 | YYYY-MM-DD HH:mm |
| 수업명 | 클릭 시 수업 상세 |
| 수업 유형 | PT/GX/필라 등 |
| 강습 세션 유형 | PT/필라테스/스트레칭/테라피 |
| 강사 | 담당 강사 |
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 지점 | 본사 통합 모드 |
| 상태 | 배지 |
| 취소 사유 | 취소 시 표시 |
| 처리자/처리일시 | 마지막 액션 |

## 주요 UX 흐름

**예약 조회**
1. 사이드바 → "수업관리 > 예약 목록" 진입
2. 기본 오늘부터 7일간 수업일 기준 표시
3. 기간(수업일/예약일 전환)·수업·강사·상태(5종) 필터 조합
4. 회원명 또는 연락처(하이픈 제거 후 비교)로 검색
5. 요약 카드 클릭 → 자동 필터 (해당 상태만)

**상태 처리**
1. 예약 행 → [회원 상세] / [수업 상세] 이동
2. 권한이 있는 사용자는 [예약 취소] / [출석] / [노쇼]
3. 취소: 사유 필수 입력 → PT 횟수 자동 복구 + 회원 알림
4. 출석: PT 횟수 자동 차감
5. 노쇼: 자동 페널티 부과 (CLS-08)
6. 상태 변경 결과 즉시 반영 + 히스토리 로그

**상태 정정 (manager+)**
1. 출석완료/노쇼 상태 행 → [상태 정정] (manager+ 권한)
2. 정정 사유 입력 (필수)
3. 정정 시 페널티 자동 해제 (노쇼→출석) 또는 부과 (출석→노쇼)

**엑셀 다운로드**
1. 필터·검색 설정 후 [다운로드]
2. 현재 조건 적용된 엑셀 생성 (최대 10,000행)
3. 파일명: `예약목록_{지점}_{기간}_{시각}.xlsx`

### 분기 · 예외 · 롤백
- **출석완료/노쇼 행 일반 취소 시도**: 차단 + "상태 정정으로만 변경할 수 있어요" 안내
- **취소 사유 미입력**: 인라인 에러 + 차단
- **트레이너 본인 외 처리 시도**: 행 read-only
- **연락처 검색 (하이픈/공백)**: 자동 정규화 후 검색
- **본사 통합 모드 권한 부족**: 지점 컬럼 hidden + 단일 지점만
- **엑셀 다운로드 10,000행 초과**: 기간 축소 안내 + 차단
- **동시 처리 충돌**: 낙관적 락 + 재로드
- **회원 탈퇴 후 예약**: 자동 취소 + 안내

## 비즈니스 규칙

1. 기준 행은 예약 1건이며, 수업 1개에 여러 회원 예약 시 회원 수만큼 행을 표시한다.
2. 예약 원천은 `lesson_bookings` 또는 동등한 예약 원장 테이블이다.
3. 기간 필터는 기본 수업 시작일시 기준이며, 예약일 기준 조회로 전환 가능하다.
4. 연락처 검색은 숫자만 남긴 값으로 비교해 `01012345678`과 `010-1234-5678`을 동일하게 처리한다.
5. 전체 지점(통합) 권한에서는 모든 지점 예약을 표시하고 지점 컬럼을 필수 노출한다.
6. 단일 지점 권한에서는 사용자의 소속 지점 예약만 조회한다.
7. 예약 상태는 `예약완료`, `출석완료`, `취소`, `노쇼`, `대기` 5종 기본 사용.
8. 예약 취소 시 취소 사유 입력은 필수이다 (최소 5자).
9. 출석완료 또는 노쇼 상태 예약은 일반 취소 불가하며, 권한이 있는 사용자의 상태 정정 플로우로만 변경한다.
10. 동일 회원이 동일 수업에 중복 예약된 경우 정상 행 1건 외 중복 의심 건에 경고 배지를 표시한다.
11. 예약 취소·출석·노쇼·상태 정정은 히스토리 로그에 처리자와 처리일시를 포함해 기록한다.
12. **출석 처리 → PT 횟수 자동 차감**: CLS-07 연동, 예약 기반 출석은 `booking_id`를 멱등성 키로 사용한다. 예약 없는 수동 체크인은 CLS-07 기준에 따라 `member_id + lesson_id` 조합으로 처리한다.
13. **취소 처리 → PT 횟수 자동 복구**: 자동 처리 + 결제 환불 안내 (해당 시).
14. **노쇼 처리 → 자동 페널티**: CLS-08 정책에 따라 자동 부과.
15. **상태 정정 권한**: manager+, 사유 필수. 노쇼→출석 정정 시 자동 페널티 자동 해제 + 횟수 자동 차감.
16. **트레이너 권한**: 본인 담당 수업 예약만 조회·처리.
17. **검색 디바운스**: 300ms.
18. **요약 카드 자동 필터**: 카드 클릭 시 해당 상태 자동 필터 적용.
19. **엑셀 다운로드 한도**: 최대 10,000행, 초과 시 기간 축소 안내.
20. **회원 탈퇴 webhook**: 자동 예약 취소 + 안내.
21. **동시 처리 낙관적 락**: 충돌 시 최신 값 재로드.
22. **본사 통합 모드 지점 컬럼**: superAdmin/primary는 필수 노출, 단일 지점은 hidden.
23. **이력 보관**: 예약 이력 영구 보관 (분쟁 대응).
24. **회원 알림**: 취소·출석·노쇼·정정 모두 회원 알림 발송.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `RSV-01`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C016`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
