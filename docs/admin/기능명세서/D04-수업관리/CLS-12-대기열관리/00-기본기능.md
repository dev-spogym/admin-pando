## 기능 목적

만석이 된 그룹 수업에 대해 대기 신청한 회원 목록을 관리하는 화면이다. 예약 취소 등으로 자리가 생기면 대기 순번에 따라 자동으로 예약을 배정하거나, 관리자가 수동으로 배정할 수 있다. 인기 수업의 공정한 자리 배분과 회원 만족도를 동시에 관리한다.

## 주요 구성요소

### 수업 선택 드롭다운

대기열을 조회할 수업 선택 (만석 수업 우선 노출).

### 대기 신청자 목록

| 컬럼 | 설명 |
|------|------|
| 순번 | 1, 2, 3... |
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 대기 신청 일시 | YYYY-MM-DD HH:mm |
| 이용권 유효 | 유효/만료 배지 |
| 자동 배정 동의 | 동의 / 알림만 |
| 액션 | [수동 배정] / [대기 취소] / [알림] |

### 자동 배정 설정

자리 발생 시 자동 배정 활성 여부 토글. 활성 시 순번 1번에게 자동 예약 처리.

### 수동 배정 버튼

특정 대기자를 직접 예약 확정 처리.

### 대기 취소 버튼

대기 신청 취소.

### 알림 발송 버튼

자리 생긴 알림을 대기자에게 수동 발송.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 대기열 | 수동·자동·취소·순번 |
| owner (센터장) | 전체 대기열 | 수동·자동·취소·순번 |
| manager | 전체 대기열 | 수동·자동·취소·순번 |
| 트레이너 | 담당 수업 대기열 | 조회만 |
| fc / 스태프 | 전체 대기열 | 수동 배정·알림 발송 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**대기열 확인 + 수동 배정**
1. 사이드바 → "수업관리 > 대기열 관리" 진입
2. 수업 선택 → 대기자 목록 + 순번 확인
3. 자리 발생 시 [수동 배정] → 예약 확정
4. 회원에게 자동 알림 발송

**자동 배정**
1. 자동 배정 토글 ON
2. 자리 발생 webhook → 순번 1번 자동 예약
3. 회원에게 알림 발송

**대기 취소**
1. 행 [취소] → 확인
2. 순번 자동 재정렬

## 화면 상태

| 상태 | 설명 |
|---|---|
| 대기자 없음 | "대기 신청자가 없어요" |
| 대기자 있음 | 순번별 목록 |
| 자동 배정 활성 | "자리 발생 시 자동 처리됩니다" |
| 처리 중 | 로딩 |

## 비즈니스 규칙

1. 자동 배정은 자동 배정 동의 회원에 한해 적용되며, 미동의 회원은 알림만 받는다.
2. 자리 발생 시 순번 1번 회원에게 우선 배정되며, 이용권이 만료된 경우 다음 순번으로 넘어간다.
3. 수동 배정은 manager+ 또는 FC/스태프가 수행할 수 있다.
4. 순번 변경은 manager+만 가능하며 사유 입력이 필수이다.
5. 대기 취소는 회원 본인 또는 manager+가 수행할 수 있다.
6. 대기 신청·배정·취소 이력은 감사 로그(SCR-097)에 기록된다.
