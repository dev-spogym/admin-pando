## 기능 목적

만석이 된 그룹 수업에 대해 대기 신청한 회원 목록을 관리하는 화면이다. 예약 취소 등으로 자리가 생기면 대기 순번에 따라 자동으로 예약을 배정하거나, 관리자가 수동으로 배정할 수 있다. 인기 수업의 공정한 자리 배분과 회원 만족도를 동시에 관리한다.

운영 맥락:
- **자리 발생 시 자동 배정**: 회원 취소 → 자동 배정 동의 1번 회원 자동 예약 + 알림.
- **수동 배정 (FC/매니저)**: 회원 전화 문의 시 직접 [수동 배정] → 즉시 예약 확정.
- **이용권 만료 자동 스킵**: 1번이 만료 → 2번으로 자동 넘어감.
- **순번 변경**: 매니저가 사유 입력 후 드래그로 순번 변경 (예: VIP 회원 우선).
- **만석 → 정원 확대 시 대기 일괄 배정**: CLS-05에서 정원 확대 → 동의 회원 일괄 배정.
- **알림 수동 발송**: 자리 발생 알림을 대기자에게 수동 발송 (자동 미동의 회원).
- **대기 신청 24시간 미응답 자동 취소 (정책)**: 알림 수신 후 N시간 미응답 → 다음 순번.
- **회원앱 대기 신청 + 본 화면 관리**: 회원앱에서 신청 → 본 화면에서 모니터링·정정.

## 주요 구성요소

### 수업 선택 드롭다운

대기열을 조회할 수업 선택 (만석 수업 우선 노출).

### 대기 신청자 목록

| 컬럼 | 설명 |
|------|------|
| 순번 | 1, 2, 3... |
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 대기 신청 일시 | YYYY-MM-DD HH:mm |
| 이용권 유효 | 유효/만료 배지 |
| 자동 배정 동의 | 동의 / 알림만 |
| 액션 | [수동 배정] / [대기 취소] / [알림] |

### 자동 배정 설정

자리 발생 시 자동 배정 활성 여부 토글. 활성 시 순번 1번에게 자동 예약 처리.

### 수동 배정 버튼

특정 대기자를 직접 예약 확정 처리.

### 대기 취소 버튼

대기 신청 취소.

### 알림 발송 버튼

자리 생긴 알림을 대기자에게 수동 발송.

## 주요 UX 흐름

**대기열 확인 + 수동 배정**
1. 사이드바 → "수업관리 > 대기열 관리" 진입
2. 수업 선택 (만석 우선 노출) → 대기자 목록 + 순번 확인
3. 자리 발생 시 [수동 배정] → 예약 확정
4. 회원에게 자동 알림 발송 + 순번 자동 재정렬

**자동 배정**
1. 자동 배정 토글 ON
2. 자리 발생 webhook → 순번 1번 자동 예약 (동의 회원)
3. 1번 미동의 또는 만료 → 2번 시도, 반복
4. 회원에게 알림 발송

**대기 취소 (회원 또는 운영자)**
1. 행 [취소] → 확인
2. 순번 자동 재정렬
3. 이력 기록

**순번 변경 (수동)**
1. manager+ 드래그로 순번 변경
2. 사유 입력 (필수)
3. 회원 알림 (정책에 따라)

### 분기 · 예외 · 롤백
- **자동 배정 미동의 회원**: 알림만, 자동 배정 미수행
- **이용권 만료 회원**: 자동 스킵 → 다음 순번
- **회원 페널티 적용 중**: 자동 배정 차단 + 안내
- **알림 수신 후 응답 만료 (24시간)**: 자동 다음 순번 또는 자리 회수 (정책)
- **수업 시작 전 N시간 이내 자리 발생**: 정책에 따라 자동 배정 차단 또는 진행
- **순번 변경 시 동시 충돌**: 낙관적 락 + 재로드
- **대기 신청 후 회원 탈퇴**: 자동 취소 + 순번 재정렬

## 비즈니스 규칙

1. 자동 배정은 자동 배정 동의 회원에 한해 적용되며, 미동의 회원은 알림만 받는다.
2. 자리 발생 시 순번 1번 회원에게 우선 배정되며, 이용권이 만료된 경우 다음 순번으로 넘어간다.
3. 수동 배정은 manager+ 또는 FC/스태프가 수행할 수 있다.
4. 순번 변경은 manager+만 가능하며 사유 입력이 필수이다.
5. 대기 취소는 회원 본인 또는 manager+가 수행할 수 있다.
6. 대기 신청·배정·취소 이력은 감사 로그(SCR-097)에 기록된다.
7. **자동 배정 정책**: 만료/페널티 적용/미동의 회원 자동 스킵 → 다음 순번 시도.
8. **이용권 검증**: 자리 발생 시점 기준 이용권 유효성 검증.
9. **응답 만료 정책 (24시간)**: 알림 수신 후 24시간 미응답 시 자동 다음 순번 또는 자리 회수.
10. **시작 임박 자리 발생**: 수업 시작 N시간 전 이내 자리 발생 시 자동 배정 차단 또는 즉시 배정 (정책).
11. **순번 자동 재정렬**: 취소/배정 시 자동 재정렬, 변경 사유 기록.
12. **알림 발송**: 자동 배정 시 자동 알림, 수동 발송 옵션.
13. **회원앱 대기 신청 동기화**: 회원앱 신청 즉시 본 화면 반영.
14. **본사 통합 모드**: 지점 컬럼 + 전 지점 합산.
15. **권한**: manager+ 전체, FC/스태프 수동 배정·알림, 트레이너 조회만, readonly 차단.
16. **수동 추가 (운영자 직접)**: manager+ 회원 검색 + 순번 추가 가능.
17. **회원 탈퇴 자동 취소**: 회원 탈퇴 webhook → 대기 자동 취소 + 순번 재정렬.
18. **인기 수업 추가 개설 안내**: 대기자 N명 이상 시 owner+에게 추가 개설 안내.
19. **데이터 보관**: 대기 신청·취소·배정 이력 90일 보관.
