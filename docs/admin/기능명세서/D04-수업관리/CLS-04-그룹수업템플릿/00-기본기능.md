## 기능 목적

그룹 수업의 기본 정보(수업명, 유형, 정원, 기본 장소, 색상 등)를 템플릿으로 저장·관리하는 화면이다. 수업 템플릿을 미리 만들어 두면 시간표 일괄 등록(CLS-03)이나 개별 수업 등록(CLS-01)에서 반복 입력 없이 템플릿을 선택하는 것만으로 수업 정보가 자동 완성된다. 자주 사용되지 않는 템플릿은 비활성화하여 선택 목록에서 숨길 수 있다.

운영 맥락:
- **분기 수업 라인업 개편**: 신규 GX 수업명·정원·색상을 템플릿에 추가 → 시간표 일괄 등록(CLS-03)에서 즉시 사용.
- **수업 정원 확대 결정**: 인기 GX 정원 12 → 16명 일괄 변경 → "이후 등록만" or "전체 기존 일정 포함" 선택.
- **계절 수업 활성/비활성**: 여름 시즌 수영 템플릿은 활성, 겨울엔 비활성 → 신규 등록 목록에서 자동 숨김.
- **유사 수업 색상 통일**: 모든 필라테스 계열 색상 변경 → 캘린더 가독성 개선.
- **사용 중지 템플릿 정리**: 사용 일정 0건 템플릿 일괄 삭제 → 선택 목록 정돈.
- **신규 트레이너 PT 템플릿 검토**: 트레이너는 활성 템플릿 조회만 가능, 등록 시 사용.

## 주요 구성요소

### 템플릿 목록

카드 또는 테이블 뷰.

| 항목 | 설명 |
|------|------|
| 수업명 | 예: GX 요가 / 기구 필라테스 |
| 유형 | GX / 기구필라테스 / 스피닝 / 매트필라테스 등 |
| 정원 | 최대 예약 인원 |
| 기본 장소 | 기본 룸·스튜디오 |
| 활성 여부 | 토글 (활성/비활성) |
| 색상 칩 | 캘린더 표시 색상 |

### 활성/비활성 토글

비활성화된 템플릿은 수업 등록 시 선택 목록에서 숨겨진다.

### 템플릿 등록 버튼

상단 우측 [+ 템플릿 등록] → DLG-C009 진입.

### 템플릿 수정

행 클릭 또는 편집 아이콘 → DLG-C009 수정 모드.

### 템플릿 삭제

삭제 아이콘 → 삭제 확인. 사용 중인 일정 있으면 삭제 불가 안내.

### 비활성 포함 보기

기본은 활성만 표시, 토글로 비활성 포함 표시 가능.

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "수업관리 > 그룹 수업 템플릿" 진입
2. [+ 템플릿 등록] → DLG-C009
3. 수업명(필수, 1~30자)·유형·정원(1~99)·장소·색상(6종)·세션 유형(4종) 입력
4. 저장 → 목록 추가 + 활성 상태 ON

**수정 (적용 범위 분기)**
1. 기존 템플릿 행 클릭 → DLG-C009 수정 모드
2. 정보 변경 → 저장
3. **적용 범위 선택**: 이후 등록만 / 전체 기존 일정 포함
   - "이후 등록만": 신규 일정만 새 값 적용
   - "전체 포함": 기존 일정의 정원·장소·색상도 일괄 갱신 (이미 진행/완료된 수업은 제외)

**비활성화**
1. 활성 토글 OFF → 신규 등록 목록에서 숨김
2. 기존 일정은 영향 없음

**삭제**
1. 삭제 아이콘 → 사용 일정 카운트 검증
2. 사용 0건 → 확인 → 삭제
3. 사용 N건 → 차단 + "사용 중 일정 N건이 있어요" 안내 + [일정 보기] 버튼

### 분기 · 예외 · 롤백
- **수업명 중복**: 동일 지점 내 활성 템플릿 중복 차단, 비활성 포함 시 허용 (이력 의미)
- **정원 변경 vs 기존 예약 인원 초과**: 기존 일정 적용 시 예약 > 새 정원이면 해당 일정 skip + 실패 목록
- **이미 진행/완료된 일정 적용**: 적용 제외 (스냅샷 보존)
- **삭제 시 사용 중 일정**: 차단 + 사용 일정 목록 모달
- **활성 토글 도중 동시 등록**: 마지막 활성 상태 우선
- **백그라운드 일괄 갱신 실패**: 성공/실패 카운트 + 실패 목록 모달

## 비즈니스 규칙

1. 템플릿 비활성화는 기존 일정에 영향을 주지 않으며, 신규 등록 시에만 선택 목록에서 숨겨진다.
2. 템플릿 삭제는 해당 템플릿을 사용하는 일정이 0건일 때만 가능하다.
3. **수정 시 적용 범위 분기**: "이후 등록만" / "전체 기존 일정 포함" 중 선택. 진행 중·완료 일정은 적용 제외.
4. **정원 확장 적용 시 예약 검증**: 정원 축소가 예약 인원보다 작아지는 일정은 skip + 실패 목록.
5. **수업명 중복 정책**: 동일 지점 내 활성 템플릿 중복 차단, 비활성 포함은 허용.
6. **수업명 길이**: 1~30자, 특수문자·이모지 차단.
7. **정원 범위**: 1 ~ 99명 (정책에 따라 변경).
8. **색상 6종 팔레트**: 캘린더(SCR-C001) 시각화 우선순위 — 강사 색상 > 세션 유형 > 분류.
9. **강습 세션 유형 4종 고정**: PT / 필라테스 / 스트레칭 / 테라피 — KPI 집계 원천.
10. **권한**: manager+ 등록·수정·활성, owner+ 삭제, 트레이너·FC는 활성 템플릿 조회만.
11. **본사 통합 정책**: 활성 시 본사 템플릿이 지점에 자동 동기화 (정책에 따라).
12. **감사 로그**: 등록·수정·삭제·활성 토글 모두 SCR-097 기록 (actor·template_id·before·after).
13. **백그라운드 일괄 갱신**: "전체 기존 일정 포함" 적용 시 비동기 잡, 진행률 + 완료 알림.
14. **사용 카운트 갱신**: 사용 일정 카운트는 5분 캐시.
15. **회원앱 노출 영향**: 비활성 토글 시 신규 등록만 영향, 기존 등록 일정의 회원앱 표시는 유지.
16. **템플릿 복제**: 기존 템플릿 복제 후 수정 가능 (정책에 따라 활성).
17. **카테고리 정책**: 유형(GX/기구필라테스/스피닝/매트필라테스 등)은 테넌트별 커스터마이즈.
18. **삭제 vs 비활성 권장**: 사용 일정 N건 있는 템플릿은 비활성화 권장 안내.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-04`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C004`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-C009 템플릿등록수정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
