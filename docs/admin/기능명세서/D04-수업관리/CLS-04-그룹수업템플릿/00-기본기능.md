## 기능 목적

그룹 수업의 기본 정보(수업명, 유형, 정원, 기본 장소, 색상 등)를 템플릿으로 저장·관리하는 화면이다. 수업 템플릿을 미리 만들어 두면 시간표 일괄 등록(CLS-03)이나 개별 수업 등록(CLS-01)에서 반복 입력 없이 템플릿을 선택하는 것만으로 수업 정보가 자동 완성된다. 자주 사용되지 않는 템플릿은 비활성화하여 선택 목록에서 숨길 수 있다.

## 주요 구성요소

### 템플릿 목록

카드 또는 테이블 뷰.

| 항목 | 설명 |
|------|------|
| 수업명 | 예: GX 요가 / 기구 필라테스 |
| 유형 | GX / 기구필라테스 / 스피닝 / 매트필라테스 등 |
| 정원 | 최대 예약 인원 |
| 기본 장소 | 기본 룸·스튜디오 |
| 활성 여부 | 토글 (활성/비활성) |
| 색상 칩 | 캘린더 표시 색상 |

### 활성/비활성 토글

비활성화된 템플릿은 수업 등록 시 선택 목록에서 숨겨진다.

### 템플릿 등록 버튼

상단 우측 [+ 템플릿 등록] → DLG-C009 진입.

### 템플릿 수정

행 클릭 또는 편집 아이콘 → DLG-C009 수정 모드.

### 템플릿 삭제

삭제 아이콘 → 삭제 확인. 사용 중인 일정 있으면 삭제 불가 안내.

### 비활성 포함 보기

기본은 활성만 표시, 토글로 비활성 포함 표시 가능.

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "수업관리 > 그룹 수업 템플릿" 진입
2. [+ 템플릿 등록] → DLG-C009
3. 수업명·유형·정원·장소·색상·세션 유형 입력
4. 저장 → 목록 추가

**수정**
1. 기존 템플릿 행 클릭 → DLG-C009 수정 모드
2. 정보 변경 → 저장
3. 적용 범위 선택 (이후 등록만 / 전체 일정)

**비활성화**
1. 활성 토글 OFF
2. 수업 등록 시 선택 목록에서 숨김

**삭제**
1. 삭제 아이콘 → 확인
2. 사용 중 일정 있으면 차단 안내

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 목록 | 활성 템플릿만 표시 |
| 비활성 포함 | 비활성 토글 ON |
| 템플릿 없음 | 빈 상태 + 등록 CTA |
| 삭제 불가 | 사용 중 일정 안내 |
| 처리 중 | 로딩 |

## 비즈니스 규칙

1. 템플릿 비활성화는 기존 일정에 영향을 주지 않으며, 신규 등록 시에만 선택 목록에서 숨겨진다.
2. 템플릿 삭제는 해당 템플릿을 사용하는 일정이 0건일 때만 가능하다.
3. 템플릿 수정 시 적용 범위를 선택할 수 있다 (이후 등록만 / 전체 기존 일정 포함).
4. 색상은 6종 팔레트에서 선택하며 캘린더(SCR-C001)에서 시각화에 사용된다.
5. 강습 세션 유형은 4종 고정으로 KPI 집계와 연동된다.
