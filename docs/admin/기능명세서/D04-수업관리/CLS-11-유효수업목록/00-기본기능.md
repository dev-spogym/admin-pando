## 기능 목적

이용권이 유효하고 예약이 확정된 수업 중 실제로 진행 가능한 수업 목록을 보여주는 화면이다. 만료되거나 취소된 수업을 제외한 "진행 예정 확정 수업"만 필터링해 출석 처리, 서명 진행, 당일 운영 확인에 활용한다. 강습 세션 유형별 수업수 검증의 원천 데이터로 사용된다.

## 주요 구성요소

### 탭 내비게이션

수업 캘린더와 동일 탭 구조. 현재 탭 "유효 수업 목록" 활성.

### 날짜 필터

오늘 / 이번 주 / 날짜 직접 선택.

### 수업 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 수업명 | 클릭 시 DLG-C005 |
| 수업 유형 | PT/GX 등 |
| 강습 세션 유형 | PT/필라테스/스트레칭/테라피 |
| 강사명 | 담당 강사 |
| 일시 | 날짜 + 시작~종료 |
| 장소 | 룸·스튜디오 |
| 예약 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 잔여 횟수 | PT 이용권 잔여 |
| 출석 상태 | 미처리/출석/결석/노쇼 |
| 액션 | [출석] / [서명] / [기록] |

### 출석 처리 버튼

각 행에서 바로 출석/결석/노쇼 처리.

### 서명 요청 버튼 (DLG-C006)

PT 수업 완료 후 회원 서명 받기. 태블릿 또는 회원 디바이스로 서명.

### 수업 기록 상세 (DLG-C005)

완료 수업의 출석·서명·메모 기록 확인.

### 출석 미처리 강조

수업 시작 시간 경과 후에도 미처리인 항목 주황 표시.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 유효 수업 | 출석·서명·기록 |
| owner (센터장) | 전체 유효 수업 | 출석·서명·기록 |
| manager | 전체 유효 수업 | 출석·서명·기록 |
| 트레이너 | 본인 담당 유효 수업 | 출석·서명·기록 |
| fc / 스태프 | 전체 유효 수업 | 출석 처리 (서명은 트레이너) |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**당일 운영**
1. SCR-C001 → "유효 수업 목록" 탭 또는 `/valid-lessons` 직접 진입
2. 오늘 날짜 기본 표시
3. 수업 진행 후 [출석] / [결석] / [노쇼] 처리
4. PT 수업은 [서명] → DLG-C006 → 태블릿/회원 디바이스 서명
5. 수업 시작 시간 경과 후 미처리는 주황 강조

**기록 확인**
1. 완료 수업 행 [기록] → DLG-C005
2. 출석·서명·메모 기록 검토

## 화면 상태

| 상태 | 설명 |
|---|---|
| 오늘 수업 | 오늘 기준 유효 수업 (기본) |
| 출석 미처리 강조 | 시작 시간 경과 + 미처리 주황 |
| 목록 없음 | "이 날짜에 유효 수업이 없어요" |
| 전체 처리 완료 | "오늘 수업 처리가 완료되었어요" |

## 비즈니스 규칙

1. 유효 수업 목록에서 처리된 출석/완료 이력은 강습 세션 유형별 수업수 검증에 사용된다.
2. 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정한다.
3. 출석 처리 시 PT 이용권 횟수가 자동 차감된다.
4. 노쇼 처리 시 자동 페널티 정책(CLS-08)에 따라 페널티가 부과될 수 있다.
5. PT 수업 완료 후 서명 미수령 시 알림으로 표시된다.
6. 트레이너는 본인 담당 수업만, FC/스태프는 출석 처리만 가능하다 (서명 요청은 트레이너 권한).
