## 기능 목적

완료된 수업의 녹화 파일을 업로드하고 관리하는 화면이다. 트레이너가 녹화한 수업 영상을 업로드하면 담당 회원에게 공유해 복습 또는 피드백 자료로 활용할 수 있다. 영상 공개 범위와 기간을 설정해 해당 회원만 일정 기간 동안 볼 수 있도록 접근을 제어한다.

운영 맥락:
- **트레이너 PT 영상 업로드**: 수업 종료 후 녹화 파일 업로드 → 회원에게 공유 → 회원 복습.
- **GX 시범 영상**: 강사가 자세 시범 영상 다수 회원 공유 → 자세 교정.
- **공개 기간 만료 자동 비공개**: 만료 시 자동 비공개 + 회원 알림.
- **워터마크 무단 유포 방지**: 회원명 워터마크 영상에 오버레이.
- **다운로드 권한 분리**: 스트리밍은 모든 공유 회원, 다운로드는 별도 권한.
- **영상 삭제 시 회원 안내**: 공유 중 영상 삭제 시 회원에게 사전 안내.
- **클라우드 스토리지 비용 관리**: 만료/삭제 영상 즉시 정리, 보관 기간 정책.
- **GDPR/개인정보**: 영상에 다른 회원 얼굴 노출 시 모자이크 처리 안내.

## 주요 구성요소

### 녹화 파일 목록

| 컬럼 | 설명 |
|------|------|
| 수업명 | 연결된 수업 |
| 강사명 | 업로더 |
| 수업 일시 | YYYY-MM-DD HH:mm |
| 파일명 | 영상 파일 이름 |
| 파일 크기 | MB/GB 표시 |
| 업로드 일시 | YYYY-MM-DD |
| 공유 상태 | 공유 중 / 비공개 / 만료 |
| 공유 대상 | 회원 수 |
| 액션 | [재생] / [다운로드] / [공유 설정] / [삭제] |

### 파일 업로드

드래그&드롭 또는 파일 선택 → 연결 수업 선택(완료 수업) → 업로드. 진행률 바 + 취소 버튼.

### 공유 설정

| 항목 | 입력 |
|------|------|
| 대상 회원 | 회원 검색 + 다중 선택 |
| 공개 기간 | 무기한 / 특정 날짜까지 |
| 다운로드 허용 | 토글 |
| 워터마크 | 회원명 워터마크 옵션 |

### 미리보기 / 다운로드

파일 재생 (스트리밍) 또는 다운로드 (권한 시).

### 파일 삭제

삭제 확인 다이얼로그 → 처리. 공유 중인 파일도 삭제 가능 (회원에게 안내).

## 주요 UX 흐름

**업로드 + 공유**
1. 사이드바 → "수업관리 > 수업 녹화 관리" 진입
2. [파일 업로드] 또는 드래그&드롭
3. 연결 완료 수업 선택 (완료 상태 수업만) → 업로드 진행 (진행률 바 + 취소 버튼)
4. 업로드 완료 후 [공유 설정] → 대상 회원 다중 선택 + 공개 기간 + 다운로드 허용 + 워터마크
5. 저장 → 공유 상태 "공유 중" → 회원앱 즉시 노출

**기간 만료 (자동)**
1. 공개 기간 만료 시점 → 자동 비공개
2. 회원에게 만료 알림 발송 (만료 1일 전 사전 알림 + 만료 알림)

**삭제**
1. 행 [삭제] → 확인 다이얼로그
2. 공유 중이면 회원 안내 발송 후 삭제
3. 클라우드 스토리지에서도 영구 삭제

**스트리밍 재생 / 다운로드**
1. 회원앱 또는 운영자 [재생] → 권한 검증 → 스트리밍 재생 (워터마크)
2. 다운로드 허용 영상 → [다운로드] → 다운로드 이력 기록

### 분기 · 예외 · 롤백
- **트레이너 본인 외 영상 업로드 시도**: 차단
- **파일 크기/형식 제한 초과**: 차단 + 안내
- **업로드 도중 네트워크 단절**: 재시도 1회 → 실패 시 임시 저장
- **공유 중 영상 삭제**: 회원 안내 발송 후 삭제
- **다운로드 권한 없는 회원 시도**: 차단 + 스트리밍 안내
- **공개 기간 만료 후 회원 시청 시도**: "공개 기간이 만료되었습니다" + 차단
- **워터마크 처리 실패**: retry 1회 → 실패 시 워터마크 없이 업로드 가능 여부 운영자 결정

## 비즈니스 규칙

1. 트레이너는 본인 수업 녹화만 업로드·공유할 수 있다.
2. 영상은 스트리밍 방식으로 재생되며 다운로드는 별도 권한이 필요하다.
3. 워터마크는 회원명을 영상에 오버레이해 무단 유포를 방지한다.
4. 공개 기간 만료 시 자동으로 비공개 전환되고 회원에게 알림이 발송된다.
5. 영상 파일은 클라우드 스토리지에 저장되며 권한 검증 후에만 접근 가능하다.
6. **파일 형식**: mp4, mov, m4v 등 (테넌트별 정책).
7. **파일 크기 제한**: 단일 파일 최대 5GB (테넌트별 조정).
8. 삭제 시 스토리지에서도 영구 삭제되며 회원에게 안내된다.
9. **연결 수업 제한**: 완료 상태 수업만 연결 가능.
10. **공개 기간**: 무기한 / 특정 날짜까지. 무기한도 90일 후 만료 알림 + 갱신 안내.
11. **다운로드 권한**: 트레이너 토글 ON 시만 회원 다운로드 가능, 다운로드 이력 기록.
12. **워터마크 정책**: 회원명 오버레이, 회원별 다른 워터마크.
13. **만료 알림 정책**: 만료 1일 전 사전 알림 + 만료 즉시 알림.
14. **권한**: 트레이너 본인 수업 업로드·공유·삭제, manager+ 전체 관리, FC/스태프 접근 불가.
15. **공유 회원 다중**: 한 영상에 여러 회원 다중 공유 가능.
16. **다운로드 이력**: 누가 언제 다운로드했는지 기록 (감사 로그).
17. **스트리밍 권한 검증**: 매 요청마다 회원·기간·공유 상태 검증.
18. **클라우드 스토리지 정리**: 만료 90일 경과 영상 자동 영구 삭제 (정책에 따라).
19. **본사 통합 모드**: 지점 컬럼 + 전 지점 합산.
20. **GDPR/개인정보**: 영상에 타 회원 얼굴 노출 시 모자이크 권장 (운영자 책임 안내).
21. **암호화 전송**: 스트리밍은 HTTPS, 토큰 기반 인증.
22. **재생 이력**: 회원별 재생 시간·횟수 통계 (정책에 따라).
