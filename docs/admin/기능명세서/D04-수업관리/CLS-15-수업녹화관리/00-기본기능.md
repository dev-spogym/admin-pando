## 기능 목적

완료된 수업의 녹화 파일을 업로드하고 관리하는 화면이다. 트레이너가 녹화한 수업 영상을 업로드하면 담당 회원에게 공유해 복습 또는 피드백 자료로 활용할 수 있다. 영상 공개 범위와 기간을 설정해 해당 회원만 일정 기간 동안 볼 수 있도록 접근을 제어한다.

## 주요 구성요소

### 녹화 파일 목록

| 컬럼 | 설명 |
|------|------|
| 수업명 | 연결된 수업 |
| 강사명 | 업로더 |
| 수업 일시 | YYYY-MM-DD HH:mm |
| 파일명 | 영상 파일 이름 |
| 파일 크기 | MB/GB 표시 |
| 업로드 일시 | YYYY-MM-DD |
| 공유 상태 | 공유 중 / 비공개 / 만료 |
| 공유 대상 | 회원 수 |
| 액션 | [재생] / [다운로드] / [공유 설정] / [삭제] |

### 파일 업로드

드래그&드롭 또는 파일 선택 → 연결 수업 선택(완료 수업) → 업로드. 진행률 바 + 취소 버튼.

### 공유 설정

| 항목 | 입력 |
|------|------|
| 대상 회원 | 회원 검색 + 다중 선택 |
| 공개 기간 | 무기한 / 특정 날짜까지 |
| 다운로드 허용 | 토글 |
| 워터마크 | 회원명 워터마크 옵션 |

### 미리보기 / 다운로드

파일 재생 (스트리밍) 또는 다운로드 (권한 시).

### 파일 삭제

삭제 확인 다이얼로그 → 처리. 공유 중인 파일도 삭제 가능 (회원에게 안내).

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 녹화 파일 | 업로드·삭제·공유 |
| owner (센터장) | 전체 녹화 파일 | 업로드·삭제·공유 |
| manager | 전체 녹화 파일 | 업로드·삭제·공유 |
| 트레이너 | 본인 수업 녹화 | 업로드·삭제·본인 수업 공유 |
| fc / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**업로드 + 공유**
1. 사이드바 → "수업관리 > 수업 녹화 관리" 진입
2. [파일 업로드] 또는 드래그&드롭
3. 연결 완료 수업 선택 → 업로드 진행
4. 업로드 후 [공유 설정] → 대상 회원·기간 설정
5. 공유 상태 "공유 중"으로 변경 → 회원앱 노출

**기간 만료**
1. 공개 기간 만료 시 자동 비공개
2. 회원에게 만료 알림 발송

**삭제**
1. 행 [삭제] → 확인
2. 공유 중이면 회원 안내
3. 처리 → 목록 갱신

## 화면 상태

| 상태 | 설명 |
|---|---|
| 파일 없음 | "업로드된 녹화 파일이 없어요" |
| 업로드 중 | 진행률 바 + 취소 |
| 공유 중 | 대상 회원 + 기간 표시 |
| 비공개 | "공유 미설정" |
| 기간 만료 | "만료" 배지 |

## 비즈니스 규칙

1. 트레이너는 본인 수업 녹화만 업로드·공유할 수 있다.
2. 영상은 스트리밍 방식으로 재생되며 다운로드는 별도 권한이 필요하다.
3. 워터마크는 회원명을 영상에 오버레이해 무단 유포를 방지한다.
4. 공개 기간 만료 시 자동으로 비공개 전환되고 회원에게 알림이 발송된다.
5. 영상 파일은 클라우드 스토리지에 저장되며 권한 검증 후에만 접근 가능하다.
6. 파일 크기 제한 및 형식(mp4, mov 등) 제한이 적용된다.
7. 삭제 시 스토리지에서도 영구 삭제되며 회원에게 안내된다.
