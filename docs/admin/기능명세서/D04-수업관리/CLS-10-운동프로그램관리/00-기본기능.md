## 기능 목적

트레이너가 회원에게 제공할 운동 프로그램을 수동으로 만들고 관리하는 화면이다. 프로그램은 여러 운동 동작으로 구성되며, 트레이너가 직접 회원에게 배정하면 PT 세션에서 해당 프로그램을 기반으로 수업이 진행된다. v1에서는 프로그램 자동 추천·자동 생성 없이 수동 등록·수정·삭제·선택·배정만 제공한다.

운영 맥락:
- **트레이너 신규 회원 프로그램 배정**: OT 후 회원 목표·체성분 데이터는 참고 정보로 확인하고, 트레이너가 등록된 프로그램 중 적합한 프로그램을 직접 선택해 회원에게 배정.
- **프로그램 진행 후 강도 조정**: 회원 진척도 보면서 세트·반복·중량 단계 상향 → 수정 후 동일 회원 재배정.
- **회원 종합평가 연계 (MBR)**: 평가 결과 따라 프로그램 변경.
- **트레이너 본인 프로그램만 편집**: 매니저는 조회·삭제만, 트레이너는 본인 작성만 수정.
- **회원 PT 세션 시 프로그램 표시 (DLG-C011)**: 세션 진행 시 트레이너가 수동 배정한 프로그램이 강사 화면에 표시.
- **운동 동작 라이브러리 활용**: 동작 라이브러리 검색 → 프로그램에 추가.
- **회원앱 운동 기록 연동**: 회원이 본인 프로그램 + 수행 기록 회원앱에서 확인.
- **계절·목표별 프로그램 라이브러리**: 다이어트·근력·재활 등 카테고리별 프로그램 템플릿화.

상단 [+ 프로그램 등록] → 드로어/등록 폼.

| 항목 | 입력 |
|------|------|

| 카테고리 | 근력/유산소/유연성/회복 등 |

### 회원 배정 기능

프로그램 → 회원 배정·해제. 배정된 회원은 PT 세션에서 자동 노출.

### 필터

- 내 프로그램만 보기
- 배정 회원 있는 프로그램만
- 활성/비활성

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "수업관리 > 운동 프로그램 관리" 진입
2. [+ 프로그램 등록] → 폼/드로어 진입
3. 프로그램명(필수, 1~50자)·카테고리·난이도 입력
4. 동작 목록 추가 (동작 라이브러리 검색 또는 직접 입력) — 세트·반복·휴식·중량·메모
5. 동작 순서 드래그&드롭 변경
6. 저장 → 목록 추가, 활성 ON

**회원 배정**
1. 프로그램 행 → [회원 배정]
2. 회원 검색 + 다중 선택 → [추가]
3. 회원의 PT 세션 시 자동 노출 (DLG-C011)

**세션 진행 시 (DLG-C011)**
1. 세션에서 DLG-C011 세션상세 → 배정된 프로그램 표시
2. 동작별 수행 기록 (실제 세트·반복·중량 입력)
3. 세션 종료 후 회원앱에 기록 동기화

**프로그램 선택 / 배정**
1. v1은 트레이너가 기존 프로그램 또는 템플릿을 직접 선택해 회원에게 배정한다.
2. 필요 시 트레이너가 새 프로그램을 수동 등록하거나 기존 프로그램을 수정한 뒤 배정한다.
3. 회원 목표·체성분(MBR) 데이터는 프로그램 검색·필터 참고 정보로만 사용한다.
4. 회원 목표·체성분·운동 이력을 분석해 프로그램을 자동 추천·자동 생성하는 기능은 v1에서 제외하고 v2 또는 별도 협의 범위로 둔다.

### 분기 · 예외 · 롤백
- **트레이너 본인 외 수정 시도**: read-only, 매니저는 삭제만
- **삭제 시 배정 회원**: 회원에게 안내 + 다른 프로그램 권장
- **비활성 프로그램 신규 배정 제한**: 신규 배정 선택 목록에서 hidden 또는 비활성 표시
- **자동 추천/생성 미제공**: v1에서는 자동 추천·자동 생성 버튼을 노출하지 않고 수동 선택/작성으로 처리
- **동작 순서 동시 변경 충돌**: 마지막 저장 우선 + 재로드
- **회원 탈퇴 후 배정 자동 해제**: 자동 처리

## 비즈니스 규칙

1. 트레이너는 본인이 작성한 프로그램만 수정 가능하며 매니저는 삭제만 가능하다.
2. 회원 배정 후에는 회원의 PT 세션에서 자동으로 프로그램이 노출된다.
3. 비활성 프로그램은 기존 배정 이력 조회는 가능하나 신규 배정 선택 목록에서는 제외하거나 비활성 상태로 표시한다.
4. 프로그램은 v1에서 자동 추천·자동 생성하지 않는다. 회원 목표·체성분 데이터는 검색·필터 참고 정보로만 사용한다.
5. 동작 순서는 드래그&드롭으로 변경 가능하며 변경 시 즉시 저장된다.
6. **프로그램명**: 1~50자 필수, 동일 트레이너 내 중복 차단 (활성).
7. **동작 라이브러리**: 본사 표준 동작 + 트레이너 커스텀 동작.
8. **카테고리**: 근력/유산소/유연성/회복/다이어트/재활 등 (테넌트 커스터마이즈).
9. **난이도**: 초급/중급/고급, 트레이너가 수동 선택할 때 참고하는 분류 기준.
10. **자동 추천/생성 정책**: 회원 목표·체성분·기존 진척도 분석 기반 자동 추천·자동 생성은 v1 개발 기준에서 제외하고 v2 또는 별도 협의 범위로 분리한다.
11. **회원 배정 다중**: 동일 프로그램을 여러 회원에게 배정 가능.
12. **배정 해제**: 트레이너·매니저 가능, 해제 시 회원에게 안내.
13. **세션 진행 기록**: DLG-C011에서 실제 수행 기록 → 회원앱 운동 기록 동기화.
14. **활성/비활성**: 비활성은 신규 추천 제외, 기존 배정 회원은 영향 없음.
15. **삭제 정책**: 매니저+ 가능, 트레이너는 본인 작성만 삭제 가능, 배정 회원에게 안내.
16. **회원 탈퇴 자동 해제**: 회원 탈퇴 시 배정 자동 해제.
17. **권한**: 트레이너 본인 작성·수정·삭제·배정, 매니저 조회·삭제, FC/스태프 접근 불가.
18. **종합평가 연계**: MBR 종합평가 결과에 따라 프로그램 변경 안내.
19. **회원앱 동기화**: 배정·수정·해제 즉시 회원앱 반영.
20. **이력**: 프로그램 수정·배정·해제 이력 90일 보관.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-10`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C010`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-C011 세션상세`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
