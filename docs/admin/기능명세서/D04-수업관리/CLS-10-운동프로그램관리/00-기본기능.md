## 기능 목적

트레이너가 회원에게 제공할 운동 프로그램을 만들고 관리하는 화면이다. 프로그램은 여러 운동 동작으로 구성되며, 회원에게 배정하면 PT 세션에서 해당 프로그램을 기반으로 수업이 진행된다. 회원 맞춤형 운동 계획을 체계적으로 관리하고 세션 진행 시 즉시 활용한다.

## 주요 구성요소

### 프로그램 목록

| 컬럼 | 설명 |
|------|------|
| 프로그램명 | 클릭 시 상세·편집 |
| 담당 트레이너 | 작성자 |
| 배정 회원 수 | 배정된 회원 카운트 |
| 동작 수 | 포함 운동 동작 |
| 생성일 | YYYY-MM-DD |
| 마지막 수정일 | YYYY-MM-DD |
| 활성/비활성 | 배지 |

### 프로그램 등록 버튼

상단 [+ 프로그램 등록] → 드로어/등록 폼.

### 프로그램 상세 / 수정 (DLG-C011 세션상세)

| 항목 | 입력 |
|------|------|
| 프로그램명 | 텍스트 |
| 카테고리 | 근력/유산소/유연성/회복 등 |
| 난이도 | 초급/중급/고급 |
| 동작 목록 | 동작명 / 세트 / 반복 횟수 / 휴식 시간 / 중량 / 메모 |
| 동작 순서 | 드래그&드롭 변경 |

### 회원 배정 기능

프로그램 → 회원 배정·해제. 배정된 회원은 PT 세션에서 자동 노출.

### 필터

- 내 프로그램만 보기
- 배정 회원 있는 프로그램만
- 활성/비활성

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 프로그램 | 조회·삭제 |
| owner (센터장) | 전체 트레이너 프로그램 | 조회·삭제 |
| manager | 전체 트레이너 프로그램 | 조회·삭제 |
| 트레이너 | 본인 작성 프로그램 | 생성·수정·삭제·배정 |
| fc / 스태프 | 접근 불가 또는 조회만 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**신규 등록**
1. 사이드바 → "수업관리 > 운동 프로그램 관리" 진입
2. [+ 프로그램 등록] → 폼 진입
3. 프로그램명·카테고리·난이도 입력
4. 동작 목록 추가 (세트·반복·중량·메모)
5. 저장 → 목록 추가

**회원 배정**
1. 프로그램 행 → [회원 배정]
2. 회원 검색 → 추가
3. 회원의 PT 세션 시 자동 노출

**세션 진행 시**
1. 세션에서 DLG-C011 세션상세 → 배정된 프로그램 표시
2. 동작별 수행 기록

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 목록 | 전체 프로그램 |
| 프로그램 없음 | 등록 안내 + CTA |
| 배정 회원 없음 | "배정 회원이 없어요" |
| 비활성 | 회색 처리 |

## 비즈니스 규칙

1. 트레이너는 본인이 작성한 프로그램만 수정 가능하며 매니저는 삭제만 가능하다.
2. 회원 배정 후에는 회원의 PT 세션에서 자동으로 프로그램이 노출된다.
3. 비활성 프로그램은 배정 가능하나 신규 회원 추천 목록에서는 제외된다.
4. 권장 프로그램 자동 생성은 회원의 목표·체성분 데이터를 기반으로 한다.
5. 동작 순서는 드래그&드롭으로 변경 가능하며 변경 시 즉시 저장된다.
