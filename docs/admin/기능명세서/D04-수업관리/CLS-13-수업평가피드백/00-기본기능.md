## 기능 목적

수업 완료 후 회원이 남긴 평가·후기를 관리자가 조회하는 화면이다. 강사별·수업별 평균 평점과 텍스트 후기를 확인해 서비스 품질을 개선하고, 우수 강사를 파악하거나 불만 사항에 대응하는 데 활용한다. 강사 NPS는 본 화면 데이터로부터 자동 집계되어 STF-02 직원 상세에 반영된다.

## 주요 구성요소

### 필터 바

| 필터 | 설명 |
|------|------|
| 기간 | 주간 / 월간 / 사용자 지정 |
| 강사 | 드롭다운 |
| 수업 유형 | PT / GX / 개인레슨 등 |
| 평점 | 1~5점 (다중 선택) |

### 평점 요약 카드

| 카드 | 표시 |
|------|------|
| 전체 평균 평점 | 별점 + 숫자 |
| 강사별 평균 평점 랭킹 | TOP 5 |
| 평점 분포 | 1~5점 막대 그래프 |
| 응답률 | 응답/완료 수업 |

### 피드백 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 회원명 | 익명 처리 옵션 |
| 수업명 | 클릭 시 SCR-C002 |
| 강사명 | 클릭 시 STF-02 |
| 수업 일시 | YYYY-MM-DD HH:mm |
| 평점 | 별점 1~5 |
| 후기 텍스트 | 미리보기 (행 클릭 시 전문) |
| 등록 일시 | YYYY-MM-DD |
| 신고 상태 | 정상 / 신고됨 |

### 피드백 상세

행 클릭 시 후기 전문 + 회원·수업·강사 정보 + 신고/삭제 액션.

### 낮은 평점 강조

3점 이하는 주황·빨강 색상.

### 신고 처리

부적절한 후기 신고 → manager+ 검토 → 숨김 또는 삭제.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 피드백 | 신고 처리·삭제 |
| owner (센터장) | 전체 강사·수업 피드백 | 신고 처리·삭제 |
| manager | 전체 피드백 | 신고 처리 |
| 트레이너 | 본인 수업 피드백만 | 조회만 |
| fc / 스태프 | 접근 불가 | ❌ |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 수업 평가 피드백" 진입
2. 기간·강사·유형 필터 설정
3. 평점 요약 카드에서 강사별 비교
4. 피드백 목록에서 낮은 평점 우선 확인
5. 행 클릭 → 후기 전문
6. 부적절 후기는 신고 처리 → 숨김

## 화면 상태

| 상태 | 설명 |
|---|---|
| 피드백 없음 | "피드백이 없어요" |
| 피드백 있음 | 목록 + 요약 카드 |
| 낮은 평점 강조 | 3점 이하 주황/빨강 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 강사 NPS는 본 화면의 평점 데이터로부터 자동 집계되어 STF-02 직원 상세에 반영된다.
2. 평점은 별점 1~5점 척도이며 텍스트 후기는 선택 입력이다.
3. 응답률 = 응답 수 / 완료 수업 수 × 100.
4. 트레이너는 본인 수업 피드백만 조회 가능하다 (자기 평가 보호).
5. 부적절한 후기는 manager+가 검토 후 숨김/삭제할 수 있으며 처리 이력이 기록된다.
6. 회원은 익명 후기 옵션을 선택할 수 있으며, 익명 시 회원명이 마스킹 표시된다.
