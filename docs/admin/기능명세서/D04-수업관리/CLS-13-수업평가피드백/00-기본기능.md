## 기능 목적

수업 완료 후 회원이 남긴 평가·후기를 관리자가 조회하는 화면이다. 강사별·수업별 평균 평점과 텍스트 후기를 확인해 서비스 품질을 개선하고, 우수 강사를 파악하거나 불만 사항에 대응하는 데 활용한다. 강사 NPS는 본 화면 데이터로부터 자동 집계되어 STF-02 직원 상세에 반영된다.

운영 맥락:
- **센터장 인사 평가 자료**: 월간 강사별 평균 평점 + 응답률 + NPS → 인사 평가 점수.
- **매니저 낮은 평점 강사 코칭**: 3점 이하 후기 다수 강사 → 코칭 면담 자료.
- **부적절 후기 신고 처리**: 회원 신고 → manager+ 검토 → 숨김/삭제.
- **회원 분쟁**: 익명 후기 vs 실명 후기 정책 + 신고 처리 이력.
- **트레이너 본인 평가 확인**: 본인 수업 후기만 조회 (자기 평가 보호).
- **낮은 평점 자동 알림**: 1~2점 등록 시 owner+에게 즉시 알림.
- **응답률 향상 캠페인**: 응답률 < 30% 시 알림 발송 마케팅(MKT).
- **본사 NPS 정합성**: SCR-094 KPI 대시보드 및 STF-02와 동일 산출 기준.

### 피드백 상세

행 클릭 시 후기 전문 + 회원·수업·강사 정보 + 신고/삭제 액션.

### 낮은 평점 강조

3점 이하는 주황·빨강 색상.

### 신고 처리

부적절한 후기 신고 → manager+ 검토 → 숨김 또는 삭제.

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 수업 평가 피드백" 진입
2. 기간(주간/월간/사용자 지정)·강사·수업 유형·평점 다중 필터 설정
3. 평점 요약 카드 (전체 평균 / 강사 랭킹 TOP5 / 평점 분포 / 응답률)
4. 피드백 목록에서 낮은 평점 우선 확인 (3점 이하 강조)
5. 행 클릭 → 후기 전문 + 회원·수업·강사 정보 + 신고/삭제 액션
6. 부적절 후기는 신고 처리 → manager+ 검토 → 숨김/삭제

### 분기 · 예외 · 롤백
- **트레이너 권한**: 본인 수업 후기만, 타 강사 hidden
- **익명 후기**: 회원명 마스킹 (***), 신고 시에도 마스킹 유지
- **삭제 vs 숨김**: 숨김은 일시적, 삭제는 영구 (manager+ 만 삭제 가능)
- **신고 누적**: 신고 N건 이상 자동 숨김 (정책 활성 시)
- **낮은 평점 자동 알림**: 1~2점 등록 즉시 owner+에게 알림
- **회원 후기 수정·삭제 (회원앱)**: 24시간 내 수정 가능 (정책)

## 비즈니스 규칙

1. 강사 NPS는 본 화면의 평점 데이터로부터 자동 집계되어 STF-02 직원 상세에 반영된다.
2. 평점은 별점 1~5점 척도이며 텍스트 후기는 선택 입력이다.
3. 응답률 = 응답 수 / 완료 수업 수 × 100.
4. 트레이너는 본인 수업 피드백만 조회 가능하다 (자기 평가 보호).
5. 부적절한 후기는 manager+가 검토 후 숨김/삭제할 수 있으며 처리 이력이 기록된다.
6. 회원은 익명 후기 옵션을 선택할 수 있으며, 익명 시 회원명이 마스킹 표시된다.
7. **NPS 산식**: 추천(9~10점, 5점 척도 환산 4.5+) - 비추천(0~6, 3점 이하) / 응답 수 × 100.
8. **평점 척도**: 별 1~5점, 0.5 단위 허용 안 함 (정수만).
9. **후기 텍스트 길이**: 최대 1000자, 빈 텍스트는 평점만 저장.
10. **익명 정책**: 회원이 익명 옵션 선택 시 회원명 마스킹 (***), 신고/삭제 시에도 유지.
11. **신고 처리**: 회원 신고 → manager+ 검토 → 숨김/삭제 → 신고자에게 결과 안내.
12. **자동 숨김 정책**: 신고 N건(예: 3건) 이상 시 자동 숨김 (manager 검토 대기).
13. **삭제 권한**: manager+ 삭제 가능, 삭제는 영구 (감사 로그 기록).
14. **낮은 평점 자동 알림**: 1~2점 등록 시 owner+에게 즉시 알림.
15. **응답률 향상 캠페인**: 응답률 < 30% 시 마케팅(MKT) 발송 옵션.
16. **회원 후기 수정**: 24시간 이내 본인 수정·삭제 가능.
17. **NPS 추이 그래프**: 월간 추이 표시.
18. **권한**: manager+ 신고 처리·삭제, 트레이너 본인 후기 조회만, FC/스태프 접근 불가.
19. **본사 통합 모드**: 지점 컬럼 + 전 지점 합산.
20. **데이터 보관**: 후기 영구 보관 (삭제는 soft delete).
21. **회원 신고 누적 관리**: 신고 다발 회원 식별 + 운영 정책 강화 (정책 활성 시).

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-13`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C013`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
