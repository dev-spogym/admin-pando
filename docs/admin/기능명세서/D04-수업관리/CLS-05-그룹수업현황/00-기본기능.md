## 기능 목적

그룹 수업별 예약 현황과 출석률, 잔여 자리를 한눈에 파악하는 현황판 화면이다. 어떤 수업이 인기 있고, 어느 수업에 빈자리가 있는지 빠르게 파악해 운영 결정(수업 추가·취소·정원 조정)에 활용한다. 마감 임박 수업은 정원 확대 또는 추가 개설 후보로, 출석률이 낮은 수업은 폐강 또는 일정 조정 후보로 식별된다.

## 주요 구성요소

### 기간 필터

주간 / 월간 / 사용자 지정 기간 토글.

### 수업 유형 필터

전체 / GX / 스피닝 / 필라테스 / 매트필라 / 요가 등 다중 선택.

### 강사 필터

특정 강사 수업만 표시.

### 현황 카드 / 테이블

| 컬럼 | 설명 |
|------|------|
| 수업명 | 클릭 시 예약 회원 목록 드로어 |
| 유형 | GX/필라테스 등 |
| 강사 | 담당 강사명 |
| 요일·시간 | 예: "월·수·금 19:00~20:00" |
| 정원 | 최대 인원 |
| 예약 수 | 현재 예약 인원 |
| 잔여 자리 | 정원 - 예약 |
| 출석률 | 출석/예약 × 100% |
| 노쇼 수 | 누적 노쇼 |
| 잔여 자리 바 | 여유(녹)/임박(주황)/마감(빨강) |

### 정렬 기능

출석률 높은 순 / 잔여 자리 적은 순 / 예약 많은 순 토글.

### 수업 행 클릭 → 예약 회원 목록

해당 수업의 예약 회원 명단을 드로어/서브 패널로 표시.

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 |
| 연락처 | 010 자동 |
| 출석 상태 | 출석/노쇼/예정 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 지점 그룹 수업 | 정원 조정·수업 취소 진입 |
| owner (센터장) | 전체 그룹 수업 현황 | 정원 조정·수업 취소 진입 |
| manager | 전체 그룹 수업 현황 | 정원 조정·수업 취소 진입 |
| 트레이너 | 본인 담당 수업 현황 | 조회만 |
| fc / 스태프 | 전체 그룹 수업 현황 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 그룹 수업 현황" 진입
2. 기간(주간/월간) + 유형·강사 필터 설정
3. 현황 카드/테이블에서 수업별 예약·출석·잔여 확인
4. 잔여 적은 수업 → 정원 확대 또는 추가 개설 검토
5. 출석률 낮은 수업 → 폐강·일정 조정 검토
6. 수업 행 클릭 → 예약 회원 명단 확인
7. 회원명 클릭 → SCR-M004 회원 상세

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 현황 | 이번 주 전체 그룹 수업 |
| 마감 강조 | 잔여 0 빨강 배지 |
| 임박 강조 | 잔여 1~2 주황 배지 |
| 데이터 없음 | "이 기간에 그룹 수업이 없어요" |
| 로딩 | 스켈레톤 카드 |

## 비즈니스 규칙

1. 출석률 = 출석 인원 / 예약 인원 × 100, 노쇼는 출석에서 제외한다.
2. 잔여 자리 바 색상은 잔여/정원 비율로 계산한다 (≤0% 빨강, ≤20% 주황, 그 외 녹색).
3. 본 화면은 그룹 수업(GX·필라테스 등)만 대상이며 1:1 PT는 SCR-C001/C002에서 관리한다.
4. 정원 조정은 manager+만 가능하며 변경 이력은 감사 로그(SCR-097)에 기록된다.
5. 트레이너는 본인 담당 수업만 조회 가능하다.
