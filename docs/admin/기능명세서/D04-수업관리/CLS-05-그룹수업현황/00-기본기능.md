## 기능 목적

그룹 수업별 예약 현황과 출석률, 잔여 자리를 한눈에 파악하는 현황판 화면이다. 어떤 수업이 인기 있고, 어느 수업에 빈자리가 있는지 빠르게 파악해 운영 결정(수업 추가·취소·정원 조정)에 활용한다. 마감 임박 수업은 정원 확대 또는 추가 개설 후보로, 출석률이 낮은 수업은 폐강 또는 일정 조정 후보로 식별된다.

운영 맥락:
- **매니저 주간 운영 회의 자료**: 출석률 정렬 + 예약 수 정렬 → TOP/BOTTOM 5 수업 식별 → 폐강·확장 결정.
- **센터장 정원 조정**: 마감(빨강) 수업 다수 식별 → 정원 12 → 16 확대. 대기열 배정은 CLS-12 대기 관리 정책이 별도로 활성화된 경우에만 후속 처리.
- **매니저 인기 수업 추가 개설**: 마감 수업의 인접 시간대 추가 개설 → CLS-03 일괄 등록 진입.
- **운영자 폐강 검토**: 출석률 30% 이하 + 예약 수 4명 이하 → 폐강 후보 → CLS-01 일괄 취소.
- **트레이너 본인 수업 인기 점검**: 본인 담당 수업만 조회 → 출석률 트렌드 확인.
- **FC 회원 안내 응대**: 마감 수업 잔여 0건 확인 → 회원에게 대기열 신청 안내(CLS-12).
- **본사 슈퍼관리자 지점 비교**: 통합 모드 + 지점별 출석률 평균 → 운영 모범 지점 식별.

## 주요 구성요소

### 기간 필터

주간 / 월간 / 사용자 지정 기간 토글.

### 수업 유형 필터

전체 / GX / 스피닝 / 필라테스 / 매트필라 / 요가 등 다중 선택.

### 강사 필터

| 컬럼 | 설명 |
|------|------|
| 수업명 | 클릭 시 예약 회원 목록 드로어 |
| 유형 | GX/필라테스 등 |
| 강사 | 담당 강사명 |
| 요일·시간 | 예: "월·수·금 19:00~20:00" |

### 정렬 기능

출석률 높은 순 / 잔여 자리 적은 순 / 예약 많은 순 토글.

## 주요 UX 흐름

1. 사이드바 → "수업관리 > 그룹 수업 현황" 진입 → 기본 이번 주
2. 기간(주간/월간/사용자 지정) + 유형·강사 필터 설정
3. 정렬 토글로 출석률 / 잔여 자리 / 예약 수 기준 정렬
4. 현황 카드·테이블에서 수업별 예약·출석·잔여·노쇼·잔여 자리 바 확인
5. 잔여 적은 수업 → [정원 조정] → 정원 변경
6. 출석률 낮은 수업 → 폐강 검토 → 캘린더(SCR-C001) 일괄 취소 진입
7. 수업 행 클릭 → 예약 회원 명단 드로어 (이름·연락처·출석 상태)
8. 회원명 클릭 → SCR-M004 회원 상세

### 분기 · 예외 · 롤백
- **정원 축소 시 예약 인원 초과**: 차단 + "예약 인원보다 작아요" → 대기열 이동 또는 취소 후 변경
- **정원 확대 시 대기열 후속 처리**: CLS-12 대기 관리 정책이 활성화된 경우에만 대기자 알림/배정 흐름으로 연결
- **트레이너 권한**: 본인 담당 수업만 조회, 정원 조정 차단
- **FC 권한**: 조회만, 정원 조정·취소 차단

## 비즈니스 규칙

1. **출석률 산식**: 출석 인원 / 예약 인원 × 100. 노쇼·취소는 분자에서 제외, 분모는 예약 인원 (대기열 제외).
2. **잔여 자리 바 색상**: ≤0% 빨강, ≤20% 주황, 그 외 녹색. 정원 0인 휴식 슬롯은 회색.
3. **마감 정의**: 잔여 0건 = 마감, 단 대기열 신청 가능 (CLS-12).
4. **본 화면 범위**: 그룹 수업(GX·필라테스 등)만 대상, 1:1 PT는 SCR-C001/C002.
5. **정원 조정 권한**: manager+만 가능, owner+ 일괄 조정 가능, 변경 이력은 감사 로그.
6. **정원 축소 검증**: 예약 인원 < 새 정원이어야 가능. 위반 시 차단.
7. **정원 확대 시 대기열 후속 처리**: CLS-12 대기 관리 정책이 활성화된 경우에만 대기자 알림/배정 흐름으로 연결한다.
8. **트레이너 본인 조회**: 담당 수업만 조회, 정원 조정 차단.
9. **노쇼 수 누적 기준**: 본 화면 기간 필터 범위 내 누적.
10. **출석률 응답률 분리**: 응답률(SCR-C013)과 다른 지표.
11. **잔여 자리 바 정렬**: 마감 우선 → 임박 → 여유 순.
12. **본사 통합 모드**: superAdmin/primary는 지점별 평균 출석률 표시.
13. **5분 캐시**: 현황 카운트는 5분 캐시, 실시간성 우선 시 [새로고침].
14. **수업 행 클릭 드로어**: 예약 회원 명단 + 출석 상태 (실시간).
15. **삭제·취소 권한 분리**: 정원 조정은 본 화면, 수업 취소는 캘린더(SCR-C001).
16. **정원 조정 회원 알림**: 정원 변경 사실은 운영자에게 표시한다. 회원 알림/대기자 배정은 CLS-12 대기 관리 정책과 연동된 경우에만 후속 처리한다.
17. **노쇼 다발 강조**: 본 화면 기간 내 노쇼 ≥ 3건 시 빨강 강조.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `CLS-05`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-C005`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
