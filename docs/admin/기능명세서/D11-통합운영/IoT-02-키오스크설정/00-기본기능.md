## 기능 목적

지점별 키오스크 운영 정책을 한 화면에서 관리한다. 출석 인식 방식(QR/RFID/얼굴인식), 대기 화면 구성, 음성 안내(TTS), 출입 규칙, 출석 후 락커 처리 정책을 5개 탭으로 구분하여 설정하며, 연결된 키오스크 기기의 상태도 함께 확인한다.

## 주요 구성요소

### 탭 구조

| 탭 | 설명 |
|----|------|
| 기본 설정 | 키오스크 활성, 체크인 수단, 직원 출석 허용 여부 |
| 화면 설정 | 배경 이미지, 센터 로고, 환영 문구, 공지 메시지 |
| TTS 설정 | 대기·성공·실패·만료 임박 음성 안내 문구 |
| 출입 규칙 | 출입 허용 시간, 만료 회원 허용, 중복 출석 방지 시간 |
| 락커 후처리 | 출석 후 락커 처리 정책, 자동 배정 존, 미배정 안내 |

### 기본 설정 탭

| 항목 | 입력/선택 |
|------|------|
| 키오스크 활성 | ON / OFF |
| 체크인 수단 | QR / RFID / 얼굴인식 (복수 선택) |
| 직원 출석 허용 | ON / OFF |
| 얼굴인식 사용 | 모듈 활성/비활성 |

### 화면 설정 탭

| 항목 | 동작 |
|------|------|
| 배경 이미지 | 업로드 |
| 센터 로고 | 업로드 |
| 환영 문구 | 텍스트 입력 |
| 공지 메시지 | 텍스트 입력 |
| 미리보기 | 키오스크 화면 기준 미리보기 |

### TTS 설정 탭

| 이벤트 | 입력 |
|------|------|
| 대기 | 반복 안내 문구 + [재생] |
| 성공 | 환영 문구 + [재생] |
| 실패 | 안내 문구 + [재생] |
| 만료 임박 | 안내 문구 + [재생] |

### 출입 규칙 탭

| 항목 | 입력 |
|------|------|
| 출입 허용 시간 | 시작·종료 시각 |
| 만료 회원 허용 | ON / OFF |
| 중복 출석 방지 시간 | 분 단위 |

### 락커 후처리 탭

| 항목 | 옵션 |
|------|------|
| 출석 후 처리 정책 | 출석만 완료 / 수동 배정 대기 / 자동 배정 시도 |
| 자동 배정 존 | 자동 배정 시 탐색할 락커 존 (다중 선택) |
| 미배정 안내 문구 | 자동 배정 실패 시 키오스크 안내 문구 |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 저장 | 현재 탭 설정 저장 |
| 연결 테스트 | 연결된 키오스크 기기 상태 확인 |
| 미리보기 | 화면 설정 기반 미리보기 |
| 배너 업로드 | 배경/로고 이미지 등록 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 키오스크 설정 | 조회 (지점별 수정은 해당 지점 관리자) |
| owner (센터장) | 소속 지점 설정 | 전체 탭 설정 변경·저장 |
| manager (프런트) | 소속 지점 설정 | 조회만 |
| 강사 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**기본 설정 변경**
1. 사이드바 → "통합운영 > 키오스크 설정" 진입
2. 기본 설정 탭에서 활성/체크인 수단 선택
3. [저장] → 토스트 "설정이 저장되었습니다."

**TTS 설정**
1. TTS 탭 → 이벤트별 문구 입력
2. [재생] → 음성 미리 확인
3. [저장]

**락커 후처리 정책**
1. 락커 후처리 탭 → "자동 배정 시도" 선택
2. 자동 배정 존 활성화 → 존 선택
3. 미배정 안내 문구 입력 → [저장]
4. SCR-I001/I004로 정책 반영

**연결 테스트**
1. [연결 테스트] → 키오스크 기기 ping → 상태 배지 갱신

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 현재 저장된 설정값 표시 |
| 수정 중 | 변경 항목 하이라이트, 저장 버튼 활성 |
| 저장 성공 | 토스트 "설정이 저장되었습니다." |
| 저장 실패 | 오류 안내 + 재시도 |
| 키오스크 미연결 | 연결 상태 경고 배지 |
| 권한 부족 | 매니저 이하 조회만 |

## 비즈니스 규칙

1. 키오스크 설정 변경은 owner(센터장) 이상에서만 가능하다.
2. 본사 관리자는 전 지점 설정을 조회만 가능하고, 수정은 해당 지점 관리자가 수행한다.
3. 락커 후처리 "자동 배정 시도" 선택 시 자동 배정 존 입력이 필수가 된다.
4. 자동 배정 실패 시 미배정 안내 문구가 키오스크 화면에 표시된다.
5. 출입 허용 시간 외 출석은 실패로 처리되며 SCR-I001 실패 로그에 기록된다.
6. 중복 출석 방지 시간 내 동일 회원의 재체크인은 "중복" 결과로 기록된다.
7. 모든 설정 변경은 감사 로그(SCR-097)에 기록된다.
8. 키오스크 미연결 상태에서도 설정값 저장은 가능하며, 다음 연결 시 자동 적용된다.
