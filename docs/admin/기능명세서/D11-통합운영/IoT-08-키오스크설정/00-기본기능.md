## 기능 목적

본 기능은 관리자 CRM D11 구현 대상이 아니다.

키오스크 설정 화면은 D09-설정관리의 SCR-082 키오스크 설정, SCR-082A 키오스크 IoT 설정, SCR-083 IoT 출입 관리에서만 관리한다. 키오스크 단말 내부 운영 화면, 관리자 패널, 단말 운영 콘솔은 KIOSK 기획문서에서 정의한다.

## D11 허용 범위

| 표시 위치 | 표시 범위 |
|---|---|
| SCR-I001 통합 출석 관리 | 키오스크/출입 게이트 출석 성공·실패 이벤트, 채널, 실패 사유 |
| SCR-I004 옷 락커 운영 관리 | 키오스크 출석 후 락커 배정 상태 |
| D11 알림/배지 | 키오스크 또는 출입 게이트 상태 수신값이 오프라인/오류인 경우 경고 표시 |

## 구현 금지

- D11에 키오스크 설정 탭, TTS 설정, 화면 설정, 출입 규칙 설정을 만들지 않는다.
- D11에 단말 연결 테스트, 설정 push, 단말 원격 제어를 만들지 않는다.
- 위 설정은 D09 문서 기준으로만 구현한다.
