## 기능 목적

지점에 설치된 모든 키오스크 단말의 운영 정책을 한 화면(SCR-I002)에서 통합 관리한다. 본 화면은 키오스크 단말 운영 설정의 **단일 진입점**으로, 키오스크는 부팅 시 또는 KIO-402 관리자 패널의 [설정 새로고침] 액션 시 본 화면 값을 가져와 적용한다. 출석 인식 방식(QR / RFID / 얼굴인식 / 바코드 / 전화번호), 대기 화면 구성, 음성 안내(TTS), 출입 규칙, 출석 후 락커 처리 정책, 골프·매점 등 부가 메뉴 토글과 선택형 주차 안내 설정을 5개 탭으로 구분하여 운영자가 화면 흐름을 끊지 않고 변경할 수 있게 한다. 골프 예약 UX는 SCR-054 골프타석관리와 동일 데이터 원천을 사용해야 하며, 주차는 지점/건물별 외부 운영 차이를 고려해 admin 연동 필수 범위에서 제외한다. D09 키오스크 도메인의 SCR-082가 키오스크 단말 자체 관리(단말 등록·이미지 빌드·펌웨어)에 가깝다면, 본 SCR-I002는 통합 운영 관점의 **정책·운영 규칙 단일 진입점**이다.

운영 맥락:
- **신규 지점 오픈 초기 설정**: 단말 등록(SCR-I003) → 본 화면에서 인증 수단·환영 문구·TTS·운영 시간 일괄 세팅
- **러시아워 중복 방지 시간 조정**: 평일 06:00~09:00 키오스크 중복 출석 방지 시간을 5분 → 3분으로 일시 단축하여 회전율 향상
- **명절 / 휴무일 운영 시간 변경**: 출입 허용 시간 일시 변경 → 키오스크 push로 즉시 반영
- **TTS 음성 변경 캠페인**: 가을 오픈 환영 캠페인 시 성공 TTS "환영합니다" → "단풍 시즌, 운동 시작!"으로 변경
- **얼굴인식 도입 단계적 활성화**: 모듈 활성 + ka.face.stillSec 1초→2초 단계 조정으로 인식률 ↑
- **자동 락커 배정 도입**: 락커 후처리 정책을 "수동 배정 대기" → "자동 배정 시도"로 전환, 자동 배정 존(A존·B존) 지정
- **얼굴 데이터 미등록 회원 안내**: TTS 만료 임박 문구를 활용하여 얼굴 등록 권유
- **본사 다지점 일괄 정책**: 본사가 전 지점 설정을 조회하며 표준화 권고, 실제 변경은 지점 owner가 수행
- **단말 단위 vs 지점 단위 분리**: 인증 수단·메뉴 노출은 단말마다 다르게, 출석 정책·골프 활성·공지는 지점 모든 키오스크 공통. 주차는 필요 지점에서만 선택 설정
- **fallback 안전 기본값 운영**: 단말이 설정 수신 실패 시 마지막 캐시 사용, 캐시도 없으면 안전 기본값(보조 메뉴 모두 숨김)
- **연결 테스트 일상 점검**: 매일 오픈 전 [연결 테스트]로 단말 ping 확인

5개 탭(기본 / 화면 / TTS / 출입 규칙 / 락커 후처리)은 각각 독립 저장 단위로 운영되며, 미저장 변경 사항은 탭 전환 시 경고 모달로 보호된다.

## 주요 구성요소

### 탭 구조

| 탭 | 설명 |
|----|------|
| 기본 설정 | 키오스크 활성, 체크인 수단, 직원 출석 허용, 얼굴인식 모듈 |
| 화면 설정 | 배경 이미지, 센터 로고, 환영 문구, 공지 메시지, 미리보기 |
| TTS 설정 | 대기·성공·실패·만료 임박 음성 안내 문구 + 재생 |
| 출입 규칙 | 출입 허용 시간, 만료 회원 허용, 중복 출석 방지 시간 |
| 락커 후처리 | 출석 후 락커 처리 정책, 자동 배정 존, 미배정 안내 |

### 기본 설정 탭

| 항목 | 입력/선택 | 기본값 |
|------|------|------|
| 키오스크 활성 | ON / OFF | ON |
| 체크인 수단 | QR / RFID / 얼굴인식 / 바코드 / 전화번호 (복수 선택) | QR + 얼굴인식 |
| 직원 출석 허용 | ON / OFF | OFF |
| 얼굴인식 사용 | 모듈 활성 / 비활성 | 비활성 (지점 정책) |
| 얼굴인식 정지 판정 시간 (ka.face.stillSec) | 1~3초 | 2초 |

### 화면 설정 탭

| 항목 | 동작 |
|------|------|
| 배경 이미지 | 업로드 (1920x1080, JPG/PNG, 최대 5MB) |
| 센터 로고 | 업로드 (PNG 권장, 투명배경, 최대 2MB) |
| 환영 문구 | 텍스트 입력 (50자) |
| 공지 메시지 | 텍스트 입력 (200자, 줄바꿈 허용) |
| 미리보기 | 키오스크 화면 기준 미리보기 |

### TTS 설정 탭

| 이벤트 | 입력 | 글자 수 |
|------|------|------|
| 대기 | 반복 안내 문구 + [재생] | 100자 |
| 성공 | 환영 문구 + [재생] | 80자 |
| 실패 | 안내 문구 + [재생] | 80자 |
| 만료 임박 | 안내 문구 + [재생] | 80자 |

### 출입 규칙 탭

| 항목 | 입력 |
|------|------|
| 출입 허용 시간 | 시작·종료 시각 (HH:mm) |
| 만료 회원 허용 | ON / OFF |
| 중복 출석 방지 시간 | 분 단위 (기본 10분) |
| 출입문 개방 시간 | 초 단위 (기본 5초) |
| 성공 모달 자동 복귀 | 초 단위 (기본 4초) |
| 실패 화면 자동 복귀 | 초 단위 (기본 7초) |
| 미수금 처리 정책 | 경고 / 차단 |

### 락커 후처리 탭

| 항목 | 옵션 |
|------|------|
| 출석 후 처리 정책 | 출석만 완료 / 수동 배정 대기 / 자동 배정 시도 |
| 자동 배정 존 | 자동 배정 시 탐색할 락커 존 (다중 선택) |
| 락커 번호 전달 방식 (ka.locker.deliveryMode) | 영수증 / 앱 / 신발장 밴드 (1택) |
| 전달 실패 fallback (ka.locker.fallbackMode) | 영수증 / 앱 / 신발장 밴드 / 프런트 호출 |
| 미배정 안내 문구 | 자동 배정 실패 시 키오스크 안내 (50자) |

### 부가 메뉴 (지점 정책)

| 항목 | 옵션 |
|------|------|
| 골프 키오스크 활성 (ka.golf.kiosk) | ON / OFF |
| 주차 등록 모드 (ka.parking.mode) | 선택 설정. 안내 / 외부링크 / 프런트호출 |
| 주차 안내 문구 (ka.parking.text) | 선택 설정. 라벨/안내/외부 URL |
| 매점 메뉴 토글 (ka.menu.shop) | ON / OFF |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 저장 | 현재 탭 설정 저장 (탭별 독립) |
| 연결 테스트 | 연결된 키오스크 기기 ping → 상태 배지 |
| 미리보기 | 화면 설정 기반 키오스크 화면 시뮬레이션 |
| 배너 업로드 | 배경/로고 이미지 등록 |
| 설정 새로고침 push | 모든 단말에 강제 갱신 명령 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 키오스크 설정 | 조회만 (수정은 지점 owner) |

| 강사 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

### 기본 설정 변경 (정상)
1. 사이드바 → "통합운영 > 키오스크 설정(/settings/kiosk)" 진입
2. 기본 설정 탭 → 활성/체크인 수단 선택
3. [저장] → 확인 모달 → 토스트 "설정이 저장되었습니다."
4. 단말이 polling(또는 push) 시점에 자동 수신, 즉시 반영하지 않으려면 [설정 새로고침 push]로 강제 갱신

### TTS 설정 + 미리보기
1. TTS 탭 → 이벤트별 문구 입력 (글자 수 카운터)
2. [재생] → TTS 엔진 미리보기 (브라우저 audio)
3. [저장]

### 락커 후처리 정책 변경
1. 락커 후처리 탭 → "자동 배정 시도" 선택 → 자동 배정 존 입력 영역 활성화
2. 존 선택 (A존, B존) → 락커 번호 전달 방식 선택 → 전달 실패 fallback 선택
3. 미배정 안내 문구 입력 → [저장]
4. SCR-I001/I004로 정책 반영 + KIO-201 → KIO-202/203/204 분기 결정

### 연결 테스트
1. [연결 테스트] → 등록 키오스크 단말 ping
2. 응답 시각·펌웨어 버전·온라인 상태 배지 갱신
3. 미연결 단말 강조 + [SCR-I003 IoT 연동 관리로 이동]

### 미리보기
1. 화면 설정 탭 → 배경/로고/문구 입력
2. [미리보기] → 모달에 키오스크 1920x1080 미니 캔버스
3. 확인 후 [저장]

### 분기·예외 흐름
- **탭 전환 시 미저장 변경 사항**: "변경 사항이 저장되지 않았습니다. 그래도 이동하시겠습니까?" 모달 + [저장] / [버리고 이동] / [취소]
- **얼굴인식 모듈 비활성인데 체크인 수단에 얼굴인식 선택**: 인라인 "얼굴인식 모듈 활성 후 선택 가능" + 차단
- **체크인 수단 0개**: "최소 1개 이상 선택해야 합니다" + [저장] 차단
- **자동 배정 시도 선택했으나 자동 배정 존 미입력**: "자동 배정 존을 선택해주세요" + [저장] 차단
- **출입 허용 시간 종료 < 시작**: "종료 시각은 시작 시각 이후로" + [저장] 차단
- **중복 방지 시간 0분 또는 60분 초과**: "1~60분 범위" + [저장] 차단
- **TTS 문구 글자 수 초과**: 인라인 카운터 빨강 + [저장] 차단
- **배경 이미지 5MB 초과**: "최대 5MB" + 업로드 거부
- **로고 이미지 비PNG**: "PNG 권장" 노랑 안내 (JPG도 허용)
- **단말 미연결 상태 저장**: 저장은 가능, 다음 연결 시 자동 적용 안내 노란 배너
- **새로고침 push 실패 (단말 오프라인)**: "X대 단말 push 실패" + 해당 단말 SCR-I003 이동 링크
- **본사 통합 모드 진입**: 모든 입력 비활성화 + 안내 "조회 전용 - 변경은 지점 owner"
- **매니저 권한 진입**: 모든 입력 비활성화 + 조회 전용
- **연결 테스트 타임아웃 (10초)**: "연결 테스트 시간 초과" + 단말 오프라인 의심 안내
- **TTS 재생 브라우저 차단 (autoplay 정책)**: "재생 버튼 클릭 후 들어주세요" 안내
- **락커 번호 전달 방식 "신발장 밴드" 선택했으나 SCR-052 카드매핑 미설정**: "신발장 밴드 매핑이 필요합니다" + SCR-052 이동 링크
- **주차 모드 "외부링크" 선택했으나 URL 미입력**: 선택 설정을 사용하는 지점에 한해 "외부 URL 입력 필수" + [저장] 차단
- **단말 단위 vs 지점 단위 혼동 방지**: 항목별 "단말별 / 지점공통" 배지 표시
- **설정 백업 / 복원**: 본사 운영자가 표준 정책 JSON export/import (옵션)

## 비즈니스 규칙

1. **수정 권한**: owner(센터장) 이상에서만 가능. 본사 슈퍼관리자도 조회만(수정은 지점 owner에 위임).
2. **단말 단위 vs 지점 단위**: 얼굴 인식·인증 수단·메뉴 노출 등은 단말 단위, 출석 정책·직원 출퇴근 허용·골프 정책·공지는 지점 단위. 주차는 필요 지점에서만 안내/외부 링크를 선택 설정한다.
3. **체크인 수단 최소 1개**: QR / RFID / 얼굴인식 / 바코드 / 전화번호 중 최소 1개 활성 필수.
4. **얼굴인식 의존성**: 체크인 수단에 얼굴인식 선택 시 모듈 활성 필수, 모듈 비활성이면 차단.
5. **자동 배정 의존성**: 락커 후처리 "자동 배정 시도" 선택 시 자동 배정 존 ≥1개 필수.
6. **자동 배정 실패 처리**: 자동 배정 실패 시 미배정 안내 문구가 키오스크에 표시되고, 본 화면 미배정 안내 문구가 그대로 사용됨.
7. **출입 허용 시간**: 종료 시각은 시작 시각 이후. 자정을 넘는 시간(예: 06:00~01:00)도 허용.
8. **중복 출석 방지 시간**: 1~60분 범위. 0분 / 60분 초과 차단.
9. **출입문 개방 시간**: 1~30초 범위 (기본 5초).
10. **성공·실패 화면 자동 복귀**: 1~30초 범위 (기본 성공 4초·실패 7초).
11. **미수금 정책**: 경고(출입 허용 + 안내) / 차단(출입 거부) 2종.
12. **TTS 글자 수**: 대기 100자, 성공·실패·만료 임박 80자. 초과 시 [저장] 차단.
13. **배경 이미지 규격**: 1920x1080 권장, JPG/PNG, 최대 5MB. 초과 시 거부.
14. **로고 이미지 규격**: PNG 권장(투명배경), 최대 2MB. JPG 허용 (노랑 안내).
15. **환영 문구 50자, 공지 메시지 200자**.
16. **설정 적용 흐름**: 저장 시 push 또는 단말 polling으로 수신, 로컬 캐시 갱신 후 화면 반영. 관리자가 [설정 새로고침 push]로 강제 갱신 가능.
17. **fallback 안전 기본값**: 단말 설정 수신 실패 시 마지막 캐시 사용, 캐시도 없으면 안전 기본값(보조 메뉴 모두 숨김).
18. **단말 미연결 상태 저장**: 저장은 가능, 다음 연결 시 자동 적용. 노란 배너 안내.
19. **본사 통합 모드**: 모든 입력 비활성, 조회 전용. 변경 시도는 지점 owner에 위임 안내.
20. **부가 메뉴 의존성**: 골프 활성 OFF면 KIO-501~504 진입 불가. 주차 선택 설정을 사용하고 모드가 "외부링크"이면 URL 필수.
21. **락커 번호 전달 방식**: 영수증 / 앱 / 신발장 밴드 1택 + 전달 실패 fallback 1택. 신발장 밴드 선택 시 SCR-052 카드매핑 의존.
22. **저장 단위 분리**: 5개 탭 + 부가 메뉴는 탭별 독립 저장. 탭 전환 시 미저장 변경 사항은 경고 모달.
23. **감사 로그**: 모든 설정 변경은 SCR-097에 actor·target_branch·changed_fields·old_value·new_value 기록.
24. **새로고침 push 실패**: X대 단말 push 실패 시 SCR-I003 이동 링크로 후속 점검 유도.
25. **TTS 재생 미리보기**: 브라우저 autoplay 정책상 사용자 클릭 후 재생, 차단 시 안내.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `IoT-08`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-I002`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
