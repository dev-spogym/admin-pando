## 기능 목적

회원과 직원의 출석 현황을 하나의 화면에서 실시간 통합 조회·관리한다. 키오스크 QR / 얼굴인식 / 앱 QR / 수동 입력 등 다양한 출석 채널의 데이터를 통합 집계하여 운영 효율을 높이고, 출석 후 옷 락커 배정 상태까지 함께 확인한다.

## 주요 구성요소

### 상단 통계 카드

| 카드 | 표시 |
|------|------|
| 오늘 총 출석 | 회원 + 직원 합산 입장 수 |
| 현재 센터 내 | 입장 후 퇴실 미처리 인원 수 |
| 미배정 락커 | 출석 완료 + 옷 락커 미배정 인원 수 |
| 실패 건수 | 금일 출석 실패(만료/중복/미등록 등) 건수 |

### 필터 영역

| 필터 | 옵션 |
|------|------|
| 기간 | 오늘(기본) / 이번 주 / 이번 달 / 직접 선택 |
| 구분 | 전체 / 회원 / 직원 / 게스트 |
| 결과 | 전체 / 성공 / 실패 / 중복 / 퇴실 |
| 채널 | 앱 QR / 키오스크 QR / 얼굴인식 / 수동 |
| 락커 상태 | 전체 / 미배정 / 수동배정 / 자동배정 / 대상 아님 |
| 검색 | 이름·연락처·회원번호·사번 |

### 출석 테이블

| 컬럼 | 표시 |
|------|------|
| 시간 | 입장 시각 |
| 구분 | 회원 / 직원 / 게스트 |
| 이름 | 이름 + 회원번호 또는 사번 |
| 채널 | 앱 QR / 키오스크 QR / 얼굴인식 / 수동 |
| 결과 | 성공 / 실패 / 중복 / 퇴실 |
| 옷 락커 | 미배정 / 수동배정(번호) / 자동배정(번호) / 대상 아님 |
| 고정 락커 | 보유 시 락커 번호, 없으면 '-' |
| 비고 | 실패 사유 또는 운영 메모 |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 수동 출석 등록 | DLG-I001 호출 |
| 실패 로그 | 실패 건만 필터링 표시 |
| 키오스크 모니터 | 최근 키오스크 이벤트 사이드 패널 |

### 행 단위 액션

| 액션 | 설명 |
|------|------|
| 퇴실 처리 | 입장 상태를 퇴실로 전환 |
| 락커 배정 | 미배정 → DLG-I002 호출 |
| 회원 상세 이동 | 행 클릭 → 회원 상세 화면 |

### 수동 출석 등록 (DLG-I001)

| 입력 | 필수 | 설명 |
|------|:--:|------|
| 구분 | ✅ | 회원 / 직원 |
| 이름·번호 검색 | ✅ | 이름·회원번호·사번 자동완성 |
| 출석 시각 | ✅ | 기본값 현재 시각 (수정 가능) |
| 비고 | — | 수동 등록 사유 메모 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 출석 현황 | 지점 선택 후 조회 |
| owner (센터장) | 소속 지점 출석 현황 | 수동 등록·퇴실·락커 배정 |
| manager (프런트) | 소속 지점 출석 현황 | 출석 조회·락커 배정 (직원 수동 등록은 관리자 승인) |
| 강사 | 소속 지점 출석 조회 | 조회만 |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

**출석 현황 모니터링**
1. 사이드바 → "통합운영 > 통합 출석 관리" 진입
2. 오늘 / 전체 / 전체 결과 기본값
3. 키오스크·앱 출석 발생 → 테이블 상단 즉시 반영 + 신규 행 강조

**미배정 락커 처리**
1. "미배정 락커" 카드 클릭 → 미배정 인원 필터링
2. 행 [락커 배정] → DLG-I002 → 락커 선택 → 완료

**수동 출석 등록**
1. [수동 출석 등록] → DLG-I001
2. 구분 선택 → 이름/번호 검색 → 자동완성 선택
3. 출석 시각 확인·수정 → 비고 입력 → [등록]
4. 성공 시 팝업 닫힘 + 토스트 + 목록 즉시 갱신

**퇴실 처리**
1. 입장 상태 행 [퇴실] → 확인 → 결과 "퇴실"로 전환

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 출석 목록 정상 표시 |
| 빈 상태 | 해당 기간 출석 없음 안내 |
| 실시간 업데이트 중 | 신규 행 강조 |
| 필터 결과 없음 | 조건 일치 없음 안내 |
| 로딩 | 스켈레톤 |

## 비즈니스 규칙

1. 회원·직원·게스트 출석은 동일 테이블에서 통합 표시되되 구분 컬럼·필터로 식별된다.
2. 키오스크/앱/얼굴인식/수동 4종 채널이 모두 동일한 출석 레코드 모델로 통합된다.
3. 키오스크 설정(SCR-I002)의 출석 후 락커 처리 정책(출석만 / 수동 배정 대기 / 자동 배정 시도)이 그대로 본 화면 락커 컬럼에 반영된다.
4. 만료 회원·중복 출석은 키오스크 출입 규칙에 따라 실패로 기록된다.
5. 직원 수동 출석 등록은 owner(센터장) 이상 권한으로만 처리 가능하며, 매니저는 회원 등록만 가능하다.
6. 강사는 조회만 가능하며 수동 등록·퇴실·락커 배정 권한이 없다.
7. 본사 관리자는 지점 선택 후 전 지점 현황을 조회한다.
8. 모든 출석·퇴실·락커 배정은 감사 로그(SCR-097)에 기록된다.
