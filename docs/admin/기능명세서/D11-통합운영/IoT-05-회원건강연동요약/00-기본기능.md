## 기능 목적

회원별 체성분, 운동 이력, 건강 목표, 외부 건강 앱(Health Connect) 연동 상태를 하나의 화면(SCR-I007)에서 통합 요약한다. 측정 데이터 자체의 검수·확정 처리는 체성분 통합 관리(SCR-I006)에서, 수기 등록은 DLG-I003에서 수행한다. 관리자가 회원의 건강 상태를 빠르게 파악하고 상담 근거로 활용한다.

## 주요 구성요소

### 1. 회원 건강 요약 (SCR-I007)

#### 요약 카드 영역

| 카드 | 표시 |
|------|------|
| 최근 출석 | 마지막 체크인 시각 |
| 오늘 옷 락커 | 당일 배정 락커 번호 또는 미배정 |
| 고정 락커 | 보유 고정 락커 번호 또는 없음 |
| 최근 InBody | 체중·골격근량·체지방률 최신 (확정 데이터) |
| 최근 7일 활동량 | 걸음수·운동 일수 (Health Connect 연동 시) |

#### 체성분 이력 섹션

| 항목 | 표시 |
|------|------|
| 측정일 | YYYY-MM-DD |
| 체중 변화 | 이전 측정 대비 증감 |
| 골격근량 / 체지방률 | 핵심 지표 그래프 |
| 입력 채널 | 수기 / 파일 업로드 / 실시간 API |

#### 운동 이력 섹션

| 항목 | 표시 |
|------|------|
| 최근 수업 이력 | 수업명·날짜·강사 |
| 운동 프로그램 | 진행 중인 프로그램 |
| 목표 달성률 | 월간 운동 목표 대비 비율 |

#### Health Connect 연동 위젯

| 항목 | 표시 |
|------|------|
| 연동 상태 | 연결됨 / 동기화 대기 / 미연결 배지 |
| 최근 동기화 | 마지막 수신 시각 |
| 활동량 비교 | 센터 출석 운동 vs 외부 활동량 |
| 안내 문구 | Android 하이브리드 앱 경유 연동 명시 |

#### 상담 메모 바로가기

회원 건강·운동 관련 상담 메모 인라인 영역 또는 링크.

### 2. 체성분 통합 관리 (SCR-I006)

#### 상단 현황 카드

| 카드 | 표시 |
|------|------|
| 오늘 측정 건수 | 금일 완료 건수 |

| 미확정 | 수집되었으나 미확정 |

| 실시간 연동 | InBody API 수신 로그 |
| 오류/검수 | 중복·매칭 실패·이상치 검수 처리 |

#### 측정 결과 컬럼

| 컬럼 | 표시 |
|------|------|
| 측정일시 | 측정 완료 시각 |

| 체중 (kg) | 측정값 |
| 골격근량 (kg) | 측정값 |
| 체지방률 (%) | 측정값 |
| BMI | 체질량지수 |
| 입력 채널 | 수기 / 파일 / 실시간 API |
| 확정 여부 | 확정 / 미확정 배지 |

#### 오류/검수 항목

| 항목 | 표시 |
|------|------|
| 오류 유형 | 회원 매칭 실패 / 중복 / 값 이상치 |
| 수집 시각 | 시각 |
| 원본 값 | 수집된 원본 |
| 처리 | 회원 직접 매칭 / 무시 / 확정 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 건강 요약·체성분 | 조회 |
| owner (센터장) | 소속 지점 회원 건강 요약·체성분 통합 | 검수·확정·수기 등록 전체 |
| 담당 강사 | 담당 회원 체성분·운동 이력 | 담당 회원 수기 등록 |
| manager (프런트) | 출석·락커 요약 카드 + 측정 결과 조회 | 수기 등록 (검수는 관리자) |
| 회원 본인 | 회원 앱에서 자신 건강 요약 | 회원 앱 별도 |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

**회원 건강 요약 조회**
1. 회원 목록 또는 회원 상세 → "건강 요약" 진입
2. 요약 카드 → 카드 클릭 시 해당 섹션 스크롤
3. Health Connect 미연동 → 회원 앱 연동 안내
4. 상담 메모 바로가기 → 상담 탭

**체성분 검수**
1. 사이드바 → "통합운영 > 체성분 통합 관리" 진입
2. 검수 대기 카드 클릭 → 오류/검수 탭 자동 이동
3. 오류 항목 선택 → 회원 매칭 또는 무시
4. 확정 처리 → 측정 결과 탭에 반영

**파일 업로드**
1. 업로드 센터 탭 → 파일 선택 → 업로드
2. 파싱 결과 미리보기 → 확정 처리

**수기 등록**
1. [수기 등록] → DLG-I003
2. 회원 검색 → 측정일시 → 체중(필수) + 선택 항목 입력
3. [등록] → 저장 → 측정 결과 갱신
4. 동일 시각 중복 시 검수 대기 안내

| 상태 | 설명 |

| 기본 (요약) | 카드 + 이력 정상 표시 |

| 장비 오프라인 | 연동 장비 카드 경고 |
| 업로드 파싱 중 | 로딩 |
| 빈 상태 | "측정 데이터가 없습니다" |

## 비즈니스 규칙

1. 회원 건강 요약(SCR-I007)에는 확정된 체성분 데이터만 노출되며, 검수 대기·미확정 데이터는 표시되지 않는다.
2. 체성분 입력 채널은 수기 / 파일 업로드 / 실시간 API 3종이며 채널별 배지로 구분된다.
3. 동일 회원·동일 측정 시각의 중복 데이터는 자동으로 "검수 대기" 상태로 저장된다.
4. 회원 매칭 실패·값 이상치도 검수 대기로 분류되며 관리자가 처리해야 확정된다.
5. 체성분 수기 등록 시 체중은 필수, 나머지 수치는 선택이다.
6. 강사는 담당 회원에 한해 수기 등록이 가능하며, 매니저는 검수 처리 권한이 없다.
7. Health Connect 연동은 Android 하이브리드 앱 경유로만 가능하며, 회원 앱에서 활성화해야 데이터가 수집된다.
8. 활동량 비교(센터 운동 vs 외부)는 Health Connect 연동된 회원에게만 표시된다.
9. 모든 검수·확정·수기 등록은 감사 로그(SCR-097)에 기록된다.
