## 기능 목적

회원별 체성분, 운동 이력, 건강 목표, 외부 건강 앱(Health Connect) 연동 상태를 하나의 화면(SCR-I007)에서 통합 요약한다. 측정 데이터 자체의 검수·확정 처리는 체성분 통합 관리(SCR-I006)에서, 수기 등록은 DLG-I003에서 수행한다. Health Connect는 회원앱 동의 기반의 선택 연동이며, v1 범위는 걸음수 / 이동 거리 / 활동 kcal / 운동 세션 요약으로 제한한다.

## 주요 구성요소

### 1. 회원 건강 요약 (SCR-I007)

#### 요약 카드 영역

| 카드 | 표시 |
|------|------|
| 최근 출석 | 마지막 체크인 시각 |
| 오늘 옷 락커 | 당일 배정 락커 번호 또는 미배정 |
| 고정 락커 | 보유 고정 락커 번호 또는 없음 |
| 최근 InBody | 체중·골격근량·체지방률 최신 (확정 데이터) |
| 최근 7일 활동량 | 걸음수·활동 kcal·운동 일수 (Health Connect 연동 시) |

#### 체성분 이력 섹션

| 항목 | 표시 |
|------|------|
| 측정일 | YYYY-MM-DD |
| 체중 변화 | 이전 측정 대비 증감 |
| 골격근량 / 체지방률 | 핵심 지표 그래프 |
| 입력 채널 | 수기 / 파일 업로드 / 실시간 API |

#### 운동 이력 섹션

| 항목 | 표시 |
|------|------|
| 최근 수업 이력 | 수업명·날짜·강사 |
| 운동 프로그램 | 진행 중인 프로그램 |
| 목표 달성률 | 월간 운동 목표 대비 비율 |

#### Health Connect 연동 위젯

| 항목 | 표시 |
|------|------|
| 연동 상태 | 연결됨 / 부분 권한 / 동기화 지연 / 미연결 / 미지원 배지 |
| 최근 동기화 | 마지막 수신 시각 |
| 수집 범위 | 걸음수 / 거리 / 활동 kcal / 운동 세션 |
| 소스 앱 | Samsung Health / Google Fit 등 최근 소스 라벨 |
| 활동량 비교 | 센터 출석 운동 vs 외부 활동량 |
| 안내 문구 | Android 하이브리드 앱 경유 연동 명시 |

#### Health Connect 데이터 범위 / 제외

| 구분 | 항목 |
|------|------|
| 수집 | 걸음수 / 이동 거리 / 활동 kcal / 운동 세션 |
| 비수집 | 심박수 / 수면 / 체온 / 혈당 / 의료 데이터 |
| 동기화 기준 | 최초 연결 시 최근 30일 백필, 이후 회원앱 재진입 또는 수동 동기화 |

#### 상담 메모 바로가기

회원 건강·운동 관련 상담 메모 인라인 영역 또는 링크.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 건강 요약·체성분 | 조회 |
| owner (센터장) | 소속 지점 회원 건강 요약·체성분 통합 | 검수·확정·수기 등록 전체 |
| 담당 강사 | 담당 회원 체성분·운동 이력 | 담당 회원 수기 등록 |
| manager (프런트) | 출석·락커 요약 카드 + 측정 결과 조회 | 수기 등록 (검수는 관리자) |
| 회원 본인 | 회원 앱에서 자신 건강 요약 | 회원 앱 별도 |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

**회원 건강 요약 조회**
1. 회원 목록 또는 회원 상세 → "건강 요약" 진입
2. 요약 카드 → 카드 클릭 시 해당 섹션 스크롤
3. Health Connect 미연동 / 부분 권한 → 회원 앱(MA-159) 연동 또는 권한 수정 안내
4. Health Connect 동기화 지연 → 최근 동기화 시각과 누락 가능성 확인
5. 상담 메모 바로가기 → 상담 탭

**체성분 검수**
1. 사이드바 → "통합운영 > 체성분 통합 관리" 진입
2. 검수 대기 카드 클릭 → 오류/검수 탭 자동 이동
3. 오류 항목 선택 → 회원 매칭 또는 무시
4. 확정 처리 → 측정 결과 탭에 반영

**파일 업로드**
1. 업로드 센터 탭 → 파일 선택 → 업로드
2. 파싱 결과 미리보기 → 확정 처리

**수기 등록**
1. [수기 등록] → DLG-I003
2. 회원 검색 → 측정일시 → 체중(필수) + 선택 항목 입력
3. [등록] → 저장 → 측정 결과 갱신
4. 동일 시각 중복 시 검수 대기 안내

## 비즈니스 규칙

1. 회원 건강 요약(SCR-I007)에는 확정된 체성분 데이터만 노출되며, 검수 대기·미확정 데이터는 표시되지 않는다.
2. 체성분 입력 채널은 수기 / 파일 업로드 / 실시간 API 3종이며 채널별 배지로 구분된다.
3. 동일 회원·동일 측정 시각의 중복 데이터는 자동으로 "검수 대기" 상태로 저장된다.
4. 회원 매칭 실패·값 이상치도 검수 대기로 분류되며 관리자가 처리해야 확정된다.
5. 체성분 수기 등록 시 체중은 필수, 나머지 수치는 선택이다.
6. 강사는 담당 회원에 한해 수기 등록이 가능하며, 매니저는 검수 처리 권한이 없다.
7. Health Connect 연동은 Android 하이브리드 앱 경유로만 가능하며, 회원 앱에서 활성화해야 데이터가 수집된다.
8. v1 수집 범위는 걸음수 / 이동 거리 / 활동 kcal / 운동 세션으로 제한한다.
9. 심박수 / 수면 / 의료 데이터는 수집·표시하지 않는다.
10. 최초 연결 성공 시 최근 30일 활동 요약을 백필한다.
11. 72시간 이상 신규 수집이 없으면 `동기화 지연` 상태로 표시한다.
12. 활동량 비교(센터 운동 vs 외부)는 Health Connect 연동된 회원에게만 표시되며 운영 상담용 참고 지표로 사용한다.
13. Health Connect 상태 변경(연결 / 해제 / 부분 권한)은 회원앱 MA-159에서만 가능하고 admin은 조회만 수행한다.
14. 모든 검수·확정·수기 등록은 감사 로그(SCR-097)에 기록된다.
