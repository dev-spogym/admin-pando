## 기능 목적

D11은 IoT 장비를 등록·삭제·제어하는 독립 운영 화면을 제공하지 않는다. D11에서 필요한 범위는 통합 출석, 락커 운영, 체성분 화면에 표시할 상태값과 이벤트 수신값이다.

기기 설정, 출입 규칙, 키오스크 화면 구성, TTS, 체크인 수단, 기기 등록은 D09-설정관리의 SCR-082/SCR-082A/SCR-083에서 처리한다. 키오스크 단말 운영 화면은 KIOSK 기획문서에서 처리한다.

## 고정 기기 종류

| 기기 종류 | D11에서 사용하는 값 | 표시 위치 |
|---|---|---|
| 출입 게이트 | 출입 성공/실패 이벤트, 온라인/오프라인/오류 상태, 마지막 통신 시각 | SCR-I001 |
| 키오스크 | 출석 체크인 성공/실패 이벤트, 온라인/오프라인/오류 상태, 마지막 통신 시각 | SCR-I001 |
| 락커 컨트롤러 | 락커 잠금/해제 결과, 온라인/오프라인/오류 상태 | SCR-I004, SCR-I005 |
| InBody 측정기 | 측정 사용자, 측정 시각, 체성분 값 | SCR-I006, SCR-I007 |

카드 리더와 얼굴인식 카메라는 별도 기기 종류가 아니라 출입 게이트 또는 키오스크의 인증 수단/부속 모듈이다.

## D11 허용 액션

| 액션 | 설명 |
|---|---|
| 상태 새로고침 | 현재 화면에 표시 중인 상태 배지와 마지막 수신 시각만 갱신 |
| 최근 이벤트 조회 | 출석/락커/체성분 화면 안에서 해당 회원 또는 해당 기기의 최근 이벤트 조회 |
| 관련 화면 이동 | 회원 상세, 락커 상세, 체성분 상세 등 CRM 내부 화면으로 이동 |

## D11 금지 액션

- 기기 추가, 기기 삭제, IP/포트 수정
- 펌웨어 관리, 원격 게이트 개방, 키오스크 원격 재시작
- 로그 다운로드, 자동 전원 스케줄 설정
- 출입 규칙, 키오스크 화면 구성, TTS, 체크인 수단 수정

## InBody 수신 범위

- InBody 측정기는 관리자 CRM에서 제어하지 않는다.
- CRM은 InBody API를 통해 측정 사용자와 사용자의 체성분 정보값만 수신해 표시한다.
- D11은 InBody 장비 연결 테스트, 측정 시작, 장비 설정, 파일 업로드를 제공하지 않는다.

## 비즈니스 규칙

1. D11의 IoT 표시는 "상태/이벤트 조회"로 제한한다.
2. 설정 변경은 D09 문서를 기준으로 구현한다.
3. 키오스크 운영 관제는 KIOSK 기획문서 기준으로 구현한다.
4. D11 화면에서 오류 상태를 표시하더라도 복구 명령 버튼을 제공하지 않는다.
