## 기능 목적

지점에 설치된 IoT 장비(출입 게이트, 키오스크, 락커 컨트롤러, InBody 측정기)의 연결 상태를 통합 모니터링·관리한다. 기기 등록·삭제, 연결 테스트, 출입 로그 조회, 원격 게이트 제어, 자동 전원 스케줄까지 5개 탭으로 분리하여 운영한다.

## 주요 구성요소

### 탭 구조

| 탭 | 설명 |
|----|------|
| 게이트 관리 | 출입문 목록, 실시간 연결 상태, 원격 개방 |
| IoT 기기 | 지점 전체 기기 목록 + 상태 배지 |
| 출입 로그 | 출입 성공/실패/예외 이벤트 이력 |
| 출입 규칙 | 시간대·요일·게이트별 출입 허용 규칙 |
| 자동 전원 | 키오스크/기기 전원 ON·OFF 스케줄 |

### IoT 기기 탭

| 컬럼 | 표시 |
|------|------|
| 기기명 | 장비 식별 이름 |
| 유형 | 게이트 / 키오스크 / 락커 컨트롤러 / InBody |
| IP/포트 | 네트워크 연결 정보 |
| 상태 | 온라인 / 오프라인 / 오류 / 점검 중 |
| 마지막 통신 | 최근 heartbeat 시각 |
| 펌웨어 버전 | 설치 펌웨어 버전 |

### InBody 채널 상태 배지

| 채널 | 설명 |
|------|------|
| 수기 | 직원 수동 입력 |
| 파일 업로드 | 장비 파일 업로드 |
| 실시간 API | InBody 직접 전송 |

### 게이트 관리 탭

| 컬럼 | 표시 |
|------|------|
| 게이트명 | 출입문 식별 이름 |
| 연결 상태 | 온라인 / 오프라인 |
| 원격 개방 | [개방] 버튼 (예외 상황) |
| 마지막 이벤트 | 최근 출입 이벤트 시각 |

### 출입 로그 탭

| 필터 | 옵션 |
|------|------|
| 기간 | 직접 선택 |
| 게이트 | 단일/다중 |
| 결과 | 성공 / 실패 / 예외 |

### 출입 규칙 탭

| 항목 | 입력 |
|------|------|
| 요일 | 월~일 다중 선택 |
| 시간 범위 | 시작·종료 시각 |
| 게이트 | 단일/다중 |

### 자동 전원 탭

| 항목 | 입력 |
|------|------|
| 대상 기기 | 키오스크/게이트/락커 컨트롤러 |
| ON 시각 | HH:mm |
| OFF 시각 | HH:mm |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 기기 추가 | 신규 장비 등록 (유형·이름·IP·포트) |
| 연결 테스트 | 선택 기기 ping |
| 원격 게이트 개방 | 강제 개방 + 히스토리 자동 |
| 삭제 | 기기 비활성/제거 |
| 전체 동기화 | 모든 기기 상태 일괄 새로고침 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 기기 현황 | 조회 (개별 제어는 해당 지점 관리자) |
| owner (센터장) | 소속 지점 기기 | 등록·삭제·원격 제어·규칙 설정 |
| manager (프런트) | 소속 지점 출입 로그 | 출입 로그 조회만 |
| 강사 | 접근 불가 | — |
| readonly | 접근 불가 | — |

## 주요 UX 흐름

**기기 등록**
1. 사이드바 → "통합운영 > IoT 연동 관리" 진입
2. IoT 기기 탭 → [기기 추가]
3. 유형·이름·IP·포트 입력 → 저장
4. 자동 연결 테스트 → 상태 배지 표시

**원격 게이트 개방**
1. 게이트 관리 탭 → 게이트 행 [원격 개방]
2. 확인 팝업 → 실행
3. 히스토리 로그 자동 생성

**출입 규칙 설정**
1. 출입 규칙 탭 → 요일·시간·게이트 선택
2. [저장] → 키오스크 설정과 연동

**자동 전원 스케줄**
1. 자동 전원 탭 → 대상 기기 선택
2. ON/OFF 시각 입력 → [저장]

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 기기 목록 + 상태 배지 |
| 기기 없음 | "등록된 기기가 없습니다" + [기기 추가] |
| 오프라인 기기 있음 | 빨간 상태 배지 강조 |
| 오류 기기 있음 | 오류 내용 툴팁 |
| 동기화 중 | 전체 동기화 버튼 로딩 |
| 권한 부족 | 매니저 이하 출입 로그만 |

## 비즈니스 규칙

1. 기기 등록·삭제·원격 제어는 owner(센터장) 이상에서만 가능하다.
2. 원격 게이트 개방은 확인 팝업 후 실행되며 히스토리 로그(누가/언제/어느 게이트)가 자동 생성된다.
3. heartbeat 미수신 임계값을 초과하면 상태가 자동으로 "오프라인"으로 전환된다.
4. InBody 측정기는 수기 / 파일 업로드 / 실시간 API 3개 채널을 모두 지원하며 채널별 상태 배지로 구분된다.
5. 출입 규칙 외 시간대 출석 시도는 실패로 기록되며 SCR-I001에 표시된다.
6. 자동 전원 스케줄은 시스템 스케줄러에 의해 자동 처리되며 실행 결과가 출입 로그에 기록된다.
7. 매니저는 출입 로그 조회만 가능하며 기기 추가/삭제/원격 제어는 불가하다.
8. 모든 기기 등록·삭제·원격 제어·규칙 변경은 감사 로그(SCR-097)에 기록된다.
