## 기능 목적

현장 키오스크 운영 상태(체크인 카운트·오류·운영 시간)를 실시간으로 모니터링한다. 정상보다 장애 상태가 먼저 강조되어, 오프라인·오류가 발생한 키오스크를 즉시 식별하고 대응할 수 있게 한다. IoT 연동 관리(SCR-I003)와 보완 관계로, IoT-03이 기기 등록·제어 중심이라면 IoT-06은 운영 모니터링 중심이다.

운영 맥락:
- **아침 오픈 전 장애 사전 확인**: 센터장이 출근 전 모바일로 화면에 접근하여 키오스크 정상 여부를 확인하고, 오프라인 단말이 있으면 원격 재시작을 선제 실행한다.
- **체크인 폭주 시간대 모니터링**: 오전·저녁 피크 타임에 오늘 체크인 카운트가 급감하면 키오스크 장애 신호로 인식하고 즉각 대응한다.
- **원격 재시작으로 현장 방문 최소화**: 프런트 스태프가 없는 시간대에 장애 키오스크를 관리자 원격 재시작 명령으로 복구하여 현장 인력 투입 없이 운영을 정상화한다.
- **OFFLINE 임계 초과 자동 알림 수신**: heartbeat 미수신 임계(5분) 초과 시 자동 알림이 센터장에게 발송되어, 관리자가 즉시 인지하고 대응 절차를 개시한다.
- **로그 다운로드로 장애 원인 분석**: 원격 재시작 후에도 반복 장애 발생 시 키오스크 로그를 다운로드하여 AS 요청 또는 펌웨어 업데이트 근거 자료로 활용한다.
- **본사 전 지점 현황 조감**: 본사 superAdmin이 전 지점 키오스크 현황을 한 화면에서 조감하여 특정 지점군 장애 패턴(예: 특정 기기 모델 반복 오류)을 파악한다.
- **SCR-082A IoT 설정과 페어링 운영**: 운영 시간 스케줄이 SCR-I003에서 변경되면 본 화면의 ON/OFF 시각이 즉시 갱신되어, 두 화면이 항상 동기화된 운영 시간 정보를 공유한다.

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업 기반이며 기기 상태 heartbeat 연동은 후속 단계.

## 주요 구성요소

### 상단 요약 카드

| 카드 | 표시 |
|------|------|
| 전체 키오스크 | 등록 키오스크 총 수 |
| 정상 운영 중 | 온라인 + 정상 동작 |
| 장애 / 오류 | 오프라인 또는 오류 발생 (강조) |
| 오늘 체크인 | 키오스크 경유 금일 체크인 합계 |

### 키오스크 카드 그리드

키오스크 1대당 1카드, 장애 카드가 그리드 상단으로 우선 정렬된다.

| 항목 | 표시 |
|------|------|
| 키오스크명 | 식별 이름 + 위치 |
| 상태 배지 | 정상 / 오프라인 / 오류 / 점검 중 |
| 마지막 통신 | 최근 heartbeat 시각 |
| 오늘 체크인 카운트 | 카운트 |
| 최근 이벤트 | 최근 출석/실패 이벤트 1~3건 |
| 운영 시간 | ON/OFF 시각 (자동 전원 스케줄 기반) |

### 장애 알림 영역

| 항목 | 표시 |
|------|------|
| 장애 발생 키오스크 | 이름 + 발생 시각 |
| 오류 코드 | 코드/사유 |
| 운영 안내 | 권장 대응 가이드 |
| 액션 | [IoT 연동 관리로 이동] / [원격 재시작] |

### 운영 안내 패널

| 항목 | 표시 |
|------|------|
| 점검 일정 | 예정된 점검 시각 |
| 운영 공지 | 본사 발송 운영 공지 |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 전체 새로고침 | 모든 키오스크 상태 갱신 |
| IoT 기기 관리 이동 | SCR-I003 IoT 연동 관리로 이동 |
| 원격 재시작 | 선택 키오스크 재시작 명령 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 키오스크 운영 현황 | 조회 (제어는 해당 지점) |
| owner (센터장) | 소속 지점 키오스크 | 새로고침·원격 재시작 |

| 강사 | 접근 불가 | — |

## 운영 시나리오 (페르소나 × 트리거 × 결과)

| 페르소나 | 사용 맥락 | 행동 | 기대 결과 |
|---|---|---|---|
| 센터장 | 아침 오픈 전 선제 점검 | 화면 진입 → 요약 카드 확인 → 오프라인 카드 클릭 → [원격 재시작] | 오픈 전 키오스크 정상화 완료, 현장 방문 불필요 |

| 센터장 | 반복 장애 키오스크 로그 수집 | 장애 카드 → [로그 다운로드] → AS 요청 첨부 | 로그 파일 확보, AS 요청 근거 자료 제출 |
| 본사 superAdmin | 전 지점 장애 패턴 분석 | 전 지점 현황 조감 → 특정 기기 모델 반복 오류 패턴 확인 | 펌웨어 일괄 업데이트 또는 기기 교체 의사결정 근거 확보 |

| 본사 운영팀 | 전사 키오스크 가동률 주간 보고 | 전 지점 정상/장애 카운트 확인 → 가동률 산출 → 보고서 작성 | 지점별 키오스크 안정성 현황 파악 |

## 분기·예외 흐름

- **heartbeat 미수신 임계(5분) 초과 시 자동 OFFLINE 전환**: 배지 "오프라인"으로 자동 변경, 장애 카드 그리드 상단 이동, 센터장 자동 알림 발송.
- **원격 재시작 명령 후 응답 없음(60초 타임아웃)**: "재시작 명령이 전달되지 않았습니다. 현장 확인이 필요합니다" 안내 + SCR-I003 이동 버튼.
- **원격 재시작 권한 미달(프런트 매니저)**: 재시작 버튼 비활성화, "센터장 이상 권한이 필요합니다" 툴팁.
- **등록된 키오스크 없음**: "등록된 키오스크가 없습니다" 빈 상태 + [IoT 연동 관리로 이동] CTA.
- **데이터 미연동 환경**: 목업 데이터 안내 배너 상시 노출, 실제 heartbeat 미수신.
- **전체 새로고침 중 장애 추가 발생**: 새로고침 완료 후 최신 상태 반영, 새로 발생한 장애 카드 상단 배치.
- **로그 다운로드 실패**: 토스트 "로그 다운로드에 실패했습니다. 다시 시도해주세요".
- **점검 중 상태 키오스크 원격 재시작 시도**: "점검 중인 키오스크입니다. 점검 완료 후 재시작해주세요" 경고.
- **SCR-I003 운영 시간 변경 후 IoT-06 미동기화**: 30초 내 자동 동기화. 초과 시 수동 새로고침 안내.
- **강사 계정 접근**: 403 화면.
- **복수 키오스크 동시 장애**: 요약 카드 장애 카운트 즉시 갱신, 모든 장애 카드 그리드 상단 정렬.

## 주요 UX 흐름

**운영 모니터링**
1. 사이드바 → "통합운영 > 키오스크 운영 현황" 진입
2. 요약 카드 + 장애 키오스크 강조 카드 우선 노출
3. 장애 발생 시 즉시 식별

**장애 대응**
1. 장애 알림 영역에서 해당 키오스크 확인
2. [원격 재시작] → 확인 → 명령 전송
3. 또는 [IoT 연동 관리로 이동] → SCR-I003에서 상세 진단

**운영 시간 확인**
1. 키오스크 카드 → ON/OFF 시각 표시 확인
2. 스케줄 변경은 IoT 연동 관리 자동 전원 탭에서 수행

## 비즈니스 규칙

1. **장애 우선 정렬**: 오프라인·오류·점검 중 카드가 그리드 상단으로 우선 정렬된다. 정상 카드는 하단 표시.
2. **OFFLINE 임계값**: heartbeat 미수신 5분 초과 시 자동으로 "오프라인" 배지 부여 + 장애 카운트 증가 + 센터장 자동 알림.
3. **heartbeat 폴링 주기**: 30초 간격으로 서버가 각 키오스크 heartbeat 수신 여부 확인.
4. **원격 재시작 권한**: owner(센터장) 이상만 가능. 프런트 매니저는 조회·새로고침만. 본사 superAdmin은 전 지점 조회만(재시작은 해당 지점 관리자 수행).
5. **원격 재시작 타임아웃**: 명령 전송 후 60초 내 응답 없으면 실패 처리 + 현장 확인 안내.
6. **원격 재시작 감사 로그**: 재시작 명령 전송·성공·실패 모두 SCR-097 기록. `actor_id`, `kiosk_id`, `action`, `result`, `executed_at` 저장.
7. **운영 시간 동기화**: SCR-I003 자동 전원 스케줄 변경 시 30초 내 IoT-06 ON/OFF 시각 자동 갱신.
8. **체크인 카운트 동기화**: 오늘 체크인 카운트는 SCR-I001 통합 출석 관리와 실시간 동기화(1분 주기).
9. **로그 다운로드**: 키오스크별 최근 7일 운영 로그 다운로드 가능. 다운로드는 owner 이상 권한. 감사 로그 기록.
10. **점검 중 상태**: SCR-I003에서 점검 일정 등록 시 자동으로 "점검 중" 배지 부여. 점검 중 원격 재시작 경고.
11. **데이터 미연동 환경**: 목업 데이터 안내 배너 상시 노출. heartbeat 실제 수신 안 됨을 명시.
12. **복수 키오스크 동시 장애**: 각 장애 건 독립 처리. 요약 카드 장애 카운트 합산 표시.
13. **자동 알림 임계**: OFFLINE 5분 + 오류 코드 수신 즉시. 알림 채널은 인앱 + (테넌트 설정에 따라) SMS.
14. **전사 가동률 집계**: 정상 키오스크 수 / 전체 키오스크 수 × 100. 주간 배치로 집계하여 본사 운영 보고에 활용.
15. **SCR-082A IoT 설정 페어링**: SCR-082A(IoT 키오스크 설정)에서 변경된 운영 정책(자동 전원·네트워크 설정)이 IoT-06 운영 현황에 즉시 반영.
16. **강사 접근 차단**: 강사 계정은 IoT-06 접근 불가. 403 처리.
17. **오류 코드 매핑**: 키오스크 오류 코드별 운영 안내 가이드(권장 대응 텍스트)가 장애 알림 영역에 자동 표시.
18. **새로고침 쿨다운**: 전체 새로고침은 10초 쿨다운. 연속 클릭 시 버튼 일시 비활성.

## 예외 / 에러 처리
