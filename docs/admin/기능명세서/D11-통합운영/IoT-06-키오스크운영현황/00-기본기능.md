## 기능 목적

본 기능은 관리자 CRM D11 구현 대상이 아니다.

키오스크 운영 현황, 단말별 장애 콘솔, 원격 재시작, 로그 다운로드, KIO-402 관리자 패널 연동은 KIOSK 기획문서에서 정의한다. D11은 별도 키오스크 운영 화면을 만들지 않고, 키오스크에서 발생한 출석 이벤트와 상태 수신값을 SCR-I001 통합 출석 관리에 표시한다.

## D11 반영 방식

| 표시 위치 | 표시 내용 | 허용 액션 |
|---|---|---|
| SCR-I001 통합 출석 관리 | 최근 키오스크 출석 이벤트, 실패 사유, 마지막 수신 시각 | 새로고침, 실패 로그 필터 |
| SCR-101 대시보드 통합 | 실시간 출석 확인 카드 | 회원 상세 이동 |
| NFR-19 알림 센터 | 키오스크/출입 게이트 오프라인 알림 | 알림 확인, 담당자 지정 |

## 구현 금지

- D11에 `/kiosk-ops` route를 만들지 않는다.
- 원격 재시작 버튼, 로그 다운로드 버튼, 기기 상세 모달, 전사 키오스크 가동률 콘솔을 만들지 않는다.
- 키오스크 운영 관제와 단말 관리자 기능은 KIOSK 문서 기준으로 개발한다.
