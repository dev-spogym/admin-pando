## 기능 목적

현장 키오스크 운영 상태(체크인 카운트·오류·운영 시간)를 실시간으로 모니터링한다. 정상보다 장애 상태가 먼저 강조되어, 오프라인·오류가 발생한 키오스크를 즉시 식별하고 대응할 수 있게 한다. IoT 연동 관리(SCR-I003)와 보완 관계로, IoT-03이 기기 등록·제어 중심이라면 IoT-06은 운영 모니터링 중심이다.

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업 기반이며 기기 상태 heartbeat 연동은 후속 단계.

## 주요 구성요소

### 상단 요약 카드

| 카드 | 표시 |
|------|------|
| 전체 키오스크 | 등록 키오스크 총 수 |
| 정상 운영 중 | 온라인 + 정상 동작 |
| 장애 / 오류 | 오프라인 또는 오류 발생 (강조) |
| 오늘 체크인 | 키오스크 경유 금일 체크인 합계 |

### 키오스크 카드 그리드

키오스크 1대당 1카드, 장애 카드가 그리드 상단으로 우선 정렬된다.

| 항목 | 표시 |
|------|------|
| 키오스크명 | 식별 이름 + 위치 |
| 상태 배지 | 정상 / 오프라인 / 오류 / 점검 중 |
| 마지막 통신 | 최근 heartbeat 시각 |
| 오늘 체크인 카운트 | 카운트 |
| 최근 이벤트 | 최근 출석/실패 이벤트 1~3건 |
| 운영 시간 | ON/OFF 시각 (자동 전원 스케줄 기반) |

### 장애 알림 영역

| 항목 | 표시 |
|------|------|
| 장애 발생 키오스크 | 이름 + 발생 시각 |
| 오류 코드 | 코드/사유 |
| 운영 안내 | 권장 대응 가이드 |
| 액션 | [IoT 연동 관리로 이동] / [원격 재시작] |

### 운영 안내 패널

| 항목 | 표시 |
|------|------|
| 점검 일정 | 예정된 점검 시각 |
| 운영 공지 | 본사 발송 운영 공지 |

### 헤더 버튼

| 버튼 | 동작 |
|------|------|
| 전체 새로고침 | 모든 키오스크 상태 갱신 |
| IoT 기기 관리 이동 | SCR-I003 IoT 연동 관리로 이동 |
| 원격 재시작 | 선택 키오스크 재시작 명령 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin (본사) | 전 지점 키오스크 운영 현황 | 조회 (제어는 해당 지점) |
| owner (센터장) | 소속 지점 키오스크 | 새로고침·원격 재시작 |
| manager (프런트) | 소속 지점 키오스크 | 조회·새로고침 (재시작은 관리자 승인) |
| 강사 | 접근 불가 | — |
| readonly | 조회 | 조회만 |

## 주요 UX 흐름

**운영 모니터링**
1. 사이드바 → "통합운영 > 키오스크 운영 현황" 진입
2. 요약 카드 + 장애 키오스크 강조 카드 우선 노출
3. 장애 발생 시 즉시 식별

**장애 대응**
1. 장애 알림 영역에서 해당 키오스크 확인
2. [원격 재시작] → 확인 → 명령 전송
3. 또는 [IoT 연동 관리로 이동] → SCR-I003에서 상세 진단

**운영 시간 확인**
1. 키오스크 카드 → ON/OFF 시각 표시 확인
2. 스케줄 변경은 IoT 연동 관리 자동 전원 탭에서 수행

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 (정상) | 모든 키오스크 정상 + 정상 카드 표시 |
| 장애 발생 | 장애 카드 그리드 상단 우선 정렬 + 빨간 배지 |
| 오프라인 키오스크 있음 | 마지막 통신 시각 강조 |
| 점검 중 | 점검 배지 표시 |
| 빈 상태 | "등록된 키오스크가 없습니다" + IoT 연동 관리 이동 |
| 데이터 미연동 | 목업 데이터 안내 배너 |
| 권한 부족 | 매니저 이하 원격 재시작 비활성 |

## 비즈니스 규칙

1. 정상 카드보다 장애·오프라인·오류 카드가 그리드 상단으로 우선 정렬된다.
2. heartbeat 미수신 임계값 초과 시 자동으로 "오프라인" 배지가 부여된다.
3. 본사 관리자는 전 지점 운영 현황을 조회만 가능하며, 원격 재시작은 해당 지점 관리자가 수행한다.
4. 매니저(프런트)는 새로고침·조회만 가능하며 원격 재시작은 owner(센터장) 이상에서 처리한다.
5. 키오스크 운영 시간은 IoT 연동 관리(SCR-I003) 자동 전원 스케줄을 그대로 반영한다.
6. 오늘 체크인 카운트는 통합 출석 관리(SCR-I001)와 동기화된다.
7. 원격 재시작·새로고침 결과는 감사 로그(SCR-097)에 기록된다.
8. 데이터 미연동 환경에서는 목업 표시 배너로 명시한다.
