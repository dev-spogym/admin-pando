## 기능 목적

출석과 연동되는 당일용 옷 락커(SCR-I004)와 상품 계약 기반 고정 물품 락커(SCR-I005)를 통합 운영한다. 락커 그리드에서 사용 현황을 한눈에 파악하고, 미배정 회원 배정·회수·고장 처리·계약 만료 연장까지 처리한다.

## 주요 구성요소

### 1. 옷 락커 운영 (SCR-I004)

#### 상단 현황 카드

| 카드 | 표시 |
|------|------|
| 전체 락커 수 | 지점 등록 옷 락커 총 수 |
| 사용 중 | 현재 배정된 락커 수 |
| 미배정 대기 | 출석 완료 + 락커 미배정 인원 수 |
| 점검 중 | 고장·청소 처리 락커 수 |

#### 락커 그리드 (상태별 색상)

| 상태 | 표시 |

#### 미배정 회원 패널

| 컬럼 | 표시 |

| 회원명 | 미배정 대기 회원 |

## 주요 UX 흐름

**옷 락커 배정**
1. 사이드바 → "통합운영 > 옷 락커 운영 관리" 진입
2. 미배정 카드 강조 → 패널 열기 유도
3. 미배정 회원 선택 → 빈 락커 선택 → DLG-I002 [배정]
4. 그리드 + 회원 패널 즉시 갱신

**옷 락커 회수**
1. 사용 중 락커 클릭 → 회원 정보 팝업
2. [회수] → 확인 → 빈 락커로 전환

**일괄 해제**
1. [일괄 해제] → 대상(만료/반납 지연) 락커 목록 확인 팝업
2. 일괄 처리 → 빈 락커로 전환

**고정 락커 신규 배정**
1. 화면 전환 → 고정 락커 관리 (SCR-I005)
2. [배정하기] → 회원 검색 → 락커 번호·만료일 입력
3. 락커 상품 미보유 시 안내 → 차단
4. 저장

**고정 락커 연장·회수**
1. 만료 예정 카드 클릭 → 만료 예정 필터
2. [연장] → 새 만료일 입력 → 저장
3. [회수] → 확인 → 회수 (이력 보존)

## 비즈니스 규칙

1. 옷 락커는 출석 기반 당일용, 고정 락커는 상품 계약 기반 장기 배정으로 모델이 분리된다.
2. 옷 락커 배정 대상은 출석 완료 + 미배정 + 락커 대상 회원에 한정된다.
3. 고정 락커 신규 배정은 회원이 락커 상품을 보유한 경우에만 가능하며, 미보유 회원은 안내 후 차단된다.
4. 옷 락커 일괄 해제는 만료/반납 지연 상태에 한해서 동작하며, 매니저는 관리자 승인을 받아야 한다.
5. 고정 락커 회수 시에도 회원-락커 매핑 이력은 보존되어 추후 조회가 가능하다.
6. 만료 예정(7일 이내) 락커는 자동으로 "만료 예정" 배지가 부여된다.
7. 키오스크 설정(SCR-I002) 락커 후처리 정책 "자동 배정 시도"가 활성화되면 출석 시 자동 배정이 실행되며, 본 화면 그리드에 자동배정으로 표시된다.
8. 고정 락커 엑셀 다운로드는 현재 필터·페이지와 무관하게 선택 조건 전체 데이터를 내려받는다.
9. 모든 배정·회수·고장 처리·연장은 감사 로그(SCR-097)에 기록된다.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `IoT-04`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-I004, SCR-I005`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-I002 옷락커배정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
