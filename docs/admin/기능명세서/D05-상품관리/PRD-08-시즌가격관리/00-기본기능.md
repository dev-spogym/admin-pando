## 기능 목적

여름 특가, 신년 이벤트, 가정의 달 등 특정 기간에만 적용되는 시즌 특별 가격을 설정하고 관리하는 화면이다. 기간(시작일~종료일), 대상 상품(다중 선택), 특가 금액(정액) 또는 할인율(정률)을 지정하여 시작일 도래 시 자동 활성화되고 종료일 후 자동으로 정상가로 복구된다. 일반 할인(PRD-04)·쿠폰·마일리지와의 중복 정책은 우선순위 규칙으로 처리되며, 진행 중 시즌은 카탈로그(PRD-05)·키오스크·결제(SCR-S003)에 자동 강조 표시된다. 달력 뷰로 월별 캠페인 일정을 시각화하고, 종료된 시즌도 회색 처리되어 이력으로 보존된다.

운영 맥락:
- **여름 / 겨울 시즌 특가**: 6~8월 헬스 6개월 회원권 -20%, 12~2월 PT 패키지 정액 5만원 할인
- **신년 이벤트 (1/1~1/15)**: 모든 회원권 -15%, "신년 결심" 마케팅 메시지 동시 발송
- **가정의 달 5월 캠페인**: 패밀리 회원권 정률 25% (가족 그룹 MBR-EXT-02 연계)
- **블랙프라이데이 단기 특가 (3일)**: 24시간 단위 시즌 등록, 카탈로그 카운트다운
- **재등록 우대 시즌**: 만료 30일 이내 회원 대상 정률 10% (자동 적용 조건 + 시즌 결합)
- **시즌 종료 자동 복구**: 종료일 23:59 자동 비활성, 다음날 정상가 결제
- **시즌 충돌 처리**: 동일 상품에 여러 시즌 등록 시 마지막 등록 우선 또는 큰 할인 우선
- **달력 뷰 캠페인 계획**: 월별 시즌 일정 시각화, 충돌 / 공백 식별
- **진행 중 시즌 부분 수정**: 대상 상품 추가는 가능, 기간·금액 변경은 제한 (혼선 방지)

## 주요 구성요소

### 시즌 특가 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 시즌명 | 예: "2026 여름 특가" |
| 적용 기간 | 시작일 ~ 종료일 |
| 대상 상품 | 적용 상품 {개수}개 |
| 특가 금액/할인율 | 정액 또는 정률 |
| 상태 | 예정 / 진행 중 / 종료 |
| 상태별 D-day | 시작 D-N / 종료 D-N |
| 액션 | [수정] / [삭제] |

### 상태별 구분

| 상태 | 조건 | 색상 |
|------|------|------|
| 예정 | 시작일 이전 | 파랑 |
| 진행 중 | 시작일~종료일 | 초록 |
| 종료 | 종료일 이후 | 회색 |

### 달력 뷰 (선택)

월별 달력에서 시즌 특가 기간 시각화. 달력 / 목록 뷰 전환. 충돌 기간은 빨강 강조.

### 시즌 특가 등록·수정 (DLG-P016)

| 입력 | 설명 |
|------|------|
| 시즌명 | 텍스트 (필수, 1~30자) |
| 시작일 ~ 종료일 | 날짜 범위 (필수) |
| 대상 상품 | 다중 선택 또는 카테고리 일괄 |
| 특가 유형 | 정액 / 정률 |
| 특가 값 | 금액 또는 % |
| 중복 정책 | 일반 할인과 중복 / 단독 / 큰 것만 |
| 비고 | textarea |
| 자동 활성 토글 | ON/OFF (수동 활성도 가능) |

### 진행 중 강조

현재 적용 중인 특가는 목록 상단 고정 또는 강조 표시. 카탈로그·키오스크에도 자동 반영.

## 주요 UX 흐름

**시즌 특가 등록**
1. 사이드바 → "상품관리 > 시즌 가격 관리" 진입
2. [시즌 특가 등록] → DLG-P016
3. 시즌명·기간·대상 상품·특가·중복 정책 입력
4. 저장 → 목록 추가 (예정 상태)
5. 시작일 도래 → 자동 활성

**시즌 특가 수정**
1. 행 [수정] → DLG-P016 채워진 폼
2. 정보 변경 → 저장
3. 진행 중인 경우 대상 상품 추가만 가능

**시즌 특가 삭제**
1. 행 [삭제] → 확인
2. 진행 중이면 안내 → 즉시 종료 처리

**진행 중 확인**
1. 상단 강조된 진행 중 시즌 확인
2. 적용 중인 상품 목록 검토

**달력 뷰 전환**
1. 목록 ↔ 달력 토글
2. 월별 시각화, 충돌 빨강 강조

### 분기·예외 흐름

- **시작일 > 종료일**: 인라인 "종료일은 시작일 이후여야 해요" + 저장 차단
- **시작일이 과거**: 노랑 경고 "시작일이 과거입니다, 즉시 활성됩니다" + 저장 가능 (소급 적용 의도)
- **시작일 = 종료일 (당일 특가)**: 허용 (당일 23:59 종료)
- **대상 상품 0개**: "최소 1개 상품을 선택해주세요" + 저장 차단
- **카테고리 일괄 선택 + 비활성 상품 포함**: 비활성 상품 자동 제외 + 안내
- **동일 상품 + 중복 시즌**: 중복 정책 토글에 따라 처리, 충돌 경고 표시
  - 마지막 등록 우선 (기본)
  - 큰 할인 우선
  - 사용자 명시 우선순위
- **정률 100% 초과 / 0 이하**: "1~100% 사이" 차단
- **정액 0 이하**: "0보다 큰 금액" 차단
- **정액 > 정상가 (음수 결제)**: "특가가 정상가를 초과합니다" 차단
- **진행 중 시즌 기간 변경 시도**: "진행 중 시즌은 기간 변경 불가" + 차단 (즉시 종료만 가능)
- **진행 중 시즌 금액 변경 시도**: "금액 변경 불가" + 차단
- **진행 중 시즌 대상 상품 추가**: 허용 + 즉시 적용
- **진행 중 시즌 대상 상품 제거**: "이미 결제 완료된 회원에게는 영향 없음" 안내 + 진행
- **진행 중 시즌 즉시 삭제**: "정상가로 즉시 복구됩니다" 확인 → 즉시 종료
- **시즌명 중복**: 허용 (의미 있음, 예: "2026 여름 특가" + "2026 여름 특가 추가")
- **종료일 도래 시 자동 비활성 실패(시스템 오류)**: 운영자에게 알림 + 수동 종료 안내
- **카탈로그 / 키오스크 동기화 지연**: 5분 캐시 + [지금 동기화]
- **PRD-04 일반 할인과 중복**: 중복 정책 우선순위 규칙 적용
  - 중복 허용: 시즌 → 할인 순차 적용
  - 단독: 할인이 있으면 시즌 무시
  - 큰 것만: 할인율 큰 쪽
- **결제(SCR-S003) 중 시즌 종료**: 결제 트랜잭션 시점 가격 보호 (락인)
- **자동 활성 OFF + 수동 활성**: 운영자가 수동으로 [활성화] 클릭 시 즉시 활성
- **본사 정의 시즌 + 지점 수정 시도**: "본사 정의 시즌은 수정 불가" + 차단
- **달력 뷰 + 모바일**: 자동 목록 뷰 전환

## 비즈니스 규칙

1. 시작일 도래 시 자동으로 특가가 활성되며, 종료일 후 자동으로 정상가로 복구된다 (Cron: 매시 정각).
2. 동일 상품에 중복 시즌 특가는 충돌 경고를 표시하며 기본 정책은 마지막 등록이 우선된다. 정책 토글로 큰 할인 우선 또는 명시 우선순위 가능.
3. 진행 중 시즌 특가는 일부 항목만 수정 가능하다 (대상 상품 추가는 가능, 기간·금액 변경은 차단).
4. 진행 중 시즌 삭제 시 즉시 종료 처리되며 정상가로 복구된다. 이미 결제 완료된 회원에게는 영향 없음(가격 락인).
5. 시즌 특가는 일반 할인(PRD-04)과 별도로 적용되며 중복 적용 정책은 설정에 따른다.
6. 변경 이력은 감사 로그(SCR-097)에 기록된다.
7. **자동 활성 / 비활성**: 매시 정각 Cron 배치. 시작일 도래 → 활성, 종료일 23:59 → 비활성. 자동 활성 토글 OFF 시 수동 활성 가능.
8. **D-day 카운트**: 예정 = "시작 D-{남은일수}", 진행 중 = "종료 D-{남은일수}", 종료 = "종료 후 {경과일수}일".
9. **카탈로그 / 키오스크 자동 강조**: 진행 중 시즌은 자동 "할인" 배지 + 정상가 취소선 + 특가 표시.
10. **결제 시점 가격 락인**: 결제 트랜잭션 시작 시점의 시즌 가격으로 결제. 결제 중 시즌 종료되어도 영향 없음.
11. **중복 정책 우선순위**:
    - **시즌 가격 → 일반 할인 → 쿠폰 → 마일리지** 순차 적용
    - 시즌 + 할인 중복 정책 토글: 중복 허용 / 단독 / 큰 것만
12. **시즌명 정책**: 1~30자, 동일 지점 내 중복 허용 (의미 있음).
13. **대상 상품 정책**: 다중 선택 또는 카테고리(MEMBERSHIP/PT/GX/PRODUCT/SERVICE) 일괄. 비활성 상품 자동 제외.
14. **자동 활성 OFF 정책**: OFF 시에도 자동 비활성은 작동 (종료일 도달 시).
15. **본사·지점 정책**: 본사 슈퍼관리자 정의 시즌은 전 지점 공통, 센터장 정의는 소속 지점만.
16. **권한별 액션**:
    - 슈퍼관리자/센터장/상품 편집 권한: 등록·수정·삭제
    - 매니저: 등록·수정 (삭제 제외)
    - 일반 직원: 조회만
17. **자동 종료 시 회원앱 / 키오스크 동기화**: 종료 직후 5분 이내 캐시 무효화 + 정상가 복구.
18. **진행 중 시즌 즉시 종료**: 진행 중 삭제 또는 종료일 오늘로 변경 시 즉시 종료.
19. **달력 뷰 충돌 표시**: 동일 상품 또는 카테고리에 2개 이상 시즌 겹치면 빨강 강조.
20. **변경 이력 추적**: 등록·수정·삭제·즉시 종료 모두 SCR-097에 기록 + DLG-P016 내부 변경 이력 표시.
21. **시즌 매출 통계**: SCR-S004 매출통계에서 시즌별 매출·할인액·전환율 분석 제공.
22. **재등록 우대 시즌**: 만료 30일 이내 회원 자동 적용 조건 (PRD-04와 결합).
23. **카운트다운 표시**: 종료 24시간 이내 시즌은 카탈로그·키오스크에 카운트다운 강조.
24. **종료된 시즌 보존**: 종료 후 회색 처리 + 1년 보존, 1년 경과 시 SCR-097 감사 로그에서 조회.
25. **회원앱 알림**: 진행 중 시즌 시작·종료 시 회원앱 푸시 알림 (NFR-19) 옵션.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `PRD-08`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-P008`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-P016 시즌가격등록수정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
