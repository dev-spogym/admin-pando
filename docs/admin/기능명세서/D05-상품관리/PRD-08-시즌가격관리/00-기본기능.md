## 기능 목적

여름 특가, 신년 이벤트 등 특정 기간에만 적용되는 시즌 특별 가격을 설정하고 관리하는 화면이다. 기간, 대상 상품, 특가 금액을 지정하여 정해진 기간 동안 자동으로 할인 가격이 적용되도록 한다. 종료일 이후에는 자동으로 정상가로 복구된다.

## 주요 구성요소

### 시즌 특가 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 시즌명 | 예: "2026 여름 특가" |
| 적용 기간 | 시작일 ~ 종료일 |
| 대상 상품 | 적용 상품 N개 |
| 특가 금액/할인율 | 정액 또는 정률 |
| 상태 | 예정 / 진행 중 / 종료 |
| 액션 | [수정] / [삭제] |

### 상태별 구분

| 상태 | 조건 | 색상 |
|------|------|------|
| 예정 | 시작일 이전 | 파랑 |
| 진행 중 | 시작일~종료일 | 초록 |
| 종료 | 종료일 이후 | 회색 |

### 달력 뷰 (선택)

월별 달력에서 시즌 특가 기간 시각화. 달력 / 목록 뷰 전환.

### 시즌 특가 등록·수정 (DLG-P016)

| 입력 | 설명 |
|------|------|
| 시즌명 | 텍스트 (필수) |
| 시작일 ~ 종료일 | 날짜 범위 |
| 대상 상품 | 다중 선택 |
| 특가 유형 | 정액 / 정률 |
| 특가 값 | 금액 또는 % |
| 비고 | textarea |

### 진행 중 강조

현재 적용 중인 특가는 목록 상단 고정 또는 강조 표시.

## 주요 UX 흐름

**시즌 특가 등록**
1. 사이드바 → "상품관리 > 시즌 가격 관리" 진입
2. [시즌 특가 등록] → DLG-P016
3. 시즌명·기간·대상 상품·특가 입력
4. 저장 → 목록 추가 (예정 상태)
5. 시작일 도래 → 자동 활성

**시즌 특가 수정**
1. 행 [수정] → DLG-P016 채워진 폼
2. 정보 변경 → 저장

**시즌 특가 삭제**
1. 행 [삭제] → 확인
2. 진행 중이면 안내 → 종료 처리

**진행 중 확인**
1. 상단 강조된 진행 중 시즌 확인
2. 적용 중인 상품 목록 검토

## 비즈니스 규칙

1. 시작일 도래 시 자동으로 특가가 활성되며, 종료일 후 자동으로 정상가로 복구된다.
2. 동일 상품에 중복 시즌 특가는 충돌 경고를 표시하며 마지막 등록이 우선된다.
3. 진행 중 시즌 특가는 일부 항목만 수정 가능하다 (대상 상품 추가는 가능, 기간·금액 변경은 제한).
4. 진행 중 시즌 삭제 시 즉시 종료 처리되며 정상가로 복구된다.
5. 시즌 특가는 일반 할인(PRD-04)과 별도로 적용되며 중복 적용 정책은 설정에 따른다.
6. 변경 이력은 감사 로그(SCR-097)에 기록된다.
