## 기능 목적

새로운 상품을 등록하거나 기존 상품을 수정하는 모달형 패널이다. SCR-P001 상품 목록에서는 우측 패널로 열리고, `/products/new` 또는 `/products/edit` 직접 경로에서는 동일한 등록 모달 레이아웃을 단독 화면으로 확인한다. 상품 구분(레슨/이용/락커/판매)에 따라 필요한 항목이 동적으로 표시되며, 저장 시 Supabase `products` 테이블에 즉시 반영된다.

## 주요 구성요소

### 상품 구분 선택

| 구분 | 설명 | 저장 유형 | 추가 항목 |
|------|------|-----------|-----------|
| 레슨 | PT, GX 등 수업형 | category=PT/GX, productType=LESSON | 레슨 시간/유효기간/횟수/수업구분 |
| 이용 | 기간제·횟수제 회원권 | category=MEMBERSHIP | 이용구분(기간/횟수/포인트) |
| 락커 | 락커 이용권 | category=PRODUCT, productType=RENTAL | 기간 입력 |
| 판매 | 실물 상품 | category=PRODUCT, productType=GENERAL | 태그 입력 |

### 기본 정보 입력

| 항목 | 필수 | 설명 |
|------|------|------|
| 상품 대분류 | 필수 | MEMBERSHIP/PT/GX/PRODUCT/SERVICE |
| 상품그룹 | 선택 | 분류 관리 탭 그룹 |
| 종목·세부종목 | 조건부 | GX 시 6종 필수 |
| 상품명 | 필수 | 동일 지점·대분류 중복 불가 |
| 현금가 | 필수 | 0 초과 |
| 카드가 | 선택 | 미입력 시 현금가 |
| 기간 | 조건부 | 기간제·락커 필수 |
| 횟수/포인트 | 조건부 | 레슨·횟수제 필수 |
| 설명 | 선택 | 부가 설명 |
| 태그 | 선택 | 검색·분류 |

### 2단계 분류 선택 규칙

| 1단계 대분류 | 2단계 종목 |
|------|------|
| MEMBERSHIP | 헬스/골프/수영/복싱/크로스핏/기타 |
| PT | PT/재활PT/그룹PT/기타 |
| GX | 요가/필라테스/스피닝/줌바/에어로빅/GX기타 |
| PRODUCT | 운동복/락커/식음료/용품/기타 |
| SERVICE | 부가서비스/대여/기타 |

### 이용 요일·시간

요일별(월~일) 체크 + 시작/종료 시간 (10분 단위).

### 옵션 설정

예약 가능 / 시설 이용 / 홀딩 / 양도 / 포인트 / 회원 직접 휴회 / 키오스크 노출 / 활성 상태.

### 상세 옵션 (조건부)

시설 이용 시간 / 예약 오픈일 / 예약 시간 간격 / 휴회 횟수·기간 / 판매 유형 / 일일 횟수 제한.

### 패키지 구성 (선택)

"패키지 상품으로 등록" 체크 시 활성 → 구성 상품 추가 + 합산 정가 + 패키지 할인가.

### 상단 액션

- 상품정보 가져오기 (DLG-P005)
- 닫기 (DLG-P002 변경 시 확인)
- 등록/저장
- 삭제 (수정 모드만, DLG-P003 또는 DLG-P004)

## 주요 UX 흐름

**등록**
1. SCR-P001 → [+ 상품 등록] → 빈 폼 패널
2. 정보 입력
3. [등록] → 저장 → 목록 갱신

**수정**
1. SCR-P001 → 행 클릭 → 정보 채워진 폼
2. 변경 → [저장]

**가져오기**
1. [상품정보 가져오기] → DLG-P005
2. 선택 → 자동 채움 → 새 상품 등록

**삭제**
1. 수정 모드 → [삭제]
2. 판매 이력 있음 → DLG-P004 비활성 안내
3. 이력 없음 → DLG-P003 삭제 확인

**작업 취소**
1. [닫기] / 외부 클릭
2. 변경 사항 있음 → DLG-P002 확인

## 비즈니스 규칙

1. 상품명은 동일 지점 + 동일 대분류에서 중복 불가하다.
2. `category=GX` 상품 저장 시 2단계 세부종목 미입력은 저장 차단된다.
3. 카드가 미입력 시 현금가와 동일하게 저장된다.
4. 판매 이력 있는 상품은 삭제 대신 "미사용" 비활성으로 전환된다.
5. 상품그룹은 자동 추론하지 않고 사용자 명시 선택을 그대로 저장한다.
6. 패키지 상품은 구성 상품 가격 합과 별도로 패키지 할인가를 가진다.
7. 작업 취소 시 변경 사항이 있으면 확인 다이얼로그를 통해 손실 방지한다.
8. 가격 변경 시 `price_history`에 자동 기록된다.
