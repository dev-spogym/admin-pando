## 기능 목적

상품 목록(SCR-P001)에서 상품을 클릭하면 화면 우측에서 슬라이드로 나타나는 상세 정보 패널이다. 상품의 모든 설정값을 한눈에 확인하고, 수정 모드로 전환하거나 가격 변경 이력을 조회할 수 있다. 누적 판매 건수와 패키지 구성도 함께 확인 가능하다.

## 주요 구성요소

### 헤더 영역

상품명 + 활성/비활성 배지 + 닫기(X).

### 상품 기본 정보

| 항목 | 내용 |
|------|------|
| 상품 구분 | 레슨/이용/락커/판매 |
| 상품 대분류 | MEMBERSHIP/PT/GX/PRODUCT/SERVICE |
| 종목·세부종목 | 2단계 분류, GX는 6종 필수 |
| 상품명 | 등록명 |
| 현금가/카드가 | 천 단위 콤마 |
| 이용 기간 | 기간제 일수 |
| 이용 횟수 | 횟수제 |
| 수업 구분 | 개인/정규클래스 (레슨) |
| 레슨 시간 | 1회 시간 (레슨) |
| 이용 구분 | 기간/횟수/포인트 |
| 태그 / 설명 | 부가 정보 |

### 분류 표시 규칙

1단계 대분류 + 2단계 종목·세부종목 함께 표시. GX는 세부종목 배지 필수 표시.

### 이용 요일·시간

요일별 체크/엑스 + 이용 시간대.

### 옵션 현황

| 옵션 | 활성 |
|------|------|
| 예약 가능 | O/X |
| 시설 이용 | O/X |
| 홀딩 가능 | O/X |
| 양도 가능 | O/X |
| 포인트 적립 | O/X |
| 회원 직접 휴회 | O/X |
| 키오스크 노출 | O/X |
| 판매 유형 | 전체/카운터/키오스크/온라인 |

### 패키지 구성 (패키지 상품만)

구성 상품 목록 + 개별 가격 + 합산 정가 + 패키지 할인가.

### 가격 변경 이력

시간순 표시: 변경 전 → 변경 후, 변경 일시, 변경자. [전체 보기] → DLG-P008.

### 판매 현황

해당 상품 누적 판매 건수.

### 액션 영역

- 수정 (편집 권한)
- 삭제 (권한 + 판매 이력 확인)

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 정보 | 수정·삭제 |
| owner (센터장) | 전체 정보 | 수정·삭제 |
| manager | 전체 정보 | 수정 |
| 상품 편집 권한 | 전체 정보 | 수정·삭제 |
| 일반 직원 | 상품 정보 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**상세 조회**
1. SCR-P001 행 클릭 → 우측 패널 슬라이드
2. 정보·옵션·이력·판매 확인
3. X 클릭 → 패널 닫기

**가격 이력 조회**
1. "가격 변경 이력" 섹션 펼치기
2. [전체 보기] → DLG-P008 가격이력조회

**삭제**
1. [삭제] 클릭 → 판매 이력 확인
2. 이력 없음 → DLG-P003 삭제 확인 → 삭제
3. 이력 있음 → DLG-P004 비활성 → 미사용 전환

## 화면 상태

| 비활성화 확인 | 이용 중 회원 수 + 전환 |

## 비즈니스 규칙

1. 상품 상세는 1단계 대분류 + 2단계 종목·세부종목을 함께 표시한다.
2. `category=GX` 상품은 세부종목 배지를 필수로 표시한다.
3. GX 세부종목 값은 매출통계 GX종목별 탭과 KPI 대시보드 GX 세부 종목 분포에서 동일 사용된다.
4. 가격 변경 이력은 변경 시점·전·후·변경자를 모두 기록한다.
5. 판매 이력 있는 상품은 삭제 대신 미사용 비활성으로 전환된다.
6. 패키지 구성은 패키지 상품에만 표시된다.
