## 기능 목적

상품 판매 시 적용할 할인 정책을 등록·수정·삭제하는 화면이다. 정률(%) 또는 정액(원) 방식의 할인을 설정하고, 최소 계약 기간 조건이나 최대 할인 한도, 적용 상품, 자동 적용 조건(회원 등급/세그먼트), 적용 기간을 지정한다. 결제 화면(SCR-S003)에서 자동/수동 적용되며, 시즌 가격(PRD-08)·쿠폰·마일리지와의 중복 정책은 우선순위 규칙으로 처리된다. 변경 이력 타임라인을 통해 최근 수정 내역을 한 화면에서 확인한다.

운영 맥락:
- **장기 계약 인센티브**: 12개월 이상 헬스 계약 시 10% 정률 할인 자동 적용 → 계약 갱신율 증대
- **VIP 등급 회원 정률 할인**: VIP/Gold/Silver 등급별 5/10/15% 자동 적용
- **신규 가입 첫 구매 정액 할인**: 첫 구매 회원 5만원 정액 할인 (1회성)
- **재등록 할인**: 만료일 이전 재구매 시 정률 할인
- **세그먼트 기반 마케팅**: "최근 90일 미방문 회원" 세그먼트 대상 정률 할인 메시지
- **단체 할인**: 회사 / 학교 단체 가입 시 정률 할인
- **할인 한도 정책**: 정률 50% 할인 + 한도 10만원 → 고가 상품에서 할인 폭 제한
- **할인 종료 / 비활성**: 캠페인 종료 시 비활성 토글 → 결제 화면 즉시 적용 제외
- **할인 변경 이력 추적**: 누가 / 언제 / 무엇을 변경했는지 타임라인 + 감사 로그(SCR-097)

할인 우선순위(중복 적용 정책):
1. **시즌 가격(PRD-08)** → 정상가 → 시즌 특가
2. **할인(PRD-04)** → 시즌 특가 또는 정상가에 할인 적용
3. **쿠폰** → 할인 후 가격에 쿠폰 적용
4. **마일리지** → 최종 결제 금액에서 마일리지 차감
5. **회원 등급 자동 할인** → 정률/정액 자동 매칭

테넌트 정책에 따라 1)+2) 중복 허용 또는 1) 또는 2) 중 큰 할인만 적용 토글 가능.

## 주요 구성요소

### 할인 정책 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 할인명 | 정책 이름 |
| 유형 | 정률(%) / 정액(원) |
| 할인 값 | 비율 또는 금액 |
| 조건 | 최소 계약 기간 (없으면 "-") |
| 한도 | 최대 할인금액 (없으면 "-") |
| 상태 | 활성 / 비활성 |
| 적용 기간 | 시작일 ~ 종료일 |
| 적용 상품 | N개 또는 전체 |
| 자동 적용 | 등급 / 세그먼트 / 수동 |
| 액션 | [수정] / [삭제] |

### 할인 추가 / 수정 (DLG-P004 / DLG-P005)

| 입력 | 설명 |
|------|------|
| 할인명 | 텍스트 (필수, 1~30자) |
| 유형 | 정률 / 정액 |
| 값 | % (1~100) 또는 원 (0 초과) |
| 조건 (최소 계약) | 일 단위 (선택) |
| 한도 (최대 할인) | 원 (정률만, 선택) |
| 적용 상품 | 다중 선택 또는 전체 |
| 자동 적용 조건 | 회원 등급 / 세그먼트 (선택, 다중) |
| 활성 토글 | ON/OFF |
| 적용 기간 | 시작일 ~ 종료일 |
| 중복 적용 정책 | 시즌 가격 중복 / 단독 / 우선 |
| 적용 횟수 제한 | 1회성 / 무제한 |
| 비고 | textarea (선택) |

### 할인 삭제 (DLG-P006)

삭제 확인 다이얼로그 + 사용 중 상품 / 적용 중 회원 안내.

### 변경 이력 타임라인

최근 등록·수정·삭제 이력 시간순 표시. 이력 0건이면 섹션 숨김.

| 항목 | 표시 |
|------|------|
| 날짜·시간 | YYYY-MM-DD HH:mm |
| 작업 구분 | 등록 / 수정 / 삭제 |
| 할인명 | 대상 |
| 요약 | 변경 내용 (예: 값 10% → 15%) |
| 작업자 | 이름 |

## 주요 UX 흐름

**할인 추가**
1. 사이드바 → "상품관리 > 할인 설정" 진입
2. [할인 추가] → DLG-P004
3. 이름·유형·값·조건·한도 입력
4. 적용 상품·자동 조건·기간·중복 정책 설정
5. 저장 → 목록 추가 + 이력 추가

**할인 수정**
1. 행 [수정] → DLG-P005
2. 정보 변경 → 저장
3. 이력 추가

**할인 삭제**
1. 행 [삭제] → DLG-P006
2. 사용 중 상품 / 적용 중 회원 안내
3. 확인 → 삭제 + 이력

### 분기·예외 흐름

- **정률 값 0 또는 100 초과**: 인라인 "1~100% 사이로 입력해주세요" + 저장 차단
- **정액 값 0 이하**: "0보다 큰 금액을 입력해주세요" + 저장 차단
- **정률 한도 입력 + 정액 선택**: "정액 할인은 한도 입력 불가" + 한도 필드 비활성
- **적용 기간 시작일 > 종료일**: "종료일은 시작일 이후여야 해요" + 저장 차단
- **적용 상품 0개 + 자동 적용 OFF**: "적용 상품 또는 자동 적용 조건 중 하나는 필수" + 저장 차단
- **자동 적용 조건 다중 선택(VIP + 세그먼트)**: AND/OR 토글로 조합 정책 명시
- **할인 한도 < 정률 적용 금액**: 한도까지만 차감 (기능 정상 작동)
- **삭제 시 적용 중 회원 있음**: "현재 적용 중인 회원 N명이 있습니다, 비활성으로 전환하시겠어요?" 분기
- **시즌 가격(PRD-08) 중복**: 중복 정책 토글에 따라 처리
  - 중복 허용: 시즌 특가 → 할인 순차 적용
  - 단독: 할인이 우선이면 시즌 특가 무시
  - 큰 것만: 할인율 큰 쪽만 적용
- **쿠폰·마일리지 결합**: 할인 후 가격에 쿠폰, 쿠폰 후 가격에 마일리지 차감 순
- **자동 적용 + 수동 적용 동시 선택**: 자동만 적용 (이중 적용 차단)
- **적용 기간 외 결제 시도**: 결제 화면에서 자동 비활성, 목록에서는 회색 처리
- **할인 후 가격 < 0**: "할인 후 가격이 0 이하가 됩니다, 한도 또는 값 조정 필요" 안내
- **할인명 중복(동일 지점)**: "이미 등록된 할인명입니다" + 저장 차단
- **권한 없음 + 직접 URL 진입**: 읽기 전용 모드
- **이력 50건 초과**: 페이지네이션 또는 [더보기] 버튼
- **동시 수정 충돌**: "다른 사용자가 먼저 저장했어요" 낙관적 락

## 비즈니스 규칙

1. 정률 할인은 1~100% 범위, 정액 할인은 0 초과 금액으로 검증한다.
2. 최대 할인금액(한도)은 정률 할인에만 적용 가능하며, 한도 이상 할인되지 않는다.
3. 최소 계약 기간 조건이 있으면 해당 기간 미만 상품에는 적용되지 않는다.
4. 자동 적용 조건(등급/세그먼트)이 설정되면 해당 회원에게 결제 화면에서 자동 적용된다.
5. 비활성 할인은 적용 대상에서 제외된다.
6. 등록·수정·삭제 시 변경 이력이 자동 기록되고 SCR-097 감사 로그에도 INSERT된다.
7. 적용 기간 외에는 자동으로 비활성된다.
8. **할인명 정책**: 1~30자, 동일 지점 내 중복 불가. 한글·영문·숫자·일부 특수문자 허용.
9. **적용 상품 정책**: 다중 선택 또는 "전체 상품" 토글. "전체 상품"은 카테고리 필터(MEMBERSHIP / PT / GX / PRODUCT / SERVICE)로 좁히기 가능.
10. **자동 적용 조건**: 회원 등급(VIP/Gold/Silver/일반), 세그먼트(MBR-EXT-04 연계, 다중 가능). AND/OR 조합 명시.
11. **중복 적용 정책**: 시즌 가격(PRD-08)과의 관계
    - **중복 허용**: 시즌 특가 → 할인 순차 적용 (테넌트 기본값)
    - **단독**: 할인이 우선이면 시즌 특가 무시
    - **큰 것만**: 할인율 큰 쪽만 적용
12. **쿠폰·마일리지 결합 우선순위**: 시즌가격 → 할인 → 쿠폰 → 마일리지. 각 단계 후 가격이 다음 단계 입력값.
13. **적용 횟수 제한**: 1회성(회원당 1회) / 무제한. 1회성은 회원 ID + 할인 ID로 중복 차단.
14. **자동 + 수동 동시 적용 차단**: 자동 적용 회원에게 수동 적용 시도 시 자동만 적용.
15. **할인 후 가격 0 이하**: 결제 시 0원으로 처리하지 않고 0원 결제 차단(0 미만 허용 토글은 정책에 따름).
16. **권한별 액션**:
    - 슈퍼관리자/센터장/관리자 권한: 등록·수정·삭제
    - 매니저: 등록·수정 (삭제 제외)
    - 일반 직원: 조회만
17. **비활성 vs 삭제**: 적용 중 회원 있는 할인은 삭제 대신 비활성 권장. 강제 삭제 시 적용 중 결제는 영향 없음(이미 적용된 가격 유지).
18. **변경 이력 50건 초과**: 페이지네이션 또는 [더보기]. 1년 경과 이력은 SCR-097에서 조회.
19. **동시 수정 충돌**: 낙관적 락 (`updated_at` 비교).
20. **본사 vs 지점 할인**: 본사 슈퍼관리자가 정의한 할인은 전 지점 공통, 센터장 정의는 소속 지점만 적용.
21. **할인 미리보기**: DLG에서 적용 상품 1개 선택 후 미리보기 → "100,000원 → 90,000원" 시뮬레이션.
22. **세그먼트 자동 갱신**: 자동 적용 조건이 세그먼트인 경우 매일 04:00 세그먼트 멤버 갱신 → 결제 시점 최신 정보 사용.
23. **감사 로그**: 등록·수정·삭제·활성/비활성 토글 모두 SCR-097에 기록. `actor_id, discount_id, action, before, after`.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 정률 값 0 또는 >100 | 인라인 "1~100% 사이" | 저장 차단 |
| 정액 값 ≤0 | "0보다 큰 금액" | 저장 차단 |
| 정액 + 한도 입력 | 한도 필드 비활성 | 정률만 한도 |
| 시작일 > 종료일 | "종료일은 시작일 이후" | 저장 차단 |
| 적용 상품 0 + 자동 OFF | "둘 중 하나 필수" | 저장 차단 |
| 할인명 중복 | "이미 등록된 할인명" | 저장 차단 |
| 삭제 + 적용 중 회원 | "회원 N명, 비활성 권장" | 비활성 / 강제 삭제 |
| 시즌 가격 중복 정책 미설정 | 기본값 "중복 허용" | 정책 명시 권장 |
| 할인 후 가격 ≤0 | "할인 후 0 이하" | 한도/값 조정 |
| 적용 기간 외 결제 | 결제 화면 자동 제외 | 회색 처리 |
| 자동 + 수동 동시 시도 | 자동만 적용 | 이중 차단 |
| 권한 없음 + 직접 URL | 읽기 전용 | - |
| 이력 50건 초과 | 페이지네이션 | - |
| 동시 수정 충돌 | "다른 사용자 먼저 저장" | [최신 보기] / [덮어쓰기] |
| 1회성 적용 회원 재시도 | "이미 사용한 할인" | 차단 |
| 본사 정의 할인 + 지점 수정 시도 | "본사 정의 할인은 수정 불가" | 차단 |
| 세그먼트 0명 | 노랑 경고 "적용 대상 없음" | 진행 가능 |
| 할인 미리보기 상품 선택 0 | 미리보기 비활성 | 상품 선택 안내 |
| 카테고리 필터 + 적용 상품 충돌 | 명시 적용 상품 우선 | 안내 토스트 |
