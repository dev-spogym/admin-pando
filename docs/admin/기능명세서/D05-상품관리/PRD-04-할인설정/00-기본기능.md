## 기능 목적

상품 판매 시 적용할 할인 정책을 등록·수정·삭제하는 화면이다. 정률(%) 또는 정액(원) 방식의 할인을 설정하고, 최소 계약 기간 조건이나 최대 할인 한도를 지정할 수 있다. 변경 이력 타임라인을 통해 최근 수정 내역도 한 화면에서 확인한다.

## 주요 구성요소

### 할인 정책 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 할인명 | 정책 이름 |
| 유형 | 정률(%) / 정액(원) |
| 할인 값 | 비율 또는 금액 |
| 조건 | 최소 계약 기간 (없으면 "-") |
| 한도 | 최대 할인금액 (없으면 "-") |
| 상태 | 활성 / 비활성 |
| 액션 | [수정] / [삭제] |

### 할인 추가 / 수정 (DLG-P004 / DLG-P005)

| 입력 | 설명 |
|------|------|
| 할인명 | 텍스트 (필수) |
| 유형 | 정률 / 정액 |
| 값 | % (1~100) 또는 원 |
| 조건 (최소 계약) | 일 단위 (선택) |
| 한도 (최대 할인) | 원 (정률만, 선택) |
| 적용 상품 | 다중 선택 또는 전체 |
| 자동 적용 조건 | 등급/세그먼트 (선택) |
| 활성 토글 | ON/OFF |
| 적용 기간 | 시작일 ~ 종료일 |

### 할인 삭제 (DLG-P006)

삭제 확인 다이얼로그 + 사용 중 상품 안내.

### 변경 이력 타임라인

최근 등록·수정·삭제 이력 시간순 표시. 이력 0건이면 섹션 숨김.

| 항목 | 표시 |
|------|------|
| 날짜·시간 | YYYY-MM-DD HH:mm |
| 작업 구분 | 등록 / 수정 / 삭제 |
| 할인명 | 대상 |
| 요약 | 변경 내용 |

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 화면 | 등록·수정·삭제 |
| owner (센터장) | 전체 화면 | 등록·수정·삭제 |
| manager | 전체 화면 | 등록·수정 |
| 관리자 권한 | 전체 화면 | 등록·수정·삭제 |
| 일반 직원 | 할인 목록·이력 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**할인 추가**
1. 사이드바 → "상품관리 > 할인 설정" 진입
2. [할인 추가] → DLG-P004
3. 이름·유형·값·조건·한도 입력
4. 적용 상품·자동 조건·기간 설정
5. 저장 → 목록 추가 + 이력 추가

**할인 수정**
1. 행 [수정] → DLG-P005
2. 정보 변경 → 저장
3. 이력 추가

**할인 삭제**
1. 행 [삭제] → DLG-P006
2. 사용 중 상품 안내
3. 확인 → 삭제 + 이력

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 테이블 스켈레톤 |
| 빈 상태 | "등록된 할인 정책이 없어요" |
| 정상 | 테이블 표시 |
| 이력 있음 | 하단 타임라인 |
| 이력 없음 | 타임라인 섹션 숨김 |

## 비즈니스 규칙

1. 정률 할인은 1~100% 범위, 정액 할인은 0 초과 금액으로 검증한다.
2. 최대 할인금액(한도)은 정률 할인에만 적용 가능하며, 한도 이상 할인되지 않는다.
3. 최소 계약 기간 조건이 있으면 해당 기간 미만 상품에는 적용되지 않는다.
4. 자동 적용 조건(등급/세그먼트)이 설정되면 해당 회원에게 자동 적용된다.
5. 비활성 할인은 적용 대상에서 제외된다.
6. 등록·수정·삭제 시 변경 이력이 자동 기록된다.
7. 적용 기간 외에는 자동으로 비활성된다.
