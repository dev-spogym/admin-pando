## 기능 목적

새로운 상품을 등록하거나 기존 상품을 수정하는 모달형 패널이다. SCR-P001 상품 목록에서는 우측 슬라이드 패널로 열리고, `/products/new` 또는 `/products/edit` 직접 경로에서는 동일한 등록 모달 레이아웃을 단독 화면으로 제공한다. 상품 구분(레슨/이용/락커/판매)에 따라 필요한 항목이 동적으로 표시되며, 저장 시 Supabase `products` 테이블에 즉시 반영되고, 가격 변경 시 `price_history`에 자동 기록되며, 비활성·삭제 시 보유 회원 영향 분석 후 분기 처리된다.

운영 맥락:
- **신규 회원권 출시**: 헬스 1개월·3개월·6개월·12개월 라인업 등록 → 카드가/현금가/VAT 정책 일괄 입력 → 카탈로그·키오스크 노출
- **PT 패키지 신규 등록**: 레슨 시간(50분/60분), 횟수(10/20/30/50회), 유효기간(30/60/90/180일), 수업구분(개인/그룹/재활) 입력 → 결합 상품 가능
- **GX 정규 클래스 등록**: 요가·필라테스·스피닝 등 6종 세부종목 + 요일·시간 + 정원 + 강사 매핑(SCR-G003 GX 강사관리 연계)
- **락커 이용권 등록**: 기간형 락커(30/60/180/365일) + 락커 위치(SCR-L001 락커 관리 연계)
- **실물 상품 등록**: 운동복·보충제·용품 + 재고 관리(PRD-07) 연동 + 매입 단가
- **상품 가져오기 (DLG-P005-상품가져오기)**: 기존 유사 상품 정보 자동 채움 → 일부만 변경 후 새 상품으로 저장(라인업 빠른 확장)
- **가격 인상 / 인하**: 수정 모드에서 가격만 변경 → `price_history` 자동 기록 → 결제 화면 즉시 반영
- **단종 처리**: 판매 이력 있는 상품을 삭제 시도 → DLG-P004-비활성화안내 비활성화 안내 → "이용 중 N명, 미사용 전환?" 확인
- **이미지 업로드 (DLG-P007-상품이미지업로드)**: 카탈로그·회원앱 노출용 대표 이미지 첨부, 다중 이미지 갤러리

## 주요 구성요소

### 상품 구분 선택

| 구분 | 설명 | 저장 유형 | 추가 항목 |
|------|------|-----------|-----------|
| 레슨 | PT, GX 등 수업형 | category=PT/GX, productType=LESSON | 레슨 시간/유효기간/횟수/수업구분 |
| 이용 | 기간제·횟수제 회원권 | category=MEMBERSHIP | 이용구분(기간/횟수/포인트) |
| 락커 | 락커 이용권 | category=PRODUCT, productType=RENTAL | 기간 입력 |
| 판매 | 실물 상품 | category=PRODUCT, productType=GENERAL | 태그 입력 |

### 기본 정보 입력

| 항목 | 필수 | 설명 |
|------|------|------|
| 상품 대분류 | 필수 | MEMBERSHIP/PT/GX/PRODUCT/SERVICE |
| 상품그룹 | 선택 | 분류 관리 탭 그룹 |
| 종목·세부종목 | 조건부 | GX 시 6종 필수 |
| 상품명 | 필수 | 동일 지점·대분류 중복 불가 |
| 현금가 | 필수 | 0 초과 |
| 카드가 | 선택 | 미입력 시 현금가 |
| 기간 | 조건부 | 기간제·락커 필수 |
| 횟수/포인트 | 조건부 | 레슨·횟수제 필수 |
| 설명 | 선택 | 부가 설명 |
| 태그 | 선택 | 검색·분류 |

### 2단계 분류 선택 규칙

| 1단계 대분류 | 2단계 종목 |
|------|------|
| MEMBERSHIP | 헬스/골프/수영/복싱/크로스핏/기타 |
| PT | PT/재활PT/그룹PT/기타 |
| GX | 요가/필라테스/스피닝/줌바/에어로빅/GX기타 |
| PRODUCT | 운동복/락커/식음료/용품/기타 |
| SERVICE | 부가서비스/대여/기타 |

### 이용 요일·시간

요일별(월~일) 체크 + 시작/종료 시간 (10분 단위).

### 옵션 설정

예약 가능 / 시설 이용 / 홀딩 / 양도 / 포인트 / 회원 직접 휴회 / 키오스크 노출 / 활성 상태.

### 상세 옵션 (조건부)

시설 이용 시간 / 예약 오픈일 / 예약 시간 간격 / 휴회 횟수·기간 / 판매 유형 / 일일 횟수 제한.

### 패키지 구성 (선택)

"패키지 상품으로 등록" 체크 시 활성 → 구성 상품 추가 + 합산 정가 + 패키지 할인가.

### 상단 액션

- 상품정보 가져오기 (DLG-P005-상품가져오기)
- 닫기 (DLG-P002-작업취소확인 변경 시 확인)
- 등록/저장
- 삭제 (수정 모드만, DLG-P003-상품삭제확인 또는 DLG-P004-비활성화안내)

## 주요 UX 흐름

**등록**
1. SCR-P001 → [+ 상품 등록] → 빈 폼 패널
2. 정보 입력
3. [등록] → 저장 → 목록 갱신

**수정**
1. SCR-P001 → 행 클릭 → 정보 채워진 폼
2. 변경 → [저장]

**가져오기**
1. [상품정보 가져오기] → DLG-P005-상품가져오기
2. 선택 → 자동 채움 → 새 상품 등록

**삭제**
1. 수정 모드 → [삭제]
2. 판매 이력 있음 → DLG-P004-비활성화안내 비활성 안내
3. 이력 없음 → DLG-P003-상품삭제확인 삭제 확인

**작업 취소**
1. [닫기] / 외부 클릭
2. 변경 사항 있음 → DLG-P002-작업취소확인 확인

**이미지 업로드**
1. DLG-P007-상품이미지업로드 → 다중 이미지 업로드
2. 대표 이미지 지정 → 카탈로그·회원앱 동기화

### 분기·예외 흐름

- **상품명 중복(동일 지점+대분류)**: 인라인 "이미 등록된 상품명입니다" + 저장 차단, 자동 제안(원본명 + " (2)") 안내
- **GX 대분류 + 세부종목 미선택**: 빨강 인라인 "GX 세부종목을 선택해 주세요" + 저장 버튼 비활성, 6종 드롭다운 강조
- **카드가 > 현금가 입력**: 빨강 인라인 "카드가는 현금가 이상일 수 없어요" + 저장 차단
- **카드가 < 현금가**: 노랑 경고 "카드 결제 우대 가격으로 저장됩니다" + 진행 가능
- **기간제 / 횟수제 동시 0**: "기간 또는 횟수 중 하나는 입력해야 해요" + 저장 차단
- **레슨 횟수 0 + 기간 0**: 저장 차단 (레슨은 횟수 또는 정기클래스 매핑 필수)
- **요일 미선택**: "최소 1개 요일을 선택해주세요" 안내 (옵션이지만 실효성 보장)
- **시간 시작 ≥ 종료**: "종료 시간은 시작 시간보다 이후여야 해요" + 저장 차단
- **휴회 활성 + 휴회 횟수·기간 미설정**: "휴회 횟수와 기간을 모두 설정해주세요"
- **패키지 구성 상품 0개**: "패키지에는 최소 1개 구성 상품이 필요해요" + 저장 차단
- **패키지 할인가 > 합산 정가**: 빨강 인라인 "할인가는 합산 정가 이하여야 해요"
- **삭제 시 판매 이력 있음**: DLG-P004-비활성화안내 → "이용 중 N명, 미사용 전환?" → 비활성 또는 취소
- **삭제 시 패키지 구성 상품으로 사용 중**: "패키지 N개에서 사용 중입니다" + 패키지 분리 안내
- **저장 중 동시 수정 충돌**: "다른 사용자가 먼저 저장했어요" + [최신 정보 보기] / [덮어쓰기]
- **이미지 업로드 용량 초과(10MB)**: "10MB 이하 이미지를 올려주세요" + 압축 안내
- **이미지 형식 미지원(jpg/png/webp 외)**: "JPG/PNG/WebP만 가능합니다"
- **본사 통합 모드 + 등록 시도**: "지점을 먼저 선택해주세요" + 지점 선택 강조
- **변경 사항 있음 + 닫기**: DLG-P002-작업취소확인 작업 취소 확인 → [확인] / [취소]
- **수정 권한 없음 + 직접 URL 진입**: 읽기 전용 모드 + 저장 버튼 hidden
- **가져오기 후 일부 옵션 충돌(예: GX 세부종목)**: 빨강 강조 + 사용자 명시 수정 요구
- **VAT 정책 변경(공급가↔소비자가)**: 자동 환산 + 안내 토스트, 환산 후 값 명시 확인 필요

## 비즈니스 규칙

1. 상품명은 동일 지점 + 동일 대분류에서 중복 불가하다. 중복 감지 시 자동 제안(원본명 + " (2)")으로 안내한다.
2. `category=GX` 상품 저장 시 2단계 세부종목 미입력은 저장 차단된다. 세부종목은 시스템 고정 6종(요가/필라/스피닝/줌바/에어로빅/GX기타).
3. 카드가 미입력 시 현금가와 동일하게 저장된다. 카드가 < 현금가는 허용(노랑 경고), 카드가 > 현금가는 저장 차단.
4. 판매 이력 있는 상품은 삭제 대신 "미사용" 비활성으로 전환된다. DLG-P004-비활성화안내로 이용 중 회원 수 안내.
5. 상품그룹은 자동 추론하지 않고 사용자 명시 선택을 그대로 저장한다. 비활성 그룹은 신규 상품 등록 시 선택 차단.
6. 패키지 상품은 구성 상품 가격 합과 별도로 패키지 할인가를 가진다. 할인가 > 합산 정가는 차단.
7. 작업 취소 시 변경 사항이 있으면 DLG-P002-작업취소확인 확인 다이얼로그를 통해 손실 방지한다.
8. 가격 변경 시 `price_history`에 자동 기록된다. `before_cash, after_cash, before_card, after_card, actor_id, changed_at` 저장.
9. **이용 구분(기간/횟수/포인트) 정책**: 기간제는 `duration` 필수, 횟수제는 `sessions` 또는 `totalCount` 필수, 포인트는 `totalCount` 필수. 셋 다 0 또는 빈값은 차단.
10. **레슨 시간 정책**: 레슨은 `lessonDuration`(분 단위) 필수. 10분 단위로 입력 가능, 최소 30분, 최대 180분.
11. **요일·시간 정책**: 요일 0개 선택 = 전 요일 이용 가능으로 해석되지 않고 명시 0개 차단. 시작/종료는 10분 단위, 종료 > 시작 필수.
12. **상품 구분(category) 변경**: 수정 모드에서 대분류 변경은 가능하나 판매 이력이 있으면 차단(분류 정합성 보호). 분류 이동은 운영 정책 변경 절차로 별도 처리.
13. **이미지 업로드 정책**: 10MB 이하, JPG/PNG/WebP 만 허용. 다중 업로드 가능, 첫 번째가 대표 이미지(변경 가능). Supabase Storage `products/{branchId}/{productId}/` 경로.
14. **VAT 정책**: 지점 정책에 따라 공급가/소비자가 표시 모드 토글. 저장은 둘 다 컬럼으로(공급가 = 소비자가 / 1.1).
15. **휴회 정책**: 회원 직접 휴회 활성 시 횟수(1/2/3회) + 기간(3/7/15/30/60일) 모두 설정 필수.
16. **권한별 액션**:
    - 슈퍼관리자/센터장: 등록·수정·삭제·이미지·패키지
    - 매니저: 등록·수정·이미지 (삭제 제외)
    - 일반 직원: 진입 불가
17. **가져오기(DLG-P005-상품가져오기) 후 새 상품 저장**: 자동 채움된 정보를 일부 변경하면 ID는 새로 발급, 가격 이력은 새 상품 기준으로 시작.
18. **패키지 구성 상품 변경**: 구성 상품 추가/제거 시 합산 정가 자동 재계산. 패키지 할인가는 운영자 명시 갱신 필요(자동 비례 조정 안 함).
19. **삭제 권한**: 삭제는 슈퍼관리자/센터장/상품 편집 권한자만. 매니저는 비활성 전환만 가능.
20. **동시 수정 충돌(낙관적 락)**: `updated_at` 비교, 다른 사용자가 먼저 저장했으면 [최신 정보 보기] / [덮어쓰기] 선택.
21. **분리 저장 트랜잭션**: 이미지·패키지·할인 매핑은 상품 저장 후 비동기 처리. 메인 저장만 성공해도 상품 등록 완료, 부가 처리 실패 시 부분 성공 토스트.
22. **변경 감지 정책**: 입력값 1개라도 dirty면 닫기 시 DLG-P002-작업취소확인 발생. dirty 비교는 초기 로드값과 현재값 deep equal.
23. **태그 정책**: 1~10개, 각 태그 1~20자. 콤마·세미콜론으로 구분 입력. 검색·분류용.
24. **감사 로그**: 등록·수정·삭제·비활성·이미지 변경 모두 SCR-097에 기록. `actor_id, product_id, action, before, after`.
