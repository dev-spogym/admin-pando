## 기능 목적

운동복, 보충제, 용품 등 실물 상품의 재고 현황을 관리하는 화면이다. 현재 재고 수량을 확인하고 입고·출고 처리를 기록하며, 재고 실사 후 수동 조정도 할 수 있다. 안전 재고 미달 시 경고 표시로 재주문 시점을 식별할 수 있고, 입출고 이력은 모두 추적 가능하다.

## 주요 구성요소

### 재고 통계 카드 (3개)

| 카드 | 내용 |
|------|------|
| 전체 품목 수 | 관리 중인 실물 상품 종류 |
| 부족 재고 | 안전 재고 미달 품목 수 |
| 품절 | 재고 0인 품목 수 |

### 필터 / 검색

- 상품 카테고리 필터
- 재고 상태 필터 (충분 / 부족 / 품절)
- 상품명 검색

### 재고 현황 테이블

| 컬럼 | 내용 |
|------|------|
| 상품명 | 실물 상품 이름 |
| 카테고리 | 분류 |
| 현재 재고 | 보유 수량 |
| 안전 재고 | 최소 유지 기준 |
| 재고 상태 | 충분 / 부족 / 품절 |
| 최근 입고일 | YYYY-MM-DD |
| 액션 | [입고] / [출고] / [조정] / [이력] |

### 입고 등록 (DLG-P012)

| 입력 | 설명 |
|------|------|
| 입고 수량 | 숫자 |
| 입고일 | YYYY-MM-DD |
| 단가 | 매입 단가 (선택) |
| 거래처 | 텍스트 |
| 비고 | textarea |

### 출고 등록 (DLG-P013)

| 입력 | 설명 |
|------|------|
| 출고 수량 | 숫자 |
| 출고 사유 | 판매 / 폐기 / 이동 |
| 출고일 | YYYY-MM-DD |
| 비고 | textarea |

### 재고 조정 (DLG-P014)

실사 후 실제 수량 입력 → 차이만큼 자동 조정 + 사유 기록.

### 입출고 이력 (DLG-P015)

상품별 시간순 입출고·조정 기록 표시.

### 강조 표시

| 상태 | 색상 |
|------|------|
| 충분 | 기본 |
| 부족 | 노랑/주황 |
| 품절 | 빨강 |

## 주요 UX 흐름

**입고 처리**
1. 사이드바 → "상품관리 > 재고 관리" 진입
2. 상품 행 [입고] → DLG-P012
3. 수량·날짜·단가·거래처 입력
4. 저장 → 재고 갱신 + 이력

**출고 처리**
1. 행 [출고] → DLG-P013
2. 수량·사유 입력
3. 저장 → 재고 차감 + 이력

**재고 조정**
1. 실사 후 행 [조정] → DLG-P014
2. 실제 수량 입력 + 사유
3. 저장 → 차이 자동 보정 + 이력

**이력 조회**
1. 행 [이력] → DLG-P015
2. 시간순 입출고·조정 기록

## 비즈니스 규칙

1. 안전 재고 미달 품목은 자동으로 경고 색상이 표시된다.
2. 재고 0 품목은 자동 품절 표시되며 카운트에 포함된다.
3. 재고 조정 시 사유 입력은 필수이며 감사 로그(SCR-097)에 기록된다.
4. 출고 사유는 판매/폐기/이동으로 구분되어 통계에 반영된다.
5. 입고 시 단가 입력은 선택이지만 입력 시 매입 원가 추적에 활용된다.
6. 모든 입출고·조정은 처리자·시간이 자동 기록된다.
