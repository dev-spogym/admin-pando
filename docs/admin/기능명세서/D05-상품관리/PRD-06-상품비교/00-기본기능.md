## 기능 목적

최대 3개 상품을 나란히 비교하여 회원 상담 시 최적의 상품을 안내할 수 있는 화면이다. 가격(현금가/카드가/시즌 특가/할인 적용가), 이용 기간·횟수, 포함 서비스, 옵션 항목(홀딩/양도/포인트/키오스크), 일일 횟수 제한, 휴회 정책을 동일한 기준으로 표시하여 상품 간 차이를 직관적으로 파악할 수 있다. 항목별로 가장 유리한 값(최저가, 최장 기간, 최다 횟수, 옵션 우위)에는 자동 하이라이트가 표시되어 추천 포인트를 쉽게 식별한다. 회원 등급·세그먼트가 입력되면 자동 적용 할인까지 시뮬레이션 가격으로 제시한다.

운영 맥락:
- **신규 회원 상담 추천**: PT 10/20/30회 비교 → "30회가 회당 가격 가장 저렴" 자동 강조
- **회원권 vs 패키지 비교**: 헬스 6개월 vs PT 결합 패키지 → 합산 정가/할인가 비교
- **GX 정규 클래스 비교**: 요가 vs 필라테스 vs 스피닝 → 시간/요일/정원 비교
- **회원 등급 시뮬레이션**: VIP / Gold / Silver 등급 입력 시 자동 할인 적용된 시뮬레이션 가격 표시
- **시즌 특가 비교**: 시즌 진행 중 상품과 정상가 상품 비교 → 시즌 특가가 더 유리하면 강조
- **상품 교체**: 비교 중 X 클릭 → 다른 상품 선택, 회원 반응 보고 빠르게 교체
- **회원 결제 점프**: 비교 후 회원이 선택한 상품 → 결제(SCR-S003) 즉시 진입
- **공유 링크**: 비교 결과 URL 발급 → 회원에게 카카오톡 / 메일 발송

## 주요 구성요소

### 상품 선택 영역

- 비교할 상품 최대 3개 선택 (드롭다운 또는 검색)
- 선택된 상품은 각 열에 표시
- 상품 제거(X) 버튼으로 비교 대상 제외
- 회원 등급 / 세그먼트 입력(선택) → 자동 할인 시뮬레이션

### 비교 테이블

| 비교 항목 | 설명 |
|-----------|------|
| 상품명 | 이름 + 유형 배지 + 패키지 배지 |
| 대분류 / 종목 | 1단계 + 2단계 분류 |
| 현금가 | 천 단위 콤마 |
| 카드가 | 천 단위 콤마 |
| 시즌 특가 | 진행 중인 경우 표시 |
| 시뮬레이션 할인가 | 등급/세그먼트 입력 시 자동 계산 |
| 회당 가격 | 횟수제 상품 회당 단가 |
| 일당 가격 | 기간제 상품 일당 단가 |
| 이용 기간 | 일 단위 |
| 이용 횟수 | 총 횟수 |
| 이용 요일 | 가능 요일 |
| 이용 시간 | 시간대 |
| 일일 횟수 제한 | 1/2/3/5/10회 |
| 홀딩 가능 | O/X + 횟수·기간 |
| 양도 가능 | O/X |
| 포인트 적립 | O/X |
| 키오스크 노출 | O/X |
| 휴회 가능 | O/X + 횟수·기간 |

### 강조 표시

- 항목별로 가장 유리한 값에 하이라이트 (예: 최저가, 최장 기간, 최다 횟수)
- 옵션 O가 더 유리한 항목(홀딩/양도/포인트)은 O인 열 강조
- 시즌 특가가 정상가보다 유리한 경우 "시즌 특가" 라벨 + 할인율 표시

### 액션

- 상품 교체: 열 X → 다른 상품 선택
- 상품 삭제: 비교 화면에서 특정 상품 → DLG-P006-상품삭제확인
- 결제 점프: [이 상품 결제하기] → SCR-S003 결제 화면, 회원 + 상품 자동 매핑
- 공유: 비교 결과 URL 복사 + 카카오톡/메일

## 주요 UX 흐름

1. 사이드바 → "상품관리 > 상품 비교" 진입
2. 상단에서 비교할 상품 1~3개 선택 (드롭다운 검색)
3. (선택) 회원 등급 / 세그먼트 입력 → 자동 할인 시뮬레이션
4. 항목별 정보 나란히 표시 + 자동 하이라이트
5. 회원 상담 시 추천 포인트 안내
6. 열 X로 상품 교체
7. 회원 선택 → [이 상품 결제하기] → 결제 화면
8. (선택) [공유] → URL / 카톡 / 메일

### 분기·예외 흐름

- **상품 0개 선택**: 빈 상태 "비교할 상품을 선택하세요" + 검색 강조
- **상품 1개만 선택**: 1열 표시 + 나머지 열 "상품 추가" 영역
- **동일 상품 중복 선택**: "이미 선택된 상품입니다" + 추가 차단
- **비활성 상품 선택**: 회색 처리 + "비활성" 배지 + 결제 점프 차단
- **최저가 동일(2개 이상)**: 모두 하이라이트
- **회원 등급 입력 + 자동 할인 미충족(최소 계약 기간 등)**: 시뮬레이션가 = 정상가, "조건 미충족" 라벨
- **시즌 특가 진행 중 + 일반 할인 동시**: 정책 우선순위 따른 최종가 표시 (PRD-04 참조)
- **횟수제 + 회당 가격 계산**: 횟수 0이면 "-" 표시
- **기간제 + 일당 가격 계산**: 기간 0이면 "-" 표시
- **상품 교체 시 비교 데이터 보존**: 다른 열은 그대로, 교체된 열만 갱신
- **상품 삭제(DLG-P006-상품삭제확인) 후 비교 화면**: 해당 열 자동 제거 + "삭제됨" 토스트
- **회원 등급 입력 후 등급 변경**: 시뮬레이션 즉시 재계산
- **카테고리 다른 상품 비교(헬스 vs PT)**: 일부 항목 N/A 표시 (예: PT의 일일 횟수 제한)
- **결제 점프 + 회원 미선택**: 회원 검색 모달 → 선택 후 결제 진입
- **결제 점프 + 비활성 상품**: 차단 + "이 상품은 신규 판매 불가" 안내
- **공유 URL 발급 + 비활성 상품 포함**: 외부 사용자에게 비활성 상품은 회색 처리
- **외부 공유 + 가격 마스킹 정책**: 테넌트 정책에 따라 가격 노출/숨김 토글
- **검색 결과 0건**: "검색 결과 없음" + [전체 보기]
- **드롭다운 검색 디바운스 중 키워드 변경**: 이전 요청 취소
- **상품 데이터 로딩 실패**: "상품 정보를 불러올 수 없어요" + [재시도]
- **항목별 자동 하이라이트 정렬 충돌(예: 가격 같음 + 기간 다름)**: 각 항목 독립적 하이라이트

## 비즈니스 규칙

1. 비교 가능 상품은 최대 3개로 제한된다 (가독성).
2. 가격·기간·횟수 등 수치 항목은 자동 비교하여 가장 유리한 값을 하이라이트한다. 동일 값은 모두 하이라이트.
3. 비활성 상품도 비교 가능하나 시각적으로 회색 표시되며 결제 점프는 차단된다.
4. 회원에게 안내 시 가격 정책(시즌가격·할인)이 자동 반영된다 (시뮬레이션 모드).
5. 비교 화면에서 상품 삭제는 manager+만 가능하다.
6. **회원 등급 시뮬레이션**: 회원 등급 또는 세그먼트 입력 시 자동 적용 할인(PRD-04)을 시뮬레이션. 최소 계약 기간 등 조건 미충족 시 "조건 미충족" 라벨.
7. **시즌 특가 자동 강조**: PRD-08 시즌 가격 진행 중 상품은 자동 강조 + 할인율 표시.
8. **회당 / 일당 가격 자동 계산**: 회당 = 가격 / 횟수, 일당 = 가격 / 기간. 분모 0이면 "-".
9. **카테고리 다른 상품 비교 정책**: 일부 항목 N/A 처리, 비교 가능한 공통 항목만 강조.
10. **상품 교체 시 데이터 보존**: 다른 열은 그대로 유지, 교체된 열만 갱신.
11. **결제 점프**: 회원 선택 → 결제 화면 자동 진입, 회원 미선택 시 회원 검색 모달.
12. **결제 점프 차단 조건**: 비활성 상품, 카탈로그 노출 OFF, 적용 기간 외.
13. **공유 URL 정책**: `/products/compare/public/{token}` 형태, 토큰 만료 24시간(외부 노출 보안).
14. **외부 공유 가격 마스킹**: 테넌트 정책에 따라 외부 사용자에게 가격 노출/숨김 토글.
15. **회원 정보 시뮬레이션**: 회원 검색 → 선택 시 등급·세그먼트·만료일 자동 입력 + 시뮬레이션 즉시 재계산.
16. **권한별 액션**:
    - 슈퍼관리자/센터장: 비교·삭제·결제 점프·공유
    - 매니저: 비교·결제 점프·공유 (삭제 제외)
    - FC: 비교·결제 점프·공유 (담당 회원 한정 결제 점프)
    - 일반 직원: 비교 조회
    - readonly: 조회만
17. **자동 하이라이트 정책**: 각 항목 독립적, 가격은 시즌·할인 적용가 기준, 옵션은 O 우위.
18. **검색 디바운스**: 300ms, 이전 요청 취소(AbortController).
19. **카드가 vs 현금가**: 회원 등급에 따라 결제 수단 시뮬레이션 가능 (현금/카드 토글).
20. **비교 데이터 캐시**: 5분 캐시, 가격 변경 시 무효화.
21. **공유 후 토큰 만료**: 24시간 경과 시 외부 사용자 접근 차단, 새 토큰 재발급 필요.
22. **감사 로그**: 결제 점프, 공유 URL 발급은 SCR-097에 기록.
