## 기능 목적

최대 3개 상품을 나란히 비교하여 회원 상담 시 최적의 상품을 안내할 수 있는 화면이다. 가격, 이용 기간, 포함 서비스, 옵션 항목을 동일한 기준으로 표시하여 상품 간 차이를 직관적으로 파악할 수 있다. 항목별로 가장 유리한 값에는 자동 하이라이트가 표시되어 추천 포인트를 쉽게 식별할 수 있다.

## 주요 구성요소

### 상품 선택 영역

- 비교할 상품 최대 3개 선택 (드롭다운 또는 목록)
- 선택된 상품은 각 열에 표시
- 상품 제거(X) 버튼으로 비교 대상 제외

### 비교 테이블

| 비교 항목 | 설명 |
|-----------|------|
| 상품명 | 이름 + 유형 배지 |
| 현금가 | 천 단위 콤마 |
| 카드가 | 천 단위 콤마 |
| 이용 기간 | 일 단위 |
| 이용 횟수 | 총 횟수 |
| 이용 요일 | 가능 요일 |
| 이용 시간 | 시간대 |
| 홀딩 가능 | O/X |
| 양도 가능 | O/X |
| 포인트 적립 | O/X |
| 키오스크 노출 | O/X |

### 강조 표시

항목별 가장 유리한 값에 자동 하이라이트 (예: 가장 저렴한 가격, 가장 긴 기간).

### 액션

- 상품 교체: 열 X → 다른 상품 선택
- 상품 삭제: 비교 화면에서 특정 상품 → DLG-P006

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 비교 화면 | 비교·삭제 진입 |
| owner (센터장) | 전체 비교 화면 | 비교·삭제 진입 |
| manager | 전체 비교 화면 | 비교 |
| 모든 직원 | 비교 화면 | 비교 조회 |
| readonly | 비교 화면 | 조회만 |

## 주요 UX 흐름

1. 사이드바 → "상품관리 > 상품 비교" 진입
2. 상단에서 비교할 상품 1~3개 선택
3. 항목별 정보 나란히 표시 + 자동 하이라이트
4. 회원 상담 시 추천 포인트 안내
5. 열 X로 상품 교체
6. 특정 상품 삭제 필요 시 → DLG-P006

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 | "비교할 상품을 선택하세요" |
| 1개 선택 | 1열 + "상품 추가" 영역 |
| 비교 중 | 2~3개 비교 테이블 |

## 비즈니스 규칙

1. 비교 가능 상품은 최대 3개로 제한된다 (가독성).
2. 가격·기간·횟수 등 수치 항목은 자동 비교하여 가장 유리한 값을 하이라이트한다.
3. 비활성 상품도 비교 가능하나 시각적으로 회색 표시된다.
4. 회원에게 안내 시 가격 정책(시즌가격·할인)이 자동 반영된다.
5. 비교 화면에서 상품 삭제는 manager+만 가능하다.
