## 기능 목적

센터에서 판매 중인 상품을 고객이 보기 좋은 카탈로그 형태로 안내하는 화면이다. 회원 상담 시 직원이 태블릿이나 모니터로 보여주거나, 인쇄·공유하여 외부 홍보(전단지·웹 공유)에 활용한다. 상품 대분류별 색상 구분과 GX 6종 세부종목 배지로 시각적 구분이 명확해 회원이 직관적으로 상품을 비교할 수 있다. 카탈로그 노출 옵션·정렬·문구·이미지는 운영자가 카탈로그 설정(DLG-P010)·편집(DLG-P011)에서 제어하며, 미리보기(DLG-P009)로 고객 노출 형태를 사전 확인한다.

운영 맥락:
- **카운터 회원 상담**: 신규 회원이 상담 데스크 방문 → 직원이 태블릿으로 카탈로그 시연 → 추천 상품 안내 → 결제 화면(SCR-S003) 점프
- **POP / 인쇄 홍보물**: A4 또는 A5 인쇄 다이얼로그로 카탈로그 전용 레이아웃 출력 → 카운터 비치
- **외부 공유 링크**: 비로그인 외부 URL 발급 → SNS / 카카오톡 / 네이버 블로그 공유 → 잠재 고객 유입
- **회원앱 동기화**: 회원앱 "상품" 화면과 동일한 정보 노출, 카탈로그 = 어드민 + 외부 + 회원앱 통합 정본
- **시즌 캠페인 노출**: 시즌 가격(PRD-08) 진행 중 상품은 "할인" 배지 + 정상가 취소선 + 특가 표시
- **카탈로그 설정 변경**: 노출 항목(가격/기간/횟수/혜택), 정렬(인기순/가격순/최신순), 그리드 컬럼 수(2/3/4) 조정
- **카탈로그 편집(DLG-P011)**: 카탈로그 헤더 문구·각 카드 추천 코멘트·이미지 변경 → 회원에게 매력적 노출
- **인쇄 모드**: 헤더·내비게이션 숨김 + 카탈로그 전용 레이아웃 + 페이지 분할

## 주요 구성요소

### 카탈로그 뷰

- 상품 카드 그리드 레이아웃 (2/3/4 컬럼 설정 가능)
- 각 카드: 상품명·가격·기간·횟수·주요 혜택 요약·이미지(선택)
- 상품 대분류별 색상 구분 (이용권/PT/GX/상품/서비스)
- GX 상품은 6종 세부종목 배지 표시 (요가·필라·스피닝·줌바·에어로빅·GX기타)
- 시즌 특가 진행 중인 상품: "할인" 배지 + 정상가 취소선 + 특가 강조
- 패키지 상품: "패키지" 배지

### 필터 바

- 1단계 상품 대분류 탭 (이용권 / PT / GX / 상품 / 서비스)
- GX 탭 선택 시 2단계 세부종목 필터 표시
- 활성 상품만 표시 (비활성 자동 제외)
- 검색창 (상품명)

### 인쇄·공유 기능

| 액션 | 동작 |
|------|------|
| 인쇄 | 브라우저 인쇄 다이얼로그 (카탈로그 전용 레이아웃, A4/A5) |
| 공유 | 카탈로그 페이지 링크 복사 + QR 코드 |
| PDF 저장 | PDF 형태로 저장 (인쇄 다이얼로그 내) |

### 카탈로그 미리보기 (DLG-P009)

- 고객에게 보여질 화면 시뮬레이션
- 어드민 헤더·내비 숨김 상태 미리보기
- 모바일 / 태블릿 / 데스크톱 뷰포트 전환

### 카탈로그 설정 (DLG-P010)

- 노출 항목: 가격/기간/횟수/혜택/태그/이미지/배지 토글
- 정렬: 인기순 / 가격 낮은순 / 가격 높은순 / 최신순 / 수동 정렬
- 그리드 컬럼: 2 / 3 / 4
- 색상 테마: 기본 / 라이트 / 다크 / 브랜드 컬러
- 헤더 노출: 센터 로고 / 연락처 / 운영시간

### 카탈로그 편집 (DLG-P011)

- 카탈로그 헤더 문구 (제목 + 부제목)
- 각 상품 카드 추천 코멘트 (선택)
- 카드 순서 드래그 앤 드롭
- 이미지 첨부 / 변경 (DLG-P007-상품이미지업로드 연동)
- 특정 상품 카탈로그 노출 OFF (활성 상품이지만 카탈로그에서만 숨김)

## 주요 UX 흐름

**회원 상담**
1. 사이드바 → "상품관리 > 상품 카탈로그" 진입
2. 활성 상품 카드 그리드 표시
3. 대분류 탭 / GX 세부종목 필터 / 검색으로 좁히기
4. 태블릿에서 회원에게 보여주기

**고객 미리보기**
1. [카탈로그 미리보기] → DLG-P009
2. 고객 화면 시뮬레이션 (모바일/태블릿/데스크톱)

**카탈로그 옵션 / 편집**
1. [설정] → DLG-P010 → 노출 옵션
2. [편집] → DLG-P011 → 문구·순서·이미지

**인쇄 / 공유**
1. [인쇄] → 브라우저 인쇄 다이얼로그 (A4/A5/PDF)
2. [공유] → 링크 복사 + QR

### 분기·예외 흐름

- **활성 상품 0개**: 빈 상태 "표시할 상품이 없습니다" + 운영자에게 [상품 등록 안내] CTA
- **필터 결과 0건(예: GX 줌바 없음)**: "해당 필터 결과가 없습니다" + [필터 초기화]
- **시즌 가격 진행 중 + 일반 할인 동시**: 카탈로그에서 더 큰 할인율 표시 (또는 정책에 따른 우선순위)
- **카탈로그 노출 OFF 토글된 상품**: 활성 상품이지만 카탈로그에서만 숨김, 키오스크/결제는 정상
- **이미지 미등록 상품**: 카드에 placeholder 이미지(상품 대분류 아이콘) + "이미지 미등록" 라벨(어드민 모드만)
- **시즌 특가 종료 직후**: 5분 캐시로 인해 잠시 노출됨 → 캐시 무효화로 즉시 갱신
- **외부 공유 링크 + 비활성 상품**: 자동 제외, 외부 사용자는 활성 상품만 조회
- **인쇄 시 페이지 분할**: 카드 단위로 분할, 카드 중간 잘림 방지 page-break-inside: avoid
- **PDF 저장 시 이미지 누락**: 외부 호스트 이미지는 CORS 정책에 따라 누락 가능, 내부 Supabase Storage만 안정 보장
- **그리드 컬럼 4 + 모바일 뷰**: 자동으로 2 컬럼으로 축소 (responsive)
- **검색 키워드 디바운스 중 다른 키워드**: 이전 요청 취소
- **링크 복사 권한 없음(클립보드 API)**: "수동 복사" 안내 + 링크 표시
- **QR 코드 생성 실패(외부 라이브러리)**: 링크 복사만 제공
- **카탈로그 편집 중 동시 수정 충돌**: "다른 사용자가 먼저 저장했어요" 낙관적 락
- **카드 순서 드래그 + 정렬 자동 토글 ON**: "수동 정렬로 전환됩니다" 안내
- **헤더 문구 100자 초과**: 인라인 "100자 이내 입력해주세요" + 저장 차단
- **추천 코멘트 50자 초과**: 인라인 차단
- **외부 노출 URL 비활성 토글**: 외부 사용자 접근 시 "현재 카탈로그가 비공개입니다" 안내
- **회원앱 동기화 지연**: 5분 캐시 + 명시 [지금 동기화] 버튼

## 비즈니스 규칙

1. 카탈로그는 활성 상품만 표시한다 (비활성·미사용 자동 제외).
2. GX 상품은 세부종목 배지를 필수로 표시한다.
3. 대분류별 색상 코드는 SCR-P001 상품관리와 동일하게 적용된다 (브랜드 일관성).
4. 회원앱 노출과 동기화되어 일관된 정보를 제공한다. 5분 캐시 + 명시 [지금 동기화] 가능.
5. 인쇄 시 헤더·내비게이션은 숨겨지고 카탈로그 전용 레이아웃이 사용된다. 카드 단위 페이지 분할.
6. 공유 링크는 외부 노출용이며 직원 인증 없이 접근 가능하다. 비활성 토글 시 외부 접근 차단.
7. **카탈로그 노출 OFF 정책**: 활성 상품이라도 DLG-P011에서 카탈로그 노출 OFF 토글 가능. 키오스크/결제는 정상 노출.
8. **시즌 특가 자동 강조**: PRD-08 시즌 가격 진행 중 상품은 "할인" 배지 + 정상가 취소선 + 특가 표시 자동 적용.
9. **할인 자동 강조**: PRD-04 할인 진행 중 상품은 자동 적용 조건이 일반(전체 회원)이면 "할인 X%" 배지 표시.
10. **카탈로그 정렬 정책**: 인기순(누적 판매), 가격 낮은순/높은순, 최신순, 수동 정렬 5종.
11. **그리드 컬럼 정책**: 데스크톱 2/3/4 선택, 태블릿 2/3, 모바일 1/2 자동 축소 (responsive).
12. **헤더 문구**: 제목 1~50자, 부제목 1~100자. 한글·영문·숫자·이모지 허용.
13. **추천 코멘트**: 1~50자, 카드별 선택 입력. 카드 하단에 표시.
14. **이미지 정책**: 상품 등록 시 첨부된 이미지(PRD-EXT-01) 또는 카탈로그 편집에서 별도 첨부 가능. 카탈로그 전용 이미지 우선.
15. **외부 공유 URL 정책**: `/catalog/public/{branchId}/{token}` 형태, 토큰 만료 없음(비활성 토글 시 차단). QR 코드는 동일 URL.
16. **인쇄 페이지 정책**: A4 1페이지 6장(2x3) 또는 A5 1페이지 4장(2x2). 페이지 헤더에 센터명·연락처·운영시간.
17. **PDF 저장**: 브라우저 인쇄 → PDF 저장 (Chrome/Edge/Safari 지원). 한글 폰트 임베드.
18. **카드 순서 드래그**: 정렬 자동(인기순 등) 모드에서는 드래그 시 "수동 정렬로 전환" 안내.
19. **권한별 액션**:
    - 슈퍼관리자/센터장: 모든 액션 (조회·인쇄·공유·설정·편집)
    - 매니저: 설정 가능, 편집 제외
    - 일반 직원: 조회·인쇄·공유
    - readonly: 조회만
20. **외부 사용자(비로그인)**: 활성 상품만 조회, 인쇄 가능, 편집·설정 불가, 가격은 카드가 우선 표시.
21. **회원앱 동기화 캐시**: 5분 캐시. 카탈로그 변경 시 캐시 무효화 이벤트 발송 → 회원앱 즉시 갱신.
22. **카탈로그 편집 동시성**: 낙관적 락 (`updated_at` 비교).
23. **감사 로그**: 카탈로그 설정·편집 변경 SCR-097에 기록.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `PRD-05`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-P005`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-P009 카탈로그미리보기, DLG-P010 카탈로그설정, DLG-P011 카탈로그편집`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
