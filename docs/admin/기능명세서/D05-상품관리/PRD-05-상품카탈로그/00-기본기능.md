## 기능 목적

센터에서 판매 중인 상품을 고객이 보기 좋은 카탈로그 형태로 안내하는 화면이다. 회원 상담 시 직원이 태블릿이나 모니터로 보여주거나, 인쇄·공유하여 외부 홍보에 활용할 수 있다. 상품 대분류별 색상 구분과 GX 세부종목 배지로 시각적 구분이 명확해 회원이 직관적으로 상품을 비교할 수 있다.

## 주요 구성요소

### 카탈로그 뷰

- 상품 카드 그리드 레이아웃
- 각 카드: 상품명·가격·기간·횟수·주요 혜택 요약·이미지(선택)
- 상품 대분류별 색상 구분 (이용권/PT/GX 등)
- GX 상품은 6종 세부종목 배지 표시 (요가·필라·스피닝·줌바·에어로빅·GX기타)

### 필터 바

- 1단계 상품 대분류 탭 (이용권 / PT / GX / 상품 / 서비스)
- GX 탭 선택 시 2단계 세부종목 필터 표시
- 활성 상품만 표시 (비활성 자동 제외)

### 인쇄·공유 기능

| 액션 | 동작 |
|------|------|
| 인쇄 | 브라우저 인쇄 다이얼로그 (카탈로그 전용 레이아웃) |
| 공유 | 카탈로그 페이지 링크 복사 |

### 카탈로그 미리보기 (DLG-P009)

고객에게 보여질 화면 시뮬레이션.

### 카탈로그 설정 (DLG-P010)

노출 옵션·정렬·표시 항목 설정.

### 카탈로그 편집 (DLG-P011)

문구·순서·이미지 편집.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 카탈로그 + 설정 | 조회·인쇄·공유·설정·편집 |
| owner (센터장) | 전체 카탈로그 + 설정 | 조회·인쇄·공유·설정·편집 |
| manager | 전체 카탈로그 + 설정 | 조회·인쇄·공유·설정 |
| 일반 직원 | 활성 카탈로그 | 조회·인쇄·공유 |
| readonly | 활성 카탈로그 | 조회만 |

## 주요 UX 흐름

**회원 상담**
1. 사이드바 → "상품관리 > 상품 카탈로그" 진입
2. 활성 상품 카드 그리드 표시
3. 대분류 탭 / GX 세부종목 필터로 좁히기
4. 태블릿에서 회원에게 보여주기

**고객 미리보기**
1. [카탈로그 미리보기] → DLG-P009
2. 고객 화면 시뮬레이션

**카탈로그 옵션 / 편집**
1. [설정] → DLG-P010 → 노출 옵션
2. [편집] → DLG-P011 → 문구·순서

**인쇄 / 공유**
1. [인쇄] → 브라우저 인쇄 다이얼로그
2. [공유] → 링크 복사

## 비즈니스 규칙

1. 카탈로그는 활성 상품만 표시한다 (비활성·미사용 자동 제외).
2. GX 상품은 세부종목 배지를 필수로 표시한다.
3. 대분류별 색상 코드는 SCR-P001 상품관리와 동일하게 적용된다.
4. 회원앱 노출과 동기화되어 일관된 정보를 제공한다.
5. 인쇄 시 헤더·내비게이션은 숨겨지고 카탈로그 전용 레이아웃이 사용된다.
6. 공유 링크는 외부 노출용이며 직원 인증 없이 접근 가능하다.
