## 기능 목적

상품 목록(SCR-P001)에서 상품을 클릭하면 화면 우측에서 슬라이드로 나타나는 상세 정보 패널이다. 상품의 모든 설정값(기본정보·요일·시간·옵션·패키지)을 한눈에 확인하고, 수정 모드로 전환하거나 가격 변경 이력을 조회할 수 있다. 누적 판매 건수, 회원별 보유 현황, 최근 가격 변경 타임라인을 함께 확인하여 운영 의사결정(가격 인상 검토·단종·재고 회전)을 지원한다.

운영 맥락:
- **회원 상담 중 빠른 정보 확인**: 카운터에서 회원 문의 시 상품 행 클릭 → 상세 패널에서 즉시 가격·옵션·기간·홀딩/양도 정책 확인
- **가격 인상 검토**: 가격 변경 이력 + 누적 판매 건수 → 가격 변동률 vs 판매량 추세 비교
- **패키지 구성 점검**: 패키지 상품 클릭 → 구성 상품 합산 정가 + 할인가 + 개별 상품 링크
- **단종 후보 식별**: 누적 판매 0건 + 등록 후 90일 경과 상품 식별 → 비활성 전환 검토
- **회원별 보유 현황 조회**: 특정 상품 보유 회원 N명 리스트 → 만료 임박자 별도 추출
- **수정 진입 빠른 경로**: 상세에서 [수정] → SCR-P002 수정 모드(폼 채워진 상태) 즉시 진입
- **삭제·비활성 흐름 분기**: 판매 이력 0건 → DLG-P003-상품삭제확인 삭제 / 1건 이상 → DLG-P004-비활성화안내 비활성

## 주요 구성요소

### 헤더 영역

상품명 + 활성/비활성 배지 + 닫기(X).

### 상품 기본 정보

| 항목 | 내용 |
|------|------|
| 상품 구분 | 레슨/이용/락커/판매 |
| 상품 대분류 | MEMBERSHIP/PT/GX/PRODUCT/SERVICE |
| 종목·세부종목 | 2단계 분류, GX는 6종 필수 |
| 상품명 | 등록명 |
| 현금가/카드가 | 천 단위 콤마 |
| 이용 기간 | 기간제 일수 |
| 이용 횟수 | 횟수제 |
| 수업 구분 | 개인/정규클래스 (레슨) |
| 레슨 시간 | 1회 시간 (레슨) |
| 이용 구분 | 기간/횟수/포인트 |
| 태그 / 설명 | 부가 정보 |

### 분류 표시 규칙

1단계 대분류 + 2단계 종목·세부종목 함께 표시. GX는 세부종목 배지 필수 표시.

### 이용 요일·시간

요일별 체크/엑스 + 이용 시간대.

### 옵션 현황

| 옵션 | 활성 |
|------|------|
| 예약 가능 | O/X |
| 시설 이용 | O/X |
| 홀딩 가능 | O/X |
| 양도 가능 | O/X |
| 포인트 적립 | O/X |
| 회원 직접 휴회 | O/X |
| 키오스크 노출 | O/X |
| 판매 유형 | 전체/카운터/키오스크/온라인 |

### 패키지 구성 (패키지 상품만)

구성 상품 목록 + 개별 가격 + 합산 정가 + 패키지 할인가. 각 구성 상품 클릭 시 해당 상품 상세 패널로 전환.

### 가격 변경 이력

시간순 표시: 변경 전 → 변경 후, 변경 일시, 변경자. 최근 5건 표시 + [전체 보기] → DLG-P008-가격이력조회.

### 판매 현황

| 항목 | 내용 |
|------|------|
| 누적 판매 건수 | 결제 완료 누적 |
| 활성 보유 회원 수 | 만료 전 보유자 |
| 최근 30일 판매 | 최근 30일 결제 건수 |
| 만료 임박 | 30일 이내 만료 N명 |

### 액션 영역

- 수정 (편집 권한)
- 삭제 (권한 + 판매 이력 확인)
- 카탈로그 미리보기 (PRD-05 노출 형태)
- 비교 추가 (PRD-06)

## 주요 UX 흐름

**상세 조회**
1. SCR-P001 행 클릭 → 우측 패널 슬라이드
2. 정보·옵션·이력·판매 확인
3. X 클릭 → 패널 닫기

**가격 이력 조회**
1. "가격 변경 이력" 섹션 펼치기
2. [전체 보기] → DLG-P008-가격이력조회 가격이력조회

**삭제**
1. [삭제] 클릭 → 판매 이력 확인
2. 이력 없음 → DLG-P003-상품삭제확인 삭제 확인 → 삭제
3. 이력 있음 → DLG-P004-비활성화안내 비활성 → 미사용 전환

**수정 진입**
1. [수정] 클릭 → SCR-P002 수정 모드 (폼 채워진 상태)

**비교 추가**
1. [비교 추가] → SCR-P006 비교 화면, 현재 상품 자동 추가

### 분기·예외 흐름

- **상품 데이터 로딩 실패(서버 5xx)**: 패널 영역에 "정보를 불러올 수 없어요" + [재시도] 버튼
- **가격 이력 0건(신규 등록 직후)**: "가격 변경 이력이 없습니다" 안내, 섹션 자체는 노출 유지
- **패키지 상품 + 구성 상품 일부 비활성**: 패키지 구성 섹션에서 비활성 상품에 회색 처리 + "비활성" 배지
- **GX 세부종목 빈값(레거시 데이터)**: 노랑 경고 배지 "세부종목 미설정" + [수정] 안내
- **비활성 상품 조회**: 헤더에 회색 배지 + 안내 "이 상품은 미사용 상태입니다, 신규 판매 불가"
- **삭제 시 패키지 구성 사용 중**: "이 상품은 패키지 N개에서 사용 중입니다" + 패키지 링크 + 분리 안내
- **판매 현황 로딩 지연(데이터 많음)**: 스켈레톤 + 비동기 로드, 기본 정보는 먼저 표시
- **권한 부족(일반 직원)**: 수정·삭제 버튼 hidden, 조회만 가능
- **FC 권한 + 담당 외 상품**: 패널 자체 미노출 또는 "권한 없음" 안내
- **다른 행 클릭(현재 패널 닫고 새 패널 열기)**: 즉시 전환, 변경 사항 없으므로 확인 불필요
- **수정 모드 진입 + 동시 수정 충돌**: SCR-P002에서 처리(PRD-EXT-01 참조)
- **가격 이력 페이지네이션(50건 초과)**: DLG-P008-가격이력조회 전체 보기에서 페이지네이션
- **만료 임박 0명**: "만료 임박 회원이 없습니다" 안내
- **상품 삭제 후 패널 잔존**: 자동 닫힘 + 목록 갱신 + 토스트 "삭제되었습니다"
- **회원별 보유 현황 클릭**: 회원 검색(SCR-M001)으로 점프, 해당 상품 보유자 자동 필터
- **카탈로그 미리보기 + 비활성 상품**: "비활성 상품은 카탈로그에 노출되지 않습니다" 안내
- **VAT 표시 정책 다름(공급가↔소비자가)**: 지점 정책에 따라 표시값 자동 보정

## 비즈니스 규칙

1. 상품 상세는 1단계 대분류 + 2단계 종목·세부종목을 함께 표시한다.
2. `category=GX` 상품은 세부종목 배지를 필수로 표시한다. 빈값은 노랑 경고.
3. GX 세부종목 값은 매출통계 GX종목별 탭과 KPI 대시보드 GX 세부 종목 분포에서 동일 사용된다.
4. 가격 변경 이력은 변경 시점·전·후·변경자를 모두 기록한다. 최근 5건 패널 인라인, 전체는 DLG-P008-가격이력조회.
5. 판매 이력 있는 상품은 삭제 대신 미사용 비활성으로 전환된다. DLG-P004-비활성화안내로 분기.
6. 패키지 구성은 패키지 상품에만 표시된다. 비패키지는 섹션 자체 미노출.
7. **판매 현황 집계 정책**: 누적 판매 = 결제 완료 누적 건수, 활성 보유 = 만료 전 보유자 수, 최근 30일 = 결제일 30일 이내, 만료 임박 = 만료일 30일 이내. 5분 캐시.
8. **패키지 구성 상품 링크**: 구성 상품 클릭 시 해당 상품 상세 패널로 전환(현재 패널 닫고 새로 열기).
9. **비활성 상품 조회**: 패널은 정상 노출되지만 헤더에 "미사용" 회색 배지 + 신규 판매 차단 안내.
10. **권한별 정보 노출**:
    - 슈퍼관리자/센터장: 전체 정보 + 판매 현황 + 가격 이력 + 회원별 보유
    - 매니저: 전체 정보 + 판매 현황 + 가격 이력
    - 일반 직원: 상품 기본 정보 + 옵션 + 판매 현황 (가격 이력은 마지막 변경자 마스킹)
    - FC: 담당 회원이 보유한 상품만 조회 (조회만)
    - readonly: 접근 불가
11. **만료 임박 30일 기준**: 만료일이 오늘 기준 30일 이내 회원 수. 만료 임박자 클릭 → SCR-M001 회원 검색에 자동 필터.
12. **가격 이력 표시 형식**: `2026-04-15 14:23 / 100,000원 → 110,000원 / 김매니저`. 시간순 내림차순(최신 위).
13. **카탈로그 미리보기**: PRD-05의 카드 형태로 즉시 미리보기. 비활성 상품은 "노출되지 않습니다" 안내.
14. **비교 추가**: 현재 상품 자동 추가 후 SCR-P006 진입. 이미 비교 화면에 3개 상품 있으면 1개 교체 안내.
15. **데이터 부분 로딩**: 기본 정보 → 옵션 → 가격 이력 → 판매 현황 순으로 비동기 로드. 기본 정보 우선 표시.
16. **다른 행 클릭 전환**: 변경 사항이 없는 조회 모드이므로 확인 없이 즉시 전환.
17. **VAT 정책**: 지점 정책에 따라 공급가/소비자가 표시 모드. 패널 우측 상단에 표시 모드 토글.
18. **태그 표시**: 태그 5개 초과 시 ... 으로 축약, 호버 시 전체 표시.
19. **이미지 갤러리**: 등록된 이미지 1~5장 슬라이드 형태. 클릭 시 라이트박스 확대.
20. **감사 로그 조회**: 슈퍼관리자/센터장은 패널에서 [감사 로그 보기] 링크로 SCR-097 점프(해당 상품 필터 자동 적용).
