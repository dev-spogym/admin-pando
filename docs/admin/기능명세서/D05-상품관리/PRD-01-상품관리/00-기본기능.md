## 기능 목적

센터에서 판매하는 모든 상품(이용권, PT 수강권, GX 수강권, 대여권, 일반 상품 등)을 한눈에 파악하고 관리하는 메인 화면이다. 상품별 가격, 이용 기간, 요일·시간 제한, 판매 현황을 목록으로 조회하고, 우측 패널을 통해 상세 정보를 확인하거나 수정할 수 있다. 슈퍼관리자는 전 지점 배포 기능으로 본사 표준 상품을 일괄 배포할 수 있다.

## 주요 구성요소

### 상단 통계 카드 (4개)

| 카드 | 설명 |
|------|------|
| 전체 상품 수 | 등록된 상품 총 개수 |
| 활성 상품 수 | 판매 중 상품 |
| 비활성 상품 수 | 판매 중지 상품 |
| 카테고리 수 | 분류 그룹 개수 |

### 3단계 필터

| 단계 | 필터 | 옵션 |
|------|------|------|
| 1단계 | 상품 유형 탭 | 전체 / 회원권 / 수강권 / 대여권 / 일반 |
| 2단계 | 상품 대분류 | 전체 / 이용권 / PT / GX / 상품 / 서비스 |
| 3단계 | 종목·세부종목 | 2단계 선택값에 따라 동적 (GX: 요가/필라/스피닝/줌바/에어로빅/GX기타) |

### 상품 마스터 분류 모델 (2단계)

| 단계 | 필드 | 값 |
|------|------|------|
| 1단계 | 상품 대분류 `category` | MEMBERSHIP / PT / GX / PRODUCT / SERVICE |
| 2단계 | 상품그룹·종목 `productGroupId` 또는 `subCategory` | "분류 관리" 탭 그룹 우선, GX 세부종목 별도 고정 |

GX 대분류 선택 시 2단계 세부종목은 6개 고정: 요가/필라테스/스피닝/줌바/에어로빅/GX기타.

### 상품 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 상품명 | 유형 배지 + 패키지 배지 + 이름 |
| 대분류 | 상품 대분류 |
| 세부종목 | 종목·세부종목 |
| 현금가 | 천 단위 콤마 |
| 카드가 | 천 단위 콤마 |
| 기간 | 일 단위 |
| 횟수 | 이용 횟수 |
| 요일 (월~일) | 체크/엑스 |
| 시간 | 이용 가능 시간대 |
| 홀딩 | O/X |
| 양도 | O/X |
| 포인트 | O/X |
| 판매 | 판매 건수 |
| 상태 | 사용/미사용 |

> 우측 상세 패널 열림 시 요일/시간/홀딩/양도/포인트/판매 컬럼은 숨겨지고 핵심 컬럼만 표시.

### 분류 관리 탭

상품 목록 탭과 전환. 분류 등록 폼(이름·정렬·활성) + 분류 목록(수정·삭제).

### 전 지점 배포 (DLG-P001)

슈퍼관리자 전용. 상품·지점 선택 후 일괄 배포.

### 상단 액션

- **+ 상품 등록**: 우측 패널 등록 모드
- **Excel**: 현재 필터 엑셀 다운로드
- **전 지점 배포** (슈퍼관리자만): DLG-P001

## 주요 UX 흐름

**상품 조회**
1. 사이드바 → "상품관리 > 상품 관리" 진입
2. 3단계 필터 + 검색으로 좁히기
3. 행 클릭 → SCR-P003 우측 상세 패널

**상품 등록**
1. [+ 상품 등록] → SCR-P002 우측 패널
2. 정보 입력 → 저장 → 목록 갱신

**분류 관리**
1. "분류 관리" 탭 → 분류 CRUD
2. 정렬 순서·활성 설정

**전 지점 배포**
1. 슈퍼관리자 → [전 지점 배포] → DLG-P001
2. 상품·지점 선택 → 일괄 배포

## 비즈니스 규칙

1. 상품 마스터는 1단계 대분류 + 2단계 종목·세부종목 2단계 분류를 정본으로 사용한다.
2. `category=GX` 상품은 세부종목 선택이 필수이다.
3. `productGroupId`가 있는 상품은 연결된 `product_groups.name`을 목록 분류 필터와 상품명 배지에 우선 표시한다.
4. `productGroupId`가 없는 상품은 `category`의 한글 표시명을 fallback으로 사용한다.
5. GX 세부종목 값은 SCR-S004 매출통계의 GX종목별 탭과 SCR-094 KPI 대시보드의 GX 세부 종목 분포 집계 기준이다.
6. 전 지점 배포는 슈퍼관리자만 가능하며 배포 이력이 감사 로그(SCR-097)에 기록된다.
7. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 필터 결과를 내려받는다.
