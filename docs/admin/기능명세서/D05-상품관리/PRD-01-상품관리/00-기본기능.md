## 기능 목적

센터에서 판매하는 모든 상품(이용권, PT 수강권, GX 수강권, 락커·대여권, 실물 상품, 서비스 상품)을 한 화면에서 파악하고 등록·수정·삭제·일괄 배포하는 상품 마스터 운영의 메인 허브이다. 상품별 가격(현금가/카드가/VAT 정책), 이용 기간·횟수, 요일·시간 제한, 옵션(홀딩/양도/포인트/키오스크 노출), 판매 채널, 누적 판매 건수까지 단일 테이블로 조회한다. 행 클릭 시 우측 `SCR-P003 상품 상세/수정 패널`에서 바로 조회·수정하고, [+ 상품 등록]으로 `SCR-P002`/`DLG-P001-상품등록모달` 등록 폼에 진입한다. 슈퍼관리자는 DLG-P002-전지점배포 전 지점 배포로 본사 표준 상품을 모든 지점에 일괄 복제한다.

운영 맥락:
- **센터장 신규 오픈 / 시즌 라인업 정비**: 분류 관리에서 그룹 정비 → 회원권/PT/GX/락커 신규 등록 → 카탈로그(PRD-05)·키오스크 동시 노출 활성화
- **본사 슈퍼관리자 표준 상품 전 지점 배포**: 본사 가격 표준 상품을 정의 후 DLG-P002-전지점배포로 200개 지점에 일괄 배포, 지점별 가격 차등은 배포 후 개별 수정
- **단종·시즌 종료 정리**: 비활성 토글로 신규 판매 차단(기존 보유 회원은 만료까지 유지), 카탈로그·키오스크에서 자동 노출 해제
- **GX 종목 추가 / 세부종목 신설**: 분류 관리에서 GX 5종 외 신규 종목 추가 시 매출통계·KPI 대시보드 집계 키도 자동 확장
- **엑셀 일괄 다운로드 → 외부 가격 검토**: 본사 마케팅이 엑셀 받아 경쟁사 비교 → 시즌가격(PRD-08) 또는 할인(PRD-04)에 반영
- **패키지 상품 정비**: PT 10회 + 헬스 1개월 묶음 패키지 등록 → 패키지 할인가 적용, 구성 상품 개별 수정 시 패키지 가격 재계산
- **세부 채널별 노출 제어**: 카운터·키오스크·온라인 채널 각각 노출 토글로 신규 회원 판매 채널 분리

상품 마스터는 전 도메인의 정본(Single Source of Truth)으로 SCR-S003 결제처리, SCR-S004 매출통계, SCR-094 KPI 대시보드, SCR-P005 카탈로그, 회원앱·키오스크가 모두 이를 기반으로 동작한다.

## 주요 구성요소

### 상단 통계 카드 (4개)

| 카드 | 설명 |
|------|------|
| 전체 상품 수 | 등록된 상품 총 개수 |
| 활성 상품 수 | 판매 중 상품 |
| 비활성 상품 수 | 판매 중지 상품 |
| 카테고리 수 | 분류 그룹 개수 |

### 3단계 필터

| 단계 | 필터 | 옵션 |
|------|------|------|
| 1단계 | 상품 유형 탭 | 전체 / 회원권 / 수강권 / 대여권 / 일반 |
| 2단계 | 상품 대분류 | 전체 / 이용권 / PT / GX / 상품 / 서비스 |
| 3단계 | 종목·세부종목 | 2단계 선택값에 따라 동적 (GX: 요가/필라테스/스피닝/줌바/GX기타) |

### 상품 마스터 분류 모델 (2단계)

| 단계 | 필드 | 값 |
|------|------|------|
| 1단계 | 상품 대분류 `category` | MEMBERSHIP / PT / GX / PRODUCT / SERVICE |
| 2단계 | 상품그룹·종목 `productGroupId` 또는 `subCategory` | "분류 관리" 탭 그룹 우선, GX 세부종목 별도 고정 |

GX 대분류 선택 시 2단계 세부종목은 5개 고정: 요가/필라테스/스피닝/줌바/GX기타.

### 상품 목록 테이블

| 컬럼 | 내용 |
|------|------|
| 상품명 | 유형 배지 + 패키지 배지 + 이름 |
| 운영 정책 | 단일지점 / 법인 / 홈&오피스 / 주말 / 통합 배지 |
| 대분류 | 상품 대분류 |
| 세부종목 | 종목·세부종목 |
| 이용 가능 지점 | 단일/복수/전체 요약 |
| 정산 정책 | 이용지점 기준 / 판매지점 기준 / 지정 정산지점 |
| 현금가 | 천 단위 콤마 |
| 카드가 | 천 단위 콤마 |
| 기간 | 일 단위 |
| 횟수 | 이용 횟수 |
| 요일 (월~일) | 체크/엑스 |
| 시간 | 이용 가능 시간대 |
| 홀딩 | O/X |
| 양도 | O/X |
| 포인트 | O/X |
| 판매 | 판매 건수 |
| 상태 | 사용/미사용 |

> 우측 상세 패널 열림 시 요일/시간/홀딩/양도/포인트/판매 컬럼은 숨겨지고 핵심 컬럼만 표시.

### 분류 관리 탭

상품 목록 탭과 전환. 분류 등록 폼(이름·정렬·활성) + 분류 목록(수정·삭제).

### 전 지점 배포 (DLG-P002-전지점배포)

슈퍼관리자 전용. 상품·지점 선택 후 일괄 배포.

### 상단 액션

- **+ 상품 등록**: `DLG-P001-상품등록모달` 기반 우측 등록 패널
- **Excel**: 현재 필터 엑셀 다운로드
- **전 지점 배포** (슈퍼관리자만): DLG-P002-전지점배포

## 주요 UX 흐름

**상품 조회**
1. 사이드바 → "상품관리 > 상품 관리" 진입
2. 3단계 필터 + 검색으로 좁히기
3. 행 클릭 → SCR-P003 우측 상세 패널

**상품 등록**
1. [+ 상품 등록] → SCR-P002 / DLG-P001-상품등록모달 우측 패널
2. 정보 입력 → 저장 → 목록 갱신

**분류 관리**
1. "분류 관리" 탭 → 분류 CRUD
2. 정렬 순서·활성 설정

**전 지점 배포**
1. 슈퍼관리자 → [전 지점 배포] → DLG-P002-전지점배포
2. 상품·지점 선택 → 일괄 배포

### 분기·예외 흐름

- **GX 대분류인데 세부종목 미선택**: 등록 진입 시 SCR-P002에서 저장 차단(PRD-EXT-01 참조). 목록에서 GX 행이 세부종목 빈값이면 노랑 경고 배지 + 본사 운영 알림
- **상품그룹 삭제 시도(연결 상품 존재)**: "이 그룹에 연결된 상품 {개수}개가 있습니다" 모달 + [그룹 이동(다른 그룹 선택)] / [취소], 강제 삭제 차단
- **패널 열림 상태에서 다른 행 클릭**: 변경 사항 없으면 즉시 전환, 변경 사항 있으면 DLG-P003-작업취소확인 작업 취소 확인
- **검색·필터 결과 0건**: 빈 상태 + [필터 초기화] CTA + 등록 권한자에게 [+ 상품 등록] 안내
- **전 지점 배포 중 일부 지점 실패**: 진행률 모달 + 성공/실패 지점 분리 표시, 실패 지점만 재시도 옵션, SCR-097에 부분 성공 로그 기록
- **엑셀 다운로드 행 1만 건 초과**: 비동기 배치 모드 전환 + "준비 후 다운로드 알림 발송" 안내
- **본사 슈퍼관리자가 지점 컨텍스트 미선택 상태에서 등록 시도**: "지점을 먼저 선택해주세요" 안내 + 지점 선택 드롭다운 강조
- **지점 비활성 / 폐점 상태에서 상품 조회**: 읽기 전용 모드 + "폐점 지점입니다, 신규 등록 불가" 배너
- **분류 비활성 → 활성 전환**: 즉시 카탈로그·키오스크 노출 재개, 신규 결제 가능
- **상품명 검색 디바운스 중 다른 키워드 입력**: 이전 요청 취소(AbortController), 마지막 키워드 결과만 반영
- **카드가 미입력 / 카드가 < 현금가**: 노랑 경고 배지("카드가 확인 필요"), 결제 시 적용은 정책 우선순위(PRD-04 참조)
- **VAT 정책 차이(소비자가 vs 공급가)**: 지점 정책 토글에 따라 표시값 자동 보정, 엑셀에는 둘 다 컬럼으로 출력
- **패널 열림 + Excel 클릭**: 현재 필터 결과 다운로드(패널 상품만 아님), 파일명에 필터 키워드 포함

| 패널 열림 | 목록 55% + 패널 45% |
| 패널 닫힘 | 목록 100% |
| 필터 결과 0건 | 빈 안내 + [필터 초기화] |
| 배포 진행 중 | 진행률 모달 + 실패 지점 표시 |
| 엑셀 비동기 모드 | "준비 중, 완료 시 알림 발송" |

## 비즈니스 규칙

1. 상품 마스터는 1단계 대분류 + 2단계 종목·세부종목 2단계 분류를 정본으로 사용한다. 다른 도메인(SCR-S003 결제, SCR-S004 매출통계, SCR-094 KPI, SCR-P005 카탈로그)은 모두 이 마스터를 참조한다.
2. `category=GX` 상품은 세부종목 선택이 필수이다. 세부종목 빈값은 저장 차단되며 기존 데이터에 빈값이 있으면 노랑 경고 배지로 표시된다.
3. `productGroupId`가 있는 상품은 연결된 `product_groups.name`을 목록 분류 필터와 상품명 배지에 우선 표시한다.
4. `productGroupId`가 없는 상품은 `category`의 한글 표시명을 fallback으로 사용한다.
5. GX 세부종목 값은 SCR-S004 매출통계의 GX종목별 탭과 SCR-094 KPI 대시보드의 GX 세부 종목 분포 집계 기준이다.
6. 전 지점 배포는 슈퍼관리자만 가능하며 배포 이력이 감사 로그(SCR-097)에 `actor·source_branch·target_branches·product_count·result_summary`로 기록된다.
7. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 필터 결과를 내려받는다. 1만 건 초과 시 비동기 배치 모드로 자동 전환되어 완료 시 알림 센터(NFR-19) 발송.
8. **운영 정책 구분 5종**: 회원권 계열 상품은 `단일지점 / 법인 / 홈&오피스 / 주말 / 통합` 중 하나를 필수 선택한다.
9. **다지점 이용 가능 지점 저장**: 법인/홈&오피스/주말/통합 상품은 `allowedUsageBranchIds`를 1개 이상 저장하며 목록에서도 요약 배지로 표시한다.
10. **귀속 기본값 저장**: 상품 마스터에 `defaultUsageBranchId`, `defaultSalesAttributionBranchId`, `defaultSettlementBranchId`, `defaultIncentivePolicy`를 저장해 결제 계약의 기본값으로 사용한다.
11. **타지점 강습 허용 정책**: PT/골프 등 강습형 상품은 `crossBranchLessonAllowed=true`일 때만 다른 지점 수업 배정이 가능하다.
12. **상품 비활성 처리**: 비활성 토글 시 신규 판매(결제·키오스크)는 즉시 차단되지만 기존 보유 회원의 이용권은 만료일까지 정상 사용된다. 카탈로그(PRD-05)·키오스크에서는 자동 제외.
13. **패키지 상품 가격 산정**: 구성 상품 합산 정가와 패키지 할인가는 별도 저장. 구성 상품 개별 가격 변경 시 패키지 합산 정가는 자동 재계산되지만 패키지 할인가는 운영자가 명시 갱신해야 한다.
14. **카드가 정책**: 카드가 미입력 시 현금가와 동일하게 저장. 카드가 < 현금가는 허용(카드 결제 우대)되지만 노랑 경고 표시. 카드가 > 현금가는 저장 차단.
15. **상품그룹 삭제 영향**: 그룹 삭제 시 연결된 상품이 있으면 차단. 그룹 비활성은 가능하나 연결 상품의 표시명 fallback이 `category` 한글명으로 전환.
16. **분류 정렬 순서**: 분류 관리에서 정렬 순서를 정수로 입력. 동일 정렬 순서는 등록일 ASC로 보조 정렬.
17. **본사·지점 컨텍스트**: 본사 슈퍼관리자는 통합 모드(전 지점 합산) + 지점별 모드 전환 가능. 등록·수정은 항상 지점 컨텍스트 필수.
18. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 + 전 지점 배포
    - 센터장: 소속 지점 + 등록·수정·삭제·엑셀
    - 매니저: 소속 지점 + 등록·수정·엑셀 (삭제 권한 없음)
    - 일반 직원: 조회·검색만
    - readonly: 접근 불가
19. **상품명 정책**: 1~50자, 동일 지점 + 동일 대분류에서 중복 불가. 특수문자 일부 허용(괄호, 쉼표, 하이픈), 이모지 차단.
20. **세부종목 신설**: GX 외 분류는 분류 관리에서 자유 추가 가능. GX 세부종목은 시스템 고정 6종 외 추가 시 슈퍼관리자만 시스템 코드로 추가 가능.
21. **판매 채널 토글**: 카운터·키오스크·온라인·전체 4종. 채널별 가격 차등은 SCR-S003에서 정책 우선순위 적용.
22. **엑셀 컬럼 규격**: 14개 목록 컬럼 + 등록일·수정일·등록자·수정자·VAT 포함 여부 컬럼 추가, 파일명 규칙 `상품관리_{지점명}_{필터요약}_{YYYYMMDD-HHmm}.xlsx`.
23. **전 지점 배포 충돌**: 대상 지점에 동일 상품명 + 동일 대분류 존재 시 [덮어쓰기] / [건너뛰기] / [이름 자동 변경] 3선택. 슈퍼관리자가 일괄 또는 지점별 선택.
24. **삭제 가능 조건**: 판매 이력이 0건이면 완전 삭제, 1건 이상이면 비활성 전환만 가능(PRD-EXT-01 참조). 패키지 구성 상품으로 사용 중이면 패키지 분리 후에만 삭제 가능.
25. **감사 로그**: 등록·수정·삭제·비활성·배포·분류 변경 모두 SCR-097에 기록. `actor_id, branch_id, product_id, action, before, after`.
26. **회원앱·키오스크 동기화**: 활성 토글·가격 변경 시 5분 캐시 무효화 + 회원앱·키오스크 동시 갱신.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `PRD-01`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-P001`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-P002-전지점배포`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
