## 기능 목적

새로운 회원을 시스템에 등록하는 화면이다. 필수 정보(Step 1)와 추가 정보(Step 2)를 단계별로 입력받아 빠른 등록과 상세 정보 입력을 분리한다. 등록 완료 후 곧바로 이용권 결제(POS)로 연결해 신규 회원의 서비스 시작을 자연스럽게 유도하며, 등록 후 5초간 [바로 결제] 버튼이 노출된다. SCR-M003 회원 수정도 동일 컴포넌트를 재사용하되 기존 정보가 자동 채움된다.

## 주요 구성요소

### 단계 표시기 + 프로필 사진

- **Step 표시**: Step 1 / Step 2 진행 단계 상단 표시. Step 1 완료 후 Step 2 이동 가능
- **프로필 사진 업로더**: 원형 영역 클릭 → 사진 등록. 미등록 시 이니셜 아바타 자동 생성

### Step 1 — 기본 인적 사항 (필수)

| 항목 | 입력 | 검증 |
|------|------|------|
| 이름 | 텍스트 | 필수, 한/영/한자 2~20자 |
| 성별 | 토글 (남/여) | 필수 |
| 연락처 | 010 자동 포맷 + [중복 확인] | 필수, 중복 시 DLG-M006 경고 |
| 회원구분 | 일반 / 기명법인 / 무기명법인 | 필수 |
| 법인 회사명 | 회원구분=법인 시 추가 노출 | - |
| 생년월일 | 캘린더 | 미래 날짜 차단 |
| 키 (cm) | 숫자 | - |

### Step 1 — 관리 정보

담당 FC / 담당 트레이너 / 방문경로 / 유입경로 / 운동 목적 (모두 선택)

### Step 2 — 추가 연락 정보

별칭·닉네임 / 이메일 / 주소(DLG-M027 주소 검색) / 상세 주소 / 회사명 / 출석번호

### Step 2 — 기타 설정

- 광고성 정보 수신 동의 체크박스
- 메모 입력란 (최대 500자, 글자 수 표시)

### 하단 고정 버튼

- Step 1: [취소] [다음]
- Step 2: [이전] [저장]
- [초기화]: 입력한 내용이 있을 때만 활성, 확인 후 전체 초기화 (DLG-M008)

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 화면 | 회원 등록 완전 접근 |
| 센터장 (owner) | 전체 화면 | 회원 등록 완전 접근 |
| 매니저 | 전체 화면 | 회원 등록 완전 접근 |
| 스태프 | 전체 화면 | 회원 등록 완전 접근 |
| FC / 트레이너 / 프런트 | 접근 불가 | 이 화면 진입 시 접근 제한 안내로 이동 |

## 주요 UX 흐름

1. SCR-M001의 [회원 추가] 버튼 → SCR-M002 진입
2. Step 1: 이름·성별·연락처·회원구분 입력 + 연락처 중복 확인
3. [다음] → Step 2 (필수 미입력 또는 중복 미완료 시 이동 불가)
4. Step 2 추가 정보 선택적 입력 → [저장]
5. 성공 시 SCR-M004 회원 상세로 이동, [바로 결제] 5초 노출
6. 취소/이탈 시 변경 사항 있으면 DLG-M007

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 상태 | 모든 입력란 비어 있음, 초기화 비활성 |
| 입력 중 | 값 입력 시작 → 초기화 활성 |
| 유효성 오류 | 필수/형식 오류 → 인라인 메시지 |
| 이미지 업로드 중 | 로딩 표시 |
| 법인 회원 모드 | 회사명 입력란 추가 노출 |
| Step 2 | Step 1 완료 후 진입 |
| 저장 중 | 버튼 비활성 + 로딩 |
| 등록 완료 | SCR-M004 자동 이동 + 바로 결제 노출 |

## 비즈니스 규칙

1. 연락처는 중복 확인을 완료해야 다음 단계로 진행할 수 있다.
2. 생년월일에 미래 날짜는 입력할 수 없다.
3. 이름은 한/영/한자 2~20자.
4. 메모는 500자 초과 불가.
5. 출석번호 미입력 시 시스템 자동 생성.
6. 법인 회원은 기명/무기명 구분, 회사명 추가 입력 필수.
7. 등록 완료 후 5초간 [바로 결제] 버튼이 단축 진입으로 노출.
