## 기능 목적

새로운 회원을 시스템에 등록하거나 기존 회원의 기본 정보를 수정한다. 필수 정보(Step 1)와 선택 정보(Step 2)를 2단계로 나눠 입력 부담을 줄이고, 전화번호 중복 확인과 프로필 이미지 업로드, 우편번호 검색 등 입력 보조 기능을 제공한다. 등록 완료 후 결제 화면으로 바로 이동하는 단축 진입을 단기간 노출한다.

## 주요 UX 흐름

**신규 등록**
1. 회원 목록 [회원 추가] → SCR-M002 진입
2. Step 1 입력 + 중복 확인 → [다음]
3. Step 2 입력 → [저장]
4. 토스트 + 회원 상세 또는 결제 화면 이동

**수정**
1. SCR-M004 헤더 [수정] → SCR-M003 진입
2. 기존 정보 자동 채움 → 변경 → [저장]
3. SCR-M004 복귀

## 화면 상태

| 상태 | 표시 |
|------|------|
| Step 1 입력 중 | 다음 버튼 활성 (필수 충족 시) |
| 중복 발견 | 인라인 에러 |
| Step 2 입력 중 | 저장 버튼 활성 |
| 이미지 업로드 실패 | 토스트 + 재시도 |
| 저장 중 | 로딩 + 백 비활성 |

## 비즈니스 규칙

1. 연락처는 중복 확인을 완료해야 신규 등록이 가능하다.
2. 생년월일에 미래 날짜는 입력할 수 없다.
3. 이름은 한/영/한자 2~20자 이내로 제한한다.
4. 메모는 500자를 초과할 수 없다.
5. 출석번호 미입력 시 시스템이 자동 생성한다.
