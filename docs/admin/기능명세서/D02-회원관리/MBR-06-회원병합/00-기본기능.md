## 기능 목적

동일인이 실수로 중복 등록된 경우 두 회원 계정을 하나로 병합하여 데이터를 통합한다. 병합 후 기준 계정은 유지되고 병합 대상은 비활성된다.

## Lv2 / Lv3 세분화 매트릭스

본 기능의 Lv2/Lv3 세분화는 회원관리.md 통합본의 매트릭스를 따른다.

## 권한 / RBAC

| 역할 | 조회 | 실행 |
|---|:---:|:---:|
| primary / owner | ✅ | ✅ |
| manager | ✅ | 일부 제한 |
| fc / staff | 일부 | 일부 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 → 회원관리 → 회원 병합 진입 또는 회원 상세에서 진입
2. 대상 회원 선택 / 검색
3. 핵심 액션 수행
4. 확인 모달 → 처리 완료
5. 목록 / 상세로 복귀

## 비즈니스 규칙

1. 권한 미보유 시 접근 차단.
2. 처리 결과는 감사 로그(SCR-097)에 기록된다.
3. 본사 통합 모드에서는 회원 실제 소속 지점(`branchId`) 기준으로 처리한다.
