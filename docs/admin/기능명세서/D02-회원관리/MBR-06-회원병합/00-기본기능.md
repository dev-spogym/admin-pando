## 기능 목적

동일인으로 판단되는 중복 회원 계정 두 개를 하나로 합치는 화면이다. 연락처 변경이나 재등록 등으로 같은 회원이 중복 등록된 경우, 양쪽 데이터를 하나의 주 계정으로 통합한다. 출석 이력·결제 이력·상담 메모·체성분 기록 등 중요한 이력 데이터는 병합 후에도 유지되며, 부 계정은 비활성 처리된다 (즉시 삭제 아님).

## 주요 구성요소

### 중복 회원 검색

이름·연락처·생년월일로 중복이 의심되는 회원 검색.

### 주 계정 / 부 계정 지정

- **주 계정** = 병합 후 남길 계정
- **부 계정** = 병합 후 비활성될 계정

### 병합 전 정보 비교 화면

주 계정과 부 계정의 주요 정보(이름·연락처·이용권·등록일·최근 방문일)를 나란히 표시.

### 병합 항목 선택

이름, 연락처, 프로필 사진 등 일부 항목에서 어느 쪽 계정 값을 채택할지 선택.

### 병합 후 처리 안내

- 부 계정의 출석/결제/상담 메모/체성분 기록은 주 계정으로 이전
- 부 계정은 비활성 상태로 전환 (즉시 삭제 아님)

### 최종 확인 다이얼로그 (DLG-M028)

병합은 되돌리기 어려운 작업임을 명시하고 "병합" 입력 확인 후 처리.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 회원 병합 가능 | 병합 처리 전체 |
| 센터장 (owner) | 소속 지점 내 회원 병합 | 병합 처리 |
| 매니저 / FC / 트레이너 / 스태프 / 프런트 | 접근 불가 | 이 기능 사용 불가 |

## 주요 UX 흐름

1. 회원 목록 또는 회원 상세에서 "회원 병합" 메뉴로 진입
2. 중복 의심 회원 검색 → 주 계정·부 계정 지정
3. 비교 화면에서 정보 확인 + 병합 항목 선택
4. [병합] → DLG-M028 → "병합" 텍스트 입력 → 최종 확인
5. 병합 완료 후 주 계정 SCR-M004 진입

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 검색 | 두 계정 모두 미선택, 검색 안내 |
| 주 계정만 선택 | 부 계정 선택 대기 |
| 두 계정 모두 선택 | 비교 화면 + 병합 버튼 활성 |
| 처리 중 | 버튼 비활성 + 로딩 |
| 병합 완료 | 주 계정 상세 페이지 이동 |

## 비즈니스 규칙

1. 병합은 되돌릴 수 없는 작업이며 "병합" 텍스트 입력 후 최종 확인.
2. 부 계정의 모든 이력(출석·결제·상담·체성분)은 주 계정으로 이전.
3. 부 계정은 즉시 삭제되지 않고 비활성 처리된다.
4. 동일 회원은 주/부 계정으로 동시 지정 불가.
5. 본사 통합 모드에서도 동일 지점 회원 간 병합만 가능 (지점 간 병합은 별도 정책).
6. 처리 이력은 감사 로그(SCR-097)에 기록.
