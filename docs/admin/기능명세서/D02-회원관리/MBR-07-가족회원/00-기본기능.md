## 기능 목적

동일 가족 구성원인 회원들을 서로 연결하여 가족 단위로 관리하는 화면(SCR-M008)이다. 가족 회원 연결을 통해 패밀리 이용권 혜택 적용, 가족 단위 결제 현황 파악, 특정 가족 묶음 대상 마케팅, 마일리지 가족 합산 사용 등을 지원한다. 한 회원은 한 그룹에만 속할 수 있으며 가족 관계(부모/자녀/배우자/형제/기타)를 명시한다.

운영 맥락:
- **부모-자녀 동시 등록 시**: 신규 등록 후 가족 그룹 생성 → 패밀리 할인 적용
- **배우자 결제 합산 마케팅**: 부부 묶음 세그먼트(MBR-09 연계)로 메시지 발송, 패밀리 이용권 권유
- **형제·자매 묶음 PT 패키지**: 가족 그룹의 모든 활성 회원에게 동일 PT 패키지 일괄 결제
- **가족 단위 마일리지 사용**: 부모가 적립한 마일리지를 자녀가 사용 (테넌트 정책에 따라)
- **미성년 자녀 보호자 동의 관리**: 자녀 회원에게 보호자 회원이 그룹 대표로 연결, 동의 / 결제 권한 관리
- **사망·이혼·가족 해체**: 가족 그룹 해체 또는 특정 멤버 분리, 회원 데이터는 모두 보존
- **본인 사망 후 가족 양도**: 양도(DLG-M019) + 가족 그룹 정리 2단계 처리

가족 단위 분석을 위해 그룹별 활성 회원 수, 총 마일리지 합산, 이용권 현황, 누적 결제 금액을 요약 카드로 제공한다.

## 주요 구성요소

### 가족 그룹 목록

등록된 가족 그룹을 카드 형태로 표시. 각 카드에 그룹 이름(예: "김씨 가족"), 구성원 수, 대표 회원 이름.

### 가족 그룹 상세

그룹 클릭 시 구성원 목록 펼침: 이름·관계·이용권 상태·최근 방문일.

### 구성원 추가 (DLG-M029)

기존 회원 검색 + 그룹 추가 + 관계 선택 (부모/자녀/배우자/형제/기타).

### 가족 그룹 생성

새 그룹 생성 버튼. 그룹 이름 + 최초 구성원 추가.

### 구성원 제거

특정 구성원을 그룹에서 분리. 분리 후 회원 데이터는 유지.

### 가족 단위 요약 정보

- 가족 전체 이용권 현황
- 활성 회원 수
- 총 마일리지 합산

## 주요 UX 흐름

### 정상 그룹 생성 흐름
1. 사이드바 "회원관리 > 가족 회원" 또는 회원 상세 관련 메뉴 진입
2. 기존 가족 그룹 목록 (카드 그리드) 확인
3. [새 그룹 만들기] 클릭 → 그룹명 입력(예: "김씨 가족") + 대표 회원 검색 + 최초 구성원 추가
4. 그룹 생성 완료 후 카드에 구성원 수·대표 회원·요약 표시
5. 그룹 클릭 → 구성원 펼침 (이름·관계·이용권 상태·최근 방문일)

### 구성원 추가 흐름
1. 그룹 카드 → [구성원 추가] 또는 DLG-M029 진입
2. 회원 검색 (이름·연락처) → 결과 카드 클릭
3. 관계 선택 (부모/자녀/배우자/형제/기타)
4. [추가] → 즉시 그룹에 반영, 회원 상세에도 가족 그룹 표시

### 분기·예외 흐름
- **이미 다른 그룹에 속한 회원 추가 시도**: "이미 다른 가족 그룹에 속해 있어요" 모달 + 기존 그룹 카드 노출 + [그룹 이동(권한자만)] / [취소]
- **자녀 회원이 미성년인데 보호자 미연결**: "미성년 회원은 보호자(대표) 연결이 권장됩니다" 안내 (강제 아님, 정책 따라)
- **그룹 대표 회원 탈퇴 처리**: 자동으로 다음 활성 회원이 대표 역할 승계 (가입일 기준 가장 오래된 회원), 모두 비활성이면 그룹 자동 해체 + 알림
- **가족 회원 1명 이관 (MBR-04)**: 그룹은 자동 분리 안 됨, 단 이관된 회원은 새 지점 컨텍스트로 가족 그룹 표시 (지점 다른 멤버끼리)
- **회원 병합 (MBR-06) 시**: 병합 대상이 가족 멤버라면 부 계정의 가족 연결만 해제, 주 계정 가족 그룹 유지
- **그룹 삭제 시도**: 구성원 데이터는 모두 유지된다는 안내 + 텍스트 입력 확인
- **회원 사망 / 사고 시 그룹에서 분리**: 탈퇴 처리 시 자동 분리 또는 그룹에 표시(정책에 따라)
- **무기명 법인 회원**: 가족 그룹 가입 불가 (개인 회원만)
- **가족 마일리지 합산 사용**: 그룹 정책에 따라 부모 → 자녀 사용 허용 / 차단 (테넌트 설정)
- **그룹 정원 초과**: 그룹당 최대 10명 (정책 한도), 초과 시 추가 차단

## 비즈니스 규칙

1. 한 회원은 여러 가족 그룹에 속할 수 없다. 다른 그룹 추가 시도 시 모달로 차단.
2. 그룹 삭제 시 구성원 회원 데이터는 그대로 유지된다. `family_members` 테이블의 연결만 끊김.
3. 가족 단위 요약(마일리지/이용권/누적결제/활성회원수)은 실시간 합산. 큰 그룹은 5분 캐시.
4. FC는 담당 회원이 포함된 그룹만 조회 가능 (RLS).
5. 가족 할인은 별도 정책(상품 관리 / 마케팅)에서 정의. 가족 그룹 자체는 연결 정보만 관리.
6. **그룹 정원**: 최대 10명. 초과 시 추가 차단 (운영 정책에 따라 변경 가능).
7. **관계 타입**: 부모 / 자녀 / 배우자 / 형제·자매 / 기타. 단일 선택. 변경 가능.
8. **그룹 대표 (head_member_id)**: 그룹당 1명. 대표 탈퇴 시 가입일 기준 다음 활성 회원이 자동 승계. 모두 비활성이면 그룹 자동 해체.
9. **무기명 법인 가입 차단**: 무기명 법인 회원은 가족 그룹 가입 불가.
10. **미성년 자녀 보호자 연결 권장**: 만 14세 미만 자녀는 보호자 회원이 그룹 대표로 연결 권장 (강제 아님, 정책에 따라 강제 가능).
11. **가족 마일리지 합산 사용**: 테넌트 정책 토글로 활성화 가능. 활성 시 부모 마일리지 → 자녀 결제 사용 허용.
12. **회원 이관 (MBR-04) 영향**: 가족 그룹 자동 분리 안 됨. 이관 후에도 그룹 유지 (지점 간 가족 그룹 허용).
13. **회원 병합 (MBR-06) 영향**: 병합 시 부 계정의 가족 연결만 해제. 주 계정 그룹 유지.
14. **회원 탈퇴 / 삭제 시**: 그룹에서 자동 분리. 단, 정책에 따라 "비활성 멤버" 상태로 표시만 하고 분리하지 않을 수도 있음(이력 추적용).
15. **그룹 삭제 권한**: 슈퍼관리자 / 센터장만 가능. 매니저는 멤버 추가·제거만 가능.
16. **권한별 가시성**:
    - 슈퍼관리자: 전 지점 그룹
    - 센터장: 소속 지점 그룹
    - 매니저: 소속 지점 그룹 (구성원 추가·제거)
    - FC: 담당 회원이 속한 그룹 조회만
    - 트레이너 / 스태프 / 프런트: 접근 불가 또는 조회만
17. **그룹명 정책**: 1~30자, 특수문자·이모지 차단. 같은 지점 내 중복 허용 (의미 있음).
18. **감사 로그**: 그룹 생성·수정·삭제·멤버 추가·제거 모두 SCR-097에 기록. `family_id`, `member_id`, `relation`, `actor_id` 저장.
19. **세그먼트 연계 (MBR-09)**: 가족 그룹을 조건으로 세그먼트 생성 가능 (예: "활성 가족 회원 3명 이상 그룹").
20. **마케팅 발송 시 가족 묶음**: 메시지 발송 시 가족 그룹 1명에게만 발송 옵션 (중복 발송 방지).
21. **결제 단위 가족 결제**: 가족 그룹 결제 (한 멤버가 전체 결제) 시 결제 이력은 결제자에게, 이용권은 각 회원에게 부여.
22. **그룹 분리 시 데이터 무결성**: 가족 마일리지 합산 사용 후 분리되면 회원별 마일리지로 자동 재산정 안 됨, 운영자가 별도 조정 필요.
