## 기능 목적

동일 가족 구성원인 회원들을 서로 연결하여 가족 단위로 관리하는 화면이다. 가족 회원 연결을 통해 패밀리 이용권 혜택 적용, 가족 단위 결제 현황 파악, 특정 가족 묶음 대상 마케팅 등을 지원한다. 가족 관계를 직관적으로 파악하고 구성원 추가·제거를 간단하게 처리한다.

## 주요 구성요소

### 가족 그룹 목록

등록된 가족 그룹을 카드 형태로 표시. 각 카드에 그룹 이름(예: "김씨 가족"), 구성원 수, 대표 회원 이름.

### 가족 그룹 상세

그룹 클릭 시 구성원 목록 펼침: 이름·관계·이용권 상태·최근 방문일.

### 구성원 추가 (DLG-M029)

기존 회원 검색 + 그룹 추가 + 관계 선택 (부모/자녀/배우자/형제/기타).

### 가족 그룹 생성

새 그룹 생성 버튼. 그룹 이름 + 최초 구성원 추가.

### 구성원 제거

특정 구성원을 그룹에서 분리. 분리 후 회원 데이터는 유지.

### 가족 단위 요약 정보

- 가족 전체 이용권 현황
- 활성 회원 수
- 총 마일리지 합산

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 가족 그룹 | 그룹 생성·수정·삭제, 구성원 추가·제거 |
| 센터장 (owner) | 소속 지점 가족 그룹 | 그룹 생성·수정·삭제, 구성원 추가·제거 |
| 매니저 | 소속 지점 가족 그룹 | 구성원 추가·제거 |
| FC | 담당 회원 포함 가족 그룹 조회 | 조회만 |
| 트레이너 / 스태프 / 프런트 | 접근 불가 또는 조회만 | 수정 불가 |

## 주요 UX 흐름

1. 사이드바 "회원관리 > 가족 회원" 또는 회원 상세 관련 메뉴 진입
2. 기존 가족 그룹 목록 확인 또는 [새 그룹 만들기]
3. 그룹에 구성원 추가 (회원 검색 + 관계 선택, DLG-M029)
4. 특정 구성원 제거 또는 그룹 자체 삭제
5. 그룹 카드 클릭 → 구성원 전체 이용 현황 확인

## 화면 상태

| 상태 | 설명 |
|---|---|
| 그룹 없음 | "가족 그룹이 없습니다" + 그룹 생성 버튼 |
| 그룹 목록 | 카드 목록 표시 |
| 구성원 상세 | 그룹 선택 후 구성원 목록 + 이용 현황 |
| 구성원 추가 중 | 회원 검색 + 관계 선택 |
| 처리 중 | 로딩 표시 |

## 비즈니스 규칙

1. 한 회원은 여러 가족 그룹에 속할 수 없다.
2. 그룹 삭제 시 구성원 회원 데이터는 그대로 유지된다.
3. 가족 단위 요약(마일리지/이용권)은 실시간 합산.
4. FC는 담당 회원이 포함된 그룹만 조회 가능.
5. 가족 할인은 별도 정책(상품 관리 / 마케팅)에서 정의.
