## 기능 목적

특정 회원의 모든 정보를 하나의 화면에서 15개 탭(회원정보/이용권/출석이력/결제이력/결제내역/예약내역/상세내역/체성분/상담메모/레슨/신체정보/종합평가/상담이력/운동프로그램/운동이력)으로 구분해 조회·관리한다. 프로필 헤더에 핵심 요약과 6개 액션(수동출석/수정/구매/메시지/이관/탈퇴)을 고정 노출하며, 만료 정책 결과·홀딩·탈퇴·삭제·복구도 한 화면에서 처리한다.

## 주요 UX 흐름

1. SCR-M001 → 회원명 클릭 → SCR-M004 진입
2. 헤더 요약 + 6액션 즉시 사용
3. 15개 탭 클릭으로 상세 정보 확인
4. 홀딩 / 탈퇴 / 삭제 처리

## 화면 상태

| 상태 | 표시 |
|------|------|
| 정상 활성 | 모든 탭 + 헤더 액션 |
| 만료 D-day | 알림 배너 강조 |
| 홀딩 중 | 헤더 "홀딩" 칩 |
| 탈퇴 처리됨 | 비활성 표시 |
| 권한 부족 | 일부 탭/액션 hidden |

## 비즈니스 규칙

1. 만료 알림 배너는 본사 정책 세트 결과가 있는 경우에만 표시한다.
2. 홀딩 처리 시 만료일이 홀딩 일수만큼 자동 연장된다.
3. 탈퇴는 status=WITHDRAWN으로 변경하며 데이터는 보존된다.
4. 삭제는 논리적 삭제(soft delete)이며 회원 목록에서 보이지 않는다.
5. 회원 복구는 센터장·매니저·슈퍼관리자에 한정한다 (DLG-M005).
6. 레슨 탭 데이터는 모바일 레슨 완료/서명과 동일 레코드를 공유한다.
