## 기능 목적

회원 등급 체계(브론즈/실버/골드/플래티넘/다이아몬드)의 기준을 설정하고 각 등급별 혜택을 관리하는 화면이다. 누적 결제 금액·이용 기간·방문 횟수 등의 조건으로 등급 산정 기준을 정의하고, 조건을 충족한 회원에게 자동으로 등급을 부여한다. 등급별 차별화된 혜택(마일리지 적립률·할인율·우선 배정·생일 혜택)으로 회원 충성도와 재방문율을 높인다.

## 주요 구성요소

### 등급 목록 패널

현재 설정된 등급(브론즈/실버/골드/플래티넘/다이아몬드)을 순서대로 표시. 각 등급에 해당하는 현재 회원 수.

### 등급 기준 설정

| 항목 | 설명 |
|------|------|
| 기준 항목 | 누적 결제 금액 / 총 이용 기간(개월) / 누적 방문 횟수 (단일 또는 조합) |
| 최솟값 입력 | 각 등급의 최솟값 → 초과 조건으로 자동 계산 |
| 예시 | 골드 = 누적 결제 300만원 + 이용 12개월 |

### 등급별 혜택 설정

| 혜택 | 설정 |
|------|------|
| 마일리지 적립률 | % (예: 실버 1% / 골드 2%) |
| 이용권 할인율 | % |
| 부가 서비스 우선 배정 | 락커·주차 등 |
| 생일 특별 혜택 | 토글 |

### 등급 자동 갱신 주기

월간 / 분기 / 연간 중 선택. 갱신 시 조건 재계산 → 등급 자동 변경.

### 등급별 회원 현황

각 등급에 속한 회원 목록 조회 링크.

### 저장 + 즉시 적용

설정 변경 후 저장. 다음 갱신 주기 또는 즉시 적용 선택.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 브랜드 등급 체계 | 등급 기준·혜택 설정, 갱신 주기 변경 |
| 센터장 (owner) | 소속 지점 등급 체계 | 등급 기준·혜택 설정 |
| 매니저 | 소속 지점 등급 현황 조회 | 조회만 (수정 불가) |
| FC / 트레이너 / 스태프 / 프런트 | 접근 불가 | 이 화면 진입 차단 |

## 주요 UX 흐름

1. 사이드바 "회원관리 > 등급 관리" 진입
2. 현재 설정된 등급 기준과 혜택 확인
3. 등급 조건 수정 (결제 금액·이용 기간·방문 횟수)
4. 등급별 혜택 설정 (마일리지·할인율 등)
5. 갱신 주기 선택 후 저장
6. 변경 즉시 적용 여부 선택 → 반영

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 5등급 + 기준/혜택 표시 |
| 편집 중 | 변경 감지 + 저장 활성 |
| 저장 중 | 로딩 |
| 즉시 적용 중 | 진행률 표시 |
| 권한 부족 | 조회만 |

## 비즈니스 규칙

1. 등급 임계값은 누적 결제 / 이용 기간 / 방문 횟수 단일 또는 조합으로 설정.
2. 갱신 주기는 월간/분기/연간 중 선택, 자동 재계산.
3. 즉시 적용 시 모든 회원 등급 재산정.
4. 매니저는 조회만 가능, 변경은 센터장+.
5. 등급 수동 변경(DLG-M030) 시 사유 기록 필수.
6. 등급별 혜택은 결제(SCR-S003) / 마일리지(SCR-074)와 자동 연동.
