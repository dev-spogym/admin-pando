## 기능 목적

센터에 등록된 전체 회원을 한눈에 조회하고, 다양한 조건으로 원하는 회원을 찾아 상세 페이지로 이동하거나 일괄 작업을 수행하는 회원관리 도메인의 핵심 허브 화면이다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우 모든 지점 회원이 조회되며, 각 회원의 소속 지점이 목록과 엑셀 내보내기에 표시된다. FC는 오늘 만료 예정 회원을 검색해 리텐션 상담을 진행하고, 매니저는 장기 미방문 회원에게 메시지를 발송하며, 센터장은 전체 회원 데이터를 엑셀로 내려받아 분석에 활용한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 전체 회원 수 | 등록된 모든 회원 카운트 | 카드 클릭 → 전체 필터 |
| 활성 회원 수 | status=active 카운트 | 활성 필터 자동 적용 |
| 정책상 조치 대상 | 본사 정책 세트 step 결과 대상 | 해당 회원만 표시 |
| 이번 달 만료 수 | 당월 만료 회원 카운트 | 만료 임박 필터 |

### 메인 탭 + 상태 필터

- **메인 탭**: 회원 전체 / 보유상품별 / 이용권 목록
- **상태 필터 탭** (회원 전체 탭 내부): 전체 / 활성 / 만료 / 미등록 / 홀딩 / 정지 + 건수 배지

### 검색 및 필터 바

- **통합 검색**: 이름·연락처
- **기본 필터**: 계약상품, 성별, 최종만료일 범위, 최근방문일 범위
- **추가 필터**: 관심회원, 미방문 기간, 회원구분, 유입경로, 만료 숨기기

### 일괄 작업 바

회원을 1명 이상 선택 시 하단에 자동 노출.

| 버튼 | 동작 | 권한 |
|------|------|------|
| 상태 변경 | DLG-M001 → 일괄 상태 전환 | manager+ |
| 메시지 전송 | SCR-071 진입 | fc+ |
| 출석 처리 | DLG-M022 → 수동 출석 | staff+ |
| 관심회원 등록 | 별표 일괄 등록 | fc+ |
| 지점이관 | 1명 선택 시만, SCR-M005 진입 | owner+ |

### 회원 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 별표 | 관심회원 즐겨찾기 토글 |
| 상태 배지 | 활성/만료/홀딩/정지 색상 분기 |
| 세그먼트 배지 | 신규/이탈위험/만료임박/충성/활발 등 7종 |
| 회원명 | 클릭 시 SCR-M004 상세 진입 |
| 소속 지점 | 본사 통합 모드 노출 |
| 성별 | M/F |
| 생년월일 | YYYY-MM-DD |
| 연락처 | 010 자동 포맷 |
| 이용권 | 보유 이용권 요약 |
| 만료일 | YYYY-MM-DD + D-day |
| 등록일 | YYYY-MM-DD |
| 이관 | [이관] 버튼 (SCR-M005 진입) |

### 페이지네이션 / 엑셀 / 등록

- 한 페이지 20/50/100건 선택, 페이지 번호 이동
- [엑셀 내보내기]: 현재 필터 적용 전체 데이터 다운로드
- [회원 추가] → SCR-M002 진입

### 삭제·탈퇴 회원 보기 토글 + 복구

- 헤더 토글 활성화 → 삭제·탈퇴 회원 별도 섹션/탭 표시
- 회원 행 [복구] 버튼 → DLG-M005 역연계 → status=active 복원
- 권한: 센터장·매니저·슈퍼관리자

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 브랜드·모든 지점 회원 / 지점 전환 / 소속 지점 컬럼 | 엑셀, 회원 추가, 상태 변경, 지점 이관 등 모든 기능 |
| 센터장 (owner) | 소속 브랜드 지점 회원 전체 | 엑셀, 회원 추가, 상태 변경, 삭제 |
| 매니저 (manager) | 소속 지점 회원 전체 | 엑셀, 회원 추가, 상태 변경 (삭제 불가) |
| FC (피트니스코치) | 소속 지점 전체 회원 (담당 회원 우선) | 메시지 전송, 출석 처리, 관심회원 (등록·수정·삭제·엑셀 불가) |
| 트레이너 | 담당 회원만 | 조회만 (별도 캘린더 화면 우선) |
| 스태프 | 소속 지점 회원 전체 | 회원 추가, 출석 처리, 관심회원 (삭제·엑셀 불가) |
| 프런트 | 소속 지점 회원 전체 | 조회 + 출석 처리만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 "회원 관리 > 회원 목록" 또는 대시보드 지표 카드 클릭으로 진입
2. 요약 지표 카드로 전체 현황 파악, 상태 탭 / 검색·필터 조합
3. 회원명 클릭 → SCR-M004 회원 상세
4. 회원 행 [이관] 또는 단일 선택 후 하단 [지점이관] → SCR-M005
5. 여러 회원 체크박스 선택 → 하단 일괄 작업 바 → 상태/메시지/출석 일괄 처리
6. 우측 상단 [회원 추가] → SCR-M002

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 테이블 자리 스켈레톤 |
| 정상 목록 | 200 응답 + 회원 1명 이상 |
| 검색 결과 없음 | 필터·검색 0건 → "검색 결과가 없습니다" |
| 전체 회원 없음 | 필터 없이 0건 → "등록된 회원이 없습니다" + 추가 안내 |
| 오류 | 서버/네트워크 오류 → 다시 시도 버튼 |
| 접근 불가 | 권한 없는 계정 → 접근 제한 안내 |
| 일괄 작업 진행 중 | 테이블 유지 + 진행 스피너 |
| 삭제·탈퇴 보기 활성 | 별도 섹션 + [복구] 버튼 노출 |

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 출석은 회원 실제 소속 지점(`branchId`) 기준으로 처리한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는다.
3. 모든 회원은 유효한 `branchId`를 가져야 하며, 미설정 시 목록에 표시되지 않는다.
4. 세그먼트는 7종 중 하나로 자동 분류되며, 우선순위 판정에 따라 단일 라벨이 부여된다.
5. 관심회원 필터는 다른 필터와 동시 적용된다.
6. 만료 숨기기 토글이 ON이면 만료 회원은 목록에서 제외된다.
7. 삭제·탈퇴 회원은 기본적으로 목록에서 hidden, 토글 ON 시 별도 섹션 표시.
8. 회원 복구는 센터장·매니저·슈퍼관리자에 한정한다.
