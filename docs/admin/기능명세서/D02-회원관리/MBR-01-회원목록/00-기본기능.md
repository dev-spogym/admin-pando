## 기능 목적

센터에 등록된 전체 회원을 한눈에 조회하고, 필터·검색·정렬을 통해 원하는 회원을 빠르게 찾는다. 본사 통합 모드에서는 전 지점 회원이 합산 조회되며 각 회원의 소속 지점이 함께 표시된다. 목록에서 바로 출석 처리, 메시지 발송, 상태 변경, 관심회원 지정 등의 일괄 작업이 가능하고, 세그먼트 자동 분류 결과(신규/이탈위험/만료임박 등)가 회원별로 표시된다. 삭제·탈퇴 회원 보기 토글로 복구 진입도 지원한다.

## 주요 UX 흐름

1. 사이드바 → 회원관리 → 회원 목록 (`/members`)
2. 4종 요약 카드로 현황 파악 → 카드 클릭 시 상태 필터 자동 적용
3. 메인 탭 / 서브탭 / 검색 / 다중 필터 조합
4. 회원명 클릭 → MBR-03 상세 진입
5. 행별 [이관] 또는 단일 선택 → MBR-04 진입
6. 다중 체크박스 → 일괄 작업 바 활성

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 출석은 회원 실제 소속 지점(`branchId`)을 사용한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는다.
3. 모든 회원은 유효한 `branchId`를 가져야 하며, 지점명이 목록에 표시되어야 한다.
4. 세그먼트는 7종 중 1개로 자동 분류된다 (우선순위 판정).
5. 관심회원 필터는 다른 필터와 동시 적용된다.
