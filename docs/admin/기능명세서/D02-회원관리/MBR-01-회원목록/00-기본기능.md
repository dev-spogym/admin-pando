## 기능 목적

센터에 등록된 전체 회원을 한눈에 조회하고, 다양한 조건으로 원하는 회원을 찾아 상세 페이지로 이동하거나 일괄 작업을 수행하는 회원관리 도메인의 핵심 허브 화면이다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우 모든 지점 회원이 조회되며, 각 회원의 소속 지점이 목록과 엑셀 내보내기에 표시된다. FC는 오늘 만료 예정 회원을 검색해 리텐션 상담을 진행하고, 매니저는 장기 미방문 회원에게 메시지를 발송하며, 센터장은 전체 회원 데이터를 엑셀로 내려받아 분석에 활용한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 전체 회원 수 | 등록된 모든 회원 카운트 | 카드 클릭 → 전체 필터 |
| 활성 회원 수 | status=active 카운트 | 활성 필터 자동 적용 |
| 정책상 조치 대상 | HQ-09 회원 이용권 만료 본사 step 및 지점 추가 step 중 해당 지점 ON 상태인 대상 | 해당 회원만 표시 |
| 이번 달 만료 수 | 당월 만료 회원 카운트 | 만료 임박 필터 |

### 메인 탭 + 상태 필터

- **메인 탭**: 회원 전체 / 보유상품별 / 이용권 목록
- **상태 필터 탭** (회원 전체 탭 내부): 전체 / 활성 / 만료 / 미등록 / 홀딩 / 정지 + 건수 배지

### 검색 및 필터 바

- **통합 검색**: 이름·연락처
- **기본 필터**: 계약상품, 성별, 최종만료일 범위, 최근방문일 범위
- **추가 필터**: 관심회원, 미방문 기간, 회원구분, 유입경로, 만료 숨기기

### 일괄 작업 바

회원을 1명 이상 선택 시 하단에 자동 노출.

| 버튼 | 동작 | 권한 |
|------|------|------|
| 상태 변경 | DLG-M001 → 일괄 상태 전환 | manager+ |
| 메시지 전송 | SCR-071 진입 | fc+ |
| 출석 처리 | DLG-M022 → 수동 출석 | staff+ |
| 관심회원 등록 | 별표 일괄 등록 | fc+ |
| 일괄 탈퇴 | DLG-M005 → 처리 가능 회원만 status=WITHDRAWN | owner+ |
| 지점이관 | 1명 선택 시만, SCR-M005 진입 | owner+ |

### 페이지네이션 / 엑셀 / 등록

- 한 페이지 20/50/100건 선택, 페이지 번호 이동
- [엑셀 내보내기]: 현재 필터 적용 전체 데이터 다운로드
- [회원 추가] → SCR-M002 진입

### 삭제·탈퇴 회원 보기 토글 + 복구

- 헤더 토글 활성화 → 삭제·탈퇴 회원 별도 섹션/탭 표시
- 회원 행 [복구] 버튼 → DLG-M005 역연계 → status=active 복원
- 권한: 센터장·매니저·슈퍼관리자

| 페르소나 | 사용 맥락 (트리거) | 행동 | 기대 결과 |

| FC (피트니스코치) | 매일 오전 출근 직후, 지점에서 ON 상태인 회원 이용권 만료 step 대상 리텐션 콜 리스트 작성 | HQ-09 회원 이용권 만료 본사 step/지점 추가 step 결과 + 해당 지점 ON 상태 + 활성 상태 필터 + 미방문 7일+ 추가 | 콜 리스트 30~50명 확보 → 메시지 일괄 발송 또는 상담 등록(MBR-02 → DLG-M011) |

| 센터장 (owner) | 분기 KPI 보고 — 신규/재계약/이탈/등급 분포 분석 | [엑셀 내보내기] 전체 다운로드 → 외부 BI 도구 분석 | 세그먼트·등급·만료일·결제경로 컬럼 포함 CSV 확보, PII는 X11 정책에 따라 마스킹 또는 권한 검증 후 원본 제공 |
| 본사 최고관리자 | 통합 모드에서 전 지점 활성률·만료 임박률 비교 | 본사 통합 토글 ON → 정책상 조치 대상 카드 클릭 → 지점별 그루핑 | 지점간 격차 파악 후 HQ-09 회원 이용권 만료 본사 step 조정 또는 지점장 ON/OFF·지점 추가 step 운영 가이드 |

| 트레이너 | 본인 담당 회원 캘린더 진입 전 컨디션 확인 | 담당 회원만 자동 필터 + 관심회원 토글 | 담당 회원 외 데이터 미노출 (RLS 적용) |

## 주요 UX 흐름

### 정상 진입 흐름
1. 사이드바 "회원 관리 > 회원 목록" 또는 대시보드 지표 카드 클릭으로 진입
2. 요약 지표 카드로 전체 현황 파악, 상태 탭 / 검색·필터 조합 (필터는 URL 쿼리 파라미터로 보존되어 새로고침/북마크/공유 가능)
3. 회원명 클릭 → SCR-M004 회원 상세
4. 회원 행 [이관] 또는 단일 선택 후 하단 [지점이관] → SCR-M005
5. 여러 회원 체크박스 선택 → 하단 일괄 작업 바 → 상태/메시지/출석/탈퇴 일괄 처리
6. 우측 상단 [회원 추가] → SCR-M002

### 분기·예외 흐름
- **일괄 처리 부분 실패**: 100명 일괄 상태 변경 시 일부 회원이 권한·상태 잠금 등으로 실패하면, 전체 롤백 없이 성공/실패 회원 목록을 결과 토스트 + 다운로드 가능한 실패 리포트(.csv)로 분리 표시
- **일괄 탈퇴 부분 실패**: 미수금, 환불 필요 이용권, 진행 예약, 가족 대표 회원, 이미 탈퇴·삭제된 회원은 탈퇴 처리에서 제외하고 실패 리포트에 사유를 표시한다. 처리 가능 회원은 전체 롤백 없이 status=WITHDRAWN으로 변경한다.
- **본사 통합 모드 일괄 출석**: 회원의 실제 `branchId` 기준으로 출석 기록이 분산 저장되며, 처리 결과는 지점별 그루핑된 요약을 제공
- **엑셀 내보내기 도중 페이지 이탈**: 내보내기 작업은 백그라운드로 분리되어 진행, 완료 시 알림 센터(NFR-19)에 다운로드 링크 push
- **이관 버튼 클릭 후 회원 상태 변경 감지**: 이관 화면 진입 직전 다른 사용자가 해당 회원을 탈퇴/삭제 처리한 경우, SCR-M005 진입 시 stale 데이터 경고 + 목록 재진입 안내
- **삭제·탈퇴 회원 복구 시 동명이인 충돌**: 동일 연락처가 신규 회원으로 재등록된 경우, 복구 시 DLG-M006 흐름과 동일한 중복 안내 후 관리자가 강제 복구/취소 결정

| 일괄 작업 진행 중 | 테이블 유지 + 진행 스피너 |
| 일괄 탈퇴 확인 중 | DLG-M005에서 선택 회원 요약·차단 대상·확인 문구 입력 표시 |
| 삭제·탈퇴 보기 활성 | 별도 섹션 + [복구] 버튼 노출 |

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 출석은 회원 실제 소속 지점(`branchId`) 기준으로 처리한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는다. 단, FC·트레이너·스태프·스태프 권한은 다운로드 자체가 차단되며, 통합 모드 다운로드는 본사 권한자만 허용한다.
3. 모든 회원은 유효한 `branchId`를 가져야 하며, 미설정 시 목록에 표시되지 않고 시스템 점검 알림 대상에 포함된다.
4. 세그먼트는 자동 분류된다. 기본 자동 라벨은 우선순위 판정(이탈위험 > 만료임박 > 신규 > 활발 > 관심필요 > 만료후미등록)에 따라 1개만 부여하고, 충성 조건을 만족하면 다른 기본 라벨과 함께 보조 라벨로 추가 표시한다.
5. 관심회원 필터는 다른 필터와 동시 적용되며, 즐겨찾기 토글은 사용자 단위로 저장(`user_favorites`)되어 다른 운영자에게 영향을 주지 않는다.
6. 만료 숨기기 토글이 ON이면 만료 회원은 목록에서 제외된다. 단, 상태 필터에서 "만료"를 명시적으로 선택한 경우는 토글과 무관하게 표시한다.
7. 삭제·탈퇴 회원은 기본적으로 목록에서 hidden, 토글 ON 시 별도 섹션 표시. PII 마스킹 정책(X11)에 따라 90일 경과 데이터는 이름·연락처가 마스킹된 상태로만 노출된다.
8. 회원 복구는 센터장·매니저·슈퍼관리자에 한정한다. 복구 시 동일 연락처의 신규 회원이 존재하면 DLG-M006 형태의 충돌 경고를 노출한다.
9. **동시성 제어**: 동일 회원에 대한 일괄 상태 변경 또는 일괄 탈퇴가 두 운영자에게서 동시에 발생할 경우, optimistic lock(`version` 컬럼) 기반으로 후행 요청은 409 Conflict로 거부되며 실패 리포트에 사유 표기.
10. **권한 충돌 시 처리**: 일괄 작업 대상 100명 중 권한 부족 회원이 섞인 경우(예: FC가 다른 FC 담당 회원 포함), 권한 가능한 회원만 처리하고 나머지는 실패 리포트로 분리.
11. **세그먼트 재계산 지연**: 세그먼트 라벨은 D+1 배치(NFR-05)로 갱신되므로, 회원 상태 변경 직후 일시적으로 라벨과 실제 상태가 불일치할 수 있음 — 회원 상세 진입 시 실시간 재판정.
12. **검색 디바운스 + 입력 길이 제한**: 통합 검색은 300ms 디바운스, 최소 2자부터 검색, 최대 50자 입력 제한.
13. **본사 통합 모드 + 지점 이관**: 일괄 작업의 [지점이관]은 1명 선택 시에만 활성, 통합 모드에서도 회원의 실제 `branchId`가 원 지점으로 기록(SCR-M005 규칙과 동일).
14. **감사 로그**: 일괄 상태 변경/메시지 발송/출석 처리/복구/일괄 탈퇴는 모두 SCR-097 히스토리 로그에 `actor_id`, `member_ids[]`, `action`, `before/after`, `reason` 필드로 기록.
15. **일괄 탈퇴 제한**: owner+만 가능하며 1회 최대 100명까지 처리한다. 미수금·환불 필요 이용권·진행 예약·가족 대표 회원은 차단하고 사전 정리 후 재시도하도록 안내한다.
16. **정책상 조치 대상 산정**: 정책상 조치 대상 카드와 만료 임박 필터는 HQ-09에서 본사가 배포한 회원 이용권 만료 기준일 step 결과와 해당 지점의 센터장(owner)이 추가한 회원 이용권 만료 지점 step 결과 중 SCR-072에서 ON으로 둔 step만 포함한다. 지점이 OFF한 step은 목록 카드·필터·일괄 메시지 추천 대상에서 제외한다.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 네트워크 오류 (5xx / timeout) | "데이터를 불러오지 못했어요" 토스트 + [다시 시도] 버튼 | 자동 재시도 1회 후 사용자 액션 대기 |
| 권한 없는 계정 진입 | 접근 제한 화면 + 사이드바 비노출 | 대시보드로 자동 이동 (3초) |
| 일괄 작업 부분 실패 | 성공 N / 실패 M 결과 카드 + 실패 리포트 다운로드 링크 | 실패 회원 ID·사유 CSV 제공 |
| 일괄 작업 전체 실패 | 빨강 토스트 + 트랜잭션 롤백 안내 | 변경 없음, 재시도 또는 개별 처리 안내 |
| 일괄 탈퇴 차단 대상 포함 | DLG-M005에 처리 가능/차단 인원 분리 표시 | 처리 가능 회원만 진행하거나 취소 후 대상 재선택 |
| 동일 회원 동시 편집 (optimistic lock 위반) | "다른 운영자가 동시에 편집했어요" 모달 | 최신 데이터 새로고침 후 재시도 |
| 엑셀 다운로드 권한 부족 | 버튼 자체 hidden | - |
| 엑셀 다운로드 데이터 50,000건 초과 | "데이터가 너무 많아요. 필터를 좁혀주세요" | 필터 좁힘 안내 |
| 일괄 메시지 발송 시 알림톡 비친구/실패 처리 | 비친구·실패 대상은 제외/실패 카운트로 표시, SMS 자동 전환 없음 (NFR-19) | 발송 결과 채널별 표시 |
| 본사 통합 모드 RLS 누락 | 빈 목록 표시 (보안) | 슈퍼관리자에게만 디버그 로그 공개 |
| 출석 처리 시 영업시간 외 | "영업시간 외 처리는 본사 정책으로 차단되었습니다" 안내 | 사유 입력 모달 → 슈퍼관리자 승인 후 강제 처리 |
| 복구 시 연락처 충돌 | "동일 연락처 신규 회원이 있어요" 모달 | 강제 복구(부 계정으로) / 취소 / 회원 병합 진입 선택지 |
| 삭제·탈퇴 회원 PII 90일 경과 | 이름·연락처 마스킹 표시 | 본사 권한자에 한해 X11 정책 사유 입력 시 일시 해제 |

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-M001`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-M001 상태변경, DLG-M005 탈퇴/복구, DLG-M022 수동출석, DLG-M023 이관확인`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 표와 아래 API 기준을 같이 적용합니다.

- **연계 화면**: SCR-M001 (메인) / SCR-M002 등록 / SCR-M004 상세 / SCR-M005 이관 / SCR-071 메시지 / SCR-097 히스토리 로그
- **연계 다이얼로그**: DLG-M001 / DLG-M005 / DLG-M022 / DLG-M023
- **API 기준**: `GET /api/members` / `POST /api/members/bulk-action` / `GET /api/members/export` / `POST /api/members/:id/restore` / `GET /api/members/segments/recalc-status`
