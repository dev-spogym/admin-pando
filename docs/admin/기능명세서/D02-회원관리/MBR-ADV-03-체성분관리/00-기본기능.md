## 기능 목적

특정 회원의 체성분(체중·골격근량·체지방률·BMI·기초대사량·체지방량·체수분) 변화 추이를 시계열 그래프와 측정 기록 표로 시각화하는 화면(SCR-M006)이다. 트레이너와 FC가 회원의 운동·영양 개선 효과를 판정하고, 재상담 또는 재계약의 근거 자료로 활용한다. InBody 장비 자동 수집과 운영자 수동 입력을 모두 지원하며, 측정 결과는 회원 상세(SCR-M004)의 체성분 탭과 동일 데이터 소스(`body_composition`)를 공유한다.

운영 맥락:
- **트레이너가 PT 세션 직전 컨디션 체크**: 최신 측정값 + 이전 대비 변화 방향(긍정/부정 색상)으로 운동 강도 즉시 조정
- **FC가 재계약 상담 시**: 추이 그래프로 회원의 개선 효과(체중 감소·근육량 증가·체지방률 감소)를 시각적 근거로 제시
- **회원 본인이 모바일 앱에서 자가 입력**: 운영자 화면과 동일 데이터 소스 공유, 자가 입력 분은 `source=self`로 구분 표시
- **목표 설정 (DLG-M017)**: 시작 체성분 + 목표 체성분 + 기간 입력 → 그래프에 목표선 overlay
- **InBody 장비 자동 연동**: 회원 카드 태그 → 측정 → 자동 INSERT, 동일 일자 측정 시 DLG-M016 덮어쓰기 안내
- **분기 종합평가(DLG-M024) 입력 시 참고 자료**: 체성분 추이를 5점 척도 평가의 근거로 활용

### 변화 추이 차트

체중 / 골격근량 / 체지방률 3개 지표 라인 차트. 지표별 표시/숨김 토글, 마우스 호버 시 툴팁 표시.

| 컬럼 |
|------|

### 측정 추가 (DLG-M015)

| 항목 | 입력 | 검증 |
|------|------|------|
| 측정일 | 캘린더 | 미래 차단 |
| 체중 | 숫자 | 20~300kg |
| 골격근량 | 숫자 | 5~80kg |
| 체지방률 | 숫자 | 3~60% |

### 추이 분석 탭 (선택)

## 주요 UX 흐름

### 정상 측정 추가 흐름
1. 사이드바 "회원관리 > 체성분 관리" 또는 SCR-M004 체성분 탭에서 진입
2. 대상 회원 선택 (회원 상세에서 진입 시 자동 선택)
3. 요약 카드 (체중·골격근량·체지방률·BMI) + 변화 방향 표시 + 추이 그래프 + 측정 기록 테이블 노출
4. [측정 추가] 클릭 → DLG-M015 → 측정일·체중·골격근량·체지방률·체수분 입력
5. BMI / 체지방량 / 기초대사량 자동 계산 (회원 키·나이 기반)
6. [저장] → 동일 일자 데이터 없으면 즉시 INSERT, 있으면 DLG-M016 덮어쓰기 확인
7. 차트·테이블·요약 카드 즉시 반영, 추이 그래프는 데이터 2건부터 표시

### 분기·예외 흐름
- **회원 키·나이 미등록**: BMI/BMR 계산 불가 → 측정 자체는 가능하나 자동 계산 필드는 "키 정보 필요" 표시 + MBR-03 회원 정보 입력 안내
- **측정값 범위 초과** (체중 < 20 또는 > 300, 골격근량 < 5 또는 > 80, 체지방률 < 3 또는 > 60): 인라인 에러 + 저장 차단
- **측정일 미래 날짜**: 캘린더에서 미래 비활성, 직접 입력 시 422
- **동일 일자 충돌**: DLG-M016 → [덮어쓰기] / [취소] / [기존 유지하고 시간만 다르게] 3선택지
- **측정 기록 0건**: "측정 기록이 없어요" 빈 상태 + [첫 측정 등록하기] CTA, 그래프 영역에 안내 메시지
- **측정 기록 1건**: 그래프 hidden + "2건부터 추이가 표시됩니다" 안내, 테이블만 노출
- **모든 지표 토글 OFF**: 그래프 영역에 "지표를 1개 이상 선택해주세요" 표시 (최소 1개 필수)
- **InBody 장비 측정값 자동 수집**: 외부 API 응답 → 자동 INSERT, `source=device` 라벨 표시
- **회원 본인 자가 입력**: 모바일 앱 PUT → `source=self` 라벨, 운영자 수정 시 `source` 변경 안 함 (이력 추적)
- **본인 등록 24시간 내 수정 (FC/트레이너)**: 본인 작성 + 24시간 내만 수정 가능, 그 이후는 매니저+ 권한 필요
- **삭제 권한**: FC·트레이너는 삭제 불가, 매니저+만 삭제 가능 (소프트 삭제, 복구 불가)
- **CSV 내보내기 권한**: FC·트레이너는 내보내기 불가, 매니저+만 가능
- **동시 측정 추가**: 2명의 운영자가 동시에 동일 일자 측정 추가 → optimistic lock, 후행 요청 409 + 덮어쓰기 안내

## 비즈니스 규칙

1. 체중은 20~300kg, 골격근량은 5~80kg, 체지방률은 3~60% 범위만 입력 가능. 범위 외 입력 시 422.
2. BMI는 체중과 키를 기반으로 자동 계산 (BMI = 체중(kg) / (키(m))²). 키는 MBR-03 회원정보 필드.
3. 기초대사량(BMR)은 체중·키·나이·성별 기반 Mifflin-St Jeor 공식으로 자동 계산. 성별 미입력 시 계산 불가.
4. 체지방량 자동 계산 = 체중 × (체지방률 / 100).
5. 측정 데이터가 2건 미만이면 차트는 표시되지 않는다 (단일 점은 추이가 아님).
6. 동일 일자 측정값 입력 시 DLG-M016 덮어쓰기 확인. 덮어쓰기 시 기존 레코드는 삭제 처리(이력 보존 안 함).
7. 측정 일자는 미래 날짜 차단. 과거 90일 이전 입력은 권한자(매니저+) 사유 입력 시 가능.
8. **데이터 출처 구분**: `source` 필드로 운영자 입력 / InBody 장비 / 회원 자가 입력 구분. UI에서 라벨 표시.
9. **변화 방향 색상**: 체중·체지방률 감소는 긍정(초록), 증가는 부정(빨강). 골격근량 증가는 긍정(초록), 감소는 부정(빨강). 측정 기록 1건만 있으면 변화량 미표시.
10. **수정 권한 + 시간 제한**: FC/트레이너는 본인 등록 + 24시간 이내만 수정 가능. 매니저+는 시간 제한 없음.
11. **삭제 권한**: 매니저+만 삭제 가능. 삭제는 소프트 삭제 아닌 hard delete (체성분 데이터는 복구 의미 없음, 단 삭제 이력은 SCR-097 로그).
12. **CSV 내보내기 권한**: 매니저+만 가능. CSV에 `source` 컬럼 포함.
13. **InBody 자동 연동**: 외부 장비 API → 회원 카드 매칭 → 자동 INSERT. 매칭 실패 시 운영자 수동 매칭 큐에 적재.
14. **회원 자가 입력 동기화**: 모바일 앱에서 입력한 측정값은 운영자 화면에서 즉시 조회 가능. 자가 입력 분도 동일 일자 충돌 시 덮어쓰기 정책 적용.
15. **목표 설정 (DLG-M017)**: 회원당 활성 목표 1개. 새 목표 등록 시 기존 활성 목표 자동 종료(`status=replaced`).
16. **목표선 그래프 overlay**: 활성 목표가 있으면 그래프에 시작점·목표점 잇는 직선 + 진행률 표시. 목표 미설정 시 표시 안 함.
17. **측정 결과 알림**: 회원이 동의한 경우 측정 완료 후 카카오 알림톡으로 결과 카드 발송 (모바일 앱에서 동의 토글).
18. **체성분 탭 동기화 (MBR-02-11)**: SCR-M004 회원 상세의 체성분 탭은 본 화면과 동일 데이터 소스 공유. 한쪽 변경 시 다른 쪽도 즉시 반영.
19. **종합평가 (DLG-M024) 연계**: 분기 종합평가 입력 시 직전 분기 체성분 추이를 자동 표시하여 평가 근거로 사용.
20. **본사 통합 모드 (SCR-I006)**: 본사 권한자는 전 지점 회원의 체성분 통계 비교 가능. 단, 개별 측정 데이터는 RLS로 제어.
21. **개인정보 보호**: 체성분 데이터는 민감 건강정보. CSV 내보내기 시 비식별 옵션(이름→이니셜) 제공.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-M006`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-M015 체성분등록, DLG-M016 체성분덮어쓰기, DLG-M017 목표설정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 표와 아래 API 기준을 같이 적용합니다.

- **연계 화면**: SCR-M004 (체성분 탭) / SCR-I006 통합 체성분 / SCR-I007 회원 건강 연동 / SCR-097
- **연계 다이얼로그**: DLG-M015 측정등록 / DLG-M016 덮어쓰기 / DLG-M017 목표설정 / DLG-M024 종합평가
- **API 기준**: `GET /api/body-composition/:memberId` / `POST /api/body-composition` / `PUT /api/body-composition/:id` / `DELETE /api/body-composition/:id` / `POST /api/body-composition/goal` / `POST /api/inbody/sync` / `GET /api/body-composition/export.csv`
