## 기능 목적

회원 등급 체계(브론즈/실버/골드/플래티넘/다이아몬드 5단계)의 기준을 설정하고 각 등급별 혜택을 관리하는 화면(SCR-M009)이다. 누적 결제 금액·이용 기간·방문 횟수 등의 조건으로 등급 산정 기준을 정의하고, 조건을 충족한 회원에게 자동으로 등급을 부여한다. 등급별 차별화된 혜택(마일리지 적립률·이용권 할인율·우선 배정·생일 혜택)으로 회원 충성도와 재방문율을 높이며, 결제(SCR-S003)·마일리지(SCR-074)·예약 시스템과 자동 연동되어 등급 혜택이 즉시 적용된다.

운영 맥락:
- **본사 최고관리자가 분기 등급 정책 개편 시**: 등급 기준 임계값 + 혜택 비율 조정 → 즉시 적용 또는 다음 갱신 주기에 반영
- **센터장이 지점 차별화 정책 적용 시**: 본사 정책 위에 지점별 추가 혜택 (예: 지점 한정 락커 우선)
- **회원 본인이 등급 상승 직전 결제 권유**: FC가 회원 상세에서 D-임박 카드 보고 추가 결제 유도
- **등급 자동 갱신 배치 후 회원 알림**: 매월 1일 새벽 04:00 갱신 → 등급 변동 회원에게 카카오 알림톡
- **등급 수동 변경 (DLG-M030)**: 본사 슈퍼관리자가 VIP 케이스 / 클레임 보상으로 강제 부여, 사유 입력 필수
- **회원 병합 (MBR-EXT-01) 시 등급 재산정**: 병합 직후 누적 결제 합산 → 등급 즉시 갱신
- **회원 이관 (MBR-ADV-02) 후 누적 결제 보존**: 이용 기간·방문 횟수·누적 결제 모두 보존, 등급 유지

등급은 회원 상세(SCR-M004) 헤더 배지로 노출되며, 회원 목록(SCR-M001) 컬럼·세그먼트 조건·마케팅 캠페인 조건에서 활용된다.

## 주요 구성요소

### 등급 목록 패널

현재 설정된 등급(브론즈/실버/골드/플래티넘/다이아몬드)을 순서대로 표시. 각 등급에 해당하는 현재 회원 수.

### 등급 기준 설정

| 항목 | 설명 |
|------|------|
| 기준 항목 | 누적 결제 금액 / 총 이용 기간(개월) / 누적 방문 횟수 (단일 또는 조합) |
| 최솟값 입력 | 각 등급의 최솟값 → 초과 조건으로 자동 계산 |
| 예시 | 골드 = 누적 결제 300만원 + 이용 12개월 |

### 등급별 혜택 설정

| 혜택 | 설정 |
|------|------|
| 마일리지 적립률 | % (예: 실버 1% / 골드 2%) |
| 이용권 할인율 | % |
| 부가 서비스 우선 배정 | 락커·주차 등 |
| 생일 특별 혜택 | 토글 |

### 등급 자동 갱신 주기

월간 / 분기 / 연간 중 선택. 갱신 시 조건 재계산 → 등급 자동 변경.

### 등급별 회원 현황

각 등급에 속한 회원 목록 조회 링크.

### 저장 + 즉시 적용

설정 변경 후 저장. 다음 갱신 주기 또는 즉시 적용 선택.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 브랜드 등급 체계 | 등급 기준·혜택 설정, 갱신 주기 변경 |
| 센터장 (owner) | 소속 지점 등급 체계 | 등급 기준·혜택 설정 |

| FC / 트레이너 / 스태프 / 프런트 | 접근 불가 | 이 화면 진입 차단 |

## 주요 UX 흐름

### 정상 정책 수정 흐름
1. 사이드바 "회원관리 > 등급 관리" 진입
2. 현재 설정된 등급 기준과 혜택 + 등급별 회원 수 확인
3. 등급 조건 수정 (누적 결제 금액 / 총 이용 기간(개월) / 누적 방문 횟수 단일 또는 조합)
4. 등급별 혜택 설정 (마일리지 적립률 / 이용권 할인율 / 부가 서비스 우선 배정 / 생일 특별 혜택)
5. 갱신 주기 선택 (월간/분기/연간)
6. [저장] → 변경 즉시 적용 여부 선택 (즉시 / 다음 갱신 주기)
7. 즉시 적용 선택 시 백그라운드 재계산 진행 (대용량은 5~10분 소요), 진행률 표시
8. 완료 후 변동 회원 카운트 + 카카오 알림톡 발송 옵션

### 등급 수동 변경 (DLG-M030) 흐름
1. 등급 관리 → [수동 변경] 또는 회원 상세에서 진입
2. 회원 검색 → 현재 등급 표시
3. 새 등급 선택 + 사유 입력 (필수, 50자 이상 권장)
4. [자동 갱신 보호] 체크 (옵션, 다음 갱신 시 자동 재계산 무시)
5. [실행] → 즉시 반영 + SCR-097 감사 로그 기록

### 분기·예외 흐름
- **임계값이 역전된 경우 (실버 < 브론즈)**: 빨강 인라인 경고 + 저장 차단
- **즉시 적용 시 회원 수 1만명 초과**: "재계산이 5~10분 소요됩니다" 안내 + 백그라운드 처리 + 완료 알림
- **즉시 적용 도중 다른 운영자가 정책 수정**: optimistic lock 위반 → 후행 요청 거부, "다른 운영자가 수정 중" 모달
- **다음 갱신 주기 적용 선택**: 즉시 변동 없음, 다음 배치(NFR-05)에서 일괄 처리
- **회원 등급 수동 변경 후 자동 갱신 보호 OFF**: 다음 자동 갱신 시 정책에 따라 자동 재계산
- **수동 변경 권한 부족**: DLG-M030 자체 hidden
- **등급 갱신 직후 회원 결제 → 등급 상승**: 다음 갱신 주기에 반영 (자동 갱신 주기 + 배치) — 즉시 등급 상승 옵션은 별도 정책
- **이용권 할인율 100% 초과 입력**: 422 + "100% 이하로 입력해주세요"
- **마일리지 적립률 음수 입력**: 422 + "0% 이상으로 입력해주세요"
- **본사 통합 모드에서 지점별 정책 충돌**: 본사 정책 우선, 지점 정책은 추가 혜택만 가능 (감점 차감 불가)
- **회원 병합 시 등급 재산정**: 병합 트랜잭션 내부에서 즉시 처리 (배치 대기 안 함)
- **회원 이관 시 등급 보존**: 등급 유지, 단 새 지점 정책이 다르면 다음 갱신 주기에 재산정

## 비즈니스 규칙

1. 등급 임계값은 누적 결제 금액 / 총 이용 기간(개월) / 누적 방문 횟수 중 단일 또는 조합 설정. 조합 시 AND 매칭(모든 조건 충족).
2. 갱신 주기는 월간 / 분기 / 연간 중 선택, 자동 재계산. 갱신 시점: 매월 1일 04:00 / 분기 첫날 / 연 1월 1일.
3. 즉시 적용 시 모든 회원 등급 재산정. 1만명 이상은 백그라운드 처리 + 완료 알림.
4. 매니저는 조회만 가능, 변경은 센터장+. FC/트레이너/스태프/프런트는 화면 진입 자체 차단.
5. 등급 수동 변경(DLG-M030) 시 사유 기록 필수 (50자 이상 권장). 본사 슈퍼관리자만 가능.
6. 등급별 혜택은 결제(SCR-S003) / 마일리지(SCR-074) / 예약 시스템과 자동 연동.
7. **임계값 정합성**: 상위 등급은 하위 등급보다 모든 임계값이 같거나 커야 함. 역전 시 저장 차단.
8. **혜택 범위**: 마일리지 적립률 0~10%, 이용권 할인율 0~100% 이내. 음수·초과 입력 시 422.
9. **등급 자동 갱신 vs 수동**: 수동 변경 + [자동 갱신 보호] 체크 시 다음 자동 갱신 시 정책 재계산 제외. 보호 만료 시점 설정 가능 (3개월 / 6개월 / 무기한).
10. **등급 강등 정책**: 자동 갱신 시 임계값 미달이면 등급 강등 가능. 단, 강등 회피 정책 토글로 "최고 도달 등급 유지" 활성 가능 (충성도 보호).
11. **신규 회원 기본 등급**: 브론즈 자동 부여. 누적 결제 0원으로 시작.
12. **누적 결제 산정**: 환불 처리 시 환불 금액만큼 누적에서 차감. 양도된 이용권은 양수자 누적에 가산, 양도자에서 차감.
13. **이용 기간 산정**: 등록일부터 현재까지 (탈퇴/홀딩 기간 제외).
14. **방문 횟수 산정**: 출석 처리(수동/자동) 기준. 동일 일자 다중 출석은 1회로 카운트.
15. **회원 이관 시 등급 보존**: 누적 결제·이용 기간·방문 횟수 모두 이전, 등급 유지. 새 지점 정책이 다르면 다음 갱신에 재산정.
16. **회원 병합 (MBR-EXT-01) 시**: 병합 트랜잭션 내부에서 누적 결제 합산 → 등급 즉시 재산정.
17. **본사 통합 모드 정책**: 본사 정책이 우선, 지점은 추가 혜택만 정의 가능 (혜택 차감 불가).
18. **지점별 회원 수 표시**: 본사 모드에서는 지점별로 등급 분포 비교 가능.
19. **혜택 적용 시점**: 등급 변동 즉시 결제·마일리지·예약 시스템에 반영. 캐시 무효화 처리.
20. **알림 정책**: 등급 변동 회원에게 카카오 알림톡(축하 또는 안내) 발송. 옵션으로 비활성화 가능.
21. **감사 로그**: 정책 수정 / 즉시 적용 / 수동 변경 모두 SCR-097에 기록. before/after JSON 형태.
22. **등급별 회원 목록 진입**: 등급 클릭 → SCR-M001 회원 목록 + 등급 필터 자동 적용.
23. **임계값 0 입력 가능**: 브론즈는 임계값 0(누구나 시작 가능). 단, 다른 등급은 0보다 커야 함.
24. **갱신 주기 변경 정책**: 변경 시 즉시 효과는 없고, 다음 주기부터 새 주기 적용.
25. **수동 변경 보호 만료**: 보호 기간 만료 시 자동 재계산 대상에 포함, 변동 시 알림 push.
26. **갱신 진행 중 동시성**: 갱신 배치 실행 중 정책 수정 시도 시 "갱신 진행 중입니다" 모달 + 차단. 완료 후 재시도.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 임계값 역전 (실버 < 브론즈) | 빨강 인라인 + "상위 등급은 하위보다 커야 합니다" | 저장 차단 |
| 마일리지 적립률 10% 초과 | 422 + "10% 이하로 입력해주세요" | 저장 차단 |
| 할인율 100% 초과 | 422 + "100% 이하로 입력해주세요" | 저장 차단 |
| 음수 입력 | 422 + "0 이상 입력해주세요" | 저장 차단 |
| 즉시 적용 회원 수 1만+ | 진행률 표시 + 백그라운드 처리 | 5~10분 소요 안내 + 완료 알림 |
| 즉시 적용 도중 동시 수정 | "다른 운영자가 정책을 수정 중입니다" | 갱신 완료 후 재시도 |
| 매니저 수정 시도 | 입력란 readonly + 저장 버튼 hidden | - |
| 수동 변경 권한 부족 | DLG-M030 진입 차단 | 본사 문의 안내 |
| 수동 변경 사유 50자 미만 | 노랑 경고 (강제 아님) | 진행 가능 |
| 자동 갱신 보호 회원 → 자동 재계산 시도 | 갱신 대상에서 자동 제외 | 보호 만료 시 재포함 |
| 강등 회피 정책 활성 + 임계값 미달 | 등급 유지 (강등 안 함) | 다음 갱신에 다시 검사 |
| 환불 시 누적 차감 후 음수 | 0으로 보정 | 등급 강등 검토 |
| 갱신 배치 진행 중 정책 수정 | "갱신 진행 중입니다. 완료 후 다시 시도해주세요" | 차단 |
| 본사 정책 + 지점 정책 충돌 | 본사 정책 우선, 지점 차감 시도 시 422 | 본사 정책 확인 안내 |
| 회원 알림톡 발송 실패 | 갱신은 성공, 알림 실패 토스트 | 운영자 수동 안내 |
| 외부 결제 시스템 동기화 실패 | 등급 갱신은 성공, 혜택 적용 지연 | 5분 캐시 만료 후 자동 동기화 |
| 등급별 회원 0명 | "회원이 없습니다" 빈 상태 | - |
| 갱신 주기 변경 직후 즉시 효과 기대 | "다음 주기부터 적용됩니다" 안내 | - |
