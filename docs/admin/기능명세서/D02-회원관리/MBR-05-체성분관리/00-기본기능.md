## 기능 목적

특정 회원의 체성분(체중·골격근량·체지방률) 변화를 시계열 차트와 테이블로 추적하는 화면이다. InBody 측정 결과를 정기 입력하여 회원의 목표 달성 여부를 모니터링하며, BMI와 기초대사량(BMR)은 입력값 + 회원 키/나이 기반으로 자동 계산된다.

## 주요 구성요소

### 요약 통계 카드

| 카드 | 표시 |
|------|------|
| 체중 | 최신 측정값 |
| 골격근량 | 최신 측정값 |
| 체지방률 | 최신 측정값 |
| BMI | 자동 계산 |

### 변화 추이 차트

체중 / 골격근량 / 체지방률 3개 지표 라인 차트. 지표별 표시/숨김 토글, 마우스 호버 시 툴팁 표시.

### 측정 기록 테이블

| 컬럼 |
|------|
| 측정일 / 체중 / 골격근량 / 체지방률 / 체지방량 / BMI / 기초대사량 |

### 측정 추가 (DLG-M015)

| 항목 | 입력 | 검증 |
|------|------|------|
| 측정일 | 캘린더 | 미래 차단 |
| 체중 | 숫자 | 20~300kg |
| 골격근량 | 숫자 | 5~80kg |
| 체지방률 | 숫자 | 3~60% |

BMI / 체지방량 / 기초대사량은 자동 계산.

### 추이 분석 탭 (선택)

측정 기록 외 추가 분석 뷰 제공.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 최고관리자 / 센터장 / 매니저 / 피트니스코치 | 전체 화면 | 측정 추가 |
| 트레이너 | 담당 회원 체성분 | 측정 추가 (담당 회원만) |
| 스태프 / 조회전용 | 접근 불가 | 접근 불가 |

## 주요 UX 흐름

1. 사이드바 "회원관리 > 체성분 관리" 또는 SCR-M004 체성분 탭에서 진입
2. 대상 회원 선택
3. 요약 카드 + 차트로 현재 상태 파악
4. [측정 추가] (DLG-M015) → 수치 입력 → 저장
5. 동일 일자 기존 데이터 있으면 DLG-M016 덮어쓰기 확인
6. 차트와 테이블에 새 데이터 반영

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 (측정 이력 있음) | 모든 카드 + 차트 + 테이블 |
| 측정 0회 (신규) | "측정 기록이 없어요" + 추가 CTA |
| 측정 1건만 | 차트 hidden, 테이블만 |
| 측정 추가 중 | DLG-M015 입력 |
| 동일 일자 충돌 | DLG-M016 덮어쓰기 확인 |
| 측정 범위 초과 | 인라인 에러 |

## 비즈니스 규칙

1. 체중은 20~300kg, 골격근량은 5~80kg, 체지방률은 3~60% 범위만 입력 가능.
2. BMI는 체중과 키를 기반으로 자동 계산 (키는 회원정보).
3. 기초대사량(BMR)은 체중·키·나이 기반 자동 계산.
4. 측정 데이터가 2건 미만이면 차트는 표시되지 않는다.
5. 동일 일자 측정값 입력 시 DLG-M016 덮어쓰기 확인.
6. 측정 일자는 미래 날짜 차단.
