## 기능 목적

공통된 특성이나 행동 패턴을 가진 회원들을 그룹(세그먼트)으로 묶어 타겟 마케팅과 맞춤 관리에 활용하는 화면이다. "30일 이상 미방문 활성 회원", "이번 달 만료 예정 회원", "신규 등록 후 한 번도 방문하지 않은 회원" 등 다양한 조건 조합으로 세그먼트를 생성하고, 해당 그룹에 메시지 발송이나 혜택 제공 등의 액션을 연결한다.

## 주요 구성요소

### 세그먼트 목록

생성된 세그먼트를 카드 형태로 표시. 각 카드: 이름·설명·해당 회원 수·생성일·마지막 업데이트.

### 세그먼트 생성 + 조건 빌더

AND / OR 조합으로 여러 조건 추가:

| 조건 | 옵션 |
|------|------|
| 회원 상태 | 활성 / 홀딩 / 만료 / 미등록 |
| 최근 방문일 | 예: 30일 이상 미방문 |
| 이용권 만료일 | 정책 step 대상, 만료 30일 이내 |
| 등록일 | 예: 최근 30일 내 등록 |
| 성별 / 연령대 / 회원구분 / 유입경로 | - |
| 누적 결제 금액 범위 | min~max |

### 미리보기

조건 설정 중 [미리보기] → 현재 조건 해당 회원 수 + 샘플 명단.

### 자동 갱신 설정

매일 / 주간 / 월간 자동 재계산.

### 세그먼트 액션 연결

세그먼트 카드에서 [메시지 발송] / [이용권 혜택 적용] 버튼.

### 수정·삭제

기존 세그먼트의 조건/이름 변경, 삭제.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 브랜드 세그먼트 | 생성·수정·삭제, 액션 실행 |
| 센터장 (owner) | 소속 지점 세그먼트 | 생성·수정·삭제, 액션 실행 |
| 매니저 | 소속 지점 세그먼트 | 생성·수정, 액션 실행 (삭제 불가) |
| FC | 소속 지점 세그먼트 조회 | 메시지 발송만 |
| 트레이너 / 스태프 / 프런트 | 접근 불가 | 이 화면 진입 차단 |

## 주요 UX 흐름

1. 사이드바 "회원관리 > 세그먼트 관리" 진입
2. 기존 세그먼트 목록 확인 또는 [새 세그먼트 만들기]
3. 이름·설명 + 조건 빌더로 필터 조건 설정
4. [미리보기] → 회원 수 확인
5. 자동 갱신 주기 설정 → 저장
6. 카드에서 [메시지 발송] 등 액션 실행

## 비즈니스 규칙

1. 세그먼트는 우선순위에 따라 회원당 단일 라벨 배정 (회원 목록 표시 시 자동 분류).
2. 7종 자동 세그먼트 (신규/만료 후 미등록/이탈 위험/만료 임박/관심 필요/충성/활발).
3. 세그먼트 기준 변경은 최고관리자·센터장만.
4. 세그먼트는 실시간 또는 자동 주기로 재계산.
5. 메시지 발송 액션은 SCR-071 / 혜택 적용은 SCR-073/074와 연동.
6. 본사 통합 모드에서는 전 지점 세그먼트 생성 가능.
