## 기능 목적

직원별 당월 급여를 자동 계산(근태 연동)하고 수당·공제 항목을 편집한 뒤 최종 급여를 확정한다. 급여 편집은 매니저 이상 가능하지만, 최종 확정은 센터장만 가능하다. 확정된 급여는 STF-07 급여 명세서에서 조회 가능해진다.

## 주요 UX 흐름

1. 사이드바 → 직원관리 → 급여 관리 진입
2. 지급월 선택 → 자동 계산 → 직원별 급여 표시
3. 수당·공제 편집 (DLG-064-001) → 실지급액 미리보기
4. [개별 확정] 또는 [일괄 확정] (센터장)
5. DLG-064-002에서 최종 확인 → 실행
6. 확정된 급여는 STF-07 명세서로 자동 이전

## 비즈니스 규칙

1. 급여 편집은 매니저 이상이 가능하지만, 최종 확정은 센터장만 가능하다.
2. 확정된 급여만 STF-07 급여 명세서에서 조회 가능하다.
3. 당월 내에는 확정 취소 후 재편집이 가능하다 (전월 이전은 잠금).
4. 근태 데이터(STF-05)는 자동 연동되어 수당이 계산된다.
5. 수당·공제 편집 시 변경 사유가 기록된다.
