## 기능 목적

직원별 당월 급여를 계산하고 수당·공제 내역을 검토한 뒤 최종 급여를 확정하는 화면이다. 근태 데이터(STF-05)와 연동되어 기본급에 각종 수당이 자동 반영되며, 관리자가 항목을 수동으로 편집한 후 일괄 확정할 수 있다. 급여 편집은 매니저 이상이 가능하지만, 최종 확정은 센터장만 가능하다. 확정된 급여는 STF-07 급여 명세서에서 조회 가능해진다.

## 주요 구성요소

### 지급 월 선택

급여를 처리할 대상 월 선택. 기본값은 당월.

### 요약 지표 카드

| 지표 | 설명 |
|------|------|
| 전체 지급 예정 금액 | 합계 |
| 확정 완료 인원 | N명 |
| 미확정 인원 | N명 |
| 이전 월 대비 증감 | + / - 표시 |

### 직원별 급여 테이블

| 컬럼 | 설명 |
|------|------|
| 직원명 | - |
| 역할 | 직무 배지 |
| 기본급 | 자동 계산 |
| 수당 합계 | 근태 연동 + 수동 편집 합산 |
| 공제 합계 | 4대 보험 + 추가 공제 |
| 실지급액 | 자동 계산 |
| 확정 상태 | 미확정 / 확정 배지 |
| 액션 | 편집 / 확정 / 확정 취소 |

### 수당·공제 편집 (DLG-064-001)

각 직원 행의 [편집] 클릭 시 다이얼로그 열림. 항목별 금액 수동 조정 + 실지급액 미리보기.

### 급여 확정 (DLG-064-002)

개별 또는 전체 직원의 급여를 확정. 확정 전 확인 다이얼로그 표시 (인원/총액 요약).

### 확정 취소

이미 확정된 급여도 당월 내에는 확정 취소 후 재편집 가능.

### 엑셀 내보내기

당월 급여 내역 전체를 엑셀 파일로 다운로드.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 | 소속 센터 전체 직원 급여 | 수당·공제 편집, 급여 확정, 확정 취소, 엑셀 내보내기 |
| 매니저 | 소속 센터 전체 직원 급여 | 수당·공제 편집 (확정 권한은 센터장만) |
| 직원 본인 | 본인 급여 정보만 | 조회만 가능 |
| FC / 트레이너 / 스태프 | 접근 불가 | 급여 관리 화면 진입 불가 |

## 주요 UX 흐름

1. 사이드바 "직원 관리 > 급여 관리" 진입
2. 지급 월 선택 → 직원별 급여 데이터 자동 로드
3. 근태 데이터 기반 기본급 + 수당 자동 계산
4. 수정이 필요한 직원 [편집] → DLG-064-001에서 항목 조정
5. 검토 후 [급여 확정] → DLG-064-002 확인
6. 확정 후 STF-07 명세서에서 조회 가능

| 확정 처리 중 | 로딩 + 중복 클릭 방지 |

## 비즈니스 규칙

1. 급여 편집은 매니저 이상이 가능하지만, 최종 확정은 센터장만 가능하다.
2. 확정된 급여만 STF-07 급여 명세서에서 조회 가능하다.
3. 당월 내에는 확정 취소 후 재편집이 가능하다 (전월 이전은 잠금).
4. 근태 데이터(STF-05)는 자동 연동되어 수당이 계산된다.
5. 수당·공제 편집 시 변경 사유가 기록된다.
6. 확정 처리는 감사 로그(SCR-097)에 기록된다.
