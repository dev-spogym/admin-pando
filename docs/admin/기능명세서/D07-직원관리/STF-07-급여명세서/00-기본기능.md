## 기능 목적

확정된 급여 명세서를 조회하고 직원에게 발송하는 화면(SCR-065)이다. 직원 본인은 본인의 월별 급여 명세서를 확인할 수 있으며, 관리자는 전체 직원의 명세서를 조회하고 개별 또는 일괄 발송할 수 있다. 발송 채널은 이메일·앱 알림이며, 인쇄·PDF 저장도 지원한다. 명세서는 STF-06 급여 관리에서 확정된 데이터를 기반으로 자동 생성된다.

운영 맥락:
- **월말 일괄 발송**: 센터장이 급여 확정 직후 전체 직원 일괄 발송 → 이메일 + 앱 알림 동시 전송
- **개별 재발송**: 직원이 못 받았다고 문의 시 [발송] 버튼 재클릭 → 발송 이력에 추가 기록
- **PDF 저장 (인사 보관용)**: 매니저가 명세서 PDF 저장 → 인사 파일 보관 또는 노무사 제출
- **직원 본인 모바일 조회**: 발송된 이메일·앱 푸시 링크 → 본인 명세서 직접 조회 + PDF 저장
- **퇴사 직원 명세서 보존 (5년)**: 퇴사 후에도 본인 이메일 링크로 5년간 조회 가능
- **확정 취소 시 명세서 무효**: STF-06에서 확정 취소 시 발송된 명세서 자동 무효 + 직원에게 재발송 안내
- **세무 신고 자료 (직원용)**: 직원이 연말 정산·이직 자료로 PDF 저장
- **본사 슈퍼관리자 전 지점 명세서 조회**: 통합 모드에서 지점별 발송 현황 확인
- **발송 실패 처리**: 이메일 반송·앱 푸시 실패 시 자동 알림 + 재시도
- **수신 확인 트래킹**: 직원이 이메일·앱 링크로 명세서 열람 시 자동 기록

명세서는 회사·세무법령에 따라 5년 이상 보존 의무가 있으며, 영구 보존을 원칙으로 한다.

## 주요 구성요소

### 조회 기간 선택

월 단위로 급여 명세서 조회. 기본값은 가장 최근 확정된 월.

### 직원 선택 필터

특정 직원 또는 전체 직원의 명세서 조회. 직무 보조 필터.

### 명세서 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 직원명 | - |
| 역할 | 직무 배지 |
| 지급 월 | YYYY-MM |
| 기본급 | - |
| 실지급액 | - |
| 발송 상태 | 미발송 / 발송완료 / 무효 배지 |
| 발송 일시 | 마지막 발송 일시 |
| 수신 확인 | 직원 열람 여부 + 일시 |
| 액션 | 발송 / 재발송 / PDF / 인쇄 |

### 명세서 상세 조회 (모달)

특정 직원의 행을 클릭하면 상세 패널 또는 모달 열림.

| 항목 | 표시 |
|------|------|
| 회사 정보 | 지점명·사업자등록번호·대표자 |
| 직원 정보 | 이름·직무·입사일·재직 기간 |
| 지급 월 | YYYY-MM |
| 기본급 | 큰 숫자 |
| 수당 상세 | 항목별 분리 (식대/교통비/성과/수업) |
| 공제 상세 | 항목별 분리 (4대 보험/소득세/지각/기타) |
| 수수료 | 트레이너 수업 건수 × 단가 |
| 실지급액 | 강조 표시 |
| 계좌 정보 | 마스킹 표시 (****-1234) |

### 개별 발송 / 일괄 발송

| 액션 | 동작 |
|------|------|
| 개별 발송 | 이메일 + 앱 알림 |
| 일괄 발송 | 체크박스로 선택 → 일괄 전송 |
| 재발송 | 발송 이력에 추가 기록 |

### 인쇄 / PDF 저장

명세서를 인쇄하거나 PDF 파일로 저장.

### 발송 이력

발송 일시·수신자·채널·상태(성공/실패) 누적 기록. 매니저+ 조회 가능.

## 주요 UX 흐름

### 정상 발송 흐름
1. 사이드바 "직원 관리 > 급여 명세서" 진입
2. 조회 월 + 대상 직원 선택 (가장 최근 확정 월 기본)
3. 명세서 목록에서 행 클릭 → 상세 모달
4. [발송] → 해당 직원에게 이메일/앱 알림 전송
5. 발송 완료 배지 + 일시 기록
6. 다중 선택 → [일괄 발송] → 확인 → 일괄 전송

### 본인 조회 흐름
1. 직원이 이메일 또는 앱 푸시 링크 클릭
2. 본인 인증 (자동 로그인 또는 OTP)
3. 본인 명세서 표시 (회사·직원 정보 + 항목 상세)
4. [PDF 저장] 또는 [인쇄] 가능

### 무효 처리 흐름
1. STF-06에서 급여 확정 취소
2. 발송된 명세서 자동 "무효" 배지 전환
3. 직원에게 자동 알림 "급여 명세서가 무효화되었습니다, 재발송 예정"
4. 재확정 후 새 명세서 자동 생성 + 재발송

### 분기·예외 흐름
- **미확정 월 조회 시도**: "급여 미확정" 안내 + STF-06 진입 안내, 발송 버튼 비활성
- **명세서 0건 (해당 월)**: "데이터 없음" 빈 상태
- **이미 발송된 명세서 [발송] 클릭**: 재발송 모드로 전환 + 이력 추가 기록
- **이메일 미등록 직원**: "이메일 미등록" 표시 + 발송 비활성, 직원 정보 수정 안내
- **앱 미가입 직원**: 이메일만 발송 + 안내
- **이메일 발송 실패 (반송)**: 토스트 "이메일 발송 실패" + 자동 재시도 (3회) + 매니저 알림
- **앱 푸시 실패**: 이메일만 발송 + 알림 센터 표시
- **확정 취소 → 무효 자동 처리**: "무효" 배지 + 직원에게 자동 알림
- **무효 명세서 발송 시도**: 차단 + "무효 명세서는 발송 불가, 재확정 필요"
- **본인 인증 실패 (모바일 링크)**: 로그인 페이지 리디렉션
- **퇴사 직원 5년 이력 조회**: 이메일 링크 + OTP 인증 → 조회 가능
- **5년 초과 데이터**: 익명화 처리 또는 아카이브, 정책 따라
- **PDF 저장 권한 부족 (다른 직원)**: 본인만 가능, 매니저+ 만 타인 PDF
- **일괄 발송 부분 실패**: 부분 성공 + 실패 직원 명단 + 개별 재시도
- **수신 확인 미열람 30일+**: 매니저 대시보드 알림
- **본사 통합 모드 권한 부족**: 토글 hidden
- **모바일 풀스크린 진입**: 카드 리스트 자동 전환
- **계좌 정보 마스킹**: 본인은 전체 표시, 매니저는 마스킹

## 비즈니스 규칙

1. 급여 확정 완료 시에만 명세서가 생성되어 발송 가능하다.
2. 발송 이력은 영구 보존된다 (재발송 시 기록 추가).
3. 직원 본인은 본인 명세서만 조회·인쇄할 수 있다.
4. 인쇄/PDF 저장은 본인 명세에 한해 직원이 가능, 매니저+는 모든 직원 가능.
5. 미확정 월의 명세서 조회 시도 시 "급여 미확정" 안내가 표시된다.
6. 발송 채널은 이메일 + 앱 알림 동시 발송을 원칙으로 한다.
7. **발송 상태 3종**: 미발송 / 발송완료 / 무효. 무효는 STF-06 확정 취소 시 자동 전환.
8. **재발송 정책**: 재발송 시 발송 이력에 추가 기록. 횟수 제한 없음.
9. **발송 실패 자동 재시도**: 이메일 반송 시 3회 자동 재시도 + 실패 시 매니저 알림.
10. **앱 푸시 실패 시**: 이메일만 발송 + 알림 센터 표시.
11. **이메일 미등록 직원**: 발송 비활성, 직원 정보(STF-03)에서 이메일 등록 안내.
12. **무효 명세서 발송 차단**: 무효 상태에서 발송 시도 시 차단 + "재확정 필요" 안내.
13. **본인 인증 (모바일 링크)**: 자동 로그인 토큰 또는 OTP 인증. 토큰 24시간 유효.
14. **5년 보존 정책**: 명세서·발송 이력 5년 보존. 퇴사 직원 본인 이메일 링크 5년 조회.
15. **5년 초과 처리**: 익명화 또는 아카이브, 정책 따라. 법령 준수.
16. **계좌 정보 마스킹**: 매니저+는 마스킹("****-1234"), 본인은 전체 표시.
17. **수신 확인 트래킹**: 이메일·앱 링크 열람 시 자동 기록. 미열람 30일+ 매니저 알림.
18. **PDF 파일명 규칙**: `yyyymm_직원명_급여명세서.pdf`.
19. **본사 슈퍼관리자 통합 조회**: 전 지점 발송 현황 통합, 매니저+ 가능.
20. **명세서 항목 분리**: 회사 정보 / 직원 정보 / 기본급 / 수당 상세 / 공제 상세 / 수수료 / 실지급액 / 계좌. 항목별 명확 표시.
21. **발송 이력 조회 권한**: 매니저+ 만 발송 이력 조회 가능. 직원 본인은 본인 발송 이력만.
22. **확정 취소 → 무효 자동 처리**: STF-06 확정 취소 시 명세서 자동 "무효" 배지 + 직원 알림.
23. **재확정 시 새 명세서 생성**: 확정 취소 후 재확정 시 무효 명세서는 보존하되 새 명세서 별도 생성·발송.
24. **법정 보존 의무**: 회사·세무법령에 따라 5년 이상 보존 의무. 영구 보존 권장.
25. **감사 로그**: 발송·재발송·무효·조회(매니저)·PDF 저장(타인) 모두 SCR-097에 기록. `actor_id`, `staff_id`, `month`, `channel`, `status` 저장.
26. **모바일 풀스크린**: 768px 미만 자동 카드 리스트 전환.
