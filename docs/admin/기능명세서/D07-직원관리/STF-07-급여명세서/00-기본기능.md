## 기능 목적

확정된 급여 명세서를 월 단위로 조회하고 직원에게 발송한다. 직원별 기본급, 수당 상세, 공제 상세, 실지급액을 명세서 양식으로 보여주고, 이메일·앱 알림으로 개별 또는 일괄 발송이 가능하다. 직원 본인은 본인 명세서만 조회·인쇄할 수 있다.

## 주요 UX 흐름

1. 사이드바 → 직원관리 → 급여 명세서 진입
2. 월 드롭다운 + 직원 검색
3. 명세서 미리보기 → 인쇄 / PDF 또는 [발송]
4. 일괄 발송 시 확인 모달 → 실행 → "발송완료" 도장 표시
5. 직원 본인 진입 시 본인 명세만 조회

## 화면 상태

| 상태 | 표시 |
|------|------|
| 확정 + 미발송 | 명세서 표시 + [발송] 활성 |
| 발송 완료 | "발송완료" 도장 + 일시 |
| 미확정 | "급여 미확정" 안내 + 발송 비활성 |
| 본인 모드 | 본인 명세만 표시 |
| 발송 중 | 로딩 + 진행 토스트 |

## 비즈니스 규칙

1. 급여 확정 완료 시에만 명세서가 생성되어 발송 가능해진다.
2. 발송 이력은 영구 보존된다 (재발송 시 기록 추가).
3. 직원 본인은 본인 명세서만 조회·인쇄할 수 있다.
4. 인쇄 / PDF 저장은 모든 권한에서 본인 명세에 한해 가능하다.
5. 미확정 월의 명세서 조회 시도 시 "급여 미확정" 안내가 표시된다.
