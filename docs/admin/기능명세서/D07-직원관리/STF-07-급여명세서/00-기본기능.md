## 기능 목적

확정된 급여 명세서를 조회하고 직원에게 발송하는 화면이다. 직원 본인은 본인의 월별 급여 명세서를 확인할 수 있으며, 관리자는 전체 직원의 명세서를 조회하고 개별 또는 일괄 발송할 수 있다. 발송 채널은 이메일·앱 알림이며, 인쇄·PDF 저장도 지원한다.

## 주요 구성요소

### 조회 기간 선택

월 단위로 급여 명세서 조회. 기본값은 가장 최근 확정된 월.

### 직원 선택 필터

특정 직원 또는 전체 직원의 명세서 조회.

### 명세서 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 직원명 | - |
| 역할 | 직무 배지 |
| 지급 월 | YYYY-MM |
| 기본급 | - |
| 실지급액 | - |
| 발송 상태 | 미발송 / 발송완료 배지 |

### 명세서 상세 조회 (모달)

특정 직원의 행을 클릭하면 상세 패널 또는 모달 열림.

| 항목 | 표시 |
|------|------|
| 기본급 | 큰 숫자 |
| 수당 상세 | 항목별 분리 |
| 공제 상세 | 항목별 분리 |
| 실지급액 | 강조 |

### 개별 발송 / 일괄 발송

| 액션 | 동작 |
|------|------|
| 개별 발송 | 이메일 + 앱 알림 |
| 일괄 발송 | 체크박스로 선택 → 일괄 전송 |

### 인쇄 / PDF 저장

명세서를 인쇄하거나 PDF 파일로 저장.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 / 매니저 | 소속 센터 전체 직원 명세서 | 명세서 발송, PDF 저장, 인쇄 |
| 직원 본인 | 본인 명세서만 | 조회, 인쇄, PDF 저장 |
| FC / 트레이너 / 스태프 | 본인 명세서만 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 "직원 관리 > 급여 명세서" 진입
2. 조회 월 + 대상 직원 선택
3. 명세서 목록에서 행 클릭 → 상세 모달
4. [발송] → 해당 직원에게 이메일/앱 알림 전송
5. 다중 선택 → [일괄 발송] → 확인 → 일괄 전송
6. 직원 본인은 앱/이메일 링크에서 직접 조회

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 데이터 로드 중 |
| 정상 목록 | 확정된 명세서 표시 |
| 미확정 상태 | "급여 미확정" 안내 + 발송 비활성 |
| 발송 완료 | "발송완료" 배지 + 일시 |
| 발송 중 | 로딩 + 중복 클릭 방지 |
| 본인 모드 | 본인 명세만 표시 |
| 발송 실패 | 토스트 + 재시도 |

## 비즈니스 규칙

1. 급여 확정 완료 시에만 명세서가 생성되어 발송 가능하다.
2. 발송 이력은 영구 보존된다 (재발송 시 기록 추가).
3. 직원 본인은 본인 명세서만 조회·인쇄할 수 있다.
4. 인쇄/PDF 저장은 본인 명세에 한해 가능하다.
5. 미확정 월의 명세서 조회 시도 시 "급여 미확정" 안내가 표시된다.
6. 발송 채널은 이메일 + 앱 알림 동시 발송을 원칙으로 한다.
