## 기능 목적

퇴사 예정인 직원의 퇴사일을 설정하고, 해당 직원이 담당하던 미완료 업무·회원·수업을 인수인계한 뒤 시스템 계정을 비활성화하는 화면이다. 퇴사 처리가 완료되면 해당 직원은 재직 상태에서 제외되고 이후 로그인이 차단된다. "퇴사처리" 텍스트를 직접 입력해야 최종 버튼이 활성화되는 이중 확인 절차(DLG-060-002)로 실수를 방지한다.

## 주요 구성요소

### 퇴사 대상 직원 정보

퇴사 처리할 직원의 이름·역할·입사일을 요약 표시.

### 퇴사일 / 예정일 설정

| 항목 | 설명 |
|------|------|
| 퇴사 확정일 | 실제 퇴사 확정일 (날짜 선택기) |
| 퇴사 예정일 | 사전 안내용 예정일 |

### 퇴사 사유 입력

자유 텍스트 입력 (내부 관리용). 필요 시 카테고리(자발/권고/계약 만료) 선택.

### 미완료 업무 인수인계

해당 직원이 담당하던 회원·예약된 수업·진행 중인 계약 등을 인계받을 담당자를 지정.

| 항목 | 인수 대상 |
|------|----------|
| 담당 회원 | FC/트레이너 인계 |
| 예약된 수업 | 트레이너 인계 |
| 진행 중인 계약 | 매니저/센터장 인계 |

### 계정 비활성화 확인

퇴사 처리 완료 시 시스템 로그인 계정이 즉시 비활성화된다는 안내.

### 처리 완료 / 취소 버튼

- [처리 완료] → DLG-060-002 표시 → "퇴사처리" 텍스트 입력 → 최종 실행
- [취소] → SCR-060 복귀

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 / 매니저 | 퇴사 처리 전체 폼 | 퇴사일 설정, 인수인계 지정, 계정 비활성화 |
| 기타 직원 | 접근 불가 | 퇴사 처리 화면 진입 불가 |

## 주요 UX 흐름

1. SCR-060에서 대상 직원을 체크박스 선택 → [퇴사 처리] 또는 STF-02 헤더 [퇴사]
2. SCR-062 진입 → 퇴사일 / 예정일 / 사유 입력
3. 미완료 업무가 있으면 인계자 지정
4. 계정 비활성화 안내 확인
5. [처리 완료] → DLG-060-002 → "퇴사처리" 입력 → 최종 확인
6. SCR-060 복귀 → 해당 직원 "퇴사" 상태 표시

## 화면 상태

| 상태 | 설명 |
|---|---|
| 정상 | 퇴사 대상 정보 + 입력 폼 |
| 미완료 업무 있음 | 인수인계 대상 목록 추가 표시 |
| 미완료 업무 없음 | "담당 업무 없음" 표시 |
| 인계 미완료 | 실행 버튼 비활성 + 경고 |
| 다이얼로그 활성 | "퇴사처리" 입력 대기 |
| 처리 중 | 버튼 로딩 + 백 비활성 |
| 처리 완료 | 성공 알림 → SCR-060 |

## 비즈니스 규칙

1. "퇴사처리" 텍스트를 정확히 입력해야 최종 버튼이 활성화된다 (실수 방지).
2. 퇴사 처리 완료 시 시스템 계정이 즉시 비활성화되어 로그인이 차단된다.
3. 인계 담당자 지정은 담당 회원/수업/계약이 있는 경우 필수이다.
4. 처리 이력은 감사 로그(SCR-097)에 append-only로 기록된다.
5. 퇴사 후 재입사는 신규 등록(STF-03)으로 처리한다.
6. 퇴사 확정일은 미래 날짜도 허용 (사전 등록).
