## 기능 목적

퇴사 예정인 직원의 퇴사일을 설정하고, 해당 직원이 담당하던 미완료 업무·회원·수업을 인수인계한 뒤 시스템 계정을 비활성화하는 화면(SCR-062)이다. 본 시스템은 `직원 1명 = 로그인 계정 1개` 정책을 따르므로 퇴사 처리는 직원 상태 변경과 로그인 계정 비활성화를 동시에 수행한다. 퇴사 처리가 완료되면 해당 직원은 재직 상태에서 제외되고 이후 로그인이 차단되며, 활성 세션도 즉시 만료된다. "퇴사처리" 텍스트를 직접 입력해야 최종 버튼이 활성화되는 이중 확인 절차(DLG-060-002)로 실수를 방지한다.

운영 맥락:
- **자발 퇴사 (이직)**: 직원 통보 → 퇴사 예정일 등록 → 인수인계 단계별 진행 → 퇴사 확정일 도래 시 자동 처리
- **권고 퇴사 (계약 위반)**: 즉시 퇴사 → 계정 즉시 비활성 + 캘린더 일정 즉시 정리 + 담당 회원 임시 매니저 인계
- **계약 만료**: 계약 종료일 = 퇴사 확정일, 사전 D-30 알림으로 인수인계 준비
- **휴직 후 미복귀 퇴사**: 휴직 상태에서 직접 퇴사 처리 가능, 인수인계는 휴직 시 사전 정리됨
- **부분 인수인계 (FC + 트레이너 겸직)**: 회원은 다른 FC, 수업은 다른 트레이너로 분리 인계
- **본사 슈퍼관리자 다른 지점 퇴사**: 통합 모드에서 처리, 인계자는 해당 지점 직원 중 선택
- **퇴사 후 재입사**: 신규 등록(STF-EXT-01)으로 처리, 기존 ID 미유지
- **퇴사 처리 취소 (당일 한정)**: 센터장만 가능, 24시간 이내 + 인계 작업 미진행 상태에서만 가능
- **임금 정산 / 4대 보험 상실 신고**: 외부 노무사 시스템과 별도 처리 (참고 안내만)

퇴사 처리 4단계 위자드: ① 퇴사정보 입력 → ② 회원/수업/계약 재배정 → ③ 스케줄 정리 → ④ 최종 확인 + 계정 비활성화.

## 주요 구성요소

### 퇴사 대상 직원 정보 (1단계)

퇴사 처리할 직원의 이름·직무·입사일·재직 기간·담당 회원 수·예약 수업 수를 요약 표시.

### 퇴사일 / 예정일 설정 (1단계)

| 항목 | 설명 |
|------|------|
| 퇴사 확정일 | 실제 퇴사 확정일 (날짜 선택기) |
| 퇴사 예정일 | 사전 안내용 예정일 (선택) |
| 퇴사 사유 카테고리 | 자발 / 권고 / 계약 만료 / 기타 |
| 추가 의견 | textarea (내부 관리용) |

### 미완료 업무 인수인계 (2단계)

해당 직원이 담당하던 회원·예약된 수업·진행 중인 계약 등을 인계받을 담당자를 지정.

| 항목 | 인수 대상 | 인계 정책 |
|------|----------|----------|
| 담당 회원 | FC/트레이너 인계 | 일괄 또는 회원별 분배 |
| 예약된 수업 | 트레이너 인계 | 수업별 또는 일괄 |
| 진행 중인 계약 | 매니저/센터장 인계 | 계약별 |
| OT 진행 중 회원 | 트레이너 인계 + 잔여 OT 자동 이전 | 일괄 |

### 스케줄 정리 (3단계)

- 퇴사 확정일 이후 모든 본인 일정 자동 정리 안내
- 회원과의 예약 수업 → 인계자 일정으로 자동 이동
- 휴가·외근 일정 → 자동 삭제
- 정리 결과 미리보기

### 계정 비활성화 확인 (4단계)

퇴사 처리 완료 시 시스템 로그인 계정이 즉시 비활성화되고 활성 세션이 즉시 만료된다는 안내 + 데이터 보존 정책.

### 처리 완료 / 취소 버튼

- [처리 완료] → DLG-060-002 표시 → "퇴사처리" 텍스트 입력 → 최종 실행
- [취소] → SCR-060 복귀 (입력 폐기 확인)

## 주요 UX 흐름

### 4단계 위자드 정상 흐름
1. SCR-060에서 대상 직원을 체크박스 선택 → [퇴사 처리] 또는 STF-02 헤더 [퇴사]
2. **1단계 퇴사 정보**: 퇴사 확정일 / 예정일 / 사유 카테고리 / 추가 의견 입력
3. **2단계 인수인계**: 담당 회원·수업·계약·OT 인계자 지정 (지점 내 직원만 선택 가능)
4. **3단계 스케줄 정리**: 자동 정리 미리보기 확인
5. **4단계 최종 확인**: 계정 비활성화 안내 + [처리 완료]
6. DLG-060-002 → "퇴사처리" 입력 → 최종 확인
7. SCR-060 복귀 → 해당 직원 "퇴사" 상태 표시

### 퇴사 취소 흐름 (당일 한정)
1. SCR-060에서 퇴사 필터 → 퇴사 직원 선택
2. STF-02 상세에서 [퇴사 취소] (센터장만, 24시간 이내)
3. 인계 데이터 복원 + 재직 상태 복귀
4. 감사 로그 기록

### 분기·예외 흐름
- **담당 회원 0건 + 예약 수업 0건**: 2단계 자동 skip + "인계 대상 없음" 표시
- **인계자 지정 누락**: [처리 완료] 클릭 시 인라인 에러 "인계자를 지정해주세요"
- **인계자가 본인 (자기 자신 선택)**: 인라인 에러 "본인은 인계자가 될 수 없습니다"
- **인계자가 같은 직무 미충족 (FC를 트레이너에게)**: 경고 + 인계 가능 직무 안내 (정책에 따라 강제)
- **인계자가 다른 지점 직원 (본사 통합 모드)**: 정책에 따라 차단 또는 허용
- **인계자가 휴직/퇴사 직원**: 차단 + 다른 인계자 안내
- **퇴사 확정일이 과거**: 경고 모달 "과거 날짜로 처리 시 즉시 퇴사 처리됩니다"
- **퇴사 확정일이 1년+ 미래**: 인라인 경고 "확정일이 1년 이상 미래입니다"
- **DLG-060-002 텍스트 불일치**: 최종 버튼 비활성 유지
- **다른 사용자 동시 퇴사 처리**: "다른 사용자가 처리 중" 차단
- **퇴사 취소 시 24시간 초과**: [퇴사 취소] 버튼 hidden
- **퇴사 취소 시 인계자 데이터 변경됨**: "인계 작업이 진행되어 취소할 수 없습니다"
- **퇴사 처리 후 본인 로그인 시도**: "비활성 계정입니다" + 로그인 차단
- **퇴사 처리 후 캘린더 수업 잔존**: 자동 정리 + 인계자 캘린더로 이동
- **휴가/외근 일정 자동 삭제**: 정리 미리보기에서 명시적 표시
- **본사 슈퍼관리자 통합 모드 처리**: 인계자 검색 시 해당 지점 직원만 노출
- **모바일 위자드 진입**: 단계별 풀스크린 슬라이드 전환

## 비즈니스 규칙

1. "퇴사처리" 텍스트를 정확히 입력해야 최종 버튼이 활성화된다 (실수 방지).
2. 퇴사 처리 완료 시 시스템 계정이 즉시 비활성화되어 로그인이 차단된다.
3. 인계 담당자 지정은 담당 회원/수업/계약/OT가 있는 경우 필수이다.
4. 처리 이력은 감사 로그(SCR-097)에 append-only로 기록된다.
5. 퇴사 후 재입사는 신규 등록(STF-EXT-01)으로 처리한다. 기존 직원 ID 미유지.
6. 퇴사 확정일은 미래 날짜도 허용 (사전 등록).
6-1. 퇴사 확정일이 오늘 또는 과거이면 `즉시 퇴사`로 간주하고 계정 비활성화와 세션 만료를 즉시 수행한다.
6-2. 퇴사 확정일이 미래이면 `퇴사 예정` 상태로 등록하고, 확정일 도래 시 자동으로 계정 비활성화와 세션 만료를 수행한다.
7. **위자드 4단계 강제**: 1→2→3→4 순차 진행. 단계 건너뛰기 불가, 단 인계 대상 없음 시 2단계 자동 skip.
8. **퇴사 사유 카테고리 4종**: 자발 / 권고 / 계약 만료 / 기타. 단일 선택. 통계 집계용.
9. **인계자 선택 정책**: 같은 지점 내 같은 직무 직원 우선 노출. 다른 직무 인계 시 경고 (정책에 따라 강제).
10. **인계자 본인 차단**: 본인을 인계자로 선택 불가, 휴직/퇴사 직원도 차단.
11. **자동 캘린더 정리**: 퇴사 확정일 이후 모든 일정 자동 정리. 수업은 인계자에게 이동, 휴가·외근은 자동 삭제.
12. **OT 잔여 자동 이전**: OT1·OT2 미완료 회원의 잔여 OT는 인계 트레이너에게 자동 부여.
13. **퇴사 D-30 사전 알림**: 퇴사 확정일 30일 전 매니저+에게 알림 (NFR-19), 인수인계 준비 유도.
14. **퇴사 D-7 인수인계 미완료 알림**: 7일 전 인계자 미지정 시 매니저에게 재알림.
15. **퇴사 취소 (당일 한정)**: 센터장만 가능. 퇴사 처리 후 24시간 이내. 인계 데이터 변경 발생 전까지만 허용.
16. **퇴사 취소 시 데이터 복원**: 인계된 회원·수업·계약·OT 모두 원래 직원에게 복원, 캘린더 일정 복원.
17. **데이터 보존 정책**: 퇴사 직원의 인사·실적·근태·급여·메모 데이터는 영구 보존 (감사·노무 목적).
18. **본인 데이터 접근**: 퇴사 직원 본인은 본인 급여 명세서 5년간 조회 가능 (이메일 링크), 그 외 시스템 접근 차단.
19. **본사 슈퍼관리자 통합 모드**: 다른 지점 퇴사 처리 가능, 인계자는 해당 지점 직원만 선택 가능.
20. **퇴사 사유 비공개**: 직원 본인은 퇴사 사유 메모 미열람 (관리자 전용).
21. **임금 정산 안내**: 퇴사 처리 화면에 "임금 정산은 별도 노무사 시스템에서 진행하세요" 안내 박스.
22. **4대 보험 상실 신고 안내**: 권고 퇴사·계약 만료 시 4대 보험 상실 신고 외부 처리 안내.
23. **휴직 → 직접 퇴사**: 휴직 상태에서 직접 퇴사 처리 가능. 인수인계는 휴직 시 사전 정리됨.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 인계 대상 0건 | "담당 업무 없음" + 2단계 skip | 3단계 진행 |
| 인계자 미지정 | 인라인 에러 + 진행 차단 | 인계자 선택 안내 |
| 인계자 본인 선택 | "본인은 인계자가 될 수 없습니다" | 다른 직원 안내 |
| 인계자 휴직/퇴사 | "휴직/퇴사 직원은 인계자 불가" | 활성 직원 안내 |
| 인계 직무 불일치 (정책) | 경고 모달 + 진행 가능 | - |
| 인계자 다른 지점 (본사 통합) | 차단 또는 허용 (정책) | 정책 안내 |
| 퇴사 확정일 과거 | 경고 모달 "즉시 퇴사 처리" | 확인 시 진행 |
| 퇴사 확정일 1년+ 미래 | 인라인 경고 | 진행 가능 |
| DLG 텍스트 불일치 | 최종 버튼 비활성 | 재입력 |
| 동시 퇴사 처리 | "다른 사용자가 처리 중" | 잠시 후 재시도 |
| 처리 중 네트워크 오류 | 토스트 + 재시도 | 위자드 상태 유지 |
| 퇴사 취소 24h 초과 | [퇴사 취소] hidden | - |
| 퇴사 취소 인계 데이터 변경 | "취소할 수 없습니다" | - |
| 퇴사 후 본인 로그인 시도 | "비활성 계정입니다" | 로그인 차단 |
| 퇴사 후 캘린더 잔존 | 자동 정리 + 인계자 이동 | - |
| 휴가/외근 자동 삭제 | 정리 미리보기 표시 | 확인 후 진행 |
| 인계 자동 이전 실패 (race) | 부분 성공 + 실패 항목 | 수동 재배정 안내 |
| 모바일 풀스크린 | 단계별 슬라이드 | - |
| 임금 정산 안내 | 안내 박스 | 외부 시스템 |
| 4대 보험 상실 안내 | 권고/계약 만료 시 표시 | 외부 처리 |
