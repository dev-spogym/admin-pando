## 기능 목적

퇴사 예정 직원의 퇴사일을 설정하고 미완료 업무(담당 회원/수업/계약)를 인계받을 담당자를 지정한 뒤, 시스템 계정을 비활성화하여 로그인을 차단한다. "퇴사처리" 텍스트를 직접 입력해야 최종 버튼이 활성화되는 이중 확인 절차를 거친다.

## 주요 UX 흐름

1. SCR-060 → 직원 선택 → [퇴사 처리] 또는 STF-02 헤더 [퇴사]
2. 퇴사 확정일 / 예정일 입력
3. 퇴사 사유 + 추가 의견 입력
4. 담당 회원/수업/계약 인계자 지정
5. [퇴사 처리 실행] → DLG-060-002 진입
6. "퇴사처리" 텍스트 입력 → 버튼 활성
7. 최종 확인 → 처리 완료 → SCR-060 갱신

## 비즈니스 규칙

1. "퇴사처리" 텍스트를 정확히 입력해야 최종 버튼이 활성화된다 (실수 방지).
2. 퇴사 처리 완료 시 시스템 계정이 즉시 비활성화되어 로그인이 차단된다.
3. 인계 담당자 지정은 담당 회원/수업/계약이 있는 경우 필수이다.
4. 처리 이력은 감사 로그(SCR-097)에 append-only로 기록된다.
5. 퇴사 후 재입사는 신규 등록(STF-03)으로 처리한다.
