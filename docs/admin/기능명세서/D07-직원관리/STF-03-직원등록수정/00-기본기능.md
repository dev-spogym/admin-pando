## 기능 목적

신규 직원을 시스템에 등록하거나 기존 직원의 정보를 수정하는 화면이다. 이름·연락처·직무 등 기본 정보와 함께 담당 서비스, 급여 형태, 시스템 계정 생성 여부, 캘린더 색상까지 한 화면에서 설정한다. 등록된 직원은 직원 목록(SCR-060)에 즉시 반영된다. 여기서 입력하는 `직무`는 인사/운영 분류값이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 매핑한다.

## 주요 구성요소

### 기본 정보 섹션

| 항목 | 입력 | 검증 |
|------|------|------|
| 직원명 | 텍스트 | 필수, 한/영/한자 2~20자 |
| 연락처 | 010 자동 포맷 | 중복 검증 (수정 시 본인 제외) |
| 이메일 | 형식 검증 | 계정 생성 시 ID로 사용 |
| 직무 | 단일 선택 (필수) | 센터장/매니저/FC/트레이너/스태프/프런트 |
| 직급 | 텍스트 | - |
| 입사일 | 캘린더 | 미래 날짜 가능 (예정 입사) |

### 담당 서비스 섹션

해당 직원이 담당할 서비스 항목을 다중 선택. (예: PT, 필라테스, 골프, GX 등)

### 급여 정보 섹션

| 항목 | 입력 |
|------|------|
| 급여 형태 | 라디오 (월급제 / 시급제 / 건별) |
| 기본급 | 숫자 + 콤마 자동 |

### 계정 설정 섹션

| 항목 | 설명 |
|------|------|
| 시스템 로그인 계정 생성 | 토글 ON/OFF |
| 로그인 ID | 이메일 주소 사용 |
| 임시 비밀번호 | 자동 생성 (직원 첫 로그인 시 변경 강제) |

### 캘린더 색상 선택

수업 캘린더(SCR-C001)에 표시될 직원 고유 색상을 6종 팔레트에서 지정.

### 저장 / 취소 버튼

- [저장]: 유효성 검사 후 SCR-060 목록 복귀
- [취소]: DLG-061-001 이탈 확인 다이얼로그 (변경 사항 있을 때)

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 / 매니저 | 전체 입력 폼 | 직원 등록 및 수정, 계정 생성 |
| FC / 트레이너 / 스태프 / 프런트 | 본인 정보 조회만 | 본인 정보 수정 불가 (관리자 권한 필요) |
| 직원 본인 | 본인 정보 조회 | 직접 수정 불가 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

**신규 등록**
1. SCR-060에서 [직원 등록] → 빈 폼으로 진입
2. 기본 정보 입력 + 연락처 중복 확인
3. 담당 서비스 / 급여 / 계정 / 색상 선택
4. [저장] → 유효성 검사 → 저장 → SCR-060 복귀

**수정**
1. SCR-060 목록 또는 STF-02 헤더에서 [수정]
2. 기존 정보 자동 채움
3. 변경 → [저장] → 토스트 + 복귀

**취소**
1. 입력 중 [취소]
2. 변경 사항 있으면 DLG-061-001 표시
3. 확인 시 입력 폐기 + 복귀

## 화면 상태

| 상태 | 설명 |
|---|---|
| 신규 등록 | 모든 필드 빈 상태 |
| 수정 모드 | 기존 정보 자동 채움 |
| 입력 중 | 변경 감지 + 저장 활성 |
| 필수 미입력 | 인라인 에러 + 저장 비활성 |
| 연락처 중복 | "이미 등록된 연락처입니다" |
| 저장 중 | 로딩 + 중복 클릭 방지 |
| 유효성 오류 | 필드별 인라인 에러 |
| 저장 완료 | 성공 알림 → SCR-060 복귀 |
| 이탈 시도 (변경 있음) | DLG-061-001 |

## 비즈니스 규칙

1. 이름과 직무는 필수 입력이다.
2. 연락처는 중복 검증을 통과해야 저장 가능하다 (수정 시 본인 제외).
3. 급여 형태와 기본급은 STF-06 급여 관리와 자동 연동된다.
4. 시스템 로그인 계정 생성 시 임시 비밀번호가 자동 발급되며, 첫 로그인 시 변경을 강제한다.
5. 입력 중 이탈 시 변경 사항이 있으면 DLG-061-001로 경고한다.
6. 캘린더 색상은 SCR-C001 수업 캘린더에서 직원 식별에 사용된다.
7. 입력하는 `직무`는 인사/운영 분류값이며, 관리자웹 메뉴 접근 권한과 동일 개념이 아니다.

## 관련 화면 / API
