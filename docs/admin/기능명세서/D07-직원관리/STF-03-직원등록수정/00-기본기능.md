## 기능 목적

신규 직원을 시스템에 등록하거나 기존 직원의 정보를 수정하는 화면(SCR-061)이다. 이름·연락처·직무 등 기본 정보와 함께 담당 서비스, 급여 형태, 시스템 계정 생성 여부, 캘린더 색상까지 한 화면에서 설정한다. 등록된 직원은 직원 목록(SCR-060)에 즉시 반영된다. 여기서 입력하는 `직무`는 인사/운영 분류값이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 매핑한다.

운영 맥락:
- **신규 트레이너 채용 (입사일 D-7)**: 채용 확정 → 입사일 미래 등록 → 캘린더 색상·담당 서비스(PT) 사전 설정 → 입사 당일 자동 활성화
- **시스템 계정 즉시 발급**: 관리자급 직원(매니저/센터장) 등록 시 계정 생성 토글 ON → 임시 비밀번호 자동 발급 + 이메일 발송 → 첫 로그인 시 변경 강제
- **외주 PT 강사 (계정 없음)**: 직무=트레이너 + 계정 생성 OFF → 캘린더 일정만 관리, 시스템 로그인 차단
- **직무 변경 (FC → 매니저 승진)**: 수정 모드 → 직무 변경 + 직급 업데이트 → SCR-081 권한 매핑 자동 재평가 안내
- **연락처 중복 검증**: 이미 등록된 직원/회원 연락처와 중복 시 인라인 에러 + 기존 데이터 안내
- **수업 캘린더 색상 충돌 방지**: 같은 지점 내 다른 직원과 색상 중복 시 경고 + 자동 추천 색상 제시
- **퇴사 직원 재입사**: 신규 등록(STF-03)으로 처리, 기존 직원 ID는 유지 안 됨, 새 직원 레코드 생성
- **본사 슈퍼관리자 다른 지점 직원 등록**: 통합 모드에서 지점 선택 후 등록, 직원의 `branchId`는 선택된 지점

전자 근로계약서 연계 시 저장 직후 계약서 발송 트리거를 옵션으로 제공한다(테넌트 정책에 따라).

## 주요 구성요소

### 기본 정보 섹션

| 항목 | 입력 | 검증 |
|------|------|------|
| 직원명 | 텍스트 | 필수, 한/영/한자 2~20자 |
| 연락처 | 010 자동 포맷 | 중복 검증 (수정 시 본인 제외) |
| 이메일 | 형식 검증 | 계정 생성 시 ID로 사용, 중복 검증 |
| 직무 | 단일 선택 (필수) | 센터장/매니저/FC/트레이너/스태프/프런트/골프프로 |
| 직급 | 텍스트 | - |
| 입사일 | 캘린더 | 미래 날짜 가능 (예정 입사) |
| 소속 지점 | 드롭다운 | 본사 통합 모드에서만 노출 |

### 담당 서비스 섹션

해당 직원이 담당할 서비스 항목을 다중 선택. (예: PT, 필라테스, 골프, GX 등)

### 급여 정보 섹션

| 항목 | 입력 |
|------|------|
| 급여 형태 | 라디오 (월급제 / 시급제 / 건별) |
| 기본급 | 숫자 + 콤마 자동 |
| 수당 정책 (선택) | 식대·교통비 자동 적용 토글 |

### 계정 설정 섹션

| 항목 | 설명 |
|------|------|
| 시스템 로그인 계정 생성 | 토글 ON/OFF |
| 로그인 ID | 이메일 주소 사용 |
| 임시 비밀번호 | 자동 생성 (직원 첫 로그인 시 변경 강제) |
| 이메일 발송 | 임시 비밀번호 자동 발송 |

### 캘린더 색상 선택

수업 캘린더(SCR-C001)에 표시될 직원 고유 색상을 6종 팔레트에서 지정.

### 근로계약서 (선택)

- 전자 계약서 발송 (이메일 + 카카오) 옵션
- 서명 완료 시 자동 저장 + 인사 파일 등록

### 저장 / 취소 버튼

- [저장]: 유효성 검사 후 SCR-060 목록 복귀
- [취소]: DLG-061-001 이탈 확인 다이얼로그 (변경 사항 있을 때)

## 주요 UX 흐름

### 신규 등록
1. SCR-060에서 [직원 등록] → 빈 폼으로 진입
2. 기본 정보 입력 + 연락처 중복 확인
3. 담당 서비스 / 급여 / 계정 / 색상 선택
4. (선택) 근로계약서 발송 옵션 체크
5. [저장] → 유효성 검사 → 저장 → SCR-060 복귀

### 수정
1. SCR-060 목록 또는 STF-02 헤더에서 [수정]
2. 기존 정보 자동 채움
3. 변경 → [저장] → 토스트 + 복귀
4. 직무 변경 시 SCR-081 권한 매핑 재평가 안내

### 취소
1. 입력 중 [취소]
2. 변경 사항 있으면 DLG-061-001 표시
3. 확인 시 입력 폐기 + 복귀
4. 변경 사항 없으면 즉시 복귀

### 분기·예외 흐름
- **연락처 중복**: 인라인 에러 "이미 등록된 연락처입니다" + 기존 직원·회원 안내 + 저장 차단
- **이메일 중복 (계정 생성 시)**: 인라인 에러 "이미 사용 중인 이메일입니다" + 저장 차단
- **이메일 형식 오류**: 실시간 인라인 에러 "올바른 이메일 형식을 입력해주세요"
- **이름 길이 미충족 (1자 또는 21자+)**: 인라인 에러 "2~20자로 입력해주세요"
- **직무 미선택 (필수)**: 인라인 에러 "직무를 선택해주세요" + 저장 비활성
- **입사일 과거 입력 (정책에 따라)**: 경고 모달 "입사일이 과거입니다, 진행하시겠습니까?" → 확인 시 저장
- **입사일 1년 이상 미래**: 인라인 경고 "입사일이 1년 이상 미래입니다, 확인해주세요"
- **캘린더 색상 충돌 (같은 지점)**: 경고 + 자동 추천 색상 제시 (강제 아님, 정책에 따라 강제)
- **계정 생성 토글 ON 상태에서 이메일 미입력**: 인라인 에러 "계정 생성 시 이메일이 필수입니다"
- **본사 통합 모드에서 지점 미선택**: 인라인 에러 "지점을 선택해주세요"
- **저장 중 네트워크 오류**: 토스트 "저장에 실패했습니다, 다시 시도해주세요" + 폼 유지
- **저장 후 연락처 중복 발견 (race condition)**: 서버 검증 실패 시 인라인 에러 + 폼 유지
- **수정 시 본인 연락처 중복 검증 제외**: 본인 ID는 중복 대상에서 자동 제외
- **변경 사항 없는 상태에서 [취소]**: DLG-061-001 표시 없이 즉시 복귀
- **입력 중 세션 만료**: 자동 저장(임시) 후 로그인 페이지 리디렉션
- **모바일 풀스크린 진입**: 섹션별 아코디언 자동 전환

## 비즈니스 규칙

1. 이름과 직무는 필수 입력이다.
2. 연락처는 중복 검증을 통과해야 저장 가능하다 (수정 시 본인 제외, 직원·회원 모두 검증 대상).
3. 급여 형태와 기본급은 STF-06 급여 관리와 자동 연동된다.
4. 시스템 로그인 계정 생성 시 임시 비밀번호가 자동 발급되며, 첫 로그인 시 변경을 강제한다.
5. 입력 중 이탈 시 변경 사항이 있으면 DLG-061-001로 경고한다.
6. 캘린더 색상은 SCR-C001 수업 캘린더에서 직원 식별에 사용된다.
7. 입력하는 `직무`는 인사/운영 분류값이며, 관리자웹 메뉴 접근 권한과 동일 개념이 아니다.
8. **이름 길이 정책**: 한/영/한자 2~20자. 특수문자·이모지 차단.
9. **직무 7종**: 센터장 / 매니저 / FC / 트레이너 / 스태프 / 프런트 / 골프프로. 단일 선택. 변경 시 SCR-081 자동 재평가.
10. **이메일 정책**: 계정 생성 토글 ON 시 필수, OFF 시 선택. 중복 검증 필수.
11. **계정 생성 시 임시 비밀번호**: 8자 이상 자동 생성(영문+숫자+특수문자), 이메일로 자동 발송, 첫 로그인 시 변경 강제.
12. **임시 비밀번호 유효기간**: 발급일로부터 7일. 미사용 시 자동 만료, 재발급 가능.
13. **입사일 정책**: 미래 날짜 허용 (사전 등록), 과거 날짜는 경고 모달 후 진행. 1년 이상 미래는 인라인 경고.
14. **캘린더 색상 6종**: 같은 지점 내 중복 가능하나 경고 표시 + 자동 추천. 정책에 따라 강제 분리 가능.
15. **본사 통합 모드 지점 선택**: 슈퍼관리자/본사 최고관리자만 지점 선택 가능, 센터장/매니저는 본인 지점 자동 설정.
16. **소속 지점 변경 (수정 시)**: 슈퍼관리자만 가능. 변경 시 캘린더·실적·근태 데이터 새 지점으로 이전.
17. **수정 권한**: 본사 슈퍼관리자/센터장/매니저만 가능. 직원 본인은 직접 수정 불가.
18. **퇴사 직원 재입사**: 신규 등록(STF-03)으로 처리. 기존 직원 ID 미유지, 새 레코드 생성. 단, 인사 파일은 검색으로 연결 가능.
19. **변경 감지**: 폼의 모든 필드 dirty 상태 추적, dirty=true 시에만 DLG-061-001 표시.
20. **자동 저장 (임시)**: 30초 주기로 임시 저장(로컬 스토리지), 세션 만료·네트워크 오류 시 복구.
21. **저장 직후 알림**: 신규 등록 시 본인에게 이메일 (계정 정보), 매니저+ 에게 알림(NFR-19).
22. **근로계약서 연계 (선택)**: 저장 시 옵션 ON 시 전자 계약서(이메일+카카오) 자동 발송, 서명 완료 시 인사 파일 자동 저장.
23. **감사 로그**: 등록·수정 모두 SCR-097에 기록. `actor_id`, `staff_id`, `before`, `after`, `action_type` 저장.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 이름 미입력 / 길이 미충족 | "2~20자로 입력해주세요" | 저장 비활성 |
| 직무 미선택 | "직무를 선택해주세요" | 저장 비활성 |
| 연락처 중복 | "이미 등록된 연락처입니다" + 기존 정보 | 저장 차단 |
| 이메일 형식 오류 | "올바른 이메일 형식을 입력해주세요" | 저장 비활성 |
| 이메일 중복 (계정 생성) | "이미 사용 중인 이메일입니다" | 저장 차단 |
| 입사일 과거 | 경고 모달 "과거 날짜입니다" | 확인 시 진행 |
| 입사일 1년+ 미래 | 인라인 경고 | 진행 가능 |
| 색상 충돌 (같은 지점) | 노랑 경고 + 추천 색상 | 진행 가능 (정책) |
| 계정 생성 ON + 이메일 미입력 | "계정 생성 시 이메일 필수" | 저장 비활성 |
| 본사 통합 + 지점 미선택 | "지점을 선택해주세요" | 저장 비활성 |
| 저장 중 네트워크 오류 | "저장 실패, 다시 시도" | 폼 유지 |
| Race condition (중복 발견) | 인라인 에러 + 폼 유지 | 재입력 |
| 변경 없음 + 취소 | 즉시 복귀 | DLG 미표시 |
| 변경 있음 + 취소 | DLG-061-001 | 입력 폐기 또는 유지 |
| 세션 만료 | 자동 임시 저장 + 로그인 | 복귀 시 폼 복원 |
| 권한 부족 (FC/스태프) | 화면 진입 차단 | 본인 정보 조회만 |
| 임시 비밀번호 만료 (7일+) | "재발급" 안내 | 매니저 재발급 |
| 모바일 풀스크린 | 아코디언 자동 전환 | - |
| 근로계약서 발송 실패 | 토스트 + 재발송 버튼 | 수동 재발송 |
| 동시 수정 충돌 | "다른 사용자가 수정했습니다" | 새로고침 안내 |

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| SCR-097 히스토리 로그 | 등록·수정 | actor·staff_id·before·after INSERT |
| SCR-081 권한 매핑 | 직무 변경 | RBAC 자동 재평가 + 안내 |
| 시스템 계정 발급 | 계정 생성 토글 ON | 임시 비밀번호 + 이메일 자동 발송 |
| 임시 비밀번호 만료 | 발급 후 7일 | 자동 만료, 재발급 알림 |
| SCR-064 급여 연동 | 급여 형태·기본급 입력 | 다음 월 급여 자동 계산 |
| SCR-C001 캘린더 색상 | 색상 선택 | 캘린더 자동 매핑 |
| SCR-060 목록 갱신 | 저장 완료 | 즉시 반영 |
| 입사일 도래 자동 활성 | 입사일 = 오늘 | 재직 상태 자동 active |
| 근로계약서 발송 | 옵션 ON + 저장 | 이메일·카카오 자동 발송 |
| 근로계약서 서명 완료 | 직원 서명 | 인사 파일 자동 저장 |
| 자동 임시 저장 | 30초 주기 | 로컬 스토리지 dirty 데이터 백업 |
| NFR-19 알림 센터 | 등록·수정 완료 | 매니저+ 에게 알림 |
| DLG-061-001 이탈 차단 | dirty=true + 이탈 시도 | 다이얼로그 표시 |
| 본사 통합 지점 변경 | 소속 지점 변경 | 캘린더·실적·근태 이전 |
