## 기능 목적

신규 직원을 시스템에 등록하거나 기존 직원의 정보를 수정한다. 기본 정보(이름/연락처/이메일/직무/직급/입사일), 담당 서비스, 급여 형태, 시스템 로그인 계정 생성 여부, 캘린더 색상 등을 한 화면에서 입력한다. 이름과 직무는 필수이며, 입력 중 취소 시 이탈 확인 다이얼로그가 표시된다.

## 주요 UX 흐름

**신규 등록**
1. SCR-060 → [직원 추가] 버튼
2. 기본 정보 입력 → 연락처 중복 확인
3. 담당 서비스 / 급여 / 색상 / 계정 옵션 선택
4. [저장] → 토스트 + 목록 복귀

**수정**
1. SCR-060 → 직원명 클릭 → [수정] 또는 STF-02 헤더 [수정]
2. 기존 정보 자동 채움
3. 변경 후 [저장] → STF-02 또는 SCR-060 복귀

## 화면 상태

| 상태 | 표시 |
|------|------|
| 입력 중 | 변경 감지 + 저장 버튼 활성 |
| 필수 미입력 | 인라인 에러 + 저장 비활성 |
| 연락처 중복 | "이미 등록된 연락처입니다" 인라인 에러 |
| 저장 중 | 로딩 + 버튼 비활성 |
| 저장 실패 | 토스트 + 재시도 |
| 이탈 시도 (변경 있음) | DLG-061-001 표시 |

## 비즈니스 규칙

1. 이름과 직무는 필수 입력이다.
2. 연락처는 중복 검증을 통과해야 저장 가능하다 (수정 시 본인 제외).
3. 급여 형태와 기본급은 STF-06 급여 관리와 자동 연동된다.
4. 시스템 로그인 계정 생성 시 임시 비밀번호가 자동 발급되며, 직원 첫 로그인 시 변경을 강제한다.
5. 입력 중 이탈 시 변경 사항이 있으면 ConfirmDialog로 경고한다.

## 관련 화면 / API

- **연계 화면**: SCR-060 / STF-02 상세 / SCR-081 권한 설정 / SCR-064 급여 관리
- **연계 다이얼로그**: DLG-061-001
- **API 추정**: `POST /api/staff` / `PUT /api/staff/:id` / `POST /api/staff/check-phone`
