## 기능 목적

센터에 소속된 모든 직원의 현황을 한눈에 파악하고, 직무·재직 상태별로 빠르게 찾을 수 있는 직원관리 도메인의 핵심 허브 화면이다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우에는 전 지점 직원이 합산 조회되며 각 직원의 소속 지점이 함께 표시된다. 센터장은 소속 지점 인력 현황을 조회하고 신규 직원을 등록하며, 매니저는 특정 직원에게 메시지를 전송하거나 퇴사 처리를 진행한다. 이 화면에서 다루는 값은 직원의 `직무`이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 매핑한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 전체 직원 수 | 전체 인원 카운트 | 카드 클릭 → 전체 필터 |
| 재직 중 인원 | status=active 카운트 | 카드 클릭 → 재직 필터 자동 적용 |
| 휴직 중 인원 | status=onLeave 카운트 | 카드 클릭 → 휴직 필터 |
| 퇴사 인원 | status=resigned 카운트 | 카드 클릭 → 퇴사 필터 |

### 검색 / 필터

- **검색 바**: 직원 이름 또는 연락처로 통합 검색 (디바운스 300ms, OR 매칭)
- **직무 필터**: 센터장 / 매니저 / FC / 트레이너 / 스태프 / 프런트 (다중)
- **소속 지점 필터**: 본사 통합 모드에서만 표시
- **재직 상태 필터**: 재직 / 휴직 / 퇴사 (단일)

### 일괄 작업 버튼 바

| 버튼 | 동작 | 권한 |
|------|------|------|
| 메시지 전송 | SCR-071 진입 (선택 ID 전달) | manager+ |
| 상태 변경 | 재직/휴직 일괄 전환 | manager+ |
| 퇴사 처리 | DLG-060-002 → SCR-062 | owner+ |
| 명단 다운로드 | 선택 직원 엑셀 | owner+ |

### 직원 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 번호 | 페이지 내 순번 |
| 직원명 | 클릭 시 STF-02 상세 패널 진입 |
| 소속 지점 | 본사 통합 모드 노출 |
| 직무 배지 | 6종 직무 색상 분기 |
| 연락처 | 010 자동 포맷 |
| 입사일 | YYYY-MM-DD |
| 재직 상태 배지 | 재직(success)/휴직(warning)/퇴사(neutral) |
| 메모 | 인사 메모 미리보기 (매니저+ 전용) |
| 더보기 | 수정/메시지/퇴사 진입 |

### 페이지네이션 / 등록

- 한 페이지 10건 + 페이지 번호 이동
- 우상단 [직원 등록] → SCR-061

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 본사 최고관리자 / 슈퍼관리자 | `전체 지점(통합)` 선택 시 전 지점 직원 목록과 지점별 소속 | 지점 전환, 전체 직원 검색·필터, 명단 다운로드, 권한 범위 내 직원 관리 |
| 센터장 / 매니저 | 소속 센터 전체 직원 목록 | 직원 등록, 상태 변경, 퇴사 처리, 메시지 전송, 명단 다운로드, 급여 확정 (센터장만) |
| FC / 트레이너 / 스태프 / 프런트 | 자신의 정보만 조회 가능 (동료 목록 열람 불가) | 본인 정보 조회만 |
| 직원 본인 | 본인 프로필 및 급여 명세서 | 본인 정보 조회 |
| readonly | 접근 불가 | 접근 불가 |

## 주요 UX 흐름

1. 사이드바에서 "직원 관리"를 클릭해 직원 목록 화면(`/staff`)으로 진입
2. 요약 카드로 전체 인원 현황 파악, 카드 클릭 시 해당 상태로 자동 필터링
3. 검색 또는 필터를 조합해 원하는 직원을 찾음
4. 직원명을 클릭하면 해당 직원의 상세 정보 화면(STF-02)으로 이동
5. 체크박스로 직원을 선택하면 일괄 작업 버튼이 활성화되어 메시지 전송 또는 퇴사 처리 진행
6. 우측 상단 "직원 등록" 버튼으로 신규 직원 등록(SCR-061)으로 이동
7. 퇴사 처리 버튼 클릭 시 확인 다이얼로그(DLG-060-002) 표시 → "퇴사처리" 텍스트 입력 후 최종 실행

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 데이터를 불러오는 동안 테이블 자리에 로딩 표시 |
| 정상 목록 | 직원이 1명 이상 존재할 때 테이블과 페이지네이션 표시 |
| 검색 결과 없음 | 검색·필터 적용 후 결과 0건이면 "직원 데이터가 없습니다" 안내 |
| 전체 직원 없음 | 필터 없이 0건이면 직원 등록 안내 메시지 + [직원 등록] CTA |
| 오류 | 데이터 로드 실패 시 오류 메시지 + 다시 시도 안내 |
| 본사 통합 모드 | 지점명 컬럼 자동 표시 + 전 지점 합산 |
| 권한 부족 (FC/스태프) | 동료 목록 비노출, 본인 정보만 표시 |

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 작업은 직원 실제 소속 지점(`branchId`) 기준으로 처리한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는 것을 원칙으로 한다.
3. 모든 직원은 유효한 `branchId`를 가져야 하며, 미설정 시 목록에 표시되지 않는다.
4. 검색 디바운스 300ms 통일, 이름·연락처 OR 매칭.
5. 다중 선택 일괄 액션은 1명 이상 선택 시 활성화되며, 메시지 발송은 선택 직원 ID 배열을 SCR-071로 전달한다.
6. 메모 컬럼은 매니저·센터장에게만 노출 (FC/스태프 hidden).
7. 직원 본인 모드에서는 본인 프로필만 표시되며 동료 직원 목록은 접근 불가.
8. 본 화면의 `직무`는 인사/운영 분류값이며, 실제 관리자웹 메뉴 접근 권한은 SCR-081에서 별도 매핑한다.
