## 기능 목적

센터에 소속된 모든 직원의 현황을 한눈에 파악하고, 직무·재직 상태별로 빠르게 찾을 수 있는 직원관리 도메인의 핵심 허브 화면(SCR-060)이다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우에는 전 지점 직원이 합산 조회되며 각 직원의 소속 지점이 함께 표시된다. 센터장은 소속 지점 인력 현황을 조회하고 신규 직원을 등록하며, 매니저는 특정 직원에게 메시지를 전송하거나 퇴사 처리를 진행한다. 이 화면에서 다루는 값은 직원의 `직무`이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 매핑한다.

운영 맥락:
- **월초 인사 점검**: 센터장이 4종 요약 카드로 재직/휴직/퇴사 인원 일괄 확인 → 휴직 복귀 예정자 사전 파악
- **신규 트레이너 채용 직후**: 채용 확정 → [직원 등록] 버튼으로 SCR-061 진입 → 등록 즉시 목록 반영 + 캘린더 색상 자동 적용
- **본사 슈퍼관리자 전 지점 인력 모니터링**: `전체 지점(통합)` 모드 → 지점명 컬럼 자동 표시 → 지점별 인력 분포 + 직무별 채용 격차 파악
- **단체 메시지 발송**: 직무 필터 (예: "트레이너 + FC") + 지점 필터 → 전체 선택 → [메시지 전송] → SCR-071로 ID 배열 전달
- **퇴사 일괄 처리**: 계약 만료 5명 동시 퇴사 → 다중 선택 → [퇴사 처리] → DLG-060-002 → SCR-062 단계별 진행
- **명단 다운로드 (감사·노무 제출용)**: 본사 통합 모드 → 모든 필터 해제 → [명단 다운로드] → 노무사·세무사 제출
- **인사 메모 누적 조회**: 매니저가 메모 컬럼 미리보기로 직원별 인사 이슈 즉시 인지 → 직원명 클릭 → STF-02 상세에서 전체 메모 조회

요약 카드는 클릭으로 재직 상태 필터를 자동 적용해 단계별 드릴다운을 지원하며, 본사 통합 모드는 지점명·지점별 합산 통계를 제공해 다지점 운영 가시성을 확보한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 전체 직원 수 | 전체 인원 카운트 | 카드 클릭 → 전체 필터 |
| 재직 중 인원 | status=active 카운트 | 카드 클릭 → 재직 필터 자동 적용 |
| 휴직 중 인원 | status=onLeave 카운트 | 카드 클릭 → 휴직 필터 |
| 퇴사 인원 | status=resigned 카운트 | 카드 클릭 → 퇴사 필터 |

### 검색 / 필터

- **검색 바**: 직원 이름 또는 연락처로 통합 검색 (디바운스 300ms, OR 매칭)
- **직무 필터**: 센터장 / 매니저 / FC / 트레이너 / 스태프 / 프런트 / 골프프로 (다중)
- **소속 지점 필터**: 본사 통합 모드에서만 표시
- **재직 상태 필터**: 재직 / 휴직 / 퇴사 (단일)

### 일괄 작업 버튼 바

| 버튼 | 동작 | 권한 |
|------|------|------|
| 메시지 전송 | SCR-071 진입 (선택 ID 전달) | manager+ |
| 상태 변경 | 재직/휴직 일괄 전환 | manager+ |
| 퇴사 처리 | DLG-060-002 → SCR-062 | owner+ |
| 명단 다운로드 | 선택 직원 엑셀 | owner+ |

### 직원 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 번호 | 페이지 내 순번 |
| 직원명 | 클릭 시 STF-02 상세 패널 진입 |
| 소속 지점 | 본사 통합 모드 노출 |
| 직무 배지 | 7종 직무 색상 분기 |
| 연락처 | 010 자동 포맷 |
| 입사일 | YYYY-MM-DD |
| 재직 상태 배지 | 재직(success)/휴직(warning)/퇴사(neutral) |
| 메모 | 인사 메모 미리보기 (매니저+ 전용) |
| 더보기 | 수정/메시지/퇴사 진입 |

### 페이지네이션 / 등록

- 한 페이지 10건 + 페이지 번호 이동
- 우상단 [직원 등록] → SCR-061

## 주요 UX 흐름

### 정상 조회 흐름
1. 사이드바에서 "직원 관리"를 클릭해 직원 목록 화면(`/staff`)으로 진입
2. 요약 카드로 전체 인원 현황 파악, 카드 클릭 시 해당 상태로 자동 필터링
3. 검색 또는 필터를 조합해 원하는 직원을 찾음
4. 직원명을 클릭하면 해당 직원의 상세 정보 화면(STF-02)으로 이동
5. 체크박스로 직원을 선택하면 일괄 작업 버튼이 활성화되어 메시지 전송 또는 퇴사 처리 진행
6. 우측 상단 "직원 등록" 버튼으로 신규 직원 등록(SCR-061)으로 이동
7. 퇴사 처리 버튼 클릭 시 확인 다이얼로그(DLG-060-002) 표시 → "퇴사처리" 텍스트 입력 후 최종 실행

### 분기·예외 흐름
- **검색 결과 0건**: "직원 데이터가 없습니다" + 검색 조건 조정 안내, 필터 칩 노출 유지
- **전체 직원 0건 (등록 전)**: 빈 상태 일러스트 + [직원 등록] CTA 강조 노출
- **본사 통합 모드 진입**: 지점명 컬럼 자동 추가 + 지점 필터 노출 + 합산 통계 카드 표시
- **본사 통합 모드 일괄 작업**: 직원 실제 소속 지점(`branchId`) 기준으로 분기 처리, 트랜잭션은 지점별로 묶음
- **FC/스태프/프런트 권한 진입**: 동료 목록 비노출, 본인 카드만 표시 + "관리자 권한이 필요합니다" 안내
- **메모 컬럼 권한 부족**: 매니저 미만 권한자에게 컬럼 자체 hidden (overflow 처리)
- **퇴사자 검색 시도**: 퇴사 필터 명시적 적용 시에만 노출, 재직 필터에서는 자동 제외
- **이미 퇴사된 직원 재선택 시도**: 체크박스 disabled + 툴팁 "이미 퇴사 처리된 직원입니다"
- **명단 다운로드 권한 부족**: FC/스태프 버튼 hidden, 매니저는 본인 지점만 가능
- **휴직 → 재직 일괄 변경 시 충돌**: 일부 직원 캘린더 충돌 시 충돌 직원 제외 + 부분 성공 토스트
- **본사 통합 모드 메시지 발송**: 지점별 발송자 권한 검증, 권한 없는 지점 직원은 자동 제외 + 안내
- **명단 엑셀 다운로드 (대용량 1000명+)**: 백그라운드 잡 처리 + "다운로드 준비 중" 토스트 → 알림 센터로 다운로드 링크 제공
- **검색 디바운스 중 추가 입력**: 이전 요청 cancel + 최신 입력으로 재요청
- **페이지 이탈 후 복귀**: 직전 필터·페이지 상태 세션 스토리지에 보존 + 자동 복원 (5분 TTL)

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 작업은 직원 실제 소속 지점(`branchId`) 기준으로 처리한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는 것을 원칙으로 하며, 1000명 초과 시 백그라운드 잡으로 전환한다.
3. 모든 직원은 유효한 `branchId`를 가져야 하며, 미설정 시 목록에 표시되지 않는다.
4. 검색 디바운스 300ms 통일, 이름·연락처 OR 매칭. 디바운스 중 추가 입력 시 이전 요청은 cancel 처리한다.
5. 다중 선택 일괄 액션은 1명 이상 선택 시 활성화되며, 메시지 발송은 선택 직원 ID 배열을 SCR-071로 전달한다.
6. 메모 컬럼은 매니저·센터장에게만 노출 (FC/스태프 hidden), 컬럼 자체가 RBAC로 제거된다.
7. 직원 본인 모드에서는 본인 프로필만 표시되며 동료 직원 목록은 접근 불가.
8. 본 화면의 `직무`는 인사/운영 분류값이며, 실제 관리자웹 메뉴 접근 권한은 SCR-081에서 별도 매핑한다.
9. **직무 7종**: 센터장 / 매니저 / FC / 트레이너 / 스태프 / 프런트 / 골프프로. 멀티 선택 가능. 직무 변경 시 SCR-081 권한 매핑 자동 재평가.
10. **재직 상태 3종**: 재직(active) / 휴직(onLeave) / 퇴사(resigned). 단일 선택. 휴직→재직 전환은 매니저+ 권한.
11. **요약 카드 합산 기준**: 슈퍼관리자 통합 모드는 전 지점 합산, 센터장은 본인 지점만, 매니저는 본인 지점만. 카드 클릭 시 재직 상태 필터가 자동 적용된다.
12. **퇴사자 노출 기본값**: 재직 필터 미선택 시 퇴사자는 자동 제외. 퇴사 필터 명시 적용 시에만 노출.
13. **본사 통합 모드 가시성**: 본사 최고관리자/슈퍼관리자만 토글 가능. 센터장/매니저는 토글 자체 hidden.
14. **퇴사 처리 권한**: 센터장+ 만 가능. 매니저는 [퇴사 처리] 버튼 hidden.
15. **상태 변경 일괄 처리**: 재직 ↔ 휴직만 일괄 가능. 퇴사 일괄 변경은 SCR-062 단계별 처리만 허용.
16. **세션 상태 보존**: 직전 필터·페이지·검색어를 세션 스토리지에 5분 TTL로 보존, 페이지 복귀 시 자동 복원.
17. **메모 미리보기 길이**: 30자 + 말줄임. 전체 메모는 STF-02 상세에서 조회.
18. **목록 정렬 기본값**: 입사일 내림차순(최신). 컬럼 헤더 클릭 시 다른 정렬 적용.
19. **본사 통합 메시지 발송 시 권한 분기**: 지점별 메시지 발송 권한 자동 검증, 권한 없는 지점 직원은 발송 대상에서 자동 제외 + 안내.
20. **연락처 010 포맷**: 표시 시 "010-1234-5678" 자동 포맷. 검색 시 하이픈 유무 무관하게 매칭.
21. **감사 로그**: 일괄 상태 변경·퇴사 처리·명단 다운로드 모두 SCR-097에 기록. `actor_id`, `staff_ids`, `action_type`, `branch_id` 저장.
22. **명단 다운로드 파일명 규칙**: `yyyymmdd_지점명_직원목록.xlsx` (통합 모드는 `yyyymmdd_전체_직원목록.xlsx`).
23. **이미 퇴사된 직원 재선택 차단**: 체크박스 disabled + 툴팁 안내. 일괄 작업 대상에서 자동 제외.

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 검색 결과 0건 | "직원 데이터가 없습니다" + 필터 칩 | 검색 조건 조정 안내 |
| 전체 직원 0건 | 빈 상태 일러스트 + [직원 등록] CTA | 신규 등록 유도 |
| 데이터 로드 실패 | 오류 박스 + [다시 시도] | 재요청 트리거 |
| FC/스태프/프런트 동료 조회 시도 | 본인 카드만 표시 | 권한 안내 |
| 메모 권한 부족 | 메모 컬럼 hidden | - |
| 퇴사 처리 권한 부족 (매니저) | [퇴사 처리] 버튼 hidden | - |
| 명단 다운로드 권한 부족 (FC/스태프) | 버튼 hidden | - |
| 본사 통합 모드 토글 권한 부족 | 토글 hidden | - |
| 일괄 작업 0명 선택 | 일괄 버튼 disabled | 선택 안내 툴팁 |
| 이미 퇴사된 직원 재선택 | 체크박스 disabled + 툴팁 | 자동 제외 |
| 휴직→재직 변경 시 일부 충돌 | 부분 성공 토스트 + 충돌 직원 명단 | 개별 처리 안내 |
| 본사 통합 메시지 발송 시 권한 없는 지점 | 자동 제외 + 안내 토스트 | - |

| 페이지네이션 마지막 페이지 초과 | 1페이지로 자동 이동 | - |
| 동시 일괄 작업 충돌 (다른 운영자) | "다른 사용자가 처리 중입니다" | 잠시 후 재시도 |
| 모바일 풀스크린 진입 | 테이블 → 카드 리스트 자동 전환 | - |
| 직원 본인 모드 진입 | 본인 카드 1건만 표시 | - |
