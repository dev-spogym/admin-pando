## 기능 목적

센터(또는 본사 통합 모드의 전 지점)에 소속된 직원·트레이너 전원의 현황을 한눈에 파악하고, 직무·재직 상태·소속 지점별로 빠르게 검색·필터링하여 인사·운영 의사결정에 활용한다. 1명 이상 선택 시 메시지 전송, 상태 변경, 퇴사 처리, 명단 다운로드 등의 일괄 작업이 가능하며, 직원명 클릭 시 직원 상세(STF-02)로 진입한다.

## 주요 UX 흐름

1. 사이드바 → 직원관리 → 직원 목록 진입 (`/staff`)
2. 상단 4종 요약 카드로 인력 현황 파악 → 카드 클릭 시 해당 상태 필터 자동 적용
3. 검색 / 직무·재직·지점 필터로 대상 좁힘
4. 직원명 클릭 → 상세 슬라이드 (STF-02 진입)
5. 다중 체크박스 선택 → 일괄 액션 바 활성화 → 메시지 / 상태 변경 / 퇴사 / 다운로드
6. 우상단 엑셀 다운로드 → 현재 필터 또는 전체 분기 → 파일 저장

## 화면 상태

| 상태 | 표시 |
|------|------|
| 정상 | 요약 카드 + 목록 표시 |
| 검색 결과 0건 | "검색 결과가 없어요" 일러스트 + 필터 해제 |
| 로딩 | 카드 + 테이블 스켈레톤 |
| API 실패 | 토스트 + 재시도 버튼 |
| 본사 통합 모드 | 지점명 컬럼 자동 표시 + 전 지점 합산 |
| 권한 부족 (FC/스태프 엑셀) | 다운로드 버튼 비활성 + 안내 |

## 비즈니스 규칙

1. 본사 통합 모드의 일괄 작업(메시지/상태)은 직원 실제 소속 지점 기준으로 처리한다.
2. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터를 내려받는 것을 원칙으로 한다.
3. 모든 직원은 유효한 소속 지점(`branchId`)을 가져야 하며, 미설정 시 목록에 표시되지 않는다.
4. 검색 디바운스는 300ms로 통일한다.
5. 다중 선택 액션은 1명 이상 선택 시 활성화된다.
