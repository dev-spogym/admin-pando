## 기능 목적

직원별 출퇴근 기록을 조회하고 지각·결근·초과근무 현황을 파악하는 화면이다. 월별·직원별로 근무 시간을 집계해 급여 산정의 기초 데이터로 활용하며, 관리자가 출퇴근 기록을 수동으로 보정할 수 있다. 모든 보정 이력은 감사 로그에 기록된다. 직원 본인은 자신의 근태만 조회할 수 있고 수정은 불가하다.

## 주요 구성요소

### 조회 기간 선택

월 단위 또는 특정 날짜 범위를 선택해 해당 기간의 근태 데이터 조회.

### 직원 선택 필터

특정 직원 또는 전체 직원 선택.

### 요약 지표 카드

| 지표 | 설명 |
|------|------|
| 정상 출근 일수 | 지각·결근·조퇴 제외 |
| 지각 횟수 | 출근 시각 기준 초과 |
| 결근 횟수 | 영업일 미출근 |
| 총 근무 시간 | 합계 |

### 근태 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 날짜 | YYYY-MM-DD |
| 직원명 | - |
| 출근 시각 | HH:MM |
| 퇴근 시각 | HH:MM |
| 근무 시간 | 자동 계산 |
| 상태 | 정상 / 지각 / 결근 / 조퇴 배지 |

### 수동 보정 기능

관리자가 출퇴근 시각을 직접 수정하거나 누락된 기록을 추가. 보정 사유 필수, 이력 기록.

### 월별 집계 요약

직원별 월 총 근무 시간과 출근율을 한눈에 비교하는 요약 뷰.

### 엑셀 내보내기

조회 결과를 엑셀 파일로 다운로드.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 / 매니저 | 소속 센터 전체 직원 근태 | 출퇴근 기록 수동 보정, 엑셀 내보내기 |
| 직원 본인 | 본인 근태만 | 조회만 가능 (수정 불가) |
| FC / 트레이너 / 스태프 | 본인 근태만 | 조회만 |
| readonly | ❌ | ❌ |

## 주요 UX 흐름

1. 사이드바 "직원 관리 > 근태 관리" 진입
2. 조회 기간(월/날짜 범위) + 대상 직원 선택
3. 근태 목록에서 일자별 출퇴근 기록 확인
4. 요약 카드로 지각·결근 현황 파악
5. 오류 기록이 있으면 [수정] 또는 [누락 추가] → 사유 입력 → 저장
6. 급여 계산 시 월별 집계 요약 데이터 활용

## 비즈니스 규칙

1. 출퇴근 기록의 수동 보정은 관리자만 가능하며, 보정 이력이 반드시 기록된다.
2. 직원 본인은 본인 기록만 조회할 수 있으며 수정·추가는 불가능하다.
3. 출근율은 (정상 출근 + 지각) / 총 영업일로 계산한다.
4. 키오스크(SCR-082) 또는 IoT 출입(SCR-083)에서 자동 수집된 데이터가 우선이다.
5. 보정 사유는 필수 입력이며 감사 로그에 기록된다.
6. 근태 데이터는 STF-06 급여 관리에 자동 연동된다.
