## 기능 목적

직원별 출퇴근 기록을 조회하고 지각·결근 현황을 파악해 급여 산정의 기초 데이터로 활용한다. 관리자는 오류 기록을 수동 보정하거나 누락 기록을 추가할 수 있으며, 모든 보정은 이력에 기록된다. 직원 본인은 자신의 근태만 조회할 수 있고 수정은 불가하다.

## 주요 UX 흐름

1. 사이드바 → 직원관리 → 근태 관리 진입
2. 기간 / 직원 필터 → [조회]
3. 요약 카드로 현황 파악
4. 일별 기록 확인 → 오류 발견 시 [보정] 또는 [누락 추가]
5. 보정 사유 입력 → 저장 → 이력 자동 기록
6. 엑셀 다운로드로 외부 보관

## 비즈니스 규칙

1. 출퇴근 기록의 수동 보정은 관리자만 가능하며, 보정 이력이 반드시 기록된다.
2. 직원 본인은 본인 기록만 조회할 수 있으며 수정·추가는 불가능하다.
3. 출근율은 (정상 출근 + 지각) / 총 근무일로 계산한다.
4. 키오스크 출입 게이트(SCR-082)나 IoT 기기 연동(SCR-083)에서 자동 수집된 데이터가 우선이다.
5. 보정 사유는 필수 입력이며 감사 로그에 기록된다.
