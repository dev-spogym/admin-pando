## 기능 목적

선택한 직원의 담당 회원·스케줄·실적·근태·인사 메모를 한 화면에서 확인해 운영 관리자가 인사·실적 의사결정을 빠르게 내릴 수 있도록 한다. 매니저·센터장은 모든 직원 상세를 조회하고 인사 메모를 작성할 수 있으며, 직원 본인은 본인 정보·실적·근태만 보고 인사 메모는 비공개 처리된다. 동료 직원의 상세 접근은 차단된다.

## 권한 / RBAC

| 역할 | 본인 상세 | 동료 상세 | 인사 메모 작성 | 실적·근태 조회 |
|---|:---:|:---:|:---:|:---:|
| superAdmin / primary | ✅ | ✅ | ✅ | ✅ |
| owner | ✅ | ✅ | ✅ | ✅ |
| manager | ✅ | ✅ | ✅ | ✅ |
| fc / staff / 트레이너 | ✅ (본인) | ❌ | ❌ | ✅ (본인만) |
| readonly | ❌ | ❌ | ❌ | ❌ |

## 주요 UX 흐름

1. SCR-060 직원 목록 → 직원명 클릭 → 상세 패널 슬라이드
2. 담당 회원 / 스케줄 / 실적 / 근태 4개 카드 확인
3. 인사 메모 (매니저·센터장 한정) 작성
4. 헤더 [수정] / [퇴사 처리] 버튼으로 외부 진입
5. 패널 닫기 → 목록으로 복귀

## 화면 상태

| 상태 | 표시 |
|------|------|
| 매니저·센터장 조회 | 모든 카드 + 인사 메모 활성 |
| 직원 본인 조회 | 인사 메모 영역 hidden, 실적·근태만 |
| 동료 직원 접근 | 차단 + "권한이 없습니다" |
| 데이터 부족 | 빈 상태 안내 (예: "담당 회원이 없어요") |
| 로딩 | 카드별 스켈레톤 |

## 비즈니스 규칙

1. 인사 메모는 매니저·센터장만 작성/조회 가능하며 직원 본인에게는 노출되지 않는다.
2. 실적 데이터는 매출관리.md의 담당자별 집계 기준을 그대로 사용한다.
3. NPS는 수업 후기(SCR-C013)에서 자동 집계된 값이다.
4. 본인 조회 모드에서도 동료 직원의 데이터에는 접근할 수 없다.
