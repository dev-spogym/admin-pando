## 기능 목적

직원 목록(SCR-060)에서 직원명 클릭 시 표시되는 상세 패널/화면이다. 선택한 직원의 담당 회원·스케줄·실적·근태·인사 메모를 한 화면에서 확인해 운영 관리자가 인사·실적 의사결정을 빠르게 내릴 수 있도록 한다. 매니저·센터장은 모든 직원의 상세 정보를 조회하고 인사 메모를 작성·조회할 수 있으며, 직원 본인은 본인 정보·실적·근태만 보고 인사 메모는 비공개 처리된다. FC/트레이너/스태프는 동료 직원의 상세 접근이 차단된다.

## 주요 구성요소

### 담당 회원 목록

해당 직원이 담당 FC 또는 트레이너로 지정된 회원 목록.

| 표시 정보 | 설명 |
|---|---|
| 회원명 | 클릭 시 SCR-M004 회원 상세 진입 |
| 연락처 | 010 자동 포맷 |
| 이용권 상태 | 활성/만료/홀딩 배지 |
| 마지막 출석일 | 상대 시간 (예: "3일 전") |

### 담당 스케줄

이번 주 / 다음 주 수업 캘린더(SCR-C001) 데이터를 직원 단위로 필터링.

- 이번 주 수업 카드 (요일별 그룹)
- 다음 주 수업 카드
- [캘린더 진입] CTA → SCR-C001 직원 필터 자동 적용

### 실적 요약 카드

| 지표 | 설명 |
|---|---|
| 이번 달 수업 진행 건수 | PT/GX/필라테스 합계 |
| 신규 매출 | 이번 달 신규 등록 매출 (담당자 귀속) |
| 재등록 매출 | 이번 달 재등록 매출 |
| OT 1·2 완료 수 | OT1 / OT2 분리 카운트 |
| NPS 평균 점수 | 수업 후기(SCR-C013) 자동 집계 |

> 매출 집계 기준은 `매출관리.md` 담당자별 집계 정의를 따른다.

### 근태 요약 카드

SCR-063 근태 관리 데이터에서 이번 달 출근일·결근·지각 횟수.

| 항목 | 표시 |
|---|---|
| 출근일 | N일 (이번 달 영업일 대비) |
| 결근 | N회 |
| 지각 | N회 |
| 출근율 | 자동 계산 % |

### 인사 메모

매니저·센터장만 볼 수 있는 비공개 메모.

- 작성 / 수정 / 삭제
- 작성자 + 일시 자동 기록
- 직원 본인 영역에서는 hidden

### 헤더 액션 버튼

| 버튼 | 동작 | 권한 |
|------|------|------|
| 수정 | SCR-061 진입 | manager+ |
| 퇴사 처리 | SCR-062 진입 | owner+ |

## 권한 분기 (RBAC)

| 역할 | 동료 상세 | 본인 상세 | 인사 메모 | 헤더 액션 |
|---|:---:|:---:|:---:|:---:|
| primary / superAdmin | ✅ | ✅ | ✅ 작성·조회 | ✅ |
| owner (센터장) | ✅ | ✅ | ✅ | ✅ (수정·퇴사) |
| manager | ✅ | ✅ | ✅ | ✅ (수정만) |
| fc / 트레이너 / 스태프 / 프런트 | ❌ | ✅ (본인만) | ❌ | ❌ |
| readonly | ❌ | ❌ | ❌ | ❌ |

## 주요 UX 흐름

1. SCR-060 직원 목록 → 직원명 클릭
2. 상세 패널 슬라이드 (모바일 풀스크린)
3. 담당 회원 / 스케줄 / 실적 / 근태 4개 카드 확인
4. 인사 메모 작성 (매니저·센터장 한정)
5. 헤더 [수정] / [퇴사 처리] → SCR-061 / SCR-062 진입
6. 패널 닫기 → SCR-060 복귀

## 화면 상태

| 상태 | 설명 |
|---|---|
| 매니저·센터장 조회 | 모든 카드 + 인사 메모 활성 |
| 직원 본인 조회 | 인사 메모 hidden, 실적·근태만 |
| 동료 접근 시도 | 차단 + "권한이 없습니다" |
| 담당 회원 0건 | 빈 상태 안내 |
| 인사 메모 0건 | "메모가 없어요" + 작성 CTA |
| 로딩 | 카드별 스켈레톤 |
| 로드 실패 | 토스트 + 재시도 |

## 비즈니스 규칙

1. 인사 메모는 매니저·센터장만 작성·조회 가능하며 직원 본인에게는 노출되지 않는다.
2. 실적 요약의 매출 집계는 `매출관리.md`의 담당자별 집계 기준을 그대로 사용한다.
3. NPS는 수업 후기(SCR-C013)에서 자동 집계된 값이다.
4. 본인 조회 모드에서도 동료 직원의 데이터에는 접근할 수 없다.
5. 담당 스케줄은 SCR-C001 캘린더 데이터를 직원 단위로 필터링해 표시한다.
6. 근태 요약은 SCR-063 데이터를 기반으로 이번 달 합산한다.
