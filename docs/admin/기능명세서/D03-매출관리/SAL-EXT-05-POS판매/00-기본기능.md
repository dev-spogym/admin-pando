## 기능 목적

센터 현장에서 직원이 직접 상품을 선택하고 구매자를 지정해 결제 화면으로 넘기는 현장 판매(POS) 화면이다. 카운터에서 회원이 방문했을 때 이용권·PT·GX 등 다양한 상품을 빠르게 장바구니에 담고, 현금가·카드가를 선택한 뒤 결제 화면(SCR-S003)으로 이동한다. 이 화면은 회원/상품 선택과 장바구니 구성을 담당하며, 실제 수납 방식 결정(전액/계약금/잔액/결제링크)은 결제 처리 화면에서 확정한다.

운영 맥락:
- **카운터 매니저 신규 회원 등록**: 1년 회원권 + 락카 묶음 → 장바구니 → 회원 검색 → [결제하기]
- **FC 상담 후 패키지 결제**: PT 12회 + 멤버십 → 회원 검색 (이름/전화번호) → 카드 결제 진입
- **회원 비대면 결제**: 회원이 카드 미소지 → [결제링크 발송] → 회원 자가 결제
- **재방문 회원 추가 결제**: 회원 검색 → 기존 회원 카드 + 새 상품 추가
- **비회원 1회 결제**: 비회원 일반 상품 (음료·운동복) → 회원 미선택 진행
- **마일리지 결제 회원**: 회원 검색 필수 → 마일리지 잔액 검증
- **상품 검색·카테고리 탐색**: 카테고리 탭 (이용권/PT/GX/기타) + 검색 → 빠른 상품 선택
- **재고 부족·품절 처리**: 재고 0 상품 클릭 차단, 5개 이하 경고
- **신규 상품 등록 단축 진입**: [상품 등록] → SCR-P002 → 신규 상품 등록 후 POS 복귀
- **현금가/카드가 분기**: 장바구니에서 가격 유형 전환, 결제수단 결정 전 미리 변경 가능

POS 현장의 빠른 응대를 위해 디바운스 300ms·키보드 단축키·실시간 검색이 적용되며 카운터 직원의 동작 흐름에 최적화되어 있다.

## 주요 구성요소

### 카테고리 탭 + 상품 검색

- **카테고리 탭**: 이용권 / PT / GX / 기타 + 소속 상품 수 배지
- **상품 검색**: 상품명 실시간 검색

### 상품 카드 그리드

| 카드 표시 |
|---|
| 상품 유형 배지 (회원권/수강권/대여권/일반) |
| 상품명 |
| 기간 / 횟수 |
| 현금가 / 카드가 |

클릭 시 장바구니 추가 (동일 상품 재클릭 → 수량 +1).

### 장바구니 패널 (우측)

- 담긴 상품 목록
- 수량 조절 (-/+)
- 현금/카드 가격 유형 전환
- 개별 상품 삭제
- 전체 삭제 버튼
- 빈 상태 안내

### 구매자 선택 + 검색 모달 (DLG-S002)

- 회원 검색 버튼 → 모달 진입
- 이름 또는 전화번호 검색
- 선택된 회원: 이름·전화번호 표시 + X 해제
- 마일리지 결제 시 회원 지정 필수
- 비회원 결제 가능

### 총 합계 + 결제 진입

- 장바구니 하단 총 결제 금액
- [결제하기] (장바구니 1건 이상 시 활성) → SCR-S003 진입
- [결제링크 발송] (회원 선택 시 활성) → SCR-S003 + 링크 발송 경로

### 상품 등록 단축 진입

[상품 등록] → SCR-P002 단축 진입.

## 주요 UX 흐름

### 신규 회원 결제 흐름
1. 사이드바 "매출관리 > POS 판매" 또는 SCR-S001 [신규 결제(POS)]
2. 카테고리 탭 = 이용권 → 상품 카드 클릭 → 장바구니 추가
3. PT 카테고리 → PT 패키지 추가
4. 수량 조절 / 현금·카드 전환 / 개별 삭제
5. 회원 검색 (DLG-S002)으로 구매자 지정
6. 총 합계 확인 → [결제하기] → SCR-S003

### 비회원 일반 상품 흐름
1. 카테고리 탭 = 기타 → 일반 상품
2. 회원 미선택 (비회원 진행)
3. [결제하기] → SCR-S003 → 카드/현금 결제

### 결제링크 발송 흐름
1. 장바구니 구성 + 회원 검색
2. [결제링크 발송] → SCR-S003 + 링크 발송 경로
3. DLG-S016에서 채널·만료일 확인 후 발송

### 분기·예외 흐름
- **마일리지 결제 시 회원 미선택**: 결제수단 선택 단계에서 차단 (SCR-S003에서 처리)
- **재고 0 상품**: 카드 흐림 + "품절" 배지 + 클릭 차단
- **재고 5개 이하**: "재고 부족" 경고 배지 (클릭 가능)
- **회원 검색 결과 2명+**: 동명이인 식별 위해 전화번호 끝자리·생년월일 추가 입력
- **회원 비활성/탈퇴**: 검색 결과에서 제외, 운영자가 사유 확인
- **장바구니 비어있음**: [결제하기] 비활성, 안내 텍스트
- **회원 미선택 시 결제링크 발송 시도**: 버튼 비활성, 회원 검색 안내
- **상품 등록 후 POS 복귀**: 신규 상품 자동 추가 옵션 (선택)
- **카드 인식 단말 연결 실패**: SCR-S003에서 안내, POS는 정상 진행
- **권한별 가시성**: FC는 담당 회원만 검색, 트레이너·스태프는 POS 접근 불가

## 비즈니스 규칙

1. **마일리지 결제 회원 필수**: 마일리지 결제는 회원 지정 필수, SCR-S003에서 검증.
2. **비회원 결제**: 비회원 결제는 비회원 거래로 기록, 영수증·세금계산서는 별도 처리.
3. **수량 누적**: 동일 상품 재클릭 시 수량 +1.
4. **재고 0 차단**: 재고 0 상품은 클릭 차단 + "품절" 배지.
5. **재고 부족 경고**: 재고 5개 이하는 "재고 부족 (N개)" 경고 배지 (클릭 가능).
6. **결제링크 발송 회원 필수**: 회원 선택 시에만 [결제링크 발송] 버튼 활성.
7. **장바구니 최소 1건**: 장바구니 1건 이상 시 [결제하기] 활성.
8. **현금/카드 가격 분리**: 상품 마스터에 현금가/카드가 분리, 장바구니에서 전환 가능.
9. **회원 검색 디바운스**: 300ms 디바운스, 실시간 검색.
10. **회원 동명이인 식별**: 검색 결과 2명+ 시 전화번호 끝자리·생년월일 추가 입력.
11. **회원 비활성/탈퇴 제외**: 검색 결과에서 제외, 운영자만 별도 권한으로 조회.
12. **카테고리 자동 분류**: 상품 마스터 `category` 필드 기반 (이용권/PT/GX/기타).
13. **GX 세부 종목**: GX 카테고리 내부 subCategory (요가·필라테스·스피닝·줌바·에어로빅·기타).
14. **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 POS 접근 불가 또는 조회만.
15. **상품 검색 범위**: 현재 카테고리 내 검색 (카테고리 전환 시 검색어 초기화).
16. **장바구니 한도**: 단일 장바구니 최대 30개 항목 (정책 한도).
17. **상품 등록 권한**: [상품 등록] 단축은 매니저+ 만 가능.
18. **신규 상품 자동 추가**: 상품 등록 후 POS 복귀 시 자동 추가 옵션 (선택).
19. **카드/현금 가격 검증**: 결제수단과 가격 유형 일치 검증, 불일치 시 SCR-S003에서 정정.
20. **장바구니 동시성**: 동일 카운터 단말에서만 장바구니 유지, 새로고침 시 초기화 (의도적).
21. **본사 통합 모드 비활성**: POS 화면은 항상 단일 지점 (현장 판매), 본사 통합 모드 미적용.
22. **감사 로그**: 장바구니 구성·구매자 변경·결제 진입 모두 SCR-097 기록.
