## 기능 목적

처리된 환불 내역을 조회하고 통계를 확인하는 화면이다. 이번 달 환불 총액·건수·평균 환불액·위약금 합계를 파악하고, 기간별로 환불 이력을 조회한다. 환불 사유와 처리 상태, 원판매 담당자별 환불 책임 현황을 함께 확인할 수 있어 고객 불만 패턴 파악 및 환불 정책 점검에 활용한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 이번 달 환불 총액 | - |
| 환불 건수 | - |
| 평균 환불액 | - |
| 위약금 합계 | 조회 기간 내 공제 위약금 총액 |

### 날짜 필터

이번 달 / 지난 달 / 최근 3개월 프리셋 + 직접 입력 + [조회].

### 환불 목록 테이블

| 컬럼 | 표시 |
|------|------|
| No / 환불일 / 회원명 / 상품명 | - |
| 환불금액 | 빨강 강조 |
| 차감금 / 위약금 / 실환불액 | - |
| 환불방법 / 결제경로 / 원결제ID | - |
| 사유 | 보조 텍스트 |
| 처리자 | - |
| 상태 배지 | 완료(초록)/처리중(노랑)/거절(빨강) |

### 원판매 담당자별 환불 책임 탭

원매출 판매 귀속 담당자별 환불 건수 / 환불 금액 / 위약금 합계 / 환불률 (원매출 대비).

### 엑셀 내보내기

현재 조회 환불 내역 전체 엑셀 다운로드.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 기간 조회, 엑셀 |
| 센터장 / 매니저 | 소속 지점 매출 | 기간 조회, 엑셀, 환불 처리 |
| FC | 담당 회원 결제 | 조회만 |
| 트레이너 / 스태프 | 매출 조회만 | 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 환불 관리" 진입
2. 상단 지표 카드로 환불 현황 + 위약금 회수 규모 파악
3. 날짜 프리셋 또는 직접 입력 + [조회]
4. 테이블에서 환불 이력·사유·상태 확인
5. 원판매 담당자별 책임 탭으로 특정 담당자 환불 집중 여부 확인
6. 엑셀로 내역 저장

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 테이블 로딩 |
| 정상 표시 | 지표 + 테이블 |
| 데이터 없음 | 빈 테이블 안내 |
| 오류 | 토스트 알림 |

## 비즈니스 규칙

1. 위약금 = 결제 후 7일 이내 0% / 30일 이내 30% / 30일 초과 50% (정책 세트 기준).
2. 환불은 PAY-05 결제 취소 / 부분 환불에서 처리되어 본 화면에 자동 반영.
3. 원판매 담당자별 환불률은 원매출 대비 비율로 계산.
4. 환불 사유 4종 + 직접 입력 + 처리자/일시 자동 기록.
5. 미결제 링크는 환불 아닌 링크 취소로 처리.
