## 기능 목적

센터 현장에서 직원이 직접 상품을 선택하고 구매자를 지정해 결제 화면으로 넘기는 현장 판매(POS) 화면이다. 카운터에서 회원이 방문했을 때 이용권·PT·GX 등 다양한 상품을 빠르게 장바구니에 담고, 현금가·카드가를 선택한 뒤 결제 화면(SCR-S003)으로 이동한다. 이 화면은 회원/상품 선택과 장바구니 구성을 담당하며, 실제 수납 방식 결정(전액/계약금/잔액/결제링크)은 결제 처리 화면에서 확정한다.

## 주요 구성요소

### 카테고리 탭 + 상품 검색

- **카테고리 탭**: 이용권 / PT / GX / 기타 + 소속 상품 수 배지
- **상품 검색**: 상품명 실시간 검색

### 상품 카드 그리드

| 카드 표시 |
|---|
| 상품 유형 배지 (회원권/수강권/대여권/일반) |
| 상품명 |
| 기간 / 횟수 |
| 현금가 / 카드가 |

클릭 시 장바구니 추가 (동일 상품 재클릭 → 수량 +1).

### 장바구니 패널 (우측)

- 담긴 상품 목록
- 수량 조절 (-/+)
- 현금/카드 가격 유형 전환
- 개별 상품 삭제
- 전체 삭제 버튼
- 빈 상태 안내

### 구매자 선택 + 검색 모달 (DLG-S002)

- 회원 검색 버튼 → 모달 진입
- 이름 또는 전화번호 검색
- 선택된 회원: 이름·전화번호 표시 + X 해제
- 마일리지 결제 시 회원 지정 필수
- 비회원 결제 가능

### 총 합계 + 결제 진입

- 장바구니 하단 총 결제 금액
- [결제하기] (장바구니 1건 이상 시 활성) → SCR-S003 진입
- [결제링크 발송] (회원 선택 시 활성) → SCR-S003 + 링크 발송 경로

### 상품 등록 단축 진입

[상품 등록] → SCR-P002 단축 진입.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 상품/장바구니/구매자/결제 이동/링크 발송/상품 등록 |
| 센터장 / 매니저 | 소속 지점 매출 | 동일 |
| FC | 담당 회원 결제 | 상품/장바구니/구매자/결제 이동/링크 발송 |
| 트레이너 / 스태프 | 매출 조회만 | POS 접근 불가 또는 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > POS 판매" 또는 SCR-S001 [신규 결제(POS)]
2. 카테고리 탭 또는 검색으로 상품 찾기
3. 상품 카드 클릭 → 장바구니 추가
4. 수량 조절 / 현금·카드 전환 / 개별 삭제
5. 회원 검색 (DLG-S002)으로 구매자 지정 (마일리지 결제 시 필수)
6. 총 합계 확인 → [결제하기] → SCR-S003
7. 또는 [결제링크 발송] → SCR-S003 + 링크 경로

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 상품 그리드 스켈레톤 |
| 상품 정상 표시 | 카테고리 카드 그리드 |
| 상품 없음 | 빈 상태 안내 |
| 품절 상품 | 흐림 + "품절" 배지 + 클릭 차단 |
| 재고 부족 | "재고 부족 (N개)" 경고 |
| 장바구니 비어있음 | 안내 + 결제 비활성 |
| 장바구니 구성 중 | 목록 + 합계 + 결제 활성 |
| 구매자 미선택 | 비회원 진행 가능 |
| 구매자 선택됨 | 이름·전화번호 표시 + X 해제 |
| 결제링크 발송 가능 | 회원 + 장바구니 → 버튼 활성 |

## 비즈니스 규칙

1. 마일리지 결제 시 회원 지정 필수.
2. 비회원 결제는 비회원 거래로 기록.
3. 동일 상품 재클릭 시 수량 +1.
4. 재고 0 상품은 클릭 차단.
5. 재고 5개 이하는 경고 배지.
6. 결제링크 발송은 회원 선택 시에만 활성.
