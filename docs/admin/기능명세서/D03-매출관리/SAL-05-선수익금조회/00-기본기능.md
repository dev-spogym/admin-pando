## 기능 목적

회원이 선납한 금액 중 아직 서비스가 제공되지 않은 금액(선수익금)의 현황을 조회하는 화면이다. 총 선수익금·이미 인식된 금액·아직 인식되지 않은 잔여 금액·이번 달 인식 예정 금액을 파악하고 계약별 진행률을 확인한다. 회원권 기간 믹스(1·3·6·12개월·기타)를 서비스일수 판정 기준으로 연결해 회계 관점의 매출 인식 기간을 일관되게 관리한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 총 선수익금 | 합계 |
| 인식 완료 금액 | 초록 강조 |
| 잔여 선수익금 | 포인트 컬러 굵게 |
| 이번 달 인식 예정 | 합계 |

### 기간 필터

시작일 ~ 종료일. 기본값 이번 달 전체.

### 선수익금 목록 테이블

| 컬럼 | 표시 |
|------|------|
| 회원명 | - |
| 상품명 | - |
| 총액 | - |
| 인식 완료 | 초록 강조 |
| 잔여 | 포인트 컬러 굵게 |
| 시작일 / 종료일 | YYYY-MM-DD |
| 진행률 | 프로그레스 바 + % (높을수록 주황~빨강) |

### 서비스일수 판정

매출통계의 개월별 판매 비율과 동일한 1·3·6·12·기타 5버킷 사용.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 기간 필터, 전체 조회 |
| 센터장 / 매니저 | 소속 지점 매출 | 기간 필터, 지점 조회 |
| FC | 담당 회원 결제 | 조회만 |
| 트레이너 / 스태프 | 매출 조회만 | 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 선수익금 조회" 진입
2. 상단 지표 카드로 전체 선수익금 현황 파악
3. 기간 필터로 계약 시작일 범위 좁힘
4. 테이블에서 계약별 인식 현황과 진행률 확인
5. 잔여 큰 계약 / 이번 달 종료 예정 계약 우선 주목

## 비즈니스 규칙

1. 서비스일수: 1개월=30일, 3개월=90일, 6개월=180일, 12개월=365일.
2. 기타 기간은 상품 마스터 실제 서비스일수 또는 계약 종료일 우선.
3. 기간 버킷 원천: `[주간월간보고]` 주차별 V5:Z5.
4. 매출 원장 `durationMonths` 값 있으면 우선.
5. 선수익금 인식 = `총액 × (경과일 / 총 서비스일수)`.
6. 환불 건은 계산 제외.
