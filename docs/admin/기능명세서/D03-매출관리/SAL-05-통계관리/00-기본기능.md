## 기능 목적

수업·매출·예약·이용 현황을 하나의 화면에서 통합 조회하고, 원하는 기간·유형·담당자·구분·회원 상태로 필터링해 CSV 파일로 내려받는 통계 보고서 화면이다. 매출현황의 `받을금액`은 VAT 제외 순매출로 명확히 정의해 재무 보고와 수익성 분석에 활용한다. 레거시 업무 시스템 스타일로 설계되어 PC 기반 센터 관리 프로그램에 익숙한 운영자도 빠르게 활용한다.

운영 맥락:
- **회계 담당자 월말 마감**: 매출현황 탭 → VAT 제외 순매출 합계 → 회계 시스템 입력
- **본사 슈퍼관리자 전사 통계 보고**: 통합 모드 + 4탭 → 전사 운영 실적 보고서
- **센터장 월간 운영 보고서**: 4탭 통합 + CSV 다운로드 → 운영 보고
- **트레이너 본인 수업 현황 점검**: 수업현황 탭 → 본인 수업 + 회원 출석률 (RLS 제한)
- **마케팅 팀 회원 활동 분석**: 이용현황 탭 → 활성 회원 수·재방문률
- **본사 인사 평가 자료**: 담당자 필터 + 매출 집계 → 인사 평가 자료
- **세무 신고 자료**: VAT 제외 순매출·VAT 포함 매출·할인·수수료 → 부가세 신고
- **레거시 사용자 호환**: 시작/종료일 직접 입력 + 4종 드롭다운 + [조회]/[신규]/[엑셀]/[종료] 버튼 (PC 기반 ERP 스타일)
- **CSV 다운로드 자동 파일명**: 탭명·기간 포함 (`매출현황_2026-05-01_2026-05-31.csv`)
- **합계 행 노란색 배경**: 전체 건수 + 각 금액 컬럼 합계, 시각적 구분

본 화면은 SAL-03 매출 통계와 달리 차트 없이 표 + CSV 중심으로 회계·세무·인사 평가 등 정형 보고 자료에 최적화되어 있다.

## 주요 구성요소

### 기간 입력

시작일 ~ 종료일 직접 입력. 기본값은 이번 달 전체.

### 필터 드롭다운 (4종)

| 필터 | 옵션 |
|------|------|
| 수업 유형 | 전체 + PT / GX / 골프 / 기타 중 현재 기간·권한 범위 데이터에 존재하는 값 |
| 담당자 | 전체 + 현재 기간·권한 범위 데이터에 존재하는 담당자명. 미지정 데이터는 "미지정"으로 표시 |
| 구분 | 전체 + 통계 테이블의 `구분` 컬럼에 존재하는 값. 매출현황은 신규 / 재등록 / 휴면복귀 / 종목추가 / 업그레이드 / 기타 기준을 사용 |
| 회원 상태 | 전체 + 활성 / 만료 / 예정 / 임박 / 홀딩 / 미등록 / 탈퇴 중 현재 기간·권한 범위 데이터에 존재하는 값 |

동적 생성은 운영자가 옵션을 새로 등록하는 기능이 아니다. 기간, 지점, 계정 권한 범위로 조회 가능한 데이터에서 각 필터 컬럼의 고유값을 추출해 드롭다운 선택지로 표시하는 방식이다. `전체`는 항상 첫 번째 옵션으로 제공하고, 데이터가 없는 필터는 `전체`만 노출한다. `정지`는 회원 상태값이 아니라 제한 플래그이므로 회원 상태 필터 옵션에 포함하지 않는다.

### 현황 탭 (4개)

수업현황 / 매출현황 / 예약현황 / 이용현황. 동일 데이터에서 해당 유형 행만 표시.

### 통계 테이블 (17개 컬럼)

| 컬럼 |
|------|
| 일자 / 담당자 / 회원명 / 성별 / 휴대폰 / 구분 / 판매금액 / 할인금액 / 받을금액(VAT 제외 순매출) / 카드 / 현금 / 계좌이체 / 마일리지(포인트) 사용액 / 미수발생 / 미수입금 / 받은금액 / 비고 |

상품권은 v1 계약 범위의 결제수단으로 정의되어 있지 않으므로 SAL-05 통계 컬럼에서 제외한다. 마일리지(포인트)는 결제수단 수납 행이 아니며, 과거 결제 또는 외부 정산 데이터에 사용액이 존재하는 경우 집계용으로만 표시한다.

### VAT 제외 매출 매핑

SAL-05-05는 별도 화면 기능이나 버튼이 아니라 통계 테이블의 `판매금액`과 `받을금액`을 VAT 포함/제외 기준으로 구분하는 표시·집계 기준이다.

| 항목 | 기준 |
|---|---|
| 판매금액 | VAT 포함 총 판매금액 기준으로 표시한다. |
| 할인금액 | 판매금액에서 차감된 할인 금액을 표시한다. |
| 받을금액 | VAT를 제외한 순매출이다. 재무 보고, 수익성 분석, CSV 다운로드 합계 기준으로 사용한다. |
| `[월매출]` I열 매핑 | 레거시/외부 시트에서 이미 계산된 VAT 제외 순매출 값이 있으면 해당 값을 `받을금액`에 우선 매핑한다. |
| fallback 계산 | `[월매출]` I열 값이 없고 VAT 포함 결제액만 있으면 공급가액 기준으로 환산해 `받을금액`에 표시한다. 일반 과세 상품은 `VAT 포함 금액 ÷ 1.1`을 원 단위 반올림한다. 면세 상품은 VAT가 0원이므로 판매금액과 받을금액을 동일하게 본다. |

### 합계 행

테이블 하단 노란색 배경. 전체 건수 + 각 금액 컬럼 합계.

### 액션 버튼

SAL-05-07은 통계 관리 화면의 화면 조작 버튼 묶음이다. 매출 입력, 결제 처리, 급여 입력 같은 업무 데이터를 생성·수정하는 기능이 아니다.

| 버튼 | 트리거 | 동작 | 비활성/제한 |
|---|---|---|---|
| [조회] | 시작일·종료일, 필터 4종, 현황 탭을 선택한 뒤 클릭 | 현재 조건으로 통계 데이터를 다시 불러오고, 테이블·합계 행·드롭다운 옵션을 갱신한다. | 시작일이 종료일보다 늦으면 비활성 또는 오류 안내 |
| [신규] | 조건 초기화가 필요할 때 클릭 | 신규 데이터를 등록하지 않는다. 기간은 이번 달 기본값으로 되돌리고, 필터는 `전체`, 현황 탭은 기본 탭(수업현황), 테이블 결과는 빈 상태로 초기화한다. | 조회 중에는 비활성 |
| [엑셀(CSV)] | 조회 결과를 파일로 내려받을 때 클릭 | 현재 선택한 현황 탭과 기간·필터 조건이 적용된 결과만 CSV로 다운로드한다. 파일명은 `{탭명}_{시작일}_{종료일}.csv`를 사용한다. | 데이터 0건이면 "내보낼 데이터가 없습니다". 30,000행 초과는 백그라운드 다운로드. CSV 권한이 없으면 hidden |
| [종료] | 통계 관리 화면을 닫거나 빠져나갈 때 클릭 | 직전 화면으로 복귀한다. 직전 화면 이력이 없으면 매출관리 > 매출현황(SCR-S001)으로 이동한다. | 복귀 실패 시 토스트 후 사이드바 이동 허용 |

정합성 메모: SAL-05-07 액션 버튼은 통계 관리 화면의 조회/신규/엑셀(CSV)/종료 조작만 의미한다. 급여 입력, 매출 입력, 결제 처리 같은 업무 입력 액션과 연결하지 않는다.

## 주요 UX 흐름

### 회계 마감 흐름
1. 사이드바 "매출관리 > 통계 관리" 진입
2. 시작/종료일 입력 (이번 달 기본)
3. 매출현황 탭 선택
4. 4종 필터 드롭다운 선택 (선택)
5. [조회] → 데이터 로드
6. 합계 행 = 받을금액(VAT 제외) 확인
7. [엑셀(CSV)] 다운로드 → 회계 시스템 입력

### 4탭 전환 흐름
1. [조회] 후 데이터 로드
2. 수업현황 → 매출현황 → 예약현황 → 이용현황 전환
3. 동일 데이터에서 해당 유형 행만 표시

### 분기·예외 흐름
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 통합 + 지점 컬럼 추가
- **드롭다운 동적 생성**: 기간·지점·권한 범위 데이터에서 수업 유형/담당자/구분/회원 상태 고유값을 추출해 옵션 자동 생성, 데이터 변경 시 옵션 갱신
- **데이터 없음**: 빈 행 12개로 공간 유지 (레거시 ERP 스타일)
- **CSV 다운로드 권한 부족**: 버튼 hidden 또는 "권한 없음" 안내
- **VAT 제외 받을금액 산출 실패**: `[월매출]` I열 값과 VAT 포함 결제액 fallback이 모두 없으면 0원 표시 + 운영자 알림
- **합계 행 시각화**: 노란색 배경 + 굵은 글씨, 인쇄 시에도 유지
- **CSV 파일명 규칙**: `{탭명}_{시작일}_{종료일}.csv` (예: `매출현황_2026-05-01_2026-05-31.csv`)
- **[신규] 초기화**: 모든 필터/결과 초기화, 기간만 이번 달 기본값 복원
- **[종료] 동작**: 이전 화면 복귀 (사이드바 또는 대시보드)
- **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만
- **CSV 다운로드 30,000행 초과**: 비동기 백그라운드 다운로드 + 완료 알림

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 상태 | 이번 달 기본 + 빈 테이블 |
| 로딩 중 | "조회중" 합계 행 표시 |
| 정상 표시 | 데이터 + 합계 행 |
| 데이터 없음 | 빈 행 12개로 공간 유지 |

| CSV 다운로드 중 | 토스트 진행률 |
| 권한 미달 | CSV 버튼 hidden |
| 통합 모드 | 지점 컬럼 추가 |
| 매핑 오류 | 받을금액 0원 + 알림 |

## 비즈니스 규칙

1. **VAT 제외 정의**: `받을금액`은 부가세 제외 순매출 기준이며, 판매금액과 구분해 재무 보고·CSV 합계에 사용한다.
2. **VAT 매핑**: `[월매출]` I열 `ARRAYFORMULA` 산출값이 있으면 `받을금액`에 우선 매핑한다. 값이 없으면 VAT 포함 결제액에서 공급가액을 환산한다.
3. **VAT fallback 계산**: 일반 과세 상품은 `VAT 포함 금액 ÷ 1.1`을 원 단위 반올림한다. 면세 상품은 VAT가 0원이므로 판매금액과 받을금액을 동일하게 본다.
4. **드롭다운 동적 생성**: 4종 필터 선택지는 기간·지점·권한 범위 데이터에서 고유값을 추출해 만든다. 운영자가 옵션을 새로 등록하는 기능이 아니며 `전체`는 항상 첫 번째 옵션이다.
5. **CSV 파일명**: `{탭명}_{시작일}_{종료일}.csv`.
6. **합계 행 시각화**: 노란색 배경 + 굵은 글씨.
7. **빈 행 공간**: 데이터 없을 때 빈 행 12개로 공간 유지 (레거시 ERP 스타일).
8. **본사 통합 모드**: 본사 슈퍼관리자만 활성, 지점 컬럼 추가.
9. **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만.
10. **VAT 제외 받을금액 산출 실패**: I열 매핑과 fallback 환산 모두 실패하면 0원 + 운영자 알림.
11. **CSV 다운로드 한도**: 30,000행 초과 시 비동기 백그라운드.
12. **17개 컬럼 고정**: 일자/담당자/회원/성별/휴대폰/구분/판매/할인/받을금액(VAT 제외)/카드/현금/계좌이체/마일리지(포인트) 사용액/미수발생/미수입금/받은금액/비고.
13. **4탭 동일 데이터**: 동일 조회 데이터에서 유형 필터로 분기 (수업/매출/예약/이용).
14. **레거시 ERP 스타일**: [조회]/[신규]/[엑셀]/[종료] 버튼 패턴.
15. **CSV 인코딩**: UTF-8 with BOM (Excel 한글 호환).
16. **CSV 한 줄 형식**: 콤마 구분, 텍스트 큰따옴표 감쌈, 줄바꿈 LF.
17. **데이터 보관**: 매출 통계 5년 보관 (회계·세무).
18. **익명화**: 5년 경과 시 PII 마스킹.
19. **감사 로그**: CSV 다운로드는 SCR-097 기록 (`actor`, `period`, `tab`, `count`).
20. **세무 신고 호환**: VAT 제외 / VAT 포함 / 할인 분리, 부가세 신고 자료에 직접 활용.
21. **합계 검증**: 합계 행 = 컬럼별 합산, 검증 실패 시 운영자 알림.
22. **드롭다운 옵션 캐시**: 데이터 갱신 시 캐시 무효화.
23. **[종료] 복귀**: 이전 화면 또는 대시보드.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-S005`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 표와 아래 API 기준을 같이 적용합니다.

- **연계 화면**: SCR-S001 / SCR-S004 매출 통계 / SCR-094 KPI / SCR-097 감사 로그
- **API 기준**: `GET /api/sales/statistics?period=&filters=` / `GET /api/sales/statistics/export` / `GET /api/sales/statistics/dropdown-options`
