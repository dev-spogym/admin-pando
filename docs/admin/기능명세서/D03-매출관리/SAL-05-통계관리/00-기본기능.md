## 기능 목적

수업·매출·예약·이용 현황을 하나의 화면에서 통합 조회하고, 원하는 기간·유형·담당자·구분·회원 상태로 필터링해 CSV 파일로 내려받는 통계 보고서 화면이다. 매출현황의 `받을금액`은 VAT 제외 순매출로 명확히 정의해 재무 보고와 수익성 분석에 활용한다. 레거시 업무 시스템 스타일로 설계되어 PC 기반 센터 관리 프로그램에 익숙한 운영자도 빠르게 활용한다.

운영 맥락:
- **회계 담당자 월말 마감**: 매출현황 탭 → VAT 제외 순매출 합계 → 회계 시스템 입력
- **본사 슈퍼관리자 전사 통계 보고**: 통합 모드 + 4탭 → 전사 운영 실적 보고서
- **센터장 월간 운영 보고서**: 4탭 통합 + CSV 다운로드 → 운영 보고
- **트레이너 본인 수업 현황 점검**: 수업현황 탭 → 본인 수업 + 회원 출석률 (RLS 제한)
- **마케팅 팀 회원 활동 분석**: 이용현황 탭 → 활성 회원 수·재방문률
- **본사 인사 평가 자료**: 담당자 필터 + 매출 집계 → 인사 평가 자료
- **세무 신고 자료**: VAT 제외 순매출·VAT 포함 매출·할인·수수료 → 부가세 신고
- **레거시 사용자 호환**: 시작/종료일 직접 입력 + 4종 드롭다운 + [조회]/[신규]/[엑셀]/[종료] 버튼 (PC 기반 ERP 스타일)
- **CSV 다운로드 자동 파일명**: 탭명·기간 포함 (`매출현황_2026-05-01_2026-05-31.csv`)
- **합계 행 노란색 배경**: 전체 건수 + 각 금액 컬럼 합계, 시각적 구분

본 화면은 SAL-03 매출 통계와 달리 차트 없이 표 + CSV 중심으로 회계·세무·인사 평가 등 정형 보고 자료에 최적화되어 있다.

## 주요 구성요소

### 기간 입력

시작일 ~ 종료일 직접 입력. 기본값은 이번 달 전체.

### 필터 드롭다운 (4종)

| 필터 | 옵션 |
|------|------|
| 수업 유형 | 동적 생성 |
| 담당자 | 동적 생성 |
| 구분 | 동적 생성 |
| 회원 상태 | 동적 생성 |

각 드롭다운 선택지는 현재 조회된 데이터에서 동적 생성.

### 현황 탭 (4개)

수업현황 / 매출현황 / 예약현황 / 이용현황. 동일 데이터에서 해당 유형 행만 표시.

### 통계 테이블 (17개 컬럼)

| 컬럼 |
|------|
| 일자 / 담당자 / 회원명 / 성별 / 휴대폰 / 구분 / 판매금액 / 할인금액 / 받을금액(VAT 제외 순매출) / 카드 / 현금 / 상품권 / 포인트 / 미수발생 / 미수입금 / 받은금액 / 비고 |

### VAT 제외 매출 매핑

`[월매출]` I열 `ARRAYFORMULA` 산출값을 `받을금액`에 매핑.

### 합계 행

테이블 하단 노란색 배경. 전체 건수 + 각 금액 컬럼 합계.

### 액션 버튼

- [조회] — 기간/필터 적용 데이터 로드
- [신규] — 모든 필터/결과 초기화
- [엑셀(CSV) 내보내기] — 파일명에 탭명·기간 포함
- [종료] — 이전 화면 복귀

## 주요 UX 흐름

### 회계 마감 흐름
1. 사이드바 "매출관리 > 통계 관리" 진입
2. 시작/종료일 입력 (이번 달 기본)
3. 매출현황 탭 선택
4. 4종 필터 드롭다운 선택 (선택)
5. [조회] → 데이터 로드
6. 합계 행 = 받을금액(VAT 제외) 확인
7. [엑셀(CSV)] 다운로드 → 회계 시스템 입력

### 4탭 전환 흐름
1. [조회] 후 데이터 로드
2. 수업현황 → 매출현황 → 예약현황 → 이용현황 전환
3. 동일 데이터에서 해당 유형 행만 표시

### 분기·예외 흐름
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 통합 + 지점 컬럼 추가
- **드롭다운 동적 생성**: 현재 조회 데이터 기반 옵션 자동 생성, 데이터 변경 시 옵션 갱신
- **데이터 없음**: 빈 행 12개로 공간 유지 (레거시 ERP 스타일)
- **CSV 다운로드 권한 부족**: 버튼 hidden 또는 "권한 없음" 안내
- **VAT 제외 매핑 누락**: `[월매출]` I열 매핑 실패 시 0원 표시 + 운영자 알림
- **합계 행 시각화**: 노란색 배경 + 굵은 글씨, 인쇄 시에도 유지
- **CSV 파일명 규칙**: `{탭명}_{시작일}_{종료일}.csv` (예: `매출현황_2026-05-01_2026-05-31.csv`)
- **[신규] 초기화**: 모든 필터/결과 초기화, 기간만 이번 달 기본값 복원
- **[종료] 동작**: 이전 화면 복귀 (사이드바 또는 대시보드)
- **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만
- **CSV 다운로드 30,000행 초과**: 비동기 백그라운드 다운로드 + 완료 알림

| 매핑 오류 | 받을금액 0원 + 알림 |

## 비즈니스 규칙

1. **VAT 제외 정의**: `받을금액`은 부가세 제외 순매출 기준.
2. **VAT 매핑**: `[월매출]` I열 `ARRAYFORMULA` 산출값 매핑.
3. **드롭다운 동적 생성**: 4종 필터 선택지는 현재 데이터 기반 동적 생성.
4. **CSV 파일명**: `{탭명}_{시작일}_{종료일}.csv`.
5. **합계 행 시각화**: 노란색 배경 + 굵은 글씨.
6. **빈 행 공간**: 데이터 없을 때 빈 행 12개로 공간 유지 (레거시 ERP 스타일).
7. **본사 통합 모드**: 본사 슈퍼관리자만 활성, 지점 컬럼 추가.
8. **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만.
9. **VAT 매핑 누락**: I열 매핑 실패 시 0원 + 운영자 알림.
10. **CSV 다운로드 한도**: 30,000행 초과 시 비동기 백그라운드.
11. **17개 컬럼 고정**: 일자/담당자/회원/성별/휴대폰/구분/판매/할인/받을금액(VAT 제외)/카드/현금/상품권/포인트/미수발생/미수입금/받은금액/비고.
12. **4탭 동일 데이터**: 동일 조회 데이터에서 유형 필터로 분기 (수업/매출/예약/이용).
13. **레거시 ERP 스타일**: [조회]/[신규]/[엑셀]/[종료] 버튼 패턴.
14. **CSV 인코딩**: UTF-8 with BOM (Excel 한글 호환).
15. **CSV 한 줄 형식**: 콤마 구분, 텍스트 큰따옴표 감쌈, 줄바꿈 LF.
16. **데이터 보관**: 매출 통계 5년 보관 (회계·세무).
17. **익명화**: 5년 경과 시 PII 마스킹.
18. **감사 로그**: CSV 다운로드는 SCR-097 기록 (`actor`, `period`, `tab`, `count`).
19. **세무 신고 호환**: VAT 제외 / VAT 포함 / 할인 분리, 부가세 신고 자료에 직접 활용.
20. **합계 검증**: 합계 행 = 컬럼별 합산, 검증 실패 시 운영자 알림.
21. **드롭다운 옵션 캐시**: 데이터 갱신 시 캐시 무효화.
22. **[종료] 복귀**: 이전 화면 또는 대시보드.

## 자동화 / 배치 / 이벤트 연계

| 연계 대상 | 트리거 | 영향 |
