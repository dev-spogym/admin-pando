## 기능 목적

법인 회원 또는 사업자 회원에게 세금계산서를 발행하고, 발행 이력을 조회·관리하는 화면이다. 세금계산서 발행이 필요한 결제 건을 선택해 공급받는 자 정보·품목 내역을 확정한 뒤 발행 처리하고, 발행된 세금계산서의 상태(발행 완료·전송 완료·오류)를 추적한다. 회계 마감 및 세무 신고에 필요한 발행 이력을 한 곳에서 관리할 수 있다.

운영 맥락:
- **회계 담당자 월말 일괄 발행**: 발행 탭 → 미발행 결제 건 일괄 발행 → 이메일 자동 전송
- **본사 슈퍼관리자 전사 세금계산서 통합 관리**: 통합 모드 + 지점별 발행 이력 점검
- **세무 담당자 부가세 신고 자료**: 이력 탭 → 분기별 발행 합계 → 부가세 신고
- **법인 영업 담당자 B2B 결제 후속**: 법인 회원 결제 직후 발행 → 즉시 이메일 전송
- **국세청 진위 확인**: 사업자번호 입력 시 국세청 API 검증 → 위·휴·폐업 판정
- **재발행 요청 처리**: 회원 이메일 분실·오류 시 [재발행] → 자동 채움 + 재발행
- **마이너스 세금계산서**: SAL-EXT-04 환불 시 마이너스 발행 (취소) → 회계 정정
- **PDF 첨부 이메일 전송**: 발행 완료 후 PDF 자동 생성 → 공급받는 자 이메일 전송
- **발행 이력 5년 보관**: 국세 기본법 준수, 5년 후 익명화 (단 사업자 정보는 보존)
- **국세청 전자세금계산서 API 연동**: 실시간 전송 + webhook 응답 처리

본 화면은 회계·세무 컴플라이언스의 핵심으로, 발행 후 수정은 불가하며 잘못 발행한 건은 마이너스 세금계산서로 취소 발행한다.

- **이력 탭**: 기발행 세금계산서 목록 조회·관리

| 필터 | 설명 |
|------|------|

| 상태 | 미발행 / 발행 가능 |

### 세금계산서 발행 폼 (DLG-S011)

| 항목 | 입력 |
|------|------|
| 사업자번호 | 10자리 자동 포맷 + 국세청 검증 |
| 상호 | 텍스트 (필수) |
| 대표자 | 텍스트 |
| 업태 / 종목 | 텍스트 |
| 이메일 | 형식 검증 (전송용) |
| 공급 품목 | 발행 대상 결제 건의 상품 라인에서 상품명 / 수량 / VAT 제외 단가 / 공급가액 자동 채움 |
| 공급가액 | 자동 계산 |
| 부가세 | 자동 계산 (10%) |
| 합계 | 공급가액 + 부가세 |

#### 공급 품목 자동 채움 기준

`공급 품목 자동 채움`은 발행 대상 결제 건을 선택하면 해당 결제에 포함된 상품 라인을 세금계산서 품목 행으로 자동 생성하는 기능이다. 별도 상품을 새로 선택하는 기능이 아니며, 발행 대상 결제 건의 실제 판매 내역을 세금계산서 폼에 복사해 운영자가 확인할 수 있게 하는 기능이다.

| 품목 행 항목 | 자동 채움 기준 | 수정 기준 |
|---|---|---|
| 상품명 | 결제 건에 포함된 상품명. 복수 상품 결제는 상품별로 행을 분리 | 발행 전 표시명만 수정 가능, 원결제 상품 연결은 유지 |
| 수량 | 결제 상품 수량. 회원권·수강권·락커처럼 수량 개념이 없는 상품은 1 | 발행 전 수정 가능하나 금액 합계가 원결제 과세 대상 금액과 일치해야 함 |
| 단가 | 해당 상품의 최종 판매금액을 수량으로 나눈 VAT 제외 단가 | 금액 합계 검증 기준에 포함 |
| 금액 | 단가 × 수량. 품목별 공급가액 | 품목 금액 합계가 공급가액 합계와 일치해야 발행 가능 |
| 과세 구분 | 상품 과세/면세 설정 또는 원결제 세액 기준 | 면세 품목은 부가세 0원 표시 |

할인은 원결제에 반영된 최종 판매금액 기준으로 배분해 품목 금액에 반영한다. 카드/현금/계좌이체/포인트 같은 결제수단은 공급 품목이 아니므로 품목 행으로 만들지 않는다. 환불로 인한 마이너스 세금계산서는 원 세금계산서의 품목 행을 기준으로 금액을 음수로 자동 채움한다.

### 발행 이력 테이블 (이력 탭)

| 컬럼 | 설명 | 클릭/동작 |
|------|------|---|
| 발행일 | 세금계산서 발행 기준일. `YYYY-MM-DD` 형식 | 정렬 가능 |
| 공급받는 자 | 거래처 상호 + 사업자번호 마스킹 표시 | 텍스트 표시 |
| 공급가액 | 부가세 제외 공급가액 합계 | 천 단위 콤마 표시 |
| 부가세 | 과세 품목 공급가액의 10%, 면세 품목은 0원 | 천 단위 콤마 표시 |
| 합계 | 공급가액 + 부가세 | 천 단위 콤마 표시 |
| 상태 | 발행 완료 / 전송 완료 / 오류 / 취소 발행 배지 | 상태별 색상 배지 표시 |
| 액션 | [상세] / [이메일 전송] / [재발행] | 상세는 세금계산서 상세 다이얼로그를 열고, 이메일 전송은 등록 이메일로 재전송, 재발행은 오류·취소 대상만 가능 |

[상세] 액션은 기획 코드 이동이 아니라 선택한 세금계산서의 상세 내용을 확인하는 기능이다. 클릭 시 세금계산서 상세 다이얼로그(DLG-S010)를 열어 세금계산서 번호, 발행일시, 발행 상태, 공급자/공급받는자 정보, 공급 품목, 공급가액, 부가세, 합계, 이메일 전송 이력을 확인한다.

### 이메일 전송

발행 완료된 세금계산서를 공급받는 자 이메일로 PDF 첨부 전송. 전송 성공 시 상태 → "전송 완료".

### 엑셀 내보내기

발행 이력 엑셀 다운로드. 파일명 `yyyymm_지점_세금계산서이력.xlsx`.

## 주요 UX 흐름

### 세금계산서 발행
1. 사이드바 → "매출관리 > 세금계산서 발행" 진입
2. 상단 카드로 이번 달 발행 현황·미발행 대기 파악
3. 발행 탭에서 대상 결제 건 선택
4. DLG-S011 발행 폼: 사업자 정보·이메일 입력
5. 사업자번호 → 국세청 진위 확인 (자동)
6. 공급 품목·공급가액·부가세·합계 확인
7. [발행] 클릭 → 발행 완료 토스트
8. [이메일 전송] → 공급받는 자 이메일로 전송
9. 이력 탭에서 발행 이력 + 상태 확인

### 재발행 흐름
1. 이력 탭 → 오류 건 [재발행]
2. 발행 폼 자동 채움 → 재발행
3. 국세청 API 재전송

### 마이너스 세금계산서 흐름
1. SAL-EXT-04 환불 webhook 수신
2. 자동 마이너스 발행 (취소 발행)
3. 회계 정정 + 이메일 알림

### 분기·예외 흐름
- **사업자번호 위/휴/폐업**: 국세청 API 응답 → 위/휴/폐업 시 발행 차단 + 안내
- **사업자번호 형식 오류**: 10자리 미만 → 인라인 에러
- **이메일 형식 오류**: 인라인 에러 + 재입력 안내
- **국세청 API 응답 지연**: 처리 중 로딩 + 60초 타임아웃 → 재시도 안내
- **발행 후 수정 시도**: "발행 후 수정 불가" 안내 + 마이너스 발행 안내
- **이메일 전송 실패**: 상태 "발행 완료" 유지 + 재전송 액션 제공
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 지점 컬럼 추가
- **권한별 발행**: 매니저+ 만 발행, FC는 이력 조회만
- **마이너스 세금계산서 자동 발행**: SAL-EXT-04 환불 webhook 자동 처리
- **발행 한도**: 일별 1000건 제한 (국세청 API 처리량)
- **환불 시 마이너스 발행 알림**: PAY-02 환불 관리에서 안내

| 오류 | "오류" 배지 + 안내 |
| 데이터 없음 | 빈 상태 안내 |
| 처리 중 | 발행 버튼 로딩 |
| 국세청 API 응답 대기 | 처리 중 + 타임아웃 카운터 |
| 국세청 진위 실패 (위·휴·폐업) | 발행 차단 + 안내 |
| 마이너스 발행 | "취소 발행" 배지 |
| 권한 미달 | 발행 버튼 hidden |
| 본사 통합 모드 | 지점 컬럼 추가 |

## 비즈니스 규칙

1. **국세청 진위 확인**: 사업자번호는 국세청 진위 확인 API로 검증한 후 발행 허용.
2. **부가세 자동 계산**: 부가세는 공급가액의 10%, 면세 품목은 별도 처리.
3. **발행 후 수정 차단**: 발행 후 수정 불가, 잘못 발행한 건은 마이너스 발행으로 취소.
4. **발행 이력 5년 보관**: 국세 기본법 준수, 감사 로그(SCR-097) 기록.
5. **이메일 전송 실패 처리**: 상태 "발행 완료" 유지, 별도 재전송 액션 제공.
6. **국세청 API 연동**: 실시간 전송 + webhook 응답 처리.
7. **마이너스 발행**: SAL-EXT-04 환불 webhook 시 자동 마이너스 세금계산서 발행.
8. **권한별 발행**: 매니저+ 만 발행 가능, FC는 조회만.
9. **본사 통합 모드**: 본사 슈퍼관리자만 활성.
10. **위/휴/폐업 차단**: 국세청 API 위/휴/폐업 응답 시 발행 차단.
11. **발행 한도**: 일별 1000건 제한 (API 처리량).
12. **익명화**: 5년 경과 후 PII 마스킹 (단 사업자 정보 보존).
13. **PDF 첨부 자동**: 발행 완료 후 PDF 자동 생성 + 이메일 첨부.
14. **사업자번호 자동 포맷**: 10자리 자동 포맷 (`xxx-xx-xxxxx`).
15. **공급 품목 자동 채움**: 발행 대상 결제 건의 상품 라인을 세금계산서 품목 행으로 자동 생성한다. 상품명·수량·VAT 제외 단가·공급가액을 채우며, 결제수단은 품목으로 만들지 않는다.
16. **공급가액·부가세·합계 자동**: 입력 시 자동 계산.
17. **이메일 형식 검증**: RFC 5322 기준.
18. **재발행**: 오류 건 자동 채움 + 재발행, 새 발행 ID 부여.
19. **상태 배지**: 발행 완료 (초록) / 전송 완료 (파랑) / 오류 (빨강) / 취소 발행 (주황).
20. **엑셀 다운로드**: 발행 이력 30,000건 초과 시 비동기.
21. **감사 로그**: 발행·재발행·이메일 전송·마이너스 발행 모두 SCR-097 기록.
22. **CFO 보고서**: 월별 발행 합계 자동 보고서 생성.
23. **다지점 RLS**: 지점별 발행 이력 격리.
24. **국세청 webhook 보안**: HMAC 서명 검증 + idempotency.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `SAL-EXT-02`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-S010`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-S010 세금계산서상세, DLG-S011 세금계산서발행`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
