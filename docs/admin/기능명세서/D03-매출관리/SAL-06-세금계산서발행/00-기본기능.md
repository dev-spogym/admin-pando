## 기능 목적

법인 회원 또는 사업자 회원에게 세금계산서를 발행하고, 발행 이력을 조회·관리하는 화면이다. 세금계산서 발행이 필요한 결제 건을 선택해 공급받는 자 정보·품목 내역을 확정한 뒤 발행 처리하고, 발행된 세금계산서의 상태(발행 완료·전송 완료·오류)를 추적한다. 회계 마감 및 세무 신고에 필요한 발행 이력을 한 곳에서 관리할 수 있다.

## 주요 구성요소

### 요약 지표 카드 (3개)

| 카드 | 표시 내용 |
|------|----------|
| 이번 달 발행 건수 | status=issued 카운트 |
| 이번 달 발행 총액 | 합계금액 합산 |
| 미발행 대기 건수 | 발행 가능 + 미발행 결제 건 |

### 발행 / 이력 탭

- **발행 탭**: 세금계산서 발행이 필요한 결제 건을 조회·발행
- **이력 탭**: 기발행 세금계산서 목록 조회·관리

### 발행 대상 조회 (발행 탭)

| 필터 | 설명 |
|------|------|
| 기간 | 결제일 기준 범위 |
| 상태 | 미발행 / 발행 가능 |
| 사업자 여부 | 법인/사업자 회원만 토글 |

### 세금계산서 발행 폼 (DLG-S011)

| 항목 | 입력 |
|------|------|
| 사업자번호 | 10자리 자동 포맷 + 국세청 검증 |
| 상호 | 텍스트 (필수) |
| 대표자 | 텍스트 |
| 업태 / 종목 | 텍스트 |
| 이메일 | 형식 검증 (전송용) |
| 공급 품목 | 상품명 / 수량 / 단가 / 금액 (자동 채움) |
| 공급가액 | 자동 계산 |
| 부가세 | 자동 계산 (10%) |
| 합계 | 공급가액 + 부가세 |

### 발행 이력 테이블 (이력 탭)

| 컬럼 | 설명 |
|------|------|
| 발행일 | YYYY-MM-DD |
| 공급받는 자 | 상호 + 사업자번호 |
| 공급가액 | 천 단위 콤마 |
| 부가세 | 자동 계산 |
| 합계 | 공급가액 + 부가세 |
| 상태 배지 | 발행 완료 / 전송 완료 / 오류 |
| 액션 | [상세] / [이메일 전송] / [재발행] |

### 이메일 전송

발행 완료된 세금계산서를 공급받는 자 이메일로 PDF 첨부 전송. 전송 성공 시 상태 → "전송 완료".

### 엑셀 내보내기

발행 이력 엑셀 다운로드. 파일명 `yyyymm_지점_세금계산서이력.xlsx`.

## 주요 UX 흐름

**세금계산서 발행**
1. 사이드바 → "매출관리 > 세금계산서 발행" 진입
2. 상단 카드로 이번 달 발행 현황·미발행 대기 파악
3. 발행 탭에서 대상 결제 건 선택
4. DLG-S011 발행 폼: 사업자 정보·이메일 입력
5. 공급 품목·공급가액·부가세·합계 확인
6. [발행] 클릭 → 발행 완료 토스트
7. [이메일 전송] → 공급받는 자 이메일로 전송
8. 이력 탭에서 발행 이력 + 상태 확인

**재발행**
1. 이력 탭 → 오류 건 [재발행]
2. 발행 폼 자동 채움 → 재발행

## 비즈니스 규칙

1. 사업자번호는 국세청 진위 확인 API로 검증한 후 발행 허용한다.
2. 부가세는 공급가액의 10%로 자동 계산되며 면세 품목은 별도 처리한다.
3. 발행 후 수정은 불가하며, 잘못 발행한 건은 마이너스 세금계산서로 취소 발행한다.
4. 발행 이력은 5년 보관(국세 기본법)되며 감사 로그(SCR-097)에도 기록된다.
5. 이메일 전송 실패 시 상태는 "발행 완료"를 유지하고 별도 재전송 액션을 제공한다.
