## 기능 목적

회원이 분할 납부 방식(`collectionMode=INSTALLMENT_PLAN`)으로 결제한 할부 계약의 전체 현황을 한눈에 파악하고, 매월 납입 회차별 진행 상태를 추적하며 미납된 회차를 후속 관리하는 화면이다. 어느 회원이 몇 회차까지 납부했고 잔여 금액이 얼마이며 다음 납입일이 언제인지를 즉시 확인하고, 미납 회차에는 경고 표시와 함께 납입 처리·연락 액션을 수행한다. 본 화면은 `정기 분납 계획` 전용이며 계약금만 받고 잔액을 단기 미수금으로 남긴 건은 SCR-S008 미수금 관리에서 우선 다룬다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 진행 중인 할부 계약 수 | status=ongoing 카운트 | 카드 클릭 → 진행중 탭 |
| 이번 달 납입 예정 건수 | 이번 달 회차 예정 합계 | 카드 클릭 → 이번 달 필터 |
| 이번 달 납입 완료 건수 | 이번 달 입금 완료 합계 | 카드 클릭 → 완료 필터 |
| 미납 총액 | 기한 초과 회차 합계 | 카드 클릭 → 미납 탭 |

### 상태 탭

전체 / 진행중 / 완납 / 미납 4개 탭으로 계약 목록을 구분한다.

### 검색 / 필터

- **회원명 검색** (디바운스 300ms)
- **기간 범위 필터**: 계약 시작일·다음 납입일 기준
- **계약 출처 필터**: 직접 등록 / 현장 결제 연계 / 결제링크 연계

### 할부 계약 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 회원 상세 진입 |
| 상품명 | 멤버십/PT 등 |
| 계약 출처 | 현장 결제 연계 / 직접 등록 / 결제링크 |
| 선납금 | 원결제 시 수납된 금액 |
| 총 할부 금액 | 잔액 기준 분할 합계 |
| 납입 완료 금액 | 회차별 입금 누적 |
| 잔여 금액 | 총액 - 완료 금액 |
| 총 회차 / 납입 회차 | 예: "12 / 4" |
| 다음 납입일 | YYYY-MM-DD |
| 상태 배지 | 진행중·완납·미납 |

### 회차별 납입 현황 펼침

계약 행 클릭 시 하단에 회차별 상세 표시.

| 컬럼 | 설명 |
|------|------|
| 회차 | 1회 / 2회 / ... |
| 예정일 | YYYY-MM-DD |
| 완료일 | 입금 시 자동 채움 |
| 금액 | 회차당 분납액 |
| 상태 | 예정 / 완료 / 미납 |
| 액션 | [납입 처리] / [메모] |

### 미납 관리

납입 기한이 지난 회차에 경고 색상·아이콘 표시. [납입 처리] 버튼으로 DLG-S008을 통해 입금 확인 처리.

### 할부 등록

[+ 할부 등록] 버튼 → DLG-S009 할부등록 다이얼로그. 회원·상품·총액·회차·시작일을 입력해 새 할부 계획 생성.

### 엑셀 내보내기

현재 필터가 적용된 할부 계약 목록 엑셀 다운로드. 파일명 `yyyymmdd_지점_할부계약목록.xlsx`.

## 주요 UX 흐름

**진행 현황 조회**
1. 사이드바 → "매출관리 > 할부결제 관리" 진입
2. 상단 지표 카드로 이번 달 예정·완료·미납 파악
3. 진행중 탭에서 활성 계약 목록 확인
4. 회원명 검색 또는 출처 필터로 좁히기

**회차 상세 + 납입 처리**
1. 계약 행 클릭 → 하단 회차 펼침
2. 미납 회차 [납입 처리] 클릭 → DLG-S008
3. 입금일·금액 확인 → 처리
4. 회차 상태 "완료" 갱신 + 잔여 금액 자동 차감

**신규 할부 등록**
1. [+ 할부 등록] → DLG-S009
2. 회원·상품·총액·회차·시작일 입력
3. 자동 일정 생성 → 저장
4. 진행중 탭에 즉시 반영

| 처리 실패 | 토스트 + 재시도 |

## 비즈니스 규칙

1. 본 화면은 `collectionMode=INSTALLMENT_PLAN` 계약만 노출한다.
2. `collectionMode=DEPOSIT` 후 잔액만 남은 건은 할부 계획으로 전환되기 전까지 SCR-S008에서 우선 관리한다.
3. 선납금은 원결제 시 이미 수납된 금액이며, 총 할부 금액은 잔액 기준으로 계산한다.
4. 회차당 분납액은 잔액 ÷ 총 회차로 자동 계산되며 마지막 회차는 끝수 보정한다.
5. 미납 회차는 납입 예정일 + 1일부터 자동 감지되어 경고 표시된다.
6. 납입 처리 시 감사 로그(SCR-097)에 기록된다.
7. 중도 상환 시 잔여 회차를 일괄 완납 처리하고 계약 상태를 "완납"으로 갱신한다.
