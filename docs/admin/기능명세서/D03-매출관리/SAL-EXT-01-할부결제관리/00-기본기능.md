## 기능 목적

회원이 분할 납부 방식(`collectionMode=INSTALLMENT_PLAN`)으로 결제한 할부 계약의 전체 현황을 한눈에 파악하고, 매월 납입 회차별 진행 상태를 추적하며 미납된 회차를 후속 관리하는 화면이다. 어느 회원이 몇 회차까지 납부했고 잔여 금액이 얼마이며 다음 납입일이 언제인지를 즉시 확인하고, 미납 회차에는 경고 표시와 함께 납입 처리·연락 액션을 수행한다. 본 화면은 `정기 분납 계획` 전용이며 계약금만 받고 잔액을 단기 미수금으로 남긴 건은 SCR-S008 미수금 관리에서 우선 다룬다.

운영 맥락:
- **카운터 매니저 매월 회차 입금 확인**: 통장 입금 확인 → 회차 펼침 → [납입처리] → DLG-S008
- **FC 본인 담당 회원 할부 추적**: 회원명 검색 → 진행률·잔여 금액·다음 납입일 확인 → 입금 약속 통화
- **센터장 월말 미납 회차 점검**: 미납 탭 → 30일+ 연체 회차 회수 작업
- **신규 할부 등록 (DLG-S009)**: 결제 처리 시 계약금 수납 + 분납 회차 입력 → 자동 일정 생성
- **중도 상환 처리**: 회원이 잔여 금액 일괄 납입 → 잔여 회차 일괄 완납 + 계약 상태 "완납"
- **할부 회차 자동 미납 감지**: 매일 00:01 크론 → 예정일 + 1일 경과 회차 자동 "미납" 갱신
- **회원 카드 진입**: 회원명 클릭 → SCR-M004 → 회원의 모든 할부 계약 + 이용권 함께 확인
- **본사 슈퍼관리자 지점별 할부 회수율 비교**: 통합 모드에서 지점별 미납 합계·회수율 점검
- **PAY-03 미수금 자동 동기화**: 미납 회차 → PAY-03에 자동 등록, 한쪽 회수 시 양쪽 자동 갱신

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 | 동작 |
|------|----------|------|
| 진행 중인 할부 계약 수 | status=ongoing 카운트 | 카드 클릭 → 진행중 탭 |
| 이번 달 납입 예정 건수 | 이번 달 회차 예정 합계 | 카드 클릭 → 이번 달 필터 |
| 이번 달 납입 완료 건수 | 이번 달 입금 완료 합계 | 카드 클릭 → 완료 필터 |
| 미납 총액 | 기한 초과 회차 합계 | 카드 클릭 → 미납 탭 |

### 상태 탭

전체 / 진행중 / 완납 / 미납 4개 탭으로 계약 목록을 구분한다.

### 검색 / 필터

- **회원명 검색** (디바운스 300ms)
- **기간 범위 필터**: 계약 시작일·다음 납입일 기준
- **계약 출처 필터**: 직접 등록 / 현장 결제 연계 / 결제링크 연계

### 할부 계약 목록 테이블

| 컬럼 | 설명 |
|------|------|
| 회원명 | 클릭 시 SCR-M004 회원 상세 진입 |
| 상품명 | 멤버십/PT 등 |
| 계약 출처 | 현장 결제 연계 / 직접 등록 / 결제링크 |
| 선납금 | 원결제 시 수납된 금액 |
| 총 할부 금액 | 잔액 기준 분할 합계 |
| 납입 완료 금액 | 회차별 입금 누적 |
| 잔여 금액 | 총액 - 완료 금액 |
| 총 회차 / 납입 회차 | 예: "12 / 4" |
| 다음 납입일 | YYYY-MM-DD |
| 상태 배지 | 진행중·완납·미납 |

### 회차별 납입 현황 펼침

계약 행 클릭 시 하단에 회차별 상세 표시.

| 컬럼 | 설명 |
|------|------|
| 회차 | 1회 / 2회 / ... |
| 예정일 | YYYY-MM-DD |
| 완료일 | 입금 시 자동 채움 |
| 금액 | 회차당 분납액 |
| 상태 | 예정 / 완료 / 미납 |
| 액션 | [납입 처리] / [메모] |

### 미납 관리

납입 기한이 지난 회차에 경고 색상·아이콘 표시. [납입 처리] 버튼으로 DLG-S008을 통해 입금 확인 처리.

### 할부 등록

[+ 할부 등록] 버튼 → DLG-S009 할부등록 다이얼로그. 회원·상품·총액·회차·시작일을 입력해 새 할부 계획 생성.

### 엑셀 내보내기

현재 필터가 적용된 할부 계약 목록 엑셀 다운로드. 파일명 `yyyymmdd_지점_할부계약목록.xlsx`.

## 주요 UX 흐름

### 진행 현황 조회
1. 사이드바 → "매출관리 > 할부결제 관리" 진입
2. 상단 지표 카드로 이번 달 예정·완료·미납 파악
3. 진행중 탭에서 활성 계약 목록 확인
4. 회원명 검색 또는 출처 필터로 좁히기

### 회차 상세 + 납입 처리
1. 계약 행 클릭 → 하단 회차 펼침
2. 미납 회차 [납입 처리] 클릭 → DLG-S008
3. 입금일·금액 확인 → 처리
4. 회차 상태 "완료" 갱신 + 잔여 금액 자동 차감
5. PAY-03 미수금 자동 동기화

### 신규 할부 등록
1. [+ 할부 등록] → DLG-S009
2. 회원·상품·총액·회차·시작일 입력
3. 자동 일정 생성 → 저장
4. 진행중 탭에 즉시 반영

### 중도 상환 흐름
1. 계약 행 → DLG-S007 할부 상세
2. [중도 상환] 클릭 → 잔여 금액 입력
3. 잔여 회차 일괄 완납 + 계약 "완납"
4. 영수증 출력 옵션

### 분기·예외 흐름
- **회차 자동 미납 감지**: 매일 00:01 크론 → 예정일 + 1일 경과 회차 → "미납" 자동 갱신
- **납입처리 입금액 < 회차 금액**: "회차 금액 미달" 경고 + 부분 입금 처리 옵션 (회차 분할 또는 다음 회차 차감)
- **납입처리 입금액 > 회차 금액**: "다음 회차에 차감" 옵션 노출
- **잔액 끝수 보정**: 회차당 분납액 = 잔액 ÷ 총 회차, 마지막 회차는 끝수 보정 (예: 100,000 / 3 → 33,333 / 33,333 / 33,334)
- **할부 등록 시 회원 신용 검증**: 회원 미수 이력 3건 이상 시 경고 (강제 차단 아님)
- **회차 납입기한 정책 step 자동 알림 (NFR-05)**: HQ-09 결제기한 만료 본사 정책 step + 지점 ON 상태 기준으로 회원·운영자에게 알림. 결제기한 만료 정책은 지점 추가 step을 허용하지 않는다.
- **계약 해지 (환불)**: SAL-EXT-04 환불 진행 시 잔여 회차 일괄 취소 + 미수 차감 + 환불 계산
- **PAY-03 동기화 실패**: 자동 재시도 (최대 3회), 실패 시 운영자 알림
- **회원 탈퇴 후 할부**: 탈퇴 회원도 할부 계약은 유지, 회원 카드 진입 차단
- **할부 등록 권한 부족**: FC는 등록 불가, 매니저+ 만 등록 가능

## 비즈니스 규칙

1. **본 화면 범위**: `collectionMode=INSTALLMENT_PLAN` 계약만 노출.
2. **PAY-03 미수금 분리**: `collectionMode=DEPOSIT` 후 잔액만 남은 건은 SCR-S008에서 우선 관리.
3. **선납금 처리**: 선납금은 원결제 시 이미 수납된 금액이며 총 할부 금액은 잔액 기준 계산.
4. **회차당 분납액**: 잔액 ÷ 총 회차로 자동 계산, 마지막 회차는 끝수 보정.
5. **자동 미납 감지**: 미납 회차는 납입 예정일 + 1일부터 자동 감지, 매일 00:01 크론.
6. **납입 처리 감사**: 납입 처리 시 SCR-097에 기록 (`installment_id`, `round`, `amount`, `actor`).
7. **중도 상환**: 잔여 회차를 일괄 완납 처리하고 계약 상태 "완납" 갱신.
8. **회차 납입기한 정책 step 자동 알림 (NFR-05)**: 회차 예정일 기준 D-N 알림일은 HQ-09 결제기한 만료 본사 정책값을 따른다. 해당 지점에서 센터장(owner)이 ON으로 둔 step만 회원·운영자에게 발송한다. 지점 추가 step은 제공하지 않는다.
9. **PAY-03 동기화**: 미납 회차는 PAY-03에 자동 INSERT, 회수 시 양쪽 자동 갱신.
10. **계약 해지 (환불)**: SAL-EXT-04 환불 시 잔여 회차 일괄 취소 + 환불 수기 입력값 기준 처리.
11. **할부 등록 권한**: FC는 등록 불가, 매니저+ 만 등록 가능 (운영 정책).
12. **회원 신용 경고**: 회원 미수 이력 3건 이상 시 등록 시 경고 (강제 차단 아님).
13. **할부 회차 한도**: 최대 24회 (정책 한도, 변경 가능).
14. **회차 금액 최소**: 회차당 분납액 최소 10,000원 (정책 한도).
15. **계약 시작일**: 시작일은 등록일 이후만 허용, 과거 시작일은 본사 권한자만 가능.
16. **회차 일정 산출**: 시작일 기준 매월 동일 일자, 말일 보정 (1/31 → 2/28).
17. **부분 입금 옵션**: 입금액 < 회차 금액 시 회차 분할 또는 다음 회차 차감 (정책 토글).
18. **초과 입금 옵션**: 입금액 > 회차 금액 시 다음 회차에 자동 차감 옵션.
19. **회원 탈퇴 후 할부**: 탈퇴 회원도 할부 계약 유지, 회원 카드 진입 차단.
20. **본사 통합 모드**: 본사 슈퍼관리자만 전 지점 통합 조회.
21. **엑셀 다운로드**: 30,000건 초과 시 비동기 백그라운드 다운로드.
22. **반복 미납 회원**: 동일 회원 3회 이상 미납 시 운영자 알림.
23. **회차 변경 권한**: 회차 일정 변경은 센터장+ 만 가능, 변경 이력 감사 로그 기록.
24. **삭제 권한**: 할부 계약 삭제는 슈퍼관리자만 가능, 일반 운영자는 환불 처리 사용.

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `SAL-EXT-01`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-S009`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-S007 할부상세, DLG-S008 납입처리, DLG-S009 할부등록`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
