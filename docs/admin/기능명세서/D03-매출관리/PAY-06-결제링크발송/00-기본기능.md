## 기능 목적

현장에서 확정한 상품·금액·할인 조건으로 회원이 직접 결제할 수 있는 결제링크를 발송하는 기능이다. 결제 처리 화면(SCR-S003)에서 수납 방식을 `결제링크 발송`으로 선택하면 DLG-S016 다이얼로그가 열리고, 운영자는 발송 채널·만료일을 확인한 후 SMS 또는 카카오톡으로 결제링크를 보낸다. 회원은 링크에서 결제수단만 선택할 수 있으며 금액·상품 구성은 수정할 수 없어 현장 합의 그대로 결제가 진행된다. 회원앱 측에서는 MA-140 결제링크 화면이 비편집 모드로 동작한다.

운영 맥락:
- **카운터 매니저 비대면 회원 결제**: 상담 후 회원이 카드 미소지 → 결제링크 SMS 발송 → 회원 자가 결제
- **FC 외부 미팅 후 결제 위임**: 미팅 후 사무실 복귀 없이 결제링크 카톡 발송 → 회원이 집에서 결제
- **계약금 + 잔액 분할 회수**: 계약금 현장 수납 + 잔액은 결제링크로 발송 → 회원 자가 결제 → PAY-03 미수금 자동 차감
- **활성 링크 재발송**: 회원이 링크 분실 → 미수금 화면에서 같은 링크 재발송, 만료 시 새 링크 생성
- **활성 링크 강제 만료 + 신규**: 금액·상품 변경 필요 → 기존 링크 강제 만료 + 새 링크 생성
- **링크 만료 D-3/D-1 자동 알림 (NFR-05)**: 회원에게 결제 임박 알림, 만료 후 새 링크 발송 안내
- **링크 미결제 환불 차단**: 미결제 상태 환불 시도 시 환불이 아닌 링크 취소(SCR-S012)로 분기
- **카카오톡 미연동 회원**: 회원앱 미설치 + 카카오 친구 미연결 → SMS 자동 폴백
- **회원 PG 결제 webhook**: 회원 자가 결제 완료 → webhook으로 매출 자동 반영 + 미수금 차감

본 화면은 발송 + 활성 링크 관리만 담당하며 발송 후 결제 처리 자체는 회원앱 MA-140 + PG webhook 흐름으로 비동기 진행된다.

## 주요 구성요소

### 회원 정보 영역

| 항목 | 표시 |
|------|------|
| 수신 회원 이름 | 자동 채움 |
| 연락처 | 010 자동 포맷 |
| 앱 연결 여부 | "회원앱 설치됨" / "미설치" |

### 결제 요약 영역

| 항목 | 설명 |
|------|------|
| 상품명 | 현장 확정 상품 |
| 수량 | 단일 / 다중 |
| 정가 | 천 단위 콤마 |
| 할인 | 할인 금액 + 사유 |
| 최종 결제 금액 | 정가 - 할인 |
| 잔액 여부 | 계약금/잔액 안내 |

### 발송 채널 선택

| 채널 | 사용 조건 |
|------|----------|
| SMS | 연락처 유효 시 기본 |
| 카카오톡 | 카카오 채널 친구·앱 연결 시 활성 |

### 링크 만료일시

발송 시점 + 7일로 고정 표시. 만료일 이후 결제 불가.

### 내부 메모

상담 메모, 발송 사유, 특이사항 textarea. 내부 관리용으로 회원에게 노출되지 않음.

### 활성 링크 처리

동일 원결제 기준 활성 링크가 이미 있을 경우.

| 옵션 | 동작 |
|------|------|
| 같은 링크 재발송 | 기존 링크 그대로 재전송 |
| 강제 만료 후 새 링크 | 기존 링크 만료 → 새 링크 생성 |

### 발송 / 취소 버튼

- [발송]: 입력값 검증 → 채널 발송 → 상태 "발송됨" 갱신
- [취소]: 발송 없이 이전 화면(SCR-S003) 복귀

### 발송 결과 처리

| 결과 | 동작 |
|------|------|
| 발송 성공 | 토스트 + SCR-S003 복귀 + 상태 "발송됨" |
| 연락처 무효 | 인라인 에러 |
| 채널 사용 불가 | 다른 채널 자동 추천 |
| 발송 실패 | 토스트 + 재시도 |

## 주요 UX 흐름

### 신규 결제링크 발송
1. SCR-S003 결제 처리에서 상품·할인·금액 확정
2. 수납 방식 → "결제링크 발송" 선택
3. DLG-S016 다이얼로그 오픈
4. 회원 정보·결제 요약·만료일 확인
5. 채널 선택 (SMS / 카카오톡)
6. 내부 메모 입력 (선택)
7. [발송] → 검증 → 발송 → 상태 "발송됨"
8. SCR-S003 복귀

### 활성 링크 재발송
1. SCR-S003 또는 SCR-S008 미수금에서 "결제링크 재발송"
2. DLG-S016 → 활성 링크 감지 안내
3. "같은 링크 재발송" 또는 "강제 만료 후 새 링크" 선택
4. [발송] → 처리

### 회원 측 결제
1. 회원이 SMS/카톡 링크 클릭
2. 회원앱 MA-140 결제링크 화면 (비편집)
3. 결제수단 선택 → PG 결제
4. 결제 완료 webhook → 매출 자동 반영

### 분기·예외 흐름
- **활성 링크 1개 제한**: 동일 원결제 기준 활성 링크는 1개만 유지, 재발송 또는 강제 만료 후 신규 옵션
- **발송 후 수정 불가**: 링크 발송 후 상품·할인·최종 금액 수정 차단 (현장 합의 보호)
- **카카오 미연동 회원**: 카카오톡 채널 미연결 → SMS 자동 폴백 + "다른 채널 추천" 안내
- **연락처 무효**: 인라인 에러 + 회원 정보 수정 안내
- **만료된 링크 재발송 시도**: "만료된 링크입니다" + 새 링크 생성 안내
- **회원 결제 완료 webhook**: PG 콜백 수신 → 결제 처리 + SCR-S001/PAY-03 자동 반영
- **회원 결제 실패 webhook**: 링크 상태 유지 + 회원에게 재시도 안내
- **링크 만료 D-3/D-1 자동 알림 (NFR-05)**: 결제 임박 회원에게 알림 발송
- **미결제 환불 시도**: 환불이 아닌 링크 취소(SCR-S012)로 분기
- **회원 연락처 변경 시**: 미발송 링크는 새 연락처로 자동 갱신, 발송된 링크는 별도 재발송 필요

## 비즈니스 규칙

1. **발송 후 수정 불가**: 링크 발송 후 상품·할인·최종 금액 수정 차단 (현장 합의 보호).
2. **활성 링크 1개 제한**: 동일 원결제 기준 활성 링크는 1개만 유지.
3. **재발송 / 강제 만료 옵션**: 활성 링크 있을 때 같은 링크 재발송 또는 강제 만료 후 새 링크.
4. **만료 후 재사용 차단**: 만료된 링크는 재사용 불가, 새 링크 발송 필요.
5. **연락처 필수**: 회원 연락처가 없거나 무효하면 발송 차단.
6. **만료일 고정**: 발송 시점 + 7일 (정책 한도, 변경 가능).
7. **회원앱 MA-140 비편집 모드**: 결제수단만 선택, 금액·상품 수정 불가.
8. **결제 완료 webhook 자동 반영**: SCR-S001 매출현황·결제 건·PAY-03 미수금에 자동 반영, 감사 로그 기록.
9. **미완료 환불 차단**: 결제 미완료 시 환불(SCR-S012) 아닌 링크 취소로 처리.
10. **발송 채널 폴백**: 카카오톡 미연동 시 SMS 자동 폴백, 둘 다 사용 불가 시 발송 차단.
11. **만료 D-3/D-1 자동 알림 (NFR-05)**: 결제 임박 회원·운영자 알림.
12. **회원 결제 실패 시**: 링크 상태 "결제 실패" + 만료까지 재시도 가능.
13. **PG webhook 보안**: webhook 서명 검증 (HMAC), 위변조 차단.
14. **idempotency**: webhook 중복 수신 시 idempotency-key로 이중 처리 차단.
15. **연락처 변경 시 미발송 링크 갱신**: 회원 연락처 변경 후 미발송 링크는 새 연락처로 자동 갱신.
16. **발송 한도**: 동일 회원 동일 원결제에 일별 발송 횟수 5회 제한 (스팸 방지).
17. **권한별 발송**: FC도 담당 회원에게 발송 가능, 트레이너·스태프는 조회만.
18. **본사 통합 모드**: 본사 슈퍼관리자만 전 지점 통합 조회.
19. **링크 토큰 보안**: 링크 토큰은 1회용 + 7일 만료, 위변조 방지 서명 포함.
20. **링크 미사용 만료 시 미수금 유지**: 링크 만료 후에도 PAY-03 미수금에 등록 유지, 새 링크 발송 안내.
21. **감사 로그**: 발송·재발송·만료·취소·결제 webhook 모두 SCR-097 기록.
22. **비정상 발송 알림**: 일별 50건 이상 발송 시 본사 슈퍼관리자 알림.

## 예외 / 에러 처리
