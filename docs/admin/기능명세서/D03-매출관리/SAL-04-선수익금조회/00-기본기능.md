## 기능 목적

회원이 선납한 금액 중 아직 서비스가 제공되지 않은 금액(선수익금)의 현황을 조회하는 화면이다. 총 선수익금·이미 인식된 금액·아직 인식되지 않은 잔여 금액·이번 달 인식 예정 금액을 파악하고 계약별 진행률을 확인한다. 회원권 기간 믹스(1·3·6·12개월·기타)를 서비스일수 판정 기준으로 연결해 회계 관점의 매출 인식 기간을 일관되게 관리한다.

운영 맥락:
- **회계 담당자 월말 매출 인식 마감**: 이번 달 인식 예정 카드 + 일별 인식 배치 결과 → 매출 인식 회계 처리
- **본사 슈퍼관리자 전사 선수익 모니터링**: 통합 모드에서 지점별 선수익 잔여 + 인식 추세
- **센터장 만기 임박 계약 점검**: 진행률 80%+ 계약 우선 주목 → 재계약 권유 / 추가 결제 유도
- **세무 담당자 부채 인식**: 잔여 선수익금 = 회계상 부채, 부가세 신고·법인세 처리
- **CFO 재무 분석**: 총 선수익금 vs 매출 인식 비율 → 현금 유동성·매출 안정성 분석
- **마케팅 팀 만기 회원 대응**: 종료일 임박 계약 → 재등록 캠페인
- **환불 시 인식 차감**: SAL-EXT-04 환불 → 잔여 선수익금 재계산 (환불 건은 계산 제외)
- **휴면·연장 처리 영향**: 회원권 휴면·연장 시 서비스일수 동적 갱신 → 인식 기간 자동 조정
- **다양한 기간 믹스 (1·3·6·12·기타)**: SAL-03 매출 통계와 동일한 5버킷 기준 사용
- **일별 인식 배치 (매일 03:00)**: 경과일에 따라 선수익금 → 매출 인식 자동 이관

회계상 매출 인식 기준은 GAAP/K-IFRS의 발생주의 원칙에 따라 서비스 제공일에 비례하여 인식한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 총 선수익금 | 합계 |

| 이번 달 인식 예정 | 합계 |

### 기간 필터

시작일 ~ 종료일. 기본값 이번 달 전체.

### 선수익금 목록 테이블

| 컬럼 | 표시 |
|------|------|
| 회원명 | - |
| 상품명 | - |
| 총액 | - |

| 잔여 | 포인트 컬러 굵게 |

### 서비스일수 판정

매출통계의 개월별 판매 비율과 동일한 1·3·6·12·기타 5버킷 사용.

## 주요 UX 흐름

### 회계 마감 흐름
1. 사이드바 "매출관리 > 선수익금 조회" 진입
2. 상단 지표 카드로 전체 선수익금 현황 파악
3. 기간 필터 = 이번 달 → 인식 예정 확인
4. 테이블에서 계약별 인식 현황과 진행률 확인
5. 잔여 큰 계약 / 이번 달 종료 예정 계약 우선 주목
6. 회계 시스템 연동 (수동 입력 또는 API)

### 만기 임박 점검 흐름
1. 진행률 80%+ 정렬
2. 종료일 임박 계약 식별
3. 회원 카드 진입 → 재계약 권유 / 추가 결제

### 분기·예외 흐름
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 통합
- **환불 건 계산 제외**: SAL-EXT-04 환불 시 자동 차감, 환불 건은 인식 계산에서 제외
- **휴면·연장 시 서비스일수 갱신**: 회원권 휴면 시 잔여일 누적, 연장 시 종료일 갱신 → 인식 기간 동적 조정
- **일별 인식 배치 실패**: 매일 03:00 크론 실패 시 운영자 알림 + 다음 배치에서 누적 처리
- **5버킷 매핑 누락**: 1/3/6/12 외 기간은 "기타" 분류, 상품 마스터 실제 서비스일수 또는 종료일 우선
- **`durationMonths` 우선**: 매출 원장에 값 있으면 우선, 없으면 5버킷 fallback
- **진행률 100% 도달**: 인식 완료, 잔여 0원, 자동 만기 처리
- **종료일 미정 (무기한 상품)**: "기타" 분류, 운영자 종료일 입력 안내
- **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만
- **다지점 RLS**: 지점별 선수익 RLS, 본사 통합 모드만 전 지점

## 비즈니스 규칙

1. **서비스일수 정의**: 1개월=30일, 3개월=90일, 6개월=180일, 12개월=365일.
2. **기타 기간 처리**: 상품 마스터 실제 서비스일수 또는 계약 종료일 우선.
3. **5버킷 동기화**: SAL-03 매출 통계의 5버킷 기준과 동일.
4. **매출 원장 `durationMonths` 우선**: 값 있으면 우선 적용, 없으면 5버킷 fallback.
5. **인식 공식**: 선수익금 인식 = `총액 × (경과일 / 총 서비스일수)`.
6. **환불 건 계산 제외**: SAL-EXT-04 환불 건은 인식 계산에서 제외, 자동 차감.
7. **일별 인식 배치**: 매일 03:00 크론으로 경과일 비례 인식 자동 이관.
8. **휴면·연장 시 서비스일수 갱신**: 휴면 시 잔여일 누적, 연장 시 종료일 갱신.
9. **본사 통합 모드**: 본사 슈퍼관리자만 활성, 지점 컬럼 추가.
10. **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만.
11. **진행률 색상**: 0~50% 초록, 50~80% 주황, 80~100% 빨강.
12. **만기 임박 라벨**: HQ-09 만기 알림 정책 step 대상이면 해당 정책 step 라벨(D-N)을 표시한다.
13. **다지점 RLS**: 지점별 선수익 RLS 격리.
14. **회계 인식 기준**: GAAP/K-IFRS 발생주의, 서비스 제공일 비례.
15. **무기한 상품 처리**: 종료일 미정 시 "기타" 분류, 운영자 종료일 입력 안내.
16. **만기 자동 처리**: 진행률 100% 시 잔여 0원, 자동 만기.
17. **인식 정확도 검증**: 매월 1일 04:00 검증 배치, 누적 합계 = 총액 검증.
18. **데이터 보관**: 선수익 이력 5년 보관 (회계·세무).
19. **익명화**: 5년 경과 시 PII 마스킹.
20. **감사 로그**: 인식 / 환불 차감 / 휴면 갱신 모두 SCR-097 기록.
21. **회계 시스템 연동**: API 또는 CSV 다운로드로 회계 시스템에 입력.
22. **선수익 보고서**: 월별 선수익 보고서 자동 생성 (운영자 다운로드).
