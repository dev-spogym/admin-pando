## 기능 목적

회원이 결제를 완료하지 못한 미수금을 추적하고 관리하는 화면이다. 미결제·일부결제·연체·완료 상태를 탭으로 구분해 현황을 파악하고, 납입이 이루어지면 상태를 직접 변경한다. 계약금 잔액, 링크 미결제, 수기 분할, 정기 할부 미납을 한 원장으로 묶어 관리하며 연체 30일 이상 건을 별도로 집계해 독촉이 필요한 회원을 빠르게 파악할 수 있다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 미수금 총액 | - |
| 미수금 건수 | - |
| 연체 (30일 이상) 건수 | 경고 강조 테두리 |
| 이번 달 회수액 | - |

### 상태 탭 (5개)

전체 / 미결제 / 일부결제 / 연체 / 완료. 각 탭에 건수 배지.

### 회원명 검색

실시간 검색.

### 미수금 목록 테이블

| 컬럼 | 표시 |
|------|------|
| No / 회원명 / 상품명 | - |
| 발생 유형 | 계약금 잔액 / 결제링크 미결제 / 수기 분할 / 정기 할부 미납 |
| 원결제ID | - |
| 미수금액 | 빨강 강조 |
| 결제 기한 | 연체 시 빨강 굵게 |
| 상태 배지 | 완료(초록)/연체(빨강)/일부결제(노랑)/미결제(기본) |
| 링크 상태 / 메모 / 등록일 / 액션 | - |

### 상태 변경

현재 상태에 따라 전환 가능한 다음 상태만 노출 (미결제→일부결제·완료, 일부결제→완료, 연체→일부결제·완료, 완료→변경 불가).

### 메모 편집 (DLG-S005)

메모 버튼 클릭 → 모달 → 즉시 저장.

### 결제링크 후속 액션

발생 유형 = 결제링크 미결제 시:
- 활성 링크(SENT, OPENED) → 같은 링크 재발송
- 수동 만료
- 만료/취소 → 새 링크 생성

### 엑셀 내보내기

현재 탭/검색 조건 적용 목록 다운로드.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 상태 변경, 메모 편집, 결제링크 후속, 엑셀 |
| 센터장 / 매니저 | 소속 지점 매출 | 동일 |
| FC | 담당 회원 결제 | 상태 변경, 메모 편집, 결제링크 후속 |
| 트레이너 / 스태프 | 매출 조회만 | 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 미수금 관리" 진입
2. 상단 지표 카드로 미수 총액·연체 파악
3. 상태 탭 선택 → 해당 상태 미수만 표시
4. 회원명 검색으로 특정 회원 미수 찾기
5. 발생 유형 + 링크 상태로 후속 조치 판단
6. 납입 시 액션 드롭다운 → 새 상태 선택
7. 링크 미결제 → 재발송/만료/새 링크
8. 메모 버튼 → 독촉 이력 기록
9. 엑셀로 저장

| 오류 | 토스트 알림 |

## 비즈니스 규칙

1. 발생 유형 4종을 한 원장으로 통합 관리 (계약금 잔액 / 결제링크 미결제 / 수기 분할 / 정기 할부 미납).
2. 연체 30일 이상은 별도 집계 + 경고 강조.
3. 상태 전환은 현재 상태에 따라 가능한 다음 상태만 노출.
4. 완료 상태는 변경 불가.
5. 결제링크 활성 상태(SENT/OPENED)만 재발송 가능.
6. 메모 변경 이력은 감사 로그에 기록.
