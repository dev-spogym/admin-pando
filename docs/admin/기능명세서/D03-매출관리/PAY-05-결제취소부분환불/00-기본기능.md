## 기능 목적

완료된 결제 건에 대해 전체 취소 또는 일부 금액 환불을 처리하는 화면이다. 단순 변심·결제 오류·서비스 불만 등의 사유로 환불 요청이 들어왔을 때 담당자가 해당 결제 건을 조회하고 전체 취소 또는 부분 환불 금액을 지정해 처리한다. 처리된 내역은 SCR-S007 환불 관리 화면에 자동 반영되며 감사 로그에 기록된다.

## 주요 구성요소

### 결제 건 검색

| 항목 | 입력 |
|------|------|
| 회원명 | 텍스트 (디바운스 300ms) |
| 상품명 | 텍스트 |
| 결제일 | 기간 범위 |
| 결제 ID | 직접 입력 |

### 결제 내역 확인

선택한 결제 건의 정보 카드.

| 항목 | 표시 |
|------|------|
| 결제일 | YYYY-MM-DD HH:mm |
| 상품명 | 멤버십/PT 등 |
| 결제 금액 | 천 단위 콤마 |
| 결제 수단 | 카드/현금/계좌이체/마일리지 |
| 결제자 | 회원명 + 담당자 |

### 환불 계산 박스

| 항목 | 설명 |
|------|------|
| 원결제 금액 | 결제 시 수납액 |
| 기사용 차감금 | 이미 사용한 회차·일수 환산 |
| 위약금 | 약관 기반 위약금 |
| 기환불 누계 | 이전 부분 환불 합계 |
| 이번 환불 가능액 | 자동 계산 (조정 가능) |
| 최종 환불액 | 입력값 (≤ 가능액) |

### 처리 유형 선택

- **전체 취소**: 환불 가능액 전액 → 사유 입력 필수
- **부분 환불**: 직접 입력 (가능액 초과 불가) → 사유 입력 필수

### 환불 사유 입력

프리셋 사유 + 추가 의견.

| 사유 카테고리 | 예시 |
|---|---|
| 단순 변심 | 회원 변심 |
| 결제 오류 | 중복 결제 / 금액 오류 |
| 회원 요청 | 휴원·이사 |
| 서비스 불만 | 강사·시설 불만 |
| 기타 | 자유 입력 |

### 환불 수단 확인

원결제 수단에 따른 환불 방법 안내.

| 원결제 수단 | 환불 방법 |
|---|---|
| 카드 | PG 환불 (영업일 3~5일) |
| 현금 | 계좌 이체 |
| 계좌이체 | 계좌 이체 |
| 마일리지 | 즉시 회복 |

### 처리 확인 모달 (DLG-S013)

환불 금액·사유·수단을 최종 확인 → [처리 완료] → 처리 중 비활성 → 결과 모달(DLG-S014).

### 처리 완료 안내

성공 메시지 + SCR-S007 환불 관리로 이동 CTA.

### 처리 이력

해당 결제 건에 대해 이전 부분 환불 이력이 있으면 하단 목록 표시.

## 주요 UX 흐름

**전체 취소**
1. 사이드바 → "매출관리 > 결제 취소/부분 환불" 진입
2. 회원명·상품명·결제일로 결제 건 검색
3. 결제 내역 확인 + 환불 계산 박스 검토
4. "전체 취소" 선택 → 사유 입력
5. [처리 확인] → DLG-S013 → [처리 완료]
6. DLG-S014 결과 모달 → SCR-S007 이동

**부분 환불**
1. 결제 건 선택 → 환불 계산 박스 확인
2. "부분 환불" 선택 → 환불 금액 입력
3. 가능액 초과 시 경고
4. 사유·수단 확인 → [처리 확인]
5. DLG-S013 → 처리 완료 → 잔여 환불 가능액 갱신

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 | 검색만 활성, 우측 입력 영역 비활성 |
| 결제 건 선택됨 | 처리 유형·사유 영역 활성 |
| 전체 취소 선택 | 최종 환불액 = 가능액 자동 |
| 부분 환불 선택 | 금액 입력 활성 + 초과 경고 |
| 처리 확인 모달 | DLG-S013 + 버튼 비활성 |
| 처리 중 | 로딩 + 백 비활성 |
| 처리 완료 | 성공 메시지 + 이동 CTA |
| 이미 취소 | "이미 전액 환불된 건" 안내 |
| 오류 | 토스트 + 재시도 |

## 비즈니스 규칙

1. `기사용 차감금`, `위약금`, `기환불 누계`는 환불 상태가 아니라 환불 계산 항목이다.
2. 할부/미수 진행 중(`INSTALLMENT`) 결제는 남은 미수금과 먼저 상계한 뒤 실제 환불액을 계산한다.
3. 아직 결제가 완료되지 않은 결제링크 건은 환불이 아니라 링크 취소(SCR-S016 / DLG-S016)로 처리한다.
4. 환불 처리 담당자는 `기사용 차감금`, `위약금`, `이번 환불 가능액`을 운영 판단에 따라 조정할 수 있으며, 조정 사유를 반드시 기록한다.
5. 최종 환불액은 확정된 환불 가능액을 초과할 수 없다.
6. 처리 결과는 SCR-S007 환불 관리에 자동 반영되며 감사 로그(SCR-097)에 append-only로 기록된다.
7. PG 카드 환불은 영업일 3~5일이 소요되며 결과는 비동기 webhook으로 갱신된다.
