## 기능 목적

센터에서 발생한 전체 매출 거래를 한눈에 조회하고 분석하는 매출관리 도메인의 핵심 허브 화면이다. 담당자는 오늘·이번 주·이번 달 매출을 즉시 확인하고, 구매자나 상품명으로 원하는 거래를 빠르게 찾을 수 있다. 매출 내역 외에도 기간별·상품별·결제수단별·담당자별 집계, 환불 내역, 미납 내역을 7개 분석 탭으로 전환하며 관리한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 순 매출 | 환불·할인 차감 후 |
| 카드 결제 | 합계 |
| 현금 결제 | 합계 |
| 미수금 | 합계 |

### 기간 프리셋 + 검색·필터

- **프리셋**: 오늘 / 이번 주 / 이번 달
- **통합 검색**: 구매자 / 상품명
- **유형 필터**: 이용권 / PT / 상품 / 기타
- **상태 필터**: 완료 / 환불 / 미납
- **결제경로 필터**: POS / 링크 / 수기
- **날짜 범위 직접 지정**

### 매출유형 필터 탭

전체 / 신규 / 재등록 / 휴면복귀 / 종목추가 / 업그레이드

### 분석 탭 (7개)

| 탭 | 내용 |
|----|------|
| 매출 내역 | 거래 목록 |
| 기간별 매출 | 일/주/월 집계 |
| 상품별 내역 | 상품별 합계 |
| 결제수단별 | 카드/현금/마일리지/복합 |
| 담당자별 | 신규/재등록/기타/판매 건수/평균 단가 |
| 환불 내역 | 건수 배지 |
| 미납 내역 | 건수 배지 |

### 매출 목록 테이블

| 컬럼 |
|------|
| 구매일 / 매출유형 / 유형 / 상품명 / 구매자 / 담당자 / 금액 / 결제수단 / 결제경로 / 현금·카드·마일리지 / 미수금 / 링크 상태 / 상태 |

상품명 클릭 → 상품 상세, 구매자 클릭 → 회원 상세.

### 하단 요약 바

총매출 / 순매출 / 현금 / 카드 / 환불 / 미납금 / 할인 합계.

### 매출 상세 모달 (DLG-S001)

테이블 행 클릭 → 결제일·상태·구매 정보·금액·결제 내역·결제경로·링크 상태·카드 승인·메모. "회원 상세 보기" 버튼.

### 신규 결제 + 엑셀 내보내기

- [신규 결제(POS)] → SCR-S002
- [엑셀 내보내기]: 현재 필터 기준 전체

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 조회·분석 | 엑셀, 신규 결제(POS) 이동, 모든 필터·탭 |
| 센터장 / 매니저 | 소속 지점 매출 전체 | 엑셀, 신규 결제 이동, 모든 필터·탭 |
| FC | 담당 회원 결제 처리 가능 | 신규 결제 이동, 조회 및 필터 |
| 트레이너 / 스태프 | 소속 지점 매출 조회 | 조회·필터·탭만 (처리 불가) |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 매출 현황" 진입
2. 상단 지표 카드로 이번 달 순매출·결제수단별 합계·미수금 파악
3. 기간 프리셋 또는 날짜 직접 입력으로 조회 기간 설정
4. 검색 / 필터 / 매출유형 탭 조합
5. 분석 탭 7종 전환으로 다양한 관점 분석
6. 담당자별 탭 신규/재등록 분리로 신규 획득과 기존 회원 유지 성과 구분
7. 테이블 행 클릭 → 매출 상세 모달
8. [신규 결제(POS)] → SCR-S002 / [엑셀 내보내기]

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 테이블 영역 스켈레톤 |
| 정상 목록 | 1건 이상 → 테이블 + 하단 요약 |
| 검색 결과 없음 | "검색 결과가 없습니다" |
| 전체 데이터 없음 | 빈 화면 안내 |
| 오류 | 토스트 알림 |
| 매출 상세 모달 | 행 클릭 시 모달 |

## 비즈니스 규칙

1. 담당자별 신규/재등록 매출은 `[매출종합]` 회원권·락카 K열 담당자, 강습·골프 K열 등록강사 기준으로 분리.
2. 본사 통합 모드의 매출은 회원 실제 소속 지점 기준으로 합산.
3. 엑셀 다운로드는 현재 필터·페이지와 무관하게 전체 데이터.
4. 매출유형(신규/재등록/휴면복귀/종목추가/업그레이드)은 자동 분류.
5. 환불·미납 탭에는 건수 배지가 자동 표시.
6. 결제경로 필터로 현장 결제 / 링크 결제 / 수기 반영 건 구분.
