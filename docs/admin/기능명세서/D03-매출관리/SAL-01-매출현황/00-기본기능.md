## 기능 목적

센터에서 발생한 전체 매출 거래를 한눈에 조회하고 분석하는 매출관리 도메인의 핵심 허브 화면이다. 담당자는 오늘·이번 주·이번 달 매출을 즉시 확인하고, 구매자나 상품명으로 원하는 거래를 빠르게 찾을 수 있다. 매출 내역 외에도 기간별·상품별·결제수단별·담당자별 집계, 환불 내역, 미납 내역을 7개 분석 탭으로 전환하며 관리한다.

운영 맥락:
- **카운터 매니저 일일 매출 점검**: 오늘 매출 카드 + 매출 내역 탭 → 일별 결산 자료
- **센터장 월말 매출 마감**: 이번 달 카드 + 결제수단별 / 담당자별 탭 → 월간 결산
- **FC 본인 영업 성과 확인**: 담당자별 탭 → 본인 신규/재등록 매출 + 평균 단가
- **본사 슈퍼관리자 지점별 매출 비교**: 통합 모드 + 지점 필터 → 지점별 매출 합산·비교
- **회계 담당자 매출 정산**: 엑셀 다운로드 → 회계 시스템 입력
- **마케팅 담당자 상품 판매 분석**: 상품별 / 매출유형 탭 (신규/재등록/휴면복귀/종목추가/업그레이드)
- **고객 결제 이력 조회**: 회원명 검색 → 회원별 매출 이력 + DLG-S001 상세 모달
- **신규 결제 카운터 진입**: [신규 결제(POS)] → SCR-S002 단축 진입
- **환불·미납 즉시 파악**: 환불·미납 탭의 건수 배지로 빠르게 후속 작업 라우팅
- **결제경로 분석**: POS / 링크 / 수기 결제경로별 매출 비율 → 비대면 결제 활용도 점검

본 화면은 D03 도메인의 시작점으로, 회원 상세 / 상품 상세 / POS 판매 / 환불 / 미수 등 모든 D03 화면으로의 진입 허브 역할을 한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 |
|------|------|
| 순 매출 | 환불·할인 차감 후 |
| 카드 결제 | 합계 |
| 현금 결제 | 합계 |
| 미수금 | 합계 |

### 기간 프리셋 + 검색·필터

- **프리셋**: 오늘 / 이번 주 / 이번 달
- **통합 검색**: 구매자 / 상품명
- **유형 필터**: 이용권 / PT / 상품 / 기타
- **상태 필터**: 완료 / 환불 / 미납
- **결제경로 필터**: POS / 링크 / 수기
- **날짜 범위 직접 지정**

### 매출유형 필터 탭

전체 / 신규 / 재등록 / 휴면복귀 / 종목추가 / 업그레이드

### 분석 탭 (7개)

| 탭 | 내용 |
|----|------|
| 매출 내역 | 거래 목록 |
| 기간별 매출 | 일/주/월 집계 |
| 상품별 내역 | 상품별 합계 |
| 결제수단별 | 카드/현금/포인트/복합 |
| 담당자별 | 신규/재등록/기타/판매 건수/평균 단가 |
| 환불 내역 | 건수 배지 |
| 미납 내역 | 건수 배지 |

### 매출 목록 테이블

| 컬럼 |
|------|
| 구매일 / 매출유형 / 유형 / 상품명 / 구매자 / 담당자 / 금액 / 결제수단 / 결제경로 / 현금·카드·포인트 / 미수금 / 링크 상태 / 상태 |

상품명 클릭 → 상품 상세, 구매자 클릭 → 회원 상세.

### 하단 요약 바

총매출 / 순매출 / 현금 / 카드 / 환불 / 미납금 / 할인 합계.

### 매출 상세 모달 (DLG-S001)

테이블 행 클릭 → 결제일·상태·구매 정보·금액·결제 내역·결제경로·링크 상태·카드 승인·메모. "회원 상세 보기" 버튼.

### 신규 결제 + 엑셀 내보내기

- [신규 결제(POS)] → SCR-S002
- [엑셀 내보내기]: 현재 필터 기준 전체

## 주요 UX 흐름

### 일일 매출 점검 흐름
1. 사이드바 "매출관리 > 매출 현황" 진입
2. 상단 지표 카드로 이번 달 순매출·결제수단별 합계·미수금 파악
3. 기간 프리셋 = 오늘 → 매출 내역 탭
4. 검색 / 필터 / 매출유형 탭 조합
5. 분석 탭 7종 전환으로 다양한 관점 분석
6. 테이블 행 클릭 → DLG-S001 매출 상세

### 월간 결산 흐름
1. 기간 프리셋 = 이번 달
2. 결제수단별 탭 → 카드/현금/포인트/복합 합계
3. 담당자별 탭 → 신규/재등록 분리
4. 하단 요약 바 → 총매출·순매출·환불·미납 확인
5. 엑셀 다운로드 → 회계 자료

### 분기·예외 흐름
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 매출 통합 합산 + 지점별 컬럼 추가
- **회원 상세 진입 (구매자 클릭)**: SCR-M004 회원 카드 진입 → 회원의 모든 매출·미수·이용권 확인
- **상품 상세 진입 (상품명 클릭)**: SCR-P003 상품 상세 → 상품별 매출 추세
- **DLG-S001 매출 상세**: 행 클릭 → 결제 정보 + 결제경로 + 링크 상태 + 카드 승인 + 메모
- **환불·미납 탭 진입**: 배지 클릭 → SCR-S007 환불 / SCR-S008 미수 화면 라우팅
- **엑셀 다운로드 30,000건 초과**: 비동기 백그라운드 다운로드 + 완료 알림
- **결제경로별 차이**: POS = SCR-S002, 링크 = SCR-S016 webhook, 수기 = 본사 운영팀 직접 INSERT
- **매출유형 자동 분류**: 회원 첫 결제 = 신규, 90일+ 미방문 후 결제 = 휴면복귀, 같은 종목 추가 = 종목추가, 상위 등급 = 업그레이드
- **권한별 가시성**: FC는 담당 회원 결제만, 트레이너·스태프는 조회만
- **실시간 갱신**: PAY-01 결제 완료 webhook → 5초 이내 카드/리스트 갱신

## 비즈니스 규칙

1. **담당자별 신규/재등록 분리**: `[매출종합]` 회원권·락카 K열 담당자, 강습·골프 K열 등록강사 기준으로 분리.
2. **본사 통합 모드 합산**: 회원 실제 소속 지점 기준으로 합산.
3. **엑셀 다운로드 범위**: 현재 필터·페이지와 무관하게 전체 데이터, 30,000건 초과 시 비동기.
4. **매출유형 자동 분류**: 회원 결제 패턴 기반 자동 분류 (신규/재등록/휴면복귀/종목추가/업그레이드).
5. **환불·미납 탭 배지**: 건수 배지 자동 표시, 클릭 시 해당 화면 라우팅.
6. **결제경로 필터**: POS / 링크 / 수기 결제경로별 매출 비율 분석.
7. **순 매출 정의**: 환불·할인 차감 후 (`총매출 - 환불 - 할인`).
8. **실시간 갱신**: PAY-01 결제 완료 / SAL-EXT-04 환불 / PAY-03 회수 webhook 5초 이내 반영.
9. **DLG-S001 매출 상세**: 결제 정보 + 결제경로 + 카드 승인번호 + 링크 상태 + 메모 표시.
10. **회원 상세 진입**: 구매자 클릭 → SCR-M004, 회원 RLS 검증.
11. **상품 상세 진입**: 상품명 클릭 → SCR-P003.
12. **권한별 가시성**: FC는 담당 회원만, 트레이너·스태프는 조회만, 본사 슈퍼관리자만 통합 모드.
13. **휴면복귀 정의**: 90일 이상 미방문 회원의 결제 (정책 기준).
14. **종목추가 정의**: 동일 회원이 다른 종목 (이용권 외 PT/GX 등) 추가 결제.
15. **업그레이드 정의**: 동일 회원이 상위 등급 상품으로 변경 결제.
16. **신규 결제 진입**: [신규 결제(POS)] 버튼은 매니저+ 만 가능, FC는 활성.
17. **매출 인식 시점**: 결제 완료 시점 (선수익금 인식은 SAL-04에서 별도 일별 배치).
18. **매출 보관**: 매출 데이터 5년 보관 (회계·세무), 5년 후 익명화.
19. **감사 로그**: 매출 상세 조회·엑셀 다운로드는 SCR-097 기록 (`actor`, `query`, `count`).
20. **결제수단 합산 검증**: 결제수단별 탭 합계 = 순 매출 (검증 실패 시 운영자 알림).
21. **다지점 RLS**: 지점별 매출 RLS로 격리, 본사 통합 모드만 전 지점 노출.
22. **외부 시트 매핑**: `[매출종합]` 시트 K열·`[월매출]` 시트 매핑으로 레거시 호환.
