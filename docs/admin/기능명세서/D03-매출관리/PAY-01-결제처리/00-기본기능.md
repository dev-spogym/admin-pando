## 기능 목적

POS 판매 화면(SCR-S002)에서 장바구니에 담은 상품의 결제를 완료하는 화면이다. 결제수단(카드·현금·마일리지·복합결제)을 선택하고 최종 결제 금액을 확인한 뒤 결제를 처리한다. 현장 전액 결제뿐 아니라 할인 적용, 계약금 수납, 잔액 계산, 결제링크 발송까지 이 화면에서 확정한다. 결제 완료 후에는 영수증 출력·문자 발송·계속 판매 등의 후속 동작을 안내한다.

운영 맥락:
- **카운터 매니저 일반 회원권 결제**: POS에서 1년 회원권 카드 결제 → 영수증 출력 → 회원 카드에 회원권 자동 활성
- **FC 신규 회원 PT 패키지 결제**: 상담 후 카드+마일리지 복합결제, 분할 결제 시 계약금 수납 + 결제링크로 잔액 회수
- **계약금만 받고 다음 달 잔액**: 즉시 개시 vs 완납 후 개시 라디오 분기, 잔액은 PAY-03 미수금/PAY-04 할부 라우팅
- **링크 발송 결제 (DLG-S016)**: 회원이 비대면일 때, 카운터에서 금액·할인 확정 후 SMS/카톡 발송 → 회원이 직접 결제 → webhook으로 매출 자동 반영
- **마일리지 단독 결제**: 회원 검색 → 보유 잔액 검증 → 부족 시 차단 또는 부족분 카드 추가 (복합결제로 전환)
- **중복 결제 의심 (DLG-S004)**: 동일 회원 동일 금액이 5분 이내 다시 입력되면 경고 → 운영자가 의도 확인 후 진행
- **PG 통신 장애·재시도**: 카드 PG 응답 지연 / 실패 시 토스트 + 재시도, 트랜잭션 idempotency-key로 이중 결제 방지
- **본사 슈퍼관리자 운영 모니터링**: 본사 통합 모드에서 지점 매출 실시간 집계, 비정상 결제 패턴 (대량 환불·중복 결제) 알림 수신

영수증 출력은 카운터 프린터 연결 시, 문자 발송은 회원 연락처 등록 시 노출되며 둘 다 옵션으로 결제 완료 후 즉시 실행할 수 있다.

## 주요 구성요소

### 결제 상품 목록 (좌측)

POS에서 담아온 상품명·수량·소계 + 하단 총 결제 금액 큰 표시.

### 회원 검색 (좌측)

마일리지 결제 시 필수. 이름/전화번호 검색 → 보유 마일리지 표시 → X 해제.

### 할인 입력

정가 / 할인 항목 / 할인 금액 입력 → 최종 결제 금액 + 잔액 즉시 재계산.

### 수납 방식 선택

| 방식 | 설명 |
|------|------|
| 전액 수납 | 현장 총액 전부 결제 |
| 계약금 수납 | 당일 수납액 + 잔액 → 미수금/할부 |
| 잔액 수납 | 기존 계약 남은 잔액만 |
| 결제링크 발송 | 금액 확정 후 고객 직접 결제 링크 |

### 잔액 요약 박스

정가 / 할인 / 당일 수납액 / 잔액 / 결제 경로 한 줄 표시.

### 이용권 개시 옵션 (계약금 수납 시)

`즉시 개시 / 완납 후 개시` 라디오.

### 결제수단 선택 (우측, 4종)

| 수단 | 동작 |
|------|------|
| 카드 | PG 진입 |
| 현금 | 즉시 처리 |
| 마일리지 | 회원 미선택 시 안내 + 비활성 / 보유 부족 시 부족액 빨강 |
| 복합결제 | 카드+현금+마일리지 입력 합계 = 총액 검증 |

### 결제링크 발송 버튼 (DLG-S016)

수납 방식 = 결제링크 발송 시 노출. 회원 연락처 + 만료일시 확인 후 발송.

### 결제 확인 모달 (DLG-S003)

상품 내역·합계·결제수단·선택 회원 최종 확인. "결제 완료" 버튼 → 처리 중 상태.

### 중복 결제 경고 (DLG-S004)

동일 회원 동일 금액 최근 결제 감지 시 경고. "계속 진행" 또는 "취소".

### 결제 완료 화면

체크 아이콘 + 완료 메시지 + 영수증 출력 / 문자 발송 / 계속 판매 / 매출 현황 이동.

## 주요 UX 흐름

### 정상 결제 흐름 (전액 카드)
1. SCR-S002에서 [결제하기] → SCR-S003 진입
2. 좌측 상품 목록 + 총 금액 확인
3. 할인 입력 / 수납 방식 = 전액 수납 선택
4. 결제수단 = 카드 → PG 진입 → 승인 대기
5. [결제 확인] (DLG-S003) → 처리 중
6. 완료 → 영수증 / 문자 / 계속 판매 / 매출 현황 이동

### 계약금 수납 + 잔액 결제링크 흐름
1. 수납 방식 = 계약금 수납 → 당일 수납액 입력
2. 이용권 개시 옵션 (즉시 / 완납 후) 선택
3. 잔액 처리 = 결제링크 발송 (DLG-S016)
4. 회원 연락처 + 만료일시 확인 → 발송
5. 회원 직접 결제 → webhook → SCR-S001 반영 + 미수금 차감

### 분기·예외 흐름
- **마일리지 결제 시 회원 미선택**: "마일리지 결제는 회원 선택이 필요해요" 안내 + 마일리지 버튼 비활성, 회원 검색 영역 강조
- **마일리지 보유 부족**: 부족액 빨강 표시, 복합결제 자동 추천 (부족분만큼 카드/현금)
- **복합결제 합계 불일치**: 차액 빨강 + [결제 확인] 비활성, 정정 후 활성화
- **DLG-S004 중복 결제 경고**: 동일 회원·금액 5분 이내 결제 감지 시 모달 → "계속 진행" 또는 "취소" 선택
- **PG 카드 결제 실패**: PG 응답 코드별 메시지 (한도 초과 / 카드 만료 / 네트워크 / 거래 거절) → 재시도 버튼 + 다른 결제수단 변경 옵션
- **PG 응답 타임아웃 (15초+)**: idempotency-key로 중복 결제 차단, 자동 폴링 → webhook 수신 시 완료
- **결제링크 발송 후 SCR-S003 복귀**: 링크 상태 "발송됨"으로 잠금, 별도 결제 재시도 차단
- **결제 완료 후 영수증 프린터 오류**: "프린터 연결 확인" 토스트, 결제는 정상 완료, 재출력 옵션 제공
- **계약금 0원 입력**: "계약금은 1원 이상 입력해주세요" + 결제 차단
- **할인 금액이 정가 초과**: 할인 입력 빨강 + 결제 차단

## 비즈니스 규칙

1. **마일리지 결제 회원 필수**: 마일리지 결제는 회원 선택이 필수이며 보유 부족 시 결제를 차단한다.
2. **복합결제 합계 일치**: 카드 + 현금 + 마일리지 합계가 총 결제 금액과 일치해야 결제 가능.
3. **중복 결제 감지 윈도우**: 동일 회원·동일 금액·동일 상품의 결제가 5분 이내 재시도 시 DLG-S004 경고.
4. **계약금 수납 이용권 개시**: 계약금 수납 시 이용권 개시 시점 (즉시 / 완납 후) 명시 필수, 미선택 시 결제 차단.
5. **결제링크 만료**: 결제링크 발송 시 만료일시는 발송 시점 + 7일 고정. 만료 후 결제 불가.
6. **PG idempotency**: PG 결제 요청은 idempotency-key를 부여해 네트워크 재시도 시 이중 결제 차단.
7. **PG 응답 타임아웃**: 15초 이내 응답 없으면 처리 중 상태 유지 + 자동 폴링, 60초 후 타임아웃 안내.
8. **결제 완료 즉시 반영**: 결제 완료 시 SCR-S001 매출 현황·회원 카드 이용권에 즉시 반영 (5초 이내).
9. **마일리지 잔액 동시성**: 마일리지 결제 시 row-level lock으로 잔액 동시 차감 충돌 방지.
10. **할인 한도**: 할인 금액은 정가의 100%를 초과할 수 없으며 무료 등록은 별도 권한자 승인.
11. **0원 결제 차단**: 최종 결제 금액이 0원인 경우(전액 할인) 결제 차단, 별도 무료 등록 플로우로 분기.
12. **계약금 최소 금액**: 계약금은 총액의 10% 이상이어야 하며 정책에 따라 변경 가능.
13. **할부 자동 라우팅**: 계약금 수납 + 잔액이 있을 때 분납 회차 입력 시 PAY-04 할부 계약 자동 생성, 단순 미수는 PAY-03 미수금에 등록.
14. **잔액 수납 모드**: 기존 계약 잔액만 수납하는 경우 결제 ID 필수 매핑.
15. **현금 결제 거스름돈**: 현금 받은 금액 입력 시 거스름돈 자동 계산, 차액이 0 미만이면 결제 차단.
16. **영수증 발행**: 결제 완료 시 영수증 자동 출력 시도, 프린터 미연결 시 PDF로 다운로드 가능.
17. **권한별 결제 한도**: FC는 1회 결제 최대 1000만원, 매니저는 무제한 (테넌트 정책 토글).
18. **결제 취소 윈도우**: 카드 결제 후 당일 18시 이전은 PG 매입 취소, 이후는 PAY-05 환불 처리로 분기.
19. **감사 로그**: 결제 시도·성공·실패·취소 모두 SCR-097에 기록 (`payment_id`, `actor_id`, `amount`, `method`, `result`).
20. **중복 회원 검색 결과**: 회원 검색 결과 2명 이상 시 추가 식별 정보 (생년월일·전화번호 끝자리) 입력 필수.
21. **회원 비활성/탈퇴 시**: 비활성 회원에게는 결제 차단 (이용권 부여 불가), 탈퇴 회원은 검색 결과에서 제외.
22. **법인 회원 결제**: 법인 회원 결제 시 SAL-06 세금계산서 발행 알림 자동 노출 + 사업자 정보 자동 채움.

| 케이스 | 표시 | 후속 조치 |

| 카드 PG 한도 초과 | "카드 한도가 부족해요" 토스트 | 다른 카드 / 결제수단 변경 |
| 카드 PG 거래 거절 | "결제가 거절되었어요" + PG 응답 코드 | 카드사 문의 안내 + 재시도 |

| 영수증 프린터 미연결 | "프린터 연결 확인" 토스트 + PDF 다운로드 | 결제는 정상 완료 |

| 0원 결제 시도 | "최종 결제 금액이 0원입니다" 안내 | 무료 등록 플로우 안내 |
| 계약금 < 총액 10% | "계약금은 총액의 10% 이상이어야 해요" | 정정 안내 |
| 동시성 충돌 (마일리지 잔액) | "잠시 후 다시 시도해주세요" | 자동 재시도 |
| FC 결제 한도 초과 | "결제 한도(1000만원)를 초과했어요" | 매니저 승인 요청 |
| 권한 부족 (트레이너) | 결제 처리 화면 진입 차단 | 매출 조회 화면 안내 |
| 비회원 마일리지 시도 | 마일리지 버튼 hidden | - |
| 0원 거스름돈 부족 | "받은 금액이 부족합니다" | 정정 안내 |
