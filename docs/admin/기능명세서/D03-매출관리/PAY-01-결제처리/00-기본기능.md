## 기능 목적

POS 판매 화면(SCR-S002)에서 장바구니에 담은 상품의 결제를 완료하는 화면이다. 결제수단(카드·현금·마일리지·복합결제)을 선택하고 최종 결제 금액을 확인한 뒤 결제를 처리한다. 현장 전액 결제뿐 아니라 할인 적용, 계약금 수납, 잔액 계산, 결제링크 발송까지 이 화면에서 확정한다. 결제 완료 후에는 영수증 출력·문자 발송·계속 판매 등의 후속 동작을 안내한다.

## 주요 구성요소

### 결제 상품 목록 (좌측)

POS에서 담아온 상품명·수량·소계 + 하단 총 결제 금액 큰 표시.

### 회원 검색 (좌측)

마일리지 결제 시 필수. 이름/전화번호 검색 → 보유 마일리지 표시 → X 해제.

### 할인 입력

정가 / 할인 항목 / 할인 금액 입력 → 최종 결제 금액 + 잔액 즉시 재계산.

### 수납 방식 선택

| 방식 | 설명 |
|------|------|
| 전액 수납 | 현장 총액 전부 결제 |
| 계약금 수납 | 당일 수납액 + 잔액 → 미수금/할부 |
| 잔액 수납 | 기존 계약 남은 잔액만 |
| 결제링크 발송 | 금액 확정 후 고객 직접 결제 링크 |

### 잔액 요약 박스

정가 / 할인 / 당일 수납액 / 잔액 / 결제 경로 한 줄 표시.

### 이용권 개시 옵션 (계약금 수납 시)

`즉시 개시 / 완납 후 개시` 라디오.

### 결제수단 선택 (우측, 4종)

| 수단 | 동작 |
|------|------|
| 카드 | PG 진입 |
| 현금 | 즉시 처리 |
| 마일리지 | 회원 미선택 시 안내 + 비활성 / 보유 부족 시 부족액 빨강 |
| 복합결제 | 카드+현금+마일리지 입력 합계 = 총액 검증 |

### 결제링크 발송 버튼 (DLG-S016)

수납 방식 = 결제링크 발송 시 노출. 회원 연락처 + 만료일시 확인 후 발송.

### 결제 확인 모달 (DLG-S003)

상품 내역·합계·결제수단·선택 회원 최종 확인. "결제 완료" 버튼 → 처리 중 상태.

### 중복 결제 경고 (DLG-S004)

동일 회원 동일 금액 최근 결제 감지 시 경고. "계속 진행" 또는 "취소".

### 결제 완료 화면

체크 아이콘 + 완료 메시지 + 영수증 출력 / 문자 발송 / 계속 판매 / 매출 현황 이동.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 모든 결제수단, 할인, 계약금/잔액, 링크 발송, 영수증, 문자 |
| 센터장 / 매니저 | 소속 지점 매출 | 동일 |
| FC | 담당 회원 결제 | 모든 결제수단, 할인, 계약금/잔액, 할부, 링크 발송 |
| 트레이너 / 스태프 | 매출 조회만 | 결제 처리 화면 접근 불가 |

## 주요 UX 흐름

1. SCR-S002에서 [결제하기] → SCR-S003 진입
2. 좌측 상품 목록 + 총 금액 확인
3. 할인 입력 / 수납 방식 선택
4. 결제수단 선택 (마일리지/복합결제 시 회원 검색)
5. 계약금 수납 시 이용권 개시 옵션 + 잔액 미수금/할부 처리
6. 결제링크 발송 시 DLG-S016
7. 조건 충족 → [결제 확인] (DLG-S003)
8. 중복 감지 시 DLG-S004
9. 완료 → 영수증 / 문자 / 계속 판매 / 매출 현황

| 상태 | 설명 |

| 결제 성공 | 완료 화면 |
| 결제 실패 | 에러 토스트 + 재시도 |
| 중복 경고 | DLG-S004 |

## 비즈니스 규칙

1. 마일리지 결제는 회원 선택 필수, 보유 부족 시 결제 차단.
2. 복합결제 합계가 총액과 일치해야 결제 가능.
3. 동일 회원·동일 금액 최근 결제는 중복 경고로 진행 여부 확인.
4. 계약금 수납 시 이용권 개시 시점 명시 (즉시/완납 후).
5. 결제링크는 회원 연락처와 만료일시 필수.
6. 결제 완료 시 매출 현황(SCR-S001)에 즉시 반영.
