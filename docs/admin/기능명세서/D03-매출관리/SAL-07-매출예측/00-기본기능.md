## 기능 목적

과거 매출 데이터를 기반으로 향후 매출을 예측하고, 설정한 목표 대비 달성률을 시각적으로 확인하는 화면이다. 센터장과 매니저는 다음 달·분기·연간 예측 매출을 미리 파악해 인력 배치, 상품 프로모션, 목표 조정 등 선제적인 운영 계획을 수립한다. 본사는 지점별 예측을 비교해 전사 자원 배분 의사결정을 지원한다.

운영 맥락:
- **센터장 월간 운영 계획**: 다음 달 예측 + 목표 설정 → 인력·프로모션 배치
- **본사 슈퍼관리자 전사 자원 배분**: 통합 모드 + 지점별 예측 비교 → 자원 배분
- **CFO 재무 계획**: 분기·연간 예측 + 목표 달성률 → 재무 계획
- **마케팅 팀 캠페인 효과 분석**: 상품별 예측 기여도 1~10위 → 집중 영역 파악
- **인사 팀 인력 계획**: 매출 예측 → 트레이너·매니저 채용 / 배치 계획
- **달성률 게이지 모니터링**: 100% 초과 시 성공 색상, 목표 조정 검토
- **YoY 비교 (전년 동기 대비)**: 12개월 예측 테이블에서 YoY 증감률 확인 → 성장 추세
- **데이터 부족 안내**: 과거 6개월 미만 시 예측 비활성, 데이터 누적 안내
- **이동평균 + 계절성 조정**: 기본 알고리즘, 향후 ML 모델 고도화 가능
- **목표 변경 이력 감사**: 목표 변경 시 SCR-097 기록, CFO·센터장 승인 이력

본 화면은 운영 의사결정 지원이 목적으로, 예측치는 참고용이며 실제 매출은 다양한 변수의 영향을 받는다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 |
|------|----------|
| 이번 달 예측 매출 | 잔여 일수 보정한 월 예측치 |
| 목표 달성률 | 누적 매출 / 목표 × 100 |
| 전월 대비 증감 | (이번 달 - 전월) / 전월 × 100 |
| 이번 분기 누적 매출 | 분기 시작일부터 합산 |

### 예측 기간 선택

라디오/세그먼트 컨트롤로 다음 달 / 다음 분기 / 연간 예측 전환.

### 매출 목표 설정 (DLG-S012)

기간별 매출 목표 금액을 직접 입력. 입력 즉시 달성률 게이지 실시간 갱신.

| 입력 | 설명 |
|------|------|
| 기간 단위 | 월 / 분기 / 연간 |
| 목표 금액 | 천 단위 콤마 자동 |
| 적용 시점 | 즉시 / 다음 기간부터 |

### 매출 예측 차트

과거 실적(실선) + 예측값(점선) + 목표 라인을 한 차트에 겹쳐 표시.

- X축: 월/분기/연
- Y축: 매출 금액
- 라인 1: 과거 실적
- 라인 2: 예측치 (점선, 신뢰 구간 음영)
- 라인 3: 목표 (수평선)

### 달성률 게이지

현재 누적 매출의 목표 대비 비율을 프로그레스 바 + 숫자로 표시. 100% 초과 시 성공 색상으로 변경.

### 상품별 예측 기여도

| 컬럼 | 설명 |
|------|------|
| 순위 | 1~10위 |
| 상품명 | 멤버십·PT·필라테스 등 |
| 예측 매출 | 다음 기간 예측치 |
| 비중 | 전체 예측 매출 대비 % |

### 월별 예측 테이블

| 컬럼 | 설명 |
|------|------|
| 월 | 다음 12개월 |
| 예측 매출 | 회귀/이동평균 기반 |
| 목표 | 입력 목표값 |
| 달성률 | 예측/목표 × 100 |
| 전년 동기 대비 | YoY 증감률 |

## 주요 UX 흐름

### 예측 조회 흐름
1. 사이드바 → "매출관리 > 매출 예측" 진입
2. 상단 지표 카드로 예측 매출·달성률·증감 확인
3. 예측 기간(다음 달·분기·연간) 선택
4. 차트에서 과거 추세 + 예측 궤적 비교
5. 상품별 기여도 1~10위 목록으로 집중 영역 파악
6. 월별 예측 테이블에서 상세 수치 확인

### 목표 설정 흐름
1. [목표 설정] → DLG-S012
2. 기간 단위·목표 금액·적용 시점 입력
3. 저장 → 게이지·달성률 즉시 갱신
4. 변경 이력 감사 로그 기록

### 본사 통합 모드 흐름
1. 본사 슈퍼관리자 통합 모드 활성
2. 전 지점 예측 통합 + 지점별 드릴다운
3. 지점별 예측 비교 → 자원 배분

### 분기·예외 흐름
- **데이터 부족 (6개월 미만)**: 예측 차트 비활성 + "데이터 누적 안내"
- **목표 미설정**: 게이지 대신 입력 안내 표시
- **목표 초과 달성**: 게이지 성공 색상 (녹색)
- **예측 실패 (모델 오류)**: 토스트 + 재시도, 운영자에게 모델 점검 알림
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 합산
- **목표 변경 권한**: 매니저+ 만 가능, FC·트레이너는 조회만
- **즉시 vs 다음 기간 적용**: 즉시 = 현재 진행 기간부터, 다음 기간 = 다음 월/분기/연부터
- **YoY 데이터 없음**: 전년 동기 매출 없으면 "비교 불가" 표시
- **이동평균 + 계절성**: 기본 알고리즘, 매주 월요일 04:00 모델 갱신
- **신뢰 구간 음영**: 예측 라인 ±10% 신뢰 구간 음영 표시
- **다지점 RLS**: 지점별 예측 RLS 격리

## 비즈니스 규칙

1. **예측 알고리즘**: 이동평균 + 계절성 조정 (기본), 향후 ML 모델 고도화 가능.
2. **데이터 부족 안내**: 과거 매출 6개월 미만이면 예측 차트 비활성.
3. **목표 변경 감사**: 목표 금액 변경 시 SCR-097 기록 (`actor`, `period`, `before`, `after`).
4. **달성률 공식**: 달성률 = 누적 매출 / 목표 × 100, 100% 초과 시 성공 색상.
5. **본사 통합 모드**: 본사 슈퍼관리자만 활성, 지점 합산 + 드릴다운.
6. **매출 집계 기준**: `매출관리.md`의 정의를 따른다.
7. **권한별 가시성**: 매니저+ 만 목표 설정, FC·트레이너는 조회만.
8. **이동평균 + 계절성**: 12개월 이동평균 + 월별 계절성 가중치.
9. **모델 갱신 주기**: 매주 월요일 04:00 자동 갱신.
10. **신뢰 구간 표시**: 예측 라인 ±10% 신뢰 구간 음영.
11. **YoY 비교**: 전년 동기 매출 대비 증감률, 데이터 없으면 "비교 불가".
12. **즉시 vs 다음 기간**: 적용 시점 명시 필수.
13. **잔여 목표 금액**: 게이지에 잔여 금액 함께 표시.
14. **상품별 기여도**: 다음 기간 예측 매출 기준 상위 10위.
15. **기간 단위 (월/분기/연)**: 목표는 기간 단위로 별도 저장.
16. **다지점 RLS**: 지점별 예측 RLS 격리.
17. **모델 정확도 모니터링**: 매월 1일 04:00 검증 배치, 정확도 < 80% 시 운영자 알림.
18. **데이터 보관**: 예측 이력 5년 보관 (회계·세무).
19. **익명화**: 5년 경과 시 PII 마스킹 (단 매출 합산 보존).
20. **차트 호버 툴팁**: 수치·신뢰 구간·증감률 표시.
21. **예측 캐시**: 5분 캐시, 갱신 시 무효화.
22. **목표 0원 처리**: 목표 0원이면 게이지 hidden, 입력 안내.
23. **연간 예측 12개월**: 다음 12개월 월별 예측 테이블.
24. **CFO 분기 보고서**: 분기별 예측 vs 실적 자동 보고서.
25. **목표 승인 워크플로우**: 1억원+ 목표는 본사 슈퍼관리자 승인 필수 (정책 토글).

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서 `SAL-07`의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-S011`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `DLG-S012 목표매출설정`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 또는 본문 내 연계 표를 같이 적용합니다.
5. API가 본문에 명시된 경우 해당 `API 기준`을 우선 적용하고, 명시가 없으면 화면 액션 단위로 API를 설계합니다.
