## 기능 목적

과거 매출 데이터를 기반으로 향후 매출을 예측하고, 설정한 목표 대비 달성률을 시각적으로 확인하는 화면이다. 센터장과 매니저는 다음 달·분기·연간 예측 매출을 미리 파악해 인력 배치, 상품 프로모션, 목표 조정 등 선제적인 운영 계획을 수립한다. 본사는 지점별 예측을 비교해 전사 자원 배분 의사결정을 지원한다.

## 주요 구성요소

### 요약 지표 카드 (4개)

| 카드 | 표시 내용 |
|------|----------|
| 이번 달 예측 매출 | 잔여 일수 보정한 월 예측치 |
| 목표 달성률 | 누적 매출 / 목표 × 100 |
| 전월 대비 증감 | (이번 달 - 전월) / 전월 × 100 |
| 이번 분기 누적 매출 | 분기 시작일부터 합산 |

### 예측 기간 선택

라디오/세그먼트 컨트롤로 다음 달 / 다음 분기 / 연간 예측 전환.

### 매출 목표 설정 (DLG-S012)

기간별 매출 목표 금액을 직접 입력. 입력 즉시 달성률 게이지 실시간 갱신.

| 입력 | 설명 |
|------|------|
| 기간 단위 | 월 / 분기 / 연간 |
| 목표 금액 | 천 단위 콤마 자동 |
| 적용 시점 | 즉시 / 다음 기간부터 |

### 매출 예측 차트

과거 실적(실선) + 예측값(점선) + 목표 라인을 한 차트에 겹쳐 표시.

- X축: 월/분기/연
- Y축: 매출 금액
- 라인 1: 과거 실적
- 라인 2: 예측치 (점선, 신뢰 구간 음영)
- 라인 3: 목표 (수평선)

### 달성률 게이지

현재 누적 매출의 목표 대비 비율을 프로그레스 바 + 숫자로 표시. 100% 초과 시 성공 색상으로 변경.

### 상품별 예측 기여도

| 컬럼 | 설명 |
|------|------|
| 순위 | 1~10위 |
| 상품명 | 멤버십·PT·필라테스 등 |
| 예측 매출 | 다음 기간 예측치 |
| 비중 | 전체 예측 매출 대비 % |

### 월별 예측 테이블

| 컬럼 | 설명 |
|------|------|
| 월 | 다음 12개월 |
| 예측 매출 | 회귀/이동평균 기반 |
| 목표 | 입력 목표값 |
| 달성률 | 예측/목표 × 100 |
| 전년 동기 대비 | YoY 증감률 |

## 주요 UX 흐름

**예측 조회**
1. 사이드바 → "매출관리 > 매출 예측" 진입
2. 상단 지표 카드로 예측 매출·달성률·증감 확인
3. 예측 기간(다음 달·분기·연간) 선택
4. 차트에서 과거 추세 + 예측 궤적 비교
5. 상품별 기여도 1~10위 목록으로 집중 영역 파악
6. 월별 예측 테이블에서 상세 수치 확인

**목표 설정**
1. [목표 설정] → DLG-S012
2. 기간 단위·목표 금액·적용 시점 입력
3. 저장 → 게이지·달성률 즉시 갱신

## 비즈니스 규칙

1. 예측 알고리즘은 이동평균 + 계절성 조정을 기본 사용한다(향후 고도화 가능).
2. 과거 매출 6개월 미만이면 예측 차트를 비활성하고 데이터 누적 안내를 표시한다.
3. 목표 금액은 기간 단위로 저장되며 변경 이력은 감사 로그(SCR-097)에 기록된다.
4. 달성률 = 누적 매출 / 목표 × 100, 100% 초과 시 성공 색상.
5. 본사 통합 모드에서는 지점 합산 예측이 표시되며 지점별 드릴다운이 가능하다.
6. 매출 집계 기준은 `매출관리.md`의 정의를 따른다.
