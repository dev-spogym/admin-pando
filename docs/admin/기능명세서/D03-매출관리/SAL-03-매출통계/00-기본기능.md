## 기능 목적

다양한 관점(상품별·상품유형별·결제수단별·종목별·개월별 판매 비율·GX 세부 종목·법인권·직군별·담당자별)으로 매출 데이터를 시각적으로 분석하는 통계 화면이다. 어떤 상품이 잘 팔리는지, 어떤 결제수단이 주로 사용되는지, 단기/장기 회원권 판매 믹스, GX 하위 종목별 수요, 법인권(B2B) 매출 규모, 담당자별 신규/재등록 매출과 골프프로별 매출을 차트와 표로 파악하고 운영 전략 수립에 활용한다.

## 주요 구성요소

### 최상위 탭 (3개)

전체 통계 / 직군별 / 담당자별. 담당자별 탭은 총매출/신규/재등록/기타/판매 건수/평균 단가 추가 표시.

### 날짜 필터 (전체 통계)

이번 달 / 지난 달 / 최근 3개월 / 최근 6개월 / 올해 프리셋 + 시작~종료 직접 입력 + [조회].

### 하위 탭 (전체 통계)

| 탭 | 차트 |
|----|------|
| 상품별 | 가로 막대 (상위 10) |
| 상품타입별 | 도넛 |
| 결제수단별 | 도넛 |
| 종목별 | 가로 막대 (상위 10) |
| 개월별 | 1/3/6/12/기타 5종 비율 막대 |
| GX종목별 | 6종 분포 (요가/필라테스/스피닝/줌바/에어로빅/GX 기타) |
| 법인권 | 가로 막대 또는 요약 테이블 |

### 전월 대비 토글

ON 시 현재 기간 옆 전월 동기 비교 (증감액·증감률, 증가 초록 / 감소 빨강).

### 집계 테이블

항목명 / 판매 건수 / 매출액 / 비율 (담당자별 탭은 신규/재등록/기타/평균 단가 추가).

### 골프프로별 매출

`[매출종합] 골프매출` 탭 K열 등록강사 기준 프로별 합계.

### 총 매출 표시

차트 영역 상단 큰 숫자.

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 모든 탭·차트·필터 |
| 센터장 / 매니저 | 소속 지점 매출 | 동일 |
| FC | 담당 회원 결제 | 조회·필터 |
| 트레이너 / 스태프 | 매출 조회만 | 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 매출 통계" 진입
2. 최상위 탭 선택 (전체/직군별/담당자별)
3. 전체 통계 탭에서 날짜 프리셋 또는 직접 입력 + [조회]
4. 하위 탭 7종 전환 → 차트 + 표
5. [전월 대비] 토글로 비교
6. 담당자별 탭에서 신규/재등록 분리 확인
7. 골프 매출은 골프프로별로 별도 해석

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 차트 스피너 + 테이블 로딩 |
| 정상 표시 | 차트 + 테이블 |
| 데이터 없음 | "조회된 데이터가 없습니다" |
| 전월 대비 ON | 비교 요약 바 + 테이블 추가 |
| 오류 | 토스트 알림 |

## 비즈니스 규칙

1. 개월별 판매 비율은 1/3/6/12/기타 5버킷 고정.
2. 매출 원장에 `durationMonths` 값이 있으면 우선 적용.
3. 1개월 비중 높으면 단기 쏠림 신호.
4. GX 세부 종목은 상품 마스터 2단계 분류 (category=GX + subCategory).
5. 법인권은 `[월매출]` E열 `구분=법인권` 거래 합계.
6. 외부 시트 매핑 (`[월매출]` C열 / `[주간월간보고]` 주차별).
7. 비인기 GX 클래스 폐지 / 인기 클래스 증설 판단에 활용.
