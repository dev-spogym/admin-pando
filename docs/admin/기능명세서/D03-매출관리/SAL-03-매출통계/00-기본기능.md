## 기능 목적

다양한 관점(상품별·상품유형별·결제수단별·종목별·개월별 판매 비율·GX 세부 종목·법인권·직군별·담당자별)으로 매출 데이터를 시각적으로 분석하는 통계 화면이다. 어떤 상품이 잘 팔리는지, 어떤 결제수단이 주로 사용되는지, 단기/장기 회원권 판매 믹스, GX 하위 종목별 수요, 법인권(B2B) 매출 규모, 담당자별 신규/재등록 매출과 골프프로별 매출을 차트와 표로 파악하고 운영 전략 수립에 활용한다.

운영 맥락:
- **센터장 월간 운영 회의 자료**: 상품별 / 결제수단별 / 담당자별 탭 → 회의 자료 구성
- **본사 슈퍼관리자 지점별 BI 분석**: 통합 모드 + 지점 필터 → 지점별 매출 믹스 비교
- **마케팅 담당자 단기/장기 쏠림 분석**: 개월별 비율 (1·3·6·12·기타) → 단기 쏠림 시 약정 강화
- **GX 매니저 클래스 수요 분석**: GX종목별 분포 (요가·필라테스·스피닝·줌바·에어로빅·기타) → 인기 클래스 증설
- **B2B 영업 담당자 법인권 매출 점검**: 법인권 탭 → B2B 매출 규모 + 단가 비교
- **FC 본인 영업 성과 비교**: 담당자별 탭 + 신규/재등록 분리 → 본인 평균 단가 + 건수
- **골프 프로 매출 점검**: 골프프로별 매출 → 프로별 등록 회원 + 매출
- **전월 대비 토글**: 증감액·증감률 비교 → 매출 성장 추세 즉각 확인
- **회계팀 매출 인식 분석**: 5종 개월별 비율 → 선수익금 인식 기간 검증 (SAL-04 연계)
- **단기 쏠림 경고**: 1개월 비중 50% 초과 시 운영자 알림 → 약정 강화·장기 회원권 프로모션

조회·분석 중심 화면이며 데이터 가공·집계는 백엔드 배치(매시간 갱신)와 실시간 쿼리 혼합으로 처리된다.

## 주요 구성요소

### 최상위 탭 (3개)

전체 통계 / 직군별 / 담당자별. 담당자별 탭은 총매출/신규/재등록/기타/판매 건수/평균 단가 추가 표시.

### 날짜 필터 (전체 통계)

이번 달 / 지난 달 / 최근 3개월 / 최근 6개월 / 올해 프리셋 + 시작~종료 직접 입력 + [조회].

### 하위 탭 (전체 통계)

| 탭 | 차트 |
|----|------|
| 상품별 | 가로 막대 (상위 10) |
| 상품타입별 | 도넛 |
| 결제수단별 | 도넛 |
| 종목별 | 가로 막대 (상위 10) |
| 개월별 | 1/3/6/12/기타 5종 비율 막대 |
| GX종목별 | 6종 분포 (요가/필라테스/스피닝/줌바/에어로빅/GX 기타) |
| 법인권 | 가로 막대 또는 요약 테이블 |

### 전월 대비 토글

ON 시 현재 기간 옆 전월 동기 비교 (증감액·증감률, 증가 초록 / 감소 빨강).

### 집계 테이블

항목명 / 판매 건수 / 매출액 / 비율 (담당자별 탭은 신규/재등록/기타/평균 단가 추가).

### 골프프로별 매출

`[매출종합] 골프매출` 탭 K열 등록강사 기준 프로별 합계.

### 총 매출 표시

차트 영역 상단 큰 숫자.

## 주요 UX 흐름

### 전체 통계 분석 흐름
1. 사이드바 "매출관리 > 매출 통계" 진입
2. 최상위 탭 = 전체 통계
3. 날짜 프리셋 = 이번 달 + [조회]
4. 하위 탭 7종 전환 → 차트 + 표
5. [전월 대비] 토글 ON → 증감 비교
6. 인사이트 도출

### 담당자별 분석 흐름
1. 최상위 탭 = 담당자별
2. 신규/재등록/기타/평균 단가 컬럼 확인
3. 정렬·필터로 특정 담당자 식별
4. FC는 본인 행만 노출 (RLS)

### GX 세부 종목 분석
1. 하위 탭 = GX종목별
2. 6종 분포 차트 (요가·필라테스·스피닝·줌바·에어로빅·기타)
3. 비인기 클래스 폐지 / 인기 클래스 증설 판단

### 분기·예외 흐름
- **본사 통합 모드**: 본사 슈퍼관리자만 활성, 전 지점 통합 + 지점별 드릴다운
- **데이터 없음**: "조회된 데이터가 없습니다" + 기간 변경 안내
- **상위 10 외 항목**: "기타"로 통합 표시, 상세 조회 시 전체 노출
- **전월 대비 데이터 없음**: 토글 ON이어도 비교 표시 불가 안내
- **개월별 5버킷 매핑 누락**: `[주간월간보고]` V5:Z5 매핑 누락 시 "기타" 분류
- **GX subCategory 미분류**: "기타"로 분류 + 운영자 알림
- **법인권 분류 기준**: `[월매출]` E열 `구분=법인권` 거래 합계
- **담당자 퇴사**: 담당자명 + "퇴사" 라벨, 매출 집계는 유지
- **골프프로 매출 분리**: `[매출종합] 골프매출` 시트 K열 등록강사 기준
- **단기 쏠림 자동 알림 (1개월 비중 50%+)**: 운영자 알림 + 약정 강화 안내
- **차트 데이터 큰 양**: 매시간 배치 갱신, 실시간 데이터는 5분 캐시

## 비즈니스 규칙

1. **개월별 5버킷 고정**: 1/3/6/12/기타 5버킷 고정.
2. **`durationMonths` 우선**: 매출 원장에 `durationMonths` 값이 있으면 우선 적용.
3. **단기 쏠림 신호**: 1개월 비중 높으면 단기 쏠림 신호 (50%+ 시 알림).
4. **GX 세부 종목 분류**: 상품 마스터 2단계 분류 (category=GX + subCategory).
5. **법인권 분류**: `[월매출]` E열 `구분=법인권` 거래 합계.
6. **외부 시트 매핑**: `[월매출]` C열 / `[주간월간보고]` 주차별.
7. **담당자별 분리 기준**: 회원권·락카 K열 담당자, 강습·골프 K열 등록강사.
8. **골프 매출 분리**: `[매출종합] 골프매출` 시트 K열 등록강사 기준.
9. **상위 10 외 통합**: 상위 10 외 항목은 "기타"로 통합 표시.
10. **전월 대비 비교**: 동일 기간 대비, 증가 초록 / 감소 빨강.
11. **본사 통합 모드**: 본사 슈퍼관리자만 활성.
12. **데이터 갱신**: 매시간 배치 갱신, 실시간 5분 캐시.
13. **권한별 가시성**: FC는 본인 매출, 트레이너·스태프는 조회만.
14. **퇴사 담당자 처리**: "퇴사" 라벨 + 매출 집계 유지.
15. **차트 호버 툴팁**: 수치·비율·증감률 표시.
16. **GX subCategory 미분류**: "기타"로 분류 + 운영자 알림.
17. **단기 쏠림 자동 알림**: 1개월 비중 50%+ 시 NFR-19 알림.
18. **데이터 보관**: 매출 통계 5년 보관 (회계·세무).
19. **감사 로그**: 통계 조회·엑셀은 SCR-097 기록 (`actor`, `query`).
20. **실시간 vs 배치 차이**: 5분 이내 결제는 실시간, 이외 배치 (매시간).
21. **분석 결과 공유 권한**: 매니저+ 만 외부 공유 가능 (정책).
22. **차트 인터랙션**: 클릭 시 필터로 자동 적용 (드릴다운).

## 개발 추적 기준

개발자는 이 기능을 구현할 때 아래 순서로 문서를 따라갑니다.

1. 본 기능명세서의 Lv2/Lv3, 비즈니스 규칙, 예외/에러 처리 기준을 먼저 확인합니다.
2. 화면 동작은 연계 화면설계서 `SCR-S004`를 기준으로 확인합니다.
3. 팝업·확인·입력 흐름은 연계 다이얼로그 `해당 없음`를 함께 확인합니다.
4. 상태 변경, 배치, 알림, 감사 로그는 `자동화 / 배치 / 이벤트 연계` 표와 아래 API 기준을 같이 적용합니다.

- **연계 화면**: SCR-S001 / SCR-S005 통계 관리 / SCR-S006 선수익금 / SCR-094 KPI / SCR-099 리포트 / SCR-097 감사 로그
- **API 기준**: `GET /api/sales/stats?period=&type=&group=` / `GET /api/sales/stats/compare` / `GET /api/sales/stats/by-staff` / `GET /api/sales/stats/by-product` / `GET /api/sales/stats/gx`
