## 기능 목적

수업·매출·예약·이용 현황을 하나의 화면에서 통합 조회하고, 원하는 기간·유형·담당자·구분·회원 상태로 필터링해 CSV 파일로 내려받는 통계 보고서 화면이다. 매출현황의 `받을금액`은 VAT 제외 순매출로 명확히 정의해 재무 보고와 수익성 분석에 활용한다. 레거시 업무 시스템 스타일로 설계되어 PC 기반 센터 관리 프로그램에 익숙한 운영자도 빠르게 활용한다.

## 주요 구성요소

### 기간 입력

시작일 ~ 종료일 직접 입력. 기본값은 이번 달 전체.

### 필터 드롭다운 (4종)

| 필터 | 옵션 |
|------|------|
| 수업 유형 | 동적 생성 |
| 담당자 | 동적 생성 |
| 구분 | 동적 생성 |
| 회원 상태 | 동적 생성 |

각 드롭다운 선택지는 현재 조회된 데이터에서 동적 생성.

### 현황 탭 (4개)

수업현황 / 매출현황 / 예약현황 / 이용현황. 동일 데이터에서 해당 유형 행만 표시.

### 통계 테이블 (17개 컬럼)

| 컬럼 |
|------|
| 일자 / 담당자 / 회원명 / 성별 / 휴대폰 / 구분 / 판매금액 / 할인금액 / 받을금액(VAT 제외 순매출) / 카드 / 현금 / 상품권 / 포인트 / 미수발생 / 미수입금 / 받은금액 / 비고 |

### VAT 제외 매출 매핑

`[월매출]` I열 `ARRAYFORMULA` 산출값을 `받을금액`에 매핑.

### 합계 행

테이블 하단 노란색 배경. 전체 건수 + 각 금액 컬럼 합계.

### 액션 버튼

- [조회] — 기간/필터 적용 데이터 로드
- [신규] — 모든 필터/결과 초기화
- [엑셀(CSV) 내보내기] — 파일명에 탭명·기간 포함
- [종료] — 이전 화면 복귀

## 계정별 차이 (RBAC)

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 | 기간 조회, 모든 필터, 탭 전환, CSV 내보내기 |
| 센터장 / 매니저 | 소속 지점 매출 | 동일 |
| FC | 담당 회원 결제 | 기간 조회, 필터, 탭 전환 |
| 트레이너 / 스태프 | 매출 조회만 | 조회만 |

## 주요 UX 흐름

1. 사이드바 "매출관리 > 통계 관리" 진입
2. 시작/종료일 입력 또는 기본값 (이번 달)
3. 4종 필터 드롭다운 선택
4. [조회] → 데이터 로드
5. 4탭 전환으로 원하는 뷰 확인
6. 합계 행에서 VAT 제외 순매출 포함 총계 확인
7. [엑셀] CSV 다운로드
8. [신규]로 초기화

## 화면 상태

| 상태 | 설명 |
|---|---|
| 초기 상태 | 이번 달 기본 + 빈 테이블 |
| 로딩 중 | "조회중" 합계 행 표시 |
| 정상 표시 | 데이터 + 합계 행 |
| 데이터 없음 | 빈 행 12개로 공간 유지 |
| CSV 불가 | "내보낼 데이터가 없습니다" |

## 비즈니스 규칙

1. `받을금액`은 부가세 제외 순매출 기준.
2. `[월매출]` I열 `ARRAYFORMULA` 산출값 매핑.
3. 필터 드롭다운 선택지는 현재 데이터 기반 동적 생성.
4. CSV 파일명에 탭명과 기간 포함.
