# FitGenie Admin ↔ Kiosk 연동매트릭스

> 문서 버전: v0.1
> 작성일: 2026-05-04
> 목적: `admin-pando` 관리자웹의 어떤 화면/기능이 `kiosk-pando`(헬스장 입구 키오스크)와 데이터/정책으로 연동되는지 정리한다. FitGenie 키오스크 단말은 admin 정책의 **현장 실행 채널**이며, 출석/락커/골프 데이터 원천은 admin 단일이다. 단, 주차는 지점/건물별 외부 운영 차이가 크므로 admin 연동 필수 범위에서 제외하고 선택 설정으로만 다룬다.

> 키오스크 측 대응 문서: `../kiosk/KIOSK-기획연계정의서.md`

> 책임 정리: 키오스크 설정은 D09-설정관리(SCR-082/SCR-082A/SCR-083)에서 관리한다. 키오스크 단말 운영 화면, 원격 재시작, 로그 다운로드, KIO-402 관리자 패널은 KIOSK 기획문서 범위다. D11-통합운영은 키오스크/출입 게이트 출석 이벤트와 상태 수신값을 CRM 화면에 표시하는 역할만 담당한다.

---

## 1. 채널 관계 요약

| 흐름 | 방향 | 의미 |
|---|---|---|
| 정책/설정 | admin → kiosk | 출석/락커/골프/메뉴 토글 등 운영 규칙 전달. 주차는 선택형 안내/외부 링크 설정만 전달 가능 |
| 마스터 데이터 | admin → kiosk | 회원/이용권/예약/카드 매핑 등 조회용 |
| 이벤트 | kiosk → admin | 출석 기록, 직원 출퇴근, 결제, 골프 예약, 감사 로그 |
| 상태 보고 | kiosk → admin | 기기 정보, 온라인 상태, 장비 점검 결과 |

키오스크는 출석/락커/골프 예약에 대해 자체 영구 저장소를 두지 않는다. 일시 단절 시 로컬 큐만 보유, 복구 즉시 admin 원천에 반영한다. 주차 등록은 외부 주차 솔루션, 웹뷰, 현장 안내로 처리할 수 있으며 admin 원장 반영을 필수로 보지 않는다.

## 2. 화면 단위 연동 매트릭스 (admin → kiosk)

### 2.1 D11-통합운영

| Admin 화면 | 책임 | 키오스크 영향 화면 | 연동 데이터 |
|---|---|---|---|
| `SCR-I001-통합출석관리` | 키오스크/출입 게이트 출석 이벤트 조회 | KIO-001, KIO-101 ~ KIO-105, KIO-201 | 출석 성공/실패 이벤트, 채널, 실패 사유 |
| `DLG-I001-수동출석등록` | 수동 출석 (관리자 화면) | 키오스크 출석 실패 후 fallback | 회원 식별, 출석 기록 |

## 3. 이벤트 단위 연동 (kiosk → admin)

| 이벤트 | 키오스크 발생 화면 | admin 적재 위치 |
|---|---|---|
| 회원 출석 성공 | KIO-201 | `SCR-I001-통합출석관리`, 출석 이력 테이블 |
| 회원 출석 실패 | KIO-201 (실패) | 운영 로그 |
| 직원 출퇴근 | KIO-104 → KIO-201 | `SCR-063-직원근태관리`, `staffAttendance` |
| 락커 자동 배정 | KIO-201 → KIO-202/204 | `SCR-050-락커관리` 락커 풀 갱신 |
| 락커 번호 앱 발송 | KIO-203 | 알림 채널(클라이언트) + admin 발송 로그 |
| 골프 예약 확정 | KIO-503 → KIO-504 | `SCR-054-골프타석관리` |
| 골프 대기 등록 | KIO-503 → KIO-504 | `SCR-054-골프타석관리` 대기열 |
| 매점 결제 | KIO-702 | `SCR-S010-현장판매` |
| 관리자 액션 (문열기/새로고침/TTS) | KIO-402 | 감사 로그 |
| 기기 상태 변경 | KIO-402 | KIOSK 운영 문서. admin D11에는 출석 화면 상태 배지로만 표시 |

## 4. 새로 추가되어야 할 admin 항목

키오스크 기획에서 신규로 정의한 정책 중, admin 화면에 신규 설정 키 또는 화면 영역으로 반영되어야 하는 항목.

| 키오스크 기능 | 필요 admin 추가 사항 | 우선순위 |
|---|---|---|
| 락커 번호 영수증 출력 (ATT-04-03) | `SCR-082` 영수증 토글, 출력 문구, 재출력 정책 | P1 |
| 락커 번호 앱 발송 (ATT-04-04) | `SCR-082` 앱 발송 토글, 안내 문구, 미연동 회원 예외 | P1 |
| 신발장 밴드 수령 (ATT-04-05) | `SCR-082` 신발장 토글, 동일번호 정책 사용 여부 + `SCR-052` 밴드 분실 정책 | P1 |
| 얼굴 인식 정지 판정 시간 (KSET-02-01) | `SCR-082A` 또는 `SCR-083`에서 얼굴 인식 인증 수단 설정 | P0 |
| 골프 예약 키오스크 활성 (KSET-03-01) | `SCR-082` 골프 키오스크 채널 토글 | P2 |
| 주차 등록 안내 (KSET-04) | 선택 항목. `SCR-082`에 주차 토글, 처리 방식, 외부 링크, 안내 문구를 둘 수 있으나 admin 연동 필수 아님 | P3 |
| 매점 키오스크 활성 (KSET-01-02) | `SCR-082` 매점 메뉴 토글 | P5 |

위 항목은 admin 측 화면 추가/보강이 완료될 때 `관리자문서_통합_ID대응표.md`에서 ID를 부여한다.

## 6. 동기화 원칙

1. **데이터 원천 단일화**: 같은 회원/예약/이용권은 admin DB 단일 원천을 사용. 키오스크는 별도 원천을 만들지 않는다.
2. **정책은 admin 우선**: 출석/락커/골프 운영 규칙은 admin 정책이 우선. 키오스크는 표시/입력만 담당.
3. **신규 설정 키 합의**: 키오스크가 새로 요구하는 설정은 admin D09의 `SCR-082/SCR-082A/SCR-083`에 명시 후 키오스크가 수신.
4. **이력은 admin으로 적재**: 출석/예약/결제/관리자 액션 모두 admin 운영 로그로 적재.
5. **주차 예외**: 주차는 admin 단일 원천/이력 적재 필수 대상이 아니다. 지점 정책상 필요한 경우에만 버튼 노출, 안내 문구, 외부 링크 정도를 admin에서 선택 관리한다.
6. **오프라인 큐**: 일시 단절 시 키오스크가 로컬 큐를 보유할 수 있으나, 복구 즉시 admin 원천에 반영.
