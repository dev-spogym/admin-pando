# DLG-072-001 알림 규칙 편집 필드 검증

```mermaid
sequenceDiagram
    autonumber
    actor Staff as 직원
    participant Modal as 알림 규칙 편집
    participant Validator as 검증

    Staff->>Modal: 저장 선택
    Modal->>Validator: 규칙명 입력 확인
    Validator-->>Modal: 규칙명 필요 또는 통과
    Modal->>Validator: 대상 조건 확인
    Validator-->>Modal: 대상 조건 필요 또는 통과
    Modal->>Validator: 발송 시점 확인
    Validator-->>Staff: 저장 가능 또는 오류 표시
```
