# DLG-071-002 발송 미리보기 필드 검증

```mermaid
sequenceDiagram
    autonumber
    actor Staff as 직원
    participant Modal as 미리보기
    participant Validator as 검증

    Staff->>Modal: 미리보기 열기
    Modal->>Validator: 대상자 존재 여부 확인
    Validator-->>Modal: 대상자 없음 또는 다음 검증
    Modal->>Validator: 본문 입력 여부 확인
    Validator-->>Modal: 본문 누락 또는 다음 검증
    Modal->>Validator: 채널 설정 확인
    Validator-->>Staff: 발송 가능 상태 또는 오류 표시
```
