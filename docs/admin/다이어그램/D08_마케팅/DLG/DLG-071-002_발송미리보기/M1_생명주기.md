# DLG-071-002 발송 미리보기 생명주기

```mermaid
sequenceDiagram
    autonumber
    actor Staff as 직원
    participant Modal as 발송 미리보기
    participant Template as 템플릿
    participant Preview as 미리보기

    Staff->>Modal: 모달 열기
    Modal->>Template: 템플릿과 대상 불러오기
    Template-->>Preview: 메시지 미리보기 생성
    Staff->>Preview: 수정 또는 발송 확인 선택
    Preview-->>Modal: 수정 내용 반영 또는 확인 상태 표시
```
