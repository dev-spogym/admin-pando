# DLG-078-002 발송 확인 모달 생명주기

```mermaid
sequenceDiagram
    autonumber
    actor Staff as 직원
    participant Modal as 발송 확인
    participant Sender as 발송 처리

    Staff->>Modal: 발송 확인 모달 열기
    Modal-->>Staff: 대상 수, 채널, 비용 표시
    Staff->>Modal: 발송 확정 또는 취소
    Modal->>Sender: 발송 요청
    Sender-->>Modal: 완료 또는 실패 결과
    Modal-->>Staff: 결과 표시
```
