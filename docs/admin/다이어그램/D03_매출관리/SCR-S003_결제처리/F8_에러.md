## 1. 목적
SCR-S003의 즉시 결제/결제링크 발송 시 오류 분기를 표현한다.

## 2. 전제조건
- DLG-S003에서 결제 완료 클릭

## 3. 다이어그램

```mermaid
flowchart TD
    EXEC[즉시 결제 실행] --> STEP1[마일리지 차감]

    STEP1 --> STEP2[payment 저장]
    STEP1 -->|": 실패"|ERR_DEDUCT((마일리지 차감에 실패했습니다.))

    STEP2 -->|": 200"|STEP3[마일리지 적립 1%]
    STEP2 -->|": 500"|ERR_INSERT((결제 저장에 실패했습니다.))
    STEP2 -->|": 409"|ERR_DUP[중복 결제 오류-S004 표시]
    STEP2 -->|": Timeout"|ERR_TIMEOUT[타임아웃\n정산 확인 필요]
    STEP2 -->|": Network"|ERR_NET[네트워크 오류\n재시도 안내]

    STEP3 --> STEP4[할인 이력 기록\n해당시]
    STEP3 -->|": 실패"|ERR_ACCRUE[적립 실패\n결제는 완료 처리]

    STEP4 --> COMPLETE[결제 완료 화면]

    LINK_EXEC[결제링크 발송 실행] --> LINK_CONTACT{연락처 유효성}
    LINK_CONTACT -->|": 누락"|ERR_CONTACT[회원 연락처가 필요합니다.]
    LINK_CONTACT -->|": 통과"|LINK_ACTIVE_CHECK{활성 링크 존재 여부}
    LINK_ACTIVE_CHECK -->|": 있음"|ERR_LINK_DUP[활성 결제링크가 이미 존재합니다.]
    LINK_ACTIVE_CHECK -->|": 없음"|LINK_SEND[메시지 발송]
    LINK_SEND -->|": 성공"|LINK_DONE[linkStatus=SENT]
    LINK_SEND -->|": 실패"|ERR_LINK_SEND[결제링크 발송에 실패했습니다.]

    ERR_INSERT --> STEP2
    ERR_NET --> STEP2

    classDef screen fill:#E3F2FD,stroke:#1976D2,color:#0D47A1
    classDef error fill:#FFEBEE,stroke:#C62828,color:#B71C1C

    class COMPLETE,LINK_DONE success
    class ERR_DEDUCT,ERR_INSERT,ERR_DUP,ERR_TIMEOUT,ERR_NET,ERR_CONTACT,ERR_LINK_DUP,ERR_LINK_SEND error
    class ERR_ACCRUE warning
    class EXEC,STEP1,STEP2,STEP3,STEP4,LINK_EXEC,LINK_CONTACT,LINK_ACTIVE_CHECK,LINK_SEND system
```

## 4. 엣지 설명

| 출발 | 도착 | 설명 |
|------|------|------|
| STEP1 | ERR_DEDUCT | 마일리지 차감 실패 |
| STEP2 | ERR_INSERT | 오류 |
| STEP2 | ERR_DUP | 409 중복 결제 |
| STEP2 | ERR_TIMEOUT | 타임아웃 |
| STEP3 | ERR_ACCRUE | 적립 실패(결제는 완료) |
| LINK_CONTACT | ERR_CONTACT | 링크 발송 연락처 누락 |
| LINK_ACTIVE_CHECK | ERR_LINK_DUP | 기존 활성 링크 존재 |
