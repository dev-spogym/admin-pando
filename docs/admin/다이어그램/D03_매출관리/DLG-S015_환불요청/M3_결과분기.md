## 1. 목적
DLG-S015 부분환불 처리 후 승인 대기 또는 즉시 완료 분기를 표현한다.

## 2. 전제조건
- DLG-S015에서 제출 완료

## 3. 다이어그램

```mermaid
flowchart TD
    SUBMIT_OK[제출 완료] --> ROUTE{처리 경로}

    ROUTE -->|": 10만원 미만"|REFUND_ROUTE{결제경로 확인}
    ROUTE -->|": 10만원 이상"|SEND_APPROVAL[승인 요청 발송\n알림 전송]

    REFUND_ROUTE -->|": 현장 영수증 등록"|EXTERNAL_REFUND[외부 POS/현금 환불 확인\n환불 증빙/메모 입력]
    REFUND_ROUTE -->|": 결제링크 완료"|LINK_PG_REFUND[결제링크 PG 환불 요청]

    EXTERNAL_REFUND -->|": 확인 완료"|PARTIAL_DONE[부분환불 완료\nsales PARTIAL_REFUNDED]
    EXTERNAL_REFUND -->|": 증빙 누락"|REFUND_ERR[환불 증빙 필요 토스트]
    LINK_PG_REFUND -->|": 성공"|PARTIAL_DONE
    LINK_PG_REFUND -->|": 실패"|REFUND_ERR

    SEND_APPROVAL --> APPROVAL_WAIT[승인 대기 상태]

    PARTIAL_DONE --> DLG_S014[DLG-S014 환불상세 표시]
    APPROVAL_WAIT --> CLOSED_WAIT([모달 닫힘\n승인 대기 토스트])
```

## 4. 엣지 설명

| 출발 | 도착 | 설명 |
|------|------|------|
| ROUTE | REFUND_ROUTE | 즉시 처리 시 결제경로 확인 |
| ROUTE | SEND_APPROVAL | 승인 요청 발송 |
| REFUND_ROUTE | EXTERNAL_REFUND | 현장 영수증 등록 건은 외부 POS/현금 환불 확인 |
| REFUND_ROUTE | LINK_PG_REFUND | 결제링크 완료 건은 PG 환불 요청 |
| EXTERNAL_REFUND | PARTIAL_DONE | 외부 환불 확인 후 부분환불 완료 |
| LINK_PG_REFUND | PARTIAL_DONE | 결제링크 PG 환불 성공 |
| PARTIAL_DONE | DLG_S014 | 환불 상세 모달 표시 |
