## 화면 목적
AI 기반 분석을 활용하여 향후 매출, 회원 수, 이탈률 등을 예측하는 화면입니다.
과거 데이터 패턴을 학습하여 미래 운영 계획 수립과 선제적 대응에 활용합니다.

## 주요 구성요소

### 예측 항목 선택
- 예측 지표 선택 (매출 / 신규 회원 수 / 이탈 회원 수 / 출석율)
- 예측 기간 선택 (향후 1개월 / 3개월 / 6개월 / 12개월)
- 대상 지점 선택

### 예측 결과 차트
- 과거 실적 + 예측 값 통합 선 차트 (예측 구간은 점선 또는 밴드로 구분)
- 예측 신뢰 구간 표시 (낙관적 / 기본 / 보수적 시나리오)
- 예측 기반 데이터 기간 안내

### 예측 인사이트
- 예측 근거 주요 요인 설명 (계절성, 최근 추이, 이벤트 영향 등)
- 이탈 위험 회원 예측 목록 (회원 이름, 이탈 위험도 수치)
- 권장 대응 액션 제안

#### 인사이트 생성 기준
- 인사이트는 사용자가 [예측 실행]을 눌러 결과가 생성될 때 시스템이 자동 생성합니다. 운영자나 담당자가 문구를 직접 작성하지 않습니다.
- [재실행] 시 기존 인사이트를 덮어쓰고 최신 데이터 기준일로 다시 생성합니다.
- 이탈 위험 회원 목록은 매일 06:00 전일 기준 위험도를 재산출해 기본 갱신되며, `이탈 회원 수` 예측 실행 시 선택 지점 기준으로 조회해 표시합니다.
- 근거 요인은 영향도가 큰 항목을 최대 3개까지 표시합니다. 각 요인은 요인명, 영향 방향, 근거 수치, 기준 기간을 함께 보여줍니다.
- 이탈 위험 회원 목록은 회원명, 소속 지점, 담당자, 위험도, 주요 근거, 마지막 방문일, 이용권 만료일, 권장 액션, 상태를 표시합니다.
- 권장 대응 액션은 근거 요인별 고정 규칙으로 제안합니다. 자동 메시지 발송, 자동 할인 적용, 자동 회원 상태 변경은 하지 않습니다.
- 사용자는 인사이트 확인 후 회원 상세로 이동하거나 담당자 케어 배정 또는 수동 후속 조치를 진행합니다.

### 시나리오 비교
- 예측 실행 결과를 낙관 / 기본 / 보수 3개 행으로 비교하는 읽기 전용 테이블입니다.
- 사용자가 표 안에서 값을 수정하거나 시나리오를 직접 생성하지 않습니다.
- 컬럼은 시나리오, 예측 기준값, 시작 대비 증감, 증감률, 신뢰 구간, 주요 해석으로 구성합니다.
- 낙관은 예측 밴드 상단값, 기본은 중앙 예측값, 보수는 예측 밴드 하단값을 표시합니다.
- 표 행 클릭 기능은 제공하지 않으며, PDF 내보내기 시 차트와 함께 포함됩니다.

## 계정별 차이
| 계정 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 | 전체 지점 예측 분석 | 항목·기간 설정, 내보내기 |
| 센터장 | 소속 지점 예측 | 항목·기간 설정 |
| 매니저 이하 | 접근 불가 | — |

## 주요 UX 흐름
1. 예측 지표, 기간, 지점을 선택한다.
2. 예측 실행 버튼 클릭 → AI 분석 처리 중 표시 → 완료 후 차트 표시.
3. 차트에서 마우스 오버 시 해당 시점의 예측 수치와 신뢰 구간 툴팁 표시.
4. 이탈 위험 회원 목록에서 회원 이름 클릭 → 해당 회원 상세 화면으로 이동.
5. 권장 대응 액션은 자동 실행하지 않고 담당자가 확인 후 수동 후속 조치한다.
