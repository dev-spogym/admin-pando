## 화면 목적
지점을 `임시휴업` 또는 `폐점` 상태로 변경하기 전 영향 범위를 안내하고 최종 확인을 받는 다이얼로그입니다.
운영 상태 변경은 회원 이용, 예약, 신규 가입, 회원앱 지점 노출, 직원 접근 권한에 영향을 줄 수 있으므로 대상 지점과 영향 범위를 확인한 뒤 확정합니다.

## 주요 구성요소
- "지점 운영 상태를 변경하시겠습니까?" 제목
- 대상 지점명과 지점 코드 표시
- 현재 운영 상태 배지 표시
- 변경 후 운영 상태 표시 또는 선택 (`임시휴업` / `폐점`)
- 적용 예정일 선택 (즉시 / 날짜 지정)
- 변경 사유 입력란 (필수)
- 영향 안내:
  - 활성 회원 수
  - 진행 예약 수
  - 신규 가입·결제·예약 차단 여부
  - 회원 앱 지점 노출 변경 여부
  - 직원 계정 접근 영향
- 취소 버튼
- 운영 상태 변경 버튼

## 주요 UX 흐름
1. 지점 관리 화면에서 비활성화 또는 운영 상태 변경 액션 클릭 → 다이얼로그 표시
2. 변경 후 상태, 적용 예정일, 변경 사유를 입력
3. 활성 회원 수, 진행 예약 수, 회원앱 노출, 신규 가입·결제·예약 차단 등 영향 범위 확인
4. 취소 → 다이얼로그 닫힘, 지점 상태 유지
5. 운영 상태 변경 확인 → 지점 상태를 `임시휴업` 또는 `폐점`으로 변경 → 관련 알림 발송 및 감사 로그 기록

## 화면 상태
| 상태 | 설명 |
|---|---|
| 표시 | 영향 범위 안내, 변경 후 상태, 예정일, 사유 입력 |
| 사유 미입력 | 변경 사유 필수 오류 표시, 확인 버튼 비활성 |
| 처리 중 | 확인 버튼 클릭 후 처리 중 (버튼 비활성) |
| 완료 | 다이얼로그 닫히고 지점 상태 배지 변경 |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| superAdmin / primary | 전체 지점의 운영 상태를 변경할 수 있습니다. |
| owner | 소속 지점 정보를 조회·수정할 수 있으나 운영 상태 변경은 할 수 없습니다. |
| manager / trainer / fc / staff / readonly | 운영 상태 변경 다이얼로그 접근 불가 |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
