# SCR-100 자동화 정책 라이브러리 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 본사 정책 세트 실데이터 연동은 후속 단계입니다.

## 화면 목적

- 본사가 전사 자동화 정책 세트를 생성·배포·중지·복제하는 화면입니다.
- D-day 기준일을 사용하는 만료 알림 정책은 `회원 이용권 만료`, `결제기한 만료`, `락커 만료` 3개 정책 유형으로 분리해 관리합니다.
- 세 정책은 모두 본사가 기준일 step을 생성해 지점에 배포하고, 각 지점 센터장(owner)만 SCR-072/SCR-080A에서 정책 또는 step의 ON/OFF를 변경할 수 있습니다.
- `회원 이용권 만료`와 `락커 만료` 정책은 지점 센터장(owner)이 지점 운영 목적의 추가 step을 생성할 수 있습니다. 지점 추가 step은 해당 지점에만 적용되며 본사 정책 원본과 다른 지점에는 영향이 없습니다.
- `결제기한 만료` 정책은 미수금·잔액·할부 납입기한에만 적용하며 지점 추가 step을 허용하지 않습니다. 결제링크 만료 알림은 PAY-06 기준 D-3/D-1 고정 정책을 따르며 본 화면의 결제기한 만료 정책과 분리합니다.

## 주요 UX 흐름

1. `정책 세트 생성` 버튼 클릭 시 [DLG-H1001-001 정책 세트 편집](../DLG-H1001-001-정책세트편집/00-기본화면.md)을 생성 모드로 엽니다.
2. 본사 담당자가 정책명, 정책 유형(회원 이용권 만료/결제기한 만료/락커 만료/운영 자동화), 적용 범위, 기본 정책 여부를 입력합니다.
3. Step 리스트에서 D-30, D-14, D-7 등 기준일과 기본 채널, 템플릿, 기본 활성값을 입력합니다.
4. 저장 전 [시뮬레이션]으로 가상 기준일에 step이 언제 발송되는지 확인합니다. 회원 이용권 만료는 이용권 종료일, 결제기한 만료는 납입기한, 락커 만료는 락커 이용 종료일을 기준일로 사용합니다.
5. 저장하면 적용 범위 내 지점에 정책 버전이 배포됩니다.
6. 각 지점의 센터장(owner)은 SCR-072/SCR-080A에서 배포받은 정책 또는 step을 ON/OFF할 수 있습니다. 회원 이용권 만료·락커 만료 정책에서는 허용된 범위 내 지점 추가 step도 생성할 수 있습니다.
7. 정책 카드 선택 시 우측 상세 패널에 적용 범위, 지점별 ON/OFF 현황, 배포 실패 지점, 변경 영향 범위를 즉시 반영합니다.
8. 사용 중지된 정책은 신규 적용만 차단하고 기존 사용 지점은 영향 범위를 고지합니다.

## 5. 운영 규칙

- 고정 D-day 대신 본사가 입력한 기준일 step 리스트 구조를 사용한다.
- 만료 알림 정책 유형은 `회원 이용권 만료`, `결제기한 만료`, `락커 만료`로 분리한다.
- `회원 이용권 만료`와 `락커 만료`는 지점 센터장(owner)의 지점 추가 step을 허용한다. 지점 추가 step은 해당 지점 전용이며 본사 원본을 수정하지 않는다.
- `결제기한 만료`는 지점 추가 step을 허용하지 않는다. 지점은 본사 step의 ON/OFF만 변경한다.
- 결제링크 만료 알림은 PAY-06의 7일 고정 링크, D-3/D-1 고정 알림 기준을 따르며 본 화면의 결제기한 만료 정책으로 관리하지 않는다.
- 지점별 ON/OFF와 지점 추가 step 생성·수정·삭제는 각 지점 센터장(owner)만 가능하며 manager/fc/staff/readonly는 변경할 수 없다.
- 지점에서 OFF 처리하거나 지점 추가 step을 등록해도 본사 정책 원본은 변경되지 않고 해당 지점의 적용 상태만 변경된다.
- 사용 중지된 정책은 신규 적용만 막고 기존 사용 지점은 영향 범위를 고지한다.

## 6. 퍼블리싱 포인트

- 본사 화면은 정책 설계 도구처럼 보여야 한다.
- 카드에서 정책 성격, 범위, 사용중 지점 수가 한 번에 읽혀야 한다.

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| superAdmin / primary | 정책 세트 생성·수정·복제·중지·배포·시뮬레이션을 수행할 수 있습니다. |
| owner / manager / trainer / fc / staff / readonly | 본사 정책 라이브러리 화면 접근 불가. 지점 ON/OFF는 SCR-072에서 owner만 수행합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
