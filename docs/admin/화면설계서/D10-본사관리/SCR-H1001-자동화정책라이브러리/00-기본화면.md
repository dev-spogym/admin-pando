# SCR-100 자동화 정책 라이브러리 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 본사 정책 세트 실데이터 연동은 후속 단계입니다.

## 화면 목적

- 본사가 전사 자동화 정책 세트를 관리하는 화면이다.

## 주요 구성요소

```text
Header
PolicySetCards
PolicyTable
StepPreviewPanel
UsageStatusPanel
```

## 주요 구성요소

- 정책 세트 생성/수정/중지
- 적용 범위 설정
- 스텝 구성
- 템플릿 연결
- 지점 수정 허용 범위 설정

## 주요 UX 흐름

1. `정책 세트 생성` 버튼 클릭 시 [DLG-100-001 정책 세트 편집](../DLG-H1001-001-정책세트편집/00-기본화면.md) 성격의 생성 다이얼로그를 연다.
2. 정책 카드 선택 시 우측 상세 패널에 적용 범위, 지점 수정 권한, 신규 적용 상태를 즉시 반영한다.
3. `허용 범위 설정` 버튼 클릭 시 적용 범위, 신규 적용 상태, 지점 수정 허용 범위를 조정하는 다이얼로그를 연다.
4. 사용 중지된 정책은 신규 적용만 차단하고 기존 사용 지점은 영향 범위를 고지한다.

## 5. 운영 규칙

- 고정 D-day 대신 본사가 입력한 기준일 step 리스트 구조를 사용한다.
- 사용 중지된 정책은 신규 적용만 막고 기존 사용 지점은 영향 범위를 고지한다.

## 6. 퍼블리싱 포인트

- 본사 화면은 정책 설계 도구처럼 보여야 한다.
- 카드에서 정책 성격, 범위, 사용중 지점 수가 한 번에 읽혀야 한다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 지점 전체 데이터를 조회하고 업무 액션을 수행할 수 있습니다. |
| trainer / fc / staff | 본인 담당 범위 또는 배정된 업무 데이터 중심으로 조회합니다. |
| readonly | 조회만 가능하며 생성·수정·삭제·확정 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
