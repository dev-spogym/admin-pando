## 화면 목적
센터장·매니저가 로그인 직후 지점 컨텍스트에서 진입하는 운영 메인 화면으로, 현재 지점의 운영 현황을 한눈에 파악합니다.
회원 현황, 매출, 출석, 주의 대상 회원(만료 예정·생일자·미수금·홀딩), 최근 활동 이력을 종합적으로 표시합니다.
공통 통합 진입 뷰는 SCR-101 기준으로 별도 관리합니다.

## 주요 구성요소

### 핵심 지표 요약 카드
- 전체 회원 수
- 활성 회원 수
- 만료 예정 회원 수 (30일 이내)
- 오늘 출석 수
- 이번 달 매출

### 분포 차트
- 회원 성별 분포 (원형 차트)
- 회원 연령대 분포 (막대 차트)

### 추이 차트
- 월별 매출 추이 (선 또는 막대 차트)
- 주간 출석 현황 (막대 차트)

### 주의 대상 위젯
- 오늘 생일 회원 목록
- 미수금 발생 회원 목록
- 홀딩 중인 회원 목록
- 만료 임박 회원 목록 (각 위젯별 전체보기 링크)

### 최근 활동 로그
- 최근 시스템 활동 이력 요약 (누가 무엇을 했는지)
- 표시 범위: 현재 지점 기준 최근 10건. 슈퍼관리자는 선택 지점 컨텍스트 기준으로 표시
- 데이터 소스: 감사 로그(HQ-EXT-06 / SCR-097) 중 운영자가 확인해야 하는 주요 이벤트
- 표시 항목: 발생 시각, 작업자, 작업 유형, 대상, 요약 문구
- 기본 노출 이벤트:
  - 회원 등록/수정/탈퇴/복구
  - 결제 등록/취소/환불
  - 이용권 등록/홀딩/연장/만료 처리
  - 수업 등록/수정/취소, 출석/노쇼 처리
  - 권한 변경, 백업/복원, 중요 설정 변경
- 제외 이벤트: 단순 조회, 페이지 진입, 자동 새로고침, 실패 없는 백그라운드 polling
- 행 클릭: 상세가 있는 이벤트는 대상 화면으로 이동, 설정/권한/감사 이벤트는 감사 로그 상세로 이동
- "전체보기" 클릭: 감사 로그(SCR-097)로 이동하며 현재 지점 필터를 유지

### 상단 액션
- 수동 새로고침 버튼

## 계정별 차이
| 계정 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 | 현재 선택된 지점의 대시보드 | 새로고침, 위젯 내 회원 상세 이동 |
| 센터장 / 매니저 / FC / 직원 | 자신이 속한 지점의 대시보드 | 새로고침, 위젯 내 회원 상세 이동 |

## 주요 UX 흐름
1. 로그인 완료 시 자동으로 이 화면으로 이동한다.
2. 첫 방문 시 환영 배너가 상단에 표시되며 닫기 버튼으로 제거한다.
3. 데이터 로딩 중에는 각 카드와 위젯에 스켈레톤이 표시된다.
4. 위젯 내 회원 이름 클릭 → 해당 회원 상세 화면으로 이동.
5. 위젯 하단 "전체보기" 클릭 → 해당 메뉴 화면으로 이동.

## 화면 상태
| 상태 | 설명 |
|---|---|
| 기본 | 지표 카드, 차트, 위젯 정상 표시 |
| 로딩 | 데이터 불러오는 중 (스켈레톤 표시) |
| 첫 방문 | 환영 배너 상단 표시 |
| 데이터 없음 | 각 위젯에 데이터 없음 안내 표시 |
| 최근 활동 없음 | "최근 활동이 없습니다" 빈 상태 표시 |
| 오류 | 데이터 로드 실패 시 재시도 안내 표시 |
