## 화면 목적

권한 매트릭스를 변경하거나 역할 자체를 삭제·교체할 때, 영향 받는 범위를 사전에 확인해 운영 사고를 방지하는 확인 다이얼로그입니다. 매니저·센터장이 의도하지 않은 권한 변경으로 직원 업무가 차단되는 상황을 막습니다.
본 다이얼로그의 영향 분석은 저장 전 확인 안내입니다. 별도 예측 산식, 영향 시뮬레이션, 분석 리포트 생성은 포함하지 않습니다.

## 트리거

- SCR-081에서 권한 매트릭스를 변경한 후 [저장] 클릭
- SCR-081에서 [역할 삭제] 클릭
- SCR-081에서 역할 복사·교체 시 (선택)

## 주요 구성요소

- **요약 헤더**: 변경 또는 삭제 대상 역할 이름과 작업 유형(권한 변경 / 역할 삭제 / 역할 교체) 표시
- **영향 범위 카드 2종**:
  - 배정된 직원 수 (예: "이 역할에 배정된 직원 12명")
  - 그 직원이 담당하는 회원 수 합계 (예: "담당 회원 합계 384명")
- **영향 직원 목록 (펼침)**: 직원명·소속 지점·직무 컬럼으로 영향 받는 직원을 표시. 5명까지 기본 표시, 더보기로 확장.
- **변경 차이 요약**: 권한 변경의 경우 추가/제거된 권한 항목을 before/after 비교로 표시.
- **확인 액션**: [취소] / [그대로 진행] 버튼. 진행 클릭 시 후속 단계(저장 또는 삭제 확인 DLG-081-004)로 이동.

## 계정별 차이

| 계정 | 권한 |
|---|---|
| 슈퍼관리자 / 센터장 | 전체 영향 정보 조회 + 진행 |
| 매니저 이하 | SCR-081 접근 불가이므로 본 다이얼로그도 접근 불가 |

## 주요 UX 흐름

1. SCR-081에서 권한 변경 후 [저장] 또는 [역할 삭제] 클릭 시 다이얼로그가 표시된다.
2. 영향 범위(직원·회원 수)와 영향 직원 목록을 확인한다.
3. 권한 변경의 경우 before/after 차이를 확인한다.
4. [그대로 진행] 클릭 → 후속 단계 진행 (저장 또는 DLG-081-004 삭제 확인).
5. [취소] 클릭 → SCR-081로 돌아가 변경 사항을 재검토한다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 | 영향 범위 카드 + 직원 목록 5건 미리보기 |
| 더보기 펼침 | 영향 직원 목록 전체 표시 |
| 영향 없음 | 배정 직원 0명일 때 안내 메시지 표시 후 진행 버튼만 활성 |
| 처리 중 | 진행 후 저장/삭제 API 처리 중 표시 |

## 비즈니스 규칙

- 배정 직원 0명이면 안내만 표시하고 빠르게 진행할 수 있도록 한다.
- 민감 기능(회원 영구 삭제, 환불 처리, 급여 확정·지급, 슈퍼관리자 권한 부여/회수, 데이터 복원, 감사로그 내보내기) 권한이 추가/제거되는 경우 별도 강조 표시한다.
- 역할 삭제 시 후속 단계인 DLG-081-004에서 직원 재배정 입력을 받아야 한다.
