# SCR-080A 지점 자동화 적용 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 본사 정책 세트 적용 데이터 연동은 후속 단계입니다.

## 화면 목적

- 지점이 본사 정책 세트를 선택 적용하는 화면이다.

## 주요 구성요소

```text
PageHeader
PolicySummaryCards
ScopeTabs
PolicySelector
StepTable
ActionFooter
```

## 주요 구성요소

- 상품군별 정책 세트 선택
- 스텝별 활성/비활성
- 테스트 발송
- 시뮬레이션 시 플랫폼 예상 비용 확인
- 적용 저장

## 4. 운영 규칙

- 지점은 새 정책 세트를 만들지 않는다.
- 지점은 본사가 허용한 스텝만 끌 수 있다.
- 지점은 정책 템플릿 본문을 수정하지 않는다.
- SMS/알림톡 비용 정보는 플랫폼 API 조회값만 참고용으로 노출한다.

## 5. 퍼블리싱 포인트

- 단순 토글 목록이 아니라 현재 적용 중인 정책 요약이 먼저 보여야 한다.
- 상품군, 스텝, 채널의 3단 구조가 읽혀야 한다.

## 주요 UX 흐름

1. 사용자가 메뉴 또는 직접 URL로 화면에 진입합니다.
2. 기본 필터와 요약 영역을 먼저 확인합니다.
3. 목록·카드에서 대상 항목을 선택해 상세 정보와 가능한 액션을 확인합니다.
4. 저장·적용·상태 변경 후 화면 데이터를 갱신하고 결과를 토스트로 안내합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 지점 전체 데이터를 조회하고 업무 액션을 수행할 수 있습니다. |
| trainer / fc / staff | 본인 담당 범위 또는 배정된 업무 데이터 중심으로 조회합니다. |
| readonly | 조회만 가능하며 생성·수정·삭제·확정 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
