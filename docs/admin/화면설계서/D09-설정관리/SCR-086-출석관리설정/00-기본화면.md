## 화면 목적
회원의 출석을 인정하는 기준과 직원 근태 자동 분류 기준을 설정하는 화면입니다.
수업/회원 출석 기준과 직원 근태 기준은 별도 정책값으로 관리합니다. 출석 인정 N분 전/후, 수업 지각 N분, 수업 지각 N회 알림 기준은 회원·수업 출석에만 적용하고, 직원 지각 기준은 `직원 근태 기준 설정`의 지점별 직원 지각 허용 N분을 따릅니다. 지점별 기준의 기본 수정 권한은 소속 지점 센터장(owner)에게 있으며, 슈퍼관리자의 개별 지점값 수정은 비상 사유 입력 시에만 허용합니다.
QR 출석은 출석 수단 중 하나로 사용할지와 화면에 노출할지를 정하는 설정이며, QR 발급·토큰 만료·서버 검증 같은 실행 로직은 이 화면에서 설정하지 않습니다.

## 주요 구성요소

### 출석 인정 시간 설정
- 출석 인정 시작 시각 (수업 시작 기준 N분 전부터 인정)
- 출석 인정 마감 시각 (수업 시작 기준 N분 후까지 인정)
- 주말/공휴일 출석 인정 여부

### 수업/회원 지각 기준 설정
- 수업 지각 판단 기준 시간 (수업 시작 후 N분까지는 정시 인정, N분 초과 입장부터 지각)
- 수업 지각 횟수 누적 시 알림 발송 기준 (집계 기간 내 N회 초과 시 자동 알림)
- 수업 지각 알림 수신자 (회원 / 관리자 / 센터장 중 선택)
- 노쇼 판단 유예 시간 (출석 인정 마감 후 N분까지 미입장 시 노쇼)

### 직원 근태 기준 설정
- 직원 지각 허용 시간 (정규 출근 시각 기준 N분까지는 정상, N분 초과 출근부터 지각)
- 직원 지각 누적 알림 기준 (월 또는 지점 설정 기간 내 N회 초과 시 알림)
- 직원 지각 알림 수신자 (센터장 / 매니저 / 직원 본인 중 선택)
- 직원 근태 기준 적용 시점 (저장 이후 신규 출퇴근 기록부터 적용, 과거 기록 소급 변경 없음)

### QR 출석 설정
- QR 출석 사용 여부
- 키오스크 QR 표시 여부
- QR 출석은 출석 수단 옵션으로만 관리하며, 갱신 주기·유효 시간·스캔 검증 정책은 본 화면의 설정 항목에 포함하지 않음
- 출석 수단 안내 (QR / 키오스크 / IoT / 수동 출석의 사용 범위와 설정 위치)

### 자동 출석 규칙
- 자동 출석 처리 활성화 여부 (IoT 출입 기록 기반 자동 출석 인정)
- 수업 없이 자유 이용 입장 시 출석 인정 여부
- 하루 중 동일 회원 출석 중복 처리 방식 (첫 입장만 / 매 입장마다)

### 출석 기록 보관 설정
- 출석 이력 보관 기간 (개월 단위)

## 계정별 차이
| 계정 | 권한 |
|---|---|
| 슈퍼관리자 | 전체 지점 설정 조회, 본사 표준 정책 세트 배포 가능. 개별 지점값 직접 수정은 비상 사유 입력 시만 허용 |
| 센터장 | 소속 지점 설정 조회 및 수정 가능 |
| 매니저 | 조회만 가능 |
| 기타 | 접근 불가 |

## 주요 UX 흐름
1. 화면 진입 시 현재 저장된 출석 설정값을 불러와 표시한다.
2. 각 항목 변경 후 저장 버튼 클릭 → 변경 내용 저장 완료 메시지 표시.
3. QR 출석 사용을 켜면 키오스크 QR 표시 토글이 활성화된다.
4. 자동 출석 처리를 활성화하면 IoT 출입 설정(SCR-083)과 연동 안내 메시지가 표시된다.
5. 직원 지각 허용 시간을 변경하면 D07 `SCR-063 직원 근태 관리`의 신규 출퇴근 자동 분류 기준이 변경된다.
6. 저장하지 않고 페이지 이탈 시 미저장 경고(DLG-080-001)가 표시된다.

## 화면 상태
| 상태 | 설명 |
|---|---|
| 기본 | 저장된 설정값 표시, 저장 버튼 비활성 |
| 수정 중 | 변경 발생 시 저장 버튼 활성 |
| 저장 완료 | 완료 메시지 표시 후 자동 해제 |
| IoT 미연결 | 자동 출석 활성화 시 IoT 기기 미연결 안내 표시 |
| QR 출석 비활성 | QR 출석 사용 OFF 상태에서는 키오스크 QR 표시 토글 비활성 |
| 직원 근태 기준 미설정 | 직원 지각 자동 분류 보류 안내와 필수 입력 강조 |
