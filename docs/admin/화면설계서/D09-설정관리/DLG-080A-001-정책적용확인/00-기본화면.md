# DLG-080A-001 ON/OFF 변경 확인 — 기본화면

## 화면 목적

- 센터장(owner)이 지점 정책/스텝 ON/OFF 변경과 지점 추가 step 변경 내용을 최종 확인하는 다이얼로그다.
- 본사 HQ-09에서 정의한 기준일·스텝 순서·트리거 조건은 확인용으로만 표시하고 수정하지 않는다.
- 회원 이용권 만료·락커 만료의 지점 추가 step은 해당 지점에만 적용되는 변경으로 표시한다. 결제기한 만료에는 지점 추가 step 변경 항목이 나타나지 않는다.

## 주요 구성요소

- 적용 대상 정책 유형: 회원 이용권 만료 / 결제기한 만료 / 락커 만료
- 선택 정책 세트명
- ON/OFF 변경 스텝 목록
- 지점 추가 step 생성·수정·삭제 목록
- 테스트 발송 여부
- 플랫폼 예상 비용 스냅샷

## 주요 UX 흐름

1. 부모 화면에서 실행 버튼을 클릭하면 다이얼로그를 엽니다.
2. 현재 선택한 정책 유형과 변경 요약을 확인합니다.
3. actor가 해당 지점의 센터장(owner)인지 검증한 뒤 저장 또는 확정 버튼을 활성화합니다.
4. 결제기한 만료 정책에 지점 추가 step 변경이 포함되어 있으면 저장을 차단하고 "결제기한 만료는 본사 정책 step만 사용할 수 있습니다"를 표시합니다.
5. 완료 시 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner | 부모 화면에서 변경한 정책/스텝 ON/OFF와 허용된 지점 추가 step 변경 내용을 확인하고 저장할 수 있습니다. |
| manager | 변경 요약 조회만 가능하며 저장·확정 액션은 숨기거나 비활성화합니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
