# SCR-082A 키오스크 IoT 설정 — 기본화면

## 화면 목적

- 키오스크와 출입 장비의 기본 설정값을 관리합니다.
- 본 화면은 설정값 등록·수정·상태 확인만 담당하며, 키오스크 단말 운영 콘솔이나 원격 제어 화면이 아닙니다.
- 고정 기기 종류는 출입 게이트 / 키오스크 / 락커 컨트롤러 / InBody 측정기 4종입니다.

## 주요 구성요소

### 장비 기본값

| 항목 | 설명 |
|---|---|
| 기기 종류 | 출입 게이트 / 키오스크 / 락커 컨트롤러 / InBody 측정기 중 1개 선택 |
| 기기명 | 운영자가 식별할 이름 |
| 설치 위치 | 예: 1층 입구, 데스크 우측, 남자 락커룸 |
| 사용 여부 | ON / OFF |
| 상태 확인 | OK / 불안정 / 오류 / 점검 중 배지와 마지막 수신 시각 |
| 헬스체크 주기 | 기본 5분. 본사(primary/superAdmin)가 전역 기준을 변경 가능 |

### 출입 규칙

- 출입 허용 시간
- 중복 출입 방지 시간
- 만료 회원 출입 허용 여부
- 직원 출석 허용 여부

### 키오스크 연동 설정

- 키오스크에서 사용할 출석 방식과 SCR-082 화면 구성 설정을 함께 확인합니다.
- 키오스크 운영 화면 자체는 KIOSK 기획문서에서 정의합니다.

## 3. 퍼블리싱 포인트

- 장비 설정과 운영 모니터링은 구분해서 보이게 한다.
- 원격 재시작, 로그 다운로드, 단말 운영 콘솔은 제공하지 않는다.

## 주요 UX 흐름

1. 사용자가 메뉴 또는 직접 URL로 화면에 진입합니다.
2. 등록된 기기의 종류, 위치, 상태 배지, 마지막 수신 시각을 확인합니다. 최신 헬스체크가 정상 응답이면 OK, 미응답·응답 지연·부분 응답이면 불안정, 인증 실패·하드웨어 오류이면 오류로 표시합니다.
3. 기기 설정 또는 출입 규칙을 수정합니다.
4. 저장 시 변경 요약을 표시하고 연결된 기기에 다음 동기화 시점부터 적용합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| 슈퍼관리자 | 전체 지점 설정 조회 가능, 본사 정책 항목 수정 가능 |
| 센터장 | 소속 지점 기기 설정과 출입 규칙 수정 가능 |
| 매니저 | 조회만 가능 |
| readonly | 조회만 가능 |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
