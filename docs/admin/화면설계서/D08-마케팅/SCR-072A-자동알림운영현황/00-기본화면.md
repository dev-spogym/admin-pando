# SCR-072A 자동알림 운영현황 — 기본화면

## 화면 목적

- 자동화 정책의 운영 결과를 마케팅 관점에서 확인합니다.
- 본사 HQ-09에서 배포한 회원 이용권 만료, 결제기한 만료, 락커 만료 step과 회원 이용권 만료·락커 만료 지점 추가 step의 적용 상태, 발송 결과, 전환 성과를 확인합니다.
- 본 화면은 운영 현황 조회 화면이며 정책 기준일 수정이나 ON/OFF 변경은 하지 않습니다. 지점별 ON/OFF 변경은 SCR-072에서 센터장(owner)만 수행합니다.

## 주요 구성요소

- **적용 정책 요약**: 정책명, 버전, 정책 유형(회원 이용권 만료/결제기한 만료/락커 만료), 기준일 step 목록, 본사 step/지점 추가 step 구분, 지점 ON/OFF 상태, 마지막 변경자(owner) 표시
- **발송 현황**: step별 대상 수, 발송 성공/실패, 제외 수, 최근 발송 시각
- **전환 성과**: 만료 step 수신 후 재등록, 상담 등록, 결제 진입 수
- **FC 후속 액션 연결**: 미응답/실패 회원을 SCR-071 메시지 발송 또는 MBR-02 상담 등록으로 연결

## 주요 UX 흐름

1. 사용자가 메뉴 또는 직접 URL로 화면에 진입합니다.
2. 기본 필터와 요약 영역을 먼저 확인합니다.
3. 목록·카드에서 대상 항목을 선택해 상세 정보와 가능한 액션을 확인합니다.
4. 저장·적용·상태 변경 후 화면 데이터를 갱신하고 결과를 토스트로 안내합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner | 소속 지점 전체 자동 알림 운영 현황 조회. ON/OFF 변경은 SCR-072에서 수행 |
| manager | 소속 지점 전체 자동 알림 운영 현황 조회. ON/OFF 변경 불가 |
| fc | 본인 담당 회원 관련 발송 결과와 후속 액션 대상 조회 |
| trainer / staff | 접근 제한 |
| readonly | 조회만 가능하며 생성·수정·삭제·확정 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
