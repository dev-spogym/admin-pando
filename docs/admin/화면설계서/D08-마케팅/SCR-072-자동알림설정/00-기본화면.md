## 화면 목적

본사 정책 세트로 내려온 만료 step과, 생일·장기 미방문 같은 지점 운영 이벤트 알림을 관리하는 화면입니다. 만료 정책은 `회원 이용권 만료`, `결제기한 만료`, `락커 만료`로 분리되어 내려오며, 기준일(D-30/D-14/D-7/D-Day 등)은 본사 HQ-09에서 생성·배포됩니다. 지점은 배포받은 정책 또는 step의 ON/OFF를 제어하고, `회원 이용권 만료`와 `락커 만료` 정책에 한해 지점 추가 step을 만들 수 있습니다. `결제기한 만료`의 미수/연체 알림 N일, 반복 주기, 발송 시각, 기본 채널은 본사(superAdmin/primary)가 HQ-09 정책 세트에서 설정해 지점에 배포하며 지점은 ON/OFF만 변경할 수 있습니다. ON/OFF 변경과 지점 추가 step 생성·수정·삭제는 각 지점 센터장(owner)만 가능합니다. 알림 채널은 Push / 카카오톡 / SMS 3종으로 고정합니다. 자동 알림은 회원앱 Push가 기본 채널이며, 회원앱 미설치 또는 Push 실패 시 카카오톡 fallback을 사용할지는 지점 상세 설정에서 선택합니다. SMS는 정책 step에서 명시 선택한 경우에만 발송하며 자동 fallback으로 전환하지 않습니다.

## 주요 구성요소

- **만료 정책 탭**: 회원 이용권 만료 / 결제기한 만료 / 락커 만료를 별도 탭으로 표시합니다. 각 탭에는 본사 step과 지점 추가 step을 구분 배지로 표시합니다.
- **고객 관련 알림 목록**: 회원 이용권 만료 step / 결제기한 만료 step / 락커 만료 step / 생일 축하 / 장기 미방문 / 등록 감사 / 첫 방문 환영만 표시합니다. 이 목록은 모든 고객 알림을 포괄하지 않으며, 목록 밖 알림은 별도 협의 항목입니다.
- **상품/결제 관련 알림 목록**: 이용권 만료 당일 / 홀딩 종료 / 결제 완료 / 환불 처리만 표시합니다. 미수금 발생, 재등록 쿠폰 동봉, 상품 변경 안내 등은 본 목록에 자동 포함하지 않습니다.
- **마일리지 소멸 예정 알림 연계**: MKT-04 자동 소멸 기능에서 발생하는 부속 알림입니다. 자동 알림 목록을 새로 확장하는 항목이 아니라, 회원앱 Push 기본 발송·발송 이력·재시도·카카오톡 fallback 같은 MKT-02 공통 발송 엔진을 사용합니다.
- **락커 만료 알림 목록**: 락커 이용 종료일 기준 본사 step과 지점 추가 step을 표시합니다.
- **예약/출석 관련 알림**: MKT-02 기본 범위에는 첫 방문 환영만 포함합니다. 예약 확정, 예약 취소, 대기열 승격, 노쇼 발생, 출석 N회 달성은 고객사 확인 또는 별도 계약 범위로 분리하며 기본 목록에는 노출하지 않습니다.
- **규칙별 토글 스위치**: 각 알림 규칙 또는 step의 지점 적용 여부를 ON/OFF로 제어합니다. OFF 시 해당 지점에서만 자동 발송이 중단되며, 본사 정책 원본·기준일·기본 템플릿은 변경되지 않습니다. 토글 조작은 센터장(owner)만 가능하며 manager 이하 계정은 disabled 상태와 권한 안내 툴팁만 확인합니다.
- **본사 필수 잠금 상태**: 본사가 `본사 필수`로 배포한 규칙 또는 step은 ON 고정 disabled 토글과 `본사 필수` 배지를 표시합니다. 센터장(owner)도 OFF할 수 없으며, 상세 설정에서 허용된 채널·메시지·발송 시각만 조정할 수 있습니다.
- **플랫폼 상태 배지**: 규칙별로 승인 템플릿 존재 여부, 발신 프로필 연결 여부, 최근 테스트 발송 결과를 배지로 표시합니다.
- **상세 설정 버튼**: 각 규칙 우측의 "상세 설정" 버튼 클릭 시 알림 규칙 상세 설정 다이얼로그가 열립니다. 이 다이얼로그에서 규칙명, 정책 유형, 본사/지점 step 구분, 현재 채널·메시지·발송 시각을 확인하고, 지점이 조정 가능한 메시지·발송 시각·카카오톡 fallback 사용 여부·SMS 명시 발송 여부를 세부 설정합니다. 본사 소유 기준일 step은 읽기 전용으로 표시되며, 지점 추가 step은 센터장(owner)만 기준일을 수정할 수 있습니다. 결제기한 만료의 미수/연체 N일·반복 주기·발송 시각·기본 채널은 본사 설정값을 읽기 전용으로 표시합니다.
- **지점 step 추가 버튼**: 회원 이용권 만료 / 락커 만료 탭에서만 노출됩니다. 클릭 시 DLG-072-002를 열어 지점 추가 만료 step을 등록합니다. 결제기한 만료 탭에서는 노출하지 않습니다.
- **규칙 추가 버튼**: 생일·장기 미방문 등 지점 운영 규칙은 [설정 추가] 버튼으로 DLG-072-002를 열어 트리거 라이브러리에서 선택해 등록합니다.
- **전체 자동 알림 ON/OFF**: 해당 지점의 모든 자동 알림을 한 번에 활성화하거나 비활성화합니다. 센터장(owner)만 조작 가능하고 본사 정책 원본과 다른 지점에는 영향이 없습니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장(owner) | 소속 지점 전체 자동 알림 규칙 목록 | 정책/step ON/OFF, 회원 이용권 만료·락커 만료 지점 추가 step 생성·수정·삭제, 전체 ON/OFF, 상세 설정 편집 |
| 매니저 | 소속 지점 전체 자동 알림 규칙 목록 | 조회·상세 설정 편집. 정책/step ON/OFF, 지점 추가 step 생성·수정·삭제, 전체 ON/OFF 불가 |
| FC / 트레이너 / 스태프 | 접근 제한 | 자동 알림 설정 불가 |

## 주요 UX 흐름

1. 사이드바 "마케팅 > 메시지 발송 > 자동 알림 설정" 또는 메시지 발송 화면(SCR-071)의 자동 알림 섹션 "상세 설정" 버튼으로 진입합니다.
2. 본사에서 내려온 step과 지점 운영 이벤트 목록을 확인합니다. 본사 step 기준일은 읽기 전용으로 표시합니다.
3. 회원 이용권 만료 또는 락커 만료에 지점 고유 기준일이 필요하면 센터장(owner)이 [지점 step 추가]를 눌러 DLG-072-002에서 추가 step을 등록합니다.
4. 결제기한 만료 탭에서는 지점 step 추가를 제공하지 않고, 본사 step의 ON/OFF만 변경합니다. 미수/연체 알림 N일, 반복 주기, 발송 시각, 기본 채널은 본사 설정값을 읽기 전용으로 확인합니다.
5. 규칙 우측 "상세 설정"을 클릭해 알림 규칙 상세 설정 다이얼로그에서 메시지 내용, 발송 시각, 카카오톡 fallback 사용 여부, SMS 명시 발송 여부를 설정하고, 테스트 발송 전 플랫폼 상태를 확인합니다.
6. 센터장(owner)은 규칙별 토글 또는 전체 ON/OFF를 변경할 수 있습니다. 단, `본사 필수` 배지가 붙은 규칙은 owner도 OFF할 수 없고 "본사 필수 알림은 지점에서 끌 수 없습니다" 안내를 표시합니다. 매니저 이하가 토글을 클릭하면 권한 안내만 표시합니다.
7. 저장 후 조건이 충족되면 자동으로 메시지가 발송됩니다.
8. 특정 규칙을 중단하려면 센터장(owner)이 해당 토글을 끕니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 알림 활성 | 토글이 켜진 규칙은 활성 상태로 표시됩니다. |
| 알림 비활성 | 토글이 꺼진 규칙은 회색으로 표시됩니다. |
| 전체 비활성 | 전체 ON/OFF가 꺼지면 모든 규칙이 일시 중단됩니다. |
| 권한 잠금 | owner가 아닌 계정은 토글 disabled + "센터장만 변경 가능" 툴팁 표시 |
| 본사 필수 잠금 | `본사 필수` 규칙은 ON 고정 disabled + `본사 필수` 배지 + "본사 필수 알림은 지점에서 끌 수 없습니다" 툴팁 표시 |
