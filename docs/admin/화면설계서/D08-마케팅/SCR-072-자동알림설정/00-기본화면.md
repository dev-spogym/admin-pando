## 화면 목적

본사 정책 세트로 내려온 만료 step과, 생일·장기 미방문 같은 지점 운영 이벤트 알림을 관리하는 화면입니다. 만료 정책은 `회원 이용권 만료`, `결제기한 만료`, `락커 만료`로 분리되어 내려오며, 기준일(D-30/D-14/D-7/D-Day 등)은 본사 HQ-09에서 생성·배포됩니다. 지점은 배포받은 정책 또는 step의 ON/OFF를 제어하고, `회원 이용권 만료`와 `락커 만료` 정책에 한해 지점 추가 step을 만들 수 있습니다. ON/OFF 변경과 지점 추가 step 생성·수정·삭제는 각 지점 센터장(owner)만 가능합니다. 자동 알림은 회원앱 Push가 기본 채널이며, 회원앱 미설치 또는 Push 실패 시 KakaoTalk fallback을 사용할지는 지점 상세 설정에서 선택합니다.

## 주요 구성요소

- **만료 정책 탭**: 회원 이용권 만료 / 결제기한 만료 / 락커 만료를 별도 탭으로 표시합니다. 각 탭에는 본사 step과 지점 추가 step을 구분 배지로 표시합니다.
- **고객 관련 알림 목록**: 회원 이용권 만료 step(D-30/D-14/D-7 등 실제 기준일은 정책값 표시) / 생일 축하 / 장기 미방문 / 등록 감사 / 첫 방문 환영 등 고객 이벤트 기반 알림 규칙을 표시합니다.
- **상품 관련 알림 목록**: 홀딩 종료 / 결제 완료 / 환불 처리 / 미수금 발생 / 재등록 쿠폰 동봉 발송 등 상품 이벤트 기반 알림 규칙을 토글로 표시합니다. 결제기한 만료 알림은 별도 `결제기한 만료` 정책 탭에서 관리합니다.
- **락커 만료 알림 목록**: 락커 이용 종료일 기준 본사 step과 지점 추가 step을 표시합니다.
- **예약/출석 관련 알림 목록**: 예약 확정 / 예약 취소 / 대기열 승격 / 노쇼 발생 / 출석 N회 달성 / 첫 방문 완료 같은 운영 이벤트 규칙을 별도 섹션으로 노출합니다.
- **규칙별 토글 스위치**: 각 알림 규칙의 활성화/비활성화를 토글 스위치로 제어합니다. 토글 조작은 센터장(owner)만 가능하며 manager 이하 계정은 disabled 상태와 권한 안내 툴팁만 확인합니다.
- **플랫폼 상태 배지**: 규칙별로 승인 템플릿 존재 여부, 발신 프로필 연결 여부, 최근 테스트 발송 결과를 배지로 표시합니다.
- **상세 설정 버튼**: 각 규칙 우측의 "상세 설정" 버튼 클릭 시 DLG-072-001이 열려 지점이 조정 가능한 메시지·발송 시각·KakaoTalk fallback 사용 여부를 세부 설정합니다. 본사 소유 기준일 step은 읽기 전용으로 표시되며, 지점 추가 step은 센터장(owner)만 기준일을 수정할 수 있습니다.
- **지점 step 추가 버튼**: 회원 이용권 만료 / 락커 만료 탭에서만 노출됩니다. 클릭 시 DLG-072-002를 열어 지점 추가 만료 step을 등록합니다. 결제기한 만료 탭에서는 노출하지 않습니다.
- **규칙 추가 버튼**: 생일·장기 미방문 등 지점 운영 규칙은 [설정 추가] 버튼으로 DLG-072-002를 열어 트리거 라이브러리에서 선택해 등록합니다.
- **전체 자동 알림 ON/OFF**: 해당 지점의 모든 자동 알림을 한 번에 활성화하거나 비활성화합니다. 센터장(owner)만 조작 가능하고 본사 정책 원본과 다른 지점에는 영향이 없습니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장(owner) | 소속 지점 전체 자동 알림 규칙 목록 | 정책/step ON/OFF, 회원 이용권 만료·락커 만료 지점 추가 step 생성·수정·삭제, 전체 ON/OFF, 상세 설정 편집 |
| 매니저 | 소속 지점 전체 자동 알림 규칙 목록 | 조회·상세 설정 편집. 정책/step ON/OFF, 지점 추가 step 생성·수정·삭제, 전체 ON/OFF 불가 |
| FC / 트레이너 / 스태프 | 접근 제한 | 자동 알림 설정 불가 |

## 주요 UX 흐름

1. 사이드바 "마케팅 > 메시지 발송 > 자동 알림 설정" 또는 메시지 발송 화면(SCR-071)의 자동 알림 섹션 "상세 설정" 버튼으로 진입합니다.
2. 본사에서 내려온 step과 지점 운영 이벤트 목록을 확인합니다. 본사 step 기준일은 읽기 전용으로 표시합니다.
3. 회원 이용권 만료 또는 락커 만료에 지점 고유 기준일이 필요하면 센터장(owner)이 [지점 step 추가]를 눌러 DLG-072-002에서 추가 step을 등록합니다.
4. 결제기한 만료 탭에서는 지점 step 추가를 제공하지 않고, 본사 step의 ON/OFF만 변경합니다.
5. 규칙 우측 "상세 설정"을 클릭해 DLG-072-001에서 메시지 내용, 발송 시각, KakaoTalk fallback 사용 여부를 설정하고, 테스트 발송 전 플랫폼 상태를 확인합니다.
6. 센터장(owner)은 규칙별 토글 또는 전체 ON/OFF를 변경할 수 있습니다. 매니저 이하가 토글을 클릭하면 권한 안내만 표시합니다.
7. 저장 후 조건이 충족되면 자동으로 메시지가 발송됩니다.
8. 특정 규칙을 중단하려면 센터장(owner)이 해당 토글을 끕니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 알림 활성 | 토글이 켜진 규칙은 활성 상태로 표시됩니다. |
| 알림 비활성 | 토글이 꺼진 규칙은 회색으로 표시됩니다. |
| 전체 비활성 | 전체 ON/OFF가 꺼지면 모든 규칙이 일시 중단됩니다. |
| 권한 잠금 | owner가 아닌 계정은 토글 disabled + "센터장만 변경 가능" 툴팁 표시 |
