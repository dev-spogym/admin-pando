## 목적

자동 알림 설정(SCR-072)에 아직 등록되지 않은 운영 이벤트를 트리거 라이브러리에서 골라 새 규칙으로 추가하는 다이얼로그입니다.

## 구성요소

- **카테고리 그룹**: 고객 / 상품 / 예약 / 출석 / 결제 / CRM 카테고리로 트리거를 묶어 보여줍니다.
- **트리거 목록**: 예시로 생일, 장기 미방문, 이용권 만료 D-N, 예약 확정, 예약 취소, 노쇼 발생, 출석 N회 달성, 첫 방문, 미수금 발생, 재등록 대상 편입 등을 리스트로 표시합니다.
- **검색창**: 트리거명을 검색해 바로 찾습니다.
- **설명 패널**: 선택된 트리거의 발생 조건, 발송 시점 추천, 기본 변수, 기본 채널을 우측에 요약합니다.
- **추가 버튼**: 선택한 트리거를 지점 규칙 목록에 추가하고 DLG-072-001 편집 단계로 넘깁니다.
- **취소 버튼**: 추가 없이 닫습니다.

## 언제 표시되나요

- 자동 알림 설정 화면(SCR-072)에서 [설정 추가] 버튼을 클릭했을 때 표시됩니다.

## 주요 흐름

1. 관리자가 SCR-072에서 [설정 추가]를 클릭합니다.
2. 카테고리 또는 검색으로 원하는 트리거를 찾습니다.
3. 우측 설명 패널에서 조건과 기본 권장값을 확인합니다.
4. [추가]를 누르면 규칙 초안이 생성되고, 곧바로 DLG-072-001에서 세부 채널/메시지를 편집합니다.

## 비즈니스 규칙

- 본사 필수 정책과 중복되는 트리거는 추가할 수 없고 기존 정책으로 이동 안내를 표시합니다.
- 동일 지점에 동일 트리거가 이미 활성화되어 있으면 중복 경고를 노출합니다.
- 트리거 라이브러리는 운영자 권한 범위에 따라 일부 항목이 숨겨질 수 있습니다.
