## 화면 목적

자동 알림 설정(SCR-072)에 아직 등록되지 않은 운영 이벤트를 트리거 라이브러리에서 골라 새 규칙으로 추가하거나, 회원 이용권 만료·락커 만료 정책의 지점 추가 step을 등록하는 다이얼로그입니다.

## 주요 구성요소

- **카테고리 그룹**: 만료 정책 / 고객 / 상품 / 예약 / 출석 / 결제 / CRM 카테고리로 트리거를 묶어 보여줍니다.
- **만료 정책 추가 모드**: 회원 이용권 만료 또는 락커 만료 탭에서 진입한 경우, 지점 추가 step 등록 폼을 표시합니다. 결제기한 만료 탭에서는 이 모드로 진입할 수 없습니다.
- **트리거 목록**: 예시로 생일, 장기 미방문, 예약 확정, 예약 취소, 노쇼 발생, 출석 N회 달성, 첫 방문, 미수금 발생, 재등록 대상 편입 등을 리스트로 표시합니다. 본사 HQ-09에서 배포되는 날짜 step은 신규 트리거로 직접 추가하지 않고 본사 정책 항목으로 안내합니다.
- **지점 추가 step 입력**: 기준일 유형(만료 전/당일/후), 기준일 값, 발송 시각, 메시지 템플릿, KakaoTalk fallback 사용 여부를 입력합니다. 기준일은 해당 지점과 해당 정책 안에서만 적용됩니다.
- **검색창**: 트리거명을 검색해 바로 찾습니다.
- **설명 패널**: 선택된 트리거의 발생 조건, 발송 시점 추천, 기본 변수, 기본 채널을 우측에 요약합니다.
- **추가 버튼**: 선택한 트리거를 지점 규칙 목록에 추가하고 알림 규칙 상세 설정 단계로 넘깁니다.
- **취소 버튼**: 추가 없이 닫습니다.

## 언제 표시되나요

- 자동 알림 설정 화면(SCR-072)에서 [설정 추가] 또는 회원 이용권 만료·락커 만료 탭의 [지점 step 추가] 버튼을 클릭했을 때 표시됩니다.

## 주요 UX 흐름

1. 관리자가 SCR-072에서 [설정 추가]를 클릭합니다.
2. 카테고리 또는 검색으로 원하는 트리거를 찾습니다. 지점 step 추가 모드에서는 기준일과 발송 시각을 입력합니다.
3. 우측 설명 패널에서 조건과 기본 권장값을 확인합니다.
4. [추가]를 누르면 규칙 초안 또는 지점 추가 step이 생성되고, 곧바로 알림 규칙 상세 설정 다이얼로그에서 세부 채널/메시지를 편집합니다.

## 비즈니스 규칙

- 본사 HQ-09에서 배포되는 날짜 step 정책과 중복되는 일반 트리거는 추가할 수 없고 기존 본사 정책 항목으로 이동 안내를 표시합니다.
- 지점 추가 step은 회원 이용권 만료·락커 만료 정책에만 등록할 수 있습니다.
- 결제기한 만료 정책에는 지점 추가 step을 등록할 수 없습니다. 필요한 기준일 변경은 본사 HQ-09 정책 변경 요청으로 처리합니다.
- 지점 추가 step은 같은 지점·같은 정책 안에서 본사 step 또는 기존 지점 추가 step과 동일 기준일을 사용할 수 없습니다. D-Day도 한 정책 안에서 중복 등록할 수 없습니다.
- 지점 추가 step 생성·수정·삭제는 센터장(owner)만 가능하며 manager 이하는 조회만 가능합니다.
- 동일 지점에 동일 트리거가 이미 활성화되어 있으면 중복 경고를 노출합니다.
- 트리거 라이브러리는 운영자 권한 범위에 따라 일부 항목이 숨겨질 수 있습니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
