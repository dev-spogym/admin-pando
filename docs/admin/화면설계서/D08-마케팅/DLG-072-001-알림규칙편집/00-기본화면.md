## 화면 목적

자동 알림 설정(SCR-072)에서 특정 알림 규칙의 지점 적용 옵션, 발송 채널, 메시지 내용을 세부적으로 편집하는 다이얼로그입니다. 만료 정책은 회원 이용권 만료, 결제기한 만료, 락커 만료를 구분해 표시합니다.

## 주요 구성요소

- **규칙명**: 편집 중인 알림 규칙 이름을 상단에 표시합니다. (예: "회원 이용권 만료 본사 step D-20", "락커 만료 지점 추가 step D-2", "장기 미방문 알림")
- **정책 유형**: 회원 이용권 만료 / 결제기한 만료 / 락커 만료 / 지점 운영 이벤트 중 하나를 표시합니다.
- **step 소유 구분**: 본사 step / 지점 추가 step을 배지로 표시합니다.
- **발송 시점 설정**: 본사 소유 step이면 기준일을 읽기 전용으로 표시합니다. 지점 추가 step은 회원 이용권 만료·락커 만료 정책에서만 센터장(owner)이 기준일을 수정할 수 있습니다. 결제기한 만료 step은 지점 추가와 기준일 수정이 모두 불가합니다. 지점 자체 운영 이벤트 규칙이면 이벤트 기준 전·당일·후 숫자를 입력합니다.
- **발송 채널 설정**: 자동 알림은 회원앱 Push를 기본 채널로 사용합니다. 회원앱 미설치·Push 실패 시 KakaoTalk fallback을 사용할지 토글로 선택하며, SMS로 자동 전환하지 않습니다.
- **플랫폼 연동 정보**: 발신 프로필, 승인 템플릿 상태, 최근 테스트 발송 결과를 표시합니다.
- **발송 시각**: 자동 발송 시각을 시·분 단위로 설정합니다.
- **대상 조건 설정**: 정책 유형별 기준 대상을 표시합니다. 회원 이용권 만료는 회원 이용권 종료일, 결제기한 만료는 미수금·잔액·할부 납입기한, 락커 만료는 락커 이용 종료일을 기준으로 합니다.
- **메시지 내용**: 자동 발송할 메시지 내용을 입력합니다. 회원명·만료일·잔여횟수·담당FC 등 변수를 삽입할 수 있습니다.
- **테스트 발송 버튼**: 저장 전 본인 또는 지정 관리자 번호로 미리보기 발송을 수행합니다.
- **저장 버튼**: 설정을 저장하고 다이얼로그를 닫습니다.
- **취소 버튼**: 변경 내용을 저장하지 않고 닫습니다.

## 언제 표시되나요

- 자동 알림 설정 화면(SCR-072)에서 특정 알림 규칙의 "상세 설정" 버튼을 클릭할 때 표시됩니다.

## 주요 UX 흐름

1. 관리자가 SCR-072에서 편집할 알림 규칙의 "상세 설정" 버튼을 클릭합니다.
2. 이 다이얼로그가 열리며 현재 설정값이 표시됩니다.
3. 발송 시점(읽기 전용 또는 편집 가능), Push 기본 채널, KakaoTalk fallback 여부, 발송 시각, 메시지 내용을 규칙 유형에 맞게 수정하고 플랫폼 연동 상태를 확인합니다.
   - 본사 step 기준일은 모든 정책에서 읽기 전용입니다.
   - 지점 추가 step 기준일은 회원 이용권 만료·락커 만료 정책에서 센터장(owner)만 편집합니다.
   - 결제기한 만료 정책은 지점 추가 step과 기준일 편집을 제공하지 않습니다.
4. "저장"을 클릭하면 변경 내용이 반영되고 다이얼로그가 닫힙니다.
5. "취소"를 클릭하면 이전 설정이 유지됩니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. 정책/step ON/OFF와 회원 이용권 만료·락커 만료 지점 추가 step 편집이 가능합니다. |
| manager | 조회·상세 설정 편집은 가능하나 정책/step ON/OFF와 지점 추가 step 생성·수정·삭제는 불가합니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
