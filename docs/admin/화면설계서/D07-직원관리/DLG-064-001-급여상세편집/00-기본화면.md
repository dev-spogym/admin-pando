## 화면 목적

자동 계산된 급여 항목 중 수당, 공제 등 일부 항목을 관리자가 직접 조정해야 할 때 사용하는 편집 다이얼로그입니다. 기본급은 직원 정보에서 가져오고, 이 다이얼로그에서는 부가 항목만 수정합니다.

## 주요 구성요소

- **직원 정보 요약**: 직원명 / 역할 / 지급월 / 급여 형태 / 확정 상태를 read-only로 표시합니다.
- **자동 계산 요약**: 기본급 / 자동 수당 / 자동 공제 / 수수료 / 현재 실지급액을 read-only로 표시합니다.
- **수당 항목 목록**: 식대 / 교통비 / 특별 수당 / 성과 수당 / 기타 수당을 수동 항목으로 추가·수정·삭제합니다. 금액은 0 이상만 허용합니다.
- **공제 항목 목록**: 지각·결근 공제 / 4대 보험 안내 항목 / 선지급·가불 차감 / 기타 공제를 수동 항목으로 추가·수정·삭제합니다. 금액은 0 이상만 허용합니다.
- **변경 사유 입력**: 수당/공제 저장 시 필수 입력합니다.
- **실지급액 미리보기**: 기본급 + 수당 합계 - 공제 합계 + 수수료를 입력값 변경 즉시 다시 계산해 표시합니다.
- **저장 버튼**: 변경 내용을 저장하고 다이얼로그를 닫습니다.
- **취소 버튼**: 변경 내용을 저장하지 않고 다이얼로그를 닫습니다.

### 수당/공제 편집 항목

| 구분 | 항목 | 입력/동작 |
|---|---|---|
| 수당 | 식대 | 금액 입력, 0 이상 |
| 수당 | 교통비 | 금액 입력, 0 이상 |
| 수당 | 특별 수당 | 금액 입력, 0 이상 |
| 수당 | 성과 수당 | 금액 입력, 0 이상 |
| 수당 | 기타 수당 | 항목명과 금액 입력 |
| 공제 | 지각·결근 공제 | 금액 입력, 0 이상 |
| 공제 | 4대 보험 안내 항목 | 금액 입력 또는 외부 산정값 확인 |
| 공제 | 선지급·가불 차감 | 금액 입력, 0 이상 |
| 공제 | 기타 공제 | 항목명과 금액 입력 |

자동 생성된 기본급, 자동 수당, 자동 공제, 수수료 원본 항목은 다이얼로그에서 직접 덮어쓰지 않습니다. 자동 계산값 보정이 필요하면 수동 수당 또는 수동 공제 항목으로 추가합니다. 수당 감소는 음수 수당을 입력하지 않고 공제 항목의 `기타 공제` 또는 `수당 보정 차감`으로 처리합니다.

## 언제 표시되나요

- 급여 관리 화면(SCR-064)에서 특정 직원 행의 "편집" 버튼을 클릭할 때 표시됩니다.

## 주요 UX 흐름

1. 관리자가 SCR-064에서 편집할 직원의 "편집" 버튼을 클릭합니다.
2. 이 다이얼로그가 열리며 현재 수당·공제 항목과 금액이 표시됩니다.
3. 필요한 수당 또는 공제 항목을 추가·수정·삭제합니다.
4. 변경 사유를 입력합니다.
5. 하단 실지급액 미리보기를 확인합니다.
6. "저장"을 클릭하면 변경 내용이 반영되고 부모 화면의 수당 합계, 공제 합계, 실지급액이 갱신됩니다.
7. "취소"를 클릭하면 변경 내용이 무시되고 다이얼로그가 닫힙니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 자동 항목 read-only | 기본급, 자동 수당, 자동 공제, 수수료 원본 항목은 직접 편집할 수 없습니다. |
| 미리보기 갱신 | 수동 수당/공제 입력값 변경 즉시 실지급액을 다시 계산합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |

| 케이스 | 표시 | 후속 조치 |

| 확정 완료 급여 | "확정 취소 후 편집할 수 있습니다" | 저장 차단 |

| 수당 마이너스 입력 | "수당은 0 이상이어야 합니다" | 저장 비활성 |
| 공제 마이너스 입력 | "공제는 0 이상이어야 합니다" | 저장 비활성 |
| 항목명 누락 | "항목명을 입력해주세요" | 저장 비활성 |
| 공제 > 기본급+수당+수수료 | "실지급액이 음수가 됩니다" 경고 | 확인 시 저장 가능 |
| 수동 항목 삭제 | 삭제 확인 문구 표시 | 확인 시 삭제, 사유 기록 |
