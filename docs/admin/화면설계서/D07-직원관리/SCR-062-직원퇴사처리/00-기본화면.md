## 화면 목적

퇴사 예정인 직원의 퇴사일을 설정하고, 해당 직원이 담당하던 미완료 업무·회원·수업을 인수인계한 뒤 시스템 계정을 비활성화하는 화면입니다. 본 시스템은 `직원 1명 = 로그인 계정 1개` 정책을 따르므로 퇴사 처리가 완료되면 해당 직원의 로그인 계정도 함께 잠금 또는 비활성화되며, 활성 세션은 즉시 만료됩니다.

## 주요 구성요소

- **퇴사 대상 직원 정보**: 퇴사 처리할 직원의 이름·역할·입사일을 요약해 표시합니다.
- **1단계 퇴사일 설정**: 실제 퇴사 확정일과 예정일을 입력하고 즉시 퇴사 여부를 결정합니다.
- **퇴사 사유 입력**: 자발 / 권고 / 계약 만료 / 기타 중 선택하고 내부 메모를 남깁니다.
- **2단계 미완료 업무 인수인계**: 해당 직원이 담당하던 회원, 예약된 수업, 진행 중인 계약 등을 인계받을 담당자를 지정합니다.
- **3단계 스케줄 정리 미리보기**: 퇴사일 이후 일정 이동/삭제 결과를 확인합니다.
- **4단계 계정 비활성화 확인**: 퇴사 처리 완료 시 시스템 로그인 계정 잠금/비활성화, 활성 세션 만료, 재로그인 차단 정책을 안내합니다.
- **처리 완료 / 취소 버튼**: 최종 확인 후 퇴사 처리를 완료하거나 취소합니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 본사 슈퍼관리자 / 최고관리자 | 전 지점 퇴사 처리 폼 | 통합 모드 처리, 계정 비활성화, 인계 범위 검토 |
| 센터장 / 매니저 | 소속 지점 퇴사 처리 전체 폼 | 퇴사일 설정, 인수인계 지정, 계정 비활성화 |
| 기타 직원 | 접근 불가 | 퇴사 처리 화면 진입 불가 |

## 주요 UX 흐름

1. 직원 목록(SCR-060)에서 대상 직원을 체크박스로 선택한 뒤 "퇴사 처리" 버튼을 클릭합니다.
2. 1단계에서 퇴사 확정일 / 예정일 / 퇴사 사유를 입력합니다.
3. 2단계에서 회원·수업·계약 인수인계가 필요한 경우 인계자를 지정합니다.
4. 3단계에서 퇴사일 이후 스케줄 이동/삭제 미리보기를 확인합니다.
5. 4단계에서 계정 비활성화, 세션 만료, 재로그인 차단 안내를 확인하고 "처리 완료" 버튼을 클릭합니다.
6. 최종 확인 다이얼로그(DLG-060-002)가 표시되며, `퇴사처리` 문구가 일치할 때만 최종 실행됩니다.
7. 당일 또는 과거 날짜 퇴사 처리라면 계정이 즉시 비활성화되고 활성 세션이 만료됩니다.
8. 미래 퇴사일이라면 예정 상태로 등록되며 확정일 도래 시 자동 비활성화됩니다.
9. 처리 완료 후 직원 목록(SCR-060)으로 돌아가며 해당 직원은 "퇴사" 상태로 표시됩니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 1단계 정상 | 퇴사 대상 직원 정보와 퇴사 정보 입력 폼이 표시됩니다. |
| 2단계 인수인계 필요 | 인계 대상 목록과 인계자 선택 영역이 표시됩니다. |
| 2단계 인수인계 없음 | 인수인계 섹션이 "담당 업무 없음"으로 표시되고 다음 단계로 이동합니다. |
| 3단계 스케줄 정리 | 자동 이동/삭제 미리보기가 표시됩니다. |
| 4단계 보안 확인 | 계정 비활성화 / 세션 만료 안내가 표시됩니다. |
| 처리 중 | 처리 완료 버튼이 로딩 상태로 변경됩니다. |
| 즉시 퇴사 | 계정 즉시 차단 안내 배너가 표시됩니다. |
| 예약 퇴사 | 확정일 도래 시 자동 처리 안내가 표시됩니다. |
| 처리 완료 | 성공 알림 후 직원 목록으로 이동합니다. |
