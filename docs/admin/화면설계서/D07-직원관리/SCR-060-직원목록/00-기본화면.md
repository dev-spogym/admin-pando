## 화면 목적

센터에 소속된 모든 직원의 현황을 한눈에 파악하고, 직무·재직 상태별로 빠르게 찾을 수 있는 직원관리 도메인의 핵심 허브 화면입니다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우에는 전 지점 직원이 합산 조회되며 각 직원의 소속 지점이 함께 표시됩니다. 센터장은 소속 지점 인력 현황을 조회하고 신규 직원을 등록하며, 매니저는 특정 직원에게 메시지를 전송하거나 권한 범위 내 상태 변경을 진행합니다. 퇴사 처리 실행·확정은 `센터장(owner)+`만 가능하며 매니저 이하는 [퇴사 처리] 버튼과 퇴사 처리 화면 직접 접근을 제공하지 않습니다. 이 화면에서 다루는 값은 직원의 `직무`이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 관리합니다.

## 주요 구성요소

- **요약 지표 카드 (4개)**: 전체 직원 수 / 재직 중 인원 / 휴직 중 인원 / 퇴사 인원을 한눈에 표시합니다. 카드 클릭 시 해당 상태로 자동 필터링됩니다.
- **검색 바**: 직원 이름 또는 연락처로 통합 검색합니다.
- **직무 필터**: 센터장 / 매니저 / FC / PT트레이너 / GX강사 / 골프강사 / 스태프 중 선택해 해당 직무 직원만 표시합니다.
- **소속 지점 필터**: 본사 통합 모드에서만 표시되며, 전 지점 직원 목록 중 특정 지점 직원만 좁혀 봅니다.
- **재직 상태 필터**: 재직 / 휴직 / 퇴사 중 선택해 필터링합니다.
- **일괄 작업 버튼 바**: 직원을 1명 이상 체크박스 선택하면 메시지 전송 / 상태 변경 / 명단 다운로드 버튼이 활성화됩니다. [퇴사 처리]는 `센터장(owner)+`에게만 노출됩니다.
- **직원 목록 테이블**: 번호 / 직원명 / 소속 지점 / 직무 배지 / 연락처 / 입사일 / 재직 상태 배지 / 메모 / 더보기 9개 컬럼으로 구성됩니다.
- **페이지네이션**: 한 페이지에 10건씩 표시하며 페이지 번호로 이동합니다.
- **직원 등록 버튼**: 신규 직원 등록용 빈 폼을 열어 직원명, 연락처, 직무, 소속 지점, 로그인 계정, 권한 템플릿, 급여 기본 정보를 입력할 수 있게 합니다.

### 요약 지표 카드 4종

| 카드명 | 집계 기준 | 클릭 동작 |
|---|---|---|
| 전체 직원 수 | 권한 범위 내 재직·휴직·퇴사 직원을 모두 합산 | 재직 상태 필터를 전체로 전환하고 퇴사 직원까지 포함해 표시 |
| 재직 중 인원 | 재직 상태가 `재직`인 직원 수 | 재직 상태 필터를 재직으로 적용 |
| 휴직 중 인원 | 재직 상태가 `휴직`인 직원 수 | 재직 상태 필터를 휴직으로 적용 |
| 퇴사 인원 | 재직 상태가 `퇴사`인 직원 수 | 재직 상태 필터를 퇴사로 적용 |

본사 통합 모드에서는 전 지점 합산으로 표시하고, 지점 필터가 선택된 경우 선택 지점 기준으로 다시 집계합니다. 센터장과 매니저는 본인 소속 지점 기준으로만 표시합니다.

### 직원 목록 테이블 9개 컬럼

| 컬럼 | 표시 내용 | 동작 |
|---|---|---|
| 번호 | 현재 페이지 내 순번 | 없음 |
| 직원명 | 직원 이름, 필요 시 프로필 썸네일 | 클릭 시 선택 직원의 상세 패널/화면 열기 |
| 소속 지점 | 직원의 실제 소속 지점명 | 단일 지점 모드에서는 현재 지점명을 표시하고, 본사 통합 모드에서는 직원별 실제 지점명을 표시해 지점 필터·정렬 기준으로 사용 |
| 직무 배지 | Owner(지점장) / 매니저 / FC / PT트레이너 / GX강사 / 골프강사 / 스태프 | 직무별 색상 배지 표시 |
| 연락처 | 휴대폰 번호 `010-0000-0000` 형식 | 클릭 시 복사 또는 메시지 발송 진입은 더보기 메뉴 사용 |
| 입사일 | `YYYY-MM-DD` | 정렬 가능 |
| 재직 상태 배지 | 재직 / 휴직 / 퇴사 | 상태별 색상 배지 표시 |
| 메모 | 인사 메모 30자 미리보기 | manager+만 표시, 클릭 시 직원 상세의 인사 메모 영역 확인 |
| 더보기 | 행 단위 액션 메뉴 버튼 | 직원 정보 수정 / 메시지 전송 / 재직·휴직 상태 변경 / 퇴사 처리 |

### 직원명 클릭 동작

직원명을 클릭하면 선택 직원의 상세 패널/화면을 열어 기본 정보, 담당 회원, 담당 스케줄, 실적 요약, 근태 요약, 인사 메모, 계정 상태를 확인합니다. PC에서는 목록 우측 패널 또는 상세 화면으로 표시하고, 모바일에서는 전체 화면 상세로 표시합니다. 상세를 닫으면 직원 목록의 검색어, 필터, 페이지 상태를 유지합니다.

### 더보기 메뉴

| 메뉴 | 기능 | 권한 | 결과 |
|---|---|---|---|
| 직원 정보 수정 | 선택 직원의 기존 정보가 채워진 직원 등록/수정 화면을 엽니다 | manager+ | 기본 정보, 직무, 연락처, 계정 상태, 급여 정보 수정 |
| 메시지 전송 | 선택 직원을 수신자로 지정한 메시지 작성 화면을 엽니다 | manager+ | 직원 1명 대상 공지/알림 작성 |
| 상태 변경 | 선택 직원의 재직 상태를 재직 또는 휴직으로 변경합니다 | manager+ | 재직↔휴직만 가능, 퇴사는 퇴사 처리 사용 |
| 퇴사 처리 | 선택 직원을 퇴사 처리 대상으로 넘기고 확인 다이얼로그 후 퇴사 처리 화면을 엽니다 | owner+ | 퇴사일, 인수인계, 계정 비활성화 절차 진행 |

### 모바일 표시

모바일에서는 9개 컬럼 테이블을 직원 카드 목록으로 전환합니다. 카드에는 직원명, 직무 배지, 재직 상태, 소속 지점, 연락처를 우선 표시하고, 메모와 더보기 메뉴는 카드 하단에 배치합니다. 카드를 누르면 직원 상세가 전체 화면으로 열리며, 닫기/뒤로 버튼으로 목록에 복귀합니다.

### 본사 통합 모드의 소속 지점 표시

본사 통합 모드는 본사 권한자가 여러 지점 직원을 한 목록에서 볼 때 사용하는 조회 방식입니다. 이 모드에서 `소속 지점` 컬럼은 각 직원이 실제로 소속된 지점명을 행마다 표시합니다. 예를 들어 강남점 직원은 `강남점`, 분당점 직원은 `분당점`으로 표시됩니다.

단일 지점 모드에서는 모든 직원이 현재 지점 소속이므로 `소속 지점` 컬럼에는 현재 지점명이 표시됩니다. 본사 통합 모드에서는 지점 필터가 함께 노출되며, 필터에서 특정 지점을 선택하면 해당 지점 소속 직원만 목록에 남고 요약 카드도 선택 지점 기준으로 다시 집계됩니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 본사 최고관리자 / 슈퍼관리자 | `전체 지점(통합)` 선택 시 전 지점 직원 목록과 지점별 소속 | 지점 전환, 전체 직원 검색·필터, 명단 다운로드, 권한 범위 내 직원 관리 |
| 센터장 | 소속 센터 전체 직원 목록 | 직원 등록, 상태 변경, 퇴사 처리, 메시지 전송, 명단 다운로드. 퇴사 취소·정산 미완료 강제 확정·급여 확정도 센터장만 가능 |
| 매니저 | 소속 센터 전체 직원 목록 | 직원 등록, 상태 변경, 메시지 전송, 명단 다운로드. 퇴사 처리·퇴사 취소·정산 미완료 강제 확정·급여 확정은 불가 |
| FC / 트레이너 / 스태프 | 자신의 정보만 조회 가능 (동료 목록 열람 불가) | 본인 정보 조회만 가능 |
| 직원 본인 | 본인 프로필 및 급여 명세서 | 본인 정보 조회 |

## 주요 UX 흐름

1. 사이드바에서 "직원 관리"를 클릭해 직원 목록 화면으로 진입합니다.
2. 요약 카드로 전체 인원 현황을 파악하고, 검색 또는 필터를 조합해 원하는 직원을 찾습니다.
3. 직원명을 클릭하면 해당 직원의 상세 패널/화면을 열어 기본 정보, 담당 회원, 담당 스케줄, 실적, 근태, 인사 메모를 확인합니다.
4. 체크박스로 직원을 선택하면 일괄 작업 버튼이 활성화되어 메시지 전송 또는 상태 변경을 진행합니다. 센터장(owner)+는 추가로 퇴사 처리를 진행할 수 있습니다.
5. 우측 상단 "직원 등록" 버튼으로 신규 직원 등록용 빈 폼을 열고 직원명, 연락처, 직무, 소속 지점, 로그인 계정, 권한 템플릿, 급여 기본 정보를 입력합니다.
6. 센터장(owner)+가 퇴사 처리 버튼을 클릭하면 퇴사 처리 확인 다이얼로그가 표시됩니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 데이터를 불러오는 동안 테이블 자리에 로딩 표시를 보여줍니다. |
| 정상 목록 | 직원이 1명 이상 존재할 때 테이블과 페이지네이션을 표시합니다. |
| 검색 결과 없음 | 검색·필터 적용 후 결과가 0건이면 "직원 데이터가 없습니다." 안내를 표시합니다. |
| 전체 직원 없음 | 필터 없이 0건이면 직원 등록 안내 메시지를 함께 표시합니다. |
| 오류 | 데이터 로드 실패 시 오류 메시지와 다시 시도 안내를 표시합니다. |

## 직원 상세 패널 (SCR-060 상세)

직원 목록에서 직원명 클릭 시 표시되는 상세 패널/화면입니다. PC에서는 목록 옆 패널 또는 상세 화면으로 열리고, 모바일에서는 전체 화면 상세로 열립니다. 계정 상태 영역은 로그인 ID, 권한 템플릿, 계정 상태, 마지막 로그인 시각, 비밀번호 변경 필요 여부까지만 표시하며, 활성 세션 수·접속 기기 목록·세션별 강제 로그아웃 기능은 제공하지 않습니다.

### 구성요소
- **담당 회원 목록**: 해당 직원이 담당 FC 또는 트레이너로 지정된 회원 목록 (이름, 연락처, 이용권 상태, 마지막 출석일). 회원명 또는 회원 카드를 클릭하면 선택 회원의 상세 화면을 열어 기본 정보, 이용권 상태, 결제·출석 이력, 상담/메모를 확인하고 뒤로가기 시 직원 상세 패널로 복귀
- **담당 스케줄**: 이번 주·다음 주 수업 캘린더 데이터를 직원 단위로 필터링해 카드 또는 리스트로 표시
- **실적 요약 카드**: 이번 달 수업 진행 건수, 신규 매출, 재등록 매출, OT 1·2 완료 수, NPS 평균 점수
- **근태 요약 카드**: 이번 달 출근일, 결근, 지각 횟수 (직원 근태 관리 데이터 기준)
- **인사 메모**: 매니저·센터장만 볼 수 있는 비공개 메모 입력·조회 영역
- **헤더 액션**: 선택 직원의 기본 정보 수정, 퇴사 처리 흐름 시작, 메시지 작성 화면 열기 버튼

### 권한 분기
- 센터장 / 매니저: 모든 직원 상세 + 인사 메모 작성·조회
- 직원 본인: 본인 상세 + 본인 실적·근태만 조회 (인사 메모는 비공개)
- FC / 트레이너 / 스태프: 동료 직원 상세 접근 차단
