## 화면 목적

신규 직원을 시스템에 등록하거나 기존 직원의 정보를 수정하는 화면입니다. 이름·연락처·직무 등 기본 정보와 함께 소속 센터, 로그인 계정, 권한 템플릿 연결 상태, 급여 정보까지 한 화면에서 설정합니다. 등록된 직원은 직원 목록(SCR-060)에 즉시 반영되며, 직원 1명당 로그인 계정 1개를 기본 원칙으로 합니다. 여기서 입력하는 `직무`는 인사/운영 분류값이며, 실제 관리자웹 메뉴 접근 권한은 `SCR-081 권한 설정`에서 별도로 매핑합니다.

## 주요 구성요소

- **기본 정보 섹션**: 직원명(필수) / 직군(관리직·트레이너·FC·안내데스크·GX강사·골프 등) / 직무 / 직급 / 팀 / 입사일 / 연락처 / 성별을 입력합니다.
- **담당 서비스 섹션**: 해당 직원이 담당할 서비스 항목(예: PT, 필라테스, GX, 골프 등)을 선택합니다.
- **급여 정보 섹션**: 급여 형태(월급제·시급제·건별·혼합)와 기본급을 입력합니다. 필요 시 급여 정책 템플릿(PAY-STF-02)과 연결합니다.
- **로그인 계정 섹션**: 로그인 ID, 이메일, 임시 비밀번호(신규 시), 계정 상태(활성/잠금), 첫 로그인 후 비밀번호 변경 강제 여부를 설정합니다. 저장 시 직원 계정과 관리자웹 로그인 계정이 함께 생성/수정됩니다.
- **권한/보안 요약 섹션**: 역할별 권한 템플릿 요약, 로그인 차단 여부, 지점 접근 범위를 요약 표시합니다.
- **캘린더 색상 선택**: 수업 캘린더에 표시될 직원 고유 색상을 지정합니다.
- **저장 / 취소 버튼**: 저장 시 유효성 검사 후 목록으로 돌아갑니다. 취소 클릭 시 DLG-061-001이 표시됩니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 / 매니저 | 전체 입력 폼 | 직원 등록 및 수정, 로그인 계정 발급/잠금 |
| FC / 트레이너 / 스태프 / 프런트 | 본인 정보 조회만 | 본인 정보 수정 불가 (관리자 권한 필요) |

## 주요 UX 흐름

1. 직원 목록(SCR-060)에서 "직원 등록" 버튼을 클릭해 빈 폼으로 진입합니다. (신규 등록)
2. 또는 목록 테이블의 직원명 클릭 후 수정 버튼을 눌러 기존 데이터가 채워진 폼으로 진입합니다. (수정)
3. 필수 항목(이름, 로그인 ID, 이메일, 직군/직무, 소속 센터)을 입력하고 임시 비밀번호 및 계정 상태를 설정합니다.
4. "저장" 버튼을 클릭하면 유효성 검사 후 직원 정보와 로그인 계정이 함께 저장됩니다.
5. 저장 성공 시 직원 목록(SCR-060)으로 돌아갑니다.
6. 입력 중 "취소"를 클릭하면 이탈 확인 다이얼로그(DLG-061-001)가 표시됩니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 신규 등록 | 모든 필드가 빈 상태로 표시됩니다. |
| 수정 | 기존 직원 정보가 각 필드에 채워진 상태로 표시됩니다. |
| 저장 중 | 저장 버튼이 로딩 상태로 변경되며 중복 클릭이 방지됩니다. |
| 유효성 오류 | 필수 항목 미입력 시 해당 필드 하단에 오류 메시지가 표시됩니다. |
| 계정 잠금 | 로그인 가능 상태가 차단되고, 직원은 재직 상태를 유지한 채 관리자 승인을 기다립니다. |
| 저장 완료 | 성공 알림 후 직원 목록(SCR-060)으로 이동합니다. |

## 관련 다이어그램

- SCR-060 직원 목록으로 복귀
- DLG-061-001 등록/수정 취소 확인
