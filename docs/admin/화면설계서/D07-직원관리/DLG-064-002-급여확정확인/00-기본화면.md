## 화면 목적

급여를 최종 확정하기 전 관리자의 의도를 재확인합니다. 확정된 급여는 직원에게 발송 가능한 급여 명세서로 전환되므로, 실수를 방지하기 위해 확인 절차를 거칩니다.

## 주요 구성요소

- **제목**: "급여를 확정하시겠습니까?"
- **안내 메시지**: "확정된 급여는 급여 명세서로 생성되며, 직원에게 발송할 수 있습니다. {인원수}명의 급여를 확정하시겠습니까?"
- **확정 대상 요약**: 확정할 직원 수와 총 지급 예정 금액을 요약해 표시합니다.
- **확정 버튼**: 급여를 최종 확정합니다.
- **취소 버튼**: 다이얼로그를 닫고 아무 처리도 하지 않습니다.

## 언제 표시되나요

- 급여 관리 화면(SCR-064)에서 개별 직원의 "급여 확정" 버튼 또는 전체 일괄 "급여 확정" 버튼을 클릭할 때 표시됩니다.

## 주요 UX 흐름

1. 관리자가 SCR-064에서 급여 항목을 검토한 뒤 "급여 확정" 버튼을 클릭합니다.
2. 이 다이얼로그가 표시되며 확정 대상 인원과 총 금액을 보여줍니다.
3. "확정"을 클릭하면 급여가 확정되고 급여 명세서(SCR-065)에서 조회 가능해집니다.
4. "취소"를 클릭하면 다이얼로그가 닫히고 미확정 상태가 유지됩니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
