## 화면 목적

직원 등록 또는 수정 중에 취소 버튼을 눌렀을 때, 입력한 내용이 저장되지 않고 사라진다는 사실을 사용자에게 미리 알려 실수로 인한 데이터 손실을 방지합니다.

## 주요 구성요소

- **제목**: "작성 중인 내용이 있습니다"
- **안내 메시지**: "취소하면 입력한 내용이 저장되지 않습니다. 정말 취소하시겠습니까?"
- **계속 작성 버튼**: 다이얼로그를 닫고 폼으로 돌아갑니다.
- **취소 확인 버튼**: 폼을 닫고 직원 목록(SCR-060)으로 이동합니다.

## 언제 표시되나요

- 직원 목록(SCR-060) 화면에서 직원 등록 또는 수정 폼이 열려 있는 상태에서 "취소" 버튼을 클릭할 때 표시됩니다.
- 폼에 아무것도 입력하지 않은 상태에서 취소하면 이 다이얼로그 없이 바로 닫힐 수 있습니다.

## 주요 UX 흐름

1. 사용자가 직원 등록 또는 수정 폼에서 일부 내용을 입력합니다.
2. "취소" 버튼을 클릭하면 이 다이얼로그가 표시됩니다.
3. "계속 작성"을 선택하면 다이얼로그가 닫히고 폼이 그대로 유지됩니다.
4. "취소 확인"을 선택하면 폼이 닫히고 직원 목록 화면으로 돌아갑니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
