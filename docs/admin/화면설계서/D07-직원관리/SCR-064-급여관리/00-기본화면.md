## 화면 목적

직원별 당월 급여를 계산하고 수당·공제 내역을 검토한 뒤 최종 급여를 확정하는 화면입니다. 근태 데이터와 연동되어 기본급에 각종 수당이 자동 반영되며, 관리자가 항목을 수동으로 편집한 후 일괄 확정할 수 있습니다. 또한 우측 정책 영역에서 직급별 급여 정책 템플릿을 관리해 정산 계산식의 기준값을 유지합니다.

## 주요 구성요소

- **지급 월 선택**: 급여를 처리할 대상 월을 선택합니다. 기본값은 시스템 날짜 기준 당월이며, 미래 월은 선택할 수 없습니다. 전월 이전 월은 선택 가능하지만 read-only 마감 월로 표시합니다.
- **요약 지표 카드**: 전체 지급 예정 금액 / 확정 완료 인원 / 미확정 인원 / 이전 월 대비 증감을 표시합니다.
- **직원별 급여 테이블**: 직원명 / 역할 / 급여 형태 / 기본급 / 수당 합계 / 공제 합계 / 수수료 / 실지급액 / 확정 상태 / 액션 10개 컬럼으로 구성됩니다.
- **급여 정책 템플릿 패널**: 화면 우측 또는 하단 보조 패널에서 직급별 정책 목록을 조회합니다. `매출 타입` / `수업 타입` 탭으로 정책 분류를 전환합니다.
- **직군별 산식 탭**: `FC / PT / GX / 공통` 탭을 제공하며, 각 직군의 정률제 / 고정급제 / 시급제 / 혼합제 산식을 따로 조회합니다.
- **정책 액션 버튼**: 정책 추가 / 정책 삭제 / 정책 수정 버튼을 제공하며, 정책 편집은 DLG-064-003에서 수행합니다.
- **정책 요약 필드**: 선택된 정책의 직급, 직군, 지급 방식, 기본급, 수업단가, 수업료(%), 매출커미션(%), 재등록 커미션(%), 환불 차감 규칙, 적용 센터/팀 범위를 요약 표시합니다.
- **수당·공제 편집**: 각 직원 행의 편집 버튼 클릭 시 DLG-064-001이 열려 항목별 금액을 수동으로 조정합니다.
- **급여 확정 버튼**: 개별 또는 전체 직원의 급여를 확정합니다. 확정 전 DLG-064-002 확인 다이얼로그가 표시됩니다.
- **확정 취소**: 이미 확정된 급여도 당월 내에는 확정 취소 후 재편집할 수 있습니다.
- **엑셀 내보내기**: 선택한 지급월의 급여 내역 전체를 엑셀 파일로 내려받습니다. 전월 이전 마감 월도 조회 권한이 있으면 다운로드할 수 있습니다.

### 지급 월 선택 및 전월 이전 잠금

| 항목 | 기준 |
|---|---|
| 편집 가능 월 | 시스템 날짜 기준 현재 월 |
| 잠금 대상 | 현재 월보다 이전 지급월 전체 |
| 잠금 시점 | 매월 1일 00:00(KST)에 직전 월 급여를 read-only 마감 월로 전환 |
| 월 선택 표시 | 전월 이전 월은 드롭다운에서 선택 가능하되 잠금 아이콘과 `마감` 배지 표시 |
| 자동 계산 | 당월 선택 시 근태/수당/공제 기준 자동 계산. 전월 이전 선택 시 저장된 급여 결과만 조회하고 자동 재계산하지 않음 |
| 비활성 액션 | [편집], [항목 추가/삭제], [개별 확정], [일괄 확정], [확정 취소], [자동 재계산], 급여 정책 재적용 |
| 허용 액션 | 월 선택, 필터/정렬, 직원별 상세 조회, 급여 명세서 조회, 엑셀 내보내기 |
| 차단 안내 | 비활성 버튼 hover 또는 직접 진입 시 "마감된 급여월은 조회만 가능합니다" 표시 |

### 요약 지표 카드 4종

| 카드 | 표시 기준 | 클릭/동작 |
|---|---|---|
| 전체 지급 예정 금액 | 선택 지급월의 직원별 `실지급액` 합계입니다. 확정/미확정 행을 모두 포함하며, 전월 이전 마감 월은 저장된 결과값 기준으로 표시합니다. | 직원별 급여 테이블의 금액 컬럼을 실지급액 내림차순으로 정렬합니다. |
| 확정 완료 인원 | 선택 지급월에서 확정 상태인 직원 수입니다. | 직원별 급여 테이블에 `확정` 상태 필터를 적용합니다. |
| 미확정 인원 | 선택 지급월에서 아직 확정되지 않은 직원 수입니다. | 직원별 급여 테이블에 `미확정` 상태 필터를 적용합니다. |
| 이전 월 대비 증감 | `(선택 월 전체 지급 예정 금액 - 직전 월 전체 지급액) / 직전 월 전체 지급액 × 100`을 `%`로 표시합니다. 직전 월 데이터가 없으면 `-`로 표시합니다. | 직원별 전월 대비 증감액/증감률 보조 컬럼을 표시하고 증감률 절대값 내림차순으로 정렬합니다. |

이전 월 대비 증감이 ±50% 이상이면 해당 카드에 경고 색상을 적용하고 "급여 증감 확인 필요" 안내를 표시합니다.

### 직원별 급여 테이블 10개 컬럼

| 컬럼 | 표시 내용 | 동작/규칙 |
|---|---|---|
| 직원명 | 급여 산정 대상 직원 이름 | 클릭 시 해당 직원 상세 정보 확인 |
| 역할 | 직원 직무 배지. 예: owner, manager, fc, trainer, staff | 직무별 산식/정책 확인 기준 |
| 급여 형태 | 고정급제 / 시급제 / 정률제 / 혼합제 배지 | 직원 등록/수정의 급여 정보 기준값을 표시 |
| 기본급 | 해당 월 기본급 또는 근태 시간 기반 기본 산출액 | 급여 형태와 근태 데이터에 따라 자동 계산 |
| 수당 합계 | 식대, 교통비, 특별 수당, 성과 수당 등 수당 항목 합계 | 근태/실적 연동값과 수동 편집값을 합산 |
| 공제 합계 | 4대 보험 안내 항목, 지각·결근 공제, 기타 공제 합계 | 자동 공제와 수동 공제를 합산 |
| 수수료 | 수업 건수 × 단가, 매출 커미션, 재등록 커미션 등 성과성 지급액 | 트레이너/FC/GX 등 직무별 산식 적용 |
| 실지급액 | 기본급 + 수당 합계 - 공제 합계 + 수수료 | 요약 카드의 전체 지급 예정 금액 합산 기준 |
| 확정 상태 | 미확정 / 확정 배지 | 확정 상태 필터와 요약 카드 카운트 기준 |
| 액션 | [편집] / [확정] / [확정 취소] 버튼 | 권한, 당월 여부, 확정 상태에 따라 노출 또는 비활성 |

### 수당·공제 편집 기준

직원별 급여 테이블의 [편집] 버튼은 당월 미확정 급여에서만 활성화됩니다. 클릭하면 DLG-064-001이 열리며, 자동 계산 결과를 다시 실행하는 것이 아니라 수동 수당/수동 공제 항목을 추가·수정·삭제합니다.

| 구분 | 기준 |
|---|---|
| 진입 가능 | 당월 지급월 + 미확정 급여 + Owner(지점장)/manager |
| 진입 차단 | 전월 이전 마감 월, 확정 완료 급여, 권한 없음 |
| 수당 항목 | 식대 / 교통비 / 특별 수당 / 성과 수당 / 기타 수당 |
| 공제 항목 | 지각·결근 공제 / 4대 보험 안내 항목 / 선지급·가불 차감 / 기타 공제 |
| 자동 항목 처리 | 기본급, 자동 수당, 자동 공제, 수수료 원본 항목은 read-only로 표시 |
| 수동 보정 | 자동 계산값 보정은 수동 수당 또는 수동 공제 항목으로 추가 |
| 저장 조건 | 항목명, 금액, 변경 사유 필수 |
| 저장 결과 | 수당 합계, 공제 합계, 실지급액 갱신. 급여 상태는 미확정 유지 |

| CRM 상태 | 기존 명세서 상태를 `무효`로 변경하고 SCR-065 목록에 `무효` 배지 표시 |

| 기존 링크 접근 | CRM/앱 링크 접근 시 "무효 처리된 명세서입니다. 재확정 후 새 명세서를 확인해주세요" 안내 표시, 상세 금액 조회 차단 |

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 센터장 | 소속 센터 전체 직원 급여 | 수당·공제 편집, 급여 확정, 확정 취소, 엑셀 내보내기 |
| 매니저 | 소속 센터 전체 직원 급여 | 수당·공제 편집 (확정 권한은 센터장만) |
| 직원 본인 | 본인 급여 정보만 | 조회만 가능 |
| FC / 트레이너 / 스태프 | 접근 불가 | 급여 관리 화면 진입 불가 |

## 주요 UX 흐름

1. 사이드바 "직원 관리 > 급여 관리"로 진입합니다.
2. 지급 월을 선택하면 해당 월 직원별 급여 데이터가 로드됩니다.
3. 근태 데이터 기반으로 기본급과 수당이 자동 계산되어 표시됩니다.
4. 정책 기준이 바뀐 경우 우측 정책 패널에서 정책을 추가/수정해 계산 기준을 먼저 정비합니다.
5. FC/PT/GX별 산식 탭에서 기준 룰을 먼저 확인한 뒤, 수정이 필요한 직원의 편집 버튼을 클릭해 수당·공제 항목을 조정합니다(DLG-064-001).
6. 검토 완료 후 "급여 확정" 버튼을 클릭하면 확정 확인 다이얼로그(DLG-064-002)가 표시됩니다.
7. 확정 후 해당 직원은 급여 명세서(SCR-065)에서 내역을 조회할 수 있습니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 급여 데이터를 계산하는 동안 로딩 표시가 나타납니다. |
| 미확정 상태 | 급여 항목이 표시되고 편집·확정 버튼이 활성화됩니다. |
| 확정 완료 | 해당 행이 "확정" 배지로 표시되며 편집 버튼이 비활성화됩니다. |
| 전월 이전 잠금 | 전월 이전 월 선택 시 화면 상단에 `마감된 급여월` 배너를 표시하고 편집·확정·확정취소·자동 재계산 버튼을 비활성화합니다. |
| 데이터 없음 | 해당 월에 재직 중인 직원이 없을 때 안내 메시지가 표시됩니다. |
| 확정 처리 중 | 확정 버튼이 로딩 상태로 변경되며 중복 클릭이 방지됩니다. |
| 정책 편집 중 | 급여 정책 템플릿 패널이 강조되고 정산 테이블은 읽기 유지 상태로 남습니다. |
| 직군별 산식 검토 중 | FC / PT / GX 탭별 정책 비교가 가능하며, 변경 전후 예상 지급액 미리보기를 함께 표시합니다. |
