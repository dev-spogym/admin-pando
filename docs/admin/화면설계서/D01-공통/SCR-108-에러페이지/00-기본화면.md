## 화면 목적
존재하지 않는 페이지 접근, 권한 없는 페이지 접근, 서버 오류 등이 발생했을 때 사용자에게 상황을 안내하고 정상 화면으로 돌아갈 수 있게 하는 화면입니다.

## 주요 구성요소
- 오류 유형 안내 아이콘
- 오류 제목 (예: "페이지를 찾을 수 없습니다")
- 오류 설명 메시지
- 현재 역할의 기본 작업공간으로 돌아가기 버튼
- 이전 화면으로 돌아가기 링크

## 오류 유형별 안내
| 오류 유형 | 제목 | 설명 |
|---|---|---|
| 404 (없는 페이지) | 페이지를 찾을 수 없습니다 | 주소를 다시 확인해주세요 |
| 403 (권한 없음) | 접근 권한이 없습니다 | 관리자에게 문의하세요 |
| 500 (서버 오류) | 일시적인 오류가 발생했습니다 | 잠시 후 다시 시도해주세요 |
| 503 (서비스 점검) | 서비스 점검 중입니다 | 점검 완료 후 이용 가능합니다 |

## 주요 UX 흐름
1. 잘못된 접근 발생 → 이 화면으로 자동 이동
2. 오류 내용 확인
3. "기본 작업공간으로 이동" 클릭 → 로그인 역할에 맞는 홈 화면으로 이동
4. 이전 화면으로 돌아가기 선택 시 직전 경로로 복귀

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 지점 전체 데이터를 조회하고 업무 액션을 수행할 수 있습니다. |
| trainer / fc / staff | 본인 담당 범위 또는 배정된 업무 데이터 중심으로 조회합니다. |
| readonly | 조회만 가능하며 생성·수정·삭제·확정 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
