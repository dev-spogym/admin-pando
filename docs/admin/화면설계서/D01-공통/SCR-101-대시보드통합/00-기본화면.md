## 화면 목적
로그인 직후 가장 먼저 마주하는 화면으로, 지점 운영 현황을 한눈에 파악하는 통합 현황판입니다.
계정 역할에 따라 보이는 정보 범위와 가능한 액션이 달라집니다.

## 주요 구성요소
- 오늘 집중 업무 코크핏 (만료 임박 / 미수금 / 홀딩 관리 우선순위 카드)
- 역할별 빠른 액션 패널 (회원, 매출, 자동 알림, Today Tasks 등 계정 역할에 맞는 바로가기)
- 오늘의 핵심 수치 요약 (오늘 출석, 당일 매출, 만료 예정 회원 수 등)
- 실시간 출석 확인 카드 (키오스크·QR·RFID·얼굴인식·수동 출석 회원 동일인 확인)
- 수업 현황 위젯 (오늘 수업 일정 및 예약 현황)
- 회원 현황 위젯 (신규 등록, 만료 예정 등)
- 매출 현황 위젯 (당월 누적 등)
- 빠른 액션 버튼 (회원 등록, 결제 처리 등)
- 엑셀 내보내기 버튼 (권한 있는 계정만)

## 계정별 차이
| 계정 유형 | 볼 수 있는 정보 | 가능한 액션 |
|---|---|---|
| 슈퍼관리자 | 전체 지점 KPI + 지점 필터 | 모든 액션 + 엑셀 내보내기 |
| 본사 최고관리자 / 센터장 / 매니저 | 소속 지점 전체 KPI | 모든 액션 + 엑셀 내보내기 |
| FC / 코치 | 오늘 일정 + 담당 출석 현황 | 읽기 전용 (엑셀 불가) |
| 스태프 | 오늘 일정 + 출석 현황 | 읽기 전용 (엑셀 불가) |

## 실시간 출석 확인 카드

FC·프런트가 대시보드에 상시 띄워두고, 키오스크·앱 QR·RFID/밴드·얼굴인식·수동 출석으로 입장한 회원이 실제 본인인지 즉시 확인하는 대형 위젯입니다.
동일 위젯은 SCR-I001 통합 출석 관리 화면에도 동일하게 배치합니다.

| 항목 | 표시 규칙 |
|---|---|
| 카드 수 | 데스크톱 기준 최대 10개 유지, 초과 시 가장 오래된 카드 제거 |
| 중복 처리 | 동일 회원 첫 출석 후 2시간 이내 재출석은 새 카드 생성 안 함 |
| 출석 채널 | 키오스크 QR, 앱 QR, RFID/밴드, 얼굴인식, 수동 출석 전체 포함 |
| 회원 사진 | 등록된 사진 표시, 없으면 기본 아바타 표시 + "사진 필요" 태그 |
| 기본 정보 | 회원명, 회원번호, 성별/나이, 이용권명, 만료일, 출석 시각, 출석 채널 |
| 주의 태그 | 만료, 만료 임박, 미수금, 중복, 사진 필요, 이용권 없음 등 |
| 만료 임박 기준 | 본사 자동화 정책/지점 키오스크 출입 규칙의 유효 만료 안내 기준일을 따름 |
| 알림 | 신규 카드 추가 시 4~5초 강조, 알림음, 토스트 노출 |
| 클릭 | 회원 카드 클릭 시 SCR-M004 회원 상세 기본정보 탭으로 이동 |
| 지점 범위 | FC·스태프는 본인 소속 지점, 본사/센터장은 현재 선택한 지점 기준 |

사진이 없는 회원의 첫 출석 카드가 뜨면 FC에게 현장에서 회원 사진 촬영이 필요하다는 토스트를 표시합니다.

## 주요 UX 흐름
1. 로그인 완료 → 대시보드 자동 진입
2. 상단 오늘 집중 업무 카드에서 만료·미수·홀딩 이슈를 먼저 확인한다.
3. 역할별 빠른 액션 패널에서 현재 계정에 맞는 운영 화면으로 즉시 이동한다.
4. 실시간 출석 확인 카드에서 신규 입장 회원의 사진·기본 정보·주의 태그를 확인한다.
5. 동일인 확인 또는 보완이 필요하면 출석 카드 클릭 → 회원 상세 기본정보로 이동한다.
6. 각 위젯을 클릭하면 해당 상세 화면으로 이동
7. 빠른 액션 버튼으로 주요 업무 즉시 시작
8. 슈퍼관리자는 상단 지점 필터로 다른 지점 현황 조회 가능

## 화면 상태
| 상태 | 설명 |
|---|---|
| 로딩 | 데이터 불러오는 중 (스켈레톤 표시) |
| 정상 | 모든 데이터 표시 |
| 빈 상태 | 오늘 데이터 없음 (신규 센터 등) |
| 오류 | 데이터 로드 실패 안내 |
| 오프라인 | 네트워크 연결 없음 안내 |
| 실시간 출석 수신 | 새 카드 강조 + 알림음 + 토스트 표시 |
| 사진 미등록 | 기본 아바타 표시 + 사진 촬영 필요 토스트 |
| 만료/미수 주의 | 카드 경고 색상 + 주의 태그 표시 |
