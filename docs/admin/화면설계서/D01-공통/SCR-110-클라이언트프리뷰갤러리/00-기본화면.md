## 화면 목적

클라이언트가 FitGenie CRM 로그인 없이 퍼블리싱 결과물을 확인할 수 있는 공개 검토용 갤러리입니다. 내부 `/publishing` 화면과 동일한 화면 목록·preview URL을 사용하지만, CRM 사이드바·헤더·권한 가드 없이 갤러리와 iframe 프리뷰만 제공합니다.

## 주요 구성요소

| 영역 | 구성 | 설명 |
|---|---|---|
| 개요 화면 | 카테고리 카드 | 공통, 인증, 본사관리, 통합운영, 회원관리 등 퍼블리싱 도메인을 카드로 표시 |
| 카테고리 화면 | 카테고리 탭 | 도메인 간 이동. 링크는 `/client-preview/{category}` 형식 유지 |
| 검색/필터 | 검색 입력, 타입 필터 | 화면명, route, 설명 기준 검색과 대시보드/목록/입력/상세 필터 |
| 화면 목록 | 좌측 리스트 | 선택 화면의 제목, route, 화면 유형, 요약 표시 |
| 프리뷰 패널 | iframe | 선택 화면의 `preview=1` URL을 렌더링 |
| 새 탭 보기 | 외부 링크 | 선택 화면을 `preview=1` 상태로 새 탭에서 열기 |

## 주요 UX 흐름

1. 외부 공유 URL `/client-preview` 접속
2. 카테고리 카드 선택
3. `/client-preview/{category}`에서 화면 목록 확인
4. 화면 선택 시 `screen` query 갱신 및 iframe 프리뷰 전환
5. 필요 시 새 탭 보기로 `preview=1` 화면 직접 확인

## 정책

- 공개 라우트는 `AppLayout`을 사용하지 않아 로그인 리다이렉트가 발생하지 않는다.
- iframe에는 반드시 `preview=1`이 포함된 URL만 사용한다.
- 클라이언트 공개 화면에는 내부 기능명세 파일명, 실제 운영 라우트 열기, 공통 개발 가이드 링크를 노출하지 않는다.
- 실제 데이터나 권한별 운영 메뉴가 노출되지 않도록 preview mock/session 기준으로만 검토한다.
- `/publishing` 내부 검수 화면은 유지하고, `/client-preview`는 외부 공유 전용 진입점으로 분리한다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 개요 | 전체 도메인 카드와 총 화면 수 표시 |
| 카테고리 선택 | 선택 도메인의 화면 목록과 iframe 표시 |
| 검색 결과 없음 | 조건에 맞는 화면이 없음을 안내 |
| 잘못된 카테고리 | 404 또는 개요 이동 안내 |
| iframe 로딩 | 선택 화면 로딩 중 브라우저 기본 iframe 로딩 상태 |

## 예외 / 에러 처리

| 케이스 | 처리 |
|---|---|
| 알 수 없는 category | `notFound()` 처리 |
| 화면 목록이 비어 있음 | 해당 카테고리에 연결된 화면이 없다는 안내 표시 |
| 선택 화면 query 없음 | 해당 카테고리의 첫 번째 화면을 자동 선택 |
| 선택 화면이 검색 필터 밖에 있음 | 현재 필터 결과 첫 번째 화면으로 자동 보정 |
