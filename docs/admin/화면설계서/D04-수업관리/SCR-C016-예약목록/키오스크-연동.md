# SCR-C016 예약 목록 — 키오스크 연동

## 연동 목적

KIO-303 예약 조회 화면에서 회원별 일반 수업 예약 원장을 조회할 때 사용하는 기준을 정의한다. SCR-C016은 예약 1건 단위의 상태 원천이며, SCR-C002의 수업 마스터와 결합해 키오스크에 표시한다.

## 책임 경계

| 구분 | 책임 |
|---|---|
| SCR-C016 | 예약 1건 단위 상태, 예약일시, 출석/노쇼/취소 처리 결과 |
| SCR-C002 | 수업명, 강사, 장소, 수업 유형, 수업 일시 |
| KIO-303 | 회원 본인의 일반 수업 예약 목록 조회 |
| client SCR-MA-122 | 회원앱의 같은 예약 목록/수업 이력 조회 |

## KIO-303 조회 조건

| 항목 | 기준 |
|---|---|
| 회원 식별 | KIO-303 본인 확인 결과의 memberId |
| 기간 | 다가오는 예약 우선, 지난 예약은 정책에 따라 제한 표시 |
| 상태 | 예약완료, 출석완료, 취소, 노쇼, 대기 |
| 정렬 | 수업 시작일시 오름차순 |

## 비즈니스 규칙

- KIO-303은 일반 수업 예약을 읽기 전용으로 제공한다.
- 일반 수업 예약 생성/변경/취소는 admin 수업관리 또는 client 예약 흐름에서 처리한다.
- 골프 타석 예약은 SCR-C016 원장과 별도로 SCR-054 기준으로 관리하고, KIO-303에서는 요약 조회만 한다.
- 키오스크 화면에서 일반 예약과 골프 예약을 섞어 보여줄 경우 카드에 `일반 수업` / `골프 타석` 구분 배지를 표시한다.
