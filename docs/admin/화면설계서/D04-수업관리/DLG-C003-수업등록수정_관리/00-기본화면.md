## 화면 목적

수업 관리 화면(SCR-C002)에서 새 수업을 등록하거나 기존 수업 정보를 수정하는 팝업입니다. 캘린더 기반의 DLG-C001과 동일한 입력 항목을 제공하되, 목록 화면의 맥락에서 호출됩니다.

## 주요 구성요소

- **수업 템플릿 선택**: 드롭다운으로 기존 수업 선택 (수업명·유형·정원 자동 완성)
- **수업명**: 직접 입력 가능 (템플릿 미선택 시)
- **수업 유형**: PT / GX / 개인레슨 / 기타 선택
- **강습 세션 유형**: PT / 필라테스 / 스트레칭 / 테라피 선택. 강습세션수 KPI 집계 대상 수업일 때 필수
- **일시**: 날짜 + 시작·종료 시간 선택
- **강사 배정**: 담당 강사 드롭다운
- **장소**: 룸·장소 드롭다운
- **정원**: 최대 예약 인원 입력
- **상태**: 예정 / 진행중 / 완료 / 취소 (수정 모드에서만 표시)
- **메모**: 내부 메모 입력 (선택)
- **저장 버튼** / **취소 버튼**

## 언제 표시되나요

- 수업 관리 화면(SCR-C002)에서 "수업 등록" 버튼을 클릭했을 때
- 수업 목록에서 특정 수업 행을 클릭했을 때 (수정 모드)

## 주요 UX 흐름

1. "수업 등록" 클릭 → 빈 폼으로 팝업 열림
2. 수업 템플릿 선택 또는 직접 입력으로 수업 정보 채우기
3. 강사·장소·일시 설정
4. 저장 클릭 → 시간 충돌 감지 후 수업 목록에 즉시 반영
5. 수정 모드: 기존 정보 자동 입력 → 변경 후 저장

## 비즈니스 규칙

- `수업 유형`은 운영 분류이고, `강습 세션 유형`은 본사 KPI 산출용 세부 분류입니다.
- 강습 세션 유형은 PT / 필라테스 / 스트레칭 / 테라피 4종으로 고정합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
