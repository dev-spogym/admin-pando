# SCR-C002 수업 관리 — 키오스크 연동

## 연동 목적

KIO-303 예약 조회 화면에서 일반 수업 예약을 표시할 때 사용하는 수업 마스터 기준을 정의한다. 키오스크는 일반 PT/GX/OT 수업을 생성하거나 변경하지 않고, 회원에게 수업명·강사·장소·일시·상태를 읽기 전용으로 보여준다.

## 책임 경계

| 구분 | 책임 |
|---|---|
| SCR-C002 | 수업명, 유형, 강사, 장소, 일시, 정원, 수업 상태 원천 |
| SCR-C016 | 회원별 예약 1건 단위 원장 |
| KIO-303 | 본인 확인 후 일반 수업 예약을 읽기 전용 표시 |
| SCR-054 | 골프 타석 예약 생성/대기 등록 원천 |

## KIO-303 표시 데이터

| 항목 | 원천 |
|---|---|
| 수업명 | SCR-C002 |
| 수업 유형 | SCR-C002 |
| 강사 | SCR-C002 |
| 장소 | SCR-C002 |
| 수업 일시 | SCR-C002 |
| 예약 상태 | SCR-C016 |
| 출석/노쇼/취소 상태 | SCR-C016 |

## 비즈니스 규칙

- 일반 수업 예약 생성, 변경, 취소, 출석 처리, 노쇼 처리는 admin 또는 client의 기존 수업 예약 흐름에서 처리한다.
- KIO-303은 조회 전용이며 일반 수업 예약 액션 버튼을 제공하지 않는다.
- 골프 타석 예약은 일반 수업 예약과 같은 목록에 요약 표시될 수 있지만, 생성/대기 등록은 KIO-501 ~ KIO-504와 SCR-054에서만 수행한다.
- 동일 회원의 예약 목록은 client `SCR-MA-122-내예약수업이력`과 같은 원천을 사용한다.
