## 화면 목적

자동 페널티 정책 외에, 관리자가 특정 회원에게 직접 페널티를 수동으로 부과하는 팝업입니다. 정책에 포함되지 않는 특수 상황에서 유연하게 페널티를 적용할 수 있습니다.

## 주요 구성요소

- **대상 회원 선택**: 회원 검색 또는 드롭다운으로 페널티 부과 대상 선택
- **페널티 유형 선택**: 노쇼 / 늦은 취소 / 기타
- **관련 수업 선택**: 페널티 사유가 된 수업 선택 (선택)
- **페널티 내용**:
  - 예약 제한: 제한 기간(일수) 입력
  - 횟수 차감: 차감 횟수 입력
  - 두 가지 병행 적용 가능
- **적용 시작일**: 페널티 적용 시작일 (기본값: 오늘)
- **사유 입력**: 페널티 부과 사유 상세 기록 (필수)
- **확인 버튼** / **취소 버튼**

## 언제 표시되나요

- 페널티 관리 화면(SCR-C008)의 페널티 현황 탭에서 "페널티 등록" 버튼을 클릭했을 때

## 주요 UX 흐름

1. "페널티 등록" 클릭 → 팝업 열림
2. 대상 회원 검색 및 선택
3. 페널티 유형·내용·시작일 설정
4. 사유 입력 (필수)
5. "확인" 클릭 → 페널티 즉시 적용, 회원에게 알림 발송 (설정에 따라)
6. "취소" 클릭 → 팝업 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
