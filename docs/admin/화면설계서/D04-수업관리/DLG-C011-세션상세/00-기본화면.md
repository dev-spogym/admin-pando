## 화면 목적

개별 PT 세션에서 진행된 운동 내용과 강사 노트를 상세하게 기록하고 조회하는 팝업입니다. 세션별로 어떤 운동을 몇 세트·몇 회·몇 kg으로 진행했는지 기록해 두면 회원의 운동 이력을 추적하고 다음 세션 계획에 활용할 수 있습니다.

## 주요 구성요소

- **세션 기본 정보**: 수업명(회원명), 날짜·시간, 담당 강사
- **운동 프로그램**: 해당 세션에 배정된 운동 프로그램명
- **운동 기록 목록**:
  - 동작명
  - 세트 수
  - 반복 횟수 (또는 시간)
  - 중량 (kg)
  - 완료 여부 체크박스
  - 동작별 메모
- **강사 노트**: 세션 전체에 대한 강사 코멘트, 특이사항, 다음 세션 제안
- **회원 컨디션 기록**: 당일 회원 컨디션 (좋음/보통/나쁨), 부상·통증 여부
- **저장 버튼** (기록 입력 시) / **닫기 버튼** (조회 시)

## 언제 표시되나요

- 운동 프로그램 관리 화면(SCR-C010)에서 특정 세션 기록 클릭 시
- 수업 기록 상세(DLG-C005)에서 "세션 기록 보기" 버튼 클릭 시
- 유효 수업 목록(SCR-C011)에서 수업 완료 후 세션 기록 입력 버튼 클릭 시

## 주요 UX 흐름

1. 수업 완료 후 "세션 기록 입력" 클릭 → 팝업 열림
2. 동작별 실제 수행 세트·횟수·중량 입력
3. 강사 노트 및 회원 컨디션 입력
4. 저장 클릭 → 세션 이력에 기록 저장
5. 조회 모드: 기존 기록 표시, 닫기로 팝업 닫힘

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
