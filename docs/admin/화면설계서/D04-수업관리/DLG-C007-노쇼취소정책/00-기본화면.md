## 화면 목적

노쇼 및 늦은 취소 발생 시 적용할 정책을 설정하는 팝업입니다. 페널티를 자동으로 부과할 기준과 내용을 정의해 두면, 이후 노쇼·늦은 취소 발생 시 수동 개입 없이 정책이 자동 적용됩니다.

## 주요 구성요소

- **노쇼 정책 섹션**:
  - 노쇼 자동 페널티 적용 여부 토글
  - 페널티 내용 선택: 예약 제한 기본 7일 / 잔여 횟수 기본 1회 차감 / 병행 적용
  - 일수 또는 횟수는 운영자가 직접 조정할 수 있으며 기본값은 7일·1회입니다.
- **늦은 취소 정책 섹션**:
  - 늦은 취소 기준 시간 설정 (수업 시작 몇 시간 전 이내 취소 시 패널티 적용)
  - 페널티 내용 선택: 예약 제한 기본 7일 / 잔여 횟수 기본 1회 차감
- **누적 노쇼 기준 추가 페널티** (선택):
  - 월 3회 이상 노쇼 시 추가 페널티 적용 여부
  - 추가 페널티 기본값은 예약 제한 14일이며 센터 정책으로 변경할 수 있습니다.
- **저장 버튼** / **취소 버튼**

## 언제 표시되나요

- 페널티 관리 화면(SCR-C008) 정책 설정 탭에서 "노쇼/취소 정책" 편집 버튼 클릭 시
- 자동 페널티 정책(DLG-C015)에서 상세 정책 설정으로 진입 시

## 주요 UX 흐름

1. 정책 설정 탭에서 편집 버튼 클릭 → 팝업 열림
2. 현재 설정된 정책 값이 자동 입력됨
3. 노쇼·늦은 취소 각각의 페널티 내용과 기준 시간 수정
4. 저장 클릭 → 이후 발생하는 노쇼·늦은 취소에 새 정책 적용
5. 취소 클릭 → 변경 없이 팝업 닫힘

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 현재 저장된 노쇼·늦은 취소 정책을 불러와 표시합니다. |
| 저장 중 | 저장 버튼 비활성화, 중복 저장을 막습니다. |
| 검증 오류 | 일수·횟수가 0 미만이거나 늦은 취소 기준 시간이 비어 있으면 저장을 차단합니다. |
| 본사 표준 정책 적용 | 지점 사용자는 값을 볼 수만 있고 수정 버튼은 비활성화합니다. |

## 계정별 차이

| 계정 | 권한 |
|---|---|

| trainer / fc / staff | 조회만 가능 |
| readonly | 접근 불가 |
