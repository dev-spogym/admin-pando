## 화면 목적

기존에 등록된 할인 정책의 내용을 수정하는 모달입니다. 등록 시 설정한 모든 항목을 변경할 수 있습니다.

---

## 주요 구성요소

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 할인명 | 필수 | 기존 이름 수정 가능 |
| 할인 유형 | 필수 | 정률(%) / 정액(원) |
| 할인 값 | 필수 | 변경할 할인율 또는 금액 |
| 최소 계약 기간 | 선택 | 조건 기간 수정 |
| 최대 할인금액 | 선택 | 한도 금액 수정 |
| 활성 상태 | 선택 | 활성/비활성 전환 |

하단 버튼: **취소** / **수정 저장**

---

## 언제 표시되나요

- SCR-P004(할인 설정) 목록에서 수정 아이콘(연필)을 클릭했을 때

---

## 주요 UX 흐름

1. 기존 할인 정책 정보가 폼에 자동 입력된 상태로 열림
2. 원하는 항목 수정
3. "수정 저장" 버튼 클릭
   - 필수 항목 미입력 시: 안내 메시지
   - 정상 저장 시: 모달 닫힘 + 목록 갱신 + 변경 이력 기록
4. "취소" 클릭: 모달 닫힘

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
