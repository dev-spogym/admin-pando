## 화면 목적

신규 상품을 등록하는 화면입니다. `SCR-P001 상품 관리`에서 [상품 등록]을 누르면 `SCR-P003 상품 상세/수정 패널`과 같은 상품 패널 입력 UI가 신규 등록 상태로 열립니다. `/products/new` 직접 진입 시에도 동일 필드 구성을 가진 등록 화면으로 표시됩니다. 화면 구성과 필드 정의의 정본은 공유 상품 패널의 신규 등록 상태(`DLG-P001-상품등록모달`)와 동일합니다.

기존 상품 수정은 별도 상품 수정 전용 모달을 사용하지 않습니다. 상품 행 클릭 후 같은 상품 패널 UI에 기존 상품 값을 채운 `SCR-P003 상품 상세/수정 패널`에서 바로 수정합니다.

---

## 주요 구성요소

### 등록 폼

| 영역 | 주요 필드 |
|---|---|
| 상품 구분 | 레슨 / 이용 / 락커 / 판매 |
| 레슨 상세 | 사용인원, 1단계, 2단계, 레슨시간, 레슨유효기간, 횟수, 수업구분 |
| 기본 정보 | 상품그룹, 상품명, 금액, 카드가, 태그, 설명 |
| 이용 조건 | 이용구분, 기간, 횟수/포인트, 횟수제한 |
| 요일/시간 | 월~일 체크, 시작/종료 시간, 10분 단위 |
| 옵션 | 예약 가능, 시설 이용 가능, 홀딩, 양도, 포인트 적립, 회원 직접 휴회, 키오스크 노출, 활성 상태 |
| 상세 설정 | 시설이용시간, 시설예약가능일, 휴회횟수, 예약시간간격, 휴회기간, 판매유형 |
| 패키지 구성 | 패키지 상품 여부, 구성 상품 선택, 구성 목록 |

### 버튼

| 버튼 | 동작 |
|---|---|
| 상품정보가져오기 | `DLG-P008-상품가져오기`를 열어 기존 상품 정보를 복사 |
| 신규 | 입력값 초기화. 변경값이 있으면 `DLG-P003-작업취소확인` |
| 등록 | 필수값 검증 후 신규 상품 등록 |
| 종료 | 변경값이 있으면 `DLG-P003-작업취소확인`, 없으면 목록 복귀 |

## 상품 구분별 표시 규칙

| 상품구분 | 필수/표시 항목 |
|---|---|
| 레슨 | 1단계, 2단계, 레슨시간, 레슨유효기간, 횟수, 수업구분 |
| 이용 | 이용구분(기간/횟수/포인트), 기간 또는 횟수/포인트 |
| 락커 | 기간, 시설 이용 가능 여부, 판매유형 |
| 판매 | 상품명, 금액, 카드가, 태그, 판매유형 |

GX 상품은 2단계 세부종목을 반드시 선택해야 하며, 선택지는 요가 / 필라테스 / 스피닝 / 줌바 / GX 기타 6종으로 고정합니다.

---

## 주요 UX 흐름

1. `SCR-P001`에서 [상품 등록] 클릭 또는 `/products/new` 직접 진입
2. 신규 등록 폼 표시
3. 상품 구분 선택
4. 상품그룹, 상품명, 금액, 카드가, 이용 조건, 요일/시간, 옵션 입력
5. 필요 시 [상품정보가져오기]로 기존 상품 값을 복사
6. [등록] 클릭
7. 검증 성공 시 목록 갱신 후 `SCR-P001`로 복귀

## 화면 상태

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 기본 | 신규 진입 | 상품구분=이용, 활성 상태 ON |
| 상품정보 가져오기 후 | `DLG-P008-상품가져오기`에서 상품 선택 | 선택 상품 값으로 폼 채움, 저장 시 새 상품으로 등록 |
| 패키지 구성 열림 | 패키지 구성 클릭 | 구성 상품 선택/추가 영역 표시 |
| 저장 중 | 등록 클릭 | 등록 버튼 비활성, 중복 저장 방지 |
| 저장 실패 | 검증 실패 또는 저장 실패 | 입력값 유지, 오류 표시 |
| 작업 취소 확인 | 변경값이 있는 상태에서 종료 | `DLG-P003-작업취소확인` 표시 |

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 등록 폼 | 상품 등록, 상품정보 가져오기, 패키지 구성 |
| owner | 소속 지점 등록 폼 | 상품 등록, 상품정보 가져오기, 패키지 구성 |
| manager | 소속 지점 등록 폼 | 상품 등록, 상품정보 가져오기, 패키지 구성 |
| trainer / fc / staff / readonly | 기본 진입 불가 | 상품 등록 버튼 hidden, 직접 URL 접근 차단 |
| readonly | 진입 불가 | 없음 |

## 필수 예외처리

| 케이스 | 처리 |
|---|---|
| 상품명 누락 | 상품명 인라인 오류, 등록 차단 |
| 금액 누락 또는 0 이하 | 금액 인라인 오류, 등록 차단 |
| 상품명 중복 | 동일 지점/분류 내 중복 안내, 등록 차단 |
| GX 세부종목 미선택 | 2단계 선택 요구, 등록 차단 |
| 기간/횟수/포인트 조건값 없음 | 선택한 이용구분에 맞는 값 입력 요구 |
| 요일 0개 선택 | 최소 1개 요일 선택 요구 |
| 시작 시간 >= 종료 시간 | 시간 오류 표시, 등록 차단 |
| 카드가 > 현금가 | 카드가 오류 표시, 등록 차단 |
| 회원 직접 휴회 ON + 상세값 미선택 | 휴회횟수/휴회기간 선택 요구 |
| 패키지 구성 ON + 구성 상품 없음 | 구성 상품 추가 요구 |
| 변경값 있음 + 종료 | `DLG-P003-작업취소확인` 표시 |
