## 화면 목적

기존에 등록된 상품의 정보를 수정하는 모달입니다. 등록 시 설정한 모든 항목을 수정할 수 있으며, 가격 변경 시에는 변경 이력이 자동으로 기록됩니다.

---

## 주요 구성요소

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 상품 구분 | 필수 | 레슨 / 이용 / 락커 / 판매 |
| 상품명 | 필수 | 중복 불가 (기존 이름 제외) |
| 현금가 | 필수 | 현금 결제 기준 가격 |
| 카드가 | 선택 | 미입력 시 현금가와 동일 저장 |
| 상품그룹 | 선택 | 상품관리 > 분류 관리 탭에서 등록한 활성 그룹 중 선택 |
| 이용 기간 / 횟수 | 조건부 | 상품 구분에 따라 표시 |
| 이용 요일·시간 | 선택 | 요일별 체크박스 + 시간 선택 |
| 각종 옵션 | 선택 | 홀딩/양도/포인트/키오스크 등 |
| 활성 상태 | 선택 | 활성/비활성 전환 |

하단 버튼: **삭제** / **닫기** / **저장**

---

## 언제 표시되나요

- SCR-P001(상품 관리) 또는 SCR-P003(상품 상세 패널)에서 기존 상품을 선택했을 때
- 상품 편집 권한이 있는 계정에서만 수정 가능합니다.

---

## 주요 UX 흐름

1. 기존 상품 정보가 폼에 자동 입력된 상태로 열림
2. 원하는 항목 수정
3. "저장" 버튼 클릭
   - 필수 항목 미입력 시: 안내 메시지 표시
   - 상품명 중복 시: 중복 안내 메시지 표시
   - 정상 저장 시: Supabase `products` update 성공 + 목록 갱신 + 완료 메시지
   - 가격 변경 시: 가격 변경 이력 자동 기록
4. "삭제" 버튼 클릭 시: [DLG-P003-상품삭제확인] 또는 [DLG-P004-비활성화안내]로 이동

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
