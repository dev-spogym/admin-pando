## 화면 목적

재고 실사(직접 세어보기) 결과가 시스템 재고와 다를 때 실제 수량으로 맞춰주는 모달입니다. 입출고 이력 없이 재고 수량을 직접 수정하므로 조정 사유를 반드시 기록해야 합니다.

---

## 주요 구성요소

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 상품명 | 자동 입력 | 조정할 상품 (변경 불가) |
| 현재 시스템 재고 | 자동 표시 | 현재 시스템에 기록된 수량 |
| 실제 재고 수량 | 필수 | 실사 후 실제 확인된 수량 |
| 조정 사유 | 필수 | 분실 / 파손 / 오류 수정 / 기타 중 선택 또는 직접 입력 |
| 조정일 | 필수 | 실사 날짜 (기본값: 오늘) |
| 메모 | 선택 | 상세 경위 기록 |

하단 버튼: **취소** / **조정 적용**

---

## 언제 표시되나요

- SCR-P007(재고 관리) 목록에서 특정 상품의 "조정" 버튼을 클릭했을 때

---

## 주요 UX 흐름

1. 대상 상품명, 현재 시스템 재고가 표시된 상태로 모달 열림
2. 실제 재고 수량과 조정 사유 입력
3. "조정 적용" 버튼 클릭
   - 실제 수량 미입력 또는 0 미만 시: 안내 메시지
   - 조정 사유 미입력 시: 안내 메시지
   - 정상 적용 시: 재고 수량 변경 + 조정 이력 기록 + 모달 닫힘 + 완료 메시지
4. "취소" 클릭: 모달 닫힘, 재고 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
