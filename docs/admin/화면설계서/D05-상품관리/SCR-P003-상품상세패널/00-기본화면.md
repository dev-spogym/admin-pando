## 화면 목적

상품 목록(`SCR-P001`)에서 상품 행을 클릭하면 우측에서 열리는 상세/수정 패널입니다. 이 패널은 조회 전용이 아니라 현재 프론트엔드 구현처럼 상품 값을 바로 편집할 수 있는 정본 화면입니다. 별도 상품 수정 전용 모달은 사용하지 않습니다.

신규 상품 등록과 기존 상품 수정은 같은 상품 패널 입력 UI를 공유합니다. 신규 등록은 빈 폼과 `상품등록` 제목, 기존 상품 수정은 기존 값이 채워진 폼과 `상품수정` 제목으로 구분합니다.

---

## 주요 구성요소

### 헤더

| 요소 | 설명 |
|---|---|
| 제목 | 기존 상품은 `상품수정` 표시 |
| 상태 배지 | 활성 / 비활성 |
| 닫기(X) | 변경값이 있으면 `DLG-P003-작업취소확인` 표시 |

### 편집 가능 필드

| 영역 | 필드 |
|---|---|
| 상품 구분 | 레슨 / 이용 / 락커 / 판매 |
| 레슨 상세 | 사용인원, 1단계, 2단계, 레슨시간, 레슨유효기간, 횟수, 수업구분 |
| 기본 정보 | 상품그룹, 상품명, 금액, 카드가, 태그, 설명 |
| 이용 조건 | 이용구분, 기간, 횟수/포인트, 횟수제한 |
| 요일/시간 | 월~일 체크, 시작/종료 시간, 10분 단위 |
| 옵션 | 예약 가능, 시설 이용 가능, 홀딩, 양도, 포인트 적립, 회원 직접 휴회, 키오스크 노출, 활성 상태 |
| 상세 설정 | 시설이용시간, 시설예약가능일, 휴회횟수, 예약시간간격, 휴회기간, 판매유형 |
| 패키지 구성 | 패키지 상품 여부, 구성 상품 추가/제거 |

### 조회성 정보

| 영역 | 설명 |
|---|---|
| 가격 변경 이력 | 최근 변경 이력을 표시하고 전체 보기 시 `DLG-P014-가격이력조회`로 이동 |
| 판매 현황 | 누적 판매 건수, 활성 보유 회원 수, 최근 30일 판매, 만료 임박 회원 수 |
| 비활성 상태 | 비활성 상품은 헤더 배지와 신규 판매 차단 안내 표시 |

## 주요 UX 흐름

1. `SCR-P001` 상품 목록에서 상품 행 클릭
2. 우측 `SCR-P003 상품 상세/수정 패널` 열림
3. 현재 상품 값이 폼에 채워진 상태로 표시
4. 사용자가 필요한 값을 바로 수정
5. [저장] 클릭
6. 검증 성공 시 상품 목록 갱신, 가격 변경 시 가격 이력에 표시

### 삭제 / 비활성 흐름

1. [삭제] 클릭
2. 판매 이력 확인
3. 판매 이력 0건이면 `DLG-P005-상품삭제확인`
4. 판매 이력 1건 이상이면 `DLG-P006-비활성화안내`

## 화면 상태

| 상태 | 조건 | 표시 내용 |
|---|---|---|
| 조회/편집 가능 | 상품 로드 완료 | 전체 필드 활성, 저장/삭제 버튼 표시 |
| 읽기 전용 | 수정 권한 없음 | 입력 비활성, 저장/삭제 버튼 hidden |
| 변경 있음 | 초기값과 현재값이 다름 | 닫기 시 `DLG-P003-작업취소확인` |
| 저장 중 | 저장 클릭 후 처리 중 | 저장 버튼 비활성, 중복 저장 방지 |
| 저장 실패 | 검증 실패 또는 저장 실패 | 입력값 유지, 오류 표시 |
| 가격 이력 로딩 | 가격 이력 펼침 | 로딩 표시 후 최근 이력 표시 |
| 비활성 상품 | 상품 상태가 비활성 | 회색 배지 + 신규 판매 불가 안내 |

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| primary / superAdmin | 전체 정보 + 판매 현황 + 가격 이력 | 수정, 삭제, 비활성, 비교, 카탈로그 미리보기 |
| owner | 소속 지점 전체 정보 | 수정, 삭제, 비활성 |
| manager | 전체 정보 | 수정 가능. 삭제는 별도 상품 삭제 권한이 있을 때만 |
| trainer / fc / staff | 상품 기본 정보 | 조회만. 별도 상품 편집 권한이 있으면 수정 가능 |
| readonly | 접근 불가 또는 조회 전용 | 변경 불가 |

## 필수 예외처리

| 케이스 | 처리 |
|---|---|
| 상품 데이터 로딩 실패 | 패널에 재시도 안내 표시 |
| 상품명 중복 | 저장 차단, 중복 안내 |
| GX 세부종목 미선택 | 저장 차단, 2단계 선택 요구 |
| 카드가 > 현금가 | 저장 차단 |
| 기간/횟수/포인트 조건값 없음 | 선택한 이용구분에 맞는 값 요구 |
| 요일 0개 선택 | 최소 1개 요일 선택 요구 |
| 시작 시간 >= 종료 시간 | 해당 요일 시간 오류 |
| 변경값 있음 + 닫기 | `DLG-P003-작업취소확인` 표시 |
| 판매 이력 있는 상품 삭제 | 삭제 대신 `DLG-P006-비활성화안내`로 미사용 전환 안내 |
| 패키지 구성 상품 삭제 | 패키지 사용 중 안내 후 분리 전 삭제 차단 |
| 동시 수정 충돌 | 최신 정보 보기 / 덮어쓰기 선택 제공 |
| 가격 이력 0건 | "가격 변경 이력이 없습니다" 안내 |
