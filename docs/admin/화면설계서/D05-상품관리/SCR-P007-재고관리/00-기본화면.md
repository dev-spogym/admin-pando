## 화면 목적

본 화면은 기존 D05 상품관리 안에 있던 재고 관리 정의입니다. v1 정본 기준에서 실제 실물 재고 수량 관리, 입고, 출고, 조정은 D06 시설관리의 `SCR-055 상품 재고 관리(FAC-06)`로 책임을 이관합니다.

D05 상품관리에서는 상품명, 상품구분, 가격, 판매 가능 여부, 결제 노출만 관리합니다. D05의 운동복 상품은 운동복 대여비/상품 비용이며, 결제 완료 시 D06 재고 수량을 자동 차감하지 않습니다.


---

## 주요 구성요소

### 재고 현황 테이블

| 컬럼 | 내용 |
|------|------|
| 상품명 | 실물 상품 이름 |
| 카테고리 | 상품 분류 |
| 현재 재고 | 현재 보유 수량 |
| 안전 재고 | 최소 유지 기준 수량 |
| 재고 상태 | 충분 / 부족 / 품절 |
| 최근 입고일 | 마지막 입고 처리 날짜 |
| 액션 | 입고 / 출고 / 조정 버튼 |

### 재고 통계 카드

| 카드 | 내용 |
|------|------|
| 전체 품목 수 | 관리 중인 실물 상품 총 종류 |
| 부족 재고 | 안전 재고 미달 품목 수 |
| 품절 | 재고 0인 품목 수 |

### 필터 및 검색

- 상품 카테고리별 필터
- 재고 상태별 필터 (충분 / 부족 / 품절)
- 상품명 검색

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|-----------|--------------|--------------|
| fc / trainer / staff / readonly | 재고 현황 조회 | 조회만 가능 |
| Owner(지점장) / manager | 소속 지점 재고 화면 | 입고·출고 처리, 재고 조정 |
| superAdmin / primary | 전체 화면 + 통계 | 입고·출고·조정 + 이력 조회 |

---

## 주요 UX 흐름

1. **재고 조회**: 화면 진입 → 전체 실물 상품 재고 현황 표시
2. **입고 처리**: 해당 상품의 "입고" 버튼 클릭 → [DLG-P019-입고등록]에서 수량·날짜 입력 후 저장
3. **출고 처리**: 해당 상품의 "출고" 버튼 클릭 → [DLG-P020-출고등록]에서 수량·사유 입력 후 저장
4. **재고 조정**: 재고 실사 후 수량 불일치 시 "조정" 버튼 → [DLG-P021-재고조정]에서 실제 수량 입력
5. **입출고 이력 조회**: 상품별 "이력" 버튼 또는 이력 탭 → [DLG-P022-입출고이력] 조회
