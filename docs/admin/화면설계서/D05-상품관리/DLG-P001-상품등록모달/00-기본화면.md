## 화면 목적

`SCR-P001 상품 관리`에서 [상품 등록]을 클릭했을 때 열리는 신규 상품 등록 상태의 기획 식별자입니다. 실제 프론트 기준으로는 `SCR-P003 상품 상세/수정 패널`과 같은 상품 패널 입력 UI를 공유하며, 신규 등록일 때 빈 폼과 `상품등록` 제목으로 표시됩니다. 등록자는 한 화면에서 상품 구분, 가격, 이용 조건, 요일/시간, 옵션, 휴회/예약 정책, 패키지 구성을 입력할 수 있어야 합니다.

상품 수정은 별도 상품 수정 전용 모달을 사용하지 않고 같은 상품 패널 UI에 기존 상품 값을 채운 `SCR-P003 상품 상세/수정 패널`에서 즉시 편집합니다.

## 주요 구성요소

### 헤더

| 요소 | 동작 |
|---|---|
| 제목 | 신규 등록 시 `상품등록` 표시 |
| 닫기(X) | 입력값이 있으면 `DLG-P003-작업취소확인` 표시 후 닫기 |

### 상품 구분

| 항목 | 필수 | 설명 |
|---|---|---|
| 상품구분 | 필수 | 레슨 / 이용 / 락커 / 판매 라디오 |
| 사용인원 | 레슨 선택 시 | 기본 1명. 레슨 상품의 기본 수업 참여 인원 |
| 1단계 | 레슨 선택 시 | PT / GX 등 레슨 대분류 |
| 2단계 | GX 선택 시 필수 | 요가 / 필라테스 / 스피닝 / 줌바 / GX 기타 |

### 기본 입력

| 항목 | 필수 | 설명 |
|---|---|---|
| 상품그룹 | 선택 | 상품 관리의 분류 관리 탭에서 등록한 활성 상품그룹 선택 |
| 상품명 | 필수 | 동일 지점 + 동일 상품그룹 또는 대분류 내 중복 불가 |
| 금액 | 필수 | 현금가. 0보다 큰 금액 |
| 카드가 | 선택 | 미입력 시 현금가와 동일 처리 |
| 태그 | 선택 | 검색·분류용 자유 태그 |
| 이용구분 | 이용 상품 필수 | 기간 / 횟수 / 포인트 |
| 기간 | 이용구분=기간 또는 락커 필수 | 숫자 입력. 일 단위로 저장 |
| 횟수/포인트 | 이용구분=횟수/포인트 또는 레슨 필수 | 숫자 입력 |
| 설명 | 선택 | 상품 상세 설명 |

### 요일 / 시간설정

| 항목 | 설명 |
|---|---|
| 월~일 체크박스 | 체크한 요일만 이용 가능 |
| 시작/종료 시간 | 체크된 요일에서만 활성화. 기본 09:00~18:00 |
| 시간 단위 | 10분 단위 |

요일을 하나도 체크하지 않은 상태는 "전 요일 허용"으로 해석하지 않고 저장 차단합니다.

### 옵션

| 옵션 | 의미 |
|---|---|
| 예약 가능 | 이 상품으로 수업/시설 예약 가능 |
| 시설 이용 가능 | 출입/시설 이용 권한 부여 |
| 홀딩 가능 | 이용권 일시정지 가능 |
| 양도 가능 | 타 회원에게 양도 가능 |
| 포인트 적립 | 구매 시 포인트 적립 |
| 회원 직접 휴회 | 회원앱에서 직접 휴회 신청 가능 |
| 키오스크 노출 | 키오스크 상품 목록에 노출 |
| 활성 상태 | 신규 판매 가능 상태 |

### 하단 상세 설정

| 항목 | 표시/동작 |
|---|---|
| 시설이용가능 + 시설이용시간 | 시설 이용 가능 체크 시 기본 / 오전 / 오후 / 종일 선택 |
| 시설예약가능 + 시설예약가능일 | 시설 예약 가능 체크 시 당일 / 1일 전 / 3일 전 / 7일 전 / 14일 전 / 30일 전 선택 |
| 회원직접휴회가능 + 휴회횟수 | 회원 직접 휴회 가능 체크 시 선택 / 1회 / 2회 / 3회 선택 |
| 예약시간간격 | 10분 / 20분 / 30분 / 40분 / 50분 / 60분 |
| 휴회기간 | 선택 / 3일 / 7일 / 15일 / 30일 / 60일 |
| 판매유형 | 전체 / 현장 / 키오스크 / 온라인 |
| 패키지 구성 | 접힘 상태 기본. 펼치면 구성 상품을 선택해 패키지 상품으로 등록 |

### 하단 액션

| 버튼 | 동작 |
|---|---|
| 상품정보가져오기 | `DLG-P008-상품가져오기`를 열어 기존 상품 값을 복사 |
| 신규 | 현재 입력값을 비우고 신규 등록 초기값으로 재설정. 입력값이 있으면 작업취소 확인 |
| 등록 | 필수값과 정책 검증 후 상품 등록 |
| 종료 | 입력값이 있으면 `DLG-P003-작업취소확인`, 없으면 닫기 |

---

## 주요 UX 흐름

1. `SCR-P001`에서 [상품 등록] 클릭
2. 공유 상품 패널이 신규 등록 상태(`DLG-P001-상품등록모달`)로 표시
3. 상품 구분 선택
4. 상품그룹, 상품명, 금액, 카드가, 이용구분, 기간/횟수, 요일/시간, 옵션 입력
5. [등록] 클릭
6. 검증 성공 시 상품 목록 갱신 후 패널 닫기 또는 신규 등록 초기화

## 화면 상태

| 상태 | 조건 | 표시 |
|---|---|---|
| 기본 | 신규 등록 진입 | 상품구분=이용, 활성 상태 ON, 키오스크 노출 ON, 포인트 적립 ON |
| 레슨 선택 | 상품구분=레슨 | 1단계/2단계, 레슨시간, 레슨유효기간, 횟수, 수업구분 표시 |
| 이용 선택 | 상품구분=이용 | 이용구분 기간/횟수/포인트, 기간 또는 횟수/포인트 표시 |
| 락커 선택 | 상품구분=락커 | 기간 입력 중심, 시설/예약 옵션은 정책에 맞게 제한 |
| 판매 선택 | 상품구분=판매 | 태그, 가격, 판매유형 중심. 이용 기간/횟수는 숨김 |
| 저장 중 | 등록 클릭 후 처리 중 | 등록 버튼 비활성, 중복 클릭 방지 |
| 검증 실패 | 필수값 누락/정책 위반 | 해당 필드 인라인 오류 + 등록 차단 |

## 필수 예외처리

| 케이스 | 처리 |
|---|---|
| 상품명 없음 | 상품명 필드 오류, 등록 차단 |
| 금액 없음 또는 0 이하 | 금액 필드 오류, 등록 차단 |
| 카드가 미입력 | 현금가와 동일하게 처리 |
| 카드가 > 현금가 | 저장 차단. 카드가는 현금가보다 클 수 없음 |
| GX 선택 후 2단계 미선택 | GX 세부종목 선택 안내, 등록 차단 |
| 기간/횟수/포인트 조건값 없음 | 선택한 이용구분에 맞는 수량 입력 요구 |
| 요일 0개 선택 | 최소 1개 요일 선택 안내 |
| 시작 시간 >= 종료 시간 | 해당 요일 시간 오류, 등록 차단 |
| 회원직접휴회가능 ON + 휴회횟수/휴회기간 미선택 | 휴회 상세값 선택 요구 |
| 패키지 구성 ON + 구성 상품 0개 | 구성 상품 추가 전 등록 차단 |
| 상품명 중복 | 동일 지점/분류 내 중복 안내, 등록 차단 |
| 닫기/종료 시 입력값 있음 | `DLG-P003-작업취소확인` 표시 |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| primary / superAdmin | 모든 상품 등록 가능 |
| owner | 소속 지점 상품 등록 가능 |
| manager | 상품 편집 권한이 있는 경우 등록 가능 |
| trainer / fc / staff | 기본 조회만 가능. 별도 상품 편집 권한 없으면 진입 불가 |
| readonly | 진입 불가 |
