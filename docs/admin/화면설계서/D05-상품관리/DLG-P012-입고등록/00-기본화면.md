## 화면 목적

실물 상품의 입고 수량을 등록하는 모달입니다. 입고 처리 시 재고 수량이 자동으로 증가하며 입출고 이력에 기록됩니다.

---

## 주요 구성요소

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 상품명 | 자동 입력 | 입고 처리할 상품 (변경 불가) |
| 입고 수량 | 필수 | 입고할 개수 (1 이상) |
| 입고일 | 필수 | 실제 입고 날짜 (기본값: 오늘) |
| 공급처 | 선택 | 납품 업체명 |
| 메모 | 선택 | 특이사항 기록 |

하단 버튼: **취소** / **입고 등록**

---

## 언제 표시되나요

- SCR-P007(재고 관리) 목록에서 특정 상품의 "입고" 버튼을 클릭했을 때

---

## 주요 UX 흐름

1. 대상 상품명이 자동 입력된 상태로 모달 열림
2. 입고 수량, 입고일 입력
3. "입고 등록" 버튼 클릭
   - 수량 미입력 또는 0 이하 시: 안내 메시지
   - 정상 등록 시: 재고 수량 증가 + 이력 기록 + 모달 닫힘 + 완료 메시지
4. "취소" 클릭: 모달 닫힘

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
