# SCR-I008 키오스크운영현황 — 키오스크 연동

본 화면은 본사/지점 운영자가 등록된 키오스크 단말의 상태를 통합 모니터링하는 화면이다. 키오스크 측 KIO-402(관리자 패널)와 양방향 데이터로 연결된다.

## 양방향 데이터

| 방향 | 항목 | 키오스크 화면 |
|---|---|---|
| kiosk → admin | 단말 정보 (kioskId/branchId/version) | KIO-402 기기 정보 카드 |
| kiosk → admin | 온라인 상태/핑 결과 | KIO-402 연결 테스트 |
| kiosk → admin | 감사 로그 (PIN 진입/문열기/TTS/설정새로고침) | KIO-402 액션 |
| admin → kiosk | 원격 명령 (예: 강제 설정 새로고침, 원격 재기동) | KIO-402 |
| admin → kiosk | 단말 차단/활성 토글 | 모든 KIO 화면 |

## 본사 통합 모드 사용 사례

- 본사 운영자가 여러 지점의 단말 상태를 한 화면에서 모니터링.
- 단말 이상 시 admin 측에서 원격으로 설정 갱신 트리거.
- 감사 로그 일괄 조회 (어떤 단말에서 언제 문열기 액션이 있었는지 등).

## 단말 라이프사이클

```
[지점 신설] → admin/SCR-I002에 단말 등록 → kioskId 발급
        ↓
[단말 부팅] → admin/SCR-I008에 online 상태 보고
        ↓
[운영]      → 감사 로그 적재, 상태 핑
        ↓
[퇴역]      → admin에서 단말 비활성 → kiosk 동작 차단
```
