# SCR-I008 키오스크운영현황 — 범위 제외

본 화면은 관리자 CRM D11 구현 대상이 아니다.

키오스크 운영 현황, 단말별 장애 콘솔, 원격 재시작, 로그 다운로드, KIO-402 관리자 패널 연동은 KIOSK 기획문서에서 정의한다. D11은 키오스크 운영 화면을 별도로 만들지 않고, 키오스크에서 발생한 출석 이벤트와 상태 수신값만 SCR-I001 통합출석관리와 SCR-101 대시보드 통합에 표시한다.

## D11 반영 방식

| 표시 위치 | 표시 내용 | 허용 액션 |
|---|---|---|
| SCR-I001 통합출석관리 | 최근 키오스크 출석 이벤트, 실패 사유, 마지막 수신 시각 | 새로고침, 실패 로그 필터 |
| SCR-101 대시보드 통합 | 실시간 출석 확인 카드 | 회원 상세 이동 |
| NFR-19 알림 센터 | 키오스크/출입 게이트 오프라인 알림 | 알림 확인 |

## D11에서 금지되는 구현

- `/kiosk-ops` route
- 원격 재시작
- 로그 다운로드
- 기기 상세 모달
- 전사 키오스크 가동률 콘솔
