# SCR-I008 키오스크 운영 현황 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 기기 상태 heartbeat 연동은 후속 단계입니다.

## 1. 화면 목적

- 현장 키오스크 운영 상태를 확인한다.

## 2. 핵심 기능

- 장비 상태 확인
- 오프라인 경고
- 운영 안내 확인
- 상태 새로고침
- 원격 재시작
- 기기 상세 상태 확인

## 3. 주요 UX 흐름

1. 상단 요약 카드 클릭으로 상태별 기기 목록을 필터링한다.
2. `상태 새로고침` 버튼 클릭 시 최근 heartbeat 기준으로 마지막 신호와 장애 메모를 갱신한다.
3. 기기명 클릭 시 기기 상세 모달을 열어 운영 모드, 최근 신호, 장애 메모를 확인한다.
4. `원격 재시작` 버튼 클릭 시 확인 모달을 거쳐 상태를 정상으로 복구한다.

## 4. 퍼블리싱 포인트

- 정상보다 장애 상태가 먼저 강조되어야 한다.
