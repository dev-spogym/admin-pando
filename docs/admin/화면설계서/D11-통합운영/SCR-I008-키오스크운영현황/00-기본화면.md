# SCR-I008 키오스크 운영 현황 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 기기 상태 heartbeat 연동은 후속 단계입니다.

## 화면 목적

- 본 화면은 관리자 CRM D11 구현 대상이 아닙니다.
- 키오스크 운영 현황, 단말 장애 대응 콘솔, 원격 재시작, 로그 다운로드, KIO-402 관리자 패널 연동은 KIOSK 기획문서에서 정의합니다.
- D11은 별도 키오스크 운영 화면을 만들지 않고, 키오스크에서 발생한 출석 이벤트와 상태 수신값을 SCR-I001 통합 출석 관리에 표시합니다.

## 주요 구성요소

| 표시 위치 | 표시 내용 | 허용 액션 |
|---|---|---|
| SCR-I001 통합 출석 관리 | 최근 키오스크 출석 이벤트, 실패 사유, 마지막 수신 시각 | 새로고침, 실패 로그 필터 |
| SCR-101 대시보드 통합 | 실시간 출석 확인 카드 | 회원 상세 이동 |
| NFR-19 알림 센터 | 키오스크/출입 게이트 오프라인 알림 | 알림 확인, 담당자 지정 |

## 주요 UX 흐름

1. 키오스크 QR/RFID/얼굴인식 체크인 성공·실패 이벤트는 통합 출석 이벤트 스트림에 적재된다.
2. SCR-I001과 SCR-101은 해당 이벤트를 출석 테이블과 실시간 출석 확인 카드로 표시한다.
3. 키오스크 오프라인/오류 상태는 D11에서 배지만 표시하고, 복구 조작은 제공하지 않는다.

## 4. 퍼블리싱 포인트

- 정상보다 장애 상태가 먼저 강조되어야 한다.
- 최근 체크인 이벤트는 운영 현황용 카운트와 FC 동일인 확인용 카드가 같은 이벤트 원천을 사용해야 한다.

## 화면 상태

본 화면은 구현 대상이 아니므로 별도 화면 상태를 정의하지 않습니다.

## 계정별 차이

본 화면은 구현 대상이 아니므로 D11 권한을 정의하지 않습니다. 키오스크 단말 운영 권한은 KIOSK 기획문서를 따릅니다.
