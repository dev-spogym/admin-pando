# SCR-I008 키오스크 운영 현황 — 기본화면

> **퍼블리싱 현황**: 퍼블리싱 완료 / 데이터 미연동. 현재 UI는 목업·임시 데이터 기준이며 기기 상태 heartbeat 연동은 후속 단계입니다.

## 화면 목적

- 현장 키오스크 운영 상태를 확인한다.

## 주요 구성요소

- 장비 상태 확인
- 오프라인 경고
- 운영 안내 확인
- 상태 새로고침
- 원격 재시작
- 기기 상세 상태 확인
- 키오스크 체크인 이벤트를 SCR-101/SCR-I001 실시간 출석 확인 카드로 전달

## 주요 UX 흐름

1. 상단 요약 카드 클릭으로 상태별 기기 목록을 필터링한다.
2. `상태 새로고침` 버튼 클릭 시 최근 heartbeat 기준으로 마지막 신호와 장애 메모를 갱신한다.
3. 기기명 클릭 시 기기 상세 모달을 열어 운영 모드, 최근 신호, 장애 메모를 확인한다.
4. `원격 재시작` 버튼 클릭 시 확인 모달을 거쳐 상태를 정상으로 복구한다.
5. 키오스크 QR/RFID/얼굴인식 체크인 성공·실패 이벤트는 통합 출석 이벤트 스트림에 적재되어 대시보드와 출석 관리의 실시간 출석 확인 카드에 반영된다.

## 4. 퍼블리싱 포인트

- 정상보다 장애 상태가 먼저 강조되어야 한다.
- 최근 체크인 이벤트는 운영 현황용 카운트와 FC 동일인 확인용 카드가 같은 이벤트 원천을 사용해야 한다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 | 주요 카드·테이블 영역에 스켈레톤을 표시합니다. |
| 정상 | 조회 조건에 맞는 데이터를 표시하고 사용 가능한 액션을 노출합니다. |
| 빈 데이터 | 데이터가 없다는 안내와 필요한 경우 등록/초기화 액션을 표시합니다. |
| 처리 중 | 저장·삭제·내보내기 등 주요 액션 버튼을 비활성화합니다. |
| 오류 | 실패 사유와 재시도 방법을 화면 내 메시지로 안내합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 지점 전체 데이터를 조회하고 업무 액션을 수행할 수 있습니다. |
| trainer / fc / staff | 본인 담당 범위 또는 배정된 업무 데이터 중심으로 조회합니다. |
| readonly | 조회만 가능하며 생성·수정·삭제·확정 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 메뉴와 직접 URL 접근을 차단하고 권한 안내 화면으로 전환합니다. |
