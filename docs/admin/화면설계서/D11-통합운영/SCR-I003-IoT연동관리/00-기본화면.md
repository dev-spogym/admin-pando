## 화면 목적

D11은 IoT 장비를 등록·삭제·제어하는 독립 운영 화면을 제공하지 않습니다. D11에서 필요한 것은 통합 출석, 락커 운영, 체성분 화면에 표시할 상태값과 이벤트 수신값입니다.

## 주요 구성요소

### 고정 기기 종류

| 기기 종류 | D11에서 표시하는 값 | 표시 위치 |
|---|---|---|
| 출입 게이트 | 출입 성공/실패 이벤트, 온라인/오프라인/오류 상태, 마지막 통신 시각 | SCR-I001 |
| 키오스크 | 출석 체크인 성공/실패 이벤트, 온라인/오프라인/오류 상태, 마지막 통신 시각 | SCR-I001 |
| 락커 컨트롤러 | 락커 잠금/해제 결과, 온라인/오프라인/오류 상태 | SCR-I004, SCR-I005 |
| InBody 측정기 | 측정 사용자, 측정 시각, 체성분 값 | SCR-I006, SCR-I007 |

### D11에서 허용되는 액션

| 액션 | 설명 |
|---|---|
| 상태 새로고침 | 현재 화면에 표시 중인 상태 배지와 마지막 수신 시각만 갱신 |
| 최근 이벤트 조회 | 출석/락커/체성분 화면 안에서 최근 이벤트 조회 |
| 관련 화면 이동 | 회원 상세, 락커 상세, 체성분 상세 등 CRM 내부 화면으로 이동 |

## 계정별 차이

D11에는 독립 IoT 관리 화면 권한을 만들지 않습니다. 각 표시 위치의 화면 권한을 따릅니다.

## 주요 UX 흐름

1. 출석, 락커, 체성분 화면 진입 시 해당 화면에서 필요한 상태값과 최근 수신 시각을 표시한다.
2. 출입 게이트/키오스크 이벤트는 SCR-I001 출석 목록과 최근 이벤트 패널에 표시한다.
3. 락커 컨트롤러 상태는 SCR-I004/SCR-I005의 락커 상태 배지로 표시한다.
4. InBody 측정값은 SCR-I006/SCR-I007에서 측정 사용자와 체성분 값으로 표시한다.

## 화면 상태

| 상태 | 설명 |
|------|------|
| 상태 정상 | 표시 위치의 상태 배지 정상 |
| 상태 미수신 | 마지막 수신 시각과 "상태 확인 불가" 표시 |
| 오류 수신 | 오류 배지와 운영자 확인 안내 |
