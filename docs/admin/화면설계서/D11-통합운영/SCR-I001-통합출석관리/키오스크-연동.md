# SCR-I001 통합출석관리 — 키오스크 연동

본 화면(`통합출석관리`)은 키오스크·출입 게이트에서 발생한 출석 이벤트를 CRM에서 조회·확인하는 화면이다. 키오스크 설정과 출입 규칙의 원천은 D09-설정관리(SCR-082/SCR-082A/SCR-083)이며, 본 화면은 수신된 결과와 실패 사유를 표시한다.

## 키오스크 측 영향

| 키오스크 화면 | 영향받는 영역 |
|---|---|
| KIO-001 (대기) | 인증 수단 노출 / 직원 출석 허용 토글 |
| KIO-101 (QR) | 회원앱 발급 QR로 회원 식별 → 출석 |
| KIO-102 (RFID) | 카드 매핑(`SCR-052`) 통해 회원 식별 → 출석 |
| KIO-103 (얼굴 인식) | 정지 판정 후 인식 → 출석 |
| KIO-104 (전화번호) | 회원/직원 자동 분기 → 출석 / 직원 출퇴근 |
| KIO-105 (바코드) | 바코드 매핑 → 출석 |
| KIO-201 (출석 결과) | 성공/실패 분기, 회원 모달, 락커 후처리 진입 |

## 정책 흐름

| 결과 | 키오스크 처리 | admin 적재 |
|---|---|---|
| 성공 (회원) | 출입문 5초 개방 + 성공 TTS + 회원 모달 4초 | 출석 이력 + 락커 후처리 |
| 성공 (직원) | 직원 출퇴근 결과 모달 | `staffAttendance` |
| 만료 | 실패 화면 + 스태프 안내 (7초) | 운영 로그 |
| 미등록 | 실패 화면 + 재시도 안내 | 운영 로그 |
| 중복 (10분) | 실패 화면 + 잠시 후 재시도 | 운영 로그 |
| 미수금 | 정책에 따라 경고 또는 차단 | 운영 로그 |
| 직원 불가 | 직원 출석 허용 OFF 시 차단 | 운영 로그 |

## 키오스크가 본 화면에 의존하는 설정

- 중복 체크인 방지 시간 (기본 10분)
- 출입문 개방 시간 (기본 5초)
- 성공 모달 자동 복귀 시간 (기본 4초)
- 실패 화면 자동 복귀 시간 (기본 7초)
- 미수금 처리 정책 (경고 / 차단)
- 직원 출석 허용 여부

위 값들은 D09-설정관리의 `SCR-082-키오스크설정`, `SCR-082A-키오스크IoT설정`, `SCR-083-IoT출입관리`에서 설정한다.

## 본사 통합 모드 영향

본사 계정이 `전체 지점(통합)`을 선택한 경우 — 키오스크는 단말이 속한 단일 지점에서만 동작하므로 본사 통합 모드의 영향을 받지 않는다. 본사 운영자가 출석 이력을 통합 조회할 때는 admin/SCR-I001에서 본다.

## 회원앱과의 데이터 공유

- 회원이 키오스크에서 출석한 결과는 회원앱(`client/SCR-MA-111-출석이력`)에서도 즉시 조회 가능해야 한다.
- 데이터 원천은 admin 단일이며, 키오스크와 회원앱은 동일 출석 이력을 다른 채널에서 표시할 뿐이다.
