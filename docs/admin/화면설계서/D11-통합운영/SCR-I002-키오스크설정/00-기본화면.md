## 화면 목적

본 화면은 관리자 CRM D11 구현 대상이 아닙니다.

키오스크 설정 화면은 D09-설정관리의 `SCR-082-키오스크설정`, `SCR-082A-키오스크IoT설정`, `SCR-083-IoT출입관리`에서만 관리합니다. 키오스크 단말 내부 운영 화면, 관리자 패널, 단말 운영 콘솔은 KIOSK 기획문서에서 정의합니다.

## 주요 구성요소

| 구분 | 기준 |
|---|---|
| 설정 책임 | D09-설정관리 |
| 키오스크 운영 화면 | KIOSK 기획문서 |
| D11 허용 범위 | 출석/락커 화면에서 키오스크 이벤트와 상태 수신값 표시 |
| D11 금지 범위 | 키오스크 설정 탭, TTS 설정, 화면 설정, 출입 규칙 설정, 단말 연결 테스트, 설정 push |

## 계정별 차이

본 화면은 구현 대상이 아니므로 D11 권한을 정의하지 않습니다. D09 설정 화면의 권한 기준을 따릅니다.

## 주요 UX 흐름

D11에서는 제공하지 않습니다.

## 화면 상태

본 화면은 구현 대상이 아니므로 화면 상태를 정의하지 않습니다.

## 연계 기능 기준

- IoT-08: [IoT-08-키오스크설정](../../../기능명세서/D11-통합운영/IoT-08-키오스크설정/00-기본기능.md) — D11 구현 제외 기준 문서

구현 시 본 화면을 D11 route로 만들지 않습니다. 키오스크 설정은 D09 문서를 기준으로 구현합니다.

## 관련 다이어그램

- D09 SCR-082/SCR-082A/SCR-083: 키오스크/IoT 설정 기준
- SCR-I001: 통합 출석 관리 (키오스크 출석 이벤트 표시)
- SCR-I004: 옷 락커 운영 관리 (키오스크 출석 후 락커 배정 결과 표시)
