# SCR-I002 키오스크설정 — 범위 제외

본 화면은 관리자 CRM D11 구현 대상이 아니다.

키오스크 설정은 D09-설정관리의 `SCR-082-키오스크설정`, `SCR-082A-키오스크IoT설정`, `SCR-083-IoT출입관리`에서 관리한다. 키오스크 단말 운영 화면과 단말 관리자 패널은 KIOSK 기획문서에서 정의한다.

## D11에서 허용되는 연동

| D11 화면 | 허용 범위 |
|---|---|
| SCR-I001 통합출석관리 | 키오스크 출석 성공/실패 이벤트, 채널, 실패 사유 표시 |
| SCR-I004 옷락커운영관리 | 키오스크 출석 후 락커 배정 결과 표시 |

## D11에서 금지되는 구현

- 키오스크 설정 탭
- TTS 설정
- 화면 설정
- 출입 규칙 설정
- 설정 새로고침 push
- 단말 연결 테스트와 원격 제어
