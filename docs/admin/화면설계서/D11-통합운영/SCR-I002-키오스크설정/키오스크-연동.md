# SCR-I002 키오스크설정 — 키오스크 연동

본 화면은 키오스크 단말 단위 운영 설정의 **단일 진입점**이다. 키오스크는 부팅 시 또는 관리자 액션 `설정 새로고침`(KIO-402 → ADM-03-01) 시 본 화면의 값을 가져와 적용한다.

## 키오스크 측 영향

| 설정 묶음 | 키오스크 영향 |
|---|---|
| 메뉴 노출 토글 | KIO-001/KIO-301에서 보조 카드 노출 여부 |
| 인증 수단 사용 여부 | KIO-101 ~ KIO-105 진입 가능 여부 |
| 직원 출석 허용 | KIO-104 직원 분기 차단 여부 |
| 얼굴 인식 정책 | KIO-001/KIO-103 캠 동작, 정지 판정 시간 |
| 락커 후처리 분기 | KIO-201 → KIO-202/203/204 분기 결정 |
| 락커 번호 전달 방식 | 영수증 / 앱 / 신발장 밴드 중 1택 |
| 골프 예약 활성 | KIO-501 ~ KIO-504 진입 가능 여부 |
| 주차 등록 정책 | KIO-601 분기 (안내 / 외부링크 / 프런트호출) |
| 공지 텍스트 | KIO-001 배너, KIO-305 공지 본문 |
| 영수증/앱/신발장 실패 시 대체 | 전달 실패 시 fallback 흐름 |

## 키오스크가 요구하는 신규 설정 항목

키오스크 기획 진행 중 본 화면에 신규로 추가되어야 할 항목.

| 코드 | 항목 | 키오스크 화면 영향 | 우선순위 |
|---|---|---|---|
| ka.face.stillSec | 얼굴 인식 정지 판정 시간 (1~3초) | KIO-103 | P0 |
| ka.locker.deliveryMode | 락커 번호 전달 방식 (`receipt`/`app`/`band`) | KIO-202/203/204 분기 | P1 |
| ka.locker.fallbackMode | 전달 실패 시 대체 방식 | KIO-202/203/204 예외 | P1 |
| ka.locker.receipt.text | 영수증 출력 문구 / 재출력 허용 여부 | KIO-202 | P1 |
| ka.locker.app.text | 앱 안내 문구 / 미연동 예외 처리 | KIO-203 | P1 |
| ka.locker.band.policy | 동일번호 정책, 밴드 분실/누락 예외 | KIO-204 + SCR-052 연동 | P1 |
| ka.golf.kiosk | 골프 키오스크 채널 활성 | KIO-501 ~ KIO-504 | P2 |
| ka.parking.mode | 주차 등록 처리 방식 (`guide`/`external_link`/`staff_call`) | KIO-601 | P3 |
| ka.parking.text | 주차 버튼 라벨/안내 문구/외부 링크 | KIO-601 | P3 |
| ka.menu.shop | 매점 메뉴 토글 | KIO-001/KIO-301 | P5 |

## 설정 적용 흐름

```
[admin/SCR-I002 변경]
        ↓ (저장 시 push 또는 키오스크 polling)
[kiosk 단말이 새 설정 수신]
        ↓
[로컬 캐시 갱신 + 화면 반영]
        ↓
[관리자 액션 ADM-03-01 '설정 새로고침'으로도 강제 갱신 가능]
```

설정 수신 실패 시 마지막 캐시 값을 사용하고, 캐시도 없으면 안전 기본값(보조 메뉴 모두 숨김)으로 동작한다.

## 단말 단위 vs 지점 단위

- **단말 단위**: 얼굴 인식, 인증 수단, 메뉴 노출 등 (단말마다 다를 수 있음)
- **지점 단위**: 출석 정책, 직원 출퇴근 허용, 골프/주차 정책, 공지 (지점 모든 키오스크 공통)
