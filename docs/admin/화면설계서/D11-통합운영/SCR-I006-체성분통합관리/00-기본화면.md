## 화면 목적

전체 회원의 체성분 측정 현황을 통합 관리한다. 관리자 CRM은 InBody 측정기를 제어하지 않고, InBody API로 수신된 측정 사용자와 체성분 정보값을 조회·검수·확정 처리한다. 수기 등록은 현장 입력 보조 수단이며, 장비 파일 업로드와 장비 설정은 본 화면 범위에서 제외한다.

## 주요 구성요소

### 상단 현황 카드

| 항목 | 설명 |
|------|------|
| 오늘 측정 건수 | 금일 체성분 측정 완료 건수 |
| 검수 대기 | 매칭 실패·중복·이상치로 검수 필요한 건수 |
| 미확정 | 수집됐지만 아직 확정 처리되지 않은 건수 |
| InBody 수신 상태 | 최근 API 수신 시각과 수신 성공/지연 상태 |

### 탭 구조

| 탭 | 설명 |
|----|------|
| 측정 결과 | 확정된 체성분 결과 목록 및 상세 조회 |
| 수신 로그 | InBody API로 수신된 측정 데이터와 처리 상태 확인 |
| 오류/검수 | 중복·회원 매칭 실패·값 이상치 건 검수 처리 |

### 측정 결과 탭 테이블

| 컬럼명 | 설명 |
|--------|------|
| 측정일시 | 체성분 측정 완료 시각 |
| 회원명 | 측정 회원 이름 |
| 체중 | 측정 체중 (kg) |
| 골격근량 | 골격근량 (kg) |
| 체지방률 | 체지방 비율 (%) |
| BMI | 체질량지수 |
| 입력 채널 | 수기 / InBody API |
| 확정 여부 | 확정 / 미확정 배지 표시 |

### 오류/검수 탭 항목

| 항목 | 설명 |
|------|------|
| 오류 유형 | 회원 매칭 실패 / 중복 / 값 이상치 |
| 수집 시각 | 데이터 수신 시각 |
| 원본 값 | 수집된 원본 측정값 |
| 처리 | 회원 직접 매칭 / 무시 / 확정 처리 |

#### 검수 처리 기준

검수 처리는 InBody API 수신값 또는 수기 입력값이 바로 회원 이력으로 확정되기 어려운 경우 관리자가 확인하는 workflow입니다.

| 검수 유형 | 발생 조건 | 기본 처리 |
|---|---|---|
| 회원 매칭 실패 | InBody 수신값의 회원 식별 정보가 기존 회원과 일치하지 않음 | 회원 직접 매칭 또는 무시 |
| 중복 의심 | 동일 회원, 동일 측정일시, 주요 수치가 동일하거나 5분 이내 반복 수신 | 기존 데이터 유지, 신규 데이터 무시 또는 별도 확정 |
| 값 이상치 | 체중 20~300kg, 골격근량 5~80kg, 체지방률 3~60% 범위를 벗어남 | 관리자 확인 후 확정 또는 무시 |
| 미확정 수기 입력 | 스태프 또는 강사가 입력했으나 관리자 확인이 필요한 정책 | 관리자 확정 |

처리 액션은 다음 세 가지로 제한합니다.

| 액션 | 결과 |
|---|---|
| 회원 직접 매칭 | 선택한 회원의 체성분 이력으로 연결하고 `확정 대기` 또는 `확정` 상태로 전환 |
| 무시 | 원본 데이터는 보관하되 회원 이력에는 반영하지 않음 |
| 확정 처리 | 회원 건강 요약 및 회원 상세 체성분 이력에 노출 |

검수 처리 이력은 처리자, 처리 시각, 처리 전 상태, 처리 후 상태, 사유를 남깁니다.

### 버튼

| 버튼 | 설명 |
|------|------|
| 수기 등록 | DLG-I003 팝업 호출, 수기 체성분 입력 |
| 수신 로그 | InBody API 수신 로그 탭으로 이동 |
| 확정 처리 | 검수 완료 항목을 확정 상태로 변경 |
| 회원 상세 이동 | 해당 행 회원 상세 화면으로 이동 |

## 계정별 차이

| 계정 유형 | 차이 |
|-----------|------|
| 센터 관리자 | 전체 탭 접근, 검수 처리, 수기 등록 가능 |
| 스태프 | 측정 결과 조회 및 수기 등록 가능, 검수 처리는 관리자만 가능 |
| 강사 | 담당 회원의 측정 결과 조회만 가능 |

## 주요 UX 흐름

1. 화면 진입 → 측정 결과 탭 기본 표시
2. 검수 대기 카드 클릭 → 오류/검수 탭 자동 이동
3. 수기 등록 버튼 → DLG-I003 팝업 → 회원 선택 → 수치 입력 → 저장
4. 수신 로그 탭: InBody API 수신값의 측정 사용자·측정 시각·체성분 값을 확인
5. 오류/검수 탭: 오류 항목 선택 → 회원 매칭 또는 무시 → 확정
6. 측정 결과 행 클릭 → 해당 회원 상세 화면으로 이동

## 화면 상태

| 상태 | 설명 |
|------|------|
| 기본(데이터 있음) | 측정 결과 테이블 정상 표시 |
| 검수 대기 있음 | 검수 탭 배지 수치 강조 |
| InBody 수신 지연 | 최근 수신 시각 경고 표시 |
| 빈 상태 | '측정 데이터가 없습니다.' 안내 |
| 검수 항목 없음 | '검수할 데이터가 없습니다.' 안내 |
