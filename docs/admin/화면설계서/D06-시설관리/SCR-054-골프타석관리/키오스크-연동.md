# SCR-054 골프타석관리 — 키오스크 연동

본 화면은 골프 타석 운영의 원천이다. 키오스크는 본 화면의 데이터를 회원용 셀프 예약 채널로 축약 표시한다. 회원앱(`client/SCR-MA-123-골프예약상세`)과 동일 데이터 원천을 공유한다.

## 채널 위치

| 채널 | 역할 |
|---|---|
| `admin/SCR-054` | 운영자 직접 편집 (정책 원천) |
| `client/SCR-MA-123` | 회원이 휴대폰에서 셀프 예약 |
| `kiosk/KIO-501 ~ 504` | 회원이 입구 단말에서 빠른 셀프 예약/대기 등록 |

세 채널은 동일 데이터 원천을 다른 UX로 노출한다.

## 키오스크 측 영향

| 키오스크 화면 | 사용 데이터 |
|---|---|
| KIO-501 (진입) | 회원 골프 이용권 보유 여부, 중복 예약 검증 |
| KIO-502 (날짜/시간) | 운영 시간대, 시간 단위(30분/1시간), 잔여 슬롯 |
| KIO-503 (타석 선택) | 타석 그리드, 사용가능/예약/점검/대기 상태 |
| KIO-504 (예약 완료) | 예약 일시/타석/상태 |

## 키오스크 → admin 적재

| 이벤트 | admin 처리 |
|---|---|
| 키오스크 예약 확정 | 본 화면 즉시 반영 + 알림 |
| 키오스크 대기 등록 | 본 화면 대기열에 push |
| 동일 시간대 중복 차단 | admin/회원앱 모두에서 차단되어야 함 (단일 검증) |

## 대기열 자동 승격

대기열 자동 승격은 **admin 정책**을 따르며, 키오스크는 결과만 표시한다. 즉, 키오스크는 자체적으로 대기열을 관리하지 않는다.

승격 시 알림 흐름:
1. admin/SCR-054에서 빈 자리 발생
2. 대기열 1순위 자동 승격
3. 회원에게 알림 (회원앱 푸시 + 키오스크 다음 진입 시 KIO-303에 표시)

## 키오스크가 요구하는 본 화면 보강

| 항목 | 필요 사항 |
|---|---|
| 키오스크 채널 표시 | 예약 행 메타에 `via=kiosk` 라벨 표시 |
| 시간 단위 | 30분 / 1시간 토글 (지점별) |
| 키오스크 채널 예약 차단 | 운영자가 키오스크 채널만 일시 차단 가능 (점검 시) |
