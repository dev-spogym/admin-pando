## 화면 목적

센터에서 실제로 보유한 일반 재고 물품의 수량을 관리하는 화면입니다. 관리 대상은 운동복, 수건, 세제, 소모품, 판매용 용품 등 센터가 실물로 보유하고 수량 확인이 필요한 품목입니다.

D05 상품관리의 `운동복` 상품은 회원에게 청구하는 운동복 대여비/상품 비용을 등록하는 결제용 상품입니다. D05에서 운동복 상품이 판매되거나 결제되어도 본 화면의 재고 수량은 자동 차감하지 않습니다. 실제 재고 수량 증감은 본 화면에서 입고, 출고, 조정으로만 처리합니다.

회원별 운동복 대여·반납, 세탁중, 파손, 복구 상태 관리는 v1 범위에서 사용하지 않습니다. 운동복도 본 화면에서는 일반 재고 품목 중 하나로만 관리합니다.

## 주요 구성요소

- **현황 요약 카드**: 전체 품목 수 / 정상 재고 품목 수 / 부족 재고 품목 수 / 품절 품목 수를 표시합니다.
- **상태 탭**: 전체 · 정상 · 부족 · 품절 탭으로 필터링하고 각 탭에 건수를 표시합니다.
- **검색창**: 품목명, 품목 코드, 분류명으로 검색합니다.
- **상품 재고 목록 테이블**:
  - 표시 항목: 품목명 / 분류 / 현재 수량 / 안전 재고 / 재고 상태 / 최근 입고일 / 최근 출고일 / 담당자 / 액션.
  - 액션 버튼: [입고] [출고] [조정] [이력].
- **품목 등록 버튼**: 신규 재고 품목을 추가합니다.
- **엑셀 다운로드**: 현재 필터 결과 기준으로 재고 현황을 엑셀로 내려받습니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| superAdmin / primary | 전체 지점 재고 목록 | 품목 등록·입고·출고·조정·이력 조회·엑셀 다운로드 |
| owner / manager | 소속 지점 재고 목록 | 품목 등록·입고·출고·조정·이력 조회·엑셀 다운로드 |
| fc / trainer / staff / readonly | 재고 현황 조회 | 변경 불가 |

## 주요 UX 흐름

1. 화면 진입 시 소속 지점의 전체 재고 품목 목록이 표시됩니다.
2. 상태 탭 또는 검색창으로 원하는 품목을 찾습니다.
3. [입고] 클릭 → 입고 수량, 입고일, 단가, 거래처, 비고 입력 → 현재 수량 증가.
4. [출고] 클릭 → 출고 수량, 출고 사유, 출고일, 비고 입력 → 현재 수량 감소.
5. [조정] 클릭 → 실사 후 실제 수량과 조정 사유 입력 → 현재 수량 보정.
6. [품목 등록] 클릭 → 품목명, 분류, 단위, 안전 재고, 메모 입력 → 저장.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 테이블 로딩 상태 표시 |
| 정상 | 현재 수량이 안전 재고 이상 |
| 부족 | 현재 수량이 안전 재고보다 낮고 0보다 큼 |
| 품절 | 현재 수량이 0 |
| 빈 상태 | "등록된 재고 품목이 없습니다" 안내 |
| 처리 중 | 입고·출고·조정 저장 중 버튼 로딩 |

## 예외 / 에러 처리

| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 품목 미등록 | "등록된 재고 품목이 없습니다" + [품목 등록] CTA | 등록 안내 |
| 품목명 중복 | 인라인 "동일 품목명이 이미 존재합니다" | 저장 차단 |
| 출고 수량 > 현재 수량 | 인라인 "현재 수량보다 많이 출고할 수 없습니다" | 저장 차단 |
| 출고 사유 미입력 | 인라인 "출고 사유를 선택해주세요" | 저장 차단 |
| 재고 조정 사유 미입력 | 인라인 "조정 사유를 입력해주세요" | 저장 차단 |
| 안전 재고 미설정 | 부족 알림 미발송 + 노랑 안내 | 저장 가능 |
| 권한 부족 | 입고·출고·조정·등록 버튼 hidden | - |
| 동시 수정 충돌 | "다른 사용자가 먼저 수정했습니다" | 최신 값 재로드 |
