# SCR-050 락커관리 — 키오스크 연동

본 화면은 락커 풀(자동 배정 존, 가용 락커, 유효기한)의 운영 원천이다. 키오스크는 출석 후처리에서 본 화면의 락커 풀을 사용한다.

## 키오스크 측 영향

| 키오스크 화면 | 사용 데이터 |
|---|---|
| KIO-201 (출석 결과) | 자동 배정 시도 → 가용 락커 검색 → 배정 |
| KIO-202 (영수증 출력) | 배정된 락커 번호 출력 |
| KIO-204 (신발장 밴드) | 신발장 번호 = 옷락커 번호 매핑 사용 |
| KIO-304 (락커 조회) | 회원의 오늘 배정 락커 표시 |

## 자동 배정 정책

| 항목 | 기본값 | 설정 위치 |
|---|---|---|
| 자동 배정 존 | A, B | SCR-I002 |
| 자동 배정 우선순위 | 회원 등급/이력 기반 | SCR-050 정책 |
| 자동 배정 실패 시 | 수동 배정 안내 | KIO-201 분기 |

## 락커 번호 전달 방식 영향

키오스크에서 결정되는 락커 번호 전달 방식(영수증/앱/신발장 밴드)은 본 화면의 락커 풀과 함께 동작해야 한다.

- **영수증 방식**: 단순 번호 출력 → 본 화면 영향 없음
- **앱 방식**: 회원 식별 필요 → 본 화면의 회원 ↔ 락커 매핑이 그대로
- **신발장 밴드 방식**: 신발장 번호 = 옷락커 번호 1:1 매핑이 본 화면 정책에 추가되어야 함 (`SCR-052` 밴드 재고와 결합)

## 본사 통합 모드 영향

본사 계정이 통합 조회 시 — 키오스크는 단말 지점의 락커 풀만 사용한다. 본 화면에서 본사 통합 조회 시에도 키오스크 단위 데이터는 단일 지점이다.
