# SCR-052 밴드카드관리 — 키오스크 연동

본 화면은 RFID 카드/밴드와 회원의 매핑을 관리한다. 키오스크는 두 곳에서 본 데이터를 사용한다.

## 키오스크 측 영향

### 1. KIO-102 RFID 체크인

| 항목 | 처리 |
|---|---|
| 카드 인식 | 리더기 태그 → 카드 ID 추출 |
| 회원 매핑 조회 | 본 화면의 매핑 테이블 |
| 매핑 없음 | 실패 처리 + 재시도 |
| 회원 식별 성공 | KIO-201 출석 결과로 진입 |

### 2. KIO-204 신발장 밴드 수령

신발장 밴드 수령 방식을 사용하는 센터에서는 `신발장 번호 = 밴드 번호 = 옷락커 번호` 1:1 매핑이 필수다. 본 화면이 밴드 재고/분실/반납 누락을 추적해야 키오스크의 신발장 밴드 분기가 정상 동작한다.

| 운영 상황 | 본 화면에 필요한 처리 |
|---|---|
| 밴드 분실 | 해당 번호 즉시 배정 불가 처리 |
| 미반납 | 회원 메모 + 다음 배정 차단 |
| 회수 후 정상화 | 재배정 가능 상태로 복원 |

## 키오스크가 요구하는 본 화면 보강

| 항목 | 필요 사항 |
|---|---|
| 동일번호 정책 토글 | 신발장-밴드-옷락커 1:1 적용 여부 (지점별) |
| 분실 사유 입력 | 분실/파손/회수 |
| 키오스크 자동 배정 차단 표시 | 배정 불가 상태가 키오스크 분기에 즉시 반영 |
