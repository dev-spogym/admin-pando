## 화면 목적

처리된 환불 내역과 승인대기 환불 요청을 조회하고 통계를 확인하는 화면입니다. 이번 달 환불 총액·건수·평균 환불액·위약금 합계를 파악하고, 기간별로 환불 이력을 조회합니다. 환불 사유와 처리 상태, 승인자, 쿠폰/마일리지 복원 여부, 원판매 담당자별 환불 책임 현황을 함께 확인할 수 있어 고객 불만 패턴 파악 및 환불 정책 점검에 활용합니다. 지점장(owner)은 이 화면에서 승인대기 건을 확인하고 승인/반려 또는 상세 처리로 이동할 수 있습니다.

## 주요 구성요소

- **요약 지표 카드 (4개)**: 이번 달 환불 총액 / 환불 건수 / 평균 환불액 / 위약금 합계를 상단에 표시합니다.
  - 위약금 합계: 조회 기간 내 환불 건에서 공제된 위약금 총액을 표시합니다.
- **날짜 필터**: 이번 달·지난 달·최근 3개월 프리셋 버튼과 시작일~종료일 직접 입력, 조회 버튼을 제공합니다.
- **환불 목록 테이블**: No / 요청일 / 환불일 / 회원명 / 상품명 / 환불금액 / 차감금 / 위약금 / 실환불액 / 환불방법 / 결제경로 / 원결제ID / 결제지점 / 이용지점 / 매출 귀속 지점 / 정산 지점 / 인센티브 귀속자 / 사유 / 요청자 / 승인자 / 쿠폰·마일리지 복원 / 상태 컬럼을 제공합니다.
  - 환불금액: 붉은색으로 강조 표시합니다.
  - 상태 배지: 요청(회색) / 승인대기(노랑) / 완료(초록) / 반려·거절(빨강) 색상으로 구분합니다.
  - 사유: 작은 글씨의 보조 텍스트로 표시합니다.
- **원판매 담당자별 환불 책임 탭**: 환불 처리자와 별도로 원매출 판매 귀속 담당자별 환불 건수, 환불 금액, 위약금 합계, 원매출 대비 환불률을 표시합니다.
- **엑셀 내보내기**: 현재 조회된 환불 내역 전체를 엑셀 파일로 내려받습니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 지점 매출 조회·분석 가능 | 기간 조회, 엑셀 내보내기 |
| 센터장 | 소속 지점 매출 전체 | 기간 조회, 엑셀 내보내기, 승인대기 건 승인/반려, 환불 상세 처리 |
| 매니저 | 소속 지점 매출 전체 | 기간 조회, 엑셀 내보내기, 환불 요청 상태 확인 |
| FC | 담당 회원 결제 처리 가능 | 조회만 가능 |
| 트레이너 / 스태프 | 매출 조회만 (처리 불가) | 조회만 가능 |

## 주요 UX 흐름

1. 사이드바에서 "매출관리 > 환불 관리"를 클릭해 진입합니다.
2. 상단 지표 카드로 이번 달 환불 현황과 위약금 회수 규모를 파악합니다.
3. 날짜 프리셋 또는 직접 입력으로 조회 기간을 설정하고 "조회" 버튼을 누릅니다.
4. 테이블에서 환불 이력·사유·처리 상태·승인자·쿠폰/마일리지 복원 상태를 확인합니다.
5. 지점장(owner)은 승인대기 건에서 [승인], [반려], [상세 처리] 중 하나를 선택합니다.
6. 원판매 담당자별 환불 책임 탭에서 특정 담당자에게 환불이 집중되는지 확인합니다.
7. 필요 시 엑셀 버튼으로 내역을 파일로 저장합니다.

## 비즈니스 규칙

- 환불 목록의 `처리자`는 환불 승인 또는 환불 처리 담당자를 의미합니다.
- `원판매 담당자`는 원결제의 판매 귀속 담당자이며, `[매출종합]` 회원권·락카 K열 `담당자`, 강습·골프 K열 `등록강사`를 기준으로 합니다.
- 담당자별 환불 책임 지표는 처리자 기준이 아니라 원판매 담당자 기준으로 집계합니다.
- 환불 행과 원매출 행의 공식 연결 키는 원거래ID 또는 카드 승인번호입니다.
- 원거래ID 또는 승인번호가 없는 환불 행은 회원명+종목+등록일+금액 조합으로 자동 확정하지 않고, 다중 후보 검수 대상으로 분리합니다.
- 차감금과 위약금은 환불금액과 별도로 보존하며, 실환불액은 고객에게 실제 지급된 금액으로 분리 표기합니다.
- 환불 보고서는 원결제에 저장된 `paymentBranchId`, `usageBranchId`, `salesAttributionBranchId`, `settlementBranchId`, `incentiveOwnerId`를 상속해 조회하며, 환불 처리 과정에서 조정된 값이 있으면 환불 레코드 값을 우선 표시합니다.
- 환불 자동 계산 산식은 미확정이므로, 이 화면은 SAL-EXT-04에서 저장된 수기 입력값을 그대로 표시하고 자동 재계산하지 않습니다.
- manager/fc가 요청한 환불은 승인대기 상태로 표시하며, 실제 환불 완료는 지점장(owner) 승인 또는 owner 직접 처리 후에만 가능합니다.
- 환불 완료 시 결제에 사용한 마일리지(포인트)를 우선 복원하고, 사용 쿠폰은 미사용 상태로 복원합니다. 복원 결과는 환불 목록과 상세 모달에서 확인할 수 있어야 합니다.
