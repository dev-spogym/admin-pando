## 목적

환불 요청이 접수된 건에 대해 환불 금액과 사유를 확정하고 처리를 완료합니다. 전체 환불 또는 부분 환불을 선택할 수 있으며, 처리 내용은 이력으로 저장됩니다. 환불 계산 로직 자체는 SCR-S012(결제 취소 / 부분 환불)의 계산 규칙을 그대로 따릅니다. 클라이언트 정책이 확정되지 않은 계산 항목은 SCR-S012와 동일하게 수기 입력·조정 사유 기록 방식으로 우선 처리합니다.

## 구성요소

| 구성요소 | 내용 |
|---|---|
| 원 매출 정보 | 환불 대상 매출 번호, 결제일, 상품명, 결제 금액 (읽기 전용) |
| 환불 계산 요약 | 기사용 차감금, 위약금, 기환불 누계, 환불 가능액 요약 |
| 환불 가능액 조정 | 처리 담당자가 이번 환불 가능액을 조정하고 사유를 기록 |
| 정책 미확정 수기 입력 | 기사용 차감금, 위약금, 기환불 누계, 외부 처리 상태, 승인 메모를 수기로 기록 |
| 환불 유형 선택 | 전체 환불 또는 부분 환불 중 선택 |
| 환불 금액 입력 | 부분 환불 선택 시 환불할 금액 직접 입력 (전체 환불 시 자동 입력) |
| 환불 사유 선택 | 사전 정의된 사유 목록에서 선택 (고객 변심, 서비스 불만, 중복 결제 등) |
| 사유 직접 입력 | 목록에 없는 경우 직접 입력 가능 |
| 환불 수단 | 환불 방법 선택 (원결제 수단 환불, 현금, 포인트 등) |
| 처리 확인 버튼 | 입력 내용으로 환불 처리 실행 |
| 취소 버튼 | 처리를 중단하고 이전 화면으로 복귀 |

## 언제 표시되나요

- DLG-S015(환불 요청)에서 처리 담당자가 승인 후 환불 처리로 진행할 때
- SCR-S007(환불 관리) 목록에서 미처리 건의 처리 버튼을 클릭했을 때
- DLG-S001(매출 상세)에서 환불 버튼을 클릭했을 때

## 주요 흐름

1. 환불 대상 매출 건을 선택하고 환불 처리 버튼을 누릅니다.
2. 환불 처리 다이얼로그가 열리며 원 매출 정보가 표시됩니다.
3. SCR-S012와 동일한 계산 규칙으로 산출된 환불 계산 요약을 확인합니다.
4. 환불 유형(전체/부분)을 선택합니다.
5. 환불 금액, 사유, 환불 수단을 입력합니다.
6. 처리 확인 버튼을 눌러 환불을 완료합니다.
7. 처리 완료 후 DLG-S014(환불 상세 결과)가 자동으로 표시됩니다.

## 비즈니스 규칙

- 계산 로직은 이 다이얼로그에 중복 정의하지 않고 SCR-S012의 환불 계산 박스를 참조합니다.
- 환불 처리 담당자는 환불 가능액을 조정할 수 있으며, 조정 사유를 반드시 남깁니다.
- 최종 환불 금액은 확정된 환불 가능액을 초과할 수 없습니다.
- `INSTALLMENT` 건은 남은 미수금 상계 후 최종 환불액을 확정합니다.
- 사용분 차감 기준, 위약금 산식, 혼합결제 환불 순서, 승인 조건, 귀속 차감 기준이 확정되지 않은 경우 자동 계산으로 단정하지 않고 수기 입력값과 메모를 이력에 남깁니다.
