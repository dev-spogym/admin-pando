## 화면 목적

새로운 할부 결제 계약을 등록합니다. 할부 기간, 월 납입액, 첫 납입일을 설정하여 회원이 상품 대금을 정기 분할 납입할 수 있는 계획을 수립합니다. 동일일자 복합결제, 현장 계약금 수납, 링크 결제 발송은 이 다이얼로그 범위가 아니며, 이 화면은 `잔액 기준 정기 분납 계획`만 다룹니다.

## 주요 구성요소

| 구성요소 | 내용 |
|---|---|
| 회원 정보 | 할부 계약 대상 회원 이름, 연락처 (읽기 전용) |
| 상품 정보 | 할부 구매할 상품명, 정가 (읽기 전용) |
| 총 할부 금액 | 선납금을 제외하고 앞으로 할부로 납입할 잔액 기준 금액 입력 |
| 할부 기간 | 납입 회차 수 선택 (예: 3, 6, 12개월) |
| 월 납입액 | 총 금액 ÷ 기간으로 자동 계산되어 표시 |
| 첫 납입일 | 첫 번째 납입 예정일 선택 |
| 납입 일정 미리보기 | 회차별 납입 예정일 및 금액 목록 |
| 등록 버튼 | 설정한 내용으로 할부 계약 등록 |
| 취소 버튼 | 등록을 취소하고 이전 화면으로 복귀 |

## 언제 표시되나요

- SCR-S002(POS 판매) 또는 SCR-S009(할부 결제 관리)에서 할부 등록 버튼을 클릭했을 때
- 결제 처리 화면에서 잔액을 `정기 분납 계획`으로 전환했을 때

## 주요 UX 흐름

1. POS 판매 화면 또는 할부 결제 관리 화면에서 할부 등록을 선택합니다.
2. 할부 등록 다이얼로그가 열립니다.
3. 잔액 기준 총 할부 금액, 할부 기간, 첫 납입일을 입력합니다.
4. 월 납입액과 납입 일정 미리보기가 자동으로 계산되어 표시됩니다.
5. 내용을 확인하고 등록 버튼을 눌러 할부 계약을 생성합니다.
6. 등록 완료 후 SCR-S009(할부 결제 관리) 목록에서 확인할 수 있습니다.

## 비즈니스 규칙

- 이 다이얼로그는 `정기 분납 계획`만 등록합니다. 당일 계약금 수납과 미수금 생성은 SCR-S003에서 먼저 확정되어야 합니다.
- 총 할부 금액은 원결제 총액이 아니라 선납금과 할인 반영 후 남은 잔액 기준입니다.
- 기존 미수금 건을 정기 분납 계획으로 전환하는 경우 원결제ID 연결이 필수입니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
