## 화면 목적

POS 판매 화면(SCR-S002)에서 장바구니에 담은 상품을 현장 판매로 확정하는 화면입니다. 실제 카드/현금/계좌이체 결제는 인포데스크(FC)가 외부 POS 또는 현장 수납 절차에서 먼저 완료하고, CRM에서는 혼합결제 행, 포인트 사용액, 결제일시, 영수증 파일, VAN/POS 승인 결과, 지점 귀속 필드를 등록해 정상 결제와 회원/이용권 등록을 확정합니다. CRM은 현장 카드 PG 승인을 직접 수행하지 않으며, 비대면 고객을 위한 결제링크 발송 경로(PAY-06)는 별도로 유지합니다.

## 주요 구성요소

- **결제 상품 목록 (좌측)**: POS에서 담아온 상품명·수량·소계를 목록으로 표시하고, 하단에 총 결제 금액을 크게 표시합니다.
- **회원 검색 (좌측)**: 포인트를 사용하거나 회원/이용권을 등록하는 결제에서는 회원 지정이 필수입니다. 이름 또는 전화번호로 검색해 회원을 선택하면 보유 포인트가 표시됩니다. 선택된 회원은 X 버튼으로 해제할 수 있습니다.
- **할인 입력 / 확인**: 결제 전 적용할 할인 항목과 할인 금액을 입력하거나 확인합니다. 할인 입력 후 최종 결제 금액과 잔액이 즉시 재계산됩니다.
- **현장 결제 등록 정보**: 결제수단별 수납 행을 1개 이상 입력합니다. 각 행에는 `결제수단(카드/현금/계좌이체) / 금액 / 승인번호 또는 이체확인번호 / 승인시각 / 영수증 파일 / 메모`를 입력합니다. 영수증 파일은 필수이며 이미지/PDF 첨부를 기준으로 합니다.
- **혼합결제 입력 그리드**: 카드+현금, 카드+계좌이체, 현금+계좌이체, 카드+현금+계좌이체 조합을 모두 허용합니다. 포인트 사용액은 혼합결제 행과 별도 필드로 관리합니다.
- **VAN/POS 결과 박스**: 승인번호, 단말 ID, 승인 결과, 응답메시지, 외부 거래번호, 영수증 매칭 상태를 표시합니다. 수기 입력 또는 연동 조회 결과를 모두 저장할 수 있습니다.
- **지점 귀속 설정**: 결제지점, 이용지점, 매출 귀속 지점, 정산 지점, 인센티브 귀속자를 표시합니다. 상품 기본값을 자동 채우되 운영자가 조정할 수 있습니다.
- **수납 방식 선택**: 현장 전액 등록 / 계약금 등록 / 잔액 등록 / 결제링크 발송 중 하나를 선택합니다.
  - **현장 전액 등록**: 외부 POS 또는 현금 수납이 끝난 전체 금액을 영수증과 함께 등록합니다.
  - **계약금 등록**: 당일 결제가격과 포인트 사용액을 입력하고, 남은 금액은 미수금 또는 할부 계획으로 넘깁니다. 이때 이용권 즉시 개시 여부를 선택할 수 있습니다.
  - **잔액 등록**: 기존 계약의 남은 잔액에 대한 현장 결제 영수증을 등록합니다.
  - **결제링크 발송**: 금액과 할인 조건을 확정한 뒤 고객이 직접 결제할 링크를 발송합니다.
- **잔액 요약 박스**: 정가 / 할인 / 당일 수납액 / 잔액 / 결제 경로를 한눈에 표시합니다.
- **이용권 개시 옵션**: 계약금 수납일 때만 노출되며 `즉시 개시 / 완납 후 개시` 중 하나를 선택합니다.
- **금액 일치 검증**: `혼합결제 행 합계 + 포인트 사용액`이 장바구니 최종 합계와 정확히 일치해야 결제 등록 버튼이 활성화됩니다. 입력 합계가 부족하거나 초과하면 차액을 붉은색으로 표시합니다.
- **포인트 사용 검증**: 포인트 사용 시 회원 선택이 필수이며, 보유 포인트가 부족하면 결제 등록을 차단합니다.
- **전자계약 후속 선택**: 현장 결제 등록 완료 직후 "계약서 미작성 / 계약서 작성" 선택 단계를 노출합니다. 계약서 작성 선택 시 강습 / 개인락커 / 양도 / 회원권 / 일일이용 유형 중 맞는 계약서를 고릅니다.
- **결제링크 발송 버튼**: 수납 방식이 `결제링크 발송`일 때 노출됩니다. 회원 연락처와 만료일시를 확인한 후 DLG-S016을 통해 발송합니다.
- **결제 등록 버튼**: 현장 결제 등록 필수값과 금액 일치 조건이 충족되면 활성화됩니다. 클릭 시 결제 확인 모달이 열립니다.
- **결제 확인 모달**: 상품 내역·장바구니 합계·결제가격·포인트 사용액·영수증 첨부 여부·선택 회원을 최종 확인하고 "결제 완료 등록" 버튼으로 처리합니다. 처리 중에는 버튼이 "등록 중..."으로 변경되고 비활성화됩니다.
- **중복 결제 경고**: 동일 회원이 최근 같은 금액을 결제한 이력이 있으면 경고 다이얼로그가 표시됩니다. "계속 진행" 또는 "취소"를 선택할 수 있습니다.
- **결제 완료 화면**: 결제 등록 성공 시 체크 아이콘과 완료 메시지가 표시됩니다. 이 시점에 결제완료 상태와 회원/이용권 등록 완료가 함께 반영됩니다. 영수증 파일 보기 / 문자 발송 / 계속 판매하기 / 매출 현황으로 이동 버튼을 제공합니다.
- **초기화 버튼**: 상단에 위치하며, 클릭 시 결제 상태를 초기 상태로 리셋합니다.
- **이전으로 돌아가기**: POS 판매 화면(SCR-S002)으로 돌아갑니다.

## 주요 UX 흐름

1. POS 판매 화면에서 "결제하기"를 눌러 진입합니다. 장바구니 상품이 자동으로 불러와집니다.
2. 좌측에서 상품 목록과 총 결제 금액을 확인합니다.
3. 할인 항목과 금액을 확인하거나 입력하고, 수납 방식(현장 전액 등록/계약금 등록/잔액 등록/결제링크 발송)을 선택합니다.
4. 현장 등록인 경우 외부 POS 또는 현금/계좌이체 수납 완료 후 혼합결제 행, 포인트 사용액, 결제일시, 영수증 파일, VAN/POS 결과, 귀속 필드를 입력합니다.
5. 포인트 사용 시 좌측에서 회원을 검색해 지정하고 보유 포인트를 확인합니다.
6. `혼합결제 행 합계 + 포인트 사용액 = 장바구니 최종 합계`가 맞고 영수증 파일이 첨부되면 "결제 등록" 버튼이 활성화됩니다.
7. 계약금 등록의 경우 당일 등록 금액과 잔액을 확인하고, 이용권 즉시 개시 여부를 선택한 뒤 필요 시 미수금 또는 할부 계획으로 넘깁니다.
8. 결제링크 발송의 경우 회원 연락처와 링크 만료일시를 확인한 뒤 발송 다이얼로그를 엽니다.
9. 동일 회원의 중복 결제가 감지되면 경고 다이얼로그에서 진행 여부를 선택합니다.
10. 현장 결제 등록 완료 시 결제완료와 회원/이용권 등록 완료를 즉시 반영하고, 계약서 미작성/작성 선택 단계를 노출합니다.
11. 링크 발송 완료 시 발송 결과 상태를 표시합니다.

| 결제 등록 준비 완료 | 상품, 혼합결제 행, 포인트 사용액, 결제일시, 영수증 파일이 유효하고 금액 합계가 일치한 상태. |
| 포인트 부족 | 보유 포인트가 사용액보다 적을 때 부족액을 붉은색으로 표시하고 결제 등록 버튼 비활성화. |
| 결제 총액 불일치 | 혼합결제 행 합계 + 포인트 사용액이 장바구니 합계와 다를 때 차액(부족/초과)을 붉은색으로 표시하고 결제 등록 버튼 비활성화. |
| 계약금 등록 중 | 당일 등록 금액과 잔액이 동시에 표시되며, 잔액 처리 방식과 이용권 개시 옵션이 확정되어야 다음 단계로 진행됩니다. |
| VAN/POS 결과 미매칭 | 카드 결제 행이 있으나 승인번호 또는 외부 거래결과가 누락된 상태. 저장은 가능하지만 경고 배지를 표시합니다. |
| 귀속 정책 검토 필요 | 법인/홈&오피스/주말/통합 회원권이 포함된 경우 지점 귀속 설정 영역을 강조합니다. |
| 결제링크 발송 준비 완료 | 회원 연락처, 고정 금액, 만료일시가 모두 유효할 때 발송 버튼이 활성화됩니다. |
| 결제 등록 중 | 결제 완료 등록 버튼 클릭 후 서버 처리 중. 버튼이 "등록 중..."으로 변경되고 재클릭 불가. |
| 중복 결제 경고 | 동일 회원·금액 중복 감지 시 경고 다이얼로그 표시. |
| 결제 완료 | 결제 등록 성공 후 완료 화면(체크 아이콘 + 후속 버튼)으로 전환하며 회원/이용권 등록을 함께 완료. |

## 비즈니스 규칙

- 결제링크 발송 경로에서는 상품, 할인, 확정 금액을 발송 후 수정할 수 없습니다. 수정이 필요하면 기존 링크를 취소하고 새 링크를 발송합니다.
- 활성 링크가 있으면 같은 링크를 재발송할 수 있고, 필요 시 강제 만료 또는 취소 후 새 링크를 생성할 수 있습니다.
- 결제링크 진입 고객은 결제수단만 선택할 수 있으며 할인, 쿠폰, 포인트, 할부 조건을 임의로 바꿀 수 없습니다.
- 현장 결제 등록은 영수증 파일 첨부가 필수입니다. 미첨부 상태에서는 결제 완료 등록이 불가합니다.
- 현장 결제 총액은 `혼합결제 행 합계 + 포인트 사용액`으로 계산하며 장바구니 최종 합계와 정확히 일치해야 합니다.
- 포인트 사용액은 회원 보유 포인트 이내여야 하며, 포인트 사용 거래 이력을 결제 기록과 함께 남깁니다.
- 결제 완료 등록 시 별도 매니저 승인 없이 결제완료와 회원/이용권 등록 완료 상태를 즉시 반영합니다.
- 계약금 등록은 `collectionMode=DEPOSIT`로 저장하며, 잔액은 미수금 또는 할부 계획과 반드시 연결되어야 합니다.
- 계약금 수납 시 `membershipStartMode=IMMEDIATE | ON_FULL_PAYMENT`를 함께 저장하며, `IMMEDIATE`를 선택하면 `INSTALLMENT` 상태에서도 이용권을 개시할 수 있습니다.
- 현장 결제수단은 카드/현금/계좌이체를 혼합해 입력할 수 있으며, 포인트 사용액은 수납 행과 별도 필드로 기록합니다.
- 카드 결제 행에는 승인번호·승인시각·단말 ID·외부거래번호를 저장할 수 있고, 계좌이체 행에는 입금자명·이체확인번호·입금시각을 저장합니다.
- 결제 레코드에는 `paymentBranchId`, `usageBranchId`, `salesAttributionBranchId`, `settlementBranchId`, `incentiveOwnerId`를 함께 저장하며 환불·KPI·급여 계산은 이 값을 참조합니다.
- 법인/홈&오피스/주말/통합 회원권은 단순 지점 귀속으로 축약하지 않고 이용 가능 지점·정산 지점·귀속 지점을 별도 필드로 저장합니다.
- 부분 환불은 원결제의 혼합결제 행을 기준으로 추적되며, 환불 화면에서는 잔여 수납 행별 환불 가능액을 계산해 표시합니다.
- 해피아워 자동 할인은 지점 설정 시간표를 우선 적용하며, 운영자가 수동 수정한 경우 원규칙과 수정 사유를 감사 로그에 남깁니다.
