## 화면 목적

POS 판매 화면(SCR-S002)에서 장바구니에 담은 상품의 결제를 완료하는 화면입니다. 결제수단(카드·현금·마일리지·복합결제)을 선택하고 최종 결제 금액을 확인한 뒤 결제를 처리합니다. 현장 전액 결제뿐 아니라 할인 적용, 계약금 수납, 잔액 계산, 결제링크 발송까지 이 화면에서 확정합니다. 결제 완료 후에는 영수증 출력·문자 발송·계속 판매 등의 후속 동작을 안내합니다.

## 주요 구성요소

- **결제 상품 목록 (좌측)**: POS에서 담아온 상품명·수량·소계를 목록으로 표시하고, 하단에 총 결제 금액을 크게 표시합니다.
- **회원 검색 (좌측)**: 마일리지 결제 시 회원 지정이 필수입니다. 이름 또는 전화번호로 검색해 회원을 선택하면 보유 마일리지가 표시됩니다. 선택된 회원은 X 버튼으로 해제할 수 있습니다.
- **할인 입력 / 확인**: 결제 전 적용할 할인 항목과 할인 금액을 입력하거나 확인합니다. 할인 입력 후 최종 결제 금액과 잔액이 즉시 재계산됩니다.
- **수납 방식 선택**: 전액 수납 / 계약금 수납 / 잔액 수납 / 결제링크 발송 중 하나를 선택합니다.
  - **전액 수납**: 현장에서 총액 전부를 결제합니다.
  - **계약금 수납**: 당일 수납액을 입력하고, 남은 금액은 미수금 또는 할부 계획으로 넘깁니다. 이때 이용권 즉시 개시 여부를 선택할 수 있습니다.
  - **잔액 수납**: 기존 계약의 남은 잔액만 이번 결제 대상으로 수납합니다.
  - **결제링크 발송**: 금액과 할인 조건을 확정한 뒤 고객이 직접 결제할 링크를 발송합니다.
- **잔액 요약 박스**: 정가 / 할인 / 당일 수납액 / 잔액 / 결제 경로를 한눈에 표시합니다.
- **이용권 개시 옵션**: 계약금 수납일 때만 노출되며 `즉시 개시 / 완납 후 개시` 중 하나를 선택합니다.
- **결제수단 선택 (우측)**: 카드 / 현금 / 마일리지 / 복합결제 중 하나를 선택합니다. 선택된 수단은 강조 표시됩니다.
  - **복합결제**: 카드·현금·마일리지 금액을 각각 입력해 합계가 총액과 일치해야 결제 버튼이 활성화됩니다. 입력 합계가 부족하거나 초과하면 차액이 붉은색으로 표시됩니다.
  - **마일리지 결제**: 회원 미선택 시 안내 문구를 표시하고 결제 버튼이 비활성화됩니다. 보유 마일리지가 부족하면 부족액을 붉은색으로 표시합니다.
- **결제링크 발송 버튼**: 수납 방식이 `결제링크 발송`일 때 노출됩니다. 회원 연락처와 만료일시를 확인한 후 DLG-S016을 통해 발송합니다.
- **결제 확인 버튼**: 모든 조건이 충족되면 활성화됩니다. 클릭 시 결제 확인 모달이 열립니다.
- **결제 확인 모달**: 상품 내역·합계·결제수단·선택 회원을 최종 확인하고 "결제 완료" 버튼으로 처리합니다. 처리 중에는 버튼이 "처리 중..."으로 변경되고 비활성화됩니다.
- **중복 결제 경고**: 동일 회원이 최근 같은 금액을 결제한 이력이 있으면 경고 다이얼로그가 표시됩니다. "계속 진행" 또는 "취소"를 선택할 수 있습니다.
- **결제 완료 화면**: 결제 성공 시 체크 아이콘과 완료 메시지가 표시됩니다. 영수증 출력 / 문자 발송 / 계속 판매하기 / 매출 현황으로 이동 버튼을 제공합니다.
- **초기화 버튼**: 상단에 위치하며, 클릭 시 결제 상태를 초기 상태로 리셋합니다.
- **이전으로 돌아가기**: POS 판매 화면(SCR-S002)으로 돌아갑니다.

| 센터장 / 매니저 | 소속 지점 매출 전체 | 모든 결제수단 처리, 할인 입력, 계약금/잔액 수납, 결제링크 발송, 영수증 출력, 문자 발송 |
| FC | 담당 회원 결제 처리 가능 | 모든 결제수단 처리, 할인 입력, 계약금/잔액 수납, 할부 계획 등록, 결제링크 발송 |
| 트레이너 / 스태프 | 매출 조회만 (처리 불가) | 결제 처리 화면 접근 불가 |

## 주요 UX 흐름

1. POS 판매 화면에서 "결제하기"를 눌러 진입합니다. 장바구니 상품이 자동으로 불러와집니다.
2. 좌측에서 상품 목록과 총 결제 금액을 확인합니다.
3. 할인 항목과 금액을 확인하거나 입력하고, 수납 방식(전액/계약금/잔액/결제링크 발송)을 선택합니다.
4. 현장 수납인 경우 우측에서 결제수단(카드·현금·마일리지·복합결제)을 선택합니다.
5. 마일리지 또는 복합결제(마일리지 포함) 선택 시, 좌측에서 회원을 검색해 지정합니다.
6. 계약금 수납의 경우 당일 수납액과 잔액을 확인하고, 이용권 즉시 개시 여부를 선택한 뒤 필요 시 미수금 또는 할부 계획으로 넘깁니다.
7. 결제링크 발송의 경우 회원 연락처와 링크 만료일시를 확인한 뒤 발송 다이얼로그를 엽니다.
8. 조건이 모두 충족되면 "결제 확인" 또는 "결제링크 발송" 버튼이 활성화됩니다.
9. 동일 회원의 중복 결제가 감지되면 경고 다이얼로그에서 진행 여부를 선택합니다.
10. 현장 수납 완료 시 완료 화면으로 전환되고, 링크 발송 완료 시 발송 결과 상태를 표시합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 결제 대기 | 결제수단 선택 및 조건 미충족 상태. 결제 확인 버튼 비활성화. |
| 결제 준비 완료 | 모든 조건(상품·결제수단·금액 등)이 충족된 상태. 결제 확인 버튼 활성화. |
| 마일리지 부족 | 보유 마일리지가 총액보다 적을 때 부족액을 붉은색으로 표시하고 결제 버튼 비활성화. |
| 복합결제 금액 불일치 | 입력한 금액 합계가 총액과 다를 때 차액(부족/초과)을 붉은색으로 표시하고 결제 버튼 비활성화. |
| 계약금 수납 중 | 당일 수납액과 잔액이 동시에 표시되며, 잔액 처리 방식과 이용권 개시 옵션이 확정되어야 다음 단계로 진행됩니다. |
| 결제링크 발송 준비 완료 | 회원 연락처, 고정 금액, 만료일시가 모두 유효할 때 발송 버튼이 활성화됩니다. |
| 결제 처리 중 | 결제 완료 버튼 클릭 후 서버 처리 중. 버튼이 "처리 중..."으로 변경되고 재클릭 불가. |
| 중복 결제 경고 | 동일 회원·금액 중복 감지 시 경고 다이얼로그 표시. |
| 결제 완료 | 결제 성공 후 완료 화면(체크 아이콘 + 후속 버튼)으로 전환. |

## 비즈니스 규칙

- 결제링크 발송 경로에서는 상품, 할인, 확정 금액을 발송 후 수정할 수 없습니다. 수정이 필요하면 기존 링크를 취소하고 새 링크를 발송합니다.
- 활성 링크가 있으면 같은 링크를 재발송할 수 있고, 필요 시 강제 만료 또는 취소 후 새 링크를 생성할 수 있습니다.
- 결제링크 진입 고객은 결제수단만 선택할 수 있으며 할인, 쿠폰, 마일리지, 할부 조건을 임의로 바꿀 수 없습니다.
- 계약금 수납은 `collectionMode=DEPOSIT`로 저장하며, 잔액은 미수금 또는 할부 계획과 반드시 연결되어야 합니다.
- 계약금 수납 시 `membershipStartMode=IMMEDIATE | ON_FULL_PAYMENT`를 함께 저장하며, `IMMEDIATE`를 선택하면 `INSTALLMENT` 상태에서도 이용권을 개시할 수 있습니다.

## 관련 다이어그램

- 결제수단별 분기 흐름 (카드 / 현금 / 마일리지 / 복합결제)
- 중복 결제 감지 및 경고 흐름
- 결제 처리 → 완료 화면 전환 흐름
- 마일리지 차감 및 적립 흐름
- 계정 권한별 접근 분기 흐름
