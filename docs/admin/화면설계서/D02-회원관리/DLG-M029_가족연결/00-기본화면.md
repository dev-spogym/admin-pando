## 화면 목적
가족 관계인 회원들을 서로 연결하는 다이얼로그입니다. 연결된 가족 회원은 일부 혜택(패밀리 이용권, 동반 출석 등)을 함께 사용할 수 있습니다.

## 주요 구성요소
- 제목: "가족 연결"
- 현재 회원 정보 표시 (읽기 전용)
- 연결할 회원 검색 (이름 또는 전화번호로 검색)
- 검색 결과 목록 (회원명, 회원번호, 연락처)
- 선택된 연결 대상 회원 표시
- 가족 관계 선택 (배우자, 부모, 자녀, 형제·자매, 기타)
- 연결 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 기본정보 탭의 가족 연결 버튼 클릭 시
- 관리자 또는 해당 권한을 가진 직원에게 표시

## 주요 UX 흐름
1. 관리자가 가족 연결 버튼 클릭 → 다이얼로그 표시
2. 연결할 회원 검색 → 검색 결과에서 대상 회원 선택
3. 가족 관계 선택
4. 연결 버튼 클릭 → 두 회원 간 가족 관계 설정, 각 회원 상세에 가족 정보 표시
5. 취소 클릭 → 다이얼로그 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
