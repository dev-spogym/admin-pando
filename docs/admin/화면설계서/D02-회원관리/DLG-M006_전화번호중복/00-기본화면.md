## 화면 목적
회원 등록 또는 수정 시 이미 다른 회원에게 등록된 전화번호를 입력하면, 중복 사실을 안내하여 동일 번호로 복수 회원이 생성되는 것을 방지하는 다이얼로그입니다.

## 주요 구성요소
- 제목: "이미 등록된 전화번호입니다"
- 안내 메시지: 해당 번호로 등록된 기존 회원명 표시
- 기존 회원 바로가기 버튼 (선택)
- 확인 버튼 (다이얼로그 닫기 후 입력 필드로 포커스 복귀)

## 언제 표시되나요
- 회원 등록 화면에서 전화번호 입력 후 중복 확인을 실행했을 때
- 회원 수정 화면에서 전화번호를 다른 회원의 번호로 변경하려 할 때

## 주요 UX 흐름
1. 관리자가 전화번호 입력 후 저장 또는 중복 확인 클릭 → 중복 감지 시 다이얼로그 표시
2. 기존 회원 바로가기 클릭 → 해당 회원 상세 페이지로 이동
3. 확인 클릭 → 다이얼로그 닫힘, 전화번호 입력 필드 초기화 후 재입력 유도

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
