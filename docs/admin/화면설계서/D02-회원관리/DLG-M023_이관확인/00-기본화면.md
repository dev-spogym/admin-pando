## 화면 목적
회원을 다른 지점으로 이관하기 전에 최종 확인을 받는 다이얼로그입니다. 이관 후에는 원 지점에서 해당 회원 정보를 더 이상 관리하지 않음을 안내합니다.

## 주요 구성요소
- 제목: "지점 이관 확인"
- 이관 대상 회원 정보 표시 (회원명, 현재 지점)
- 이관 대상 지점 표시 (이관될 지점명)
- 이관 시 함께 이전되는 정보 안내 (이용권, 출석 이력, 체성분 등)
- 이관 후 변경 사항 안내 메시지
- 확인(이관 처리) 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 기본정보 탭의 지점 이관 버튼 클릭 후, 이관 대상 지점을 선택한 직후
- 지점 이관 처리의 마지막 단계에서 표시

## 주요 UX 흐름
1. 이관 대상 지점 선택 완료 → 이관 확인 다이얼로그 표시
2. 이관 정보 및 안내 사항 확인
3. 확인 클릭 → 회원 소속 지점 변경, 해당 지점 관리자에게 이관 알림 발송
4. 취소 클릭 → 다이얼로그 닫힘, 이관 취소

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
