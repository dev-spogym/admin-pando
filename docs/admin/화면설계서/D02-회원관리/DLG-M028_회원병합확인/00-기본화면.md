## 화면 목적
중복으로 생성된 회원 계정을 하나로 합치기 전에 최종 확인을 받는 다이얼로그입니다. 병합 후 데이터 합산 결과를 미리보기로 제공하여 실수를 방지합니다.

## 주요 구성요소
- 제목: "회원 병합 확인"
- 기준 회원 정보 표시 (병합 후 유지될 계정 — 회원명, 회원번호, 가입일)
- 대상 회원 정보 표시 (병합 후 삭제될 계정 — 회원명, 회원번호, 가입일)
- 병합 후 데이터 합산 미리보기
  - 이용권: 기준 + 대상 이용권 목록
  - 출석 이력: 통합 건수
  - 마일리지: 합산 잔액
  - 결제 이력: 통합 건수
- 주의 안내 메시지 ("병합 후 대상 계정은 삭제되며 복구할 수 없습니다")
- 확인(병합 처리) 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 목록 또는 회원 상세에서 병합 대상 회원을 선택한 후 병합 버튼 클릭 시
- 관리자 권한을 가진 사용자에게만 표시

## 주요 UX 흐름
1. 병합 대상 회원 선택 완료 → 병합 확인 다이얼로그 표시, 합산 미리보기 제공
2. 미리보기 내용 확인
3. 확인 클릭 → 대상 회원 데이터를 기준 회원에 통합, 대상 계정 비활성화
4. 취소 클릭 → 다이얼로그 닫힘, 병합 취소

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
