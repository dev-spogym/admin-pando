## 화면 목적
트레이너가 회원의 체력 수준, 자세, 목표 달성도 등을 종합적으로 평가하여 기록하는 다이얼로그입니다. 정기적인 평가 기록을 통해 회원의 운동 진행 상황을 추적합니다.

## 주요 구성요소
- 제목: "종합 평가 등록"
- 평가 날짜 선택 (기본값: 오늘)
- 체력 평가 항목 (근력, 유연성, 심폐지구력 등 각 항목별 점수 또는 등급 선택)
- 자세 평가 항목 (척추, 골반, 어깨 등 주요 부위별 평가)
- 목표 달성도 (목표 대비 현재 달성 수준, 퍼센트 또는 등급)
- 종합 의견 입력 (자유 텍스트)
- 다음 평가 예정일 설정 (선택)
- 저장 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 평가 탭에서 평가 등록 버튼 클릭 시
- 트레이너 또는 관리자 권한을 가진 사용자만 표시

## 주요 UX 흐름
1. 트레이너가 평가 등록 버튼 클릭 → 다이얼로그 표시
2. 각 평가 항목 입력 및 종합 의견 작성
3. 저장 클릭 → 평가 기록 저장, 평가 탭에 이력 반영
4. 취소 클릭 → 다이얼로그 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
