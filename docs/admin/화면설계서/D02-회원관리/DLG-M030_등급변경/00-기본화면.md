## 화면 목적
관리자가 회원의 등급을 수동으로 변경하는 다이얼로그입니다. 자동 등급 산정 기준과 관계없이 특별한 사유가 있을 때 등급을 조정합니다.

## 주요 구성요소
- 제목: "등급 변경"
- 현재 등급 표시 (읽기 전용)
- 변경할 등급 선택 (등급 목록 — 예: 일반, 실버, 골드, VIP 등)
- 각 등급별 혜택 요약 안내 (선택 시 표시)
- 변경 사유 입력 (필수, 텍스트 입력 또는 사유 목록 선택)
- 변경 적용일 선택 (기본값: 즉시 적용)
- 확인 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 기본정보 탭의 등급 변경 버튼 클릭 시
- 관리자 권한을 가진 사용자에게만 표시

## 주요 UX 흐름
1. 관리자가 등급 변경 버튼 클릭 → 다이얼로그 표시, 현재 등급 표시
2. 변경할 등급 선택 → 해당 등급의 혜택 안내 표시
3. 사유 및 적용일 입력
4. 확인 클릭 → 등급 변경 완료, 변경 이력 기록, 회원에게 등급 변경 알림 발송(선택)
5. 취소 클릭 → 다이얼로그 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
