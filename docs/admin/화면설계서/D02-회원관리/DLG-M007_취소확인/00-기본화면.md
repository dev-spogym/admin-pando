## 화면 목적
회원 등록 또는 수정 작업 중 취소 버튼을 클릭했을 때, 입력된 내용이 저장되지 않고 사라질 수 있음을 안내하여 실수로 인한 데이터 손실을 방지하는 다이얼로그입니다.

## 주요 구성요소
- 제목: "작업을 취소하시겠습니까?"
- 안내 메시지: "입력하신 내용이 저장되지 않습니다."
- 확인 버튼 (작업 취소 실행, 이전 화면으로 이동)
- 계속 작업 버튼 (다이얼로그 닫기, 작업 유지)

## 언제 표시되나요
- 회원 등록 화면에서 취소 버튼을 클릭했을 때
- 회원 수정 화면에서 변경 사항이 있는 상태에서 취소 버튼을 클릭했을 때
- 변경 사항이 없는 경우 다이얼로그 없이 즉시 이전 화면으로 이동

## 주요 UX 흐름
1. 관리자가 작업 중 취소 버튼 클릭 → 다이얼로그 표시
2. 확인 → 입력 내용 폐기, 이전 화면(목록 또는 상세)으로 이동
3. 계속 작업 → 다이얼로그 닫힘, 작업 화면 유지

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
