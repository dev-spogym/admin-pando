## 화면 목적
체성분 측정 기기와 연동되지 않는 환경에서, 관리자가 회원의 체성분 측정값을 수동으로 입력하여 건강 데이터를 기록하는 다이얼로그입니다.

## 주요 구성요소
- 제목: "체성분 등록"
- 측정일 선택 (날짜 선택, 기본값: 오늘)
- 체중 입력 (kg)
- 체지방률 입력 (%)
- 근육량 입력 (kg)
- 체수분율 입력 (%, 선택 사항)
- BMI 자동 계산 표시 (체중·신장 기반)
- 등록 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 체성분 탭에서 체성분 등록 버튼을 클릭했을 때
- 같은 날 이미 등록된 데이터가 있는 경우 DLG-M016(체성분 덮어쓰기) 다이얼로그로 분기

## 주요 UX 흐름
1. 관리자가 체성분 등록 버튼 클릭 → 다이얼로그 표시
2. 측정일 선택 및 측정값 입력
3. 등록 버튼 클릭 → 체성분 데이터 저장 완료, 다이얼로그 닫힘, 체성분 그래프 즉시 갱신
4. 취소 → 다이얼로그 닫힘, 저장 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
