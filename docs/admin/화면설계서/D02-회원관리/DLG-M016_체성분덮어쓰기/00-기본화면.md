## 화면 목적
같은 날짜에 체성분 기록이 이미 존재할 때, 기존 데이터를 새 데이터로 덮어쓸지 확인하는 다이얼로그입니다. 실수로 중복 기록이 생기는 것을 방지합니다.

## 주요 구성요소
- 제목: "체성분 덮어쓰기"
- 안내 메시지: "[날짜]에 이미 등록된 체성분 기록이 있습니다. 덮어쓰시겠습니까?"
- 기존 기록 요약 표시 (측정일, 체중, 체지방률 등 주요 수치)
- 확인(덮어쓰기) 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 체성분 탭에서 체성분 등록 시
- 입력한 측정일에 이미 체성분 데이터가 존재하는 경우

## 주요 UX 흐름
1. 체성분 등록 다이얼로그에서 날짜 입력 후 저장 클릭 → 중복 날짜 감지 → 덮어쓰기 다이얼로그 표시
2. 확인(덮어쓰기) 클릭 → 기존 기록 삭제 후 새 데이터 저장, 다이얼로그 닫힘
3. 취소 클릭 → 다이얼로그 닫힘, 체성분 등록 화면으로 복귀(입력값 유지)

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
