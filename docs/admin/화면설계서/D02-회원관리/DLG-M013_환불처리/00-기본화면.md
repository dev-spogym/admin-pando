## 화면 목적
특정 결제 건에 대해 환불을 처리할 때, 환불 금액과 사유를 입력하고 최종 확인을 받는 다이얼로그입니다.

## 주요 구성요소
- 제목: "환불 처리"
- 원결제 정보 표시 (결제일, 결제 금액, 결제 수단)
- 환불 금액 입력 (기본값: 원결제 금액, 부분 환불 시 직접 입력)
- 환불 사유 입력 (드롭다운 + 직접 입력)
- 환불 후 잔액 표시 (부분 환불 시)
- 확인 버튼 (환불 실행)
- 취소 버튼 (다이얼로그 닫기)

## 언제 표시되나요
- 회원 상세 > 결제 탭에서 특정 결제 건의 환불 버튼을 클릭했을 때
- 이미 환불 처리된 건은 환불 버튼 비활성화

## 주요 UX 흐름
1. 관리자가 환불 버튼 클릭 → 원결제 정보가 채워진 상태로 다이얼로그 표시
2. 환불 금액 확인 또는 수정, 사유 입력
3. 확인 → 환불 처리 완료, 다이얼로그 닫힘, 결제 목록 상태 갱신
4. 취소 → 다이얼로그 닫힘, 환불 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
