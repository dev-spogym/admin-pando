## 화면 목적
관리자가 특정 회원에게 쿠폰을 수동으로 적용하는 다이얼로그입니다. 쿠폰 코드를 직접 입력하거나 발급 가능한 쿠폰 목록에서 선택하여 적용합니다.

## 주요 구성요소
- 제목: "쿠폰 적용"
- 쿠폰 적용 방식 선택 탭 (코드 입력 / 목록 선택)
  - 코드 입력: 쿠폰 코드 입력 필드 + 조회 버튼
  - 목록 선택: 적용 가능한 쿠폰 목록 (쿠폰명, 혜택 내용, 유효기간)
- 선택된 쿠폰 상세 정보 표시 (할인 유형, 할인액/율, 사용 조건)
- 쿠폰 적용 대상 이용권 선택 (해당 시)
- 적용 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 이용권 또는 결제 탭에서 쿠폰 적용 버튼 클릭 시
- 결제 진행 중 쿠폰 적용 단계에서 표시

## 주요 UX 흐름
1. 관리자가 쿠폰 적용 버튼 클릭 → 다이얼로그 표시
2. 코드 직접 입력 또는 목록에서 쿠폰 선택 → 쿠폰 정보 표시
3. 적용 버튼 클릭 → 해당 회원에게 쿠폰 적용, 할인 반영
4. 취소 클릭 → 다이얼로그 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
