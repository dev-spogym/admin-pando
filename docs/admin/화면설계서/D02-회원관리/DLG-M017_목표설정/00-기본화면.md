## 화면 목적
회원의 운동 목표(목표 체중, 체지방률, 골격근량 등)를 입력·수정하는 다이얼로그입니다. 목표 수치를 기록해 두면 이후 체성분 변화와 비교하여 달성 여부를 추적할 수 있습니다.

## 주요 구성요소
- 제목: "목표 설정"
- 목표 체중 입력 (kg, 소수점 첫째 자리)
- 목표 체지방률 입력 (%, 소수점 첫째 자리)
- 목표 골격근량 입력 (kg, 소수점 첫째 자리, 선택)
- 목표 달성 기간 입력 (날짜 선택 또는 개월 수 입력, 선택)
- 메모 입력 (자유 텍스트, 선택)
- 저장 버튼
- 취소 버튼

## 언제 표시되나요
- 회원 상세 > 체성분 탭에서 목표 설정 버튼 클릭 시
- 기존 목표가 있는 경우 현재 값이 미리 채워진 상태로 표시

## 주요 UX 흐름
1. 관리자 또는 트레이너가 목표 설정 버튼 클릭 → 다이얼로그 표시
2. 목표 수치 입력 후 저장 클릭 → 목표 저장, 체성분 탭에 목표 수치 반영
3. 취소 클릭 → 다이얼로그 닫힘, 변경 없음

## 화면 상태

| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

## 계정별 차이

| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
