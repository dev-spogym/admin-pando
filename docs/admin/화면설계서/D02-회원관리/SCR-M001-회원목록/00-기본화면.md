## 화면 목적

센터에 등록된 전체 회원을 한눈에 조회하고, 다양한 조건으로 원하는 회원을 찾아 상세 페이지로 이동하거나 일괄 작업을 수행하는 회원관리 도메인의 핵심 허브 화면입니다. 본사 관계자가 `전체 지점(통합)`을 선택한 경우 모든 지점 회원이 조회되며, 각 회원의 소속 지점이 목록과 엑셀 내보내기에 표시됩니다. FC는 오늘 만료 예정 회원을 검색해 리텐션 상담을 진행하고, 매니저는 장기 미방문 회원에게 메시지를 발송하며, 센터장은 전체 회원 데이터를 엑셀로 내려받아 분석에 활용합니다.

## 주요 구성요소

- **요약 지표 카드 (4개)**: 전체 회원 수 / 활성 회원 수 / 정책상 조치 대상 회원 수 / 이번 달 만료 수를 한눈에 표시. 카드 클릭 시 해당 상태로 자동 필터링됩니다.
- **운영 포커스 바**: 요약 카드 아래에 `지금 바로 봐야 할 회원군` 블록을 배치합니다. 재등록 집중 보기(14일 내 만료), 이탈 위험 보기(14일 이상 미방문), 관심회원 보기 같은 바로가기 카드를 제공해 운영자가 즉시 목록 문맥을 전환할 수 있게 합니다.
- **액션 큐**: 운영 포커스 바 우측에 선택 회원 기준의 메시지 발송, 상태 변경, 수동 출석 실행 버튼을 모읍니다. 선택 회원이 없을 때는 사용 가이드를, 있을 때는 선택된 회원 이름 요약을 노출합니다.
- **운영 보기 탭**: 회원 목록 / 회원권 목록 / 수강권 목록 / 락커 목록 / 운동복 목록으로 보기 방식을 전환합니다. 센터 운영 방식에 따라 일부 탭은 숨길 수 있습니다.
- **저장 뷰 탭**: 상담내역 / 상담예약 / 재등록대상 / (구)고객관리 같은 운영 저장 뷰를 상단 서브 탭으로 제공합니다. CRM-01 리드관리와 분리된 회원 원장 관점의 조회 뷰입니다.
- **상태 필터 탭**: 전체 · 활성 · 만료 · 예정 · 임박 · 홀딩 · 미등록 · 정지를 건수 배지와 함께 표시합니다. 클릭 시 해당 상태의 회원만 표시됩니다.
- **검색 및 필터 바**: 이름·연락처·운동 ID 통합 검색, 계약상품·성별·최종만료일·최근방문일 필터를 제공합니다. 추가 필터로 관심회원만 보기, 미방문 기간, 회원구분, 유입경로, 만료 상품 숨기기, 출석 시 상세 팝업 기본값을 제어합니다.
- **상단 액션 바**: 선택된 회원 수(`선택된 목록 n/N`)를 표시하고, 메시지 전송 / 상태 변경 / 엑셀 다운로드 액션을 상단에서 즉시 실행합니다. 지점 운영 설정에 따라 "출석시 상세 팝업" 토글을 노출합니다.
- **일괄 작업 바**: 회원을 1명 이상 선택하면 화면 하단에 자동으로 노출됩니다. 상태 변경 / 메시지 전송 / 출석 처리 / 관심회원 등록 / 지점이관 버튼을 제공합니다. 지점이관은 회원 1명 선택 시에만 진행합니다.
- **회원 목록 테이블**: 선택 체크박스 / No / 상태 배지 / 회원명 / 성별 / 생년월일 / 나이 / 연락처 / 보유 이용권 / 소속 지점 / 마지막 방문일 / 등록일 컬럼으로 구성합니다. 행 클릭 또는 OPEN 액션으로 상세 진입이 가능합니다.
- **우측 상세 팝업 패널**: 상단 토글이 켜져 있으면 회원 행 선택 시 우측 패널이 슬라이드 인 됩니다. 패널에는 프로필, 방문기록 유무, 출석 체크 / 상품 구매 / 메시지 / 더보기 액션, 기본 인적사항, 상담 담당자, 방문경로, 운동목적, 구독 플랜, 외부 연동 상태를 요약 표시합니다.
- **페이지 이동**: 한 페이지에 20 / 50 / 100건 선택 가능, 페이지 번호 이동.
- **엑셀 내보내기**: 현재 필터를 적용한 전체 데이터를 엑셀 파일로 내려받습니다.
- **회원 추가 버튼**: 신규 회원 등록 화면(SCR-M002)으로 이동.
- **삭제·탈퇴 회원 보기 토글 (헤더)**: 활성화하면 삭제 또는 탈퇴 처리된 회원이 별도 섹션 또는 별도 탭으로 표시됩니다. 토글 OFF 상태에서는 삭제·탈퇴 회원이 목록에서 숨겨집니다.
- **회원 복구 액션**: 삭제·탈퇴 섹션에서 회원 행의 [복구] 버튼 클릭 시 복구 확인 다이얼로그(DLG-M005 역연계)를 통해 회원을 다시 활성 상태로 복원합니다. 권한은 센터장·매니저·슈퍼관리자에 한정합니다.

## 계정별 차이

| 계정 유형 | 볼 수 있는 것 | 할 수 있는 것 |
|---|---|---|
| 슈퍼관리자 / 본사 최고관리자 | 전체 브랜드·모든 지점 회원 / 지점 전환 드롭다운 / 소속 지점 컬럼 | 엑셀 내보내기, 회원 추가, 상태 변경, 지점 이관 등 모든 기능 |
| 센터장 (owner) | 소속 브랜드 지점 회원 전체 | 엑셀 내보내기, 회원 추가, 상태 변경, 삭제 |
| 매니저 | 소속 지점 회원 전체 | 엑셀 내보내기, 회원 추가, 상태 변경 (삭제 불가) |
| FC (피트니스 코치) | 소속 지점 전체 회원 (기본: 담당 회원 우선) | 메시지 전송, 출석 처리, 관심회원 등록 (등록·수정·삭제·엑셀 불가) |
| 트레이너 | 담당 회원만 | 조회만 (별도 캘린더 화면 우선 진입) |
| 스태프 | 소속 지점 회원 전체 | 회원 추가, 출석 처리, 관심회원 (삭제·엑셀 불가) |
| 프런트 | 소속 지점 회원 전체 | 조회 및 출석 처리만 |

## 주요 UX 흐름

1. 사이드바에서 "회원 관리 > 회원 목록"을 클릭하거나, 대시보드 지표 카드를 클릭해 진입합니다.
2. 운영 포커스 바에서 재등록 대상, 장기 미방문, 관심회원 같은 우선 회원군으로 빠르게 전환합니다.
3. 운영 보기 탭 또는 저장 뷰 탭으로 현재 업무 문맥(회원 원장, 재등록 대상, 상담 예약 등)을 고릅니다.
4. 요약 지표 카드로 전체 현황을 파악하고, 상태 탭 또는 검색·필터를 조합해 원하는 회원을 찾습니다.
5. "출석시 상세 팝업" 토글이 켜져 있으면 회원을 선택하는 즉시 우측 상세 팝업이 열리고, 꺼져 있으면 회원 상세(SCR-M004)로 이동합니다.
6. 회원 행의 "이관" 버튼 또는 단일 선택 후 하단 "지점이관" 버튼으로 회원 이관 화면(SCR-M005)에 진입합니다.
7. 여러 회원을 체크박스로 선택하면 상단 액션 바, 액션 큐, 하단 일괄 작업 바가 동시에 활성화되어 상태 변경·메시지·출석 처리 등을 일괄 처리합니다.
8. 권한이 있는 역할은 우측 상단 "회원 추가" 버튼으로 신규 등록(SCR-M002)으로 이동합니다.

## 화면 상태

| 상태 | 설명 |
|---|---|
| 로딩 중 | 데이터를 불러오는 동안 테이블 자리에 스켈레톤(뼈대 화면)을 표시 |
| 정상 목록 | 200 응답 + 회원 1명 이상 존재 시 테이블 및 페이지네이션 표시 |
| 검색 결과 없음 | 필터/검색 적용 후 결과가 0건일 때 "검색 결과가 없습니다" 안내 |
| 전체 회원 없음 | 필터 없이 0건일 때 "등록된 회원이 없습니다" + 회원 추가 안내 |
| 오류 | 서버 또는 네트워크 오류 시 오류 메시지와 "다시 시도" 버튼 표시 |
| 접근 불가 | 권한 없는 계정 진입 시 접근 제한 안내 화면으로 전환 |
| 일괄 작업 진행 중 | 벌크 액션 처리 중 테이블 유지 + 진행 스피너 표시 |
| 삭제·탈퇴 보기 활성 | 토글 ON 상태에서 삭제 또는 탈퇴 회원이 별도 섹션/탭에 표시되며 [복구] 버튼이 노출됨 |
| 우측 팝업 열림 | 상세 팝업 토글 ON 상태에서 행 선택 시 우측 패널 슬라이드 인 + 본문 가로폭 축소 |
