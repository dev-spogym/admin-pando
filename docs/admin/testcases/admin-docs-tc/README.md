# Admin Docs 전체 TC 세트

## 목적
- `docs/admin` 기준으로 E2E 이전에 필요한 전체 TC 모체를 화면, 다이얼로그, 시나리오, 자동화, 예외, 키오스크 연동 단위로 전부 분해한다.
- 각 항목은 실제 문서 ID 기준으로 추적 가능해야 하며, 이후 자동화 대상을 고를 때 기준 키로 사용한다.

## 전체 커버리지
- 화면: 118
- 다이얼로그: 159
- 시나리오 시퀀스: 34
- 자동화 크론: 12
- 에러 예외: 20
- 키오스크 연동 문서: 7

- `16_d06_facility_tc.md`: D06 시설관리 전체 화면/다이얼로그 TC

## 작성 원칙
- 화면은 `F1~F9` 기준으로 진입, 메인, 버튼, 필터, 모달, 상태, 권한, 에러, 피드백을 기본 커버리지로 잡는다.
- 다이얼로그는 `오픈, 표시, 검증, 취소, 확정, 실패`를 최소 단위로 강제한다.
- 시나리오/자동화/예외 문서는 운영 플로우와 상태 반영 검증까지 묶어서 관리한다.
