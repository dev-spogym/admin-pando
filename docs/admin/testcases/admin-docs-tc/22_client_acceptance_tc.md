# 클라이언트 추가 체크리스트 인수검수 TC

## 목적
- 2026-05 클라이언트 추가 체크리스트 1~6번 항목을 화면설계서, 기능명세서, 시나리오 기준으로 인수검수 가능한 단위까지 분해한다.
- `1.0 / 1.5` 범위 해석, 귀속 필드 분리, 다지점 회원권 정책, 혼합결제/부분환불, VAN/POS 결과 조회, 페이롤 규칙 반영 여부를 SQA가 단일 문서에서 추적할 수 있도록 정리한다.
- 본 문서는 클라이언트 회신용 기준표와 QA 실행 기준표를 겸한다.
