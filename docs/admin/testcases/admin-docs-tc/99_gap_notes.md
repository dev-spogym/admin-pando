# Admin Gap Notes

## 목적
- 전체 TC를 문서 ID 기준으로 다 펼친 뒤에도 실제 E2E 자동화 전에 막히는 설계 공백을 따로 관리한다.

## 공백 유형
- 권한 키와 역할 라벨이 문서마다 다르게 표현되는 문제
- 상태 전이 다이어그램과 화면 버튼 라벨의 불일치
- 실패 토스트는 있으나 재시도 정책이 없는 항목
- 배치/자동화는 정의됐지만 운영 화면에서 결과 확인 경로가 없는 항목
- 외부 연동은 있으나 타임아웃/중복 수신/부분 성공 기준이 비어 있는 항목
