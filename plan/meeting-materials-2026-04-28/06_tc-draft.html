핵심 기능 TC 초안

전체 시스템을 대표하는 핵심 기능 12개를 기준으로 작성한 초안입니다. 실제 납품 단계에서는 외주 개발사가 이 초안을 상세 TC로 확장해 제출하도록 가져가면 됩니다.

TC Table

대표 기능 12개

ID 기능 시나리오 기대 결과 우선순위 증빙
TC-001 로그인 정상 계정으로 로그인 권한에 맞는 초기 화면으로 진입 P0 성공 캡처, 세션 확인
TC-002 로그인 예외 잘못된 비밀번호 / 권한 없는 계정 정의된 에러 메시지와 차단 흐름 노출 P0 에러 캡처, 메시지 확인
TC-003 회원목록 조회 검색/필터/권한별 조회 조건에 맞는 목록과 빈 상태가 정확히 표시 P0 목록 캡처, 필터 결과 비교
TC-004 회원상세 상태 노출 ACTIVE / HOLDING / EXPIRED / SUSPENDED 상태별 배지, CTA, 제한 문구가 기준서와 일치 P0 상태별 캡처 세트
TC-005 회원등록 필수값 입력 후 저장 유효성 검증 후 정상 등록되고 후속 화면으로 연결 P0 등록 결과, 생성 데이터 확인
TC-006 상태변경 / 홀딩 상태변경, 홀딩등록, 홀딩해제 정책/권한에 맞는 처리 결과와 이력이 반영 P1 전후 비교 캡처, 이력 확인
TC-007 수업 예약 / 대기열 정상 예약, 만석 시 대기등록 예약 가능 여부와 대기 전환 흐름이 정확히 동작 P1 예약 상태 캡처, 대기열 반영 확인
TC-008 결제 처리 정상 결제, 복합 결제, 불일치 케이스 결제 수단별 성공/실패 처리와 토스트가 기준과 일치 P0 결제 로그, 영수증/결과 캡처
TC-009 환불 처리 전액 / 부분 환불 요청 및 처리 권한과 상태 조건에 맞는 환불 결과가 반영 P1 환불 상세, 결과 상태 확인
TC-010 정책 세트 적용 본사 정책 등록 후 지점 적용 지점 화면에 선택 가능한 정책만 노출되고 결과 표시가 일치 P0-정책 정책 설정 캡처, 적용 결과 비교
TC-011 알림 / 자동화 결과 표시 만료 알림, 자동화 실행 결과 확인 정책 결과 기준으로 상태와 메시지가 표시 P1-정책 알림 캡처, 스케줄 로그 확인
TC-012 권한별 접근 제한 본사 / 지점 / FC / 스태프별 메뉴 접근 접근 가능 화면과 차단 화면이 역할 기준과 일치 P0 권한별 캡처, 차단 메시지 확인
How To Use

미팅에서의 사용법

  • 이 표는 "TC는 반드시 필요하다"는 메시지를 보여주는 샘플입니다.
  • 외주 개발사에는 기능별 세부 케이스, 예외 케이스, 증빙 형식까지 확장해 제출하도록 요구하면 됩니다.
  • 정책 확정이 필요한 항목은 `P0-정책`, `P1-정책`처럼 따로 분리해두는 것이 안전합니다.
초안 목적: TC의 존재 자체보다, 완료 기준을 검수 가능한 형태로 잠그기 위함
