Checklist 8 Question List

미팅 질문 리스트

미팅에서 반드시 답을 받아와야 하는 질문을 영역별로 정리했습니다. 각 질문은 단순 확인용이 아니라, 이후 일정과 책임 구조를 잠그기 위한 질문입니다.

Questions

핵심 질문 12개

구분 질문 왜 필요한가 받아와야 할 답
변경관리 변경사항은 어떤 주기로 공유하고 누가 정리할 것인가? 화면 변경 시 "못 봤다" 이슈 방지 공유 주기 + 담당자
변경관리 반영 기준 버전은 언제 고정할 것인가? 병렬 개발 시 버전 혼선 방지 버전 고정 시점
변경관리 긴급 변경이 생기면 승인 루트는 어떻게 되는가? 구두 전달로 인한 오해 방지 승인자와 전달 방식
문서 검토 기획문서를 실제로 읽고 해석 승인하는 담당자는 누구인가? 해석 책임 공백 방지 담당자 이름
문서 검토 AI는 어디까지 활용하고 최종 판단은 누가 하는가? AI-only 작업 방식 차단 AI 활용 범위 + 최종 승인자
문서 검토 애매한 항목이 생기면 어떤 채널로 질의할 것인가? 추정 구현 방지 질의 채널 + 응답 SLA
QA / TC TC는 누가 작성하고 언제 제출할 것인가? 완료 기준 선확정 작성 주체 + 제출 시점
QA / TC 검수 보고서는 어떤 형식으로 받을 것인가? 검수 흔적 누락 방지 포맷 + 포함 항목
QA / TC 자동화와 수동 검수의 비율은 어떻게 가져갈 것인가? AI-only 인상 차단 도구 + 수동 확인 범위
일정 현재 일정상 병목이 될 가능성이 높은 부분은 무엇인가? 리스크 선제 확인 병목 항목 + 대응책
책임 누가 어떤 화면/기능 범위를 오너십 있게 맡는가? 책임 분산 방지 범위별 담당자
판단 기준 추후 이슈 발생 시 최종 판단 기준 문서는 무엇인가? 분쟁 시 기준점 확보 우선 문서와 버전
Usage Tip

질문 순서 추천

  1. 변경관리 3개를 먼저 묻고, 협업 방식의 큰 틀을 잠급니다.
  2. 문서 검토와 AI 활용 기준을 묻고, 해석 책임자를 명확히 합니다.
  3. 마지막으로 TC/QA와 일정/책임을 묻고 완료 기준을 고정합니다.
목적: 회의가 추상적으로 흐르지 않도록, 반드시 결정해야 할 질문을 구조화하기 위함
