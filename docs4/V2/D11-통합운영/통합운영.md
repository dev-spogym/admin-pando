## 범위 제한: IoT 상태/이벤트 수신 기준

> 기존 IoT 연동 관리는 D11의 독립 운영 화면으로 구현하지 않습니다.

D11은 IoT 장비를 등록·삭제·제어하는 화면을 제공하지 않습니다. D11에서 필요한 것은 통합 출석, 락커 운영, 체성분 화면에 표시할 상태값과 이벤트 수신값입니다.

| 기기 종류 | CRM에서 사용하는 값 | D11 표시 위치 |

| 출입 게이트 | 출입 성공/실패 이벤트, OK/불안정/오류 상태, 마지막 통신 시각 | SCR-I001 통합 출석 관리 |
| 키오스크 | 출석 체크인 성공/실패 이벤트, OK/불안정/오류 상태, 마지막 통신 시각 | SCR-I001 통합 출석 관리 |

### 3. D11에서 허용되는 액션
| 액션 | 설명 |
|---|---|
| 상태 새로고침 | 현재 화면에 표시 중인 상태 배지와 마지막 수신 시각만 갱신 |

## SCR-I004 옷 락커 운영 관리

> 유형: 화면
> URL 경로: `/clothing-locker`
> 연결 기능: `FAC-EXT-01`, `IoT-04`

### 1. 목적
출석과 연동되는 당일용 옷 락커를 실시간으로 운영한다. 락커 그리드에서 사용 현황을 한눈에 파악하고, 출석 완료 후 미배정 상태인 회원에게 락커를 배정하거나 회수할 수 있다.

### 2. UI 구성
### 상단 현황 카드

| 항목 | 설명 |
|------|------|
| 전체 락커 수 | 지점 등록 옷 락커 총 수량 |
| 사용 중 | 현재 배정된 락커 수 |
| 미배정 대기 | 출석 완료 후 락커 미배정 인원 수 |
| 점검 중 | 고장·청소 처리된 락커 수 |

### 락커 그리드

락커를 번호 순서로 격자 형태로 표시하며, 상태별 색상 배지로 구분한다.

| 상태 | 설명 |
|------|------|
| 빈 락커 | 배정 가능 상태 |
| 사용 중 | 회원 배정 완료 |
| 당일용 옷 락커 만료 임박 | 당일 마감 시간 근접 |
| 반납 지연 | 퇴실 후 미반납 상태 |
| 점검 중 | 고장 또는 청소 처리 중 |

### 미배정 회원 패널

화면 우측 또는 하단 패널로 오늘 출석 후 락커 미배정 상태인 회원 목록을 표시한다.

| 항목 | 설명 |
|------|------|
| 회원명 | 미배정 대기 회원 이름 |
| 출석 시각 | 체크인 완료 시각 |
| 이용권 상품명/유형 | 실제 구매한 회원권·수강권 상품명 또는 이용권 유형 |
| 배정 버튼 | 해당 회원에게 빈 락커 배정 |

### 버튼

| 버튼 | 설명 |
|------|------|
| 미배정 회원 보기 | 미배정 패널 열기/닫기 |
| 회원 배정 | 선택 회원과 선택 락커 배정 처리 |
| 회수 | 배정된 락커에서 회원 연결 제거 |
| 고장 처리 | 해당 락커를 점검 상태로 변경 |
| 복구 | 점검 상태 락커를 정상 복구 |
| 일괄 해제 | 만료·반납 지연 락커 일괄 회수 |

### 3. 액션 / 흐름
1. 화면 진입 → 락커 그리드 + 상단 현황 카드 표시
2. 미배정 회원 있음 → 상단 카드 '미배정 대기' 수치 강조 → 패널 열기 유도
3. 미배정 회원 선택 → 빈 락커 선택 → 배정 버튼 클릭 → 배정 완료
4. 락커 클릭 → 사용 중이면 배정 회원 정보 팝업 표시
5. 사용 중 락커 → 회수 버튼 클릭 → 확인 후 회수 처리
6. 고장 락커 → 복구 버튼 클릭 → 정상 상태 복원
7. 일괄 해제 → 대상 락커 목록 확인 팝업 → 일괄 처리

### 4. 핵심 상태

| 미배정 대기 있음 | 미배정 카드 강조, 패널 자동 열기 유도 |
| 락커 전체 사용 중 | '빈 락커 없음' 안내 표시 |
| 일괄 처리 중 | 처리 중 로딩 표시 |
| 빈 상태(락커 미등록) | '등록된 락커가 없습니다.' 안내 |

## SCR-I005 고정 물품 락커 관리

> 유형: 화면
> URL 경로: `/locker/management`
> 연결 기능: `FAC-EXT-01`, `IoT-04`

### 1. 목적
상품 계약 기반으로 회원에게 장기 배정하는 개인 소지품 보관 락커를 관리한다. 배정 현황 조회, 신규 배정, 만료 연장, 회수를 처리하며 락커 계약 만료 예정 회원을 사전에 관리한다.

동일한 `/locker/management` 화면 안에서 D06 `SCR-051 사물함 배정 관리`와 함께 탭 또는 섹션으로 표시됩니다. SCR-I005는 고정 물품 락커 탭이며, 사용 가능 상태의 락커에만 회원을 배정할 수 있습니다. 정비중·고장·사용불가 상태의 락커는 배정 클릭을 차단하고 "회원 배정 불가"를 표시합니다.
