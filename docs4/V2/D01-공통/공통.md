## SCR-102 사이드바 네비게이션

> 유형: 화면
> URL 경로: `(전체 화면 공통)`
> 연결 기능: `MFN-SCR-102`

### 1. 목적
모든 화면에서 공통으로 사용되는 좌측 메뉴 영역으로, 시스템의 주요 기능으로 이동할 수 있는 네비게이션입니다.
계정 역할에 따라 접근 가능한 메뉴 항목이 다르게 표시됩니다.

### 2. UI 구성
- 브랜드 로고 (클릭 시 계정 역할의 기본 작업공간으로 이동)
- 지점명 표시
- 메뉴 항목 목록 (아이콘 + 텍스트)
- 현재 위치 강조 표시
- 접기/펼치기 버튼 (아이콘만 보기로 전환)
- 슈퍼관리자 전용 본사 관리 섹션
- 권한 없는 메뉴 자동 숨김 로직

### 3. 액션 / 흐름
1. 원하는 메뉴 클릭 → 해당 화면으로 이동
2. 현재 위치한 메뉴가 강조 표시됨
3. 현재 경로에 맞는 메뉴 그룹이 자동으로 펼쳐짐
4. 브랜드 로고 클릭 시 현재 역할의 기본 작업공간으로 복귀
5. 좁은 화면 또는 접기 버튼 클릭 시 아이콘만 표시
6. 모바일에서는 햄버거 버튼으로 사이드바 열기/닫기

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 펼침 | 메뉴명 + 아이콘 모두 표시 |
| 접힘 | 아이콘만 표시 (마우스 올리면 툴팁) |
| 모바일 열림 | 전체화면 오버레이로 표시 |
| 모바일 닫힘 | 숨김 상태 |

### 5. 권한
| 계정 유형 | 표시되지 않는 메뉴 |
|---|---|
| 슈퍼관리자 | 없음, 본사 관리 섹션 추가 노출 |
| primary / Owner(지점장) / manager | 본사 전용 메뉴 숨김 |
| FC | 매출·설정·직원관리 등 운영 메뉴 제한, 수업/회원 중심 노출 |
| 스태프 | 출석·회원·POS·시설 위주 메뉴만 노출 |
| 조회전용 | 급여 명세서, 예약 조회 등 읽기 전용 메뉴만 노출 |

### 6. 필수 예외처리
| 케이스 | 처리 |
|---|---|
| 권한 없는 URL 직접 접근 | SCR-108 403 에러 페이지로 리다이렉트 |
| 모바일 화면 회전 | 오버레이 상태 초기화, 현재 모드 재계산 |
| 세션 만료 중 메뉴 클릭 | DLG-000 세션 만료 다이얼로그 표시 |

### 8. 핵심 디자인 요청사항
- 공통 색상, 간격, 폰트, 토스트 규칙은 `_공통/디자인_시스템.md`, `_공통/토스트_메시지.md`를 따른다.
- 본 섹션에 별도 명시된 UI 상태와 권한 차이가 있으면 도메인 공통보다 화면 정의를 우선한다.

## SCR-103 글로벌 검색

> 유형: 화면
> URL 경로: `(전체 화면 공통 - 상단 검색창)`
> 연결 기능: `MFN-SCR-103`

### 1. 목적
어느 화면에서든 상단 검색창을 통해 회원, 직원, 수업, 상품 등을 빠르게 찾을 수 있는 통합 검색 기능입니다.

### 2. UI 구성
- 상단 검색 입력창 (클릭 또는 단축키로 열기)
- 검색어 입력 영역
- 검색 결과 드롭다운 (카테고리별 구분)
  - 회원
  - 직원
  - 수업
  - 상품
- 최근 검색어 목록
- 결과 클릭 시 해당 상세 화면으로 이동

### 3. 액션 / 흐름
1. 상단 검색창 클릭 (또는 Cmd+K) → 검색 오버레이 열림
2. 검색어 입력 시 실시간으로 결과 표시
3. 결과 항목 클릭 → 해당 화면으로 이동
4. ESC 키 또는 바깥 클릭으로 닫기

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 닫힘 | 상단 검색 아이콘/바만 표시 |
| 열림 (초기) | 최근 검색어 표시 |
| 검색 중 | 입력하면서 실시간 결과 표시 |
| 결과 없음 | "검색 결과가 없습니다" 안내 |

### 5. 권한
| 계정 유형 | 검색 가능 범위 |
|---|---|
| 슈퍼관리자 | 전체 지점 데이터 |
| Owner(지점장) / 매니저 / FC | 소속 지점 데이터만 |
| 트레이너 / 스태프 | 담당 회원 및 수업만 |

### 6. 필수 예외처리
| 케이스 | 처리 |
|---|---|
| 검색어 2자 미만 | 결과 표시 안 함, 최근 검색어 유지 |
| 결과 없음 | "검색 결과가 없습니다" 안내 |
| 오프라인 | 오프라인 안내, 검색 비활성 |
| 권한 없는 카테고리 | 해당 카테고리 섹션 미노출 |

### 8. 핵심 디자인 요청사항
- 공통 색상, 간격, 폰트, 토스트 규칙은 `_공통/디자인_시스템.md`, `_공통/토스트_메시지.md`를 따른다.

## SCR-105 프로필 / 계정 설정

> 유형: 화면
> URL 경로: `/profile`
> 연결 기능: `MFN-SCR-105`
> 연결 다이얼로그: `DLG-004` 저장 확인

### 1. 목적
현재 로그인한 계정의 개인 정보를 확인하고 수정하는 화면입니다.
이름, 연락처, 비밀번호 변경 등 기본 계정 관리를 할 수 있으며, `직원 1명 = 로그인 계정 1개` 정책에 따라 현재 직원에게 발급된 로그인 계정의 보안 상태를 함께 확인하는 개인 보안 관리 화면입니다.

### 2. UI 구성
- 프로필 사진 (업로드/변경)
- 이름
- 로그인 ID (읽기 전용)
- 이메일 (비밀번호 재설정 / 보안 알림 수신용)
- 연락처
- 소속 지점명
- 역할/직책
- 비밀번호 변경 버튼
- 저장 버튼
- 2단계 인증 설정 (활성화/비활성화)
- 최근 로그인 이력 요약
- 활성 세션 / 접속 기기 목록
- 다른 기기 로그아웃 버튼
- 첫 로그인 후 비밀번호 변경 필요 여부 배지
- 계정 상태 표시 (정상 / 잠금 / 비활성)
- 로그아웃 버튼

### 3. 액션 / 흐름
1. 상단 우측 프로필 아이콘 클릭 → 프로필 메뉴 열림
2. "내 계정" 또는 "프로필" 클릭 → 이 화면으로 이동
3. 기본 정보, 2FA, 최근 로그인 이력, 활성 세션 상태를 함께 확인
4. 정보 수정 후 저장 버튼 클릭 → 완료 안내
5. 비밀번호 변경 클릭 → 비밀번호 재설정 화면으로 이동
6. 다른 기기 세션 종료 클릭 시 해당 세션 즉시 만료
7. 계정이 잠금 상태라면 관리자 문의 안내와 함께 self-service 해제 불가를 표시

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 기본 | 현재 정보 표시 |
| 편집 중 | 입력 필드 활성화 |
| 저장 중 | 저장 버튼 처리 중 |
| 저장 완료 | 완료 토스트 메시지 표시 |
| 잠금 상태 | 계정 잠금 배지 + 보안 안내 표시 |
| 세션 만료 예정 | 자동 로그아웃 경고 토스트 표시 |

### 5. 권한
| 계정 유형 | 특이사항 |
|---|---|
| 슈퍼관리자 | 이름·연락처·사진·2FA·세션 관리 가능. 역할·소속 지점은 이 화면에서 읽기 전용이며 변경은 D09 권한 관리 또는 D07 직원 관리에서 처리 |
| 일반 계정 | 역할·소속 지점·권한 템플릿은 읽기 전용, 본인 보안 설정만 수정 가능 |
| readonly | 조회만 가능, 저장 버튼 비활성 |

### 6. 필수 예외처리
| 케이스 | 처리 |
|---|---|
| 이름 빈값 제출 | "이름을 입력해주세요" 인라인 오류 |
| 연락처 형식 오류 | "올바른 연락처 형식을 입력해주세요" 인라인 오류 |
| 이미지 용량 초과 | "5MB 이하 이미지를 선택해주세요" 오류 안내 |
| 이미지 형식 불일치 | "jpg, png, gif 형식만 지원합니다" 오류 안내 |
| 2FA 확인 코드 불일치 | "인증 코드가 올바르지 않습니다" 인라인 오류 |
| 잠금 계정 본인 해제 시도 | "잠금 해제는 관리자에게 문의해주세요" 안내 |
| 타 기기 로그아웃 실패 | "세션 종료에 실패했습니다" 토스트 |
| 미저장 상태 이탈 | DLG-002 이탈 경고 다이얼로그 표시 |

### 8. 핵심 디자인 요청사항
- 공통 색상, 간격, 폰트, 토스트 규칙은 `_공통/디자인_시스템.md`, `_공통/토스트_메시지.md`를 따른다.

## SCR-106 비밀번호 재설정

> 유형: 화면
> URL 경로: `/reset-password`
> 연결 기능: `MFN-SCR-106`

### 1. 목적
비밀번호를 잊어버린 사용자가 이메일 인증을 통해 새 비밀번호를 설정할 수 있는 화면입니다.

### 2. UI 구성
**1단계 - 이메일 입력**
- 이메일 입력란
- 인증 메일 발송 버튼
- 로그인 화면으로 돌아가기 링크

**2단계 - 인증 메일 확인 안내**
- 이메일 발송 완료 안내 메시지
- 이메일 재발송 버튼

**3단계 - 새 비밀번호 설정** (메일 링크 클릭 후 진입)
- 새 비밀번호 입력란
- 새 비밀번호 확인 입력란
- 비밀번호 변경 완료 버튼

### 3. 액션 / 흐름
1. 로그인 화면에서 "비밀번호 재설정" 클릭 → 이 화면 진입
2. 가입된 이메일 입력 → 인증 메일 발송
3. 이메일 수신 → 메일의 링크 클릭
4. 새 비밀번호 입력 및 확인 → 변경 완료
5. 로그인 화면으로 자동 이동

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 이메일 입력 | 1단계: 이메일 입력 대기 |
| 메일 발송 완료 | 2단계: 인박스 확인 안내 |
| 새 비밀번호 입력 | 3단계: 새 비밀번호 설정 |
| 완료 | 변경 완료 후 로그인 안내 |
| 링크 만료 | 인증 링크 유효시간 초과 안내 |

### 5. 권한
모든 계정 동일하게 적용 (비로그인 상태에서 접근)

### 6. 필수 예외처리
| 케이스 | 처리 |
