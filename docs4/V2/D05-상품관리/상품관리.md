## SCR-P004 할인 설정

> 유형: 화면
> URL 경로: `/discount-settings`
> 연결 기능: `PRD-04`

### 1. 목적
상품 판매 시 사용할 할인 정책을 등록·수정·삭제하고, 변경 이력을 확인하는 화면입니다. 정률(%) 또는 정액(원) 방식, 최소 계약 기간, 최대 할인 한도, 적용 상품, 적용 기간을 관리합니다.

v1 기준에서 이 화면은 할인 정책의 등록·수정·삭제·조회까지만 정의합니다. 결제 화면 자동 적용, 중복 적용, 우선순위, 직원 수동 변경 가능 여부는 개발 기준으로 삼지 않습니다.

후속 확인 기준안은 `docs2/_정책미확정_확인필요.md`의 "결제 자동 적용정책" 항목으로 관리합니다. 쿠폰/마일리지는 자동 적용하지 않고 사용자 선택 시에만 적용하며, 직원이 임의로 바꾸지 못합니다. 마일리지는 다른 혜택과 중복 가능하고, 마일리지를 제외한 할인/쿠폰/시즌특가/등급할인은 중복 적용하지 않는 방향입니다. 시즌특가와 등급할인이 동시에 걸리면 더 큰 할인 1개만 적용하는 방향이나, 고객사 확인 전까지 개발하지 않습니다.

## SCR-P005 상품 카탈로그

> 유형: 화면
> URL 경로: `/products/catalog`
> 연결 기능: `PRD-05`

### 1. 목적
센터에서 판매 중인 상품을 고객이 보기 좋은 카탈로그 형태로 안내하는 화면입니다. 회원 상담 시 직원이 태블릿이나 모니터로 보여주거나, 인쇄·공유하여 외부 홍보에 활용할 수 있습니다.

### 2. UI 구성
### 카탈로그 뷰

- 상품 카드 그리드 레이아웃
- 각 카드: 상품명, 가격, 기간/횟수, 주요 혜택 요약
- 상품 대분류별 색상 구분(회원권, 수강권, 락커, 운동복, 일반)
- GX 상품은 요가 / 필라테스 / 스피닝 / 줌바 / GX 기타 세부종목 배지를 함께 표시
- 이미지 첨부 가능 (미구현)

### 필터 바

- 1단계 상품 대분류 탭 필터 (회원권 / 수강권 / 락커 / 운동복 / 일반)
- GX 탭 선택 시 2단계 세부종목 필터 표시 (요가 / 필라테스 / 스피닝 / 줌바 / GX 기타)
- 활성 상품만 표시 (비활성 상품 제외)

### 인쇄 · 공유 기능

- 인쇄: 브라우저 인쇄 다이얼로그 연동 (카탈로그 전용 레이아웃)
- 공유: 카탈로그 페이지 링크 복사

---

### 3. 액션 / 흐름
1. **카탈로그 조회**: 화면 진입 → 활성 상품이 카드 형태로 표시
2. **필터**: 상품 유형 탭 클릭 → 해당 유형 상품만 표시
3. **카탈로그 미리보기**: [DLG-P016-카탈로그미리보기]에서 고객에게 보여질 화면 확인
4. **옵션 설정**: [DLG-P017-카탈로그설정]에서 노출 옵션 설정
5. **내용 편집**: [DLG-P018-카탈로그편집]에서 카탈로그 문구·순서 편집
6. **인쇄**: 인쇄 버튼 클릭 → 카탈로그 전용 레이아웃으로 인쇄 다이얼로그 실행

## DLG-P013-할인정책추가수정 복합 할인 정책 추가/수정

> 유형: 다이얼로그
> 연결 기능: `PRD-04`, `PRD-EXT-01`

### 1. 목적
여러 조건을 동시에 적용하는 복합 할인 정책을 등록하거나 수정하는 모달입니다. 단순 정률/정액 외에 다중 조건(기간 + 금액 한도 + 대상 상품 등)을 조합한 정책을 설정할 수 있습니다.

### 2. UI 구성
| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 정책명 | 필수 | 복합 할인 정책 이름 |
| 기본 할인 유형 | 필수 | 정률(%) / 정액(원) |
| 기본 할인 값 | 필수 | 할인율 또는 금액 |
| 추가 조건 | 선택 | 최소 계약 기간, 최대 할인 한도 |
| 적용 기간 | 선택 | 정책 유효 시작일 ~ 종료일 |
| 활성 상태 | 선택 | 활성/비활성 |

하단 버튼: **취소** / **저장**

---

### 3. 액션 / 흐름
1. 정책명, 할인 유형, 할인 값 등 필수 항목 입력
2. 추가 조건 및 적용 기간 선택 (선택 사항)
3. "저장" 버튼 클릭
   - 필수 항목 미입력 시: 안내 메시지
   - 정상 저장 시: 모달 닫힘 + 목록 갱신
4. "취소" 클릭: 모달 닫힘

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
