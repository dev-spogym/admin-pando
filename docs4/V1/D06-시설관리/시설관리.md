## SCR-050 락커 관리

> 연결 기능: 없음 (V1 범위 직접 연결 기능 없음; 공통/보조 화면 또는 V2 기능은 V2 문서에서 관리)
### 2. UI 구성

- **현황 요약 카드**: 전체 락커 수 / 사용중 수 / 만료 임박 수 / 고장 수를 화면 상단에 4개 카드로 표시합니다.

- **자동 회수 정책 상태 배지**: D09 `SCR-080A 지점 자동화 적용`에서 현재 적용 중인 만료 경과 자동 회수, 이용권 만료 이벤트 자동 회수의 ON/OFF 상태를 읽기 전용으로 표시합니다.

- **구역 탭**: A구역 · B구역 · C구역으로 탭을 분리하여 원하는 구역료 집중해서 볼 수 있습니다.

- **보기 전환**: 박스 뷰 / 리스트 뷰를 전환할 수 있습니다. 박스 뷰는 실제 배치와 상태 시각화에, 리스트 뷰는 대량 검색과 정렬에 적합합니다.

- **상태 필터 칩**: 전체 / 사용중 / 미배정 / 만료 임박 / 고장 필터를 칩 형태로 제공하고 각 상태 건수를 함께 표시합니다.

- **락커 배치 그리드**: 실제 락커 배치와 동일한 형태의 격자 화면으로 각 락커를 색상으로 구분합니다.

  - 사용중: 파란색 계열 / 만료 임박(HQ-09 락커 만료 본사 step 또는 지점 추가 step 대상): 주황색 계열 / 고장: 빨간색 계열 / 빈 락커: 회색

  - 각 셀에 락커 번호, 회원명(배정 시), 남은 일수를 표시합니다.

  - 셀에 마우스를 올리면 기록 · 이동 · 회수 · 배정 · 고장 처리 버튼이 나타납니다.

- **리스트 뷰 테이블**: 락커 번호 / 구역 / 상태 / 배정 회원 / 상품명 / 시작일 / 만료일 / 남은 일수 / 비고 / 액션 컬럼을 제공합니다.

- **색상 범례**: 그리드 하단에 상태별 색상 의미를 안내합니다.

- **검색창**: 락커 번호 또는 배정된 회원명으로 빠르게 해당 락커를 찾을 수 있습니다.

- **미배정 우측 패널**: 빈 락커를 클릭하면 우측에서 회원 검색 패널이 열리고, 회원 검색·추천 후보·만료일 입력 후 바로 배정할 수 있습니다.

- **만료 임박 일괄 해제**: 탭 우측에 버튼을 클릭하면 만료 임박 락커를 선택해 한 번에 회수할 수 있습니다.

### 3. 액션 / 흐름

1. 화면 진입 시 현황 요약 카드와 A구역 그리드가 기본으로 표시됩니다.

2. 구역 탭·상태 필터·보기 전환을 조합해 현재 작업 문맥(시각화/검색/배정)을 선택합니다.

3. 검색창에 락커 번호·회원명을 입력해 원하는 락커를 찾습니다.

4. 박스 뷰에서는 셀 hover로 액션 버튼을 보고, 리스트 뷰에서는 행 액션 메뉴에서 동일 동작을 수행합니다.

5. 빈 락커: [배정] 버튼 또는 셀 클릭 → 우측 회원 검색 패널 오픈 → 회원 선택 → 만료일 입력 → 배정 완료.

8. 일괄 배정: [일괄 배정] 버튼 클릭 → 빈 락커를 클릭해 선택 → 회원·만료일 입력 → 한 번에 배정.

### 1. 목적
센터 내 일일 사물함·개인 사물함·골프 사물함의 실시간 이용 현황을 시각적 그리드로 보여주고, 회원을 검색해 빈 사물함에 즉시 배정할 수 있는 화면입니다. 일반 락커 관리(SCR-050)가 장기 배정 관리에 초점을 맞춘다면, 이 화면은 당일 또는 단기 보관용 사물함(개인 소지품 보관)의 빠른 배정·해제에 초점을 맞춥니다.

동일한 `/locker/management` 화면 안에서 D11 `SCR-I005 고정 물품 락커 관리`가 별도 탭 또는 섹션으로 함께 표시됩니다. SCR-051은 사물함 배정 운영 탭, SCR-I005는 상품 계약 기반 고정 물품 락커 운영 탭으로 구분합니다.

### 2. UI 구성
- **현황 요약 카드**: 총 사물함 수 / 사용 가능 수 / 사용중 수 / 시간 초과 수 / 상태 비정상 수를 5개 카드로 표시합니다.
- **자동 회수 정책 상태 배지**: D09 `SCR-080A 지점 자동화 적용`의 일일 사물함 22:00 상태 갱신(고정 ON)과 실제 일괄 회수 ON/OFF 상태를 읽기 전용으로 표시합니다.
- **사물함 유형 탭**: 일일 사물함 · 개인 사물함 · 골프 사물함으로 탭을 분리합니다. 각 탭에 현재 사물함 수를 표시합니다.
- **회원 배정 패널**: 탭 영역 상단에 배치됩니다.
  - 회원 검색 자동완성: 회원명 · 회원번호 · 연락처로 검색해 선택합니다.
  - 추천 사물함: 사용 가능한 사물함 중 번호가 가장 작은 것을 자동 추천합니다.
  - 만료일 입력: 배정 기간을 설정합니다 (기본값: 오늘로부터 3개월 후).
  - [배정하기] 버튼: 회원과 사물함이 모두 선택된 경우에만 활성화됩니다.
- **사물함 그리드**: 현재 탭의 사물함 전체를 격자로 표시합니다.
  - 빈 사물함: 클릭하면 해당 사물함이 배정 대상으로 선택됩니다.
  - 사용중: 파란색 / 시간 초과: 경고 아이콘 + 주황색 / 상태 비정상: 빨간색 (클릭 불가).
- **만료 사물함 일괄 해제**: 시간 초과(overtime) 상태 사물함을 한 번에 해제합니다.

### 3. 액션 / 흐름
1. 화면 진입 시 일일 사물함 탭이 기본 표시됩니다.
2. 회원 검색창에 이름·번호·연락처를 입력하면 자동완성 목록이 나타나고 회원을 선택합니다.
3. 추천 사물함이 자동 표시되거나, 그리드에서 원하는 빈 사물함을 직접 클릭해 선택합니다.
4. 만료일을 확인·수정한 뒤 [배정하기]를 클릭하면 배정 완료 메시지가 3초간 표시됩니다.
5. 시간 초과 사물함이 있을 경우 [만료 사물함 일괄 해제] 버튼이 활성화되어 한 번에 해제할 수 있습니다.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|

| 시간 초과 사물함 | 경고 아이콘과 함께 주황색으로 표시, 깜빡임 효과 적용 |

| 사용 가능 사물함 없음 | 추천 사물함 영역에 "사용 가능한 사물함 없음" 안내 |

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 빈 사물함 0개 | "사용 가능한 사물함 없음" + 배정 영역 비활성 | 일괄 해제 안내 |
| 회원 검색 0건 | "검색 결과가 없어요" | 검색어 조정 |
| 회원 미선택 + [배정하기] | 버튼 비활성, "회원을 먼저 선택해주세요" | 회원 선택 유도 |
| 만료일 과거 입력 | 인라인 "과거 일자로 배정할 수 없습니다" | 저장 차단 |
| 상태 비정상 사물함 클릭 | 토스트 "상태 비정상 사물함은 배정 불가" | 점검 안내 |
| 이미 사물함 보유 회원 추가 배정 | 모달 + 기존 번호 노출 | [회수 후 재배정]/[추가 허용 권한자]/[취소] |
| 일괄 해제 0개 | 버튼 비활성 | - |
| 시간 초과 100개 초과 일괄 해제 | "백그라운드 처리, 진행률 토스트" | 완료 시 알림 |
| 동시 배정 충돌 | "이미 배정되었습니다, 새로고침하세요" | 재추천 |
| 사물함 번호 중복 등록 시도 | 인라인 "동일 번호가 이미 존재합니다" | 저장 차단 |
| 권한 부족 액션 | 버튼 hidden 또는 "권한이 없습니다" | - |
| 본사 통합 모드 다른 지점 변경 시도 | 지점 컨텍스트 안내 | 컨텍스트 전환 |
| 자동완성 응답 지연 | 스피너 표시 | 타임아웃 시 재시도 |
| 시간 초과 알림 발송 실패 | 사물함 처리 성공, 알림 재시도 큐 등록 | 큐 모니터링 |
| 엑셀 다운로드 30,000행 초과 | "범위를 좁혀주세요" | 필터 적용 |
