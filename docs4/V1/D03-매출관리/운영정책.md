## 2. 상태 / 운영 정의

- **카운터 매니저 일반 회원권 등록**: POS에서 1년 회원권 장바구니 구성 → 외부 POS 카드 결제 완료 → 영수증 첨부 → 회원권 즉시 활성

- 영수증 파일 첨부는 현장 판매 결제 등록의 필수 조건이다. 첨부가 없으면 결제 완료 등록 버튼은 활성화되지 않는다.

- 상품별 수납 행 합계가 장바구니 최종 합계와 정확히 일치해야 결제 완료 등록이 가능하다. 각 상품 행의 결제금액은 해당 상품의 최종금액으로 고정하며, 같은 상품 안에서 금액을 나누어 카드/현금/계좌이체로 분할하지 않는다. 불일치하면 차액을 붉은색으로 표시하고 버튼을 비활성화한다.

- CRM 내부 결제 식별은 `결제그룹` 기준으로 관리한다. 하나의 장바구니 결제 등록에는 CRM 내부 승인번호 1개를 자동 부여하며, 장바구니 상품이 여러 개여도 내부 승인번호는 상품별로 나누지 않는다. 회원 결제내역, 영수증/인보이스, 취소/환불 진입은 이 내부 승인번호를 기준으로 묶어 조회한다.

- 상품별 수납 행은 내부 승인번호 아래의 하위 행이며 결제 상품 목록과 1:1로 생성한다. 각 상품 행은 카드/현금/계좌이체 중 하나를 독립 선택하고, 카드 행은 외부 POS/VAN 승인번호와 단말 ID를, 현금 행은 현금영수증 처리 정보를, 계좌이체 행은 이체확인번호와 입금자명을 입력한다. 계좌이체 입금자명은 회원명과 달라도 허용하며 직원이 확인한 실제 입금자명을 필수로 남긴다.

- 상품별 혼합결제는 상품 행 단위로만 지원한다. 장바구니 각 상품은 정가, 수동 할인, 최종 상품금액, 상품별 결제금액, 미수 잔액을 가진다. 결제 등록 시 `상품별 결제금액 = 상품별 최종금액`, `전체 상품별 결제금액 합계 = 장바구니 최종 합계`가 모두 일치해야 한다. 예를 들어 12개월 이용권 300,000원과 1개월 이용권 100,000원을 함께 결제하면 하나의 CRM 내부 승인번호 아래에 두 상품 행을 만들고, 각 행마다 카드/현금/계좌이체 중 하나를 선택한다.

- 수납행 취소와 상품 환불/계약 취소는 분리한다. 카드 승인 취소, 현금 반환, 계좌이체 반환처럼 결제수단 일부 또는 전체를 취소하되 상품 계약을 유지하는 경우, 취소된 수납금액은 즉시 해당 상품의 미수금으로 전환한다. 이후 동일 내부 승인번호와 상품별 수납 행을 참조해 재결제하면 미수금이 완납 처리된다.

- 카드 승인 건은 기본적으로 외부 승인금액 단위 전체 취소를 원칙으로 본다. 상품 일부 취소나 결제수단 일부 변경이 필요한 경우 CRM은 취소 대상 상품별 수납 행과 취소 금액을 기록하고, 취소로 비는 금액을 미수금으로 남긴 뒤 새 상품별 수납 행으로 재결제하게 한다.

- 상품 자체를 해지하거나 이용권을 환불하는 경우에는 상품 환불/계약 취소 플로우로 처리한다. 이때는 매출과 계약을 줄이는 환불이므로, 상품을 계속 유지하는 수납행 취소처럼 자동 미수금을 만들지 않는다.
