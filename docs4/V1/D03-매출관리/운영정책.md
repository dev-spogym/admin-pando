## 2. 상태 / 운영 정의

- POS 판매 화면(SCR-S002)에서 구성한 장바구니를 결제완료 상태로 확정하는 기능이다. 현장 판매에서는 CRM이 카드 PG 승인을 직접 수행하지 않는다. 인포데스크(FC)가 외부 POS 단말 또는 현금/계좌이체 수납으로 실제 결제를 먼저 완료하고, CRM에는 혼합결제 행, 포인트 사용액, 결제일시, 영수증 파일, VAN/POS 결과, 지점 귀속 필드를 등록한다. 등록이 성공하면 별도 매니저 승인 없이 결제완료와 회원권/수강권/락커/운동복/일반 상품 구매 완료가 즉시 반영된다.

- **카운터 매니저 일반 회원권 등록**: POS에서 1년 회원권 장바구니 구성 → 외부 POS 카드 결제 완료 → 영수증 첨부 → 회원권 즉시 활성

- 영수증 파일 첨부는 현장 판매 결제 등록의 필수 조건이다. 첨부가 없으면 결제 완료 등록 버튼은 활성화되지 않는다.

- `혼합결제 행 합계 + 포인트 사용액 = 장바구니 최종 합계`가 정확히 일치해야 결제 완료 등록이 가능하다. 불일치하면 차액을 붉은색으로 표시하고 버튼을 비활성화한다.
