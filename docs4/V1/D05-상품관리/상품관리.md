### D05 다이얼로그 ID 원칙
- D05에서는 `P001`처럼 번호만 축약해 부르지 않습니다. 항상 `DLG-P001-상품등록모달`처럼 전체 ID를 사용합니다.
- 상품 등록과 상품 상세/수정은 실제 프론트 기준으로 같은 상품 패널 입력 UI를 공유합니다. 신규 등록은 `isNew=true` 상태, 기존 상품 조회/수정은 상품 데이터가 채워진 상태로 구분합니다.
- `DLG-P001-상품등록모달`은 별도 컴포넌트명이 아니라, 공유 상품 패널의 신규 등록 상태를 가리키는 기획 식별자입니다.
- 별도 상품 수정 전용 모달은 사용하지 않습니다. 기존 상품 수정은 `SCR-P003 상품 상세/수정 패널`에서 같은 패널 UI로 바로 처리합니다.
- 전 지점 배포부터 시즌가격 등록/수정까지 모든 다이얼로그는 P001~P023 번호대를 사용하되, 문서 참조 시에는 항상 `DLG-P001-상품등록모달` 같은 전체 ID로 표기합니다.

## SCR-P001 상품 관리

> 유형: 화면
> URL 경로: `/products`
> 연결 기능: `PRD-01`

### 1. 목적
센터에서 판매하는 모든 상품(회원권, 수강권, 락커, 운동복, 일반 상품)을 한눈에 파악하고 관리하는 메인 화면입니다. 상품별 가격, 이용 기간, 요일·시간 제한, 판매 현황을 목록으로 조회하고, 우측 패널을 통해 상세 정보를 확인하거나 수정할 수 있습니다.

### 2. UI 구성
### 상단 통계 카드

| 카드 | 설명 |
|------|------|
| 전체 상품 수 | 센터에 등록된 상품 총 개수 |
| 활성 상품 수 | 현재 판매 중인 상품 수 |
| 비활성 상품 수 | 판매 중지된 상품 수 |
| 카테고리 수 | 등록된 상품 분류 개수 |

### 3단계 필터

| 단계 | 필터 유형 | 옵션 |
|------|-----------|------|
| 1단계 | 상품 대분류 탭 | 전체 / 회원권 / 수강권 / 락커 / 운동복 / 일반 |
| 2단계 | 세부 유형 필터 | 1단계 선택값에 따라 동적 표시. 수강권 선택 시 PT / GX / 골프 / 기타 수강권, GX 선택 시 요가 / 필라테스 / 스피닝 / 줌바 / GX 기타 |
| 3단계 | 상품그룹 필터 | 상품관리 "분류 관리" 탭에서 등록한 상품그룹. 선택한 대분류 안에서만 표시 |

- 우측 상단에 상품명 검색 입력창 제공

### 상품 마스터 분류 모델

상품 마스터는 5개 대분류를 정본으로 사용합니다.

| 단계 | 필드 | 값 |
|------|------|------|
| 1단계 | 상품 대분류 `category` | `MEMBERSHIP`(회원권) / `LESSON_PASS`(수강권) / `LOCKER`(락커) / `WEAR`(운동복) / `GENERAL`(일반) |
| 2단계 | 세부 유형 `lessonType` 또는 `subCategory` | 수강권은 PT / GX / 골프 / 기타 수강권으로 구분하고, GX 세부종목은 별도 고정 옵션으로 관리 |
| 3단계 | 상품그룹 `productGroupId` | 상품관리 "분류 관리" 탭의 그룹을 우선 표시 |

수강권에서 GX를 선택하면 GX 세부종목은 아래 5개로 고정합니다.

| 대분류 | 세부종목 |
|------|------|
| GX | 요가 / 필라테스 / 스피닝 / 줌바 / GX 기타 |

- `category=LESSON_PASS`이고 `lessonType=GX`인 상품은 GX 세부종목 선택이 필수입니다.
- `productGroupId`가 있는 상품은 연결된 `product_groups.name`을 목록 분류 필터와 상품명 배지에 우선 표시합니다.
- `productGroupId`가 없는 상품은 `category`의 한글 표시명(회원권/수강권/락커/운동복/일반)을 fallback으로 사용합니다.
- 이 세부종목 값은 SCR-S004 매출통계의 GX종목별 탭과 SCR-094 KPI 대시보드의 GX 세부 종목 분포 집계 기준입니다.

### 상품 목록 테이블

패널이 닫혀 있을 때 전체 컬럼이 표시됩니다.

| 컬럼 | 내용 |
|------|------|
| 상품명 | 유형 배지 + 패키지 배지 + 운영정책 배지(단일지점/법인/홈&오피스/주말/통합) + 상품명 |
| 대분류 | 상품 대분류 |
| 세부종목 | 종목·세부종목. GX 상품은 5개 고정 옵션 중 하나 |
| 이용 가능 지점 | 단일/복수/전체 지점 요약 |
| 정산 정책 | 이용지점 기준 / 판매지점 기준 / 지정 정산지점 |
| 현금가 | 현금 결제 시 가격 |
| 카드가 | 카드 결제 시 가격 |
| 기간 | 이용 가능 기간 (일 단위) |
| 횟수 | 이용 가능 횟수 |
| 요일 (월~일) | 이용 가능 요일 표시 (체크/엑스) |
| 시간 | 이용 가능 시간대 |
| 홀딩 | 홀딩(일시정지) 가능 여부 |
| 양도 | 양도 가능 여부 |
| 포인트 | 포인트 적립 여부 |
| 판매 | 해당 상품 판매 건수 |
| 상태 | 사용 / 미사용 |

> 우측 상세 패널이 열리면 요일/시간/홀딩/양도/포인트/판매 컬럼은 자동으로 숨겨지고 핵심 컬럼만 표시됩니다.

### 분류 관리 탭

- 분류 목록 테이블: 분류명 / 정렬 순서 / 상태 / 수정·삭제 버튼

### 3. 액션 / 흐름
1. **상품 조회**: 화면 진입 시 센터 전체 상품 목록 표시 → 필터/검색으로 원하는 상품 찾기
2. **상품 상세 보기**: 목록에서 상품 행 클릭 → 우측에 상세 패널이 슬라이드로 열림
3. **상품 등록**: 상단 "+ 상품 등록" 버튼 클릭 → 우측 패널이 등록 모드로 열림
4. **분류 관리**: "분류 관리" 탭 클릭 → 상품 분류 등록/수정/삭제
5. **전 지점 배포** (슈퍼관리자): "전 지점 배포" 버튼 → 배포 모달에서 상품·지점 선택 후 일괄 배포
6. **Excel 내보내기**: "Excel" 버튼 → 현재 필터된 상품 목록을 엑셀 파일로 다운로드

## DLG-P003-작업취소확인 작업 취소 확인

> 유형: 다이얼로그
> 연결 기능: `PRD-EXT-01`

### 1. 목적
상품 등록 또는 수정 작업 중 입력한 내용이 있을 때, 작업을 취소하면 변경 사항이 사라진다는 것을 사용자에게 알리고 최종 확인을 받는 다이얼로그입니다.

### 2. UI 구성
- 안내 문구: "입력한 내용이 저장되지 않습니다. 작업을 취소하시겠습니까?"
- 하단 버튼: **계속 작업** / **취소하기**

---

### 3. 액션 / 흐름
1. 작업 중 닫기 시도
2. 변경 사항 감지 시 이 다이얼로그 표시
3. "계속 작업" 클릭: 다이얼로그 닫힘, 작업 화면으로 복귀
4. "취소하기" 클릭: 변경 사항 폐기, 작업 화면 닫힘

### 4. 핵심 상태

| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |
