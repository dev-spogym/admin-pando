## SCR-P001 상품 관리

> 유형: 화면
> URL 경로: `/products`
> 연결 기능: `PRD-01`
> 원본: `docs/admin/화면설계서/D05-상품관리/SCR-P001-상품관리/00-기본화면.md` / `docs/admin/기능명세서/D05-상품관리/PRD-01-상품관리/00-기본기능.md`

### 1. 목적
센터에서 판매하는 모든 상품(이용권, PT 수강권, GX 수강권, 대여권, 일반 상품 등)을 한눈에 파악하고 관리하는 메인 화면입니다. 상품별 가격, 이용 기간, 요일·시간 제한, 판매 현황을 목록으로 조회하고, 우측 패널을 통해 상세 정보를 확인하거나 수정할 수 있습니다.

### 2. UI 구성
### 상단 통계 카드

| 카드 | 설명 |
|------|------|
| 전체 상품 수 | 센터에 등록된 상품 총 개수 |
| 활성 상품 수 | 현재 판매 중인 상품 수 |
| 비활성 상품 수 | 판매 중지된 상품 수 |
| 카테고리 수 | 등록된 상품 분류 개수 |

### 3단계 필터

| 단계 | 필터 유형 | 옵션 |
|------|-----------|------|
| 1단계 | 상품 유형 탭 | 전체 / 회원권 / 수강권 / 대여권 / 일반 |
| 2단계 | 상품 대분류 | 전체 / 이용권 / PT / GX / 상품 / 서비스 |
| 3단계 | 종목·세부종목 필터 | 2단계 선택값에 따라 동적 표시. GX 선택 시 요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX 기타 |

- 우측 상단에 상품명 검색 입력창 제공

### 상품 마스터 분류 모델

상품 마스터는 2단계 분류를 정본으로 사용합니다.

| 단계 | 필드 | 값 |
|------|------|------|
| 1단계 | 상품 대분류 `category` | `MEMBERSHIP` / `PT` / `GX` / `PRODUCT` / `SERVICE` |
| 2단계 | 상품그룹·종목·세부종목 `productGroupId` 또는 `subCategory` | 상품관리 "분류 관리" 탭의 그룹을 우선 표시하고, GX 세부종목은 별도 고정 옵션으로 관리 |

GX 대분류 선택 시 2단계 세부종목은 아래 6개로 고정합니다.

| 대분류 | 세부종목 |
|------|------|
| GX | 요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX 기타 |

- `category=GX` 상품은 세부종목 선택이 필수입니다.
- `productGroupId`가 있는 상품은 연결된 `product_groups.name`을 목록 분류 필터와 상품명 배지에 우선 표시합니다.
- `productGroupId`가 없는 상품은 `category`의 한글 표시명(이용권/PT/GX/기타)을 fallback으로 사용합니다.
- 이 세부종목 값은 SCR-S004 매출통계의 GX종목별 탭과 SCR-094 KPI 대시보드의 GX 세부 종목 분포 집계 기준입니다.

### 상품 목록 테이블

패널이 닫혀 있을 때 전체 컬럼이 표시됩니다.

| 컬럼 | 내용 |
|------|------|
| 상품명 | 유형 배지 + 패키지 배지 + 운영정책 배지(단일지점/법인/홈&오피스/주말/통합) + 상품명 |
| 대분류 | 상품 대분류 |
| 세부종목 | 종목·세부종목. GX 상품은 6개 고정 옵션 중 하나 |
| 이용 가능 지점 | 단일/복수/전체 지점 요약 |
| 정산 정책 | 이용지점 기준 / 판매지점 기준 / 지정 정산지점 |
| 현금가 | 현금 결제 시 가격 |
| 카드가 | 카드 결제 시 가격 |
| 기간 | 이용 가능 기간 (일 단위) |
| 횟수 | 이용 가능 횟수 |
| 요일 (월~일) | 이용 가능 요일 표시 (체크/엑스) |
| 시간 | 이용 가능 시간대 |
| 홀딩 | 홀딩(일시정지) 가능 여부 |
| 양도 | 양도 가능 여부 |
| 포인트 | 포인트 적립 여부 |
| 판매 | 해당 상품 판매 건수 |
| 상태 | 사용 / 미사용 |

> 우측 상세 패널이 열리면 요일/시간/홀딩/양도/포인트/판매 컬럼은 자동으로 숨겨지고 핵심 컬럼만 표시됩니다.

### 분류 관리 탭

상품 목록 탭과 분류 관리 탭을 전환할 수 있습니다.

- 분류 등록 폼: 분류명, 정렬 순서, 활성 여부 입력
- 분류 목록 테이블: 분류명 / 정렬 순서 / 상태 / 수정·삭제 버튼

### 3. 액션 / 흐름
1. **상품 조회**: 화면 진입 시 센터 전체 상품 목록 표시 → 필터/검색으로 원하는 상품 찾기
2. **상품 상세 보기**: 목록에서 상품 행 클릭 → 우측에 상세 패널이 슬라이드로 열림
3. **상품 등록**: 상단 "+ 상품 등록" 버튼 클릭 → 우측 패널이 등록 모드로 열림
4. **분류 관리**: "분류 관리" 탭 클릭 → 상품 분류 등록/수정/삭제
5. **전 지점 배포** (슈퍼관리자): "전 지점 배포" 버튼 → 배포 모달에서 상품·지점 선택 후 일괄 배포
6. **Excel 내보내기**: "Excel" 버튼 → 현재 필터된 상품 목록을 엑셀 파일로 다운로드

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 상품 0건(신규 지점) | 빈 상태 + [+ 상품 등록] CTA | 등록 안내 |
| 검색·필터 결과 0건 | 빈 안내 + [필터 초기화] | 조건 초기화 |
| 상품명 중복(동일 지점·대분류) | 인라인 "이미 등록된 상품명입니다" | 저장 차단 |
| GX 세부종목 미선택 | 빨강 인라인 + 저장 버튼 비활성 | 세부종목 선택 안내 |
| 카드가 < 현금가 | 노랑 경고 배지 | 진행 가능 |
| 카드가 > 현금가 | 빨강 인라인 + 저장 차단 | 가격 재확인 |
| 상품그룹 삭제 시도(연결 상품 존재) | 모달 + 연결 상품 {개수}개 | [그룹 이동] / [취소] |
| 전 지점 배포 일부 실패 | 진행률 모달 + 실패 지점 분리 | 실패 지점만 재시도 |
| 엑셀 1만 건 초과 | "비동기 모드 전환" 토스트 | 알림 센터 통보 |
| 폐점 지점 등록 시도 | "폐점 지점은 신규 등록 불가" | 차단 |
| 본사 통합 모드 등록 시도 | "지점을 먼저 선택해주세요" | 지점 선택 강조 |
| 패널 열림 중 다른 행 클릭(변경 있음) | DLG-P002-작업취소확인 작업 취소 확인 | [확인] / [취소] |
| 동시 수정 충돌(다른 매니저) | "다른 사용자가 먼저 저장했어요" | [최신 정보 보기] / [덮어쓰기] |
| 패키지 구성 상품 삭제 시도 | "패키지에 사용 중입니다" + 패키지 {개수}개 | 패키지 분리 후 삭제 |
| 비활성 그룹 신규 상품 등록 | "비활성 그룹은 신규 등록 불가" | 활성 전환 안내 |
| 키오스크 노출 ON + 비활성 상품 | 자동 OFF + 안내 토스트 | 키오스크 자동 제외 |
| Excel 다운로드 권한 없음 | 버튼 hidden | - |
| 분류 관리 정렬 충돌(동일 순서) | 등록일 ASC로 자동 보조 정렬 | 인라인 안내 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| 회원앱 / 키오스크 동기화 | 활성 토글·가격·노출 변경 | 5분 캐시 무효화 + 동시 갱신 |
| SCR-S003 결제처리 | 가격·할인·VAT 변경 | 결제 화면 가격 즉시 반영 |
| SCR-S004 매출통계 | 분류·세부종목 변경 | 집계 키 갱신, 분류축 재정렬 |
| SCR-094 KPI 대시보드 | 카테고리 추가·세부종목 신설 | GX 종목 분포·매출 트렌드 자동 확장 |
| PRD-05 카탈로그 | 비활성 토글 / 활성 전환 | 카탈로그 자동 노출/제외 |

| NFR-19 알림 센터 | 전 지점 배포 완료·엑셀 비동기 완료 | 운영자 알림 발송 |
| 패키지 합산 정가 자동 재계산 | 구성 상품 가격 변경 | 합산 정가 즉시 갱신, 할인가는 명시 갱신 |
| Cron - 비활성 만료 회원 정리 | 매일 04:00 | 비활성 상품 보유 회원 만료 시 정리 |
| 분류 관리 정렬 순서 충돌 보정 | 정렬 순서 저장 | 동일 순서 → 등록일 ASC 자동 보조 정렬 |

| 기본 이용지점 | 조건부 필수 | 기본 출석/예약 기준 지점 |
| 기본 매출 귀속 지점 | 조건부 필수 | KPI·매출 귀속 기본값 |
| 기본 정산 지점 | 조건부 필수 | 환불/정산 기본 기준 지점 |
| 기본 인센티브 귀속자 정책 | 조건부 필수 | 판매 담당자 / 지정 FC / 지정 트레이너 / 지점 기본값 |
| 타지점 수업 허용 | 선택 | PT/골프 등 강습 상품의 타지점 진행 허용 여부 |

### 2단계 분류 선택 규칙

| 1단계 상품 대분류 | 2단계 종목·세부종목 표시 |
|------|------|
| `MEMBERSHIP` | 헬스 / 골프 / 수영 / 복싱 / 크로스핏 / 기타 |
| `PT` | PT / 재활PT / 그룹PT / 기타 |
| `GX` | 요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX 기타 |
| `PRODUCT` | 운동복 / 락커 / 식음료 / 용품 / 기타 |
| `SERVICE` | 부가서비스 / 대여 / 기타 |

- 사용자가 1단계에서 `GX`를 선택하면 2단계 드롭다운은 반드시 6개 GX 세부종목만 표시합니다.
- `GX` 상품 저장 시 2단계 세부종목이 비어 있으면 저장 버튼을 비활성화하고 "GX 세부종목을 선택해 주세요" 오류를 표시합니다.
- 저장 데이터는 `category=GX`와 `sportType` 조합으로 상품 마스터에 기록합니다. 상품그룹은 별도 `productGroupId`로 선택 저장합니다.

| UI/상태 | 저장 컬럼 | 규칙 |

| 현재 지점 | `branchId` | 현재 선택된 지점 ID |

> 원본: `docs/admin/화면설계서/D05-상품관리/DLG-P004-비활성화안내/00-기본화면.md` / `docs/admin/기능명세서/D05-상품관리/PRD-04-할인설정/00-기본기능.md`

### 1. 목적
현재 이용 중인 회원이 있는 상품을 삭제하려 할 때, 삭제 대신 "미사용(비활성화)" 전환을 안내하는 다이얼로그입니다. 기존 회원의 이용권에 영향을 주지 않으면서 신규 판매만 중단할 수 있습니다.

### 2. UI 구성
- 안내 문구: "이 상품을 이용 중인 회원이 {인원수}명 있습니다. 삭제 대신 '미사용'으로 전환하시겠습니까?"
- 현재 이용 중인 회원 수 표시
- 하단 버튼: **취소** / **미사용으로 전환**

---

### 3. 액션 / 흐름
1. 수정 패널에서 "삭제" 버튼 클릭
2. 이용 중인 회원 수 조회 → 1명 이상이면 이 다이얼로그 표시
3. "취소" 클릭: 다이얼로그 닫힘, 상품 유지
4. "미사용으로 전환" 클릭: 상품 상태를 비활성(미사용)으로 변경 → 완료 메시지 → 패널 닫힘

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

### 5. 권한
| 계정 | 동작 기준 |
|---|---|
| owner / manager | 부모 화면에서 허용된 경우 조회·입력·저장할 수 있습니다. |
| trainer / fc / staff | 담당 업무 범위에 포함된 데이터만 조회하며, 수정 권한은 부모 화면 정책을 따릅니다. |
| readonly | 조회만 가능하며 저장·삭제·확정 같은 변경 액션은 숨기거나 비활성화합니다. |
| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 정률 값 0 또는 >100 | 인라인 "1~100% 사이" | 저장 차단 |
| 정액 값 ≤0 | "0보다 큰 금액" | 저장 차단 |
| 정액 + 한도 입력 | 한도 필드 비활성 | 정률만 한도 |
| 시작일 > 종료일 | "종료일은 시작일 이후" | 저장 차단 |

| 할인 미리보기 상품 선택 0 | 미리보기 비활성 | 상품 선택 안내 |
| 카테고리 필터 + 적용 상품 충돌 | 명시 적용 상품 우선 | 안내 토스트 |

## DLG-P005-상품가져오기 상품 정보 가져오기

> 유형: 다이얼로그
> 연결 기능: `PRD-04`, `PRD-EXT-01`
> 원본: `docs/admin/화면설계서/D05-상품관리/DLG-P005-상품가져오기/00-기본화면.md` / `docs/admin/기능명세서/D05-상품관리/PRD-04-할인설정/00-기본기능.md`

### 1. 목적
기존에 등록된 상품의 정보를 복사하여 새 상품 등록의 기초 정보로 활용하는 모달입니다. 유사한 상품을 빠르게 등록할 때 유용하며, 가져온 정보는 새 상품으로 저장되어 원본 상품에 영향을 주지 않습니다.

### 2. UI 구성
- 상품명 검색 입력창
- 현재 편집 중인 상품을 제외한 전체 상품 목록
  - 상품명, 가격, 유형 표시
  - 행 클릭으로 선택

하단 버튼: **닫기**

---

### 3. 액션 / 흐름
1. 모달 열림 → 전체 상품 목록 표시 (현재 편집 중인 상품 제외)
2. 검색어 입력으로 원하는 상품 찾기
3. 상품 행 클릭 → 해당 상품 정보가 등록 폼에 자동 입력
4. 모달 닫힘 + "상품 정보를 불러왔습니다. 등록 시 새 상품으로 저장됩니다." 안내 메시지
5. 가져온 정보를 바탕으로 수정 후 새 상품으로 등록

## DLG-P016-시즌가격등록수정 시즌 특가 등록/수정

> 유형: 다이얼로그
> 연결 기능: `PRD-08`
> 연결 다이얼로그: DLG-P016 시즌가격등록수정
> 원본: `docs/admin/화면설계서/D05-상품관리/DLG-P016-시즌가격등록수정/00-기본화면.md` / `docs/admin/기능명세서/D05-상품관리/PRD-08-시즌가격관리/00-기본기능.md`

### 1. 목적
시즌 특별 가격을 등록하거나 기존 시즌 특가를 수정하는 모달입니다. 특정 기간 동안만 적용되는 할인 가격을 상품별로 설정할 수 있습니다.

### 2. UI 구성
| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 시즌 이름 | 필수 | 예: "2026 여름 특가", "신년 이벤트" |
| 적용 시작일 | 필수 | 특가 시작 날짜 |
| 적용 종료일 | 필수 | 특가 종료 날짜 (시작일 이후) |
| 대상 상품 선택 | 필수 | 체크박스로 특가 적용 상품 1개 이상 선택 |
| 특가 설정 방식 | 필수 | 정률(%) 할인 / 정액(원) 할인 / 직접 입력 가격 |
| 특가 값 | 필수 | 할인율, 할인 금액, 또는 직접 입력 가격 |
| 활성 상태 | 선택 | 기본값: 활성 |

하단 버튼: **취소** / **저장**

---

### 3. 액션 / 흐름
**등록 모드:**
1. 빈 폼으로 모달 열림
2. 시즌명, 기간, 대상 상품, 특가 설정 입력
3. "저장" 클릭
   - 필수 항목 미입력 시: 안내 메시지
   - 종료일이 시작일보다 이르면: "종료일을 확인하세요." 안내
   - 대상 상품 미선택 시: 안내 메시지
   - 정상 저장 시: 모달 닫힘 + 목록 갱신

**수정 모드:**
1. 기존 정보가 채워진 상태로 모달 열림
2. 원하는 항목 수정
3. "저장" 클릭 → 수정 저장 + 목록 갱신
4. "취소" 클릭: 변경 사항 폐기, 모달 닫힘

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 기본 표시 | 부모 화면에서 선택한 대상의 최신 값을 불러와 표시합니다. |
| 입력/수정 중 | 필수값 누락, 형식 오류, 권한 제한을 인라인 메시지로 표시합니다. |
| 저장/처리 중 | 주요 버튼을 비활성화하고 중복 요청을 막습니다. |
| 완료 | 저장 또는 처리 성공 후 부모 화면 데이터를 갱신하고 다이얼로그를 닫습니다. |
| 실패 | 실패 사유를 토스트 또는 인라인 메시지로 안내하고 입력값은 유지합니다. |

### 5. 권한
| 계정 | 동작 기준 |

| 권한 없음 | 다이얼로그 진입을 차단하고 부모 화면에서 권한 안내를 표시합니다. |
