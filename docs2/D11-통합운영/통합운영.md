## 화면
## SCR-I001 통합 출석 관리

> 유형: 화면
> URL 경로: `/attendance`
> 연결 기능: `IoT-01`
> 연결 다이얼로그: DLG-I001 수동출석등록, DLG-I002 옷락커배정
> 원본: `docs/admin/화면설계서/D11-통합운영/SCR-I001-통합출석관리/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-01-통합출석관리/00-기본기능.md`

### 1. 목적
회원과 직원의 출석 현황을 하나의 화면에서 실시간으로 통합 조회·관리한다. 키오스크 QR, 얼굴인식, 앱 QR, 수동 입력 등 다양한 출석 채널의 데이터를 통합 집계하여 운영 효율을 높이고, 출석 후 옷 락커 배정 상태까지 함께 확인할 수 있다.

### 2. UI 구성
### 상단 통계 카드

| 항목 | 설명 |
|------|------|
| 오늘 총 출석 | 회원 + 직원 합산 입장 수 |
| 현재 센터 내 | 입장 후 퇴실 미처리 인원 수 |
| 미배정 락커 | 출석은 완료됐으나 옷 락커 미배정 인원 수 |
| 실패 건수 | 금일 출석 실패(만료·중복·미등록 등) 건수 |

### 필터 영역

| 필터 | 선택 옵션 |
|------|-----------|
| 기간 | 오늘(기본값), 이번 주, 이번 달, 직접 선택 |
| 구분 | 전체, 회원, 직원, 게스트 |
| 결과 | 전체, 성공, 실패, 중복, 퇴실 |
| 채널 | 앱 QR, 키오스크 QR, 얼굴인식, 수동 |
| 락커 상태 | 전체, 미배정, 수동배정, 자동배정, 대상 아님 |
| 검색 | 이름, 연락처, 회원번호, 사번 |

### 출석 테이블

| 컬럼명 | 설명 |
|--------|------|
| 시간 | 입장 시각 |
| 구분 | 회원 / 직원 / 게스트 |
| 이름 | 이름 + 회원번호 또는 사번 |
| 채널 | 앱 QR / 키오스크 QR / 얼굴인식 / 수동 |
| 결과 | 성공 / 실패 / 중복 / 퇴실 |
| 옷 락커 | 미배정 / 수동배정(번호) / 자동배정(번호) / 대상 아님 |
| 고정 락커 | 보유 시 락커 번호, 없으면 '-' |
| 비고 | 실패 사유 또는 운영 메모 |

### 실시간 출석 확인 카드

SCR-101 대시보드 통합과 동일한 출석 확인 위젯을 일별 뷰 상단에 배치한다.
FC·프런트는 목록 테이블을 보기 전에 가장 최근 입장 회원을 카드 단위로 확인하여 동일인 여부와 운영상 주의사항을 빠르게 판단한다.

| 항목 | 표시 규칙 |
|------|-----------|
| 카드 수 | 데스크톱 기준 최대 10개 유지 |
| 초과 처리 | 10개 초과 시 가장 먼저 출석한 카드부터 제거 |
| 중복 처리 | 동일 회원 첫 출석 후 2시간 이내 재출석은 새 카드 생성 안 함 |
| 포함 채널 | 키오스크 QR, 앱 QR, RFID/밴드, 얼굴인식, 수동 출석 |
| 표시 정보 | 사진/기본 아바타, 이름, 회원번호, 성별/나이, 이용권, 만료일, 출석 시각, 출석 채널 |
| 주의 표시 | 만료, 만료 임박, 미수금, 중복, 이용권 없음, 사진 미등록 |
| 만료 임박 기준 | 본사 자동화 정책 또는 지점 키오스크 출입 규칙에서 적용 중인 만료 안내 기준일 |
| 신규 이벤트 | 카드 4~5초 강조 + 알림음 + 토스트 |
| 사진 없음 | 기본 아바타 표시 + "사진 필요" 태그 + 현장 촬영 안내 토스트 |
| 클릭 | 회원 상세(SCR-M004) 기본정보 탭으로 이동 |

### 헤더 버튼

| 버튼 | 설명 |
|------|------|
| 수동 출석 등록 | DLG-I001 팝업 호출 |
| 실패 로그 | 실패 건만 필터링하여 표시 |
| 키오스크 모니터 | 최근 키오스크 이벤트 사이드 패널 열기 |

### 행 단위 액션

| 액션 | 설명 |
|------|------|
| 퇴실 처리 | 입장 상태의 회원·직원을 퇴실로 전환 |
| 락커 배정 | 미배정 상태에서 옷 락커 배정 화면 또는 인라인 연동 |
| 회원 상세 | 해당 회원의 상세 화면으로 이동 |

### 3. 액션 / 흐름
1. 화면 진입 시 기본값: 오늘 날짜, 전체 구분, 전체 결과
2. 키오스크·앱에서 출석 이벤트 발생 → 테이블 상단에 즉시 반영
3. 실시간 출석 확인 카드에 회원 사진·기본 정보·주의 태그 표시
4. FC가 동일인 여부를 확인하고 필요 시 카드 클릭 → 회원 상세 기본정보로 이동
5. 미배정 락커 카드 클릭 → 미배정 인원만 필터링
6. 출석 행 클릭 → 해당 회원 상세 화면으로 이동
7. 행 내 락커 배정 버튼 클릭 → DLG-I002(옷 락커 배정) 팝업 호출
8. 수동 출석 등록 버튼 → DLG-I001 팝업 호출 → 등록 완료 시 목록 자동 갱신

| 로딩 | 데이터 조회 중 스켈레톤 표시 |

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 출석 데이터 없음 | "해당 기간 출석 없음" | 기간 필터 조정 안내 |
| 검색 0건 | "검색 결과가 없습니다" | [수동 출석 등록] CTA |
| 만료 회원 출석 시도 | 결과=실패·비고="이용권 만료" | 회원 상세 → 재결제 안내 |
| 미등록 회원 출석 시도 | 결과=실패·비고="미등록" | [수동 출석 등록] 안내 |
| 중복 출석 (10분 내) | 결과=중복·비고="X분 경과" | 별도 카운트, 운영 메모 |
| 미수금 차단 정책 | 결과=실패·비고="미수금 N원" | 결제 유도 |
| 직원 출석 허용 OFF | 결과=실패·비고="직원 출석 불가" | SCR-I002 설정 안내 |
| 얼굴인식 시간 초과 | 결과=실패·비고="얼굴인식 시간 초과" | 회원 얼굴 재등록 |
| 수동 등록 미래 시각 | 인라인 "현재 시각 이후 불가" | 시각 수정 |
| 수동 등록 동일 시각 중복 | 결과=중복·토스트 안내 | 별도 행 적재 |
| WebSocket 연결 끊김 | 노란 배너 "실시간 연결 끊김" | 30초 폴링 fallback |
| 권한 부족 (강사 액션) | 버튼 hidden 또는 비활성 | - |
| 본사 통합 모드 변경 액션 | "지점 선택 후 등록 가능" | 지점 선택 안내 |
| 마감 시간 외 출석 | 결과=실패·비고="허용 시간 외" | 운영 시간 안내 |
| 통계 카드 클릭 후 필터 결과 0 | "조건에 맞는 데이터 없음" | 필터 초기화 안내 |
| 동시 퇴실 처리 (lock 충돌) | "잠시 후 다시 시도" | 재시도 |
| 퇴실 후 재방문 | 별도 행 결과=성공 | 정상 처리 |
| 게스트 출석 정책 OFF | 게스트 채널 hidden | 정책 변경 안내 |

## SCR-I002 키오스크 설정

> 유형: 화면
> URL 경로: `/settings/kiosk`
> 연결 기능: `IoT-02`
> 원본: `docs/admin/화면설계서/D11-통합운영/SCR-I002-키오스크설정/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-02-키오스크설정/00-기본기능.md`

### 1. 목적
지점별 키오스크 운영 정책을 설정한다. 출석 인식 방식(QR·RFID·얼굴인식), 대기 화면 구성, 음성 안내(TTS), 출입 규칙, 출석 후 락커 처리 정책을 한 화면에서 관리한다.

### 2. UI 구성
### 탭 구조

| 탭 | 설명 |
|----|------|
| 기본 설정 | 키오스크 활성 여부, 체크인 수단(QR·RFID·얼굴인식), 직원 출석 허용 여부 |
| 화면 설정 | 배경 이미지, 센터 로고, 환영 문구, 공지 메시지 등 키오스크 화면 구성 |
| TTS 설정 | 대기·성공·실패·만료 임박 상황별 음성 안내 문구 관리 |
| 출입 규칙 | 출입 허용 시간, 만료 회원 허용 여부, 중복 출석 방지 시간 설정 |
| 락커 후처리 | 출석 완료 후 락커 처리 정책, 자동 배정 존, 미배정 안내 문구 |

### 기본 설정 탭 주요 항목

| 항목 | 설명 |
|------|------|
| 키오스크 활성 | 지점 키오스크 사용 여부 ON/OFF |
| 체크인 수단 | QR, RFID, 얼굴인식 복수 선택 가능 |
| 직원 출석 허용 | 직원도 키오스크로 출퇴근 처리 가능 여부 |
| 얼굴인식 사용 | 얼굴인식 모듈 활성/비활성 |

### 락커 후처리 탭 주요 항목

| 항목 | 선택 옵션 |
|------|-----------|
| 출석 후 처리 정책 | 출석만 완료 / 수동 배정 대기 / 자동 배정 시도 |
| 자동 배정 존 | 자동 배정 시 탐색할 락커 존 선택 |
| 미배정 안내 문구 | 자동 배정 실패 시 키오스크 화면에 표시할 안내 문구 |

### TTS 설정 탭 주요 항목

| 이벤트 | 설명 |
|--------|------|

## SCR-I003 IoT 연동 관리

> 원본: `docs/admin/화면설계서/D11-통합운영/SCR-I003-IoT연동관리/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-03-IoT연동관리/00-기본기능.md`

### 1. 목적
지점에 설치된 IoT 장비(출입 게이트, 키오스크, 락커 컨트롤러, InBody 측정기)의 연결 상태를 모니터링하고 관리한다. 기기 등록·삭제, 연결 테스트, 출입 로그 조회, 원격 게이트 제어를 지원한다.

### 2. UI 구성
### 탭 구조

| 탭 | 설명 |
|----|------|
| 게이트 관리 | 출입문 목록, 실시간 연결 상태, 원격 개방 |
| IoT 기기 | 지점 전체 기기 목록 및 상태 배지 |
| 출입 로그 | 출입 성공·실패·예외 이벤트 이력 조회 |
| 출입 규칙 | 시간대·요일·게이트별 출입 허용 규칙 설정 |
| 자동 전원 | 키오스크·기기 전원 ON/OFF 스케줄 설정 |

### IoT 기기 탭 주요 항목

| 항목 | 설명 |
|------|------|
| 기기명 | 장비 식별 이름 |
| 유형 | 게이트 / 키오스크 / 락커 컨트롤러 / InBody |
| IP/포트 | 네트워크 연결 정보 |
| 상태 | 온라인 / 오프라인 / 오류 / 점검 중 |
| 마지막 통신 | 최근 heartbeat 시각 |
| 펌웨어 버전 | 현재 설치된 펌웨어 버전 |

heartbeat는 단말 60초 주기 송신을 기준으로 표시하며, 서버가 5분 초과 미수신을 확인하면 상태를 오프라인으로 전환합니다.

### 1. 목적
출석과 연동되는 당일용 옷 락커를 실시간으로 운영한다. 락커 그리드에서 사용 현황을 한눈에 파악하고, 출석 완료 후 미배정 상태인 회원에게 락커를 배정하거나 회수할 수 있다.

### 2. UI 구성
### 상단 현황 카드

| 항목 | 설명 |
|------|------|
| 전체 락커 수 | 지점 등록 옷 락커 총 수량 |
| 사용 중 | 현재 배정된 락커 수 |
| 미배정 대기 | 출석 완료 후 락커 미배정 인원 수 |
| 점검 중 | 고장·청소 처리된 락커 수 |

### 락커 그리드

락커를 번호 순서로 격자 형태로 표시하며, 상태별 색상 배지로 구분한다.

| 상태 | 설명 |
|------|------|
| 빈 락커 | 배정 가능 상태 |
| 사용 중 | 회원 배정 완료 |
| 만료 임박 | 당일 마감 시간 근접 |
| 반납 지연 | 퇴실 후 미반납 상태 |
| 점검 중 | 고장 또는 청소 처리 중 |

### 미배정 회원 패널

화면 우측 또는 하단 패널로 오늘 출석 후 락커 미배정 상태인 회원 목록을 표시한다.

| 항목 | 설명 |
|------|------|
| 회원명 | 미배정 대기 회원 이름 |
| 출석 시각 | 체크인 완료 시각 |
| 회원권 유형 | 일반 / VIP 등 |
| 배정 버튼 | 해당 회원에게 빈 락커 배정 |

### 버튼

| 버튼 | 설명 |
|------|------|
| 미배정 회원 보기 | 미배정 패널 열기/닫기 |
| 회원 배정 | 선택 회원과 선택 락커 배정 처리 |
| 회수 | 배정된 락커에서 회원 연결 제거 |
| 고장 처리 | 해당 락커를 점검 상태로 변경 |
| 복구 | 점검 상태 락커를 정상 복구 |
| 일괄 해제 | 만료·반납 지연 락커 일괄 회수 |

### 3. 액션 / 흐름
1. 화면 진입 → 락커 그리드 + 상단 현황 카드 표시
2. 미배정 회원 있음 → 상단 카드 '미배정 대기' 수치 강조 → 패널 열기 유도
3. 미배정 회원 선택 → 빈 락커 선택 → 배정 버튼 클릭 → 배정 완료
4. 락커 클릭 → 사용 중이면 배정 회원 정보 팝업 표시
5. 사용 중 락커 → 회수 버튼 클릭 → 확인 후 회수 처리
6. 고장 락커 → 복구 버튼 클릭 → 정상 상태 복원
7. 일괄 해제 → 대상 락커 목록 확인 팝업 → 일괄 처리

### 4. 핵심 상태
| 상태 | 설명 |
|------|------|
| 기본(정상 운영) | 그리드 + 현황 카드 정상 표시 |
| 미배정 대기 있음 | 미배정 카드 강조, 패널 자동 열기 유도 |
| 락커 전체 사용 중 | '빈 락커 없음' 안내 표시 |
| 일괄 처리 중 | 처리 중 로딩 표시 |
| 빈 상태(락커 미등록) | '등록된 락커가 없습니다.' 안내 |

### 5. 권한
| 계정 유형 | 차이 |
|-----------|------|
| 센터 관리자 | 전체 기능 사용 가능 (배정, 회수, 고장 처리, 일괄 해제) |
| 프런트 직원 | 배정 및 회수 가능, 일괄 해제는 관리자 승인 필요 |
| 강사 | 조회만 가능 |

### 6. 필수 예외처리

| 고정 물품 락커 미등록 | "등록된 고정 물품 락커가 없습니다" + [등록 CTA] | 등록 안내 |

## SCR-I005 고정 물품 락커 관리

> 유형: 화면
> URL 경로: `/locker/management`
> 연결 기능: `FAC-EXT-01`, `IoT-04`
> 원본: `docs/admin/화면설계서/D11-통합운영/SCR-I005-고정물품락커관리/00-기본화면.md` / `docs/admin/기능명세서/D06-시설관리/FAC-EXT-01-옷락커고정물품락커/00-기본기능.md`

### 1. 목적
상품 계약 기반으로 회원에게 장기 배정하는 개인 소지품 보관 락커를 관리한다. 배정 현황 조회, 신규 배정, 만료 연장, 회수를 처리하며 계약 만료 예정 회원을 사전에 관리한다.

### 2. UI 구성
### 상단 현황 카드

| 항목 | 설명 |
|------|------|
| 전체 고정 락커 | 등록된 고정 물품 락커 총 수량 |
| 배정 중 | 현재 회원에게 배정된 수량 |
| 만료 예정 | 7일 이내 만료 예정 수량 |
| 회수 대기 | 계약 만료 후 미회수 수량 |

### 락커 유형 탭

| 탭 | 설명 |
|----|------|
| 개인 물품 | 일반 소형 개인 소지품 보관 락커 |
| 골프 | 골프백 보관용 대형 락커 |
| 프리미엄 | 계약 기반 프리미엄 락커 |

### 배정 현황 테이블

| 컬럼명 | 설명 |
|--------|------|
| 락커 번호 | 락커 식별 번호 |
| 회원명 | 배정된 회원 이름 |
| 상품명 | 연결된 락커 상품명 |
| 배정일 | 최초 배정 날짜 |
| 만료일 | 계약 만료 날짜 |
| 상태 | 사용 중 / 만료 예정 / 만료 / 회수 대기 |
| 관리 | 연장 / 회수 버튼 |

### 버튼

| 버튼 | 설명 |
|------|------|
| 배정하기 | 회원 + 락커 + 만료일 신규 배정 |
| 연장 | 선택 락커 계약 만료일 연장 |
| 회수 | 회원 연결 제거 (이력은 보존) |
| 상태 동기화 | 만료 상태 재계산 및 갱신 |
| 엑셀 다운로드 | 현재 배정 목록 엑셀 파일 다운로드 |

### 검색·필터

| 필터 | 옵션 |
|------|------|
| 상태 | 전체, 사용 중, 만료 예정, 만료, 회수 대기 |
| 만료 기간 | 이번 주, 이번 달, 직접 선택 |
| 검색 | 회원명, 락커 번호, 상품명 |

### 3. 액션 / 흐름
1. 화면 진입 → 기본 탭(개인 물품) 배정 현황 표시
2. 만료 예정 카드 → 클릭 시 만료 예정 필터 자동 적용
3. 배정하기 → 회원 검색 → 락커 번호 선택 → 만료일 입력 → 저장
   - 락커 상품 미보유 회원은 배정 불가 안내 표시
4. 연장 버튼 → 새 만료일 입력 팝업 → 저장
5. 회수 버튼 → 확인 팝업 → 회수 처리 (이력 보존)
6. 상태 동기화 → 만료 여부 재계산 후 상태 배지 갱신

### 4. 핵심 상태

|------|------|

| 락커 없음 | '등록된 고정 락커가 없습니다.' 안내 |

## SCR-I006 체성분 통합 관리

> 유형: 화면
> URL 경로: `/body-composition`
> 연결 기능: `IoT-05`
> 연결 다이얼로그: DLG-I003 체성분수기등록
> 원본: `docs/admin/화면설계서/D11-통합운영/SCR-I006-체성분통합관리/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-05-회원건강연동요약/00-기본기능.md`

### 1. 목적
전체 회원의 체성분 측정 현황을 통합 관리한다. InBody 등 측정 장비 연동, 파일 업로드, 수기 입력 세 가지 채널로 수집된 데이터를 검수하고 확정 처리한다.

### 2. UI 구성
### 상단 현황 카드

| 항목 | 설명 |
|------|------|
| 오늘 측정 건수 | 금일 체성분 측정 완료 건수 |
| 검수 대기 | 매칭 실패·중복·이상치로 검수 필요한 건수 |
| 미확정 | 수집됐지만 아직 확정 처리되지 않은 건수 |
| 연동 장비 | 현재 온라인 상태인 InBody 장비 수 |

### 탭 구조

| 탭 | 설명 |
|----|------|

| 업로드 센터 | 장비 파일(CSV/XLSX 등) 업로드 및 파싱 결과 확인 |
| 오류/검수 | 중복·회원 매칭 실패·값 이상치 건 검수 처리 |

| 컬럼명 | 설명 |
|--------|------|
| 측정일시 | 체성분 측정 완료 시각 |
| 회원명 | 측정 회원 이름 |
| 체중 | 측정 체중 (kg) |
| 골격근량 | 골격근량 (kg) |

| 원본 값 | 수집된 원본 측정값 |
| 처리 | 회원 직접 매칭 / 무시 / 확정 처리 |

#### 검수 처리 기준

검수 처리는 자동 수집 또는 업로드된 체성분 데이터가 바로 회원 이력으로 확정되기 어려운 경우 관리자가 확인하는 workflow입니다.

| 검수 유형 | 발생 조건 | 기본 처리 |
|---|---|---|
| 회원 매칭 실패 | 장비/파일 데이터의 이름·회원번호·연락처가 기존 회원과 일치하지 않음 | 회원 직접 매칭 또는 무시 |
| 중복 의심 | 동일 회원, 동일 측정일시, 주요 수치가 동일하거나 5분 이내 반복 수신 | 기존 데이터 유지, 신규 데이터 무시 또는 별도 확정 |
| 값 이상치 | 체중 20~300kg, 골격근량 5~80kg, 체지방률 3~60% 범위를 벗어남 | 관리자 확인 후 확정 또는 무시 |
| 미확정 수기 입력 | 프런트 직원 또는 강사가 입력했으나 관리자 확인이 필요한 정책 | 관리자 확정 |

처리 액션은 다음 세 가지로 제한합니다.

| 액션 | 결과 |
|---|---|
| 회원 직접 매칭 | 선택한 회원의 체성분 이력으로 연결하고 `확정 대기` 또는 `확정` 상태로 전환 |
| 무시 | 원본 데이터는 보관하되 회원 이력에는 반영하지 않음 |
| 확정 처리 | 회원 건강 요약 및 회원 상세 체성분 이력에 노출 |

검수 처리 이력은 처리자, 처리 시각, 처리 전 상태, 처리 후 상태, 사유를 남깁니다.

### 버튼

| 버튼 | 설명 |
|------|------|
| 수기 등록 | DLG-I003 팝업 호출, 수기 체성분 입력 |
| 파일 업로드 | 업로드 센터 탭으로 이동 또는 파일 선택 |
| 연동 로그 | 실시간 연동 탭으로 이동 |
| 확정 처리 | 검수 완료 항목을 확정 상태로 변경 |
| 회원 상세 이동 | 해당 행 회원 상세 화면으로 이동 |

### 3. 액션 / 흐름
1. 화면 진입 → 측정 결과 탭 기본 표시
2. 검수 대기 카드 클릭 → 오류/검수 탭 자동 이동
3. 수기 등록 버튼 → DLG-I003 팝업 → 회원 선택 → 수치 입력 → 저장
4. 파일 업로드 탭: 파일 선택 → 업로드 → 파싱 결과 미리보기 → 확정 처리
5. 오류/검수 탭: 오류 항목 선택 → 회원 매칭 또는 무시 → 확정
6. 측정 결과 행 클릭 → 해당 회원 상세 화면으로 이동

### 4. 핵심 상태
| 상태 | 설명 |
|------|------|
| 기본(데이터 있음) | 측정 결과 테이블 정상 표시 |
| 검수 대기 있음 | 검수 탭 배지 수치 강조 |

## DLG-I001 수동 출석 등록

> 유형: 다이얼로그
> URL 경로: `/attendance`
> 연결 기능: `IoT-01`
> 연결 다이얼로그: DLG-I001 수동출석등록, DLG-I002 옷락커배정
> 원본: `docs/admin/화면설계서/D11-통합운영/DLG-I001-수동출석등록/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-01-통합출석관리/00-기본기능.md`

### 1. 목적
키오스크·QR 등 기기를 통한 출석이 불가한 상황에서 관리자(프런트 직원)가 직접 회원 또는 직원의 출석을 수동으로 등록한다. 별도 기기 없이 시스템에서 직접 출석 처리가 가능하다.

### 2. UI 구성
### 팝업 구조

모달 팝업 형태로 통합 출석 관리 화면(SCR-I001) 위에 오버레이로 표시된다.

### 입력 항목

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 구분 | 필수 | 회원 / 직원 선택 |
| 이름 또는 번호 검색 | 필수 | 회원명, 회원번호, 사번으로 검색 |
| 출석 시각 | 필수 | 기본값: 현재 시각 (수정 가능) |
| 비고 | 선택 | 수동 등록 사유 메모 |

### 버튼

| 버튼 | 설명 |
|------|------|
| 등록 | 입력값 유효성 검사 후 출석 저장 |
| 취소 | 팝업 닫기, 입력값 초기화 |

### 3. 액션 / 흐름
1. 통합 출석 관리 화면 → '수동 출석 등록' 버튼 클릭 → 팝업 열림
2. 구분(회원/직원) 선택
3. 이름 또는 번호 입력 → 자동완성 목록에서 선택
4. 출석 시각 확인 (필요 시 수정)
5. 비고 입력 (선택)
6. 등록 버튼 클릭 → 성공 시 팝업 닫힘 + 출석 목록 즉시 갱신
7. 실패 시 인라인 오류 메시지 표시

### 4. 핵심 상태
| 상태 | 설명 |
|------|------|
| 기본(입력 대기) | 입력 항목 비어있음, 등록 버튼 비활성 |
| 검색 중 | 자동완성 드롭다운 표시 |
| 검색 결과 없음 | '일치하는 회원/직원이 없습니다.' 메시지 |
| 입력 완료 | 등록 버튼 활성화 |
| 등록 성공 | 팝업 닫힘 + 토스트 '출석이 등록되었습니다.' |
| 등록 실패 | 인라인 오류 메시지 표시 |

### 5. 권한
| 계정 유형 | 차이 |
|-----------|------|
| 센터 관리자 | 회원·직원 모두 수동 등록 가능 |
| 프런트 직원 | 회원 수동 등록 가능, 직원 등록은 관리자만 가능 |
| 강사 | 수동 출석 등록 불가 |

## DLG-I002 옷 락커 배정

> 유형: 다이얼로그
> URL 경로: `/locker`
> 연결 기능: `IoT-01`, `IoT-04`
> 연결 다이얼로그: DLG-I001 수동출석등록, DLG-I002 옷락커배정
> 원본: `docs/admin/화면설계서/D11-통합운영/DLG-I002-옷락커배정/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-01-통합출석관리/00-기본기능.md`

### 1. 목적
출석 완료 후 옷 락커가 미배정 상태인 회원에게 빈 락커를 선택하여 배정한다. 통합 출석 관리 또는 옷 락커 운영 관리 화면에서 호출되는 팝업 형태이다.

### 2. UI 구성
### 팝업 구조

모달 팝업 형태. 출석 관리(SCR-I001) 또는 옷 락커 운영 관리(SCR-I004)에서 오버레이로 표시된다.

### 회원 정보 표시 영역 (읽기 전용)

| 항목 | 설명 |
|------|------|
| 회원명 | 배정 대상 회원 이름 |
| 출석 시각 | 해당 회원의 체크인 시각 |
| 회원권 유형 | 일반 / VIP 등 |
| 고정 락커 | 보유 중인 고정 물품 락커 번호 (있는 경우) |

### 락커 선택 영역

빈 락커 목록을 번호 순으로 표시하며, 선택 가능한 락커를 클릭하여 배정한다.

| 상태 | 설명 |
|------|------|
| 선택 가능 | 클릭하여 배정 |
| 사용 중 | 선택 불가 (회색 처리) |
| 점검 중 | 선택 불가 (경고 표시) |

### 버튼

| 버튼 | 설명 |
|------|------|
| 배정 | 선택한 락커를 해당 회원에게 배정 |
| 취소 | 팝업 닫기, 배정하지 않음 |

### 3. 액션 / 흐름
1. 출석 목록(SCR-I001) 또는 락커 운영(SCR-I004)에서 '락커 배정' 버튼 클릭
2. 팝업 열림 → 대상 회원 정보 자동 표시
3. 빈 락커 목록에서 번호 클릭하여 선택
4. 배정 버튼 클릭 → 배정 완료
5. 성공 시 팝업 닫힘 + 출석 목록 및 락커 그리드 즉시 갱신
6. 빈 락커 없는 경우 → '배정 가능한 락커가 없습니다.' 안내

### 4. 핵심 상태
| 상태 | 설명 |
|------|------|

## DLG-I003 체성분 수기 등록

> 유형: 다이얼로그
> URL 경로: `/body-composition`
> 연결 기능: `IoT-05`
> 연결 다이얼로그: DLG-I003 체성분수기등록
> 원본: `docs/admin/화면설계서/D11-통합운영/DLG-I003-체성분수기등록/00-기본화면.md` / `docs/admin/기능명세서/D11-통합운영/IoT-05-회원건강연동요약/00-기본기능.md`

### 1. 목적
InBody 등 측정 장비 없이 관리자가 직접 체성분 수치를 수동으로 입력하여 등록한다. 측정지 원본을 보고 수기로 전산화하거나, 장비 연동이 불가한 환경에서 임시 등록 시 사용한다.

### 2. UI 구성
### 팝업 구조

모달 팝업 형태. 체성분 통합 관리(SCR-I006) 화면에서 오버레이로 표시된다.

### 입력 항목

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| 회원 검색 | 필수 | 이름 또는 회원번호로 회원 선택 |
| 측정일시 | 필수 | 기본값: 현재 시각 (수정 가능) |
| 체중 (kg) | 필수 | 소수점 1자리 입력 |
| 골격근량 (kg) | 선택 | 소수점 1자리 입력 |
| 체지방량 (kg) | 선택 | 소수점 1자리 입력 |
| 체지방률 (%) | 선택 | 소수점 1자리 입력 |
| BMI | 선택 | 소수점 1자리 입력 |
| 기초대사량 (kcal) | 선택 | 정수 입력 |
| 체수분 (L) | 선택 | 소수점 1자리 입력 |
| 비고 | 선택 | 수기 등록 사유 또는 메모 |

### 버튼

| 버튼 | 설명 |
|------|------|
| 등록 | 입력값 유효성 검사 후 저장 |
| 취소 | 팝업 닫기, 입력값 초기화 |

### 3. 액션 / 흐름
1. 체성분 통합 관리(SCR-I006) → '수기 등록' 버튼 클릭 → 팝업 열림
2. 회원 검색 → 자동완성 목록에서 선택
3. 측정일시 확인 (필요 시 수정)
4. 체중 등 수치 입력 (체중은 필수, 나머지는 선택)
5. 등록 버튼 클릭 → 저장
6. 성공 시 팝업 닫힘 + 측정 결과 목록 즉시 갱신
7. 동일 회원·동일 측정 시각의 중복 데이터는 '검수 대기' 상태로 저장되며 안내 메시지 표시

### 4. 핵심 상태
| 상태 | 설명 |
|------|------|
| 기본(입력 대기) | 입력 항목 비어있음, 등록 버튼 비활성 |
| 회원 선택됨 | 회원 정보 표시, 나머지 항목 입력 활성화 |
| 필수 항목 입력됨 | 등록 버튼 활성화 |
| 중복 데이터 감지 | '동일 시각 데이터가 있습니다. 검수 대기로 저장됩니다.' 안내 |
| 등록 성공 | 팝업 닫힘 + 토스트 '체성분이 등록되었습니다.' |
| 등록 실패 | 인라인 오류 메시지 표시 |

### 5. 권한
| 계정 유형 | 차이 |
|-----------|------|
| 센터 관리자 | 모든 회원 체성분 수기 등록 가능 |
| 프런트 직원 | 체성분 수기 등록 가능 |
| 강사 | 담당 회원에 한해 수기 등록 가능 |
