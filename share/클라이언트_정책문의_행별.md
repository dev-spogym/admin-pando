# 클라이언트 운영 정책 문의 - 행별 정리

대상 시트: `개발사 계약 및 상세 기능리스트_제로스트 피드백_260518` > `3.CRM (admin)_제로스트_0518논의`

기준:
- T:W 열 범례에 `스포짐`, `판도`, `스포짐 판도`가 표시된 행만 정리했습니다.
- 기능 존재 여부가 아니라, 스포짐 운영자가 실제 사용할 때 확정해야 하는 정책값/판단 기준/권한/예외 처리만 질문으로 작성했습니다.
- 같은 기능 묶음이라도 원본 행 추적이 쉽도록 행별로 분리했습니다.

## 클라이언트용 읽는 방법

이 문서의 기획 코드와 기능명은 내부 추적용입니다. 클라이언트에게 전달할 때는 아래 순서로 읽히게 하는 것이 좋습니다.

1. 먼저 `기능 배경`에서 해당 기능이 실제 운영에서 어떤 상황에 쓰이는지 설명합니다.
2. `현재 임시 기획 기준`은 판도에서 우선 잡아둔 기준안입니다. 스포짐의 확정 정책이 아닙니다.
3. `스포짐에 확인할 질문`은 실제 운영 기준으로 확정해야 하는 내용입니다.

즉, 각 질문은 “이 기능을 만들까요?”가 아니라 “현재는 이렇게 기준을 잡아두었는데, 스포짐 실제 운영 기준은 무엇인가요?”라는 의미입니다.

## 117행 - HQ-03-04 액션 큐

대상: 스포짐

기능 배경:
- 오늘 처리해야 할 상담/재등록/만료 대상 업무를 담당자별로 모아 보여주는 기능입니다.

현재 임시 기획 기준:
- 액션 큐는 역할별 오늘 처리 업무를 모아 보여주고, 각 업무를 긴급 / 우선 / 일반 / 완료가능 우선순위로 구분합니다.

스포짐에 확인할 질문:
1. 긴급 / 우선 / 일반 / 완료가능을 나누는 실제 운영 기준은 무엇인가요?
2. 전화 문의 후 미방문, 방문 후 미등록, 상담 결과 미기입, 재등록 상담 대상은 각각 며칠 이상 미처리되면 상위 우선순위로 올려야 하나요?
3. 액션 큐 완료 처리는 담당자 본인만 가능한가요, 지점장/매니저가 대리 완료할 수 있나요?
4. 완료 처리 시 사유 또는 메모를 필수로 남겨야 하는 업무가 있나요?
