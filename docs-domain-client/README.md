# docs-domain-client — 회원앱 자기완결형 화면설계서

이 폴더는 회원앱(FitGenie Mobile App, iOS/Android) 화면별 자기완결형 요구사항 정의서입니다. 각 README.md 한 장만 보면 그 화면에 들어가는 모든 영역·버튼·모달·권한·예외 처리·운영 정책까지 전부 이해할 수 있도록 작성됩니다.

`client2`가 회원앱 도메인 정리 문서(개발사용 납품 문서)라면, `docs-domain-client`는 그 정합 기준 위에서 화면 단위로 풀어 쓴 자기완결형 설계서입니다. `docs-domain`이 관리자 CRM(`docs2`)의 화면설계서이듯, `docs-domain-client`는 회원앱(`client2`)의 화면설계서입니다.

## 정합 기준

- `client2`의 도메인 정리 문서가 정본이며 본 화면설계서는 그 위에서 화면 단위로 풀어 씁니다.
- 관리자 CRM 데이터(회원·예약·결제·이용권·출석)는 `docs2` 정본을 따릅니다.
- 회원앱 자체 UX(QR·서명·푸시·딥링크·오프라인)는 본 폴더가 정본입니다.
- 권한 영문 키워드는 회원앱 5종 role (`member / trainer / golf_trainer / fc / staff`)을 사용합니다.
