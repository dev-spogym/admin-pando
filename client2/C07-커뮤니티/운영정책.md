# C07-커뮤니티 회원앱 — 운영정책

## 1. 핵심 원칙
- 회원앱 커뮤니티 도메인은 회원이 공개 Q&A·FAQ로 정보를 교환하는 영역이다.
- 커뮤니티는 회원앱 작성·조회 채널이며, FAQ 원천·운영자 검토·신고 처리·감사 로그는 docs4 기준을 따른다.
- 신고 기능 + 자동 숨김(3건 누적) + 자동 필터로 안전한 커뮤니티 유지.
- 부적절 게시물 처리 이벤트는 docs4 SCR-097 감사 로그에 기록.

## 2. 상태 / 운영 정의

### 게시물 상태 4종
정상 / 신고됨 / 자동 숨김 (3건 신고) / 삭제됨 (soft delete)

### 카테고리 5종
운동 / 식단 / 이용권 / 시설 / 기타

### 신고 사유 5종
스팸 / 욕설 / 홍보 / 부적절 / 기타

### 답변자 역할 배지 3종
회원 / 강사 / 운영자

## 4. KPI / 성과 측정
| KPI | 산식 | 측정 주기 |
|---|---|---|
| 일간 게시물 수 | 작성된 Q&A·답변 합산 | 일 단위 |
| 답변률 | 답변 있는 질문 / 전체 질문 × 100 | 주 단위 |
| 평균 답변 시간 | 질문 작성 ~ 첫 답변 시간 평균 | 일 단위 |
| 신고 비율 | 신고된 게시물 / 전체 게시물 × 100 | 월 단위 |
| 자동 숨김 비율 | 3건 신고 자동 숨김 / 신고된 게시물 × 100 | 월 단위 |

## 5. 자동화 정책
| 자동화 | 실행 시점 | 처리 동작 |
|---|---|---|
| 부적절 자동 필터 | 게시물 작성 시 | 욕설 패턴 매칭 + 자동 차단 |
| 신고 자동 숨김 | 신고 3건 누적 | 자동 숨김 + "검토 대기" 라벨 |
| 운영자 검토 알림 | 자동 숨김 발생 | docs4/V1 D10 운영자에게 알림 (NFR-19) |
| 24시간 수정 만료 | 작성 후 24시간 | 수정·삭제 잠금 |
| 인기 질문 갱신 | 매시간 | 좋아요·답변 수 기준 인기 게시물 갱신 |
| 회원 누적 신고 5건 알림 | 신고 누적 시 | docs4/V1 D10 본사관리 보안 알림 |

## 6. 운영 예외 처리
| 케이스 | 처리 방식 | 후속 조치 |
|---|---|---|
| 제목 50자 초과 | "제목은 50자 이내" | 입력 차단 |
| 본문 2000자 초과 | "본문은 2000자 이내" | 입력 차단 |
| 사진 5장 초과 첨부 | "사진은 최대 5장" | 추가 차단 |
| 사진 10MB 초과 | "10MB 이하 이미지" | 업로드 차단 |
| 본인 글 신고 시도 | "본인 글은 신고 불가" | 차단 |
| 동일 게시물 중복 신고 | "이미 신고한 게시물" | 차단 |
| 자동 필터 차단 (욕설) | "부적절한 표현이 포함되어 있습니다" | 작성 차단 |
| 24시간 경과 수정 시도 | "수정 가능 시간(24시간)이 지났어요" | 차단 |
| 베스트 답변 다중 채택 시도 | "베스트 답변은 1개만 채택 가능" | 차단 |
| 신고 3건 자동 숨김 | 자동 숨김 + 운영자 검토 큐 | 자동 |
| 운영자 검토 후 영구 삭제 | soft delete + 감사 로그 | 자동 |
| 익명 작성 후 운영자 노출 (신고 처리 시) | 운영자는 작성자 확인 가능 | - |
| 회원 누적 신고 5건 | 회원 알림 + 경고 메시지 | 본사 보안 검토 |

## 7. CRM 연동 기준
- 부적절 게시물 처리: docs4 SCR-097 감사 로그에 INSERT
- 회원 누적 신고: docs4/V1 D10 본사관리 보안 알림 (NFR-19)
- FAQ 작성: CRM 관리자 화면 기준 등록·수정, 회원앱은 조회만
- Q&A·답변·좋아요·신고 이벤트: 회원앱에서 발생하지만 운영 검토·삭제·보안 알림은 SCR-097/NFR-19 기준
- 부적절 자동 필터, 익명 마스킹, 인기 질문 정렬은 회원앱 표시 로직이며 개인정보/감사 로그 기준은 docs4를 따른다.
