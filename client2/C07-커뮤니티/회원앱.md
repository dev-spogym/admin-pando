# C07-커뮤니티 회원앱

> 개발사용 정리 문서입니다.

## 문서 메타
- 전체 화면 수: 7 (MA-6XX 커뮤니티·신뢰)
- 도메인 코드: C07
- 도메인명: 커뮤니티 · 신뢰
- 역할: member
- 관리자 CRM 정합 도메인: 없음 (회원앱 자체 신규 도메인). 부적절 게시물 신고는 docs2 D11 통합운영의 감사 로그(SCR-097)에 기록.

## 도메인 개요
- 회원이 공개 Q&A·FAQ를 통해 센터·강사·운동 관련 질문을 주고받는 커뮤니티 영역이다.
- 신고 기능과 자동 숨김(3건 누적)으로 안전한 커뮤니티를 유지한다.
- 회원앱 자체 정본 도메인이며 신고된 부적절 게시물 처리는 CRM 운영자에게 알림.

## 화면

### MA-600 커뮤니티 홈
- 공개 Q&A 목록·인기 질문·내가 작성한 글
- 카테고리 필터 (운동·식단·이용권·시설·기타)
- 검색

### MA-601 Q&A 목록
- 시간 역순·인기순 정렬
- 답변 수·좋아요 수 표시
- 답변 완료 / 답변 대기 상태 배지

### MA-610 Q&A 상세
- 질문 원문·답변 목록·내가 좋아요·신고 버튼
- 답변 작성 (회원·강사·운영자 모두 가능)
- 베스트 답변 채택 (질문 작성자만)

### MA-620 Q&A 작성
- 제목·본문·카테고리·태그
- 익명 옵션 (회원명 마스킹)
- 사진 첨부 (최대 5장)

### MA-630 FAQ
- 운영자가 등록한 FAQ 목록
- 카테고리·검색

### MA-640 신고 / 차단 관리
- 본인이 신고한 게시물 이력
- 신고 사유: 스팸·욕설·홍보·부적절·기타

### MA-650 내 활동
- 내가 작성한 질문·답변·좋아요 이력

## 핵심 정책

### Q&A 작성 정책
- 제목 1~50자, 본문 1~2000자
- 카테고리 5종 (운동·식단·이용권·시설·기타)
- 태그 최대 5개
- 사진 첨부 최대 5장 (각 10MB 이하)
- 익명 옵션 선택 시 회원명 마스킹 (운영자에게는 보임)

### 답변 정책
- 회원·강사·운영자 모두 답변 가능
- 답변자 역할 배지 표시 (회원/강사/운영자)
- 베스트 답변 채택은 질문 작성자만 가능 (1개)
- 답변 작성 후 24시간 이내 수정·삭제 가능

### 좋아요 정책
- 회원 1인당 질문·답변별 1회 좋아요
- 좋아요 취소 가능

### 신고 정책
- 신고 사유 5종: 스팸·욕설·홍보·부적절·기타
- 본인 글·답변 신고 불가
- 동일 회원이 동일 게시물 중복 신고 불가
- 신고 3건 누적 시 자동 숨김 + 운영자 검토 큐
- 부적절 자동 필터 (욕설 패턴 매칭)

### FAQ 정책
- 운영자(Owner(지점장)/매니저)만 작성·수정 가능
- 회원앱에서는 조회만
- 카테고리·검색 지원

### 데이터 보호 정책
- 익명 옵션 작성 시 회원명 마스킹 (***)
- 운영자는 신고 처리 시에만 익명 작성자 확인 가능
- 게시물·답변은 작성 후 24시간 이내 수정·삭제 가능
- 삭제는 soft delete (감사 로그 보존)

## CRM 연동 기준
- 신고 자동 숨김 이벤트 → docs2 SCR-097 감사 로그에 비동기 INSERT
- FAQ 작성은 CRM 관리자가 회원앱 백오피스에서 등록 (회원앱 자체 백오피스 또는 CRM 확장)
- 회원 신고 누적 5건 이상 시 docs2 D10 본사관리 보안 알림

회원앱 자체 정본 영역:
- Q&A 작성·답변·좋아요 흐름
- 신고 자동 필터
- FAQ 검색
- 익명 마스킹
- 커뮤니티 카테고리
