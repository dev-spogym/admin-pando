# C07-커뮤니티 회원앱

> 개발사용 정리 문서입니다.

## 문서 메타
- 전체 화면 수: 7 (MA-6XX 커뮤니티·신뢰)
- 도메인 코드: C07
- 도메인명: 커뮤니티 · 신뢰
- 역할: member
- 관리자 CRM 정합 도메인: `docs4/V1/D09-설정관리` 공지/FAQ 운영, `docs4/V1/D10-본사관리` 운영 알림·KPI, `docs4/_공통/공통참조_코드인덱스.md` SCR-097 감사 로그, NFR-19 알림 기준.

## 도메인 개요
- 회원이 공개 Q&A·FAQ를 통해 센터·강사·운동 관련 질문을 조회·작성하는 회원앱 채널이다.
- 신고 기능과 자동 숨김(3건 누적)으로 안전한 커뮤니티를 유지한다.
- FAQ 원천과 신고/차단 처리 이력은 docs4 공지/감사 로그/알림 기준에 귀속한다. 회원앱은 작성·조회 UX만 담당한다.

## 화면

### MA-600 커뮤니티 홈
- 공개 Q&A 목록·인기 질문·내가 작성한 글
- 카테고리 필터 (운동·식단·이용권·시설·기타)
- 검색

### MA-601 Q&A 목록
- 시간 역순·인기순 정렬
- 답변 수·좋아요 수 표시
- 답변 완료 / 답변 대기 상태 배지

### MA-610 Q&A 상세
- 질문 원문·답변 목록·내가 좋아요·신고 버튼
- 답변 작성 (회원·강사·운영자 모두 가능)
- 베스트 답변 채택 (질문 작성자만)

### MA-620 Q&A 작성
- 제목·본문·카테고리·태그
- 익명 옵션 (회원명 마스킹)
- 사진 첨부 (최대 5장)

### MA-630 FAQ
- 운영자가 등록한 FAQ 목록
- 카테고리·검색

### MA-640 신고 / 차단 관리
- 본인이 신고한 게시물 이력
- 신고 사유: 스팸·욕설·홍보·부적절·기타

### MA-650 내 활동
- 내가 작성한 질문·답변·좋아요 이력

## 핵심 정책

### Q&A 작성 정책
- 제목 1~50자, 본문 1~2000자
- 카테고리 5종 (운동·식단·이용권·시설·기타)
- 태그 최대 5개
- 사진 첨부 최대 5장 (각 10MB 이하)
- 익명 옵션 선택 시 회원명 마스킹 (운영자에게는 보임)

### 답변 정책
- 회원·강사·운영자 모두 답변 가능
- 답변자 역할 배지 표시 (회원/강사/운영자)
- 베스트 답변 채택은 질문 작성자만 가능 (1개)
- 답변 작성 후 24시간 이내 수정·삭제 가능

### 좋아요 정책
- 회원 1인당 질문·답변별 1회 좋아요
- 좋아요 취소 가능

### 신고 정책
- 신고 사유 5종: 스팸·욕설·홍보·부적절·기타
- 본인 글·답변 신고 불가
- 동일 회원이 동일 게시물 중복 신고 불가
- 신고 3건 누적 시 자동 숨김 + 운영자 검토 큐
- 부적절 자동 필터 (욕설 패턴 매칭)

### FAQ 정책
- 운영자(Owner(지점장)/매니저)만 작성·수정 가능
- 회원앱에서는 조회만
- 카테고리·검색 지원

### 데이터 보호 정책
- 익명 옵션 작성 시 회원명 마스킹 (***)
- 운영자는 신고 처리 시에만 익명 작성자 확인 가능
- 게시물·답변은 작성 후 24시간 이내 수정·삭제 가능
- 삭제는 soft delete (감사 로그 보존)

## CRM 연동 기준
- 신고 자동 숨김 이벤트 → docs4 SCR-097 감사 로그에 비동기 INSERT
- FAQ 작성은 CRM 관리자 화면 기준으로 등록·수정하며, 회원앱은 조회만 제공한다.
- 회원 신고 누적 5건 이상 시 docs4/V1 D10 본사관리 보안 알림
- Q&A/답변/좋아요/신고 이벤트는 회원앱에서 발생하지만 처리 이력·알림·운영 검토는 SCR-097/NFR-19 기준을 따른다.
- 익명 마스킹과 개인정보 노출 제한은 docs4 D02 개인정보/마스킹 기준을 따른다.
