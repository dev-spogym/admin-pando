# C08-시스템공통 회원앱

> 개발사용 정리 문서입니다.

C08 시스템공통은 docs2(CRM)에 대응 도메인이 없는 **회원앱 자체 도메인**입니다. 네트워크 오류·서버 점검·신규 환영·공통 컴포넌트 등 회원앱 전역 시스템 영역만 책임지며, CRM과의 매핑 없이 본 폴더 정본이 유일 기준입니다.

## 문서 메타
- 전체 화면 수: 8 (MA-9XX 시스템·공통) + 공통 컴포넌트 4종
- 도메인 코드: C08
- 도메인명: 시스템 · 공통
- 역할: 전체 (member / trainer / golf_trainer / fc / staff)
- 관리자 CRM 정합 도메인: `docs2/D01-공통`, `docs2/D09-설정관리`

## 도메인 개요
- 회원앱의 시스템 레벨 화면(신규 회원 환영·네트워크 오류·서버 점검·앱 업데이트)과 공통 컴포넌트(토스트·모달·로딩·에러 바운더리)를 다룬다.
- 모든 역할이 공통으로 사용하는 화면이며 역할별 분기 없음.
- docs2 D01 공통의 모바일 채널이며 공통 컴포넌트는 회원앱 자체 디자인 시스템 정본.

## 화면

### MA-900 신규 회원 환영
- 앱 첫 연동 완료 후 자동 진입
- 회원명·등급·앱 사용 가이드 (3단계 캐로셀)
- "시작하기" → 홈(MA-100) 진입

### MA-910 네트워크 오류
- 인터넷 단절 시 자동 표시 (전체 화면)
- "재시도" 버튼
- 일부 화면(QR·예약)은 오프라인 큐잉 안내

### MA-920 서버 점검
- 본사 점검 공지 시 표시
- 점검 시간·복구 예상 시간 안내
- "공지사항 보기" CTA

### MA-930 앱 업데이트 안내
- 강제 업데이트 (Critical 버전)
- 권장 업데이트 (Minor 버전)
- App Store / Google Play 진입

### MA-940 권한 요청
- 푸시 알림·위치·카메라(QR) 권한 요청
- 거부 시 설정 진입 안내

### MA-950 약관 / 개인정보 처리방침
- 회원 가입 시 동의 화면
- 마이페이지에서 재조회

### MA-960 디자인 시스템 가이드 (개발자용)
- 디자인 토큰 (색상·간격·폰트)
- 컴포넌트 카탈로그

### MA-970 디바이스 / 앱 정보
- 앱 버전·OS 버전·디바이스 정보
- 푸시 토큰·로그아웃·앱 데이터 초기화

## 공통 컴포넌트 4종

### 토스트 (Toast)
- 성공 (녹색) / 정보 (파랑) / 경고 (노랑) / 오류 (빨강) 4종
- 자동 dismiss 3초
- 상단 / 하단 위치 (도메인별 설정)
- docs2 `_공통/토스트_메시지.md` 정합

### 모달 (Modal)
- 중앙 정렬 dialog
- 확인 / 취소 2버튼 또는 단일 확인
- ESC·배경 클릭으로 닫기 (취소와 동일)
- 풀스크린 모달 (서명 패드·QR 등)

### 로딩 (Loading)
- 스피너 (인라인·풀스크린)
- 스켈레톤 (목록·카드)
- 진행률 바 (파일 업로드)

### 에러 바운더리 (ErrorBoundary)
- 앱 충돌 시 fallback 화면
- "재시도" / "홈으로" CTA
- 에러 리포트 자동 전송 (Sentry/Firebase Crashlytics)

## 핵심 정책

### 권한 정책
- 푸시 알림: 첫 로그인 후 요청, 거부 시 푸시 미발송
- 위치: GPS 검색 진입 시 요청
- 카메라: QR 스캔·체성분 사진 시 요청
- 사진: 프로필·후기·체성분 첨부 시 요청
- 권한 거부 시 설정 진입 안내 (강제 권한 요청 없음)

### 푸시 알림 정책
- 채널: 예약·이용권·상담·공지·HQ-09 만료 알림·결제·마일리지
- FCM (Android) + APNs (iOS) 통합
- 카카오 알림톡 fallback (회원 미설치 시)
- 알림 무음 시간: 22:00 ~ 08:00 (긴급 알림 제외)

### 앱 업데이트 정책
- Critical (강제): 보안 패치·치명 버그 → 업데이트 전 진입 차단
- Minor (권장): 기능 추가 → 24시간 이후 재안내
- 버전 비교: semantic versioning (X.Y.Z)

### 오프라인 모드 정책
- QR 코드 표시: 캐시 사용 (마지막 갱신 7일 이내)
- QR 스캔 결과: 오프라인 큐잉 → 복구 후 동기화
- 예약·결제: 오프라인 차단
- 캐시 정책: 5분 TTL 또는 사용자 명시 새로고침

### 디바이스 호환성
- iOS 14+ / Android 8+ 지원
- 미지원 OS는 진입 시 안내 + 업데이트 권장

### 약관 동의 정책
- 가입 시 필수 동의: 서비스 이용약관·개인정보 처리방침
- 선택 동의: 마케팅 정보 수신
- 동의 이력은 docs2 D01 정본에 저장 (consent_at, consent_version)

### 에러 리포트 정책
- 충돌 시 자동 전송 (디바이스·OS·앱 버전·스택 트레이스)
- 회원 PII는 제외 (디바이스 ID만 포함)
- 운영자 알림은 1일 1회 요약

## CRM 연동 기준
- 약관 동의 / 회원 가입: docs2 D01 / D02 정본
- 푸시 토큰 등록: docs2 D09 키오스크 설정과 별개, 회원앱 자체 정본
- 본사 공지 (서버 점검·이벤트): docs2 D09 SCR-085 공지사항 정본
- 디자인 토큰: docs2 `_공통/디자인_시스템.md` 정합

회원앱 자체 정본 영역:
- 신규 회원 환영 UX
- 네트워크 오류·오프라인 큐잉
- 앱 업데이트 흐름
- 푸시 알림 채널·우선순위
- 디바이스 권한 요청 UX
- 공통 컴포넌트 4종 (토스트·모달·로딩·에러 바운더리)
- 디자인 시스템 가이드
- 에러 리포트 (Sentry/Crashlytics)
