# C03-FC-스태프 회원앱

> 개발사용 정리 문서입니다.

## 문서 메타
- 전체 화면 수: 19 (FC 12 + 스태프 7)
- 도메인 코드: C03
- 도메인명: FC · 스태프
- 역할: fc / staff
- 관리자 CRM 정합 도메인: `docs4/V1/D02-회원관리`, `docs4/V1/D08-마케팅` (CRM-01 리드관리), `docs4/V1/D07-직원관리`

## 도메인 개요
- FC(Fitness Consultant)는 리드 관리·상담 이력·만료 예정 회원 재등록 상담을 수행한다.
- 스태프는 회원 조회(읽기 전용) + 수동 출석 처리를 수행한다.
- 회원앱 role: `fc` / `staff`이며 관리자 CRM 권한 `fc` / `staff`와 분리된 채널이다.
- FC 채널은 회원앱에서 docs4/V1 D08 SCR-070 리드 관리의 모바일 확장 역할을 하되, `등록완료` 직접 확정은 불가하다 (docs4 정합 — 결제 완료 시 자동 확정).
- FC가 회원 등록을 시도하면 회원 등록 요청을 생성해 Owner(지점장)/매니저에게 이어받기 알림이 발송된다.

## MA-400 FC 홈 대시보드

> 유형: 화면
> URL 경로: FC 로그인 후 디폴트 (FcNavigator의 홈)
> 연결 기능: `MFN-401`

### 1. 목적
FC가 출근 직후 오늘 상담 일정·만료 예정 회원·전환율 KPI·미처리 후속 액션을 한 화면에서 파악하는 메인 허브 화면입니다.

### 2. UI 구성
- **상단 인사**: "안녕하세요, {FC명}님"
- **오늘 상담 카드**: 시간순 정렬, 회원명·상담 유형·연락처
- **요약 카드 4종**: 오늘 상담 N건·만료 예정 N명·이번 달 전환율 N%·미처리 후속 N건
- **만료 예정 회원 알림**: HQ-09 회원 이용권 만료 step 대상 회원
- **빠른 액션 4종**: 상담 등록·리드 목록·만료 회원·KPI 대시보드
- **이번 달 KPI**: 상담 건수·등록 전환율·재등록률
- **하단 탭바**: 홈 · 상담 · 회원 · KPI · 설정 (5탭)

### 3. 액션 / 흐름
1. FC 로그인 직후 진입.
2. 오늘 상담 카드 클릭 → 상담 등록(MA-411).
3. 만료 예정 알림 클릭 → 만료 예정 회원 목록(MA-430).
4. 빠른 액션 → 각 화면 진입.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 정상 | 오늘 상담·만료 회원·KPI 정상 표시 |
| 상담 없음 | "오늘 예정된 상담이 없어요" |
| 미처리 강조 | 후속 액션 미처리 시 빨강 배지 |
| 만료 예정 ≥ 5명 | 강조 색상 |

### 5. 권한
`fc`만 진입 가능합니다.

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 만료 회원 데이터 미동기화 | 캐시 + 재시도 | 자동 재시도 |
| 본인 미배정 (담당 회원 0명) | "담당 회원이 배정되지 않았습니다" | 운영자 문의 안내 |

## MA-411 상담 이력 등록

> 유형: 화면
> URL 경로: MA-410 리드 목록 또는 회원 상세에서 진입
> 연결 기능: `MFN-411`

### 1. 목적
FC가 신규 상담·재등록 상담·OT·체험 등 상담 이력을 등록하는 화면입니다. CRM CRM-01 리드 관리와 동일 데이터를 공유합니다.

### 2. UI 구성
- **회원 검색**: 이름·전화번호 (CRM 매칭) 또는 신규 리드 입력
- **상담 유형**: 상담 / OT / 체험 / 재등록상담 (라디오)
- **상담 일시**: 자동 (현재)
- **상담 방식**: 대면 / 유선 / 부재 (라디오)
- **상담 내용**: 자유 텍스트 (최대 1000자)
- **상담 단계 (7종)**: 신규 / 연락완료 / 상담예정 / 방문완료 / 등록완료 / 미전환 / 보류
- **상담 결과**: 등록 / 미등록 / 보류 ("완료" 단계일 때만 입력)
- **후속 조치**: 미등록/보류 시 필수 입력 (다음 연락 일정)
- **유입경로**: 9종 드롭다운 (간판·인터넷·전단지·추천·SNS·카카오톡·전화문의·방문·기타)
- **저장 버튼**

### 3. 액션 / 흐름
1. 리드 목록 또는 회원 상세에서 [상담 등록] 클릭.
2. 회원 검색 → CRM 매칭 또는 신규 리드 입력.
3. 상담 유형·방식·내용 입력.
4. 상담 단계 선택 (DnD 칸반 또는 드롭다운).
5. 결과 + 후속 조치 입력 (필수).
6. 저장 → CRM 동기화 (CRM-01 리드 관리에 즉시 반영).

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 입력 중 | 폼 미완료 |
| 저장 중 | 버튼 로딩 |
| 저장 완료 | "상담 이력이 등록되었어요" + 목록 갱신 |
| 회원 미선택 | 저장 차단 |
| 후속 조치 미입력 (미등록/보류) | 저장 차단 |

### 5. 권한
- `fc`: 본인 담당 리드·회원만 등록 가능
- 타 FC 담당 리드는 read-only (strict_owner 모드)

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 회원 검색 0건 | "검색 결과 없음" | 신규 리드 등록 안내 |
| 상담 단계 `등록완료` 시도 | "회원 등록 권한이 없어 등록 요청으로 전환됩니다" | 등록 요청 생성 + Owner(지점장)/매니저 알림 (docs4/V1 D08 SCR-070 정합) |
| 후속 조치 미입력 (미등록/보류) | "후속 조치를 입력해주세요" | 차단 |
| 상담 내용 1000자 초과 | "1000자 이내" | 차단 |
| 동시 수정 충돌 | "다른 FC가 먼저 수정" | 재로드 |
| 7일 경과 수정 시도 | "수정 가능 기간(7일) 초과" | 차단 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| CRM CRM-01 리드 관리 | 상담 등록 | 5초 이내 CRM 반영 |
| 후속 예정일 D-1 알림 | 후속 예정일 24시간 전 | FC 푸시 발송 |
| 보류 30일 경과 알림 | 매일 04:00 | 보류 리드 노랑 배지 + 후속 액션 권유 |
| 전환율 통계 갱신 | 단계 변경 / 첫 정상 결제 완료 | 5분 캐시 무효화 + 재계산 |
| 등록완료 자동 확정 | 첫 정상 결제 완료 이벤트 | FC 수동 저장 불가 (docs4 정합) |

### 8. 핵심 디자인 요청사항
- 칸반 뷰는 가로 스크롤 + DnD 지원 (모바일 한정 정적 리스트로 fallback)
- 후속 조치 필드는 미등록/보류 선택 시 자동 펼침
- 7단계 상태 배지는 docs4/V1 D08 SCR-070과 동일 색상

## MA-520 수동 출석 처리 (스태프 전용)

> 유형: 화면
> URL 경로: 스태프 탭바 출석 (StaffNavigator)
> 연결 기능: `MFN-520`

### 1. 목적
스태프가 회원의 QR 스캔이 불가능할 때 (회원 폰 분실·QR 오류 등) 수동으로 출석 처리하는 화면입니다.

### 2. UI 구성
- **회원 검색**: 이름·전화번호로 즉시 검색
- **회원 카드**: 매칭된 회원 정보 (이름·이용권·잔여 횟수·마지막 방문)
- **출석 처리 버튼**: 회원 선택 후 활성
- **이용권 만료 경고**: 만료 회원도 출석은 처리 가능 (비고 표시)
- **최근 수동 출석 목록**: 본인 처리 이력 (최근 10건)

### 3. 액션 / 흐름
1. 스태프 탭바 출석 → 본 화면 진입.
2. 회원 검색 → 매칭 카드 표시.
3. [출석 처리] 클릭 → CRM 출석 등록 + 자동 동기화.
4. 최근 처리 이력 즉시 반영.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 검색 중 | 검색어 입력 + 자동완성 |
| 회원 선택됨 | 출석 처리 버튼 활성 |
| 처리 완료 | "출석 처리 완료" 토스트 |
| 만료 회원 | 경고 배너 표시 (출석은 가능) |

### 5. 권한
`staff`만 진입 가능합니다.

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 검색 0건 | "회원을 찾을 수 없습니다" | 회원 등록 안내 |
| 당일 중복 체크인 | "오늘 이미 출석했어요" | 차단 |
| 페널티 적용 중 | "예약 제한 중" | 차단 |
| 비활성/탈퇴 회원 | "유효하지 않은 회원" | 차단 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| CRM 출석 시스템 | 수동 출석 등록 | last_visit_at 갱신 |
| CRM 회원 마스터 | 수동 출석 등록 | 출석 결과 = 성공 (docs4 정합) |
| 감사 로그 | 수동 출석 | actor·member_id·timestamp 비동기 INSERT |

## 핵심 정책 (도메인 공통)

### FC 권한 정책 (docs4/V1 D08 SCR-070 정합)
- FC는 본인 담당 리드·회원만 수정 가능
- 타 FC 담당은 read-only 또는 hidden (strict_owner 모드)
- 회원 등록 직접 확정 불가 → "회원 등록 요청" 생성
- 상담 단계 `등록완료` 수동 저장 불가 → 첫 정상 결제 완료 이벤트 시 자동 확정
- FC가 등록완료로 단계 변경 시도 시 "회원 등록 권한이 없어 등록 요청으로 전환됩니다" 안내

### 스태프 권한 정책
- 회원 조회 read-only (수정 불가)
- 수동 출석 처리 가능
- 수업 일정 조회만 가능 (수정 불가)

### 상담 단계 7종 (docs4 정합)
신규 / 연락완료 / 상담예정 / 방문완료 / 등록완료 / 미전환 / 보류
- `등록완료`는 조회 필터에만 포함, 수동 저장 불가
- `보류` 30일 경과 시 자동 재상담 권유 알림

### 후속 조치 정책
- 미등록/보류 시 후속 조치 입력 필수 (다음 연락 일정)
- 후속 예정일 D-1 푸시 알림 자동 발송
- 미처리 후속 액션은 홈 대시보드에 빨강 배지로 강조

### 데이터 보호 정책
- FC는 본인 담당 회원만 PII 조회 가능
- 스태프는 회원 조회 read-only (수정·삭제·엑셀 불가)
- 모든 상담·메모 작성 이력은 SCR-097 감사 로그에 비동기 INSERT
