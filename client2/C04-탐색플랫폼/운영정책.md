# C04-탐색플랫폼 회원앱 — 운영정책

## 1. 핵심 원칙
- 탐색플랫폼은 docs4에 등록된 센터·강사·상품을 회원앱에서 조회·탐색하는 모바일 채널이다.
- 회원앱은 탐색 UX를 담당하고, 센터/강사/상품/예약/결제의 원천 데이터와 운영 판정은 docs4 정본을 따른다.
- 비로그인 진입을 허용하되 결제·예약·스크랩·메신저·리뷰는 로그인 후 사용 가능.
- 위치 기반 검색·카테고리 필터·강사 프로필·센터 리뷰·스크랩·메신저를 제공한다.

## 2. 상태 / 운영 정의

### 카테고리 14종
헬스 / 요가 / 필라테스 / 골프 / 복싱 / 크로스핏 / PT 전문 / 여성 전용 / 시니어 전용 / 그룹 / 1:1 / 재활 / 다이어트 / 기타

### 스크랩 상태
활성 / 만료 (대상 상품·센터 비활성 시 자동 전환)

### 리뷰 상태 4종
정상 / 신고됨 / 자동 숨김 (3건 신고) / 삭제됨

### 메신저 상태 5종
미열람 / 열람 / 답변 대기 (24시간 SLA) / 답변 완료 / 종료

## 6. 운영 예외 처리
| 케이스 | 처리 방식 | 후속 조치 |
|---|---|---|
| GPS 권한 거부 | "위치 권한이 없습니다. 동·구 직접 입력 가능" | 수동 입력 fallback |
| 검색 결과 0건 | "검색 결과가 없어요" + 다른 카테고리 추천 | - |
| 비로그인 + 예약/스크랩/메신저 시도 | "로그인이 필요해요" 모달 | 로그인 화면 진입 |
| 후기 작성 시도 (미구매 회원) | "이용권을 구매한 회원만 작성 가능" | 차단 |
| 후기 500자 초과 | "500자 이내" | 입력 차단 |
| 본인 후기 신고 시도 | "본인 후기는 신고할 수 없습니다" | 차단 |
| 신고 3건 누적 | 자동 숨김 + "검토 대기" 라벨 | 운영자 검토 |
| 메신저 부적절 메시지 (욕설·스팸 패턴) | 자동 필터 + 발송 차단 | 안내 |
| 스크랩 100건 초과 | "스크랩은 최대 100건" | 초과 차단 |
| 만료 상품·폐점 센터 스크랩 클릭 | "비활성된 항목입니다" + 비활성 표시 | - |
| 강사 프로필 미작성 (탐색 노출 시) | 강사에게 "프로필 작성 요청" 알림 | - |

## 7. CRM 연동 기준
- 센터 마스터: docs4/V1 D10 본사관리 SCR-092 정본
- 강사 마스터: docs4/V1 D07 직원관리 SCR-060 정본
- 상품 마스터: docs4/V1 D05 상품관리 정본
- 결제 / 예약: 결제·예약 발생 시 docs4/V1 D03·D04에 즉시 동기화
- 후기/신고/메신저 이벤트: SCR-097 감사 로그와 NFR-19 알림 기준
- 카테고리 14종: docs4/V1 D05 상품관리 분류를 회원앱 탐색용 라벨로 노출
- 스크랩/즐겨찾기: 회원 선호 이벤트로 저장하되 상품·센터 상태는 docs4 정본 상태를 따른다.
- 비로그인 클릭 로그: 개인 식별 없이 D10 KPI/리포트용 집계만 허용

## 8. 비기능 정책
- 탐색 홈 첫 로딩 < 1.5초
- 지도 1000+ 핀 60fps 유지
- 검색 결과 < 5초
- 이미지 lazy loading + CDN 캐시
- 비로그인 사용자도 동일한 UX 품질
