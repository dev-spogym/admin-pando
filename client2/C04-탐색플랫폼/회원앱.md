# C04-탐색플랫폼 회원앱

> 개발사용 정리 문서입니다.

## 문서 메타
- 전체 화면 수: 10+ (마켓플레이스 발견 영역, MA-3XX)
- 도메인 코드: C04
- 도메인명: 탐색 플랫폼 (Discover Marketplace)
- 역할: member (비로그인 부분 진입 가능)
- 관리자 CRM 정합: 별도 도메인 없음 (회원앱 자체 신규 도메인)

## 도메인 개요
- 회원이 새로운 센터와 강사를 발견하고 탐색하는 마켓플레이스 영역이다.
- 비로그인 회원도 일부 화면(탐색 홈·센터 둘러보기)에 진입 가능하며 결제·예약·스크랩은 로그인 필수.
- 위치 기반 검색·카테고리 필터·강사 프로필·센터 리뷰·스크랩·메신저를 제공한다.
- 회원앱 자체 정본 도메인 (CRM과 데이터 동기화는 회원·결제·예약 시점에만 발생).

## 화면

### MA-300 탐색 홈
- 유형: 탭바 탐색 진입 첫 화면
- 연결 기능: `MFN-301`
- 핵심 영역: 추천 센터·인기 강사·근처 신규 센터·카테고리 바로가기·검색창
- 비로그인 사용자도 진입 가능 (스크랩·예약은 로그인 유도)

### MA-310 내 주변 센터
- 위치 기반 (GPS) 또는 수동 동·구 입력
- 거리순·평점순·신규순 정렬
- 비로그인 사용자도 조회 가능

### MA-311 카테고리 검색
- 카테고리 14종 (헬스·요가·필라테스·골프·복싱·크로스핏·PT 전문·여성 전용 등)
- 필터: 가격대·운영시간·시설 옵션 (샤워실·라커·주차)

### MA-312 센터 상세 (마켓)
- 센터 프로필·이용권 상품·강사 리스트·후기·운영시간·위치 (지도)
- [예약] 또는 [상품 구매] 버튼 → 로그인 유도 또는 C05 결제·주문 흐름

### MA-313 지도 보기
- 지도 + 핀 + 클러스터링
- 핀 탭 → 센터 카드 미리보기

### MA-320 강사 둘러보기
- 강사 카드 리스트 (사진·전문 분야·평점·이력)
- 정렬: 평점·예약 수·신규
- 필터: 전문 분야·지역

### MA-321 강사 상세 (마켓)
- 강사 프로필·소속 센터·이력·자격증·NPS·후기
- [PT 문의] / [예약] → 메신저 또는 예약 화면 진입

### MA-330 스크랩 (즐겨찾기)
- 센터·강사·상품 스크랩 모음
- 로그인 필수

### MA-340 메신저
- 회원 ↔ 센터 운영자 / 강사 1:1 메시지
- CS 문의·예약 사전 협의·견적 요청
- 로그인 필수

### MA-350 센터 리뷰
- 별점 + 후기 작성
- 실제 이용권 구매 회원만 작성 가능 (검증)
- 신고 기능 + 자동 숨김 (3건 누적)

## 핵심 정책

### 컨텍스트 정책
- 회원앱 첫 진입 시 탐색 홈을 노출 (비로그인 사용자도 사용)
- 결제·예약·스크랩·메신저는 로그인 후 가능

### 위치 정책
- GPS 권한 요청은 사용자 명시 동의 후
- 거부 시 수동 동·구 입력으로 fallback
- 위치 데이터는 검색 시점에만 사용, 저장하지 않음

### 카테고리 정책
- 카테고리 14종 (헬스·요가·필라테스·골프·복싱·크로스핏 등)
- 다중 선택 가능
- 카테고리 추가는 본사 관리자만 (회원앱 신규 도메인이므로 CRM에 별도 카테고리 마스터 등록 필요)

### 스크랩 정책
- 로그인 사용자만 가능
- 회원당 최대 100건 (확장 시 무제한)
- 만료된 상품·폐점 센터는 자동 비활성 + 안내

### 메신저 정책
- 회원 ↔ 센터 운영자(Owner/매니저) / 강사 1:1
- 영업시간 외 메시지는 다음 영업일 응답 안내
- 24시간 미응답 시 자동 알림 (운영자에게)
- 신고 기능 + 부적절 메시지 자동 필터

### 리뷰 정책
- 실제 이용권 구매·완료 회원만 작성 가능
- 별점 1~5점 + 후기 (최대 500자)
- 작성 후 24시간 이내 수정·삭제 가능
- 신고 3건 누적 시 자동 숨김 + 운영자 검토

### 비로그인 정책
- 탐색 홈·내 주변·카테고리·센터 상세·강사 상세까지는 비로그인 진입 가능
- 결제·예약·스크랩·메신저·리뷰는 로그인 필수
- 로그인 유도 시 "회원이 되어 더 많은 혜택을 누리세요" CTA

## CRM 연동
- 센터·강사 마스터 데이터는 CRM에서 동기화 (Owner 본인 지점)
- 회원 결제·예약·스크랩 이벤트는 CRM에 즉시 반영
- 비로그인 데이터(검색 통계, 클릭 로그)는 회원앱 자체 BI에 저장

## 비기능 요구
- 탐색 홈 첫 화면 로딩 < 1.5초
- 지도 핀 1000개 이상에서도 60fps 유지 (클러스터링 활용)
- 위치 기반 검색은 사용자 GPS 허용 후 5초 이내 결과 표시
