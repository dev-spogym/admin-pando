# C06-리워드활동 회원앱 — 운영정책

## 1. 핵심 원칙
- 회원앱 리워드·활동 도메인은 회원의 충성도(loyalty) 강화 영역이다.
- 회원 등급 5단계는 docs2 D02 M009 정본을 따른다.
- 마일리지·쿠폰은 docs2 D08 마케팅 정본을 모바일 채널에서 사용한다.
- 활동 이력은 docs2 정본 데이터를 단순 표시하며 자체 수정 권한 없음.

## 2. 상태 / 운영 정의

### 회원 등급 5단계 (docs2 정본)
브론즈 / 실버 / 골드 / 플래티넘 / 다이아몬드

### 마일리지 상태
적립 / 사용 / 만료 (1년 후 자동 만료)

### 쿠폰 상태 4종
활성 / 사용됨 / 만료됨 / 비활성

### 친구 초대 상태
- 초대 전송 / 친구 가입 / 친구 결제 완료 (보상 지급 트리거)

### 미션 상태
진행중 / 완료 / 만료 (매월 1일 갱신)

## 3. 권한·책임 분리
| 역할 | 본 도메인 접근 |
|---|---|
| member | 본인 등급·마일리지·쿠폰·친구 초대·활동 이력 전체 |

## 4. KPI / 성과 측정
| KPI | 산식 | 측정 주기 |
|---|---|---|
| 등급 분포 | 등급별 회원 수 | 월 단위 |
| 마일리지 사용률 | 사용 마일리지 / 적립 마일리지 × 100 | 월 단위 |
| 쿠폰 사용률 | 사용 쿠폰 / 발급 쿠폰 × 100 | 월 단위 |
| 친구 초대 가입률 | 초대 후 가입 / 초대 발송 × 100 | 월 단위 |
| 친구 초대 결제 전환율 | 초대 친구 결제 / 초대 후 가입 × 100 | 월 단위 |
| 미션 완료율 | 완료 미션 / 전체 미션 × 100 | 월 단위 |

## 5. 자동화 정책
| 자동화 | 실행 시점 | 처리 동작 |
|---|---|---|
| 등급 자동 재산정 | 매월 1일 04:00 | 누적 결제·이용 기간·출석 기준 자동 산정 |
| 마일리지 적립 | 결제 완료 즉시 | 1% 적립 (센터 설정) |
| 마일리지 만료 알림 | 만료 30일 전 | 회원 푸시 발송 |
| 마일리지 자동 만료 | 적립 후 1년 | 만료 처리 |
| 쿠폰 만료 알림 | 만료 7일 전 | 회원 푸시 발송 |
| 쿠폰 자동 만료 | 만료일 도달 | 자동 비활성 |
| 미션 자동 갱신 | 매월 1일 00:00 | 새 미션 자동 생성 |
| 미션 완료 보상 지급 | 미션 완료 즉시 | 마일리지/쿠폰 자동 지급 |
| 친구 초대 보상 지급 | 친구 첫 정상 결제 완료 | 마일리지/쿠폰 자동 지급 |
| 등급 변경 알림 | 등급 산정 후 | 회원 푸시 발송 (승급/강등) |

## 6. 운영 예외 처리
| 케이스 | 처리 방식 | 후속 조치 |
|---|---|---|
| 마일리지 사용 시 잔여 부족 | "마일리지가 부족합니다" | 차단 |
| 쿠폰 만료 후 사용 시도 | "만료된 쿠폰입니다" | 차단 |
| 쿠폰 사용 조건 미충족 (최소 결제 금액) | "최소 결제 금액 N원 이상" | 차단 |
| 동일 친구 중복 초대 | "이미 초대한 친구입니다" | 차단 |
| 초대 보상 지급 후 친구 환불 | 마일리지 회수 + 운영자 알림 | 자동 |
| 초대 100명 한도 초과 | "최대 100명까지 초대 가능" | 차단 |
| 미션 완료 보상 지급 실패 | retry 1회 → 운영자 알림 | 자동 재시도 |
| 등급 강등 시 알림 누락 (회원 푸시 권한 거부) | 인앱 알림으로 fallback | - |
| 마일리지 음수 (오류) | 운영자 알림 + 자동 보정 | 자동 |
| 동시 마일리지 사용 (이중 결제 시도) | 멱등성 키로 차단 | - |

## 7. CRM 정합 기준
- 회원 등급: docs2 D02 M009 정본
