# FitGenie 회원앱 개발사용 납품 문서

이 폴더는 회원앱(Mobile App, iOS/Android) 구현을 위해 기존 기획 내용을 개발자가 보기 쉬운 구조로 재정리한 문서입니다. 회원앱 화면 UX는 `client2`를 기준으로 보되, 회원·예약·이용권·결제·출석·마케팅·알림·권한·감사 로그의 원천 데이터와 운영 판정은 `docs4`를 정본으로 따릅니다.

## 사용 방법
- 한 화면을 구현할 때는 해당 도메인의 `{도메인명}.md`와 `운영정책.md`를 우선 확인합니다.
- 공통 권한, 공통 예외, 자동화, 토스트, 디자인 기준은 `_공통/` 문서를 확인합니다.
- API/DB 상세는 백엔드 설계 범위이므로 이 문서에서는 다루지 않습니다.
- 다이어그램은 개발사 요청 범위와 사용자 지시에 따라 납품 문서에서 제외했습니다.
- 정책값이 아직 확정되지 않은 항목은 `_정책미확정_확인필요.md`에서 확인합니다.
- 관리자 CRM과의 데이터 연동 기준은 `_docs4_기획연계.md`를 통해 `docs4`의 동일 도메인 운영정책을 참조합니다.

## 문서 기준
- `client2`는 회원앱 개발사용 납품 문서입니다.
- 화면별 구현 기준은 각 도메인 `{도메인명}.md`의 `UI 구성`, `액션 / 흐름`, `권한`, `필수 예외처리`를 기준으로 합니다.
- 운영 기준은 각 도메인 `운영정책.md`와 `_공통/` 문서를 기준으로 합니다.
- 문서 간 값이 충돌하면 `docs4` 값을 우선하고 `client2`를 그 기준으로 보정합니다.

## 채널 분리 원칙
- 회원앱 role 키는 `member / trainer / golf_trainer / fc / staff` 5종을 사용합니다.
- 관리자 CRM 권한 키 `superAdmin / primary / owner / manager / fc / trainer / staff / readonly` 와 별도로 운영합니다.
- 같은 표기인 `fc`, `staff`도 채널에 따라 접근 범위와 화면이 다르며, 회원앱 문맥에서는 앱 role로만 해석합니다.
- 한 계정은 하나의 역할만 가지며(멀티 역할 없음), 역할은 CRM에서 사전 지정됩니다.

## 생성 범위
- 화면: 회원앱 MA-001 ~ MA-9XX (모든 역할 합산 약 80화면)
- 기능 명세 연결 기준: 8개 도메인 (회원앱.md + 운영정책.md 16개 파일)
- 도메인: 8개
- CRM 연동 기준: `_docs4_기획연계.md`에서 지정한 `docs4` D01~D11 도메인 데이터 동기화

## 관리자 CRM(docs4)과의 정합 기준
회원앱은 관리자 CRM의 모바일 확장이며, 회원·예약·이용권·결제·출석 데이터는 CRM과 동일 기준을 공유합니다. 따라서 다음 정책은 `docs4`를 정본으로 따릅니다.
- 회원 실제 상태 7종(ACTIVE/EXPIRED/SCHEDULED/EXPIRING/HOLDING/UNREGISTERED/WITHDRAWN) — docs4 `_공통/상태전이.md` 정본
- 강습 세션 4종(PT·GX·골프·기타) — docs4/V1 D04 정본
- GX 세부종목 5종(요가·필라테스·스피닝·줌바·GX 기타) — docs4/V1 D05 정본
- 상품 대분류 5종(MEMBERSHIP·LESSON_PASS·LOCKER·WEAR·GENERAL) — docs4/V1 D05 정본
- HQ-09 회원 이용권 만료 step / NFR-05 만료 알림 결과 — docs4/V1 D10 본사관리 + docs4/_공통 정본
- 결제링크 5종 상태(발송됨·결제완료·만료·무효화·발송실패) — docs4/V2 D03 PAY-06 정본
- PAY-06 결제링크 기준안은 고객사 확인 전까지 회원앱에서 노출하지 않음 — docs4 `_정책확인필요.md` 정본

회원앱 화면 동작(QR 스캔, 쌍방서명, 푸시 알림, 딥링크, 오프라인 큐)은 `client2`가 구체화하지만 보안·상태·알림·토스트·감사 로그 기준은 `docs4` 공통 기준을 따릅니다.

## docs4 연계 / docs4 채널 정합 확인

- 모든 회원앱 화면 ID와 기능 코드는 `_docs4_기획연계.md`에서 `docs4 정합 / 부분 정합 / docs4 V2 정합 / docs4 채널 정합`로 분류합니다.
- `docs4 채널 정합` 항목은 별도 CRM 정본을 새로 만드는 것이 아니라, docs4의 회원·상품·수업·매출·마케팅·본사·공통 데이터를 회원앱 채널에서 조회/접수/알림으로 노출하는 항목입니다.
- 새 화면이나 기능을 추가할 때는 먼저 `_docs4_기획연계.md`에 원천 데이터, 운영 판정, 감사 로그, 알림 기준을 연결합니다.
