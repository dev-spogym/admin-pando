# C05-결제주문 회원앱

> 개발사용 정리 문서입니다.

## 문서 메타
- 전체 화면 수: 12 (MA-8XX 결제·주문 통합)
- 도메인 코드: C05
- 도메인명: 결제 · 주문
- 역할: member
- 관리자 CRM 정합 도메인: `docs4/V1/D03-매출관리` (PAY-01 결제 처리), `docs4/V2/D03-매출관리` (PAY-06 결제링크), `docs4/V1/D05-상품관리`

## 도메인 개요
- 회원앱에서 이용권·PT 패키지·일반 상품·구독 결제를 처리하는 도메인이다.
- 결제 수단: 토스페이먼츠 (카드/계좌이체/간편결제) — 직접 결제는 docs4/V1 D03 PAY-01, 결제링크는 docs4/V2 D03 PAY-06 정본을 따른다.
- PAY-06 결제링크는 docs4 _정책확인필요에 따라 고객사 확인 전까지 회원앱에서 노출하지 않으며 본 도메인은 PAY-01 직접 결제만 제공한다.
- 결제 완료 후 이용권 자동 생성, 환불은 CRM 관리자(Owner(지점장)/매니저) 승인 후 처리.
- 모든 결제·환불 데이터는 docs4/V1 D03 매출관리 정본을 공유한다.

## 화면

### MA-800 결제 옵션 선택
- 상품 카탈로그 또는 PT 패키지에서 진입
- 결제 수단 선택 (카드/계좌이체/간편결제)
- 쿠폰 적용 (1장만), 마일리지 사용

### MA-801 장바구니
- 상품 다중 선택 (이용권·일반 상품·운동복 등)
- 수량 조정·삭제
- 총 결제 금액·할인 적용 표시

### MA-810 토스페이먼츠 결제 (외부)
- 토스페이먼츠 SDK 호출
- 결제 성공/실패 콜백 → MA-811 결제 완료 또는 실패 처리

### MA-811 결제 완료
- 결제 결과 + 영수증 PDF 다운로드
- 이용권 자동 생성 안내 ("PT 10회권이 활성화되었습니다")
- "홈으로" / "이용권 보기" CTA

### MA-812 결제 실패
- 실패 사유 안내
- "다시 시도" / "결제 수단 변경" CTA
- 결제 실패는 미수금으로 집계되지 않음 (PAY-06 결제링크 미사용 정합)

### MA-820 주문 / 예약 통합 내역
- 결제 이력 + 진행 중 예약 + 완료 수업
- 시간 역순 정렬, 상태별 필터 (결제완료·환불·진행·완료)

### MA-821 주문 상세
- 단일 결제 건의 상세 (영수증·이용권 정보·환불 가능 여부)
- [환불 요청] 버튼 (조건 충족 시)

### MA-830 환불 요청
- 환불 사유 입력 (필수, 최소 10자)
- 환불 가능 금액 자동 계산 안내 (사용분 차감)
- [요청] 클릭 → CRM 운영자 승인 큐로 전송

### MA-831 환불 진행 상태
- 환불 요청 후 진행 상태 (대기 → 승인 → 환불 완료)
- 거절 시 사유 표시

### MA-840 결제수단 관리
- 등록된 카드 / 계좌 관리
- 기본 결제수단 설정
- 삭제·재등록

### MA-850 영수증 / 세금계산서
- 결제 건별 영수증 PDF
- 세금계산서 발행 요청 (사업자 회원)

### MA-860 구독 / 자동결제
- 구독 상품 관리 (월 자동결제, docs4/V1 D09 설정관리 및 D03 매출관리 기준)
- 자동결제 일시정지·해지

## 핵심 정책

### 결제 정책 (docs4/V1 D03 PAY-01 정합)
- 결제 수단: 토스페이먼츠 (카드/계좌이체/간편결제)
- 한국 시장 전용 (해외 확장 시 결제 모듈 교체 필요)
- 결제 완료 후 이용권 자동 생성 (즉시 활성화)
- 영수증 PDF 자동 발급

### 환불 정책 (docs4/V1 D03 정합)
- 회원이 앱에서 환불 요청 → CRM에서 Owner(지점장)/매니저가 승인
- 환불 자동 계산 산식은 미확정 (docs4 _정책확인필요)
- 사용분 차감금·위약금·기환불 누계·이번 환불 가능액·최종 환불액은 운영자가 수기 입력
- 무분별한 환불 방지를 위해 관리자 승인 필수

### 쿠폰 정책
- 결제 시 1장만 적용 가능 (중복 할인 방지)
- 만료 쿠폰은 자동 비활성
- 쿠폰 + 마일리지 중복 가능

### 마일리지 정책 (D02 정합)
- 결제 금액 1% 적립 (센터 설정)
- 1마일리지 = 1원 사용
- 마일리지는 다른 혜택과 중복 가능 (docs4/V1 D04 정합)
- 마일리지 사용은 회원 명시 선택 시에만 적용

### PAY-06 결제링크 (docs4 _정책확인필요)
- 회원앱에서 결제링크 노출 없음 (PAY-06 운영 확정 전까지 비활성)
- 확정 후 노출 시 회원상세 결제내역 미결제/발송됨 표시값과 정합
- 결제링크는 계약금·잔액·할부 결제에 사용하지 않음

### 영수증 / 세금계산서 정책
- 모든 결제는 영수증 PDF 자동 발급
- 세금계산서는 사업자 회원이 발급 요청 시 자동 생성

### 구독 / 자동결제 정책 (docs4/V1 D09/D03 정합)
- 월 1회 자동결제 (다음 결제일 표시)
- 자동결제 실패 시 grace period 7일
- 일시정지·해지는 회원이 직접 가능

## CRM 연동 기준
- 결제 / 환불: docs4/V1 D03 매출관리 정본
- 이용권 자동 생성: docs4/V1 D05 상품관리 정본
- 영수증·세금계산서: docs4/V1 D03 SCR-S010 정본
- 결제수단 관리: 토스페이먼츠 빌링키, 저장/실패/알림은 docs4 외부연동 EXT-PAY-01 및 D09/D03 기준
- 결제 완료 → 5초 이내 CRM 매출 카드 갱신 (docs4 SCR-S001 정합)
