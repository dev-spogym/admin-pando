# C02-트레이너-골프강사 회원앱 — 운영정책

## 1. 핵심 원칙
- 트레이너와 골프강사는 동일 화면 세트를 공유하되 골프강사는 쌍방서명·레슨 확인서 화면이 추가된다.
- 모든 수업·회원 데이터는 docs4/V1 D04 수업관리·D02 회원관리·D07 직원관리 정본을 따른다.
- 회원앱 role: `trainer` / `golf_trainer` 2종.
- 강사는 본인 담당 수업과 회원만 접근 가능하며, 타 강사 데이터는 read-only 또는 hidden.
- 강습 세션 4종(PT·GX·골프·기타)은 docs4 정본.
- 횟수 차감 시점은 수업 완료(completed)이며 CLS-07 정본.

## 2. 상태 / 운영 정의

### 수업 상태 6종 (docs4/V1 D04 정본)
| 상태 | 설명 | 회원앱 표시 |
|---|---|---|
| 예정 | 등록 후 시작 전 | 회색 배지 |
| 진행중 | 시작 + 출석 1건 | 파랑 |
| 완료 (서명대기) | 종료 + 출석 + 미서명 | 노랑 |
| 완료 + 서명완료 | completed | 녹색 |
| 노쇼 | 시작 + 30분 미체크인 | 빨강 |
| 취소 | 운영자 또는 회원 취소 | 회색 (취소선) |

### 서명 상태 4종
- `미서명` / `강사서명완료` / `회원서명완료(골프)` / `양측서명완료(completed)`

### 원격 서명 만료 단계
- 0~12시간: 대기
- 12시간 경과: 리마인드 자동 푸시
- 24시간 경과: 만료 → 강사 액션 필요

## 3. 권한·책임 분리
| 역할 | 본인 담당 수업 | 타 강사 수업 | 본인 담당 회원 | 타 강사 담당 회원 |
|---|---|---|---|---|
| trainer | 등록·수정·완료·서명 | read-only 또는 hidden (strict_owner 모드) | 조회·체성분 기록·평가 | hidden 또는 read-only |
| golf_trainer | 등록·수정·완료·쌍방서명 | read-only 또는 hidden | 조회·체성분 기록·평가 | hidden 또는 read-only |

회원 데이터 접근 정책은 본인 담당 수업이 1회 이상 있는 회원만 가능합니다 (CRM 매핑 기준).

## 6. 정책 결정 근거
- 화면별 구현 판단은 `UI 구성`, `액션 / 흐름`, `권한`, `필수 예외처리` 순서로 확인한다.
- 골프 쌍방서명은 1회 단가 10~20만원으로 인한 분쟁 방지가 본질이므로, PT/GX와 분리된 정책이다.
- 회원 데이터 접근 범위(본인 담당만)는 데이터 보호와 강사 책임 명확화를 위한 정책이다.
- 정책값이 확정되지 않은 항목은 docs4 `_정책확인필요.md`에 별도 관리한다.

## 7. 운영 예외 처리
| 케이스 | 처리 방식 | 후속 조치 | 연결 기능 |
|---|---|---|---|
| 시작 시간 외 시작 시도 (±15분 범위 외) | "시작 가능 시간이 아닙니다" | 차단 | MFN-204 |
| 출석 체크 없이 완료 시도 | "출석 체크 후 완료 가능" | 차단 | MFN-208 |
| 노쇼 처리 후 출석 정정 | 자동 페널티 해제 + 알림 | 자동 | MFN-213 |
| 골프 원격 서명 12시간 경과 | 리마인드 푸시 자동 발송 | 자동 | MFN-312 |
| 골프 원격 서명 24시간 만료 | 강사 알림 + 재요청 또는 대면 전환 | 강사 액션 | MFN-312 |
| PT 차감 실패 (이용권 만료) | "잔여 횟수가 없습니다" | 운영자 횟수 조정 안내 | MFN-209 |
| 트레이너 타 강사 수업 수정 시도 | hidden 또는 read-only | strict_owner 모드 적용 | MFN-203 |
| 동시 수정 충돌 (낙관적 락) | "다른 사용자가 먼저 처리" | 최신 값 재로드 | MFN-204, MFN-208 |
| 회원 거절 (수업 안 받았다고 주장) | 사유 입력 + 운영자 처리 | 분쟁 처리 | MFN-312 |
| 서명 이미지 저장 실패 | retry 1회 → 운영자 알림 | 재시도 | MFN-209 / MFN-312 |
| 디바이스 정보 캡처 실패 | "재시도해주세요" | 재시도 | MFN-312 |
| 네트워크 단절 (서명 진행 중) | 서명 이미지 임시 저장 + 복구 후 동기화 | 자동 | MFN-209 / MFN-312 |
| QR + 수동 출석 충돌 | 마지막 처리 우선 + 로그 | 자동 | MFN-205 |
| 회원 후기 1~2점 등록 | owner+에게 즉시 알림 + 강사 홈 배지 | NFR-19 알림 | MA-200 |
| 본인 외 수업 캘린더 강제 진입 | 본인 담당만 표시 | hidden | MFN-202 |
| 회원 본인 외 체성분 기록 시도 | "담당 회원만 가능" | 차단 | MFN-222 |

## 8. CRM 정합 기준
회원앱 트레이너/골프강사는 다음 docs4 도메인의 정본 데이터를 참조한다.
- 수업 / 캘린더 / 출석 / 노쇼: docs4/V1 D04 수업관리
- 회원 / 이용권 / 횟수: docs4/V1 D02 회원관리, D05 상품관리
- 강사 정보 / OT 운영: docs4/V1 D07 직원관리, D04 CLS-06
- KPI (NPS·강습세션수): docs4/V1 D10 SCR-094

회원앱 UX 영역:
- 모바일 서명 패드 UX·가로 모드 전환은 회원앱 표시 방식이며 서명 결과와 차감 판정은 docs4/V1 D04 기준을 따른다.
- 원격 서명 푸시·리마인드·만료 흐름은 NFR-19 알림과 D04 서명/수업 완료 기준을 따른다.
- 디바이스 정보 캡처·법적 증거 보관은 SCR-097 감사 로그와 보안 정책 기준을 따른다.
- 강사 일정 표시와 빠른 액션은 회원앱 UX이며 원천 일정은 D04 수업관리 기준을 따른다.
- 알림 푸시 채널·우선순위는 NFR-19와 EXT-MSG-01 기준을 따른다.
