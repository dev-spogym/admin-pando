## 문서 메타
- 전체 화면 수: 19 (트레이너 17 + 골프강사 2)
- 도메인 코드: C02
- 도메인명: 트레이너 · 골프강사
- 역할: trainer / golf_trainer
- 공통 권한: `_공통/권한매트릭스.md`

## 도메인 개요
- 트레이너는 본인 담당 수업과 회원을 관리하는 현장 업무 도구로 회원앱을 사용한다.
- 골프강사는 트레이너 화면 전체를 사용하며 쌍방서명·레슨 확인서가 추가된다.
- 회원앱 role은 `trainer` 또는 `golf_trainer`이며 직원 로그인 → 트레이너 선택으로 진입한다.
- 모든 수업·회원 데이터는 docs4/V1 D04 수업관리·D02 회원관리 정본을 공유한다.
- 강습 세션 4종(PT·필라테스·스트레칭·테라피)은 docs4/V1 D04 정본을 따른다.
- GX 세부종목 6종(요가·필라테스·스피닝·줌바·에어로빅·GX 기타)은 docs4/V1 D05 정본을 따른다.
- 횟수 차감 시점은 수업 완료(completed) 시점이며 CRM CLS-07 횟수 관리 정본을 따른다.

## MA-200 강사 홈 대시보드

> 유형: 화면
> URL 경로: 트레이너 로그인 후 디폴트 (TrainerNavigator의 홈)
> 연결 기능: `MFN-201`

### 1. 목적
트레이너 또는 골프강사가 출근 직후 오늘 수업 현황·담당 회원 알림·완료 미서명 건·NPS 평점을 한 화면에서 파악하는 메인 허브 화면입니다.

### 2. UI 구성
- **상단 인사**: "안녕하세요, {강사명}님"
- **오늘 수업 카드**: 시간순 정렬, 시작 시간·종목·회원명·상태 배지 (예정/진행중/완료/노쇼)
- **요약 카드 4종**: 오늘 수업 N개·완료 N개·노쇼 N건·완료 미서명 N건
- **담당 회원 알림**: 만료 임박 회원·이용권 잔여 1회 회원
- **빠른 액션 4종**: 수업 캘린더·담당 회원 목록·체성분 기록·QR 출석 보조
- **NPS 평점**: 이번 달 평균 별점 (회원 후기 기반)
- **하단 탭바**: 홈 · 회원 · 일정 · 피드백 · MY (5탭)

### 3. 액션 / 흐름
1. 트레이너 로그인 직후 또는 홈 탭 클릭 시 진입.
2. 오늘 수업 카드 클릭 → MA-211 수업 목록 또는 MA-212 수업 시작/완료.
3. 완료 미서명 건 클릭 → 서명 화면 (PT는 강사 서명, 골프는 쌍방서명).
4. 담당 회원 알림 클릭 → MA-220 담당 회원 목록.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 정상 | 오늘 수업 + 회원 알림 정상 표시 |
| 수업 없음 | "오늘 예정된 수업이 없어요" |
| 완료 미서명 강조 | 빨강 배지 + 즉시 처리 안내 |
| 노쇼 발생 | 노쇼 카드 강조 |

### 5. 권한
`trainer` 또는 `golf_trainer`만 진입 가능합니다. `member` / `fc` / `staff`는 본 화면 미진입.

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 수업 시작 30분 전 알림 | 푸시 + 홈 카드 강조 | - |
| 노쇼 자동 처리 (30분 미체크인) | A05 자동 처리 후 알림 | 강사 확인 |
| 네트워크 오류 | 캐시 데이터 + 재시도 | 자동 재시도 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| CRM 수업 시스템 | 화면 진입 | 5분 캐시 |
| 자동 노쇼 A05 | 시작 + 30분 미체크인 | 자동 노쇼 처리 + 페널티 부과 |
| NPS 일일 집계 | 매일 04:00 | 평점 갱신 |
| 만료 임박 회원 (HQ-09) | 매일 03:00 NFR-05 | 담당 회원 알림 |

## MA-212 수업 시작 / 완료 / 서명

> 유형: 화면
> URL 경로: MA-211 수업 목록의 단일 수업 진입
> 연결 기능: `MFN-204` (수업 시작) + `MFN-208` (수업 완료) + `MFN-209` (서명)

### 1. 목적
트레이너가 수업을 시작하고 완료 처리하며 강사 서명(PT/GX) 또는 쌍방서명(골프)을 받는 핵심 현장 화면입니다.

### 2. UI 구성
- **수업 정보 카드**: 일시·종목·회원명·세션 유형(PT/필라테스/스트레칭/테라피)
- **상태 표시**: 예정 → 진행중 → 완료 단계
- **수업 시작 버튼**: 예정 상태에서 활성 (시작 시간 ±15분 범위)
- **출석 체크 토글**: 회원 출석 / 노쇼 / 결석
- **수업 메모 입력**: 자유 텍스트 (선택)
- **수업 완료 버튼**: 출석 체크 후 활성
- **서명 패드**: PT는 강사 단독, 골프는 강사 + 회원 쌍방
- **회원 정보 빠른 보기**: 잔여 횟수·체성분 최근 기록 링크

### 3. 액션 / 흐름
1. MA-211 수업 목록에서 수업 클릭 → 본 화면 진입.
2. **수업 시작 (시작 시간 ±15분)**: [수업 시작] → 상태=진행중 + CRM 동기화.
3. **출석 체크**: 회원이 키오스크 QR로 자동 출석되었거나 강사가 수동 출석 처리.
4. **수업 완료**: 출석 체크 완료 후 [수업 완료] → 서명 단계로 이동.
5. **PT/GX 서명**: 강사 패드에 서명 → 자동 저장 → 수업 상태=completed → CLS-07 횟수 자동 차감.
6. **골프 쌍방서명 (MA-312)**: 강사 서명 → [대면 서명] 또는 [원격 서명 요청] 선택 → 회원 서명 완료 시 confirm → 레슨 확인서 자동 생성.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 예정 | 시작 버튼 활성 (±15분 범위) |
| 진행중 | 완료 버튼 활성, 메모 입력 가능 |
| 완료 - 서명 대기 | 강사 또는 회원 서명 미완료 |
| 완료 + 서명 완료 | 수업 상태=completed, CRM 횟수 차감 |
| 노쇼 | 시작 + 30분 미체크인 → A05 자동 노쇼 |
| 원격 서명 대기 | 골프 - 회원 미서명 (12시간 후 리마인드, 24시간 만료) |

### 5. 권한
`trainer` 또는 `golf_trainer` 본인 담당 수업만 가능합니다. 타 강사 수업은 read-only.

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 시작 시간 외 시작 시도 | "시작 가능 시간이 아닙니다 (±15분)" | 차단 |
| 출석 체크 없이 완료 시도 | "출석 체크 후 완료 가능" | 차단 |
| 노쇼 처리 후 출석 정정 | 자동 페널티 해제 + 알림 | 자동 |
| 골프 원격 서명 12시간 경과 | 리마인드 푸시 자동 발송 | 자동 |
| 골프 원격 서명 24시간 만료 | "서명 만료" 알림 + 재요청 또는 대면 전환 안내 | 강사 액션 |
| PT 차감 실패 (이용권 만료) | "잔여 횟수가 없습니다" 토스트 | 운영자 횟수 조정 안내 |
| 동시 수정 충돌 | "다른 사용자가 먼저 처리" | 최신 값 재로드 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| CRM 수업 시스템 (CLS-01) | 수업 시작·완료 | 캘린더 자동 반영 |
| CRM 횟수 관리 (CLS-07) | 수업 완료 (completed) | PT 횟수 자동 차감 (멱등성 키) |
| 자동 노쇼 A05 | 시작 + 30분 미체크인 | 자동 노쇼 + 페널티 |
| NFR-19 알림 | 골프 원격 서명 요청 | 회원 푸시 발송 |
| 레슨 확인서 PDF 생성 | 골프 쌍방서명 완료 | 서명 이미지 + 타임스탬프 + 디바이스 정보 |
| 감사 로그 (SCR-097) | 수업 등록·완료·서명·노쇼 | actor·lesson_id·before·after 비동기 INSERT |

### 8. 핵심 디자인 요청사항
- 서명 패드는 풀스크린에서 가로 모드 자동 전환
- "수업을 정상 수강했습니다" 문구는 회원 서명 단계에서 강한 강조
- 골프 쌍방서명 후 PDF 자동 생성 안내 모달 표시

## MA-312 수업 완료 쌍방서명 (골프강사 전용)

> 유형: 화면
> URL 경로: MA-212 수업 완료 후 골프강사가 진입
> 연결 기능: `MFN-312`

### 1. 목적
골프 레슨은 1회 단가가 10~20만원으로 높아 분쟁 발생 빈도가 크기 때문에 강사 + 회원 쌍방서명을 필수화하여 법적 증거력을 확보하는 화면입니다.

### 2. UI 구성
- **수업 정보 요약**: 날짜·시간·회원·종목·내용(드라이버 스윙 교정 등)
- **강사 서명 패드**: 가로 모드 풀스크린
- **회원 서명 선택**: [대면 서명] (회원이 옆에 있을 때) / [원격 서명 요청] (회원이 먼저 퇴장)
- **회원 서명 패드**: 회원이 직접 서명 (대면) 또는 회원 앱 푸시 (원격)
- **"수업을 정상 수강했습니다" 문구**: 회원 서명 단계 상단 강조
- **완료 버튼**: 양측 서명 완료 시 활성 + 레슨 확인서 PDF 자동 생성

### 3. 액션 / 흐름
1. MA-212에서 수업 완료 → 강사 서명 입력.
2. [대면 서명] 선택 시 → 디바이스를 회원에게 전달 → 회원이 문구 확인 후 서명 → 완료.
3. [원격 서명 요청] 선택 시 → 회원 앱으로 푸시 발송 → 회원이 알림 → 서명 화면 → 완료.
4. 양측 서명 완료 → 수업 상태=completed + 레슨 확인서 PDF 자동 생성 → CLS-07 횟수 자동 차감.

### 4. 핵심 상태
| 상태 | 설명 |
|---|---|
| 강사 서명 대기 | 강사 서명 패드 표시 |
| 회원 서명 선택 | 대면 / 원격 선택 |
| 대면 서명 진행 | 회원 서명 패드 표시 |
| 원격 서명 대기 | 24시간 카운트다운 표시 |
| 12시간 경과 | 리마인드 자동 발송 |
| 24시간 만료 | 서명 만료 → 강사 액션 필요 |
| 양측 서명 완료 | PDF 생성 + 수업 completed |

### 5. 권한
`golf_trainer`만 진입 가능합니다. 회원은 원격 서명 요청 시 푸시 알림으로만 서명 화면에 진입.

### 6. 필수 예외처리
| 케이스 | 표시 | 후속 조치 |
|---|---|---|
| 강사 서명 미완료 + 완료 시도 | "강사 서명을 먼저 완료해주세요" | 차단 |
| 회원 거절 | "수업을 진행하지 않았습니다" 사유 입력 + 운영자 처리 | 분쟁 처리 |
| 원격 서명 12시간 경과 | 리마인드 푸시 자동 | 자동 |
| 원격 서명 24시간 만료 | 강사에게 "서명 만료" 알림 | 재요청 또는 대면 전환 |
| 디바이스 정보 캡처 실패 | "재시도해주세요" | 재시도 |
| 네트워크 오류 | 서명 이미지 임시 저장 + 복구 후 동기화 | 자동 |

### 7. 연동 / 자동화 참조
| 연계 대상 | 트리거 | 영향 |
|---|---|---|
| 회원 푸시 (FCM/APNs) | 원격 서명 요청 | "[골프 레슨] 강사가 수업 완료 서명을 요청합니다" |
| 서명 리마인드 잡 | 12시간 경과 | 자동 푸시 재발송 |
| 서명 만료 잡 | 24시간 경과 | 강사 알림 + 만료 처리 |
| 레슨 확인서 PDF 생성 | 양측 서명 완료 | 서명 이미지 + 타임스탬프 + 디바이스 정보 |
| 감사 로그 | 서명 등록·만료 | actor·lesson_id·signature 비동기 INSERT |

### 8. 핵심 디자인 요청사항
- 서명 패드 가로 모드 + 풀스크린 자동 전환
- "수업을 정상 수강했습니다" 문구 강조 (회원이 의식적으로 확인하도록)
- PDF 다운로드 버튼은 양측 서명 후에만 활성

## 핵심 정책 (도메인 공통)

### 수업 시작/완료 정책
- 수업 시작은 시작 시간 ±15분 범위에서만 가능
- 출석 체크 후 수업 완료 가능
- 노쇼 자동 처리: 시작 + 30분 미체크인 (A05 정합)
- 횟수 차감: 수업 완료(completed) 시점 (CLS-07 정합)

### 서명 정책 (docs4/V1 D04 정합)
- **일반 PT/GX**: 강사 서명만으로 완료 (1회 단가 3~5만원으로 분쟁 빈도 낮음)
- **골프 레슨**: 강사 + 회원 쌍방서명 필수 (1회 10~20만원으로 분쟁 가능성 높음)
- **서명 만료**: 원격 서명 24시간 (12시간 후 리마인드)
- **서명 저장**: 이미지 + 타임스탬프 + 디바이스 정보 → 법적 증거력 확보

### 노쇼 정책
- 1회: 경고 알림
- 3회 누적: 예약 제한 (센터 설정에 따라 1주/2주)
- 강사가 수동 면제 가능 (사고·질병 등)

### 회원 데이터 접근 정책
- 트레이너/골프강사는 본인 담당 회원만 접근 가능
- 담당 외 회원은 hidden 또는 read-only
- 회원 평가·체성분 기록은 본인 작성 권한 (다른 강사 작성분은 read-only)

### NPS 집계 정책
- 회원이 수업 후기/만족도(MA-126)에서 평점 + 후기 등록
- 매일 04:00 NPS 일일 집계 잡이 강사별 평균 평점 갱신
- 1~2점 등록 시 owner+에게 즉시 알림 (NFR-19)
- D04 SCR-094 KPI 대시보드 강사 NPS와 동일 데이터 (1:1 매칭)

### OT 운영 정책 (CLS-06 정합)
- OT 1차/2차 배정, 완료, 거절(거부+보류 합산), 이월 관리
- MA-240 강사 근무현황에 OT 지표 표시
- D04 SCR-094 KPI의 트레이너별 OT 합계와 1:1 매칭
