# 회원앱 토스트 메시지 표준

> 회원앱(FitGenie)에서 사용하는 토스트 메시지 패턴과 문구입니다. docs2 `_공통/토스트_메시지.md`와 어미 정합을 맞춥니다.

## 1. 토스트 종류 4종

| 종류 | 색상 | 자동 dismiss | 사용 케이스 |
|---|---|---|---|
| 성공 | 녹색 | 3초 | 저장·등록·완료 |
| 정보 | 파랑 | 5초 | 안내·진행 상태 |
| 경고 | 노랑 | 5초 | 주의 필요·일부 실패 |
| 오류 | 빨강 | 5초 (또는 사용자 dismiss) | 실패·차단 |

## 2. 어미 정책

회원앱은 **`~되었어요` 친근체**를 기본으로 합니다. 다만 일부 시스템 / 보안 / 결제 같은 격식 필요 영역에서는 `~되었습니다`를 사용합니다. 같은 도메인 내에서는 어미를 일관되게 유지합니다.

| 영역 | 어미 | 예시 |
|---|---|---|
| 일반 회원 영역 (홈·예약·이용권·체성분·후기) | ~되었어요 | "예약되었어요" |
| 결제 / 환불 / 세금계산서 | ~되었습니다 | "결제되었습니다" |
| 시스템 / 보안 | ~되었습니다 | "비밀번호가 변경되었습니다" |
| 강사용 화면 (수업 시작·완료·서명) | ~되었어요 | "수업 완료되었어요" |
| FC 상담 | ~되었어요 | "상담이 등록되었어요" |

|---|---|

## 5. 토스트 사용 원칙

- 짧고 명확하게 (1~2줄 권장, 최대 40자)
- 단답형 + 친근체 (회원앱 대상이므로)
- 결제·보안·시스템은 격식 (`~되었습니다`)
- 일반 영역은 친근 (`~되었어요`)
- 동일 작업의 토스트 어미는 도메인 내 일관되게 유지
- 오류 토스트는 사용자 dismiss 옵션 제공 (확인 후 닫기)
- 같은 토스트 1초 내 중복 발생 시 마지막 1건만 표시 (디바운스)
