# 회원앱 상태전이 정의

> 회원앱(FitGenie)에서 사용되는 모든 상태값을 한 자리에서 정의합니다. docs2 `_공통/상태전이.md` 정본을 따르되 회원앱 컨텍스트에서 추가 상태(예약 단계·서명·푸시·오프라인 큐 등)를 함께 정의합니다.

## 1. 회원 실제 상태 (docs2 정본 7종)

| code | 한글 | 설명 |
|---|---|---|
| ACTIVE | 활성 | 이용권 유효 + 정상 출석 가능 |
| EXPIRED | 만료 | 이용권 종료일 도달 |
| SCHEDULED | 예정 | 만료일 D-30 ~ D-8 |
| EXPIRING | 임박 | 만료일 D-7 ~ D-Day |
| HOLDING | 홀딩 | 일시 정지 (기간제, 7~30일) |
| UNREGISTERED | 미등록 | 일부 정보만 들어와 있고 정식 등록 미완 |
| WITHDRAWN | 탈퇴 | 운영자 탈퇴 처리 완료 |

한국어 라벨 한 줄 요약: 활성 / 만료 / 예정 / 임박 / 홀딩 / 미등록 / 탈퇴.

회원 제한 플래그 `정지`는 실제 회원 상태값이 아니며 현재 상태 위에 추가되는 플래그입니다. 회원앱은 본래 상태 + 정지 배지로 함께 표시합니다.

## 2. 출석 결과 (docs2 정본 3종)

| code | 한글 | 설명 |
|---|---|---|
| SUCCESS | 성공 | 정상 출석 (CRM 자동 차감) |
| FAILURE | 실패 | 만료·미등록·미수금 차단·정지·페널티·중복 외 차단·허용 시간 외 |
| DUPLICATE | 중복 | 동일 회원 10분 이내 재시도 (별도 카운트) |

퇴실 이벤트는 출석 결과와 별개 이벤트로 기록됩니다.

## 3. 예약 상태 (회원앱 정본 5종)

| code | 한글 | 설명 |
|---|---|---|
| PENDING_APPROVAL | 승인 대기 | 회원이 트레이너에게 요청 (강사 승인 필요) |
| CONFIRMED | 확정 | 예약 완료 |
| IN_PROGRESS | 진행중 | 수업 시작 + 출석 1건 |
| COMPLETED | 완료 | 수업 완료 + 서명 (PT/GX) 또는 양측 서명 (골프) |
| CANCELLED | 취소 | 회원 또는 강사 취소 |
| NOSHOW | 노쇼 | 시작 + 30분 미체크인 (A05 자동) |

## 4. 수업 서명 상태 (골프강사 정본 4종)

| code | 한글 | 설명 |
|---|---|---|
| NONE | 미서명 | 수업 완료 + 서명 없음 |
| TRAINER_SIGNED | 강사서명완료 | 강사만 서명 |
| MEMBER_SIGNED | 회원서명완료 | PT는 회원만 (불가), 골프는 강사 + 회원 서명 가능 |
| BOTH_SIGNED | 양측서명완료 | 골프 쌍방서명 완료 (completed) |

원격 서명 단계:
- 0~12시간: 대기 (회원 푸시 발송)
- 12시간 경과: 리마인드 자동 푸시
- 24시간 경과: 만료 (강사 액션 필요)

## 5. 결제 상태 (docs2 D03 정합)

| code | 한글 | 설명 |
|---|---|---|
| PENDING | 대기 | 결제 시작 전 |
| IN_PROGRESS | 결제중 | 토스페이먼츠 호출 |
| COMPLETED | 결제완료 | 결제 성공 + 이용권 자동 생성 |
| FAILED | 결제실패 | 토스 실패 응답 |
| REFUND_REQUESTED | 환불요청중 | 회원이 환불 신청, 운영자 승인 대기 |
| REFUND_APPROVED | 환불승인됨 | 운영자 승인, 처리 진행 |
| REFUNDED | 환불완료 | 환불 처리 완료 |
| REFUND_REJECTED | 환불거절 | 운영자 거절 |

## 6. 결제링크 상태 (docs2 PAY-06 정본 5종, 회원앱 노출 대기)

| code | 한글 | 설명 |
|---|---|---|
| SENT | 발송됨 | 링크 발송 완료, 회원 결제 대기 |
| PAID | 결제완료 | 회원이 결제 완료 |
| EXPIRED | 만료 | 7일 경과 자동 만료 |
| INVALIDATED | 무효화 | 운영자 수동 무효화 |
| FAILED | 발송실패 | 전송 단계 실패 |

회원앱 노출은 docs2 _정책미확정 확정 후로 보류됩니다.

## 7. 이용권 상태 (docs2 D02/D05 정합)

| code | 한글 | 설명 |
|---|---|---|
| ACTIVE | 활성 | 정상 사용 가능 |
| EXPIRING | 임박 | 만료 D-7 ~ D-Day |
| EXPIRED | 만료 | 종료일 도달 또는 잔여 0회 |
| HOLDING | 홀딩 | 일시 정지 |
| CANCELLED | 취소 | 환불 처리 완료 |

## 8. 푸시 알림 상태 (회원앱 정본 5종)

| code | 한글 | 설명 |
|---|---|---|
| SENT | 발송됨 | 푸시 발송 완료 |
| DELIVERED | 도착됨 | 디바이스 도착 |
| READ | 읽음 | 회원 알림센터 열람 |
| ACTIONED | 액션 수행 | 회원이 알림 클릭 → 화면 진입 |
| FAILED | 발송실패 | FCM/APNs 실패 |

## 9. 오프라인 큐 상태 (회원앱 정본 4종)

| code | 한글 | 설명 |
|---|---|---|
| QUEUED | 큐잉 | 오프라인 시 큐에 저장 |
| SYNCING | 동기화 중 | 네트워크 복구 후 자동 동기화 |
| SYNCED | 동기화 완료 | 백엔드 응답 성공 |
| FAILED | 실패 | 동기화 실패 → retry 또는 회원 알림 |

## 10. 리드 상담 단계 (docs2 D08 정본 7종)

신규 / 연락완료 / 상담예정 / 방문완료 / 등록완료 / 미전환 / 보류

`등록완료`는 조회 필터에만 포함, FC가 수동 저장 불가 → 첫 정상 결제 완료 이벤트 시 자동 확정.

## 11. 리뷰 상태 (회원앱 정본 4종)

정상 / 신고됨 / 자동 숨김 (3건 신고) / 삭제됨 (soft delete)

## 12. 쿠폰 상태 (docs2 D08 정합 4종)

활성 / 사용됨 / 만료됨 / 비활성

## 13. 회원 자동 세그먼트 (docs2 D02 정본 7종)

신규 / 이탈위험 / 만료임박 / 충성 / 활발 / 관심필요 / 만료후미등록

우선순위: 이탈위험 > 만료임박 > 신규 > 활발 > 관심필요 > 만료후미등록 (단일 표시).
`충성`은 보조 라벨로 다른 라벨과 동시 표시 가능.

## 14. 회원 등급 (docs2 D02 M009 정본 5단계)

브론즈 / 실버 / 골드 / 플래티넘 / 다이아몬드

## 15. 상품 대분류 (docs2 D05 정본 5종)

라벨 한 줄 요약: 회원권 / 수강권 / 락커 / 운동복 / 일반.

| 코드 | 라벨 |
|---|---|
| MEMBERSHIP | 회원권 |
| LESSON_PASS | 수강권 (lessonType: PT/GX/골프/기타) |
| LOCKER | 락커 |
| WEAR | 운동복 |
| GENERAL | 일반 |

## 16. GX 세부종목 (docs2 D05 정본 6종)

요가 / 필라테스 / 스피닝 / 줌바 / 에어로빅 / GX 기타

GX 상품은 `category=LESSON_PASS`이고 `lessonType=GX`일 때 `subCategory`로 6종 중 하나 필수.

## 17. 강습 세션 유형 (docs2 D04 정본 4종)

PT / 필라테스 / 스트레칭 / 테라피

## 18. 상태전이 흐름 (메인)

### 회원 등록 흐름
```
미등록 → 활성 (정상 결제 완료 시)
활성 → 만료예정 → 만료임박 → 만료
활성 → 홀딩 → 활성 (해제 시)
활성/만료 → 탈퇴
```

### 예약 흐름
```
신청 → 승인대기(트레이너 대상) 또는 확정(일반)
확정 → 진행중 (시작 + 출석)
진행중 → 완료 (서명) → completed
확정 → 취소 (마감 전)
확정 → 노쇼 (시작 + 30분 미체크인)
```

### 결제 흐름
```
대기 → 결제중 → 결제완료 → (이용권 자동 생성)
결제완료 → 환불요청중 → 환불승인됨 → 환불완료
환불요청중 → 환불거절
```

### 골프 쌍방서명 흐름
```
수업 완료 → 강사 서명 → 회원 서명 선택
  ├─ 대면 서명: 즉시 회원 서명 → BOTH_SIGNED (completed)
  └─ 원격 서명: 회원 푸시 → 12시간 리마인드 → 24시간 만료
       ├─ 회원 서명: BOTH_SIGNED
       └─ 만료: 강사 재요청 또는 대면 전환
```
