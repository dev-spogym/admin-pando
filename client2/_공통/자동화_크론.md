# 회원앱 자동화 / 크론

> 회원앱(FitGenie)에서 사용하는 자동화 트리거·크론 배치 목록입니다. docs4 `_공통/자동화_크론.md`, NFR-19 알림, 상태전이, 외부연동 기준과 정합합니다. 푸시·QR·오프라인 큐·딥링크는 회원앱 UX이지만 운영 판정과 이력 기준은 docs4를 따릅니다.

## 1. 인증 / 세션

| 자동화 | 실행 시점 | 처리 동작 | 도메인 |
|---|---|---|---|
| 푸시 토큰 갱신 | 로그인 시점 + 24시간 주기 | FCM/APNs 토큰 백엔드 등록 | C01 / C08 |
| JWT 토큰 갱신 | 만료 5분 전 | refresh 토큰으로 자동 갱신 | C08 |
| 비밀번호 만료 알림 | 만료 7일 전 | 회원 푸시 발송 | C01 |
| 5회 연속 인증 실패 | 즉시 | 30분 일시 잠금 | C01 |
| 30분 미사용 자동 로그아웃 | 백그라운드 30분 | 토큰 무효화 + 재로그인 안내 | C08 |
| 직원 퇴사 처리 (CRM) | CRM 처리 시점 | 다음 로그인 시 자동 로그아웃 + 토큰 무효화 | C08 |
