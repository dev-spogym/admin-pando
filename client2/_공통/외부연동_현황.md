| 항목 | 정책 |

| 인증 | JWT (만료 1시간 + refresh 토큰) |

## 11. 정합 한 줄 요약 (회원앱 정본)

- **출석 인증 수단 4종**: 밴드 / QR코드 / 얼굴 인식 / 핀번호. 기기 종류 4종(출입 게이트·키오스크·락커 컨트롤러·InBody 측정기)과 별개 축이며 docs2 D09 정합.
- **알림 3채널**: 푸시(FCM/APNs) / SMS(PASS/NHN/통신사) / 인앱. NFR-05 알림 결과 동기화 정본을 따른다.
- **A05 자동 노쇼 정책**: 출석 인정 마감 + 지점 노쇼 유예 N분(**기본 30분**). N분 미설정 시 자동 노쇼 보류 (docs2 D04 CLS-11/CLS-14 정합).
- **회원 알림함 (보관함)**: 회원이 받은 푸시/SMS/인앱 알림은 회원앱 알림함(MA-151)에 자동 저장된다. 결제·이용권·예약·페널티·공지 5 카테고리별 필터 + 미확인 수 배지 + 90일 보존(이후 자동 삭제).
- **키오스크 fallback**: QR 미동작 시 회원은 핀번호 입력으로 대체 출석할 수 있다. docs2 D09 IoT 정합 — 출입 게이트·키오스크는 회원앱과 별도로 핀번호 입력 화면을 제공.
- **회원 홈 KPI 카드 (MA-100)**: 회원 홈은 오늘 출석 여부·이용권 잔여(횟수/일수)·다음 예약·미확인 알림 수 4종을 KPI 카드로 1화면 요약 표시한다.
- **이용권 자동 연장 (자동결제 기반)**: 자동결제 등록된 회원의 만료 임박 이용권은 약정일에 자동 연장되며, 실패 시 grace period 7일(C05 자동결제 정합) + 회원 알림 + 이용권 일시정지 처리한다.
- **CRM 화면 직접 노출 금지**: 회원앱은 본인 영역만 노출하며, docs2 SCR-XXX(CRM 관리자 화면)을 회원앱에 직접 임베드하거나 노출하지 않는다. 운영자 액션(환불 승인·페널티 부과·FAQ 등록·신고 검토)은 CRM 백오피스 위임이며 회원앱은 결과만 표시한다.
- **결제 종류 4분류 (docs2 D03 정합)**: 선결제 / 후결제 / 자동결제 / 미수금. 회원앱은 본인 결제 건만 노출하며 분류 배지로 시각 구분한다.
- **결제 취소 vs 환불 차이**: 결제 취소는 결제 당일 100% 원복(이용권 미사용 + 무료 취소), 환불은 사용분 차감 + 위약금 산정 후 운영자 승인 시 토스 환불 처리(docs2 D03 정합). 회원앱 환불 요청(MA-430)은 후자 흐름이다.

## 12. 핵심 사용자 여정 (전사 흐름 요약)

- **회원 온보딩**: 가입 → 본인 인증 → 이용권 발급 → QR 입장 (MA-001 → MA-002 → MA-100 → MA-110).
- **수업 사이클**: 예약 → 수업 → 출석 → 자동 차감 (MA-120 → MA-110 → CRM 자동 차감 CLS-07).
- **결제 사이클**: 결제 → 이용권 자동 생성 → 활성화 (MA-410 → 백엔드 INSERT → MA-131).
- **환불 사이클**: 환불 요청 → 운영자 승인 → 자동 환불 (MA-430 → CRM 운영자 승인 → 토스 환불 → 회원 알림).
- **자동결제 사이클**: D-3 알림 → 자동결제 → 실패 시 grace 7일 (push → 자동결제 → 미결제 시 일시정지).

## 13. 모니터링 / SLA

- **푸시 발송 성공률** (docs2 NFR-05 정합): FCM/APNs/카카오 알림톡 발송 결과를 CRM에 동기화하여 발송 성공률·실패 사유를 집계한다. 실패율 5% 초과 시 운영자 알림.
- **출석 성공률**: QR 스캔 시도 대비 SUCCESS 비율을 KPI로 집계. 90% 미만 시 키오스크/게이트 점검 알림.
- **결제 성공률 (토스 SLA 정합)**: 토스페이먼츠 SDK 응답 성공률을 집계. 95% 미만 5분 지속 시 운영자 알림.
- **에러 / 크래시 리포트**: Sentry 또는 Crashlytics로 회원 PII 자동 제외 후 수집 (디바이스 ID·OS·앱 버전·스택 트레이스만 포함).

## 14. 추가 보안 정책 (모바일)

- **SSL pinning (인증서 고정)**: 회원앱 ↔ 백엔드 통신은 SSL pinning을 적용하여 중간자 공격을 차단.
- **root / jailbreak 차단**: rooted Android 또는 jailbroken iOS는 회원앱 실행 차단 + "보안 정책상 사용 불가" 안내.
- **세션 만료 자동 로그아웃**: JWT 만료(1시간) 후 refresh 실패 시 자동 로그아웃 + MA-001 진입.
- **비밀번호 정책**: 최소 8자 + 영문/숫자 혼합 + 특수문자 1자 이상 권장. 3회 연속 실패 시 5분 잠금.
