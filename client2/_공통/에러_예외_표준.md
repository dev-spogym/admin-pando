# 회원앱 에러 / 예외 표준

> 회원앱(FitGenie)에서 공통적으로 사용하는 에러 코드·메시지·후속 액션 표준입니다.

## 1. HTTP 응답 코드별 처리

| 코드 | 의미 | 회원앱 처리 | 후속 |
|---|---|---|---|
| 200 | 정상 | 정상 흐름 | - |
| 201 | 생성 완료 | 성공 토스트 | 목록 갱신 |
| 400 | Bad Request | 인라인 에러 + 입력값 보존 | 사용자 재입력 |
| 401 | 인증 필요 | 토큰 갱신 시도 → 실패 시 로그인 화면 | 자동 처리 |
| 403 | 권한 없음 | "권한이 없어요" 토스트 | 변경 안 됨 |
| 404 | 데이터 없음 | 빈 상태 안내 | - |
| 409 | 충돌 (낙관적 락) | "다른 사용자가 먼저 처리" + 최신 값 재로드 | 사용자 선택 |
| 422 | 검증 실패 | 인라인 에러 (필드별) | 사용자 재입력 |
| 429 | Rate Limit | "잠시 후 다시 시도해주세요" | 자동 대기 후 재시도 |
| 500 | 서버 오류 | "서버 오류가 발생했습니다" + 재시도 | 자동 재시도 1회 |
| 503 | 서비스 점검 | MA-920 점검 화면 | 복구까지 대기 |

## 3. 에러 표시 위치 표준

| 에러 유형 | 표시 위치 | 색상 |
|---|---|---|
| 입력 검증 (인라인) | 입력 필드 아래 | 빨강 |
| 토스트 (일시적) | 화면 상단 | 빨강 / 노랑 / 녹색 / 파랑 |
| 모달 (블로킹) | 중앙 정렬 | 흰 배경 + 강조 색 |
| 풀스크린 (네트워크·점검) | 전체 화면 | 회색 + CTA |
| 인앱 알림 | 알림센터 | 카테고리별 |

## 4. 자동 재시도 정책

| 케이스 | 정책 |
|---|---|
| 네트워크 5xx | 자동 1회 재시도 (1초 대기) |
| 토스 timeout | 자동 1회 재시도 (3초 대기) |
| 푸시 토큰 등록 실패 | retry 3회 (30초 간격) → 운영자 알림 |
| 서명 이미지 저장 실패 | retry 1회 → 운영자 알림 |
| 오프라인 동기화 | 네트워크 복구 시 즉시 재시도 |
| Rate Limit 429 | 자동 대기 후 재시도 (응답 헤더 Retry-After 준수) |

## 5. 에러 리포트 정책

- 충돌 시 Sentry / Firebase Crashlytics 자동 전송
- 회원 PII 자동 제외 (디바이스 ID·OS·앱 버전·스택 트레이스만 포함)
- 운영자 알림은 1일 1회 요약 (회원앱 자체 BI 대시보드)
- 동일 에러 1시간 내 100회 발생 시 운영자 즉시 알림 (NFR-19)
