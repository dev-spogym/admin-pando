# 회원앱 디자인 시스템

> 회원앱(FitGenie)의 디자인 토큰·컴포넌트·UX 원칙입니다. docs4 `_공통/디자인_시스템.md`(웹 CRM)와는 분리된 모바일 디자인 시스템이며 다크 모드를 기본 지원합니다.

상태 색상 토큰 한 줄 요약 (4종 시맨틱): **Primary / Success / Warning / Error** (Error = `--danger`). 이 4종 외 보조 토큰(secondary/info)은 부속 컬러로 사용한다.

## 2. 컴포넌트 카탈로그

### 버튼 (Button)
| 종류 | 사용 케이스 |
|---|---|
| Primary | 메인 CTA (결제·예약·로그인) |
| Secondary | 보조 액션 (취소·되돌아가기) |
| Destructive | 삭제·환불·탈퇴 (빨강 톤) |
| Ghost | 약한 강조 (텍스트만) |
| Icon Button | 아이콘 단독 (X·뒤로가기·공유) |

### 입력 필드 (Input)
| 종류 | 사용 케이스 |
|---|---|
| Text | 일반 텍스트 입력 |
| Password | 비밀번호 (가림/보임 토글) |
| Search | 검색 (디바운스 300ms 기본) |
| Number | 숫자 키패드 호출 |
| Phone | 전화번호 (자동 하이픈) |
| Date | 날짜 선택 (네이티브 picker) |
| Time | 시간 선택 |
| Textarea | 다줄 입력 (자동 높이) |

### 카드 (Card)
| 종류 | 사용 케이스 |
|---|---|
| Standard | 일반 정보 카드 |
| Action | 클릭 가능 카드 (호버/터치 효과) |
| Image | 이미지 중심 (상품·강사) |
| Stat | 통계 / 카운트 |
| Empty | 빈 상태 (안내 + CTA) |

### 탭바 (Tab Bar)
- 회원 / 강사 / FC / 스태프 별 5탭 구성
- 활성 탭은 Primary 색상 + 아이콘 채우기
- 미확인 알림은 빨강 배지 (숫자 99+ 표시)

### 모달 (Modal)
| 종류 | 사용 케이스 |
|---|---|
| Confirm | 확인 / 취소 (삭제·환불 확인) |
| Alert | 단일 확인 (안내) |
| Bottom Sheet | 옵션 선택 / 액션 메뉴 |
| Full Screen | 서명 패드 / QR 표시 / 카메라 |

### 토스트 (Toast)
docs4와 어미 분리. 자세한 내용은 `_공통/토스트_메시지.md` 참조.

### 로딩 (Loading)
- 스피너 (인라인 / 풀스크린)
- 스켈레톤 (목록 / 카드)
- 진행률 바 (파일 업로드 / 결제)

## 3. 딥링크 (Deep Link)

### URL 스킴
```
fitgenie://
```

### 핵심 딥링크 경로
| 경로 | 도착 화면 | 용도 |
|---|---|---|
| `fitgenie://home` | MA-100 홈 | 푸시·외부 진입 |
| `fitgenie://qr` | MA-110 QR 입장 | 빠른 QR 호출 |
| `fitgenie://reserve/:lessonId` | MA-121 예약 상세 | 예약 푸시 |
| `fitgenie://lesson-complete/:lessonId` | MA-212 수업 완료 | 강사 푸시 |
| `fitgenie://sign/:signatureRequestId` | MA-312 골프 원격 서명 | 골프 서명 요청 푸시 |
| `fitgenie://refund/:paymentId` | MA-830 환불 요청 | 환불 알림 |
| `fitgenie://invite/:inviteCode` | MA-730 친구 초대 | 친구 초대 링크 |
| `fitgenie://notice/:noticeId` | MA-152 공지사항 상세 | 공지 알림 |

앱 미설치 시 App Store / Google Play로 자동 fallback (Universal Links / App Links).

## 4. 접근성 (Accessibility)

- 색상 대비 WCAG AA 이상 (4.5:1)
- 모든 버튼·아이콘에 `accessibilityLabel` 제공
- 동적 폰트 크기 지원 (iOS Dynamic Type, Android Scale)
- VoiceOver / TalkBack 호환
- 색맹 친화 (색상만으로 정보 전달 금지, 아이콘·텍스트 병기)
- 터치 영역 최소 44x44pt
- 키보드 입력 가능 (외장 키보드 사용자 고려)

## 5. 다크 모드

- OS 설정 자동 추적 (앱 진입 시 OS theme 감지)
- 회원이 명시적으로 라이트/다크 선택 가능 (MA-155 설정)
- 모든 색상 토큰은 라이트/다크 변형 제공
- 이미지 / 아이콘은 다크 모드 대응 변형 사용 (또는 자동 invert)

## 6. 모션 / 애니메이션

| 종류 | 지속 시간 | easing |
|---|---|---|
| 화면 전환 | 250ms | ease-out |
| 모달 표시 | 300ms | ease-out |
| 토스트 표시 | 200ms | ease-in-out |
| 풀투리프레시 | 시스템 기본 | - |
| 스와이프 (탭 전환) | 200ms | ease-out |

## 7. 화면 회전

- 기본: 세로 모드 고정 (Portrait)
- 풀스크린 모달 (서명 패드·QR): 가로 모드 허용 또는 강제

## 8. 안전 영역 (Safe Area)

- 모든 화면은 iOS Safe Area / Android Insets 준수
- 노치·홈 인디케이터·키보드를 가리지 않도록 padding 자동
- 풀스크린 모달은 Safe Area를 무시 가능

## 9. 다국어 / i18n

- 기본 언어: 한국어 (ko_KR)
- 지원 예정: 영어 (en_US), 일본어 (ja_JP)
- 모든 문구는 i18n 키로 관리
- 날짜·시간·통화는 locale에 맞춰 포맷팅

## 10. 디자인 거버넌스

- 디자인 토큰·컴포넌트는 docs4 본사 디자인 시스템과 매핑 (브랜드 일관성)
- 모바일 컴포넌트(탭바·BottomSheet·서명 패드·QR)는 회원앱 UX로 구체화하되 색상·간격·토스트·접근성 기준은 docs4 디자인 시스템을 따른다.
- 디자인 변경 시 본 문서 동시 갱신 필수
- 디자인 토큰은 Figma + Style Dictionary 자동 동기화
